Computer setup

Make the computer ready before the player.

Most connection problems come from the driver, permissions, cable, or timing. Windows needs the MediaTek driver installed. Linux needs the right USB permissions. Find your platform below.

Get Updater CETroubleshooting

Windows

  1. Download the MediaTek driver installer below.
  2. Run the installer and allow Windows to install the driver.
  3. Restart the computer.
  4. Open Updater CE and wait for the connect prompt before you plug in the powered-off player.

Some Windows systems block the driver through Core isolation (Memory integrity). If Updater CE still cannot see the player after a restart, turn Memory integrity off in Windows Security, restart, and reinstall the driver. Turn the setting back on when you are finished if your system allows it.

Windows won't launch the app? If Windows Security or Smart App Control stops Updater CE from opening, open Settings (press Win + I) → Privacy & security → Windows Security → App & browser control → Smart App Control settings and set it to Off. Smart App Control is currently impacting popular applications like the Epic Overlay Service (used by Fortnite) — Updater CE is safe and verified to use. To re-enable later, set VerifiedAndReputablePolicyState to 1 (On) or 2 (Evaluation Mode) under HKEY_LOCAL_MACHINE\SYSTEM\CurrentControlSet\Control\CI\Policy in Registry Editor.

Linux USB permissions

Linux needs your user account to be allowed to talk to the MediaTek USB chip inside the player. Updater CE usually sorts this out during install, and the same permission covers SP Flash Tool, so treat this as a fix-it step rather than a normal stage.

  1. Run Updater CE as your normal user, not as root. The installer asks for administrator access only when it needs it.
  2. Check the player is seen at all. Power the player off, connect the cable, and run the lsusb command in a terminal. A connected player shows up as a MediaTek device with the vendor ID 0e8d.
lsusb
  1. If it appears in lsusb but Innioasis Updater CE or SP Flash Tool says permission denied or cannot open the port, your user is missing access to the USB device. The same udev rule covers both tools, so add one that lets the users group read it.
SUBSYSTEM=="usb", ATTR{idVendor}=="0e8d", MODE="0666", GROUP="plugdev"

Save that line to a new file named /etc/udev/rules.d/51-innioasis.rules, then run:

sudo udevadm control --reload && sudo udevadm trigger
  1. Unplug the player fully, plug it back in, and try the install again.
  2. If SP Flash Tool reports a serial permission or port race, unplug fully and reconnect only when prompted.
Do not improvise flash offsets.If you move to a manual recovery tool, use the files and model-specific configuration shipped with the project.

Cable and timing

  1. Use a known USB data cable.
  2. Avoid hubs while troubleshooting.
  3. Power the correct model fully off.
  4. Connect only at the prompt.
