Zainstaluj lub przywróć go za pomocą narzędzia Updater

Set up the computer first, then let Updater prepare the model-matched package.

  1. Otwórz Innioasis Updater CE na swoim komputerze (jeśli potrzebujesz aplikacji, Pobierz Updater CE). Zestaw Model urządzenia do Y2.
  2. Wybierz Oprogramowanie oryginalne oraz wydanie Y2.
  3. Kliknij Zainstaluj / Przywróć.
  4. Wyłącz i podłącz Y2 tylko wtedy, gdy pojawi się monit na żywo.

Można użyć ręcznych pakietów pełnej instalacji rom_y2.zip. Nie traktuj Y1 rom.zip jako substytut.

Najczęstsze pytania

Can I return from Rockbox or another custom software?

Użyj tego samego procesu przywracania Y2: wybierz Y2, wybierz Oryginalne oprogramowanie i postępuj zgodnie z monitem o połączenie. Nie mieszaj plików modeli.

Dlaczego pakiet Y2 wygląda inaczej?

Wydania Y2 mogą używać innej nazwy pakietu i wpisu wydania. Wybierz Y2 w Aktualizatorze, zamiast zgadywać na podstawie ręcznej nazwy pliku ZIP.

Co się stanie, jeśli gracz nie zostanie wykryty?

Sprawdź kabel do transmisji danych, uprawnienia komputera lub sterowniki oraz synchronizację. Podłącz wyłączony Y2 dopiero po tym, jak Updater poinformuje, że jest gotowy.

Potrzebujesz listy kontrolnej odzyskiwania?

Postępuj zgodnie z całością Y2 samouczek przywracania, a następnie otwórz rozwiązywanie problemów jeśli aplikacja zgłosi awarię.
