SP Flash Tool внутри Innioasis средства обновления CE

SP Flash Tool не является отдельной загрузкой, и в папке приложения ничего нет. Это метод установки Innioasis Updater CE на компьютеры Windows x64 и Linux x86-64 с процессорами Intel или AMD. Выберите свою прошивку обычным способом, затем установите Показать дополнительные настройки > Способ установки > SP Flash Tool и установить.

Выберите прошивку, затем выберите движок

Установка в Updater CE всегда выполняется по одному и тому же пути: выберите свою модель, выберите прошивку и версию, затем запустите «Установить/Восстановить». Метод установки только решает, какой механизм MediaTek выполняет перепрошивку. Оставь это включенным Авто если у вас нет причины закрепить его и установить для него значение SP Flash Tool когда ты это делаешь.

На каких компьютерах есть SP Flash Tool

MediaTek публикует SP Flash Tool только для x86-64, поэтому Updater CE предлагает его на компьютерах x86-64 и нигде больше. Само приложение работает в большем количестве мест, чем движок.

Windows x64: доступно

Windows 10 или 11 на процессоре Intel или AMD. SP Flash Tool метод установки и SP Flash Tool обе кнопки есть.

Linux x86-64: доступно

64-битный компьютер Intel или AMD Linux с изображением приложения Updater CE. Тот же метод установки, та же кнопка.

macOS: недоступно

SP Flash Tool не существует для macOS ни в какой форме. Вместо этого Updater CE устанавливает и восстанавливает с помощью MTKClient, а метода или кнопки установки SP Flash Tool нет. Держите Mac по указанному маршруту или используйте Мак заметки.

Linux ARM64: недоступен

Raspberry Pi, платы ARM и ARM64 Linux — это та же история, что и macOS: MediaTek не поставляется с сборкой ARM, поэтому Updater CE использует там MTKClient.

Не уверены в машине? Откройте настройки и включите Показать дополнительные настройки: если нет Метод установки с опцией SP Flash Tool этот компьютер не сможет его запустить. На macOS и ARM64 Linux плеер по-прежнему устанавливается нормально, поэтому используйте пошаговый маршрут с автоматическим выбором и переходите на компьютер с Windows x64 или Linux x86-64 только в том случае, если вам конкретно нужен SP Flash Tool.

Установите выбранную прошивку с помощью SP Flash Tool

  1. Откройте Updater CE и выберите модель, напечатанную на вашем плеере: Innioasis Y1, Y2, G1, G3, G5, R1 или PR1 или модель Timmkoo.
  2. Выберите желаемое программное обеспечение, Заводское ПО или проект сообщества, затем выберите выпуск. Это тот же список, то же соответствие модели и те же проверки, что и при любой другой установке.
  3. Открыть Настройки и включи Показать дополнительные настройки.
  4. Найти Метод установки и выбери SP Flash Tool вместо Авто.
  5. Вернитесь на экран установки и нажмите Установить / Восстановить.
  6. Полностью выключите плеер, когда приложение запросит это, а затем подключите кабель для передачи данных USB непосредственно к компьютеру по запросу. Используйте кабель для передачи данных, а не кабель только для зарядки, и пропускайте концентраторы.
  7. Подождите, пока Updater CE сообщит, что установка завершена, затем отсоедините кабель и запустите плеер.

Вот и все путешествие. Средство обновления CE по-прежнему предоставляет пакет для конкретной модели, агент загрузки MediaTek, проверки драйверов и приглашение на подключение; выбор SP Flash Tool меняет только нижний движок.

Держите модели отдельно. Пакет Y1 и пакет Y2 никогда не являются взаимозаменяемыми, а скаттер-файл одной модели не описывает другую. Если Updater CE не предлагает прошивку для выбранной вами модели, остановитесь и вместо этого выберите пакет, указанный для этой модели.

Для чего нужна кнопка SP Flash Tool

На поддерживаемом компьютере Updater CE также имеет SP Flash Tool кнопка, которая открывает инструмент MediaTek для прямой работы с ним, например, с помощью скаттер-пакета, который вы предоставили сами. Для рутинной установки, обновления и восстановления это не требуется: метод установки выполняет ту же работу с сопоставлением модели, проверкой драйверов и запросами на подключение, обрабатываемыми за вас.

Если кнопка отсутствует, компьютер относится к одной из неподдерживаемых систем, указанных выше, или выбранная вами модель использует другой поток. В этом случае используйте метод установки или пошаговый маршрут вместо поиска двоичного файла инструмента.

Когда SP Flash Tool — правильный метод установки

  • Плеер, который не загружается. Режим загрузки SP Flash Tool по-прежнему может достигать устройства, предварительный загрузчик или загрузочный образ которого поврежден, поэтому требуется тщательная работа по восстановлению.
  • Вспышка, которая зависает на поддерживаемом ПК. Если Auto или MTKClient останавливается на полпути на машине Windows x64 или Linux x86-64, привязка установки к SP Flash Tool дает другому движку возможность включить тот же пакет.
  • Заводская упаковка, которой вы доверяете. Выпуски оригинального программного обеспечения от архив прошивок хорошо сочетается с ним, потому что восстановление стандартных разделов — это именно то, для чего создан SP Flash Tool .

Для обычного обновления или первой установки оставьте Метод установки на Авто. Оно выбирает движок, соответствующий вашей модели и платформе, и приложение поддерживает поддерживаемый путь без дополнительных настроек.

Если установка не запускается

  1. Убедитесь, что модель, которую вы выбрали в Updater CE, соответствует модели, напечатанной на плеере, и что для нее указан пакет.
  2. Перед подключением убедитесь, что плеер полностью выключен, и подключайтесь только по запросу приложения.
  3. В Windows установите драйвер MediaTek и перезапустите; на Linux проверьте разрешения USB, указанные в настройка компьютера.
  4. Попробуйте другой порт USB прямо на компьютере, без хаба, и снова запустите установку/восстановление.

Все дальнейшее принадлежит Поиск неисправностей. А на macOS или ARM64 Linux ответ не другая кнопка: держать управляемая установка и используйте SP Flash Tool только с компьютера Windows x64 или Linux x86-64.
