    Získejte Innioasis Updater CE

    Innioasis Updater CE je aplikace, která instaluje oficiální aktualizace a komunitní software do vašeho přehrávače. Uchovává vaši hudbu a nastavení a běží na Windows, MacOS a Linux.

    Windows

    Stáhněte si instalační program, spusťte jej a po dokončení restartujte počítač.

    Získejte ovladačeStáhnout Updater CE

    Pokud vám systém Windows zabrání spouštění aplikace nebo ji nelze spustit, otevřete Nastavení, klikněte na Soukromí a zabezpečení → Zabezpečení Windows → Ovládání aplikací a prohlížeče a vypněte Smart App Control.     Poznámky k nastavení Linuxu

    Potřebujete svůj přehrávač, datový kabel USB, který přenáší data (kabel pouze pro nabíjení nelze nainstalovat) a několik minut. Nechte kabel připojený, dokud Updater CE neoznámí, že je hotovo.

    Vyberte si svůj model a software

    1. Model zařízení: vyberte model vytištěný na přehrávači, Y1 nebo Y2. Software vytvořený pro jeden model nelze nainstalovat na druhý.
    2. Software a vydání: vyberte Original Software, Rockbox, Solar, JJ Launcher, Inniclassic, Y2Player nebo Koensayr, pokud je uveden pro váš model, a poté vyberte verzi. Stabilní je bezpečná volba.
    3. Instalace: klikněte Nainstalovat / Obnovit, úplně vypněte přehrávač a připojte kabel USB pouze tehdy, když Updater CE požádá.
    4. Dokončit: ponechte přehrávač a kabel v klidu, dokud se nezobrazí zpráva o úspěchu, poté odpojte a spusťte přehrávač.

    Y1 hráči, kteří byli dodáni s originálním softwarem před verzí 2.0.0, potřebují Zařízení Type B. Všichni ostatní si ponechají výchozí Type A.

    Vraťme se k původnímu softwaru

    Vlastní software je reverzibilní. V Updater CE vyberte svůj model, vyberte Původní software, vyberte stabilní vydání a poté spusťte Nainstalovat / Obnovit stejným způsobem. Není co ručně mazat.

    Windows nespustí aplikaci? Řešení Smart App Control

    Windows Defender SmartScreen nebo Smart App Control mohou blokovat nově stažené komunitní aplikace dříve, než se rozšíří reputace signatur. Smart App Control v současné době ovlivňuje oblíbené aplikace, jako je Epic Overlay Service (používaná Fortnite) – Updater CE je bezpečný a ověřený pro použití. Vypnutí Smart App Control umožní Updater CE normálně otevřít a spustit.

    1. Otevřít Nastavení na vašem počítači se systémem Windows (stiskněte Win + I).
    2. Klikněte Soukromí a zabezpečení v levém postranním panelu a poté klikněte Windows Security.
    3. Klikněte Ovládání aplikací a prohlížeče.
    4. Pod Inteligentní ovládání aplikací, klikněte Nastavení Smart App Control.
    5. Nastavte přepínač na Vypnuto aby bylo možné spustit Updater CE.

    Staženo přes Edge? Pokud Edge blokuje stahování samotné, klikněte na tlačítko Další možnosti (…) → Nechat → Zobrazit více → Stejně si ponechat.

    Později znovu povolte Smart App Control: Když budete chtít Smart App Control znovu zapnout, můžete jej znovu povolit prostřednictvím registru Windows pod HKEY_LOCAL_MACHINE\SYSTEM\CurrentControlSet\Control\CI\Policy nastavením VerifiedAndReputablePolicyState do 1 (Zapnuto) nebo 2 (Režim hodnocení) a restartování.
