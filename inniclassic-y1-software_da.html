Inniclassic Y1 install steps

  1. Åbn Innioasis Updater CE på din computer (hvis du har brug for appen, Hent Updater CE). Sæt Enhedsmodel til Y1.
  2. Vælg Inniclassic ind Software.
  3. Vælg den udgivelse, der er angivet for Y1.
  4. Klik Installer / Gendan.
  5. Sluk og tilslut kun Y1, når Updater CE spørger.

Ofte stillede spørgsmål

Kan jeg gendanne standard Y1-softwaren?

Ja. Vælg Y1 og original software i Updater CE. Den Y1 lager-software guide dækker returvejen.

Hvad hvis installationen mislykkes?

Note whether Updater failed before or after detecting the Y1, then check the cable, platform setup, model, and connection timing in fejlfinding.

Can I use Inniclassic on Y2?

Yes. Inniclassic is available on both models — the same maintained project publishes a Y2 package from the same releases. Select Y2 in Updater CE and install the Y2 build; never flash a Y1 package to a Y2. The Y2 installationsside covers it.
