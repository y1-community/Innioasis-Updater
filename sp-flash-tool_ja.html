インストール方法

Innioasis アップデータ CE 内の SP Flash Tool

SP Flash Tool は個別にダウンロードされるものではなく、アプリ フォルダーには何も見つかりません。これは、Intel または AMD プロセッサを搭載した Windows x64 および Linux x86-64 PC 上の Innioasis Updater CE でのインストール方法です。通常の方法でファームウェアを選択し、設定します 詳細設定を表示 > インストール方法 > SP Flash Tool そしてインストールします。

Updater CEを入手してインストールするファームウェアのダウンロードトラブルシューティング

通常ルートが先です

ファームウェアを選択してからエンジンを選択してください

Updater CE でのインストールは常に同じ手順です。モデルを選択し、ファームウェアとリリースを選択して、インストール/復元を実行します。インストール メソッドは、どの MediaTek エンジンがフラッシュを実行するかを決定するだけです。そのままにしておきます 自動 ピン留めして次のように設定する理由がない限り、 SP Flash Tool そうするとき。

SP Flash Tool を持つコンピュータはどれですか

MediaTek は x86-64 のみに SP Flash Tool を公開するため、Updater CE はそれを x86-64 PC 上で提供し、他には提供しません。アプリ自体はエンジンよりも多くの場所で実行されます。

Windows x64: 利用可能

Intel または AMD プロセッサでは Windows 10 または 11。の SP Flash Tool インストール方法と SP Flash Tool ボタンは両方あります。

Linux x86-64: 利用可能

Updater CE AppImage を実行している 64 ビット Intel または AMD Linux マシン。同じインストール方法、同じボタン。

macOS: 利用できません

SP Flash Tool は、どの形式でも macOS に対して存在しません。 Updater CE は、代わりに MTKClient を使用してインストールと復元を行います。SP Flash Tool のインストール方法やボタンはありません。 Mac をガイド付きルート上に置いておくか、 Macのメモ.

Linux ARM64: 利用できません

Raspberry Pi、ARM ボード、ARM64 Linux は macOS と同じです。MediaTek には ARM ビルドが付属していないため、Updater CE は MTKClient を使用します。

機械についてよくわからないですか?設定を開いてオンにします 詳細設定を表示: ない場合 インストール方法 SP Flash Tool オプションを指定すると、そのコンピューターでは実行できません。 macOS および ARM64 Linux では、プレーヤーは引き続き通常どおりインストールされるため、自動でガイド付きルートを使用し、SP Flash Tool が特に必要な場合にのみ Windows x64 または Linux x86-64 PC に移動してください。

SP Flash Tool を使用して選択したファームウェアをインストールします

  1. Updater CE を開き、プレーヤーに印刷されているモデルを選択します: Innioasis Y1、Y2、G1、G3、G5、R1 または PR1、または Timmkoo モデル。
  2. 必要なソフトウェアを選択し、 純正ソフトウェア またはコミュニティ プロジェクトを選択し、リリースを選択します。これは、他のインストールと同じリスト、同じモデルの一致、および同じチェックです。
  3. 開く 設定 そして電源を入れます 詳細設定を表示.
  4. 探す インストール方法 そして選択してください SP Flash Tool 自動の代わりに。
  5. インストール画面に戻り、 をクリックします。 インストール / 復元.
  6. アプリから要求されたらプレーヤーの電源を完全にオフにし、プロンプトが表示されたら USB データ ケーブルをコンピューターに直接接続します。充電専用ケーブルではなくデータ ケーブルを使用し、ハブをスキップします。
  7. Updater CE がインストールの完了を報告するまで待ち、ケーブルを取り外してプレーヤーを起動します。

それが旅のすべてです。 Updater CE は、モデル固有のパッケージ、MediaTek ダウンロード エージェント、ドライバー チェック、および接続プロンプトを引き続き提供します。 SP Flash Tool を選択すると、その下のエンジンが交換されるだけです。

モデルを別々にしておきます。 Y1 パッケージと Y2 パッケージは決して交換可能ではなく、一方のモデルのスキャッタ ファイルは他方のモデルを記述しません。 Updater CE が選択したモデルのファームウェアを提供していない場合は、停止し、代わりにそのモデルにリストされているパッケージを選択します。

SP Flash Toolボタンの用途

サポートされているコンピュータでは、Updater CE には SP Flash Tool MediaTek のツールを開くボタン。これを使用して直接操作することができます (たとえば、自分で提供したスキャター パッケージを使用する場合など)。日常的なインストール、更新、復元には必要ありません。インストール方法は、モデルの照合、ドライバーのチェック、接続プロンプトの処理と同じように機能します。

ボタンが表示されない場合は、コンピューターが上記のサポートされていないシステムのいずれかであるか、選択したモデルで別のフローが使用されています。その場合は、ツールのバイナリを探すのではなく、インストール方法またはガイド付きルートを使用してください。

SP Flash Tool が正しいインストール方法の場合

  • 起動しないプレーヤー。 SP Flash Tool のダウンロード モードは、プリローダーまたはブート イメージが破損しているデバイスにも引き続き到達する可能性があるため、慎重な回復作業が行われます。
  • サポートされている PC でフラッシュが停止する。 Windows x64 または Linux x86-64 マシンで Auto または MTKClient が途中で停止した場合、インストールを SP Flash Tool に固定すると、他のエンジンが同じパッケージで起動できるようになります。
  • 信頼できる工場出荷時のパッケージ。 オリジナル ソフトウェア リリース ファームウェアアーカイブ ストック パーティションの復元はまさに SP Flash Tool の目的に構築されているため、これと組み合わせるのが最適です。

通常のアップデートまたは最初のインストールの場合は、そのままにしておきます インストール方法 オートで。モデルとプラットフォームに適したエンジンが選択され、追加の設定を行わなくても、アプリはサポートされているパスを維持します。

インストールが開始されない場合

  1. Updater CE で選択したモデルがプレーヤーに印刷されているモデルと一致し、そのモデルのパッケージがリストされていることを確認します。
  2. 接続する前にプレーヤーの電源が完全にオフになっていることを確認し、アプリのプロンプトが表示された場合にのみ接続してください。
  3. Windows に MediaTek ドライバーをインストールして再起動します。 Linux で、に記載されている USB 権限を確認してください。 コンピュータのセットアップ.
  4. ハブを使用せずに、コンピュータ上の別の USB ポートを直接試して、インストール/復元を再度開始してください。

それ以上のものはすべて以下に属します トラブルシューティング。 macOS または ARM64 Linux では、答えは別のボタンではありません。 ガイド付きインストール Windows x64 または Linux x86-64 PC からのみ SP Flash Tool を使用してください。
