JJ Launcher Y1 étapes d'installation

  1. Ouvrez Innioasis Updater CE sur votre ordinateur (si vous avez besoin de l'application, Obtenir Updater CE). Ensemble Modèle d'appareil à Y1.
  2. Choisissez JJ Launcher dans Logiciel.
  3. Choisissez la version affichée pour Y1.
  4. Cliquez Installer / Restaurer.
  5. Éteignez et connectez le Y1 uniquement lorsque Updater CE le demande.

FAQ

Puis-je installer l'entrée Y2 sur un Y1 ?

Non. Gardez le modèle et l’emballage correspondant. Si l'entrée Y1 est manquante, ne forcez pas un fichier Y2.

Puis-je revenir au logiciel d'origine ?

Oui. Choisissez Y1 et Logiciel original dans Updater CE. Voir le Y1 page de restauration.

Où sont toutes les versions JJ Launcher ?

Les versions actuelles sont en Téléchargements de logiciels. Les notes de version sont sur le projet notes de version.

Configuration de l'ordinateur

Le programme de mise à jour peut être utilisé sous Windows, macOS et Linux une fois que la configuration appropriée est prête. Commencez par le guide de la plateforme.
