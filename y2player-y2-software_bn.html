Y2Player install steps

  1. আপনার কম্পিউটারে Innioasis Updater CE খুলুন (যদি আপনার অ্যাপটির প্রয়োজন হয়, Updater CE নিন) সেট ডিভাইস মডেল থেকে Y2.
  2. বেছে নিন Y2Player মধ্যে সফটওয়্যার.
  3. Choose a release listed for Y2.
  4. ক্লিক করুন ইনস্টল / পুনরুদ্ধার.
  5. Power off and connect the Y2 at the live prompt.

Some Y2 full-install packages use rom_y2.zip. Let Updater choose the package when possible.

সাধারণ প্রশ্ন

Can I go back to the original software?

Yes. Select Y2 and Original Software in Updater CE, then follow the Y2 পুনরুদ্ধার গাইড.

Can I use this on a Y1?

No. This page is for the Y2Player Y2 entry. Keep Y1 and Y2 packages separate.

What if the Y2 is not detected?

Check platform setup, cable, power-off state, model selection, and timing. Use সমস্যা সমাধান before trying manual recovery.
