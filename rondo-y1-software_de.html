Installationsschritte

  1. Starten Innioasis Updater CE auf Ihrem Windows-, Mac- oder Linux-Computer.
  2. Auswählen Y1 aus der Dropdown-Liste „Gerätemodell“.
  3. Auswählen Rondo aus der Dropdown-Liste „Software“.
  4. Klicken Sie Installieren / Wiederherstellen und warten Sie, bis das Tool die Dateien heruntergeladen und vorbereitet hat.
  5. Wenn Sie von Updater CE dazu aufgefordert werden, schalten Sie Ihr Y1 aus und schließen Sie das USB-Kabel an.
  6. Komplette Einrichtung nach der Installation

    Befolgen Sie die Schritte in diesen Leitfaden um die Einrichtung auf Ihrem Y1 abzuschließen.
