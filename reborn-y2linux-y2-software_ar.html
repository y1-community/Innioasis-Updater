خطوات التثبيت

  1. افتح برنامج التحديث CE. متاح لأنظمة التشغيل Windows وmacOS وLinux.
  2. حدد Y2 كنموذج الجهاز.
  3. حدد Reborn (Y2Linux) كالبرنامج.
  4. انقر فوق تثبيت / استعادة. انتظر حتى يقوم Updater CE بتحضير الملفات.
  5. قم بتوصيل USB عند سؤالك. قم بإيقاف تشغيل Y2 أولاً.
  6. قم بإعداد Wi-Fi وBluetooth وراديو FM
