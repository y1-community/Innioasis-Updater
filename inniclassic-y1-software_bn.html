আপনি যে কম্পিউটারটি ব্যবহার করছেন তার জন্য গাইডটি বেছে নিন। প্রতিটি সংস্করণে প্ল্যাটফর্ম সেটআপ, Updater CE পদক্ষেপ এবং স্টকে ফিরে যাওয়ার উপায় রয়েছে।

Inniclassic Y1 install steps

  1. আপনার কম্পিউটারে Innioasis Updater CE খুলুন (যদি আপনার অ্যাপটির প্রয়োজন হয়, Updater CE নিন) সেট ডিভাইস মডেল থেকে Y1.
  2. বেছে নিন Inniclassic মধ্যে সফটওয়্যার.
  3. Y1-এর জন্য তালিকাভুক্ত রিলিজ বেছে নিন।
  4. ক্লিক করুন ইনস্টল / পুনরুদ্ধার.
  5. পাওয়ার বন্ধ করুন এবং শুধুমাত্র Updater CE বললেই Y1 সংযোগ করুন।

সাধারণ প্রশ্ন

আমি কি স্টক Y1 সফ্টওয়্যার পুনরুদ্ধার করতে পারি?

হ্যাঁ। Updater CE-এ Y1 এবং অরিজিনাল সফটওয়্যার নির্বাচন করুন। দ Y1 স্টক-সফ্টওয়্যার গাইড ফেরার পথ কভার করে।

ইনস্টলেশন ব্যর্থ হলে কি হবে?

Note whether Updater failed before or after detecting the Y1, then check the cable, platform setup, model, and connection timing in সমস্যা সমাধান.

Can I use Inniclassic on Y2?

Yes. Inniclassic is available on both models — the same maintained project publishes a Y2 package from the same releases. Select Y2 in Updater CE and install the Y2 build; never flash a Y1 package to a Y2. The Y2 ইনস্টল পৃষ্ঠা covers it.
