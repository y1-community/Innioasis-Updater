การตั้งค่าคอมพิวเตอร์

เตรียมคอมพิวเตอร์ให้พร้อมก่อนเครื่องเล่น

ปัญหาการเชื่อมต่อส่วนใหญ่มาจากไดรเวอร์ สิทธิ์อนุญาต สายเคเบิล หรือไทม์มิ่ง Windows จำเป็นต้องติดตั้งไดรเวอร์ MediaTek Linux ต้องการสิทธิ์ USB ที่ถูกต้อง ค้นหาแพลตฟอร์มของคุณด้านล่าง

รับ Updater CEการแก้ไขปัญหา

หน้าต่าง

  1. ดาวน์โหลดตัวติดตั้งไดรเวอร์ MediaTek ด้านล่าง
  2. เรียกใช้โปรแกรมติดตั้งและอนุญาตให้ Windows ติดตั้งไดรเวอร์
  3. รีสตาร์ทคอมพิวเตอร์
  4. เปิด Updater CE และรอข้อความแจ้งการเชื่อมต่อก่อนที่คุณจะเสียบปลั๊กเครื่องเล่นที่ปิดอยู่

ระบบ Windows บางระบบบล็อกไดรเวอร์ผ่านการแยกคอร์ (ความสมบูรณ์ของหน่วยความจำ) หาก Updater CE ยังคงไม่เห็นเครื่องเล่นหลังจากรีสตาร์ท ให้ปิด Memory Integrity ใน Windows Security จากนั้นรีสตาร์ท และติดตั้งไดรเวอร์ใหม่ เปิดการตั้งค่าอีกครั้งเมื่อคุณดำเนินการเสร็จสิ้นหากระบบของคุณอนุญาต

Windows won't launch the app? If Windows Security or Smart App Control stops Updater CE from opening, open การตั้งค่า (press Win + I) → Privacy & security → Windows Security → App & browser control → Smart App Control settings and set it to ปิด. Smart App Control is currently impacting popular applications like the Epic Overlay Service (used by Fortnite) — Updater CE is safe and verified to use. To re-enable later, set VerifiedAndReputablePolicyState ถึง 1 (On) or 2 (Evaluation Mode) under HKEY_LOCAL_MACHINE\SYSTEM\CurrentControlSet\Control\CI\Policy in Registry Editor.

สิทธิ์ลินุกซ์ USB

Linux ต้องการให้บัญชีผู้ใช้ของคุณได้รับอนุญาตให้พูดคุยกับชิป MediaTek USB ภายในเครื่องเล่น Updater CE มักจะเรียงลำดับสิ่งนี้ระหว่างการติดตั้ง และการอนุญาตเดียวกันครอบคลุม SP Flash Tool ดังนั้นให้ถือว่านี่เป็นขั้นตอนการแก้ไขแทนที่จะเป็นขั้นตอนปกติ

  1. เรียกใช้ Updater CE ในฐานะผู้ใช้ปกติของคุณ ไม่ใช่ในฐานะรูท โปรแกรมติดตั้งจะขอสิทธิ์การเข้าถึงของผู้ดูแลระบบเมื่อจำเป็นเท่านั้น
  2. ตรวจสอบผู้เล่นว่ามองเห็นได้เลย ปิดเครื่องเล่น เชื่อมต่อสายเคเบิล และรันคำสั่ง lsusb ในเทอร์มินัล เครื่องเล่นที่เชื่อมต่อจะแสดงเป็นอุปกรณ์ MediaTek โดยมี ID ผู้จำหน่าย 0e8d
lsusb
  1. หากปรากฏใน lsusb แต่ Innioasis Updater CE หรือ SP Flash Tool ระบุว่าสิทธิ์ถูกปฏิเสธหรือไม่สามารถเปิดพอร์ตได้ แสดงว่าผู้ใช้ของคุณไม่สามารถเข้าถึงอุปกรณ์ USB กฎ udev เดียวกันครอบคลุมเครื่องมือทั้งสอง ดังนั้นให้เพิ่มกฎที่ช่วยให้กลุ่มผู้ใช้อ่านได้
SUBSYSTEM=="usb", ATTR{idVendor}=="0e8d", MODE="0666", GROUP="plugdev"

บันทึกบรรทัดนั้นลงในไฟล์ใหม่ชื่อ /etc/udev/rules.d/51-innioasis.rules จากนั้นรัน:

sudo udevadm control --reload && sudo udevadm trigger
  1. ถอดปลั๊กเครื่องเล่นออกจนสุด เสียบกลับเข้าไปใหม่ แล้วลองติดตั้งอีกครั้ง
  2. หาก SP Flash Tool รายงานการอนุญาตแบบอนุกรมหรือการแข่งขันของพอร์ต ให้ถอดปลั๊กออกจนสุดแล้วเชื่อมต่อใหม่เมื่อได้รับแจ้งเท่านั้น
อย่าทำการชดเชยแฟลชแบบด้นสดหากคุณเปลี่ยนไปใช้เครื่องมือการกู้คืนด้วยตนเอง ให้ใช้ไฟล์และการกำหนดค่าเฉพาะรุ่นที่มาพร้อมกับโปรเจ็กต์
