Was ist Slideia?

📋 Manifestsystem

Slideia bietet ein umfassendes XML-Manifestsystem, das alle verfügbaren Firmware-Pakete, Themes und Tools für Y1 Geräte katalogisiert. Dieser zentralisierte Ansatz erleichtert das Erkennen und Verwalten von Ressourcen.

🔗 Repository-Integration

Stellt eine Verbindung zu Projekt-Repositorys her, sodass Sie die neuesten Firmware-Versionen, Updates und Community-Beiträge erhalten können.

📱 Gerätekompatibilität

Speziell für Y1-Geräte mit umfassender Gerätetyp- und Modellunterstützung entwickelt, um die Kompatibilität über alle Y1-Varianten hinweg sicherzustellen.

⚡ Leistungsoptimiert

Leistungsstarke Paketerkennung und -verwaltung mit intelligentem Caching und Ratenbegrenzung für einen optimalen Release-Feed.

🌍 Plattformübergreifend

Läuft unter Windows, macOS und Linux.

🛠️ Entwicklerfreundlich

Saubere APIs und eine gut dokumentierte Struktur erleichtern Entwicklern die Erweiterung und Integration mit ihren eigenen Tools und Anwendungen.

Erstellt mit ❤️ von Ryan Specter und Team Slide · r/Innioasis · Discord

🚀 Holen Sie sich Innioasis Updater

Laden Sie die Desktop-App für Ihr System herunter

🪟 Windows-Installation

Laden Sie das Windows-Installationsprogramm herunter und befolgen Sie die Installationsanweisungen. Nach der Installation müssen Sie die MTK-Treiber für eine ordnungsgemäße Gerätekommunikation installieren.

🍎 macOS-Installation

Kopieren Sie diesen Befehl, fügen Sie ihn in das Terminal ein und drücken Sie die Eingabetaste:

/bin/bash -c "$(curl -fsSL https://raw.githubusercontent.com/team-slide/Innioasis-Updater/main/run_mac.sh)"

Dadurch wird automatisch alles eingerichtet, was Sie brauchen!

Nach der ersten Ausführung können Sie denselben Befehl erneut verwenden, um die App für zukünftige Verwendungen zu starten.

Notiz: Dies ist eine vorübergehende Vorschauversion. In Kürze wird es eine Installations-App geben, bei der Sie das Terminalfenster nicht benötigen.

🐧 Linux-Installation

Für das beste Erlebnis wird Ubuntu empfohlen, aber auch andere Distributionen sollten funktionieren.

Führen Sie diesen einzeiligen Installationsbefehl in Ihrem Terminal aus:

curl -sL https://github.com/y1-community/Innioasis-Updater/releases/latest/download/run_linux.sh | bash

Für Einzelheiten zu Abhängigkeiten und zur Fehlerbehebung öffnen Sie die vollständige Anleitung.

🖥️ ChromeOS/FydeOS

Möglicherweise können Sie Innioasis Updater im Linux-Modus ausführen, aber wir haben diese Konfiguration nicht getestet. Befolgen Sie die Linux-Anweisungen im neuen Tab und versuchen Sie, es in Ihrer Linux-Umgebung auszuführen.

Hinweis: Dies ist experimentell und funktioniert möglicherweise nicht wie erwartet.

🪟 Windows ARM64

Für Windows ARM64-Benutzer können fortgeschrittenere Benutzer möglicherweise die Linux-Version mit Python, Libusb, Android-Platform-Tools, USBIPD-Win und WSLg ausführen. Ubuntu wird empfohlen.
