Model-correct checks

  1. Otwórz Innioasis Updater CE na swoim komputerze (jeśli potrzebujesz aplikacji, Pobierz Updater CE). Zestaw Model urządzenia do Y2.
  2. Confirm JJ Launcher appears for Y2 in the current release data.
  3. Read the project release note and select the listed Y2 release.
  4. Kliknij Zainstaluj / Przywróć.
  5. Power off and connect the Y2 only when prompted.
Do not substitute: a Y1 package is not a Y2 package. Stop if the model and release do not agree.

Najczęstsze pytania

Is Y2 support guaranteed?

There's a Y2 build listed, but what's supported can change. Check the latest listing and the project's notes before installing.

How do I restore the Y2?

Select Y2 and Original Software in Updater CE, then follow the Y2 restore steps.

What if JJ Launcher is not listed?

Do not force a Y1 package. Check the project releases and the przewodnik rozwiązywania problemów.
