Koensayr Y1 étapes d'installation

  1. Ouvrez Innioasis Updater CE sur votre ordinateur (si vous avez besoin de l'application, Obtenir Updater CE). Ensemble Modèle d'appareil à Y1.
  2. Choisissez Koensayr dans Logiciel.
  3. Choisissez la version Y1 répertoriée.
  4. Cliquez Installer / Restaurer.
  5. Éteignez et connectez le Y1 uniquement lorsque Updater CE le demande.

FAQ

Puis-je restaurer le logiciel Y1 d'origine ?

Oui. Sélectionnez Y1 et Logiciel original dans Updater CE. Voir le Y1 page de stock de logiciels pour l'itinéraire de restauration complet.

Que dois-je vérifier en cas d'échec ?

Vérifiez le modèle, la version, le câble, la configuration de la plate-forme et si le lecteur était connecté avant l'invite. Utilisez ensuite dépannage.

Existe-t-il un package Koensayr Y2 ?

La version actuelle est pour Y1. Ne l'utilisez pas sur un Y2 à moins que le projet ne publie une version distincte pour celui-ci.

Commencez par la configuration de l'ordinateur

Le programme de mise à jour fonctionne sous Windows, macOS et Linux une fois la configuration de la plate-forme prête. Lire le guide général d'abord.
