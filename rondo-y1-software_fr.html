Étapes d'installation

  1. Lancement Innioasis Programme de mise à jour CE sur votre ordinateur Windows, Mac ou Linux.
  2. Sélectionnez Y1 dans la liste déroulante Modèle d'appareil.
  3. Sélectionnez Rondo dans la liste déroulante Logiciel.
  4. Cliquez Installer / Restaurer et attendez que l'outil télécharge et prépare les fichiers.
  5. Lorsque Updater CE vous y invite, éteignez votre Y1 et connectez le câble USB.
  6. Terminer la configuration post-installation

    Suivez les étapes dans ce guide pour terminer la configuration sur votre Y1.
