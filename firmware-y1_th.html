เฟิร์มแวร์สำหรับ Innioasis Y1

เรียกดู Y1 ดาวน์โหลด รับ Updater CE แกลลอรี่ธีม

ระบบปฏิบัติการที่ใช้ได้สำหรับ Innioasis Y1

Y1 ใช้งานระบบซอฟต์แวร์หลายระบบ รวมถึงบิลด์ที่รองรับตัวแปลงสัญญาณออดิโอไฟล์ ตัวเรียกใช้งานสมัยใหม่ และการคืนค่าจากโรงงาน เลือกอันที่เหมาะกับวิธีการฟังของคุณ:

Rockbox

มาตรฐานทองคำในการเล่นเสียงโอเพ่นซอร์ส Parametric EQ, การเล่น FLAC/MP3 ที่ไม่มีช่องว่าง, ธีม และชุดแบบอักษรที่สามารถติดตั้งได้โดยตรงใน Updater CE

Y1 Rockbox แนะนำ →

Better-Y

อนุพันธ์ที่ได้รับการปรับปรุงของเฟิร์มแวร์ดั้งเดิมพร้อมแพตช์ความเสถียรของ Bluetooth การปรับเส้นโค้งระดับเสียง และความเข้ากันได้ของ Themes Gallery 100%

Better-Y คำแนะนำ →

Solar

เครื่องเล่นเพลงโอเพ่นซอร์สร่วมสมัยที่สร้างด้วย Flutter นำเสนอแอนิเมชั่น 60fps ที่ราบรื่น ตารางปกอัลบั้ม และตัวพิมพ์สมัยใหม่

Solar Y1 แนะนำ →

Rondo

ตัวเรียกใช้โอเพ่นซอร์ส Y1 สำหรับแทร็กและการสตรีมในเครื่องพร้อมการนำทางที่รวดเร็วและตอบสนอง

Rondo Y1 แนะนำ →

Koensayr

โครงสร้างเฟิร์มแวร์แบบกำหนดเองพร้อมสัญลักษณ์ของตัวเอง การปรับเทียบแบตเตอรี่ที่ดีขึ้น และการรองรับธีมสต็อก

Koensayr คำแนะนำ →

วิธีการติดตั้งหรืออัพเดตเฟิร์มแวร์ Y1

การอัพเกรดหรือยกเลิกการปิดกั้น Innioasis Y1 ของคุณทำได้ง่าย ๆ ด้วยชุดซอฟต์แวร์หลายแพลตฟอร์มของเรา:

  1. เปิด Innioasis Updater CE: เปิดตัวอัปเดตบน macOS, Windows หรือ Linux
  2. เลือกรุ่น Y1: เลือก Y1 ในเมนูแบบเลื่อนลงรุ่นอุปกรณ์
  3. เลือกระบบปฏิบัติการของคุณ: เลือก Rockbox, Better-Y, Solar หรือซอฟต์แวร์ต้นฉบับ
  4. คลิกติดตั้ง: Updater CE ดาวน์โหลดแพ็คเกจเฟิร์มแวร์โดยตรงจากรุ่นของผู้พัฒนา เมื่อได้รับแจ้ง ให้เชื่อมต่อ Y1 ขณะปิดเครื่องผ่าน USB เพื่อเริ่มการกะพริบ
เรียกดูข่าว Y1 ทั้งหมด คู่มือการติดตั้งทีละขั้นตอน
