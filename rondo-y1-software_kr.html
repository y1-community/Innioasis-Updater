설치 단계

  1. 발사 Innioasis 업데이터 CE Windows, Mac 또는 Linux 컴퓨터에서.
  2. 선택 Y1 장치 모델 드롭다운에서
  3. 선택 Rondo 소프트웨어 드롭다운에서
  4. 클릭 설치 / 복원 도구가 파일을 다운로드하고 준비할 때까지 기다립니다.
  5. Updater CE에서 메시지가 표시되면 Y1의 전원을 끄고 USB 케이블을 연결합니다.
  6. 설치 후 설정 완료
