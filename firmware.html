Install your choice with Updater CE

  1. Open the guide and install Innioasis Updater CE for your computer if you do not have it yet.
  2. In Updater CE, select the model printed on your player from Device Model.
  3. From Software, select the software you want to run on that model.
  4. Select a release, click Install / Restore, then power off and connect the player only when Updater CE asks.

Need the community installer? Open the guide and expand the Updater CE download section.

If something goes wrong

The safe way back

Check the model

Y1 and Y2 Software is not interchangeable. Re-select the model in Updater CE and start again.

Wait for the prompt

Power the player fully off and connect it only when Updater CE says it is ready.

Restore Original Software

Choose Original Software for the same model. If manual recovery is needed, open the troubleshooting guide first.

A note on the two tools

Updater or Updater CE?

Innioasis Updater CE is the community-made, donation-supported utility. It loads official firmware from Innioasis and current custom releases from the Community Firmware Archive directly in the app. Use CE for Rockbox, JJ Launcher, Inniclassic, Solar, and similar projects so you do not have to chase download links and tutorial versions.

Innioasis Updater is the manufacturer-provided manual flasher for official firmware packages supplied as .zip or .rar files. If you already have a specific official package, that is the tool it is intended for.

Most community walkthroughs, including Catsteal3r's TikTok and Dammit Jeff's “How To Actually Quit Spotify” video, demonstrate the CE workflow.
