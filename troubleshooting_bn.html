It stopped before the USB prompt

This is a computer problem, not a cable problem. Check your model. Unpack the file again. Then try ইনস্টল / পুনরুদ্ধার. If the release list is empty, open the firmware directory.

It cannot connect to the player

  1. Fully power off the correct Y1 or Y2.
  2. Unplug the cable, close other flash or Android tools, and start the install again.
  3. Connect only when Updater says it is ready.
  4. Use a short USB data cable directly in the computer, not a hub if possible.
  5. On Windows, reinstall the MediaTek driver and restart. On Linux, check USB/serial permissions.

It detected the player but the flash failed

Stop here. Do not try a different model. Close other tools, check you picked the right Y1 or Y2, and use the matching Original Software if the player will not start. SP Flash Tool and MTKClient are included if you need them, and the files are on the firmware page.

Windows driver notes

Some Windows installations block the MediaTek driver because of Core isolation. Follow the current Windows security guidance before changing Memory integrity, and turn it back on when you are finished if your system allows it.
