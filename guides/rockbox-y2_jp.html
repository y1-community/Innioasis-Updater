ビデオ: クリスティアンプラザ (スペイン語)。 Y1 へのインストールを示します。選ぶ Y2 このガイドの Updater CE にあります。

「インストール」をクリックする前に

充電済みの Innioasis Y2、データ ケーブル USB、および Innioasis Updater CE がインストールされたコンピューターを用意します (まだインストールしていない場合は、 Updater CE を入手 Windows、macOS、または Linux の場合）。名前が似ているという理由だけで Y1 リリースを使用しないでください。

モデルチェック: Y2 のフルインストール パッケージでは次のものが使用される場合があります rom_y2.zip。ファイル名は手動ダウンロードの手がかりとして役立ちますが、パッケージの選択はアップデーターが処理する必要があります。

アップデーターで Y2 を選択します

  1. Updater CE を開きます (または次のコマンドで起動します) Updater CE で入手) を設定してください デバイスモデル 支援先: Y2.
  2. 選択してください Rockbox で ソフトウェア.
  3. Y2 にリストされているリリースを選択します。 Y2 リリースがリストされていない場合は、Y1 リリースを置き換えないでください。
  4. クリック インストール / 復元 Updater CE がコミュニティ開発者のリリースからパッケージを直接ダウンロードできるようにします。

電源を切ってから接続してください

  1. ライブ接続プロンプトが表示されるまで待ちます。
  2. Y2 の電源を完全にオフにします。通常のシャットダウンが失敗した場合は、アップデータによって表示される正確なリセットまたは回復手順を使用してください。
  3. 要求されたら、USB ケーブルを接続します。完了メッセージが表示されるまでそのままにしておきます。
  4. 安全に接続を解除し、Y2 を開始してください。

元のソフトウェアに戻る

Rockbox はカスタム ソフトウェアに閉じ込められることはありません。コンピューター用にアップデーターをセットアップしたら、Windows、macOS、または Linux でそれを使用して、Rockbox またはリストされている別のプロジェクトに戻ります。 Y2、 選ぶ 純正ソフトウェア、実行します インストール / 復元.

  1. アップデーターが Y2 ストック パッケージを準備するまで待ちます。
  2. アプリが尋ねたら、Y2 の電源を切ります。
  3. USB データ ケーブルはライブ プロンプトでのみ接続してください。
  4. 成功メッセージが表示されるまでプレーヤーを動かさないでください。

Y1 パッケージと Y2 パッケージは別々に保管してください。最初に Rockbox ファイルを手動で削除しないでください。復元によりシステム ソフトウェアが置き換えられます。
