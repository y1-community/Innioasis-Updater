Installieren Sie es

  1. Öffnen Sie Innioasis Updater CE auf Ihrem Computer (falls Sie es noch nicht haben, Updater CE holen). Auswählen Y1 In Gerätemodell.
  2. Wählen Sie Android 4.2 (Entwickler) In Software (oder starten Sie mit In Updater CE erhalten).
  3. Wählen Sie eine Veröffentlichung aus und klicken Sie Installieren / Wiederherstellen.
  4. Schalten Sie das Y1 erst aus und schließen Sie es an, wenn Sie vom Updater dazu aufgefordert werden.
  5. Verwenden Sie Y1 Original-Software für den Wiederherstellungspfad.
