Timmkoo SR1 で元のソフトウェアを復元します

プレーヤーに同梱されていたソフトウェアに完全に戻りました。アップデートに失敗した後、プレーヤーを販売する前、またはカスタム システムが自分に合わないときはいつでも、これを使用してください。

コンピュータを使用して SR1 上の元のソフトウェアを復元します

使用しているコンピュータのガイドを選択してください。 すべてのバージョンには、プラットフォームのセットアップ、Updater CE の手順、および在庫に戻る方法が含まれています。

必要なもの

  • Windows、macOS、または Linux コンピューター。 Updater CE は 3 つすべてで実行されます。
  • プレーヤーに付属の USB データ ケーブル。充電専用ケーブルは動作しません。
  • 役人 rom_sr1.zip アップデータがダウンロードするパッケージ、または SR1 アーカイブ 手動でフラッシュしたい場合。
  • プレーヤーに充電します。電源を失った状態での復元は、悪い状況をさらに悪化させる唯一の一般的な方法です。

これにより、システムが置き換えられ、内部ストレージが消去されます。 まず音楽、録音、写真をコンピュータにコピーします。

ルートA: Updater CE (推奨)

  1. インストール Innioasis アップデーター CE そしてそれを開きます。
  2. セット デバイスモデル 支援先: SR1。モデルはプレーヤーと正確に一致する必要があります。
  3. 選択してください 純正ソフトウェア ソフトウェアリストにある。
  4. リリースを選択します。最新の安定したビルドが安全なデフォルトです。
  5. プレス インストール / 復元 パッケージがダウンロードされて解凍されるまで待ちます。
  6. プレーヤーの電源を完全にオフにし、アップデーターが要求した場合にのみ USB ケーブルを接続します。
  7. 成功メッセージが表示されるまで、プレーヤーやケーブルに触れないでください。接続を外してプレーヤーを起動します。
「動作させる」ために別のモデルを選択しないでください。 SR1 には SR1 パッケージが必要です。モデルを混合すると、プレイヤーは手動での回復が必要になります。

ルートB: SP Flash Tool (手動)

コンピューターで Updater CE を実行できない場合、または既にパッケージを持っていて従来のツールを使用したい場合に、これを使用します。

  1. ダウンロード rom_sr1.zip からの SR1 アーカイブ そしてそれを解凍します。
  2. スキャッタファイルを画像の隣に置いてください。画像の名前を変更したり、移動したりしないでください。
  3. SP Flash Tool を開き、選択します ダウンロードのみをクリックして、スキャッタ ファイルをロードします。
  4. プレーヤーの電源を切り、 を押します ダウンロードを選択し、ケーブルを接続します。
  5. 切断する前に、緑色の成功マークが点灯するまで待ちます。

の SP Flash Tool ガイド ドライバーと Windows プロンプトについて詳しく説明します。 Linux および macOS では、Updater CE が独自の USB 処理を行うため、より簡単なルートです。

復元後

  1. プレーヤーを切断し、自動的に起動できるようにします。
  2. 言語を選択し、時計を設定します。
  3. Wi-Fi または Bluetooth を使用している場合は、それらに再接続します。
  4. 音楽をコピーして戻します。の 乗換案内 フォルダ名が付いています。

プレーヤーは起動しても、画面、ホイール、またはボタンの動作がまだ正しくない場合は、復元は機能しています。それはハードウェアまたはセットアップの問題であり、ソフトウェアの問題ではありません。の トラブルシューティングガイド 次の停留所です。

人々が尋ねる質問

これにより私の音楽は削除されますか?

はい、内部ストレージは消去されます。通常、microSD カード上のファイルは残りますが、最初に安全な場所にコピーしてください。

その後 Rockbox に戻ることはできますか?

はい。元のソフトウェアの復元は一方通行ではありません。ご使用のモデルのカスタム ソフトウェア ページから再度インストールできます。

Type A / Type B の設定は必要ですか?

その選択肢があるのは Y1 だけであり、オリジナル ソフトウェアのみです。他のすべてのモデルは単一のパッケージを使用します。
