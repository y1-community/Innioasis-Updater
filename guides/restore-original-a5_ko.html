Innioasis 및 Timmkoo A5에서 원본 소프트웨어 복원

Innioasis 펌웨어 아카이브의 검증된 패키지를 사용하여 Innioasis A5 또는 Timmkoo A5 플레이어의 공식 공장 소프트웨어를 복원하려면 이 튜토리얼을 따르십시오.

Updater CE 받기 A5 다운로드 보기

1단계: Updater CE에서 설정

  1. 발사 Innioasis 업데이터 CE Windows, macOS 또는 Linux 컴퓨터에서.
  2. 세트 기기 모델 에 A5.
  3. 선택 원본 소프트웨어. 업데이터 CE는 공식 다운로드 rom_a5.zip 패키지를 직접 출시하세요.
  4. 클릭 설치 / 복원 준비가 완료될 때까지 기다립니다.

2단계: 프롬프트에서 연결

  1. A5 장치의 전원을 완전히 끄십시오.
  2. USB 데이터 케이블을 연결하기 전에 컴퓨터 화면에 메시지가 나타날 때까지 기다리십시오.
  3. 깜박이는 프로세스가 중단 없이 완료되도록 허용합니다.
  4. 새로 복원된 A5 플레이어의 연결을 끊고 재부팅하세요.
