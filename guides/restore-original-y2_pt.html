De Rockbox ou outro software personalizado

Assim que a configuração relevante do Windows, macOS ou Linux estiver pronta, retornar à interface padrão Y2 usa o mesmo fluxo do Updater da instalação de um projeto da comunidade. Não misture manualmente os arquivos Y1 no player nem exclua as pastas do sistema primeiro.

  1. Abra Innioasis Updater CE no seu computador (se ainda não o tiver instalado, Obtenha o atualizador CE para Windows, macOS, ou Linux).
  2. Definir Modelo do dispositivo para Y2.
  3. Escolher Software Original.
  4. Selecione uma versão estável Y2. Pacotes de instalação completa manual podem usar rom_y2.zip.
  5. Clique Instalar / Restaurar e aguarde a etapa de extração.
Não substitua: um Y1 rom.zip não é um pacote Y2. Se a lista de lançamentos parecer errada, pare e selecione novamente Y2.

Siga o prompt de conexão

Windows, macOS e Linux têm notas de configuração de computador diferentes, mas a sequência do lado do player permanece a mesma: desligue quando solicitado e conecte o cabo de dados no prompt ao vivo.

  1. Desligue o Y2 totalmente quando o Updater solicitar.
  2. Conecte USB somente quando o aplicativo disser que está pronto.
  3. Deixe o cabo sozinho até a mensagem de sucesso.
  4. Desconecte-se com segurança e inicie o player.

Ainda preso?

Verifique o modelo, embalagem, cabo e tempo de conexão antes de tentar uma ferramenta manual. O guia de solução de problemas explica o que significa uma falha antes de USB em comparação com uma falha após a detecção do dispositivo.

Mantenha os pacotes separados: um Y1 rom.zip não é uma restauração Y2. Se a lista de lançamentos parecer errada, pare e selecione Y2 novamente.
