Prima di fare clic su Installa

Avere un Innioasis Y2 carico, un cavo dati USB e un computer con Innioasis Updater CE installato (se non l'hai ancora installato, Ottieni Updater CE per Windows, macOS o Linux). Non utilizzare una versione Y1 solo perché il suo nome è simile.

Controllo del modello: Y2 i pacchetti di installazione completa possono utilizzare rom_y2.zip. Il nome del file è un utile indizio per il download manuale, ma Updater dovrebbe gestire la selezione del pacchetto per te.

Scegli Y2 in Updater

  1. Apri Updater CE (o avvia con Ottieni questo in Updater CE) e impostare Modello del dispositivo a Y2.
  2. Scegli Rockbox dentro Software.
  3. Scegli una versione elencata per Y2. Se non è elencata alcuna versione Y2, non sostituire una versione Y1.
  4. Fare clic Installa / Ripristina e lascia che Updater CE scarichi il pacchetto direttamente dalla versione dello sviluppatore della community.

Spegnere, quindi connettere

  1. Attendi la richiesta di connessione live.
  2. Spegnere completamente Y2. Utilizzare le istruzioni esatte di ripristino o ripristino mostrate da Updater se il normale arresto non riesce.
  3. Collegare il cavo USB quando richiesto. Lasciarlo fermo fino al messaggio di completamento.
  4. Disconnettiti in sicurezza e avvia Y2.

Ritorna al software originale

Rockbox non ti vincola al software personalizzato. Una volta configurato Updater per il tuo computer, utilizzalo su Windows, macOS o Linux per tornare indietro da Rockbox o da un altro progetto elencato: seleziona Y2, scegliere Software originalee corri Installa / Ripristina.

  1. Attendi che Updater prepari il pacchetto stock Y2.
  2. Spegni il Y2 quando richiesto dall'app.
  3. Collegare il cavo dati USB solo al prompt live.
  4. Lasciare fermo il lettore fino al messaggio di successo.

Mantieni separati i pacchetti Y1 e Y2. Non eliminare prima manualmente i file Rockbox; il ripristino sostituisce il software di sistema.
