Restaure o software original em Innioasis e Timmkoo A5

Siga este tutorial para restaurar o software oficial de fábrica em seu player Innioasis A5 ou Timmkoo A5 com pacotes verificados do arquivo de firmware Innioasis.

Obtenha o atualizador CE Ver A5 downloads

Etapa 1: configuração em Updater CE

  1. Lançar Innioasis Atualizador CE em seu computador Windows, macOS ou Linux.
  2. Definir Modelo do dispositivo para A5.
  3. Selecione Software Original. Updater CE baixa o oficial rom_a5.zip liberar pacote diretamente.
  4. Clique Instalar / Restaurar e aguarde a conclusão da preparação.

Etapa 2: Conecte-se no prompt

  1. Desligue o dispositivo A5 completamente.
  2. Aguarde o aviso na tela do computador antes de conectar o cabo de dados USB.
  3. Permita que o processo de flashing termine sem interrupção.
  4. Desconecte e reinicie seu player A5 recém-restaurado.
