Step-by-step installation

  1. Install Updater CE: Download Innioasis Updater CE for Windows, macOS or Linux, then open it.
  2. Select Y2: Choose Y2 as the device model.
  3. Select Reborn: Choose Reborn (Y2Linux) and the latest release.
  4. Install: Click Install / Restore, power the Y2 off, and connect USB when prompted.
  5. Wait: Keep the player still until Updater CE confirms, then disconnect.
  6. Set up Wi-Fi, Bluetooth & FM radio

    Copy system.img to the player once. Reborn does the rest.
