Werksreset · Innioasis G1

So setzen Sie einen Innioasis G1 auf die Werkseinstellungen zurück

Ein eindeutiger Reset, der die guten Dateien behält und das Problem beseitigt. Diese Seite behandelt die Route „Einstellungen“, die Route „eingefrorener Spieler“ und den einen Fall, in dem ein Zurücksetzen die falsche Lösung darstellt.

Bevor Sie beginnen

Bei einem Zurücksetzen auf die Werkseinstellungen wird der interne Speicher des Players gelöscht. Es entfernt Einstellungen, Konten, Wiedergabelisten und alle Dateien, die im Player und nicht auf einer microSD-Karte gespeichert sind. Kopieren Sie Ihre Musik und Aufnahmen zunächst auf einen Computer. Wenn Sie nur langsame Menüs reparieren möchten, verwenden Sie Cache leeren stattdessen; es lässt Dateien in Ruhe.

Das Reset-Loch ist kein Werksreset. Bei Modellen mit einem kleinen Zurücksetzen Durch Drücken des Stifts wird nur dann ein Herunterfahren erzwungen, wenn der Player eingefroren ist. Es werden keine Daten gelöscht und die Werkseinstellungen werden nicht wiederhergestellt.

Der normale Weg

  1. Kopieren Sie alles, was Sie behalten möchten, auf einen Computer. Ein Reset löscht den internen Speicher.
  2. Laden Sie den Spieler mindestens auf die Hälfte auf.
  3. Offen Einstellungen auf dem Spieler.
  4. Wählen Sie Werksreset und bestätigen.
  5. Warten Sie, während es neu startet. Ziehen Sie nicht den Stecker heraus und halten Sie keine Taste gedrückt.

Wenn es wieder angezeigt wird, wählen Sie Ihre Sprache und stellen Sie erneut eine Verbindung zu WLAN oder Bluetooth her, falls Sie diese verwenden. Ihre microSD-Karte wird normalerweise in Ruhe gelassen, aber überprüfen Sie sie, bevor Sie sich darauf verlassen.

Wenn der Player eingefroren ist

  1. Halten Sie die Stromversorgung etwa zehn Sekunden lang gedrückt. Die meisten Spieler erzwingen einen Shutdown.
  2. Wenn das nichts bringt, drücken Sie die kleine Taste Zurücksetzen Loch mit einer Nadel oder einer Büroklammer.
  3. Laden Sie es eine Stunde lang auf, schalten Sie es dann ein und versuchen Sie es erneut mit den Einstellungen.

Der Pin bringt Sie nur zurück zu einem laufenden Spieler. Die Software wird nicht zurückgesetzt; Die Route „Einstellungen“ funktioniert.

Wenn der Player überhaupt nicht startet

Ein Reset kann nicht auf einem Player ausgeführt werden, der nie den Startbildschirm erreicht. Das ist ein Softwareproblem, kein Einstellungsproblem. Benutzen Innioasis Updater CE um die Originalsoftware für G1 wiederherzustellen, oder befolgen Sie die Anweisungen G1 Wiederherstellungsanleitung für die manuelle SP Flash Tool-Route. Wenn der Player überhaupt nicht reagiert, lesen Sie die Wiederherstellungsleitfaden zuerst.

Auf Werkseinstellungen zurücksetzen oder neu installieren?

Werksreset

Behält die installierte Software und löscht Ihre Daten. Verwenden Sie es, wenn der Player funktioniert, sich aber unordentlich oder langsam anfühlt oder in einer schlechten Einstellung hängen bleibt.

Software neu installieren

Ersetzt das System selbst. Verwenden Sie es, wenn der Player nicht startet, ein Update fehlgeschlagen ist oder wenn Sie ein benutzerdefiniertes System verlassen und zur Originalsoftware zurückkehren möchten.

Fragen, die Menschen stellen

Wird durch einen Reset meine microSD-Karte gelöscht?

Normalerweise nicht. Ein Zurücksetzen auf die Werkseinstellungen zielt auf den internen Speicher ab. Wenn Sie sicher sein möchten, entfernen Sie die Karte vor dem Zurücksetzen.

Entfernt es eine benutzerdefinierte Firmware?

Nein. Beim Zurücksetzen auf die Werkseinstellungen werden Daten im aktuellen System gelöscht. Um Rockbox oder ein anderes benutzerdefiniertes System zu entfernen, installieren Sie stattdessen die Originalsoftware neu.

Wie lange dauert es?

Ein paar Minuten. Wenn es nach zehn Jahren nicht neu gestartet wurde, laden Sie es auf und versuchen Sie es mit der Ein-/Aus-Taste. Wenn es immer noch nicht reagiert, verwenden Sie die Wiederherstellungsanleitung.
