Schritt-für-Schritt-Installation

  1. Installieren Sie Updater CE: Herunterladen Innioasis Updater CE für Windows, macOS oder Linux, dann öffnen Sie es.
  2. Wählen Sie Y2: Wählen Sie Y2 als Gerätemodell.
  3. Wählen Sie Reborn: Wählen Sie Reborn (Y2Linux) und die neueste Version.
  4. Installieren: Klicken Sie Installieren / Wiederherstellen, schalten Sie Y2 aus und schließen Sie USB an, wenn Sie dazu aufgefordert werden.
  5. Warten: Halten Sie den Player still, bis Updater CE bestätigt, und trennen Sie dann die Verbindung.
  6. Richten Sie WLAN, Bluetooth und UKW-Radio ein
