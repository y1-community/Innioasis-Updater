Android 4.2 (Dev) · Innioasis Y1

Install Android 4.2 (Dev) on a Y1.

Android 4.2 is a community development ROM for testing and hacking on the Innioasis Y1 hardware. Select Y1 before choosing it in Updater CE.

Get Updater CEGet this in Updater CEProject source

Install it

  1. Open Innioasis Updater CE on your computer (if you don't have it yet, Get Updater CE). Select Y1 in Device Model.
  2. Choose Android 4.2 (Dev) in Software (or launch with Get this in Updater CE).
  3. Select a release and click Install / Restore.
  4. Power off and connect the Y1 only when Updater prompts you.
  5. Use Y1 Original Software for the restore path.

Developer build note

Developer build: This is a development image intended for experimentation. Read the repository release notes for current hardware support and known issues.
