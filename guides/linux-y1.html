Linux (Dev) · Innioasis Y1

Install Linux on a Y1.

Linux for Y1 is an experimental community Linux kernel and rootfs port for the Innioasis Y1. Select Y1 before choosing it in Updater CE.

Get Updater CEGet this in Updater CEProject source

Install it

  1. Open Innioasis Updater CE on your computer (if you don't have it yet, Get Updater CE). Select Y1 in Device Model.
  2. Choose Linux for Y1 (Dev) in Software (or launch with Get this in Updater CE).
  3. Select a release and click Install / Restore.
  4. Power off and connect the Y1 only when Updater prompts you.
  5. Use Y1 Original Software for the restore path.

Experimental Port

Experimental build: This is a barebones Linux port intended for developers and enthusiasts. Refer to the project repository for UART and console details.
