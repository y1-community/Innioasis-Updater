Install it

  1. Open Innioasis Updater CE on your computer (if you don't have it yet, Get Updater CE). Select Y1 in Device Model.
  2. Choose Linux for Y1 (Dev) in Software (or launch with Get this in Updater CE).
  3. Select a release and click Install / Restore.
  4. Power off and connect the Y1 only when Updater prompts you.
  5. Use Y1 Original Software for the restore path.

Experimental build: This is a barebones Linux port intended for developers and enthusiasts. UART and console details are in the project docs.
