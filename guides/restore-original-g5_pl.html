Krok 1: Przygotuj swój komputer

Innioasis Updater CE działa natywnie w systemach Windows, macOS i Linux bez konieczności stosowania skomplikowanych wiązek do flashowania:

  1. Uruchom Innioasis Aktualizator CE na komputerze stacjonarnym lub laptopie.
  2. Zestaw Model urządzenia do G5.
  3. Wybierz Oprogramowanie oryginalne na liście rozwijanej oprogramowania. Updater CE automatycznie pobiera oficjalną wersję rom_g5.zip wypuść pakiet bezpośrednio.
  4. Kliknij Zainstaluj / Przywróć aby rozpocząć przygotowania.

Krok 2: Podłącz G5 po wyświetleniu monitu

Nigdy nie podłączaj odtwarzacza, zanim aplikacja nie wyświetli monitu:

  1. Upewnij się, że urządzenie Innioasis G5 jest całkowicie wyłączone.
  2. Gdy program Updater wyświetli monit o połączenie USB, podłącz kabel danych USB-C do komputera i odtwarzacza.
  3. Nie dotykaj kabla ani przycisków zasilania podczas flashowania.
  4. Po wyświetleniu potwierdzenia powodzenia odłącz kabel USB i włącz urządzenie G5.
