Wählen Sie die Route Y2.

  1. Öffnen Sie Innioasis Updater CE auf Ihrem Computer (falls Sie es noch nicht haben, Updater CE holen). Auswählen Y2 In Gerätemodell.
  2. Wählen Sie Solar In Software (oder starten Sie mit In Updater CE erhalten).
  3. Lesen Sie die Versionshinweise, bestätigen Sie den Eintrag Y2 und klicken Sie auf Installieren / Wiederherstellen.
  4. Schalten Sie den Player nur aus und schließen Sie ihn an, wenn der Updater Sie dazu auffordert.
  5. Mit Y2 wiederherstellen Original-Software wenn Sie die Standardschnittstelle erneut benötigen.

Behalten Sie die Projektnotiz im Blick

Solar befindet sich in der aktiven Entwicklung. Funktionen und Modellunterstützung können sich ändern. Sehen Sie sich daher die Versionshinweise des Projekts an. Der Updater zeigt, was derzeit für Ihr Modell verfügbar ist. Ersetzen Sie kein Y1-Paket, wenn der Eintrag Y2 fehlt.

Gehen Sie zurück zur Originalsoftware

Solar ändert die Route zurück zur Standardschnittstelle nicht. Sobald Updater für Ihren Computer eingerichtet ist, öffnen Sie es unter Windows, macOS oder Linux und wählen Sie Y2 Plus Original-Software statt Solar.

  1. Wählen Sie eine stabile Y2 Originalsoftwareversion.
  2. Klicken Sie Installieren / Wiederherstellen und warten Sie auf die Live-Verbindungsaufforderung.
  3. Schalten Sie Y2 nur aus, wenn Sie dazu aufgefordert werden.
  4. Schließen Sie bei der Aufforderung das USB-Datenkabel an und lassen Sie es bis zum Erfolg ruhen.

Entfernen Sie nicht zuerst Solar-Dateien manuell und verwenden Sie kein Y1-Paket. Wenn der Fehler vor der Eingabeaufforderung USB aufgetreten ist, überprüfen Sie zunächst die Computerkonfiguration, das Kabel und die Modellauswahl.
