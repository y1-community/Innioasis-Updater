Из Rockbox или другого специального программного обеспечения.

Как только соответствующая установка Windows, macOS или Linux будет готова, для возврата к стандартному интерфейсу Y2 будет использоваться тот же процесс обновления, что и для установки проекта сообщества. Не смешивайте Y1 файлы вручную в плеере и не удаляйте предварительно системные папки.

  1. Откройте Innioasis Updater CE на своем компьютере (если он еще не установлен, Скачать Updater CE для Окна, macOS, или Линукс).
  2. Набор Модель устройства в адрес Y2.
  3. Выбирать Заводское ПО.
  4. Выберите стабильную версию Y2. Пакеты полной установки вручную могут использовать rom_y2.zip.
  5. Нажмите Установить / Восстановить и дождитесь этапа извлечения.
Не заменяйте: а Y1 rom.zip не является пакетом Y2. Если список выпусков выглядит неправильно, остановитесь и повторно выберите Y2.

Следуйте инструкциям по подключению

Windows, macOS и Linux имеют разные примечания по настройке компьютера, но последовательность действий на стороне игрока остается той же: выключите питание, когда вас спросят, затем подключите кабель для передачи данных по запросу в реальном времени.

  1. Полностью выключите Y2 по запросу программы обновлений.
  2. Подключайте USB только тогда, когда приложение сообщит, что оно готово.
  3. Оставьте кабель в покое до сообщения об успехе.
  4. Безопасно отключитесь и запустите плеер.

Все еще застрял?

Прежде чем использовать ручной инструмент, проверьте модель, упаковку, кабель и время подключения. руководство по устранению неполадок объясняет, что означает сбой до USB по сравнению с сбоем после обнаружения устройства.

Храните пакеты отдельно: а Y1 rom.zip не является восстановлением Y2. Если список выпусков выглядит неправильно, остановитесь и снова выберите Y2.
