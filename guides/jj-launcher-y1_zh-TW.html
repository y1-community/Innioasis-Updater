選擇Y1路線

  1. 在您的電腦上開啟 Innioasis Updater CE（如果您還沒有， 取得 Updater CE）。選擇 Y1 在 裝置型號.
  2. 選擇 JJ Launcher 在 軟體 （或啟動 在 Updater CE 中取得此內容).
  3. 閱讀發行說明，選擇 Y1 版本，然後按一下 安裝 / 還原.
  4. 僅當更新程式要求時關閉並連接播放器。
  5. 使用 Y1 恢復 原廠軟體 如果您再次需要庫存接口。

模型不匹配是首先要檢查的事情

JJ Launcher 也有一個 Y2 條目。如果套件名稱看起來錯誤，請返回裝置模型。不要將 Y2 包強行放到 Y1 上。

返回原始軟體

JJ Launcher 不會變更返回庫存介面的路由。為您的電腦設定更新程式後，請在 Windows、macOS 或 Linux 上開啟它，然後選擇 Y1 加號 原廠軟體 而不是 JJ Launcher。

  1. 選擇穩定的 Y1 原始軟體版本。
  2. 點選 安裝 / 還原 並等待即時連線提示。
  3. 僅在詢問時關閉 Y1 電源。
  4. 根據提示連接USB數據線並保持不動直至成功。

不要先手動刪除 JJ Launcher 文件，並且不要使用 Y2 套件。如果故障發生在USB提示之前，請先檢查電腦設定、電纜和型號選擇。
