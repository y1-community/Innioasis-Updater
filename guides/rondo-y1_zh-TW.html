逐步安裝

  1. 開啟更新程式CE： 發射 Innioasis 更新程式 CE 在您的 Windows、macOS 或 Linux 電腦上。
  2. 選擇設備型號 Y1： 選擇 Y1 在裝置型號下拉清單中（如果您的 Y1 附帶 2.0.0 之前的原始軟體，請選擇 Type B；否則保留 Type A）。
  3. 從軟體下拉清單中選擇 Rondo： 選擇 Rondo 在软件列表中并选择最新版本。更新程式 CE 使用 Android 4.2 Wi-Fi 基礎 ROM 和 Rondo 自動發布來源。
  4. 閃光播放器： 點選 安裝 / 還原，完全關閉 Y1 電源，並在 Updater CE 提示時透過 USB 數據線連接。
  5. 斷開連線並啟動： 在拔下 Y1 之前，請等待綠色完成訊息。
  6. 完成安裝後設定
