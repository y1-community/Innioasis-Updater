التثبيت خطوة بخطوة

  1. افتح برنامج التحديث CE: إطلاق Innioasis برنامج التحديث CE على جهاز الكمبيوتر الذي يعمل بنظام التشغيل Windows أو macOS أو Linux.
  2. اختر طراز الجهاز Y1: اختر Y1 في القائمة المنسدلة طراز الجهاز (اختر Type B إذا تم شحن Y1 مع البرنامج الأصلي الأقدم من 2.0.0؛ وإلا احتفظ بـ Type A).
  3. اختر Rondo من القائمة المنسدلة للبرنامج: اختر Rondo في قائمة البرامج واختر الإصدار الأحدث. يستخدم Updater CE قاعدة Android 4.2 Wi-Fi ROM وخلاصة الإصدار Rondo تلقائيًا.
  4. فلاش المشغل: انقر تثبيت / استعادة، قم بإيقاف تشغيل Y1 الخاص بك تمامًا، وقم بتوصيله عبر كابل بيانات USB عندما يطالبك Updater CE.
  5. قطع الاتصال والتمهيد: انتظر رسالة الإكمال الخضراء قبل فصل Y1.
