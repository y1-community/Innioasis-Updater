Le nom du projet est partagé, mais le package disponible dépend toujours du fait que votre lecteur soit un Y1 ou un Y2. Choisissez votre modèle ci-dessous et le guide correspondra au package.

Quel guide dois-je utiliser ?

Les lecteurs Y1 et Y2 installent JJ Launcher via Innioasis Updater CE (si vous avez besoin de l'application, Obtenir Updater CE pour votre PC, ou lancez-le avec Disponible dans Updater CE). Choisissez votre modèle ci-dessous :

Innioasis Y1

Suivez l'itinéraire Y1 spécifique au modèle et conservez le package Y1 sélectionné.

Y1 étapes d'installation

Innioasis Y2

Suivez l'itinéraire Y2 spécifique au modèle et conservez le package Y2 sélectionné.
