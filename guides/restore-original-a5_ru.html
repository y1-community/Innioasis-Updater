Восстановите исходное программное обеспечение на Innioasis и Timmkoo A5

Следуйте этому руководству, чтобы восстановить официальное заводское программное обеспечение на вашем проигрывателе Innioasis A5 или Timmkoo A5 с помощью проверенных пакетов из Innioasis архива прошивки.

Скачать Updater CE Посмотреть A5 загрузок

Шаг 1. Настройка в Updater CE

  1. Запуск Innioasis Программа обновления CE на вашем компьютере с Windows, macOS или Linux.
  2. Набор Модель устройства в адрес A5.
  3. Выбирать Заводское ПО. Updater CE скачивает официальную rom_a5.zip выпустить пакет напрямую.
  4. Нажмите Установить / Восстановить и дождитесь завершения подготовки.

Шаг 2. Подключитесь по запросу

  1. Полностью выключите устройство A5.
  2. Прежде чем подключать кабель для передачи данных USB, дождитесь сообщения на экране компьютера.
  3. Позвольте процессу перепрошивки завершиться без перерыва.
  4. Отключите и перезагрузите только что восстановленный A5 плеер.
