Y1 ルートを選択してください

  1. コンピュータで Innioasis Updater CE を開きます (まだお持ちでない場合は、 Updater CE を入手）。選択 Y1 で デバイスモデル.
  2. 選択してください JJ Launcher で ソフトウェア (または次のように起動します) Updater CE で入手).
  3. リリース ノートを読み、Y1 バージョンを選択して、 インストール / 復元.
  4. アップデーターが要求した場合にのみ、プレーヤーの電源を切り、接続してください。
  5. Y1 で復元します 純正ソフトウェア ストックインターフェイスが再度必要な場合。

ビデオを見る

doitall によるビデオ。 Innioasis Y1 に JJ Launcher をインストールする方法と、インストールのトラブルシューティングを示しています。以下に記載されている手順は Y1 と Y2 を対象としています。

最初に確認するのはモデルの不一致です

JJ Launcher には Y2 エントリもあります。パッケージ名が間違っていると思われる場合は、「デバイス モデル」に戻ります。 Y2 パッケージを Y1 に無理に押し付けないでください。

元のソフトウェアに戻る

JJ Launcher は、ストック インターフェイスに戻るルートを変更しません。コンピューターにアップデーターをセットアップしたら、Windows、macOS、または Linux 上でアップデーターを開いて、 Y1 プラス 純正ソフトウェア JJ Launcher の代わりに。

  1. 安定した Y1 オリジナル ソフトウェア リリースを選択してください。
  2. クリック インストール / 復元 そして、ライブ接続プロンプトが表示されるまで待ちます。
  3. Y1 の電源をオフにするのは、要求された場合のみにしてください。
  4. プロンプトで USB データ ケーブルを接続し、成功するまでそのままにしておきます。

最初に JJ Launcher ファイルを手動で削除したり、Y2 パッケージを使用したりしないでください。 USB プロンプトが表示される前に障害が発生した場合は、まずコンピューターのセットアップ、ケーブル、モデルの選択を確認してください。
