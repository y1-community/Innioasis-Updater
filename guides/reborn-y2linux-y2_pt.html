Instalação passo a passo

  1. Instalar Updater CE: Download Innioasis Atualizador CE para Windows, macOS ou Linux e abra-o.
  2. Selecione Y2: Escolher Y2 como o modelo do dispositivo.
  3. Selecione Reborn: Escolher Reborn (Y2Linux) e o último lançamento.
  4. Instalar: Clique Instalar / Restaurar, desligue o Y2 e conecte USB quando solicitado.
  5. Espere: Mantenha o player imóvel até que Updater CE confirme e depois desconecte.
  6. Configurar Wi-Fi, Bluetooth e rádio FM

    Copiar system.img para o jogador uma vez. Reborn faz o resto.
