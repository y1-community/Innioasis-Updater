Da Rockbox o da un altro software personalizzato

Una volta pronta la configurazione Windows, macOS o Linux pertinente, Updater utilizza la stessa installazione guidata per un ripristino stock come per l'installazione di un software personalizzato. Non è necessario eliminare prima manualmente Rockbox o i file di un altro software personalizzato.

  1. Apri Innioasis Updater CE sul tuo computer (se non lo hai ancora installato, Ottieni Updater CE per Finestre, macOS, o Linux).
  2. Impostato Modello del dispositivo a Y1.
  3. Scegli Software originale dentro Software (o utilizzare Ottieni questo in Updater CE).
  4. Scegli l'ultima versione stabile Y1. Il solito pacchetto manuale è rom.zip. Type A copre Y1 lettori forniti con la versione del software originale 2.0.0 o successiva; Type B copre i lettori forniti con una versione precedente di Software originale e può utilizzare un nome di pacchetto più specifico.
  5. Fare clic Installa / Ripristina e attendi l'estrazione del pacchetto.

Collegare Y1 quando richiesto

Il sistema operativo modifica la configurazione dell'Updater, non il percorso di ripristino stesso. Su ogni piattaforma, attendi il messaggio live prima di connetterti.

  1. Spegnere completamente il lettore quando richiesto dall'Updater.
  2. Collegare il cavo dati USB solo quando richiesto.
  3. Non toccare il lettore durante l'esecuzione dell'installazione.
  4. Disconnettersi dopo il messaggio di successo e avviare Y1.

Se ancora non si avvia

Ripetere il ripristino una volta con il modello, il tipo e la versione selezionati. Se il programma di aggiornamento fallisce prima del prompt USB, controllare la configurazione del computer, il driver o le autorizzazioni, il cavo dati e i file estratti. Se fallisce dopo aver rilevato Y1, utilizzare il file guida alla risoluzione dei problemi prima di passare al ripristino manuale SP Flash Tool o MTKClient.

Non passare ai file Y2. Un ripristino Y1 richiede una versione del software originale Y1, anche se il lettore sta attualmente utilizzando un software personalizzato diverso.
