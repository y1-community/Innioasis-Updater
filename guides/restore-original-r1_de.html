Was Sie brauchen

  • Ein Windows-, macOS- oder Linux-Computer. Updater CE läuft auf allen dreien.
  • Das mit dem Player gelieferte USB-Datenkabel. Nur-Ladekabel funktionieren nicht.
  • Der Beamte rom_r1.zip Paket, das Updater für Sie herunterlädt, oder eine Kopie von R1 Archiv wenn Sie lieber von Hand flashen möchten.
  • Laden Sie den Player auf. Eine Wiederherstellung, bei der die Stromversorgung verloren geht, ist die einzige Möglichkeit, eine schlechte Situation noch schlimmer zu machen.

Dadurch wird das System ersetzt und der interne Speicher gelöscht. Kopieren Sie Musik, Aufnahmen und Fotos zunächst auf einen Computer.

Route A: Updater CE (empfohlen)

  1. Installieren Innioasis Updater CE und öffne es.
  2. Satz Gerätemodell an R1. Das Modell muss genau zum Spieler passen.
  3. Wählen Sie Original-Software in der Softwareliste.
  4. Wählen Sie eine Veröffentlichung. Der neueste stabile Build ist der sichere Standard.
  5. Drücken Sie Installieren / Wiederherstellen und warten Sie, während das Paket heruntergeladen und extrahiert wird.
  6. Schalten Sie den Player vollständig aus und schließen Sie das USB-Kabel erst an, wenn der Updater Sie dazu auffordert.
  7. Berühren Sie weder den Player noch das Kabel, bis die Erfolgsmeldung erscheint. Trennen Sie den Player und starten Sie ihn.
Wählen Sie niemals ein anderes Modell, um „es zum Laufen zu bringen“. Ein R1 benötigt ein R1-Paket. Durch das Mischen von Modellen benötigen Spieler letztendlich eine manuelle Wiederherstellung.

Route B: SP Flash Tool (manuell)

Verwenden Sie dies, wenn ein Computer Updater CE nicht ausführen kann oder wenn Sie das Paket bereits haben und das klassische Tool bevorzugen.

  1. Herunterladen rom_r1.zip aus dem R1 Archiv und entpacken Sie es.
  2. Bewahren Sie die Scatter-Datei neben den Bildern auf. Benennen Sie die Bilder nicht um oder verschieben Sie sie nicht.
  3. Öffnen Sie SP Flash Tool und wählen Sie Nur herunterladen, und laden Sie die Scatter-Datei.
  4. Schalten Sie den Player aus und drücken Sie Herunterladen, und schließen Sie dann das Kabel an.
  5. Warten Sie auf die grüne Erfolgsmarkierung, bevor Sie die Verbindung trennen.

Die SP Flash Tool Anleitung behandelt Treiber und die Windows-Eingabeaufforderungen ausführlicher. Unter Linux und macOS ist Updater CE der einfachere Weg, da es über ein eigenes USB-Handling verfügt.

Nach der Wiederherstellung

  1. Trennen Sie den Player vom Computer und lassen Sie ihn selbstständig starten.
  2. Wählen Sie Ihre Sprache und stellen Sie die Uhr ein.
  3. Stellen Sie erneut eine Verbindung zu WLAN oder Bluetooth her, wenn Sie diese verwenden.
  4. Kopieren Sie Ihre Musik zurück. Die Transferführer hat die Ordnernamen.

Wenn der Player startet, aber der Bildschirm, das Rad oder die Tasten immer noch nicht funktionieren, hat die Wiederherstellung funktioniert; Das ist eine Hardware- oder Setup-Frage, keine Software-Frage. Die Anleitung zur Fehlerbehebung ist die nächste Station.

Wenn es nicht funktioniert

Der Updater sieht den Player nie

Wechseln Sie das Kabel und dann den USB-Anschluss. Vermeiden Sie Hubs. Installieren Sie unter Windows den Treiber MediaTek von Treiberseite.

Der Blitz stoppt vorzeitig

Stellen Sie die Verbindung wieder her, laden Sie den Player auf und beginnen Sie erneut. Wechseln Sie nicht zu einem anderen Modellpaket.

Der Spieler bleibt schwarz

Laden Sie das Gerät eine Stunde lang auf und halten Sie es dann zehn Sekunden lang aufrecht. Wenn es immer noch tot ist, lesen Sie das Wiederherstellungsleitfaden bevor Sie es erneut versuchen.

Fragen, die Menschen stellen

Wird dadurch meine Musik gelöscht?

Ja, der interne Speicher wird gelöscht. Dateien auf einer microSD-Karte bleiben normalerweise erhalten, aber kopieren Sie sie zuerst an einen sicheren Ort.

Kann ich danach zu Rockbox zurückkehren?

Ja. Die Wiederherstellung der Originalsoftware ist keine Einbahnstraße; Auf der Seite „Benutzerdefinierte Software“ für Ihr Modell können Sie es erneut installieren.

Benötige ich die Einstellung Type A / Type B?

Nur das Y1 hat diese Wahl und nur für Originalsoftware. Jedes andere Modell verwendet ein einzelnes Paket.
