你需要什麼

一個 Innioasis Y1、一塊充滿電的電池、一根 USB 數據線和一台安裝了 Innioasis Updater CE 的計算機（如果您尚未安裝， 取得 Updater CE 適用於 Windows、macOS 或 Linux）。 Type A 適合 Y1 隨附原始軟體版本 2.0.0 或更高版本的播放器； Type B 適合使用早期版本的玩家 原廠軟體。從 Type A 開始，除非您已經知道您的玩家需要 Type B 版本。

觀看 Rockbox 路線

影片由弗勞吉斯拍攝。它適用於 Y1 和 Y2 型號 - 在 Innioasis Updater CE 中，選擇 Y1 作為你的模型。以下的書面步驟涵蓋了 Y1 安裝順序。

影片由 克里斯蒂安廣場 （西班牙文），從 Rockbox 安裝階段開始。以下的書面步驟涵蓋了 Y1 序列。

在更新程式中

  1. 開啟 Updater CE（或使用下列命令啟動 在 Updater CE 中取得此內容）並設定 裝置型號 到 Y1.
  2. 選擇 Rockbox 在 軟體。確切的項目標籤在發布資料中可能顯示為 Rockbox-Y1。
  3. 選擇一個穩定的版本。 240p 版本具有最廣泛的舊主題相容性；360p 版本適用於 Y1 主題路徑。當差異很重要時，請檢查發行說明。
  4. 點選 安裝 / 還原。等待 Updater CE 直接從社群開發人員的版本下載軟體包並準備它。

連接 Y1

  1. 等待更新程式詢問播放器。
  2. 將 Y1 完全關閉。如果無法關閉，請使用更新程式顯示的恢復指令。
  3. 僅當應用程式提示時才連接 USB 資料線。將播放器放下，不要幹擾連線。
  4. Updater確認成功後才斷開連接，然後啟動Y1。

返回原始軟體

Rockbox 不會將您鎖定在自訂軟體中。為您的電腦設定更新程式後，請在 Windows、macOS 或 Linux 上使用它：選擇 Y1， 選擇 原廠軟體，然後運行 安裝 / 還原.

  1. 等待更新程序完成庫存包的準備。
  2. 當應用程式詢問時，關閉 Y1 電源。
  3. 僅在出現即時提示時連接 USB 數據線。
  4. 讓玩家保持靜止，直到出現成功訊息。

請勿使用 Y2 軟體包，也不要在恢復前手動刪除 Rockbox 檔案。對於 Type B 輪行為，請在變更裝置類型之前檢查符合的版本變體。
