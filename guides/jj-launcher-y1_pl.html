Wybierz trasę Y1.

  1. Otwórz Innioasis Updater CE na swoim komputerze (jeśli jeszcze go nie masz, Pobierz Updater CE). Wybierz Y1 w Model urządzenia.
  2. Wybierz JJ Launcher w Oprogramowanie (lub uruchom za pomocą Zdobądź to w Updater CE).
  3. Przeczytaj informację o wydaniu, wybierz wersję Y1 i kliknij Zainstaluj / Przywróć.
  4. Wyłącz i podłącz odtwarzacz tylko wtedy, gdy aktualizator o to poprosi.
  5. Przywróć za pomocą Y1 Oprogramowanie oryginalne jeśli potrzebujesz ponownie interfejsu podstawowego.

Pierwszą rzeczą do sprawdzenia jest niedopasowanie modelu

JJ Launcher also has a Y2 entry. If the package name looks wrong, return to Device Model. Do not force a Y2 package onto a Y1.

Wróć do oryginalnego oprogramowania

JJ Launcher nie zmienia trasy z powrotem do standardowego interfejsu. Po skonfigurowaniu narzędzia Updater na komputerze otwórz go w systemie Windows, macOS lub Linux i wybierz Y1 plus Oprogramowanie oryginalne zamiast JJ Launcher.

  1. Wybierz stabilną Y1 oryginalną wersję oprogramowania.
  2. Kliknij Zainstaluj / Przywróć i poczekaj na monit o połączenie na żywo.
  3. Wyłącz Y1 tylko wtedy, gdy zostaniesz o to poproszony.
  4. Po wyświetleniu monitu podłącz kabel danych USB i pozostaw go nieruchomo, aż do powodzenia.

Nie usuwaj najpierw ręcznie plików JJ Launcher i nie używaj pakietu Y2. Jeśli awaria wystąpiła przed pojawieniem się monitu USB, sprawdź najpierw konfigurację komputera, kabel i wybór modelu.
