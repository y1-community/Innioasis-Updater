段階的なインストール

  1. Updater CE を開きます: 打ち上げ Innioasis アップデーター CE Windows、macOS、または Linux コンピューター上で。
  2. デバイス モデル Y1 を選択してください: 選択 Y1 [デバイス モデル] ドロップダウンで (Y1 が 2.0.0 より前のオリジナル ソフトウェアに同梱されている場合は Type B を選択します。それ以外の場合は Type A のままにします)。
  3. [ソフトウェア] ドロップダウンから Rondo を選択します。 選択 Rondo ソフトウェア リストで最新のリリースを選択します。 Updater CE は、Android 4.2 Wi-Fi ベース ROM および Rondo リリース フィードを自動的に使用します。
  4. プレーヤーをフラッシュします。 クリック インストール / 復元Updater CE のプロンプトが表示されたら、Y1 の電源を完全にオフにし、USB データ ケーブルを介して接続します。
  5. 切断して起動します。 Y1 のプラグを抜く前に、緑色の完了メッセージが表示されるまで待ちます。
  6. インストール後のセットアップを完了する
