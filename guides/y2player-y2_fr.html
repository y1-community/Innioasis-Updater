Dans le programme de mise à jour

  1. Ouvrez Innioasis Updater CE sur votre ordinateur (si vous ne l'avez pas encore, Obtenir Updater CE). Sélectionnez Y2 dans Modèle d'appareil.
  2. Choisissez Y2Player dans Logiciel (ou lancer avec Disponible dans Updater CE).
  3. Choisissez la version Y2 répertoriée.
  4. Cliquez Installer / Restaurer, éteignez-le lorsque vous y êtes invité et connectez USB à l'invite.
  5. Restaurer avec Y2 Logiciel d'origine si nécessaire.

Ne remplacez pas un package Y1

Vérifiez deux fois : Y2 les packages d'installation complète peuvent utiliser rom_y2.zip. Un simple package Y1 n'est pas un substitut sûr.
