プレイヤーの回復 · Innioasis Y2

Innioasis Y2 がオンになりません

黒い画面は必ずしもプレイヤーが死亡したことを意味するわけではありません。手動フラッシュを試す前に、充電、強制再起動、コンピューターでの検出を行ってください。

Updater CE を入手ファームウェアのダウンロードリカバリガイド

何よりもまず Y2 を適切に充電してください

「Y2 の電源が入らない」レポートのほとんどは、バッテリー切れ、充電専用ケーブル、または十分な電流を供給できない充電器です。 Y2 が深く消耗している場合、画面に何も表示されるまでに電源を入れてから 20 ～ 30 分かかることがあります。

  • 既知の USB を使用します データ 充電専用ケーブルではありません。
  • 壁の充電器を試してから、ハブではなくコンピュータの USB ポートを直接試してください。
  • 30 ～ 60 分間接続したままにし、充電アイコンまたはバックライトを監視します。
  • 次に進む前に、2 番目のケーブルと充電器を試してください。

強制的に再起動する

電源ボタンを約 15 秒間押して放し、5 秒待ってから電源を 1 回押します。これにより、ブートのハングが解消され、安全に繰り返し実行できます。

画面にロゴが表示されてから黒くなった場合は、プレーヤーが起動していて失敗しています。以下のファームウェアの復元に進んでください。何も起こらない場合は、充電したままにして、30 分後にもう一度試してください。

コンピュータがプレーヤーを認識できるかどうかを確認する

電源がオフになっている Y2 をデータ ケーブルで接続し、Windows でデバイス マネージャーを開きます。 lsusb Linux では MTKClient、macOS では MTKClient。動作中のプレーヤーは、ベンダー ID を持つ MediaTek デバイスとして表示されます 0e8d。表示された場合は、画面が暗いままでもハードウェアが再フラッシュできるほど生きています。

何も表示されない場合は、まず MediaTek ドライバーを Windows にインストールします。 ドライバーガイド Windows と Linux の権限について説明します。

Y2 ストック ファームウェアを復元します

プレーヤーが検出されても起動しない場合は、Y2 オリジナル ソフトウェアを再インストールしてください。 Y2 パッケージのみを使用してください。 Y1 ビルドは Y2 ハードウェアでは開始されません。

  1. 開く アップデーター CE あなたのコンピュータ上で。
  2. セット デバイスモデル 支援先: Y2.
  3. 選択してください 純正ソフトウェア で ソフトウェア 安定版 Y2 リリースを選択します。マニュアル パッケージは次のとおりです。 rom_y2.zip.
  4. クリック インストール / 復元 そしてパッケージを解凍します。
  5. Y2 の電源を完全にオフにし、アップデーターが要求した場合にのみ USB データ ケーブルを接続し、成功メッセージが表示されるまでそのままにしておきます。
電力を安定して保ちます。 フラッシュの電力が失われると、プレーヤーが使用できなくなる可能性があります。まず充電してからコンピュータに直接接続してください。

アップデーターがプレーヤーを認識できない場合の手動回復

Updater CE には、ガイド付きインストールが完了できない場合に備えた手動回復ツールが含まれています。 SP Flash Tool は Windows と Linux x86 にバンドルされており、MTKClient ルートは macOS をカバーします。どちらも、モデルに一致するファームウェア パッケージが必要です。 ファームウェアのダウンロード ページ。

スキャッタ ファイルやオフセットを即興で作成するのではなく、プラットフォームのツール ガイドに従ってください。どのツールでもプレーヤーが検出されない場合は、バッテリー、充電ポート、またはボードに障害がある可能性があります。

それでも起動しない場合は

点滅を停止し、ハードウェアとして扱います。ケースを開けたり、バッテリーを押したりしないでください。モデルを使用してコミュニティに、画面の機能、コンピュータがそれを検出するかどうか、どのパッケージを試したかを尋ねます。 Discord コミュニティ サービスルートを特定するのに役立ちます。

在庫復元ではシステムが置き換えられるため、フラッシュする前にプレーヤーの内部メモリに保存されているものをすべてバックアップしてください。 MicroSD カード上の音楽は復元の対象になりません。

Innioasis Y2 電力に関するよくある質問

Innioasis Y2 がオンにならないのはなぜですか?

通常の原因は、バッテリーが完全に消耗していること、充電専用のケーブルまたは充電器が弱いこと、起動を停止するファームウェアのクラッシュ、またはハードウェアの障害です。プレーヤーが故障したと判断する前に、既知のデータ ケーブルを使用して 30 分間充電してください。

Innioasis Y2 を強制的に再起動するにはどうすればよいですか?

電源ボタンを約 15 秒間押して放し、5 秒待ってから電源を 1 回押します。何も表示されない場合は、充電したままにして、30 分後にもう一度試してください。

電源が入らない Y2 を回復できますか?

多くの場合、そうです。コンピュータが依然として MediaTek デバイスを検出する場合は、Updater CE を使用して Y2 オリジナル ソフトウェア パッケージを再インストールします。検出されない場合は、Updater CE に含まれる SP Flash Tool または MTKClient リカバリと、モデルに一致する Y2 ファームウェア ファイルを使用してください。

Y2は点滅する前に充電する必要がありますか?

はい。フラッシュの電力が失われると、プレーヤーが使用できなくなる可能性があります。まず充電し、ハブを介さずにコンピューターに直接接続します。
