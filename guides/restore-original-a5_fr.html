Restaurer le logiciel d'origine sur Innioasis et Timmkoo A5

Suivez ce didacticiel pour restaurer le logiciel d'usine officiel sur votre lecteur Innioasis A5 ou Timmkoo A5 avec les packages vérifiés de l'archive du micrologiciel Innioasis.

Obtenir Updater CE Afficher A5 téléchargements

Étape 1 : Configuration dans Updater CE

  1. Lancement Innioasis Programme de mise à jour CE sur votre ordinateur Windows, macOS ou Linux.
  2. Ensemble Modèle d'appareil à A5.
  3. Sélectionnez Logiciel d'origine. Updater CE télécharge le fichier officiel rom_a5.zip publier le package directement.
  4. Cliquez Installer / Restaurer et attendez la fin de la préparation.

Étape 2 : Connectez-vous à l'invite

  1. Éteignez complètement l'appareil A5.
  2. Attendez l'invite sur l'écran de votre ordinateur avant de connecter le câble de données USB.
  3. Laissez le processus de clignotement se terminer sans interruption.
  4. Déconnectez et redémarrez votre lecteur A5 fraîchement restauré.
