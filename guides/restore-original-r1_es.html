lo que necesitas

  • Una computadora con Windows, macOS o Linux. Updater CE se ejecuta en los tres.
  • El cable de datos USB que viene con el reproductor. Los cables de sólo carga no funcionarán.
  • El funcionario rom_r1.zip paquete, que Updater descarga por usted, o una copia del R1 archivo si prefieres flashear a mano.
  • Carga en el reproductor. Una restauración que pierde potencia es la única forma común de empeorar una situación mala.

Esto reemplaza el sistema y borra el almacenamiento interno. Primero copie música, grabaciones y fotografías a una computadora.

Ruta A: Updater CE (recomendada)

  1. Instalar Innioasis Actualizador CE y ábrelo.
  2. conjunto Modelo del dispositivo a R1. El modelo debe coincidir exactamente con el jugador.
  3. elegir Software original en la lista de Software.
  4. Elija un comunicado. La versión estable más nueva es la predeterminada segura.
  5. prensa Instalar / Restaurar y espere mientras el paquete se descarga y extrae.
  6. Apague el reproductor por completo y luego conecte el cable USB solo cuando el Actualizador lo solicite.
  7. No toque el reproductor ni el cable hasta que aparezca el mensaje de éxito. Desconecta e inicia el reproductor.
Nunca elijas un modelo diferente para "hacer que funcione". Un R1 necesita un paquete R1. Mezclar modelos es la forma en que los jugadores terminan necesitando una recuperación manual.

Ruta B: SP Flash Tool (manual)

Úselo cuando una computadora no pueda ejecutar Updater CE, o cuando ya tenga el paquete y prefiera la herramienta clásica.

  1. Descargar rom_r1.zip desde el R1 archivo y descomprímelo.
  2. Mantenga el archivo de dispersión junto a las imágenes. No cambie el nombre ni mueva las imágenes.
  3. Abra SP Flash Tool, elija Descargar sóloy cargue el archivo de dispersión.
  4. Apague el reproductor, presione Descargary luego conecte el cable.
  5. Espere a que aparezca la marca verde de éxito antes de desconectarse.

el SP Flash Tool guía Cubre los controladores y las indicaciones de Windows con más detalle. En Linux y macOS, Updater CE es la ruta más fácil porque trae su propio manejo de USB.

Después de la restauración

  1. Desconecta el reproductor y deja que se inicie solo.
  2. Elige tu idioma y configura el reloj.
  3. Vuelva a conectarse a Wi-Fi o Bluetooth si los usa.
  4. Copia tu música nuevamente. el guía de transferencia tiene los nombres de las carpetas.

Si el reproductor se inicia pero la pantalla, la rueda o los botones aún funcionan mal, la restauración funcionó; Esa es una cuestión de hardware o configuración, no de software. el guía de solución de problemas es la siguiente parada.

Si no funciona

El actualizador nunca ve al jugador

Cambie el cable, luego el puerto USB. Evite los centros. En Windows, instale el controlador MediaTek desde el página del conductor.

El flash se detiene temprano

Vuelva a conectarse, cargue el reproductor y comience de nuevo. No cambie al paquete de un modelo diferente.

El jugador se queda negro.

Cargue durante una hora, luego mantenga la energía durante diez segundos. Si todavía está muerto, lea el guía de recuperación antes de volver a intentarlo.

Preguntas que hace la gente

¿Esto borrará mi música?

Sí, se borra el almacenamiento interno. Los archivos en una tarjeta microSD generalmente sobreviven, pero cópielos primero en un lugar seguro.

¿Puedo volver a Rockbox después?

Sí. Restaurar el software original no es una puerta unidireccional; La página de software personalizado para su modelo puede instalarlo nuevamente.

¿Necesito la configuración Type A / Type B?

Sólo el Y1 tiene esa opción, y sólo para el software original. Todos los demás modelos utilizan un solo paquete.
