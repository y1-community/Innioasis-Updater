Schritte installieren

  1. Öffnen Sie Innioasis Updater CE auf Ihrem Computer (falls Sie es noch nicht haben, Updater CE holen). Auswählen Y1 In Gerätemodell.
  2. Wählen Sie Koensayr In Software (oder starten Sie mit In Updater CE erhalten).
  3. Wählen Sie die aufgelistete Version aus und klicken Sie auf Installieren / Wiederherstellen.
  4. Schalten Sie das Y1 nur aus und schließen Sie es an, wenn die App Sie dazu auffordert.
  5. Verwenden Sie Y1 Original-Software um den Aktienpfad wiederherzustellen.

Wenn etwas scheitert

Überprüfen Sie zunächst die Modell- und Typauswahl. Überprüfen Sie dann das Kabel und ob der Player vor der Aufforderung angeschlossen war. Wenn die App gestoppt wurde, bevor sie auf USB gewartet hat, öffnen Sie sie Fehlerbehebung.
