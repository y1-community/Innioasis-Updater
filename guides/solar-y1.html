Choose the Y1 route

  1. Open Innioasis Updater CE on your computer (if you don't have it yet, Get Updater CE). Select Y1 in Device Model.
  2. Choose Solar in Software (or launch with Get this in Updater CE).
  3. Read the release note, select a version, and click Install / Restore.
  4. Power off and connect the player only when Updater asks.
  5. Restore with Y1 Original Software if you need the stock interface again.

Keep the project note in view

Solar is under active development. Features and model support can change, so check the project’s release notes. Updater shows what’s available for your model right now.

Go back to Original Software

Solar does not change the route back to the stock interface. Once Updater is set up for your computer, open it on Windows, macOS, or Linux and select Y1 plus Original Software instead of Solar.

  1. Choose a stable Y1 Original Software release.
  2. Click Install / Restore and wait for the live connection prompt.
  3. Power off the Y1 only when asked.
  4. Connect the USB data cable at the prompt and leave it still until success.

Do not manually remove Solar files first, and do not use a Y2 package. If the failure happened before the USB prompt, check the computer setup, cable, and model selection first.
