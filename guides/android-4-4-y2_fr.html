Installez-le

  1. Ouvrez Innioasis Updater CE sur votre ordinateur (si vous ne l'avez pas encore, Obtenir Updater CE). Sélectionnez Y2 dans Modèle d'appareil.
  2. Choisissez Android 4.4 (développement) dans Logiciel (ou lancer avec Disponible dans Updater CE).
  3. Sélectionnez une version et cliquez sur Installer / Restaurer.
  4. Éteignez et connectez le Y2 uniquement lorsque le programme de mise à jour vous le demande.
  5. Utiliser Y2 Logiciel d'origine pour le chemin de restauration.
