在單擊安裝之前

準備好一條已充電的 Innioasis Y2、一條 USB 數據線以及一台安裝了 Innioasis Updater CE 的計算機（如果您尚未安裝， 取得 Updater CE 適用於 Windows、macOS 或 Linux）。不要僅僅因為名稱相似而使用 Y1 版本。

型號檢查： Y2 完整安裝包可使用 rom_y2.zip。檔案名稱是有用的手動下載線索，但更新程式應該為您處理軟體包選擇。

在更新程式中選擇Y2

  1. 開啟 Updater CE（或使用下列命令啟動 在 Updater CE 中取得此內容）並設定 裝置型號 到 Y2.
  2. 選擇 Rockbox 在 軟體.
  3. 選擇 Y2 列出的版本。若未列出 Y2 版本，請勿取代 Y1 版本。
  4. 點選 安裝 / 還原 並讓Updater CE直接從社群開發者的release下載套件。

關閉電源，然後連接

  1. 等待即時連線提示。
  2. 將 Y2 完全關閉。如果正常關機失敗，請使用更新程式顯示的確切重設或恢復指令。
  3. 當詢問時連接 USB 電纜。讓它保持靜止，直到出現完成訊息。
  4. 安全斷開並啟動 Y2。

返回原始軟體

Rockbox 不會將您鎖定在自訂軟體中。為您的電腦設定更新程式後，請在 Windows、macOS 或 Linux 上使用它從 Rockbox 或其他列出的項目返回：選擇 Y2， 選擇 原廠軟體，然後運行 安裝 / 還原.

  1. 等待更新程式準備 Y2 庫存包。
  2. 當應用程式詢問時，關閉 Y2 電源。
  3. 僅在出現即時提示時連接 USB 數據線。
  4. 讓玩家保持靜止，直到出現成功訊息。

將 Y1 和 Y2 包分開。先不要手動刪除Rockbox檔案；恢復會取代系統軟體。
