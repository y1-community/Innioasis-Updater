Ripristina il software originale su Innioasis e Timmkoo A5

Segui questo tutorial per ripristinare il software di fabbrica ufficiale sul tuo lettore Innioasis A5 o Timmkoo A5 con pacchetti verificati dall'archivio firmware Innioasis.

Ottieni Updater CE Visualizza A5 download

Passaggio 1: installazione in Updater CE

  1. Lancio Innioasis Programma di aggiornamento CE sul tuo computer Windows, macOS o Linux.
  2. Impostato Modello del dispositivo a A5.
  3. Seleziona Software originale. Updater CE scarica il file ufficiale rom_a5.zip rilasciare direttamente il pacchetto.
  4. Fare clic Installa / Ripristina e attendere il completamento della preparazione.

Passaggio 2: connettersi quando richiesto

  1. Spegnere completamente il dispositivo A5.
  2. Attendere la richiesta sullo schermo del computer prima di collegare il cavo dati USB.
  3. Consentire al processo di flashing di terminare senza interruzioni.
  4. Disconnetti e riavvia il lettore A5 appena ripristinato.
