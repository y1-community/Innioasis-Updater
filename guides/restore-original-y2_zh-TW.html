來自 Rockbox 或其他自訂軟體

一旦相關的 Windows、macOS 或 Linux 設定準備就緒，返回 Y2 庫存介面將使用與安裝社群專案相同的更新程式流程。請勿手動將 Y1 檔案混合到播放器中或先刪除系統資料夾。

  1. 在您的電腦上開啟 Innioasis Updater CE（如果您尚未安裝， 取得 Updater CE 為了 窗戶, macOS, 或 Linux).
  2. 套裝 裝置型號 到 Y2.
  3. 選擇 原廠軟體.
  4. 選擇穩定的 Y2 版本。可使用手動完整安裝包 rom_y2.zip.
  5. 點選 安裝 / 還原 並等待提取步驟。
不要替代： 一個Y1 rom.zip 不是 Y2 包。如果發布清單看起來有誤，請停止並重新選擇 Y2。

依照連接提示操作

Windows、macOS 和 Linux 有不同的電腦設定說明，但播放器端順序保持不變：在詢問時關閉電源，然後根據即時提示連接資料線。

  1. 當更新程式要求時，將 Y2 完全關閉。
  2. 僅當應用程式表示已準備就緒時才連接 USB。
  3. 保持電纜不​​變，直到出現成功訊息。
  4. 安全斷開連線並啟動播放器。

還卡住了嗎？

在嘗試手動工具之前，請檢查型號、封裝、電纜和連接時序。這 故障排除指南 解釋了 USB 先前的故障與設備檢測之後的故障相比意味著什麼。
