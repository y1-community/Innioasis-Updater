Прежде чем нажать кнопку «Установить»

Имейте в наличии заряженный Innioasis Y2, кабель для передачи данных USB и компьютер с установленным Innioasis Updater CE (если вы еще не установили его, Скачать Updater CE для Windows, macOS или Linux). Не используйте выпуск Y1 только потому, что его имя похоже.

Проверка модели: Y2 пакеты полной установки могут использовать rom_y2.zip. Имя файла является полезным подсказкой для загрузки вручную, но программа обновлений должна сделать выбор пакета за вас.

Выберите Y2 в программе обновлений.

  1. Откройте Updater CE (или запустите с помощью Получите это в Updater CE) и установите Модель устройства в адрес Y2.
  2. Выбирать Rockbox в Программное обеспечение.
  3. Выберите выпуск, указанный для Y2. Если в списке нет версии Y2, не заменяйте версию Y1.
  4. Нажмите Установить / Восстановить и позвольте Updater CE загрузить пакет непосредственно из версии разработчика сообщества.

Выключите питание, затем подключите

  1. Подождите, пока появится приглашение на подключение к реальному времени.
  2. Полностью выключите Y2. Используйте точную инструкцию сброса или восстановления, показанную программой обновления, если нормальное завершение работы не удалось.
  3. Когда вас спросят, подключите кабель USB. Оставьте его до появления сообщения о завершении.
  4. Безопасно отключитесь и запустите Y2.

Вернуться к исходному программному обеспечению

Rockbox не привязывает вас к пользовательскому программному обеспечению. После настройки Updater для вашего компьютера используйте его в Windows, macOS или Linux, чтобы вернуться из Rockbox или другого проекта в списке: выберите Y2, выбирать Заводское ПОи запустить Установить / Восстановить.

  1. Подождите, пока программа обновлений подготовит стандартный пакет Y2.
  2. Выключите Y2, когда приложение спросит.
  3. Подключайте кабель передачи данных USB только при появлении подсказки в режиме реального времени.
  4. Оставьте плеер неподвижным до появления сообщения об успехе.

Пакеты Y1 и Y2 храните отдельно. Не удаляйте сначала вручную Rockbox файлов; восстановление заменяет системное программное обеспечение.
