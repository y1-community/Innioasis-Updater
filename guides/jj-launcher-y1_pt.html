Escolha a rota Y1

  1. Abra Innioasis Updater CE no seu computador (se ainda não o tiver, Obtenha o atualizador CE). Selecione Y1 em Modelo do dispositivo.
  2. Escolher JJ Launcher em Programas (ou lançar com Obtenha isso em Updater CE).
  3. Leia a nota de lançamento, selecione a versão Y1 e clique em Instalar / Restaurar.
  4. Desligue e conecte o player somente quando o Updater solicitar.
  5. Restaurar com Y1 Software Original se você precisar da interface de estoque novamente.

A incompatibilidade de modelo é a primeira coisa a verificar

JJ Launcher também possui uma entrada Y2. Se o nome do pacote parecer errado, retorne ao Modelo do Dispositivo. Não force um pacote Y2 em um Y1.

Volte para o software original

JJ Launcher não altera a rota de volta para a interface padrão. Assim que o Updater estiver configurado para o seu computador, abra-o no Windows, macOS ou Linux e selecione Y1 mais Software Original em vez de JJ Launcher.

  1. Escolha uma versão de software original estável Y1.
  2. Clique Instalar / Restaurar e aguarde o prompt de conexão ao vivo.
  3. Desligue o Y1 somente quando solicitado.
  4. Conecte o cabo de dados USB no prompt e deixe-o imóvel até obter sucesso.

Não remova manualmente os arquivos JJ Launcher primeiro e não use um pacote Y2. Se a falha ocorreu antes do prompt USB, verifique primeiro a configuração do computador, o cabo e a seleção do modelo.
