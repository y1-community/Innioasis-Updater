Z Rockbox lub innego niestandardowego oprogramowania

Gdy odpowiednia konfiguracja systemu Windows, macOS lub Linux będzie już gotowa, powrót do standardowego interfejsu Y2 wykorzystuje ten sam przepływ narzędzia Updater, co podczas instalacji projektu społecznościowego. Nie mieszaj ręcznie plików Y1 w odtwarzaczu ani nie usuwaj najpierw folderów systemowych.

  1. Otwórz Innioasis Updater CE na swoim komputerze (jeśli jeszcze go nie masz zainstalowanego, Pobierz Updater CE Do Okna, macOSlub Linuksa).
  2. Zestaw Model urządzenia do Y2.
  3. Wybierz Oprogramowanie oryginalne.
  4. Wybierz stabilną wersję Y2. Można użyć ręcznych pakietów pełnej instalacji rom_y2.zip.
  5. Kliknij Zainstaluj / Przywróć i poczekaj na etap ekstrakcji.
Nie zastępuj: Y1 rom.zip nie jest pakietem Y2. Jeśli lista wydań wygląda nieprawidłowo, zatrzymaj się i ponownie wybierz Y2.

Postępuj zgodnie z monitem o połączenie

W systemach Windows, macOS i Linux obowiązują różne uwagi dotyczące konfiguracji komputera, ale sekwencja po stronie odtwarzacza pozostaje taka sama: wyłącz zasilanie, gdy zostaniesz o to poproszony, a następnie podłącz kabel danych po wyświetleniu monitu.

  1. Całkowicie wyłącz Y2, gdy program aktualizujący poprosi o to.
  2. Połącz USB tylko wtedy, gdy aplikacja poinformuje, że jest gotowa.
  3. Zostaw kabel w spokoju do czasu pojawienia się komunikatu o powodzeniu.
  4. Odłącz bezpiecznie i uruchom odtwarzacz.

Nadal utknąłeś?

Przed wypróbowaniem narzędzia ręcznego sprawdź model, opakowanie, kabel i czas połączenia. The przewodnik rozwiązywania problemów wyjaśnia, co oznacza awaria przed USB w porównaniu z awarią po wykryciu urządzenia.

Trzymaj pakiety oddzielnie: Y1 rom.zip nie jest przywracaniem Y2. Jeśli lista wydań wygląda nieprawidłowo, zatrzymaj się i ponownie wybierz Y2.
