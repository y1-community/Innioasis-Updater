Como redefinir os padrões de fábrica de um Innioasis G5

Uma redefinição clara que mantém os arquivos bons e remove o problema. Esta página cobre a rota de configurações, a rota do jogador congelado e o único caso em que uma redefinição é a solução errada.

Antes de começar

Uma redefinição de fábrica apaga o armazenamento interno do player. Ele remove configurações, contas, listas de reprodução e qualquer arquivo armazenado no player, em vez de em um cartão microSD. Copie suas músicas e gravações primeiro para um computador. Se você deseja apenas corrigir menus lentos, use Limpar cache em vez de; ele deixa os arquivos em paz.

O orifício de redefinição não é uma redefinição de fábrica. Em modelos com um pequeno Reiniciar pino, pressioná-lo apenas força o desligamento quando o player está congelado. Não apaga dados e não restaura as configurações de fábrica.

A rota normal

  1. Copie tudo o que deseja manter em um computador. Uma redefinição apaga o armazenamento interno.
  2. Carregue o jogador pelo menos pela metade.
  3. Abrir Configurações no jogador.
  4. Escolher Redefinição de fábrica e confirme.
  5. Espere enquanto ele reinicia. Não desconecte ou segure nenhum botão.

Quando voltar, escolha seu idioma e conecte-se ao Wi-Fi ou Bluetooth novamente, se você usá-los. Seu cartão microSD geralmente é deixado sozinho, mas verifique-o antes de confiar nele.

Se o jogador estiver congelado

  1. Mantenha a energia por cerca de dez segundos. A maioria dos jogadores força um desligamento.
  2. Se isso não fizer nada, pressione o pequeno Reiniciar furo com um alfinete ou clipe de papel.
  3. Carregue por uma hora, ligue-o e tente novamente a rota Configurações.

A imobilização apenas leva você de volta a um jogador em execução. Não reinicia o software; a rota Configurações faz.

Se o jogador não iniciar

Uma redefinição não pode ser executada em um jogador que nunca chega à tela inicial. Isso é um problema de software, não um problema de configuração. Usar Innioasis Atualizador CE para restaurar o software original para G5, ou siga o G5 guia de restauração para a rota manual SP Flash Tool. Se o player não responder completamente, leia o guia de recuperação primeiro.

Redefinir ou reinstalar os padrões de fábrica?

Redefinição de fábrica

Mantém o software instalado, apaga seus dados. Use-o quando o player funciona, mas parece confuso, lento ou preso em um ambiente ruim.

Reinstale o software

Substitui o próprio sistema. Use-o quando o player não inicializar, quando uma atualização falhar ou quando você quiser sair de um sistema personalizado e retornar ao software original.

Perguntas que as pessoas fazem

Uma redefinição excluirá meu cartão microSD?

Geralmente não. Uma redefinição de fábrica tem como alvo o armazenamento interno. Remova o cartão antes de redefinir se quiser ter certeza.

Ele remove um firmware personalizado?

Não. Uma redefinição de fábrica limpa os dados do sistema atual. Para remover Rockbox ou outro sistema personalizado, reinstale o software original.

Quanto tempo leva?

Alguns minutos. Se não reiniciar depois das dez, carregue-o e experimente o botão liga / desliga; se ainda não responder, use o guia de recuperação.
