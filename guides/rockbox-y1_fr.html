Ce dont vous avez besoin

Un Innioasis Y1, une batterie chargée, un câble de données USB et un ordinateur avec Innioasis Updater CE installé (si vous ne l'avez pas encore installé, Obtenir Updater CE pour Windows, macOS ou Linux). Type A convient aux lecteurs Y1 livrés avec le logiciel d'origine version 2.0.0 ou ultérieure ; Type B convient aux joueurs livrés avec une version antérieure du Logiciel d'origine. Commencez par Type A, sauf si vous savez déjà que votre lecteur a besoin d'un build Type B.

Dans le programme de mise à jour

  1. Ouvrez Updater CE (ou lancez avec Disponible dans Updater CE) et définissez Modèle d'appareil à Y1.
  2. Choisissez Rockbox dans Logiciel. L'étiquette exacte du projet peut apparaître sous la forme Rockbox-Y1 dans les données de version.
  3. Choisissez une version stable. Les versions 240p ont la plus large compatibilité avec les thèmes plus anciens ; Les versions 360p sont destinées au chemin du thème Y1. Consultez les notes de version lorsque la distinction est importante.
  4. Cliquez Installer / Restaurer. Attendez pendant que Updater CE télécharge le package directement à partir de la version du développeur de la communauté et le prépare.

Connectez le Y1

  1. Attendez que Updater demande le lecteur.
  2. Éteignez complètement le Y1. S'il ne s'arrête pas, utilisez les instructions de récupération affichées par Updater.
  3. Connectez le câble de données USB uniquement lorsque l'application le demande. Posez le lecteur et ne perturbez pas la connexion.
  4. Déconnectez-vous uniquement après que le programme de mise à jour ait confirmé le succès, puis démarrez Y1.

Revenir au logiciel d'origine

Rockbox ne vous verrouille pas dans le logiciel personnalisé. Une fois le programme de mise à jour configuré pour votre ordinateur, utilisez-le sous Windows, macOS ou Linux : sélectionnez Y1, choisir Logiciel d'origine, et cours Installer / Restaurer.

  1. Attendez que le programme de mise à jour ait fini de préparer le package de stock.
  2. Éteignez le Y1 lorsque l'application vous le demande.
  3. Connectez le câble de données USB uniquement à l'invite en direct.
  4. Laissez le joueur immobile jusqu'au message de réussite.

N'utilisez pas le package Y2 et ne supprimez pas manuellement les fichiers Rockbox avant la restauration. Pour le comportement de la roue Type B, vérifiez la variante de version correspondante avant de modifier le type d'appareil.
