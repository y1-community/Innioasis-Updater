Что вам нужно

Innioasis Y1, заряженный аккумулятор, USB кабель для передачи данных и компьютер с установленным Innioasis Updater CE (если вы еще не установили его, Скачать Updater CE для Windows, macOS или Linux). Type A подходит для Y1 игроков, поставлявших оригинальное программное обеспечение версии 2.0.0 или более поздней; Type B подходит игрокам, которые поставлялись с более ранней версией Заводское ПО. Начните с Type A, если вы еще не знаете, что вашему плееру нужна сборка Type B.

В программе обновлений

  1. Откройте Updater CE (или запустите с помощью Получите это в Updater CE) и установите Модель устройства в адрес Y1.
  2. Выбирать Rockbox в Программное обеспечение. Точная метка проекта может отображаться как Rockbox-Y1 в данных выпуска.
  3. Выберите стабильную версию. Сборки 240p имеют самую широкую совместимость со старыми темами; Сборки 360p предназначены для пути темы Y1. Если различие имеет значение, проверьте примечания к выпуску.
  4. Нажмите Установить / Восстановить. Подождите, пока Updater CE загрузит пакет непосредственно из версии разработчика сообщества и подготовит его.

Подключите Y1

  1. Подождите, пока программа обновлений не запросит плеер.
  2. Полностью выключите Y1. Если он не выключится, используйте инструкцию по восстановлению, показанную программой обновлений.
  3. Подключайте кабель для передачи данных USB только тогда, когда приложение предложит это. Отложите плеер и не нарушайте соединение.
  4. Отключитесь только после того, как программа обновлений подтвердит успех, затем запустите Y1.

Вернуться к исходному программному обеспечению

Rockbox не привязывает вас к пользовательскому программному обеспечению. После настройки Updater на вашем компьютере используйте его в Windows, macOS или Linux: выберите Y1, выбирать Заводское ПОи запустить Установить / Восстановить.

  1. Подождите, пока программа обновления завершит подготовку стандартного пакета.
  2. Выключите Y1, когда приложение спросит.
  3. Подключайте кабель передачи данных USB только при появлении подсказки в режиме реального времени.
  4. Оставьте плеер неподвижным до появления сообщения об успехе.

Не используйте пакет Y2 и не удаляйте вручную файлы Rockbox перед восстановлением. Для поведения колеса Type B проверьте соответствующий вариант выпуска перед изменением типа устройства.
