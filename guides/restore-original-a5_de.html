Wiederherstellungsanleitung · Modell A5

Originalsoftware auf Innioasis & Timmkoo A5 wiederherstellen

Befolgen Sie dieses Tutorial, um die offizielle Werkssoftware auf Ihrem Innioasis A5- oder Timmkoo A5-Player mit verifizierten Paketen aus dem Innioasis-Firmware-Archiv wiederherzustellen.

Updater CE holen A5 Downloads anzeigen

Schritt 1: Einrichtung in Updater CE

  1. Starten Innioasis Updater CE auf Ihrem Windows-, macOS- oder Linux-Computer.
  2. Satz Gerätemodell an A5.
  3. Auswählen Original-Software. Updater CE lädt den offiziellen herunter rom_a5.zip Paket direkt freigeben.
  4. Klicken Sie Installieren / Wiederherstellen und warten Sie, bis die Vorbereitung abgeschlossen ist.

Schritt 2: Stellen Sie an der Eingabeaufforderung eine Verbindung her

  1. Schalten Sie das A5-Gerät vollständig aus.
  2. Warten Sie auf die Eingabeaufforderung auf Ihrem Computerbildschirm, bevor Sie das Datenkabel USB anschließen.
  3. Lassen Sie den Flash-Vorgang ohne Unterbrechung abschließen.
  4. Trennen Sie Ihren frisch wiederhergestellten A5-Player und starten Sie ihn neu.
