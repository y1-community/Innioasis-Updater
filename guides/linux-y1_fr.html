Installez-le

  1. Ouvrez Innioasis Updater CE sur votre ordinateur (si vous ne l'avez pas encore, Obtenir Updater CE). Sélectionnez Y1 dans Modèle d'appareil.
  2. Choisissez Linux pour Y1 (développement) dans Logiciel (ou lancer avec Disponible dans Updater CE).
  3. Sélectionnez une version et cliquez sur Installer / Restaurer.
  4. Éteignez et connectez le Y1 uniquement lorsque le programme de mise à jour vous y invite.
  5. Utiliser Y1 Logiciel d'origine pour le chemin de restauration.

Port expérimental

Construction expérimentale : Il s'agit d'un port Linux barebones destiné aux développeurs et aux passionnés. Les détails de l'UART et de la console se trouvent dans la documentation du projet.
