설치 단계

  1. 컴퓨터에서 Innioasis Updater CE를 엽니다. (아직 없다면, Updater CE 받기). 선택 Y1 안으로 기기 모델.
  2. 선택 Koensayr 안으로 소프트웨어 (또는 다음으로 시작 이것을 Updater CE에서 얻으세요).
  3. 나열된 릴리스를 선택하고 클릭하십시오. 설치 / 복원.
  4. 앱이 요청할 때만 전원을 끄고 Y1을 연결하세요.
  5. Y1 사용 원본 소프트웨어 재고 경로를 복원합니다.

뭔가 실패했을 때

먼저 모델과 유형 선택을 확인하세요. 그런 다음 프롬프트가 표시되기 전에 케이블과 플레이어가 연결되었는지 확인하십시오. 앱이 USB을 기다리기 전에 중지된 경우 다음을 엽니다. 문제 해결.
