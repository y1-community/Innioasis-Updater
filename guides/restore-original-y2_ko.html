관련 Windows, macOS 또는 Linux 설정이 준비되면 Y2 스톡 인터페이스로 돌아가면 커뮤니티 프로젝트를 설치할 때와 동일한 업데이터 흐름을 사용합니다. Y1 파일을 플레이어에 수동으로 혼합하거나 시스템 폴더를 먼저 삭제하지 마십시오.

  1. 컴퓨터에서 Innioasis 업데이터 CE를 엽니다(아직 설치하지 않은 경우 Updater CE 받기 ~을 위한 윈도우, macOS, 또는 리눅스).
  2. 세트 기기 모델 에 Y2.
  3. 선택 원본 소프트웨어.
  4. 안정적인 Y2 릴리스를 선택하세요. 수동 전체 설치 패키지는 다음을 사용할 수 있습니다. rom_y2.zip.
  5. 클릭 설치 / 복원 추출 단계를 기다립니다.
대체하지 마십시오: Y1 rom.zip Y2 패키지가 아닙니다. 릴리스 목록이 잘못된 것 같으면 중지하고 Y2을(를) 다시 선택하십시오.

연결 프롬프트를 따르세요

Windows, macOS 및 Linux는 컴퓨터 설정 참고 사항이 다르지만 플레이어 측 순서는 동일하게 유지됩니다. 요청 시 전원을 끈 다음 라이브 프롬프트에서 데이터 케이블을 연결합니다.

  1. 업데이터가 요청할 때 Y2의 전원을 완전히 끄십시오.
  2. 앱에서 준비되었다고 표시되는 경우에만 USB을 연결하세요.
  3. 성공 메시지가 나타날 때까지 케이블을 그대로 두십시오.
  4. 안전하게 연결을 끊고 플레이어를 시작하세요.
