How to factory reset an Innioasis PR1

A clear reset that keeps the good files and removes the problem. This page covers the Settings route, the frozen-player route, and the one case where a reset is the wrong fix.

Before you start

A factory reset erases the player's internal storage. It removes settings, accounts, playlists and any file stored in the player rather than on a microSD card. Copy your music and recordings to a computer first. If you only want to fix slow menus, use Clear cache instead; it leaves files alone.

The reset hole is not a factory reset. On models with a small Reset pin, pressing it only forces a shutdown when the player is frozen. It does not erase data and does not restore factory settings.

The normal route

  1. Copy your recordings to a computer first. Recordings in internal storage are erased.
  2. Charge the recorder to at least half.
  3. Open Settings and choose Factory reset.
  4. Confirm and wait for the recorder to restart.

When it comes back, choose your language and connect to Wi-Fi or Bluetooth again if you use them. Your microSD card is usually left alone, but check it before you rely on it.

If the player is frozen

  1. Hold power for about ten seconds. Most players force a shutdown.
  2. If that does nothing, press the small Reset hole with a pin or paperclip.
  3. Charge for an hour, then turn it on and try the Settings route again.

The pin only gets you back to a running player. It does not reset the software; the Settings route does.

If the player will not start at all

A reset cannot run on a player that never reaches the home screen. That is a software problem, not a settings problem. Use Innioasis Updater CE to restore Original Software for PR1, or follow the PR1 restore guide for the manual SP Flash Tool route. If the player is completely unresponsive, read the recovery guide first.

Factory reset or reinstall?

Factory reset

Keeps the installed software, erases your data. Use it when the player works but feels messy, slow or stuck in a bad setting.

Reinstall software

Replaces the system itself. Use it when the player will not boot, when an update failed, or when you want to leave a custom system and return to Original Software.

Questions people ask

Will a reset delete my microSD card?

Usually not. A factory reset targets internal storage. Remove the card before resetting if you want to be certain.

Does it remove a custom firmware?

No. A factory reset clears data inside the current system. To remove Rockbox or another custom system, reinstall Original Software instead.

How long does it take?

A few minutes. If it has not restarted after ten, charge it and try the power button; if it still does not respond, use the recovery guide.
