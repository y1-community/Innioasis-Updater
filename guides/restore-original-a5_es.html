Restaurar el software original en Innioasis y Timmkoo A5

Siga este tutorial para restaurar el software oficial de fábrica en su reproductor Innioasis A5 o Timmkoo A5 con paquetes verificados del Innioasis Archivo de firmware.

Obtener Updater CE Ver A5 Descargas

Paso 1: Configuración en Updater CE

  1. Lanzamiento Innioasis Actualizador CE en su computadora con Windows, macOS o Linux.
  2. conjunto Modelo del dispositivo a A5.
  3. Seleccionar Software original. Updater CE descarga el oficial rom_a5.zip lanzar el paquete directamente.
  4. Haga clic Instalar / Restaurar y espere a que se complete la preparación.

Paso 2: Conéctese cuando se le solicite

  1. Apague el dispositivo A5 por completo.
  2. Espere el mensaje en la pantalla de su computadora antes de conectar el cable de datos USB.
  3. Permita que el proceso de flasheo finalice sin interrupción.
  4. Desconecta y reinicia tu reproductor A5 recién restaurado.
