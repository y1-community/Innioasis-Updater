分步安装

  1. 打开更新程序CE： 发射 Innioasis 更新程序 CE 在您的 Windows、macOS 或 Linux 计算机上。
  2. 选择设备型号 Y1： 选择 Y1 在设备型号下拉列表中（如果您的 Y1 附带 2.0.0 之前的原始软件，请选择 Type B；否则保留 Type A）。
  3. 从软件下拉列表中选择 Rondo： 选择 Rondo 在软件列表中并选择最新版本。更新程序 CE 使用 Android 4.2 Wi-Fi 基础 ROM 和 Rondo 自动发布源。
  4. 闪光播放器： 点击 安装 / 恢复，完全关闭 Y1 电源，并在 Updater CE 提示时通过 USB 数据线连接。
  5. 断开连接并启动： 在拔下 Y1 之前，请等待绿色完成消息。
  6. 完成安装后设置
