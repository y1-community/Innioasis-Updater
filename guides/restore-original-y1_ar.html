من Rockbox أو برنامج مخصص آخر

بمجرد أن يصبح إعداد Windows أو macOS أو Linux ذي الصلة جاهزًا، يستخدم Updater نفس التثبيت الموجه لاستعادة المخزون كما يفعل لتثبيت برنامج مخصص. لا تحتاج إلى حذف Rockbox أو ملفات برنامج مخصص آخر يدويًا أولاً.

  1. افتح Innioasis Updater CE على جهاز الكمبيوتر الخاص بك (إذا لم تكن قد قمت بتثبيته بعد، احصل على Updater CE ل ويندوز, ماكأو لينكس).
  2. تعيين طراز الجهاز ل Y1.
  3. اختر البرنامج الأصلي في البرنامج (أو استخدم احصل على هذا في Updater CE).
  4. اختر أحدث إصدار ثابت Y1. الحزمة اليدوية المعتادة هي rom.zip. Type A يغطي Y1 المشغلات التي تم شحنها مع الإصدار 2.0.0 من البرنامج الأصلي أو الأحدث؛ Type B يغطي اللاعبين الذين تم شحنهم مع إصدار سابق من البرنامج الأصلي وقد يستخدم اسم حزمة أكثر تحديدًا.
  5. انقر تثبيت / استعادة وانتظر حتى يتم استخراج الحزمة.

قم بتوصيل Y1 في الموجه

يقوم نظام التشغيل بتغيير الإعداد حول Updater، وليس رحلة الاستعادة نفسها. على كل منصة، انتظر المطالبة المباشرة قبل الاتصال.

  1. قم بإيقاف تشغيل المشغل بالكامل عندما يطلب منك التحديث ذلك.
  2. قم بتوصيل كابل البيانات USB فقط عند المطالبة.
  3. لا تلمس المشغل أثناء تشغيل التثبيت.
  4. اقطع الاتصال بعد رسالة النجاح وابدأ تشغيل Y1.

إذا كان لا يزال لا يبدأ

كرر عملية الاستعادة مرة واحدة مع تحديد النموذج والنوع والإصدار. إذا فشل برنامج التحديث قبل المطالبة USB، فافحص إعداد الكمبيوتر وبرنامج التشغيل أو الأذونات وكابل البيانات والملفات المستخرجة. إذا فشل بعد اكتشاف Y1، فاستخدم دليل استكشاف الأخطاء وإصلاحها قبل الانتقال إلى الاسترداد اليدوي SP Flash Tool أو MTKClient.

لا تقم بالتبديل إلى ملفات Y2. تحتاج عملية الاستعادة Y1 إلى إصدار البرنامج الأصلي Y1، حتى إذا كان المشغل يقوم حاليًا بتشغيل برنامج مخصص مختلف.
