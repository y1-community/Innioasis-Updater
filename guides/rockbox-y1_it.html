Di cosa hai bisogno

Un Innioasis Y1, una batteria carica, un USB cavo dati e un computer con Innioasis Updater CE installato (se non lo hai ancora installato, Ottieni Updater CE per Windows, macOS o Linux). Type A è adatto a Y1 giocatori forniti con la versione del software originale 2.0.0 o successiva; Type B è adatto ai giocatori forniti con una versione precedente di Software originale. Inizia con Type A a meno che tu non sappia già che il tuo giocatore ha bisogno di una build Type B.

Nell'Aggiornamento

  1. Apri Updater CE (o avvia con Ottieni questo in Updater CE) e impostare Modello del dispositivo a Y1.
  2. Scegli Rockbox dentro Software. L'etichetta esatta del progetto potrebbe essere visualizzata come Rockbox-Y1 nei dati di rilascio.
  3. Scegli una versione stabile. Le build 240p hanno la più ampia compatibilità con i temi precedenti; Le build a 360p sono destinate al percorso tematico Y1. Controlla le note di rilascio quando la distinzione è importante.
  4. Fare clic Installa / Ripristina. Attendi che Updater CE scarichi il pacchetto direttamente dalla release della community di sviluppatori e lo prepari.

Collega il Y1

  1. Attendi finché Updater non richiede il lettore.
  2. Spegnere completamente Y1. Se non si spegne, utilizzare le istruzioni di ripristino mostrate da Updater.
  3. Collega il cavo dati USB solo quando richiesto dall'app. Metti giù il lettore e non disturbare la connessione.
  4. Disconnettersi solo dopo che l'Updater ha confermato il successo, quindi avviare Y1.

Ritorna al software originale

Rockbox non ti vincola al software personalizzato. Una volta configurato Updater per il tuo computer, utilizzalo su Windows, macOS o Linux: seleziona Y1, scegliere Software originalee corri Installa / Ripristina.

  1. Attendi che Updater finisca di preparare il pacchetto stock.
  2. Spegni il Y1 quando richiesto dall'app.
  3. Collegare il cavo dati USB solo al prompt live.
  4. Lasciare fermo il lettore fino al messaggio di successo.

Non utilizzare il pacchetto Y2 e non eliminare manualmente i file Rockbox prima del ripristino. Per il comportamento della ruota Type B, verificare la variante di rilascio corrispondente prima di cambiare tipo di dispositivo.
