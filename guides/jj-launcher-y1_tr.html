Y1 rotasını seçin

  1. Bilgisayarınızda Innioasis Updater CE'yi açın (henüz sahip değilseniz, Updater CE edin). Seçme Y1 içinde Cihaz modeli.
  2. Seçmek JJ Launcher içinde Yazılım (veya şununla başlat: Bunu Güncelleyici CE'den edinin).
  3. Sürüm notunu okuyun, Y1 sürümünü seçin ve Yükle / Geri yükle.
  4. Oynatıcıyı yalnızca Güncelleyici sorduğunda kapatın ve bağlayın.
  5. Y1 ile geri yükle Orijinal yazılım Stok arayüzüne tekrar ihtiyacınız varsa.

Model uyuşmazlığı kontrol edilecek ilk şeydir

JJ Launcher also has a Y2 entry. If the package name looks wrong, return to Device Model. Do not force a Y2 package onto a Y1.

Orijinal Yazılıma geri dön

JJ Launcher, rotayı stok arayüzüne geri döndürmez. Güncelleyici bilgisayarınız için ayarlandıktan sonra Windows, macOS veya Linux'ta açın ve Y1 artı Orijinal yazılım JJ Launcher yerine.

  1. Kararlı bir Y1 Orijinal Yazılım sürümü seçin.
  2. Tıklamak Yükle / Geri yükle ve canlı bağlantı istemini bekleyin.
  3. Y1'ı yalnızca istendiğinde kapatın.
  4. USB veri kablosunu istem üzerine bağlayın ve başarılı olana kadar hareketsiz bırakın.

Öncelikle JJ Launcher dosyalarını manuel olarak kaldırmayın ve Y2 paketini kullanmayın. Arıza USB isteminden önce meydana geldiyse, öncelikle bilgisayar kurulumunu, kabloyu ve model seçimini kontrol edin.
