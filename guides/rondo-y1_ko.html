단계별 설치

  1. 오픈 업데이터 CE: 발사 Innioasis 업데이터 CE Windows, macOS 또는 Linux 컴퓨터에서.
  2. 장치 모델 선택 Y1: 선택 Y1 장치 모델 드롭다운에서(Y1이 2.0.0 이전의 원본 소프트웨어와 함께 제공된 경우 Type B을 선택하고, 그렇지 않으면 Type A를 유지).
  3. 소프트웨어 드롭다운에서 Rondo을 선택합니다. 선택 Rondo 소프트웨어 목록에서 최신 릴리스를 선택합니다. 업데이터 CE는 Android 4.2 Wi-Fi 기반 ROM 및 Rondo 릴리스 피드를 자동으로 사용합니다.
  4. 플레이어 플래시: 클릭 설치 / 복원, Y1의 전원을 완전히 끄고 Updater CE가 메시지를 표시하면 USB 데이터 케이블을 통해 연결하십시오.
  5. 연결을 끊고 부팅합니다. Y1의 플러그를 뽑기 전에 녹색 완료 메시지가 나타날 때까지 기다리십시오.
  6. 설치 후 설정 완료
