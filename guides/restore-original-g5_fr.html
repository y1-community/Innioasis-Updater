Étape 1 : Préparez votre ordinateur

Innioasis Updater CE fonctionne nativement sur Windows, macOS et Linux sans nécessiter de harnais de flashage complexes :

  1. Lancement Innioasis Programme de mise à jour CE sur votre ordinateur de bureau ou portable.
  2. Ensemble Modèle d'appareil à G5.
  3. Sélectionnez Logiciel d'origine dans la liste déroulante des logiciels. Updater CE télécharge automatiquement le fichier officiel rom_g5.zip publier le package directement.
  4. Cliquez Installer / Restaurer pour commencer la préparation.

Étape 2 : connectez le G5 à l'invite

Ne connectez jamais votre lecteur avant que l'application ne vous demande :

  1. Assurez-vous que votre Innioasis G5 est complètement éteint.
  2. Lorsque le programme de mise à jour affiche l'invite de connexion USB, branchez votre câble de données USB-C à l'ordinateur et au lecteur.
  3. Ne touchez pas le câble ou les boutons d'alimentation pendant le clignotement.
  4. Une fois la confirmation de réussite affichée, débranchez le câble USB et allumez votre G5.
