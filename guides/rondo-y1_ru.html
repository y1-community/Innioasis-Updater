Пошаговая установка

  1. Откройте программу обновлений CE: Запуск Innioasis Программа обновления CE на вашем компьютере с Windows, macOS или Linux.
  2. Выберите модель устройства Y1: Выбирать Y1 в раскрывающемся списке «Модель устройства» (выберите Type B, если ваше Y1 поставляется с исходным программным обеспечением более ранней версии, чем 2.0.0; в противном случае сохраните Type A).
  3. Выберите Rondo в раскрывающемся списке «Программное обеспечение»: Выбирать Rondo в списке Программное обеспечение и выберите последнюю версию. Программа обновлений CE автоматически использует базовый канал Wi-Fi Android 4.2 ROM и Rondo.
  4. Прошить плеер: Нажмите Установить / Восстановить, полностью отключите питание Y1 и подключите его через кабель для передачи данных USB, когда вам будет предложено Updater CE.
  5. Отключите и загрузитесь: Дождитесь зеленого сообщения о завершении, прежде чем отключать Y1.
  6. Полная настройка после установки

    Следуйте инструкциям в это руководство для завершения настройки на вашем Y1.
