Antes de hacer clic en instalar

Tener un Innioasis Y2 cargado, un cable de datos USB y una computadora con Innioasis Updater CE instalado (si aún no lo has instalado, Obtener Updater CE para Windows, macOS o Linux). No utilice una versión Y1 solo porque su nombre parece similar.

Verificación de modelo: Y2 los paquetes de instalación completa pueden usar rom_y2.zip. El nombre del archivo es una pista útil para la descarga manual, pero Updater debería encargarse de la selección del paquete por usted.

Elija Y2 en el Actualizador

  1. Abra Updater CE (o ejecútelo con Obtener en Updater CE) y establecer Modelo del dispositivo a Y2.
  2. elegir Rockbox en Software.
  3. Elija una versión listada para Y2. Si no aparece ninguna versión Y2, no la sustituya por una versión Y1.
  4. Haga clic Instalar / Restaurar y permita que Updater CE descargue el paquete directamente desde la versión del desarrollador de la comunidad.

Apague y luego conecte

  1. Espere el mensaje de conexión en vivo.
  2. Apague el Y2 por completo. Utilice las instrucciones exactas de restablecimiento o recuperación que muestra el Actualizador si falla el apagado normal.
  3. Conecte el cable USB cuando se le solicite. Déjelo quieto hasta que aparezca el mensaje de finalización.
  4. Desconéctese de forma segura e inicie el Y2.

Volver al software original

Rockbox no lo bloquea en el software personalizado. Una vez que Updater esté configurado para su computadora, utilícelo en Windows, macOS o Linux para regresar desde Rockbox u otro proyecto listado: seleccione Y2, elegir Software originaly corre Instalar / Restaurar.

  1. Espere a que Updater prepare el paquete de acciones Y2.
  2. Apague el Y2 cuando la aplicación lo solicite.
  3. Conecte el cable de datos USB solo cuando se le indique en vivo.
  4. Deje al jugador quieto hasta que aparezca el mensaje de éxito.

Mantenga los paquetes Y1 y Y2 separados. No elimine manualmente los archivos Rockbox primero; la restauración reemplaza el software del sistema.
