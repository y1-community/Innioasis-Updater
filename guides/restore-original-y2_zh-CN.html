一旦相关的 Windows、macOS 或 Linux 设置准备就绪，返回到 Y2 库存界面将使用与安装社区项目相同的更新程序流程。请勿手动将 Y1 文件混合到播放器中或先删除系统文件夹。

  1. 在您的计算机上打开 Innioasis Updater CE（如果您尚未安装， 获取 Updater CE 为了 窗户, macOS, 或 Linux).
  2. 套装 设备型号 至 Y2.
  3. 选择 原厂软件.
  4. 选择稳定的 Y2 版本。可以使用手动完整安装包 rom_y2.zip.
  5. 点击 安装 / 恢复 并等待提取步骤。
不要替代： 一个Y1 rom.zip 不是 Y2 包。如果发布列表看起来有误，请停止并重新选择 Y2。

按照连接提示操作

Windows、macOS 和 Linux 具有不同的计算机设置说明，但播放器端顺序保持不变：在询问时关闭电源，然后根据实时提示连接数据线。

  1. 当更新程序要求时，将 Y2 完全关闭。
  2. 仅当应用程序表示已准备就绪时才连接 USB。
  3. 保持电缆不变，直到出现成功消息。
  4. 安全断开连接并启动播放器。
