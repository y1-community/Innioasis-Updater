你需要什么

  • Windows、macOS 或 Linux 计算机。 Updater CE 在所有三个上运行。
  • 播放器附带的USB数据线。仅充电电缆将不起作用。
  • 官方 rom_g1.zip 包，更新程序为您下载，或从 G1 存档 如果您喜欢手动闪光。
  • 在播放器中充电。断电恢复是使糟糕情况变得更糟的唯一常见方法。

这会替换系统并擦除内部存储。 首先将音乐、录音和照片复制到计算机上。

路线A：Updater CE（推荐）

  1. 安装 Innioasis 更新程序 CE 并打开它。
  2. 套装 设备型号 至 G1。该模型必须与玩家完全匹配。
  3. 选择 原厂软件 在软件列表中。
  4. 选择一个版本。最新的稳定版本是安全的默认版本。
  5. 新闻 安装 / 恢复 并等待包下载和解压。
  6. 完全关闭播放器电源，然后仅在更新程序要求时连接 USB 电缆。
  7. 在出现成功消息之前，请勿触摸播放器或电缆。断开连接并启动播放器。
切勿选择不同的模型来“使其发挥作用”。 G1 需要 G1 包。混合模型是玩家最终需要手动恢复的原因。

路线 B：SP Flash Tool（手动）

当计算机无法运行 Updater CE 时，或者当您已经拥有该软件包并且更喜欢经典工具时，请使用此选项。

  1. 下载 rom_g1.zip 从 G1 存档 并解压它。
  2. 将分散文件保留在图像旁边。请勿重命名或移动图像。
  3. 打开SP Flash Tool，选择 仅供下载，并加载分散文件。
  4. 关闭播放器电源，按 下载，然后连接电缆。
  5. 等待绿色成功标记后再断开连接。

的 SP Flash Tool 指南 更详细地介绍了驱动程序和 Windows 提示。在 Linux 和 macOS 上，Updater CE 是更简单的路线，因为它带来了自己的 USB 处理。

恢复后

  1. 断开播放器并让它自行启动。
  2. 选择您的语言并设置时钟。
  3. 如果您使用 Wi-Fi 或蓝牙，请重新连接它们。
  4. 将您的音乐复制回来。的 转乘指南 有文件夹名称。

如果播放器启动但屏幕、滚轮或按钮仍然出现故障，则恢复成功；这是硬件或设置问题，而不是软件问题。的 故障排除指南 是下一站。

如果不起作用

更新者永远看不到玩家

更换电缆，然后更换 USB 端口。避免枢纽。在 Windows 上，从以下位置安装 MediaTek 驱动程序 驱动程序页面.

闪光灯提前停止

重新连接，为播放器充电，然后重新开始。请勿切换至不同型号的封装。

玩家保持黑色

充电一小时，然后保持电量十秒钟。如果它仍然死了，请阅读 恢复指南 再次尝试之前。

人们提出的问题

这会删除我的音乐吗？

是的，内部存储已被删除。 microSD 卡上的文件通常会保留下来，但首先将它们复制到安全的地方。

之后我可以返回Rockbox吗？

是的。恢复原始软件不是一扇单向门；而是一扇单向门。您的型号的自定义软件页面可以再次安装。

我需要 Type A / Type B 设置吗？

只有 Y1 有这样的选择，并且仅限于原始软件。所有其他模型都使用单个包。
