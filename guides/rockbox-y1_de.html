Was Sie brauchen

Ein Innioasis Y1, ein geladener Akku, ein USB Datenkabel und ein Computer mit installiertem Innioasis Updater CE (falls Sie es noch nicht installiert haben, Updater CE holen für Windows, macOS oder Linux). Type A eignet sich für Y1 Spieler, die mit der Originalsoftwareversion 2.0.0 oder höher ausgeliefert wurden; Type B eignet sich für Spieler, die mit einer früheren Version von ausgeliefert wurden Original-Software. Beginnen Sie mit Type A, es sei denn, Sie wissen bereits, dass Ihr Player einen Type B-Build benötigt.

Im Updater

  1. Öffnen Sie Updater CE (oder starten Sie mit In Updater CE erhalten) und einstellen Gerätemodell an Y1.
  2. Wählen Sie Rockbox In Software. Die genaue Projektbezeichnung wird in den Veröffentlichungsdaten möglicherweise als Rockbox-Y1 angezeigt.
  3. Wählen Sie eine stabile Version. 240p-Builds verfügen über die umfassendste Kompatibilität mit älteren Themes; 360p-Builds sind für den Themenpfad Y1 vorgesehen. Sehen Sie sich die Versionshinweise an, wenn die Unterscheidung wichtig ist.
  4. Klicken Sie Installieren / Wiederherstellen. Warten Sie, während Updater CE das Paket direkt aus der Version des Community-Entwicklers herunterlädt und vorbereitet.

Verbinden Sie die Y1

  1. Warten Sie, bis der Updater nach dem Player fragt.
  2. Schalten Sie den Y1 vollständig aus. Wenn es nicht heruntergefahren werden kann, verwenden Sie die vom Updater angezeigten Wiederherstellungsanweisungen.
  3. Schließen Sie das Datenkabel USB nur an, wenn die App Sie dazu auffordert. Legen Sie den Player ab und stören Sie die Verbindung nicht.
  4. Trennen Sie die Verbindung erst, nachdem der Updater den Erfolg bestätigt hat, und starten Sie dann Y1.

Zurück zur Originalsoftware

Rockbox bindet Sie nicht an die benutzerdefinierte Software. Sobald Updater für Ihren Computer eingerichtet ist, können Sie es unter Windows, macOS oder Linux verwenden: Wählen Sie aus Y1, wählen Original-Software, und renne Installieren / Wiederherstellen.

  1. Warten Sie, bis der Updater die Vorbereitung des Standardpakets abgeschlossen hat.
  2. Schalten Sie Y1 aus, wenn die App Sie dazu auffordert.
  3. Schließen Sie das Datenkabel USB nur bei der Live-Eingabeaufforderung an.
  4. Lassen Sie den Player ruhig stehen, bis die Erfolgsmeldung erscheint.

Verwenden Sie nicht das Paket Y2 und löschen Sie die Dateien Rockbox vor der Wiederherstellung nicht manuell. Überprüfen Sie für das Radverhalten von Type B die passende Release-Variante, bevor Sie den Gerätetyp ändern.
