在单击安装之前

准备好一根已充电的 Innioasis Y2、一根 USB 数据线以及一台安装了 Innioasis Updater CE 的计算机（如果您尚未安装， 获取 Updater CE 适用于 Windows、macOS 或 Linux）。不要仅仅因为名称相似而使用 Y1 版本。

型号检查： Y2 完整安装包可以使用 rom_y2.zip。文件名是有用的手动下载线索，但更新程序应该为您处理软件包选择。

在更新程序中选择Y2

  1. 打开 Updater CE（或使用以下命令启动 在 Updater CE 中获取）并设置 设备型号 至 Y2.
  2. 选择 Rockbox 在 软件.
  3. 选择 Y2 列出的版本。如果未列出 Y2 版本，请勿替换 Y1 版本。
  4. 点击 安装 / 恢复 并让Updater CE直接从社区开发者的release下载包。

关闭电源，然后连接

  1. 等待实时连接提示。
  2. 将 Y2 完全关闭。如果正常关机失败，请使用更新程序显示的确切重置或恢复指令。
  3. 当询问时连接 USB 电缆。让它保持静止，直到出现完成消息。
  4. 安全断开并启动 Y2。

返回原始软件

Rockbox 不会将您锁定在自定义软件中。为您的计算机设置更新程序后，请在 Windows、macOS 或 Linux 上使用它从​​ Rockbox 或其他列出的项目返回：选择 Y2， 选择 原厂软件，然后运行 安装 / 恢复.

  1. 等待更新程序准备 Y2 库存包。
  2. 当应用程序询问时，关闭 Y2 电源。
  3. 仅在出现实时提示时连接 USB 数据线。
  4. 让玩家保持静止，直到出现成功消息。

将 Y1 和 Y2 包分开。先不要手动删除Rockbox文件；恢复会替换系统软件。
