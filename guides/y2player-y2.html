Install Y2Player on the Y2.

Y2Player is a Y2 project. The safe route starts with the model selection, not the project name.

General Updater guideProject source

In Updater

  1. Set Device Model to Y2.
  2. Choose Y2Player in Software.
  3. Choose the listed Y2 release.
  4. Click Install / Restore, power off when asked, and connect USB at the prompt.
  5. Restore with Y2 Original Software if needed.

Do not substitute a Y1 package

Check twice: Y2 full-install packages may use rom_y2.zip. A plain Y1 package is not a safe substitute.
