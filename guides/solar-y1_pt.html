Escolha a rota Y1

  1. Abra Innioasis Updater CE no seu computador (se ainda não o tiver, Obtenha o atualizador CE). Selecione Y1 em Modelo do dispositivo.
  2. Escolher Solar em Programas (ou lançar com Obtenha isso em Updater CE).
  3. Leia a nota de lançamento, selecione uma versão e clique em Instalar / Restaurar.
  4. Desligue e conecte o player somente quando o Updater solicitar.
  5. Restaurar com Y1 Software Original se você precisar da interface de estoque novamente.

Mantenha a nota do projeto à vista

Solar está em desenvolvimento ativo. Os recursos e o suporte do modelo podem mudar, portanto verifique as notas de lançamento do projeto. O atualizador mostra o que está disponível para o seu modelo no momento.

Volte para o software original

Solar não altera a rota de volta para a interface padrão. Assim que o Updater estiver configurado para o seu computador, abra-o no Windows, macOS ou Linux e selecione Y1 mais Software Original em vez de Solar.

  1. Escolha uma versão de software original estável Y1.
  2. Clique Instalar / Restaurar e aguarde o prompt de conexão ao vivo.
  3. Desligue o Y1 somente quando solicitado.
  4. Conecte o cabo de dados USB no prompt e deixe-o imóvel até obter sucesso.

Não remova manualmente os arquivos Solar primeiro e não use um pacote Y2. Se a falha ocorreu antes do prompt USB, verifique primeiro a configuração do computador, o cabo e a seleção do modelo.
