Android 4.4 (Dev) · Innioasis Y2

Install Android 4.4 (Dev) on a Y2.

Android 4.4 is a community development ROM for testing and hacking on the Innioasis Y2 hardware. Select Y2 before choosing it in Updater CE.

Get Updater CEGet this in Updater CEProject source

Install it

  1. Open Innioasis Updater CE on your computer (if you don't have it yet, Get Updater CE). Select Y2 in Device Model.
  2. Choose Android 4.4 (Dev) in Software (or launch with Get this in Updater CE).
  3. Select a release and click Install / Restore.
  4. Power off and connect the Y2 only when Updater prompts you.
  5. Use Y2 Original Software for the restore path.

Developer build note

Developer build: This is a development image intended for experimentation. Read the repository release notes for current hardware support and known issues.
