Rockbox 또는 다른 사용자 정의 소프트웨어에서

관련 Windows, macOS 또는 Linux 설정이 준비되면 Updater는 사용자 정의 소프트웨어 설치와 동일한 기본 복원 설치 안내를 사용합니다. 먼저 Rockbox 또는 다른 사용자 정의 소프트웨어의 파일을 수동으로 삭제할 필요가 없습니다.

  1. 컴퓨터에서 Innioasis 업데이터 CE를 엽니다(아직 설치하지 않은 경우 Updater CE 받기 ~을 위한 윈도우, macOS, 또는 리눅스).
  2. 세트 기기 모델 에 Y1.
  3. 선택 원본 소프트웨어 안으로 소프트웨어 (또는 사용 이것을 Updater CE에서 얻으세요).
  4. 최신 안정 Y1 릴리스를 선택하세요. 일반적인 수동 패키지는 다음과 같습니다. rom.zip. Type A은 원본 소프트웨어 버전 2.0.0 이상과 함께 배송된 Y1 플레이어에 적용됩니다. Type B 이전 버전과 함께 출시된 플레이어에 대해 설명합니다. 원본 소프트웨어 보다 구체적인 패키지 이름을 사용할 수도 있습니다.
  5. 클릭 설치 / 복원 패키지가 추출될 때까지 기다립니다.

프롬프트에서 Y1을 연결합니다.

운영 체제는 복원 과정 자체가 아닌 업데이터 주변의 설정을 변경합니다. 모든 플랫폼에서 연결하기 전에 실시간 프롬프트를 기다립니다.

  1. 업데이터가 요청할 때 플레이어의 전원을 완전히 끄십시오.
  2. USB 데이터 케이블은 프롬프트에서만 연결하십시오.
  3. 설치가 실행되는 동안 플레이어를 만지지 마십시오.
  4. 성공 메시지 이후 연결을 끊고 Y1을 시작합니다.

그래도 시작되지 않는 경우

모델, 유형 및 릴리스를 선택한 상태에서 복원을 한 번 반복합니다. USB 프롬프트 이전에 업데이터가 실패하면 컴퓨터 설정, 드라이버 또는 권한, 데이터 케이블 및 추출된 파일을 검사하십시오. Y1을 감지한 후 실패하면 문제 해결 가이드 수동 SP Flash Tool 또는 MTKClient 복구로 이동하기 전에.

Y2 파일로 전환하지 마십시오. Y1 복원에는 플레이어가 현재 다른 사용자 정의 소프트웨어를 실행 중이더라도 Y1 원본 소프트웨어 릴리스가 필요합니다.
