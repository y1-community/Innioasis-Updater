Installation étape par étape

  1. Ouvrir Updater CE : Lancement Innioasis Programme de mise à jour CE sur votre ordinateur Windows, macOS ou Linux.
  2. Choisissez le modèle de périphérique Y1 : Sélectionnez Y1 dans la liste déroulante Modèle de périphérique (choisissez Type B si votre Y1 a été livré avec le logiciel d'origine antérieur à 2.0.0 ; sinon conservez Type A).
  3. Choisissez Rondo dans la liste déroulante Logiciel : Sélectionnez Rondo dans la liste Logiciels et choisissez la dernière version. Updater CE utilise automatiquement la base Wi-Fi Android 4.2 ROM et Rondo.
  4. Flasher le lecteur : Cliquez Installer / Restaurer, éteignez complètement votre Y1 et connectez-le via un câble de données USB lorsque Updater CE vous y invite.
  5. Déconnectez-vous et démarrez : Attendez le message de fin vert avant de débrancher votre Y1.
  6. Terminer la configuration post-installation

    Suivez les étapes dans ce guide pour terminer la configuration sur votre Y1.
