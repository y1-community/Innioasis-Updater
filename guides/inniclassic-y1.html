Install Inniclassic on a Y1.

Inniclassic is listed as a Y1 project. Select Y1 before choosing it so the release list stays model-aware.

General Updater guideProject source

Install it

  1. Choose Y1 in Device Model.
  2. Choose Inniclassic in Software.
  3. Select a release and click Install / Restore.
  4. Power off and connect the Y1 only when Updater prompts you.
  5. Use Y1 Original Software for the restore path.

Keep the connection still

If the install fails, note whether the failure happened before or after Updater detected the player. That detail makes troubleshooting much faster.
