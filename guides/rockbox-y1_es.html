lo que necesitas

Un Innioasis Y1, una batería cargada, un cable de datos USB y una computadora con Innioasis Updater CE instalado (si aún no lo has instalado, Obtener Updater CE para Windows, macOS o Linux). Type A se adapta a Y1 reproductores que se enviaron con la versión 2.0.0 o posterior del software original; Type B se adapta a los jugadores que vienen con una versión anterior del Software original. Comience con Type A a menos que ya sepa que su reproductor necesita una compilación Type B.

Mira la ruta Rockbox

Vídeo de Frawgeeys. Funciona para los modelos Y1 y Y2; en Innioasis Updater CE, seleccione Y1 como tu modelo. Los pasos escritos a continuación cubren la secuencia de instalación de Y1.

Vídeo de cristian plaza (Español), comenzando en la etapa de instalación Rockbox. Los pasos escritos a continuación cubren la secuencia Y1.

En el actualizador

  1. Abra Updater CE (o ejecútelo con Obtener en Updater CE) y establecer Modelo del dispositivo a Y1.
  2. elegir Rockbox en Software. La etiqueta exacta del proyecto puede aparecer como Rockbox-Y1 en los datos de la versión.
  3. Elija una versión estable. Las compilaciones de 240p tienen la compatibilidad más amplia con temas antiguos; Las compilaciones de 360p están destinadas a la ruta del tema Y1. Consulte las notas de la versión cuando la distinción sea importante.
  4. Haga clic Instalar / Restaurar. Espere mientras Updater CE descarga el paquete directamente desde la versión del desarrollador de la comunidad y lo prepara.

Conecte el Y1

  1. Espere hasta que Updater solicite el reproductor.
  2. Apague el Y1 por completo. Si no se apaga, utilice las instrucciones de recuperación que muestra el Actualizador.
  3. Conecte el cable de datos USB solo cuando la aplicación lo indique. Deje el reproductor y no perturbe la conexión.
  4. Desconéctese solo después de que el Actualizador confirme el éxito, luego inicie Y1.

Volver al software original

Rockbox no lo bloquea en el software personalizado. Una vez que Updater esté configurado para su computadora, úselo en Windows, macOS o Linux: seleccione Y1, elegir Software originaly corre Instalar / Restaurar.

  1. Espere a que Updater termine de preparar el paquete de valores.
  2. Apague el Y1 cuando la aplicación lo solicite.
  3. Conecte el cable de datos USB solo cuando se le indique en vivo.
  4. Deje al jugador quieto hasta que aparezca el mensaje de éxito.

No utilice el paquete Y2 y no elimine manualmente los archivos Rockbox antes de la restauración. Para el comportamiento de la rueda Type B, verifique la variante de versión correspondiente antes de cambiar el tipo de dispositivo.
