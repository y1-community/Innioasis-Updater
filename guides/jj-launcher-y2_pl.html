Wybierz trasę Y2.

  1. Otwórz Innioasis Updater CE na swoim komputerze (jeśli jeszcze go nie masz, Pobierz Updater CE). Wybierz Y2 w Model urządzenia.
  2. Wybierz JJ Launcher w Oprogramowanie (lub uruchom za pomocą Zdobądź to w Updater CE).
  3. Przeczytaj informację o wydaniu, potwierdź wpis Y2 i kliknij Zainstaluj / Przywróć.
  4. Wyłącz i podłącz odtwarzacz tylko wtedy, gdy aktualizator o to poprosi.
  5. Przywróć za pomocą Y2 Oprogramowanie oryginalne jeśli potrzebujesz ponownie interfejsu podstawowego.

Pierwszą rzeczą do sprawdzenia jest niedopasowanie modelu

JJ Launcher also has a Y1 entry. If the package name looks wrong, return to Device Model. Do not force a Y1 package onto a Y2.

Wróć do oryginalnego oprogramowania

JJ Launcher nie zmienia trasy z powrotem do standardowego interfejsu. Po skonfigurowaniu narzędzia Updater na komputerze otwórz go w systemie Windows, macOS lub Linux i wybierz Y2 plus Oprogramowanie oryginalne zamiast JJ Launcher.

  1. Wybierz stabilną Y2 oryginalną wersję oprogramowania.
  2. Kliknij Zainstaluj / Przywróć i poczekaj na monit o połączenie na żywo.
  3. Wyłącz Y2 tylko wtedy, gdy zostaniesz o to poproszony.
  4. Po wyświetleniu monitu podłącz kabel danych USB i pozostaw go nieruchomo, aż do powodzenia.

Nie usuwaj najpierw ręcznie plików JJ Launcher i nie używaj pakietu Y1. Jeśli awaria wystąpiła przed pojawieniem się monitu USB, sprawdź najpierw konfigurację komputera, kabel i wybór modelu.
