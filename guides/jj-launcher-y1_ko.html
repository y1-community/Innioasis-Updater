Y1 경로를 선택하세요

  1. 컴퓨터에서 Innioasis Updater CE를 엽니다. (아직 없다면, Updater CE 받기). 선택 Y1 안으로 기기 모델.
  2. 선택 JJ Launcher 안으로 소프트웨어 (또는 다음으로 시작 이것을 Updater CE에서 얻으세요).
  3. 릴리스 노트를 읽고 Y1 버전을 선택한 후 설치 / 복원.
  4. 업데이터가 요청할 때만 전원을 끄고 플레이어를 연결하십시오.
  5. Y1을(를) 사용하여 복원 원본 소프트웨어 재고 인터페이스가 다시 필요한 경우.

모델 불일치가 가장 먼저 확인해야 할 사항입니다

JJ Launcher에는 Y2 항목도 있습니다. 패키지 이름이 잘못된 경우 장치 모델로 돌아가세요. Y2 패키지를 Y1에 강제로 넣지 마십시오.

원래 소프트웨어로 돌아가기

JJ Launcher은 경로를 스톡 인터페이스로 다시 변경하지 않습니다. Updater가 컴퓨터에 설정되면 Windows, macOS 또는 Linux에서 열고 다음을 선택하세요. Y1 플러스 원본 소프트웨어 JJ Launcher 대신.

  1. 안정적인 Y1 원본 소프트웨어 릴리스를 선택하십시오.
  2. 클릭 설치 / 복원 라이브 연결 프롬프트를 기다립니다.
  3. 요청이 있을 때만 Y1의 전원을 끄십시오.
  4. 프롬프트에 따라 USB 데이터 케이블을 연결하고 성공할 때까지 그대로 두십시오.

먼저 JJ Launcher 파일을 수동으로 제거하지 말고 Y2 패키지를 사용하지 마십시오. USB 프롬프트 이전에 오류가 발생한 경우 먼저 컴퓨터 설정, 케이블 및 모델 선택을 확인하십시오.
