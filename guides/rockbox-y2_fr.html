Avant de cliquer sur installer

Ayez un Innioasis Y2 chargé, un câble de données USB et un ordinateur avec Innioasis Updater CE installé (si vous ne l'avez pas encore installé, Obtenir Updater CE pour Windows, macOS ou Linux). N'utilisez pas une version Y1 simplement parce que son nom semble similaire.

Vérification du modèle : Y2 les packages d'installation complète peuvent utiliser rom_y2.zip. Le nom du fichier est un indice utile pour le téléchargement manuel, mais le programme de mise à jour doit gérer la sélection du package pour vous.

Choisissez Y2 dans le programme de mise à jour

  1. Ouvrez Updater CE (ou lancez avec Disponible dans Updater CE) et définissez Modèle d'appareil à Y2.
  2. Choisissez Rockbox dans Logiciel.
  3. Choisissez une version répertoriée pour Y2. Si aucune version Y2 n'est répertoriée, ne la remplacez pas par une version Y1.
  4. Cliquez Installer / Restaurer et laissez Updater CE télécharger le package directement à partir de la version du développeur de la communauté.

Éteignez, puis connectez

  1. Attendez l'invite de connexion en direct.
  2. Éteignez complètement le Y2. Utilisez les instructions exactes de réinitialisation ou de récupération affichées par le programme de mise à jour si l'arrêt normal échoue.
  3. Connectez le câble USB lorsque vous y êtes invité. Laissez-le immobile jusqu'au message de fin.
  4. Déconnectez-vous en toute sécurité et démarrez le Y2.

Revenir au logiciel d'origine

Rockbox ne vous verrouille pas dans le logiciel personnalisé. Une fois le programme de mise à jour configuré pour votre ordinateur, utilisez-le sous Windows, macOS ou Linux pour revenir de Rockbox ou d'un autre projet répertorié : sélectionnez Y2, choisir Logiciel d'origine, et cours Installer / Restaurer.

  1. Attendez que le programme de mise à jour prépare le package de stock Y2.
  2. Éteignez le Y2 lorsque l'application vous le demande.
  3. Connectez le câble de données USB uniquement à l'invite en direct.
  4. Laissez le joueur immobile jusqu'au message de réussite.

Gardez les packages Y1 et Y2 séparés. Ne supprimez pas manuellement les fichiers Rockbox en premier ; la restauration remplace le logiciel système.
