Desde Rockbox u otro software personalizado

Una vez que la configuración relevante de Windows, macOS o Linux esté lista, regresar a la interfaz estándar Y2 utiliza el mismo flujo de actualización que instalar un proyecto comunitario. No mezcle manualmente archivos Y1 en el reproductor ni elimine carpetas del sistema primero.

  1. Abra Innioasis Updater CE en su computadora (si aún no lo tiene instalado, Obtener Updater CE para ventanas, macos, o linux).
  2. conjunto Modelo del dispositivo a Y2.
  3. elegir Software original.
  4. Seleccione una versión estable Y2. Los paquetes de instalación completa manual pueden utilizar rom_y2.zip.
  5. Haga clic Instalar / Restaurar y espere el paso de extracción.
No sustituir: un Y1 rom.zip no es un paquete Y2. Si la lista de versiones parece incorrecta, deténgase y vuelva a seleccionar Y2.

Siga el mensaje de conexión

Windows, macOS y Linux tienen diferentes notas de configuración de la computadora, pero la secuencia del lado del reproductor sigue siendo la misma: apague cuando se le solicite, luego conecte el cable de datos cuando se le indique en vivo.

  1. Apague completamente el Y2 cuando el Actualizador lo solicite.
  2. Conecte USB solo cuando la aplicación indique que está lista.
  3. Deje el cable en paz hasta que aparezca el mensaje de éxito.
  4. Desconéctese de forma segura e inicie el reproductor.

¿Sigues estancado?

Verifique el modelo, el paquete, el cable y la sincronización de la conexión antes de probar una herramienta manual. El guía de solución de problemas explica lo que significa una falla antes de USB en comparación con una falla después de la detección del dispositivo.

Mantenga los paquetes separados: un Y1 rom.zip no es una restauración Y2. Si la lista de versiones parece incorrecta, deténgase y seleccione Y2 nuevamente.
