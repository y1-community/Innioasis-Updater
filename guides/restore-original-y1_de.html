Von Rockbox oder einer anderen benutzerdefinierten Software

Sobald das entsprechende Windows-, macOS- oder Linux-Setup bereit ist, verwendet Updater für eine Bestandswiederherstellung dieselbe geführte Installation wie für eine benutzerdefinierte Softwareinstallation. Sie müssen Rockbox oder die Dateien einer anderen benutzerdefinierten Software nicht zuerst manuell löschen.

  1. Öffnen Sie Innioasis Updater CE auf Ihrem Computer (falls Sie es noch nicht installiert haben, Updater CE holen für Windows, macOS, oder Linux).
  2. Satz Gerätemodell an Y1.
  3. Wählen Sie Original-Software In Software (oder verwenden In Updater CE erhalten).
  4. Wählen Sie die neueste stabile Version Y1. Das übliche Handbuchpaket ist rom.zip. Type A gilt für Y1 Spieler, die mit der Originalsoftwareversion 2.0.0 oder höher ausgeliefert wurden; Type B gilt für Spieler, die mit einer früheren Version von ausgeliefert wurden Original-Software und kann einen spezifischeren Paketnamen verwenden.
  5. Klicken Sie Installieren / Wiederherstellen und warten Sie, bis das Paket extrahiert wurde.

Verbinden Sie Y1 an der Eingabeaufforderung

Das Betriebssystem ändert das Setup rund um den Updater, nicht den Wiederherstellungsvorgang selbst. Warten Sie auf jeder Plattform auf die Live-Eingabeaufforderung, bevor Sie eine Verbindung herstellen.

  1. Schalten Sie den Player vollständig aus, wenn der Updater Sie dazu auffordert.
  2. Schließen Sie das Datenkabel USB erst an, wenn Sie dazu aufgefordert werden.
  3. Berühren Sie den Player nicht, während die Installation läuft.
  4. Trennen Sie nach der Erfolgsmeldung die Verbindung und starten Sie die Y1.

Wenn es immer noch nicht startet

Wiederholen Sie die Wiederherstellung einmal mit überprüftem Modell, Typ und Release. Wenn Updater vor der Eingabeaufforderung USB fehlschlägt, überprüfen Sie das Computer-Setup, den Treiber oder die Berechtigungen, das Datenkabel und die extrahierten Dateien. Wenn es nach der Erkennung von Y1 fehlschlägt, verwenden Sie die Anleitung zur Fehlerbehebung bevor Sie zur manuellen SP Flash Tool- oder MTKClient-Wiederherstellung wechseln.

Wechseln Sie nicht zu Y2-Dateien. Für eine Y1-Wiederherstellung ist eine Y1 Original-Softwareversion erforderlich, auch wenn auf dem Player derzeit eine andere benutzerdefinierte Software ausgeführt wird.
