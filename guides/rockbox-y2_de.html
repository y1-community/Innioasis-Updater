Bevor Sie auf „Installieren“ klicken

Halten Sie ein aufgeladenes Innioasis Y2, ein USB-Datenkabel und einen Computer bereit, auf dem Innioasis Updater CE installiert ist (falls Sie es noch nicht installiert haben, Updater CE holen für Windows, macOS oder Linux). Verwenden Sie keine Y1-Version, nur weil ihr Name ähnlich aussieht.

Modellcheck: Y2 Vollinstallationspakete dürfen verwenden rom_y2.zip. Der Dateiname ist ein nützlicher Hinweis für den manuellen Download, aber Updater sollte die Paketauswahl für Sie übernehmen.

Wählen Sie im Updater Y2.

  1. Öffnen Sie Updater CE (oder starten Sie mit In Updater CE erhalten) und einstellen Gerätemodell an Y2.
  2. Wählen Sie Rockbox In Software.
  3. Wählen Sie eine für Y2 aufgeführte Version aus. Wenn keine Y2-Version aufgeführt ist, ersetzen Sie sie nicht durch eine Y1-Version.
  4. Klicken Sie Installieren / Wiederherstellen und lassen Sie Updater CE das Paket direkt von der Community-Entwicklerversion herunterladen.

Ausschalten, dann anschließen

  1. Warten Sie auf die Aufforderung zur Live-Verbindung.
  2. Schalten Sie den Y2 vollständig aus. Verwenden Sie die genauen Reset- oder Wiederherstellungsanweisungen, die Updater anzeigt, wenn das normale Herunterfahren fehlschlägt.
  3. Schließen Sie das Kabel USB an, wenn Sie dazu aufgefordert werden. Lassen Sie es ruhig stehen, bis die Abschlussmeldung erscheint.
  4. Sicher trennen und Y2 starten.

Zurück zur Originalsoftware

Rockbox bindet Sie nicht an die benutzerdefinierte Software. Sobald Updater für Ihren Computer eingerichtet ist, können Sie es unter Windows, macOS oder Linux verwenden, um von Rockbox oder einem anderen aufgelisteten Projekt zurückzukehren: Wählen Sie aus Y2, wählen Original-Software, und renne Installieren / Wiederherstellen.

  1. Warten Sie, bis der Updater das Bestandspaket Y2 vorbereitet hat.
  2. Schalten Sie Y2 aus, wenn die App Sie dazu auffordert.
  3. Schließen Sie das Datenkabel USB nur bei der Live-Eingabeaufforderung an.
  4. Lassen Sie den Player ruhig stehen, bis die Erfolgsmeldung erscheint.

Halten Sie die Pakete Y1 und Y2 getrennt. Löschen Sie Rockbox Dateien nicht zuerst manuell; Die Wiederherstellung ersetzt die Systemsoftware.
