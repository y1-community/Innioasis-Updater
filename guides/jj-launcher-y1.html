JJ Launcher · Innioasis Y1

Install JJ Launcher on your Y1.

This is the Y1 route for the JJ Launcher project. Choose the model first so Updater does not offer the wrong package.

General Updater guideProject source

Also available: JJ Launcher on Y2

Choose the Y1 route

  1. Set Device Model to Y1.
  2. Choose JJ Launcher in Software.
  3. Read the release note, select the Y1 version, and click Install / Restore.
  4. Power off and connect the player only when Updater asks.
  5. Restore with Y1 Original Software if you need the stock interface again.

Model mismatch is the first thing to check

JJ Launcher also has a Y2 entry. If the package name looks wrong, return to Device Model. Do not force a Y2 package onto a Y1.

Go back to Original Software

JJ Launcher does not change the route back to the stock interface. Once Updater is set up for your computer, open it on Windows, macOS, or Linux and select Y1 plus Original Software instead of JJ Launcher.

  1. Choose a stable Y1 Original Software release.
  2. Click Install / Restore and wait for the live connection prompt.
  3. Power off the Y1 only when asked.
  4. Connect the USB data cable at the prompt and leave it still until success.

Do not manually remove JJ Launcher files first, and do not use a Y2 package. If the failure happened before the USB prompt, check the computer setup, cable, and model selection first.
