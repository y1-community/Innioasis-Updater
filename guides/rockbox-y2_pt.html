Antes de clicar em instalar

Tenha um Innioasis Y2, um cabo de dados USB carregado e um computador com Innioasis Updater CE instalado (se você ainda não o instalou, Obtenha o atualizador CE para Windows, macOS ou Linux). Do not use a Y1 release just because its name looks similar.

Verificação do modelo: Y2 pacotes de instalação completa podem usar rom_y2.zip. O nome do arquivo é uma pista útil para download manual, mas o Updater deve cuidar da seleção do pacote para você.

Escolha Y2 no Atualizador

  1. Abra Updater CE (ou inicie com Obtenha isso em Updater CE) e definir Modelo do dispositivo para Y2.
  2. Escolher Rockbox em Programas.
  3. Escolha um lançamento listado para Y2. Se nenhuma versão Y2 estiver listada, não substitua uma versão Y1.
  4. Clique Instalar / Restaurar and let Updater CE download the package directly from the community developer's release.

Desligue e conecte

  1. Aguarde o prompt de conexão ao vivo.
  2. Desligue o Y2 totalmente. Use as instruções exatas de redefinição ou recuperação mostradas pelo Updater se o desligamento normal falhar.
  3. Conecte o cabo USB quando solicitado. Deixe parado até a mensagem de conclusão.
  4. Desconecte com segurança e inicie o Y2.

Retornar ao software original

Rockbox não bloqueia você no software personalizado. Depois que o Updater estiver configurado para o seu computador, use-o no Windows, macOS ou Linux para voltar de Rockbox ou de outro projeto listado: selecione Y2, escolher Software Originale corra Instalar / Restaurar.

  1. Aguarde até que o Updater prepare o pacote de ações Y2.
  2. Desligue o Y2 quando o aplicativo solicitar.
  3. Conecte o cabo de dados USB somente no prompt ao vivo.
  4. Deixe o player imóvel até a mensagem de sucesso.

Mantenha os pacotes Y1 e Y2 separados. Não exclua manualmente Rockbox arquivos primeiro; a restauração substitui o software do sistema.
