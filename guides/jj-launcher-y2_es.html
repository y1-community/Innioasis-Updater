Elige la ruta Y2

  1. Abra Innioasis Updater CE en su computadora (si aún no lo tiene, Obtener Updater CE). Seleccionar Y2 en Modelo del dispositivo.
  2. elegir JJ Launcher en Software (o iniciar con Obtener en Updater CE).
  3. Lea la nota de la versión, confirme la entrada Y2 y haga clic en Instalar / Restaurar.
  4. Apague y conecte el reproductor solo cuando el Actualizador lo solicite.
  5. Restaurar con Y2 Software original Si necesita la interfaz original nuevamente.

La discrepancia del modelo es lo primero que hay que comprobar

JJ Launcher también tiene una entrada Y1. Si el nombre del paquete parece incorrecto, regrese al Modelo de dispositivo. No fuerces un paquete Y1 sobre un Y2.

Volver al software original

JJ Launcher no cambia la ruta de regreso a la interfaz original. Una vez que Updater esté configurado para su computadora, ábralo en Windows, macOS o Linux y seleccione Y2 más Software original en lugar de JJ Launcher.

  1. Elija una versión estable del software original Y2.
  2. Haga clic Instalar / Restaurar y espere el mensaje de conexión en vivo.
  3. Apague el Y2 solo cuando se le solicite.
  4. Conecte el cable de datos USB cuando se le indique y déjelo quieto hasta que tenga éxito.

No elimine manualmente los archivos JJ Launcher primero y no utilice un paquete Y1. Si la falla ocurrió antes del mensaje USB, verifique primero la configuración de la computadora, el cable y la selección del modelo.
