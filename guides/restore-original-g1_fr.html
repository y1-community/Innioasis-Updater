Ce dont vous avez besoin

  • Un ordinateur Windows, macOS ou Linux. Updater CE s'exécute sur les trois.
  • Le câble de données USB fourni avec le lecteur. Les câbles de charge uniquement ne fonctionneront pas.
  • Le fonctionnaire rom_g1.zip package, que le programme de mise à jour télécharge pour vous, ou une copie du G1 archives si vous préférez flasher à la main.
  • Chargez dans le lecteur. Une restauration qui perd de la puissance est le seul moyen courant d’aggraver une mauvaise situation.

Cela remplace le système et efface le stockage interne. Copiez d'abord la musique, les enregistrements et les photos sur un ordinateur.

Itinéraire A : Updater CE (recommandé)

  1. Installer Innioasis Programme de mise à jour CE et ouvrez-le.
  2. Ensemble Modèle d'appareil à G1. Le modèle doit correspondre exactement au joueur.
  3. Choisissez Logiciel d'origine dans la liste des logiciels.
  4. Choisissez une version. La version stable la plus récente est la valeur par défaut sûre.
  5. Presse Installer / Restaurer et attendez que le package soit téléchargé et extrait.
  6. Éteignez complètement le lecteur, puis connectez le câble USB uniquement lorsque le programme de mise à jour le demande.
  7. Ne touchez pas le lecteur ou le câble jusqu'au message de réussite. Déconnectez et démarrez le lecteur.
Ne choisissez jamais un modèle différent pour « le faire fonctionner ». Un G1 a besoin d'un package G1. C’est en mélangeant des modèles que les joueurs finissent par avoir besoin d’une récupération manuelle.

Itinéraire B : SP Flash Tool (manuel)

Utilisez-le lorsqu'un ordinateur ne peut pas exécuter Updater CE, ou lorsque vous disposez déjà du package et préférez l'outil classique.

  1. Télécharger rom_g1.zip de la G1 archives et décompressez-le.
  2. Conservez le fichier scatter à côté des images. Ne renommez pas et ne déplacez pas les images.
  3. Ouvrez SP Flash Tool, choisissez Téléchargement uniquement, et chargez le fichier scatter.
  4. Éteignez le lecteur, appuyez sur Télécharger, puis connectez le câble.
  5. Attendez la marque verte de réussite avant de vous déconnecter.

Le SP Flash Tool guide couvre les pilotes et les invites Windows plus en détail. Sous Linux et macOS, Updater CE est la solution la plus simple car elle apporte sa propre gestion USB.

Après la restauration

  1. Déconnectez le lecteur et laissez-le démarrer tout seul.
  2. Choisissez votre langue et réglez l'horloge.
  3. Reconnectez-vous au Wi-Fi ou au Bluetooth si vous les utilisez.
  4. Copiez votre musique. Le guide de transfert a les noms de dossiers.

Si le lecteur démarre mais que l'écran, la molette ou les boutons se comportent toujours mal, la restauration a fonctionné ; c'est une question de matériel ou de configuration, pas de logiciel. Le guide de dépannage est le prochain arrêt.

Si ça ne marche pas

Le programme de mise à jour ne voit jamais le joueur

Changez le câble, puis le port USB. Évitez les hubs. Sous Windows, installez le pilote MediaTek à partir du page du pilote.

Le flash s'arrête tôt

Reconnectez-vous, chargez le lecteur et recommencez. Ne passez pas au package d’un autre modèle.

Le joueur reste noir

Chargez pendant une heure, puis maintenez l'alimentation pendant dix secondes. S'il est toujours mort, lisez le guide de récupération avant de réessayer.

Les questions que les gens posent

Est-ce que cela supprimera ma musique ?

Oui, la mémoire interne est effacée. Les fichiers sur une carte microSD survivent généralement, mais copiez-les d'abord dans un endroit sûr.

Puis-je revenir à Rockbox par la suite ?

Oui. La restauration du logiciel d'origine n'est pas une porte à sens unique ; la page du logiciel personnalisé pour votre modèle peut l'installer à nouveau.

Ai-je besoin du paramètre Type A / Type B ?

Seul le Y1 a ce choix, et uniquement pour les logiciels originaux. Tous les autres modèles utilisent un seul package.
