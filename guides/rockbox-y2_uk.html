Дивіться маршрут Rockbox.

Відео від Frawgeeys. Це працює як для моделей Y1, так і для Y2 — у Innioasis Updater CE виберіть Y2 як свою модель. Написані нижче кроки охоплюють послідовність встановлення Y2.

Відео автора Крістіан Плаза (іспанська). Він демонструє встановлення на Y1; вибрати Y2 в Updater CE для цього посібника.

Перш ніж натиснути «Установити».

Майте заряджений Innioasis Y2, USB кабель даних і комп’ютер із інстальованим Innioasis Updater CE (якщо ви його ще не встановили, Отримати Updater CE для Windows, macOS або Linux). Не використовуйте випуск Y1 лише тому, що його назва виглядає схожою.

Перевірка моделі: Y2 пакетів повної інсталяції можуть використовуватися rom_y2.zip. Назва файлу є корисною підказкою для завантаження вручну, але Updater має обробити вибір пакета за вас.

Виберіть Y2 в Updater

  1. Відкрийте Updater CE (або запустіть за допомогою Отримайте це в Updater CE) і встановіть Модель пристрою для Y2.
  2. Виберіть Rockbox в Програмне забезпечення.
  3. Виберіть випуск зі списку для Y2. Якщо в списку немає Y2 випуску, не замінюйте Y1 випуск.
  4. Натисніть Встановити / Відновити and let Updater CE download the package directly from the community developer's release.

Вимкніть, потім підключіть

  1. Дочекайтеся підказки підключення.
  2. Повністю вимкніть Y2. Використовуйте точні інструкції щодо скидання або відновлення, які показує Updater, якщо звичайне завершення роботи не вдається.
  3. Коли буде запропоновано, під’єднайте кабель USB. Залиште його нерухомим до повідомлення про завершення.
  4. Безпечно від’єднайте та запустіть Y2.

Повернутися до оригінального програмного забезпечення

Rockbox не блокує вас у спеціальному програмному забезпеченні. Налаштувавши Updater для вашого комп’ютера, використовуйте його в Windows, macOS або Linux, щоб повернутися з Rockbox або іншого проекту зі списку: виберіть Y2, вибрати Заводське ПЗ, і бігти Встановити / Відновити.

  1. Зачекайте, доки програма оновлення підготує стандартний пакет Y2.
  2. Вимкніть Y2, коли програма запитає.
  3. Підключайте кабель передачі даних USB лише за підказкою в реальному часі.
  4. Залиште плеєр нерухомим до повідомлення про успішне виконання.

Зберігайте пакети Y1 і Y2 окремо. Не видаляйте спочатку Rockbox файли вручну; відновлення замінює системне програмне забезпечення.
