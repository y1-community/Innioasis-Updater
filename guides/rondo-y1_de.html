Schritt-für-Schritt-Installation

  1. Öffnen Sie Updater CE: Starten Innioasis Updater CE auf Ihrem Windows-, macOS- oder Linux-Computer.
  2. Wählen Sie das Gerätemodell Y1: Auswählen Y1 im Dropdown-Menü „Gerätemodell“ (wählen Sie Type B, wenn Ihr Y1 mit der Originalsoftware vor 2.0.0 geliefert wurde; andernfalls behalten Sie Type A bei).
  3. Wählen Sie Rondo aus der Dropdown-Liste „Software“: Auswählen Rondo in der Softwareliste und wählen Sie die neueste Version aus. Updater CE verwendet automatisch den Android 4.2 Wi-Fi Base ROM und Rondo Release-Feed.
  4. Flashen Sie den Player: Klicken Sie Installieren / Wiederherstellen, schalten Sie Ihr Y1 vollständig aus und verbinden Sie es über ein USB-Datenkabel, wenn Updater CE Sie dazu auffordert.
  5. Trennen und booten: Warten Sie auf die grüne Abschlussmeldung, bevor Sie Ihr Y1 ausstecken.
  6. Komplette Einrichtung nach der Installation

    Befolgen Sie die Schritte in diesen Leitfaden um die Einrichtung auf Ihrem Y1 abzuschließen.
