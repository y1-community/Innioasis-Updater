O que você precisa

  • Um computador Windows, macOS ou Linux. Updater CE é executado em todos os três.
  • O cabo de dados USB que acompanha o player. Cabos somente para carga não funcionarão.
  • O oficial rom_r1.zip pacote, que o Updater baixa para você, ou uma cópia do R1 arquivo se você preferir piscar manualmente.
  • Carregue no player. Uma restauração que perde energia é a única maneira comum de piorar uma situação ruim.

Isso substitui o sistema e apaga o armazenamento interno. Copie músicas, gravações e fotos primeiro para um computador.

Rota A: Updater CE (recomendado)

  1. Instalar Innioasis Atualizador CE e abra-o.
  2. Definir Modelo do dispositivo para R1. O modelo deve corresponder exatamente ao jogador.
  3. Escolher Software Original na lista Software.
  4. Escolha um lançamento. A versão estável mais recente é o padrão seguro.
  5. Imprensa Instalar / Restaurar e espere enquanto o pacote é baixado e extraído.
  6. Desligue o player totalmente e conecte o cabo USB somente quando o Updater solicitar.
  7. Não toque no player ou no cabo até aparecer a mensagem de sucesso. Desconecte e inicie o player.
Nunca escolha um modelo diferente para “fazer funcionar”. Um R1 precisa de um pacote R1. Misturar modelos é como os jogadores acabam precisando de uma recuperação manual.

Rota B: SP Flash Tool (manual)

Use isto quando um computador não consegue executar Updater CE, ou quando você já possui o pacote e prefere a ferramenta clássica.

  1. Download rom_r1.zip do R1 arquivo e descompacte-o.
  2. Mantenha o arquivo scatter próximo às imagens. Não renomeie ou mova as imagens.
  3. Abra SP Flash Tool, escolha Baixar apenase carregue o arquivo scatter.
  4. Desligue o player, pressione Downloade conecte o cabo.
  5. Aguarde a marca verde de sucesso antes de desconectar.

O SP Flash Tool guia aborda os drivers e os prompts do Windows com mais detalhes. No Linux e no macOS, Updater CE é o caminho mais fácil porque traz seu próprio tratamento USB.

Após a restauração

  1. Desconecte o player e deixe-o iniciar sozinho.
  2. Escolha o seu idioma e acerte o relógio.
  3. Reconecte-se ao Wi-Fi ou Bluetooth se você os usar.
  4. Copie sua música de volta. O guia de transferência tem os nomes das pastas.

Se o player iniciar, mas a tela, a roda ou os botões ainda funcionarem mal, a restauração funcionou; essa é uma questão de hardware ou configuração, não de software. O guia de solução de problemas A próxima parada é.

Se não funcionar

O atualizador nunca vê o player

Troque o cabo e depois a porta USB. Evite hubs. No Windows, instale o driver MediaTek do página do motorista.

O flash para mais cedo

Reconecte, carregue o player e comece novamente. Não mude para um pacote de modelo diferente.

O jogador permanece preto

Carregue por uma hora e mantenha a energia por dez segundos. Se ainda estiver morto, leia o guia de recuperação antes de tentar novamente.

Perguntas que as pessoas fazem

Isso excluirá minha música?

Sim, o armazenamento interno foi apagado. Os arquivos em um cartão microSD geralmente sobrevivem, mas primeiro copie-os para algum lugar seguro.

Posso voltar para Rockbox depois?

Sim. A restauração do software original não é uma porta de mão única; a página do software personalizado para o seu modelo pode instalá-lo novamente.

Preciso da configuração Type A / Type B?

Somente Y1 tem essa escolha, e apenas para Software Original. Todos os outros modelos usam um único pacote.
