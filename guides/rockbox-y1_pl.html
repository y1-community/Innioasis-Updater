Czego potrzebujesz

Innioasis Y1, naładowana bateria, USB kabel do transmisji danych i komputer z zainstalowanym narzędziem Innioasis Updater CE (jeśli jeszcze go nie zainstalowałeś, Pobierz Updater CE dla systemów Windows, macOS lub Linux). Type A pasuje do Y1 odtwarzaczy dostarczonych z oryginalnym oprogramowaniem w wersji 2.0.0 lub nowszej; Type B pasuje do graczy wyposażonych w wcześniejszą wersję Oprogramowanie oryginalne. Zacznij od Type A, chyba że już wiesz, że Twój odtwarzacz potrzebuje kompilacji Type B.

W Aktualizatorze

  1. Otwórz Updater CE (lub uruchom za pomocą Zdobądź to w Updater CE) i ustaw Model urządzenia do Y1.
  2. Wybierz Rockbox w Oprogramowanie. Dokładna etykieta projektu może pojawić się jako Rockbox-Y1 w danych wydania.
  3. Wybierz stabilną wersję. Kompilacje 240p mają najszerszą kompatybilność ze starszymi motywami; Kompilacje 360p są przeznaczone dla ścieżki motywu Y1. Sprawdź informacje o wydaniu, jeśli rozróżnienie ma znaczenie.
  4. Kliknij Zainstaluj / Przywróć. Poczekaj, aż Updater CE pobierze pakiet bezpośrednio z wydania społecznościowego i przygotuje go.

Podłącz Y1

  1. Poczekaj, aż program aktualizujący poprosi o odtwarzacz.
  2. Całkowicie wyłącz Y1. Jeśli nie można go zamknąć, skorzystaj z instrukcji odzyskiwania wyświetlonych przez narzędzie Updater.
  3. Podłącz kabel danych USB tylko wtedy, gdy aplikacja tak każe. Odłóż odtwarzacz i nie zakłócaj połączenia.
  4. Rozłącz się dopiero po potwierdzeniu powodzenia programu aktualizującego, a następnie uruchom Y1.

Wróć do oryginalnego oprogramowania

Rockbox nie blokuje dostępu do niestandardowego oprogramowania. Po skonfigurowaniu narzędzia Updater na komputerze możesz go używać w systemie Windows, macOS lub Linux: wybierz Y1, wybierać Oprogramowanie oryginalnei biegnij Zainstaluj / Przywróć.

  1. Poczekaj, aż Updater zakończy przygotowywanie pakietu podstawowego.
  2. Wyłącz Y1, gdy aplikacja o to poprosi.
  3. Podłącz kabel danych USB tylko po wyświetleniu komunikatu na żywo.
  4. Pozostaw gracza w bezruchu do czasu pojawienia się komunikatu o powodzeniu.

Nie używaj pakietu Y2 i nie usuwaj ręcznie plików Rockbox przed przywróceniem. W przypadku zachowania koła Type B przed zmianą typu urządzenia sprawdź pasujący wariant zwolnienia.
