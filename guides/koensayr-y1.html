Install steps

  1. Open Innioasis Updater CE on your computer (if you don't have it yet, Get Updater CE). Select Y1 in Device Model.
  2. Choose Koensayr in Software (or launch with Get this in Updater CE).
  3. Select the listed release and click Install / Restore.
  4. Power off and connect the Y1 only when the app asks.
  5. Use Y1 Original Software to restore the stock path.

When something fails

Check the model and Type selection first. Then check the cable and whether the player was connected before the prompt. If the app stopped before it waited for USB, open troubleshooting.
