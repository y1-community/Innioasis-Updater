來自 Rockbox 或其他自訂軟體

一旦相關的 Windows、macOS 或 Linux 設定準備就緒，更新程式就會使用與自訂軟體安裝相同的指導安裝進行庫存恢復。您無需先手動移除Rockbox或其他自訂軟體的檔案。

  1. 在您的電腦上開啟 Innioasis Updater CE（如果您尚未安裝， 取得 Updater CE 為了 窗戶, macOS, 或 Linux).
  2. 套裝 裝置型號 到 Y1.
  3. 選擇 原廠軟體 在 軟體 （或使用 在 Updater CE 中取得此內容).
  4. 選擇最新的穩定 Y1 版本。通常的手動包是 rom.zip。 Type A 涵蓋隨原始軟體版本 2.0.0 或更高版本一起提供的 Y1 個播放器； Type B 涵蓋了附帶早期版本的播放器 原廠軟體 並且可以使用更具體的套件名稱。
  5. 點選 安裝 / 還原 並等待包解壓縮。

根據提示連接 Y1

作業系統更改更新程式周圍的設置，而不是恢復過程本身。在每個平台上，在連接之前等待即時提示。

  1. 當更新程式要求時，請完全關閉播放器電源。
  2. 僅在出現提示時連接 USB 資料線。
  3. 安裝運作時請勿觸摸播放器。
  4. 收到成功訊息後斷開連線並啟動 Y1。

如果仍然沒有啟動

在檢查型號、類型和版本的情況下重複恢復一次。如果更新程式在出現 USB 提示之前失敗，請檢查電腦設定、驅動程式或權限、資料線和擷取的檔案。如果偵測到Y1後失敗，則使用 故障排除指南 在進行手動 SP Flash Tool 或 MTKClient 恢復之前。

不要切換到 Y2 檔案。 Y1 復原需要 Y1 原始軟體版本，即使播放器目前正在執行不同的自訂軟體。
