Выберите маршрут Y2

  1. Откройте Innioasis Updater CE на своем компьютере (если у вас его еще нет, Скачать Updater CE). Выбирать Y2 в Модель устройства.
  2. Выбирать JJ Launcher в Программное обеспечение (или запустить с помощью Получите это в Updater CE).
  3. Прочтите примечание к выпуску, подтвердите запись Y2 и нажмите Установить / Восстановить.
  4. Выключайте и подключайте плеер только по запросу Updater.
  5. Восстановить с помощью Y2 Заводское ПО если вам снова понадобится стандартный интерфейс.

Несоответствие модели — первое, что нужно проверить

JJ Launcher также имеет запись Y1. Если имя пакета выглядит неправильно, вернитесь к модели устройства. Не навязывайте пакет Y1 пакету Y2.

Вернуться к исходному программному обеспечению

JJ Launcher не меняет маршрут обратно на стандартный интерфейс. Как только программа обновлений будет настроена для вашего компьютера, откройте ее в Windows, macOS или Linux и выберите Y2 плюс Заводское ПО вместо JJ Launcher.

  1. Выберите стабильную Y2 версию оригинального программного обеспечения.
  2. Нажмите Установить / Восстановить и дождитесь приглашения на подключение к реальному времени.
  3. Выключайте Y2 только по запросу.
  4. Подключите USB-кабель для передачи данных по запросу и оставьте его до успешного завершения.

Не удаляйте сначала файлы JJ Launcher вручную и не используйте пакет Y1. Если сбой произошел до появления приглашения USB, сначала проверьте настройку компьютера, кабель и выбор модели.
