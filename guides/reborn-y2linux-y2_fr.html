Installation étape par étape

  1. Installez Updater CE : Télécharger Innioasis Programme de mise à jour CE pour Windows, macOS ou Linux, puis ouvrez-le.
  2. Sélectionnez Y2 : Choisissez Y2 comme modèle d'appareil.
  3. Sélectionnez Reborn : Choisissez Reborn (Y2Linux) et la dernière version.
  4. Installer: Cliquez Installer / Restaurer, éteignez le Y2 et connectez USB lorsque vous y êtes invité.
  5. Attendez: Gardez le lecteur immobile jusqu'à ce que Updater CE confirme, puis déconnectez-vous.
  6. Configurer le Wi-Fi, le Bluetooth et la radio FM
