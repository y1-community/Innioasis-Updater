アップデーター内

  1. Updater CE を開きます (または次のコマンドで起動します) Updater CE で入手) を設定してください デバイスモデル 支援先: Y1.
  2. 選択してください Rockbox で ソフトウェア。正確なプロジェクト ラベルは、リリース データでは Rockbox-Y1 として表示される場合があります。
  3. 安定したリリースを選択してください。 240p ビルドには、最も幅広い古いテーマの互換性があります。 360p ビルドは Y1 テーマ パスを対象としています。違いが重要な場合は、リリース ノートを確認してください。
  4. クリック インストール / 復元。 Updater CE がコミュニティ開発者のリリースからパッケージを直接ダウンロードして準備するまで待ちます。

Y1を接続します

  1. Updater がプレーヤーを要求するまで待ちます。
  2. Y1 の電源を完全にオフにします。シャットダウンしない場合は、アップデーターが表示する復旧手順をご利用ください。
  3. USB データ ケーブルは、アプリが指示した場合にのみ接続してください。プレーヤーを置き、接続を妨げないでください。
  4. アップデータが成功を確認した後でのみ切断し、Y1 を開始します。

元のソフトウェアに戻る

Rockbox はカスタム ソフトウェアに閉じ込められることはありません。アップデーターをコンピューターにセットアップしたら、Windows、macOS、または Linux で使用します。 Y1、 選ぶ 純正ソフトウェア、実行します インストール / 復元.
