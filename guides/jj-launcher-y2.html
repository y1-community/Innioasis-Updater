Choose the Y2 route

  1. Open Innioasis Updater CE on your computer (if you don't have it yet, Get Updater CE). Select Y2 in Device Model.
  2. Choose JJ Launcher in Software (or launch with Get this in Updater CE).
  3. Read the release note, confirm the Y2 entry, and click Install / Restore.
  4. Power off and connect the player only when Updater asks.
  5. Restore with Y2 Original Software if you need the stock interface again.

Model mismatch is the first thing to check

JJ Launcher also has a Y1 entry. If the package name looks wrong, return to Device Model. Do not force a Y1 package onto a Y2.

Go back to Original Software

JJ Launcher does not change the route back to the stock interface. Once Updater is set up for your computer, open it on Windows, macOS, or Linux and select Y2 plus Original Software instead of JJ Launcher.

  1. Choose a stable Y2 Original Software release.
  2. Click Install / Restore and wait for the live connection prompt.
  3. Power off the Y2 only when asked.
  4. Connect the USB data cable at the prompt and leave it still until success.

Do not manually remove JJ Launcher files first, and do not use a Y1 package. If the failure happened before the USB prompt, check the computer setup, cable, and model selection first.
