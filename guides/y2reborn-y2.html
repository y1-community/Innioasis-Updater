Install Y2Reborn on the Y2.

Y2Reborn brings native Linux, 60 FPS GPU graphics, and a Rust audio player by Schulzcode to the Innioasis Y2. The safe route starts with model selection.

Get Updater CEGet this in Updater CEWhy Y2Reborn?

In Updater

  1. Open Innioasis Updater CE on your computer (if you don't have it yet, Get Updater CE). Select Y2 in Device Model.
  2. Choose Y2Reborn in Software (or launch with Get this in Updater CE).
  3. Choose the listed Y2 release.
  4. Click Install / Restore, power off when asked, and connect USB at the prompt.
  5. Restore with Y2 Original Software if needed.

Do not substitute a Y1 package

Check twice: Y2 full-install packages use rom_y2.zip. A plain Y1 package is not a safe substitute.

First boot and setup tips

  • Connecting to Wi-Fi — Navigate to Settings -> Wi-Fi, pick your network, and type your password using the click-wheel keyboard.
  • Last.fm scrobbling — Open Settings -> Scrobbling -> Last.fm and scan the generated QR code with your phone. Once authenticated, scrobbles are queued offline and uploaded automatically when reconnected.
  • Internet Radio — Select Radio from the main menu to stream thousands of global stations from radio-browser.info by genre, country, and language with live logos.
  • Headphone AutoEQ presets — Open Settings -> Audio -> Equalizer to choose from 47 calibrated AutoEQ correction curves for popular IEMs and headphones.
  • Theme customization — Go to Settings -> Themes to choose from 16 built-in skins, or place custom skins into /media/sd/Skins/ on your MicroSD card.
  • Over-The-Air updates — Check for future releases directly from your player by opening Settings -> About & Updates -> Update Now.
