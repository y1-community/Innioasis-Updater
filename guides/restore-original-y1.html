From Rockbox or another custom software

Once the relevant Windows, macOS, or Linux setup is ready, Updater uses the same guided install for a stock restore as it does for a custom software install. You do not need to manually delete Rockbox or another custom software's files first.

  1. Open Updater on Windows, macOS, or Linux.
  2. Set Device Model to Y1.
  3. Choose Original Software in Software.
  4. Choose the latest stable Y1 release. The usual manual package is rom.zip. Type A covers Y1 players that shipped with Original Software version 2.0.0 or later; Type B covers players that shipped with an earlier version of the Original Software and may use a more specific package name.
  5. Click Install / Restore and wait for the package to extract.

Connect the Y1 at the prompt

The operating system changes the setup around Updater, not the restore journey itself. On every platform, wait for the live prompt before connecting.

  1. Power the player fully off when Updater asks.
  2. Connect the USB data cable only at the prompt.
  3. Do not touch the player while the install runs.
  4. Disconnect after the success message and start the Y1.

If it still does not start

Repeat the restore once with the model, Type, and release checked. If Updater fails before the USB prompt, inspect the computer setup, driver or permissions, data cable, and extracted files. If it fails after detecting the Y1, use the troubleshooting guide before moving to manual SP Flash Tool or MTKClient recovery.

Do not switch to Y2 files. A Y1 restore needs a Y1 Original Software release, even if the player is currently running a different custom software.
