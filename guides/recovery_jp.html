Y1 パッケージと Y2 パッケージは互換性がありません

モデルをクロスフラッシュしないでください。 Y1 rom.zip Y2 パッケージではなく、Y2 パッケージでもありません rom_y2.zip Y1 では実行されません。間違ったモデルをフラッシュすることは、プレーヤーが無効なコントロールやブート ループに陥る最も一般的な理由の 1 つです。

プレーヤーに印刷されているモデルを確認し、Updater CE で一致させてからリリースを選択してください。

プレーヤーの電源をオフにし、アップデーターが要求した場合にのみ USB データ ケーブルを接続します。成功メッセージが表示されるまで接続したままにしておきます。

Updater CE に同梱されている手動リカバリ

アップデーターがジョブを完了できない場合、同じインストールには手動ツールが含まれます。 SP Flash Tool は Windows および Linux x86 マシンにバンドルされており、MTKClient ルートは macOS をカバーします。どちらも、モデルに一致するファームウェア パッケージが必要です。 ファームウェアのダウンロード ページ。

お使いのプラットフォームのガイドを使用して、プレーヤーを充電し続けてください。どのツールもプレーヤーをまったく検出しない場合は、ファームウェアではなくハードウェアに問題がある可能性があります。

助けを求めるときに含めるべきもの

  • モデル — Y1 または Y2 — プレーヤーに印刷されています。
  • 画面の機能: 何もない、ロゴ、ブート ループ、またはホーム画面。
  • コンピューターがプレーヤーを MediaTek デバイスとして検出するかどうか。
  • 正確なアップデータ メッセージと選択したパッケージ。
  • 手動ツールを含む、すでに試したこと。

Innioasis リカバリに関するよくある質問

電源が入らない Innioasis プレーヤーを修正するにはどうすればよいですか?

既知のデータ ケーブルを使用して 30 分間充電し、15 秒間電源を保持して強制的に再起動し、コンピュータがそれを検出するかどうかを確認します。存在する場合は、モデルが一致した元のソフトウェアを復元します。そうでない場合は、Updater CE に含まれている手動回復ツールを使用してください。

Y1 または Y2 スクロール ホイールが機能しないのはなぜですか?

アップデート後にホイールが停止した場合は、通常、ファームウェアの不一致が原因です。モデルに一致する元のソフトウェアを再インストールし、再度テストします。すべてのファームウェアでホイールが故障している場合は、ハードウェア障害として扱います。

リカバリ用のファームウェアはどこからダウンロードすればよいですか?

innioasis.app/firmware.html のファームウェア ダウンロード ページには、各モデルのオリジナル パッケージとカスタム パッケージがホストされています。プレーヤーに一致する Y1 または Y2 パッケージを常に選択してください。

Updater CE にはどのような回復ツールが含まれていますか?

Updater CE には、Windows および Linux の SP Flash Tool と、通常のインストールが完了できない場合の手動回復用の macOS を含む MTKClient ルートが含まれています。

関連する修正

  • Y1 スクロールホイールが機能しない — アップデート後にクリックホイールが反応しなくなる
  • Y2 スクロール ホイールが機能しない — Y2 についても同じチェック
  • Y1がオンになりません — 充電、再起動、手動回復
  • Y2がオンになりません — Y2 についても同じチェック
  • SP Flash Tool ガイド — Windows および Linux での手動フラッシュ
