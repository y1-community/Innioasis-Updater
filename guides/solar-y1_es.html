Elige la ruta Y1

  1. Abra Innioasis Updater CE en su computadora (si aún no lo tiene, Obtener Updater CE). Seleccionar Y1 en Modelo del dispositivo.
  2. elegir Solar en Software (o iniciar con Obtener en Updater CE).
  3. Lea la nota de la versión, seleccione una versión y haga clic Instalar / Restaurar.
  4. Apague y conecte el reproductor solo cuando el Actualizador lo solicite.
  5. Restaurar con Y1 Software original Si necesita la interfaz original nuevamente.

Mantenga la nota del proyecto a la vista

Solar está en desarrollo activo. Las características y la compatibilidad con el modelo pueden cambiar, así que consulte las notas de la versión del proyecto. El actualizador muestra lo que está disponible para su modelo en este momento.

Volver al software original

Solar no cambia la ruta de regreso a la interfaz original. Una vez que Updater esté configurado para su computadora, ábralo en Windows, macOS o Linux y seleccione Y1 más Software original en lugar de Solar.

  1. Elija una versión estable del software original Y1.
  2. Haga clic Instalar / Restaurar y espere el mensaje de conexión en vivo.
  3. Apague el Y1 solo cuando se le solicite.
  4. Conecte el cable de datos USB cuando se le indique y déjelo quieto hasta que tenga éxito.

No elimine manualmente los archivos Solar primero y no utilice un paquete Y2. Si la falla ocurrió antes del mensaje USB, verifique primero la configuración de la computadora, el cable y la selección del modelo.
