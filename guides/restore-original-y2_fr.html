Depuis Rockbox ou un autre logiciel personnalisé

Une fois que la configuration Windows, macOS ou Linux appropriée est prête, le retour à l'interface stock Y2 utilise le même flux de mise à jour que l'installation d'un projet communautaire. Ne mélangez pas manuellement les fichiers Y1 dans le lecteur et ne supprimez pas d'abord les dossiers système.

  1. Ouvrez Innioasis Updater CE sur votre ordinateur (si vous ne l'avez pas encore installé, Obtenir Updater CE pour Fenêtres, macOS, ou Linux).
  2. Ensemble Modèle d'appareil à Y2.
  3. Choisissez Logiciel d'origine.
  4. Sélectionnez une version stable Y2. Les packages d'installation complète manuelle peuvent utiliser rom_y2.zip.
  5. Cliquez Installer / Restaurer et attendez l’étape d’extraction.
Ne remplacez pas : un Y1 rom.zip n'est pas un package Y2. Si la liste des versions semble erronée, arrêtez et resélectionnez Y2.

Suivez l'invite de connexion

Windows, macOS et Linux ont des notes de configuration informatiques différentes, mais la séquence côté lecteur reste la même : éteignez-le lorsque vous y êtes invité, puis connectez le câble de données à l'invite en direct.

  1. Éteignez complètement le Y2 lorsque le programme de mise à jour le demande.
  2. Connectez USB uniquement lorsque l'application indique qu'elle est prête.
  3. Laissez le câble tranquille jusqu'au message de réussite.
  4. Déconnectez-vous en toute sécurité et démarrez le lecteur.

Toujours bloqué ?

Vérifiez le modèle, l'emballage, le câble et le timing de connexion avant d'essayer un outil manuel. Le guide de dépannage explique ce que signifie une panne avant USB par rapport à une panne après la détection du périphérique.

Gardez les colis séparés : un Y1 rom.zip n'est pas une restauration Y2. Si la liste des versions semble incorrecte, arrêtez et sélectionnez à nouveau Y2.
