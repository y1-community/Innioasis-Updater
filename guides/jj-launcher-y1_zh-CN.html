选择Y1路线

  1. 在您的计算机上打开 Innioasis Updater CE（如果您还没有， 获取 Updater CE）。选择 Y1 在 设备型号.
  2. 选择 JJ Launcher 在 软件 （或启动 在 Updater CE 中获取).
  3. 阅读发行说明，选择 Y1 版本，然后单击 安装 / 恢复.
  4. 仅当更新程序要求时关闭并连接播放器。
  5. 使用 Y1 恢复 原厂软件 如果您再次需要库存接口。

模型不匹配是首先要检查的事情

JJ Launcher 也有一个 Y2 条目。如果包名称看起来错误，请返回设备模型。不要将 Y2 包强行放到 Y1 上。

返回原始软件

JJ Launcher 不会更改返回库存接口的路由。为您的计算机设置更新程序后，请在 Windows、macOS 或 Linux 上打开它，然后选择 Y1 加号 原厂软件 而不是 JJ Launcher。

  1. 选择稳定的 Y1 原始软件版本。
  2. 点击 安装 / 恢复 并等待实时连接提示。
  3. 仅在询问时关闭 Y1 电源。
  4. 根据提示连接USB数据线并保持不动直至成功。

不要先手动删除 JJ Launcher 文件，并且不要使用 Y2 包。如果故障发生在USB提示之前，请首先检查计算机设置、电缆和型号选择。
