Wählen Sie die Route Y1.

  1. Öffnen Sie Innioasis Updater CE auf Ihrem Computer (falls Sie es noch nicht haben, Updater CE holen). Auswählen Y1 In Gerätemodell.
  2. Wählen Sie JJ Launcher In Software (oder starten Sie mit In Updater CE erhalten).
  3. Lesen Sie die Versionshinweise, wählen Sie die Version Y1 aus und klicken Sie Installieren / Wiederherstellen.
  4. Schalten Sie den Player nur aus und schließen Sie ihn an, wenn der Updater Sie dazu auffordert.
  5. Wiederherstellen mit Y1 Original-Software wenn Sie die Standardschnittstelle erneut benötigen.

Die Nichtübereinstimmung der Modelle ist das erste, was überprüft werden muss

JJ Launcher hat auch einen Y2-Eintrag. Wenn der Paketname falsch aussieht, kehren Sie zum Gerätemodell zurück. Erzwingen Sie kein Y2-Paket auf einem Y1.

Gehen Sie zurück zur Originalsoftware

JJ Launcher ändert die Route zurück zur Standardschnittstelle nicht. Sobald Updater für Ihren Computer eingerichtet ist, öffnen Sie es unter Windows, macOS oder Linux und wählen Sie Y1 Plus Original-Software statt JJ Launcher.

  1. Wählen Sie eine stabile Y1 Originalsoftwareversion.
  2. Klicken Sie Installieren / Wiederherstellen und warten Sie auf die Live-Verbindungsaufforderung.
  3. Schalten Sie Y1 nur aus, wenn Sie dazu aufgefordert werden.
  4. Schließen Sie bei der Aufforderung das USB-Datenkabel an und lassen Sie es bis zum Erfolg ruhen.

Entfernen Sie nicht zuerst JJ Launcher-Dateien manuell und verwenden Sie kein Y2-Paket. Wenn der Fehler vor der Eingabeaufforderung USB aufgetreten ist, überprüfen Sie zunächst die Computerkonfiguration, das Kabel und die Modellauswahl.
