Installazione passo dopo passo

  1. Apri Updater CE: Lancio Innioasis Programma di aggiornamento CE sul tuo computer Windows, macOS o Linux.
  2. Scegli il modello del dispositivo Y1: Seleziona Y1 nel menu a discesa Modello dispositivo (scegli Type B se il tuo Y1 è stato fornito con il software originale prima della 2.0.0; altrimenti mantieni Type A).
  3. Scegli Rondo dal menu a discesa Software: Seleziona Rondo nell'elenco Software e seleziona la versione più recente. Updater CE utilizza automaticamente la base Wi-Fi di Android 4.2 ROM e il feed di rilascio Rondo.
  4. Flashare il lettore: Fare clic Installa / Ripristina, spegni completamente il tuo Y1 e collegalo tramite un cavo dati USB quando Updater CE lo richiede.
  5. Disconnetti e avvia: Attendi il messaggio verde di completamento prima di scollegare il tuo Y1.
  6. Completa la configurazione post-installazione
