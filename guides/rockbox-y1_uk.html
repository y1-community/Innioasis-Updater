Те, що вам потрібно

Innioasis Y1, заряджена батарея, USB кабель даних і комп’ютер із встановленим Innioasis Updater CE (якщо ви ще не встановили його, Отримати Updater CE для Windows, macOS або Linux). Type A підходить для Y1 гравців, які постачаються з оригінальним програмним забезпеченням версії 2.0.0 або новішої; Type B підходить гравцям, які постачалися з попередньою версією Заводське ПЗ. Почніть з Type A, якщо ви вже не знаєте, що вашому гравцеві потрібна збірка Type B.

Дивіться маршрут Rockbox.

Відео від Frawgeeys. Це працює як для моделей Y1, так і для Y2 — у Innioasis Updater CE виберіть Y1 як свою модель. Написані нижче кроки охоплюють послідовність встановлення Y1.

Відео автора Крістіан Плаза (іспанською), починаючи з етапу встановлення Rockbox. Наведені нижче кроки охоплюють послідовність Y1.

У програмі оновлення

  1. Відкрийте Updater CE (або запустіть за допомогою Отримайте це в Updater CE) і встановіть Модель пристрою для Y1.
  2. Виберіть Rockbox в Програмне забезпечення. Точна мітка проекту може відображатися як Rockbox-Y1 у даних випуску.
  3. Виберіть стабільний випуск. Збірки 240p мають найширшу сумісність старих тем; Збірки 360p призначені для шляху теми Y1. Перевірте примітки до випуску, якщо відмінність має значення.
  4. Натисніть Встановити / Відновити. Зачекайте, поки Updater CE завантажить пакет безпосередньо з випуску розробника спільноти та підготує його.

Підключіть Y1

  1. Зачекайте, доки програма оновлення запитає плеєр.
  2. Повністю вимкніть Y1. Якщо він не вимикається, скористайтеся інструкцією з відновлення, яку показує Updater.
  3. Підключайте кабель даних USB лише тоді, коли програма каже. Відкладіть плеєр і не заважайте з'єднанню.
  4. Відключіться лише після того, як програма оновлення підтвердить успішне виконання, а потім запустіть Y1.

Повернутися до оригінального програмного забезпечення

Rockbox не блокує вас у спеціальному програмному забезпеченні. Після налаштування програми оновлення для вашого комп’ютера використовуйте її в Windows, macOS або Linux: виберіть Y1, вибрати Заводське ПЗ, і бігти Встановити / Відновити.

  1. Зачекайте, доки програма оновлення завершить підготовку стандартного пакета.
  2. Вимкніть Y1, коли програма запитає.
  3. Підключайте кабель передачі даних USB лише за підказкою в реальному часі.
  4. Залиште плеєр нерухомим до повідомлення про успішне виконання.

Не використовуйте пакет Y2 і не видаляйте файли Rockbox вручну перед відновленням. Для Type B поведінки колеса перевірте відповідний варіант випуску перед зміною типу пристрою.
