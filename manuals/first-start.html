First start: charge, power on and pick a language

A new player only needs three things: a little charge, a long press on power, and a minute in Settings.

All player manuals Firmware archive

Charge the player before its first proper listen. A full charge from empty takes about an hour and a half on the Y series, and longer on the larger players. You can use the player while it charges, but a flash or a firmware update should always start with a healthy battery.

  1. Charge it. Use the cable that came with the player. A phone charger works too; a computer USB port is slower.
  2. Turn it on. Press and hold power for about three seconds. On the players with a scroll wheel, the power button is on the side.
  3. Pick your language. Open Settings, choose Language, and set the language you read most comfortably.
  4. Set the clock. Still in Settings, set the date and time so recordings and playlists sort correctly.
  5. Add music. Connect the player to a computer and copy files across, or insert a microSD card. The file transfer guide walks through both.
A note about the reset pin. The small hole marked Reset forces the player to shut down when it freezes. It is not a factory reset. If you want to erase the player, use the Settings menu or the factory reset guide.
