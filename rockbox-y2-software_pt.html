Rockbox Y2 etapas de instalação

  1. Abra o Innioasis Updater CE no seu computador (se precisar do aplicativo, Obter o Updater CE). Definir Modelo do aparelho para Y2.
  2. Escolher Rockbox em Software.
  3. Escolha uma versão listada explicitamente para Y2.
  4. Clique Instalar / Restaurar e aguarde a preparação do pacote.
  5. Desligue e conecte o Y2 somente quando Updater CE solicitar.

Não force um pacote Y1 porque o nome do projeto parece o mesmo. Se nenhuma versão Y2 aparecer, pare e verifique o modelo e os dados da versão atual.

Perguntas frequentes

Posso restaurar o software Y2 original mais tarde?

Sim. Escolha Y2 e Software Original em Updater CE. Veja o Y2 página de software de estoque para a sequência de restauração.

Por que o pacote pode ser chamado rom_y2.zip?

Essa é uma pista de download manual usada por algumas Y2 versões de instalação completa. A escolha mais segura ainda é selecionar Y2 em Updater CE e usar o release que ele apresenta.

Posso usar o tutorial Y1 Rockbox?

Use-o apenas para uma ideia ampla. Para a seleção do pacote e do modelo, siga este Y2 guia específico.
