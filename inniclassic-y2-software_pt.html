Inniclassic Y2 etapas de instalação

  1. Abra o Innioasis Updater CE no seu computador (se precisar do aplicativo, Obter o Updater CE). Definir Modelo do aparelho para Y2.
  2. Escolher Inniclassic em Software.
  3. Escolha o lançamento listado para Y2.
  4. Clique Instalar / Restaurar.
  5. Desligue e conecte o Y2 somente quando Updater CE solicitar.

Perguntas frequentes

Posso restaurar o software padrão Y2?

Sim. Selecione Y2 e Software Original em Updater CE. O Y2 guia de software de estoque cobre o caminho de retorno.

Posso usar Inniclassic em Y1?

Sim. O mesmo projeto também publica Y1 pacotes — rom.zip para Type A e rom_type_b.zip para Type B. Selecione Y1 em Updater CE e instale a compilação Y1; o Página de instalação do Y1 cobre isso.

E se a instalação falhar?

Observe se o Updater falhou antes ou depois de detectar o Y2, então verifique o cabo, configuração da plataforma, modelo e tempo de conexão em solução de problemas.
