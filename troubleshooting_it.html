Si è fermato prima del prompt USB.

Questo è un problema del computer, non un problema del cavo. Controlla il tuo modello. Decomprimere nuovamente il file. Allora prova Installa / Ripristina. Se l'elenco delle versioni è vuoto, aprire il file directory del firmware.

Non è possibile connettersi al lettore

  1. Spegnere completamente il Y1 o Y2 corretto.
  2. Scollega il cavo, chiudi altri strumenti Flash o Android e avvia nuovamente l'installazione.
  3. Connettiti solo quando Updater dice che è pronto.
  4. Utilizzare un cavo dati USB corto direttamente nel computer, se possibile non un hub.
  5. Su Windows, reinstallare il driver MediaTek e riavviare. Su Linux, controlla le autorizzazioni USB/serial.

Ha rilevato il lettore ma il flash non è riuscito

Si fermi qui. Non provare un modello diverso. Chiudi gli altri strumenti, verifica di aver scelto il Y1 o il Y2 corretto e utilizza il software originale corrispondente se il lettore non si avvia. SP Flash Tool e MTKClient sono inclusi se ne hai bisogno e i file si trovano nel formato pagina del firmware.

Note sui driver di Windows

Alcune installazioni Windows bloccano il driver MediaTek a causa dell'isolamento del Core. Seguire le attuali linee guida sulla sicurezza di Windows prima di modificare l'integrità della memoria e riattivarla al termine, se il sistema lo consente.
