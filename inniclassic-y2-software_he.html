Inniclassic Y2 שלבי התקנה

  1. פתח את Innioasis Updater CE במחשב שלך (אם אתה צריך את האפליקציה, הורדת Updater CE). סט דגם המכשיר ל Y2.
  2. בחר Inniclassic ב תוכנה.
  3. בחר את הגרסה הרשומה עבור Y2.
  4. לחץ התקנה / שחזור.
  5. כבה וחבר את ה-Y2 רק כאשר Updater CE מבקש.

שאלות נפוצות

האם אוכל לשחזר את תוכנת המניות Y2?

כֵּן. בחר Y2 ותוכנה מקורית בעדכון CE. ה Y2 מדריך תוכנה למניות מכסה את נתיב החזרה.

האם אני יכול להשתמש ב-Inniclassic ב-Y1?

כֵּן. אותו פרויקט מפרסם גם חבילות Y1 - rom.zip עבור Type A ו rom_type_b.zip עבור Type B. בחר Y1 ב- Updater CE והתקן את ה-Y1 build; את דף ההתקנה של Y1 מכסה אותו.

מה אם ההתקנה נכשלת?

שים לב אם העדכון נכשל לפני או אחרי זיהוי ה-Y2, ולאחר מכן בדוק את הכבל, הגדרת הפלטפורמה, הדגם ותזמון החיבור ב- פתרון בעיות.

השתמשו במסלול המודרך

פעם ראשונה שאתה משתמש ב-Updater? עיין בהגדרה המודרכת ל הורדת Updater CE ב-Windows, macOS או Linux לפני חיבור הנגן.
