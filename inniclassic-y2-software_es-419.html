Inniclassic Y2 pasos de instalación

  1. Abra Innioasis Updater CE en su computadora (si necesita la aplicación, Obtener Updater CE). conjunto Modelo del dispositivo a Y2.
  2. elegir Inniclassic en Software.
  3. Elija la versión listada para Y2.
  4. Haga clic Instalar / Restaurar.
  5. Apague y conecte el Y2 solo cuando Updater CE lo solicite.

Preguntas frecuentes

¿Puedo restaurar el software original Y2?

Sí. Seleccione Y2 y Software original en Updater CE. El Y2 guía de software de stock cubre el camino de regreso.

¿Puedo usar Inniclassic en Y1?

Sí. El mismo proyecto también publica Y1 paquetes: rom.zip para Type A y rom_type_b.zip para Type B. Seleccione Y1 en Updater CE e instale la compilación Y1; el Página de instalación de Y1 lo cubre.

¿Qué pasa si la instalación falla?

Tenga en cuenta si el Actualizador falló antes o después de detectar Y2, luego verifique el cable, la configuración de la plataforma, el modelo y el tiempo de conexión en solución de problemas.
