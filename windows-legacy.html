Install software, firmware or updates on an older Windows PC

Updater CE is a 64-bit application and needs Windows 10 (1809) or newer, so it cannot open on Windows XP, Vista, 7, 8, 8.1 or on a 32-bit PC. Your player is not stuck: every package in the archive also has a for Windows XP/7/8 32/64-bit zip that carries SP Flash Tool beside the rom, and that tool runs on those systems.

Which package do I download?

Open the firmware list, find your model, then find the software you want: Original Software, Rockbox, Solar, JJ Launcher, Inniclassic, Y2Player, Koensayr or a community system. Each release shows its packages as buttons. On an older or 32-bit Windows PC the archive offers the Windows XP/7/8 (32/64-bit) package; on a supported PC the same row offers the normal Windows, macOS and Linux builds.

The package name tells you what it is. A legacy package is named after the release, with -windows-legacy before .zip. It holds the firmware files (rom and scatter file), SP Flash Tool, the MediaTek USB driver and a donate.txt. Nothing in it needs an internet connection.

Firmware is model-specific. Software written for the Y1 cannot be installed on a Y2, and the reverse is also true. Check the model printed on the player before you download.

Step 1: install the MediaTek USB driver

  1. Unpack the legacy package somewhere simple, such as C:\Innioasis. Avoid Download folders with long names and spaces.
  2. Open the Driver folder and run the installer inside it. On Windows XP accept the unsigned-driver warning.
  3. Restart the PC. The driver only works after a reboot.

If the player is never detected later, reinstall the driver and try another USB port on the PC itself rather than a hub.

Step 2: unpack the firmware package

Unpack the package with the built-in Windows zip support, 7-Zip, or WinRAR. You need the folder that contains the scatter file (a small text file ending in _Android_scatter.txt) and the rom files beside it.

If the archive has a Firmware or SP_Flash_Tool subfolder, the scatter file is inside it.

Step 3: flash with SP Flash Tool

  1. Open flash_tool.exe from the SP Flash Tool folder.
  2. Click Scatter-loading, choose the scatter file you found, and confirm the partition list appears.
  3. Leave the default Download Only mode. Keep Preloader ticked only if you are restoring a player that will not start at all.
  4. Click Download, then power the player fully off and connect the USB cable.
  5. Wait for the green success box. Do not unplug before it appears, and do not close SP Flash Tool while the progress bar is moving.

Time and safety. A full flash takes a few minutes on an older PC. Use a cable that carries data, not a charge-only cable, and keep the PC awake. If the progress bar does not start, disconnect, hold the player's power button for ten seconds, and start again from the Download button.

Software, firmware, update or package: what is the difference?

The words are used interchangeably on this site, and the steps above are the same for each:

  • Firmware or rom: the complete system image for a model. Flashing it replaces everything on the player's system partition.
  • Software or system: a community build such as Rockbox, Solar or JJ Launcher, delivered as the same kind of rom package.
  • Update: a newer release of either of the above. Install it exactly like a fresh package.
  • Package or zip: the download itself. The legacy package is the one that includes SP Flash Tool.

Updater CE does the same job with fewer steps, and it keeps your music and Bluetooth pairings. It is only available on 64-bit Windows 10 (1809 or newer), macOS and Linux. A legacy package flash writes the system partition, so copy your music off the player first if you have files you cannot replace.

After the flash

Disconnect the player, switch it on, and let it finish its first boot. If it starts but shows the wrong language, install the package again with the language you want. If it does not start, connect it while switched off and flash again, this time with Preloader ticked.
