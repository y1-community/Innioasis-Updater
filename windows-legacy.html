Install software, firmware or updates on an older Windows PC

On Windows XP, Vista, 7, 8, 8.1 or a 32-bit PC we install with a Windows XP/7/8 software install zip instead of Updater CE. Every package in the archive has one, it runs on this computer, and it contains everything needed for the install: the firmware, the MediaTek driver and the installer. On 32-bit Linux, read the Linux page instead.

Which package do I download?

Open the firmware list, find your model, then find the software you want: Original Software, Rockbox, Solar, JJ Launcher, Inniclassic, Y2Player, Koensayr or a community system. Each release shows its packages as buttons. On an older or 32-bit PC the archive offers the Windows XP/7/8 software install zip; on a supported PC the same row offers the Windows, macOS and Linux builds.

The package name tells you what it is. A software install zip is named after the release, with -windows-legacy before .zip. Inside you get the firmware files (the rom and its scatter file), the MediaTek USB driver, the installer that writes the firmware, a readme with the details of that release and a donate.txt. Nothing in it needs an internet connection.

Firmware is model-specific. Software written for the Y1 cannot be installed on a Y2, and the reverse is also true. Check the model printed on the player before you download.

Step 1: install the MediaTek USB driver

  1. Unpack the software install zip somewhere simple, such as C:\Innioasis. Avoid Download folders with long names and spaces.
  2. Run the driver installer from the zip. It is named 1. Install Drivers and Reboot PC. On Windows XP accept the unsigned-driver warning.
  3. Restart the PC. The driver only works after a reboot.

The folders in the zip are numbered in the order you use them, so the next step is the folder numbered 2.

Step 2: unpack the firmware

Unpack the zip with the built-in Windows zip support, 7-Zip, or WinRAR. You need the folder that contains the scatter file (a small text file ending in _Android_scatter.txt) and the rom files beside it.

If the archive has a firmware or tool subfolder, the scatter file is inside it. Keep the folder together; the installer reads the files next to itself.

Step 3: write the firmware

  1. Open the app in the folder numbered 2 (its name begins with 2. Open and run).
  2. Choose Scatter-loading, pick the scatter file you found, and check that the partition list fills with the rom files beside it.
  3. Leave the default Download Only mode. Keep Preloader ticked only if you are restoring a player that will not start at all.
  4. Press Download. Then power the player fully off and plug in the USB cable. The app writes the firmware the moment the player appears.
  5. Wait for the green success box. Do not unplug the player, and do not close the app, while the progress bar is moving.

If the player will not switch on at all, straighten a paperclip and press the small reset hole on the player for a second before you connect it. That resets the power state without touching your files, and it is the usual fix when nothing appears after you press Download.

Time and safety. A full write takes a few minutes on an older PC. Use a cable that carries data, not a charge-only cable, and keep the PC awake. If the progress bar does not start, unplug the player, hold its power button for ten seconds, and start again from the Download button.

Software, firmware, update or package: what is the difference?

The words are used interchangeably on this site, and the steps above are the same for each:

  • Firmware or rom: the complete system image for a model. Installing it replaces everything on the player's system partition.
  • Software or system: a community build such as Rockbox, Solar or JJ Launcher, delivered as the same kind of rom package.
  • Update: a newer release of either of the above. Install it exactly like a fresh package.
  • Package, zip or software install zip: the download itself. The software install zip is the one built for this PC.

Updater CE does the same job with fewer steps, and it keeps your music and Bluetooth pairings. It is only available on 64-bit Windows 10 (1809 or newer), macOS and 64-bit Linux. A software install zip install writes the system partition, so copy your music off the player first if you have files you cannot replace.

After the install

Disconnect the player, switch it on, and let it finish its first boot. If it starts but shows the wrong language, install the package again with the language you want. If it does not start, connect it while switched off and write the firmware again, this time with Preloader ticked.
