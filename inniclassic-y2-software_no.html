Inniclassic Y2 installasjonstrinn

  1. Åpne Innioasis Updater CE på datamaskinen din (hvis du trenger appen, Få Updater CE). Sett Enhetsmodell til Y2.
  2. Velg Inniclassic inn Programvare.
  3. Velg utgivelsen som er oppført for Y2.
  4. Klikk Installer / Gjenopprett.
  5. Slå av og koble til Y2 kun når Updater CE spør.

Vanlige spørsmål

Kan jeg gjenopprette aksjeprogramvaren Y2?

Ja. Velg Y2 og original programvare i Updater CE. Den Y2 lagerprogramvareveiledning dekker returveien.

Kan jeg bruke Inniclassic på Y1?

Ja. Det samme prosjektet publiserer Y1 pakker også - rom.zip for Type A og rom_type_b.zip for Type B. Velg Y1 i Updater CE og installer Y1 build; den Y1 installasjonsside dekker det.

Hva hvis installasjonen mislykkes?

Legg merke til om oppdateringen mislyktes før eller etter oppdagelsen av Y2, og sjekk deretter kabelen, plattformoppsettet, modellen og tilkoblingstidspunktet i feilsøking.
