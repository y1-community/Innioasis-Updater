Rockbox Y1 install steps

  1. Innioasis Updater CE را در رایانه خود باز کنید (اگر به برنامه نیاز دارید، دریافت Updater CE). تنظیم کنید مدل دستگاه به Y1.
  2. انتخاب کنید Rockbox در نرم‌افزار.
  3. Pick the release and variant that match your intended screen or theme path.
  4. کلیک کنید نصب / بازگردانی and wait for the app to prepare it.
  5. Power off and connect the Y1 only at the live prompt.

Use the written Rockbox Y1 guide for the screenshots, video, Type A or Type B note, and connection checklist.

پرسش‌های متداول

Can I go back to the original Y1 software?

Yes. Choose Y1 and Original Software in Updater CE, then run Install / Restore. The Y1 stock-software page explains that route.

Which Rockbox release should I choose?

Choose a release shown for Y1 and read its release note. If you need older theme compatibility, check the resolution and variant notes rather than selecting a Y2 build.

Can I install this on a Y2?

No. Use the separate Rockbox Y2 page and select Y2 in Updater CE.
