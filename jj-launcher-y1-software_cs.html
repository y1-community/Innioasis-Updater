JJ Launcher Y1 install steps

  1. Otevřete Innioasis Updater CE na svém počítači (pokud potřebujete aplikaci, Získat Updater CE). Soubor Model zařízení do Y1.
  2. Vyberte si JJ Launcher v Software.
  3. Choose the release shown for Y1.
  4. Klikněte Nainstalovat / Obnovit.
  5. Vypněte a připojte Y1 pouze tehdy, když se zeptá Updater CE.

Časté dotazy

Can I install the Y2 entry on a Y1?

No. Keep the model and package matched. If the Y1 entry is missing, do not force a Y2 file.

Can I go back to the original software?

Yes. Choose Y1 and Original Software in Updater CE. See the Y1 restore page.

Where are all the JJ Launcher releases?

Current builds are in Software ke stažení. Release notes are on the project’s release notes.
