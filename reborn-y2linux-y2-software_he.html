שלבי התקנה

  1. פתח את Updater CE. זמין עבור Windows, macOS ו-Linux.
  2. בחר Y2 כדגם המכשיר.
  3. בחר Reborn (Y2Linux) בתור התוכנה.
  4. לחץ על התקן / שחזור. המתן בזמן שהעדכון CE מכין את הקבצים.
  5. חבר את USB כאשר תתבקש. כבה תחילה את Y2.
  6. הגדר Wi-Fi, Bluetooth ורדיו FM
