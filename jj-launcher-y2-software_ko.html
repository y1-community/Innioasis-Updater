전체 JJ Launcher 가이드 열기이것을 Updater CE에서 얻으세요왜 JJ Launcher인가요?

컴퓨터에 대한 설치 가이드

컴퓨터를 사용하여 Y2에 JJ Launcher을(를) 설치합니다.

사용 중인 컴퓨터에 대한 가이드를 선택하세요. 모든 버전에는 플랫폼 설정, Updater CE 단계 및 재고로 돌아가는 방법이 있습니다.

모든 Innioasis Y2 가이드 · 모든 JJ Launcher 가이드

모델이 올바른지 확인

  1. 컴퓨터에서 Innioasis Updater CE를 엽니다(앱이 필요한 경우, Updater CE 받기). 세트 기기 모델 에 Y2.
  2. 확인하다 JJ Launcher 현재 릴리스 데이터의 Y2에 나타납니다.
  3. 프로젝트 릴리스 노트를 읽고 나열된 Y2 릴리스를 선택하십시오.
  4. 클릭 설치 / 복원.
  5. 전원을 끄고 메시지가 나타날 때만 Y2을 연결하십시오.
대체하지 마십시오: Y1 패키지는 Y2 패키지가 아닙니다. 모델과 릴리스가 일치하지 않으면 중지하십시오.

자주 묻는 질문

Y2 지원이 보장되나요?

Y2 빌드가 나열되어 있지만 지원되는 항목은 변경될 수 있습니다. 설치하기 전에 최신 목록과 프로젝트 메모를 확인하세요.

Y2을(를) 어떻게 복원하나요?

Updater CE에서 Y2 및 Original Software를 선택한 후 다음을 따르십시오. Y2 복원 단계.

JJ Launcher이 목록에 없으면 어떻게 되나요?

Y1 패키지를 강제로 실행하지 마세요. 프로젝트 릴리스와 문제 해결 가이드.
