Langkah-Langkah Instalasi

  1. Buka Pembaruan CE. Tersedia untuk Windows, macOS dan Linux.
  2. Pilih Y2 sebagai model perangkat.
  3. Pilih Reborn (Y2Linux) sebagai perangkat lunak.
  4. Klik Instal / Pulihkan. Tunggu sementara Updater CE menyiapkan file.
  5. Hubungkan USB ketika ditanya. Matikan Y2 terlebih dahulu.
  6. Siapkan Wi-Fi, Bluetooth & radio FM
