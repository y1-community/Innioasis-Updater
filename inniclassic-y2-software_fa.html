Inniclassic Y2 install steps

  1. Innioasis Updater CE را در رایانه خود باز کنید (اگر به برنامه نیاز دارید، دریافت Updater CE). تنظیم کنید مدل دستگاه به Y2.
  2. انتخاب کنید Inniclassic در نرم‌افزار.
  3. Choose the release listed for Y2.
  4. کلیک کنید نصب / بازگردانی.
  5. فقط زمانی که Updater CE درخواست کرد، Y2 را خاموش و وصل کنید.

پرسش‌های متداول

Can I restore the stock Y2 software?

Yes. Select Y2 and Original Software in Updater CE. The Y2 stock-software guide مسیر بازگشت را پوشش می دهد.

Can I use Inniclassic on Y1?

Yes. The same project publishes Y1 packages as well — rom.zip for Type A and rom_type_b.zip for Type B. Select Y1 in Updater CE and install the Y1 build; the صفحه نصب Y1 covers it.

اگر نصب ناموفق باشد چه؟

Note whether Updater failed before or after detecting the Y2, then check the cable, platform setup, model, and connection timing in عیب یابی.
