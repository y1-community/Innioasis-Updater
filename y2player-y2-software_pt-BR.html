Y2Player etapas de instalação

  1. Abra o Innioasis Updater CE no seu computador (se precisar do aplicativo, Obter o Updater CE). Definir Modelo do aparelho para Y2.
  2. Escolher Y2Player em Software.
  3. Escolha um lançamento listado para Y2.
  4. Clique Instalar / Restaurar.
  5. Desligue e conecte o Y2 no prompt ao vivo.

Alguns Y2 pacotes de instalação completa usam rom_y2.zip. Deixe o Updater escolher o pacote quando possível.

Perguntas frequentes

Posso voltar ao software original?

Sim. Selecione Y2 e Software Original em Updater CE e siga as instruções Guia de restauração Y2.

Posso usar isso em um Y1?

Não. Esta página é para a entrada Y2Player Y2. Mantenha os pacotes Y1 e Y2 separados.

E se o Y2 não for detectado?

Verifique a configuração da plataforma, o cabo, o estado de desligamento, a seleção do modelo e o tempo. Usar solução de problemas antes de tentar a recuperação manual.
