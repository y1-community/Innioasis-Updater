Better-Y Y1 install steps

  1. Otevřete Innioasis Updater CE na svém počítači (pokud potřebujete aplikaci, Získat Updater CE). Soubor Model zařízení do Y1.
  2. Vyberte si Better-Y v Software.
  3. Vyberte vydání uvedené pro Y1.
  4. Klikněte Nainstalovat / Obnovit.
  5. Vypněte a připojte Y1 pouze tehdy, když se zeptá Updater CE.

Časté dotazy

What is improved over the stock firmware?

Better-Y adds track numbers, splits multi-artist tags, uses real titles, and adds playback shortcuts, plus fixes for caching and Bluetooth. Same themes as before.

Mohu obnovit software Y1?

Ano. Vyberte Y1 a originální software v Updater CE. The Y1 průvodce skladovým softwarem pokrývá zpáteční cestu.

Can I use my existing themes?

Yes! Better-Y is built on official stock 3.1.2 and maintains 100% compatibility with all custom themes from the Themes Gallery.

Co když se instalace nezdaří?

Note whether Updater failed before or after detecting the Y1, then check the cable, platform setup, model, and connection timing in odstraňování problémů.
