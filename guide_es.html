Comenzando con Innioasis Updater CE

Funciona con todos los reproductores de audio Innioasis y Timmkoo. Instale Innioasis Updater CE en su computadora, elija su modelo y el software que desee, luego siga las instrucciones.

    Obtener Updater CETutorial escrito completo

    Obtener Innioasis Updater CE

    Innioasis Actualizador CE es la aplicación que instala actualizaciones oficiales y software comunitario en tu reproductor. Conserva tu música y tu configuración y se ejecuta en Windows, macOS y Linux.

    Windows

    Descargue el instalador, ejecútelo y luego reinicie su PC cuando finalice.

    Obtener controladoresDescargar Updater CE

    Si Windows le impide ejecutar la aplicación o no la inicia, abra Configuración, haga clic en Privacidad y seguridad → Seguridad de Windows → Control de aplicaciones y navegador y desactive el Control inteligente de aplicaciones. Smart App Control actualmente afecta a aplicaciones populares como Epic Overlay Service (usado por Fortnite): Updater CE es seguro y su uso está verificado. ¿Windows no inicia la aplicación? Ayuda

    Reinicie su PC después de la instalación. La ayuda al conductor está en el Notas de configuración de Windows.

    macOS

    Descargar Updater CE

    Si tu Mac te impide ejecutar la app por primera vez, abre Ajustes del Sistema, haz clic en Privacidad y seguridad, baja hasta Seguridad y haz clic en Abierto de todos modos. También puedes hacer Control-clic (o clic derecho) en la aplicación en el Finder y seleccionar Abrir.

    Funciona en Mac Intel y Apple Silicon con macOS Monterey y versiones posteriores.

    Linux

    Descargue AppImage para sistemas Intel y AMD, hágalo ejecutable y ejecútelo.

    Descargar AppImage para Intel/AMD

    Notas de configuración de Linux

    Necesitas tu reproductor, un cable de datos USB que transporte datos (no se puede instalar un cable de solo carga) y unos minutos. Mantenga el cable conectado hasta que Updater CE indique que está listo.

    Elija su modelo y software

    1. Modelo de dispositivo: elige el modelo impreso en el reproductor, Y1 o Y2. El software creado para un modelo no se puede instalar en el otro.
    2. Software y lanzamiento: elija Software original, Rockbox, Solar, JJ Launcher, Inniclassic, Y2Player o Koensayr cuando aparezca en la lista para su modelo, luego elija una versión. Estable es la opción segura.
    3. Instalar: hacer clic Instalar / Restaurar, apague el reproductor por completo y conecte el cable USB solo cuando Updater CE lo solicite.
    4. Finalizar: deje el reproductor y el cable en paz hasta que aparezca el mensaje de éxito, luego desconecte e inicie el reproductor.

    Y1 los reproductores que se enviaron con software original anterior a 2.0.0 necesitan Dispositivo Type B. Todos los demás mantienen el valor predeterminado Type A.

    Volver al software original

    El software personalizado es reversible. En Updater CE, elija su modelo, seleccione Software original, elija una versión estable y luego ejecute Instalar / Restaurar de la misma manera. No hay nada que borrar a mano.

    ¿Windows no inicia la aplicación? Solución alternativa al control inteligente de aplicaciones

    Windows Defender SmartScreen o Smart App Control pueden bloquear aplicaciones comunitarias recién descargadas antes de que se propague la reputación de las firmas. Smart App Control está afectando actualmente a aplicaciones populares como Epic Overlay Service (utilizado por Fortnite): Updater CE es seguro y su uso está verificado. Desactivar Smart App Control permite que Updater CE se abra y se ejecute normalmente.

    1. Abierto Configuración en su PC con Windows (presione Win + I).
    2. Haga clic Privacidad y seguridad en la barra lateral izquierda, luego haga clic Windows Security.
    3. Haga clic Control de aplicaciones y navegador.
    4. Bajo Control inteligente de aplicaciones, haga clic Configuración de control de aplicaciones inteligentes.
    5. Establezca el interruptor en Apagado para permitir que se inicie Updater CE.

    ¿Descargado a través de Edge? Si Edge bloquea la descarga, haga clic en el botón Más opciones (…) → Mantener → Mostrar más → Mantener de todos modos.

    Volver a habilitar Smart App Control más tarde: Cuando desee volver a activar Smart App Control, puede volver a habilitarlo a través del Registro de Windows en HKEY_LOCAL_MACHINE\SYSTEM\CurrentControlSet\Control\CI\Policy estableciendo VerifiedAndReputablePolicyState a 1 (Activado) o 2 (Modo de evaluación) y reiniciar.
