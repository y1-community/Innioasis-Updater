🚀 Innioasis Updater - Widget insluiten

Kopieer en plak deze code in uw website om de Innioasis Updater-widget in te sluiten:

<!-- Innioasis Updater Embed Widget --> <iframe src="https://inniaosis.app/innioasis-simple-embed.html" width="300" height="120" frameborder="0" style="position: fixed; bottom: 20px; right: 20px; z-index: 999999; border-radius: 12px; box-shadow: 0 8px 32px rgba(0,0,0,0.3);" allowtransparency="true"> </iframe>

📝 Hoe te gebruiken:

  1. Kopieer de bovenstaande code
  2. Plak het in de HTML van uw website
  3. De widget verschijnt in de rechterbenedenhoek
  4. Gebruikers kunnen klikken om installatiehandleidingen voor hun platform te krijgen
