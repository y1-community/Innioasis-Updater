Méthode d'installation

SP Flash Tool dans Innioasis Programme de mise à jour CE

SP Flash Tool n'est pas un téléchargement séparé et il n'y a rien à trouver dans le dossier de l'application. Il s'agit d'une méthode d'installation dans Innioasis Updater CE sur des PC Windows x64 et Linux x86-64 équipés de processeurs Intel ou AMD. Choisissez votre firmware de la manière habituelle, puis configurez Afficher les paramètres avancés > Méthode d'installation > SP Flash Tool et installer.

La voie normale passe en premier

Choisissez votre firmware, puis choisissez le moteur

Une installation dans Updater CE est toujours le même parcours : sélectionnez votre modèle, choisissez le firmware et la version, puis exécutez Install/Restore. La méthode d'installation décide uniquement quel moteur MediaTek effectue le flash. Laissez-le allumé Automatique sauf si vous avez une raison de l'épingler et de le définir sur SP Flash Tool quand tu le fais.

Quels ordinateurs ont SP Flash Tool

MediaTek publie SP Flash Tool pour x86-64 uniquement, Updater CE le propose donc sur les PC x86-64 et nulle part ailleurs. L’application elle-même s’exécute à plus d’endroits que le moteur.

Windows x64 : disponible

Windows 10 ou 11 sur un processeur Intel ou AMD. Le SP Flash Tool méthode d'installation et le SP Flash Tool le bouton est tous les deux là.

Linux x86-64 : disponible

Une machine Intel ou AMD Linux 64 bits exécutant Updater CE AppImage. Même méthode d'installation, même bouton.

macOS : non disponible

SP Flash Tool n'existe pour macOS sous aucune forme. Updater CE installe et restaure avec MTKClient à la place, et il n'existe pas de méthode ou de bouton d'installation SP Flash Tool. Gardez le Mac sur l'itinéraire guidé ou utilisez le Remarques Mac.

Linux ARM64 : non disponible

Raspberry Pi, les cartes ARM et ARM64 Linux sont la même histoire que macOS : MediaTek ne fournit aucune version ARM, donc Updater CE utilise MTKClient ici.

Vous n'êtes pas sûr d'une machine ? Ouvrez les paramètres et allumez Afficher les paramètres avancés: s'il n'y a pas Méthode d'installation avec une option SP Flash Tool, cet ordinateur ne peut pas l'exécuter. Sur macOS et ARM64 Linux, le lecteur s'installe toujours normalement, utilisez donc l'itinéraire guidé avec Auto et ne déplacez-vous vers un PC Windows x64 ou Linux x86-64 que si vous avez spécifiquement besoin de SP Flash Tool.

Installez le firmware de votre choix avec SP Flash Tool

  1. Ouvrez Updater CE et sélectionnez le modèle imprimé sur votre lecteur : Innioasis Y1, Y2, G1, G3, G5, R1 ou PR1, ou un modèle Timmkoo.
  2. Choisissez le logiciel que vous souhaitez, Logiciel d'origine ou un projet communautaire, puis choisissez la version. Il s'agit de la même liste, de la même correspondance de modèle et des mêmes vérifications que toute autre installation.
  3. Ouvert Paramètres et allumer Afficher les paramètres avancés.
  4. Trouver Méthode d'installation et choisissez SP Flash Tool au lieu de Auto.
  5. Revenez à l'écran d'installation et cliquez sur Installer / Restaurer.
  6. Éteignez complètement le lecteur lorsque l'application vous le demande, puis connectez le câble de données USB directement à l'ordinateur lorsque vous y êtes invité. Utilisez un câble de données, pas un câble de charge uniquement, et ignorez les hubs.
  7. Attendez que Updater CE signale que l'installation est terminée, puis débranchez le câble et démarrez le lecteur.

C'est tout le voyage. Updater CE fournit toujours le package spécifique au modèle, l'agent de téléchargement MediaTek, les vérifications de pilotes et l'invite de connexion ; choisir SP Flash Tool n'échange que le moteur en dessous.

Gardez les modèles séparés. Un package Y1 et un package Y2 ne sont jamais interchangeables, et un fichier scatter d'un modèle ne décrit pas l'autre. Si Updater CE ne propose pas le micrologiciel pour le modèle que vous avez sélectionné, arrêtez-vous et choisissez plutôt le package répertorié pour ce modèle.

À quoi sert le bouton SP Flash Tool

Sur un ordinateur pris en charge, Updater CE dispose également d'un SP Flash Tool bouton qui ouvre l'outil de MediaTek pour travailler directement avec lui, par exemple avec un package scatter que vous avez fourni vous-même. Les installations, mises à jour et restaurations de routine n'en ont pas besoin : la méthode d'installation effectue le même travail avec la correspondance du modèle, les vérifications des pilotes et les invites de connexion gérées pour vous.

Si le bouton est manquant, l'ordinateur est l'un des systèmes non pris en charge ci-dessus ou le modèle sélectionné utilise un flux différent. Utilisez la méthode d'installation ou l'itinéraire guidé dans ce cas plutôt que de rechercher un outil binaire.

Lorsque SP Flash Tool est la bonne méthode d'installation

  • Un lecteur qui ne démarre pas. Le mode de téléchargement de SP Flash Tool peut toujours atteindre un périphérique dont le préchargeur ou l'image de démarrage est endommagé, c'est là qu'un travail de récupération minutieux est effectué.
  • Un flash qui se bloque sur un PC pris en charge. Si Auto ou MTKClient s'arrête à mi-chemin sur une machine Windows x64 ou Linux x86-64, épingler l'installation sur SP Flash Tool donne à l'autre moteur un tour sur le même package.
  • Un package d'usine auquel vous faites confiance. Versions logicielles originales du archives du micrologiciel associez-le bien, car la restauration des partitions d'origine est exactement ce pour quoi SP Flash Tool est conçu.

Pour une mise à jour ordinaire ou une première installation, laissez Méthode d'installation sur Auto. Il sélectionne le moteur qui convient à votre modèle et à votre plate-forme, et l'application vous maintient sur le chemin pris en charge sans paramètres supplémentaires.

Si l'installation ne démarre pas

  1. Confirmez que le modèle que vous avez sélectionné dans Updater CE correspond au modèle imprimé sur le lecteur et que le package est répertorié pour celui-ci.
  2. Vérifiez que le lecteur est complètement éteint avant de le connecter et connectez-vous uniquement à l'invite de l'application.
  3. Sur Windows, installez le pilote MediaTek et redémarrez ; sur Linux, vérifiez les autorisations USB notées dans configuration de l'ordinateur.
  4. Essayez un autre port USB directement sur l'ordinateur, sans hub, et relancez l'installation/restauration.

Tout ce qui suit appartient à dépannage. Et sur macOS ou ARM64 Linux, la réponse n'est pas un bouton différent : gardez le installation guidée et utilisez SP Flash Tool uniquement à partir d'un PC Windows x64 ou Linux x86-64.
