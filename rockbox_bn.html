Rockbox reference

Getting Rockbox on your Y1 or Y2

Rockbox changes the player software and opens up a deeper music-player interface, playback controls, sorting, and theme options. The install is guided, but Y1 and Y2 are separate journeys.

What the install changes

Rockbox is custom software. It does not remove your ability to return to the stock interface when the matching Original Software package is available. It can improve music browsing and customisation, but features, resolution, battery life, and theme compatibility depend on the build.

Do not mix models. Select Y1 for a Y1 player and Y2 for a Y2 player. A similar-looking release name is not enough evidence that a package is compatible.

240p, 360p, and themes

Older Rockbox theme collections may be made for 240p. Y1 community builds also use 360p compatibility labels. Read the release notes and theme source before choosing a build. A theme made for one resolution or software family may not work on another.

I reinstalled Rockbox and it didn't fix anything.

Reinstalling Rockbox writes the same build over the same files, so it cannot reset the things Rockbox keeps on the MicroSD. If the problem is a broken setting, theme, playlist, or database that lives on the card, reinstalling will not clear it. The reliable reset is deleting the .rockbox folder from the MicroSD — Rockbox builds a fresh one on the next boot.

  1. Power the player fully off and remove the MicroSD card, or connect the player as a USB drive.
  2. Show hidden files on your computer so the folder is visible. Show dotfiles on your computerWindows: in File Explorer open the View tab and tick Hidden items.macOS: in Finder press Cmd+Shift+. to toggle hidden files.Linux · GNOME Files: প্রেস Ctrl+H, or open the menu and choose Show Hidden Files.Linux · KDE Dolphin: প্রেস Ctrl+H, বা ব্যবহার করুন View → Show Hidden Files.
  3. Delete the .rockbox folder from the card root.
  4. Reinsert the card and start the player. Rockbox recreates the folder with defaults.
  5. Re-apply your theme and settings. If the problem only comes back after a specific theme, that theme is the cause.

Deleting .rockbox does not uninstall Rockbox and does not touch your music — the folder holds settings, themes, and caches, and is rebuilt automatically. If you want to keep your themes, copy the folder out of .rockbox before deleting it, or rename the folder to .rockbox-old প্রথম

Why can't I see the .rockbox folder on my MicroSD?

Folders whose name starts with a dot are hidden by default on most computers. You do not need to see it to install Rockbox — Updater handles the files. If you are troubleshooting and want to delete it, turn on hidden files first. Will deleting .rockbox reset my theme and settings?

Yes — .rockbox holds Rockbox's settings, theme, playlists, and cached database. Deleting it returns Rockbox to a clean default state. Back up the whole folder (or rename it to .rockbox-old) if you might want any of it back, then start the player and Rockbox creates a new folder.
