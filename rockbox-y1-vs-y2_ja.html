Rockbox-Y1 · Rockbox-Y2

Rockbox-Y1 対 Rockbox-Y2

Rockbox-Y1 と Rockbox-Y2 は、異なるプレーヤー用に作成された個別のファームウェア ビルドです。ビルドはプレーヤーに印刷されているモデルと常に一致させてください。

最初にモデルを選択することが重要な理由

どちらのビルドも Rockbox を実行しますが、Innioasis Y1 と Y2 はハードウェアとパーティションのレイアウトが異なります。 Y2 で Y1 ROM を点滅させたり、Y1 で Y2 ROM を点滅させたりしないでください。

Innioasis Updater CE は、選択するとすぐに利用可能なソフトウェアをフィルタリングすることで不一致を防ぎます Y1 または Y2 で デバイスモデル。 Updater CE は常に、選択したパッケージをコミュニティ ファームウェア開発者のリリースから直接ダウンロードします (Updater CE にリリースをリストする責任は開発者にあります)。

どのガイドが必要ですか?

  • Innioasis Y1 — に行きます Rockbox-Y1 ハブ。 Type A (2.0.0 以降に同梱されたプレイヤーの場合) または Type B (古いユニットの場合) を選択し、240p または 360p ビルドを選択します。
  • Innioasis Y2 — に行きます Rockbox-Y2 ハブ。 Updater CE で Y2 を選択し、最新の Y2 リリースを選択します。

両方のポートが共有するもの

どちらも Rockbox のタグベースの音楽データベース、ギャップレス再生、イコライザー、カスタム テーマ、プレーヤーでの 100% オフライン再生を実現します。読む なぜ Rockbox Rockbox が工場出荷時のソフトウェアに何を追加するかを確認します。
