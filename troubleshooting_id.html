Kembali ke panduan normalPeriksa firmware

Itu berhenti sebelum prompt USB

Ini masalah komputer, bukan masalah kabel. Periksa model Anda. Buka kemasan file lagi. Lalu coba Pasang / Pulihkan. Jika daftar rilis kosong, buka direktori firmware.

Itu tidak dapat terhubung ke pemutar

  1. Matikan sepenuhnya Y1 atau Y2 yang benar.
  2. Cabut kabelnya, tutup flashdisk lain atau alat Android, dan mulai instalasi lagi.
  3. Hubungkan hanya ketika Updater mengatakan sudah siap.
  4. Gunakan kabel data pendek USB langsung di komputer, bukan hub jika memungkinkan.
  5. Di Windows, instal ulang driver MediaTek dan mulai ulang. Di Linux, periksa izin USB/serial.

Itu mendeteksi pemutar tetapi flashnya gagal

Berhenti di sini. Jangan mencoba model lain. Tutup alat lainnya, periksa apakah Anda memilih Y1 atau Y2 yang benar, dan gunakan Perangkat Lunak Asli yang cocok jika pemutar tidak dapat dijalankan. SP Flash Tool dan MTKClient disertakan jika Anda membutuhkannya, dan file-file tersebut ada di halaman firmware.

Catatan pengemudi Windows

Beberapa instalasi Windows memblokir driver MediaTek karena isolasi Core. Ikuti panduan keamanan Windows saat ini sebelum mengubah integritas Memori, dan aktifkan kembali setelah Anda selesai jika sistem Anda mengizinkannya.
