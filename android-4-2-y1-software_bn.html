Android 4.2 Y1 install steps

  1. আপনার কম্পিউটারে Innioasis Updater CE খুলুন (যদি আপনার অ্যাপটির প্রয়োজন হয়, Updater CE নিন) সেট ডিভাইস মডেল থেকে Y1.
  2. বেছে নিন Android 4.2 (Dev) মধ্যে সফটওয়্যার.
  3. Y1-এর জন্য তালিকাভুক্ত রিলিজ বেছে নিন।
  4. ক্লিক করুন ইনস্টল / পুনরুদ্ধার.
  5. পাওয়ার বন্ধ করুন এবং শুধুমাত্র Updater CE বললেই Y1 সংযোগ করুন।

সাধারণ প্রশ্ন

আমি কি স্টক Y1 সফ্টওয়্যার পুনরুদ্ধার করতে পারি?

হ্যাঁ। Updater CE-এ Y1 এবং অরিজিনাল সফটওয়্যার নির্বাচন করুন। দ Y1 স্টক-সফ্টওয়্যার গাইড ফেরার পথ কভার করে।

Is this a daily driver ROM?

This is an experimental developer ROM intended for testing and development. Feature updates are on the project's page.
