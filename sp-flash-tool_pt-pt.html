Método de instalação

SP Flash Tool dentro de Innioasis Atualizador CE

SP Flash Tool não é um download separado e não há nada para encontrar na pasta da aplicação. É um método de instalação no Innioasis Updater CE em Windows PCs x64 e Linux x86-64 com processadores Intel ou AMD. Escolha o seu firmware normalmente e defina Mostrar definições avançadas > Método de instalação > SP Flash Tool e instale.

A via normal vem primeiro

Escolha o seu firmware e, em seguida, escolha o mecanismo

Uma instalação no Updater CE é sempre a mesma jornada: selecione o seu modelo, escolha o firmware e a versão e execute Instalar/Restaurar. O método de instalação decide apenas qual o mecanismo MediaTek que executa o flash. Deixe ligado Automático a menos que tenha um motivo para o fixar e configurá-lo para SP Flash Tool quando o fizer.

Que computadores têm SP Flash Tool

MediaTek publica SP Flash Tool apenas para x86-64, pelo que o Updater CE o oferece em PCs x86-64 e em mais lado nenhum. A própria aplicação é executada em mais lugares do que o motor.

Windows x64: disponível

Windows 10 ou 11 num processador Intel ou AMD. O SP Flash Tool método de instalação e o SP Flash Tool botão estão ambos lá.

Linux x86-64: disponível

Uma máquina Intel ou AMD Linux de 64 bits que executa o Updater CE AppImage. Mesmo método de instalação, mesmo botão.

macOS: não disponível

SP Flash Tool não existe para macOS de qualquer forma. O Updater CE é instalado e restaurado com MTKClient, não existindo qualquer método ou botão de instalação SP Flash Tool. Mantenha o Mac na rota guiada ou utilize o Notas do Mac.

Linux ARM64: não disponível

Raspberry Pi, placas ARM e ARM64 Linux são a mesma história que macOS: MediaTek não vem com build ARM, por isso o Updater CE usa MTKClient lá.

Não tem a certeza sobre uma máquina? Abra as Definições e ative Mostrar configurações avançadas: se não houver Método de instalação com uma opção SP Flash Tool, esse computador não o conseguirá executar. Em macOS e ARM64 Linux o leitor ainda é instalado normalmente, por isso utilize a rota guiada com Auto e só mude para um PC Windows x64 ou Linux x86-64 se precisar especificamente de SP Flash Tool.

Instale o firmware escolhido com SP Flash Tool

  1. Abra o Updater CE e selecione o modelo impresso no seu leitor: Innioasis Y1, Y2, G1, G3, G5, R1 ou PR1, ou um modelo Timmkoo.
  2. Escolha o software que pretende, Software Original ou um projeto comunitário e escolha o lançamento. Esta é a mesma lista, a mesma correspondência de modelo e as mesmas verificações de qualquer outra instalação.
  3. Abrir Configurações e ligue Mostrar configurações avançadas.
  4. Encontrar Método de instalação e escolha SP Flash Tool em vez de Automático.
  5. Volte ao ecrã de instalação e clique em Instalar / Restaurar.
  6. Desligue totalmente o leitor quando a aplicação o solicitar e, em seguida, ligue o cabo de dados USB diretamente ao computador quando solicitado. Utilize um cabo de dados, e não um cabo apenas de carga, e ignore os hubs.
  7. Aguarde até que o Updater CE comunique que a instalação foi concluída, desligue o cabo e inicie o leitor.

Essa é toda a viagem. O Updater CE fornece ainda o pacote específico do modelo, o agente de download MediaTek, as verificações de controladores e o prompt de ligação; escolher SP Flash Tool apenas troca o motor por baixo.

Mantenha os modelos separados. Um pacote Y1 e um pacote Y2 nunca são intercambiáveis, e um ficheiro de dispersão de um modelo não descreve o outro. Se o Updater CE não oferecer o firmware para o modelo selecionado, pare e escolha o pacote listado para esse modelo.

Para que serve o botão SP Flash Tool

Num computador suportado, o Updater CE também possui um SP Flash Tool botão que abre a ferramenta do MediaTek para trabalhar diretamente com ele, por exemplo, com um pacote scatter que o próprio forneceu. As instalações, atualizações e restaurações de rotina não precisam disto: o método de instalação faz o mesmo trabalho com a correspondência de modelos, verificações de controladores e avisos de ligação manipulados para si.

Se o botão estiver em falta, o computador é um dos sistemas não suportados acima ou o modelo selecionado utiliza um fluxo diferente. Utilize o método de instalação ou a rota guiada nesse caso, em vez de procurar uma ferramenta binária.

Quando SP Flash Tool é o método de instalação correto

  • Um jogador que não arranca. O modo de download do SP Flash Tool pode ainda alcançar um dispositivo cujo pré-carregador ou imagem de arranque está danificado, que é onde ocorre um cuidadoso trabalho de recuperação.
  • Um flash que bloqueia num PC compatível. Se Auto ou MTKClient pararem a meio do caminho numa máquina Windows x64 ou Linux x86-64, a fixação da instalação em SP Flash Tool dá ao outro mecanismo uma rotação no mesmo pacote.
  • Um pacote de fábrica em que confia. Versões de software originais do ficheiro de firmware combine bem com ele, porque restaurar partições de stock é exatamente o que SP Flash Tool foi criado.

Para uma atualização normal ou uma primeira instalação, deixe Método de instalação em Automático. Escolhe o motor adequado ao seu modelo e plataforma, e a aplicação mantém-no no caminho compatível sem configurações extra.

Se a instalação não iniciar

  1. Confirme se o modelo selecionado no Updater CE corresponde ao modelo impresso no leitor e se o pacote está listado para o mesmo.
  2. Confirme se o leitor está totalmente desligado antes de o ligar e ligue-o apenas quando solicitado pela aplicação.
  3. Em Windows, instale o driver MediaTek e reinicie; em Linux, verifique as permissões USB indicadas em configuração do computador.
  4. Experimente uma porta USB diferente diretamente no computador, sem hub, e inicie novamente a instalação/reposição.

Qualquer coisa para além disso pertence solução de problemas. E em macOS ou ARM64 Linux, a resposta não é um botão diferente: manter o instalação guiada e utilize SP Flash Tool apenas num PC Windows x64 ou Linux x86-64.
