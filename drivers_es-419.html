Configuración de la computadora

Prepare la computadora antes que el reproductor.

La mayoría de los problemas de conexión provienen del controlador, los permisos, el cable o la sincronización. Windows necesita tener instalado el controlador MediaTek. Linux necesita los permisos USB correctos. Encuentre su plataforma a continuación.

Obtener Updater CESolución de problemas

Windows

  1. Descargue el instalador del controlador MediaTek a continuación.
  2. Ejecute el instalador y permita que Windows instale el controlador.
  3. Reinicie la computadora.
  4. Abra Updater CE y espere el mensaje de conexión antes de enchufar el reproductor apagado.

Algunos sistemas Windows bloquean el controlador mediante el aislamiento del núcleo (integridad de la memoria). Si Updater CE aún no puede ver el reproductor después de reiniciar, desactive la integridad de la memoria en Seguridad de Windows, reinicie y reinstale el controlador. Vuelva a activar la configuración cuando haya terminado si su sistema lo permite.

Windows won't launch the app? If Windows Security or Smart App Control stops Updater CE from opening, open Configuración (press Win + I) → Privacy & security → Windows Security → App & browser control → Smart App Control settings and set it to Off. To re-enable later, set VerifiedAndReputablePolicyState a 1 (On) or 2 (Evaluation Mode) under HKEY_LOCAL_MACHINE\SYSTEM\CurrentControlSet\Control\CI\Policy in Registry Editor.

Permisos de Linux USB

Linux necesita que su cuenta de usuario pueda comunicarse con el chip MediaTek USB dentro del reproductor. Updater CE generalmente soluciona esto durante la instalación, y el mismo permiso cubre SP Flash Tool, así que trátelo como un paso de reparación en lugar de una etapa normal.

  1. Ejecute Updater CE como usuario normal, no como root. El instalador solicita acceso de administrador sólo cuando lo necesita.
  2. Compruebe que el reproductor se vea en absoluto. Apague el reproductor, conecte el cable y ejecute el comando lsusb en una terminal. Un reproductor conectado aparece como un dispositivo MediaTek con el ID de proveedor 0e8d.
lsusb
  1. Si aparece en lsusb pero Innioasis Updater CE o SP Flash Tool dice permiso denegado o no puede abrir el puerto, su usuario no tiene acceso al dispositivo USB. La misma regla udev cubre ambas herramientas, así que agregue una que permita al grupo de usuarios leerla.
SUBSYSTEM=="usb", ATTR{idVendor}=="0e8d", MODE="0666", GROUP="plugdev"

Guarde esa línea en un nuevo archivo llamado /etc/udev/rules.d/51-innioasis.rules, luego ejecute:

sudo udevadm control --reload && sudo udevadm trigger
  1. Desenchufe completamente el reproductor, vuelva a enchufarlo e intente la instalación nuevamente.
  2. Si SP Flash Tool informa un permiso de serie o una carrera de puerto, desconéctelo completamente y vuelva a conectarse solo cuando se le solicite.
No improvises compensaciones de flash.Si pasa a una herramienta de recuperación manual, utilice los archivos y la configuración específica del modelo que se incluyen con el proyecto.

Cable y sincronización

  1. Utilice un cable de datos USB conocido.
  2. Evite los concentradores mientras soluciona problemas.
  3. Apague completamente el modelo correcto.
  4. Conéctese solo cuando se le indique.
