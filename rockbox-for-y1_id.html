Rockbox-Y1 · Innioasis Y1

Rockbox untuk Y1 (Rockbox-Y1)

“Rockbox”, “Rockbox-Y1”, dan “Rockbox untuk Y1” semuanya mengacu pada firmware komunitas Rockbox yang sama untuk Innioasis Y1. Inilah yang ditambahkan ke pemutar Anda, build mana yang harus dipilih, dan cara menginstalnya dengan Innioasis Updater CE.

Pasang Rockbox-Y1 Unduh ROM Tutorial tertulis Rockbox-pusat Y1

Satu firmware, beberapa nama

Di Innioasis Updater CE, firmware ini muncul sebagai Rockbox saat Anda memilih model perangkat Y1. Panduan, video, dan catatan rilis juga menyebutnya Rockbox-Y1 atau Rockbox untuk Y1 jadi jelas bahwa build tersebut untuk Y1 dan bukan Y2.

Selalu periksa model yang tercetak pada pemutar Anda sebelum menginstal: paket firmware Y1 dan Y2 tidak dapat dipertukarkan.

Apa yang Rockbox-Y1 tambahkan ke Y1 Anda

Rockbox-Y1 adalah port komunitas dari firmware pemutar musik sumber terbuka Rockbox untuk Innioasis Y1:

  • Perpustakaan musik berbasis tag — telusuri menurut artis, album, genre, dan tahun menggunakan tag audio, atau jelajahi folder secara langsung.
  • Pemutaran audio tingkat lanjut — pemutaran tanpa celah, crossfade, ReplayGain, dan equalizer penuh.
  • Tema khusus — pilih dari ratusan tema komunitas 240p dan 360p, termasuk tata letak bergaya iPod klasik.
  • Radio FM — dukungan radio FM bawaan.
  • Ekstra opsional — pengunduhan podcast melalui Wi-Fi dan Last.fm / ListenBrainz / Maloja melakukan scrobbling pada build yang didukung.
  • Boot ganda — beralih kembali ke Perangkat Lunak Asli pabrik tanpa melakukan flashing pada build yang didukung.

Versi Y1 mana yang harus saya pilih?

  • 240p vs.360p — Versi 240p berfungsi dengan tema klasik 320×240 Rockbox; Versi 360p menggunakan tema 480×360 Y1 yang lebih tajam. Cocokkan resolusi build dengan tema yang ingin Anda gunakan (Panduan 240p vs. 360p).
  • Type A vs.Type B — Type A ditujukan untuk pemutar Y1 yang dikirimkan dengan perangkat lunak pabrik 2.0.0 atau lebih baru; Type B adalah untuk unit Y1 sebelumnya. Pilih Type A kecuali Anda tahu Y1 Anda adalah Type B.
  • Stabil vs. Malam hari — Pilih build stabil untuk mendengarkan sehari-hari, atau build malam untuk menguji perubahan terbaru.

Unduhan langsung dari komunitas pengembang

Innioasis Updater CE selalu mengunduh paket firmware langsung dari komunitas pengembang firmware (rockbox-y1/rockbox), dan pengembangnya sendiri bertanggung jawab penuh untuk mencantumkan rilis perangkat lunak mereka di Updater CE.

Anda dapat membiarkan Updater CE mengunduh dan menginstal firmware secara otomatis, atau mengunduh paket ROM dari kami Rockbox-Y1 halaman unduhan dan Rockbox ROM halaman unduh.

Cara menginstal Rockbox-Y1

  1. Buka Innioasis Updater CE dan atur Model perangkat untuk Y1.
  2. Pilih Rockbox di Perangkat lunak.
  3. Pilih rilis stabil (atau aktifkan nightly build untuk menguji pratinjau).
  4. Klik Pasang / Pulihkan jadi Updater CE mengunduh paket langsung dari pengembangnya.
  5. Matikan Y1 sepenuhnya dan sambungkan dengan kabel data USB saat Updater CE meminta Anda.
  6. Tunggu pesan penyelesaian, lalu putuskan sambungan dan hidupkan pemutar Anda.

Untuk tangkapan layar dan kiat pengaturan mendetail, baca tutorial lengkap Rockbox-Y1.

Memulihkan perangkat lunak Y1 asli

Anda dapat kembali ke perangkat lunak pabrik kapan saja: pilih Y1 dan Perangkat lunak asli di Updater CE, pilih rilis stabil, dan klik Pasang / Pulihkan. Musik Anda di kartu MicroSD dipertahankan. Lihat panduan pemulihan dan Y1 Halaman Perangkat Lunak Asli.

Pertanyaan yang sering diajukan

Apakah Rockbox untuk Y1 sama dengan Rockbox-Y1?

Ya. Rockbox, Rockbox-Y1, Rockbox untuk Y1, dan rockbox-y1 semuanya mengacu pada port komunitas Rockbox yang sama untuk Innioasis Y1.

Dari mana Updater CE mengunduh Rockbox-Y1?

Updater CE selalu mengunduh paket firmware langsung dari rilis milik pengembang firmware komunitas (rockbox-y1/rockbox). Pengembang sepenuhnya bertanggung jawab untuk mencantumkan rilis perangkat lunak mereka di Updater CE.

Bisakah saya menginstal Rockbox-Y1 pada Y2?

Tidak. Y2 memiliki versi firmware tersendiri. Gunakan Rockbox untuk Y2 sebagai gantinya.

Apakah menginstal Rockbox-Y1 akan menghapus musik saya?

Tidak. Musik disimpan pada kartu MicroSD dan tidak terpengaruh saat mem-flash firmware internal pemutar.
