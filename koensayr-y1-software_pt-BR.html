Koensayr Y1 etapas de instalação

  1. Abra o Innioasis Updater CE no seu computador (se precisar do aplicativo, Obter o Updater CE). Definir Modelo do aparelho para Y1.
  2. Escolher Koensayr em Programas.
  3. Escolha a versão Y1 listada.
  4. Clique Instalar / Restaurar.
  5. Desligue e conecte o Y1 somente quando o Updater CE solicitar.

Perguntas frequentes

Posso restaurar o software original Y1?

Sim. Selecione Y1 e Software Original em Updater CE. Veja o Y1 página de software de estoque para a rota de restauração completa.

O que devo verificar quando falhar?

Verifique o modelo, a versão, o cabo, a configuração da plataforma e se o player estava conectado antes do aviso. Então use solução de problemas.

Existe um pacote Koensayr Y2?

A compilação atual é para Y1. Não use-o em Y2, a menos que o projeto publique uma versão separada para ele.

Comece com a configuração do computador

O atualizador funciona em Windows, macOS e Linux depois que a configuração da plataforma estiver pronta. Leia o guia geral primeiro.
