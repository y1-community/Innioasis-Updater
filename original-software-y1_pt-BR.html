Instale ou restaure-o com o Updater

O atualizador usa o mesmo fluxo guiado, quer o Y1 esteja executando seu software original ou um projeto da comunidade.

  1. Abra o Innioasis Updater CE no seu computador (se precisar do aplicativo, Obter o Updater CE). Definir Modelo do aparelho para Y1.
  2. Escolher Software original em Programas (ou usar Obter no Updater CE para pular para as etapas guiadas).
  3. Clique Instalar / Restaurar e deixe o aplicativo preparar o pacote.
  4. Desligue e conecte o Y1 somente quando o prompt ao vivo solicitar.

Ao baixar manualmente, o pacote de instalação completa usual é nomeado rom.zip. A seleção do modelo no Updater é a maneira mais segura de escolher arquivos.

Perguntas frequentes

Posso restaurar de Rockbox ou outro software personalizado?

Sim, use o modelo Y1 e o caminho do software original Y1. Não exclua os arquivos do sistema primeiro e não substitua um pacote Y2.

E se meu Y1 não for detectado?

Verifique o cabo de dados, a configuração do computador e o tempo de conexão. O player deve ser desligado e conectado somente no prompt do Atualizador.

Qual pacote devo usar para meu Y1?

Mantenha o modelo impresso no seu player selecionado no Updater. Os pacotes Y1 e Y2 são separados — pare se a lista de lançamentos não corresponder ao seu modelo.
