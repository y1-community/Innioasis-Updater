    Linux

    Take the file that matches your processor. Intel and AMD PCs use the x86_64 builds; ARM boards and ARM laptops, including Raspberry Pi and Snapdragon machines, use the arm64 builds.

    AppImage for Intel/AMDAppImage for ARM64tar.gz for Intel/AMDtar.gz for ARM64zip for Intel/AMDzip for ARM64

    An AppImage needs chmod +x before it runs. The tar.gz and the zip are folders to unpack, not installers. Every one of these files carries the terminal interface, so --tui opens the same app without a window.

    To skip the downloads and let the launcher choose, copy this into a terminal. It reads your processor, fetches the matching build, and asks whether to install or run once:

    curl -fsSL https://innioasis.app/run_linux.sh | bash

    Windows non avvia l'app? Come disattivare il controllo intelligente delle app

    Windows Defender SmartScreen o Smart App Control possono bloccare le applicazioni della community appena scaricate prima che la reputazione delle firme si propaghi. Il controllo intelligente delle app sta attualmente influenzando le applicazioni più diffuse come il servizio Epic Overlay (utilizzato da Fortnite): Updater CE è sicuro e verificato da usare. La disattivazione del Controllo intelligente delle app consente l'apertura e l'esecuzione normale di Updater CE.

    1. Aperto Impostazioni sul tuo PC Windows (premi Win + I).
    2. Fare clic Privacy e sicurezza nella barra laterale sinistra, quindi fare clic su Windows Security.
    3. Fare clic Controllo di app e browser.
    4. Sotto Controllo intelligente delle app, fare clic Impostazioni di controllo intelligente delle app.
    5. Impostare l'interruttore su Spento per consentire l'avvio di Updater CE.

    Bloccato da Edge? Se Microsoft Edge blocca il download stesso, fai clic sul pulsante Altre opzioni (…) → Mantenere → Mostra di più → Tienilo comunque.

    Riattivare Smart App Control in un secondo momento: Quando desideri riattivare Smart App Control, puoi riattivarlo tramite il registro di Windows in HKEY_LOCAL_MACHINE\SYSTEM\CurrentControlSet\Control\CI\Policy impostando VerifiedAndReputablePolicyState a 1 (Attivo) o 2 (modalità di valutazione) e riavvio.
