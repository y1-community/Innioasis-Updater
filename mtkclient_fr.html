Comprendre le mode BootROM (BROM)

Lorsqu'il est complètement éteint, le processeur MediaTek MT6572 / MT6580 écoute sur le bus USB un paquet de prise de contact avant de charger le chargeur de démarrage principal. Si un flash corrompu se produit, le mode BROM permet une réécriture de récupération complète.
