プレーヤーに接続できません

  1. 正しい Y1 または Y2 の電源を完全にオフにします。
  2. ケーブルを取り外し、他のフラッシュまたは Android ツールを閉じて、インストールを再度開始します。
  3. アップデーターが準備ができたと通知した場合にのみ接続してください。
  4. 可能であればハブではなく、短い USB データ ケーブルをコンピュータに直接使用してください。
  5. Windows では、MediaTek ドライバーを再インストールして再起動します。 Linux では、USB/serial 権限を確認してください。

Windowsドライバーのメモ

一部の Windows インストールでは、コア分離により MediaTek ドライバーがブロックされます。メモリの整合性を変更する前に現在の Windows セキュリティ ガイダンスに従ってください。システムで許可されている場合は、変更が完了したらオンに戻してください。
