תחילת העבודה עם Innioasis Updater CE

עובד עם כל נגני השמע Innioasis ו-Timmkoo. התקן את Innioasis Updater CE במחשב שלך, בחר את הדגם שלך ואת התוכנה הרצויה, ולאחר מכן עקוב אחר ההנחיות.

    הורדת Updater CEהדרכה כתובה מלאה

    קבל Innioasis Updater CE

    Innioasis Updater לספירה היא האפליקציה שמתקינה עדכונים רשמיים ותוכנת קהילה על הנגן שלך. זה שומר על המוזיקה וההגדרות שלך, והוא פועל על Windows, macOS ו-Linux.

    Windows

    הורד את תוכנית ההתקנה, הפעל אותו ולאחר מכן הפעל מחדש את המחשב בסיום.

    קבל דרייבריםהורד את Updater CE

    אם Windows מונע ממך להפעיל את האפליקציה או לא מפעיל אותה, פתח את 'הגדרות', לחץ על פרטיות ואבטחה ← אבטחת Windows ← בקרת אפליקציות ודפדפן, וכבה את בקרת האפליקציה החכמה. בקרת אפליקציות חכמה משפיעה כיום על יישומים פופולריים כמו Epic Overlay Service (בשימוש על ידי Fortnite) - Updater CE בטוח ומאומת לשימוש. Windows לא יפעיל את האפליקציה? עזרה

    הפעל מחדש את המחשב לאחר ההתקנה. עזרה לנהגים נמצאת ב הערות התקנה של Windows.

    macOS

    הורד את Updater CE

    אם ה-Mac שלך מונע ממך להפעיל את האפליקציה בפעם הראשונה, פתח את הגדרות מערכת, לחץ על פרטיות ואבטחה, גלול מטה אל אבטחה ולחץ על פתוח בכל מקרה. אתה יכול גם ללחוץ על האפליקציה ב-Finder ולבחור פתח (או ללחוץ לחיצה ימנית).

    Works on Intel and Apple Silicon Macs with macOS Monterey and later.

    Linux

    הורד את AppImage עבור מערכות אינטל ו-AMD, הפוך אותה לניתנת להפעלה והפעל אותה.

    הורד את AppImage עבור Intel/AMD

    הערות התקנה של לינוקס

    אתה צריך את הנגן שלך, כבל נתונים USB הנושא נתונים (כבל לטעינה בלבד לא יכול להתקין), וכמה דקות. השאר את הכבל מחובר עד Updater CE אומר שזה נעשה.

    בחר את הדגם והתוכנה שלך

    1. דגם מכשיר: בחר את הדגם המודפס על הנגן, Y1 או Y2. לא ניתן להתקין תוכנה המיועדת לדגם אחד על הדגם השני.
    2. תוכנה והפצה: בחר תוכנה מקורית, Rockbox, Solar, JJ Launcher, Inniclassic, Y2Player, או Koensayr כשהיא רשומה עבור הדגם שלך, ולאחר מכן בחר מהדורה. יציב היא הבחירה הבטוחה.
    3. התקן: לחץ התקנה / שחזור, כבה את הנגן לחלוטין וחבר את הכבל USB רק כאשר Updater CE מבקש.
    4. סיום: השאר את הנגן והכבל לבד עד להודעת ההצלחה, ואז נתק והפעל את הנגן.

    Y1 שחקנים שנשלחו עם תוכנה מקורית לפני 2.0.0 צריכים מכשיר Type B. כל השאר שומרים על ברירת המחדל Type A.

    חוזרים לתוכנה המקורית

    תוכנה מותאמת אישית היא הפיכה. ב-Updater CE, בחר את הדגם שלך, בחר תוכנה מקורית, בחר גרסה יציבה ואז הרץ התקנה / שחזור באותה דרך. אין מה למחוק ביד.

    מדריך שחזור Y1מדריך שחזור Y2

    אם הבזק מפסיק לפני ההנחיה USB, בדוק תחילה את הכבל, את הגדרת הפלטפורמה והדגם. ראה פתרון בעיות לתיקונים, ה Y1 ו-Y2 מדריך התאוששות עבור תקלות חשמל וגלגלים, ו SP Flash Tool להתאוששות מתקדמת.

    Windows לא יפעיל את האפליקציה? עקיפת הבעיה של בקרת אפליקציות חכמה

    Windows Defender SmartScreen או Smart App Control יכולים לחסום יישומי קהילה שהורדו לאחרונה לפני שהמוניטין החתימה יתפשט. בקרת אפליקציות חכמה משפיעה כעת על יישומים פופולריים כמו שירות ה-Epic Overlay (בשימוש על ידי Fortnite) - Updater CE בטוח ומאומת לשימוש. כיבוי Smart App Control מאפשר ל-Update CE להיפתח ולהפעיל כרגיל.

    1. פתוח הגדרות במחשב Windows שלך (לחץ על Win + I).
    2. לחץ פרטיות ואבטחה בסרגל הצד השמאלי ולאחר מכן לחץ Windows Security.
    3. לחץ שליטה באפליקציה ובדפדפן.
    4. מתחת בקרת אפליקציה חכמה, לחץ הגדרות בקרת אפליקציה חכמה.
    5. הגדר את המתג למצב כבוי כדי לאפשר את הפעלת Updater CE.

    הורדת דרך Edge? אם Edge חוסם את ההורדה עצמה, לחץ על כפתור אפשרויות נוספות (…) → שמור → הצג עוד → שמור בכל מקרה.

    הפעלה מחדש של בקרת אפליקציות חכמה מאוחר יותר: כאשר אתה רוצה להפעיל מחדש את בקרת האפליקציות החכמה, אתה יכול להפעיל אותה מחדש דרך הרישום של Windows תחת HKEY_LOCAL_MACHINE\SYSTEM\CurrentControlSet\Control\CI\Policy לפי הגדרה VerifiedAndReputablePolicyState ל 1 (מופעל) או 2 (מצב הערכה) והפעלה מחדש.

    Windows לא יפעיל את האפליקציה? כיצד לכבות את בקרת האפליקציה החכמה
