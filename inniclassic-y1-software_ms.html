Inniclassic Y1 install steps

  1. Buka Innioasis Updater CE pada komputer anda (jika anda memerlukan apl itu, Dapatkan Updater CE). Tetapkan Model Peranti kepada Y1.
  2. pilih Inniclassic dalam Perisian.
  3. Pilih keluaran yang disenaraikan untuk Y1.
  4. klik Pasang / Pulihkan.
  5. Matikan dan sambungkan Y1 hanya apabila Updater CE bertanya.

Soalan Lazim

Bolehkah saya memulihkan perisian stok Y1?

ya. Pilih Y1 dan Perisian Asal dalam Updater CE. The Panduan perisian stok Y1 meliputi laluan pulang.

Bagaimana jika pemasangan gagal?

Note whether Updater failed before or after detecting the Y1, then check the cable, platform setup, model, and connection timing in penyelesaian masalah.

Can I use Inniclassic on Y2?

Yes. Inniclassic is available on both models — the same maintained project publishes a Y2 package from the same releases. Select Y2 in Updater CE and install the Y2 build; never flash a Y1 package to a Y2. The Halaman pemasangan Y2 covers it.
