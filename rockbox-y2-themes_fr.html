Vérifiez la compatibilité du thème pour votre build

Rockbox-Y2 est développé séparément du port Y1, la compatibilité des thèmes suit donc la version de build Y2 que vous avez installée. Vérifiez le Rockbox-Y2 notes de version pour votre version avant d'installer un pack de thèmes.

Voir Rockbox-Y1 contre Rockbox-Y2 pour une comparaison complète des deux ports.

Comment installer des thèmes sur le Y2

Les thèmes sont stockés sur votre carte MicroSD à l'intérieur du .rockbox dossier.

  1. Démarrez Rockbox-Y2 au moins une fois pour créer le .rockbox dossier sur votre carte MicroSD.
  2. Extrayez ou copiez les fichiers de thème dans .rockbox/ (donc themes, wps, fonts, et backdrops fusionner dans .rockbox/).
  3. Sur le lecteur, ouvrez Paramètres → Paramètres du thème → Parcourir les fichiers de thème et sélectionnez votre thème.

Pour afficher les dossiers cachés sur votre ordinateur : appuyez sur Cmd+Shift+. sur macOS, activez Affichage → Éléments masqués sous Windows, ou appuyez sur Ctrl+H sous Linux.

Comment réinitialiser un thème cassé

Si un thème rend l'écran difficile à lire, renommez ou supprimez le .rockbox dossier sur votre carte MicroSD et redémarrez le lecteur. Rockbox-Y2 créera un nouveau .rockbox dossier avec le thème par défaut tout en gardant votre musique intacte.
