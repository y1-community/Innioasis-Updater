إعداد الكمبيوتر

اجعل الكمبيوتر جاهزًا قبل اللاعب.

تأتي معظم مشكلات الاتصال من برنامج التشغيل أو الأذونات أو الكابل أو التوقيت. يحتاج Windows إلى تثبيت برنامج التشغيل MediaTek. يحتاج Linux إلى أذونات USB الصحيحة. ابحث عن النظام الأساسي الخاص بك أدناه.

احصل على Updater CEاستكشاف الأخطاء وإصلاحها

ويندوز

  1. قم بتنزيل مثبت برنامج التشغيل MediaTek أدناه.
  2. قم بتشغيل برنامج التثبيت واسمح لـ Windows بتثبيت برنامج التشغيل.
  3. أعد تشغيل الكمبيوتر.
  4. افتح Updater CE وانتظر حتى تظهر رسالة الاتصال قبل توصيل المشغل الذي تم إيقاف تشغيله.

تقوم بعض أنظمة Windows بحظر برنامج التشغيل من خلال العزل الأساسي (تكامل الذاكرة). إذا ظل Updater CE غير قادر على رؤية المشغل بعد إعادة التشغيل، فقم بإيقاف تشغيل تكامل الذاكرة في Windows Security، وأعد تشغيل برنامج التشغيل وأعد تثبيته. قم بإعادة تشغيل الإعداد عند الانتهاء إذا كان نظامك يسمح بذلك.

لن يقوم Windows بتشغيل التطبيق؟ إذا أدى أمان Windows أو التحكم الذكي في التطبيقات إلى إيقاف فتح Updater CE، فافتحه الإعدادات (يضعط Win + I) → الخصوصية والأمان → أمن ويندوز → التحكم في التطبيق والمتصفح → إعدادات التحكم في التطبيقات الذكية وتعيينه على عن. يؤثر التحكم الذكي في التطبيقات حاليًا على التطبيقات الشائعة مثل Epic Overlay Service (المستخدم في Fortnite) - تطبيق Updater CE آمن وموثوق للاستخدام. لإعادة التمكين لاحقًا، اضبط VerifiedAndReputablePolicyState ل 1 (على) أو 2 (وضع التقييم) تحت HKEY_LOCAL_MACHINE\SYSTEM\CurrentControlSet\Control\CI\Policy في محرر التسجيل.

أذونات لينكس USB

يحتاج Linux إلى السماح لحساب المستخدم الخاص بك بالتحدث إلى الشريحة MediaTek USB الموجودة داخل المشغل. عادةً ما يقوم Updater CE بفرز هذا الأمر أثناء التثبيت، ويغطي نفس الإذن SP Flash Tool، لذا تعامل مع هذا كخطوة إصلاح بدلاً من مرحلة عادية.

  1. قم بتشغيل Updater CE كمستخدم عادي، وليس كجذر. يطلب المثبت وصول المسؤول فقط عندما يحتاج إليه.
  2. تحقق وينظر إلى لاعب على الإطلاق. قم بإيقاف تشغيل المشغل، وقم بتوصيل الكابل، وقم بتشغيل الأمر lsusb في الجهاز الطرفي. يظهر المشغل المتصل كجهاز MediaTek بمعرف البائع 0e8d.
lsusb
  1. إذا ظهر في lsusb ولكن يقول Innioasis Updater CE أو SP Flash Tool أن الإذن مرفوض أو لا يمكنه فتح المنفذ، فهذا يعني أن المستخدم الخاص بك يفقد الوصول إلى جهاز USB. تغطي نفس قاعدة udev كلتا الأداتين، لذا أضف واحدة تسمح للمستخدمين بقراءتها.
SUBSYSTEM=="usb", ATTR{idVendor}=="0e8d", MODE="0666", GROUP="plugdev"

احفظ هذا السطر في ملف جديد باسم /etc/udev/rules.d/51-innioasis.rules، ثم قم بتشغيل:

sudo udevadm control --reload && sudo udevadm trigger
  1. افصل المشغل بالكامل، ثم قم بتوصيله مرة أخرى، ثم حاول التثبيت مرة أخرى.
  2. إذا أبلغ SP Flash Tool عن إذن تسلسلي أو سباق منفذ، فافصل القابس بالكامل وأعد الاتصال فقط عند المطالبة بذلك.
لا ترتجل تعويضات الفلاش.إذا انتقلت إلى أداة الاسترداد اليدوية، فاستخدم الملفات والتكوين الخاص بالطراز المرفق مع المشروع.

الكابل والتوقيت

  1. استخدم كبل بيانات USB معروفًا.
  2. تجنب المحاور أثناء استكشاف الأخطاء وإصلاحها.
  3. قم بإيقاف تشغيل الطراز الصحيح بالكامل.
  4. الاتصال فقط في الموجه.
