🎨 Y1 和 360p Rockbox 主題下載器

直接在瀏覽器中下載並安裝適合您的 Y1 裝置的主題

📱 設備設置

Y1 設備： 開啟 Y1 電源，透過 USB 連接，並啟用 USB 儲存模式

電腦: 您的 Y1 應顯示為可移動磁碟機（通常命名為「Y1」或類似名稱）

主題地點： 尋找名為的資料夾 .rockbox 在您的 Y1 裝置上

📋 手動安裝說明

⚠️重要： 下載主題後，您需要手動將它們複製到您的 Y1 裝置。瀏覽器無法直接存取您裝置的檔案系統。

🎯 對於 Y1 主題：

  1. 使用上面的按鈕下載選定的 Y1 主題
  2. 將下載的 ZIP 檔案解壓縮到臨時資料夾
  3. 透過 USB 連接您的 Y1 裝置並啟用 USB 儲存模式
  4. 在檔案總管中導覽至您的 Y1 設備
  5. 建立一個名為的資料夾 Themes 在您的 Y1 裝置的根目錄中（如果不存在）
  6. 對於每個主題，將主題資料夾複製到 Themes/ 在您的 Y1 裝置上
  7. 每個主題應該位於自己的子資料夾中： Themes/ThemeName/
  8. 主題檔案應直接放置在主題子資料夾內（不要嵌套得更深）
Y1 设备/ ├── .rockbox/ ├── 主题/ │ ├── 主题1/ │ │ ├── theme.wps │ │ ├── theme.sbs │ │ └── ... │ ├── 主题2/ │ │ ├── theme.wps │ │ └── ... │ └── ... └── ...

🎨 對於 Rockbox 360p 主題：

  1. 使用上面的按鈕下載選定的 Rockbox 主題
  2. 將下載的 ZIP 檔案解壓縮到臨時資料夾
  3. 透過 USB 連接您的 Y1 裝置並啟用 USB 儲存模式
  4. 在檔案總管中導覽至您的 Y1 設備
  5. 找到 .rockbox 您的 Y1 裝置上的資料夾
  6. 對於每個主題，打開該主題的 .rockbox 資料夾
  7. 複製主題的所有文件 .rockbox 資料夾直接放入您的 Y1 的 .rockbox 資料夾
  8. 出現提示時覆蓋現有文件（這對於主題安裝來說是正常的）
Y1 Device/ ├── .rockbox/ │ ├──主題/ │ ├── fonts/ │ ├── wps/ │ ├── (主旨檔案合併於此) │ └── ... │ ├── (主題檔案合併於此) │ └── ... └── ...
💡專業提示： 您可以選擇多個主題並一次下載它們。每個主題都將位於下載的 ZIP 檔案中自己的資料夾中。

🔄 安裝後：

  1. 從電腦中安全地彈出您的 Y1 設備
  2. 斷開 USB 電纜
  3. 在您的 Y1 裝置上，前往 設定 → 主題
  4. 從清單中選擇您新安裝的主題
  5. 享受你的新主題吧！

🗑️ 刪除主題：

  1. 對於 Y1 主題：從下列位置刪除主題資料夾 Themes/ 在您的 Y1 裝置上
  2. 對於 Rockbox 主題：使用上面的“重置 Rockbox 資料夾”按鈕刪除所有非 360p 主題
