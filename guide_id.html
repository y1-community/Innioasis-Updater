Memulai dengan Innioasis Pembaruan CE

Bekerja dengan semua pemutar audio Innioasis dan Timmkoo. Instal Innioasis Updater CE di komputer Anda, pilih model dan perangkat lunak yang Anda inginkan, lalu ikuti petunjuknya.

    Dapatkan Innioasis Updater CE

    Innioasis Updater Masehi adalah aplikasi yang menginstal pembaruan resmi dan perangkat lunak komunitas pada pemutar Anda. Itu menyimpan musik dan pengaturan Anda, dan berjalan di Windows, macOS dan Linux.

    Windows

    Unduh penginstal, jalankan, lalu mulai ulang PC Anda setelah selesai.

    Dapatkan DriverUnduh Updater CE

    Jika Windows menghentikan Anda menjalankan aplikasi atau tidak dapat meluncurkannya, buka Pengaturan, klik Privasi & keamanan → Keamanan Windows → Kontrol aplikasi & browser, dan matikan Kontrol Aplikasi Cerdas. Kontrol Aplikasi Cerdas saat ini memengaruhi aplikasi populer seperti Epic Overlay Service (digunakan oleh Fortnite) — Updater CE aman dan terverifikasi untuk digunakan. Windows tidak meluncurkan aplikasi? Bantuan

    Restart PC Anda setelah menginstal. Bantuan pengemudi ada di Catatan pengaturan Windows.

    macOS

    Unduh Updater CE

    Jika Mac menghentikan Anda menjalankan aplikasi untuk pertama kalinya, buka Pengaturan Sistem, klik Privasi & Keamanan, gulir ke bawah ke Keamanan dan klik Buka Pokoknya. Anda juga dapat Control-klik (atau klik kanan) aplikasi di Finder dan pilih Buka.

    Berfungsi di Intel dan Apple Silicon Mac dengan macOS Monterey dan versi lebih baru.

    Catatan pengaturan Linux

    Anda memerlukan pemutar Anda, kabel data USB yang membawa data (kabel khusus pengisi daya tidak dapat dipasang), dan beberapa menit. Biarkan kabel tetap tersambung hingga Updater CE menyatakan sudah selesai.

    Pilih model dan perangkat lunak Anda

    1. Model Perangkat: pilih model yang tercetak di pemutar, Y1 atau Y2. Perangkat lunak yang dibuat untuk satu model tidak dapat diinstal pada model lainnya.
    2. Perangkat lunak dan rilis: pilih Perangkat Lunak Asli, Rockbox, Solar, JJ Launcher, Inniclassic, Y2Player, atau Koensayr ketika terdaftar untuk model Anda, lalu pilih rilis. Stabil adalah pilihan yang aman.
    3. Instal: klik Pasang / Pulihkan, matikan pemutar sepenuhnya, dan sambungkan kabel USB hanya jika Updater CE memintanya.
    4. Selesai: biarkan player dan kabelnya sendiri sampai muncul pesan sukses, lalu putuskan sambungan dan nyalakan player.

    Y1 pemain yang dikirimkan dengan Perangkat Lunak Asli sebelum versi 2.0.0 membutuhkannya Perangkat Type B. Semua orang mempertahankan Type A default.

    Kembali ke Perangkat Lunak Asli

    Perangkat lunak khusus dapat dibalik. Di Updater CE, pilih model Anda, pilih Perangkat lunak asli, pilih rilis stabil, lalu jalankan Pasang / Pulihkan dengan cara yang sama. Tidak ada yang perlu dihapus dengan tangan.

    Windows tidak meluncurkan aplikasi? Solusi Kontrol Aplikasi Cerdas

    Windows Defender SmartScreen atau Smart App Control dapat memblokir aplikasi komunitas yang baru diunduh sebelum reputasi tanda tangan menyebar. Kontrol Aplikasi Cerdas saat ini memengaruhi aplikasi populer seperti Epic Overlay Service (digunakan oleh Fortnite) — Updater CE aman dan terverifikasi untuk digunakan. Mematikan Kontrol Aplikasi Cerdas memungkinkan Updater CE terbuka dan berjalan normal.

    1. Buka Pengaturan di PC Windows Anda (tekan Win + I).
    2. Klik Privasi & keamanan di sidebar kiri, lalu klik Windows Security.
    3. Klik Kontrol aplikasi & browser.
    4. Di bawah Kontrol Aplikasi Cerdas, klik Pengaturan Kontrol Aplikasi Cerdas.
    5. Setel tombol ke Mati untuk mengizinkan Updater CE diluncurkan.

    Diunduh melalui Edge? Jika Edge memblokir unduhan itu sendiri, klik tombol Opsi lainnya (…) → Simpan → Tampilkan lebih banyak → Tetap pertahankan.

    Mengaktifkan kembali Kontrol Aplikasi Cerdas nanti: Saat Anda ingin mengaktifkan kembali Smart App Control, Anda dapat mengaktifkannya kembali melalui Windows Registry di bawah HKEY_LOCAL_MACHINE\SYSTEM\CurrentControlSet\Control\CI\Policy dengan mengatur VerifiedAndReputablePolicyState untuk 1 (Aktif) atau 2 (Mode Evaluasi) dan memulai ulang.
