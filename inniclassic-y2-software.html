Inniclassic Y2 install steps

  1. Open Innioasis Updater CE on your computer (if you need the app, Get Updater CE). Set Device Model to Y2.
  2. Choose Inniclassic in Software.
  3. Choose the release listed for Y2.
  4. Click Install / Restore.
  5. Power off and connect the Y2 only when Updater CE asks.

FAQs

Can I restore the stock Y2 software?

Yes. Select Y2 and Original Software in Updater CE. The Y2 stock-software guide covers the return path.

Can I use Inniclassic on Y1?

Yes. The same project publishes Y1 packages as well — rom.zip for Type A and rom_type_b.zip for Type B. Select Y1 in Updater CE and install the Y1 build; the Y1 install page covers it.

What if installation fails?

Note whether Updater failed before or after detecting the Y2, then check the cable, platform setup, model, and connection timing in troubleshooting.
