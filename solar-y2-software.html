Model-correct Y2 checks

  1. Set Updater’s Device Model to Y2.
  2. Confirm that Solar is listed for Y2 in the current release data.
  3. Read the project release note and check its Y2 support.
  4. Choose the listed release and click Install / Restore.
  5. Power off and connect the Y2 only when Updater asks.
Do not substitute a Y1 package. A project being available for Y1 does not make its Y1 package safe for Y2.

FAQs

Is Solar Y2 guaranteed to be supported?

The current Updater catalogue lists Solar for Y2, but project support and release contents can change. Check the current entry and release notes immediately before installing.

How do I go back to stock?

Choose Y2 and Original Software in Updater, then follow the Y2 restore guide.

What if Solar is not shown for Y2?

Do not force a Y1 package. Check the project source and the troubleshooting guide, then wait for a compatible release.
