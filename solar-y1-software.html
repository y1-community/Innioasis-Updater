Solar Y1 install steps

  1. Open Innioasis Updater CE on your computer (if you need the app, Get Updater CE). Set Device Model to Y1.
  2. Choose Solar in Software.
  3. Read the project release note and choose a Y1 release.
  4. Click Install / Restore.
  5. Power off and connect the Y1 only when the prompt appears.

Solar features and availability can change. Features can change between releases, so check the project's release page and the current listing for your model.

FAQs

Can I return from Solar to the original software?

Use Y1 Original Software in Updater CE. You do not need to manually remove Solar first. Follow the Y1 restore steps.

Can I install the Solar Y2 entry on this player?

No. Keep the Y1 player on the Y1 entry and check the model before installing.

Where should I check current Solar features?

Read the release notes before choosing a release.

Need the wider Updater explanation?

See the Windows, macOS, and Linux Updater guide before starting, especially if the Y1 is not detected.
