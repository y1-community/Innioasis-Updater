Model-correct checks

  1. פתח את Innioasis Updater CE במחשב שלך (אם אתה צריך את האפליקציה, הורדת Updater CE). סט דגם המכשיר ל Y2.
  2. Confirm JJ Launcher appears for Y2 in the current release data.
  3. Read the project release note and select the listed Y2 release.
  4. לחץ התקנה / שחזור.
  5. Power off and connect the Y2 only when prompted.
Do not substitute: a Y1 package is not a Y2 package. Stop if the model and release do not agree.
