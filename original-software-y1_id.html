Instal atau pulihkan dengan Updater

Updater menggunakan alur terpandu yang sama baik Y1 saat ini menjalankan perangkat lunak aslinya atau proyek komunitas.

  1. Buka Innioasis Updater CE di komputer Anda (jika Anda memerlukan aplikasinya, Dapatkan Updater CE). Tetapkan Model perangkat untuk Y1.
  2. Pilih Perangkat lunak asli di Perangkat lunak (atau gunakan Dapatkan ini di Updater CE untuk melompat ke langkah-langkah yang dipandu).
  3. Klik Pasang / Pulihkan dan biarkan aplikasi menyiapkan paketnya.
  4. Matikan dan sambungkan Y1 hanya ketika perintah langsung menanyakan.

Saat mengunduh secara manual, paket instalasi lengkap yang biasa diberi nama rom.zip. Pemilihan model di Updater adalah cara yang lebih aman untuk memilih file.

Pertanyaan umum

Bisakah saya memulihkan dari Rockbox atau perangkat lunak khusus lainnya?

Ya, gunakan model Y1 dan jalur Y1 Perangkat Lunak Asli. Jangan hapus file sistem terlebih dahulu dan jangan gantikan paket Y2.

Bagaimana jika Y1 saya tidak terdeteksi?

Periksa kabel data, pengaturan komputer, dan waktu koneksi. Pemutar harus dimatikan dan dihubungkan hanya pada perintah Updater.

Paket mana yang harus saya gunakan untuk Y1 saya?

Biarkan model yang tercetak pada pemutar Anda tetap dipilih di Updater. Paket Y1 dan Y2 terpisah — hentikan jika daftar rilis tidak cocok dengan model Anda.
