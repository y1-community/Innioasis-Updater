Installationssteg

  1. Lansering Innioasis Uppdaterare CE på din Windows-, Mac- eller Linux-dator.
  2. Välj Y1 från rullgardinsmenyn Enhetsmodell.
  3. Välj Rondo från rullgardinsmenyn Programvara.
  4. Klicka Installera / Återställ och vänta på att verktyget laddar ner och förbereder filerna.
  5. När du uppmanas av Updater CE, stäng av din Y1 och anslut USB-kabeln.
  6. Slutför installationen efter installationen

    Följ stegen i denna guide för att slutföra installationen på din Y1.
