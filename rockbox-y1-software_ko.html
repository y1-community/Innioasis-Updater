컴퓨터에 대한 설치 가이드

사용 중인 컴퓨터에 대한 가이드를 선택하세요. 모든 버전에는 플랫폼 설정, Updater CE 단계 및 재고로 돌아가는 방법이 있습니다.

Rockbox Y1 설치 단계

  1. 컴퓨터에서 Innioasis Updater CE를 엽니다(앱이 필요한 경우, Updater CE 받기). 세트 기기 모델 에 Y1.
  2. 선택 Rockbox 안으로 소프트웨어.
  3. 의도한 화면이나 테마 경로와 일치하는 릴리스와 변형을 선택하세요.
  4. 클릭 설치 / 복원 앱이 준비할 때까지 기다리세요.
  5. 전원을 끄고 라이브 프롬프트에서만 Y1을 연결하십시오.

사용 Rockbox Y1 가이드 작성 스크린샷, 동영상, Type A 또는 Type B 메모, 연결 체크리스트를 확인하세요.

자주 묻는 질문

원래 Y1 소프트웨어로 돌아갈 수 있나요?

예. Updater CE에서 Y1 및 원본 소프트웨어를 선택한 다음 설치/복원을 실행합니다. 그만큼 Y1 재고 소프트웨어 페이지 그 경로를 설명합니다.

어떤 Rockbox 릴리스를 선택해야 합니까?

Y1에 표시된 릴리스를 선택하고 해당 릴리스 노트를 읽어보세요. 이전 테마 호환성이 필요한 경우 Y2 빌드를 선택하는 대신 해상도와 변형 메모를 확인하세요.

Y2에 설치할 수 있나요?

아니요. 별도의 Rockbox Y2 페이지 Updater CE에서 Y2을 선택합니다.

Rockbox-Y1 페이지

설치 단계, ROM 다운로드, 테마, 복원 및 문제 해결과 Y2 페이지가 포함되어 있어 두 빌드가 혼동되지 않습니다.
