    Otwórz pełne porównanie

    System Windows nie uruchamia aplikacji? Jak wyłączyć inteligentną kontrolę aplikacji

    Funkcja Windows Defender SmartScreen lub Smart App Control może blokować nowo pobrane aplikacje społecznościowe, zanim reputacja sygnatur zacznie się rozprzestrzeniać. Inteligentna kontrola aplikacji ma obecnie wpływ na popularne aplikacje, takie jak usługa Epic Overlay Service (używana przez Fortnite) — użycie narzędzia Updater CE jest bezpieczne i zweryfikowane. Wyłączenie inteligentnej kontroli aplikacji umożliwia normalne otwieranie i działanie narzędzia Updater CE.

    1. Otwórz Ustawienia na komputerze z systemem Windows (naciśnij Win + I).
    2. Kliknij Prywatność i bezpieczeństwo na lewym pasku bocznym, a następnie kliknij Windows Security.
    3. Kliknij Kontrola aplikacji i przeglądarki.
    4. Pod Inteligentna kontrola aplikacji, kliknij Ustawienia inteligentnej kontroli aplikacji.
    5. Ustaw przełącznik na Wyłączony aby umożliwić uruchomienie Updatera CE.

    Zablokowany przez Edge'a? Jeśli Microsoft Edge blokuje samo pobieranie, kliknij przycisk Więcej opcji (…) → Trzymać → Pokaż więcej → Mimo to zachowaj.

    Ponowne włączenie inteligentnej kontroli aplikacji później: Jeśli chcesz ponownie włączyć funkcję Smart App Control, możesz ją ponownie włączyć za pośrednictwem rejestru systemu Windows w obszarze HKEY_LOCAL_MACHINE\SYSTEM\CurrentControlSet\Control\CI\Policy poprzez ustawienie VerifiedAndReputablePolicyState do 1 (Wł.) lub 2 (Tryb ewaluacyjny) i ponowne uruchomienie.
