Model-correct Y2 checks

  1. Open Innioasis Updater CE on your computer (if you need the app, Updater CE प्राप्त करें). सेट डिवाइस मॉडल को Y2.
  2. Confirm that Solar is listed for Y2 in the current release data.
  3. Read the project release note and check its Y2 support.
  4. Choose the listed release and click इंस्टॉल / पुनर्स्थापित.
  5. बिजली बंद करें और Y2 को तभी कनेक्ट करें जब Updater CE पूछे।
Do not substitute a Y1 package. A project being available for Y1 does not make its Y1 package safe for Y2.

अक्सर पूछे जाने वाले प्रश्न

Is Solar Y2 guaranteed to be supported?

A Solar Y2 build is listed, but support and contents can change. Check the latest listing and release notes before installing.

How do I go back to stock?

Choose Y2 and Original Software in Updater CE, then follow the Y2 पुनर्स्थापना मार्गदर्शिका.

What if Solar is not shown for Y2?

Do not force a Y1 package. Check the project source and the समस्या निवारण मार्गदर्शिका, then wait for a compatible release.
