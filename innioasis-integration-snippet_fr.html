<!-- Innioasis Updater Install Guide Widget --> <script> (function() { // Créer et injecter le widget const script = document.createElement('script'); script.src = 'https://your-domain.com/innioasis-embed.html'; script.async = true; // Alternative : charger à partir d'un fichier local // script.src = './innioasis-embed.html'; document.head.appendChild(script); // Créer conteneur iframe const iframe = document.createElement('iframe'); iframe.src = 'https://your-domain.com/innioasis-embed.html'; iframe.style.cssText = ` position : fixe ; none; `; // Rendre l'iframe interactif iframe.onload = function() { iframe.style.pointerEvents = 'auto' }; </script>

🌐 Exigences d'hébergement

Pour utiliser ce widget sur votre site Web, vous devez :

  1. Téléchargez le innioasis-embed.html fichier sur votre serveur Web
  2. Mettez à jour les URL dans l'extrait d'intégration pour qu'elles pointent vers votre serveur
  3. Assurez-vous que votre serveur prend en charge HTTPS (obligatoire pour les navigateurs modernes)
  4. Testez le widget sur votre site Web pour vous assurer qu'il fonctionne correctement
