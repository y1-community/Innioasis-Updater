JJ Launcher Y1 passaggi di installazione

  1. Apri Innioasis Updater CE sul tuo computer (se ti serve l'app, Ottieni Updater CE). Impostato Modello del dispositivo a Y1.
  2. Scegli JJ Launcher dentro Software.
  3. Scegli la versione mostrata per Y1.
  4. Fare clic Installa / Ripristina.
  5. Spegnere e collegare Y1 solo quando Updater CE lo richiede.

Domande frequenti

Posso installare la voce Y2 su un Y1?

No. Mantieni il modello e il pacchetto abbinati. Se manca la voce Y1, non forzare un file Y2.

Posso tornare al software originale?

SÌ. Scegli Y1 e il software originale in Updater CE. Vedi il Y1 pagina di ripristino.

Dove sono tutte le JJ Launcher versioni?

Le build attuali sono presenti Download di software. Le note di rilascio si trovano sul progetto note di rilascio.

Configurazione del computer

Updater può essere utilizzato su Windows, macOS e Linux una volta pronta la relativa configurazione. Inizia con il guida della piattaforma.
