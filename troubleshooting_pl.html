Zatrzymało się przed monitem o USB

To problem z komputerem, a nie z kablem. Sprawdź model. Rozpakuj plik ponownie. Potem spróbuj Install / Restore. Jeśli lista wydań jest pusta, otwórz katalog firmware.

Nie może połączyć się z odtwarzaczem

  1. Całkowicie wyłącz właściwy odtwarzacz: Y1 lub Y2.
  2. Odłącz kabel, zamknij inne narzędzia do wgrywania i narzędzia Android, a potem uruchom instalację ponownie.
  3. Podłącz dopiero wtedy, gdy Updater poinformuje, że jest gotowy.
  4. Użyj krótkiego kabla USB do transmisji danych, podłączonego bezpośrednio do komputera, jeśli to możliwe bez huba.
  5. W Windows zainstaluj ponownie sterownik MediaTek i uruchom komputer ponownie. W Linuksie sprawdź uprawnienia USB/portu szeregowego.

Wykrył odtwarzacz, ale wgrywanie się nie powiodło

Zatrzymaj się. Nie próbuj innego modelu. Zamknij inne narzędzia, sprawdź, czy wybrano właściwy Y1 lub Y2, a jeśli odtwarzacz się nie uruchamia, użyj pasującego oryginalnego oprogramowania. Updater CE zawiera Metoda instalacji SP Flash Tool i MTKClient na przypadki, które ich wymagają, a pliki znajdziesz na strona firmware. Jeśli Updater CE nie działa na tym komputerze, użyj pakietu instalacyjnego ZIP przygotowanego dla niego.

Uwagi o sterownikach w Windows

Niektóre instalacje Windows blokują sterownik MediaTek z powodu izolacji rdzenia (Core isolation). Zanim zmienisz ustawienie Integralność pamięci, zapoznaj się z aktualnymi wskazówkami dotyczącymi zabezpieczeń Windows i włącz ją ponownie po zakończeniu, jeśli system na to pozwala.
