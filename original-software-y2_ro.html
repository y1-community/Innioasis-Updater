Instalați-l sau restaurați-l cu Updater

Configurați mai întâi computerul, apoi lăsați Updater să pregătească pachetul potrivit pentru model.

  1. Deschideți Innioasis Updater CE pe computer (dacă aveți nevoie de aplicație, Obține Updater CE). Setați Model dispozitiv la Y2.
  2. Alege Software original și o lansare Y2.
  3. Faceți clic Instalează / Restaurează.
  4. Opriți și conectați Y2 numai când promptul live vă solicită.

Se pot folosi pachete cu instalare completă manuală rom_y2.zip. Nu tratați un Y1 rom.zip ca înlocuitor.

Întrebări frecvente

Mă pot întoarce de la Rockbox sau de la un alt software personalizat?

Utilizați același flux de restaurare Y2: alegeți Y2, selectați Software original și urmați promptul de conectare. Nu amestecați fișierele model.

De ce pachetul Y2 arată diferit?

Y2 versiuni pot folosi un nume de pachet și o intrare diferită. Selectați Y2 în Updater, în loc să ghiciți dintr-un nume de fișier ZIP manual.

Ce se întâmplă dacă jucătorul nu este detectat?

Verificați cablul de date, permisiunile computerului sau driverele și sincronizarea. Conectați Y2 oprit numai după ce Updater spune că este gata.
