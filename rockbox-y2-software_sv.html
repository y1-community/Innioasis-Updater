Rockbox Y2 installationssteg

  1. Öppna Innioasis Updater CE på din dator (om du behöver appen, Hämta Updater CE). Ställ in Enhetsmodell till Y2.
  2. Välj Rockbox i Programvara.
  3. Välj en version som uttryckligen anges för Y2.
  4. Klicka Installera / Återställ och vänta på paketberedning.
  5. Stäng av och anslut Y2 endast när Updater CE frågar.

Tvinga inte fram ett Y1-paket eftersom projektnamnet ser likadant ut. Om ingen Y2 release visas, stoppa och kontrollera modellen och aktuella releasedata.

Vanliga frågor

Kan jag återställa den ursprungliga Y2 programvaran senare?

Ja. Välj Y2 och originalprogramvara i Updater CE. Se den Y2 sida med lagerprogramvara för återställningssekvensen.

Varför kan paketet heta rom_y2.zip?

Det är en ledtråd för manuell nedladdning som används av vissa Y2 fullständiga versioner. Det säkrare valet är fortfarande att välja Y2 i Updater CE och använda den version som den presenterar.

Kan jag använda handledningen Y1 Rockbox?

Använd den bara för den breda idén. För val av paket och modell, följ detta Y2-specifik guide.
