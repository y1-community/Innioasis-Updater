🚀 Innioasis Updater - ウィジェットを埋め込む

このコードをコピーして Web サイトに貼り付けて、Innioasis Updater ウィジェットを埋め込みます。

<!-- Innioasis Updater 埋め込みウィジェット --> <iframe src="https://inniaosis.app/innioasis-simple-embed.html" width="300" height="120" Frameborder="0" style="position:fixed;bottom:20px;right:20px;z-index:999999;border-radius:12px;box-shadow:0 8px 32px rgba(0,0,0,0.3);" allowtransparency="true"> </iframe>

📝 使用方法:

  1. 上のコードをコピーします
  2. Web サイトの HTML に貼り付けます
  3. ウィジェットは右下隅に表示されます
  4. ユーザーはクリックして自分のプラットフォームのインストール ガイドを入手できます

🎯 デモ

下のボタンをクリックして、埋め込みウィジェットの動作を確認してください。

✨ 特徴:

  • ユーザーのオペレーティング システムを自動的に検出します
  • プラットフォーム固有のインストール ガイドを表示します
  • システムフォントを使用したクリーンでモダンなデザイン
  • レスポンシブでモバイルフレンドリー
  • 外部依存関係は必要ありません
