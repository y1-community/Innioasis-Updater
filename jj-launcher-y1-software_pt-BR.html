JJ Launcher Y1 etapas de instalação

  1. Abra o Innioasis Updater CE no seu computador (se precisar do aplicativo, Obter o Updater CE). Definir Modelo do aparelho para Y1.
  2. Escolher JJ Launcher em Programas.
  3. Escolha o lançamento mostrado para Y1.
  4. Clique Instalar / Restaurar.
  5. Desligue e conecte o Y1 somente quando o Updater CE solicitar.

Perguntas frequentes

Posso instalar a entrada Y2 em um Y1?

Não. Mantenha o modelo e a embalagem correspondentes. Se a entrada Y1 estiver faltando, não force um arquivo Y2.

Posso voltar ao software original?

Sim. Escolha Y1 e Software Original em Updater CE. Veja o Y1 página de restauração.

Onde estão todos os JJ Launcher lançamentos?

As compilações atuais estão em Downloads de software. As notas de lançamento estão no projeto notas de lançamento.

Configuração do computador

O atualizador pode ser usado no Windows, macOS e Linux assim que a configuração relevante estiver pronta. Comece com o guia da plataforma.
