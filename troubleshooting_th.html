มันหยุดตรงไหน? นั่นจะบอกคุณว่าต้องแก้ไขอะไร

กลับสู่คำแนะนำปกติตรวจสอบเฟิร์มแวร์

มันหยุดก่อนข้อความแจ้ง USB

นี่เป็นปัญหาของคอมพิวเตอร์ ไม่ใช่ปัญหาเกี่ยวกับสายเคเบิล ตรวจสอบรุ่นของคุณ แตกไฟล์อีกครั้ง จากนั้นลอง ติดตั้ง / คืนค่า. If the release list is empty, open the ไดเร็กทอรีเฟิร์มแวร์.

ไม่สามารถเชื่อมต่อกับเครื่องเล่นได้

  1. ปิด Y1 หรือ Y2 ที่ถูกต้องจนสุด
  2. ถอดสายเคเบิล ปิดแฟลชหรือเครื่องมือ Android อื่นๆ แล้วเริ่มการติดตั้งอีกครั้ง
  3. เชื่อมต่อเฉพาะเมื่อ Updater บอกว่าพร้อมแล้ว
  4. ใช้สายเคเบิลข้อมูลสั้น USB โดยตรงในคอมพิวเตอร์ ไม่ใช่ฮับ หากเป็นไปได้
  5. บน Windows ให้ติดตั้งไดรเวอร์ MediaTek ใหม่แล้วรีสตาร์ท บน Linux ให้ตรวจสอบสิทธิ์ USB/serial

ตรวจพบเครื่องเล่นแต่แฟลชล้มเหลว

หยุดที่นี่ อย่าลองใช้รุ่นอื่น ปิดเครื่องมืออื่นๆ ตรวจสอบว่าคุณเลือก Y1 หรือ Y2 ที่ถูกต้อง และใช้ซอฟต์แวร์ต้นฉบับที่ตรงกันหากเครื่องเล่นไม่เริ่มทำงาน SP Flash Tool และ MTKClient จะรวมอยู่ด้วยหากคุณต้องการ และไฟล์จะอยู่ใน หน้าเฟิร์มแวร์.

หมายเหตุไดรเวอร์ Windows

การติดตั้ง Windows บางอย่างบล็อกไดรเวอร์ MediaTek เนื่องจากการแยกคอร์ ปฏิบัติตามคำแนะนำด้านความปลอดภัยของ Windows ปัจจุบันก่อนที่จะเปลี่ยนความสมบูรณ์ของหน่วยความจำ และเปิดอีกครั้งเมื่อคุณดำเนินการเสร็จสิ้นหากระบบของคุณอนุญาต

เปิดคู่มือผู้ขับขี่คู่มือการติดตั้งใหม่ทั้งหมด

วงล้อไม่ทำงาน หรือผู้เล่นจะไม่สตาร์ท

ข้อผิดพลาดด้านอินพุตและกำลังไฟต้องมีขั้นตอนที่แตกต่างจากแฟลชที่ล้มเหลว คำแนะนำเหล่านี้ครอบคลุมกรณีทั่วไปของ Y1 และ Y2

Y1 ล้อเลื่อนY2 ล้อเลื่อนY1 เปิดไม่ติดY2 เปิดไม่ติดคู่มือการกู้คืน

ยังติดอยู่เหรอ?

เมื่อขอความช่วยเหลือ ให้ระบุรุ่น ระบบปฏิบัติการ ข้อความ Updater ที่แน่นอน ตรวจพบเครื่องเล่นหรือไม่ และแพ็คเกจ/โปรเจ็กต์ที่คุณเลือก ห้ามโพสต์โทเค็นส่วนตัวหรือไฟล์ระบบที่ไม่เกี่ยวข้อง
