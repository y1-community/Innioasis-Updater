# ติดตั้ง Rockbox บน Y1 โดยไม่ต้องเดาไฟล์

นี่คือเส้นทาง Y1 สำหรับซอฟต์แวร์ ธีม และขั้นตอนการเชื่อมต่อตัวอัปเดต Rockbox การเลือกรุ่นจะต้องมาก่อนการเลือกโครงการ[เปิดคำแนะนำ Rockbox ฉบับเต็ม](guides/rockbox-y1.html)[รับสิ่งนี้ใน Updater CE](guide_th.html?model=Y1&software=rockbox-y1)[ทำไมต้อง Rockbox?](rockbox-benefits_th.html)

## ติดตั้ง Rockbox บน Y1 ด้วยคอมพิวเตอร์ของคุณ

เลือกคำแนะนำสำหรับคอมพิวเตอร์ที่คุณใช้ ทุกรุ่นมีการตั้งค่าแพลตฟอร์ม ขั้นตอน Updater CE และวิธีคืนสินค้าในสต็อก[คู่มือวินโดวส์](install/rockbox-y1-windows.html)[คู่มือ macOS](install/rockbox-y1-mac.html)[คู่มือลินุกซ์](install/rockbox-y1-linux.html)

[คำแนะนำ Innioasis Y1 ทั้งหมด](install/y1.html) · [คำแนะนำ Rockbox ทั้งหมด](install/rockbox_th.html)

## Rockbox Y1 ขั้นตอนการติดตั้ง
  - เปิด Innioasis Updater CE บนคอมพิวเตอร์ของคุณ (หากคุณต้องการแอป [รับ Updater CE](guide_th.html#platform)). ชุด รุ่นอุปกรณ์ ถึง Y1.
  - เลือก Rockbox ใน ซอฟต์แวร์.
  - เลือกรุ่นและรูปแบบที่ตรงกับหน้าจอหรือเส้นทางธีมที่คุณต้องการ
  - คลิก ติดตั้ง / คืนค่า และรอให้แอปเตรียมการ
  - ปิดเครื่องและเชื่อมต่อ Y1 เฉพาะเมื่อมีข้อความแสดงสดเท่านั้น

ใช้ [เขียนคำแนะนำ Rockbox Y1](guides/rockbox-y1.html) สำหรับภาพหน้าจอ วิดีโอ บันทึก Type A หรือ Type B และรายการตรวจสอบการเชื่อมต่อ

## คำถามที่พบบ่อยฉันสามารถกลับไปใช้ซอฟต์แวร์ Y1 ดั้งเดิมได้หรือไม่

ใช่. เลือก Y1 และซอฟต์แวร์ต้นฉบับใน Updater CE จากนั้นเรียกใช้ Install / Restore ที่ [Y1 หน้าสต็อกซอฟต์แวร์](original-software-y1_th.html) อธิบายเส้นทางนั้นฉันควรเลือก Rockbox รุ่นใด

เลือกรุ่นที่แสดงสำหรับ Y1 และอ่านบันทึกประจำรุ่น หากคุณต้องการความเข้ากันได้ของธีมแบบเก่า ให้ตรวจสอบความละเอียดและหมายเหตุตัวแปร แทนที่จะเลือกบิวด์ Y2ฉันสามารถติดตั้งสิ่งนี้บน Y2 ได้หรือไม่

เลขที่ ใช้แยก [Rockbox Y2 หน้า](rockbox-y2-software_th.html) และเลือก Y2 ใน Updater CE
