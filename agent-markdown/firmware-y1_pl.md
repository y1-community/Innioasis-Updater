# Oprogramowanie sprzętowe dla Innioasis Y1

Y1 oferuje najszerszy wybór systemów niestandardowych. Wszystko poniżej jest tutaj hostowane, sprawdzane i instalowane jednym kliknięciem za pomocą narzędzia Updater CE.[Przeglądaj Y1 pliki do pobrania](firmware_pl.html?model=Y1)[Pobierz Updater CE](guide_pl.html#platform)[Galeria tematów](https://themes.innioasis.app/?lang=pl)

## Dostępne systemy operacyjne dla Innioasis Y1

Y1 obsługuje kilka systemów oprogramowania, w tym kompilacje z obsługą audiofilskich kodeków, nowoczesne programy uruchamiające i przywracanie ustawień fabrycznych. Wybierz ten, który pasuje do Twojego sposobu słuchania:

### [Rockbox](rockbox-benefits_pl.html)

Złoty standard odtwarzania dźwięku typu open source. Korektor parametryczny, odtwarzanie plików FLAC/MP3 bez przerw, motywy i pakiety czcionek do zainstalowania bezpośrednio w Updater CE.[Y1 Rockbox Przewodnik →](guides/rockbox-y1.html)

### [Better-Y](better-y-benefits_pl.html)

Ulepszona pochodna oryginalnego oprogramowania z poprawkami stabilności Bluetooth, regulacją krzywej głośności i 100% kompatybilnością z Galerią motywów.[Better-Y Przewodnik →](guides/better-y-y1.html)

### [Solar](solar-benefits_pl.html)

Współczesny odtwarzacz muzyki typu open source zbudowany z Flutter, oferujący płynne animacje 60 klatek na sekundę, siatki okładek albumów i nowoczesną typografię.[Solar Y1 Przewodnik →](guides/solar-y1.html)

### [Rondo](rondo-benefits_pl.html)

Program uruchamiający Y1 o otwartym kodzie źródłowym do lokalnych utworów i przesyłania strumieniowego, z szybką i responsywną nawigacją.[Rondo Y1 Przewodnik →](guides/rondo-y1.html)

### [Koensayr](koensayr-benefits.html)

Niestandardowa wersja oprogramowania sprzętowego z własną ikonografią, lepszą kalibracją baterii i obsługą motywów standardowych.[Koensayr Przewodnik →](guides/koensayr-y1.html)

### [Oryginalne oprogramowanie (przywracanie zapasów)](original-software-benefits_pl.html)

Wyczyść fabryczne obrazy oprogramowania sprzętowego dla odtwarzaczy Type A (v2.0.0+) i Type B (v1.x) Y1. Bezpiecznie odblokuj lub przywróć urządzenie do stanu fabrycznego.[Przywróć Y1 Przewodnik →](guides/restore-original-y1.html)

## Jak zainstalować lub zaktualizować Y1 oprogramowanie sprzętowe

Aktualizacja lub usunięcie awarii Innioasis Y1 jest prosta dzięki naszemu wieloplatformowemu pakietowi oprogramowania:
  - Otwórz Innioasis Aktualizator CE: Uruchom aktualizator w systemie macOS, Windows lub Linux.
  - Wybierz model Y1: Wybierz Y1 na liście rozwijanej Model urządzenia.
  - Wybierz swój system operacyjny: Wybierz Rockbox, Better-Y, Solar lub oryginalne oprogramowanie.
  - Kliknij Zainstaluj: Updater CE pobiera pakiet oprogramowania bezpośrednio z wersji deweloperskiej. Po wyświetleniu monitu podłącz wyłączony Y1 przez USB, aby rozpocząć flashowanie.
