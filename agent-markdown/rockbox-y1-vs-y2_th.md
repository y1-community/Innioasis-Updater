# Rockbox-Y1 กับ Rockbox-Y2

Rockbox-Y1 และ Rockbox-Y2 เป็นเฟิร์มแวร์ที่สร้างแยกกันซึ่งสร้างขึ้นสำหรับผู้เล่นที่แตกต่างกัน จับคู่โครงสร้างกับรุ่นที่พิมพ์บนเครื่องเล่นของคุณเสมอ[Rockbox-Y1 ติดตั้ง](rockbox-y1/install.html)[Rockbox-Y2 ติดตั้ง](rockbox-y2/install.html)[ดาวน์โหลดทั้ง ROM](rockbox-rom-download_th.html)

## เทียบเคียงกัน````[``](firmware_th.html?model=Y1&software=rockbox-y1)[``](firmware_th.html?model=Y2&software=rockbox-y2)``````

| รายละเอียด | Rockbox-Y1 | Rockbox-Y2 |
| --- | --- | --- |
| รุ่นผู้เล่น | Innioasis Y1 | Innioasis Y2 |
| โครงการพัฒนา | rockbox-y1/rockbox | spycemagic/y2-rockbox |
| แพ็คเกจนักพัฒนา ROM | rom.zip (และ rom_type_b.zip) | rom_y2.zip |
| Updater CE แหล่งดาวน์โหลด | โดยตรงจากการเปิดตัวของนักพัฒนา | โดยตรงจากการเปิดตัวของนักพัฒนา |
| ตัวเลือกการสร้าง | 240p / 360p, Type A / Type B คงที่และทุกคืน | รุ่นเบต้ารุ่น |
| ธีมส์ | คอลเลกชันธีม 240p และ 360p | Themes matched to the installed Y2 build |
| คืนค่าโรงงาน | Y1 ซอฟต์แวร์ต้นฉบับใน Updater CE | Y2 ซอฟต์แวร์ต้นฉบับใน Updater CE |

## เหตุใดการเลือกรุ่นของคุณจึงมีความสำคัญเป็นอันดับแรก

แม้ว่าทั้งสองบิลด์จะทำงาน Rockbox แต่ Innioasis Y1 และ Y2 มีฮาร์ดแวร์และโครงร่างพาร์ติชันที่แตกต่างกัน ห้ามแฟลช Y1 ROM บน Y2 หรือ Y2 ROM บน Y1

Innioasis Updater CE ป้องกันข้อมูลที่ไม่ตรงกันโดยการกรองซอฟต์แวร์ที่มีอยู่ทันทีที่คุณเลือก Y1 หรือ Y2 ใน รุ่นอุปกรณ์. Updater CE ดาวน์โหลดแพ็คเกจที่เลือกโดยตรงจากรีลีสของผู้พัฒนาเฟิร์มแวร์ชุมชนเสมอ (ผู้พัฒนามีหน้าที่รับผิดชอบแต่เพียงผู้เดียวในการแสดงรายการรีลีสของตนใน Updater CE)

## คุณต้องการคำแนะนำใด?
  - Innioasis Y1 — ไปที่ [Rockbox-Y1 ฮับ](rockbox-y1/). เลือก Type A (สำหรับผู้เล่นที่จัดส่งเวอร์ชัน 2.0.0+) หรือ Type B (สำหรับยูนิตรุ่นเก่า) จากนั้นเลือกบิลด์ 240p หรือ 360p
  - Innioasis Y2 — ไปที่ [Rockbox-Y2 ฮับ](rockbox-y2/). เลือก Y2 ใน Updater CE และเลือก Y2 รุ่นล่าสุด

## สิ่งที่ทั้งสองพอร์ตใช้ร่วมกัน

ทั้งสองนำฐานข้อมูลเพลงตามแท็กของ Rockbox การเล่นแบบไม่มีช่องว่าง อีควอไลเซอร์ ธีมที่กำหนดเอง และการฟังแบบออฟไลน์ 100% จากเครื่องเล่นของคุณ อ่าน [เพราะเหตุใด Rockbox](rockbox-benefits_th.html) เพื่อดูว่า Rockbox เพิ่มอะไรจากซอฟต์แวร์จากโรงงาน[Rockbox สำหรับ Y1](rockbox-for-y1_th.html)[Rockbox สำหรับ Y2](rockbox-for-y2_th.html)[Rockbox ภาพรวม](rockbox_th.html)
