## Vérifications correctes du modèle
  - Ouvrez Innioasis Updater CE sur votre ordinateur (si vous avez besoin de l'application, [Obtenir Updater CE](guide_fr.html#platform)). Ensemble Modèle d'appareil à Y2.
  - Confirmer JJ Launcher apparaît pour Y2 dans les données de la version actuelle.
  - Lisez la note de version du projet et sélectionnez la version Y2 répertoriée.
  - Cliquez Installer / Restaurer.
  - Éteignez et connectez le Y2 uniquement lorsque vous y êtes invité.
Ne remplacez pas : un package Y1 n'est pas un package Y2. Arrêtez-vous si le modèle et la version ne concordent pas.

## FAQLe support de Y2 est-il garanti ?

Une version Y2 est répertoriée, mais ce qui est pris en charge peut changer. Vérifiez la dernière liste et les notes du projet avant l'installation.Comment restaurer le Y2 ?

Sélectionnez Y2 et Logiciel original dans Updater CE, puis suivez les instructions [Y2 étapes de restauration](original-software-y2_fr.html).Que faire si JJ Launcher n'est pas répertorié ?

Ne forcez pas un package Y1. Vérifiez les versions du projet et les [guide de dépannage](troubleshooting_fr.html).
