## Αποκτήστε το Innioasis Updater CE

Εδώ μπορείτε να ξεκινήσετε εάν δεν έχετε ήδη αποκτήσει το Updater CE.Αποκτήστε το στο Updater CEμε καθοδηγούμενη εγκατάσταση

### Windows

Κάντε λήψη του προγράμματος εγκατάστασης, ανοίξτε το και ακολουθήστε τις οδηγίες εγκατάστασης.[Λήψη και εγκατάσταση προγράμματος οδήγησης](https://github.com/y1-community/supplemental-apks/releases/latest/download/DriverInstall.exe)[Κατεβάστε την εφαρμογή και τα προγράμματα οδήγησης](https://github.com/y1-community/Innioasis-Updater/releases/latest/download/installer.exe)[Αποκλείστηκε από τον Edge;](#)

Εάν τα Windows σας εμποδίσουν να εκτελέσετε την εφαρμογή ή δεν την εκκινήσουν, ανοίξτε τις Ρυθμίσεις, κάντε κλικ στην επιλογή Απόρρητο και ασφάλεια → Ασφάλεια των Windows → Έλεγχος εφαρμογών και προγράμματος περιήγησης και απενεργοποιήστε τον Έλεγχο Smart App. [Τα Windows δεν θα εκκινήσουν την εφαρμογή; Βοήθεια](#smart-app-control)

Θα χρειαστεί να επανεκκινήσετε τον υπολογιστή σας μετά την εγκατάσταση για να λειτουργήσει.

### macOS

Κατεβάστε την εφαρμογή και μετακινήστε την στις Εφαρμογές. Εάν το macOS το αποκλείσει, ανοίξτε τις Ρυθμίσεις συστήματος, στη συνέχεια Απόρρητο και ασφάλεια και κάντε κλικ στο Άνοιγμα ούτως ή άλλως. [Πώς λειτουργεί αυτό](https://support.apple.com/en-gb/102445#openanyway)[Κατεβάστε το Updater CE](https://github.com/y1-community/Innioasis-Updater/releases/latest/download/Innioasis.Updater.for.Mac.dmg)

### Linux

Κατεβάστε το AppImage για συστήματα Intel και AMD, κάντε το εκτελέσιμο και εκτελέστε το.[Κατεβάστε το AppImage για Intel/AMD](https://github.com/y1-community/innioasis-updater/releases/latest/download/UpdaterCE.AppImage)[Σημειώσεις εγκατάστασης Linux](drivers_el.html#linux)Άλλη πλατφόρμα;

Χρειάζεστε τις μεγαλύτερες σημειώσεις εγκατάστασης υπολογιστή; Ανοίξτε το [Windows](drivers_el.html#windows) ή [Linux](drivers_el.html#linux) οδηγός εγκατάστασης.

Innioasis Ενημερωτής CE είναι ο ασφαλέστερος τρόπος για να ενημερώσετε τη συσκευή σας. Διατηρεί τη μουσική, τα βίντεο και τις ζεύξεις Bluetooth. Σας ενημερώνει πότε είναι έτοιμες οι ενημερώσεις. ### Τα Windows δεν θα εκκινήσουν την εφαρμογή; Πώς να απενεργοποιήσετε το Smart App Control

Το Windows Defender SmartScreen ή το Smart App Control μπορεί να αποκλείσει τις εφαρμογές κοινότητας που λήφθηκαν πρόσφατα πριν από τη διάδοση της φήμης της υπογραφής. Ο Έξυπνος Έλεγχος εφαρμογών επηρεάζει επί του παρόντος δημοφιλείς εφαρμογές όπως η υπηρεσία Epic Overlay (που χρησιμοποιείται από το Fortnite) — Το Updater CE είναι ασφαλές και επαληθευμένο για χρήση. Η απενεργοποίηση του Smart App Control επιτρέπει στο Updater CE να ανοίγει και να λειτουργεί κανονικά.
  - Ανοίξτε Ρυθμίσεις στον υπολογιστή σας με Windows (πατήστε Win + I).
  - Κάντε κλικ Απόρρητο και ασφάλεια στην αριστερή πλαϊνή γραμμή και, στη συνέχεια, κάντε κλικ Windows Security.
  - Κάντε κλικ Έλεγχος εφαρμογών και προγράμματος περιήγησης.
  - Κάτω Έξυπνος έλεγχος εφαρμογών, κάντε κλικ Ρυθμίσεις Smart App Control.
  - Ρυθμίστε την εναλλαγή σε Απενεργοποίηση για να επιτρέψετε την εκκίνηση του Updater CE.

Αποκλείστηκε από τον Edge; Εάν ο Microsoft Edge μπλοκάρει τη λήψη, κάντε κλικ στο κουμπί Περισσότερες επιλογές (…) → Κρατήστε → Εμφάνιση περισσότερων → Διατήρησε πάντως.

Εκ νέου ενεργοποίηση Smart App Control αργότερα: Όταν θέλετε να ενεργοποιήσετε ξανά τον Έλεγχο Smart App, μπορείτε να τον ενεργοποιήσετε ξανά μέσω του Μητρώου των Windows κάτω `HKEY_LOCAL_MACHINE\SYSTEM\CurrentControlSet\Control\CI\Policy` με ρύθμιση `VerifiedAndReputablePolicyState` να `1` (Ενεργό) ή `2` (Λειτουργία αξιολόγησης) και επανεκκίνηση.Κλείσιμο βοήθειας
