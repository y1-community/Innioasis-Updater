## JJ Launcher Y1 etapas de instalação
  - Abra Innioasis Updater CE no seu computador (se precisar do aplicativo, [Obtenha o atualizador CE](guide_pt.html#platform)). Definir Modelo do dispositivo para Y1.
  - Escolher JJ Launcher em Programas.
  - Escolha o lançamento mostrado para Y1.
  - Clique Instalar / Restaurar.
  - Desligue e conecte o Y1 somente quando Updater CE solicitar.

## Perguntas frequentesPosso instalar a entrada Y2 em um Y1?

Não. Mantenha o modelo e a embalagem correspondentes. Se a entrada Y1 estiver faltando, não force um arquivo Y2.Posso voltar ao software original?

Sim. Escolha Y1 e Software Original em Updater CE. Veja o [Y1 página de restauração](original-software-y1_pt.html).Onde estão todos os JJ Launcher lançamentos?

As compilações atuais estão em [Downloads de software](firmware_pt.html#y1). As notas de lançamento estão no projeto [notas de lançamento](release_notes_pt.html?software=jj-launcher-y1).
