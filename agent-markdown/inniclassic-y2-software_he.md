# התקן את Inniclassic ב-Y2.

Inniclassic זמין עבור Innioasis Y2, ואותו פרויקט בונה גם את החבילות Y1. דף זה נותן לך את הסקירה Y2 וקישורים למדריך המלא.[פתח את המדריך המלא Inniclassic](guides/inniclassic-y2.html)[קבל את זה ב-Updater CE](guide_he.html?model=Y2&software=inniclassic-y2)[למה Inniclassic?](inniclassic-benefits_he.html)

מדריך התקנת המחשב שלך

## התקן את Inniclassic ב-Y2 שלך עם המחשב שלך

בחר את המדריך עבור המחשב שבו אתה משתמש. לכל גרסה יש את הגדרת הפלטפורמה, Updater CE שלבים והדרך חזרה למלאי.[מדריך Windows](install/inniclassic-y2-windows.html)[מדריך macOS](install/inniclassic-y2-mac.html)[מדריך לינוקס](install/inniclassic-y2-linux.html)

[כל Innioasis מדריכי Y2](install/y2.html) · [כל המדריכים Inniclassic](install/inniclassic.html)

## Inniclassic Y2 שלבי התקנה
  - פתח את Innioasis Updater CE במחשב שלך (אם אתה צריך את האפליקציה, [הורדת Updater CE](guide_he.html#platform)). סט דגם המכשיר ל Y2.
  - בחר Inniclassic ב תוכנה.
  - בחר את הגרסה הרשומה עבור Y2.
  - לחץ התקנה / שחזור.
  - כבה וחבר את ה-Y2 רק כאשר Updater CE מבקש.

## שאלות נפוצותהאם אוכל לשחזר את תוכנת המניות Y2?

כֵּן. בחר Y2 ותוכנה מקורית בעדכון CE. ה [Y2 מדריך תוכנה למניות](original-software-y2_he.html) מכסה את נתיב החזרה.האם אני יכול להשתמש ב-Inniclassic ב-Y1?

כֵּן. אותו פרויקט מפרסם גם חבילות Y1 - rom.zip עבור Type A ו rom_type_b.zip עבור Type B. בחר Y1 ב- Updater CE והתקן את ה-Y1 build; את [דף ההתקנה של Y1](inniclassic-y1-software_he.html) מכסה אותו.מה אם ההתקנה נכשלת?

שים לב אם העדכון נכשל לפני או אחרי זיהוי ה-Y2, ולאחר מכן בדוק את הכבל, הגדרת הפלטפורמה, הדגם ותזמון החיבור ב- [פתרון בעיות](troubleshooting_he.html).

## השתמשו במסלול המודרך

פעם ראשונה שאתה משתמש ב-Updater? עיין בהגדרה המודרכת ל [הורדת Updater CE](guide_he.html#platform) ב-Windows, macOS או Linux לפני חיבור הנגן.
