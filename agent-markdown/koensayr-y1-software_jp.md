# Y1 に Koensayr をインストールします。

Koensayr は Y1 コミュニティ ソフトウェア オプションとしてリストされています。ファイル名でパッケージを探す代わりに、モデル対応のアップデーター フローを使用します。[Koensayr ガイド全体を開く](guides/koensayr-y1.html)[Updater CE で入手](guide_ja.html?model=Y1&software=koensayr-y1)[なぜKoensayr?](koensayr-benefits_ja.html)

お使いのコンピューターのインストールガイド

## コンピュータを使用して Y1 に Koensayr をインストールします

使用しているコンピュータのガイドを選択してください。 すべてのバージョンには、プラットフォームのセットアップ、Updater CE の手順、および在庫に戻る方法が含まれています。[Windowsガイド](install/koensayr-y1-windows.html)[macOS ガイド](install/koensayr-y1-mac.html)[Linuxガイド](install/koensayr-y1-linux.html)

[すべての Innioasis Y1 ガイド](install/y1.html) · [すべての Koensayr ガイド](install/koensayr.html)

## Koensayr Y1 のインストール手順
  - コンピューターで Innioasis Updater CE を開きます (アプリが必要な場合は、 [Updater CE を入手](guide_ja.html#platform)）。セット デバイスモデル 支援先: Y1.
  - 選択してください Koensayr で ソフトウェア.
  - リストされている Y1 リリースを選択します。
  - クリック インストール / 復元.
  - Updater CE が要求した場合にのみ、電源をオフにして Y1 を接続してください。

## よくある質問元の Y1 ソフトウェアを復元できますか?

はい。 Y1を選択し、Updater CEでオリジナルソフトウェアを選択します。を参照してください。 [Y1 ストック ソフトウェア ページ](original-software-y1_ja.html) 完全な復元ルートについては、失敗した場合は何を確認すればよいですか?

モデル、リリース、ケーブル、プラットフォームの設定、およびプロンプトが表示される前にプレーヤーが接続されているかどうかを確認してください。次に、使用します [トラブルシューティング](troubleshooting_ja.html).Koensayr Y2 パッケージはありますか?

現在のビルドは Y1 用です。プロジェクトが個別のリリースを公開しない限り、Y2 では使用しないでください。

## まずはパソコンのセットアップから

プラットフォームのセットアップが完了すると、アップデータは Windows、macOS、Linux で動作します。読んでください [一般的なガイド](guide_ja.html#platform) まず。
