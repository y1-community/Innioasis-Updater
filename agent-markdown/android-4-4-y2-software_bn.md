# Install Android 4.4 (Dev) on the Y2.

Android 4.4 is a community development ROM for testing and hacking on Innioasis Y2 hardware. ## Android 4.4 Y2 install steps
  - আপনার কম্পিউটারে Innioasis Updater CE খুলুন (যদি আপনার অ্যাপটির প্রয়োজন হয়, [Updater CE নিন](guide_bn.html#platform)) সেট ডিভাইস মডেল থেকে Y2.
  - বেছে নিন Android 4.4 (Dev) মধ্যে সফটওয়্যার.
  - Choose the release listed for Y2.
  - ক্লিক করুন ইনস্টল / পুনরুদ্ধার.
  - পাওয়ার বন্ধ করুন এবং শুধুমাত্র Updater CE বললেই Y2 কানেক্ট করুন।

## সাধারণ প্রশ্নCan I restore the stock Y2 software?

Yes. Select Y2 and Original Software in Updater CE. The [Y2 stock-software guide](original-software-y2_bn.html) ফেরার পথ কভার করে।Is this a daily driver ROM?

This is an experimental developer ROM intended for testing and development. Release updates are on the project's page.
