# Драйверы Innioasis Y1 и Y2 USB | Драйвер Windows и разрешения Linux - Innioasis Средство обновления

Настройка компьютера

# Подготовьте компьютер раньше игрока.

Большинство проблем с подключением возникают из-за драйвера, разрешений, кабеля или времени. Windows необходимо установить драйвер MediaTek. Linux необходимы правильные разрешения USB. Найдите свою платформу ниже.[Скачать Updater CE](guide_ru.html#platform)[Устранение неполадок](troubleshooting_ru.html)

## Windows
  - Загрузите установщик драйвера MediaTek ниже.
  - Запустите установщик и разрешите Windows установить драйвер.
  - Перезагрузите компьютер.
  - Откройте Updater CE и дождитесь запроса на подключение, прежде чем подключать выключенный плеер.

Некоторые системы Windows блокируют драйвер через изоляцию ядра (целостность памяти). Если программа обновления CE по-прежнему не видит плеер после перезагрузки, отключите целостность памяти в разделе «Безопасность Windows», перезагрузите компьютер и переустановите драйвер. Когда вы закончите, снова включите эту настройку, если ваша система позволяет это.

Windows не запускает приложение? Если безопасность Windows или Smart App Control не позволяют открыть Updater CE, откройте Настройки (нажимать Win + I) → Конфиденциальность и безопасность → Windows Security → Управление приложениями и браузерами → Настройки смарт-контроля приложений и установите его на Выключенный. Функция «Умное управление приложениями» в настоящее время влияет на популярные приложения, такие как Epic Overlay Service (используется Fortnite) — Updater CE безопасен и проверен. Чтобы повторно включить позже, установите `VerifiedAndReputablePolicyState` в адрес `1` (Вкл.) или `2` (Режим оценки) в разделе `HKEY_LOCAL_MACHINE\SYSTEM\CurrentControlSet\Control\CI\Policy` в редакторе реестра.[Загрузите драйвер для Windows](https://github.com/y1-community/supplemental-apks/releases/latest/download/DriverInstall.exe)

## Разрешения Linux USB

Linux необходимо, чтобы вашей учетной записи пользователя было разрешено общаться с чипом MediaTek USB внутри плеера. Программа обновления CE обычно решает эту проблему во время установки, и то же разрешение распространяется на SP Flash Tool, поэтому рассматривайте это как шаг по исправлению ситуации, а не как обычный этап.
  - Запустите Updater CE от имени обычного пользователя, а не от имени пользователя root. Установщик запрашивает доступ администратора только тогда, когда он ему нужен.
  - Проверьте, видит ли плеер вообще. Выключите плеер, подключите кабель и выполните команду lsusb в терминале. Подключенный плеер отображается как устройство MediaTek с идентификатором поставщика 0e8d.
`lsusb`
  - Если он появляется в lsusb, но Innioasis Updater CE или SP Flash Tool сообщает, что разрешение отклонено или не может открыть порт, у вашего пользователя отсутствует доступ к устройству USB. Одно и то же правило udev распространяется на оба инструмента, поэтому добавьте тот, который позволит группе пользователей читать его.
`SUBSYSTEM=="usb", ATTR{idVendor}=="0e8d", MODE="0666", GROUP="plugdev"`

Сохраните эту строку в новый файл с именем /etc/udev/rules.d/51-innioasis.rules, затем запустите:`sudo udevadm control --reload && sudo udevadm trigger`
  - Полностью отключите плеер от сети, подключите его снова и повторите попытку установки.
  - Если SP Flash Tool сообщает о разрешении последовательного порта или гонке портов, полностью отключите его и подключитесь повторно только при появлении соответствующего запроса.
Не импровизируйте смещения вспышки.Если вы переходите к инструменту восстановления вручную, используйте файлы и конфигурацию для конкретной модели, поставляемые вместе с проектом.

## Кабель и синхронизация
  - Используйте известный кабель передачи данных USB.
  - Избегайте хабов при устранении неполадок.
  - Полностью выключите нужную модель.
  - Подключайтесь только по подсказке.
