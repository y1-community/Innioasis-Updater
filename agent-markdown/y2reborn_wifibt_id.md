# Pengaturan Wi-Fi, Bluetooth &amp; Radio FM untuk Reborn (Y2Linux) - Innioasis Updater

Innioasis Y2 · Reborn Pasca Pemasangan

# Siapkan Wi-Fi, Bluetooth & radio FM.

Salin satu file ke pemutar Anda. Reborn menangani sisanya.[Unduh system.img (860 MB)](https://github.com/y1-community/y1-stock-rom/releases/download/3.2.0-fm/system.img)[Panduan Instalasi](guides/reborn-y2linux-y2.html)[Mengapa Y2Reborn?](reborn-y2linux-benefits_id.html)

## Mengapa file ini?

Wi-Fi, Bluetooth, dan radio FM memerlukan lima modul firmware MediaTek yang Reborn tidak dapat dikirimkan. Mereka berada di dalam Y2 resmi `system.img`. Reborn mengekstraknya satu kali, memeriksanya, dan menghapus file.

## Pengaturan
  - Unduh sistem.img

Unduh FM v3.2.0 `system.img` ke komputer Anda.[ Unduh sistem.img ](https://github.com/y1-community/y1-stock-rom/releases/download/3.2.0-fm/system.img)
  - Boot Reborn sekali

Nyalakan pemutar. Tunggu Menyiapkan penyimpanan untuk menyelesaikan, lalu mulai ulang sekali.
  - Hubungkan ke komputer Anda

Gunakan kabel data USB. Pemain muncul sebagai Penyimpanan Internal.Di Mac?

Instal [BukaMTP](https://openmtp.ganeshrvel.com/) untuk menelusuri pemutar. Windows dan Linux memasangnya secara otomatis.
  - Salin system.img ke Firmware

Buat folder bernama `Firmware` di akar Penyimpanan Internal. Salin `system.img` ke dalamnya.
  - Tunggu hingga pengaturan selesai

Reborn menginstal firmware radio secara otomatis dan menghapusnya `system.img`. Ini membutuhkan waktu sekitar 10–20 detik. Tunggu Wi-Fi dan Bluetooth sudah siap.
  - Hubungkan Wi-Fi, Bluetooth, dan radio FM
    - Wi-Fi: Pengaturan → Sistem → Jaringan → Wi-Fi. Pilih jaringan 2,4 GHz Anda.
    - Bluetooth: Letakkan headphone Anda dalam mode berpasangan. Pengaturan → Bluetooth → pilih.
    - Radio FM: Colokkan headphone berkabel sebagai antena, lalu buka Radio FM.

  - Perbarui melalui Wi-Fi

Pembaruan Reborn di masa mendatang diinstal dari Pengaturan → Sistem → Pembaruan Perangkat Lunak. Firmware radio Anda tetap terpasang.
