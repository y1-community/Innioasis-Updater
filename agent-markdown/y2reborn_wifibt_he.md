# הגדרת Wi-Fi, Bluetooth ורדיו FM עבור Reborn (Y2Linux) - Innioasis עדכון

Innioasis Y2 · Reborn לאחר התקנה

# הגדר Wi-Fi, Bluetooth ורדיו FM.

העתק קובץ אחד לנגן שלך. Reborn מטפל בשאר.[הורד system.img (860 MB)](https://github.com/y1-community/y1-stock-rom/releases/download/3.2.0-fm/system.img)[מדריך להתקנה](guides/reborn-y2linux-y2.html)[למה Y2Reborn?](reborn-y2linux-benefits_he.html)

## למה הקובץ הזה?

Wi-Fi, Bluetooth ורדיו FM זקוקים לחמישה MediaTek מודולי קושחה ש-Reborn לא יכולים לשלוח. הם בתוך הרשמית Y2 `system.img`. Reborn מחלץ אותם פעם אחת, בודק אותם ומוחק את הקובץ.

## הגדרה
  - הורד את system.img

הורד את v3.2.0 FM `system.img` למחשב שלך.[ הורד את system.img ](https://github.com/y1-community/y1-stock-rom/releases/download/3.2.0-fm/system.img)
  - אתחל את Reborn פעם אחת

הפעל את הנגן. חכה ל הגדרת אחסון כדי לסיים, ולאחר מכן הפעל אותו מחדש פעם אחת.
  - התחבר למחשב שלך

השתמש בכבל נתונים USB. השחקן מופיע בתור אחסון פנימי.על מק?

התקן [OpenMTP](https://openmtp.ganeshrvel.com/) כדי לעיין בנגן. Windows ולינוקס מעלים אותו באופן אוטומטי.
  - העתק את system.img לקושחה

צור תיקיה בשם `Firmware` בשורש האחסון הפנימי. העתק `system.img` לתוך זה.
  - המתן לסיום ההגדרה

Reborn מתקין את קושחת הרדיו באופן אוטומטי ומוחק `system.img`. זה לוקח בערך 10-20 שניות. חכה ל Wi-Fi ו-Bluetooth מוכנים.
  - חבר Wi-Fi, Bluetooth ורדיו FM
    - Wi-Fi: הגדרות ← מערכת ← רשת ← Wi-Fi. בחר את רשת 2.4 GHz שלך.
    - בלוטות': שים את האוזניות שלך במצב התאמה. הגדרות ← Bluetooth ← בחר אותן.
    - רדיו FM: חבר אוזניות חוטיות כאנטנה, ואז פתח את רדיו FM.

  - עדכן באמצעות Wi-Fi

התקנה של עדכונים עתידיים Reborn מהגדרות ← מערכת ← עדכון תוכנה. קושחת הרדיו שלך נשארת במקום.
