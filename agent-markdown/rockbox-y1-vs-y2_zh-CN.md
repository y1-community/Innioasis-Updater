# Rockbox-Y1 与 Rockbox-Y2

Rockbox-Y1 和 Rockbox-Y2 是为不同播放器创建的单独固件版本。始终将构建与播放器上打印的型号相匹配。[Rockbox-Y1安装](rockbox-y1/install.html)[Rockbox-Y2安装](rockbox-y2/install.html)[两个 ROM 下载](rockbox-rom-download_zh-CN.html)

## 为什么首先选择模型很重要

尽管两个版本都运行 Rockbox，但 Innioasis Y1 和 Y2 具有不同的硬件和分区布局。切勿在 Y2 上闪烁 Y1 ROM 或在 Y1 上闪烁 Y2 ROM。

Innioasis 更新程序 CE 通过在您选择后立即过滤可用软件来防止不匹配 Y1 或 Y2 在 设备型号。 Updater CE 始终直接从社区固件开发人员的版本下载选定的软件包（开发人员全权负责在 Updater CE 中列出其版本）。

## 您需要哪个指南？
  - Innioasis Y1 — 前往 [Rockbox-Y1 轮毂](rockbox-y1/)。选择 Type A（对于附带 2.0.0+ 版本的玩家）或 Type B（对于较旧的设备），然后选择 240p 或 360p 版本。
  - Innioasis Y2 — 前往 [Rockbox-Y2 轮毂](rockbox-y2/)。在 Updater CE 中选择 Y2 并选择最新的 Y2 版本。

## 两个端口共享什么

两者都带来了 Rockbox 基于标签的音乐数据库、无缝播放、均衡器、自定义主题以及 100% 离线聆听播放器。读 [为什么Rockbox](rockbox-benefits_zh-CN.html) 看看 Rockbox 在工厂软件上添加了什么。[Y1 的 Rockbox](rockbox-for-y1_zh-CN.html)[Y2 的 Rockbox](rockbox-for-y2_zh-CN.html)[Rockbox 概述](rockbox_zh-CN.html)
