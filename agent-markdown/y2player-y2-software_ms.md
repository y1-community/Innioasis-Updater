# Install Y2Player on the Y2.

Y2Player is built for the Y2. Pick your model first so you don't accidentally use a Y1 package.[Open the full Y2Player guide](guides/y2player-y2.html)[Dapatkan ini dalam Updater CE](guide_ms.html?model=Y2&software=y2player-y2)[Mengapa Y2Player?](y2player-benefits_ms.html)

Pilih panduan untuk komputer yang anda gunakan. Setiap versi mempunyai persediaan platform, Updater CE langkah dan jalan kembali ke stok.[Panduan Windows](install/y2player-y2-windows.html)[panduan macOS](install/y2player-y2-mac.html)[Panduan Linux](install/y2player-y2-linux.html)

## Y2Player install steps
  - Buka Innioasis Updater CE pada komputer anda (jika anda memerlukan apl itu, [Dapatkan Updater CE](guide_ms.html#platform)). Tetapkan Model Peranti kepada Y2.
  - pilih Y2Player dalam Perisian.
  - Choose a release listed for Y2.
  - klik Pasang / Pulihkan.
  - Power off and connect the Y2 at the live prompt.

Some Y2 full-install packages use `rom_y2.zip`. Let Updater choose the package when possible.

## Soalan LazimCan I go back to the original software?

Yes. Select Y2 and Original Software in Updater CE, then follow the [Panduan pemulihan Y2](original-software-y2_ms.html).Can I use this on a Y1?

No. This page is for the Y2Player Y2 entry. Keep Y1 and Y2 packages separate.What if the Y2 is not detected?

Check platform setup, cable, power-off state, model selection, and timing. Use [penyelesaian masalah](troubleshooting_ms.html) before trying manual recovery.
