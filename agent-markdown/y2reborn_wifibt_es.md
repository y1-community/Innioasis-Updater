# Configuración de Wi-Fi, Bluetooth y radio FM para Reborn (Y2Linux) - Innioasis Actualizador

Innioasis Y2 · Reborn Postinstalación

# Configure Wi-Fi, Bluetooth y radio FM.

Copie un archivo a su reproductor. Reborn se encarga del resto.[Descargar system.img (860 MB)](https://github.com/y1-community/y1-stock-rom/releases/download/3.2.0-fm/system.img)[Guía de instalación](guides/reborn-y2linux-y2.html)[¿Por qué Y2Reborn?](reborn-y2linux-benefits_es.html)

## ¿Por qué este archivo?

Wi-Fi, Bluetooth y radio FM necesitan cinco módulos de firmware MediaTek que Reborn no se pueden enviar. Están dentro del oficial Y2 `system.img`. Reborn los extrae una vez, los verifica y elimina el archivo.

## Configuración
  - Descargar sistema.img

Descarga la v3.2.0 FM `system.img` a tu computadora.[ Descargar sistema.img ](https://github.com/y1-community/y1-stock-rom/releases/download/3.2.0-fm/system.img)
  - Arranque Reborn una vez

Enciende el reproductor. Esperar Configurar el almacenamiento para finalizar, luego reinícielo una vez.
  - Conéctate a tu computadora

Utilice un cable de datos USB. El jugador aparece como Almacenamiento interno.¿En una Mac?

Instalar [AbiertoMTP](https://openmtp.ganeshrvel.com/) para navegar por el reproductor. Windows y Linux lo montan automáticamente.
  - Copie system.img al firmware

Crea una carpeta llamada `Firmware` en la raíz del almacenamiento interno. Copiar `system.img` en ello.
  - Espere a que finalice la configuración

Reborn instala el firmware de la radio automáticamente y elimina `system.img`. Esto tarda entre 10 y 20 segundos. Esperar Wi-Fi y Bluetooth están listos.
  - Conecta Wi-Fi, Bluetooth y radio FM
    - Wifi: Configuración → Sistema → Red → Wi-Fi. Elija su red de 2,4 GHz.
    - Bluetooth: Pon tus auriculares en modo de emparejamiento. Configuración → Bluetooth → selecciónelos.
    - Radio FM: Conecte unos auriculares con cable como antena y luego abra la radio FM.

  - Actualización a través de Wi-Fi

Las actualizaciones futuras Reborn se instalan desde Configuración → Sistema → Actualización de software. El firmware de su radio permanece fijo.
