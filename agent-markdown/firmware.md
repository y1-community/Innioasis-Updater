## Install your choice with Updater CE
  - Open the guide and install Innioasis Updater CE for your computer if you do not have it yet.
  - In Updater CE, select the model printed on your player from Device Model.
  - From Software, select the software you want to run on that model.
  - Select a release, click Install / Restore, then power off and connect the player only when Updater CE asks.

Need the installer? [Open the guide and expand the Updater CE download section](guide.html#download-updater).

## The safe way back

### Check the model

Y1 and Y2 software is not interchangeable. Re-select the model in Updater CE and start again.

### Wait for the prompt

Power the player fully off and connect it only when Updater CE says it is ready.

### Restore Original Software

Choose Original Software for the same model. If manual recovery is needed, open the [troubleshooting guide](troubleshooting.html) first.

## Supported Devices and Official Stock Firmware

The Innioasis Firmware Archive hosts verified stock firmware, original factory restore images, and custom operating systems for portable players:

### Innioasis Y1 & Y2

Official software and custom systems including Rockbox, Better-Y, and Solar.

### Innioasis G1, G3 & G5

### Innioasis R1 & PR1

### Timmkoo Q5 & Q3

Packages provided for Timmkoo players via Updater CE.

New releases appear here as soon as they are verified.

## Which tool should I use?

Innioasis Updater CE is the recommended tool for daily updates and community OS installs across Windows, macOS, and Linux. Flashing through Updater CE preserves your library and pairings.

The legacy Universal Flash Tool remains available for emergency unbricking when a device cannot boot into fastboot.[Compare flashing tools](updater-comparison.html)
