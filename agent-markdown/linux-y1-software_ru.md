## Linux Y1 шаги по установке
  - Откройте Innioasis Updater CE на своем компьютере (если вам нужно приложение, [Скачать Updater CE](guide_ru.html#platform)). Набор Модель устройства в адрес Y1.
  - Выбирать Linux для Y1 (Дев) в Программное обеспечение.
  - Выберите выпуск, указанный для Y1.
  - Нажмите Установить / Восстановить.
  - Выключите питание и подсоедините Y1 только тогда, когда появится запрос Updater CE.

## Вопросы и ответыМогу ли я восстановить стандартное программное обеспечение Y1?

Да. Выберите Y1 и оригинальное программное обеспечение в Updater CE. [Y1 руководство по стандартному программному обеспечению](original-software-y1_ru.html) перекрывает обратный путь.Это повседневный пользовательский интерфейс?

Это экспериментальный порт для разработчиков и любителей Linux. Инструкции по терминалу и консоли находятся в документации проекта.
