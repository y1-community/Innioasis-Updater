## Controls

Most controls are identical to the iPod 6G, refer to this [manual](https://download.rockbox.org/daily/manual/rockbox-ipod6g.pdf)

Exceptions:
  - Center (Short): Accept / Enter
  - Center (Long): Open Context Menu
  - Center (Very Long): Turn Off Screen
  - Play/Pause (Short, Text Input): Open Keyboard
  - Holding Next + Previous (>10 seconds): Restart Rockbox (Thanks, u/thinkVHS!)
  - FM Radio App:
    - Back/Menu: Return to Rockbox
    - Previous: Left
    - Next: Right
    - Play/Pause (Short): Down
    - Play/Pause (Long): Up
    - Touch Wheel: Volume

## How to switch between Rockbox and Stock

The bundled ROM allows you to switch between Rockbox and a modified version of [better-Y](https://innioasis.app/firmware.html?model=Y1&software=better-y-y1) (an improved mod of the Stock interface)

### In Rockbox
  - Main Menu > System > Switch to Stock Firmware

### In Stock
  - Main Menu > Settings > Back to Rockbox

This fork adds a plugin to fetch and download your podcasts using the built-in wifi chip. For more information, follow this [guide.](https://innioasis.app/post_install.html?url=https%3A%2F%2Fgithub.com%2Frockbox-y1%2Frockbox%2Fblob%2FHEAD%2FINTERNET.md%23podcasts&anchor=podcasts)

## Scrobbling: Last.fm, ListenBrainz, Maloja,...

This fork extends the Last.fm plugin to upload scrobbles to your favorite platform using the built-in wifi chip.
