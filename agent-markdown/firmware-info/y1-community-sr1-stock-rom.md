# Timmkoo SR1 original software

Archived original (stock) firmware for the Timmkoo SR1, published here so a player can always be restored to the software it shipped with. Every release tag is the package's own build name from Innioasis.

## Download

Each release carries `rom_sr1.zip`. Unzip it and flash it with SP Flash Tool using the scatter file inside the archive, or install it with Innioasis Updater CE once the model is listed there.

The archive index for every bundled model is at

[https://innioasis.app/firmware.html?model=SR1](https://innioasis.app/firmware.html?model=SR1).

## Notes
  - These are unmodified manufacturer images. No root, no repack.
  - Flashing erases the player. Back up music first.
  - Always use the scatter file that ships inside the same release.

Maintained by the Innioasis community. Updater CE and this archive are independent community projects.
