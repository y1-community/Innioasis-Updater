# Innioasis Updater is the official firmware installation tool for the Innioasis Y1, built by Y1 users, for Y1 users. To get started with Innioasis Updater, or if you're looking for firmware downloads or updates for another Innioasis device, please head to [https://innioasis.app/guide.html](https://innioasis.app/guide.html)

[Innioasis Updater Screenshot](https://innioasis.app)

# Innioasis UpdaterInnioasis Updater Icon Innioasis Updater is an easy, one-click firmware installer for the Innioasis Y1 MP3 player running Android firmwares. It lists official software updates as well as community built firmwares.

## Installing on Linux (Not officially supported - you're on you're own)

Please clone the repo on your linux system and follow the [MTKclient setup instructions](https://github.com/bkerler/mtkclient), once you've completed the setup process for MTKclient, simply open a terminal window, change into the directory you cloned Innioasis Updater into and run the command below.`python updater.py`
