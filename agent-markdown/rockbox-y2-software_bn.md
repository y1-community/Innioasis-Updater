## Rockbox Y2 install steps
  - আপনার কম্পিউটারে Innioasis Updater CE খুলুন (যদি আপনার অ্যাপটির প্রয়োজন হয়, [Updater CE নিন](guide_bn.html#platform)) সেট ডিভাইস মডেল থেকে Y2.
  - বেছে নিন Rockbox মধ্যে সফটওয়্যার.
  - Choose a release explicitly listed for Y2.
  - ক্লিক করুন ইনস্টল / পুনরুদ্ধার and wait for package preparation.
  - পাওয়ার বন্ধ করুন এবং শুধুমাত্র Updater CE বললেই Y2 কানেক্ট করুন।

Do not force a Y1 package because the project name looks the same. If no Y2 release appears, stop and check the model and current release data.
