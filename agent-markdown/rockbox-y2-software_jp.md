## Rockbox Y2 のインストール手順
  - コンピューターで Innioasis Updater CE を開きます (アプリが必要な場合は、 [Updater CE を入手](guide_ja.html#platform)）。セット デバイスモデル 支援先: Y2.
  - 選択してください Rockbox で ソフトウェア.
  - Y2 に明示的にリストされているリリースを選択してください。
  - クリック インストール / 復元 そしてパッケージの準備を待ちます。
  - Updater CE が要求した場合にのみ、電源をオフにして Y2 を接続してください。

プロジェクト名は同じに見えるため、Y1 パッケージを強制しないでください。 Y2 リリースが表示されない場合は、停止してモデルと現在のリリース データを確認してください。

## よくある質問後で元の Y2 ソフトウェアを復元できますか?

はい。 Y2 を選択し、Updater CE でオリジナル ソフトウェアを選択します。を参照してください。 [Y2 ストック ソフトウェア ページ](original-software-y2_ja.html) 復元シーケンスの場合。パッケージが rom_y2.zip と呼ばれるのはなぜですか?

これは、一部の Y2 フルインストール リリースで使用される手動ダウンロードの手掛かりです。より安全な選択は、Updater CE で Y2 を選択し、そこに表示されるリリースを使用することです。Y1 Rockbox チュートリアルを使用できますか?

広い意味でのみ使用してください。パッケージとモデルの選択については、これに従ってください [Y2 固有のガイド](guides/rockbox-y2.html).
