## Koensayr Y1 install steps
  - Open Innioasis Updater CE on your computer (if you need the app, [Szerezze be az Updater CE-t](guide_hu.html#platform)). Set Device Model to Y1.
  - Choose Koensayr in Software.
  - Choose the listed Y1 release.
  - Click Install / Restore.
  - Power off and connect the Y1 only when Updater CE asks.

## FAQsCan I restore the original Y1 software?

Yes. Select Y1 and Original Software in Updater CE. See the [Y1 stock-software page](original-software-y1_hu.html) for the complete restore route.What should I check when it fails?

Check the model, release, cable, platform setup, and whether the player was connected before the prompt. Then use [troubleshooting](troubleshooting_hu.html).Is there a Koensayr Y2 package?

The current build is for Y1. Don't use it on a Y2 unless the project publishes a separate release for it.
