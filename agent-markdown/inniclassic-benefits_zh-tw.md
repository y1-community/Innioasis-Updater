# 為什麼 Inniclassic 適合你的 Innioasis Y1 和 Y2

Inniclassic 使 iPod Classic 回歸。菜單、平移專輯封面、點擊輪感覺，甚至還有音樂測驗。全部在 Y1 和 Y2 上，採用現代格式。[在更新程式中取得 Inniclassic](guide_zh-TW.html?model=Y1&software=inniclassic-y1)[Y1安裝頁面](inniclassic-y1-software_zh-TW.html)[Y2安裝頁面](inniclassic-y2-software_zh-TW.html)

## 型號可用性

哪些 Innioasis 型號運行它？[Y1 · 可用](inniclassic-y1-software_zh-TW.html)[Y2 · 可用](inniclassic-y2-software_zh-TW.html)

一個維護的項目發布了兩種型號的構建，每種型號都有一個單獨的包 - 在軟體下載中獲取為您的播放器製作的包，並且永遠不要將其中一個替換為另一個。

## 為什麼人們選擇它

經典，回到你的手中。
  - 1:1 iPod 經典外觀 — 純文字選單、系統相符的粗體和螢幕名稱狀態列 — 包括淺色和深色主題變體。
  - 封面瀏覽 — 兩窗格選單，帶有緩慢平移的專輯封面，一直延伸到螢幕頂部，就像真實的東西一樣。
  - 真正的音樂測驗 — 使用您自己的庫進行從頭開始的遊戲：5 輪，共 8 個問題，帶有回合和勝利畫面。
  - 同步歌詞 — 來自 .lrc 檔案或嵌入標籤的時間同步滾動歌詞，直接從「正在播放」切換。
  - 播放您擁有的一切 — MP3、FLAC、WAV、OGG Vorbis、Opus、ALAC/M4A 和 AAC — 復古面貌下的現代編解碼器。
  - 廣播、播客、影片、有聲讀物 — 透過硬體調諧器收聽 FM 廣播、播客訂閱、全螢幕影片和添加書籤的有聲讀物。

## 社群

社區怎麼說

Inniclassic 建立在 JJ Launcher 的媒體引擎之上，因此它具有成熟的基礎。每個版本都增加了一些改進，使其感覺像是真實的東西。

由於它直接建構在 JJ Launcher 的媒體引擎上，Inniclassic 繼承了成熟的基礎，同時在經典細節上進行了分層。該專案的發布記錄了一系列旨在實現一個目標的改進：使其感覺像真實的東西，只有使用 FLAC。
  - [r/innioasis · Inniclassic 線程](https://www.reddit.com/r/innioasis/)

## 該項目提供什麼
  - 捆綁 iPod Classic 主題（淺色 + 深色），旨在實現 1:1 外觀
  - 兩窗格主選單和帶有 Ken Burns 專輯封面的音樂選單
  - 重新設計的《Now Playing》採用有角度的反光封面和長標題字幕
  - 中心點擊循環“進度”→“搜尋”→“隨機播放和重複”→“評級”，就像真正的經典一樣
  - 隨身播放清單和長按「正在播放」保留選單
  - 在每個按字母順序排列的清單上快速滾動字母跳躍
  - 帶有心形指示器的收藏夾
  - 從 .lrc 檔案或 ID3/FLAC/ALAC 標籤同步歌詞
  - 寬格式支援：MP3、FLAC、WAV、OGG Vorbis、Opus、ALAC/M4A、AAC
  - Last.fm scrobbling — 自動本機記錄日誌，選用帳戶同步
  - 播客、透過真實硬體調諧器播放的 FM 廣播、透過 libVLC 播放的影片以及可恢復的有聲讀物
  - 透過 Wi-Fi 無線 PC 上傳

## 首先要知道的事情
  - 兩款型號均可用 — Y1 需要 rom.zip (Type A) 或 rom_type_b.zip (Type B) 和 Y2 取 rom_y2.zip;這三個都來自同一個項目
  - 方法 1 隨附 Y1 軟體 3.1.2，其中包含 Inniclassic；方法 2 在現有 JJ Launcher 安裝上安裝 APK（先卸載）
  - 在隨機播放關閉且佇列中沒有 FLAC 的情況下，為包含 15 個或更少曲目的播放清單啟動無縫播放
  - 保持視訊檔案適度（640×480、30fps、~2 Mbps 或更少）以實現流暢播放
  - 仍然是一個社區專案 - 如果出現任何問題，請恢復原始軟體
