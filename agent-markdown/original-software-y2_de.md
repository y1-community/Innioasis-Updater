## Installieren oder wiederherstellen Sie es mit Updater

Richten Sie zuerst den Computer ein und lassen Sie dann Updater das zum Modell passende Paket vorbereiten.
  - Öffnen Sie Innioasis Updater CE auf Ihrem Computer (wenn Sie die App benötigen, [Updater CE holen](guide_de.html#platform)). Satz Gerätemodell an Y2.
  - Wählen Sie Original-Software und eine Y2-Veröffentlichung.
  - Klicken Sie Installieren / Wiederherstellen.
  - Schalten Sie den Y2 nur dann aus und schließen Sie ihn an, wenn Sie in der Live-Eingabeaufforderung dazu aufgefordert werden.

Es können manuelle Vollinstallationspakete verwendet werden `rom_y2.zip`. Behandeln Sie kein Y1 `rom.zip` als Ersatz.

## FAQKann ich von Rockbox oder einer anderen benutzerdefinierten Software zurückkehren?

Verwenden Sie denselben Y2-Wiederherstellungsablauf: Wählen Sie Y2, wählen Sie Originalsoftware und folgen Sie der Verbindungsaufforderung. Mischen Sie keine Modelldateien.Warum sieht das Paket Y2 anders aus?

Y2-Releases können einen anderen Paketnamen und einen anderen Release-Eintrag verwenden. Wählen Sie Y2 im Updater, anstatt anhand eines manuellen ZIP-Dateinamens zu raten.Was passiert, wenn der Player nicht erkannt wird?

Überprüfen Sie das Datenkabel, die Computerberechtigungen oder Treiber und das Timing. Schließen Sie das ausgeschaltete Y2 erst an, wenn der Updater meldet, dass es bereit ist.
