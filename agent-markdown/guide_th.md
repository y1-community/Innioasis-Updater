# เริ่มต้นใช้งาน Innioasis Updater CE | ติดตั้งหรือกู้คืนเฟิร์มแวร์บนเครื่องเล่น Innioasis หรือ Timmkoo - Innioasis Updater

# เริ่มต้นใช้งาน Innioasis Updater CE

ใช้งานได้กับเครื่องเล่นเสียง Innioasis และ Timmkoo ทั้งหมด ติดตั้ง Innioasis Updater CE บนคอมพิวเตอร์ของคุณ เลือกรุ่นและซอฟต์แวร์ที่คุณต้องการ จากนั้นปฏิบัติตามคำแนะนำ

## รับ Innioasis Updater ซีอี

Innioasis Updater ส.ค เป็นแอปที่ติดตั้งการอัปเดตอย่างเป็นทางการและซอฟต์แวร์ชุมชนบนเครื่องเล่นของคุณ มันเก็บเพลงและการตั้งค่าของคุณไว้ และทำงานบน Windows, macOS และ Linux

### Windows

ดาวน์โหลดตัวติดตั้ง รัน จากนั้นรีสตาร์ทพีซีของคุณเมื่อเสร็จสิ้น[รับไดรเวอร์](https://github.com/y1-community/supplemental-apks/releases/latest/download/DriverInstall.exe)[ดาวน์โหลด Updater CE](https://github.com/y1-community/Innioasis-Updater/releases/latest/download/installer.exe)

หาก Windows หยุดคุณไม่ให้เรียกใช้แอปหรือไม่เปิดใช้งาน โปรดเปิดการตั้งค่า คลิกความเป็นส่วนตัวและความปลอดภัย → ความปลอดภัยของ Windows → การควบคุมแอปและเบราว์เซอร์ และปิดการควบคุมแอปอัจฉริยะ การควบคุมแอปอัจฉริยะในปัจจุบันส่งผลกระทบต่อแอปพลิเคชันยอดนิยม เช่น Epic Overlay Service (ใช้โดย Fortnite) — Updater CE ปลอดภัยและได้รับการตรวจสอบแล้วว่าใช้งานได้ [Windows จะไม่เปิดแอปใช่ไหม ช่วย](#smart-app-control)

รีสตาร์ทพีซีของคุณหลังการติดตั้ง ระบบช่วยเหลือผู้ขับขี่อยู่ใน [บันทึกการตั้งค่า Windows](drivers_th.html#windows).

### macOS[ดาวน์โหลด Updater CE](https://github.com/y1-community/Innioasis-Updater/releases/latest/download/Innioasis.Updater.for.Mac.dmg)

หาก Mac ของคุณหยุดไม่ให้คุณเรียกใช้แอพเป็นครั้งแรก โปรดเปิดการตั้งค่าระบบ คลิกความเป็นส่วนตัวและความปลอดภัย เลื่อนลงไปที่ความปลอดภัยแล้วคลิก [เปิดยังไงก็ได้](https://support.apple.com/en-gb/102445#openanyway). คุณยังสามารถกด Control ค้างไว้แล้วคลิก (หรือคลิกขวา) แอพใน Finder แล้วเลือกเปิด

ใช้งานได้บน Intel และ Apple Silicon Mac ที่มี macOS Monterey และใหม่กว่า

### Linux

ดาวน์โหลด AppImage สำหรับระบบ Intel และ AMD ทำให้สามารถปฏิบัติการได้ และเปิดใช้งาน[ดาวน์โหลด AppImage สำหรับ Intel/AMD](https://github.com/y1-community/innioasis-updater/releases/latest/download/UpdaterCE.AppImage)

[บันทึกการตั้งค่า Linux](drivers_th.html#linux)แพลตฟอร์มอื่น?

คุณต้องมีเครื่องเล่น สายเคเบิลข้อมูล USB ที่รองรับข้อมูล (ไม่สามารถติดตั้งสายเคเบิลแบบชาร์จอย่างเดียวได้) และใช้เวลาสักครู่ เชื่อมต่อสายเคเบิลไว้จนกว่า Updater CE จะแจ้งว่าเสร็จสิ้น

## เลือกรุ่นและซอฟต์แวร์ของคุณ
  - รุ่นอุปกรณ์: เลือกรุ่นที่พิมพ์บนเครื่องเล่น Y1 หรือ Y2. ซอฟต์แวร์ที่สร้างขึ้นสำหรับรุ่นหนึ่งไม่สามารถติดตั้งบนอีกรุ่นได้
  - ซอฟต์แวร์และรุ่น: เลือกซอฟต์แวร์ต้นฉบับ, Rockbox, Solar, JJ Launcher, Inniclassic, Y2Player หรือ Koensayr เมื่ออยู่ในรายการสำหรับรุ่นของคุณ จากนั้นเลือกรุ่น ความมั่นคงคือทางเลือกที่ปลอดภัย
  - ติดตั้ง: คลิก ติดตั้ง / คืนค่าปิดเครื่องเล่นจนสุด และเชื่อมต่อสายเคเบิล USB เมื่อ Updater CE ถามเท่านั้น
  - เสร็จ: ปล่อยให้เครื่องเล่นและสายเคเบิลอยู่ตามลำพังจนกระทั่งข้อความแสดงความสำเร็จ จากนั้นถอดการเชื่อมต่อและเริ่มการทำงานของเครื่องเล่น

Y1 ผู้เล่นที่จัดส่งมาพร้อมกับซอฟต์แวร์ต้นฉบับก่อนความต้องการ 2.0.0 อุปกรณ์ Type B. คนอื่นๆ คงค่าเริ่มต้น Type A ไว้คำแนะนำการเชื่อมต่ออัพเดตสำหรับการเชื่อมต่อเครื่องเล่นที่ปิดอยู่ปฏิบัติตามข้อความแจ้งเตือนสด Updater CE สำหรับโมเดลของคุณ

## กลับไปที่ซอฟต์แวร์ดั้งเดิม

ซอฟต์แวร์ที่กำหนดเองสามารถย้อนกลับได้ ใน Updater CE เลือกรุ่นของคุณ เลือก ซอฟต์แวร์ดั้งเดิมเลือกรุ่นเสถียรแล้วรัน ติดตั้ง / คืนค่า แบบเดียวกัน ไม่มีอะไรจะลบด้วยมือ[คู่มือการคืนค่า Y1](guides/restore-original-y1.html)[คู่มือการคืนค่า Y2](guides/restore-original-y2.html)

หากแฟลชหยุดก่อนข้อความ USB ให้ตรวจสอบสายเคเบิล การตั้งค่าแพลตฟอร์ม และรุ่นก่อน ดู [การแก้ไขปัญหา](troubleshooting_th.html) สำหรับการแก้ไข [คำแนะนำการกู้คืน Y1 และ Y2](guides/recovery.html) สำหรับความผิดปกติของระบบไฟฟ้าและล้อ และ [SP Flash Tool](sp-flash-tool_th.html) เพื่อการฟื้นฟูขั้นสูง

## Windows จะไม่เปิดแอปใช่ไหม วิธีแก้ปัญหาการควบคุมแอปอัจฉริยะ

Windows Defender SmartScreen หรือ Smart App Control สามารถบล็อกแอปพลิเคชันชุมชนที่ดาวน์โหลดใหม่ก่อนที่จะเผยแพร่ชื่อเสียงของลายเซ็น ขณะนี้การควบคุมแอปอัจฉริยะกำลังส่งผลกระทบต่อแอปพลิเคชันยอดนิยม เช่น Epic Overlay Service (ใช้โดย Fortnite) — Updater CE ปลอดภัยและตรวจสอบแล้วว่าใช้งานได้ การปิดการควบคุมแอปอัจฉริยะทำให้ Updater CE สามารถเปิดและทำงานได้ตามปกติ
  - เปิด การตั้งค่า บนพีซี Windows ของคุณ (กด Win + I).
  - คลิก ความเป็นส่วนตัวและความปลอดภัย ในแถบด้านข้างซ้าย จากนั้นคลิก Windows Security.
  - คลิก การควบคุมแอปและเบราว์เซอร์.
  - ภายใต้ การควบคุมแอปอัจฉริยะคลิก การตั้งค่าการควบคุมแอปอัจฉริยะ.
  - ตั้งค่าสลับเป็น ปิด เพื่อให้ Updater CE สามารถเปิดใช้งานได้

ดาวน์โหลดผ่าน Edge? หาก Edge บล็อกการดาวน์โหลดเอง ให้คลิกปุ่มตัวเลือกเพิ่มเติม (…) → เก็บ → แสดงเพิ่มเติม → ยังไงก็เก็บไว้.

เปิดใช้งานการควบคุมแอปอัจฉริยะอีกครั้งในภายหลัง: เมื่อคุณต้องการเปิด Smart App Control อีกครั้ง คุณสามารถเปิดใช้งานได้อีกครั้งผ่านทาง Windows Registry ที่อยู่ด้านล่าง `HKEY_LOCAL_MACHINE\SYSTEM\CurrentControlSet\Control\CI\Policy` โดยการตั้งค่า `VerifiedAndReputablePolicyState` ถึง `1` (เปิด) หรือ `2` (โหมดการประเมินผล) และรีสตาร์ท
