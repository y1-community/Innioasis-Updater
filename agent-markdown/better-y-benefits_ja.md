# なぜ Better-Y が Innioasis Y1 なのか | Better-Y の特典 - Innioasis ファームウェアのダウンロード

カスタム ソフトウェア · Better-Y

# Innioasis Y1 に Better-Y を選択する理由

Better-Y は、改良されたストック プレーヤーです。 Leska1337 によって公式 3.1.2 ソフトウェア上に構築されました。タグ、トラック番号、キャッシュと再生コントロールが修正され、見慣れた外観、ホイール、テーマが維持されます。[アップデーターで Better-Y を取得](firmware_ja.html?model=Y1&software=better-y-y1)[Y1 インストールページ](better-y-y1-software_ja.html)[Y1 の完全なチュートリアル](guides/better-y-y1.html)[プロジェクトソース](https://github.com/Leska1337/better-Y)

## モデルの入手可能性

どの Innioasis モデルで実行されますか?[Y1 (Type A) · 利用可能](better-y-y1-software_ja.html)Y2 · 利用できません

Better-Y は Innioasis Y1 (Type A ハードウェア) 用に作成されています。 Y1 ビルドと Y2 ビルドは別個であるため、一方を他方と交換しないでください。

## 人々がそれを選ぶ理由

株式に関して気に入ったものはすべて揃っており、奇抜な点はありません。
  - 番号が属する場所を追跡する — アルバム ビューには最終的にトラック番号が表示されるため、アルバムは任意の並べ替えではなく、意図したトラックリストの順序で再生および表示されます。
  - インテリジェントなタグ分割 — マルチアーティストの曲 (カンマまたはセミコロンで区切られている) は、個々のアーティストの下に表示されます。複数のジャンルのタグ (カンマ、セミコロン、またはスラッシュで区切られた) が、一致するすべてのジャンルの下に表示されます。
  - ファイル名上の ID3 メタデータ — 曲のタイトル、アルバム、アーティストは、生のファイル名を表示するのではなく、ID3 タグから適切に読み取られます。
  - インタラクティブ コントロールを再生中 — お気に入り (ハート)、シャッフル切り替え、リピート モード (1 つ/すべて/オフ)、歌詞、A-B リピート ループ、再生キュー、ブックマークの位置、速度コントロール、スリープ タイマー用の直接画面上のアイコン。
  - スムーズでちらつきのない RAM キャッシュ — 完全に作り直された画像キャッシュ エンジンにより、大規模な音楽ライブラリをスクロールする際の UI の点滅、ちらつき、遅延が解消されます。
  - 公式 3.1.2 基盤 — 最新の 3.1.2 ベースに構築されており、公式の Apple AirPods 接続修正を維持しながら、すべてのカスタム ストック テーマとの 100% の互換性を維持します。

## コミュニティとリリース

コミュニティの意見

Better-Y は、r/innioasis サブレディットで議論されている日常のユーザビリティの問題に正確に対処するために、開発者 Leska1337 によって作成されました。 Better-Y は、システムを別の OS に置き換えるのではなく、ユーザーがすでに知っていて気に入っているネイティブ プレーヤー エクスペリエンスを完璧にします。

人々は、その親しみやすさを気に入っています。テーマ ギャラリーの既存のテーマは引き続き機能し、プレイリストと Bluetooth は標準品のように動作し、ナビゲーションが著しく高速になります。
  - [r/innioasis · Better-Y v1.0.0 リリース ディスカッション](https://www.reddit.com/r/innioasis/comments/1w6wt7i/bettery_v100_release_stock_launcher_but_better/)
  - [Leska1337/better-Y ソース](https://github.com/Leska1337/better-Y)

## プロジェクトが提供するもの
  - アルバムトラックリストにトラック番号が直接表示される
  - カンマ (,) とセミコロン (;) による複数アーティストのタグ分割
  - カンマ (,)、セミコロン (;)、スラッシュ (/) による複数ジャンルのタグ分割
  - コンピレーション、トリビュート、およびフィーチャーに対するフル アルバム アーティスト タグのサポート
  - 外部カバーアートのサポート (自動検出) `cover.jpg`, `cover.png`, `folder.jpg`)
  - マルチディスクリリースのディスク番号表示 (CD 1、CD 2、ビニール面)
  - インタラクティブな再生中アイコン (お気に入り、シャッフル、リピート、歌詞、A-B ループ、キュー、ブックマーク、スピード、スリープ タイマー)
  - 自動切り抜き/塗りつぶしと傾き修正/切り替えを備えた、より大きなアルバム アートワークのプレゼンテーション
  - 長いトラックタイトルやアーティスト名のスムーズなマーキーテキスト自動スクロール
  - 歌詞行のオーバーフローとテキスト切り捨てのバグを修正
  - 大規模な図書館での迅速なホイール ナビゲーションのためのアルファベット順の高速スクロール インデックス バー
  - 選択カーソルは自動的に記憶され、現在再生中のトラックを追跡します。
  - アーティスト ビューでは、すべての曲をフラット リストにダンプするのではなく、最初にアルバムが表示されます。
  - フォルダービューに「すべての曲を表示」ボタンと「シャッフル」ボタンが追加されました
  - デフォルトの閲覧ショートカットは直接ジャンプします `/Music/` そして `/Videos/`
  - 再生/一時停止ハードウェア ボタンを 2 回押すと、どの画面からでも再生中に直接ジャンプします。
  - アルバムをリリース年ごとに並べ替えます。プレイリストを追加日で並べ替える
  - 高速RAMイメージキャッシュエンジンによりリストのちらつきを解消
  - インスタント「ライブラリ更新」オプションを備えた高速ライブラリ スキャナ
  - フォルダー内の最後の曲が削除されたときの空の親ディレクトリの自動クリーンアップ
  - 検索を容易にする Caps Lock と Case Switch を備えた 3 レイアウトのオンスクリーン キーボード
  - 歌詞表示中および読み上げ表示中のディスプレイキープアウェイク設定
  - ハードウェア緊急再起動ショートカット (上下のボタンを同時に押し続ける)

## 最初に知っておくべきこと
  - Innioasis Y1 (Type A ハードウェア) 専用に構築されています - Y2 にフラッシュしません
  - すべてのカスタムテーマおよびストック設定との完全な互換性を維持します
  - Updater CE 経由で Y1 オリジナル ソフトウェアをフラッシュすることで、いつでも完全に元に戻すことができます
  - フラッシュする前にリリース ノートを確認し、モデルを確認してください

## 始めましょう

Updater CE で Y1 を選択し、Better-Y を選択して安定したリリースを選択し、プロンプトが表示されたら電源がオフのプレーヤーを接続します。ステップバイステップのガイドでは、プロセス全体が説明されています。[Better-Y のリリースを参照する](firmware_ja.html?model=Y1&software=better-y-y1)[Y1 インストールの概要](better-y-y1-software_ja.html)[Y1 の完全なチュートリアル](guides/better-y-y1.html)
