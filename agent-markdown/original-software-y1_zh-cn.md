## 使用更新程序安装或恢复它

无论 Y1 当前正在运行其原始软件还是社区项目，更新程序都使用相同的引导流程。
  - 在您的计算机上打开 Innioasis Updater CE（如果您需要该应用程序， [获取 Updater CE](guide_zh-CN.html#platform)）。套装 设备型号 至 Y1.
  - 选择 原厂软件 在 软件 （或使用 [在 Updater CE 中获取](guide_zh-CN.html?model=Y1&software=original-y1) 跳转到引导步骤）。
  - 点击 安装 / 恢复 并让应用程序准备包。
  - 仅当实时提示询问时才关闭电源并连接 Y1。

手动下载时，通常的完整安装包名为 `rom.zip`。 Updater 中的模型选择是选择文件的更安全的方式。

## 常见问题我可以从 Rockbox 或其他自定义软件恢复吗？

是的，使用 Y1 模型和 Y1 原始软件路径。不要先删除系统文件，也不要替换 Y2 包。如果我的 Y1 没有被检测到怎么办？

检查数据线、计算机设置和连接时间。仅应在出现更新程序提示时关闭播放器并连接。我的 Y1 应该使用哪个包？

将模型打印在更新程序中选择的播放器上。 Y1 和 Y2 包是独立的 - 如果发布列表与您的型号不匹配，请停止。
