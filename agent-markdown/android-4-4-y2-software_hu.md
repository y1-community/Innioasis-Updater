## Android 4.4 Y2 install steps
  - Open Innioasis Updater CE on your computer (if you need the app, [Szerezze be az Updater CE-t](guide_hu.html#platform)). Set Device Model to Y2.
  - Choose Android 4.4 (Dev) in Software.
  - Choose the release listed for Y2.
  - Click Install / Restore.
  - Power off and connect the Y2 only when Updater CE asks.
