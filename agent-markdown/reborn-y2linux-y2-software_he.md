# Reborn (Y2Linux) עבור Innioasis Y2

הפצה מהירה ומיועדת של Debian Linux עם ממשק משתמש מקורי של גלגל קליקים עבור Innioasis Y2, הכוללת יציבות אוזניות Bluetooth ופיתוח קהילה פעיל.[מדריך Y2 שלב אחר שלב](guides/reborn-y2linux-y2.html)[למה Y2Reborn?](reborn-y2linux-benefits_he.html)[הורד מהדורות](firmware_he.html?model=Y2&software=reborn-y2linux-y2)

מדריך התקנת המחשב שלך

## התקן את Reborn (Y2Linux) ב-Y2 שלך עם המחשב שלך

בחר את המדריך עבור המחשב שבו אתה משתמש. לכל גרסה יש את הגדרת הפלטפורמה, Updater CE שלבים והדרך חזרה למלאי.[מדריך Windows](install/reborn-y2linux-y2-windows.html)[מדריך macOS](install/reborn-y2linux-y2-mac.html)[מדריך לינוקס](install/reborn-y2linux-y2-linux.html)

[כל Innioasis מדריכי Y2](install/y2.html) · [כל המדריכים Reborn (Y2Linux).](install/reborn.html)

## שלבי התקנה
  - פתח את Updater CE. זמין עבור Windows, macOS ו-Linux.
  - בחר Y2 כדגם המכשיר.
  - בחר Reborn (Y2Linux) בתור התוכנה.
  - לחץ על התקן / שחזור. המתן בזמן שהעדכון CE מכין את הקבצים.
  - חבר את USB כאשר תתבקש. כבה תחילה את Y2.
  - הגדר Wi-Fi, Bluetooth ורדיו FM

העתק `system.img` לשחקן פעם אחת. Reborn עושה את השאר.[סיים את ההגדרה →](y2reborn_wifibt_he.html)
