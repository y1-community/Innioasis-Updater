## JJ Launcher Y1 passaggi di installazione
  - Apri Innioasis Updater CE sul tuo computer (se ti serve l'app, [Ottieni Updater CE](guide_it.html#platform)). Impostato Modello del dispositivo a Y1.
  - Scegli JJ Launcher dentro Software.
  - Scegli la versione mostrata per Y1.
  - Fare clic Installa / Ripristina.
  - Spegnere e collegare Y1 solo quando Updater CE lo richiede.
