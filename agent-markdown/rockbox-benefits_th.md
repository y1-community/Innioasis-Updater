# ทำไมต้อง Rockbox สำหรับ Innioasis ของคุณ

Rockbox เปลี่ยนเครื่องเล่นของคุณให้เป็นคลังเพลงที่เหมาะสม การเล่นแบบไม่มีช่องว่าง อีควอไลเซอร์ และไลบรารีธีมแบบลึก มันยังคงบู๊ตกลับไปเป็นซอฟต์แวร์ดั้งเดิมเมื่อคุณต้องการ[รับ Rockbox ใน Updater CE](guide_th.html?model=Y1&software=rockbox-y1)[หน้าติดตั้ง Y1](rockbox-y1-software_th.html)[หน้าติดตั้ง Y2](rockbox-y2-software_th.html)

## ความพร้อมของรุ่น

Innioasis รุ่นใดที่ใช้งานได้[Y1 · ว่าง](rockbox-y1-software_th.html)[Y2 · มีจำหน่าย](rockbox-y2-software_th.html)

บิลด์ Y1 และ Y2 แยกจากกัน ดังนั้นคว้าอันที่สร้างมาเพื่อเครื่องเล่นของคุณในการดาวน์โหลดซอฟต์แวร์ — อย่าสลับอันหนึ่งกับอันอื่น

## ทำไมคนถึงเลือกมัน

ห้องสมุดกลายเป็นประเด็น
  - หยุดเลื่อนตามชื่อไฟล์ — Rockbox อ่านแท็กในเพลงของคุณและจัดเรียงตามอัลบั้ม ศิลปิน และประเภทตามที่ห้องสมุดจริงควร คอลเลกชันขนาดใหญ่หยุดรู้สึกเหมือนเป็นไฟล์ดัมพ์
  - ไม่มีช่องว่าง, ครอสเฟด, EQ — เพลงไหลเข้าหากันโดยไม่มีช่องว่าง และอีควอไลเซอร์เต็มรูปแบบช่วยให้คุณปรับแต่งเสียงโดยไม่ต้องออกจากเครื่องเล่น
  - ธีมสำหรับทุกรสนิยม — ตั้งแต่รูปลักษณ์เรียบง่ายไปจนถึงอินเทอร์เฟซสไตล์ iPod ไลบรารีธีมมีขนาดใหญ่มาก — และชุมชน Y1 บิวด์ใช้ป้ายกำกับความเข้ากันได้แบบ 360p เพื่อช่วยคุณเลือก
  - บูตคู่พร้อมสต็อก — รีบูตกลับไปเป็นซอฟต์แวร์ต้นฉบับได้ตลอดเวลาจากเมนู Rockbox เป็นการทดลองโดยเปิดประตูทิ้งไว้
  - พอดแคสต์และ scrobbling — ทางแยกนี้จะเพิ่มการดาวน์โหลดพอดแคสต์ผ่าน Wi-Fi ในตัวและ Last.fm / ListenBrainz / Maloja scrobbling เพื่อให้ประวัติการฟังของคุณยังคงเป็นของคุณ
  - ออฟไลน์โดยการออกแบบ — Rockbox ทำงานบนไฟล์ในเครื่อง ไม่มีบัญชี ไม่มีการสมัครสมาชิก ไม่มีการพึ่งพาการสตรีม — เหตุผลที่สมาชิกชุมชนหลายคนบอกว่าสิ่งนี้ช่วยให้พวกเขาเลิกสมัครสมาชิกลู่วิ่งไฟฟ้าได้

## ชุมชน

สิ่งที่ชุมชนพูด

Innioasis Updater เกิดขึ้นเนื่องจากชุมชน Rockbox เป็นเส้นทางที่คลื่นลูกแรกของเจ้าของ Y1 และ Y2 ปฏิบัติตามเพื่อเปลี่ยนเครื่องเล่นของตนจากกล่องเพลงสต็อกให้เป็นฐานข้อมูลเพลงที่เหมาะสม และยังคงเป็นซอฟต์แวร์เกี่ยวกับวิดีโอแนะนำการใช้งานส่วนใหญ่ในไซต์นี้

ผู้สร้างอย่าง Dammit Jeff (ซึ่งมีวิดีโอเกี่ยวกับวิธีออกจากบริการสตรีมมิ่งอย่างแท้จริง), Frawgeeys, TUXX Reviews และ veromarstars ครอบคลุมการติดตั้ง Rockbox ธีม และการใช้งานในแต่ละวันบน YouTube และ TikTok ธีมที่สอดคล้องกันในความคิดเห็นและการตอบกลับ: ไลบรารีแบบแท็กและตัวเลือกธีมเชิงลึกทำให้ผู้เล่นรู้สึกเหมือนเป็นของคุณเอง

  - [Frawgeeys · อัปเดตและ Rockbox](https://www.youtube.com/watch?v=Jzo8LNJNE5I)

## สิ่งที่โครงการนำเสนอ
  - ฐานข้อมูลตามแท็ก: อัลบั้มและศิลปินจัดเรียงตามแท็ก ไม่ใช่ชื่อไฟล์
  - การเล่นแบบไม่มีช่องว่าง ครอสเฟด และอีควอไลเซอร์ในตัว
  - ไลบรารีธีมแบบลึกรวมถึงอินเทอร์เฟซแบบ iPod; Y1 บิลด์มีป้ายกำกับความเข้ากันได้ 360p
  - การควบคุมแบบ iPod 6G พร้อมทางลัดการรีสตาร์ท (กด Next + Previous ค้างไว้ 10 วินาที)
  - แอปวิทยุ FM ภายใน Rockbox
  - ปลั๊กอินดาวน์โหลดพอดแคสต์โดยใช้ชิป Wi-Fi ในตัว
  - Scrobbling ไปที่ Last.fm, ListenBrainz หรือ Maloja
  - บูตคู่: รีบูตเป็นสต็อกจากเมนูหลัก → ระบบ และย้อนกลับโดยกด Menu/Back + Play/Pause ค้างไว้
  - แยก Y1 และ Y2 บิลด์ - แพ็คเกจ Y2 เป็นของตัวเอง ROM และจะต้องไม่ถูกสลับ

## เรื่องน่ารู้ก่อน
  - นี่เป็นงานสร้างทดลอง — ตัวโปรเจ็กต์เองก็เตือนว่าไม่เกี่ยวข้องกับ Innioasis และการกะพริบนั้นอาจมีความเสี่ยงอย่างมากหากเร่งรีบ
  - เลือกรุ่นที่ระบุไว้สำหรับรุ่นที่แน่นอนของคุณเสมอ (Y1 หรือ Y2)
  - คอลเลกชันธีมเก่าๆ อาจสร้างด้วยความละเอียด 240p; ตรวจสอบความละเอียดและบันทึกประจำรุ่นก่อนเลือกบิลด์
  - คุณสามารถกู้คืนซอฟต์แวร์ต้นฉบับได้ในภายหลังด้วยแพ็คเกจสต็อก Y1 หรือ Y2 ที่ตรงกัน
