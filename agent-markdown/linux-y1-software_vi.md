# Install Linux on the Y1.

Linux for Y1 is an experimental community Linux kernel and rootfs port for the Innioasis Y1 hardware. This page links to the full installation guide and releases.[Open the full Linux for Y1 (Dev) guide](guides/linux-y1.html)[Nhận cái này trong Updater CE](guide_vi.html?model=Y1&software=linux-y1)[Nguồn dự án](https://github.com/y1-community/y1-linux-rom)

## Install Linux for Y1 (Dev) on your Y1 with your computer

Chọn hướng dẫn cho máy tính bạn đang sử dụng. Mỗi phiên bản đều có phần thiết lập nền tảng, các bước Updater CE và đường về kho.[Hướng dẫn Windows](install/linux-y1-windows.html)[hướng dẫn macOS](install/linux-y1-mac.html)[Hướng dẫn Linux](install/linux-y1-linux.html)

## Linux Y1 install steps
  - Mở Innioasis Updater CE trên máy tính của bạn (nếu bạn cần ứng dụng này, [Tải Updater CE](guide_vi.html#platform)). Đặt Mẫu thiết bị để Y1.
  - chọn Linux cho Y1 (Nhà phát triển) trong Phần mềm.
  - Chọn bản phát hành được liệt kê cho Y1.
  - nhấp chuột Cài đặt / Khôi phục.
  - Tắt nguồn và chỉ kết nối Y1 khi Updater CE yêu cầu.
