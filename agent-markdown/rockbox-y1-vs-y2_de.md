# Rockbox-Y1 vs. Rockbox-Y2

Rockbox-Y1 und Rockbox-Y2 sind separate Firmware-Builds, die für verschiedene Player erstellt wurden. ## Warum es wichtig ist, zuerst Ihr Modell auszuwählen

Obwohl beide Builds Rockbox ausführen, haben Innioasis Y1 und Y2 unterschiedliche Hardware- und Partitionslayouts. Flashen Sie niemals ein Y1 ROM auf einem Y2 oder ein Y2 ROM auf einem Y1.

Innioasis Updater CE verhindert Diskrepanzen, indem verfügbare Software gefiltert wird, sobald Sie dies wünschen Y1 oder Y2 In Gerätemodell. Updater CE lädt das ausgewählte Paket immer direkt von der Version des Community-Firmware-Entwicklers herunter (die Entwickler sind allein dafür verantwortlich, ihre Versionen in Updater CE aufzulisten).

## Welchen Ratgeber benötigen Sie?
  - Innioasis Y1 – Gehe zum [Rockbox-Y1-Hub](rockbox-y1/). Wählen Sie Type A (für Player, die mit 2.0.0+ ausgeliefert wurden) oder Type B (für ältere Geräte) und wählen Sie dann einen 240p- oder 360p-Build.
  - Innioasis Y2 – Gehe zum [Rockbox-Y2-Hub](rockbox-y2/). Wählen Sie Y2 in Updater CE und wählen Sie die neueste Y2-Version aus.

## Was beide Ports gemeinsam haben

Beide bieten die Tag-basierte Musikdatenbank von Rockbox, lückenlose Wiedergabe, Equalizer, benutzerdefinierte Themen und 100 % Offline-Hören auf Ihrem Player.
