# התקן את Y2Player ב-Y2.

Y2Player בנוי עבור Y2. תחילה בחר את הדגם שלך כדי שלא תשתמש בטעות בחבילה Y1.[פתח את המדריך המלא Y2Player](guides/y2player-y2.html)[קבל את זה ב-Updater CE](guide_he.html?model=Y2&software=y2player-y2)[למה Y2Player?](y2player-benefits_he.html)

מדריך התקנת המחשב שלך

## התקן את Y2Player ב-Y2 שלך עם המחשב שלך

בחר את המדריך עבור המחשב שבו אתה משתמש. לכל גרסה יש את הגדרת הפלטפורמה, Updater CE שלבים והדרך חזרה למלאי.[מדריך Windows](install/y2player-y2-windows.html)[מדריך macOS](install/y2player-y2-mac.html)[מדריך לינוקס](install/y2player-y2-linux.html)

[כל Innioasis מדריכי Y2](install/y2.html) · [כל המדריכים Y2Player](install/y2player.html)

## Y2Player שלבי התקנה
  - פתח את Innioasis Updater CE במחשב שלך (אם אתה צריך את האפליקציה, [הורדת Updater CE](guide_he.html#platform)). סט דגם המכשיר ל Y2.
  - בחר Y2Player ב תוכנה.
  - בחר מהדורה הרשומה עבור Y2.
  - לחץ התקנה / שחזור.
  - כבה וחבר את ה-Y2 בהנחיה החיה.

כמה Y2 חבילות בהתקנה מלאה משתמשות `rom_y2.zip`. תן ל-Update לבחור את החבילה כשאפשר.

## שאלות נפוצותהאם אוכל לחזור לתוכנה המקורית?

כן. בחר Y2 ובתוכנה מקורית ב-Updater CE, ולאחר מכן עקוב אחר ההוראות [מדריך שחזור Y2](original-software-y2_he.html).האם אני יכול להשתמש בזה על Y1?

לא. דף זה מיועד לערך Y2Player Y2. שמור על חבילות Y1 ו-Y2 נפרדות.מה אם ה-Y2 לא מזוהה?

בדוק את הגדרת הפלטפורמה, הכבל, מצב הכיבוי, בחירת הדגם והתזמון. השתמש [פתרון בעיות](troubleshooting_he.html) לפני שתנסה שחזור ידני.
