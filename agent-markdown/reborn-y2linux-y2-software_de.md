## Installieren Sie Reborn (Y2Linux) auf Ihrem Y2 mit Ihrem Computer

Wählen Sie die Anleitung für den Computer aus, den Sie verwenden. Jede Version verfügt über das Plattform-Setup, Updater CE Schritte und den Weg zurück zum Lagerbestand.[Windows-Anleitung](install/reborn-y2linux-y2-windows.html)[macOS-Anleitung](install/reborn-y2linux-y2-mac.html)[Linux-Anleitung](install/reborn-y2linux-y2-linux.html)

[Alle Innioasis Y2-Anleitungen](install/y2.html) · [Alle Reborn (Y2Linux) Anleitungen](install/reborn.html)

## Installationsschritte
  - Öffnen Sie Updater CE. Verfügbar für Windows, macOS und Linux.
  - Wählen Sie Y2 als Gerätemodell.
  - Wählen Sie Reborn (Y2Linux) als die Software.
  - Klicken Sie auf Installieren/Wiederherstellen. Warten Sie, während Updater CE die Dateien vorbereitet.
  - Verbinden Sie USB, wenn Sie dazu aufgefordert werden. Schalten Sie zuerst den Y2 aus.
  - Richten Sie WLAN, Bluetooth und UKW-Radio ein

Kopieren `system.img` einmal an den Spieler. Reborn erledigt den Rest.[Einrichtung abschließen →](y2reborn_wifibt_de.html)
