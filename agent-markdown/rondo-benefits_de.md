# Warum Rondo auf Ihrem Innioasis Y1 installieren?

Rondo ist eine Open-Source-Firmware für Clickwheel-Musikplayer, die speziell für die Innioasis Y1-Hardware entwickelt wurde. Es bietet sauberes Durchsuchen der Bibliothek, saubere Typografie und schnelle Audiodekodierung.[Installieren Sie Rondo auf Y1](guides/rondo-y1.html)[Durchsuchen Sie Veröffentlichungen](firmware_de.html?model=Y1&software=rondo-y1)

## Höhepunkte von Rondo

### Schnelle Clickwheel-Reaktion

Sorgfältig abgestimmte Beschleunigungskurve, abgestimmt auf das physikalisch-kapazitive Touchwheel Y1 für reibungsloses Scrollen durch große Musikbibliotheken.

### Fokussierter Audioplayer

Keine Bloatware, Hintergrundanalysen oder unnötige Daemons: 100 % der Hardwareressourcen werden für die gestochen scharfe Audioausgabe verwendet.

### Jederzeit umkehrbar

Installieren Sie einfach mit Innioasis Updater CE und kehren Sie jederzeit zur Originalsoftware oder Rockbox zurück.
