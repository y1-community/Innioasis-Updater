# Rockbox-Y2 FAQ

Clear answers to the most common questions about installing, updating, and using Rockbox-Y2 on the Innioasis Y2.[Get it in Updater CE](../guide.html?model=Y2&software=rockbox-y2)[Full written tutorial](../guides/rockbox-y2.html)

## At a glance

Rockbox, Rockbox-Y2, and “Rockbox for Y2” are the same community firmware for the Innioasis Y2. Innioasis Updater CE always downloads packages directly from the community firmware developers (spycemagic/y2-rockbox), who are solely responsible for listing their releases in Updater CE.

## Frequently asked questionsAre Rockbox, Rockbox-Y2, and Rockbox for Y2 the same thing?

Yes. Updater CE lists it as Rockbox when Y2 is selected, while guides and release notes call it Rockbox-Y2 so it is clear which player model it is for.Where does Updater CE download Rockbox-Y2 from?

Updater CE always downloads firmware packages directly from the community firmware developers' own releases (spycemagic/y2-rockbox), never from a mirror archive. The developers are solely responsible for listing their software releases in Updater CE.How do I install Rockbox-Y2?

Follow the [6-step install guide](install.html) in Innioasis Updater CE.Can I install Rockbox-Y2 on an Innioasis Y1?

No. Use [Rockbox-Y1](../rockbox-y1/) for the Y1.Will installing Rockbox-Y2 erase my music?

No. Your music lives on the MicroSD card and is not touched by flashing the firmware.How do I go back to factory software?

Install Original Software for Y2 in Updater CE ([restore guide](restore-stock.html)).
