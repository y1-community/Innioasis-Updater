# Remove Rockbox-Y2 or reset it to defaults

Whether you want to remove Rockbox-Y2 completely and return to factory software, or simply reset Rockbox-Y2 back to default settings, both take only a few minutes.[Get it in Updater CE](../guide.html?model=Y2&software=rockbox-y2)[Full written tutorial](../guides/rockbox-y2.html)

## Option 1: Return to factory Original Software

To replace Rockbox-Y2 with the factory firmware, open Innioasis Updater CE, select Y2, choose Original Software, and click Install / Restore. See the [restore guide](restore-stock.html).

## Option 2: Reset Rockbox-Y2 settings to default

To keep Rockbox-Y2 installed but reset all settings, themes, and database caches, delete or rename the hidden `.rockbox` folder on your MicroSD card and reboot the player. See the [MicroSD card guide](sd-card.html).

## Frequently asked questionsDoes deleting .rockbox uninstall the firmware?

No. It only resets your settings and themes; the player recreates a clean .rockbox folder on the next boot.Can I reinstall Rockbox-Y2 after restoring Original Software?

Yes, at any time through Innioasis Updater CE.
