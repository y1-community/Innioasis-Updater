# What you need before installing Rockbox-Y2

Check these five items before installing Rockbox-Y2 on your Innioasis Y2: the model printed on the player, a USB data cable, battery charge, computer drivers, and connection timing.[Get it in Updater CE](../guide.html?model=Y2&software=rockbox-y2)[Full written tutorial](../guides/rockbox-y2.html)

## What you need
  - An Innioasis Y2 — verify the model name on the player.
  - A USB data cable (charge-only cables cannot transfer firmware).
  - A charged battery (at least 50%% recommended).
  - Windows: MediaTek USB drivers. Linux: udev permissions for `0e8d:*`. macOS: no extra driver needed.
  - About 1 GB of free disk space on your computer.

Need help with drivers? See the [USB drivers guide](../drivers.html) or [troubleshooting](troubleshooting.html).

## Choosing the right Rockbox-Y2 build

Rockbox-Y2 is developed separately for the Y2 hardware. Check the release notes for your version to see supported features and theme compatibility.
  - Y2: Only install builds listed for the Y2.
  - Choose a stable release for everyday use, or a nightly build to test the latest changes.
