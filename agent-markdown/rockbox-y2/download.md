## Which package should I choose?
  - Install with Updater CE (recommended) — Updater CE downloads the package directly from the developer's release and flashes your Y2 automatically.
  - Developer ROM package (`rom_y2.zip`) — the firmware ZIP published by the developer for offline archiving or manual installation.
  - Earlier beta builds — browse all versions in the [firmware directory](../firmware.html?model=Y2&software=rockbox-y2).

Current recommended release tag: v0.2.5-beta.

## Install with one click in Updater CE

You do not need to download ZIP files manually for a normal install. Open Updater CE, select Y2 and Rockbox, and it will download the release directly from the developer.[Get it in Updater CE](../guide.html?model=Y2&software=rockbox-y2)[Browse all releases](../firmware.html?model=Y2&software=rockbox-y2)

## Frequently asked questionsWhere do Rockbox-Y2 downloads come from?
