# Rockbox-Y2 vs Original Software

Compare Rockbox-Y2 and the factory Original Software on the Innioasis Y2 so you can decide which system fits how you listen.[Get it in Updater CE](../guide.html?model=Y2&software=rockbox-y2)[Full written tutorial](../guides/rockbox-y2.html)

## Feature comparison

| Feature | Original Software | Rockbox-Y2 |
| --- | --- | --- |
| Music library | Folder and basic tag browsing | Full tag database (artist, album, genre, year) + folder view |
| Playback | Standard playback | Gapless playback, crossfade, ReplayGain, parametric EQ |
| Themes | Built-in factory themes | Hundreds of custom community themes |
| FM radio | Built-in FM radio | Included on builds/models with FM hardware |
| Restoring factory OS | Already installed | One-click restore via Original Software in Updater CE |

## Which should you choose?
  - Choose Rockbox-Y2 if you want gapless playback, custom themes, a faster tag database, and fine-grained audio controls.
  - Choose Original Software if you prefer the simple out-of-the-box factory interface.
  - You can switch back and forth at any time using Innioasis Updater CE.
