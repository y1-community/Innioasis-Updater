# Update Rockbox-Y2

Updating Rockbox-Y2 on your Innioasis Y2 uses the exact same steps in Updater CE as a first-time install, and keeps the music, themes, and settings stored on your MicroSD card.[Get it in Updater CE](../guide.html?model=Y2&software=rockbox-y2)[Full written tutorial](../guides/rockbox-y2.html)

## How to update to a newer release
  - Open Innioasis Updater CE and select Y2 in Device Model.
  - Choose Rockbox and select the newer stable or nightly release.
  - Click Install / Restore and connect your powered-off player when prompted.
  - Turn on the player once the update finishes.

Updater CE downloads the new release directly from the community developer's repository.

## Stable vs. nightly builds

Stable releases are recommended for everyday listening. Nightly builds let you test the newest changes and bug fixes. You can read what changed in every version on the [Rockbox-Y2 release notes page](../release-notes/rockbox-y2/index.html).

## Frequently asked questionsDo I need to uninstall the old version before updating?

No. Flashing the new release overwrites the previous firmware while leaving your MicroSD card untouched.Can I downgrade to an earlier release?

Yes. Select any earlier release listed for your model in Updater CE and install it the same way.
