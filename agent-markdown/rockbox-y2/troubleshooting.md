# Rockbox-Y2 install problems and how to fix them

If your Rockbox-Y2 installation does not start or stops early, check these five common causes in order.[Get it in Updater CE](../guide.html?model=Y2&software=rockbox-y2)[Full written tutorial](../guides/rockbox-y2.html)

## 5 checks that fix most install issues
  - Device Model: Confirm Y2 is selected in Updater CE before choosing Rockbox.
  - USB Cable: Use a known-good USB data cable; charge-only cables never connect.
  - Connection Timing: Click Install / Restore first, power the player completely off, and plug it in only when Updater CE asks.
  - USB Drivers: On Windows, install the MediaTek driver; on Linux, add udev permissions ([drivers guide](../drivers.html)).
  - Recovery: If an interrupted flash leaves the player unresponsive, follow the [recovery guide](../guides/recovery.html).

## More troubleshooting help

See the main [Innioasis Updater troubleshooting page](../troubleshooting.html) for step-by-step diagnostics on Windows, macOS, and Linux.

## Frequently asked questionsUpdater CE does not detect my player when I plug it in.

Make sure the player is powered completely off before connecting the USB cable, try a different USB data cable, and check your USB drivers.The flash stopped halfway through — is my player bricked?

Usually not. MediaTek preloader mode stays available even after an interrupted flash. Re-run Install / Restore in Updater CE.
