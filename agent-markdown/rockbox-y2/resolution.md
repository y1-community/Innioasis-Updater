# Rockbox-Y2 240p and 360p builds

Rockbox-Y2 is developed separately for the Y2 hardware. Check the release notes for your version to see supported features and theme compatibility.[Get it in Updater CE](../guide.html?model=Y2&software=rockbox-y2)[Full written tutorial](../guides/rockbox-y2.html)

## What 240p and 360p mean

Resolution labels describe the display layout and theme format that the build uses. A 240p theme is designed for 320×240 builds, while a 360p theme is designed for 480×360 builds.

## How to choose
  - Pick the build resolution that matches the themes you want to use.
  - 360p Rockbox-Y1 themes can be copied to a Y2 by hand; check the release notes for your Rockbox-Y2 version first.
[Rockbox-Y2 theme guide](../rockbox-y2-themes.html)[Rockbox-Y1 themes](../rockbox-y1-themes.html)

## Frequently asked questionsCan I switch themes later?

Yes. Themes are files in the `.rockbox` folder, so adding or removing one never needs a reflash.
