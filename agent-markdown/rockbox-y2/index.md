# Rockbox-Y2

Rockbox-Y2 is the community Rockbox firmware for the Innioasis Y2. It adds a tag-based music library, gapless playback, a full equalizer, and custom themes. Use this hub to install Rockbox-Y2 with Updater CE, download ROM packages, browse themes, or restore the factory software.[Install Rockbox-Y2](install.html)[Download the ROM](download.html)[Full written tutorial](../guides/rockbox-y2.html)

## Rockbox, Rockbox-Y2 and “Rockbox for Y2” are the same firmware

Innioasis Updater CE lists this firmware as Rockbox under device model Y2. Guides, videos, and search results also call it Rockbox-Y2 or Rockbox for Y2. All of these names refer to the exact same Y2 port. Always select Y2 first so you do not install a Y1 build by mistake.

## Direct downloads from the community developers

Innioasis Updater CE always downloads firmware packages directly from the community firmware developers ([spycemagic/y2-rockbox](../firmware.html?model=Y2&software=rockbox-y2)), who are solely responsible for publishing and listing their software releases in Updater CE. You can let Updater CE download and install the release for you, or download the ROM package from our firmware directory.[Rockbox-Y2 downloads](download.html)[Get it in Updater CE](../guide.html?model=Y2&amp;software=rockbox-y2)[Release notes (v0.2.5-beta)](../release_notes.html?author=spycemagic&project=y2-rockbox&version=v0.2.5-beta&software=rockbox-y2)

## Before you install
  - Select Y2 in Device Model before choosing Rockbox.
  - Choose a stable release for daily use, or enable nightly builds if you want to test a preview.
  - Use a USB data cable and a charged player; power the player off and connect it only when Updater CE asks.
  - You can return to factory firmware at any time by installing Original Software for the Y2.

Rockbox-Y2 is developed separately for the Y2 hardware. Check the release notes for your version to see supported features and theme compatibility.

## Frequently asked questionsIs Rockbox-Y2 safe to install?

Yes. It uses the same MediaTek flashing process as the factory firmware, and you can restore Original Software at any time. Always use a reliable USB data cable and keep the player charged.Where does Updater CE download Rockbox-Y2 from?

Updater CE downloads firmware packages directly from the community firmware developers' own releases (spycemagic/y2-rockbox). The developers themselves are solely responsible for listing their releases in Updater CE.Can I install Rockbox-Y2 on an Innioasis Y1?

No. The Y1 and Y2 use different hardware and separate firmware builds. Select Y1 in Updater CE and use the [Rockbox-Y1 guide](../rockbox-y1/) instead.How do I return to the original factory software?

In Updater CE, select Y2, choose Original Software, pick a stable release, and click Install / Restore. See the [restore guide](restore-stock.html).
