## Rockbox Y2 langkah-langkah pemasangan
  - Buka Innioasis Updater CE di komputer Anda (jika Anda memerlukan aplikasinya, [Dapatkan Updater CE](guide_id.html#platform)). Tetapkan Model perangkat untuk Y2.
  - Pilih Rockbox di Perangkat lunak.
  - Pilih rilis yang secara eksplisit tercantum untuk Y2.
  - Klik Pasang / Pulihkan dan tunggu persiapan paket.
  - Matikan dan sambungkan Y2 hanya ketika Updater CE diminta.

Jangan memaksakan paket Y1 karena nama proyek terlihat sama. Jika tidak ada rilis Y2 yang muncul, hentikan dan periksa model dan data rilis saat ini.
