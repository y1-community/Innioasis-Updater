## Installationsschritte für Linux Y1.
  - Öffnen Sie Innioasis Updater CE auf Ihrem Computer (wenn Sie die App benötigen, [Updater CE holen](guide_de.html#platform)). Satz Gerätemodell an Y1.
  - Wählen Sie Linux für Y1 (Dev) In Software.
  - Wählen Sie die für Y1 aufgeführte Version aus.
  - Klicken Sie Installieren / Wiederherstellen.
  - Schalten Sie das Y1 nur aus und schließen Sie es an, wenn Updater CE dazu fragt.

## FAQKann ich die Standard-Y1-Software wiederherstellen?

Ja. Wählen Sie Y1 und Originalsoftware in Updater CE. Die [Y1-Aktiensoftware-Leitfaden](original-software-y1_de.html) deckt den Rückweg ab.Handelt es sich um eine alltägliche Benutzeroberfläche?

Dies ist eine experimentelle Portierung für Entwickler und Linux-Tüftler. Anweisungen zu Terminal und Konsole finden Sie in den Projektdokumenten.
