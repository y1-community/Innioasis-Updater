# Rockbox-Y2 thèmes

Comment installer des thèmes sur Rockbox-Y2, vérifier la compatibilité des thèmes avec votre version installée et réinitialiser un thème s'il ne s'affiche pas correctement.[Rockbox-Y2 notes de version](release-notes/rockbox-y2/index.html)[Parcourir les thèmes de la communauté](https://themes.innioasis.app/)[Installer Rockbox-Y2](rockbox-y2/install.html)

## Vérifiez la compatibilité du thème pour votre build

Rockbox-Y2 est développé séparément du port Y1, la compatibilité des thèmes suit donc la version de build Y2 que vous avez installée. Vérifiez le [Rockbox-Y2 notes de version](release-notes/rockbox-y2/index.html) pour votre version avant d'installer un pack de thèmes.

Voir [Rockbox-Y1 contre Rockbox-Y2](rockbox-y1-vs-y2_fr.html) pour une comparaison complète des deux ports.

## Comment installer des thèmes sur le Y2

Les thèmes sont stockés sur votre carte MicroSD à l'intérieur du `.rockbox` dossier.
  - Démarrez Rockbox-Y2 au moins une fois pour créer le `.rockbox` dossier sur votre carte MicroSD.
  - Extrayez ou copiez les fichiers de thème dans `.rockbox/` (donc `themes`, `wps`, `fonts`, et `backdrops` fusionner dans `.rockbox/`).
  - Sur le lecteur, ouvrez Paramètres → Paramètres du thème → Parcourir les fichiers de thème et sélectionnez votre thème.

Pour afficher les dossiers cachés sur votre ordinateur : appuyez sur Cmd+Shift+. sur macOS, activez Affichage → Éléments masqués sous Windows, ou appuyez sur Ctrl+H sous Linux.

## Comment réinitialiser un thème cassé

Si un thème rend l'écran difficile à lire, renommez ou supprimez le `.rockbox` dossier sur votre carte MicroSD et redémarrez le lecteur. Rockbox-Y2 créera un nouveau `.rockbox` dossier avec le thème par défaut tout en gardant votre musique intacte.[Le dossier .rockbox](rockbox-y2/sd-card.html)[Mise à jour de Rockbox-Y2](rockbox-y2/update.html)[Rockbox-Y2 notes de construction](rockbox-y2/resolution.html)
