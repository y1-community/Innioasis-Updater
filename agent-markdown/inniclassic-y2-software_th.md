# Inniclassic เฟิร์มแวร์สำหรับ Innioasis Y2 | ติดตั้งบทช่วยสอน - Innioasis ดาวน์โหลดเฟิร์มแวร์

Inniclassic · Innioasis Y2

# ติดตั้ง Inniclassic บน Y2

Inniclassic พร้อมใช้งานสำหรับ Innioasis Y2 และโปรเจ็กต์เดียวกันก็สร้างแพ็คเกจ Y1 ด้วย หน้านี้จะให้ภาพรวมของ Y2 และลิงก์ไปยังบทช่วยสอนฉบับเต็ม[เปิดคำแนะนำ Inniclassic ฉบับเต็ม](guides/inniclassic-y2.html)[รับสิ่งนี้ใน Updater CE](guide_th.html?model=Y2&software=inniclassic-y2)[ทำไมต้อง Inniclassic?](inniclassic-benefits_th.html)

คู่มือการติดตั้งสำหรับคอมพิวเตอร์ของคุณ

## ติดตั้ง Inniclassic บน Y2 ด้วยคอมพิวเตอร์ของคุณ

เลือกคำแนะนำสำหรับคอมพิวเตอร์ที่คุณใช้ ทุกรุ่นมีการตั้งค่าแพลตฟอร์ม ขั้นตอน Updater CE และวิธีคืนสินค้าในสต็อก[คู่มือวินโดวส์](install/inniclassic-y2-windows.html)[คู่มือ macOS](install/inniclassic-y2-mac.html)[คู่มือลินุกซ์](install/inniclassic-y2-linux.html)

[คำแนะนำ Innioasis Y2 ทั้งหมด](install/y2.html) · [คำแนะนำ Inniclassic ทั้งหมด](install/inniclassic.html)

## Inniclassic Y2 ขั้นตอนการติดตั้ง
  - เปิด Innioasis Updater CE บนคอมพิวเตอร์ของคุณ (หากคุณต้องการแอป [รับ Updater CE](guide_th.html#platform)). ชุด รุ่นอุปกรณ์ ถึง Y2.
  - เลือก Inniclassic ใน ซอฟต์แวร์.
  - เลือกรุ่นที่แสดงรายการสำหรับ Y2
  - คลิก ติดตั้ง / คืนค่า.
  - ปิดเครื่องและเชื่อมต่อ Y2 เมื่อ Updater CE ถามเท่านั้น

## คำถามที่พบบ่อยฉันสามารถกู้คืนซอฟต์แวร์สต็อก Y2 ได้หรือไม่

ใช่. เลือก Y2 และซอฟต์แวร์ต้นฉบับใน Updater CE ที่ [Y2 คู่มือซอฟต์แวร์หุ้น](original-software-y2_th.html) ครอบคลุมเส้นทางขากลับฉันสามารถใช้ Inniclassic กับ Y1 ได้หรือไม่

ใช่. โครงการเดียวกันนี้เผยแพร่แพ็คเกจ Y1 เช่นกัน - rom.zip สำหรับ Type A และ rom_type_b.zip สำหรับ Type B เลือก Y1 ใน Updater CE และติดตั้งบิลด์ Y1 ที่ [หน้าติดตั้ง Y1](inniclassic-y1-software_th.html) ครอบคลุมมันจะทำอย่างไรถ้าการติดตั้งล้มเหลว?

โปรดทราบว่าตัวอัปเดตล้มเหลวก่อนหรือหลังการตรวจจับ Y2 จากนั้นตรวจสอบสายเคเบิล การตั้งค่าแพลตฟอร์ม รุ่น และระยะเวลาการเชื่อมต่อใน [การแก้ไขปัญหา](troubleshooting_th.html).

## ใช้เส้นทางที่แนะนำ

ครั้งแรกที่ใช้ Updater? ดูการตั้งค่าที่แนะนำไปที่ [รับ Updater CE](guide_th.html#platform) บน Windows, macOS หรือ Linux ก่อนที่จะเชื่อมต่อเครื่องเล่นของคุณ
