# Install Android 4.2 (Dev) on the Y1.

Android 4.2 is a community development ROM for testing and hacking on Innioasis Y1 hardware. ## Android 4.2 Y1 install steps
  - আপনার কম্পিউটারে Innioasis Updater CE খুলুন (যদি আপনার অ্যাপটির প্রয়োজন হয়, [Updater CE নিন](guide_bn.html#platform)) সেট ডিভাইস মডেল থেকে Y1.
  - বেছে নিন Android 4.2 (Dev) মধ্যে সফটওয়্যার.
  - Y1-এর জন্য তালিকাভুক্ত রিলিজ বেছে নিন।
  - ক্লিক করুন ইনস্টল / পুনরুদ্ধার.
  - পাওয়ার বন্ধ করুন এবং শুধুমাত্র Updater CE বললেই Y1 সংযোগ করুন।

## সাধারণ প্রশ্নআমি কি স্টক Y1 সফ্টওয়্যার পুনরুদ্ধার করতে পারি?

হ্যাঁ। Updater CE-এ Y1 এবং অরিজিনাল সফটওয়্যার নির্বাচন করুন। দ [Y1 স্টক-সফ্টওয়্যার গাইড](original-software-y1_bn.html) ফেরার পথ কভার করে।Is this a daily driver ROM?

This is an experimental developer ROM intended for testing and development. Feature updates are on the project's page.
