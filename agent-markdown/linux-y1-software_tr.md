# Install Linux on the Y1.

Linux for Y1 is an experimental community Linux kernel and rootfs port for the Innioasis Y1 hardware. ## Linux Y1 install steps
  - Bilgisayarınızda Innioasis Updater CE'yi açın (uygulamaya ihtiyacınız varsa, [Updater CE edin](guide_tr.html#platform)). Ayarlamak Cihaz modeli ile Y1.
  - Seçmek Linux for Y1 (Dev) içinde Yazılım.
  - Y1 için listelenen sürümü seçin.
  - Tıklamak Yükle / Geri yükle.
  - Y1'i yalnızca Updater CE sorduğunda kapatın ve bağlayın.
