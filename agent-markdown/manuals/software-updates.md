# Update or restore your player's software

A software update is not the same as a factory reset. One keeps your files; the other erases them.[All player manuals](index.html)[Firmware archive](../firmware.html)

Use [Innioasis Updater CE](../guide.html) on Windows, macOS or Linux. It downloads the right package for the model you select, prepares it, and tells you exactly when to connect the powered-off player.
  - Open Updater CE and choose the model printed on the player.
  - Choose Original Software for the stock system, or a community project such as Rockbox if one is listed for that model.
  - Pick a release and press Install / Restore.
  - Power the player off and connect the USB cable only when Updater asks.
  - Leave the player and the cable alone until the success message.

Official stock packages are archived on the [firmware archive](../firmware.html). Each model has its own repository, so you can also download a package by hand and flash it with SP Flash Tool.Never flash a package for a different model. Y1 files do not belong on a Y2, a G1 package is not a G3 package, and a recorder is not a player. The model check is the most important step.
