# 为什么 Better-Y 适合您的 Innioasis Y1

Better-Y 是库存播放器，经过改进。由 Leska1337 在官方 3.1.2 软件上构建。它修复了标签、曲目编号、缓存和播放控件，并保留了熟悉的外观、滚轮和主题。[在更新程序中获取 Better-Y](firmware_zh-CN.html?model=Y1&software=better-y-y1)[Y1安装页面](better-y-y1-software_zh-CN.html)[完整的Y1教程](guides/better-y-y1.html)[项目来源](https://github.com/Leska1337/better-Y)

## 型号可用性

哪些 Innioasis 型号运行它？[Y1 (Type A) · 可用](better-y-y1-software_zh-CN.html)Y2 · 不可用

Better-Y 是为 Innioasis Y1（Type A 硬件）制作的。 Y1 和 Y2 版本是分开的，因此请勿将其中一个交换为另一个。

## 为什么人们选择它

库存的一切都是你喜欢的，没有任何怪癖。
  - 跟踪号码所属的位置 — 专辑视图最终会显示曲目编号，以便您的专辑按照预期的曲目列表顺序播放和显示，而不是任意排序。
  - 智能标签分割 — 多艺术家歌曲（用逗号或分号分隔）出现在每个艺术家的下方。多流派标签（用逗号、分号或正斜杠分隔）出现在每个匹配流派下。
  - 文件名上的 ID3 元数据 — 歌曲标题、专辑和艺术家可以从 ID3 标签中正确读取，而不是显示原始文件名。
  - 正在播放交互式控件 — 直接在屏幕上显示收藏夹（心形）、随机播放切换、重复模式（一个/全部/关闭）、歌词、A-B 重复循环、播放队列、书签位置、速度控制和睡眠定时器的图标。
  - 流畅、无闪烁的 RAM 缓存 — 完全重新设计的图像缓存引擎消除了滚动浏览大型音乐库时的 UI 闪烁、闪烁和延迟。
  - 官方3.1.2基础 — 基于最新的 3.1.2 基础构建，保留官方 Apple AirPods 连接修复，同时保留与所有自定义库存主题 100% 的兼容性。

## 社区与发布

社区怎么说

Better-Y 由开发者 Leska1337 创建，旨在解决 r/innioasis subreddit 上讨论的具体日常可用性问题。 Better-Y 不是用不同的操作系统替换系统，而是完善用户已经了解和喜爱的本机玩家体验。

人们喜欢这种熟悉的感觉：主题库中的现有主题继续工作，播放列表和蓝牙表现得像库存一样，导航速度明显更快。
  - [r/innioasis · Better-Y v1.0.0 发布讨论](https://www.reddit.com/r/innioasis/comments/1w6wt7i/bettery_v100_release_stock_launcher_but_better/)
  - [Leska1337/better-Y 源](https://github.com/Leska1337/better-Y)

## 该项目提供什么
  - 曲目编号直接显示在专辑曲目列表中
  - 多艺术家标签以逗号 (,) 和分号 (;) 分割
  - 按逗号 (,)、分号 (;) 和斜杠 (/) 分割多类型标签
  - 对合辑、致敬和功能的完整专辑艺术家标签支持
  - 外部封面艺术支持（自动检测 `cover.jpg`, `cover.png`, `folder.jpg`)
  - 多光盘版本的光盘编号显示（CD 1、CD 2、乙烯基面）
  - 交互式正在播放图标（收藏夹、随机播放、重复、歌词、A-B 循环、队列、书签、速度、睡眠计时器）
  - 更大的专辑插图演示，具有自动裁剪/填充和倾斜固定/切换功能
  - 平滑的选取框文本自动滚动，显示长曲目标题和艺术家姓名
  - 修复了歌词行溢出和文本截断错误
  - 按字母顺序快速滚动索引栏，用于大型图书馆中的快速轮式导航
  - 选择光标自动记住并跟随当前播放的曲目
  - 艺术家视图首先显示专辑，而不是将所有歌曲转储到平面列表中
  - 文件夹视图添加“显示所有歌曲”和“随机播放”按钮
  - 默认浏览快捷方式直接跳转到 `/Music/` 和 `/Videos/`
  - 双击播放/暂停硬件按钮快捷方式可从任何屏幕直接跳转到“正在播放”
  - 按发行年份对专辑进行排序；按添加日期对播放列表进行排序
  - 高速 RAM 图像缓存引擎消除列表闪烁
  - 具有即时“更新库”选项的快速库扫描器
  - 删除文件夹中的最后一首歌曲时自动清理空父目录
  - 3 布局屏幕键盘，带大写锁定和大小写开关，更方便搜索
  - 在歌词和阅读显示期间显示保持唤醒设置
  - 硬件紧急重启快捷方式（同时按住顶部和底部按钮）

## 首先要知道的事情
  - 专为 Innioasis Y1（Type A 硬件）构建 - 不刷新到 Y2
  - 保留与所有自定义主题和库存设置的完全兼容性
