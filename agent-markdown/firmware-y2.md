# Firmware for Innioasis Y2

The Y2 has better audio hardware, Bluetooth and a file manager. Pick a custom system, a Linux build, or the official software to restore.[Browse Y2 Downloads](firmware.html?model=Y2)[Get Updater CE](guide.html#platform)[Y2 Themes Guide](https://themes.innioasis.app/y2-themes.html)

## Available Operating Systems for Innioasis Y2

Pick what you want to run on your Y2:

### [Reborn (Y2Linux)](reborn-y2linux-benefits.html)

Native embedded Linux OS combining Buildroot, LVGL, PipeWire, and MPD. Offers 3-second boot times, true Bluetooth headphone reconnection fixes, and gapless playback.[Y2Reborn Guide →](guides/reborn-y2linux-y2.html)

### [Rockbox for Y2](rockbox-benefits.html)

The ultimate audiophile firmware ported to the Innioasis Y2. Parametric equalization, custom fonts, crossfeed, and extensive plugin library support.[Y2 Rockbox Guide →](guides/rockbox-y2.html)

### [Solar for Y2](solar-benefits.html)

Modern, fluid Flutter-based music player interface for the Y2. Features rich visualizers, large album art presentation, and gesture navigation.[Solar Y2 Guide →](guides/solar-y2.html)

### [Y2Player](y2player-benefits.html)

Lightweight community audio player made for Y2 hardware with simple folder browsing and fast index scanning.[Y2Player Guide →](guides/y2player-y2.html)

### [Original Software (Factory Restore)](original-software-benefits.html)

Official stock firmware image (rom_y2.zip) for restoring an Innioasis Y2 to original factory condition, complete with Themes Gallery skin support.[Restore Y2 Guide →](guides/restore-original-y2.html)

## Installing Firmware on Your Innioasis Y2

Updater CE grabs the right files and checks the driver before flashing:
  - Launch Innioasis Updater CE: Available natively on macOS, Linux, and Windows.
  - Set Model: Select Y2 in the Device Model menu.
  - Choose Operating System: Pick Reborn, Rockbox, Solar, or Original Software.
  - Flash Safely: Follow the on-screen prompts to connect your device over USB for a clean, verified flash.
