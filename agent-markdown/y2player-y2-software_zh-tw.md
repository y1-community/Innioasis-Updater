# 在 Y2 上安裝 Y2Player。

Y2Player 是為 Y2 而建構的。首先選擇您的型號，這樣您就不會意外使用 Y1 套件。[開啟完整的 Y2Player 指南](guides/y2player-y2.html)[在 Updater CE 中取得此內容](guide_zh-TW.html?model=Y2&software=y2player-y2)[為什麼是Y2Player？](y2player-benefits_zh-TW.html)

適用於您的電腦的安裝指南

## 使用計算機在 Y2 上安裝 Y2Player

選擇適合您正在使用的計算機的指南。 每個版本都有平台設定、Updater CE步驟和返回庫存的方式。[Windows 指南](install/y2player-y2-windows.html)[macOS 指南](install/y2player-y2-mac.html)[Linux指南](install/y2player-y2-linux.html)

[所有 Innioasis Y2 指南](install/y2.html) · [所有 Y2Player 指南](install/y2player.html)

## Y2Player安裝步驟
  - 在您的電腦上開啟 Innioasis Updater CE（如果您需要該應用程序， [取得 Updater CE](guide_zh-TW.html#platform)）。套裝 裝置型號 到 Y2.
  - 選擇 Y2Player 在 軟體.
  - 選擇 Y2 列出的版本。
  - 點選 安裝 / 還原.
  - 依照即時提示關閉電源並連接 Y2。

一些 Y2 完整安裝包使用 `rom_y2.zip`。如果可能，讓更新程式選擇套件。

## 常見問題我可以回到原來的軟體嗎？

是的。在 Updater CE 中選擇 Y2 和原始軟體，然後依照 [Y2恢復指南](original-software-y2_zh-TW.html).我可以在 Y1 上使用它嗎？

否。此頁面用於 Y2Player Y2 條目。將 Y1 和 Y2 包分開。如果沒有偵測到Y2怎麼辦？

檢查平台設定、電纜、斷電狀態、型號選擇和計時。使用 [故障排除](troubleshooting_zh-TW.html) 在嘗試手動恢復之前。
