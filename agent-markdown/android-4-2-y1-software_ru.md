# Установите Android 4.2 (Dev) на Y1.

Android 4.2 — это разработка сообщества ROM для тестирования и взлома на Innioasis Y1 оборудовании. На этой странице можно найти полное руководство и список выпусков.[Открыть полное руководство по Android 4.2 (для разработчиков)](guides/android-4-2-y1.html)[Получите это в Updater CE](guide_ru.html?model=Y1&software=android-4-2-y1)[Источник проекта](https://github.com/y1-community/y1-ata-rom)

## Установите разработку Android ROM на свой Y1 с помощью компьютера.

Выберите руководство для компьютера, который вы используете. В каждой версии есть настройка платформы, Updater CE шагов и возврат к стоку.[Руководство по Windows](install/android-4-2-y1-windows.html)[руководство по macOS](install/android-4-2-y1-mac.html)[Руководство по Linux](install/android-4-2-y1-linux.html)

## Действия по установке Android 4.2 Y1
  - Откройте Innioasis Updater CE на своем компьютере (если вам нужно приложение, [Скачать Updater CE](guide_ru.html#platform)). Набор Модель устройства в адрес Y1.
  - Выбирать Android 4.2 (для разработчиков) в Программное обеспечение.
  - Выберите выпуск, указанный для Y1.
  - Нажмите Установить / Восстановить.
  - Выключите питание и подсоедините Y1 только тогда, когда появится запрос Updater CE.

## Вопросы и ответыМогу ли я восстановить стандартное программное обеспечение Y1?

Да. Выберите Y1 и оригинальное программное обеспечение в Updater CE. [Y1 руководство по стандартному программному обеспечению](original-software-y1_ru.html) перекрывает обратный путь.Это ежедневный водитель ROM?

Это экспериментальный разработчик ROM, предназначенный для тестирования и разработки. Обновления функций находятся на странице проекта.

## Используйте маршрут с гидом

Впервые пользуетесь программой обновлений? См. пошаговую настройку, чтобы [Скачать Updater CE](guide_ru.html#platform) в Windows, macOS или Linux перед подключением плеера.
