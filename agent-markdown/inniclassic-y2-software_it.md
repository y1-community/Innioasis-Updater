## Inniclassic Y2 passaggi di installazione
  - Apri Innioasis Updater CE sul tuo computer (se ti serve l'app, [Ottieni Updater CE](guide_it.html#platform)). Impostato Modello del dispositivo a Y2.
  - Scegli Inniclassic dentro Software.
  - Scegli la versione elencata per Y2.
  - Fare clic Installa / Ripristina.
  - Spegni e collega Y2 solo quando Updater CE lo richiede.

## Domande frequentiPosso ripristinare il software Y2 originale?

SÌ. Selezionare Y2 e Software originale in Updater CE. IL [Y2 guida al software stock](original-software-y2_it.html) copre il percorso di ritorno.Posso utilizzare Inniclassic su Y1?

SÌ. Lo stesso progetto pubblica anche Y1 pacchetti — rom.zip per Type A e rom_type_b.zip per Type B. Selezionare Y1 in Updater CE e installare la build Y1; IL [Pagina di installazione Y1](inniclassic-y1-software_it.html) lo copre.Cosa succede se l'installazione fallisce?

Annotare se il programma di aggiornamento ha avuto esito negativo prima o dopo il rilevamento di Y2, quindi controllare il cavo, la configurazione della piattaforma, il modello e i tempi di connessione in [risoluzione dei problemi](troubleshooting_it.html).
