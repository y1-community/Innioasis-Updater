Escolha o guia para o computador que você está usando. Cada versão possui a configuração da plataforma, as etapas do Updater CE e o caminho de volta ao estoque.[Guia do Windows](install/y2player-y2-windows.html)[guia macOS](install/y2player-y2-mac.html)[Guia Linux](install/y2player-y2-linux.html)

[Todos os guias Innioasis Y2](install/y2.html) · [Todos Y2Player guias](install/y2player.html)

## Y2Player etapas de instalação
  - Abra o Innioasis Updater CE no seu computador (se precisar do aplicativo, [Obter o Updater CE](guide_pt-BR.html#platform)). Definir Modelo do aparelho para Y2.
  - Escolher Y2Player em Software.
  - Escolha um lançamento listado para Y2.
  - Clique Instalar / Restaurar.
  - Desligue e conecte o Y2 no prompt ao vivo.

Alguns Y2 pacotes de instalação completa usam `rom_y2.zip`. Deixe o Updater escolher o pacote quando possível.

## Perguntas frequentesPosso voltar ao software original?

Sim. Selecione Y2 e Software Original em Updater CE e siga as instruções [Guia de restauração Y2](original-software-y2_pt-BR.html).Posso usar isso em um Y1?

Não. Esta página é para a entrada Y2Player Y2. Mantenha os pacotes Y1 e Y2 separados.E se o Y2 não for detectado?

Verifique a configuração da plataforma, o cabo, o estado de desligamento, a seleção do modelo e o tempo. Usar [solução de problemas](troubleshooting_pt-BR.html) antes de tentar a recuperação manual.
