# Reborn (Y2Linux) برای Innioasis Y2

یک توزیع سریع و هدفمند Debian Linux با یک رابط کاربری بومی چرخش کلیک برای Innioasis Y2، که دارای ثبات هدفون بلوتوث و توسعه فعال جامعه است.[راهنمای گام به گام Y2](guides/reborn-y2linux-y2.html)[چرا Y2Reborn؟](reborn-y2linux-benefits_fa.html)[دانلود نسخه ها](firmware_fa.html?model=Y2&software=reborn-y2linux-y2)

راهنمای نصب کامپیوتر شما

## Reborn (Y2Linux) را با رایانه خود روی Y2 خود نصب کنید

راهنمای رایانه ای را که استفاده می کنید انتخاب کنید. هر نسخه دارای راه اندازی پلت فرم، Updater CE مراحل و راه بازگشت به انبار است.[راهنمای ویندوز](install/reborn-y2linux-y2-windows.html)[راهنمای macOS](install/reborn-y2linux-y2-mac.html)[راهنمای لینوکس](install/reborn-y2linux-y2-linux.html)

[همه Innioasis راهنماهای Y2](install/y2.html) · [همه Reborn (Y2Linux) راهنماها](install/reborn.html)

## مراحل نصب
  - Updater CE را باز کنید. برای ویندوز، macOS و لینوکس موجود است.
  - Y2 را انتخاب کنید به عنوان مدل دستگاه
  - Reborn (Y2Linux) را انتخاب کنید به عنوان نرم افزار
  - روی Install / Restore کلیک کنید. صبر کنید تا Updater CE فایل ها را آماده کند.
  - در صورت درخواست، USB را وصل کنید. ابتدا Y2 را خاموش کنید.
  - Wi-Fi، بلوتوث و رادیو FM را تنظیم کنید

کپی کنید `system.img` یک بار به بازیکن Reborn بقیه کارها را انجام می دهد.[پایان راه اندازی →](y2reborn_wifibt_fa.html)
