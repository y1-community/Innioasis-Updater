# Rondo עבור Innioasis Y1

קושחה מינימליסטית של נגן גלגל קליקים שתוכננה במיוחד עבור החומרה הקיבולית Innioasis Y1 והתמקדה כולה בהשמעה מגיבה וניווט נקי.[מדריך Y1 שלב אחר שלב](guides/rondo-y1.html)[למה Rondo?](rondo-benefits_he.html)[הורד מהדורות](firmware_he.html?model=Y1&software=rondo-y1)

מדריך התקנת המחשב שלך

## התקן את Rondo ב-Y1 שלך עם המחשב שלך

בחר את המדריך עבור המחשב שבו אתה משתמש. לכל גרסה יש את הגדרת הפלטפורמה, Updater CE שלבים והדרך חזרה למלאי.[מדריך Windows](install/rondo-y1-windows.html)[מדריך macOS](install/rondo-y1-mac.html)[מדריך לינוקס](install/rondo-y1-linux.html)

[כל Innioasis מדריכי Y1](install/y1.html) · [כל המדריכים Rondo](install/rondo.html)

## שלבי התקנה
  - השקה Innioasis Updater לספירה במחשב Windows, Mac או Linux שלך.
  - בחר Y1 מהתפריט הנפתח דגם מכשיר.
  - בחר Rondo מהתפריט הנפתח תוכנה.
  - לחץ התקנה / שחזור והמתן עד שהכלי יוריד ויכין את הקבצים.
  - כאשר תתבקש על ידי Updater CE, כבה את Y1 וחבר את הכבל USB.
  - השלם את ההגדרה לאחר ההתקנה

בצע את השלבים ב [המדריך הזה](post_install_he.html?software=rondo-y1&model=Y1) להשלמת ההגדרה ב-Y1 שלך.[צפה במדריך](post_install_he.html?software=rondo-y1&model=Y1)
