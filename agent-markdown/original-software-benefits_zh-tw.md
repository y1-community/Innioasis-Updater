## 為什麼要使用或恢復原始軟體？

### 完整的主題庫支持

Y1 和 Y2 上的原始軟體可直接使用來自 [主題畫廊](https://themes.innioasis.app/?lang=zh-TW)。更改圖示、背景桌布、播放器錶盤和字體，而無需修改核心系統分區。

### 一切開箱即用

全面支援藍牙耳機和汽車音響、實體滾輪導航、硬體調頻收音機、有聲書書籤、電子書和影片播放，零手動設定。

### 安全恢復和解鎖基線

如果您想要從自訂韌體實驗中恢復或恢復無法啟動的播放器，Updater CE 可以透過單一指導步驟恢復原始軟體。
