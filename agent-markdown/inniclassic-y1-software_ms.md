# Install Inniclassic on the Y1.

Inniclassic is a community software project for the Y1, and the same project also publishes a Y2 build, so it is available on both players. This page gives you the Y1 search-friendly answer and links to the detailed connection steps.[Open the full Inniclassic guide](guides/inniclassic-y1.html)[Dapatkan ini dalam Updater CE](guide_ms.html?model=Y1&software=inniclassic-y1)[Mengapa Inniclassic?](inniclassic-benefits_ms.html)

## Inniclassic Y1 install steps
  - Buka Innioasis Updater CE pada komputer anda (jika anda memerlukan apl itu, [Dapatkan Updater CE](guide_ms.html#platform)). Tetapkan Model Peranti kepada Y1.
  - pilih Inniclassic dalam Perisian.
  - Pilih keluaran yang disenaraikan untuk Y1.
  - klik Pasang / Pulihkan.
  - Matikan dan sambungkan Y1 hanya apabila Updater CE bertanya.

ya. Pilih Y1 dan Perisian Asal dalam Updater CE. The [Panduan perisian stok Y1](original-software-y1_ms.html) meliputi laluan pulang.Bagaimana jika pemasangan gagal?

Note whether Updater failed before or after detecting the Y1, then check the cable, platform setup, model, and connection timing in [penyelesaian masalah](troubleshooting_ms.html).Can I use Inniclassic on Y2?

Yes. Inniclassic is available on both models — the same maintained project publishes a Y2 package from the same releases. Select Y2 in Updater CE and install the Y2 build; never flash a Y1 package to a Y2. The [Halaman pemasangan Y2](inniclassic-y2-software_ms.html) covers it.
