# Incorpora la guida all'installazione di Innioasis Updater - Innioasis Updater

# 🚀 Innioasis Updater - Guida all'installazione incorporabile

Questo è un widget di guida all'installazione completo e incorporabile che può essere facilmente integrato in qualsiasi sito web. È dotato di un interessante CTA popup nell'angolo in basso a destra che apre una guida di installazione completa per utenti Windows, macOS e Linux.

### 🎨 Bellissimo design

Design moderno e reattivo che funziona su tutti i dispositivi con supporto della modalità oscura

### 📱 Multipiattaforma

Guide di installazione complete per Windows, macOS e Linux con istruzioni dettagliate

### 🔧 Integrazione facile

Basta copiare e incollare lo snippet: non sono necessarie dipendenze o configurazioni complesse

### 💾 Archiviazione intelligente

Ricorda se gli utenti hanno chiuso il banner per evitare di essere invadenti

## 📋 Istruzioni per l'integrazione

Per aggiungere la guida all'installazione di Innioasis Updater al tuo sito web, copia e incolla semplicemente questo snippet di codice nel tuo codice HTML: <!-- Innioasis Widget guida all'installazione dell'aggiornamento --> <script> (function() { // Crea e inserisci il widget const script = document.createElement('script'); script.src = 'https://your-domain.com/innioasis-embed.html'; script.async = true; // Alternativa: carica dal file locale // script.src = './innioasis-embed.html'; document.head.appendChild(script); // Create iframe container const iframe = document.createElement('iframe'); iframe.src = 'https://your-domain.com/innioasis-embed.html'; iframe.style.cssText = ` position: fixed; bottom: 20px; right: 20px; width: 400px; height: 200px; border: none; z-index: 999999; eventi puntatore: nessuno `; // Rendi iframe interattivo iframe.onload = funzione() { iframe.style.pointerEvents = 'auto'; </script> 📋 Copia il Codice Integrazione

## 🌐 Requisiti di hosting

Per utilizzare questo widget sul tuo sito web, devi:
  - Carica il `innioasis-embed.html` file sul tuo server web
  - Aggiorna gli URL nello snippet di integrazione in modo che puntino al tuo server
  - Assicurati che il tuo server supporti HTTPS (richiesto per i browser moderni)
  - Testa il widget sul tuo sito web per assicurarti che funzioni correttamente
