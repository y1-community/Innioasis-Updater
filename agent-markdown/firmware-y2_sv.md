# Firmware för Innioasis Y2

Y2 har bättre ljudhårdvara, Bluetooth och en filhanterare. Välj ett anpassat system, en Linux-build eller den officiella programvaran att återställa.[Bläddra Y2 Nedladdningar](firmware_sv.html?model=Y2)[Hämta Updater CE](guide_sv.html#platform)[Y2 Temaguide](https://themes.innioasis.app/y2-themes.html?lang=sv)

## Tillgängliga operativsystem för Innioasis Y2

Välj vad du vill köra på din Y2:

### [Reborn (Y2Linux)](reborn-y2linux-benefits_sv.html)

Native inbäddade Linux OS som kombinerar Buildroot, LVGL, PipeWire och MPD. Erbjuder 3-sekunders starttider, äkta återkopplingsfixar för Bluetooth-hörlurar och uppspelning utan mellanrum.[Y2Reborn Guide →](guides/reborn-y2linux-y2.html)

### [Rockbox för Y2](rockbox-benefits_sv.html)

Den ultimata audiofila firmware portad till Innioasis Y2. Parametrisk utjämning, anpassade typsnitt, korsmatning och omfattande stöd för pluginbibliotek.[Y2 Rockbox Guide →](guides/rockbox-y2.html)

### [Solar för Y2](solar-benefits_sv.html)

Modernt, flytande Flutter-baserat musikspelaregränssnitt för Y2. Innehåller rika visualiserare, stor albumomslagspresentation och gestnavigering.[Solar Y2 Guide →](guides/solar-y2.html)

### [Y2Player](y2player-benefits_sv.html)

Lätt gemenskapsljudspelare gjord för Y2 hårdvara med enkel mappsökning och snabb indexskanning.[Y2Player Guide →](guides/y2player-y2.html)

### [Originalprogramvara (fabriksåterställning)](original-software-benefits_sv.html)

Officiell firmware-bild (rom_y2.zip) för att återställa Innioasis Y2 till det ursprungliga fabriksskicket, komplett med Themes Gallery-skalstöd.[Återställ Y2 Guide →](guides/restore-original-y2.html)

## Installera firmware på din Innioasis Y2

Updater CE tar tag i rätt filer och kontrollerar drivrutinen innan den blinkar:
  - Starta Innioasis Updater CE: Tillgänglig på macOS, Linux och Windows.
  - Set modell: Välj Y2 i menyn Enhetsmodell.
  - Välj operativsystem: Välj Reborn, Rockbox, Solar eller originalprogramvara.
  - Flash säkert: Följ anvisningarna på skärmen för att ansluta din enhet över USB för en ren, verifierad blixt.
