# Installera Inniclassic på Y2.

Inniclassic är tillgängligt för Innioasis Y2, och samma projekt bygger även Y1-paketen. Den här sidan ger dig Y2 översikten och länkar till hela handledningen.[Öppna hela Inniclassic guiden](guides/inniclassic-y2.html)[Hämta detta i Updater CE](guide_sv.html?model=Y2&software=inniclassic-y2)[Varför Inniclassic?](inniclassic-benefits_sv.html)

## Installera Inniclassic på din Y2 med din dator

Välj guiden för den dator du använder. Varje version har plattformsinställningen, Updater CE steg och vägen tillbaka till lager.[Windows guide](install/inniclassic-y2-windows.html)[macOS guide](install/inniclassic-y2-mac.html)[Linux guide](install/inniclassic-y2-linux.html)

[Alla Innioasis Y2-guider](install/y2.html) · [Alla Inniclassic guider](install/inniclassic.html)

## Inniclassic Y2 installationssteg
  - Öppna Innioasis Updater CE på din dator (om du behöver appen, [Hämta Updater CE](guide_sv.html#platform)). Ställ in Enhetsmodell till Y2.
  - Välj Inniclassic i Programvara.
  - Välj utgåvan som listas för Y2.
  - Klicka Installera / Återställ.
  - Stäng av och anslut Y2 endast när Updater CE frågar.

## Vanliga frågorKan jag återställa standardprogramvaran Y2?

Ja. Välj Y2 och originalprogramvara i Updater CE. Den [Y2 lagerprogramvaruguide](original-software-y2_sv.html) täcker returvägen.Kan jag använda Inniclassic på Y1?

Ja. Samma projekt publicerar Y1 paket också — rom.zip för Type A och rom_type_b.zip för Type B. Välj Y1 i Updater CE och installera Y1 build; den [Y1 installationssida](inniclassic-y1-software_sv.html) täcker det.Vad händer om installationen misslyckas?

Notera om uppdateringen misslyckades före eller efter att Y2 upptäcktes], kontrollera sedan kabel, plattformsinställningar, modell och anslutningstid i [felsökning](troubleshooting_sv.html).
