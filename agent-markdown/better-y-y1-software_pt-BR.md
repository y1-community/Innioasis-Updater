# Instale Better-Y no Y1.

Better-Y fornece uma experiência de estoque aprimorada para o Innioasis Y1 com divisão de tags, números de faixas de álbuns, atalhos em reprodução e cache de RAM mais suave, mantendo 100% de compatibilidade de tema.[Abra o guia Better-Y completo](guides/better-y-y1.html)[Obter no Updater CE](guide_pt-BR.html?model=Y1&software=better-y-y1)[Por que Better-Y?](better-y-benefits_pt-BR.html)

## Instale Better-Y em seu Y1 com seu computador

Escolha o guia para o computador que você está usando. Cada versão possui a configuração da plataforma, as etapas do Updater CE e o caminho de volta ao estoque.[Guia do Windows](install/better-y-y1-windows.html)[guia macOS](install/better-y-y1-mac.html)[Guia Linux](install/better-y-y1-linux.html)

## Better-Y Y1 etapas de instalação
  - Abra o Innioasis Updater CE no seu computador (se precisar do aplicativo, [Obter o Updater CE](guide_pt-BR.html#platform)). Definir Modelo do aparelho para Y1.
  - Escolher Better-Y em Software.
  - Escolha o lançamento listado para Y1.
  - Clique Instalar / Restaurar.
  - Desligue e conecte o Y1 somente quando o Updater CE solicitar.

## Perguntas frequentesO que foi melhorado em relação ao firmware padrão?

Better-Y adiciona números de faixa, divide tags de vários artistas, usa títulos reais e adiciona atalhos de reprodução, além de correções para cache e Bluetooth. Os mesmos temas de antes.Posso restaurar o software padrão Y1?

Sim. Selecione Y1 e Software Original em Updater CE. O [Y1 guia de software de estoque](original-software-y1_pt-BR.html) cobre o caminho de retorno.Posso usar meus temas existentes?

Sim! Better-Y é baseado no estoque oficial 3.1.2 e mantém 100% de compatibilidade com todos os temas personalizados da Galeria de Temas.E se a instalação falhar?

Observe se o Updater falhou antes ou depois de detectar o Y1, então verifique o cabo, configuração da plataforma, modelo e tempo de conexão em [solução de problemas](troubleshooting_pt-BR.html).
