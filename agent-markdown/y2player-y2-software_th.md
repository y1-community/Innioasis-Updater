# ติดตั้ง Y2Player บน Y2

Y2Player ถูกสร้างขึ้นสำหรับ Y2 เลือกรุ่นของคุณก่อน จะได้ไม่เผลอใช้แพ็คเกจ Y1[เปิดคำแนะนำ Y2Player ฉบับเต็ม](guides/y2player-y2.html)[รับสิ่งนี้ใน Updater CE](guide_th.html?model=Y2&software=y2player-y2)[ทำไมต้อง Y2Player?](y2player-benefits_th.html)

คู่มือการติดตั้งสำหรับคอมพิวเตอร์ของคุณ

## ติดตั้ง Y2Player บน Y2 ด้วยคอมพิวเตอร์ของคุณ

เลือกคำแนะนำสำหรับคอมพิวเตอร์ที่คุณใช้ ทุกรุ่นมีการตั้งค่าแพลตฟอร์ม ขั้นตอน Updater CE และวิธีคืนสินค้าในสต็อก[คู่มือวินโดวส์](install/y2player-y2-windows.html)[คู่มือ macOS](install/y2player-y2-mac.html)[คู่มือลินุกซ์](install/y2player-y2-linux.html)

[คำแนะนำ Innioasis Y2 ทั้งหมด](install/y2.html) · [คำแนะนำ Y2Player ทั้งหมด](install/y2player.html)

## Y2Player ขั้นตอนการติดตั้ง
  - เปิด Innioasis Updater CE บนคอมพิวเตอร์ของคุณ (หากคุณต้องการแอป [รับ Updater CE](guide_th.html#platform)). ชุด รุ่นอุปกรณ์ ถึง Y2.
  - เลือก Y2Player ใน ซอฟต์แวร์.
  - เลือกรุ่นที่แสดงรายการสำหรับ Y2
  - คลิก ติดตั้ง / คืนค่า.
  - ปิดเครื่องและเชื่อมต่อ Y2 เมื่อพร้อมท์แสดงสด

ใช้แพ็คเกจการติดตั้งแบบเต็ม Y2 บางส่วน `rom_y2.zip`. ให้ Updater เลือกแพ็คเกจเมื่อเป็นไปได้

## คำถามที่พบบ่อยฉันสามารถกลับไปใช้ซอฟต์แวร์ดั้งเดิมได้หรือไม่

ใช่. เลือก Y2 และซอฟต์แวร์ต้นฉบับใน Updater CE จากนั้นปฏิบัติตาม [คู่มือการคืนค่า Y2](original-software-y2_th.html).ฉันสามารถใช้สิ่งนี้กับ Y1 ได้หรือไม่

ไม่ หน้านี้มีไว้สำหรับรายการ Y2Player Y2 เก็บแพ็คเกจ Y1 และ Y2 แยกกันจะเกิดอะไรขึ้นหากตรวจไม่พบ Y2

ตรวจสอบการตั้งค่าแพลตฟอร์ม สายเคเบิล สถานะการปิดเครื่อง การเลือกรุ่น และเวลา ใช้ [การแก้ไขปัญหา](troubleshooting_th.html) ก่อนที่จะลองกู้คืนด้วยตนเอง
