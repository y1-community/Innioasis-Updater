# Install Android 4.4 (Dev) on the Y2.

Android 4.4 is a community development ROM for testing and hacking on Innioasis Y2 hardware. This page links to the full tutorial and release list.[Open the full Android 4.4 (Dev) guide](guides/android-4-4-y2.html)[احصل على هذا في Updater CE](guide_ar.html?model=Y2&software=android-4-4-y2)[مصدر المشروع](https://github.com/y1-community/y2-ata-rom)

## Install Android development ROM on your Y2 with your computer

اختر دليل الكمبيوتر الذي تستخدمه. يحتوي كل إصدار على إعداد النظام الأساسي وخطوات Updater CE وطريقة العودة إلى المخزون.[دليل ويندوز](install/android-4-4-y2-windows.html)[دليل ماك](install/android-4-4-y2-mac.html)[دليل لينكس](install/android-4-4-y2-linux.html)

[جميع أدلة Innioasis Y2](install/y2.html) · [جميع أدلة ROM لتطوير Android](install/android-dev.html)

## Android 4.4 Y2 install steps
  - افتح Innioasis Updater CE على جهاز الكمبيوتر الخاص بك (إذا كنت بحاجة إلى التطبيق، [احصل على Updater CE](guide_ar.html#platform)). تعيين طراز الجهاز ل Y2.
  - اختر أندرويد 4.4 (مطور) في البرنامج.
  - Choose the release listed for Y2.
  - انقر تثبيت / استعادة.
  - قم بإيقاف تشغيل Y2 وتوصيله فقط عندما يطلب منك Updater CE.
