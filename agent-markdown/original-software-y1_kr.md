## 업데이터로 설치 또는 복원

업데이터는 Y1이 현재 원본 소프트웨어를 실행 중이든 커뮤니티 프로젝트를 실행 중이든 동일한 안내 흐름을 사용합니다.
  - 컴퓨터에서 Innioasis Updater CE를 엽니다(앱이 필요한 경우, [Updater CE 받기](guide_ko.html#platform)). 세트 기기 모델 에 Y1.
  - 선택 원본 소프트웨어 안으로 소프트웨어 (또는 사용 [이것을 Updater CE에서 얻으세요](guide_ko.html?model=Y1&software=original-y1) 안내된 단계로 이동하려면)
  - 클릭 설치 / 복원 앱이 패키지를 준비하도록 합니다.
  - 라이브 프롬프트가 나타날 때만 전원을 끄고 Y1을 연결하십시오.

수동으로 다운로드하는 경우 일반적인 전체 설치 패키지 이름은 다음과 같습니다. `rom.zip`. Updater에서 모델을 선택하는 것이 파일을 선택하는 더 안전한 방법입니다.

## 자주 묻는 질문Rockbox 또는 다른 사용자 정의 소프트웨어에서 복원할 수 있습니까?

예, Y1 모델 및 Y1 원본 소프트웨어 경로를 사용합니다. 먼저 시스템 파일을 삭제하지 말고 Y2 패키지를 대체하지 마십시오.내 Y1이 감지되지 않으면 어떻게 되나요?

데이터 케이블, 컴퓨터 설정, 연결 타이밍을 확인하세요. 플레이어의 전원을 끄고 업데이터 프롬프트에서만 연결해야 합니다.Y1에는 어떤 패키지를 사용해야 합니까?

업데이터에서 선택한 플레이어에 인쇄된 모델을 유지하세요. Y1 및 Y2 패키지는 별개입니다. 릴리스 목록이 해당 모델과 일치하지 않으면 중지하십시오.
