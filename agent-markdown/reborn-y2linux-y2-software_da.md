# Reborn (Y2Linux) for Innioasis Y2

En hurtig, specialbygget Debian Linux-distribution med en indbygget klikhjulsbrugergrænseflade til Innioasis Y2, med Bluetooth-hovedtelefonstabilitet og aktiv samfundsudvikling.[Trin-for-trin Y2 Vejledning](guides/reborn-y2linux-y2.html)[Hvorfor Y2Reborn?](reborn-y2linux-benefits_da.html)[Download udgivelser](firmware_da.html?model=Y2&software=reborn-y2linux-y2)

## Installer Reborn (Y2Linux) på din Y2 med din computer

Vælg vejledningen til den computer, du bruger. Hver version har platformsopsætningen, Updater CE trin og vejen tilbage til lageret.[Windows guide](install/reborn-y2linux-y2-windows.html)[macOS guide](install/reborn-y2linux-y2-mac.html)[Linux guide](install/reborn-y2linux-y2-linux.html)

[Alle Innioasis Y2 guider](install/y2.html) · [Alle Reborn (Y2Linux) guider](install/reborn.html)

## Installationstrin
  - Åbn Updater CE. Tilgængelig til Windows, macOS og Linux.
  - Vælg Y2 som enhedsmodel.
  - Vælg Reborn (Y2Linux) som softwaren.
  - Klik på Installer / Gendan. Vent, mens Updater CE forbereder filerne.
  - Tilslut USB, når du bliver bedt om det. Sluk for Y2 først.
  - Konfigurer Wi-Fi, Bluetooth og FM-radio

Kopiér `system.img` til spilleren én gang. Reborn klarer resten.[Afslut opsætning →](y2reborn_wifibt_da.html)
