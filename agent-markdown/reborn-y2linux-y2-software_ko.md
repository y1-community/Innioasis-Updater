# Innioasis Y2에 대한 Reborn (Y2Linux)

Bluetooth 헤드폰 안정성과 활발한 커뮤니티 개발을 특징으로 하는 Innioasis Y2용 기본 클릭휠 사용자 인터페이스를 갖춘 빠르고 특수 제작된 Debian Linux 배포판입니다.[단계별 Y2 가이드](guides/reborn-y2linux-y2.html)[왜 Y2Reborn인가요?](reborn-y2linux-benefits_ko.html)[릴리스 다운로드](firmware_ko.html?model=Y2&software=reborn-y2linux-y2)

## 컴퓨터를 사용하여 Y2에 Reborn (Y2Linux)을(를) 설치합니다.

사용 중인 컴퓨터에 대한 가이드를 선택하세요. 모든 버전에는 플랫폼 설정, Updater CE 단계 및 재고로 돌아가는 방법이 있습니다.[윈도우 가이드](install/reborn-y2linux-y2-windows.html)[macOS 가이드](install/reborn-y2linux-y2-mac.html)[리눅스 가이드](install/reborn-y2linux-y2-linux.html)

[모든 Innioasis Y2 가이드](install/y2.html) · [모든 Reborn (Y2Linux) 가이드](install/reborn.html)

## 설치 단계
  - 업데이터 CE를 엽니다. Windows, macOS, Linux에서 사용할 수 있습니다.
  - Y2을 선택하세요 장치 모델로.
  - Reborn (Y2Linux) 선택 소프트웨어로.
  - 설치/복원을 클릭하세요. Updater CE가 파일을 준비하는 동안 기다리십시오.
  - 요청 시 USB을 연결합니다. 먼저 Y2의 전원을 끄세요.
  - Wi-Fi, Bluetooth, FM 라디오 설정

복사 `system.img` 플레이어에게 한 번. Reborn이 나머지 작업을 수행합니다.[설정 완료 →](y2reborn_wifibt_ko.html)
