Inniclassic · Innioasis Y2

# Установите Inniclassic на Y2.

Inniclassic доступен для Innioasis Y2, и тот же проект также собирает пакеты Y1. На этой странице представлен обзор Y2 и ссылки на полное руководство.[Открыть полное руководство Inniclassic](guides/inniclassic-y2.html)[Получите это в Updater CE](guide_ru.html?model=Y2&software=inniclassic-y2)[Почему Inniclassic?](inniclassic-benefits_ru.html)

Руководство по установке для вашего компьютера

## Установите Inniclassic на свой Y2 с помощью компьютера.

Выберите руководство для компьютера, который вы используете. В каждой версии есть настройка платформы, Updater CE шагов и возврат к стоку.[Руководство по Windows](install/inniclassic-y2-windows.html)[руководство по macOS](install/inniclassic-y2-mac.html)[Руководство по Linux](install/inniclassic-y2-linux.html)

[Все Innioasis Y2 руководства](install/y2.html) · [Все Inniclassic руководства](install/inniclassic.html)

## Inniclassic Y2 шаги установки
  - Откройте Innioasis Updater CE на своем компьютере (если вам нужно приложение, [Скачать Updater CE](guide_ru.html#platform)). Набор Модель устройства в адрес Y2.
  - Выбирать Inniclassic в Программное обеспечение.
  - Выберите выпуск, указанный для Y2.
  - Нажмите Установить / Восстановить.
  - Выключите питание и подсоедините Y2 только при запросе Updater CE.

## Вопросы и ответыМогу ли я восстановить стандартное программное обеспечение Y2?

Да. Выберите Y2 и оригинальное программное обеспечение в Updater CE. [Y2 руководство по стандартному программному обеспечению](original-software-y2_ru.html) перекрывает обратный путь.Могу ли я использовать Inniclassic на Y1?

Да. Тот же проект также публикует Y1 пакетов — rom.zip для Type A и rom_type_b.zip для Type B. Выберите Y1 в Updater CE и установите сборку Y1; тот [Y1 страница установки](inniclassic-y1-software_ru.html) покрывает это.Что делать, если установка не удалась?

Обратите внимание, произошел сбой программы обновления до или после обнаружения Y2, затем проверьте кабель, настройку платформы, модель и время подключения в [Поиск неисправностей](troubleshooting_ru.html).

## Используйте маршрут с гидом

Впервые пользуетесь программой обновлений? См. пошаговую настройку, чтобы [Скачать Updater CE](guide_ru.html#platform) в Windows, macOS или Linux перед подключением плеера.
