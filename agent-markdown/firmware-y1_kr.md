# Innioasis Y1용 펌웨어

Y1은 사용자 정의 시스템의 선택 폭이 가장 넓습니다. 아래의 모든 항목은 여기에서 호스팅되고 확인되며 Updater CE를 사용하여 한 번의 클릭으로 설치됩니다.[Y1 다운로드 찾아보기](firmware_ko.html?model=Y1)[Updater CE 받기](guide_ko.html#platform)[테마 갤러리](https://themes.innioasis.app/?lang=ko)

## Innioasis Y1에 사용 가능한 운영 체제

Y1은 오디오 애호가 코덱 지원 빌드, 최신 실행 프로그램 및 공장 복원을 포함한 여러 소프트웨어 시스템을 실행합니다. 듣는 방식에 맞는 것을 선택하세요.

### [Rockbox](rockbox-benefits_ko.html)

오픈 소스 오디오 재생의 표준. 파라메트릭 EQ, 끊김 없는 FLAC/MP3 재생, 테마 및 글꼴 팩을 Updater CE에 직접 설치할 수 있습니다.[Y1 Rockbox 안내 →](guides/rockbox-y1.html)

### [Better-Y](better-y-benefits_ko.html)

Bluetooth 안정성 패치, 볼륨 곡선 조정 및 100% 테마 갤러리 호환성을 갖춘 원래 펌웨어의 향상된 파생물입니다.[Better-Y 안내 →](guides/better-y-y1.html)

### [Solar](solar-benefits_ko.html)

Flutter로 제작된 최신 오픈 소스 음악 플레이어로 부드러운 60fps 애니메이션, 앨범 아트 그리드 및 현대적인 타이포그래피를 제공합니다.[Solar Y1 안내 →](guides/solar-y1.html)

### [Rondo](rondo-benefits_ko.html)

빠르고 반응성이 뛰어난 탐색 기능을 갖춘 로컬 트랙 및 스트리밍용 오픈 소스 Y1 실행기입니다.[Rondo Y1 안내 →](guides/rondo-y1.html)

### [Koensayr](koensayr-benefits.html)

자체 아이콘, 더 나은 배터리 보정 및 스톡 테마 지원을 갖춘 맞춤형 펌웨어 빌드입니다.[Koensayr 안내 →](guides/koensayr-y1.html)

### [원본 소프트웨어(재고 복원)](original-software-benefits_ko.html)

Type A (v2.0.0+) 및 Type B (v1.x) Y1 플레이어의 공장 펌웨어 이미지를 정리합니다. 안전하게 벽돌을 제거하거나 장치를 공장 상태로 복원하세요.[Y1 가이드 복원 →](guides/restore-original-y1.html)

## Y1 펌웨어 설치 또는 업데이트 방법

멀티 플랫폼 소프트웨어 제품군을 사용하면 Innioasis Y1을(를) 업그레이드하거나 브릭 해제하는 것이 간단합니다.
  - Innioasis 업데이터 열기 CE: macOS, Windows 또는 Linux에서 업데이터를 실행합니다.
  - 모델 선택 Y1: 선택 Y1 장치 모델 드롭다운에서
  - 운영 체제를 선택하세요: Rockbox, Better-Y, Solar 또는 원본 소프트웨어를 선택합니다.
  - 설치를 클릭하세요. Updater CE는 개발자 릴리스에서 직접 펌웨어 패키지를 다운로드합니다. 메시지가 표시되면 전원이 꺼진 Y1을 USB을 통해 연결하여 깜박이기 시작합니다.
