# שחזר את התוכנה המקורית ב-Innioasis Y1 שלך.

מחפש תוכנת מניות Y1, שחזור מפעל, או דרך חזרה מ-Rockbox או תוכנה מותאמת אישית אחרת? זהו מסלול Updater המתאים לדגם.[פתח את מדריך התוכנה המקורית המלא](guides/restore-original-y1.html)[קבל את זה ב-Updater CE](guide_he.html?model=Y1&software=original-y1)[עיין במהדורות Y1](firmware_he.html#y1)

מדריך התקנת המחשב שלך

## שחזר תוכנה מקורית ב-Y1 באמצעות המחשב שלך

בחר את המדריך עבור המחשב שבו אתה משתמש. לכל גרסה יש את הגדרת הפלטפורמה, Updater CE שלבים והדרך חזרה למלאי.[מדריך Windows](install/original-y1-windows.html)[מדריך macOS](install/original-y1-mac.html)[מדריך לינוקס](install/original-y1-linux.html)

[כל Innioasis מדריכי Y1](install/y1.html) · [כל מדריכי התוכנה המקורית](install/original-software.html)

## התקן או שחזר אותו באמצעות Updater

Updater משתמש באותה זרימה מודרכת בין אם ה-Y1 מריץ כעת את התוכנה המקורית שלו או פרויקט קהילתי.
  - פתח את Innioasis Updater CE במחשב שלך (אם אתה צריך את האפליקציה, [הורדת Updater CE](guide_he.html#platform)). סט דגם המכשיר ל Y1.
  - בחר תוכנה מקורית ב תוכנה (או להשתמש [קבל את זה ב-Updater CE](guide_he.html?model=Y1&software=original-y1) לקפוץ לשלבים המודרכים).
  - לחץ התקנה / שחזור ותנו לאפליקציה להכין את החבילה.
  - כבה וחבר את Y1 רק כאשר ההנחיה החיה מבקשת.

בעת הורדה ידנית, שמה של החבילה הרגילה להתקנה מלאה `rom.zip`. בחירת הדגם ב- Updater היא הדרך הבטוחה יותר לבחור קבצים.

## שאלות נפוצותהאם אוכל לשחזר מ-Rockbox או מתוכנה מותאמת אישית אחרת?

כן, השתמש במודל Y1 ובנתיב התוכנה המקורית Y1. אל תמחק תחילה קובצי מערכת ואל תחליף חבילה Y2.מה אם Y1 שלי לא מזוהה?

בדוק את כבל הנתונים, הגדרת המחשב ותזמון החיבור. יש לכבות את הנגן ולחבר אותו רק בהנחיית Updater.באיזו חבילה עלי להשתמש עבור ה-Y1 שלי?

שמור את הדגם מודפס על הנגן שלך שנבחר ב-Updater. חבילות Y1 ו-Y2 נפרדות - הפסק אם רשימת ההפצות אינה תואמת לדגם שלך.

## שמור על השלב הבא פשוט

פעם ראשונה שאתה משתמש ב-Updater? עיין בהגדרה המודרכת ל [הורדת Updater CE](guide_he.html#platform), קרא את המפורט [Y1 הדרכה לשחזור](guides/restore-original-y1.html), או להשתמש [פתרון בעיות](troubleshooting_he.html).
