# Install Android 4.2 (Dev) on the Y1.

Android 4.2 is a community development ROM for testing and hacking on Innioasis Y1 hardware. This page links to the full tutorial and release list.[Open the full Android 4.2 (Dev) guide](guides/android-4-2-y1.html)[Obțineți asta în Updater CE](guide_ro.html?model=Y1&software=android-4-2-y1)[Sursa proiectului](https://github.com/y1-community/y1-ata-rom)

## Install Android development ROM on your Y1 with your computer

Alegeți ghidul pentru computerul pe care îl utilizați. Fiecare versiune are configurarea platformei, Updater CE pași și calea de întoarcere la stoc.[Ghidul Windows](install/android-4-2-y1-windows.html)[ghid macOS](install/android-4-2-y1-mac.html)[Ghid Linux](install/android-4-2-y1-linux.html)

[Toate ghidurile Innioasis Y1](install/y1.html) · [Toate ghidurile de dezvoltare Android ROM](install/android-dev.html)

## Android 4.2 Y1 install steps
  - Deschideți Innioasis Updater CE pe computer (dacă aveți nevoie de aplicație, [Obține Updater CE](guide_ro.html#platform)). Setați Model dispozitiv la Y1.
  - Alege Android 4.2 (dezvoltare) in Software.
  - Alegeți versiunea listată pentru Y1.
  - Faceți clic Instalează / Restaurează.
  - Opriți și conectați Y1 numai când Updater CE vă cere.
