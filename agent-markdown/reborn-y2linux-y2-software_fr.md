# Reborn (Y2Linux) pour Innioasis Y2

Une distribution Debian Linux rapide et spécialement conçue avec une interface utilisateur native à molette cliquable pour le Innioasis Y2, offrant la stabilité des écouteurs Bluetooth et le développement actif de la communauté.[Guide étape par étape Y2](guides/reborn-y2linux-y2.html)[Pourquoi Y2Reborn ?](reborn-y2linux-benefits_fr.html)[Télécharger les versions](firmware_fr.html?model=Y2&software=reborn-y2linux-y2)

## Installez Reborn (Y2Linux) sur votre Y2 avec votre ordinateur

Choisissez le guide correspondant à l'ordinateur que vous utilisez. Chaque version comprend la configuration de la plate-forme, Updater CE étapes et le chemin de retour au stock.[Guide Windows](install/reborn-y2linux-y2-windows.html)[Guide macOS](install/reborn-y2linux-y2-mac.html)[Guide Linux](install/reborn-y2linux-y2-linux.html)

[Tous les Innioasis guides Y2](install/y2.html) · [Tous les guides Reborn (Y2Linux)](install/reborn.html)

## Étapes d'installation
  - Ouvrez Updater CE. Disponible pour Windows, macOS et Linux.
  - Sélectionnez Y2 comme modèle d'appareil.
  - Sélectionnez Reborn (Y2Linux) comme le logiciel.
  - Cliquez sur Installer/Restaurer. Attendez pendant que Updater CE prépare les fichiers.
  - Connectez USB lorsque cela vous est demandé. Éteignez d'abord le Y2.
  - Configurer le Wi-Fi, le Bluetooth et la radio FM

Copier `system.img` au joueur une fois. Reborn fait le reste.[Terminer la configuration →](y2reborn_wifibt_fr.html)
