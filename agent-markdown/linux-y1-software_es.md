# Instale Linux en Y1.

Linux para Y1 es un kernel de Linux comunitario experimental y un puerto rootfs para el hardware Innioasis Y1. Esta página enlaza con la guía de instalación completa y las versiones.[Abra la guía completa de Linux para Y1 (Dev)](guides/linux-y1.html)[Obtener en Updater CE](guide_es.html?model=Y1&software=linux-y1)[Fuente del proyecto](https://github.com/y1-community/y1-linux-rom)

Guía de instalación para su computadora

## Instale Linux para Y1 (Dev) en su Y1 con su computadora

Elija la guía para la computadora que está utilizando. Cada versión tiene la configuración de la plataforma, Updater CE pasos y el camino de regreso al stock.[guía de windows](install/linux-y1-windows.html)[guía de macos](install/linux-y1-mac.html)[guía de linux](install/linux-y1-linux.html)

[Todas las Innioasis Y1 guías](install/y1.html) · [Todas las guías de Linux para Y1 (Dev)](install/linux-dev.html)

## Pasos de instalación de Linux Y1
  - Abra Innioasis Updater CE en su computadora (si necesita la aplicación, [Obtener Updater CE](guide_es.html#platform)). conjunto Modelo del dispositivo a Y1.
  - elegir Linux para Y1 (desarrollador) en Software.
  - Elija la versión listada para Y1.
  - Haga clic Instalar / Restaurar.
  - Apague y conecte el Y1 solo cuando Updater CE lo solicite.

## Preguntas frecuentes¿Puedo restaurar el software Y1 original?

Sí. Seleccione Y1 y Software original en Updater CE. el [Guía de software de stock Y1](original-software-y1_es.html) cubre el camino de regreso.¿Es esta una interfaz de usuario cotidiana?

Este es un puerto experimental para desarrolladores y expertos en Linux. Las instrucciones de la terminal y la consola se encuentran en los documentos del proyecto.
