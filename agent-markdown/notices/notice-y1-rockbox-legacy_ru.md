# Rockbox Y1 Предупреждение о совместимости

Эта версия Rockbox-Y1 предшествует версии 0.5 и несовместима с устройствами Y1, поставляемыми с прошивкой 3.0.7 или более поздней версии. Перепрошивка предотвратит загрузку.

Модели: Y1 · Программное обеспечение: rockbox · Версия v0.4.*,0.4.*,v0.3.*,0.3.*,v0.2.*,0.2.*,v0.1.*,0.1.*

Этот выпуск Rockbox-Y1 предшествует версии 0.5. Он несовместим с оборудованием Innioasis Y1, поставляемым после марта 2026 г., с предустановленной Innioasis ОС 3.0.7. Прошивка этой устаревшей сборки на этих устройствах предотвратит загрузку до тех пор, пока она не будет восстановлена ​​через [Механизм обновления CE SP Flash Tool](https://innioasis.app/Troubleshooting/recover-non-booting-device.html#sp-flash-tool-engine).
