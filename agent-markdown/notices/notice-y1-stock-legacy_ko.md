# 원본 소프트웨어 Y1 호환성 경고

이 원본 소프트웨어 릴리스는 3.0.7 이전 버전이며 호환 가능한 빌드가 설치될 때까지 최신 Y1 하드웨어에서 부팅되지 않습니다.

모델: Y1 · 소프트웨어: y1-stock-rom, y1-stock-rom-mirror · 버전 v3.0.0,3.0.0,v3.0.1,3.0.1,v3.0.2,3.0.2,v3.0.3,3.0.3,v3.0.4,3.0.4,v3.0.5,3.0.5,v3.0.6,3.0.6,v2.*,2.*,v1.*,1.*

이 원본 소프트웨어 릴리스는 3.0.7 이전 버전입니다. Innioasis OS 3.0.7 이상으로 제조된 Y1 장치와 호환되지 않습니다. 이를 깜박이면 다음을 사용하여 3.0.7 이상이 설치될 때까지 장치가 부팅되지 않는 상태로 유지됩니다. [업데이터 CE의 SP Flash Tool 엔진](https://innioasis.app/Troubleshooting/recover-non-booting-device.html#sp-flash-tool-engine).
