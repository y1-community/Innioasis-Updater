# تحذير توافق البرنامج الأصلي Y1

يسبق إصدار البرنامج الأصلي الإصدار 3.0.7 وسيمنع التشغيل على أجهزة Y1 الأحدث حتى يتم تثبيت إصدار متوافق.

النماذج: Y1 · البرمجيات: y1-stock-rom، y1-stock-rom-mirror · الإصدار v3.0.0,3.0.0,v3.0.1,3.0.1,v3.0.2,3.0.2,v3.0.3,3.0.3,v3.0.4,3.0.4,v3.0.5,3.0.5,v3.0.6,3.0.6,v2.*,2.*,v1.*,1.*

يسبق إصدار البرنامج الأصلي الإصدار 3.0.7. وهو غير متوافق مع الوحدات Y1 المصنعة بنظام التشغيل Innioasis OS 3.0.7 أو الأحدث. سيؤدي وميضه إلى ترك الجهاز في حالة عدم التشغيل حتى يتم تثبيت الإصدار 3.0.7 أو أعلى باستخدام [محرك التحديث CE SP Flash Tool](https://innioasis.app/Troubleshooting/recover-non-booting-device.html#sp-flash-tool-engine).
