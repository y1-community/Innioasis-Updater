# Rockbox Y1 相容性警告

此 Rockbox-Y1 版本早於 0.5，並且與附帶韌體 3.0.7 或更高版本的 Y1 裝置不相容。閃爍會阻止啟動。

型號：Y1 · 軟體：rockbox · 版本 v0.4.*,0.4.*,v0.3.*,0.3.*,v0.2.*,0.2.*,v0.1.*,0.1.*

此 Rockbox-Y1 版本早於版本 0.5。它與 2026 年 3 月後發貨且預裝 Innioasis OS 3.0.7 的 Innioasis Y1 硬體不相容。在這些裝置上刷新此舊版本將阻止啟動，直到透過恢復 [更新程式 CE 的 SP Flash Tool 引擎](https://innioasis.app/Troubleshooting/recover-non-booting-device.html#sp-flash-tool-engine).
