# 原始软件Y1兼容性警告

此原始软件版本早于 3.0.7，并且在安装兼容版本之前将阻止在较新的 Y1 硬件上启动。

型号：Y1 · 软件：y1-stock-rom、y1-stock-rom-mirror · 版本v3.0.0,3.0.0,v3.0.1,3.0.1,v3.0.2,3.0.2,v3.0.3,3.0.3,v3.0.4,3.0.4,v3.0.5,3.0.5,v3.0.6,3.0.6,v2.*,2.*,v1.*,1.*

此原始软件版本早于 3.0.7。它与使用 Innioasis OS 3.0.7 或更高版本制造的 Y1 设备不兼容。刷新它将使设备处于非启动状态，直到使用以下命令安装 3.0.7 或更高版本 [更新程序 CE 的 SP Flash Tool 引擎](https://innioasis.app/Troubleshooting/recover-non-booting-device.html#sp-flash-tool-engine).
