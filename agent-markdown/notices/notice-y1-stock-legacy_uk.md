# Попередження про сумісність оригінального програмного забезпечення Y1

Цей випуск оригінального програмного забезпечення передує версії 3.0.7 і запобігатиме завантаженню на новішому обладнанні Y1, доки не буде встановлено сумісну збірку.

Моделі: Y1 · Програмне забезпечення: y1-stock-rom, y1-stock-rom-mirror · Версія v3.0.0,3.0.0,v3.0.1,3.0.1,v3.0.2,3.0.2,v3.0.3,3.0.3,v3.0.4,3.0.4,v3.0.5,3.0.5,v3.0.6,3.0.6,v2.*,2.*,v1.*,1.*

Цей оригінальний випуск програмного забезпечення передує версії 3.0.7. Він несумісний з Y1 пристроями, виробленими з Innioasis OS 3.0.7 або новішої версії. Прошивка залишить пристрій у стані незавантаження, доки не буде встановлено 3.0.7 або новішу версію за допомогою [Оновлення CE SP Flash Tool двигуна](https://innioasis.app/Troubleshooting/recover-non-booting-device.html#sp-flash-tool-engine).

[Відкрийте сторінку за посиланням](https://innioasis.app/Troubleshooting/recover-non-booting-device.html#sp-flash-tool-engine)
