# 現在のお知らせ

デバイスの安全性に関する勧告とリリース ノートは Innioasis Updater に示されています。2026-10-25 · 2026-12-31 まで · モデル: Y1、Y2

### [Windows 10/11 アプリの起動の問題と Smart App Control の回避策](2026-11-07-codesigning_ja.html)

Windows 10/11 または Smart App Control によってアプリの起動が停止された場合は、こちらの回避策に従ってください。モデル: Y1 · ソフトウェア: Rockbox · バージョン v0.4.*、0.4.*、v0.3.*、0.3.*、v0.2.*、0.2.*、v0.1.*、0.1.*

### [Rockbox Y1 互換性に関する警告](notice-y1-rockbox-legacy_ja.html)

この Rockbox-Y1 リリースは 0.5 より前のものであり、ファームウェア 3.0.7 以降で出荷された Y1 ユニットとは互換性がありません。点滅すると起動できなくなります。モデル: Y1 · ソフトウェア: y1-stock-rom、y1-stock-rom-mirror · バージョンv3.0.0、3.0.0、v3.0.1、3.0.1、v3.0.2、3.0.2、v3.0.3、3.0.3、v3.0.4、3.0.4、v3.0.5、3.0.5、v3.0.6、3.0.6、v2.*、2.*、v1.*、1.*

### [オリジナル ソフトウェア Y1 の互換性に関する警告](notice-y1-stock-legacy_ja.html)

このオリジナル ソフトウェア リリースは 3.0.7 より前のものであり、互換性のあるビルドがインストールされるまで、新しい Y1 ハードウェアでは起動できなくなります。
