# Rockbox Y1 兼容性警告

此 Rockbox-Y1 版本早于 0.5，并且与附带固件 3.0.7 或更高版本的 Y1 设备不兼容。闪烁会阻止启动。

型号：Y1 · 软件：rockbox · 版本 v0.4.*,0.4.*,v0.3.*,0.3.*,v0.2.*,0.2.*,v0.1.*,0.1.*

此 Rockbox-Y1 版本早于版本 0.5。它与 2026 年 3 月后发货且预装 Innioasis OS 3.0.7 的 Innioasis Y1 硬件不兼容。在这些设备上刷新此旧版本将阻止启动，直到通过恢复 [更新程序 CE 的 SP Flash Tool 引擎](https://innioasis.app/Troubleshooting/recover-non-booting-device.html#sp-flash-tool-engine).
