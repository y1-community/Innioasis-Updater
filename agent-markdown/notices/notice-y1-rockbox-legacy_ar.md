# Rockbox Y1 تحذير التوافق - Innioasis المحدث

# تحذير توافق Rockbox Y1

يسبق إصدار Rockbox-Y1 الإصدار 0.5 وهو غير متوافق مع وحدات Y1 التي يتم شحنها مع البرنامج الثابت 3.0.7 أو إصدار أحدث. سيمنع الوميض عملية التشغيل.

النماذج: Y1 · البرنامج: rockbox · الإصدار v0.4.*,0.4.*,v0.3.*,0.3.*,v0.2.*,0.2.*,v0.1.*,0.1.*

هذا الإصدار Rockbox-Y1 يسبق الإصدار 0.5. إنه غير متوافق مع Innioasis Y1 الأجهزة التي تم شحنها بعد مارس 2026 مع Innioasis OS 3.0.7 المثبت مسبقًا. سيؤدي تحديث هذا الإصدار القديم على هذه الأجهزة إلى منع التشغيل حتى يتم استعادته عبر [محرك التحديث CE SP Flash Tool](https://innioasis.app/Troubleshooting/recover-non-booting-device.html#sp-flash-tool-engine).
