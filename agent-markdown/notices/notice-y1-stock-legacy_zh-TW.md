# 原始軟體Y1相容性警告

此原始軟體版本早於 3.0.7，並且在安裝相容版本之前將阻止在較新的 Y1 硬體上啟動。

型號：Y1 · 軟體：y1-stock-rom、y1-stock-rom-mirror ·版本v3.0.0,3.0.0,v3.0.1,3.0.1,v3.0.2,3.0.2,v3.0.3,3.0.3,v3.0.4,3.0.4,v3.0.5,3.0.5,v3.0.4,3.0.4,v3.0.5,3.0.5,v3.0.6,3.0.6,v*v.

此原始軟體版本早於 3.0.7。它與使用 Innioasis OS 3.0.7 或更高版本製造的 Y1 設備不相容。刷新它將使裝置處於非啟動狀態，直到使用以下命令安裝 3.0.7 或更高版本 [更新程式 CE 的 SP Flash Tool 引擎](https://innioasis.app/Troubleshooting/recover-non-booting-device.html#sp-flash-tool-engine).
