# Usuarios que tienen problemas con Rockbox para Y2.

Rockbox Los temas de 360p no funcionan y la música no se lee desde MicroSD.

Desde 2026-11-03 · hasta 2026-12-31 · Modelos: Y2 · Software: y2-rockbox · Versión *

Rockbox para Y2 tiene dos problemas abiertos reportados por la comunidad:
  - No se aplican temas de 360p. El reproductor sigue mostrando la obra de arte original en 360p.
  - La música de una tarjeta MicroSD no aparece en la lista después de una instalación Rockbox.

Si depende de una biblioteca MicroSD, permanezca en el software original hasta que se solucionen.

Restaurar el firmware original requiere una ejecución del Actualizador CE. La música de su tarjeta MicroSD se deja sola, pero la música guardada en el almacenamiento interno de Y2 se borra: en Y2 la opción Conservar datos en Updater CE 2.5.1 solo transporta datos entre firmwares que sean compatibles entre sí, y pasar al software original no es uno de esos casos.

Los pasos están en el [Y2 guía de restauración de stock](https://innioasis.app/guides/restore-original-y2.html).
