# Original Software Y1 Compatibility Warning

This Original Software release predates 3.0.7 and will prevent booting on newer Y1 hardware until a compatible build is installed.

Models: Y1 · Software: y1-stock-rom, y1-stock-rom-mirror · Version v3.0.0,3.0.0,v3.0.1,3.0.1,v3.0.2,3.0.2,v3.0.3,3.0.3,v3.0.4,3.0.4,v3.0.5,3.0.5,v3.0.6,3.0.6,v2.*,2.*,v1.*,1.*

This Original Software release predates 3.0.7. It is not compatible with Y1 units manufactured with Innioasis OS 3.0.7 or later. Flashing it will leave the device in a non-booting state until 3.0.7 or higher is installed using [Updater CE's SP Flash Tool engine](https://innioasis.app/Troubleshooting/recover-non-booting-device.html#sp-flash-tool-engine).
