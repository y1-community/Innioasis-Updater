# Rockbox Y1 Avertissement de compatibilité

Cette version Rockbox-Y1 est antérieure à la version 0.5 et n'est pas compatible avec les unités Y1 livrées avec le micrologiciel 3.0.7 ou version ultérieure. Le clignotement empêchera le démarrage.

Modèles : Y1 · Logiciel : rockbox · Version v0.4.*,0.4.*,v0.3.*,0.3.*,v0.2.*,0.2.*,v0.1.*,0.1.*

Cette version Rockbox-Y1 est antérieure à la version 0.5. Il n'est pas compatible avec le matériel Innioasis Y1 expédié après mars 2026 avec Innioasis OS 3.0.7 préinstallé. Flasher cette version héritée sur ces appareils empêchera le démarrage jusqu'à ce qu'il soit restauré via [Moteur SP Flash Tool du programme de mise à jour CE](https://innioasis.app/Troubleshooting/recover-non-booting-device.html#sp-flash-tool-engine).

[Ouvrez la page liée](https://innioasis.app/Troubleshooting/recover-non-booting-device.html#sp-flash-tool-engine)
