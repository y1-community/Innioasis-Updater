# Rockbox Y1 Ostrzeżenie o zgodności — Innioasis Aktualizacja

Modele: Y1 · Oprogramowanie: rockbox · Wersja v0.4.*,0.4.*,v0.3.*,0.3.*,v0.2.*,0.2.*,v0.1.*,0.1.*

# Ostrzeżenie dotyczące kompatybilności Rockbox Y1

Ta wersja Rockbox-Y1 jest starsza niż 0.5 i nie jest kompatybilna z jednostkami Y1 dostarczanymi z oprogramowaniem sprzętowym 3.0.7 lub nowszym. Flashowanie uniemożliwi uruchomienie.

Modele: Y1 · Oprogramowanie: rockbox · Wersja v0.4.*,0.4.*,v0.3.*,0.3.*,v0.2.*,0.2.*,v0.1.*,0.1.*

To wydanie Rockbox-Y1 jest starsze niż wersja 0.5. Nie jest kompatybilny ze sprzętem Innioasis Y1 dostarczonym po marcu 2026 r. z preinstalowanym systemem operacyjnym Innioasis OS 3.0.7. Flashowanie tej starszej wersji na tych urządzeniach uniemożliwi uruchomienie systemu do czasu przywrócenia go [Silnik aktualizacji CE SP Flash Tool.](https://innioasis.app/Troubleshooting/recover-non-booting-device.html#sp-flash-tool-engine).
