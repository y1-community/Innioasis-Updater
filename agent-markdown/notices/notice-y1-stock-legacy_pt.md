# Software original Y1 Aviso de compatibilidade

Esta versão do software original é anterior à 3.0.7 e impedirá a inicialização em hardware Y1 mais recente até que uma versão compatível seja instalada.

Modelos: Y1 · Software: y1-stock-rom, y1-stock-rom-mirror · Versão v3.0.0,3.0.0,v3.0.1,3.0.1,v3.0.2,3.0.2,v3.0.3,3.0.3,v3.0.4,3.0.4,v3.0.5,3.0.5,v3.0.6,3.0.6,v2.*,2.*,v1.*,1.*

Esta versão do software original é anterior à 3.0.7. Não é compatível com Y1 unidades fabricadas com Innioasis OS 3.0.7 ou posterior. Piscar deixará o dispositivo em um estado sem inicialização até que 3.0.7 ou superior seja instalado usando [Mecanismo SP Flash Tool do atualizador CE](https://innioasis.app/Troubleshooting/recover-non-booting-device.html#sp-flash-tool-engine).
