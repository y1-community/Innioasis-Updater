# 關於 Updater CE 中的通知

您將收到有關社區報告的設備安全問題的重要警報，例如當設備被某些韌體損壞時。

2026-10-25 · 至 2026-12-31 · 型號：Y1,Y2

通知是社區如何警告設備安全問題、不應安裝在特定硬體版本上的韌體以及新軟體版本的方式。
  - 每個通知都有自己的頁面 在此網站上，因此可以完整閱讀警告，而不必將其縮減為一行。
  - 該應用程式顯示相同的文本，通知的詳細資訊從橫幅中打開。
  - 沒有特定頁面的通知 只需在這裡打開自己的頁面即可；指向裸網站根目錄的連結將被忽略。

使用響鈴圖示隨時查看目前通知。
