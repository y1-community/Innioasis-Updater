# Software original Y1 Advertencia de compatibilidad

Esta versión del software original es anterior a la 3.0.7 y evitará el arranque en hardware Y1 más nuevo hasta que se instale una versión compatible.

Modelos: Y1 · Software: y1-stock-rom, y1-stock-rom-mirror · Versión v3.0.0,3.0.0,v3.0.1,3.0.1,v3.0.2,3.0.2,v3.0.3,3.0.3,v3.0.4,3.0.4,v3.0.5,3.0.5,v3.0.6,3.0.6,v2.*,2.*,v1.*,1.*

Esta versión del software original es anterior a la 3.0.7. No es compatible con unidades Y1 fabricadas con Innioasis OS 3.0.7 o posterior. Al parpadearlo dejará el dispositivo en un estado sin inicio hasta que se instale 3.0.7 o superior usando [Motor SP Flash Tool del actualizador CE](https://innioasis.app/Troubleshooting/recover-non-booting-device.html#sp-flash-tool-engine).
