# Ostrzeżenie o zgodności oryginalnego oprogramowania Y1

Ta oryginalna wersja oprogramowania jest starsza niż 3.0.7 i uniemożliwia uruchomienie komputera na nowszym sprzęcie Y1 do czasu zainstalowania kompatybilnej kompilacji.

Modele: Y1 · Oprogramowanie: y1-stock-rom, y1-stock-rom-mirror · Wersja v3.0.0,3.0.0,v3.0.1,3.0.1,v3.0.2,3.0.2,v3.0.3,3.0.3,v3.0.4,3.0.4,v3.0.5,3.0.5,v3.0.6,3.0.6,v2.*,2.*,v1.*,1.*

Ta oryginalna wersja oprogramowania jest starsza niż wersja 3.0.7. Nie jest kompatybilny z urządzeniami Y1 wyprodukowanymi z systemem Innioasis OS 3.0.7 lub nowszym. Flashowanie spowoduje, że urządzenie nie będzie się uruchamiało, dopóki nie zostanie zainstalowana wersja 3.0.7 lub nowsza [Silnik aktualizacji CE SP Flash Tool.](https://innioasis.app/Troubleshooting/recover-non-booting-device.html#sp-flash-tool-engine).
