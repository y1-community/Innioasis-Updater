# Исходное программное обеспечение Y1 Предупреждение о совместимости

Эта версия оригинального программного обеспечения предшествует версии 3.0.7 и не позволяет загружать новое оборудование Y1 до тех пор, пока не будет установлена ​​совместимая сборка.

Модели: Y1 · Программное обеспечение: y1-stock-rom, y1-stock-rom-mirror · Версия v3.0.0,3.0.0,v3.0.1,3.0.1,v3.0.2,3.0.2,v3.0.3,3.0.3,v3.0.4,3.0.4,v3.0.5,3.0.5,v3.0.6,3.0.6,v2.*,2.*,v1.*,1.*

Эта версия оригинального программного обеспечения предшествует версии 3.0.7. Он несовместим с устройствами Y1 с ОС Innioasis версии 3.0.7 или более поздней. При перепрошивке устройство останется в незагружаемом состоянии до тех пор, пока не будет установлена ​​версия 3.0.7 или выше с помощью [Механизм обновления CE SP Flash Tool](https://innioasis.app/Troubleshooting/recover-non-booting-device.html#sp-flash-tool-engine).
