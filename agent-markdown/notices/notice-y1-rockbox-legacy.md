# Rockbox Y1 Compatibility Warning

This Rockbox-Y1 release predates 0.5 and is not compatible with Y1 units shipped with firmware 3.0.7 or later. Flashing will prevent booting.

Models: Y1 · Software: rockbox · Version v0.4.*,0.4.*,v0.3.*,0.3.*,v0.2.*,0.2.*,v0.1.*,0.1.*

This Rockbox-Y1 release predates version 0.5. It is not compatible with Innioasis Y1 hardware shipped after March 2026 with Innioasis OS 3.0.7 pre-installed. Flashing this legacy build on those devices will prevent booting until restored via [Updater CE's SP Flash Tool engine](https://innioasis.app/Troubleshooting/recover-non-booting-device.html#sp-flash-tool-engine).
