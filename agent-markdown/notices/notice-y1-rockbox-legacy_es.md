# Rockbox Y1 Advertencia de compatibilidad

Esta versión Rockbox-Y1 es anterior a la 0.5 y no es compatible con las unidades Y1 enviadas con firmware 3.0.7 o posterior. El flasheo impedirá el arranque.

Modelos: Y1 · Software: rockbox · Versión v0.4.*,0.4.*,v0.3.*,0.3.*,v0.2.*,0.2.*,v0.1.*,0.1.*

Esta versión Rockbox-Y1 es anterior a la versión 0.5. No es compatible con el hardware Innioasis Y1 enviado después de marzo de 2026 con Innioasis OS 3.0.7 preinstalado. Actualizar esta versión heredada en esos dispositivos evitará el arranque hasta que se restaure a través de [Motor SP Flash Tool del actualizador CE](https://innioasis.app/Troubleshooting/recover-non-booting-device.html#sp-flash-tool-engine).
