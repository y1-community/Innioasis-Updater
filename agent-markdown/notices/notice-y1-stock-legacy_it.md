# Software originale Y1 Avviso di compatibilità

Questa versione del software originale è precedente alla 3.0.7 e impedirà l'avvio sull'hardware Y1 più recente finché non verrà installata una build compatibile.

Modelli: Y1 · Software: y1-stock-rom, y1-stock-rom-mirror · Versione v1.*,1.*

Questa versione del software originale è precedente alla 3.0.7. Non è compatibile con Y1 unità prodotte con Innioasis OS 3.0.7 o versioni successive. Se lo lampeggia, il dispositivo rimarrà in uno stato di non avvio fino all'installazione della versione 3.0.7 o successiva [Motore di aggiornamento SP Flash Tool di CE](https://innioasis.app/Troubleshooting/recover-non-booting-device.html#sp-flash-tool-engine).
