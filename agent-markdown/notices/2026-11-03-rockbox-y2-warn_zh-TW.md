# 使用者對 Y2 的 Rockbox 有問題。

Rockbox 360p 主題不起作用，也無法從 MicroSD 讀取音樂。

從 2026-11-03 · 至 2026-12-31 · 型號：Y2 · 軟體：y2-rockbox · 版本 *

Y2 的 Rockbox 有兩個社區報告的未決問題：
  - 360p 主題不適用。 播放器不斷顯示庫存的 360p 圖稿。
  - MicroSD 卡片上的音樂未列出 安裝Rockbox後。

如果您依賴 MicroSD 庫，請繼續使用原始軟體，直到這些問題已修復。

恢復原始韌體需要運行一次 Updater CE。 MicroSD 卡上的音樂將被保留，但保存到 Y2 內部存儲的音樂將被刪除：在 Y2 上，Updater CE 2.5.1 中的“保留數據”選項僅在交叉兼容的固件之間傳輸數據，而遷移到原始軟體不是這些情況之一。

步驟在 [Y2庫存恢復指南](https://innioasis.app/guides/restore-original-y2.html).
