# Rockbox Y1 互換性に関する警告

この Rockbox-Y1 リリースは 0.5 より前のものであり、ファームウェア 3.0.7 以降で出荷された Y1 ユニットとは互換性がありません。点滅すると起動できなくなります。

モデル: Y1 · ソフトウェア: Rockbox · バージョン v0.4.*、0.4.*、v0.3.*、0.3.*、v0.2.*、0.2.*、v0.1.*、0.1.*

この Rockbox-Y1 リリースはバージョン 0.5 より前のものです。 Innioasis OS 3.0.7 がプリインストールされた 2026 年 3 月以降に出荷された Innioasis Y1 ハードウェアとは互換性がありません。これらのデバイスでこのレガシー ビルドをフラッシュすると、復元するまで起動できなくなります。 [アップデータ CE の SP Flash Tool エンジン](https://innioasis.app/Troubleshooting/recover-non-booting-device.html#sp-flash-tool-engine).
