# Rockbox Y1 Aviso de compatibilidade

Esta versão Rockbox-Y1 é anterior à 0.5 e não é compatível com unidades Y1 enviadas com firmware 3.0.7 ou posterior. Piscar impedirá a inicialização.

Modelos: Y1 · Software: rockbox · Versão v0.4.*,0.4.*,v0.3.*,0.3.*,v0.2.*,0.2.*,v0.1.*,0.1.*

Esta versão Rockbox-Y1 é anterior à versão 0.5. Não é compatível com hardware Innioasis Y1 enviado após março de 2026 com Innioasis OS 3.0.7 pré-instalado. Atualizar esta versão legada nesses dispositivos impedirá a inicialização até ser restaurada via [Mecanismo SP Flash Tool do atualizador CE](https://innioasis.app/Troubleshooting/recover-non-booting-device.html#sp-flash-tool-engine).
