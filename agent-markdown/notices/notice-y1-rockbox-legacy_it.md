# Rockbox Y1 Avviso di compatibilità

Questa versione Rockbox-Y1 è precedente alla 0.5 e non è compatibile con le unità Y1 fornite con firmware 3.0.7 o successivo. Il lampeggio impedirà l'avvio.

Modelli: Y1 · Software: rockbox · Versione v0.4.*,0.4.*,v0.3.*,0.3.*,v0.2.*,0.2.*,v0.1.*,0.1.*

Questa versione Rockbox-Y1 è precedente alla versione 0.5. Non è compatibile con l'hardware Innioasis Y1 spedito dopo marzo 2026 con Innioasis sistema operativo 3.0.7 preinstallato. Il flashing di questa build legacy su tali dispositivi impedirà l'avvio fino al ripristino tramite [Motore di aggiornamento SP Flash Tool di CE](https://innioasis.app/Troubleshooting/recover-non-booting-device.html#sp-flash-tool-engine).
