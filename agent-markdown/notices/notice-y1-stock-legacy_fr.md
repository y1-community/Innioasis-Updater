# Logiciel d'origine Y1 Avertissement de compatibilité

Cette version du logiciel d'origine est antérieure à la version 3.0.7 et empêchera le démarrage sur un matériel Y1 plus récent jusqu'à ce qu'une version compatible soit installée.

Modèles : Y1 · Logiciel : y1-stock-rom, y1-stock-rom-mirror · Version v3.0.0,3.0.0,v3.0.1,3.0.1,v3.0.2,3.0.2,v3.0.3,3.0.3,v3.0.4,3.0.4,v3.0.5,3.0.5,v3.0.6,3.0.6,v2.*,2.*,v1.*,1.*

Cette version du logiciel original est antérieure à la version 3.0.7. Il n'est pas compatible avec les unités Y1 fabriquées avec Innioasis OS 3.0.7 ou version ultérieure. Le faire clignoter laissera l'appareil dans un état de non-démarrage jusqu'à ce que la version 3.0.7 ou supérieure soit installée à l'aide de [Moteur SP Flash Tool du programme de mise à jour CE](https://innioasis.app/Troubleshooting/recover-non-booting-device.html#sp-flash-tool-engine).

[Ouvrez la page liée](https://innioasis.app/Troubleshooting/recover-non-booting-device.html#sp-flash-tool-engine)
