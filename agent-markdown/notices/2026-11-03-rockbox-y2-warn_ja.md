# Y2 の Rockbox に問題があるユーザー。

Rockbox 360p テーマが機能せず、音楽が MicroSD から読み込まれません。

2026-11-03 から 2026-12-31 まで · モデル: Y2 · ソフトウェア: y2-rockbox · バージョン *

Y2 の Rockbox には、コミュニティによって報告された 2 つの未解決の問題があります。
  - 360p テーマは適用されません。 プレーヤーはストック 360p アートワークを表示し続けます。
  - MicroSD カードの音楽がリストにありません Rockbox インストール後。

MicroSD ライブラリに依存している場合は、これらが修正されるまでオリジナル ソフトウェアを使用してください。

元のファームウェアを復元するには、Updater CE を 1 回実行する必要があります。 MicroSD カード上の音楽はそのまま残りますが、Y2 の内部ストレージに保存された音楽は消去されます。Y2 では、Updater CE 2.5.1 のデータ保持オプションは、相互互換性のあるファームウェア間でデータを転送するだけであり、オリジナル ソフトウェアへの移行はそのようなケースには含まれません。

手順は次のとおりです。 [Y2 在庫復元ガイド](https://innioasis.app/guides/restore-original-y2.html).
