# オリジナル ソフトウェア Y1 の互換性に関する警告

このオリジナル ソフトウェア リリースは 3.0.7 より前のものであり、互換性のあるビルドがインストールされるまで、新しい Y1 ハードウェアでは起動できなくなります。

モデル: Y1 · ソフトウェア: y1-stock-rom、y1-stock-rom-mirror · バージョンv3.0.0、3.0.0、v3.0.1、3.0.1、v3.0.2、3.0.2、v3.0.3、3.0.3、v3.0.4、3.0.4、v3.0.5、3.0.5、v3.0.6、3.0.6、v2.*、2.*、v1.*、1.*

このオリジナル ソフトウェア リリースは 3.0.7 より前のものです。 Innioasis OS 3.0.7 以降で製造された Y1 ユニットとは互換性がありません。これをフラッシュすると、3.0.7 以降がインストールされるまでデバイスは非起動状態になります。 [アップデータ CE の SP Flash Tool エンジン](https://innioasis.app/Troubleshooting/recover-non-booting-device.html#sp-flash-tool-engine).
