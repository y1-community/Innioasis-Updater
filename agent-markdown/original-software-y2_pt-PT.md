## Instale ou restaure-o com o Updater

Configure o computador primeiro e depois deixe o Updater preparar o pacote correspondente ao modelo.
  - Abra Innioasis Updater CE no seu computador (se precisar do aplicativo, [Obtenha o atualizador CE](guide_pt-PT.html#platform)). Definir Modelo do dispositivo para Y2.
  - Escolher Software Original e uma versão Y2.
  - Clique Instalar / Restaurar.
  - Desligue e conecte o Y2 somente quando o prompt ao vivo solicitar.

Pacotes de instalação completa manual podem usar `rom_y2.zip`. Não trate um Y1 `rom.zip` como substituto.

## Perguntas frequentesPosso retornar de Rockbox ou de outro software personalizado?

Use o mesmo fluxo de restauração Y2: escolha Y2, selecione Software Original e siga o prompt de conexão. Não misture arquivos de modelo.Por que o pacote Y2 parece diferente?

Y2 versões podem usar um nome de pacote e entrada de versão diferentes. Selecione Y2 no Atualizador em vez de adivinhar a partir de um nome de arquivo ZIP manual.E se o jogador não for detetado?

Verifique o cabo de dados, as permissões ou drivers do computador e o tempo. Conecte o Y2 desligado somente depois que o Updater disser que está pronto.
