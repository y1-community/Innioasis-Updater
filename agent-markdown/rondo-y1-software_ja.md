## コンピュータを使用して Y1 に Rondo をインストールします

使用しているコンピュータのガイドを選択してください。 すべてのバージョンには、プラットフォームのセットアップ、Updater CE の手順、および在庫に戻る方法が含まれています。[Windowsガイド](install/rondo-y1-windows.html)[macOS ガイド](install/rondo-y1-mac.html)[Linuxガイド](install/rondo-y1-linux.html)

## インストール手順
  - 打ち上げ Innioasis アップデータ CE Windows、Mac、または Linux コンピューター上で。
  - 選択 Y1 [デバイス モデル] ドロップダウンから。
  - 選択 Rondo [ソフトウェア]ドロップダウンから。
  - クリック インストール / 復元 ツールがファイルをダウンロードして準備するまで待ちます。
  - Updater CE のプロンプトが表示されたら、Y1 の電源を切り、USB ケーブルを接続します。
  - インストール後のセットアップを完了する

の手順に従います [このガイド](post_install_ja.html?software=rondo-y1&model=Y1) Y1 でのセットアップを完了します。[ガイドを見る](post_install_ja.html?software=rondo-y1&model=Y1)
