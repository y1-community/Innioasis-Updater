# Installez Linux sur le Y1.

Linux pour Y1 est un noyau Linux communautaire expérimental et un port rootfs pour le matériel Innioasis Y1. Cette page renvoie au guide d'installation complet et aux versions.[Ouvrez le guide complet Linux pour Y1 (Dev)](guides/linux-y1.html)[Disponible dans Updater CE](guide_fr.html?model=Y1&software=linux-y1)[Origine du projet](https://github.com/y1-community/y1-linux-rom)

## Installez Linux pour Y1 (Dev) sur votre Y1 avec votre ordinateur

Choisissez le guide correspondant à l'ordinateur que vous utilisez. Chaque version comprend la configuration de la plate-forme, Updater CE étapes et le chemin de retour au stock.[Guide Windows](install/linux-y1-windows.html)[Guide macOS](install/linux-y1-mac.html)[Guide Linux](install/linux-y1-linux.html)

[Tous les guides Innioasis Y1](install/y1.html) · [Tous les guides Linux pour Y1 (Dev)](install/linux-dev.html)

## Étapes d'installation de Linux Y1
  - Ouvrez Innioasis Updater CE sur votre ordinateur (si vous avez besoin de l'application, [Obtenir Updater CE](guide_fr.html#platform)). Ensemble Modèle d'appareil à Y1.
  - Choisissez Linux pour Y1 (développement) dans Logiciel.
  - Choisissez la version répertoriée pour Y1.
  - Cliquez Installer / Restaurer.
  - Éteignez et connectez le Y1 uniquement lorsque Updater CE le demande.

## FAQPuis-je restaurer le logiciel d'origine Y1 ?

Oui. Sélectionnez Y1 et le logiciel original dans Updater CE. Le [Guide des logiciels boursiers Y1](original-software-y1_fr.html) couvre le chemin de retour.Est-ce une interface utilisateur quotidienne ?

Il s'agit d'un port expérimental pour les développeurs et les bricoleurs Linux. Les instructions du terminal et de la console se trouvent dans la documentation du projet.
