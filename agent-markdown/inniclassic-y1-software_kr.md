# Innioasis Y1에 대한 Inniclassic 펌웨어 | 설치 튜토리얼 - Innioasis 펌웨어 다운로드

Inniclassic · Innioasis Y1

# Y1에 Inniclassic을(를) 설치합니다.

Inniclassic은(는) Y1의 커뮤니티 소프트웨어 프로젝트이고 동일한 프로젝트에서 Y2 빌드도 게시하므로 두 플레이어 모두에서 사용할 수 있습니다. 이 페이지는 Y1 검색하기 쉬운 답변과 자세한 연결 단계에 대한 링크를 제공합니다.[전체 Inniclassic 가이드 열기](guides/inniclassic-y1.html)[이것을 Updater CE에서 얻으세요](guide_ko.html?model=Y1&software=inniclassic-y1)[왜 Inniclassic인가요?](inniclassic-benefits_ko.html)

컴퓨터에 대한 설치 가이드

## 컴퓨터를 사용하여 Y1에 Inniclassic을(를) 설치합니다.

사용 중인 컴퓨터에 대한 가이드를 선택하세요. 모든 버전에는 플랫폼 설정, Updater CE 단계 및 재고로 돌아가는 방법이 있습니다.[윈도우 가이드](install/inniclassic-y1-windows.html)[macOS 가이드](install/inniclassic-y1-mac.html)[리눅스 가이드](install/inniclassic-y1-linux.html)

[모든 Innioasis Y1 가이드](install/y1.html) · [모든 Inniclassic 가이드](install/inniclassic.html)

## Inniclassic Y1 설치 단계
  - 컴퓨터에서 Innioasis Updater CE를 엽니다(앱이 필요한 경우, [Updater CE 받기](guide_ko.html#platform)). 세트 기기 모델 에 Y1.
  - 선택 Inniclassic 안으로 소프트웨어.
  - Y1에 대해 나열된 릴리스를 선택합니다.
  - 클릭 설치 / 복원.
  - 전원을 끄고 Updater CE이 묻는 경우에만 Y1을 연결하세요.

## 자주 묻는 질문재고 Y1 소프트웨어를 복원할 수 있나요?

예. Updater CE에서 Y1과 원본 소프트웨어를 선택합니다. 는 [Y1 스톡 소프트웨어 가이드](original-software-y1_ko.html) 복귀 경로를 덮습니다.설치에 실패하면 어떻게 되나요?

Y1을(를) 감지하기 전이나 후에 업데이터가 실패했는지 확인한 다음, 다음에서 케이블, 플랫폼 설정, 모델 및 연결 타이밍을 확인하세요. [문제 해결](troubleshooting_ko.html).Y2에 Inniclassic을(를) 사용할 수 있나요?

예. Inniclassic은 두 모델 모두에서 사용할 수 있습니다. 동일한 유지 관리 프로젝트가 동일한 릴리스의 Y2 패키지를 게시합니다. Updater CE에서 Y2를 선택하고 Y2 빌드를 설치합니다. Y1 패키지를 Y2로 플래시하지 마십시오. 그만큼 [Y2 설치 페이지](inniclassic-y2-software_ko.html) 그것을 덮는다.

## 안내 경로를 이용하세요

업데이터를 처음 사용하시나요? 안내된 설정을 참조하세요. [Updater CE 받기](guide_ko.html#platform) 플레이어를 연결하기 전에 Windows, macOS 또는 Linux에서.
