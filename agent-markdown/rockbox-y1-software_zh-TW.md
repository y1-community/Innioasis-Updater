## Rockbox Y1 安裝步驟
  - 在您的電腦上開啟 Innioasis Updater CE（如果您需要該應用程序， [取得 Updater CE](guide_zh-TW.html#platform)）。套裝 裝置型號 到 Y1.
  - 選擇 Rockbox 在 軟體.
  - 選擇與您的預期畫面或主題路徑相符的版本和變體。
  - 點選 安裝 / 還原 並等待應用程式準備好。
  - 僅在即時提示時關閉電源並連接 Y1。

使用 [書面 Rockbox Y1 指南](guides/rockbox-y1.html) 取得螢幕截圖、影片、Type A 或 Type B 註解以及連線清單。

## 常見問題我可以回到原來的 Y1 軟體嗎？

是的。在 Updater CE 中選擇 Y1 和原始軟體，然後執行安裝/復原。這 [Y1 庫存軟體頁面](original-software-y1_zh-TW.html) 解釋了那條路線。我應該選擇哪個 Rockbox 版本？

選擇 Y1 顯示的版本並閱讀其發行說明。如果您需要較舊的主題相容性，請檢查解析度和變體註釋，而不是選擇 Y2 版本。我可以將其安裝在 Y2 上嗎？

否。使用單獨的 [Rockbox Y2 頁](rockbox-y2-software_zh-TW.html) 並在 Updater CE 中選擇 Y2。
