## Solar Y1 install steps
  - Open Innioasis Updater CE on your computer (if you need the app, [Get Updater CE](guide.html#platform)). Set Device Model to Y1.
  - Choose Solar in Software.
  - Read the project release note and choose a Y1 release.
  - Click Install / Restore.
  - Power off and connect the Y1 only when the prompt appears.

Solar features and availability can change. Features can change between releases, so check the project's release page and the current listing for your model.
