# Reborn (Y2Linux / Y2Reborn) を Innioasis Y2 にインストールするのはなぜですか? - Innioasis ファームウェアのダウンロード

Innioasis Y2 - ネイティブ Linux と Reborn UI

# Innioasis Y2 に Reborn (Y2Linux) をインストールする理由は何ですか?

SchulzCode によって構築され、 Reborn (Y2Linux / Y2Reborn) クリーンで応答性の高い Debian ベースの Linux 基盤と専用のクリックホイール インターフェイスを Innioasis Y2 にもたらします。これは以前の Y2Player プロジェクトを引き継ぎ、長年の Y2 Bluetooth ヘッドフォンとライブラリのナビゲーションの問題を解決します。[Reborn (Y2Linux) を Y2 にインストールします](guides/reborn-y2linux-y2.html)[Y2Reborn リリースを参照](firmware_ja.html?model=Y2&software=reborn-y2linux-y2)[Wi-Fi & Bluetooth セットアップガイド](y2reborn_wifibt_ja.html)

## Y2Reborn が Y2 よりも目立つ理由

### 信頼性の高い Bluetooth ヘッドフォン

コミュニティメンバー `r/innioasis` Y2Reborn は、Wi-Fi および Bluetooth ファームウェア パッケージが有効になると、最新の Bluetooth ヘッドフォンおよびイヤフォンとのペアリングと再生のドロップアウトを解決すると報告しています。

### 高速クリックホイールナビゲーション

Y2 クリックホイールと物理ボタンを中心に一から設計された Y2Reborn は、瞬時のメニュー応答、高速なアルファベット順のスクラブ、スムーズなライブラリ スクロールを提供します。

### 本物の Debian Linux の内部

SchulzCode/Y2Linux および SchulzCode/Y2Reborn を利用して、最新の ALSA オーディオ ドライバーとコミュニティ アップデートを備えた完全な Linux 環境を提供します。

## Y2Reborn で始めましょうステップ1

### Updater CE でインストールします

Innioasis Updater CE を開き、選択します Y2、選択します Reborn (Y2Linux)をクリックして、 インストール / 復元.ステップ2

### Wi-Fi と Bluetooth を有効にする

読んでください [Wi-Fi と Bluetooth セットアップガイド](y2reborn_wifibt_ja.html) ヘッドフォンとネットワーク同期の初期ペアリングを完了します。安全なロールバック

### いつでも元のソフトウェアに戻る

工場出荷時の状態に戻したい場合は、Updater CE でいつでも Y2 を元のソフトウェアに戻すことができます。
