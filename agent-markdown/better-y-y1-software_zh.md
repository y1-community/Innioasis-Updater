Better-Y 为 Innioasis Y1 提供增强的库存体验，包括标签分割、专辑曲目编号、“正在播放”快捷方式和更流畅的 RAM 缓存，同时保持 100% 的主题兼容性。[打开完整的 Better-Y 指南](guides/better-y-y1.html)[在 Updater CE 中获取](guide_zh-CN.html?model=Y1&software=better-y-y1)[为什么是Better-Y？](better-y-benefits_zh-CN.html)

## Better-Y Y1 安装步骤
  - 在您的计算机上打开 Innioasis Updater CE（如果您需要该应用程序， [获取 Updater CE](guide_zh-CN.html#platform)）。套装 设备型号 至 Y1.
  - 选择 Better-Y 在 软件.
  - 选择为 Y1 列出的版本。
  - 点击 安装 / 恢复.
  - 仅当 Updater CE 询问时关闭电源并连接 Y1。

## 常见问题与原厂固件相比有何改进？

Better-Y 添加曲目编号、分割多艺术家标签、使用真实标题、添加播放快捷方式以及缓存和蓝牙修复。和以前一样的主题。我可以恢复原厂Y1软件吗？

是的。在Updater CE中选择Y1和原始软件。的 [Y1库存软件指南](original-software-y1_zh-CN.html) 覆盖返回路径。我可以使用现有的主题吗？

是的！ Better-Y 基于官方库存 3.1.2 构建，并与主题库中的所有自定义主题保持 100% 兼容性。如果安装失败怎么办？

请注意更新程序在检测到 Y1 之前或之后是否失败，然后检查线缆、平台设置、型号和连接时序 [故障排除](troubleshooting_zh-CN.html).
