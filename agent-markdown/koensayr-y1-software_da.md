Vælg vejledningen til den computer, du bruger. Hver version har platformsopsætningen, Updater CE trin og vejen tilbage til lageret.[Windows guide](install/koensayr-y1-windows.html)[macOS guide](install/koensayr-y1-mac.html)[Linux guide](install/koensayr-y1-linux.html)

## Koensayr Y1 install steps
  - Åbn Innioasis Updater CE på din computer (hvis du har brug for appen, [Hent Updater CE](guide_da.html#platform)). Sæt Enhedsmodel til Y1.
  - Vælg Koensayr ind Software.
  - Choose the listed Y1 release.
  - Klik Installer / Gendan.
  - Sluk og tilslut kun Y1, når Updater CE spørger.

## Ofte stillede spørgsmålCan I restore the original Y1 software?

Yes. Select Y1 and Original Software in Updater CE. See the [Y1 stock-software page](original-software-y1_da.html) for the complete restore route.What should I check when it fails?

Check the model, release, cable, platform setup, and whether the player was connected before the prompt. Then use [fejlfinding](troubleshooting_da.html).Is there a Koensayr Y2 package?

The current build is for Y1. Don't use it on a Y2 unless the project publishes a separate release for it.
