## Innioasis 업데이터 CE란 무엇입니까?

Innioasis 업데이터 CE is an open-source tool that simplifies updating and restoring your player across Windows, macOS, and Linux.

Flashing through Updater CE preserves your music library, video collection, and Bluetooth pairings while guiding each step on screen.[Updater CE 받기](guide_ko.html#platform)[Compare flashing tools](updater-comparison_ko.html)[소프트웨어 찾아보기](firmware_ko.html)

## Getting started with Rockbox

### Y1에 Rockbox을(를) 설치합니다.

Select Y1, choose Rockbox stable, and connect only when prompted.[Y1 instructions](guides/rockbox-y1.html)[왜 Rockbox인가요?](rockbox-benefits_ko.html)

### Y2에 Rockbox을(를) 설치합니다.

Select Y2 in the tool. The Y2 route uses hardware-specific binaries.[Y2 instructions](guides/rockbox-y2.html)[왜 Rockbox인가요?](rockbox-benefits_ko.html)

### Restore factory software

Returning to factory software uses the same flow: select your model and choose Original Software.[Y1 factory restore](guides/restore-original-y1.html)[Y2 factory restore](guides/restore-original-y2.html)

Compatible with Windows, macOS, and Linux.
