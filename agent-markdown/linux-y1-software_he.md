# Install Linux on the Y1.

Linux for Y1 is an experimental community Linux kernel and rootfs port for the Innioasis Y1 hardware. This page links to the full installation guide and releases.[Open the full Linux for Y1 (Dev) guide](guides/linux-y1.html)[קבל את זה ב-Updater CE](guide_he.html?model=Y1&software=linux-y1)[מקור הפרויקט](https://github.com/y1-community/y1-linux-rom)

## Install Linux for Y1 (Dev) on your Y1 with your computer

בחר את המדריך עבור המחשב שבו אתה משתמש. לכל גרסה יש את הגדרת הפלטפורמה, Updater CE שלבים והדרך חזרה למלאי.[מדריך חלונות](install/linux-y1-windows.html)[מדריך macOS](install/linux-y1-mac.html)[מדריך לינוקס](install/linux-y1-linux.html)

## Linux Y1 install steps
  - פתח את Innioasis Updater CE במחשב שלך (אם אתה צריך את האפליקציה, [הורדת Updater CE](guide_he.html#platform)). סט דגם המכשיר ל Y1.
  - בחר לינוקס עבור Y1 (Dev) ב תוכנה.
  - בחר את המהדורה הרשומה עבור Y1.
  - לחץ התקנה / שחזור.
  - כבה וחבר את ה-Y1 רק כאשר Updater CE מבקש.

## שאלות נפוצותהאם אוכל לשחזר את תוכנת המניות Y1?

כֵּן. בחר Y1 ותוכנה מקורית ב-Updater CE. ה [Y1 מדריך תוכנה למניות](original-software-y1_he.html) מכסה את נתיב החזרה.Is this an everyday user interface?
