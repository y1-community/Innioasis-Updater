# Firmware para Innioasis Y1

El Y1 tiene la más amplia variedad de sistemas personalizados. Todo lo que aparece a continuación está alojado aquí, verificado y se instala con un solo clic con Updater CE.[Explorar Y1 Descargas](firmware_es.html?model=Y1)[Obtener Updater CE](guide_es.html#platform)[Galería de temas](https://themes.innioasis.app/?lang=es)

## Sistemas operativos disponibles para Innioasis Y1

El Y1 ejecuta varios sistemas de software, incluidas compilaciones con soporte para códecs audiófilos, lanzadores modernos y una restauración de fábrica. Elige el que se ajuste a tu forma de escuchar:

### [Rockbox](rockbox-benefits_es.html)

El estándar de oro en reproducción de audio de código abierto. Ecualizador paramétrico, reproducción FLAC/MP3 sin interrupciones, temas y paquetes de fuentes instalables directamente en Updater CE.[Y1 Rockbox Guía →](guides/rockbox-y1.html)

### [Better-Y](better-y-benefits_es.html)

Un derivado mejorado del firmware original con parches de estabilidad de Bluetooth, ajustes de curva de volumen y compatibilidad 100% con la Galería de temas.[Better-Y Guía →](guides/better-y-y1.html)

### [Solar](solar-benefits_es.html)

Un reproductor de música contemporáneo de código abierto creado con Flutter, que ofrece animaciones fluidas a 60 fps, cuadrículas de carátulas de álbumes y tipografía moderna.[Solar Y1 Guía →](guides/solar-y1.html)

### [Rondo](rondo-benefits_es.html)

Un iniciador Y1 de código abierto para pistas locales y streaming, con navegación rápida y responsiva.[Rondo Y1 Guía →](guides/rondo-y1.html)

### [Koensayr](koensayr-benefits.html)

Una compilación de firmware personalizada con su propia iconografía, mejor calibración de la batería y compatibilidad con temas de stock.[Koensayr Guía →](guides/koensayr-y1.html)

### [Software original (restauración de stock)](original-software-benefits_es.html)

Limpiar imágenes de firmware de fábrica para reproductores Type A (v2.0.0+) y Type B (v1.x) Y1. Desbloquee o restaure de forma segura su dispositivo al estado de fábrica.[Restaurar Y1 Guía →](guides/restore-original-y1.html)

## Cómo instalar o actualizar el firmware Y1

Actualizar o desbloquear tu Innioasis Y1 es sencillo con nuestro paquete de software multiplataforma:
  - Abra Innioasis Actualizador CE: Inicie el actualizador en macOS, Windows o Linux.
  - Seleccione el modelo Y1: elegir Y1 en el menú desplegable Modelo de dispositivo.
  - Elija su sistema operativo: Seleccione Rockbox, Better-Y, Solar o Software original.
  - Haga clic en Instalar: Updater CE descarga el paquete de firmware directamente desde la versión del desarrollador. Cuando se le solicite, conecte su Y1 apagado a través de USB para comenzar a parpadear.
