# Instal Inniclassic pada Y1.

Inniclassic adalah proyek perangkat lunak komunitas untuk Y1, dan proyek yang sama juga menerbitkan versi Y2, sehingga tersedia di kedua pemain. Halaman ini memberi Anda Y1 jawaban yang ramah pencarian dan tautan ke langkah-langkah koneksi terperinci.[Buka panduan lengkap Inniclassic](guides/inniclassic-y1.html)[Dapatkan ini di Updater CE](guide_id.html?model=Y1&software=inniclassic-y1)[Mengapa Inniclassic?](inniclassic-benefits_id.html)

Panduan instalasi untuk komputer Anda

## Instal Inniclassic pada Y1 Anda dengan komputer Anda

Pilih panduan untuk komputer yang Anda gunakan. Setiap versi memiliki pengaturan platform, Updater CE langkah-langkahnya, dan cara kembali ke stok.[Panduan Windows](install/inniclassic-y1-windows.html)[panduan macOS](install/inniclassic-y1-mac.html)[Panduan Linux](install/inniclassic-y1-linux.html)

[Semua Innioasis panduan Y1](install/y1.html) · [Semua panduan Inniclassic](install/inniclassic.html)

## Inniclassic Y1 langkah-langkah pemasangan
  - Buka Innioasis Updater CE di komputer Anda (jika Anda memerlukan aplikasinya, [Dapatkan Updater CE](guide_id.html#platform)). Tetapkan Model perangkat untuk Y1.
  - Pilih Inniclassic di Perangkat lunak.
  - Pilih rilis yang terdaftar untuk Y1.
  - Klik Pasang / Pulihkan.
  - Matikan dan sambungkan Y1 hanya ketika Updater CE diminta.

## Pertanyaan umumBisakah saya memulihkan perangkat lunak stok Y1?

Ya. Pilih Y1 dan Perangkat Lunak Asli di Updater CE. Itu [Panduan perangkat lunak stok Y1](original-software-y1_id.html) meliputi jalur pulang.Bagaimana jika instalasi gagal?

Catat apakah Updater gagal sebelum atau setelah mendeteksi Y1, lalu periksa kabel, pengaturan platform, model, dan waktu koneksi di [pemecahan masalah](troubleshooting_id.html).Bisakah saya menggunakan Inniclassic pada Y2?

Ya. Inniclassic tersedia pada kedua model — proyek yang dikelola sama menerbitkan paket Y2 dari rilis yang sama. Pilih Y2 di Updater CE dan instal build Y2; jangan pernah mem-flash paket Y1 ke Y2. Itu [Halaman pemasangan Y2](inniclassic-y2-software_id.html) menutupinya.

## Gunakan rute yang dipandu
