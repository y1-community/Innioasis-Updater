# 固件和软件问题解答

库存和回收

## 库存固件、解锁和支持的型号

### 在哪里可以找到库存固件来解锁我的播放器？

选择您的型号。然后下载该文件，或让 Updater CE 为您安装。每个包裹在上架前都会经过检查。

### Innioasis 固件存档支持哪些型号？

我们托管软件用于 Innioasis Y1, Y2, G1, G3, G5, R1, PR1 和D1。新的构建一旦准备好就会出现。 Timmkoo Q5 和 Q3 也通过 Updater CE 安装。

### 我可以从自定义固件返回到工厂软件吗？

是的。在 Updater CE 中，选择您的型号，然后选择 原厂软件，然后运行安装/恢复。切勿将文件用于不同的模型。

## 选择适合您聆听方式的软件。

### 原厂软件

您的播放器附带的软件。本地音乐、蓝牙和熟悉的界面。没什么可设置的。这是安全的基线，也是最快的返回路线。

[在 Y1 上恢复](original-software-y1_zh-CN.html) · [在 Y2 上恢复](original-software-y2_zh-CN.html)

### Better-Y

Leska1337 改进的 Y1 库存系统。更清晰的标签、曲目编号、更快的导航和完整的主题支持。

[Y1 上的 Better-Y](better-y-y1-software_zh-CN.html) · [为什么是Better-Y？](better-y-benefits_zh-CN.html)

### Rockbox

音乐爱好者的选择。按标签而不是文件名排序。无缝播放、交叉淡入淡出、均衡器和大型主题库。离线工作。

[Y1 上的 Rockbox](rockbox-y1-software_zh-CN.html) · [Y2 上的 Rockbox](rockbox-y2-software_zh-CN.html) · [为什么是Rockbox？](rockbox-benefits_zh-CN.html)

### Solar

Solar 打开 Wi-Fi，以便播放器可以串流和下载。 Deezer、Soulseek、播客和 YouTube，以及 Stem 播放器。 Rockbox也出现了。

[Y1 上的 Solar](solar-y1-software_zh-CN.html) · [Y2 上的 Solar](solar-y2-software_zh-CN.html) · [为什么是Solar？](solar-benefits_zh-CN.html)

### JJ Launcher

快速、适合轮子的发射器。快速库扫描、均衡器预设、使用任何屏幕上的硬件按钮跳过曲目、通过 Wi-Fi 无线文件上传、应用内蓝牙配对以及您可以插入或使用 Web 主题编辑器设计的主题。

[Y1 上的 JJ Launcher](jj-launcher-y1-software.html) · [Y2 上的 JJ Launcher](jj-launcher-y2-software.html) · [为什么是JJ Launcher？](jj-launcher-benefits.html)

### Inniclassic

基于 JJ Launcher 的 iPod Classic 致敬。经典的菜单外观、点击轮式音乐测验、同步歌词、Last.fm 记录，以及播客、调频广播和视频。 Y1 和 Y2 社区建设。

[Y1 上的 Inniclassic](inniclassic-y1-software_zh-CN.html) · [Y2 上的 Inniclassic](inniclassic-y2-software_zh-CN.html) · [为什么是Inniclassic？](inniclassic-benefits_zh-CN.html)

### Y2Player

Y2 的音乐第一主屏幕。具有持久队列的离线播放、无缝和交叉淡入淡出过渡、从停止处恢复的有声读物以及从 FLAC 到 Opus 的各种常见格式。蓝牙音频工作正常，无需互联网连接。

[Y2 上的 Y2Player](y2player-y2-software_zh-CN.html) · [为什么是Y2Player？](y2player-benefits_zh-CN.html)

### Koensayr

保持库存 Y1 外观。按艺术家浏览音乐，蓝牙显示曲目名称并与您的汽车控件配合使用。

[Y1 上的 Koensayr](koensayr-y1-software.html) · [为什么是Koensayr？](koensayr-benefits.html)

这些项目进展很快。 安装前请阅读每个项目的发行说明和问题跟踪器。如果出现任何问题，恢复您的模型的原始软件是安全的恢复方法。

## 我应该使用哪个工具？

Innioasis Updater 行政长官 是更新播放器的最安全方法。它可以保存您的音乐、视频和蓝牙配对。 Innioasis Universal Flash Tool 擦除它们。

它会告诉您更新何时准备就绪。它在屏幕上显示每个步骤。它可以在 Windows、macOS 和 Linux 上运行。
