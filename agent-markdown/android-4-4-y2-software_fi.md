# Install Android 4.4 (Dev) on the Y2.

Android 4.4 is a community development ROM for testing and hacking on Innioasis Y2 hardware. This page links to the full tutorial and release list.[Open the full Android 4.4 (Dev) guide](guides/android-4-4-y2.html)[Hanki tämä Updater CE](guide_fi.html?model=Y2&software=android-4-4-y2)[Projektin lähde](https://github.com/y1-community/y2-ata-rom)

## Install Android development ROM on your Y2 with your computer

Valitse käyttämäsi tietokoneen opas. Jokaisessa versiossa on alustan asetukset, Updater CE vaiheet ja tie takaisin varastoon.[Windowsin opas](install/android-4-4-y2-windows.html)[macOS-opas](install/android-4-4-y2-mac.html)[Linux opas](install/android-4-4-y2-linux.html)

[Kaikki Innioasis Y2-oppaat](install/y2.html) · [Kaikki Android-kehitysROM-oppaat](install/android-dev.html)

## Android 4.4 Y2 install steps
  - Avaa Innioasis Updater CE tietokoneellasi (jos tarvitset sovelluksen, [Hanki Updater CE](guide_fi.html#platform)). Aseta Laitteen malli to Y2.
  - Valitse Android 4.4 (kehittäjä) sisään Ohjelmisto.
  - Choose the release listed for Y2.
  - Napsauta Asenna / Palauta.
  - Katkaise virta ja liitä Y2 vain, kun Updater CE kysyy.
