## Inniclassic Y2 Installationsschritte
  - Öffnen Sie Innioasis Updater CE auf Ihrem Computer (wenn Sie die App benötigen, [Updater CE holen](guide_de.html#platform)). Satz Gerätemodell an Y2.
  - Wählen Sie Inniclassic In Software.
  - Wählen Sie die für Y2 aufgeführte Version aus.
  - Klicken Sie Installieren / Wiederherstellen.
  - Schalten Sie das Y2 nur aus und schließen Sie es an, wenn Updater CE dazu fragt.

## FAQKann ich die Standardsoftware Y2 wiederherstellen?

Ja. Wählen Sie Y2 und Originalsoftware in Updater CE. Der [Y2 Stock-Software-Leitfaden](original-software-y2_de.html) deckt den Rückweg ab.Kann ich Inniclassic auf Y1 verwenden?

Ja. Das gleiche Projekt veröffentlicht auch Y1 Pakete – rom.zip für Type A und rom_type_b.zip für Type B. Wählen Sie Y1 in Updater CE und installieren Sie den Build Y1; Die [Y1-Installationsseite](inniclassic-y1-software_de.html) deckt es ab.Was passiert, wenn die Installation fehlschlägt?

Beachten Sie, ob der Updater vor oder nach der Erkennung von Y2 fehlgeschlagen ist, und überprüfen Sie dann das Kabel, die Plattformeinrichtung, das Modell und das Verbindungs-Timing [Fehlerbehebung](troubleshooting_de.html).
