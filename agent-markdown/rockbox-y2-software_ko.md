# Y1 빌드가 아닌 Y2 Rockbox 소프트웨어를 설치하십시오.

업데이터 여정은 익숙하지만 Y2에는 자체 모델 선택 및 릴리스가 필요합니다. 이 페이지는 시작하기 전에 일반적인 “Y2에 대한 Rockbox” 질문에 대한 답변을 제공합니다.[전체 Rockbox 가이드 열기](guides/rockbox-y2.html)[이것을 Updater CE에서 얻으세요](guide_ko.html?model=Y2&software=rockbox-y2)[왜 Rockbox인가요?](rockbox-benefits_ko.html)

## 컴퓨터를 사용하여 Y2에 Rockbox을(를) 설치합니다.

사용 중인 컴퓨터에 대한 가이드를 선택하세요. 모든 버전에는 플랫폼 설정, Updater CE 단계 및 재고로 돌아가는 방법이 있습니다.[윈도우 가이드](install/rockbox-y2-windows.html)[macOS 가이드](install/rockbox-y2-mac.html)[리눅스 가이드](install/rockbox-y2-linux.html)

[모든 Innioasis Y2 가이드](install/y2.html) · [모든 Rockbox 가이드](install/rockbox_ko.html)

## Rockbox Y2 설치 단계
  - 컴퓨터에서 Innioasis Updater CE를 엽니다(앱이 필요한 경우, [Updater CE 받기](guide_ko.html#platform)). 세트 기기 모델 에 Y2.
  - 선택 Rockbox 안으로 소프트웨어.
  - Y2에 대해 명시적으로 나열된 릴리스를 선택하십시오.
  - 클릭 설치 / 복원 그리고 패키지 준비를 기다립니다.
  - 전원을 끄고 Updater CE이 요청하는 경우에만 Y2를 연결하세요.

프로젝트 이름이 동일해 보이기 때문에 Y1 패키지를 강제로 적용하지 마세요. Y2 릴리스가 나타나지 않으면 중지하고 모델 및 현재 릴리스 데이터를 확인하십시오.

## 자주 묻는 질문나중에 원본 Y2 소프트웨어를 복원할 수 있습니까?

예. Updater CE에서 Y2 및 원본 소프트웨어를 선택합니다. 참조 [Y2 재고 소프트웨어 페이지](original-software-y2_ko.html) 복원 순서에 대해패키지 이름이 rom_y2.zip인 이유는 무엇입니까?

이는 일부 Y2 전체 설치 릴리스에서 사용되는 수동 다운로드 단서입니다. 더 안전한 선택은 여전히 ​​Updater CE에서 Y2을 선택하고 제공되는 릴리스를 사용하는 것입니다.Y1 Rockbox 튜토리얼을 사용할 수 있나요?

광범위한 아이디어에만 사용하십시오. 패키지 및 모델 선택은 다음을 따르십시오. [Y2 특정 가이드](guides/rockbox-y2.html).
