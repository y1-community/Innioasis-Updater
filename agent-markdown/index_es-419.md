## ¿Qué es Innioasis Actualizador CE?

Innioasis Actualizador CE es la manera fácil de actualizar tu reproductor. Es de uso gratuito. Es la herramienta que los creadores recomiendan primero.

Mantiene su música, vídeos y emparejamientos Bluetooth. Le indica cuándo están listas las actualizaciones. Muestra cada paso en pantalla. ## Comenzando con Rockbox en tu Innioasis

### Instale Rockbox en Y1

Elija Y1, seleccione Rockbox, elija una versión estable y luego conéctese solo cuando el Actualizador lo solicite.[Leer Y1 pasos](guides/rockbox-y1.html)[¿Por qué Rockbox?](rockbox-benefits_es-419.html)

### Instale Rockbox en Y2

Elija Y2 primero. La ruta Y2 utiliza un paquete diferente y no debe tratarse como una instalación Y1.[Leer Y2 pasos](guides/rockbox-y2.html)[¿Por qué Rockbox?](rockbox-benefits_es-419.html)

### Restaurar software original

Al regresar de Rockbox u otro software personalizado se utiliza el mismo flujo de actualización: seleccione su modelo, elija Software original y ejecute Instalar/Restaurar.[Y1 restauración de existencias](guides/restore-original-y1.html)[Y2 restauración de existencias](guides/restore-original-y2.html)

Funciona en Windows, macOS o Linux una vez que la configuración del Actualizador de esa computadora esté lista.
