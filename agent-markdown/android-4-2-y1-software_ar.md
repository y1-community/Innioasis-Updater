اختر دليل الكمبيوتر الذي تستخدمه. يحتوي كل إصدار على إعداد النظام الأساسي وخطوات Updater CE وطريقة العودة إلى المخزون.[دليل ويندوز](install/android-4-2-y1-windows.html)[دليل ماك](install/android-4-2-y1-mac.html)[دليل لينكس](install/android-4-2-y1-linux.html)

## Android 4.2 Y1 install steps
  - افتح Innioasis Updater CE على جهاز الكمبيوتر الخاص بك (إذا كنت بحاجة إلى التطبيق، [احصل على Updater CE](guide_ar.html#platform)). تعيين طراز الجهاز ل Y1.
  - اختر أندرويد 4.2 (مطور) في البرنامج.
  - اختر الإصدار المدرج لـ Y1.
  - انقر تثبيت / استعادة.
  - قم بإيقاف تشغيل Y1 وتوصيله فقط عندما يطلب منك Updater CE.
