# התקן את Solar ב-Innioasis Y1 שלך.

Solar הוא פרויקט תוכנה קהילתי עבור הנתיב Y1. בדוק את הערות הגרסה הנוכחיות, ולאחר מכן תן ל-Update לטפל בהתקנה התואמת לדגם.[פתח את המדריך המלא Solar](guides/solar-y1.html)[קבל את זה ב-Updater CE](guide_he.html?model=Y1&software=solar-y1)[למה Solar?](solar-benefits_he.html)

מדריך התקנת המחשב שלך

## התקן את Solar ב-Y1 שלך עם המחשב שלך

בחר את המדריך עבור המחשב שבו אתה משתמש. לכל גרסה יש את הגדרת הפלטפורמה, Updater CE שלבים והדרך חזרה למלאי.[מדריך Windows](install/solar-y1-windows.html)[מדריך macOS](install/solar-y1-mac.html)[מדריך לינוקס](install/solar-y1-linux.html)

[כל Innioasis מדריכי Y1](install/y1.html) · [כל המדריכים Solar](install/solar.html)

## Solar Y1 שלבי התקנה
  - פתח את Innioasis Updater CE במחשב שלך (אם אתה צריך את האפליקציה, [הורדת Updater CE](guide_he.html#platform)). סט דגם המכשיר ל Y1.
  - בחר Solar ב תוכנה.
  - קרא את הערת השחרור של הפרויקט ובחר מהדורה Y1.
  - לחץ התקנה / שחזור.
  - כבה וחבר את ה-Y1 רק כאשר מופיעה ההנחיה.

Solar תכונות וזמינות יכולים להשתנות. תכונות יכולות להשתנות בין מהדורות, אז בדוק את דף ההפצה של הפרויקט ואת הרישום הנוכחי עבור הדגם שלך.

## שאלות נפוצותהאם אוכל לחזור מ-Solar לתוכנה המקורית?

השתמש בתוכנה מקורית Y1 ב-Updater CE. אינך צריך להסיר ידנית את Solar תחילה. עקוב אחר ה [Y1 שלבי שחזור](original-software-y1_he.html).האם אוכל להתקין את הערך Solar Y2 בנגן הזה?

לא. השאר את הנגן Y1 בכניסה Y1 ובדוק את הדגם לפני ההתקנה.היכן עלי לבדוק תכונות נוכחיות של Solar?

קרא את [הערות שחרור](release_notes_he.html?software=solar-y1) לפני בחירת שחרור.

## צריך את ההסבר הרחב יותר של Updater?

ראה את [מדריך לעדכון Windows, macOS ו-Linux](guide_he.html) לפני ההתחלה, במיוחד אם ה-Y1 לא מזוהה.
