# เฟิร์มแวร์หุ้นดั้งเดิมสำหรับ Innioasis Y2 | ติดตั้งและกู้คืน - Innioasis ดาวน์โหลดเฟิร์มแวร์

ซอฟต์แวร์ต้นฉบับ · Y2 ซอฟต์แวร์สต็อก

# กู้คืนซอฟต์แวร์ต้นฉบับบน Innioasis Y2 ของคุณ

หน้านี้มีไว้สำหรับ Y2 ซอฟต์แวร์สต็อก การกู้คืนจากโรงงาน และการส่งคืนจากโครงการชุมชน เก็บรุ่น Y2 และแพ็คเกจไว้ด้วยกัน[เปิดคู่มือซอฟต์แวร์ต้นฉบับฉบับเต็ม](guides/restore-original-y2.html)[รับสิ่งนี้ใน Updater CE](guide_th.html?model=Y2&software=original-y2)[เรียกดู Y2 รุ่น](firmware_th.html#y2)

คู่มือการติดตั้งสำหรับคอมพิวเตอร์ของคุณ

## กู้คืนซอฟต์แวร์ต้นฉบับบน Y2 ของคุณด้วยคอมพิวเตอร์ของคุณ

เลือกคำแนะนำสำหรับคอมพิวเตอร์ที่คุณใช้ ทุกรุ่นมีการตั้งค่าแพลตฟอร์ม ขั้นตอน Updater CE และวิธีคืนสินค้าในสต็อก[คู่มือวินโดวส์](install/original-y2-windows.html)[คู่มือ macOS](install/original-y2-mac.html)[คู่มือลินุกซ์](install/original-y2-linux.html)

[คำแนะนำ Innioasis Y2 ทั้งหมด](install/y2.html) · [คู่มือซอฟต์แวร์ต้นฉบับทั้งหมด](install/original-software.html)

## ติดตั้งหรือกู้คืนด้วย Updater

ตั้งค่าคอมพิวเตอร์ก่อน จากนั้นให้ Updater เตรียมแพ็คเกจที่ตรงกับรุ่น
  - เปิด Innioasis Updater CE บนคอมพิวเตอร์ของคุณ (หากคุณต้องการแอป [รับ Updater CE](guide_th.html#platform)). ชุด รุ่นอุปกรณ์ ถึง Y2.
  - เลือก ซอฟต์แวร์ดั้งเดิม และการเปิดตัว Y2
  - คลิก ติดตั้ง / คืนค่า.
  - ปิดเครื่องและเชื่อมต่อ Y2 เฉพาะเมื่อมีการถามสดเท่านั้น

อาจใช้แพ็คเกจการติดตั้งแบบเต็มด้วยตนเอง `rom_y2.zip`. อย่ารักษา Y1 `rom.zip` เป็นตัวแทน

## คำถามที่พบบ่อยฉันสามารถคืนจาก Rockbox หรือซอฟต์แวร์อื่นที่กำหนดเองได้หรือไม่

ใช้โฟลว์การคืนค่า Y2 เดียวกัน: เลือก Y2 เลือกซอฟต์แวร์ต้นฉบับ และปฏิบัติตามข้อความแจ้งการเชื่อมต่อ อย่าผสมไฟล์โมเดลเหตุใดแพ็คเกจ Y2 จึงดูแตกต่างออกไป

Y2 การเผยแพร่สามารถใช้ชื่อแพ็คเกจและรายการการเผยแพร่ที่แตกต่างกัน เลือก Y2 ใน Updater แทนที่จะเดาจากชื่อไฟล์ ZIP แบบกำหนดเองจะเกิดอะไรขึ้นหากตรวจไม่พบผู้เล่น?

ตรวจสอบสายเคเบิลข้อมูล สิทธิ์ของคอมพิวเตอร์หรือไดรเวอร์ และเวลา เชื่อมต่อการปิดเครื่อง Y2 หลังจากที่ Updater แจ้งว่าพร้อมแล้วเท่านั้น
