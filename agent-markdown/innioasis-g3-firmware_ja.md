# Innioasis G3 & G1 ファームウェアのダウンロード

Innioasis G3 および G1 ポータブル ミュージック プレーヤーの公式の工場出荷時のファームウェア アップデートとリカバリ配布。ダウンロードが確認されました `rom_g3.zip` そして `rom_g1.zip` Innioasis ファームウェア アーカイブのソフトウェア ダウンロード セクションから直接パッケージをダウンロードします。[G3 ダウンロードを参照](firmware_ja.html?model=G3)[G1 ダウンロードを参照](firmware_ja.html?model=G1)[Updater CE を入手](guide_ja.html#platform)

## G シリーズ プレーヤー向けの信頼性の高いファームウェア

の Innioasis G3 そして Innioasis G1 は、バッテリー寿命が長く、オフラインで聴くことができるように設計された、コンパクトでポケットに入れられるオーディオ プレーヤーです。プレーヤーが応答しなくなったり、起動時にフリーズしたり、新しいシステム ソフトウェアが必要な場合には、当社のアーカイブがテスト済みの工場出荷時復元イメージを提供します。

G シリーズ ファームウェア カタログの特徴:
  - オリジナルストックソフトウェア: 工場出荷時のオーディオ プレーヤー、FM ラジオ機能、Bluetooth ドライバーを復元します。
  - クロスプラットフォームのインストール: を使用して直接インストールします [Innioasis アップデーター CE](guide_ja.html) macOS、Linux、または Windows 上で。
  - いつでも利用可能: コミュニティによってホストされており、期限切れのファイル共有リンクはありません。

## プレーヤーを Updater CE でフラッシュする

G3 または G1 プレーヤーを復元するには:
  - 開く Innioasis アップデーター CE デスクトップまたはラップトップ上で。
  - 選択 G3 または G1 デバイスモデルメニューから。
  - 選択してください 純正ソフトウェア Updater は適切なファイルを取得します。 `rom_g3.zip` または `rom_g1.zip`.
  - 接続プロンプトに従ってプレーヤーを USB に接続し、フラッシュを完了します。
