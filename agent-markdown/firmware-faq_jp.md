# ファームウェアとソフトウェアに関する質問への回答

Innioasis および Timmkoo デバイス用の公式ストック ファームウェア、工場出荷時のリカバリ ROM、およびカスタム OS オプション (Rockbox、Better-Y、Solar、JJ Launcher、Inniclassic、Y2Player、Koensayr) に関するわかりやすい英語のガイド。[Updater CE を入手](guide_ja.html#platform)[ファームウェアアーカイブを参照](firmware_ja.html)

ストックと回収

## ストックファームウェア、ブリック解除、およびサポートされているモデル

### プレーヤーのブリックを解除するためのストック ファームウェアはどこで見つけられますか?

モデルを選択してください。次に、ファイルをダウンロードするか、Updater CE にインストールさせます。すべてのパッケージは、アップされる前にチェックされます。

### Innioasis ファームウェア アーカイブはどのモデルをサポートしていますか?

私たちは次のソフトウェアをホストしています Innioasis Y1, Y2, G1, G3, G5, R1, PR1 とD1。新しいビルドは準備が整うとすぐに表示されます。 Timmkoo Q5 および Q3 も Updater CE を通じてインストールされます。

### カスタムファームウェアから工場出荷時のソフトウェアに戻すことはできますか?

はい。 Updater CE でモデルを選択し、 純正ソフトウェアをクリックしてから、インストール/復元を実行します。別のモデルのファイルは絶対に使用しないでください。

各ルートで得られるもの

## あなたの聴き方に合ったソフトウェアをお選びください。

### 純正ソフトウェア

プレーヤーに同梱されているソフトウェア。ローカル音楽、Bluetooth、そして使い慣れたインターフェース。何も設定する必要はありません。それが安全なベースラインであり、最も早く戻る方法です。

[Y1 に復元します](original-software-y1_ja.html) · [Y2 に復元します](original-software-y2_ja.html)

### Better-Y

Leska1337 による Y1 の改良されたストック システム。よりクリーンなタグ、トラック番号、より迅速なナビゲーション、および完全なテーマのサポート。

[Y1 の Better-Y](better-y-y1-software_ja.html) · [なぜBetter-Y?](better-y-benefits_ja.html)

### Rockbox

音楽愛好家の選択。ファイル名ではなくタグで並べ替えます。ギャップレス再生、クロスフェード、イコライザー、豊富なテーマ ライブラリ。オフラインでも動作します。

[Y1 の Rockbox](rockbox-y1-software_ja.html) · [Y2 の Rockbox](rockbox-y2-software_ja.html) · [なぜRockbox?](rockbox-benefits_ja.html)

### Solar

Solar は Wi-Fi をオンにし、プレーヤーがストリーミングおよびダウンロードできるようにします。 Deezer、Soulseek、ポッドキャスト、YouTube、ステム プレーヤー。 Rockboxも付いてきます。

[Y1 の Solar](solar-y1-software_ja.html) · [Y2 の Solar](solar-y2-software_ja.html) · [なぜSolar?](solar-benefits_ja.html)

### JJ Launcher

高速でホイールに優しいランチャー。ライブラリの高速スキャン、イコライザーのプリセット、任意の画面からのハードウェア ボタンによるトラック スキップ、Wi-Fi 経由のワイヤレス ファイル アップロード、アプリ内 Bluetooth ペアリング、Web テーマ エディターでドロップインまたはデザインできるテーマ。

[Y1 の JJ Launcher](jj-launcher-y1-software.html) · [Y2 の JJ Launcher](jj-launcher-y2-software.html) · [なぜJJ Launcher?](jj-launcher-benefits.html)

### Inniclassic

JJ Launcher に基づいて構築された iPod Classic のトリビュート。クラシックなメニューの外観、クリックホイール スタイルの音楽クイズ、同期された歌詞、Last.fm のスクロブルに加えて、ポッドキャスト、FM ラジオ、およびビデオ。 Y1 および Y2 コミュニティ ビルド。

[Y1 の Inniclassic](inniclassic-y1-software_ja.html) · [Y2 の Inniclassic](inniclassic-y2-software_ja.html) · [なぜInniclassic?](inniclassic-benefits_ja.html)

### Y2Player

Y2 の音楽ファーストのホーム画面。永続的なキューによるオフライン再生、ギャップレスおよびクロスフェードトランジション、停止した場所から再開するオーディオブック、FLAC から Opus までのあらゆる一般的なフォーマット。 Bluetooth オーディオが機能し、インターネット接続は必要ありません。

[Y2 の Y2Player](y2player-y2-software_ja.html) · [なぜY2Player?](y2player-benefits_ja.html)

### Koensayr

在庫 Y1 の外観を維持します。音楽はアーティストごとに閲覧でき、Bluetooth はトラック名を表示し、車のコントロールと連動します。

[Y1 の Koensayr](koensayr-y1-software.html) · [なぜKoensayr?](koensayr-benefits.html)

これらのプロジェクトは迅速に進みます。 インストールする前に、各プロジェクトのリリース ノートと問題トラッカーをお読みください。何か問題が発生した場合は、モデルの元のソフトウェアを復元するのが安全な方法です。

## どのツールを使用すればよいですか?

Innioasis アップデータ CE プレーヤーを更新する最も安全な方法です。音楽、ビデオ、Bluetooth のペアリングを維持します。 Innioasis Universal Flash Tool はそれらを消去します。

アップデートの準備が完了すると通知されます。各ステップを画面に表示します。 Windows、macOS、Linux 上で動作します。

Catsteal3r の TikTok や Dammit Jeff の「実際に Spotify を終了する方法」ビデオなどのコミュニティのチュートリアルでは、Updater CE の使用を推奨しています。[ツールを比較する](updater-comparison_ja.html)
