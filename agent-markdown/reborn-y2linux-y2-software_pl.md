# Reborn (Y2Linux) dla Innioasis Y2

Szybka, specjalnie zaprojektowana dystrybucja Debiana Linux z natywnym interfejsem użytkownika z kółkiem do klikania dla Innioasis Y2, zapewniająca stabilność słuchawek Bluetooth i aktywny rozwój społeczności.[Przewodnik krok po kroku Y2.](guides/reborn-y2linux-y2.html)[Dlaczego Y2Reborn?](reborn-y2linux-benefits_pl.html)[Pobierz wydania](firmware_pl.html?model=Y2&software=reborn-y2linux-y2)

## Zainstaluj Reborn (Y2Linux) na swoim Y2 za pomocą komputera

Wybierz przewodnik dla komputera, którego używasz. Każda wersja ma konfigurację platformy, Updater CE kroki i drogę powrotną do stanu magazynowego.[Przewodnik po Windowsie](install/reborn-y2linux-y2-windows.html)[przewodnik po macOS-ie](install/reborn-y2linux-y2-mac.html)[Przewodnik po Linuksie](install/reborn-y2linux-y2-linux.html)

[Wszystkie Innioasis prowadnice Y2](install/y2.html) · [Wszystkie przewodniki Reborn (Y2Linux).](install/reborn.html)

## Kroki instalacji
  - Otwórz Aktualizator CE. Dostępne dla systemów Windows, macOS i Linux.
  - Wybierz Y2 jako model urządzenia.
  - Wybierz Reborn (Y2Linux) jak oprogramowanie.
  - Kliknij Zainstaluj/Przywróć. Poczekaj, aż Updater CE przygotuje pliki.
  - Połącz USB, gdy zostaniesz o to poproszony. Najpierw wyłącz Y2.
  - Skonfiguruj Wi-Fi, Bluetooth i radio FM

Kopiuj `system.img` raz do gracza. Reborn zajmie się resztą.[Zakończ konfigurację →](y2reborn_wifibt_pl.html)
