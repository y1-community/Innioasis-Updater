## Instal atau pulihkan dengan Updater

Siapkan komputer terlebih dahulu, lalu biarkan Updater menyiapkan paket yang sesuai model.
  - Buka Innioasis Updater CE di komputer Anda (jika Anda memerlukan aplikasinya, [Dapatkan Updater CE](guide_id.html#platform)). Tetapkan Model perangkat untuk Y2.
  - Pilih Perangkat lunak asli dan rilis Y2.
  - Klik Pasang / Pulihkan.
  - Matikan dan sambungkan Y2 hanya ketika perintah langsung menanyakan.

Paket instalasi lengkap manual dapat digunakan `rom_y2.zip`. Jangan perlakukan Y1 `rom.zip` sebagai pengganti.

## Pertanyaan umumBisakah saya kembali dari Rockbox atau perangkat lunak khusus lainnya?

Gunakan alur pemulihan Y2 yang sama: pilih Y2, pilih Perangkat Lunak Asli, dan ikuti perintah koneksi. Jangan mencampur file model.Mengapa paket Y2 terlihat berbeda?

Y2 rilis dapat menggunakan nama paket dan entri rilis yang berbeda. Pilih Y2 di Updater daripada menebak-nebak nama file ZIP manual.Bagaimana jika pemain tidak terdeteksi?

Periksa kabel data, izin komputer atau driver, dan waktunya. Hubungkan Y2 yang dimatikan hanya setelah Updater menyatakan siap.
