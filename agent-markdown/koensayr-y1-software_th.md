# ติดตั้ง Koensayr บน Y1

Koensayr แสดงเป็นตัวเลือกซอฟต์แวร์ชุมชน Y1 ใช้โฟลว์ตัวอัปเดตที่ทราบโมเดลแทนการค้นหาแพ็คเกจตามชื่อไฟล์[เปิดคำแนะนำ Koensayr ฉบับเต็ม](guides/koensayr-y1.html)[รับสิ่งนี้ใน Updater CE](guide_th.html?model=Y1&software=koensayr-y1)[ทำไมต้อง Koensayr?](koensayr-benefits_th.html)

คู่มือการติดตั้งสำหรับคอมพิวเตอร์ของคุณ

## ติดตั้ง Koensayr บน Y1 ด้วยคอมพิวเตอร์ของคุณ

เลือกคำแนะนำสำหรับคอมพิวเตอร์ที่คุณใช้ ทุกรุ่นมีการตั้งค่าแพลตฟอร์ม ขั้นตอน Updater CE และวิธีคืนสินค้าในสต็อก[คู่มือวินโดวส์](install/koensayr-y1-windows.html)[คู่มือ macOS](install/koensayr-y1-mac.html)[คู่มือลินุกซ์](install/koensayr-y1-linux.html)

[คำแนะนำ Innioasis Y1 ทั้งหมด](install/y1.html) · [คำแนะนำ Koensayr ทั้งหมด](install/koensayr.html)

## Koensayr Y1 ขั้นตอนการติดตั้ง
  - เปิด Innioasis Updater CE บนคอมพิวเตอร์ของคุณ (หากคุณต้องการแอป [รับ Updater CE](guide_th.html#platform)). ชุด รุ่นอุปกรณ์ ถึง Y1.
  - เลือก Koensayr ใน ซอฟต์แวร์.
  - เลือกรุ่น Y1 ที่อยู่ในรายการ
  - คลิก ติดตั้ง / คืนค่า.
  - ปิดเครื่องและเชื่อมต่อ Y1 เมื่อ Updater CE ถามเท่านั้น

## คำถามที่พบบ่อยฉันสามารถกู้คืนซอฟต์แวร์ Y1 ดั้งเดิมได้หรือไม่

ใช่. เลือก Y1 และซอฟต์แวร์ต้นฉบับใน Updater CE ดู [Y1 หน้าสต็อกซอฟต์แวร์](original-software-y1_th.html) เพื่อเส้นทางการคืนค่าที่สมบูรณ์ฉันควรตรวจสอบอะไรเมื่อมันล้มเหลว?

ตรวจสอบรุ่น ปล่อย สายเคเบิล การตั้งค่าแพลตฟอร์ม และดูว่าเครื่องเล่นเชื่อมต่ออยู่หรือไม่ก่อนที่จะได้รับแจ้ง จากนั้นใช้ [การแก้ไขปัญหา](troubleshooting_th.html).มีแพ็คเกจ Koensayr Y2 หรือไม่?

โครงสร้างปัจจุบันมีไว้สำหรับ Y1 อย่าใช้ใน Y2 เว้นแต่โครงการจะเผยแพร่รุ่นแยกต่างหากสำหรับมัน

## เริ่มต้นด้วยการตั้งค่าคอมพิวเตอร์

Updater ทำงานได้กับ Windows, macOS และ Linux หลังจากการตั้งค่าแพลตฟอร์มพร้อมแล้ว อ่าน [คำแนะนำทั่วไป](guide_th.html#platform) ก่อน
