# Rockbox ROM stažení pro Y1 a Y2

Stáhněte si Rockbox balíčky firmwaru ROM pro Innioasis Y1 (Rockbox-Y1) a Y2 (Rockbox-Y2) přímo od komunitních vývojářů nebo nainstalujte jedním kliknutím pomocí Innioasis Updater CE.

## Nejprve si vyberte model přehrávače

Rockbox-Y1 a Rockbox-Y2 jsou samostatné sestavení firmwaru vytvořené pro jiný hardware. Před stažením nebo flashováním zkontrolujte, zda je váš přehrávač Innioasis Y1 nebo Y2.

## Jak Updater CE stahuje firmware

Innioasis Updater CE vždy stahuje balíčky firmwaru přímo z vlastních verzí firmwaru komunitních vývojářů a sami vývojáři jsou výhradně zodpovědní za uvedení svých verzí softwaru v Updater CE. Každý balíček ROM obsahuje rozptylový soubor MediaTek a obrazy diskových oddílů pro daný model.
  - Rockbox-Y1 balíček vydání pro vývojáře: `rom.zip` (a `rom_type_b.zip` pro Type B Y1 jednotek).
  - Rockbox-Y2 balíček vydání pro vývojáře: `rom_y2.zip`.

## Nainstalujte automaticky pomocí Updater CE

Pro nejjednodušší nastavení otevřete Innioasis Updater CE, vyberte model přehrávače a Rockbox a nechte aplikaci stáhnout a flashovat vydání přímo. Postupujte podle [Rockbox-Y1 průvodce instalací](rockbox-y1/install.html) nebo [Rockbox-Y2 průvodce instalací](rockbox-y2/install.html).
