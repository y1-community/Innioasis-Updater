## Rockbox Y2 etapas de instalação
  - Abra o Innioasis Updater CE no seu computador (se precisar do aplicativo, [Obter o Updater CE](guide_pt-BR.html#platform)). Definir Modelo do aparelho para Y2.
  - Escolher Rockbox em Software.
  - Escolha uma versão listada explicitamente para Y2.
  - Clique Instalar / Restaurar e aguarde a preparação do pacote.
  - Desligue e conecte o Y2 somente quando Updater CE solicitar.

Não force um pacote Y1 porque o nome do projeto parece o mesmo. Se nenhuma versão Y2 aparecer, pare e verifique o modelo e os dados da versão atual.
