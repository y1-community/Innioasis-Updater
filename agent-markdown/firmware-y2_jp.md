# Innioasis Y2 のファームウェア

Y2 は、より優れたオーディオ ハードウェア、Bluetooth、ファイル マネージャーを備えています。復元するカスタム システム、Linux ビルド、または公式ソフトウェアを選択します。[Y2 ダウンロードを参照](firmware_ja.html?model=Y2)[Updater CE を入手](guide_ja.html#platform)[Y2 テーマ ガイド](https://themes.innioasis.app/y2-themes.html?lang=ja)

## Innioasis Y2 で利用可能なオペレーティング システム

Y2 で実行したいものを選択してください:

### [Reborn (Y2Linux)](reborn-y2linux-benefits_ja.html)

Buildroot、LVGL、PipeWire、MPD を組み合わせたネイティブ組み込み Linux OS。 3 秒の起動時間、真の Bluetooth ヘッドフォン再接続修正、ギャップレス再生を実現します。[Y2Reborn ガイド →](guides/reborn-y2linux-y2.html)

### [Y2 の Rockbox](rockbox-benefits_ja.html)

Innioasis Y2 に移植された究極のオーディオファイル ファームウェア。パラメトリック イコライゼーション、カスタム フォント、クロスフィード、および広範なプラグイン ライブラリのサポート。[Y2 Rockbox ガイド →](guides/rockbox-y2.html)

### [Y2 の Solar](solar-benefits_ja.html)

Y2 用の最新の流動的な Flutter ベースの音楽プレーヤー インターフェイス。豊富なビジュアライザ、大規模なアルバム アート プレゼンテーション、ジェスチャ ナビゲーションを備えています。[Solar Y2 ガイド →](guides/solar-y2.html)

### [Y2Player](y2player-benefits_ja.html)

Y2 ハードウェア用に作られた軽量のコミュニティ オーディオ プレーヤーで、シンプルなフォルダーの参照と高速なインデックス スキャンを備えています。[Y2Player ガイド →](guides/y2player-y2.html)

### [オリジナルソフトウェア (工場出荷時復元)](original-software-benefits_ja.html)

Innioasis Y2 を工場出荷時の状態に復元するための公式ストック ファームウェア イメージ (rom_y2.zip)。テーマ ギャラリー スキンのサポートも完備。[Y2 の復元ガイド →](guides/restore-original-y2.html)

## Innioasis Y2 にファームウェアをインストールしています

Updater CE は適切なファイルを取得し、フラッシュする前にドライバーをチェックします。
  - Innioasis Updater CE を起動します: macOS、Linux、Windows でネイティブに利用できます。
  - セットモデル: 選択 Y2 [デバイスモデル]メニューで。
  - オペレーティング システムを選択してください: Reborn、Rockbox、Solar、またはオリジナル ソフトウェアを選択します。
  - 安全にフラッシュ: 画面上のプロンプトに従って、USB 経由でデバイスを接続し、クリーンで検証済みのフラッシュを取得します。
[Y2 ファームウェア カタログを探索する](firmware_ja.html?model=Y2)[インストールの概要](guide_ja.html)
