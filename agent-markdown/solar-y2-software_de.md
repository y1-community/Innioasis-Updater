## Modellkorrekte Y2-Prüfungen
  - Öffnen Sie Innioasis Updater CE auf Ihrem Computer (wenn Sie die App benötigen, [Updater CE holen](guide_de.html#platform)). Satz Gerätemodell an Y2.
  - Bestätigen Sie das Solar ist in den aktuellen Versionsdaten für Y2 aufgeführt.
  - Lesen Sie die Versionshinweise zum Projekt und überprüfen Sie die Y2-Unterstützung.
  - Wählen Sie die aufgelistete Version aus und klicken Sie auf Installieren / Wiederherstellen.
  - Schalten Sie das Y2 nur aus und schließen Sie es an, wenn Updater CE dazu fragt.
Ersetzen Sie kein Y1-Paket. Wenn ein Projekt für Y1 verfügbar ist, ist sein Paket Y1 nicht für Y2 sicher.

## FAQWird Solar Y2 garantiert unterstützt?

Ein Solar Y2 Build ist aufgeführt, aber Unterstützung und Inhalte können sich ändern. Überprüfen Sie vor der Installation die aktuelle Auflistung und die Versionshinweise.Wie kehre ich zum Lagerbestand zurück?

Wählen Sie Y2 und Originalsoftware in Updater CE und folgen Sie dann den Anweisungen [Y2-Wiederherstellungsanleitung](original-software-y2_de.html).Was passiert, wenn Solar für Y2 nicht angezeigt wird?

Erzwingen Sie kein Y1-Paket. Überprüfen Sie die Projektquelle und die [Anleitung zur Fehlerbehebung](troubleshooting_de.html), und warten Sie dann auf eine kompatible Version.

## Richten Sie zunächst den Computer ein

Der spielerseitige Ablauf ist derselbe, nachdem die Plattformeinrichtung fertig ist. Beginnen Sie mit dem [Updater-Anleitung für Windows, macOS oder Linux](guide_de.html#platform).
