## 使用更新程式安裝或恢復它

無論 Y1 目前正在運行其原始軟體還是社區項目，更新程式都使用相同的引導流程。
  - 在您的電腦上開啟 Innioasis Updater CE（如果您需要該應用程序， [取得 Updater CE](guide_zh-TW.html#platform)）。套裝 裝置型號 到 Y1.
  - 選擇 原廠軟體 在 軟體 （或使用 [在 Updater CE 中取得此內容](guide_zh-TW.html?model=Y1&software=original-y1) 跳到引導步驟）。
  - 點選 安裝 / 還原 並讓應用程式準備包。
  - 僅在即時提示詢問時才關閉電源並連接 Y1。

手動下載時，通常的完整安裝套件名為 `rom.zip`。 Updater 中的模型選擇是選擇檔案的更安全的方式。

## 常見問題我可以從 Rockbox 或其他自訂軟體恢復嗎？

是的，使用 Y1 模型和 Y1 原始軟體路徑。不要先刪除系統文件，也不要替換 Y2 套件。如果我的 Y1 沒有被偵測到怎麼辦？

檢查數據線、電腦設定和連接時間。僅應在出現更新程式提示時關閉播放器並連線。我的 Y1 應該使用哪個套件？

將模型列印在更新程式中選擇的播放器上。 Y1 和 Y2 套件是獨立的 - 如果發布清單與您的型號不匹配，請停止。
