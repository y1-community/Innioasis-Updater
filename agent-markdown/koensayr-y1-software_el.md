## Koensayr Y1 install steps
  - Ανοίξτε το Innioasis Updater CE στον υπολογιστή σας (αν χρειάζεστε την εφαρμογή, [Αποκτήστε το Updater CE](guide_el.html#platform)). Σειρά Μοντέλο συσκευής να Y1.
  - Επιλέγω Koensayr σε Λογισμικό.
  - Choose the listed Y1 release.
  - Κλικ Εγκατάσταση / Επαναφορά.
  - Απενεργοποιήστε και συνδέστε το Y1 μόνο όταν σας ζητήσει το Updater CE.

Check the model, release, cable, platform setup, and whether the player was connected before the prompt. Then use [αντιμετώπιση προβλημάτων](troubleshooting_el.html).Is there a Koensayr Y2 package?

The current build is for Y1. Don't use it on a Y2 unless the project publishes a separate release for it.
