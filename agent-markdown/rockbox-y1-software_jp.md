## Rockbox Y1 のインストール手順
  - コンピューターで Innioasis Updater CE を開きます (アプリが必要な場合は、 [Updater CE を入手](guide_ja.html#platform)）。セット デバイスモデル 支援先: Y1.
  - 選択してください Rockbox で ソフトウェア.
  - 目的の画面またはテーマのパスに一致するリリースとバリアントを選択してください。
  - クリック インストール / 復元 アプリが準備するまで待ちます。
  - 電源を切り、ライブ プロンプトでのみ Y1 を接続します。

を使用します。 [書かれた Rockbox Y1 ガイド](guides/rockbox-y1.html) スクリーンショット、ビデオ、Type A または Type B のメモ、接続チェックリストについては、こちらをご覧ください。

## よくある質問元の Y1 ソフトウェアに戻ることはできますか?

はい。 Y1 を選択し、Updater CE で元のソフトウェアを選択し、インストール/復元を実行します。の [Y1 ストック ソフトウェア ページ](original-software-y1_ja.html) そのルートを説明します。どの Rockbox リリースを選択すればよいですか?

Y1 に表示されているリリースを選択し、そのリリース ノートをお読みください。古いテーマの互換性が必要な場合は、Y2 ビルドを選択するのではなく、解像度とバリアントの注意事項を確認してください。これを Y2 にインストールできますか?

いいえ。別途使用してください。 [Rockbox Y2 ページ](rockbox-y2-software_ja.html) Updater CEでY2を選択します。
