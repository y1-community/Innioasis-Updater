# 🚀 Слідія

Платформа керування мікропрограмою професійного рівня📦

### Управління пакетами

Комплексна система керування пакетами для мікропрограм, тем і налаштувань🔧

### Розширені інструменти

Інструменти професійного рівня для розробників і досвідчених користувачів🌐

### Система репозиторіїв

Централізована система репозиторію для легкого доступу до всіх Y1 ресурсів[📚 Переглянути репозиторій Slidia ](https://github.com/team-slide/slidia)

## Що таке Slidia?

### 📋 Система маніфестів

Slidia надає повну систему XML-маніфестів, яка каталогізує всі доступні пакети мікропрограм, теми та інструменти для Y1 пристроїв. Цей централізований підхід полегшує пошук ресурсів і керування ними.

### 🔗 Інтеграція репозиторію

Підключається до сховищ проектів, щоб ви могли отримувати найновіші випуски мікропрограм, оновлення та внески спільноти.

### 📱 Сумісність пристрою

Створено спеціально для Y1 пристроїв із повною підтримкою типів і моделей пристроїв, що забезпечує сумісність усіх Y1 варіантів.

### ⚡ Оптимізовано продуктивність

Високопродуктивне виявлення пакетів і керування ними з інтелектуальним кешуванням і обмеженням швидкості для оптимального випуску.

### 🌍 Кросплатформенність

Працює в Windows, macOS і Linux.

### 🛠️ Зручний для розробників

Чисті API і добре задокументована структура дозволяють розробникам легко розширювати та інтегрувати власні інструменти та програми.
