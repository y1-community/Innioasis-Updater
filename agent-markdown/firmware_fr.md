## Installez votre choix avec Updater CE
  - Ouvrez le guide et installez Innioasis Updater CE pour votre ordinateur si vous ne l'avez pas encore.
  - Dans Updater CE, sélectionnez le modèle imprimé sur votre lecteur parmi Modèle d'appareil.
  - Depuis Logiciel, sélectionnez le logiciel que vous souhaitez exécuter sur ce modèle.
  - Sélectionnez une version, cliquez sur Installer / Restaurer, puis éteignez et connectez le lecteur uniquement lorsque Updater CE le demande.

Besoin de l'installateur ? [Ouvrez le guide et développez la section de téléchargement Updater CE](guide_fr.html#download-updater).

## Le retour en toute sécurité

### Vérifiez le modèle

Y1 and Y2 software is not interchangeable. Re-select the model in Updater CE and start again.

### Attendez l'invite

Éteignez complètement le lecteur et connectez-le uniquement lorsque Updater CE indique qu'il est prêt.

### Restaurer le logiciel d'origine

Choisissez le logiciel original pour le même modèle. Si une récupération manuelle est nécessaire, ouvrez le [guide de dépannage](troubleshooting_fr.html) d'abord.

## Supported Devices and Official Stock Firmware

The Innioasis Firmware Archive hosts verified stock firmware, original factory restore images, and custom operating systems for portable players:

### Innioasis Y1 & Y2

Official software and custom systems including Rockbox, Better-Y, and Solar.

### Innioasis G1, G3 & G5

Logiciels officiels et fichiers de récupération pour les lecteurs à écran tactile.

### Innioasis R1 & PR1

Logiciels originaux et fichiers de récupération pour lecteurs audio.

### Timmkoo Q5 & Q3

Packages provided for Timmkoo players via Updater CE.

New releases appear here as soon as they are verified.

## Quel outil dois-je utiliser ?

Innioasis Programme de mise à jour CE is the recommended tool for daily updates and community OS installs across Windows, macOS, and Linux. Flashing through Updater CE preserves your library and pairings.

The legacy Universal Flash Tool remains available for emergency unbricking when a device cannot boot into fastboot.[Compare flashing tools](updater-comparison_fr.html)
