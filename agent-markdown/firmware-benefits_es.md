# Comparar firmwares y opciones de software

Desde software original oficial de fábrica hasta creaciones comunitarias como Rockbox, Solar, Better-Y y Reborn (Y2Linux), descubra el mejor software para sus hábitos de audio.[Explorar descargas de software](firmware_es.html)[Ayúdame a elegir](firmware-faq_es.html)[Obtener Updater CE](guide_es.html#platform)

## Descripción general del softwareFirmware de fábrica

### Software original

Soporte completo para audio Bluetooth, radio FM, audiolibros y máscaras personalizadas de la Galería de temas. [Más información →](original-software-benefits_es.html)Estándar de audiófilo

### Rockbox

Ecualizador paramétrico, reproducción sin interrupciones, alimentación cruzada y amplia personalización de temas. [Más información →](rockbox-benefits_es.html)Fábrica mejorada

### Better-Y

Mejoras de la comunidad además del software original con arranques personalizados, aplicaciones parcheadas y compatibilidad con temas. [Más información →](better-y-benefits_es.html)Interfaz de usuario moderna

### Solar

Interfaz limpia y moderna con ricas ilustraciones de artistas y animaciones personalizadas. [Más información →](solar-benefits_es.html)Linux nativo

### Reborn (Y2Linux)

Sistema operativo basado en Debian diseñado para la rueda de clic Y2, que soluciona los cortes de Bluetooth. [Más información →](reborn-y2linux-benefits_es.html)Velocidad y enfoque

### Rondo

Firmware de audio ligero con rueda de clic dedicado para Y1. [Más información →](rondo-benefits_es.html)
