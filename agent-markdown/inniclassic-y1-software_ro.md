# Instalați Inniclassic pe Y1.

Inniclassic este un proiect software comunitar pentru Y1, iar același proiect publică și o versiune Y2, deci este disponibilă pentru ambii jucători. Această pagină vă oferă Y1 răspunsul ușor de căutat și link-uri către pașii de conectare detaliați.[Deschideți ghidul complet Inniclassic.](guides/inniclassic-y1.html)[Obțineți asta în Updater CE](guide_ro.html?model=Y1&software=inniclassic-y1)[De ce Inniclassic?](inniclassic-benefits_ro.html)

Ghid de instalare pentru computerul dvs

## Instalați Inniclassic pe Y1 cu computerul dvs

Alegeți ghidul pentru computerul pe care îl utilizați. Fiecare versiune are configurarea platformei, Updater CE pași și calea de întoarcere la stoc.[Ghidul Windows](install/inniclassic-y1-windows.html)[ghid macOS](install/inniclassic-y1-mac.html)[Ghid Linux](install/inniclassic-y1-linux.html)

[Toate ghidurile Innioasis Y1](install/y1.html) · [Toate ghidurile Inniclassic.](install/inniclassic.html)

## Inniclassic Y1 pași de instalare
  - Deschideți Innioasis Updater CE pe computer (dacă aveți nevoie de aplicație, [Obține Updater CE](guide_ro.html#platform)). Setați Model dispozitiv la Y1.
  - Alege Inniclassic în Software.
  - Alegeți versiunea listată pentru Y1.
  - Faceți clic Instalează / Restaurează.
  - Opriți și conectați Y1 numai când Updater CE vă cere.

## Întrebări frecventePot restaura software-ul stoc Y1?

Da. Selectați Y1 și Software original în Updater CE. The [Ghid de stoc-software Y1](original-software-y1_ro.html) acoperă calea de întoarcere.Ce se întâmplă dacă instalarea eșuează?

Rețineți dacă Updater a eșuat înainte sau după detectarea Y1, apoi verificați cablul, configurarea platformei, modelul și sincronizarea conexiunii în [depanare](troubleshooting_ro.html).Pot folosi Inniclassic pe Y2?

Da. Inniclassic este disponibil pe ambele modele — același proiect menținut publică un pachet Y2 din aceleași versiuni. Selectați Y2 în Updater CE și instalați versiunea Y2; nu flash niciodată un pachet Y1 către un Y2. The [Pagina de instalare Y2](inniclassic-y2-software_ro.html) o acoperă.

## Utilizați traseul ghidat

Prima dată când folosești Updater? Consultați configurarea ghidată către [Obține Updater CE](guide_ro.html#platform) pe Windows, macOS sau Linux înainte de a vă conecta playerul.
