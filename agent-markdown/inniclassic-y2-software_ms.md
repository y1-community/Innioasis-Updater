# Install Inniclassic on the Y2.

Inniclassic is available for the Innioasis Y2, and the same project also builds the Y1 packages. This page gives you the Y2 overview and links to the full tutorial.[Open the full Inniclassic guide](guides/inniclassic-y2.html)[Dapatkan ini dalam Updater CE](guide_ms.html?model=Y2&software=inniclassic-y2)[Mengapa Inniclassic?](inniclassic-benefits_ms.html)

## Inniclassic Y2 install steps
  - Buka Innioasis Updater CE pada komputer anda (jika anda memerlukan apl itu, [Dapatkan Updater CE](guide_ms.html#platform)). Tetapkan Model Peranti kepada Y2.
  - pilih Inniclassic dalam Perisian.
  - Choose the release listed for Y2.
  - klik Pasang / Pulihkan.
  - Matikan dan sambungkan Y2 hanya apabila Updater CE bertanya.

## Soalan LazimCan I restore the stock Y2 software?

Yes. Select Y2 and Original Software in Updater CE. The [Y2 stock-software guide](original-software-y2_ms.html) meliputi laluan pulang.Can I use Inniclassic on Y1?

Yes. The same project publishes Y1 packages as well — rom.zip for Type A and rom_type_b.zip for Type B. Select Y1 in Updater CE and install the Y1 build; the [Halaman pemasangan Y1](inniclassic-y1-software_ms.html) covers it.Bagaimana jika pemasangan gagal?

Note whether Updater failed before or after detecting the Y2, then check the cable, platform setup, model, and connection timing in [penyelesaian masalah](troubleshooting_ms.html).
