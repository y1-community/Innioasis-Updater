# Reborn (Y2Linux) Innioasis Y2

Nopea, tarkoitukseen rakennettu Debian Linux -jakelu, jossa on natiivi käyttöliittymä Innioasis Y2:lle, Bluetooth-kuulokkeiden vakaus ja aktiivinen yhteisökehitys.[Vaiheittainen Y2 opas](guides/reborn-y2linux-y2.html)[Miksi Y2Reborn?](reborn-y2linux-benefits_fi.html)[Lataa julkaisut](firmware_fi.html?model=Y2&software=reborn-y2linux-y2)

Asennusopas tietokoneellesi

## Asenna Reborn (Y2Linux) Y2-laitteeseen tietokoneesi kanssa

Valitse käyttämäsi tietokoneen opas. Jokaisessa versiossa on alustan asetukset, Updater CE vaiheet ja tie takaisin varastoon.[Windowsin opas](install/reborn-y2linux-y2-windows.html)[macOS-opas](install/reborn-y2linux-y2-mac.html)[Linux opas](install/reborn-y2linux-y2-linux.html)

[Kaikki Innioasis Y2-oppaat](install/y2.html) · [Kaikki Reborn (Y2Linux) oppaat](install/reborn.html)

## Asennusvaiheet
  - Avaa Updater CE. Saatavilla Windowsille, macOS:lle ja Linuxille.
  - Valitse Y2 laitteen mallina.
  - Valitse Reborn (Y2Linux) ohjelmistona.
  - Napsauta Asenna / Palauta. Odota, kun Updater CE valmistelee tiedostot.
  - Yhdistä USB pyydettäessä. Katkaise ensin Y2 virta.
  - Määritä Wi-Fi, Bluetooth ja FM-radio

Kopioi `system.img` pelaajalle kerran. Reborn hoitaa loput.[Viimeistele asennus →](y2reborn_wifibt_fi.html)
