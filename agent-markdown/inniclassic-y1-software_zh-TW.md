# 在 Y1 上安裝 Inniclassic。

Inniclassic 是 Y1 的社群軟體項目，同一項目也發布了 Y2 版本，因此兩個播放器都可用。此頁面為您提供 Y1 易於搜尋的答案以及詳細連接步驟的連結。[開啟完整的 Inniclassic 指南](guides/inniclassic-y1.html)[在 Updater CE 中取得此內容](guide_zh-TW.html?model=Y1&software=inniclassic-y1)[為什麼是Inniclassic？](inniclassic-benefits_zh-TW.html)

## Inniclassic Y1 安裝步驟
  - 在您的電腦上開啟 Innioasis Updater CE（如果您需要該應用程序， [取得 Updater CE](guide_zh-TW.html#platform)）。套裝 裝置型號 到 Y1.
  - 選擇 Inniclassic 在 軟體.
  - 選擇為 Y1 列出的版本。
  - 點選 安裝 / 還原.
  - 僅當 Updater CE 詢問時關閉電源並連接 Y1。

## 常見問題我可以恢復原廠Y1軟體嗎？

是的。在Updater CE中選擇Y1和原始軟體。的 [Y1庫存軟體指南](original-software-y1_zh-TW.html) 覆蓋返迴路徑。如果安裝失敗怎麼辦？

請注意更新程式在偵測到 Y1 之前或之後是否失敗，然後檢查線纜、平台設定、型號和連接時序 [故障排除](troubleshooting_zh-TW.html).我可以在 Y2 上使用 Inniclassic 嗎？

是的。 Inniclassic 在兩種模型上均可使用 — 同一維護項目從相同版本發布 Y2 套件。在 Updater CE 中選擇 Y2 並安裝 Y2 版本；切勿將 Y1 套件刷新到 Y2。這 [Y2安裝頁面](inniclassic-y2-software_zh-TW.html) 覆蓋它。

## 使用引導路線

第一次使用更新程式？請參閱指導設定 [取得 Updater CE](guide_zh-TW.html#platform) 在 Windows、macOS 或 Linux 上，然後再連接播放器。
