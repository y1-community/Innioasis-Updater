# Instale Koensayr en Y1.

Koensayr aparece como una opción de software comunitario Y1. Utilice el flujo de actualización compatible con el modelo en lugar de buscar un paquete por nombre de archivo.[Abra la guía completa Koensayr](guides/koensayr-y1.html)[Obtener en Updater CE](guide_es-419.html?model=Y1&software=koensayr-y1)[¿Por qué Koensayr?](koensayr-benefits_es-419.html)

Guía de instalación para su computadora

## Instala Koensayr en tu Y1 con tu computadora

Elija la guía para la computadora que está utilizando. Cada versión tiene la configuración de la plataforma, Updater CE pasos y el camino de regreso al stock.[guía de windows](install/koensayr-y1-windows.html)[guía de macos](install/koensayr-y1-mac.html)[guía de linux](install/koensayr-y1-linux.html)

[Todas las Innioasis Y1 guías](install/y1.html) · [Todas las Koensayr guías](install/koensayr.html)

## Koensayr Y1 pasos de instalación
  - Abra Innioasis Updater CE en su computadora (si necesita la aplicación, [Obtener Updater CE](guide_es-419.html#platform)). conjunto Modelo del dispositivo a Y1.
  - elegir Koensayr en Software.
  - Elija la versión Y1 listada.
  - Haga clic Instalar / Restaurar.
  - Apague y conecte el Y1 solo cuando Updater CE lo solicite.

## Preguntas frecuentes¿Puedo restaurar el software Y1 original?

Sí. Seleccione Y1 y Software original en Updater CE. Ver el [Y1 página de software de stock](original-software-y1_es-419.html) para la ruta de restauración completa.¿Qué debo comprobar cuando falla?

Verifique el modelo, la versión, el cable, la configuración de la plataforma y si el reproductor estaba conectado antes del mensaje. Entonces usa [solución de problemas](troubleshooting_es-419.html).¿Existe un paquete Koensayr Y2?

La compilación actual es para Y1. No lo use en un Y2 a menos que el proyecto publique una versión separada para él.

## Comience con la configuración de la computadora

El actualizador funciona en Windows, macOS y Linux una vez que la configuración de la plataforma está lista. Lea el [guia general](guide_es-419.html#platform) primero.
