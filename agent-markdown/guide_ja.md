# Innioasis Updater CE を使ってみる

すべての Innioasis および Timmkoo オーディオ プレーヤーで動作します。コンピュータに Innioasis Updater CE をインストールし、モデルと必要なソフトウェアを選択して、画面の指示に従います。

## 

[Updater CE を入手](guide_ja.html#download-updater)[完全な書面によるチュートリアル](guide_ja.html)

## Innioasis Updater CEを取得

Innioasis アップデータ CE は、プレーヤーに公式アップデートとコミュニティ ソフトウェアをインストールするアプリです。音楽と設定を保持し、Windows、macOS、Linux 上で実行できます。

### Windows

インストーラーをダウンロードして実行し、完了したら PC を再起動します。[ドライバーを入手する](https://github.com/y1-community/supplemental-apks/releases/latest/download/DriverInstall.exe)[ダウンロード Updater CE](https://github.com/y1-community/Innioasis-Updater/releases/latest/download/installer.exe)

Windows によってアプリの実行が停止されたり、起動されない場合は、[設定] を開き、[プライバシーとセキュリティ] → [Windows セキュリティ] → [アプリとブラウザー コントロール] をクリックして、スマート アプリ コントロールをオフにしてください。 Smart App Control は現在、Epic Overlay Service (Fortnite で使用) などの人気のあるアプリケーションに影響を与えています。Updater CE は安全で、使用が検証されています。 [Windows ではアプリが起動しませんか?ヘルプ](#smart-app-control)

インストール後、PC を再起動します。ドライバーのヘルプは、 [Windows セットアップに関するメモ](drivers_ja.html#windows).

### macOS[ダウンロード Updater CE](https://github.com/y1-community/Innioasis-Updater/releases/latest/download/Innioasis.Updater.for.Mac.dmg)

初めてアプリを実行する際にMacでブロックされた場合は、「システム設定」を開き、「プライバシーとセキュリティ」をクリックして、「セキュリティ」まで下にスクロールし、 [とにかく開く](https://support.apple.com/en-gb/102445#openanyway)をクリックしてください。FinderでアプリをControlキーを押しながらクリック（または右クリック）して「開く」を選択することもできます。

macOS Monterey 以降を搭載した Intel および Apple Silicon Mac で動作します。

### Linux

Intel および AMD システム用の AppImage をダウンロードし、実行可能にして実行します。[Intel/AMD 用の AppImage をダウンロード](https://github.com/y1-community/innioasis-updater/releases/latest/download/UpdaterCE.AppImage)

[Linux セットアップに関するメモ](drivers_ja.html#linux)別のプラットフォームですか？

プレーヤー、データを伝送する USB データ ケーブル (充電専用ケーブルでは取り付けられません)、そして数分が必要です。 Updater CE で完了と表示されるまで、ケーブルを接続したままにしてください。

## モデルとソフトウェアを選択してください
  - デバイスモデル: プレーヤーに印刷されているモデルを選択し、 Y1 または Y2。あるモデル用に作成されたソフトウェアを他のモデルにインストールすることはできません。
  - ソフトウェアとリリース: モデルにリストされているオリジナル ソフトウェア Rockbox、Solar、JJ Launcher、Inniclassic、Y2Player、または Koensayr を選択し、リリースを選択します。安定したものを選択するのが安全です。
  - インストール： クリック インストール / 復元、プレーヤーの電源を完全にオフにし、Updater CE が要求した場合にのみ USB ケーブルを接続します。
  - 仕上げる： 成功メッセージが表示されるまでプレーヤーとケーブルを放置し、接続を解除してプレーヤーを起動します。

2.0.0 より前のオリジナル ソフトウェアとともに出荷された Y1 プレーヤーには、 デバイス Type B。他の人はデフォルトの Type A をそのまま使用します。電源がオフのプレーヤーを接続するためのアップデーターの接続手順モデルのライブ Updater CE プロンプトに従います。

## 元のソフトウェアに戻る

カスタム ソフトウェアは元に戻すことができます。 Updater CE でモデルを選択し、 純正ソフトウェア、安定したリリースを選択して実行します インストール / 復元 同じように。手動で削除するものはありません。[Y1 復元ガイド](guides/restore-original-y1.html)[Y2 復元ガイド](guides/restore-original-y2.html)

USB プロンプトが表示される前にフラッシュが停止する場合は、まずケーブル、プラットフォームの設定、モデルを確認してください。見る [トラブルシューティング](troubleshooting_ja.html) 修正するには、 [Y1 および Y2 リカバリ ガイド](guides/recovery.html) 動力と車輪の故障、そして [SP Flash Tool](sp-flash-tool_ja.html) 高度な回復のために。

## Windows ではアプリが起動しませんか?スマート アプリ コントロールの回避策

Windows Defender SmartScreen または Smart App Control は、署名の評価が伝播する前に、新しくダウンロードされたコミュニティ アプリケーションをブロックできます。 Smart App Control は現在、Epic Overlay Service (Fortnite で使用) などの人気のあるアプリケーションに影響を与えています。Updater CE は安全で、使用が検証されています。 Smart App Control をオフにすると、Updater CE が正常に開いて実行できるようになります。
  - 開く 設定 Windows PC 上で ( Win + I).
  - クリック プライバシーとセキュリティ 左側のサイドバーで をクリックし、 Windows Security.
  - クリック アプリとブラウザの制御.
  - 下 スマートアプリコントロール、 クリック スマートアプリコントロールの設定.
  - トグルを次のように設定します オフ Updater CE の起動を許可します。

Edge経由でダウンロードしましたか? Edge がダウンロード自体をブロックする場合は、[その他のオプション] ボタン (…) → 保つ → もっと見る → とにかく保管してください.

後でスマート アプリ コントロールを再度有効にします。 スマート アプリ コントロールをオンに戻したい場合は、次の Windows レジストリから再度有効にすることができます。 `HKEY_LOCAL_MACHINE\SYSTEM\CurrentControlSet\Control\CI\Policy` 設定により `VerifiedAndReputablePolicyState` 支援先: `1` (オン) または `2` （評価モード）して再起動します。
