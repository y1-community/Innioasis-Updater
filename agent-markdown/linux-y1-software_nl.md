# Install Linux on the Y1.

Linux for Y1 is an experimental community Linux kernel and rootfs port for the Innioasis Y1 hardware. This page links to the full installation guide and releases.[Open the full Linux for Y1 (Dev) guide](guides/linux-y1.html)[Ontvang dit in Updater CE](guide_nl.html?model=Y1&software=linux-y1)[Projectbron](https://github.com/y1-community/y1-linux-rom)

Kies de handleiding voor de computer die u gebruikt. Elke versie heeft de platformconfiguratie, Updater CE stappen en de weg terug naar de voorraad.[Windows-gids](install/linux-y1-windows.html)[macOS-gids](install/linux-y1-mac.html)[Linux-gids](install/linux-y1-linux.html)

## Linux Y1 install steps
  - Open Innioasis Updater CE op uw computer (als u de app nodig heeft, [Updater CE downloaden](guide_nl.html#platform)). Instellen Apparaatmodel aan Y1.
  - Kies Linux voor Y1 (ontwikkelaar) binnen Software.
  - Choose the release listed for Y1.
  - Klik Installeren / Herstellen.
  - Schakel de Y1 alleen uit en sluit deze alleen aan als Updater CE daarom vraagt.
