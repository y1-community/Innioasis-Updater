# Innioasis Depanarea programului de actualizare | Innioasis și Timmkoo probleme de instalare - Innioasis Updater

Depanare

# Găsiți punctul în care s-a oprit instalarea.

Unde s-a oprit? Asta vă spune ce să remediați.[Reveniți la ghidul normal](guide_ro.html)[Verificați firmware-ul](firmware_ro.html)

## S-a oprit înainte de promptul USB.

Aceasta este o problemă de computer, nu o problemă de cablu. Verificați-vă modelul. Despachetați fișierul din nou. Atunci încearcă Instalează / Restaurează. Dacă lista de lansări este goală, deschideți [directorul de firmware](firmware_ro.html).

## Nu se poate conecta la player
  - Opriți complet Y1 sau Y2.
  - Deconectați cablul, închideți alte instrumente flash sau Android și începeți din nou instalarea.
  - Conectați-vă numai când Updater spune că este gata.
  - Utilizați un cablu de date scurt USB direct în computer, nu un hub dacă este posibil.
  - Pe Windows, reinstalați driverul MediaTek și reporniți. Pe Linux, verificați permisiunile USB/serial.
Solicitare de conectare la actualizatorPromptul Live Updater este autorizat pentru modelul și platforma actuale.

## A detectat playerul, dar blițul a eșuat

Oprește-te aici. Nu încercați un alt model. Închideți alte instrumente, verificați că ați ales Y1 sau Y2 corect și utilizați software-ul original corespunzător dacă playerul nu pornește. [SP Flash Tool](sp-flash-tool_ro.html) și MTKClient sunt incluse dacă aveți nevoie de ele, iar fișierele sunt pe [pagina de firmware](firmware_ro.html).

## Note despre driverul Windows

Unele instalări Windows blochează driverul MediaTek din cauza izolării Core. Urmați instrucțiunile actuale de securitate Windows înainte de a schimba integritatea memoriei și reporniți-o când ați terminat, dacă sistemul dvs. permite acest lucru.[Deschideți ghidul șoferului](drivers_ro.html)[Ghid de instalare curat](Troubleshooting/clean_install.html)

## Roata nu funcționează sau playerul nu pornește

Defecțiunile de intrare și de alimentare necesită pași diferiți față de un blitz eșuat. Aceste ghiduri acoperă cazurile comune Y1 și Y2.[Y1 rotiță de defilare](guides/y1-scroll-wheel-not-working.html)[Y2 rotiță de defilare](guides/y2-scroll-wheel-not-working.html)[Y1 nu se va porni](guides/y1-wont-turn-on.html)[Y2 nu se va porni](guides/y2-wont-turn-on.html)[Ghid de recuperare](guides/recovery.html)
