# Innioasis Y2 的固件

Y2 具有更好的音频硬件、蓝牙和文件管理器。选择自定义系统、Linux 版本或官方软件进行恢复。[浏览 Y2 下载](firmware_zh-CN.html?model=Y2)[获取 Updater CE](guide_zh-CN.html#platform)[Y2 主题指南](https://themes.innioasis.app/y2-themes.html?lang=zh-CN)

## Innioasis Y2 的可用操作系统

选择您想要在 Y2 上运行的内容：

### [Reborn (Y2Linux)](reborn-y2linux-benefits_zh-CN.html)

结合了 Buildroot、LVGL、PipeWire 和 MPD 的原生嵌入式 Linux 操作系统。提供 3 秒启动时间、真正的蓝牙耳机重新连接修复和无缝播放。[Y2Reborn 指南 →](guides/reborn-y2linux-y2.html)

### [Y2 的 Rockbox](rockbox-benefits_zh-CN.html)

移植到 Innioasis Y2 的终极发烧友固件。参数均衡、自定义字体、交叉馈送和广泛的插件库支持。[Y2 Rockbox 指南 →](guides/rockbox-y2.html)

### [Solar 为 Y2](solar-benefits_zh-CN.html)

Y2 的基于 Flutter 的现代、流畅的音乐播放器界面。具有丰富的可视化工具、大型专辑封面演示和手势导航。[Solar Y2 指南 →](guides/solar-y2.html)

### [Y2Player](y2player-benefits_zh-CN.html)

专为 Y2 硬件打造的轻量级社区音频播放器，具有简单的文件夹浏览和快速索引扫描功能。[Y2Player 指南 →](guides/y2player-y2.html)

### [原始软件（恢复出厂设置）](original-software-benefits_zh-CN.html)

官方库存固件映像 (rom_y2.zip) 用于将 Innioasis Y2 恢复到原始出厂状态，并配有主题库皮肤支持。[恢复 Y2 指南 →](guides/restore-original-y2.html)

## 在您的 Innioasis Y2 上安装固件

更新程序 CE 会抓取正确的文件并在刷新之前检查驱动程序：
  - 启动 Innioasis 更新程序 CE： 本机可在 macOS、Linux 和 Windows 上使用。
  - 设定型号： 选择 Y2 在设备型号菜单中。
  - 选择操作系统： 选择 Reborn、Rockbox、Solar 或原始软件。
  - 安全闪光： 按照屏幕上的提示通过 USB 连接您的设备，以获得干净、经过验证的闪存。
