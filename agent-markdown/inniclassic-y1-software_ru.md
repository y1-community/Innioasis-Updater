Inniclassic · Innioasis Y1

# Установите Inniclassic на Y1.

Inniclassic — это проект сообщества программного обеспечения для Y1, и этот же проект также публикует сборку Y2, поэтому она доступна для обоих игроков. На этой странице вы найдете Y1 удобный для поиска ответ и ссылки на подробные инструкции по подключению.[Открыть полное руководство Inniclassic](guides/inniclassic-y1.html)[Получите это в Updater CE](guide_ru.html?model=Y1&software=inniclassic-y1)[Почему Inniclassic?](inniclassic-benefits_ru.html)

Руководство по установке для вашего компьютера

## Установите Inniclassic на свой Y1 с помощью компьютера.

Выберите руководство для компьютера, который вы используете. В каждой версии есть настройка платформы, Updater CE шагов и возврат к стоку.[Руководство по Windows](install/inniclassic-y1-windows.html)[руководство по macOS](install/inniclassic-y1-mac.html)[Руководство по Linux](install/inniclassic-y1-linux.html)

[Все Innioasis Y1 руководства](install/y1.html) · [Все Inniclassic руководства](install/inniclassic.html)

## Inniclassic Y1 шаги установки
  - Откройте Innioasis Updater CE на своем компьютере (если вам нужно приложение, [Скачать Updater CE](guide_ru.html#platform)). Набор Модель устройства в адрес Y1.
  - Выбирать Inniclassic в Программное обеспечение.
  - Выберите выпуск, указанный для Y1.
  - Нажмите Установить / Восстановить.
  - Выключите питание и подсоедините Y1 только тогда, когда появится запрос Updater CE.

## Вопросы и ответыМогу ли я восстановить стандартное программное обеспечение Y1?

Да. Выберите Y1 и оригинальное программное обеспечение в Updater CE. [Y1 руководство по стандартному программному обеспечению](original-software-y1_ru.html) перекрывает обратный путь.Что делать, если установка не удалась?

Обратите внимание, произошел сбой программы обновления до или после обнаружения Y1, затем проверьте кабель, настройку платформы, модель и время подключения в [Поиск неисправностей](troubleshooting_ru.html).Могу ли я использовать Inniclassic на Y2?

Да. Inniclassic доступен на обеих моделях — один и тот же поддерживаемый проект публикует пакет Y2 из одних и тех же выпусков. Выберите Y2 в Updater CE и установите сборку Y2; никогда не прошивайте пакет Y1 в Y2. [Y2 страница установки](inniclassic-y2-software_ru.html) покрывает это.
