# Original Software for Innioasis & Timmkoo Players

Original Software is the system your player shipped with. Stable, with themes from the [Themes Gallery](https://themes.innioasis.app/), FM radio, Bluetooth, audiobooks, and a safe restore in Updater CE.[Browse Software Downloads](firmware.html)[Get Updater CE](guide.html#platform)[Browse Themes Gallery](https://themes.innioasis.app/)

## Why use or restore Original Software?

### Full Themes Gallery Support

Original Software on Y1 and Y2 works directly with custom skins from the [Themes Gallery](https://themes.innioasis.app/). Change icons, background wallpapers, player dials, and fonts without modifying core system partitions.

### Everything Works Out of the Box

Full support for Bluetooth headphones and car audio, physical clickwheel navigation, hardware FM radio tuning, audiobook bookmarking, e-books, and video playback with zero manual configuration.

### Safe Recovery & Unbrick Baseline

If you ever want to revert from a custom firmware experiment or recover a player that will not boot, Updater CE restores Original Software in a single guided step.
