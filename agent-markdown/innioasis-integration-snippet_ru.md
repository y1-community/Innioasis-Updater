# Встроить руководство по установке Innioasis Updater - Innioasis Updater

# 🚀 Innioasis Updater - Встраиваемое руководство по установке

Это полноценный встраиваемый виджет руководства по установке, который можно легко интегрировать в любой веб-сайт. Он имеет классный всплывающий призыв к действию в правом нижнем углу, который открывает подробное руководство по установке для пользователей Windows, macOS и Linux.

### 🎨 Красивый дизайн

Современный адаптивный дизайн, работающий на всех устройствах с поддержкой темного режима.

### 📱 Кроссплатформенность

Полные руководства по установке для Windows, macOS и Linux с пошаговыми инструкциями.

### 🔧 Простая интеграция

Просто скопируйте и вставьте фрагмент — никаких зависимостей или сложной настройки не требуется.

### 💾 Умное хранилище

Запоминает, закрыли ли пользователи баннер, чтобы не быть навязчивыми.

## 📋 Инструкции по интеграции

Чтобы добавить руководство по установке Innioasis Updater на свой веб-сайт, просто скопируйте и вставьте этот фрагмент кода в свой HTML: <!-- Innioasis Виджет «Руководство по установке обновления» --> <script> (function() { // Создание и внедрение виджета const script = document.createElement('script'); script.src = 'https://your-domain.com/innioasis-embed.html'; script.async = true; // Альтернатива: загрузка из локального файла // script.src = './innioasis-embed.html'; document.head.appendChild(script); // Создать контейнер iframe = document.createElement('iframe'); iframe.src = 'https://your-domain.com/innioasis-embed.html'; iframe.style.cssText = `position: fix; low: 20px; right: 20px; height: 200px; 999999; pointer-events: none; // Делаем iframe интерактивным iframe.onload = function() { iframe.style.pointerEvents = 'auto'; document.body.appendChild(iframe })(); </скрипт> 📋 Скопируйте код интеграции

## 🌐 Требования к хостингу

Чтобы использовать этот виджет на своем сайте, вам необходимо:
  - Загрузите `innioasis-embed.html` файл на ваш веб-сервер
  - Обновите URL-адреса в фрагменте интеграции, чтобы они указывали на ваш сервер.
  - Убедитесь, что ваш сервер поддерживает HTTPS (требуется для современных браузеров).
  - Проверьте виджет на своем сайте, чтобы убедиться, что он работает правильно.
