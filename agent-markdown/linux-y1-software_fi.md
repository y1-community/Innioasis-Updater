# Install Linux on the Y1.

Linux for Y1 is an experimental community Linux kernel and rootfs port for the Innioasis Y1 hardware. This page links to the full installation guide and releases.[Open the full Linux for Y1 (Dev) guide](guides/linux-y1.html)[Hanki tämä Updater CE](guide_fi.html?model=Y1&software=linux-y1)[Projektin lähde](https://github.com/y1-community/y1-linux-rom)

## Install Linux for Y1 (Dev) on your Y1 with your computer

Valitse käyttämäsi tietokoneen opas. Jokaisessa versiossa on alustan asetukset, Updater CE vaiheet ja tie takaisin varastoon.[Windowsin opas](install/linux-y1-windows.html)[macOS-opas](install/linux-y1-mac.html)[Linux opas](install/linux-y1-linux.html)

## Linux Y1 install steps
  - Avaa Innioasis Updater CE tietokoneellasi (jos tarvitset sovelluksen, [Hanki Updater CE](guide_fi.html#platform)). Aseta Laitteen malli to Y1.
  - Valitse Linux for Y1 (kehittäjä) sisään Ohjelmisto.
  - Valitse Y1:lle listattu julkaisu.
  - Napsauta Asenna / Palauta.
  - Katkaise virta ja liitä Y1 vain, kun Updater CE kysyy.
