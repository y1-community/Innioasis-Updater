## Jak Updater CE pobiera oprogramowanie sprzętowe

Innioasis Updater CE zawsze pobiera pakiety oprogramowania sprzętowego bezpośrednio z własnych wydań twórców oprogramowania sprzętowego społeczności, a sami programiści ponoszą wyłączną odpowiedzialność za umieszczenie swoich wersji oprogramowania w serwisie Updater CE. Każdy pakiet ROM zawiera plik rozproszony MediaTek i obrazy partycji dla tego modelu.
  - Rockbox-Y1 pakiet wersji dla programistów: `rom.zip` (I `rom_type_b.zip` dla Type B Y1 jednostek).
  - Rockbox-Y2 pakiet wersji dla programistów: `rom_y2.zip`.

## Zainstaluj automatycznie za pomocą narzędzia Updater CE

Aby ułatwić konfigurację, otwórz Innioasis Updater CE, wybierz model odtwarzacza i Rockbox, a następnie pozwól aplikacji pobrać i bezpośrednio zaktualizować wersję. Postępuj zgodnie z [Rockbox-Y1 instrukcja instalacji](rockbox-y1/install.html) lub [Rockbox-Y2 instrukcja instalacji](rockbox-y2/install.html).
