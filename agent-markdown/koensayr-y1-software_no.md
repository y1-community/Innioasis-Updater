## Koensayr Y1 install steps
  - Åpne Innioasis Updater CE på datamaskinen din (hvis du trenger appen, [Få Updater CE](guide_no.html#platform)). Sett Enhetsmodell til Y1.
  - Velg Koensayr inn Programvare.
  - Choose the listed Y1 release.
  - Klikk Installer / Gjenopprett.
  - Slå av og koble til Y1 bare når Updater CE spør.
