# Начало работы с Innioasis Updater CE

Работает со всеми аудиоплеерами Innioasis и Timmkoo. Установите Innioasis Updater CE на свой компьютер, выберите свою модель и необходимое программное обеспечение, затем следуйте подсказкам.

## 

[Скачать Updater CE](guide_ru.html#download-updater)[Полное письменное руководство](guide_ru.html)

## Получить Innioasis Обновление CE

Innioasis Средство обновления CE это приложение, которое устанавливает на ваш плеер официальные обновления и программное обеспечение сообщества. Он сохраняет вашу музыку и настройки и работает на Windows, macOS и Linux.

### Windows

Загрузите установщик, запустите его, а затем перезагрузите компьютер, когда он завершится.[Получить драйверы](https://github.com/y1-community/supplemental-apks/releases/latest/download/DriverInstall.exe)[Скачать программу обновления CE](https://github.com/y1-community/Innioasis-Updater/releases/latest/download/installer.exe)

Если Windows не позволяет вам запустить приложение или не запускает его, откройте «Настройки», нажмите «Конфиденциальность и безопасность» → «Безопасность Windows» → «Управление приложениями и браузером» и отключите Smart App Control. Smart App Control в настоящее время влияет на популярные приложения, такие как Epic Overlay Service (используется Fortnite) — Updater CE безопасен и проверен для использования. [Windows не запускает приложение? Помощь](#smart-app-control)

Перезагрузите компьютер после установки. Помощь водителю находится в [Замечания по установке Windows](drivers_ru.html#windows).

### macOS[Скачать программу обновления CE](https://github.com/y1-community/Innioasis-Updater/releases/latest/download/Innioasis.Updater.for.Mac.dmg)

Если Mac блокирует первый запуск приложения, откройте «Системные настройки», выберите «Конфиденциальность и безопасность», прокрутите вниз до раздела «Безопасность» и нажмите [Все равно открыть](https://support.apple.com/en-gb/102445#openanyway). Вы также можете нажать на приложение в Finder удерживая клавишу Control (или правой кнопкой мыши) и выбрать «Открыть».

Работает на компьютерах Mac Intel и Apple Silicon с macOS Monterey и более поздних версиях.

### Linux

Загрузите AppImage для систем Intel и AMD, сделайте его исполняемым и запустите.[Загрузите AppImage для Intel/AMD](https://github.com/y1-community/innioasis-updater/releases/latest/download/UpdaterCE.AppImage)

[Замечания по настройке Linux](drivers_ru.html#linux)Другая платформа?

Вам понадобится плеер, кабель для передачи данных USB, по которому передаются данные (кабель только для зарядки установить невозможно), и несколько минут. Держите кабель подключенным до тех пор, пока программа Updater CE не сообщит, что все готово.

## Выберите свою модель и программное обеспечение
  - Модель устройства: выберите модель, напечатанную на плеере, Y1 или Y2. Программное обеспечение, созданное для одной модели, не может быть установлено на другую.
  - Программное обеспечение и версия: выберите оригинальное программное обеспечение, Rockbox, Solar, JJ Launcher, Inniclassic, Y2Player или Koensayr, если оно указано для вашей модели, затем выберите версию. Стабильный — безопасный выбор.
  - Установить: щелкнуть Установить / Восстановить, полностью выключите плеер и подключайте кабель USB только по запросу Updater CE.
  - Заканчивать: оставьте плеер и кабель в покое до появления сообщения об успехе, затем отключите и запустите плеер.

Y1 игрокам, которые поставлялись с оригинальным программным обеспечением до версии 2.0.0, необходимо Устройство Type B. Все остальные сохраняют значение по умолчанию Type A.Инструкция по подключению апдейтера для подключения выключенного плеераСледуйте интерактивному запросу Updater CE для вашей модели.

## Возврат к оригинальному программному обеспечению

Пользовательское программное обеспечение является обратимым. В Updater CE выберите свою модель, выберите Заводское ПО, выберите стабильную версию и запустите Установить / Восстановить таким же образом. Руками удалять нечего.[Y1 руководство по восстановлению](guides/restore-original-y1.html)[Y2 руководство по восстановлению](guides/restore-original-y2.html)

Если вспышка прекращается до появления приглашения USB, сначала проверьте кабель, настройку платформы и модель. Видеть [Поиск неисправностей](troubleshooting_ru.html) для исправлений, [Y1 и Y2 руководство по восстановлению](guides/recovery.html) за неисправности питания и колес, а также [SP Flash Tool](sp-flash-tool_ru.html) для ускоренного восстановления.

## Windows не запускает приложение? Обходной путь Smart App Control

SmartScreen Защитника Windows или Smart App Control могут блокировать недавно загруженные приложения сообщества до распространения репутации подписи. Smart App Control в настоящее время влияет на популярные приложения, такие как Epic Overlay Service (используется Fortnite) — Updater CE безопасен и проверен для использования. Отключение Smart App Control позволяет Updater CE открываться и работать в обычном режиме.
  - Открыть Настройки на вашем ПК с Windows (нажмите Win + I).
  - Нажмите Конфиденциальность и безопасность на левой боковой панели, затем нажмите Windows Security.
  - Нажмите Управление приложениями и браузерами.
  - Под Интеллектуальное управление приложениями, нажмите Настройки смарт-контроля приложений.
  - Установите переключатель в положение Выключенный чтобы разрешить запуск Updater CE.

Скачивали через Edge? Если Edge блокирует саму загрузку, нажмите кнопку «Дополнительные параметры» (…) → Держать → Показать больше → Сохранить в любом случае.

Повторное включение Smart App Control позже: Если вы хотите снова включить Smart App Control, вы можете снова включить его через реестр Windows в разделе `HKEY_LOCAL_MACHINE\SYSTEM\CurrentControlSet\Control\CI\Policy` установив `VerifiedAndReputablePolicyState` в адрес `1` (Вкл.) или `2` (Режим оценки) и перезапуск.
