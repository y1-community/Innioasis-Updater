## Installationssteg
  - Lansering Innioasis Uppdaterare CE på din Windows-, Mac- eller Linux-dator.
  - Välj Y1 från rullgardinsmenyn Enhetsmodell.
  - Välj Rondo från rullgardinsmenyn Programvara.
  - Klicka Installera / Återställ och vänta på att verktyget laddar ner och förbereder filerna.
  - När du uppmanas av Updater CE, stäng av din Y1 och anslut USB-kabeln.
  - Slutför installationen efter installationen

Följ stegen i [denna guide](post_install_sv.html?software=rondo-y1&model=Y1) för att slutföra installationen på din Y1.[Visa guide](post_install_sv.html?software=rondo-y1&model=Y1)
