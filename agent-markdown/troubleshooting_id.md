# Innioasis Pemecahan masalah pembaruan | Innioasis dan Timmkoo masalah instalasi - Innioasis Updater

Pemecahan masalah

# Temukan titik di mana instalasi berhenti.

Dimana berhentinya? Itu memberitahu Anda apa yang harus diperbaiki.[Kembali ke panduan normal](guide_id.html)[Periksa firmware](firmware_id.html)

## Itu berhenti sebelum prompt USB

Ini masalah komputer, bukan masalah kabel. Periksa model Anda. Buka kemasan file lagi. Lalu coba Pasang / Pulihkan. Jika daftar rilis kosong, buka [direktori firmware](firmware_id.html).

## Itu tidak dapat terhubung ke pemutar
  - Matikan sepenuhnya Y1 atau Y2 yang benar.
  - Cabut kabelnya, tutup flashdisk lain atau alat Android, dan mulai instalasi lagi.
  - Hubungkan hanya ketika Updater mengatakan sudah siap.
  - Gunakan kabel data pendek USB langsung di komputer, bukan hub jika memungkinkan.
  - Di Windows, instal ulang driver MediaTek dan mulai ulang. Di Linux, periksa izin USB/serial.
Perintah koneksi pembaruanPerintah Updater langsung berlaku untuk model dan platform saat ini.

## Itu mendeteksi pemutar tetapi flashnya gagal

Berhenti di sini. Jangan mencoba model lain. Tutup alat lainnya, periksa apakah Anda memilih Y1 atau Y2 yang benar, dan gunakan Perangkat Lunak Asli yang cocok jika pemutar tidak dapat dijalankan. [SP Flash Tool](sp-flash-tool_id.html) dan MTKClient disertakan jika Anda membutuhkannya, dan file-file tersebut ada di [halaman firmware](firmware_id.html).

## Catatan pengemudi Windows

Beberapa instalasi Windows memblokir driver MediaTek karena isolasi Core. Ikuti panduan keamanan Windows saat ini sebelum mengubah integritas Memori, dan aktifkan kembali setelah Anda selesai jika sistem Anda mengizinkannya.[Buka panduan pengemudi](drivers_id.html)[Panduan pemasangan bersih](Troubleshooting/clean_install.html)

## Roda tidak berfungsi, atau pemutar tidak dapat memulai

Kesalahan input dan daya memerlukan langkah yang berbeda dari flash yang gagal. Panduan ini mencakup kasus umum Y1 dan Y2.[Y1 roda gulir](guides/y1-scroll-wheel-not-working.html)[Y2 roda gulir](guides/y2-scroll-wheel-not-working.html)[Y1 tidak mau hidup](guides/y1-wont-turn-on.html)[Y2 tidak mau hidup](guides/y2-wont-turn-on.html)[Panduan pemulihan](guides/recovery.html)
