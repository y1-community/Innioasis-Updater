## JJ Launcher Y1 install steps
  - Deschideți Innioasis Updater CE pe computer (dacă aveți nevoie de aplicație, [Obține Updater CE](guide_ro.html#platform)). Setați Model dispozitiv la Y1.
  - Alege JJ Launcher in Software.
  - Choose the release shown for Y1.
  - Faceți clic Instalează / Restaurează.
  - Opriți și conectați Y1 numai când Updater CE vă cere.

## Întrebări frecventeCan I install the Y2 entry on a Y1?

No. Keep the model and package matched. If the Y1 entry is missing, do not force a Y2 file.Can I go back to the original software?

Yes. Choose Y1 and Original Software in Updater CE. See the [Y1 restore page](original-software-y1_ro.html).Where are all the JJ Launcher releases?
