# ทำไมต้องติดตั้ง Reborn (Y2Linux / Y2Reborn) บน Innioasis Y2 - Innioasis ดาวน์โหลดเฟิร์มแวร์

Innioasis Y2 - Native Linux & Reborn UI

# ทำไมต้องติดตั้ง Reborn (Y2Linux) บน Innioasis Y2 ของคุณ?

สร้างโดย SchulzCode Reborn (Y2Linux / Y2Reborn) นำรากฐาน Linux ที่ใช้ Debian ที่สะอาดและตอบสนองได้ดีและอินเทอร์เฟซแบบคลิกวีลที่สร้างขึ้นตามวัตถุประสงค์มาสู่ Innioasis Y2 ประสบความสำเร็จในโครงการ Y2Player ก่อนหน้านี้ และแก้ปัญหา Y2 หูฟังบลูทูธและการนำทางในห้องสมุดที่มีมายาวนาน[ติดตั้ง Reborn (Y2Linux) บน Y2](guides/reborn-y2linux-y2.html)[เรียกดู Y2Reborn ข่าวประชาสัมพันธ์](firmware_th.html?model=Y2&software=reborn-y2linux-y2)[คู่มือการตั้งค่า Wi-Fi และบลูทูธ](y2reborn_wifibt_th.html)

## สิ่งที่ทำให้ Y2Reborn โดดเด่นใน Y2

### หูฟังบลูทูธที่เชื่อถือได้

สมาชิกชุมชนบน `r/innioasis` รายงานว่า Y2Reborn แก้ไขการจับคู่และการเล่นแบบเลื่อนลงด้วยหูฟังบลูทูธและเอียร์บัดรุ่นใหม่เมื่อเปิดใช้งานแพ็คเกจเฟิร์มแวร์ Wi-Fi และบลูทูธ

### การนำทางแบบคลิกวีลอย่างรวดเร็ว

ได้รับการออกแบบตั้งแต่พื้นฐานจนถึงปุ่มคลิกวีลและปุ่มทางกายภาพ Y2 Y2Reborn ให้การตอบสนองเมนูทันที การเลื่อนตัวอักษรอย่างรวดเร็ว และการเลื่อนไลบรารีที่ราบรื่น

### Real Debian Linux ภายใต้ประทุน

ขับเคลื่อนโดย SchulzCode/Y2Linux และ SchulzCode/Y2Reborn มอบสภาพแวดล้อม Linux เต็มรูปแบบพร้อมไดรเวอร์เสียง ALSA ที่ทันสมัยและการอัปเดตชุมชน

## เริ่มต้นด้วย Y2Rebornขั้นตอนที่ 1

### ติดตั้งด้วย Updater CE

เปิด Innioasis Updater CE เลือก Y2, เลือก Reborn (Y2Linux)และคลิก ติดตั้ง / คืนค่า.ขั้นตอนที่ 2

### เปิดใช้งาน Wi-Fi และบลูทูธ

อ่าน [คู่มือการตั้งค่า Wi-Fi และบลูทูธ](y2reborn_wifibt_th.html) เพื่อทำการจับคู่เริ่มต้นสำหรับหูฟังและการซิงค์เครือข่ายการย้อนกลับอย่างปลอดภัย

### กลับสู่ซอฟต์แวร์ต้นฉบับได้ตลอดเวลา

หากคุณต้องการกลับสู่สต็อกของโรงงาน Updater CE สามารถกู้คืน Y2 ของคุณกลับไปเป็นซอฟต์แวร์ต้นฉบับได้ตลอดเวลา
