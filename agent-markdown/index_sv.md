## Vad är Innioasis Updater CE?

Innioasis Uppdaterare CE is an open-source tool that simplifies updating and restoring your player across Windows, macOS, and Linux.

Flashing through Updater CE preserves your music library, video collection, and Bluetooth pairings while guiding each step on screen.[Hämta Updater CE](guide_sv.html#platform)[Compare flashing tools](updater-comparison_sv.html)[Bläddra i programvaran](firmware_sv.html)

### Innioasis G1, G3 & G5

### Timmkoo A5, Q5 & Q3

Updater CE supports packages provided for Timmkoo players.[Timmkoo guide](firmware-faq_sv.html)

Every package is verified before publication. New builds appear as soon as they are tested.

## Getting started with Rockbox

### Installera Rockbox på Y1

Select Y1, choose Rockbox stable, and connect only when prompted.[Y1 instructions](guides/rockbox-y1.html)[Varför Rockbox?](rockbox-benefits_sv.html)

### Installera Rockbox på Y2

Select Y2 in the tool. The Y2 route uses hardware-specific binaries.[Y2 instructions](guides/rockbox-y2.html)[Varför Rockbox?](rockbox-benefits_sv.html)

### Restore factory software

Returning to factory software uses the same flow: select your model and choose Original Software.[Y1 factory restore](guides/restore-original-y1.html)[Y2 factory restore](guides/restore-original-y2.html)

Compatible with Windows, macOS, and Linux.
