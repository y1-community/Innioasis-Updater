# 为什么要在 Innioasis Y1 上安装 Rondo？

Rondo 是一款开源、专用的点击轮音乐播放器固件，专为 Innioasis Y1 硬件设计。它提供干净的库浏览、干净的排版和快速的音频解码。[在 Y1 上安装 Rondo](guides/rondo-y1.html)[浏览版本](firmware_zh-CN.html?model=Y1&software=rondo-y1)

## Rondo 的亮点

### 快速滚轮响应

精心调整的加速曲线与 Y1 物理电容式触摸轮相匹配，可平滑滚动大型音乐库。

### 专注的音频播放器

没有臃肿软件、后台分析或不必要的守护进程：100% 的硬件资源专用于清晰的音频输出。

### 随时可逆

使用 Innioasis Updater CE 轻松安装，并在您选择时返回原始软件或 Rockbox。
