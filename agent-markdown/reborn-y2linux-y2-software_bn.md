## Installation Steps
  - Open Updater CE. Available for Windows, macOS and Linux.
  - Select Y2 as the device model.
  - Select Reborn (Y2Linux) as the software.
  - Click Install / Restore. Wait while Updater CE prepares the files.
  - Connect USB when asked. Power the Y2 off first.
  - Set up Wi-Fi, Bluetooth & FM radio
