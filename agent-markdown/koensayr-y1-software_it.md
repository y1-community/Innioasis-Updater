## Koensayr Y1 passaggi di installazione
  - Apri Innioasis Updater CE sul tuo computer (se ti serve l'app, [Ottieni Updater CE](guide_it.html#platform)). Impostato Modello del dispositivo a Y1.
  - Scegli Koensayr dentro Software.
  - Scegli la versione Y1 elencata.
  - Fare clic Installa / Ripristina.
  - Spegnere e collegare Y1 solo quando Updater CE lo richiede.

## Domande frequentiPosso ripristinare il software Y1 originale?

SÌ. Selezionare Y1 e Software originale in Updater CE. Vedi il [Y1 pagina del software stock](original-software-y1_it.html) per il percorso di ripristino completo.Cosa devo controllare quando fallisce?

Controlla il modello, la versione, il cavo, la configurazione della piattaforma e se il lettore era collegato prima della richiesta. Quindi utilizzare [risoluzione dei problemi](troubleshooting_it.html).Esiste un pacchetto Koensayr Y2?

La build attuale è per Y1. Non utilizzarlo su un Y2 a meno che il progetto non pubblichi una versione separata per esso.
