# Install Android 4.2 (Dev) on the Y1.

Android 4.2 is a community development ROM for testing and hacking on Innioasis Y1 hardware. This page links to the full tutorial and release list.[Open the full Android 4.2 (Dev) guide](guides/android-4-2-y1.html)[Få dette i Updater CE](guide_no.html?model=Y1&software=android-4-2-y1)[Prosjektkilde](https://github.com/y1-community/y1-ata-rom)

## Android 4.2 Y1 install steps
  - Åpne Innioasis Updater CE på datamaskinen din (hvis du trenger appen, [Få Updater CE](guide_no.html#platform)). Sett Enhetsmodell til Y1.
  - Velg Android 4.2 (Dev) inn Programvare.
  - Velg utgivelsen som er oppført for Y1.
  - Klikk Installer / Gjenopprett.
  - Slå av og koble til Y1 bare når Updater CE spør.
