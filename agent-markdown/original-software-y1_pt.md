## Instale ou restaure-o com o Updater

O atualizador usa o mesmo fluxo guiado, quer o Y1 esteja executando seu software original ou um projeto da comunidade.
  - Abra o Innioasis Updater CE no seu computador (se precisar do aplicativo, [Obter o Updater CE](guide_pt-BR.html#platform)). Definir Modelo do aparelho para Y1.
  - Escolher Software original em Software (ou usar [Obter no Updater CE](guide_pt-BR.html?model=Y1&software=original-y1) para pular para as etapas guiadas).
  - Clique Instalar / Restaurar e deixe o aplicativo preparar o pacote.
  - Desligue e conecte o Y1 somente quando o prompt ao vivo solicitar.

Ao baixar manualmente, o pacote de instalação completa usual é nomeado `rom.zip`. A seleção do modelo no Updater é a maneira mais segura de escolher arquivos.
