## Rockbox Y1 install steps
  - Open Innioasis Updater CE on your computer (if you need the app, [Get Updater CE](guide.html#platform)). Set Device Model to Y1.
  - Choose Rockbox in Software.
  - Pick the release and variant that match your intended screen or theme path.
  - Click Install / Restore and wait for the app to prepare it.
  - Power off and connect the Y1 only at the live prompt.

Use the [written Rockbox Y1 guide](guides/rockbox-y1.html) for the screenshots, video, Type A or Type B note, and connection checklist.

## FAQsCan I go back to the original Y1 software?

Yes. Choose Y1 and Original Software in Updater CE, then run Install / Restore. The [Y1 stock-software page](original-software-y1.html) explains that route.Which Rockbox release should I choose?

Choose a release shown for Y1 and read its release note. If you need older theme compatibility, check the resolution and variant notes rather than selecting a Y2 build.Can I install this on a Y2?

No. Use the separate [Rockbox Y2 page](rockbox-y2-software.html) and select Y2 in Updater CE.
