# Rockbox ROM unduh untuk Y1 dan Y2

Unduh paket firmware ROM Rockbox untuk Innioasis Y1 (Rockbox-Y1) dan Y2 (Rockbox-Y2) langsung dari komunitas pengembang, atau instal dalam satu klik dengan Innioasis Updater CE.

## Pilih model pemutar Anda terlebih dahulu

Rockbox-Y1 dan Rockbox-Y2 adalah build firmware terpisah yang dibuat untuk perangkat keras berbeda. Periksa apakah pemutar Anda adalah Innioasis Y1 atau Y2 sebelum mengunduh atau mem-flash.

## Rockbox-Y1 (Innioasis Y1)``[](https://github.com/rockbox-y1/rockbox/releases/download/stable-v0.6/rom.zip)``[](https://github.com/rockbox-y1/rockbox/releases/download/stable-v0.6/rom_type_b.zip)

| Paket | Mengajukan | Tautan |
| --- | --- | --- |
| Rockbox-Y1 paket pengembang ROM | rom.zip | Unduh |
| Rockbox-Y1 Type B paket pengembang ROM | rom_type_b.zip | Unduh |

Diterbitkan oleh [rockbox-y1/rockbox](firmware_id.html?model=Y1&software=rockbox-y1) pengembang dalam rilis [stable-v0.6](release_notes_id.html?author=rockbox-y1&project=rockbox&version=stable-v0.6&software=rockbox-y1) ([proyek README](firmware_info_id.html?repo=rockbox-y1%2Frockbox&software=rockbox-y1)). Innioasis Updater CE selalu mengunduh paket firmware langsung dari komunitas pengembang firmware itu sendiri, dan pengembang tersebut sepenuhnya bertanggung jawab untuk mencantumkan rilis mereka di Updater CE.[Pasang Rockbox-Y1](rockbox-y1/install.html)[Rockbox-Y1 unduhan](rockbox-y1/download.html)[Rockbox untuk Y1](rockbox-for-y1_id.html)

## Bagaimana Updater CE mengunduh firmware

Innioasis Updater CE selalu mengunduh paket firmware langsung dari rilis milik pengembang firmware komunitas, dan pengembang sendiri bertanggung jawab penuh untuk mencantumkan rilis perangkat lunak mereka di Updater CE. Setiap paket ROM berisi file pencar MediaTek dan gambar partisi untuk model tersebut.
  - Rockbox-Y1 paket rilis pengembang: `rom.zip` (dan `rom_type_b.zip` untuk unit Type B Y1).
  - Rockbox-Y2 paket rilis pengembang: `rom_y2.zip`.

## Instal secara otomatis dengan Updater CE

Untuk pengaturan termudah, buka Innioasis Updater CE, pilih model pemutar Anda dan Rockbox, lalu biarkan aplikasi mengunduh dan mem-flash rilisnya secara langsung. Ikuti [Rockbox-Y1 panduan pemasangan](rockbox-y1/install.html) atau itu [Rockbox-Y2 panduan pemasangan](rockbox-y2/install.html).
