# Mantenha as coisas boas acontecendo.

Updater CE é gratuito. Ele é construído por pessoas que desejam que Innioasis e Timmkoo jogadores continuem úteis. Seu suporte paga pelo arquivo, pelos servidores e pelo tempo.

## Este é um projeto movido por pessoas.

Cada contribuição ajuda alguém a encontrar um firmware funcional, testar um novo projeto ou manter um player antigo ativo por mais algum tempo.
