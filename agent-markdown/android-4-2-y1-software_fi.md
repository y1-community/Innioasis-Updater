# Install Android 4.2 (Dev) on the Y1.

Android 4.2 is a community development ROM for testing and hacking on Innioasis Y1 hardware. This page links to the full tutorial and release list.[Open the full Android 4.2 (Dev) guide](guides/android-4-2-y1.html)[Hanki tämä Updater CE](guide_fi.html?model=Y1&software=android-4-2-y1)[Projektin lähde](https://github.com/y1-community/y1-ata-rom)

## Install Android development ROM on your Y1 with your computer

Valitse käyttämäsi tietokoneen opas. Jokaisessa versiossa on alustan asetukset, Updater CE vaiheet ja tie takaisin varastoon.[Windowsin opas](install/android-4-2-y1-windows.html)[macOS-opas](install/android-4-2-y1-mac.html)[Linux opas](install/android-4-2-y1-linux.html)

## Android 4.2 Y1 install steps
  - Avaa Innioasis Updater CE tietokoneellasi (jos tarvitset sovelluksen, [Hanki Updater CE](guide_fi.html#platform)). Aseta Laitteen malli to Y1.
  - Valitse Android 4.2 (kehittäjä) sisään Ohjelmisto.
  - Valitse Y1:lle listattu julkaisu.
  - Napsauta Asenna / Palauta.
  - Katkaise virta ja liitä Y1 vain, kun Updater CE kysyy.
