# 为什么要在 Innioasis Y2 上安装 Reborn (Y2Linux)？

由 SchulzCode 构建， Reborn (Y2Linux / Y2Reborn) 为 Innioasis Y2 带来了干净、响应灵敏的基于 Debian 的 Linux 基础和专门构建的点击轮界面。它继承了早期的 Y2Player 项目，并解决了长期存在的 Y2 蓝牙耳机和图书馆导航问题。[在 Y2 上安装 Reborn (Y2Linux)](guides/reborn-y2linux-y2.html)[浏览 Y2Reborn 版本](firmware_zh-CN.html?model=Y2&software=reborn-y2linux-y2)[Wi-Fi 和蓝牙设置指南](y2reborn_wifibt_zh-CN.html)

## 是什么让 Y2Reborn 在 Y2 中脱颖而出

### 可靠的蓝牙耳机

社区成员在 `r/innioasis` 报告称，一旦启用 Wi-Fi 和蓝牙固件包，Y2Reborn 就可以解决现代蓝牙耳机和耳塞的配对和播放丢失问题。

### 快速点击轮导航

Y2Reborn 围绕 Y2 拨轮和物理按钮从头开始设计，提供即时菜单响应、快速字母顺序擦洗和流畅的库滚动。

### 真正的 Debian Linux 底层

由 SchulzCode/Y2Linux 和 SchulzCode/Y2Reborn 提供支持，为您提供带有现代 ALSA 音频驱动程序和社区更新的完整 Linux 环境。

## 开始使用 Y2Reborn步骤1

### 下载刷机包

打开InnioasisUpdater CE，选择 Y2， 选择 Reborn (Y2Linux)，然后单击 安装 / 恢复.步骤2

### 启用 Wi-Fi 和蓝牙

阅读 [Wi-Fi 和蓝牙设置指南](y2reborn_wifibt_zh-CN.html) 完成耳机的初始配对和网络同步。安全回滚

### 随时返回原始软件

如果您希望恢复出厂库存，Updater CE 可以随时将您的 Y2 恢复为原始软件。
