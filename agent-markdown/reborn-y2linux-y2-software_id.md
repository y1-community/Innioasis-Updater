# Reborn (Y2Linux) untuk Innioasis Y2

Distribusi Debian Linux yang cepat dan dibuat khusus dengan antarmuka pengguna clickwheel asli untuk Innioasis Y2, menampilkan stabilitas headphone Bluetooth dan pengembangan komunitas aktif.[Panduan langkah demi langkah Y2](guides/reborn-y2linux-y2.html)[Mengapa Y2Reborn?](reborn-y2linux-benefits_id.html)[Unduh Rilis](firmware_id.html?model=Y2&software=reborn-y2linux-y2)

## Instal Reborn (Y2Linux) pada Y2 Anda dengan komputer Anda

Pilih panduan untuk komputer yang Anda gunakan. Setiap versi memiliki pengaturan platform, Updater CE langkah-langkahnya, dan cara kembali ke stok.[Panduan Windows](install/reborn-y2linux-y2-windows.html)[panduan macOS](install/reborn-y2linux-y2-mac.html)[Panduan Linux](install/reborn-y2linux-y2-linux.html)

[Semua Innioasis panduan Y2](install/y2.html) · [Semua panduan Reborn (Y2Linux).](install/reborn.html)

## Langkah-Langkah Instalasi
  - Buka Pembaruan CE. Tersedia untuk Windows, macOS dan Linux.
  - Pilih Y2 sebagai model perangkat.
  - Pilih Reborn (Y2Linux) sebagai perangkat lunak.
  - Klik Instal / Pulihkan. Tunggu sementara Updater CE menyiapkan file.
  - Hubungkan USB ketika ditanya. Matikan Y2 terlebih dahulu.
  - Siapkan Wi-Fi, Bluetooth & radio FM

Salin `system.img` ke pemain satu kali. Reborn melakukan sisanya.[Selesaikan penyiapan →](y2reborn_wifibt_id.html)
