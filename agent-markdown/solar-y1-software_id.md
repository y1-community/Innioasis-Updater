# Instal Solar pada Innioasis Y1 Anda.

Solar adalah proyek perangkat lunak komunitas untuk jalur Y1. Periksa catatan rilis saat ini, lalu biarkan Updater menangani pemasangan yang sesuai dengan model.[Buka panduan lengkap Solar](guides/solar-y1.html)[Dapatkan ini di Updater CE](guide_id.html?model=Y1&software=solar-y1)[Mengapa Solar?](solar-benefits_id.html)

Panduan instalasi untuk komputer Anda

## Instal Solar pada Y1 Anda dengan komputer Anda

Pilih panduan untuk komputer yang Anda gunakan. Setiap versi memiliki pengaturan platform, Updater CE langkah-langkahnya, dan cara kembali ke stok.[Panduan Windows](install/solar-y1-windows.html)[panduan macOS](install/solar-y1-mac.html)[Panduan Linux](install/solar-y1-linux.html)

[Semua Innioasis panduan Y1](install/y1.html) · [Semua panduan Solar](install/solar.html)

## Solar Y1 langkah-langkah pemasangan
  - Buka Innioasis Updater CE di komputer Anda (jika Anda memerlukan aplikasinya, [Dapatkan Updater CE](guide_id.html#platform)). Tetapkan Model perangkat untuk Y1.
  - Pilih Solar di Perangkat lunak.
  - Baca catatan rilis proyek dan pilih rilis Y1.
  - Klik Pasang / Pulihkan.
  - Matikan dan sambungkan Y1 hanya ketika perintah muncul.

Solar fitur dan ketersediaan dapat berubah. Fitur dapat berubah antar rilis, jadi periksa halaman rilis proyek dan daftar model Anda saat ini.
