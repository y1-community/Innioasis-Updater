### 📥 MediaTek 驅動程式安裝訊息

安裝 MediaTek 驅動程式時，您可能會看到一個對話框，詢問是否刪除「原始驅動程式」。怎麼做：重要的： 如果安裝程式詢問“刪除原始驅動程式？”，請按一下 是的。這是正常現象，有助於確保驅動程式在您的 Y1 裝置上正常運作。 

這一步是必要的，因為：
  - 它刪除了任何可能幹擾的衝突驅動程式
  - 它確保 MediaTek 驅動程式完全控制 USB 通訊
  - 它可以防止可能導致連接問題的驅動程式衝突

安裝完成後，根據提示重新啟動電腦即可完成設定。×

#### 第 1 步：取得合適的驅動程式

您的計算機需要知道如何與您的 Y1 對話。我們將安裝兩個驅動程式來實現這一點：📥 MediaTek 司機

這有助於您的電腦識別您的 Y1 設備下載 MediaTek 驅動程式幫助[已經這樣做了](#)下一步：下載應用程式 →

#### 步驟 2： 下載 Innioasis 更新程序

現在讓我們取得將處理韌體更新的實際應用程式：📱 Innioasis Windows 更新程序

這是引導您更新 Y1 的主應用程式下載 Windows 安裝程式← 返回驅動程式下一步：安裝 →

#### 第 3 步：安裝所有內容

快到了！接下來要做的事情如下：
  - 安裝您下載的 MediaTek 驅動程式
  - 安裝 Innioasis 更新程序
  - 重新啟動計算機 （這很重要！）
  - 從開始功能表啟動 Innioasis 更新程序
← 返回下載完成設定1自製2下載3安裝

#### 步驟1：安裝自製軟體

Homebrew 就像一個套件管理器，可以幫助安裝 Mac 所需的所有元件。將其視為一個有用的助手，確保一切正常工作。📥 取得自製軟體

點擊下面的按鈕訪問 Homebrew 網站並遵循其簡單的安裝指南：造訪自製網站下一步：下載應用程式 →

#### 步驟 2： 下載 Innioasis 更新程序

現在讓我們來獲取實際的應用程式。點擊下面的按鈕，它將開始下載到您的下載資料夾：📱 Innioasis Mac 更新程序

這會將 .dmg 檔案（磁碟映像）下載到您的下載資料夾中下載 Mac 版← 返回自製程序下一步：安裝 →

#### 第 3 步：安裝應用程式

現在讓我們在 Mac 上安裝該應用程式：
  - 雙擊下載的 .dmg 檔案（它看起來像磁碟映像）
  - 將 Innioasis 更新程式應用程式拖曳至您的應用程式資料夾
  - 從您的應用程式資料夾中打開它
🔒 安全設定

您可能需要告訴您的 Mac 可以運行此應用程式。確切的步驟取決於您的 macOS 版本：開啟安全指南← 返回下載完成設定
