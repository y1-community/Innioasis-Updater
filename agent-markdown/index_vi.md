## Innioasis Trình cập nhật CE là gì?

Innioasis Updater CN is an open-source tool that simplifies updating and restoring your player across Windows, macOS, and Linux.

Flashing through Updater CE preserves your music library, video collection, and Bluetooth pairings while guiding each step on screen.[Tải Updater CE](guide_vi.html#platform)[Compare flashing tools](updater-comparison_vi.html)[Duyệt phần mềm](firmware_vi.html)

## Supported device models[Duyệt qua tất cả các bản tải xuống](firmware_vi.html)Innioasis

### Innioasis Y1 & Y2

Official software, restore files, and custom systems including Rockbox, Better-Y, and Solar.[Y1 Phần sụn](firmware_vi.html?model=Y1)[Y2 Phần sụn](firmware_vi.html?model=Y2)Innioasis

### Innioasis G1, G3 & G5

Official software and recovery files for touchscreen models. Restore factory apps or unbrick.[G-Series ROMs](firmware_vi.html?brand=Innioasis)Innioasis

### Innioasis R1 & PR1

Original firmware and recovery images for dedicated audio players.[R-Series ROMs](firmware_vi.html?brand=Innioasis)Timmkoo

### Timmkoo A5, Q5 & Q3

Updater CE supports packages provided for Timmkoo players.[Timmkoo guide](firmware-faq_vi.html)

Every package is verified before publication. New builds appear as soon as they are tested.

## Getting started with Rockbox

### Cài đặt Rockbox trên Y1

Select Y1, choose Rockbox stable, and connect only when prompted.[Y1 instructions](guides/rockbox-y1.html)[Tại sao Rockbox?](rockbox-benefits_vi.html)

### Cài đặt Rockbox trên Y2

Select Y2 in the tool. The Y2 route uses hardware-specific binaries.[Y2 instructions](guides/rockbox-y2.html)[Tại sao Rockbox?](rockbox-benefits_vi.html)

### Restore factory software

Returning to factory software uses the same flow: select your model and choose Original Software.[Y1 factory restore](guides/restore-original-y1.html)[Y2 factory restore](guides/restore-original-y2.html)

Compatible with Windows, macOS, and Linux.
