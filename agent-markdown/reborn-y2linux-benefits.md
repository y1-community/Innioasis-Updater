# Why install Reborn (Y2Linux) on your Innioasis Y2?

Built by SchulzCode, Reborn (Y2Linux / Y2Reborn) brings a clean, responsive Debian-based Linux foundation and purpose-built clickwheel interface to the Innioasis Y2. It succeeds the earlier Y2Player project and solves long-standing Y2 Bluetooth headphone and library navigation quirks.[Install Reborn (Y2Linux) on Y2](guides/reborn-y2linux-y2.html)[Browse Y2Reborn Releases](firmware.html?model=Y2&software=reborn-y2linux-y2)[Wi-Fi & Bluetooth Setup Guide](y2reborn_wifibt.html)

## What makes Y2Reborn stand out on the Y2

### Reliable Bluetooth headphones

Community members on `r/innioasis` report that Y2Reborn resolves pairing and playback dropouts with modern Bluetooth headphones and earbuds once the Wi-Fi and Bluetooth firmware package is enabled.

### Fast clickwheel navigation

Designed from the ground up around the Y2 clickwheel and physical buttons, Y2Reborn provides instant menu response, fast alphabetical scrubbing, and smooth library scrolling.

### Real Debian Linux under the hood

Powered by SchulzCode/Y2Linux and SchulzCode/Y2Reborn, giving you a full Linux environment with modern ALSA audio drivers and community updates.
