# Innioasis Y2 に元のソフトウェアを復元します。

このページは Y2 ストック ソフトウェア、工場出荷時復元、およびコミュニティ プロジェクトからの復帰に関するものです。 Y2 モデルとパッケージを一緒に保管してください。[完全なオリジナル ソフトウェア ガイドを開く](guides/restore-original-y2.html)[Updater CE で入手](guide_ja.html?model=Y2&software=original-y2)[Y2 のリリースを参照する](firmware_ja.html#y2)

お使いのコンピューターのインストールガイド

## コンピュータを使用して Y2 上の元のソフトウェアを復元します

使用しているコンピュータのガイドを選択してください。 すべてのバージョンには、プラットフォームのセットアップ、Updater CE の手順、および在庫に戻る方法が含まれています。[Windowsガイド](install/original-y2-windows.html)[macOS ガイド](install/original-y2-mac.html)[Linuxガイド](install/original-y2-linux.html)

[すべての Innioasis Y2 ガイド](install/y2.html) · [すべてのオリジナル ソフトウェア ガイド](install/original-software.html)

## アップデーターを使用してインストールまたは復元する

まずコンピューターをセットアップしてから、アップデーターにモデルに一致するパッケージを準備させます。
  - コンピューターで Innioasis Updater CE を開きます (アプリが必要な場合は、 [Updater CE を入手](guide_ja.html#platform)）。セット デバイスモデル 支援先: Y2.
  - 選択してください 純正ソフトウェア そして Y2 リリース。
  - クリック インストール / 復元.
  - ライブプロンプトが要求した場合にのみ、電源を切り、Y2 を接続してください。

手動フルインストール パッケージでは次のものが使用される場合があります `rom_y2.zip`。 Y1 は扱わないでください `rom.zip` 代わりとして。

## よくある質問Rockbox または別のカスタム ソフトウェアから戻ることはできますか?

同じ Y2 復元フローを使用します。Y2 を選択し、元のソフトウェアを選択し、接続プロンプトに従います。モデルファイルを混在させないでください。Y2 パッケージの外観が異なるのはなぜですか?

Y2 リリースでは、異なるパッケージ名とリリース エントリを使用できます。手動の ZIP ファイル名から推測するのではなく、アップデータで Y2 を選択します。プレーヤーが検出されない場合はどうすればよいですか?

データ ケーブル、コンピューターの許可またはドライバー、およびタイミングを確認してください。電源がオフになっている Y2 は、アップデーターが準備ができたと通知した後でのみ接続してください。
