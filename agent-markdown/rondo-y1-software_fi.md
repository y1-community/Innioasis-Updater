# Rondo Innioasis Y1

Minimalistinen napsautuspyöräsoittimen laiteohjelmisto, joka on suunniteltu erityisesti Innioasis Y1 kapasitiiviselle laitteistolle ja keskittyy täysin reagoivaan toistoon ja selkeään navigointiin.[Vaiheittainen Y1 opas](guides/rondo-y1.html)[Miksi Rondo?](rondo-benefits_fi.html)[Lataa julkaisut](firmware_fi.html?model=Y1&software=rondo-y1)

Asennusopas tietokoneellesi

## Asenna Rondo Y1-laitteeseen tietokoneesi kanssa

Valitse käyttämäsi tietokoneen opas. Jokaisessa versiossa on alustan asetukset, Updater CE vaiheet ja tie takaisin varastoon.[Windowsin opas](install/rondo-y1-windows.html)[macOS-opas](install/rondo-y1-mac.html)[Linux opas](install/rondo-y1-linux.html)

[Kaikki Innioasis Y1-oppaat](install/y1.html) · [Kaikki Rondo oppaat](install/rondo.html)

## Asennusvaiheet
  - Käynnistä Innioasis Päivittäjä CE Windows-, Mac- tai Linux-tietokoneellasi.
  - Valitse Y1 avattavasta Laitemalli-valikosta.
  - Valitse Rondo Ohjelmisto-pudotusvalikosta.
  - Napsauta Asenna / Palauta ja odota, että työkalu lataa ja valmistelee tiedostot.
  - Kun Updater CE pyytää, sammuta Y1 ja kytke USB-kaapeli.
  - Viimeistele asennuksen jälkeinen asennus

Seuraa ohjeita [tämä opas](post_install_fi.html?software=rondo-y1&model=Y1) suorittaaksesi Y1 asennuksen loppuun.[Näytä opas](post_install_fi.html?software=rondo-y1&model=Y1)
