## JJ Launcher Y1 install steps
  - Buka Innioasis Updater CE pada komputer anda (jika anda memerlukan apl itu, [Dapatkan Updater CE](guide_ms.html#platform)). Tetapkan Model Peranti kepada Y1.
  - pilih JJ Launcher dalam Perisian.
  - Choose the release shown for Y1.
  - klik Pasang / Pulihkan.
  - Matikan dan sambungkan Y1 hanya apabila Updater CE bertanya.

## Soalan LazimCan I install the Y2 entry on a Y1?

No. Keep the model and package matched. If the Y1 entry is missing, do not force a Y2 file.Can I go back to the original software?

Yes. Choose Y1 and Original Software in Updater CE. See the [Y1 restore page](original-software-y1_ms.html).Where are all the JJ Launcher releases?

Current builds are in [Muat Turun Perisian](firmware_ms.html#y1). Release notes are on the project’s [release notes](release_notes_ms.html?software=jj-launcher-y1).
