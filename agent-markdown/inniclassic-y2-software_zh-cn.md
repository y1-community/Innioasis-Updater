选择适合您正在使用的计算机的指南。 每个版本都有平台设置、Updater CE步骤和返回库存的方式。[Windows 指南](install/inniclassic-y2-windows.html)[macOS 指南](install/inniclassic-y2-mac.html)[Linux指南](install/inniclassic-y2-linux.html)

## Inniclassic Y2 安装步骤
  - 在您的计算机上打开 Innioasis Updater CE（如果您需要该应用程序， [获取 Updater CE](guide_zh-CN.html#platform)）。套装 设备型号 至 Y2.
  - 选择 Inniclassic 在 软件.
  - 选择 Y2 列出的版本。
  - 点击 安装 / 恢复.
  - 仅当 Updater CE 询问时关闭电源并连接 Y2。

## 常见问题我可以恢复库存 Y2 软件吗？

是的。在 Updater CE 中选择 Y2 和原始软件。这 [Y2 库存软件指南](original-software-y2_zh-CN.html) 覆盖返回路径。我可以在 Y1 上使用 Inniclassic 吗？

是的。同一个项目也发布了 Y1 包 - rom.zip 对于 Type A 和 rom_type_b.zip 对于Type B。在 Updater CE 中选择 Y1 并安装 Y1 版本；这 [Y1安装页面](inniclassic-y1-software_zh-CN.html) 覆盖它。如果安装失败怎么办？

请注意更新程序在检测到 Y2 之前或之后是否失败，然后检查线缆、平台设置、型号和连接时序 [故障排除](troubleshooting_zh-CN.html).
