# 韌體和軟體問題解答

適用於 Innioasis 和 Timmkoo 設備的官方庫存韌體、出廠恢復 ROM 和自訂作業系統選項（Rockbox、Better-Y、Solar、JJ Launcher、Inniclassic、Y2Player、Koensayr）的簡明英語指南。[取得 Updater CE](guide_zh-TW.html#platform)[瀏覽韌體存檔](firmware_zh-TW.html)

庫存和回收

## 庫存韌體、解鎖和支援的型號

### 在哪裡可以找到庫存韌體來解鎖我的播放器？

選擇您的型號。然後下載該文件，或讓 Updater CE 為您安裝。每個包裹在上架前都會經過檢查。

### Innioasis 韌體存檔支援哪些型號？

我們託管軟體用於 Innioasis Y1, Y2, G1, G3, G5, R1, PR1 和D1。新的構建一旦準備好就會出現。 Timmkoo Q5 和 Q3 也透過 Updater CE 安裝。

### 我可以從自訂韌體返回工廠軟體嗎？

是的。在 Updater CE 中，選擇您的型號，然後選擇 原廠軟體，然後執行安裝/恢復。切勿將文件用於不同的模型。

每條路線為您提供什麼

## 選擇適合您聆聽方式的軟體。

### 原廠軟體

您的播放器隨附的軟體。本地音樂、藍牙和熟悉的介面。沒什麼好設定的。這是安全的基線，也是最快的返迴路線。

[在 Y1 上恢復](original-software-y1_zh-TW.html) · [在 Y2 上恢復](original-software-y2_zh-TW.html)

### Better-Y

Leska1337 改進的 Y1 庫存系統。更清晰的標籤、曲目編號、更快的導航和完整的主題支援。

[Y1 上的 Better-Y](better-y-y1-software_zh-TW.html) · [為什麼是Better-Y？](better-y-benefits_zh-TW.html)

### Rockbox

音樂愛好者的選擇。按標籤而不是檔案名稱排序。無縫播放、交叉淡入淡出、均衡器和大型主題庫。離線工作。

[Y1 上的 Rockbox](rockbox-y1-software_zh-TW.html) · [Y2 上的 Rockbox](rockbox-y2-software_zh-TW.html) · [為什麼是Rockbox？](rockbox-benefits_zh-TW.html)

### Solar

Solar 開啟 Wi-Fi，以便播放器可以串流和下載。 Deezer、Soulseek、播客和 YouTube，以及 Stem 播放器。 Rockbox也出現了。

[Y1 上的 Solar](solar-y1-software_zh-TW.html) · [Y2 上的 Solar](solar-y2-software_zh-TW.html) · [為什麼是Solar？](solar-benefits_zh-TW.html)

### JJ Launcher

快速、適合輪子的發射器。快速庫掃描、均衡器預設、使用任何螢幕上的硬體按鈕跳過曲目、透過 Wi-Fi 無線檔案上傳、應用程式內藍牙配對以及您可以插入或使用 Web 主題編輯器設計的主題。

[Y1 上的 JJ Launcher](jj-launcher-y1-software.html) · [Y2 上的 JJ Launcher](jj-launcher-y2-software.html) · [為什麼是JJ Launcher？](jj-launcher-benefits.html)

### Inniclassic

基于 JJ Launcher 的 iPod Classic 致敬。經典的選單外觀、點擊輪式音樂測驗、同步歌詞、Last.fm 記錄，以及播客、調頻廣播和影片。 Y1 和 Y2 社区建设。

[Y1 上的 Inniclassic](inniclassic-y1-software_zh-TW.html) · [Y2 上的 Inniclassic](inniclassic-y2-software_zh-TW.html) · [為什麼是Inniclassic？](inniclassic-benefits_zh-TW.html)

### Y2Player

Y2 的音樂第一主畫面。具有持久隊列的離線播放、無縫和交叉淡入淡出過渡、從停止處恢復的有聲讀物以及從 FLAC 到 Opus 的各種常見格式。藍牙音訊工作正常，無需網路連線。

[Y2 上的 Y2Player](y2player-y2-software_zh-TW.html) · [為什麼是Y2Player？](y2player-benefits_zh-TW.html)

### Koensayr

保持庫存 Y1 外觀。按藝術家瀏覽音樂，藍牙顯示曲目名稱並與您的汽車控制項搭配使用。

[Y1 上的 Koensayr](koensayr-y1-software.html) · [為什麼是Koensayr？](koensayr-benefits.html)

這些項目進展很快。 安裝前請閱讀每個項目的發行說明和問題追蹤器。如果出現任何問題，恢復您的模型的原始軟體是安全的恢復方法。
