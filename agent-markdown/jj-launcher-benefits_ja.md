# Innioasis に JJ Launcher を選択する理由

JJ Launcher が高速です。大きなライブラリをすばやくスキャンし、どこからでもハードウェア ボタンを使用してトラックをスキップし、コードを書かずに外観を変更できます。[アップデーターで JJ Launcher を取得](guide_ja.html?model=Y1&software=jj-launcher-y1)[Y1 インストールページ](jj-launcher-y1-software_ja.html)[Y2 インストールページ](jj-launcher-y2-software_ja.html)

## モデルの入手可能性

どの Innioasis モデルで実行されますか?[Y1 · 利用可能](jj-launcher-y1-software_ja.html)[Y2 · 利用可能](jj-launcher-y2-software_ja.html)

Y1 ビルドと Y2 ビルドは別個であるため、ソフトウェア ダウンロードでプレーヤー用に作成されたビルドを入手してください。一方をもう一方と交換しないでください。

## 人々がそれを選ぶ理由

速く、親指で操作できます。
  - ライブラリの高速スキャン — カスタム メディア スキャナーは、Android システム スキャナーを待たずに大規模なライブラリを分類します。
  - どの画面からでもトラックをスキップ — グローバル ハードウェア キー マッピングにより、音楽アプリを使用していない場合でも、前と次が常に機能します。
  - EQプリセットとシャッフル — 完全なシャッフル モードとリピート モードに加えて、内蔵デバイス イコライザー プリセット。
  - コードのないテーマ — ファイルをコピーしてカスタム カラー テーマをドロップするか、Web ベースのテーマ エディタで独自のテーマをデザインして .zip をエクスポートします。
  - ケーブルを使用しないファイルのアップロード — ローカル Wi-Fi Web サーバーをホストし、PC ブラウザから音楽をアップロードします — ケーブルは引き出しの中に収まります。
  - アプリ内Bluetoothペアリング — アプリを終了せずに、ランチャー設定から Bluetooth デバイスをスキャンしてペアリングします。

## コミュニティ

コミュニティの意見

JJ Launcher は、親指 1 本でホイールを操作して、プレーヤーが速く感じられるようにしたい人向けです。他のいくつかのプロジェクトがその上に構築されており、これがコアについて多くのことを物語っています。

コミュニティ クリエイターの doitall は、Y1 の JJ Launcher の短いインストールとトラブルシューティングのビデオを公開しています。テーマ エディターを使用すると、所有者は新しいリリースを待たずに外観を交換したり調整したりできます。
  - [doitall · JJ Launcher のインストールとトラブルシューティング](https://www.youtube.com/shorts/wW7Vg_fb-JU)

## プロジェクトが提供するもの
  - 大規模なライブラリを迅速に分類するカスタム組み込みメディア スキャナー
  - シャッフル、リピートモード、内蔵EQプリセット
  - グローバル ハードウェア キー マッピング - あらゆる画面からのスキップを追跡
  - アルバムアートとトラック情報のリアルタイムメイン画面同期
  - フォルダーをコピーすることで無限のカスタム テーマを作成できます。 Y1 独自のテーマをデザインできるテーマ エディター
  - 再生中のアルバム アートから生成されたダイナミック HD ブラー背景
  - アプリ内 Bluetooth スキャンとペアリング
  - ホイールに最適化された Wi-Fi パスワード用の仮想キーボード
  - ローカル Wi-Fi Web サーバー経由でのワイヤレス PC ファイルのアップロード

## 最初に知っておくべきこと
  - プロジェクトはアルファ段階にあります - 予期しないバグや安定性の問題が発生する可能性があります
  - システム ソフトウェア 2.1.9 でテストされました。インストールする前に自分のソフトウェアのバージョンを確認してください
  - 一部の Bluetooth 接続では、安全な設定のために 1 回限りの ADB 権限付与が必要な場合があります
  - Web エディター用に作成されたテーマには Launcher 0.8 以降が必要です
