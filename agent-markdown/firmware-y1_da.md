# Firmware til Innioasis Y1

Y1 har det bredeste udvalg af brugerdefinerede systemer. Alt nedenfor hostes her, kontrolleres og installeres med et enkelt klik med Updater CE.[Gennemse Y1 Downloads](firmware_da.html?model=Y1)[Få Updater CE](guide_da.html#platform)[Temagalleri](https://themes.innioasis.app/?lang=da)

## Tilgængelige operativsystemer til Innioasis Y1

Y1 kører adskillige softwaresystemer, inklusive builds med audiofil codec-understøttelse, moderne launchers og en fabriksgendannelse. Vælg den, der passer til, hvordan du lytter:

### [Rockbox](rockbox-benefits_da.html)

Guldstandarden inden for open source-lydafspilning. Parametrisk EQ, mellemrumsfri FLAC/MP3-afspilning, temaer og fontpakker, der kan installeres direkte i Updater CE.[Y1 Rockbox Vejledning →](guides/rockbox-y1.html)

### [Better-Y](better-y-benefits_da.html)

En forbedret afledning af den originale firmware med Bluetooth-stabilitetspatches, lydstyrkekurvejusteringer og 100 % Temagalleri-kompatibilitet.[Better-Y Vejledning →](guides/better-y-y1.html)

### [Solar](solar-benefits_da.html)

En moderne open source-musikafspiller bygget med Flutter, der tilbyder jævne 60fps-animationer, albumcover-gitter og moderne typografi.[Solar Y1 Vejledning →](guides/solar-y1.html)

### [Rondo](rondo-benefits_da.html)

En open source Y1 launcher til lokale spor og streaming med hurtig, responsiv navigation.[Rondo Y1 Vejledning →](guides/rondo-y1.html)

### [Koensayr](koensayr-benefits.html)

En brugerdefineret firmware-bygning med sin egen ikonografi, bedre batterikalibrering og understøttelse af lagertemaer.[Koensayr Vejledning →](guides/koensayr-y1.html)

### [Original software (lagergendannelse)](original-software-benefits_da.html)

Rens fabriksfirmwarebilleder for Type A (v2.0.0+) og Type B (v1.x) Y1 afspillere. Fjern mursten eller gendan din enhed til fabrikstilstand.[Gendan Y1 Guide →](guides/restore-original-y1.html)

## Sådan installeres eller opdateres Y1-firmware

Det er nemt at opgradere eller fjerne klodser på din Innioasis Y1 med vores multi-platform softwarepakke:
  - Åbn Innioasis Updater CE: Start opdateringsprogrammet på macOS, Windows eller Linux.
  - Vælg model Y1: Vælg Y1 i rullemenuen Enhedsmodel.
  - Vælg dit operativsystem: Vælg Rockbox, Better-Y, Solar eller original software.
  - Klik på Installer: Updater CE downloader firmwarepakken direkte fra udviklerens udgivelse. Når du bliver bedt om det, skal du tilslutte din slukkede Y1 via USB for at begynde at blinke.
