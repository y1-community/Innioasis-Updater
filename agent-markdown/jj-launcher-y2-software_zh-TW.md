# 安裝前檢查 JJ Launcher 中的 Y2。

Y2 有一個 JJ Launcher 版本，但其中包含的內容可能會在版本之間發生變化。在開始之前檢查當前清單。[開啟完整的 JJ Launcher 指南](guides/jj-launcher-y2.html)[在 Updater CE 中取得此內容](guide_zh-TW.html?model=Y2&software=jj-launcher-y2)[為什麼是JJ Launcher？](jj-launcher-benefits_zh-TW.html)

## 模型正確性檢查
  - 在您的電腦上開啟 Innioasis Updater CE（如果您需要該應用程序， [取得 Updater CE](guide_zh-TW.html#platform)）。套裝 裝置型號 到 Y2.
  - 確認 JJ Launcher 在目前版本資料中顯示 Y2。
  - 閱讀項目發行說明並選擇列出的 Y2 版本。
  - 點選 安裝 / 還原.
  - 僅在出現提示時關閉電源並連接 Y2。
不要替代： Y1 包不是 Y2 包。如果模型和版本不一致，請停止。

## 常見問題Y2 支援有保證嗎？

列出了 Y2 版本，但支援的內容可能會發生變化。安裝前檢查最新清單和項目說明。如何恢復Y2？

在 Updater CE 中選擇 Y2 和原始軟體，然後依照 [Y2恢復步驟](original-software-y2_zh-TW.html).如果 JJ Launcher 未列出怎麼辦？

不要強制使用 Y1 包。檢查項目版本和 [故障排除指南](troubleshooting_zh-TW.html).
