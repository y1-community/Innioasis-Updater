# Rondo pour Innioasis Y1

Un micrologiciel minimaliste de lecteur de musique à molette cliquable conçu spécifiquement pour le matériel capacitif Innioasis Y1, entièrement axé sur une lecture réactive et une navigation claire.[Guide étape par étape Y1](guides/rondo-y1.html)[Pourquoi Rondo ?](rondo-benefits_fr.html)[Télécharger les versions](firmware_fr.html?model=Y1&software=rondo-y1)

## Installez Rondo sur votre Y1 avec votre ordinateur

Choisissez le guide correspondant à l'ordinateur que vous utilisez. Chaque version comprend la configuration de la plate-forme, Updater CE étapes et le chemin de retour au stock.[Guide Windows](install/rondo-y1-windows.html)[Guide macOS](install/rondo-y1-mac.html)[Guide Linux](install/rondo-y1-linux.html)

[Tous les Innioasis guides Y1](install/y1.html) · [Tous les guides Rondo](install/rondo.html)

## Étapes d'installation
  - Lancement Innioasis Programme de mise à jour CE sur votre ordinateur Windows, Mac ou Linux.
  - Sélectionnez Y1 dans la liste déroulante Modèle d'appareil.
  - Sélectionnez Rondo dans la liste déroulante Logiciel.
  - Cliquez Installer / Restaurer et attendez que l'outil télécharge et prépare les fichiers.
  - Lorsque Updater CE vous y invite, éteignez votre Y1 et connectez le câble USB.
  - Terminer la configuration post-installation

Suivez les étapes dans [ce guide](post_install_fr.html?software=rondo-y1&model=Y1) pour terminer la configuration sur votre Y1.[Voir le guide](post_install_fr.html?software=rondo-y1&model=Y1)
