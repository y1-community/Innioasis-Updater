## Android 4.4 Y2 install steps
  - Ανοίξτε το Innioasis Updater CE στον υπολογιστή σας (αν χρειάζεστε την εφαρμογή, [Αποκτήστε το Updater CE](guide_el.html#platform)). Σειρά Μοντέλο συσκευής να Y2.
  - Επιλέγω Android 4.4 (Dev) σε Λογισμικό.
  - Choose the release listed for Y2.
  - Κλικ Εγκατάσταση / Επαναφορά.
  - Power off and connect the Y2 only when Updater CE asks.
