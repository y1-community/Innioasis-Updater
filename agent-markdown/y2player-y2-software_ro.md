# Instalați Y2Player pe Y2.

Y2Player este creat pentru Y2. Alegeți mai întâi modelul dvs., astfel încât să nu folosiți accidental un pachet Y1.[Deschideți ghidul complet Y2Player.](guides/y2player-y2.html)[Obțineți asta în Updater CE](guide_ro.html?model=Y2&software=y2player-y2)[De ce Y2Player?](y2player-benefits_ro.html)

Ghid de instalare pentru computerul dvs

## Instalați Y2Player pe Y2 cu computerul dvs

Alegeți ghidul pentru computerul pe care îl utilizați. Fiecare versiune are configurarea platformei, Updater CE pași și calea de întoarcere la stoc.[Ghidul Windows](install/y2player-y2-windows.html)[ghid macOS](install/y2player-y2-mac.html)[Ghid Linux](install/y2player-y2-linux.html)

[Toate ghidurile Innioasis Y2](install/y2.html) · [Toate ghidurile Y2Player.](install/y2player.html)

## Y2Player pași de instalare
  - Deschideți Innioasis Updater CE pe computer (dacă aveți nevoie de aplicație, [Obține Updater CE](guide_ro.html#platform)). Setați Model dispozitiv la Y2.
  - Alege Y2Player în Software.
  - Alegeți o versiune listată pentru Y2.
  - Faceți clic Instalează / Restaurează.
  - Opriți și conectați Y2 la promptul live.

Unele Y2 pachete cu instalare completă folosesc `rom_y2.zip`. Lăsați Updater să aleagă pachetul atunci când este posibil.

## Întrebări frecventePot reveni la software-ul original?

Da. Selectați Y2 și Software-ul original în Updater CE, apoi urmați [Ghid de restaurare Y2](original-software-y2_ro.html).Pot folosi asta pe un Y1?

Nu. Această pagină este pentru intrarea Y2Player Y2. Păstrați pachetele Y1 și Y2 separate.Ce se întâmplă dacă Y2 nu este detectat?

Verificați configurarea platformei, cablul, starea de oprire, selecția modelului și sincronizarea. Utilizați [depanare](troubleshooting_ro.html) înainte de a încerca recuperarea manuală.
