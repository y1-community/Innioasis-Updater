# התקן את Inniclassic ב-Y1.

Inniclassic הוא פרויקט תוכנה קהילתי עבור Y1, ואותו פרויקט מפרסם גם Y2 build, כך שהוא זמין בשני השחקנים. דף זה נותן לך את התשובה הידידותית לחיפוש Y1 וקישורים לשלבי החיבור המפורטים.[פתח את המדריך המלא Inniclassic](guides/inniclassic-y1.html)[קבל את זה ב-Updater CE](guide_he.html?model=Y1&software=inniclassic-y1)[למה Inniclassic?](inniclassic-benefits_he.html)

מדריך התקנת המחשב שלך

## התקן את Inniclassic ב-Y1 שלך עם המחשב שלך

בחר את המדריך עבור המחשב שבו אתה משתמש. לכל גרסה יש את הגדרת הפלטפורמה, Updater CE שלבים והדרך חזרה למלאי.[מדריך Windows](install/inniclassic-y1-windows.html)[מדריך macOS](install/inniclassic-y1-mac.html)[מדריך לינוקס](install/inniclassic-y1-linux.html)

[כל Innioasis מדריכי Y1](install/y1.html) · [כל המדריכים Inniclassic](install/inniclassic.html)

## Inniclassic Y1 שלבי התקנה
  - פתח את Innioasis Updater CE במחשב שלך (אם אתה צריך את האפליקציה, [הורדת Updater CE](guide_he.html#platform)). סט דגם המכשיר ל Y1.
  - בחר Inniclassic ב תוכנה.
  - בחר את המהדורה הרשומה עבור Y1.
  - לחץ התקנה / שחזור.
  - כבה וחבר את ה-Y1 רק כאשר Updater CE מבקש.

## שאלות נפוצותהאם אוכל לשחזר את תוכנת המניות Y1?

כֵּן. בחר Y1 ותוכנה מקורית ב-Updater CE. ה [Y1 מדריך תוכנה למניות](original-software-y1_he.html) מכסה את נתיב החזרה.מה אם ההתקנה נכשלת?

שים לב אם העדכון נכשל לפני או אחרי זיהוי ה-Y1, ולאחר מכן בדוק את הכבל, הגדרת הפלטפורמה, הדגם ותזמון החיבור ב- [פתרון בעיות](troubleshooting_he.html).האם אני יכול להשתמש ב-Inniclassic ב-Y2?

כֵּן. Inniclassic זמין בשני הדגמים - אותו פרויקט מתוחזק מפרסם חבילה Y2 מאותן מהדורות. בחר Y2 ב-Updater CE והתקן את ה-Y2 build; לעולם אל תבזיק חבילה Y1 ל-Y2. ה [דף ההתקנה של Y2](inniclassic-y2-software_he.html) מכסה אותו.

## השתמשו במסלול המודרך

פעם ראשונה שאתה משתמש ב-Updater? עיין בהגדרה המודרכת ל [הורדת Updater CE](guide_he.html#platform) ב-Windows, macOS או Linux לפני חיבור הנגן.
