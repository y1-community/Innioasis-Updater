# Hvorfor installere Rondo på Innioasis Y1?

Rondo er en åpen kildekode, spesialbygd klikkhjul-musikkspillerfastvare designet spesielt for Innioasis Y1-maskinvaren. Den tilbyr ren bibliotekslesing, ren typografi og rask lyddekoding.[Installer Rondo på Y1](guides/rondo-y1.html)[Bla gjennom utgivelser](firmware_no.html?model=Y1&software=rondo-y1)

## Høydepunkter fra Rondo

### Rask klikkhjulrespons

Nøye avstemt akselerasjonskurve tilpasset det Y1 fysiske kapasitive berøringshjulet for jevn rulling gjennom store musikkbiblioteker.

### Fokusert lydspiller

Ingen bloatware, bakgrunnsanalyser eller unødvendige demoner: 100 % av maskinvareressursene er dedikert til skarp lydutgang.

### Reversibel når som helst

Installer enkelt ved å bruke Innioasis Updater CE og gå tilbake til original programvare eller Rockbox når du vil.
