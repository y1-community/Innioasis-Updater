## Koensayr Y1 install steps
  - פתח את Innioasis Updater CE במחשב שלך (אם אתה צריך את האפליקציה, [הורדת Updater CE](guide_he.html#platform)). סט דגם המכשיר ל Y1.
  - בחר Koensayr ב תוכנה.
  - Choose the listed Y1 release.
  - לחץ התקנה / שחזור.
  - כבה וחבר את ה-Y1 רק כאשר Updater CE מבקש.

## שאלות נפוצותCan I restore the original Y1 software?

Yes. Select Y1 and Original Software in Updater CE. See the [Y1 stock-software page](original-software-y1_he.html) for the complete restore route.What should I check when it fails?

Check the model, release, cable, platform setup, and whether the player was connected before the prompt. Then use [פתרון בעיות](troubleshooting_he.html).Is there a Koensayr Y2 package?

The current build is for Y1. Don't use it on a Y2 unless the project publishes a separate release for it.
