## Instálalo o restáuralo con Updater

Primero configure la computadora y luego deje que Updater prepare el paquete correspondiente al modelo.
  - Abra Innioasis Updater CE en su computadora (si necesita la aplicación, [Obtener Updater CE](guide_es.html#platform)). conjunto Modelo del dispositivo a Y2.
  - elegir Software original y una versión Y2.
  - Haga clic Instalar / Restaurar.
  - Apague y conecte el Y2 solo cuando se lo solicite el mensaje en vivo.

Los paquetes de instalación completa manual pueden utilizar `rom_y2.zip`. No tratar un Y1 `rom.zip` como sustituto.

## Preguntas frecuentes¿Puedo regresar desde Rockbox u otro software personalizado?

Utilice el mismo flujo de restauración Y2: elija Y2, seleccione Software original y siga las indicaciones de conexión. No mezcle archivos de modelo.¿Por qué el paquete Y2 se ve diferente?

Las versiones Y2 pueden usar un nombre de paquete y una entrada de versión diferentes. Seleccione Y2 en el Actualizador en lugar de adivinar a partir de un nombre de archivo ZIP manual.¿Qué pasa si no se detecta al jugador?

Verifique el cable de datos, los permisos o controladores de la computadora y la sincronización. Conecte el Y2 apagado solo después de que el Actualizador diga que está listo.
