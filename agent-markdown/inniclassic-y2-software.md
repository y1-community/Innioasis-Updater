## Inniclassic Y2 install steps
  - Open Innioasis Updater CE on your computer (if you need the app, [Get Updater CE](guide.html#platform)). Set Device Model to Y2.
  - Choose Inniclassic in Software.
  - Choose the release listed for Y2.
  - Click Install / Restore.
  - Power off and connect the Y2 only when Updater CE asks.

## FAQsCan I restore the stock Y2 software?

Yes. Select Y2 and Original Software in Updater CE. The [Y2 stock-software guide](original-software-y2.html) covers the return path.Can I use Inniclassic on Y1?

Yes. The same project publishes Y1 packages as well — rom.zip for Type A and rom_type_b.zip for Type B. Select Y1 in Updater CE and install the Y1 build; the [Y1 install page](inniclassic-y1-software.html) covers it.What if installation fails?

Note whether Updater failed before or after detecting the Y2, then check the cable, platform setup, model, and connection timing in [troubleshooting](troubleshooting.html).
