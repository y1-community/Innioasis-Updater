## JJ Launcher Y1 install steps
  - Buka Innioasis Updater CE di komputer Anda (jika Anda memerlukan aplikasinya, [Dapatkan Updater CE](guide_id.html#platform)). Tetapkan Model perangkat untuk Y1.
  - Pilih JJ Launcher di Perangkat lunak.
  - Choose the release shown for Y1.
  - Klik Pasang / Pulihkan.
  - Matikan dan sambungkan Y1 hanya ketika Updater CE diminta.

## Pertanyaan umumCan I install the Y2 entry on a Y1?

No. Keep the model and package matched. If the Y1 entry is missing, do not force a Y2 file.Can I go back to the original software?

Yes. Choose Y1 and Original Software in Updater CE. See the [Y1 restore page](original-software-y1_id.html).Where are all the JJ Launcher releases?
