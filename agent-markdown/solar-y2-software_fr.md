## Vérifications Y2 correctes du modèle
  - Ouvrez Innioasis Updater CE sur votre ordinateur (si vous avez besoin de l'application, [Obtenir Updater CE](guide_fr.html#platform)). Ensemble Modèle d'appareil à Y2.
  - Confirmez que Solar est répertorié pour Y2 dans les données de la version actuelle.
  - Lisez la note de version du projet et vérifiez sa prise en charge Y2.
  - Choisissez la version répertoriée et cliquez sur Installer / Restaurer.
  - Éteignez et connectez le Y2 uniquement lorsque Updater CE le demande.
Ne remplacez pas un package Y1. Un projet disponible pour Y1 ne rend pas son package Y1 sûr pour Y2.
