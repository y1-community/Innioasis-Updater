# Reborn (Y2Linux) สำหรับ Innioasis Y2

การกระจาย Debian Linux ที่รวดเร็วและสร้างขึ้นตามจุดประสงค์พร้อมอินเทอร์เฟซผู้ใช้แบบคลิกวีลดั้งเดิมสำหรับ Innioasis Y2 พร้อมความเสถียรของหูฟัง Bluetooth และการพัฒนาชุมชนที่กระตือรือร้น[คำแนะนำทีละขั้นตอน Y2](guides/reborn-y2linux-y2.html)[ทำไมต้อง Y2Reborn?](reborn-y2linux-benefits_th.html)[ดาวน์โหลดเผยแพร่](firmware_th.html?model=Y2&software=reborn-y2linux-y2)

## ติดตั้ง Reborn (Y2Linux) บน Y2 ด้วยคอมพิวเตอร์ของคุณ

เลือกคำแนะนำสำหรับคอมพิวเตอร์ที่คุณใช้ ทุกรุ่นมีการตั้งค่าแพลตฟอร์ม ขั้นตอน Updater CE และวิธีคืนสินค้าในสต็อก[คู่มือวินโดวส์](install/reborn-y2linux-y2-windows.html)[คู่มือ macOS](install/reborn-y2linux-y2-mac.html)[คู่มือลินุกซ์](install/reborn-y2linux-y2-linux.html)

[คำแนะนำ Innioasis Y2 ทั้งหมด](install/y2.html) · [คำแนะนำ Reborn (Y2Linux) ทั้งหมด](install/reborn.html)

## ขั้นตอนการติดตั้ง
  - เปิด Updater CE ใช้งานได้กับ Windows, macOS และ Linux
  - เลือก Y2 เป็นรุ่นอุปกรณ์
  - เลือก Reborn (Y2Linux) เป็นซอฟต์แวร์
  - คลิกติดตั้ง / กู้คืน รอในขณะที่ Updater CE เตรียมไฟล์
  - เชื่อมต่อ USB เมื่อถูกถาม ปิด Y2 ก่อน
  - ตั้งค่า Wi-Fi, บลูทูธ และวิทยุ FM

คัดลอก `system.img` ให้กับผู้เล่นหนึ่งครั้ง Reborn ทำส่วนที่เหลือ[ตั้งค่าให้เสร็จสิ้น →](y2reborn_wifibt_th.html)
