# Innioasis Y2에서 원래 소프트웨어를 복원하십시오.

이 페이지는 Y2 재고 소프트웨어, 공장 복원 및 커뮤니티 프로젝트 복귀에 대한 것입니다. Y2 모델과 패키지를 함께 유지하세요.[전체 원본 소프트웨어 가이드 열기](guides/restore-original-y2.html)[이것을 Updater CE에서 얻으세요](guide_ko.html?model=Y2&software=original-y2)[Y2 릴리스 찾아보기](firmware_ko.html#y2)

## 컴퓨터를 사용하여 Y2의 원본 소프트웨어를 복원하세요.

사용 중인 컴퓨터에 대한 가이드를 선택하세요. 모든 버전에는 플랫폼 설정, Updater CE 단계 및 재고로 돌아가는 방법이 있습니다.[윈도우 가이드](install/original-y2-windows.html)[macOS 가이드](install/original-y2-mac.html)[리눅스 가이드](install/original-y2-linux.html)

[모든 Innioasis Y2 가이드](install/y2.html) · [모든 원본 소프트웨어 가이드](install/original-software.html)

## 업데이터로 설치 또는 복원

먼저 컴퓨터를 설정한 다음 업데이터가 모델과 일치하는 패키지를 준비하도록 하세요.
  - 컴퓨터에서 Innioasis Updater CE를 엽니다(앱이 필요한 경우, [Updater CE 받기](guide_ko.html#platform)). 세트 기기 모델 에 Y2.
  - 선택 원본 소프트웨어 그리고 Y2 릴리스.
  - 클릭 설치 / 복원.
  - 라이브 프롬프트가 나타날 때만 전원을 끄고 Y2을 연결하십시오.

수동 전체 설치 패키지는 다음을 사용할 수 있습니다. `rom_y2.zip`. Y1을 처리하지 않음 `rom.zip` 대체품으로.

## 자주 묻는 질문Rockbox 또는 다른 사용자 정의 소프트웨어에서 돌아올 수 있습니까?

동일한 Y2 복원 흐름을 사용합니다. Y2을 선택하고 원본 소프트웨어를 선택한 후 연결 프롬프트를 따릅니다. 모델 파일을 혼합하지 마십시오.Y2 패키지가 다르게 보이는 이유는 무엇입니까?

Y2 릴리스는 다른 패키지 이름과 릴리스 항목을 사용할 수 있습니다. 수동으로 ZIP 파일 이름을 추측하는 대신 Updater에서 Y2을 선택하세요.플레이어가 감지되지 않으면 어떻게 되나요?

데이터 케이블, 컴퓨터 권한이나 드라이버, 타이밍을 확인하세요. 업데이터가 준비되었다고 말한 후에만 전원이 꺼진 Y2을 연결하십시오.
