## Solar Y1 installationssteg
  - Öppna Innioasis Updater CE på din dator (om du behöver appen, [Hämta Updater CE](guide_sv.html#platform)). Ställ in Enhetsmodell till Y1.
  - Välj Solar i Programvara.
  - Läs projektets release not och välj en Y1 release.
  - Klicka Installera / Återställ.
  - Stäng av och anslut Y1 endast när uppmaningen visas.

Solar funktioner och tillgänglighet kan ändras. Funktioner kan ändras mellan utgåvor, så kontrollera projektets utgivningssida och aktuell lista för din modell.
