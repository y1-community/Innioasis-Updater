# Installer Inniclassic på Y2.

Inniclassic er tilgjengelig for Innioasis Y2, og det samme prosjektet bygger også Y1-pakkene. Denne siden gir deg Y2-oversikten og lenker til hele opplæringen.[Åpne hele Inniclassic-guiden](guides/inniclassic-y2.html)[Få dette i Updater CE](guide_no.html?model=Y2&software=inniclassic-y2)[Hvorfor Inniclassic?](inniclassic-benefits_no.html)

## Installer Inniclassic på Y2 med datamaskinen

Velg veiledningen for datamaskinen du bruker. Hver versjon har plattformoppsettet, Updater CE trinn og veien tilbake til lageret.[Windows guide](install/inniclassic-y2-windows.html)[macOS-veiledning](install/inniclassic-y2-mac.html)[Linux guide](install/inniclassic-y2-linux.html)

## Inniclassic Y2 installasjonstrinn
  - Åpne Innioasis Updater CE på datamaskinen din (hvis du trenger appen, [Få Updater CE](guide_no.html#platform)). Sett Enhetsmodell til Y2.
  - Velg Inniclassic inn Programvare.
  - Velg utgivelsen som er oppført for Y2.
  - Klikk Installer / Gjenopprett.
  - Slå av og koble til Y2 kun når Updater CE spør.

## Vanlige spørsmålKan jeg gjenopprette aksjeprogramvaren Y2?

Ja. Velg Y2 og original programvare i Updater CE. Den [Y2 lagerprogramvareveiledning](original-software-y2_no.html) dekker returveien.Kan jeg bruke Inniclassic på Y1?

Ja. Det samme prosjektet publiserer Y1 pakker også - rom.zip for Type A og rom_type_b.zip for Type B. Velg Y1 i Updater CE og installer Y1 build; den [Y1 installasjonsside](inniclassic-y1-software_no.html) dekker det.Hva hvis installasjonen mislykkes?

Legg merke til om oppdateringen mislyktes før eller etter oppdagelsen av Y2, og sjekk deretter kabelen, plattformoppsettet, modellen og tilkoblingstidspunktet i [feilsøking](troubleshooting_no.html).
