## Koensayr Y1 install steps
  - Open Innioasis Updater CE op uw computer (als u de app nodig heeft, [Updater CE downloaden](guide_nl.html#platform)). Instellen Apparaatmodel aan Y1.
  - Kies Koensayr binnen Software.
  - Choose the listed Y1 release.
  - Klik Installeren / Herstellen.
  - Schakel de Y1 alleen uit en sluit deze alleen aan als Updater CE daarom vraagt.

## Veelgestelde vragenCan I restore the original Y1 software?

Yes. Select Y1 and Original Software in Updater CE. See the [Y1 stock-software page](original-software-y1_nl.html) for the complete restore route.What should I check when it fails?

Check the model, release, cable, platform setup, and whether the player was connected before the prompt. Then use [probleemoplossing](troubleshooting_nl.html).Is there a Koensayr Y2 package?

The current build is for Y1. Don't use it on a Y2 unless the project publishes a separate release for it.
