# Innioasis Y1 및 Y2에 Inniclassic이 필요한 이유

Inniclassic은 iPod Classic을 다시 가져옵니다. 메뉴, 패닝 앨범 표지, 클릭 휠 느낌, 심지어 음악 퀴즈까지. Y1 및 Y2에 모두 최신 형식이 포함되어 있습니다.[업데이터에서 Inniclassic 가져오기](guide_ko.html?model=Y1&software=inniclassic-y1)[Y1 설치 페이지](inniclassic-y1-software_ko.html)[Y2 설치 페이지](inniclassic-y2-software_ko.html)

## 모델 가용성

어떤 Innioasis 모델이 이를 실행합니까?[1학년 · 가능](inniclassic-y1-software_ko.html)[2학년 · 가능](inniclassic-y2-software_ko.html)

하나의 유지 관리 프로젝트는 각 모델에 대해 별도의 패키지를 사용하여 두 모델에 대한 빌드를 게시합니다. 소프트웨어 다운로드에서 플레이어용으로 만들어진 패키지를 가져오고 서로 교체하지 마십시오.

## 사람들이 그것을 선택하는 이유

클래식을 다시 손에 넣으세요.
  - 1:1 iPod 클래식 보기 — 일반 텍스트 메뉴, 시스템에 맞는 굵은 글꼴, 화면 이름 상태 표시줄 — 밝은 테마와 어두운 테마 변형이 포함되어 있습니다.
  - 표지 탐색 — 실제처럼 화면 상단까지 흘러내리는 천천히 패닝하는 앨범 표지가 있는 2개 창 메뉴.
  - 실제 음악 퀴즈 — 자신만의 라이브러리를 사용하여 처음부터 다시 만들기: 라운드 및 승리 화면이 포함된 8개 질문으로 구성된 5라운드.
  - 동기화된 가사 — .lrc 파일 또는 내장된 태그의 시간 동기화 스크롤 가사, Now Playing에서 바로 전환됩니다.
  - 당신이 소유한 모든 것을 재생합니다 — MP3, FLAC, WAV, OGG Vorbis, Opus, ALAC/M4A 및 AAC — 복고풍 얼굴 아래에 설정된 최신 코덱입니다.
  - 라디오, 팟캐스트, 비디오, 오디오북 — 하드웨어 튜너를 통한 FM 라디오, 팟캐스트 구독, 전체 화면 비디오 및 북마크된 오디오북.

## 커뮤니티

커뮤니티에서 말하는 내용

Inniclassic은 JJ Launcher의 미디어 엔진을 기반으로 구축되었으므로 성숙한 기반에서 시작됩니다. 각 릴리스에는 실제와 같은 느낌을 주는 개선 사항이 추가됩니다.

JJ Launcher의 미디어 엔진을 기반으로 직접 구축되었기 때문에 Inniclassic은 클래식 세부 사항을 레이어링하면서 성숙한 기반을 상속받습니다. 프로젝트 릴리스에는 하나의 목표, 즉 FLAC만을 사용하여 실제처럼 느껴지게 만드는 것을 목표로 하는 개선 사항의 긴 목록이 문서화되어 있습니다.
  - [r/innioasis · Inniclassic 스레드](https://www.reddit.com/r/innioasis/)

## 프로젝트가 제공하는 것
  - 1:1 룩을 지향하는 iPod Classic 테마(밝음 + 어두움) 번들 제공
  - Ken Burns 앨범 표지가 포함된 두 창으로 구성된 기본 메뉴 및 음악 메뉴
  - 각진 반사 표지와 긴 제목을 위한 선택 윤곽으로 새롭게 디자인된 Now Playing
  - 중앙 클릭 사이클 진행 → 탐색 → 임의 재생 및 반복 → 실제 클래식과 같은 평가
  - On-The-Go 재생 목록 및 길게 누르기 지금 재생 보류 메뉴
  - 모든 알파벳순 목록에서 빠른 스크롤 문자 점프
  - 심장 표시가 있는 즐겨찾기
  - .lrc 파일 또는 ID3/FLAC/ALAC 태그에서 동기화된 가사
  - 와이드 포맷 지원: MP3, FLAC, WAV, OGG Vorbis, Opus, ALAC/M4A, AAC
  - Last.fm 스크로블 — 자동 로컬 스크로블 로그, 선택적 계정 동기화
  - 팟캐스트, 실제 하드웨어 튜너를 통한 FM 라디오, libVLC를 통한 비디오 및 재개 가능한 오디오북
  - Wi-Fi를 통한 무선 PC 업로드

## 먼저 알아야 할 사항
  - 두 모델 모두에서 사용 가능 — Y1 소요 rom.zip (Type A) 또는 rom_type_b.zip (Type B), 그리고 Y2은 rom_y2.zip; 세 개 모두 같은 프로젝트에서 나왔습니다.
  - 방법 1은 Inniclassic이 포함된 Y1 소프트웨어 3.1.2를 제공합니다. 방법 2는 기존 JJ Launcher 설정 위에 APK를 설치합니다(먼저 제거).
  - 셔플이 꺼지고 대기열에 FLAC가 없는 15개 트랙 이하의 재생 목록에 대해 끊김 없는 재생이 활성화됩니다.
  - 원활한 재생을 위해 비디오 파일을 적정 수준(640×480, 30fps, ~2Mbps 이하)으로 유지하세요.
  - 여전히 커뮤니티 프로젝트 — 오작동하는 경우 원본 소프트웨어를 복원합니다.
