# Innioasis 업데이터 CE 시작하기

모든 Innioasis 및 Timmkoo 오디오 플레이어에서 작동합니다. 컴퓨터에 Innioasis Updater CE를 설치하고, 모델과 원하는 소프트웨어를 선택한 다음 프롬프트를 따르십시오.

## 

[Updater CE 받기](guide_ko.html#download-updater)[전체 서면 튜토리얼](guide_ko.html)

## Innioasis Updater CE 획득

Innioasis 업데이터 CE 플레이어에 공식 업데이트와 커뮤니티 소프트웨어를 설치하는 앱입니다. 음악과 설정을 유지하며 Windows, macOS 및 Linux에서 실행됩니다.

### Windows

설치 프로그램을 다운로드하고 실행한 후 완료되면 PC를 다시 시작하세요.[드라이버 받기](https://github.com/y1-community/supplemental-apks/releases/latest/download/DriverInstall.exe)[Updater CE 다운로드](https://github.com/y1-community/Innioasis-Updater/releases/latest/download/installer.exe)

Windows에서 앱 실행이 중지되거나 실행되지 않는 경우 설정을 열고 개인정보 및 보안 → Windows 보안 → 앱 및 브라우저 제어를 클릭한 후 스마트 앱 제어를 끄세요. Smart App Control은 현재 Epic Overlay Service(Fortnite에서 사용)와 같은 널리 사용되는 애플리케이션에 영향을 미칩니다. Updater CE는 안전하고 사용이 검증되었습니다. [Windows에서 앱이 실행되지 않습니까? 돕다](#smart-app-control)

설치 후 PC를 다시 시작하세요. 운전자 지원은 [Windows 설정 참고 사항](drivers_ko.html#windows).

### macOS[Updater CE 다운로드](https://github.com/y1-community/Innioasis-Updater/releases/latest/download/Innioasis.Updater.for.Mac.dmg)

Mac에서 앱을 처음 실행할 때 차단되면 시스템 설정을 열고 개인정보 보호 및 보안을 클릭한 다음 보안까지 아래로 스크롤하여 [어쨌든 열기](https://support.apple.com/en-gb/102445#openanyway)을(를) 클릭하세요. Finder에서 앱을 Control-클릭(또는 마우스 우클릭)한 후 '열기'를 선택할 수도 있습니다.

macOS Monterey 이상이 설치된 Intel 및 Apple Silicon Mac에서 작동합니다.

### Linux

Intel 및 AMD 시스템용 AppImage를 다운로드하여 실행 가능하게 만들고 실행합니다.[Intel/AMD용 AppImage 다운로드](https://github.com/y1-community/innioasis-updater/releases/latest/download/UpdaterCE.AppImage)

[Linux 설정 참고 사항](drivers_ko.html#linux)또 다른 플랫폼?

플레이어, 데이터를 전달하는 USB 데이터 케이블(충전 전용 케이블은 설치할 수 없음), 그리고 몇 분이 필요합니다. Updater CE가 완료되었다고 말할 때까지 케이블을 연결된 상태로 유지하세요.

## 모델과 소프트웨어를 선택하세요
  - 장치 모델: 플레이어에 인쇄된 모델을 선택하고, Y1 또는 Y2. 한 모델용으로 제작된 소프트웨어를 다른 모델에 설치할 수 없습니다.
  - 소프트웨어 및 릴리스: 해당 모델에 대해 나열된 경우 원본 소프트웨어, Rockbox, Solar, JJ Launcher, Inniclassic, Y2Player 또는 Koensayr를 선택한 다음 릴리스를 선택합니다. 안정적인 것이 안전한 선택입니다.
  - 설치하다: 딸깍 하는 소리 설치 / 복원, 플레이어의 전원을 완전히 끄고, Updater CE가 요청할 때만 USB 케이블을 연결하세요.
  - 마치다: 성공 메시지가 나타날 때까지 플레이어와 케이블을 그대로 둔 다음 플레이어를 분리하고 시작하십시오.

Y1 2.0.0 이전에 원본 소프트웨어와 함께 배송된 플레이어에는 장치 Type B. 다른 모든 사람은 기본값 Type A을 유지합니다.전원이 꺼진 플레이어 연결을 위한 업데이터 연결 지침해당 모델에 대한 라이브 업데이터 CE 프롬프트를 따르십시오.

## 원래 소프트웨어로 돌아가기

맞춤형 소프트웨어는 되돌릴 수 있습니다. Updater CE에서 모델을 선택하고 원본 소프트웨어, 안정적인 릴리스를 선택한 다음 실행하십시오. 설치 / 복원 같은 방식으로. 손으로 지울 일은 없습니다.[Y1 복원 가이드](guides/restore-original-y1.html)[Y2 복원 가이드](guides/restore-original-y2.html)

USB 프롬프트 이전에 플래시가 멈추면 케이블, 플랫폼 설정 및 모델을 먼저 확인하십시오. 보다 [문제 해결](troubleshooting_ko.html) 수정을 위해 [Y1 및 Y2 복구 가이드](guides/recovery.html) 전원 및 휠 결함에 대해 [SP Flash Tool](sp-flash-tool_ko.html) 고급 복구를 위해.

## Windows에서 앱이 실행되지 않습니까? 스마트 앱 제어 해결 방법

Windows Defender SmartScreen 또는 Smart App Control은 서명 평판이 전파되기 전에 새로 다운로드한 커뮤니티 응용 프로그램을 차단할 수 있습니다. Smart App Control은 현재 Epic Overlay Service(Fortnite에서 사용)와 같은 인기 애플리케이션에 영향을 미치고 있습니다. Updater CE는 안전하고 사용이 검증되었습니다. Smart App Control을 끄면 Updater CE가 정상적으로 열리고 실행될 수 있습니다.
  - 열기 설정 Windows PC에서 (누르세요. Win + I).
  - 클릭 개인정보 보호 및 보안 왼쪽 사이드바에서 Windows Security.
  - 클릭 앱 및 브라우저 제어.
  - 아래에 스마트 앱 제어, 클릭 스마트 앱 제어 설정.
  - 토글을 다음으로 설정하세요. 끄다 Updater CE가 실행되도록 허용합니다.

Edge를 통해 다운로드하셨나요? Edge가 다운로드 자체를 차단하는 경우 추가 옵션 버튼(…) → 유지하다 → 더 보기 → 어쨌든 유지.

나중에 스마트 앱 제어를 다시 활성화하려면: 스마트 앱 제어를 다시 켜려면 아래의 Windows 레지스트리를 통해 다시 활성화할 수 있습니다. `HKEY_LOCAL_MACHINE\SYSTEM\CurrentControlSet\Control\CI\Policy` 설정으로 `VerifiedAndReputablePolicyState` 에 `1` (켜짐) 또는 `2` (평가 모드) 및 다시 시작.
