# Rockbox-Y1 contre Rockbox-Y2

Rockbox-Y1 et Rockbox-Y2 sont des versions de micrologiciels distinctes créées pour différents lecteurs. Faites toujours correspondre la construction au modèle imprimé sur votre lecteur.[Rockbox-Y1 installer](rockbox-y1/install.html)[Rockbox-Y2 installer](rockbox-y2/install.html)[Les deux ROM téléchargements](rockbox-rom-download_fr.html)

## Pourquoi la sélection de votre modèle est importante en premier

Bien que les deux versions exécutent Rockbox, Innioasis Y1 et Y2 ont des dispositions de matériel et de partition différentes. Ne faites jamais clignoter un Y1 ROM sur un Y2 ou un Y2 ROM sur un Y1.

Innioasis Updater CE évite les incohérences en filtrant les logiciels disponibles dès que vous le souhaitez Y1 ou Y2 dans Modèle d'appareil. Updater CE télécharge toujours le package sélectionné directement à partir de la version du développeur du micrologiciel de la communauté (les développeurs sont seuls responsables de la liste de leurs versions dans Updater CE).

## De quel guide avez-vous besoin ?
  - Innioasis Y1 — Allez au [Rockbox-Y1 centre](rockbox-y1/). Choisissez Type A (pour les joueurs livrés avec la version 2.0.0+) ou Type B (pour les unités plus anciennes), puis choisissez une version 240p ou 360p.
  - Innioasis Y2 — Allez au [Rockbox-Y2 centre](rockbox-y2/). Sélectionnez Y2 dans Updater CE et choisissez la dernière version de Y2.

## Ce que les deux ports partagent

Les deux apportent la base de données musicale basée sur des balises de Rockbox, une lecture sans interruption, un égaliseur, des thèmes personnalisés et une écoute 100 % hors ligne de votre lecteur.
