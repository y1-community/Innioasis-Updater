# Innioasis Updater solução de problemas | Innioasis e Timmkoo problemas de instalação - Innioasis Updater

Solução de problemas

# Encontre o ponto onde a instalação foi interrompida.

Onde isso parou? Isso lhe diz o que consertar.[Voltar ao guia normal](guide_pt-BR.html)[Verifique o firmware](firmware_pt-BR.html)

## Parou antes do prompt USB

Este é um problema de computador, não de cabo. Verifique seu modelo. Descompacte o arquivo novamente. Então tente Instalar / Restaurar. Se a lista de lançamentos estiver vazia, abra o [diretório de firmware](firmware_pt-BR.html).

## Não é possível conectar ao player
  - Desligue totalmente o Y1 ou Y2 correto.
  - Desconecte o cabo, feche outras ferramentas flash ou Android e reinicie a instalação.
  - Conecte-se somente quando o Updater disser que está pronto.
  - Use um cabo de dados curto USB diretamente no computador, não um hub, se possível.
  - On Windows, reinstall the MediaTek driver and restart. No Linux, verifique as permissões USB/serial.
Prompt de conexão do atualizadorO prompt do atualizador ao vivo é oficial para o modelo e plataforma atuais.

## Ele detectou o player, mas o flash falhou

Pare aqui. Não tente um modelo diferente. Feche as outras ferramentas, verifique se você escolheu Y1 ou Y2 correto e use o software original correspondente se o player não iniciar. [SP Flash Tool](sp-flash-tool_pt-BR.html) e MTKClient estão incluídos se você precisar deles, e os arquivos estão no [página de firmware](firmware_pt-BR.html).

## Notas sobre drivers do Windows

Algumas instalações do Windows bloqueiam o driver MediaTek devido ao isolamento do Core. Siga as orientações de segurança atuais do Windows antes de alterar a integridade da memória e ligue-a novamente quando terminar, se o seu sistema permitir.[Abra o guia do driver](drivers_pt-BR.html)[Guia de instalação limpa](Troubleshooting/clean_install.html)

## A roda não funciona ou o jogador não inicia

As falhas de entrada e de energia precisam de etapas diferentes de uma falha de flash. Esses guias cobrem os casos comuns Y1 e Y2.[Y1 roda de rolagem](guides/y1-scroll-wheel-not-working.html)[Y2 roda de rolagem](guides/y2-scroll-wheel-not-working.html)[Y1 não liga](guides/y1-wont-turn-on.html)[Y2 não liga](guides/y2-wont-turn-on.html)[Guia de recuperação](guides/recovery.html)
