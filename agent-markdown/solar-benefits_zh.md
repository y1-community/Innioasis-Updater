# 为什么 Solar 适合您的 Innioasis

Solar 打开 Wi-Fi。直接在播放器上流式传输和下载音乐：Deezer、Soulseek、播客，甚至 YouTube。不需要电话。[在更新程序 CE 中获取 Solar](guide_zh-CN.html?model=Y1&software=solar-y1)[Y1安装页面](solar-y1-software_zh-CN.html)[Y2安装页面](solar-y2-software_zh-CN.html)

## 型号可用性

哪些 Innioasis 型号运行它？[Y1 · 可用](solar-y1-software_zh-CN.html)[Y2 · 可用](solar-y2-software_zh-CN.html)

Y1 和 Y2 版本是分开的，因此请在软件下载中获取为您的播放器制作的版本 - 切勿将其中一个替换为另一个。

## 为什么人们选择它

播放器连接到互联网。
  - 从 Deezer 串流和下载 — 使用您自己的帐户从 Deezer 进行搜索、流媒体和下载 — 免费帐户上的 MP3、Premium 上的 FLAC。
  - 灵魂搜寻搜索 — 在长期运行的文件共享网络 Soulseek 上搜索同行库，并直接抓取曲目。
  - 播客下载 — 通过 Wi-Fi 直接订阅、浏览和下载剧集到设备。
  - 一个茎玩家 — 使用 Lalal.ai 词干分离将歌曲分成人声、鼓、贝斯和旋律，然后使用滚轮将一到三个曲目混合在一起。
  - Rockbox 在同一个 ROM — Solar 和 Rockbox-Y1 一起骑行 — 从“设置”切换启动器，无需重新刷新或重新启动。
  - YouTube播放 — 网络优先路线包括 YouTube 播放，将播放器变成更多的袖珍媒体机。

## 社区

社区怎么说

Solar 适合那些看着自己的播放器并询问 Wi-Fi 为什么不起作用的人。当话题转向流媒体和下载时，这是 r/innoasis 上讨论最多的路线。

该项目自己的版本将 Solar 描述为一个正在进行的界面，社区也是这样对待它的：点击时令人兴奋，设置步骤（例如连接您的 Deezer 帐户）会奖励耐心的读者。
  - [r/innioasis · Solar 讨论](https://www.reddit.com/r/innioasis/)

## 该项目提供什么
  - 覆盖范围：统一的 Deezer + Soulseek 搜索、流媒体和下载
  - 获取音乐：从主菜单组合 Deezer 和 Reach 搜索
  - 通过 Wi-Fi 订阅播客和下载剧集
  - Stem Player：Gen1风格的人声/鼓/贝斯/旋律通过滚轮混合
  - 用于从任何屏幕播放、队列、Wi-Fi 和蓝牙的全局快捷菜单
  - Y1 主题支持 — 应用原始 Y1 软件中的主题
  - Rockbox-Y1 与统一的键盘映射共同安装；无需重启即可切换启动器
  - 关于包含版本、归属和 OTA 更新检查的屏幕

## 首先要知道的事情
  - Solar 是一个正在进行中的界面 - 版本迭代很快，并且预计会出现一些粗糙的情况
  - Deezer 需要您自己帐户的 arl cookie，通过同一 Wi-Fi 上的 PC 设置；将 arl 视为密码
  - FLAC 质量需要 Deezer Premium 帐户；免费帐户使用 MP3
  - 流媒体和下载需要 Wi-Fi 网络 - 这不是离线优先的软件
  - 如果出现故障，恢复您模型的原始软件是解决问题的方法
