# چرا Rondo در Innioasis Y1 نصب شود؟ - Innioasis بارگیری میان‌افزار

Innioasis Y1 · سفت‌افزار سفارشی

# چرا Rondo را روی Innioasis Y1 خود نصب کنید؟

Rondo یک سفت‌افزار پخش‌کننده موسیقی با منبع باز و هدفمند است که به‌طور خاص برای سخت‌افزار Innioasis Y1 طراحی شده است. این مرورگر کتابخانه تمیز، تایپوگرافی تمیز، و رمزگشایی سریع صدا را ارائه می دهد.[نصب Rondo در Y1](guides/rondo-y1.html)[مرور انتشارات](firmware_fa.html?model=Y1&software=rondo-y1)

## نکات برجسته Rondo

### پاسخ سریع چرخ کلیک

منحنی شتاب با دقت تنظیم شده با چرخ لمسی خازنی فیزیکی Y1 برای پیمایش روان در کتابخانه های موسیقی بزرگ مطابقت دارد.

### پخش کننده صوتی متمرکز

بدون bloatware، تجزیه و تحلیل پس زمینه، یا شیطان های غیر ضروری: 100٪ از منابع سخت افزاری به خروجی صدای واضح اختصاص داده شده است.

### قابل برگشت در هر زمان

با استفاده از Innioasis Updater CE به راحتی نصب کنید و هر زمان که خواستید به نرم افزار اصلی یا Rockbox برگردید.
