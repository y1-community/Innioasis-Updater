# Install Linux on the Y1.

Linux for Y1 is an experimental community Linux kernel and rootfs port for the Innioasis Y1 hardware. ## Install Linux for Y1 (Dev) on your Y1 with your computer

اختر دليل الكمبيوتر الذي تستخدمه. يحتوي كل إصدار على إعداد النظام الأساسي وخطوات Updater CE وطريقة العودة إلى المخزون.[دليل ويندوز](install/linux-y1-windows.html)[دليل ماك](install/linux-y1-mac.html)[دليل لينكس](install/linux-y1-linux.html)

## Linux Y1 install steps
  - افتح Innioasis Updater CE على جهاز الكمبيوتر الخاص بك (إذا كنت بحاجة إلى التطبيق، [احصل على Updater CE](guide_ar.html#platform)). تعيين طراز الجهاز ل Y1.
  - اختر Linux لنظام Y1 (المطور) في البرنامج.
  - اختر الإصدار المدرج لـ Y1.
  - انقر تثبيت / استعادة.
  - قم بإيقاف تشغيل Y1 وتوصيله فقط عندما يطلب منك Updater CE.
