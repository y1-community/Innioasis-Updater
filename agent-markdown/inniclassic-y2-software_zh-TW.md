# 在 Y2 上安裝 Inniclassic。

Inniclassic 可用於 Innioasis Y2，同一專案也建構 Y1 套件。此頁面為您提供 Y2 概述以及完整教程的連結。[開啟完整的 Inniclassic 指南](guides/inniclassic-y2.html)[在 Updater CE 中取得此內容](guide_zh-TW.html?model=Y2&software=inniclassic-y2)[為什麼是Inniclassic？](inniclassic-benefits_zh-TW.html)

## 使用計算機在 Y2 上安裝 Inniclassic

選擇適合您正在使用的計算機的指南。 每個版本都有平台設定、Updater CE步驟和返回庫存的方式。[Windows 指南](install/inniclassic-y2-windows.html)[macOS 指南](install/inniclassic-y2-mac.html)[Linux指南](install/inniclassic-y2-linux.html)

## Inniclassic Y2 安裝步驟
  - 在您的電腦上開啟 Innioasis Updater CE（如果您需要該應用程序， [取得 Updater CE](guide_zh-TW.html#platform)）。套裝 裝置型號 到 Y2.
  - 選擇 Inniclassic 在 軟體.
  - 選擇 Y2 列出的版本。
  - 點選 安裝 / 還原.
  - 僅當 Updater CE 詢問時關閉電源並連接 Y2。

## 常見問題我可以恢復庫存 Y2 軟體嗎？

是的。在 Updater CE 中選擇 Y2 和原始軟體。這 [Y2 庫存軟體指南](original-software-y2_zh-TW.html) 覆蓋返迴路徑。我可以在 Y1 上使用 Inniclassic 嗎？

是的。同一個專案也發布了 Y1 包 - rom.zip 對於 Type A 和 rom_type_b.zip 對於Type B。在 Updater CE 中選擇 Y1 並安裝 Y1 版本；這 [Y1安裝頁面](inniclassic-y1-software_zh-TW.html) 覆蓋它。如果安裝失敗怎麼辦？

請注意更新程式在偵測到 Y2 之前或之後是否失敗，然後檢查線纜、平台設定、型號和連接時序 [故障排除](troubleshooting_zh-TW.html).

## 使用引導路線

第一次使用更新程式？請參閱指導設定 [取得 Updater CE](guide_zh-TW.html#platform) 在 Windows、macOS 或 Linux 上，然後再連接播放器。
