# Install Android 4.4 (Dev) on the Y2.

Android 4.4 is a community development ROM for testing and hacking on Innioasis Y2 hardware. This page links to the full tutorial and release list.[Open the full Android 4.4 (Dev) guide](guides/android-4-4-y2.html)[Dapatkan ini dalam Updater CE](guide_ms.html?model=Y2&software=android-4-4-y2)[Sumber projek](https://github.com/y1-community/y2-ata-rom)

Pilih panduan untuk komputer yang anda gunakan. Setiap versi mempunyai persediaan platform, Updater CE langkah dan jalan kembali ke stok.[Panduan Windows](install/android-4-4-y2-windows.html)[panduan macOS](install/android-4-4-y2-mac.html)[Panduan Linux](install/android-4-4-y2-linux.html)

## Android 4.4 Y2 install steps
  - Buka Innioasis Updater CE pada komputer anda (jika anda memerlukan apl itu, [Dapatkan Updater CE](guide_ms.html#platform)). Tetapkan Model Peranti kepada Y2.
  - pilih Android 4.4 (Dev) dalam Perisian.
  - Choose the release listed for Y2.
  - klik Pasang / Pulihkan.
  - Matikan dan sambungkan Y2 hanya apabila Updater CE bertanya.
