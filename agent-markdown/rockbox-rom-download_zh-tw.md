# Rockbox ROM 下載 Y1 和 Y2

## 首先選擇您的播放器型號

Rockbox-Y1 和 Rockbox-Y2 是為不同硬體建立的單獨韌體版本。下載或刷機前請檢查您的播放器是 Innioasis Y1 還是 Y2。

## Updater CE 如何下載韌體

Innioasis Updater CE 始終直接從社區韌體開發人員自己的版本下載韌體包，並且開發人員自己全權負責在 Updater CE 中列出他們的軟體版本。每個 ROM 套件包含該模型的 MediaTek 分散檔案和分割映像。
  - Rockbox-Y1 開發者發布包： `rom.zip` （和 `rom_type_b.zip` 對於 Type B Y1 單位）。
  - Rockbox-Y2 開發者發布包： `rom_y2.zip`.

## 使用 Updater CE 自動安裝

要進行最簡單的設置，請打開 Innioasis Updater CE，選擇您的播放器型號和 Rockbox，然後讓應用程式直接下載並刷新版本。遵循 [Rockbox-Y1安裝指南](rockbox-y1/install.html) 或 [Rockbox-Y2安裝指南](rockbox-y2/install.html).
