## Instal pilihan Anda dengan Updater CE
  - Buka panduan dan instal Innioasis Updater CE untuk komputer Anda jika Anda belum memilikinya.
  - Di Updater CE, pilih model yang dicetak pada pemutar Anda Model perangkat.
  - Dari Perangkat lunak, pilih perangkat lunak yang ingin Anda jalankan pada model tersebut.
  - Pilih rilis, klik Pasang / Pulihkan, lalu matikan dan sambungkan pemutar hanya jika Updater CE memintanya.

Butuh penginstalnya? [Buka panduan dan perluas bagian unduhan Updater CE](guide_id.html#download-updater).

## Jalan kembali yang aman

### Periksa modelnya

Y1 and Y2 software is not interchangeable. Re-select the model in Updater CE and start again.

### Tunggu perintahnya

Matikan pemutar sepenuhnya dan sambungkan hanya jika Updater CE menyatakan sudah siap.

### Pulihkan Perangkat Lunak Asli

Pilih Perangkat Lunak Asli untuk model yang sama. Jika pemulihan manual diperlukan, buka [panduan pemecahan masalah](troubleshooting_id.html) pertama.

## Supported Devices and Official Stock Firmware

The Innioasis Firmware Archive hosts verified stock firmware, original factory restore images, and custom operating systems for portable players:

### Innioasis Y1 & Y2

Official software and custom systems including Rockbox, Better-Y, and Solar.

### Innioasis G1, G3 & G5

Perangkat lunak resmi dan file pemulihan untuk pemutar layar sentuh.

### Innioasis R1 & PR1

Perangkat lunak asli dan file pemulihan untuk pemutar audio.

### Timmkoo Q5 & Q3

Packages provided for Timmkoo players via Updater CE.

New releases appear here as soon as they are verified.

## Alat mana yang harus saya gunakan?

Innioasis Updater Masehi is the recommended tool for daily updates and community OS installs across Windows, macOS, and Linux. Flashing through Updater CE preserves your library and pairings.

The legacy Universal Flash Tool remains available for emergency unbricking when a device cannot boot into fastboot.[Compare flashing tools](updater-comparison_id.html)
