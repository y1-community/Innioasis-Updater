# วิธีการกู้คืนผู้เล่นที่ไม่ได้บู๊ต MediaTek หลังจาก MTKclient ล้มเหลว · Innioasis ชุมชน

การแก้ไขปัญหาและการกู้คืนอุปกรณ์

# การกู้คืนอุปกรณ์ที่ไม่ได้บู๊ตหลังจาก MTKclient กระพริบ

หากอุปกรณ์ Innioasis Y1, Y2 หรือ MediaTek ของคุณไม่สามารถเปิดเครื่องได้หรือแสดงหน้าจอสีดำหลังจากกระพริบด้วย MTKclient บน macOS หรือ Linux อย่าตกใจ ฮาร์ดแวร์ BootROM (BROM) เป็นแบบถาวรและไม่สามารถถูกทำลายได้

## เหตุใด MTKclient อาจหยุดทำงานหรือปล่อยให้หน้าจอสีดำ

MTKclient อาศัยเพย์โหลดการหาประโยชน์จากซอฟต์แวร์ (kamakiri / amonet) เพื่อเลี่ยงผ่านการตรวจสอบสิทธิ์ DA และการสื่อสารดิบ USB ผ่าน libusb บนระบบ macOS และ Linux ARM64:
  - USB เวลาแฝงของการจับมือหรือการหมดเวลาพอร์ตบน macOS อาจทำให้การถ่ายโอนเพย์โหลด DA หยุดกลางการถ่ายโอนได้
  - ส่วนหัวของพาร์ติชันที่ขาดหายไปหรือไม่สมบูรณ์ทำให้ bootloader (preloader / lk) อยู่ในสถานะไม่ตอบสนอง
  - เครื่องเล่นดูเหมือนตายสนิท ไม่มีไฟ LED ไม่มีไอคอนการชาร์จ ไม่มีแสงพื้นหลังของหน้าจอ

แม้จะอยู่ในสถานะนี้ ชิปเซ็ต MediaTek ก็จะลดลงกลับเข้าไป โหมดบรอม (USB VID 0e8d, PID 0003) พร้อมสำหรับการกู้คืนระดับต่ำอย่างเป็นทางการ

## วิธีการกู้คืนขั้นสุดท้าย: SP Flash Tool เครื่องยนต์ใน Updater CE

วิธีที่ปลอดภัยและเชื่อถือได้มากที่สุดในการกู้คืนเครื่องเล่นที่ติดอยู่บนอิฐของคุณคือการใช้ ตัวอัพเดต CE กำหนดไว้กับทางการ SP Flash Tool แบ็กเอนด์

### ขั้นตอนที่แน่นอนใน Updater CE:
  - เปิด ตัวอัพเดต CE.
  - คลิก การตั้งค่า ในแถบนำทางด้านซ้าย
  - เลื่อนลงไปที่ส่วนขั้นสูงแล้วเปิดใช้งาน แสดงการตั้งค่าขั้นสูง.
  - ภายใต้ วิธีการติดตั้ง (หรือ Flashing Engine สำหรับตัวติดตั้ง MediaTek) ค้นหา วิธีแฟลช แบบเลื่อนลง
  - เปลี่ยนการเลือกจาก อัตโนมัติ (แนะนำ) หรือ MTKClient ถึง SP Flash Tool.
  - ยืนยันข้อความแจ้งและกลับสู่ขั้นตอนการติดตั้งหลัก

## สถาปัตยกรรมแพลตฟอร์มและข้อกำหนดระบบปฏิบัติการสำหรับ SP Flash Tool

MediaTekอย่างเป็นทางการ `SP Flash Tool` ไบนารี่ถูกคอมไพล์โดยกำเนิดเป็น x86_64 ไบนารี ELF สำหรับ Linux และก PE32+ ปฏิบัติการได้สำหรับ Windows x64.หมายเหตุฮาร์ดแวร์ที่สำคัญสำหรับผู้ใช้ macOS และ ARM64 Linux:
 เนื่องจาก MediaTek ไม่ได้คอมไพล์ SP Flash Tool สำหรับ macOS (Darwin) หรือ Linux ARM64 (aarch64) ผู้ใช้ macOS และผู้ใช้ ARM64 Linux (เช่น Raspberry Pi หรือ Apple Silicon ที่ใช้ Asahi Linux) ที่ประสบปัญหาต้องเชื่อมต่อเครื่องเล่นกับ: 
  - หนึ่ง x64 วินโดวส์พีซี (Windows 10 / 11 64 บิต) หรือ
  - หนึ่ง x86_64 ลินุกซ์พีซี (อูบุนตู, เดเบียน, Fedora, Arch 64 บิต)

## กระบวนการปลดอิฐฮาร์ดแวร์ทีละขั้นตอน
  - ตัดการเชื่อมต่อเครื่องเล่น: ถอดปลั๊กสายเคเบิล USB ออกจากเครื่องเล่นและพีซีอย่างสมบูรณ์
  - ปิดเครื่องอย่างหนัก: กดปุ่มเปิด/ปิดค้างไว้ (หรือเปิด/ปิด + ลดระดับเสียง) เป็นเวลา 15 วินาทีเพื่อให้แน่ใจว่าชิปเซ็ตปิดเครื่องโดยสมบูรณ์และไม่ติดอยู่ในลูป USB ที่ใช้พลังงานต่ำ
  - เปิด Updater CE ด้วยโหมด SP Flash Tool: เลือกรุ่นอุปกรณ์ของคุณ (เช่น Innioasis Y1 หรือ Innioasis Y2) และเลือก ซอฟต์แวร์ดั้งเดิม เพื่อเรียกคืนพาร์ติชั่นสต็อก
  - เริ่มต้นการติดตั้ง / กู้คืน: คลิก ติดตั้ง / คืนค่า ใน Updater CE รอจนกระทั่งข้อความแจ้งสถานะแจ้งว่า กำลังรอผู้เล่น...
  - ใส่สายเคเบิล USB เพื่อทริกเกอร์ BROM: ในขณะที่อุปกรณ์ปิดอยู่ ให้เสียบสายเคเบิล USB เข้ากับพอร์ตมาเธอร์บอร์ดความเร็วสูง USB โดยตรง (หลีกเลี่ยงฮับ USB ที่ไม่ได้รับพลังงาน)
  - ระบบจะตรวจจับพอร์ต MediaTek VCOM กด Download Agent (DA) เขียนตารางพาร์ติชั่นใหม่ และกู้คืนอิมเมจเฟิร์มแวร์ทั้งหมดอย่างหมดจด

## การเรียงสับเปลี่ยนตามรุ่นและระบบปฏิบัติการ

| แบบอย่าง | แพลตฟอร์มล้มเหลว | การตั้งค่าการกู้คืนที่แนะนำ | เครื่องยนต์และโหมด |
| --- | --- | --- | --- |
| Innioasis Y1 | macOS (แอปเปิลซิลิคอน / อินเทล) | พีซี Windows x64 / Linux x86_64 | SP Flash Tool + Y1 หุ้น ROM |
| Innioasis Y1 | ลินุกซ์ ARM64 / x86_64 | Linux x86_64 หรือพีซี Windows x64 | SP Flash Tool + ชุมชน DA |
| Innioasis Y2 | macOS (ไคลเอนต์ MTK หยุดทำงาน) | พีซี Windows x64 / Linux x86_64 | SP Flash Tool + Y2 การกู้คืนแบบกระจาย |
| Innioasis G1 / G3 / G5 | ไคลเอนต์ MTK macOS / Linux | พีซี Windows x64 พร้อมไดรเวอร์ VCOM | SP Flash Tool + เฟิร์มแวร์จากโรงงาน |
| Mechen H1 / Timmkoo A5 | แพลตฟอร์มใดก็ได้ | พีซี Windows x64 หรือ Linux x86_64 | SP Flash Tool + ไฟล์กระจาย |
