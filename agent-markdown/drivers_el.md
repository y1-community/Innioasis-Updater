# Innioasis Y1 και Y2 USB προγράμματα οδήγησης | Δικαιώματα προγράμματος οδήγησης Windows και Linux - Innioasis Ενημέρωση

Ρύθμιση υπολογιστή

# Ετοιμάστε τον υπολογιστή πριν από τη συσκευή αναπαραγωγής.

Τα περισσότερα προβλήματα σύνδεσης προέρχονται από το πρόγραμμα οδήγησης, τις άδειες, το καλώδιο ή το χρονισμό. Τα Windows χρειάζονται εγκατεστημένο το πρόγραμμα οδήγησης MediaTek. Το Linux χρειάζεται τα σωστά USB δικαιώματα. Βρείτε την πλατφόρμα σας παρακάτω.[Αποκτήστε το Updater CE](guide_el.html#platform)[Αντιμετώπιση προβλημάτων](troubleshooting_el.html)

## Windows
  - Κατεβάστε το πρόγραμμα εγκατάστασης του προγράμματος οδήγησης MediaTek παρακάτω.
  - Εκτελέστε το πρόγραμμα εγκατάστασης και επιτρέψτε στα Windows να εγκαταστήσουν το πρόγραμμα οδήγησης.
  - Κάντε επανεκκίνηση του υπολογιστή.
  - Ανοίξτε το Updater CE και περιμένετε το μήνυμα σύνδεσης προτού συνδέσετε τη συσκευή αναπαραγωγής που είναι απενεργοποιημένη.

Ορισμένα συστήματα Windows μπλοκάρουν το πρόγραμμα οδήγησης μέσω της απομόνωσης πυρήνα (ακεραιότητα μνήμης). Εάν το Updater CE εξακολουθεί να μην μπορεί να δει τη συσκευή αναπαραγωγής μετά από επανεκκίνηση, απενεργοποιήστε την ακεραιότητα μνήμης στο Windows Security, επανεκκινήστε και εγκαταστήστε ξανά το πρόγραμμα οδήγησης. Ενεργοποιήστε ξανά τη ρύθμιση όταν τελειώσετε, εάν το επιτρέπει το σύστημά σας.

Τα Windows δεν θα εκκινήσουν την εφαρμογή; Εάν η Ασφάλεια των Windows ή ο Έλεγχος Smart App σταματήσει το άνοιγμα του Updater CE, ανοίξτε Ρυθμίσεις (πατήστε Win + I) → Απόρρητο και ασφάλεια → Windows Security → Έλεγχος εφαρμογών και προγράμματος περιήγησης → Ρυθμίσεις Smart App Control και ρυθμίστε το σε Απενεργοποίηση. Ο Έξυπνος Έλεγχος εφαρμογών επηρεάζει επί του παρόντος δημοφιλείς εφαρμογές όπως η υπηρεσία Epic Overlay (που χρησιμοποιείται από το Fortnite) — Το Updater CE είναι ασφαλές και επαληθευμένο για χρήση. Για να ενεργοποιήσετε ξανά αργότερα, ορίστε `VerifiedAndReputablePolicyState` να `1` (Ενεργό) ή `2` (Λειτουργία αξιολόγησης) κάτω από `HKEY_LOCAL_MACHINE\SYSTEM\CurrentControlSet\Control\CI\Policy` στον Επεξεργαστή Μητρώου.[Κατεβάστε το πρόγραμμα οδήγησης των windows](https://github.com/y1-community/supplemental-apks/releases/latest/download/DriverInstall.exe)

[Επιστροφή στον κύριο οδηγό](guide_el.html#windows) · [Λήψεις λογισμικού](firmware_el.html)

## Δικαιώματα Linux USB

Το Linux χρειάζεται ο λογαριασμός χρήστη σας να επιτρέπεται να μιλά στο τσιπ MediaTek USB μέσα στη συσκευή αναπαραγωγής. Το Updater CE συνήθως το επιλύει αυτό κατά την εγκατάσταση και η ίδια άδεια καλύπτει το SP Flash Tool, επομένως αντιμετωπίστε το ως βήμα επιδιόρθωσης και όχι ως κανονικό στάδιο.
  - Εκτελέστε το Updater CE ως κανονικός χρήστης, όχι ως root. Το πρόγραμμα εγκατάστασης ζητά πρόσβαση διαχειριστή μόνο όταν το χρειάζεται.
  - Ελέγξτε ότι ο παίκτης φαίνεται καθόλου. Απενεργοποιήστε τη συσκευή αναπαραγωγής, συνδέστε το καλώδιο και εκτελέστε την εντολή lsusb σε ένα τερματικό. Μια συνδεδεμένη συσκευή αναπαραγωγής εμφανίζεται ως συσκευή MediaTek με αναγνωριστικό προμηθευτή 0e8d.
`lsusb`
  - Εάν εμφανίζεται στο lsusb αλλά το Innioasis Updater CE ή το SP Flash Tool λέει ότι η άδεια δεν επιτρέπεται ή δεν μπορεί να ανοίξει τη θύρα, ο χρήστης σας δεν έχει πρόσβαση στη συσκευή USB. Ο ίδιος κανόνας udev καλύπτει και τα δύο εργαλεία, επομένως προσθέστε ένα που επιτρέπει στην ομάδα χρηστών να το διαβάσει.
`SUBSYSTEM=="usb", ATTR{idVendor}=="0e8d", MODE="0666", GROUP="plugdev"`

Αποθηκεύστε αυτήν τη γραμμή σε ένα νέο αρχείο με το όνομα /etc/udev/rules.d/51-innioasis.rules και, στη συνέχεια, εκτελέστε:`sudo udevadm control --reload && sudo udevadm trigger`
  - Αποσυνδέστε πλήρως τη συσκευή αναπαραγωγής, συνδέστε την ξανά και δοκιμάστε να την εγκαταστήσετε ξανά.
  - Εάν ο SP Flash Tool αναφέρει σειριακή άδεια ή αγώνα θύρας, αποσυνδέστε πλήρως και επανασυνδέστε μόνο όταν σας ζητηθεί.
Μην αυτοσχεδιάζετε μετατοπίσεις φλας.Εάν μετακινηθείτε σε ένα εργαλείο μη αυτόματης ανάκτησης, χρησιμοποιήστε τα αρχεία και τις ρυθμίσεις παραμέτρων για συγκεκριμένο μοντέλο που αποστέλλονται μαζί με το έργο.

## Καλώδιο και χρονισμός
  - Χρησιμοποιήστε ένα γνωστό καλώδιο δεδομένων USB.
  - Αποφύγετε τους κόμβους κατά την αντιμετώπιση προβλημάτων.
  - Απενεργοποιήστε πλήρως το σωστό μοντέλο.
  - Συνδεθείτε μόνο με την προτροπή.
