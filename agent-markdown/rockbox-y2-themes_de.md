# Rockbox-Y2-Themen

So installieren Sie Themes auf Rockbox-Y2, überprüfen die Theme-Kompatibilität mit Ihrem installierten Build und setzen ein Theme zurück, wenn es nicht richtig angezeigt wird.[Rockbox-Y2 Versionshinweise](release-notes/rockbox-y2/index.html)[Durchsuchen Sie Community-Themen](https://themes.innioasis.app/)[Installieren Sie Rockbox-Y2](rockbox-y2/install.html)

## Überprüfen Sie die Theme-Kompatibilität für Ihren Build

Rockbox-Y2 wird separat vom Y1-Port entwickelt, daher richtet sich die Theme-Kompatibilität nach der von Ihnen installierten Build-Version Y2. Überprüfen Sie die [Rockbox-Y2 Versionshinweise](release-notes/rockbox-y2/index.html) für Ihre Version, bevor Sie ein Theme-Paket installieren.

Sehen [Rockbox-Y1 vs. Rockbox-Y2](rockbox-y1-vs-y2_de.html) für einen vollständigen Vergleich der beiden Ports.

## So installieren Sie Themes auf dem Y2

Themen werden auf Ihrer MicroSD-Karte im Verborgenen gespeichert `.rockbox` Ordner.
  - Starten Sie Rockbox-Y2 mindestens einmal, damit es erstellt wird `.rockbox` Ordner auf Ihrer MicroSD-Karte.
  - Extrahieren oder kopieren Sie die Theme-Dateien in `.rockbox/` (Also `themes`, `wps`, `fonts`, und `backdrops` verschmelzen in `.rockbox/`).
  - Auf dem Player öffnen Einstellungen → Theme-Einstellungen → Theme-Dateien durchsuchen und wählen Sie Ihr Thema aus.

So zeigen Sie versteckte Ordner auf Ihrem Computer an: Drücken Sie Cmd+Shift+. unter macOS aktivieren Ansicht → Versteckte Elemente unter Windows, oder drücken Sie Ctrl+H unter Linux.

## So setzen Sie ein defektes Theme zurück

Wenn ein Thema die Lesbarkeit des Bildschirms erschwert, benennen Sie es um oder löschen Sie es `.rockbox` Ordner auf Ihrer MicroSD-Karte und starten Sie den Player neu. Rockbox-Y2 wird ein neues erstellen `.rockbox` Ordner mit dem Standardthema, während Ihre Musik erhalten bleibt.[Der .rockbox-Ordner](rockbox-y2/sd-card.html)[Aktualisierung von Rockbox-Y2](rockbox-y2/update.html)[Rockbox-Y2 Build-Notizen](rockbox-y2/resolution.html)
