## Rockbox Y2 шаги установки
  - Откройте Innioasis Updater CE на своем компьютере (если вам нужно приложение, [Скачать Updater CE](guide_ru.html#platform)). Набор Модель устройства в адрес Y2.
  - Выбирать Rockbox в Программное обеспечение.
  - Выберите выпуск, явно указанный для Y2.
  - Нажмите Установить / Восстановить и дождитесь подготовки посылки.
  - Выключите питание и подсоедините Y2 только при запросе Updater CE.

Не используйте пакет Y1 принудительно, поскольку имя проекта выглядит одинаково. Если версия Y2 не отображается, остановитесь и проверьте модель и данные текущей версии.

## Вопросы и ответыМогу ли я позже восстановить исходное программное обеспечение Y2?

Да. Выберите Y2 и оригинальное программное обеспечение в Updater CE. См. [Y2 страница стандартного программного обеспечения](original-software-y2_ru.html) для последовательности восстановления.Почему пакет может называться rom_y2.zip?

Это подсказка для загрузки вручную, используемая в некоторых Y2 выпусках с полной установкой. Более безопасным выбором по-прежнему остается выбор Y2 в Updater CE и использование представленной версии.Могу ли я использовать учебник Y1 Rockbox?

Используйте его только для широкой идеи. Для выбора пакета и модели следуйте этому [Y2-специальное руководство](guides/rockbox-y2.html).
