# Install Innioasis and Timmkoo software on Windows

Set up Innioasis Updater CE on a Windows PC, then use the model-specific guide for the software you want. Windows 10 and 11 x64 are the normal targets. ARM64 Windows is experimental.[Get Updater CE for Windows](../guide.html#windows)[Windows install guides](windows.html)[Download the Windows MediaTek driver](../drivers.html#windows)

## Prepare Windows for the install
  - Download the Innioasis Updater CE installer (`installer.exe`) from the official GitHub release and run it. If SmartScreen says “Windows protected your PC”, choose More info then Run anyway only for the file you just downloaded from `github.com/y1-community/Innioasis-Updater`.
  - Install the MediaTek USB driver with `DriverInstall.exe`, then restart the PC. The driver is what lets Windows see a powered-off player when Updater CE asks for it.
  - Use a USB port on the PC itself and a cable that carries data. A charge-only cable or an unpowered hub is the usual reason the player never appears.

Windows 10 and 11 x64 are the normal targets. ARM64 Windows is experimental. [Full Windows setup notes](../drivers.html#windows).

## Questions people askDo I need to install a driver on Windows?

Yes. Install DriverInstall.exe and restart before connecting the player.Does Updater CE keep my music?

A normal Updater CE install keeps the music on the microSD card. A full stock restore can wipe internal storage, so back up first.Where are the model-specific guides?

Use the software table above, or open the model card for your player. Every install page names the model and platform in its title.Can I use a different computer?

Yes. Each guide has links to the Windows, macOS and Linux versions at the top of the page.
