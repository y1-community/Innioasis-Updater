## Why people install Inniclassic

Inniclassic recreates the click-wheel Classic experience with modern fixes: dual-storage library scanning, a microSD watchdog, FM radio support and lower headphone gain.

Source: [FabianZettl/inniclassic and JonaszPotoniec/inniclassic-y2](https://github.com/FabianZettl/inniclassic)

## Questions people askWhat is Inniclassic?

An iPod Classic-style interface for the Innioasis Y1 and Y2. Inniclassic recreates the click-wheel Classic experience with modern fixes: dual-storage library scanning, a microSD watchdog, FM radio support and lower headphone gain.Is InniClassic the same as Inniclassic?

Yes. InniClassic, Inni Classic, iPod Classic firmware, Classic Y1, Classic Y2 all refer to the same project.Which models are supported?

Innioasis Y1, Innioasis Y2. Use the model-specific guide before installing.How do I go back to stock?

Restore Original Software for the same model if you want the stock interface back.
