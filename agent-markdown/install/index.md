## Questions people askWhich install guide should I open?

Open the platform page for the computer you are using, then choose the model and software. Every guide names both the model and the platform in its title.Do the guides cover Windows, macOS and Linux?

Yes. Each software/model combination has a Windows, a macOS and a Linux page, and the top of every page links to the other two platforms.What software is covered?

Rockbox, Solar, Reborn (Y2Linux), JJ Launcher, Inniclassic, Y2Player, Koensayr, Better-Y, Rondo, the Android development ROMs, Linux for Y1 and Original Software for every supported model.Where do downloads come from?

Innioasis Updater CE downloads each package from the project's official release. The software archive also links the original release and portable ZIPs.
