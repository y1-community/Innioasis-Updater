# Install Innioasis and Timmkoo software on macOS

Set up Innioasis Updater CE on a Mac, then use the model-specific guide for the software you want. Intel and Apple Silicon Macs are supported. The current guide targets macOS Monterey (12.0) or later.[Get Updater CE for macOS](../guide.html#macos)[macOS install guides](mac.html)[macOS setup notes](../drivers.html#macos)

## Prepare macOS for the install
  - Download the macOS disk image (`Innioasis.Updater.for.Mac.dmg`), open it, and drag Innioasis Updater CE into Applications.
  - The first launch is blocked by Gatekeeper until you approve it. Right-click the app and choose Open, or open System Settings → Privacy & Security and click Open Anyway. Do not disable Gatekeeper for the whole Mac.
  - No separate USB driver is needed. Connect the player directly to the Mac, not through an unpowered hub; some USB-C adapters drop the connection during a flash.

Intel and Apple Silicon Macs are supported. The current guide targets macOS Monterey (12.0) or later. [Full macOS setup notes](../drivers.html#macos).

## Questions people askDo I need to install a driver on macOS?

No separate driver. Approve Updater CE in Privacy & Security the first time you open it.Does Updater CE keep my music?

A normal Updater CE install keeps the music on the microSD card. A full stock restore can wipe internal storage, so back up first.Where are the model-specific guides?

Use the software table above, or open the model card for your player. Every install page names the model and platform in its title.Can I use a different computer?

Yes. Each guide has links to the Windows, macOS and Linux versions at the top of the page.
