# Install Koensayr on macOS

A stock-derived Y1 patch that adds Artist-to-Album navigation and root while keeping the stock feel. These macOS guides cover every model the project supports. People also search for Koensayr Y1, Koensayr Auto, Koensayr firmware; this is the same Koensayr install.[Get Updater CE for macOS](../guide.html#macos)[macOS install guides](mac.html)[macOS setup notes](../drivers.html#macos)Your computer[Windows](koensayr-windows.html)[macOS](koensayr-mac.html)[Linux](koensayr-linux.html)[All platforms](index.html)

## Prepare macOS for the install
  - Download the macOS disk image (`Innioasis.Updater.for.Mac.dmg`), open it, and drag Innioasis Updater CE into Applications.
  - The first launch is blocked by Gatekeeper until you approve it. Right-click the app and choose Open, or open System Settings → Privacy & Security and click Open Anyway. Do not disable Gatekeeper for the whole Mac.
  - No separate USB driver is needed. Connect the player directly to the Mac, not through an unpowered hub; some USB-C adapters drop the connection during a flash.

Intel and Apple Silicon Macs are supported. The current guide targets macOS Monterey (12.0) or later. [Full macOS setup notes](../drivers.html#macos).

## How the install works
  - Install Updater CE on macOS using the steps above.
  - Select the model printed on the player, then choose Koensayr.
  - Choose a stable release listed for that model.
  - Click Install / Restore, power the player off and connect it at the prompt.
  - Wait for success. Open the after-install notes for the extra patch options and the first-start checks.
