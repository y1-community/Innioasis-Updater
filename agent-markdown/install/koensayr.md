## Why people install Koensayr

Koensayr improves the stock Y1 software instead of replacing it: Artist-to-Album navigation, a root option and a small set of audio patches.

Source: [ryan-specter/koensayr-auto](https://github.com/ryan-specter/koensayr-auto)
