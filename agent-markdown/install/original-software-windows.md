# Restore Original Software (stock firmware) on Windows

The factory system image from Innioasis or Timmkoo, used to undo a custom install or recover a player that will not boot. These Windows guides cover every model the project supports. People also search for stock firmware, factory firmware, stock ROM, original firmware; this is the same Original Software install.[Get Updater CE for Windows](../guide.html#windows)[Windows install guides](windows.html)[Download the Windows MediaTek driver](../drivers.html#windows)Your computer[Windows](original-software-windows.html)[macOS](original-software-mac.html)[Linux](original-software-linux.html)[All platforms](index.html)

## Prepare Windows for the install
  - Download the Innioasis Updater CE installer (`installer.exe`) from the official GitHub release and run it. If SmartScreen says “Windows protected your PC”, choose More info then Run anyway only for the file you just downloaded from `github.com/y1-community/Innioasis-Updater`.
  - Install the MediaTek USB driver with `DriverInstall.exe`, then restart the PC. The driver is what lets Windows see a powered-off player when Updater CE asks for it.
  - Use a USB port on the PC itself and a cable that carries data. A charge-only cable or an unpowered hub is the usual reason the player never appears.

Windows 10 and 11 x64 are the normal targets. ARM64 Windows is experimental. [Full Windows setup notes](../drivers.html#windows).

## How the install works
  - Install Updater CE on Windows using the steps above.
  - Select the model printed on the player, then choose Original Software.
  - Choose a stable release listed for that model.
  - Click Install / Restore, power the player off and connect it at the prompt.
  - Wait for success. The first start can take a few minutes. Set the language, Wi-Fi and Bluetooth again if the restore cleared them.

## Questions people askWhich Original Software package should I download on Windows?

Use Innioasis Updater CE and select the model first. The app downloads the package from the project's official release. If you download manually, use the ZIP that names the model and, on a Y1, the correct Type A or Type B asset.Does Original Software work on every model?

Open the model card for the exact guide.Is stock firmware the same as Original Software?

Yes. stock firmware, factory firmware, stock ROM are names people use for the same project.Do I need a driver?

Yes. Install the MediaTek driver with DriverInstall.exe and restart before connecting the player.Can I undo it?

This is the restore path itself: choose Original Software for the model and run Install / Restore.
