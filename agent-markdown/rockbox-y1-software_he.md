# התקן את Rockbox ב-Y1 מבלי לנחש קבצים.

זהו המסלול Y1 עבור תוכנות Rockbox, ערכות נושא ושלב החיבור של Updater. בחירת הדגם באה לפני בחירת הפרויקט.[פתח את המדריך המלא Rockbox](guides/rockbox-y1.html)[קבל את זה ב-Updater CE](guide_he.html?model=Y1&software=rockbox-y1)[למה Rockbox?](rockbox-benefits_he.html)

## התקן את Rockbox ב-Y1 שלך עם המחשב שלך

בחר את המדריך עבור המחשב שבו אתה משתמש. לכל גרסה יש את הגדרת הפלטפורמה, Updater CE שלבים והדרך חזרה למלאי.[מדריך Windows](install/rockbox-y1-windows.html)[מדריך macOS](install/rockbox-y1-mac.html)[מדריך לינוקס](install/rockbox-y1-linux.html)

[כל Innioasis מדריכי Y1](install/y1.html) · [כל המדריכים Rockbox](install/rockbox_he.html)

## Rockbox Y1 שלבי התקנה
  - פתח את Innioasis Updater CE במחשב שלך (אם אתה צריך את האפליקציה, [הורדת Updater CE](guide_he.html#platform)). סט דגם המכשיר ל Y1.
  - בחר Rockbox ב תוכנה.
  - בחר את המהדורה והגרסה שתואמים למסך או נתיב הנושא המיועד שלך.
  - לחץ התקנה / שחזור והמתן עד שהאפליקציה תכין אותה.
  - כבה וחבר את ה-Y1 רק בהנחיה החיה.

השתמש ב- [מדריך כתוב Rockbox Y1](guides/rockbox-y1.html) עבור צילומי המסך, הסרטון, ההערה Type A או Type B ורשימת הבדיקה לחיבורים.

## שאלות נפוצותהאם אוכל לחזור לתוכנה המקורית Y1?

כֵּן. בחר Y1 ותוכנה מקורית ב-Updater CE, ולאחר מכן הפעל את ההתקנה/שחזור. ה [Y1 דף תוכנה במניות](original-software-y1_he.html) מסביר את המסלול הזה.באיזו Rockbox מהדורה עלי לבחור?

בחר מהדורה המוצגת עבור Y1 וקרא את הערת ההפצה שלה. אם אתה זקוק לתאימות ערכות נושא ישנות יותר, בדוק את הרזולוציה והערות לגרסה במקום לבחור במבנה Y2.האם אני יכול להתקין את זה על Y2?

לא. השתמש בנפרד [Rockbox עמוד Y2](rockbox-y2-software_he.html) ובחר Y2 בעדכון CE.
