## Solar Y1 Installationsschritte
  - Öffnen Sie Innioasis Updater CE auf Ihrem Computer (wenn Sie die App benötigen, [Updater CE holen](guide_de.html#platform)). Satz Gerätemodell an Y1.
  - Wählen Sie Solar In Software.
  - Lesen Sie die Versionshinweise zum Projekt und wählen Sie eine Y1-Version aus.
  - Klicken Sie Installieren / Wiederherstellen.
  - Schalten Sie das Y1 erst aus und schließen Sie es an, wenn die Aufforderung erscheint.

Solar Funktionen und Verfügbarkeit können sich ändern. Die Funktionen können sich zwischen den Veröffentlichungen ändern. Überprüfen Sie daher die Veröffentlichungsseite des Projekts und die aktuelle Auflistung Ihres Modells.

## FAQKann ich von Solar zur Originalsoftware zurückkehren?

Verwenden Sie Y1 Originalsoftware in Updater CE. Sie müssen Solar nicht zuerst manuell entfernen. Folgen Sie dem [Y1 Wiederherstellungsschritte](original-software-y1_de.html).Kann ich den Eintrag Solar Y2 auf diesem Player installieren?

Nein. Lassen Sie den Y1-Player auf dem Y1-Eintrag und überprüfen Sie das Modell vor der Installation.Wo kann ich die aktuellen Solar-Funktionen überprüfen?

Lesen Sie die [Versionshinweise](release_notes_de.html?software=solar-y1) bevor Sie sich für eine Veröffentlichung entscheiden.
