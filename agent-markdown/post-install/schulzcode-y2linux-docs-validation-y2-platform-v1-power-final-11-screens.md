## Change

Reborn: computer connection/copying screens, Bluetooth pairing progress and failure dialog, update-download and scanning spinners, battery-low dialog, SD removed and songs-added toasts, crossfade icon, charging-screen art (docs: Y2Reborn `docs/ui/REBORN-PRODUCT-UI-V3.md`). Linux: `tools/production/offline-charge.c` redraws its display from `tools/graphics/offline-charge-art.h` (generated by `make-charge-art.py` from Reborn's layout) plus a procedural sweeping ring; decision logic, gates and writes unchanged. ## Tests

Locked-container production suite PASS, 632 cases (two new charger-frame tests render real frames into a memory framebuffer: sweep, full and paused ring, text, bounds); 29 packaging-host and 27 splash PASS; package, ELF closure, installed-ARM, inventory and privacy PASS. Reborn: fmt, strict Clippy, 362 workspace tests PASS (new: computer screen, low-battery dialog, Bluetooth progress/failure, spinners, crossfade icon, charging copy); all 73 preview frames render identically through the production GL code on a host GLES2 and the Python rasteriser.
