# Navigation model
  - Wheel clockwise: next / increase
  - Wheel counter-clockwise: previous / decrease
  - Confirm: open / toggle / accept
  - Back: previous screen
  - Menu: context menu
  - Play/Pause: global transport
  - Previous/Next: track change
  - Volume: global volume adjustment

No swipes, drag gestures, hidden touch affordances, or hover states. Focus is persistent and always visible.

These are Y2Reborn's own instructions, shown here word for word.
