# Y2Linux complete document catalog

Updated 2026-10-04 for the installed Platform 1.0 baseline. Every project-owned Markdown page in this repository is listed once; vendored upstream package documentation is excluded. Platform 1.0 Baseline01 is software-sealed and installed; its smoke/CPU campaign was interrupted by an owner restart during the USB-off prerequisite wait; USB diagnosis is pending. UART01 retains complete bounded CPU-idle proof and the fallback reference. Historical Baseline02 RTC wake failure remains open. Start with the current-state page; a historical report records its own build/session, not the presently installed image. Raw hardware and build evidence is preserved unchanged. The catalogs document links, rather than relocating or deleting proof. See the [shared knowledge rules](https://innioasis.app/post_install.html?url=https%3A%2F%2Fgithub.com%2Fschulzcode%2Fy2linux%2Fblob%2FHEAD%2Fdocs%2FKNOWLEDGE_BASE.md) and the other repository's catalog for product-wide context.
