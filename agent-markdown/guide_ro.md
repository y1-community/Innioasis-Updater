# Noțiuni introductive cu Innioasis Updater CE

Funcționează cu toate playerele audio Innioasis și Timmkoo. Instalați Innioasis Updater CE pe computer, alegeți modelul și software-ul dorit, apoi urmați instrucțiunile.

## 

[Obține Updater CE](guide_ro.html#download-updater)[Tutorial scris complet](guide_ro.html)

## Obțineți Innioasis Updater CE

Innioasis Updater CE este aplicația care instalează actualizări oficiale și software comunitar pe playerul tău. Îți păstrează muzica și setările și rulează pe Windows, macOS și Linux.

### Windows

Descărcați programul de instalare, rulați-l, apoi reporniți computerul când se termină.[Obțineți șoferi](https://github.com/y1-community/supplemental-apks/releases/latest/download/DriverInstall.exe)[Descărcați Updater CE](https://github.com/y1-community/Innioasis-Updater/releases/latest/download/installer.exe)

Dacă Windows vă împiedică să rulați aplicația sau nu o lansează, deschideți Setări, faceți clic pe Confidențialitate și securitate → Securitate Windows → Control aplicație și browser și dezactivați Controlul aplicației inteligente. Smart App Control afectează în prezent aplicațiile populare, cum ar fi Epic Overlay Service (utilizat de Fortnite) - Updater CE este sigur și verificat pentru utilizare. [Windows nu va lansa aplicația? Ajutor](#smart-app-control)

Reporniți computerul după instalare. Ajutorul șoferului este în [Note de instalare Windows](drivers_ro.html#windows).

### macOS[Descărcați Updater CE](https://github.com/y1-community/Innioasis-Updater/releases/latest/download/Innioasis.Updater.for.Mac.dmg)

Dacă Mac-ul dvs. vă oprește să rulați aplicația pentru prima dată, deschideți Setări sistem, faceți clic pe Confidențialitate și securitate, derulați în jos la Securitate și faceți clic pe [Deschide oricum](https://support.apple.com/en-gb/102445#openanyway). Puteți, de asemenea, să faceți Control-clic (sau să faceți clic dreapta) pe aplicație în Finder și să alegeți Deschidere.

Funcționează pe Intel și Apple Silicon Mac cu macOS Monterey și mai târziu.

### Linux

Descărcați AppImage pentru sistemele Intel și AMD, faceți-l executabil și rulați-l.[Descărcați AppImage pentru Intel/AMD](https://github.com/y1-community/innioasis-updater/releases/latest/download/UpdaterCE.AppImage)

[Note de configurare Linux](drivers_ro.html#linux)O altă platformă?

Aveți nevoie de playerul dvs., de un cablu de date USB care transportă date (un cablu de încărcare nu poate fi instalat) și de câteva minute. Țineți cablul conectat până când Updater CE spune că s-a terminat.

## Alegeți modelul și software-ul dvs
  - Model de dispozitiv: alege modelul imprimat pe player, Y1 sau Y2. Software-ul creat pentru un model nu poate fi instalat pe celălalt.
  - Software și lansare: alegeți Software original, Rockbox, Solar, JJ Launcher, Inniclassic, Y2Player sau Koensayr când este listat pentru modelul dvs., apoi alegeți o versiune. Stabil este alegerea sigură.
  - Instalați: faceți clic Instalează / Restaurează, opriți complet playerul și conectați cablul USB numai când Updater CE vă solicită.
  - Terminare: lăsați playerul și cablul în pace până la mesajul de succes, apoi deconectați și porniți playerul.

Y1 jucători care au fost livrate cu software-ul original înainte de 2.0.0 au nevoie Dispozitiv Type B. Toți ceilalți păstrează valoarea implicită Type A.Instrucțiuni de conectare pentru actualizator pentru conectarea unui player opritUrmați promptul Live Updater CE pentru modelul dvs.

## Revenind la software-ul original

Software-ul personalizat este reversibil. În Updater CE, alegeți modelul dvs., selectați Software original, alegeți o versiune stabilă, apoi rulați Instalează / Restaurează la fel. Nu există nimic de șters manual.[Ghid de restaurare Y1](guides/restore-original-y1.html)[Ghid de restaurare Y2](guides/restore-original-y2.html)

Dacă blițul se oprește înainte de promptul USB, verificați mai întâi cablul, configurarea platformei și modelul. Vezi [depanare](troubleshooting_ro.html) pentru remedieri, the [Y1 și Y2 ghid de recuperare](guides/recovery.html) pentru defecte de putere și roți și [SP Flash Tool](sp-flash-tool_ro.html) pentru recuperare avansată.

## Windows nu va lansa aplicația? Soluție pentru controlul aplicațiilor inteligente

Windows Defender SmartScreen sau Smart App Control pot bloca aplicațiile comunitare recent descărcate înainte ca reputația semnăturii să se propage. Smart App Control afectează în prezent aplicațiile populare, cum ar fi Epic Overlay Service (utilizat de Fortnite) - Updater CE este sigur și verificat pentru utilizare. Dezactivarea Smart App Control permite ca Updater CE să se deschidă și să ruleze normal.
  - Deschide Setări pe computerul dvs. cu Windows (apăsați Win + I).
  - Faceți clic Confidențialitate și securitate în bara laterală din stânga, apoi faceți clic Windows Security.
  - Faceți clic Controlul aplicației și browserului.
  - Sub Control inteligent al aplicației, faceți clic Setări Smart App Control.
  - Setați comutatorul la Oprit pentru a permite lansarea Updater CE.

Descărcat prin Edge? Dacă Edge blochează descărcarea în sine, faceți clic pe butonul Mai multe opțiuni (…) → Păstrează → Arată mai multe → Păstrați oricum.

Reactivarea Smart App Control mai târziu: Când doriți să reactivați Smart App Control, îl puteți reactiva prin Registrul Windows de sub `HKEY_LOCAL_MACHINE\SYSTEM\CurrentControlSet\Control\CI\Policy` prin setare `VerifiedAndReputablePolicyState` la `1` (Activat) sau `2` (Mod de evaluare) și repornire.
