## Rockbox Y2 install steps
  - Buka Innioasis Updater CE pada komputer anda (jika anda memerlukan apl itu, [Dapatkan Updater CE](guide_ms.html#platform)). Tetapkan Model Peranti kepada Y2.
  - pilih Rockbox dalam Perisian.
  - Choose a release explicitly listed for Y2.
  - klik Pasang / Pulihkan and wait for package preparation.
  - Matikan dan sambungkan Y2 hanya apabila Updater CE bertanya.

Do not force a Y1 package because the project name looks the same. If no Y2 release appears, stop and check the model and current release data.
