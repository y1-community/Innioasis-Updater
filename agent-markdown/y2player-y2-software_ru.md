# Установите Y2Player на Y2.

Y2Player создан для Y2. Сначала выберите свою модель, чтобы случайно не использовать пакет Y1.[Открыть полное руководство Y2Player](guides/y2player-y2.html)[Получите это в Updater CE](guide_ru.html?model=Y2&software=y2player-y2)[Почему Y2Player?](y2player-benefits_ru.html)

Руководство по установке для вашего компьютера

## Установите Y2Player на свой Y2 с помощью компьютера.

Выберите руководство для компьютера, который вы используете. В каждой версии есть настройка платформы, Updater CE шагов и возврат к стоку.[Руководство по Windows](install/y2player-y2-windows.html)[руководство по macOS](install/y2player-y2-mac.html)[Руководство по Linux](install/y2player-y2-linux.html)

[Все Innioasis Y2 руководства](install/y2.html) · [Все Y2Player руководства](install/y2player.html)

## Y2Player шаги установки
  - Откройте Innioasis Updater CE на своем компьютере (если вам нужно приложение, [Скачать Updater CE](guide_ru.html#platform)). Набор Модель устройства в адрес Y2.
  - Выбирать Y2Player в Программное обеспечение.
  - Выберите выпуск, указанный для Y2.
  - Нажмите Установить / Восстановить.
  - Выключите питание и подключите Y2 в командной строке.

Некоторые Y2 пакеты полной установки используют `rom_y2.zip`. По возможности позвольте программе обновлений выбрать пакет.

## Вопросы и ответыМогу ли я вернуться к исходному программному обеспечению?

Да. Выберите Y2 и оригинальное программное обеспечение в Updater CE, затем следуйте инструкциям. [Y2 руководство по восстановлению](original-software-y2_ru.html).Могу ли я использовать это на Y1?

Нет. Эта страница предназначена для записи Y2Player Y2. Пакеты Y1 и Y2 храните отдельно.Что делать, если Y2 не обнаружен?

Проверьте настройку платформы, кабель, состояние отключения питания, выбор модели и время. Использовать [Поиск неисправностей](troubleshooting_ru.html) прежде чем пытаться восстановить вручную.
