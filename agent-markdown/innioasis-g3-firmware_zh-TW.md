## 使用更新程式 CE 刷新您的播放器

若要恢復您的 G3 或 G1 播放器：
  - 打開 Innioasis 更新程式 CE 在您的桌上型電腦或筆記型電腦上。
  - 選擇 G3 或 G1 從設備型號選單。
  - 選擇 原廠軟體 更新程式將獲取正確的檔案： `rom_g3.zip` 或 `rom_g1.zip`.
  - 請依照連線提示將播放器連接到 USB 並完成刷機。
