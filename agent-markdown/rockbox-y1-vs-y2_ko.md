# Rockbox-Y1 대 Rockbox-Y2

Rockbox-Y1 및 Rockbox-Y2은 서로 다른 플레이어용으로 생성된 별도의 펌웨어 빌드입니다. 항상 플레이어에 인쇄된 모델과 빌드를 일치시키십시오.[Rockbox-Y1 설치](rockbox-y1/install.html)[Rockbox-Y2 설치](rockbox-y2/install.html)[ROM 둘 다 다운로드](rockbox-rom-download_ko.html)

## 모델을 먼저 선택하는 것이 중요한 이유

두 빌드 모두 Rockbox을 실행하지만 Innioasis Y1과 Y2의 하드웨어 및 파티션 레이아웃은 다릅니다. Y2의 Y1 ROM 또는 Y1의 Y2 ROM을 깜박이지 마십시오.

Innioasis 업데이터 CE는 선택하자마자 사용 가능한 소프트웨어를 필터링하여 불일치를 방지합니다. Y1 또는 Y2 안으로 기기 모델. Updater CE는 항상 커뮤니티 펌웨어 개발자 릴리스에서 직접 선택한 패키지를 다운로드합니다(개발자는 Updater CE에 릴리스를 나열할 전적인 책임을 집니다).

## 어떤 가이드가 필요하세요?
  - Innioasis Y1 — 로 이동 [Rockbox-Y1 허브](rockbox-y1/). Type A(2.0.0+와 함께 출시된 플레이어의 경우) 또는 Type B(이전 장치의 경우)을 선택한 다음 240p 또는 360p 빌드를 선택합니다.
  - Innioasis Y2 — 로 이동 [Rockbox-Y2 허브](rockbox-y2/). Updater CE에서 Y2을 선택하고 최신 Y2 릴리스를 선택합니다.

## 두 포트가 공유하는 것

둘 다 Rockbox의 태그 기반 음악 데이터베이스, 끊김 없는 재생, 이퀄라이저, 사용자 정의 테마 및 플레이어에서 100% 오프라인 청취를 제공합니다. 읽다 [왜 Rockbox](rockbox-benefits_ko.html) Rockbox이 공장 소프트웨어에 무엇을 추가하는지 확인하세요.[Y1의 경우 Rockbox](rockbox-for-y1_ko.html)[Y2의 경우 Rockbox](rockbox-for-y2_ko.html)[Rockbox 개요](rockbox_ko.html)
