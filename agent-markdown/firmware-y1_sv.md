# Firmware för Innioasis Y1

Y1 har det bredaste urvalet av anpassade system. Allt nedan finns här, kontrolleras och installeras med ett klick med Updater CE.[Bläddra Y1 Nedladdningar](firmware_sv.html?model=Y1)[Hämta Updater CE](guide_sv.html#platform)[Temagalleri](https://themes.innioasis.app/?lang=sv)

## Tillgängliga operativsystem för Innioasis Y1

Y1 kör flera mjukvarusystem, inklusive builds med audiofil codec-stöd, moderna startprogram och en fabriksåterställning. Välj den som passar hur du lyssnar:

### [Rockbox](rockbox-benefits_sv.html)

Guldstandarden för ljuduppspelning med öppen källkod. Parametrisk EQ, gapfri FLAC/MP3-uppspelning, teman och teckensnittspaket kan installeras direkt i Updater CE.[Y1 Rockbox Guide →](guides/rockbox-y1.html)

### [Better-Y](better-y-benefits_sv.html)

En förbättrad derivata av den ursprungliga firmware med Bluetooth-stabilitetskorrigeringar, volymkurvor och 100 % temagallerikompatibilitet.[Better-Y Guide →](guides/better-y-y1.html)

### [Solar](solar-benefits_sv.html)

En modern musikspelare med öppen källkod byggd med Flutter, som erbjuder smidiga 60fps-animationer, skivomslagsrutnät och modern typografi.[Solar Y1 Guide →](guides/solar-y1.html)

### [Rondo](rondo-benefits_sv.html)

Ett startprogram med öppen källkod Y1 för lokala spår och streaming, med snabb, lyhörd navigering.[Rondo Y1 Guide →](guides/rondo-y1.html)

### [Koensayr](koensayr-benefits.html)

En anpassad firmware-konstruktion med sin egen ikonografi, bättre batterikalibrering och stöd för lagertema.[Koensayr Guide →](guides/koensayr-y1.html)

### [Originalprogramvara (Stock Restore)](original-software-benefits_sv.html)

Rengör fabriksfirmwarebilder för Type A (v2.0.0+) och Type B (v1.x) Y1 spelare. Ta bort klossar på ett säkert sätt eller återställ din enhet till fabriksstatus.[Återställ Y1 Guide →](guides/restore-original-y1.html)

## Hur man installerar eller uppdaterar Y1 Firmware

Att uppgradera eller ta bort klossar på din Innioasis Y1 är enkelt med vår programsvit för flera plattformar:
  - Öppna Innioasis Updater CE: Starta uppdateringsprogrammet på macOS, Windows eller Linux.
  - Välj modell Y1: Välj Y1 i rullgardinsmenyn Enhetsmodell.
  - Välj ditt operativsystem: Välj Rockbox, Better-Y, Solar eller originalprogramvara.
  - Klicka på Installera: Updater CE laddar ner firmwarepaketet direkt från utvecklarens utgåva. När du uppmanas, anslut din avstängda Y1 via USB för att börja blinka.
