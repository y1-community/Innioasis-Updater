# Install Linux on the Y1.

Linux for Y1 is an experimental community Linux kernel and rootfs port for the Innioasis Y1 hardware. This page links to the full installation guide and releases.[Open the full Linux for Y1 (Dev) guide](guides/linux-y1.html)[Get this in Updater CE](guide.html?model=Y1&software=linux-y1)[Project source](https://github.com/y1-community/y1-linux-rom)

## Linux Y1 install steps
  - Open Innioasis Updater CE on your computer (if you need the app, [Get Updater CE](guide.html#platform)). Set Device Model to Y1.
  - Choose Linux for Y1 (Dev) in Software.
  - Choose the release listed for Y1.
  - Click Install / Restore.
  - Power off and connect the Y1 only when Updater CE asks.
