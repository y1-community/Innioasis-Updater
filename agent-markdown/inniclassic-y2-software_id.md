# Instal Inniclassic pada Y2.

Inniclassic tersedia untuk Innioasis Y2, dan proyek yang sama juga membuat paket Y1. Halaman ini memberi Anda ikhtisar Y2 dan tautan ke tutorial lengkap.[Buka panduan lengkap Inniclassic](guides/inniclassic-y2.html)[Dapatkan ini di Updater CE](guide_id.html?model=Y2&software=inniclassic-y2)[Mengapa Inniclassic?](inniclassic-benefits_id.html)

## Instal Inniclassic pada Y2 Anda dengan komputer Anda

Pilih panduan untuk komputer yang Anda gunakan. Setiap versi memiliki pengaturan platform, Updater CE langkah-langkahnya, dan cara kembali ke stok.[Panduan Windows](install/inniclassic-y2-windows.html)[panduan macOS](install/inniclassic-y2-mac.html)[Panduan Linux](install/inniclassic-y2-linux.html)

[Semua Innioasis panduan Y2](install/y2.html) · [Semua panduan Inniclassic](install/inniclassic.html)

## Inniclassic Y2 langkah-langkah pemasangan
  - Buka Innioasis Updater CE di komputer Anda (jika Anda memerlukan aplikasinya, [Dapatkan Updater CE](guide_id.html#platform)). Tetapkan Model perangkat untuk Y2.
  - Pilih Inniclassic di Perangkat lunak.
  - Pilih rilis yang terdaftar untuk Y2.
  - Klik Pasang / Pulihkan.
  - Matikan dan sambungkan Y2 hanya ketika Updater CE diminta.

## Pertanyaan umumDapatkah saya memulihkan perangkat lunak stok Y2?

Ya. Pilih Y2 dan Perangkat Lunak Asli di Updater CE. Itu [Y2 panduan perangkat lunak stok](original-software-y2_id.html) meliputi jalur pulang.Bisakah saya menggunakan Inniclassic pada Y1?

Ya. Proyek yang sama juga menerbitkan paket Y1 — rom.zip untuk Type A dan rom_type_b.zip untuk Type B. Pilih Y1 di Updater CE dan instal build Y1; itu [Halaman pemasangan Y1](inniclassic-y1-software_id.html) menutupinya.Bagaimana jika instalasi gagal?

Catat apakah Updater gagal sebelum atau setelah mendeteksi Y2, lalu periksa kabel, pengaturan platform, model, dan waktu koneksi di [pemecahan masalah](troubleshooting_id.html).
