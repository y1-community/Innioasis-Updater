## Rockbox Y2 étapes d'installation
  - Ouvrez Innioasis Updater CE sur votre ordinateur (si vous avez besoin de l'application, [Obtenir Updater CE](guide_fr.html#platform)). Ensemble Modèle d'appareil à Y2.
  - Choisissez Rockbox dans Logiciel.
  - Choisissez une version explicitement répertoriée pour Y2.
  - Cliquez Installer / Restaurer et attendez la préparation du colis.
  - Éteignez et connectez le Y2 uniquement lorsque Updater CE le demande.

Ne forcez pas un package Y1 car le nom du projet est identique. Si aucune version Y2 n'apparaît, arrêtez et vérifiez les données du modèle et de la version actuelle.

## FAQPuis-je restaurer le logiciel Y2 d'origine ultérieurement ?

Oui. Choisissez Y2 et Logiciel original dans Updater CE. Voir le [Y2 page de stock de logiciels](original-software-y2_fr.html) pour la séquence de restauration.Pourquoi le package pourrait-il s'appeler rom_y2.zip ?

Il s'agit d'un indice de téléchargement manuel utilisé par certaines versions d'installation complète de Y2. Le choix le plus sûr consiste toujours à sélectionner Y2 dans Updater CE et à utiliser la version qu'il présente.Puis-je utiliser le didacticiel Y1 Rockbox ?

Utilisez-le uniquement pour une idée générale. Pour la sélection du package et du modèle, suivez ceci [Guide spécifique à Y2](guides/rockbox-y2.html).
