# 為什麼 Better-Y 適合您的 Innioasis Y1

Better-Y 是库存播放器，经过改进。由 Leska1337 在官方 3.1.2 软件上构建。它修復了標籤、曲目編號、快取和播放控件，並保留了熟悉的外觀、滾輪和主題。[在更新程式中取得 Better-Y](firmware_zh-TW.html?model=Y1&software=better-y-y1)[Y1安裝頁面](better-y-y1-software_zh-TW.html)[完整的Y1教程](guides/better-y-y1.html)[專案來源](https://github.com/Leska1337/better-Y)

## 型號可用性

哪些 Innioasis 型號運行它？[Y1 (Type A) · 可用](better-y-y1-software_zh-TW.html)Y2 · 不可用

Better-Y 是為 Innioasis Y1（Type A 硬體）製作的。 Y1 和 Y2 版本是分開的，因此請勿將其中一個交換為另一個。

## 為什麼人們選擇它

庫存的一切都是你喜歡的，沒有任何怪癖。
  - 追蹤號碼所屬的位置 — 專輯視圖最終會顯示曲目編號，以便您的專輯按照預期的曲目清單順序播放和顯示，而不是任意排序。
  - 智慧標籤分割 — 多藝人歌曲（以逗號或分號分隔）出現在每位藝人的下方。多流派標籤（以逗號、分號或正斜線分隔）出現在每個匹配流派下。
  - 檔案名稱上的 ID3 元數據 — 歌曲標題、專輯和藝術家可以從 ID3 標籤中正確讀取，而不是顯示原始檔案名稱。
  - 正在播放互動式控件 — 直接在螢幕上顯示收藏夾（心形）、隨機播放切換、重複模式（一個/全部/關閉）、歌詞、A-B 重複循環、播放佇列、書籤位置、速度控制和睡眠定時器的圖示。
  - 流暢、無閃爍的 RAM 緩存 — 完全重新設計的圖像快取引擎消除了滾動瀏覽大型音樂庫時的 UI 閃爍、閃爍和延遲。
  - 官方3.1.2基礎 — 基於最新的 3.1.2 基礎構建，保留官方 Apple AirPods 連接修復，同時保留與所有自訂庫存主題 100% 的兼容性。

  - 外部封面藝術支援（自動偵測 `cover.jpg`, `cover.png`, `folder.jpg`)
  - 多光碟版本的光碟編號顯​​示（CD 1、CD 2、乙烯基面）
  - 互動式正在播放圖示（收藏夾、隨機播放、重複、歌詞、A-B 循環、佇列、書籤、速度、睡眠計時器）

  - 按字母順序快速滾動索引欄，用於大型圖書館中的快速輪式導航
  - 選擇遊標自動記住並跟隨目前播放的曲目
  - 藝術家視圖首先顯示專輯，而不是將所有歌曲轉儲到平面列表中
