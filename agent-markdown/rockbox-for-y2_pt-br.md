# Rockbox para Y2 (Rockbox-Y2)

Rockbox-Y2 (também chamado de “Rockbox para Y2”) é a porta de firmware da comunidade Rockbox dedicada para Innioasis Y2. Ele usa seu próprio pacote ROM (`rom_y2.zip`) e é instalado diretamente por meio de Innioasis Updater CE.[Instalar Rockbox-Y2](rockbox-y2/install.html)[Baixe o ROM](rockbox-y2/download.html)[Tutorial escrito](guides/rockbox-y2.html)[Hub Rockbox-Y2](rockbox-y2/)

## Construído especificamente para o Innioasis Y2

Em Innioasis Updater CE, este firmware está listado como Rockbox quando Y2 está selecionado. Seus lançamentos são publicados pela [spycemagic/y2-rockbox](firmware_pt-BR.html?model=Y2&software=rockbox-y2) projeto com o nome do pacote `rom_y2.zip`.

Nunca instale um pacote de firmware Y1 em um Y2. Selecionando Y2 em Updater CE filtra automaticamente a lista de lançamentos apenas para compilações compatíveis com Y2.

## O que Rockbox-Y2 oferece
  - Biblioteca de música baseada em tags — navegue por álbuns, artistas e gêneros a partir de suas tags de arquivos de áudio ou navegue diretamente pelas pastas.
  - Controles de reprodução - configurações de reprodução contínua, crossfade, ReplayGain e equalizador.
  - Temas personalizados — instale temas compatíveis com sua compilação Rockbox-Y2 ([Y2 guia temático](rockbox-y2-themes.html)).
  - 100% off-line — reproduz arquivos locais do seu cartão MicroSD sem contas ou assinaturas.
  - Fácil restauração de fábrica — retornar ao Y2 Software Original a qualquer momento em Updater CE.

## Escolhendo uma versão Rockbox-Y2
  - Sempre selecione Y2 em Modelo do aparelho primeiro.
  - Escolha a versão mais recente, a menos que esteja testando uma versão específica.
  - Leia o [Rockbox-Y2 notas de lançamento](release-notes/rockbox-y2/index_pt-BR.html) para ver o que mudou em cada compilação.

## Downloads diretos dos desenvolvedores da comunidade

Innioasis Updater CE sempre baixa pacotes de firmware diretamente dos desenvolvedores de firmware da comunidade ([spycemagic/y2-rockbox](firmware_pt-BR.html?model=Y2&software=rockbox-y2)), e esses desenvolvedores são os únicos responsáveis ​​por listar suas versões de software em Updater CE.

Você pode deixar Updater CE baixar e atualizar `rom_y2.zip` automaticamente ou baixe o pacote em nosso [Rockbox-Y2 página de downloads](rockbox-y2/download.html) e [Rockbox ROM página de download](rockbox-rom-download_pt-BR.html).[Rockbox-Y2 downloads](rockbox-y2/download.html)[Instalar a partir de um ZIP local](rockbox-y2/portable-zip.html)

## Como instalar Rockbox-Y2
  - Abra Innioasis Updater CE e defina Modelo do aparelho para Y2.
  - Selecione Rockbox em Software.
  - Escolha um lançamento Y2 da lista.
  - Clique Instalar / Restaurar então Updater CE baixa o pacote diretamente do desenvolvedor.
  - Desligue o Y2 completamente e conecte-o com um cabo de dados USB quando Updater CE solicitar.
  - Aguarde a mensagem de conclusão, desconecte e ligue o Y2.

Para obter o passo a passo completo, leia o [Rockbox-Y2 tutorial](guides/rockbox-y2.html).

## Restaurando o software Y2 original

Para voltar ao firmware de fábrica, selecione Y2 e Software original em Updater CE, escolha uma versão estável e clique Instalar / Restaurar. Veja o [guia de restauração](rockbox-y2/restore-stock.html) e [Y2 Página do software original](original-software-y2_pt-BR.html).

## Perguntas frequentesDe onde Updater CE baixa Rockbox-Y2?

Updater CE sempre baixa pacotes de firmware diretamente dos próprios lançamentos dos desenvolvedores de firmware da comunidade (`spycemagic/y2-rockbox`). Os desenvolvedores são os únicos responsáveis ​​por listar seus lançamentos de software em Updater CE.Por que o pacote é chamado rom_y2.zip?

O desenvolvedor nomeia o arquivo de firmware Y2 `rom_y2.zip` então não pode ser confundido com o Y1 `rom.zip`.Os temas Y1 funcionam no Y2?

Nem sempre. Verifique as notas de lançamento da sua compilação Y2 e veja o [Rockbox-Y2 guia temático](rockbox-y2-themes.html).
