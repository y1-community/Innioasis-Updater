# Innioasis 업데이터 문제 해결 | Innioasis 및 Timmkoo 설치 문제 - Innioasis 업데이터

문제 해결

# 설치가 중지된 지점을 찾으세요.

어디서 멈췄나요? 수정해야 할 부분을 알려줍니다.[일반 가이드로 돌아가기](guide_ko.html)[펌웨어 확인](firmware_ko.html)

## USB 프롬프트 전에 중지되었습니다.

케이블 문제가 아니라 컴퓨터 문제입니다. 모델을 확인하세요. 파일의 압축을 다시 풀어보세요. 그럼 시도해 보세요 설치 / 복원. 릴리스 목록이 비어 있으면 [펌웨어 디렉토리](firmware_ko.html).

## 플레이어에 연결할 수 없습니다
  - 올바른 Y1 또는 Y2의 전원을 완전히 끕니다.
  - 케이블을 분리하고 다른 플래시 또는 Android 도구를 닫은 후 설치를 다시 시작하세요.
  - 업데이터가 준비되었다고 말할 때만 연결하십시오.
  - 가능하면 허브가 아닌 짧은 USB 데이터 케이블을 컴퓨터에 직접 사용하십시오.
  - Windows에서는 MediaTek 드라이버를 다시 설치하고 다시 시작하세요. Linux에서는 USB/serial 권한을 확인하세요.
업데이터 연결 프롬프트라이브 업데이터 프롬프트는 현재 모델 및 플랫폼에 대해 신뢰할 수 있습니다.

## 플레이어를 감지했지만 플래시가 실패했습니다.

여기서 멈춰라. 다른 모델을 시도하지 마십시오. 다른 도구를 닫고 올바른 Y1 또는 Y2을 선택했는지 확인하고 플레이어가 시작되지 않으면 일치하는 원본 소프트웨어를 사용하십시오. [SP Flash Tool](sp-flash-tool_ko.html) 필요한 경우 및 MTKClient이 포함되며 파일은 다음 위치에 있습니다. [펌웨어 페이지](firmware_ko.html).

## Windows 드라이버 참고사항

일부 Windows 설치에서는 코어 격리로 인해 MediaTek 드라이버를 차단합니다. 메모리 무결성을 변경하기 전에 현재 Windows 보안 지침을 따르고, 시스템에서 허용하는 경우 완료한 후 다시 켜십시오.[드라이버 가이드 열기](drivers_ko.html)[클린 설치 가이드](Troubleshooting/clean_install.html)

## 휠이 작동하지 않거나 플레이어가 시작되지 않습니다

입력 및 전원 오류는 실패한 플래시와 다른 단계가 필요합니다. 이 가이드에서는 일반적인 Y1 및 Y2 사례를 다룹니다.[Y1 스크롤 휠](guides/y1-scroll-wheel-not-working.html)[Y2 스크롤 휠](guides/y2-scroll-wheel-not-working.html)[Y1이 켜지지 않습니다](guides/y1-wont-turn-on.html)[Y2가 켜지지 않습니다](guides/y2-wont-turn-on.html)[복구 가이드](guides/recovery.html)
