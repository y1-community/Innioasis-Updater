## Installationsschritte für Android 4.4 Y2.
  - Öffnen Sie Innioasis Updater CE auf Ihrem Computer (wenn Sie die App benötigen, [Updater CE holen](guide_de.html#platform)). Satz Gerätemodell an Y2.
  - Wählen Sie Android 4.4 (Entwickler) In Software.
  - Wählen Sie die für Y2 aufgeführte Version aus.
  - Klicken Sie Installieren / Wiederherstellen.
  - Schalten Sie das Y2 nur aus und schließen Sie es an, wenn Updater CE dazu fragt.

## FAQKann ich die Standardsoftware Y2 wiederherstellen?

Ja. Wählen Sie Y2 und Originalsoftware in Updater CE. Der [Y2 Stock-Software-Leitfaden](original-software-y2_de.html) deckt den Rückweg ab.Ist das ein Daily Driver ROM?

Dies ist ein experimenteller Entwickler ROM, der für Tests und Entwicklung gedacht ist. Release-Updates finden Sie auf der Projektseite.
