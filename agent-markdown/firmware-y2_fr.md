# Micrologiciel pour Innioasis Y2

Le Y2 dispose d'un meilleur matériel audio, du Bluetooth et d'un gestionnaire de fichiers. Choisissez un système personnalisé, une version Linux ou le logiciel officiel à restaurer.[Parcourir Y2 Téléchargements](firmware_fr.html?model=Y2)[Obtenir Updater CE](guide_fr.html#platform)[Y2 Guide des thèmes](https://themes.innioasis.app/y2-themes.html?lang=fr)

## Systèmes d'exploitation disponibles pour Innioasis Y2

Choisissez ce que vous souhaitez exécuter sur votre Y2 :

### [Reborn (Y2Linux)](reborn-y2linux-benefits_fr.html)

Système d'exploitation Linux embarqué natif combinant Buildroot, LVGL, PipeWire et MPD. Offre des temps de démarrage de 3 secondes, de véritables correctifs de reconnexion des écouteurs Bluetooth et une lecture sans interruption.[Y2Reborn Guider →](guides/reborn-y2linux-y2.html)

### [Rockbox pour l'an 2](rockbox-benefits_fr.html)

Le micrologiciel audiophile ultime porté sur le Innioasis Y2. Égalisation paramétrique, polices personnalisées, flux croisés et prise en charge étendue de la bibliothèque de plugins.[Y2 Rockbox Guider →](guides/rockbox-y2.html)

### [Solar pour Y2](solar-benefits_fr.html)

Interface de lecteur de musique moderne et fluide basée sur Flutter pour le Y2. Comprend des visualiseurs riches, une grande présentation de pochettes d'album et une navigation gestuelle.[Solar Y2 Guider →](guides/solar-y2.html)

### [Y2Player](y2player-benefits_fr.html)

Lecteur audio communautaire léger conçu pour le matériel Y2 avec une navigation simple dans les dossiers et une analyse rapide des index.[Y2Player Guider →](guides/y2player-y2.html)

### [Logiciel original (restauration d'usine)](original-software-benefits_fr.html)

Image officielle du micrologiciel d'origine (rom_y2.zip) pour restaurer un Innioasis Y2 à son état d'usine d'origine, avec prise en charge du skin Themes Gallery.[Restaurer Y2 Guide →](guides/restore-original-y2.html)

## Installation du micrologiciel sur votre Innioasis Y2

Updater CE récupère les bons fichiers et vérifie le pilote avant de flasher :
  - Lancer Innioasis Updater CE : Disponible nativement sur macOS, Linux et Windows.
  - Modèle de jeu : Sélectionnez Y2 dans le menu Modèle d'appareil.
  - Choisissez le système d'exploitation : Choisissez Reborn, Rockbox, Solar ou Logiciel d'origine.
  - Flashez en toute sécurité : Suivez les invites à l'écran pour connecter votre appareil via USB pour un flash propre et vérifié.
