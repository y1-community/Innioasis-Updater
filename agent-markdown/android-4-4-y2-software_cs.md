# Install Android 4.4 (Dev) on the Y2.

Android 4.4 is a community development ROM for testing and hacking on Innioasis Y2 hardware. This page links to the full tutorial and release list.[Open the full Android 4.4 (Dev) guide](guides/android-4-4-y2.html)[Získejte to v Updater CE](guide_cs.html?model=Y2&software=android-4-4-y2)[Zdroj projektu](https://github.com/y1-community/y2-ata-rom)

## Install Android development ROM on your Y2 with your computer

Vyberte průvodce pro počítač, který používáte. Každá verze má nastavení platformy, Updater CE kroky a cestu zpět na sklad.[Průvodce Windows](install/android-4-4-y2-windows.html)[průvodce macOS](install/android-4-4-y2-mac.html)[Linux průvodce](install/android-4-4-y2-linux.html)

## Android 4.4 Y2 install steps
  - Otevřete Innioasis Updater CE na svém počítači (pokud potřebujete aplikaci, [Získat Updater CE](guide_cs.html#platform)). Soubor Model zařízení do Y2.
  - Vyberte si Android 4.4 (Dev) v Software.
  - Choose the release listed for Y2.
  - Klikněte Nainstalovat / Obnovit.
  - Vypněte a připojte Y2 pouze tehdy, když se zeptá Updater CE.
