# 為什麼 Rockbox 適合您的 Innioasis

Rockbox 將您的播放器變成一個合適的音樂庫。無縫播放、均衡器和深度主題庫。當您需要時，它仍然會啟動回原始軟體。[在更新程式 CE 中取得 Rockbox](guide_zh-TW.html?model=Y1&software=rockbox-y1)[Y1安裝頁面](rockbox-y1-software_zh-TW.html)[Y2安裝頁面](rockbox-y2-software_zh-TW.html)

## 為什麼人們選擇它

圖書館成為重點。
  - 停止按檔案名稱滾動 — Rockbox 讀取音樂上的標籤，並按照真正的圖書館的方式按專輯、藝術家和流派進行排序。大集合不再感覺像資料夾轉儲。
  - 無間隙、交叉淡入淡出、EQ — 歌曲毫無間隙地相互流動，完整的均衡器讓您無需離開播放器即可調整聲音。
  - 適合各種口味的主題 — 從乾淨簡約的外觀到 iPod 風格的介面，主題庫非常龐大 — 並且 Y1 社群建立使用 360p 相容性標籤來幫助您選擇。
  - 帶庫存的雙啟動 — 隨時從 Rockbox 選單重新啟動回原始軟體。這是一個敞開著門的實驗。
  - 播客和亂寫 — 此分支新增了透過內建 Wi-Fi 和 Last.fm / ListenBrainz / Maloja scrobbling 進行播客下載的功能，因此您的聆聽歷史記錄始終屬於您。
  - 離線設計 — Rockbox 在本機檔案上執行。沒有帳戶，沒有訂閱，沒有串流媒體依賴——許多社區成員說這幫助他們退出了訂閱跑步機。

## 該項目提供什麼
  - 基於標籤的資料庫：專輯和藝術家按標籤排序，而不是檔案名
  - 無縫播放、交叉淡入淡出和內建等化器
  - 深層主題庫，包括 iPod 風格的介面； Y1 版本帶有 360p 相容性標籤
  - 具有重啟快捷方式的 iPod 6G 風格控制項（按住「下一個」+「上一個」10 秒）
  - Rockbox 內的 FM 收音機應用程式
  - 使用內建 Wi-Fi 晶片的播客下載插件
  - 搜尋 Last.fm、ListenBrainz 或 Maloja
  - 雙重啟動：從主選單→系統重新啟動到庫存，並透過按住選單/返回+播放/暫停返回
  - 單獨的 Y1 和 Y2 建構 - Y2 包是它自己的 ROM 並且不能交換

## 首先要知道的事情
  - 這是一個實驗性構建 - 項目本身警告它與 Innioasis 無關，並且如果倉促，閃爍會帶來變磚風險
  - 始終選擇為您的特定型號列出的版本（Y1 或 Y2）
  - 較舊的主題合集可能會以 240p 的價格製作；在選擇版本之前檢查解析度和發行說明
  - 之後您可以使用匹配的 Y1 或 Y2 庫存包恢復原始軟體
