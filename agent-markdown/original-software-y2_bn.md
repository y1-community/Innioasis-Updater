## Install or restore it with Updater

Set up the computer first, then let Updater prepare the model-matched package.
  - আপনার কম্পিউটারে Innioasis Updater CE খুলুন (যদি আপনার অ্যাপটির প্রয়োজন হয়, [Updater CE নিন](guide_bn.html#platform)) সেট ডিভাইস মডেল থেকে Y2.
  - বেছে নিন মূল সফটওয়্যার and a Y2 release.
  - ক্লিক করুন ইনস্টল / পুনরুদ্ধার.
  - Power off and connect the Y2 only when the live prompt asks.

Manual full-install packages may use `rom_y2.zip`. Do not treat a Y1 `rom.zip` as a substitute.

## সাধারণ প্রশ্নCan I return from Rockbox or another custom software?

Use the same Y2 restore flow: choose Y2, select Original Software, and follow the connection prompt. Do not mix model files.Why does the Y2 package look different?

Y2 releases can use a different package name and release entry. Select Y2 in Updater rather than guessing from a manual ZIP filename.What if the player is not detected?

Check the data cable, computer permissions or drivers, and the timing. Connect the powered-off Y2 only after Updater says it is ready.
