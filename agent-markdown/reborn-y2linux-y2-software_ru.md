# Reborn (Y2Linux) для Innioasis Y2

Быстрый, специально созданный дистрибутив Debian Linux со встроенным пользовательским интерфейсом с колесом управления для Innioasis Y2, обеспечивающий стабильность работы наушников Bluetooth и активную разработку сообщества.[Пошаговое руководство Y2](guides/reborn-y2linux-y2.html)[Почему Y2Reborn?](reborn-y2linux-benefits_ru.html)[Скачать релизы](firmware_ru.html?model=Y2&software=reborn-y2linux-y2)

Руководство по установке для вашего компьютера

## Установите Reborn (Y2Linux) на свой Y2 с помощью компьютера.

Выберите руководство для компьютера, который вы используете. В каждой версии есть настройка платформы, Updater CE шагов и возврат к стоку.[Руководство по Windows](install/reborn-y2linux-y2-windows.html)[руководство по macOS](install/reborn-y2linux-y2-mac.html)[Руководство по Linux](install/reborn-y2linux-y2-linux.html)

[Все Innioasis Y2 руководства](install/y2.html) · [Все руководства Reborn (Y2Linux)](install/reborn.html)

## Этапы установки
  - Откройте программу обновлений CE. Доступно для Windows, macOS и Linux.
  - Выберите Y2 как модель устройства.
  - Выберите Reborn (Y2Linux) как программное обеспечение.
  - Нажмите Установить/Восстановить. Подождите, пока Updater CE подготовит файлы.
  - Подключите USB по запросу. Сначала выключите Y2.
  - Настройте Wi-Fi, Bluetooth и FM-радио

Копировать `system.img` игроку один раз. Reborn делает все остальное.[Завершить настройку →](y2reborn_wifibt_ru.html)
