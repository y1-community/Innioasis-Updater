# Asenna Y2Player laitteeseen Y2.

Y2Player on rakennettu Y2:lle. Valitse ensin mallisi, jotta et vahingossa käytä Y1-pakettia.[Avaa koko Y2Player-opas](guides/y2player-y2.html)[Hanki tämä Updater CE](guide_fi.html?model=Y2&software=y2player-y2)[Miksi Y2Player?](y2player-benefits_fi.html)

Asennusopas tietokoneellesi

## Asenna Y2Player Y2-laitteeseen tietokoneesi kanssa

Valitse käyttämäsi tietokoneen opas. Jokaisessa versiossa on alustan asetukset, Updater CE vaiheet ja tie takaisin varastoon.[Windowsin opas](install/y2player-y2-windows.html)[macOS-opas](install/y2player-y2-mac.html)[Linux opas](install/y2player-y2-linux.html)

[Kaikki Innioasis Y2-oppaat](install/y2.html) · [Kaikki Y2Player oppaat](install/y2player.html)

## Y2Player asennusvaiheet
  - Avaa Innioasis Updater CE tietokoneellasi (jos tarvitset sovelluksen, [Hanki Updater CE](guide_fi.html#platform)). Aseta Laitteen malli to Y2.
  - Valitse Y2Player sisään Ohjelmisto.
  - Valitse luettelosta julkaisu Y2.
  - Napsauta Asenna / Palauta.
  - Katkaise virta ja liitä Y2 live-kehotteessa.

Jotkut Y2 täyden asennuspaketit käyttävät `rom_y2.zip`. Anna Updaterin valita paketti, kun mahdollista.
