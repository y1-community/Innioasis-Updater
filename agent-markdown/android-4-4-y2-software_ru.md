# Установите Android 4.4 (Dev) на Y2.

Android 4.4 — это разработка сообщества ROM для тестирования и взлома на Innioasis Y2 оборудовании. На этой странице можно найти полное руководство и список выпусков.[Открыть полное руководство по Android 4.4 (для разработчиков)](guides/android-4-4-y2.html)[Получите это в Updater CE](guide_ru.html?model=Y2&software=android-4-4-y2)[Источник проекта](https://github.com/y1-community/y2-ata-rom)

Руководство по установке для вашего компьютера

## Установите разработку Android ROM на свой Y2 с помощью компьютера.

Выберите руководство для компьютера, который вы используете. В каждой версии есть настройка платформы, Updater CE шагов и возврат к стоку.[Руководство по Windows](install/android-4-4-y2-windows.html)[руководство по macOS](install/android-4-4-y2-mac.html)[Руководство по Linux](install/android-4-4-y2-linux.html)

[Все Innioasis Y2 руководства](install/y2.html) · [Все руководства по разработке для Android ROM](install/android-dev.html)

## Действия по установке Android 4.4 Y2
  - Откройте Innioasis Updater CE на своем компьютере (если вам нужно приложение, [Скачать Updater CE](guide_ru.html#platform)). Набор Модель устройства в адрес Y2.
  - Выбирать Android 4.4 (для разработчиков) в Программное обеспечение.
  - Выберите выпуск, указанный для Y2.
  - Нажмите Установить / Восстановить.
  - Выключите питание и подсоедините Y2 только при запросе Updater CE.

## Вопросы и ответыМогу ли я восстановить стандартное программное обеспечение Y2?

Да. Выберите Y2 и оригинальное программное обеспечение в Updater CE. [Y2 руководство по стандартному программному обеспечению](original-software-y2_ru.html) перекрывает обратный путь.Это ежедневный водитель ROM?

Это экспериментальный разработчик ROM, предназначенный для тестирования и разработки. Обновления релиза находятся на странице проекта.

## Используйте маршрут с гидом

Впервые пользуетесь программой обновлений? См. пошаговую настройку, чтобы [Скачать Updater CE](guide_ru.html#platform) в Windows, macOS или Linux перед подключением плеера.
