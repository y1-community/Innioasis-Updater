# 🚀 Innioasis Updater - Guide d'installation intégrable

Il s'agit d'un widget de guide d'installation complet et intégrable qui peut être facilement intégré à n'importe quel site Web. Il comporte un CTA contextuel dans le coin inférieur droit qui ouvre un guide d'installation complet pour les utilisateurs de Windows, macOS et Linux.

Conception moderne et réactive qui fonctionne sur tous les appareils prenant en charge le mode sombre

### 📱 Multiplateforme

Guides d'installation complets pour Windows, macOS et Linux avec des instructions étape par étape

### 🔧 Intégration facile

Copiez et collez simplement l'extrait - aucune dépendance ni configuration complexe n'est requise

### 💾 Stockage intelligent

Se souvient si les utilisateurs ont fermé la bannière pour éviter d'être intrusifs

## 📋 Instructions d'intégration

Pour ajouter le guide d'installation Innioasis Updater à votre site Web, copiez et collez simplement cet extrait de code dans votre code HTML : <!-- Innioasis Updater Install Guide Widget --> <script> (function() { // Créer et injecter le widget const script = document.createElement('script'); script.src = 'https://your-domain.com/innioasis-embed.html'; script.async = true; // Alternative : charger à partir d'un fichier local // script.src = './innioasis-embed.html'; document.head.appendChild(script); // Créer conteneur iframe const iframe = document.createElement('iframe'); iframe.src = 'https://your-domain.com/innioasis-embed.html'; iframe.style.cssText = ` position : fixe ; none; `; // Rendre l'iframe interactif iframe.onload = function() { iframe.style.pointerEvents = 'auto' }; </script> 📋 Copier le code d'intégration

## 🌐 Exigences d'hébergement

Pour utiliser ce widget sur votre site Web, vous devez :
  - Téléchargez le `innioasis-embed.html` fichier sur votre serveur Web
  - Mettez à jour les URL dans l'extrait d'intégration pour qu'elles pointent vers votre serveur
  - Assurez-vous que votre serveur prend en charge HTTPS (obligatoire pour les navigateurs modernes)
  - Testez le widget sur votre site Web pour vous assurer qu'il fonctionne correctement
