# การสนับสนุนและเครดิตของชุมชน - Innioasis Updater

ความช่วยเหลือเพียงเล็กน้อยก็ช่วยได้มาก

# ให้สิ่งดีๆดำเนินต่อไป

Updater CE ฟรี มันถูกสร้างขึ้นโดยผู้ที่ต้องการให้ผู้เล่น Innioasis และ Timmkoo ยังคงมีประโยชน์ การสนับสนุนของคุณจะจ่ายค่าไฟล์เก็บถาวร เซิร์ฟเวอร์ และเวลา

## นี่เป็นโครงการที่ขับเคลื่อนด้วยผู้คน

ทุกการสนับสนุนช่วยให้ใครบางคนสามารถค้นหาเฟิร์มแวร์ที่ใช้งานได้ ลองโปรเจ็กต์ใหม่ หรือทำให้ผู้เล่นเก่ามีชีวิตอยู่ต่อไปอีกหน่อย ขอบคุณที่เป็นส่วนหนึ่งของมัน[บริจาค](#donate)[ดูโครงการที่คุณกำลังช่วยเหลือ](#projects-supported)[พบปะผู้สนับสนุน](#supporters)Loading supporters...ไรอัน (ผู้พัฒนา)

## มันต้องใช้เวลา คุณ.โครงการของเราอาศัยการบริจาค

สวัสดี ฉันไรอัน ฉันร่วมกับ Innioasis ดูแล Innioasis Updater CE ไฟล์เก็บถาวรเฟิร์มแวร์นี้ และแกลเลอรีธีม ฉันจ่ายเงินให้พวกเขาเองเพื่อให้พวกเขาอยู่ฟรีสำหรับทุกคน การวิ่งทั้งสามคนมีค่าใช้จ่ายประมาณ $200 ต่อเดือน และผู้เล่นที่ฉันซื้อเพื่อทดสอบแต่ละรุ่นก็มามากกว่านั้น ดังนั้นการสนับสนุนใดๆ ก็ตามจะช่วยได้

## เงินไปไหน.

การใช้งาน Updater CE แกลเลอรีธีมและไฟล์เก็บถาวรเฟิร์มแวร์มีค่าใช้จ่ายประมาณ 200 ดอลลาร์ต่อเดือน ยิ่งไปกว่านั้น ยังมาพร้อมกับค่าธรรมเนียม Apple Developer ในแต่ละปี, Mac mini แบบจ่ายครั้งเดียวสำหรับการทดสอบ และฮาร์ดแวร์: เครื่องเล่นสำหรับทุกรุ่นและรุ่นต่างๆ ที่คุ้มค่ากับการทดสอบ และผู้เล่นบางส่วนเหล่านั้นไม่รอดจากงานนี้ การสนับสนุนของชุมชนในปัจจุบันครอบคลุมประมาณ 15% ของยอดรวมจริง ที่เหลือก็ออกมาจากกระเป๋าของฉันเองค่าใช้จ่ายทั้งหมดจนถึงตอนนี้$0กำลังบวกเพิ่ม...การมีส่วนร่วมของชุมชน$0ได้รับจากผู้สนับสนุนชุมชน การสนับสนุนเชิงพาณิชย์จะถูกแยกออกจากกันInnioasis การสนับสนุน$0ได้รับการสนับสนุนเชิงพาณิชย์จาก Innioasis ซึ่งระบุไว้แยกต่างหากด้านล่างบัญชีแยกประเภทชุมชนโครงการชุมชนได้รับการสนับสนุน$0เงินที่ส่งไปยังผู้สร้างและโปรเจ็กต์อื่นๆ ซึ่งแสดงแยกต่างหากจากการสนับสนุนของชุมชนใบรับรองนักพัฒนา Apple$0$ 99 ในแต่ละปีฮาร์ดแวร์ทดสอบ Mac mini$599ฮาร์ดแวร์ทดสอบแพลตฟอร์มแบบครั้งเดียวสำหรับ macOS

ตัวเลขข้างต้นนับรวมบิลปกติ ไม่นับผู้เล่นทดสอบ: สิ่งเหล่านี้จะซื้อต่อรุ่น และบางส่วนจะสูญหายไปเนื่องจากแฟลชที่ล้มเหลวในขณะที่กำลังตรวจสอบบิลด์ การสนับสนุนจากชุมชนคิดเป็นประมาณ 15% ของค่าใช้จ่ายจริงของโครงการ
