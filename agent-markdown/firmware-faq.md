# Firmware & Software Questions Answered

A plain-English guide to official stock firmware, factory recovery ROMs, and custom OS options (Rockbox, Better-Y, Solar, JJ Launcher, Inniclassic, Y2Player, Koensayr) for Innioasis and Timmkoo devices.[Get Updater CE](guide.html#platform)[Browse Firmware Archive](firmware.html)

Stock & recovery

## Stock Firmware, Unbricking & Supported Models

### Where can I find stock firmware to unbrick my player?

Pick your model. Then download the file, or let Updater CE install it for you. Every package is checked before it goes up.

### Which models does the Innioasis Firmware Archive support?

We host software for Innioasis Y1, Y2, G1, G3, G5, R1, PR1 and D1. New builds appear as soon as they are ready. Timmkoo Q5 and Q3 install through Updater CE too.

### Can I return from custom firmware to factory software?

Yes. In Updater CE, pick your model, choose Original Software, then run Install / Restore. Never use files for a different model.

What each route gives you

## Pick the software that matches how you listen.

### Original Software

The software your player shipped with. Local music, Bluetooth, and the familiar interface. Nothing to set up. It is the safe baseline, and the quickest way back.

[Restore on Y1](original-software-y1.html) · [Restore on Y2](original-software-y2.html)

### Better-Y

An improved stock system for the Y1 by Leska1337. Cleaner tags, track numbers, quicker navigation, and full theme support.

[Better-Y on Y1](better-y-y1-software.html) · [Why Better-Y?](better-y-benefits.html)

### Rockbox

The music lover's choice. Sorts by tags instead of file names. Gapless playback, crossfade, an equalizer, and a big theme library. Works offline.

[Rockbox on Y1](rockbox-y1-software.html) · [Rockbox on Y2](rockbox-y2-software.html) · [Why Rockbox?](rockbox-benefits.html)

### Solar

Solar switches on Wi-Fi, so the player can stream and download. Deezer, Soulseek, podcasts and YouTube, plus a stem player. Rockbox comes along too.

[Solar on Y1](solar-y1-software.html) · [Solar on Y2](solar-y2-software.html) · [Why Solar?](solar-benefits.html)

### JJ Launcher

A fast, wheel-friendly launcher. Rapid library scanning, equalizer presets, track skipping with the hardware buttons from any screen, wireless file uploads over Wi-Fi, in-app Bluetooth pairing, and themes you can drop in or design with the web theme editor.

[JJ Launcher on Y1](jj-launcher-y1-software.html) · [JJ Launcher on Y2](jj-launcher-y2-software.html) · [Why JJ Launcher?](jj-launcher-benefits.html)

### Inniclassic

An iPod Classic tribute built on JJ Launcher. The classic menu look, a click-wheel style Music Quiz, synced lyrics, Last.fm scrobbling, plus podcasts, FM radio, and video. Y1 and Y2 community builds.

[Inniclassic on Y1](inniclassic-y1-software.html) · [Inniclassic on Y2](inniclassic-y2-software.html) · [Why Inniclassic?](inniclassic-benefits.html)

### Y2Player

A music-first home screen for the Y2. Offline playback with a persistent queue, gapless and crossfade transitions, audiobooks that resume where you stopped, and every common format from FLAC to Opus. Bluetooth audio works, and no internet connection is required.

[Y2Player on Y2](y2player-y2-software.html) · [Why Y2Player?](y2player-benefits.html)

### Koensayr

Keeps the stock Y1 look. Music browses by artist, and Bluetooth shows track names and works with your car controls.

[Koensayr on Y1](koensayr-y1-software.html) · [Why Koensayr?](koensayr-benefits.html)

These projects move fast. Read each project's release notes and issues tracker before installing. If anything goes wrong, restoring Original Software for your model is the safe way back.

A note on the two tools

## Which tool should I use?

Innioasis Updater CE is the safest way to update your player. It keeps your music, videos and Bluetooth pairings. The Innioasis Universal Flash Tool wipes them.

It tells you when updates are ready. It shows each step on screen. It runs on Windows, macOS and Linux.

Community walkthroughs, including Catsteal3r's TikTok and Dammit Jeff's “How To Actually Quit Spotify” video, recommend using Updater CE.[Compare the tools](updater-comparison.html)
