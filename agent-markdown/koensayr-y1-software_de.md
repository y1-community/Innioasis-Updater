## Koensayr Y1 Installationsschritte
  - Öffnen Sie Innioasis Updater CE auf Ihrem Computer (wenn Sie die App benötigen, [Updater CE holen](guide_de.html#platform)). Satz Gerätemodell an Y1.
  - Wählen Sie Koensayr In Software.
  - Wählen Sie die aufgeführte Version Y1 aus.
  - Klicken Sie Installieren / Wiederherstellen.
  - Schalten Sie das Y1 nur aus und schließen Sie es an, wenn Updater CE dazu fragt.

## FAQKann ich die ursprüngliche Y1-Software wiederherstellen?

Ja. Wählen Sie Y1 und Originalsoftware in Updater CE. Siehe die [Y1 Aktien-Software-Seite](original-software-y1_de.html) für die vollständige Wiederherstellungsroute.Was sollte ich überprüfen, wenn es fehlschlägt?

Überprüfen Sie Modell, Release, Kabel, Plattform-Setup und ob der Player vor der Aufforderung angeschlossen war. Dann verwenden [Fehlerbehebung](troubleshooting_de.html).Gibt es ein Koensayr Y2-Paket?

Der aktuelle Build ist für Y1. Verwenden Sie es nicht auf einem Y2, es sei denn, das Projekt veröffentlicht eine separate Version dafür.
