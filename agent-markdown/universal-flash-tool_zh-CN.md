## 社区版协作

Innioasis 更新程序 由 Ryan Specter 和一群音频爱好者开始，与 Innioasis 一起工作。从那时起它就一直在增长： Innioasis Updater 行政长官.

创建者推荐 Updater CE，因为它是由制作定制软件的人员构建的。它可以保存您的音乐、视频和蓝牙配对。它会告诉您更新何时准备就绪。它可以在 Windows、macOS 和 Linux 上的新旧计算机上运行。

## 什么是 Innioasis Universal Flash Tool / 共享 Flash 工具？

的 Innioasis Universal Flash Tool，也称为 共享闪存工具 (v5.0.2) 是工厂实用程序。它适用于服务中心。对于大多数业主来说，这比需要的更困难：
  - 擦拭巾内部存储： 使用共享/通用闪存工具进行刷新会完全擦除设备上的内部存储。这意味着您必须在更新后重新连接蓝牙音频设备并替换所有音乐和视频。 （存储在 microSD 卡上的媒体不受这两种工具的影响。）
  - 无更新通知： 仅限离线使用的实用程序，在为您的播放器发布新更新或改进时没有提醒您的机制。
  - 无指导： 没有任何内容解释应用程序中的步骤。您必须观看外部视频并阅读 PDF，才能让播放器做好准备。更新程序 CE 会向您显示每个步骤。
  - 有限的 Mac 支持： 其 Mac 版本需要运行 macOS 15 或更高版本的 Apple Silicon Mac。英特尔 Mac 电脑被排除在外；更新程序 CE 在 macOS 10.15 及更高版本上运行。
  - 无 Linux 或 ARM64 Windows 版本： Universal Flash Tool 没有 Linux 版本或 ARM 上的 Windows 支持，而 Updater CE 提供了适用于 Linux 的官方 AppImage 和有效的 ARM64 Windows 支持。
  - 仅限离线： 你发现 `.zip` 或 `.rar` 包装自己。更新程序 CE 会为您下载它。
  - 仅工厂软件： Universal Flash Tool 无法安装 Rockbox、Better-Y、Solar、Koensayr、Rondo 或 Reborn (Y2Linux) 等自定义系统。
