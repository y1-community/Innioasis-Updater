# Firmware para Innioasis Y2

El Y2 tiene mejor hardware de audio, Bluetooth y un administrador de archivos. Elija un sistema personalizado, una compilación de Linux o el software oficial para restaurar.[Explorar Y2 Descargas](firmware_es.html?model=Y2)[Obtener Updater CE](guide_es.html#platform)[Y2 Guía de temas](https://themes.innioasis.app/y2-themes.html?lang=es)

## Sistemas operativos disponibles para Innioasis Y2

Elija lo que desea ejecutar en su Y2:

### [Reborn (Y2Linux)](reborn-y2linux-benefits_es.html)

Sistema operativo Linux integrado nativo que combina Buildroot, LVGL, PipeWire y MPD. Ofrece tiempos de arranque de 3 segundos, verdaderas correcciones de reconexión de auriculares Bluetooth y reproducción sin interrupciones.[Y2Reborn Guía →](guides/reborn-y2linux-y2.html)

### [Rockbox para Y2](rockbox-benefits_es.html)

El firmware para audiófilos definitivo adaptado al Innioasis Y2. Ecualización paramétrica, fuentes personalizadas, alimentación cruzada y amplia compatibilidad con la biblioteca de complementos.[Y2 Rockbox Guía →](guides/rockbox-y2.html)

### [Solar para Y2](solar-benefits_es.html)

Interfaz de reproductor de música moderna y fluida basada en Flutter para Y2. Incluye visualizadores enriquecidos, presentación de carátulas de álbumes de gran tamaño y navegación por gestos.[Solar Y2 Guía →](guides/solar-y2.html)

### [Y2Player](y2player-benefits_es.html)

Reproductor de audio comunitario liviano diseñado para hardware Y2 con exploración sencilla de carpetas y escaneo rápido de índices.[Y2Player Guía →](guides/y2player-y2.html)

### [Software original (restauración de fábrica)](original-software-benefits_es.html)

Imagen de firmware oficial (rom_y2.zip) para restaurar un Innioasis Y2 a su condición original de fábrica, completa con compatibilidad con aspectos de la Galería de temas.[Restaurar Y2 Guía →](guides/restore-original-y2.html)

## Instalación de firmware en su Innioasis Y2

Updater CE toma los archivos correctos y verifica el controlador antes de flashear:
  - Inicie Innioasis Actualizador CE: Disponible de forma nativa en macOS, Linux y Windows.
  - Modelo de conjunto: Seleccionar Y2 en el menú Modelo de dispositivo.
  - Elija el sistema operativo: Elija Reborn, Rockbox, Solar o Software original.
  - Flashear de forma segura: Siga las instrucciones en pantalla para conectar su dispositivo a través de USB para obtener un flash limpio y verificado.
