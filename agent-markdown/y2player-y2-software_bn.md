## Y2Player install steps
  - আপনার কম্পিউটারে Innioasis Updater CE খুলুন (যদি আপনার অ্যাপটির প্রয়োজন হয়, [Updater CE নিন](guide_bn.html#platform)) সেট ডিভাইস মডেল থেকে Y2.
  - বেছে নিন Y2Player মধ্যে সফটওয়্যার.
  - Choose a release listed for Y2.
  - ক্লিক করুন ইনস্টল / পুনরুদ্ধার.
  - Power off and connect the Y2 at the live prompt.

Some Y2 full-install packages use `rom_y2.zip`. Let Updater choose the package when possible.
