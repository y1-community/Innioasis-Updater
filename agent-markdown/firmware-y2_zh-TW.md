# Innioasis Y2 的韌體

Y2 具有更好的音訊硬體、藍牙和檔案管理器。選擇自訂系統、Linux 版本或官方軟體進行復原。[瀏覽 Y2 下載](firmware_zh-TW.html?model=Y2)[取得 Updater CE](guide_zh-TW.html#platform)[Y2 主題指南](https://themes.innioasis.app/y2-themes.html?lang=zh-TW)

## Innioasis Y2 的可用作業系統

選擇您想要在 Y2 上運行的內容：

### [Reborn (Y2Linux)](reborn-y2linux-benefits_zh-TW.html)

結合了 Buildroot、LVGL、PipeWire 和 MPD 的原生嵌入式 Linux 作業系統。提供 3 秒啟動時間、真正的藍牙耳機重新連接修復和無縫播放。[Y2Reborn 指南 →](guides/reborn-y2linux-y2.html)

### [Y2 的 Rockbox](rockbox-benefits_zh-TW.html)

移植到 Innioasis Y2 的終極發燒友韌體。參數均衡、自訂字體、交叉饋送和廣泛的插件庫支援。[Y2 Rockbox 指引 →](guides/rockbox-y2.html)

### [Solar 為 Y2](solar-benefits_zh-TW.html)

Y2 的基於 Flutter 的現代、流暢的音樂播放器介面。具有豐富的視覺化工具、大型專輯封面演示和手勢導航。[Solar Y2 指引 →](guides/solar-y2.html)

### [Y2Player](y2player-benefits_zh-TW.html)

專為 Y2 硬體打造的輕量級社群音訊播放器，具有簡單的資料夾瀏覽和快速索引掃描功能。[Y2Player 指南 →](guides/y2player-y2.html)

### [原始軟體（恢復出廠設定）](original-software-benefits_zh-TW.html)

官方庫存韌體映像 (rom_y2.zip) 用於將 Innioasis Y2 恢復到原始出廠狀態，並配有主題庫皮膚支援。[恢復 Y2 指南 →](guides/restore-original-y2.html)

## 在您的 Innioasis Y2 上安裝韌體

更新程式 CE 會抓取正確的檔案並在刷新之前檢查驅動程式：
  - 啟動 Innioasis 更新程式 CE： 本機可在 macOS、Linux 和 Windows 上使用。
  - 設定型號： 選擇 Y2 在設備型號選單中。
  - 選擇作業系統： 選擇 Reborn、Rockbox、Solar 或原始軟體。
  - 安全閃光： 按照螢幕上的指示透過 USB 連接您的設備，以獲得乾淨、經過驗證的快閃記憶體。
