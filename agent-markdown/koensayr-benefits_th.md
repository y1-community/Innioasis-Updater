# ทำไมต้อง Koensayr สำหรับ Innioasis Y1 | ของคุณ ประโยชน์ Koensayr - Innioasis ดาวน์โหลดเฟิร์มแวร์

ซอฟต์แวร์แบบกำหนดเอง · Koensayr

# ทำไมต้อง Koensayr สำหรับ Innioasis Y1 ของคุณ

Koensayr เก็บอินเทอร์เฟซที่คุณรู้จักและแก้ไขสิ่งที่ทำให้คุณรำคาญ เรียกดูเพลงตามศิลปิน และ Bluetooth จะแสดงชื่อแทร็กและทำงานร่วมกับส่วนควบคุมรถของคุณ[รับ Koensayr ใน Updater](guide_th.html?model=Y1&software=koensayr-y1)[หน้าติดตั้ง Y1](koensayr-y1-software_th.html)

## ความพร้อมของรุ่น

Innioasis รุ่นใดที่ใช้งานได้[Y1 · ว่าง](koensayr-y1-software_th.html)Y2 · ไม่พร้อมใช้งาน

บิลด์ Y1 และ Y2 แยกจากกัน ดังนั้นคว้าอันที่สร้างมาเพื่อเครื่องเล่นของคุณในการดาวน์โหลดซอฟต์แวร์ — อย่าสลับอันหนึ่งกับอันอื่น

## ทำไมคนถึงเลือกมัน

รักษาผู้เล่นหุ้นไว้ แก้ไขส่วนที่น่ารำคาญ
  - ศิลปิน → การนำทางอัลบั้ม — แอพเพลงสต็อกได้รับกระแสศิลปินถึงอัลบั้มที่ขาดหายไป — ไม่ต้องขุดผ่านโฟลเดอร์อีกต่อไป
  - บลูทูธที่ใช้งานได้ภายในรถยนต์ — ข้อมูลเมตาและการควบคุม AVRCP 1.3 ที่เป็นไปตามข้อกำหนด: เฮดยูนิตของคุณจะเห็นชื่อแทร็ก ส่วนหัวของตัวควบคุมการเล่น และสถานะเล่นซ้ำ/สุ่ม
  - จับคู่ที่เข้าคู่กันจริงๆ — การกำหนดค่าเสียงและการจับคู่ได้รับการปรับแต่งสำหรับเครื่องเสียงและชุดหูฟังในรถยนต์ รวมถึงการแก้ไขการจับคู่อัตโนมัติ
  - รูทเมื่อคุณต้องการมัน — มีการติดตั้ง setuid su ขั้นต่ำสำหรับการเพิ่มระดับ adb ซึ่งมีประโยชน์สำหรับการวินิจฉัยและการซ่อมแซม
  - บวมน้อยลง — แอประบบที่ไม่เคยใช้งานจะถูกลบออกเพื่อเพิ่ม RAM และลดการทำงานเบื้องหลัง
  - ไม่มีเส้นโค้งการเรียนรู้ — อินเทอร์เฟซคืออินเทอร์เฟซ Y1 Koensayr เปลี่ยนพฤติกรรมไม่ใช่หน้าตา

## ชุมชน

สิ่งที่ชุมชนพูด

Koensayr เป็นซอฟต์แวร์สำหรับผู้ที่ชื่นชอบอินเทอร์เฟซหุ้น Y1 และเพียงต้องการแก้ไขในส่วนที่หงุดหงิด ชื่อของมันคือการตัดลึกของ Star Wars — Koensayr สร้าง Y-Wing และ Y-Wing นำไปสู่ ​​Y1

ชัยชนะที่ได้รับการพูดถึงมากที่สุดในชุมชนคือ Bluetooth: ข้อมูลเมตาของแทร็กที่เหมาะสมและการควบคุมเครื่องเสียงและชุดหูฟังในรถยนต์ (AVRCP 1.3) ซึ่งซอฟต์แวร์ในสต็อกมักผิดพลาด หากคุณอาศัยอยู่ในรถ นี่คือซอฟต์แวร์ที่ผู้คนแนะนำคุณ
  - [r/innioasis · Koensayr และบลูทูธในรถยนต์](https://www.reddit.com/r/innioasis/)

## สิ่งที่โครงการนำเสนอ
  - ศิลปิน → การนำทางอัลบั้มที่แพตช์ลงในเพลงของระบบ APK
  - ข้อมูลเมตาและการควบคุม AVRCP 1.3: ข้อมูลเมตาแบบเต็มแทร็ก, ส่วนหัวของตัวควบคุม ms-precision, การแจ้งเตือนแทร็กและแบตเตอรี่ และการทำซ้ำ/สุ่มแบบสองทิศทาง
  - การแก้ไขการจับคู่ Bluetooth: การแก้ไข audio.conf, auto_pairing.conf, blacklist.conf และ build.prop สำหรับการจับคู่รถยนต์และชุดหูฟัง
  - การเข้าถึงรูทผ่าน setuid su ขั้นต่ำสำหรับการเพิ่มระดับ adb หุ้น adbd ยังคงไม่ถูกแตะต้อง
  - ระบบ debloat - ลบ bloatware ที่ติดตั้งไว้ล่วงหน้าแล้ว
  - การเปิดใช้งาน ADB เพิ่มเติมใน build.prop
  - เครื่องมือวินิจฉัยเพื่อตรวจสอบพฤติกรรมของ Bluetooth บนฮาร์ดแวร์จริง

## เรื่องน่ารู้ก่อน
  - ปัจจุบัน Y1 เท่านั้น และจะเก็บอินเทอร์เฟซสต็อกไว้ — เป็นตัวแก้ไข ไม่ใช่ตัวเรียกใช้งาน
  - เป็นเส้นทางที่มีเทคนิคมากที่สุด: โปรแกรมแก้ไขทำงานบนโฮสต์ Linux และกะพริบผ่าน MTKClient ดังนั้นจึงเหมาะกับผู้ใช้ที่มั่นใจ
  - โปรเจ็กต์จะแพตช์เฉพาะซอฟต์แวร์สต็อกที่รู้จักเท่านั้น — ตรวจสอบเวอร์ชันซอฟต์แวร์ของคุณที่ตรงกัน
  - การกู้คืนซอฟต์แวร์ต้นฉบับสำหรับโมเดลของคุณยังคงเป็นวิธีย้อนกลับไปหากคุณเปลี่ยนใจ
