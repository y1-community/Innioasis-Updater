# คำแนะนำหลังการติดตั้ง

ขั้นตอนที่โปรเจ็กต์ขอให้คุณดำเนินการให้เสร็จสิ้นหลังจากติดตั้งเฟิร์มแวร์แล้ว

[ดาวน์โหลดเฟิร์มแวร์ →](firmware_th.html)[คู่มือการติดตั้ง](guide_th.html)

## คำแนะนำหลังการติดตั้งโดยเฟิร์มแวร์

นี่คือลิงก์คำแนะนำหลังการติดตั้ง Updater CE สำหรับเฟิร์มแวร์แต่ละตัว เลือกเฟิร์มแวร์ของคุณเพื่อเปิดขั้นตอนการตั้งค่า
