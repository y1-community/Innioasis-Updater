## Rockbox Y2 Installationsschritte
  - Öffnen Sie Innioasis Updater CE auf Ihrem Computer (wenn Sie die App benötigen, [Updater CE holen](guide_de.html#platform)). Satz Gerätemodell an Y2.
  - Wählen Sie Rockbox In Software.
  - Wählen Sie eine Version, die explizit für Y2 aufgeführt ist.
  - Klicken Sie Installieren / Wiederherstellen und warten Sie auf die Paketvorbereitung.
  - Schalten Sie das Y2 nur aus und schließen Sie es an, wenn Updater CE dazu fragt.

Erzwingen Sie kein Y1-Paket, da der Projektname gleich aussieht. Wenn keine Version Y2 angezeigt wird, halten Sie an und überprüfen Sie das Modell und die aktuellen Versionsdaten.
