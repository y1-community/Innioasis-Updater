# Install Inniclassic on the Y1.

Inniclassic is a community software project for the Y1, and the same project also publishes a Y2 build, so it is available on both players. This page gives you the Y1 search-friendly answer and links to the detailed connection steps.[Open the full Inniclassic guide](guides/inniclassic-y1.html)[এটি Updater CE এ পান](guide_bn.html?model=Y1&software=inniclassic-y1)[কেন Inniclassic?](inniclassic-benefits_bn.html)

## Install Inniclassic on your Y1 with your computer

আপনি যে কম্পিউটারটি ব্যবহার করছেন তার জন্য গাইডটি বেছে নিন। প্রতিটি সংস্করণে প্ল্যাটফর্ম সেটআপ, Updater CE পদক্ষেপ এবং স্টকে ফিরে যাওয়ার উপায় রয়েছে।[উইন্ডোজ গাইড](install/inniclassic-y1-windows.html)[macOS গাইড](install/inniclassic-y1-mac.html)[লিনাক্স গাইড](install/inniclassic-y1-linux.html)

## Inniclassic Y1 install steps
  - আপনার কম্পিউটারে Innioasis Updater CE খুলুন (যদি আপনার অ্যাপটির প্রয়োজন হয়, [Updater CE নিন](guide_bn.html#platform)) সেট ডিভাইস মডেল থেকে Y1.
  - বেছে নিন Inniclassic মধ্যে সফটওয়্যার.
  - Y1-এর জন্য তালিকাভুক্ত রিলিজ বেছে নিন।
  - ক্লিক করুন ইনস্টল / পুনরুদ্ধার.
  - পাওয়ার বন্ধ করুন এবং শুধুমাত্র Updater CE বললেই Y1 সংযোগ করুন।

## সাধারণ প্রশ্নআমি কি স্টক Y1 সফ্টওয়্যার পুনরুদ্ধার করতে পারি?

হ্যাঁ। Updater CE-এ Y1 এবং অরিজিনাল সফটওয়্যার নির্বাচন করুন। দ [Y1 স্টক-সফ্টওয়্যার গাইড](original-software-y1_bn.html) ফেরার পথ কভার করে।ইনস্টলেশন ব্যর্থ হলে কি হবে?

Note whether Updater failed before or after detecting the Y1, then check the cable, platform setup, model, and connection timing in [সমস্যা সমাধান](troubleshooting_bn.html).Can I use Inniclassic on Y2?

Yes. Inniclassic is available on both models — the same maintained project publishes a Y2 package from the same releases. Select Y2 in Updater CE and install the Y2 build; never flash a Y1 package to a Y2. The [Y2 ইনস্টল পৃষ্ঠা](inniclassic-y2-software_bn.html) covers it.
