# Innioasis Y1 のファームウェア

Y1 にはカスタム システムの選択肢が最も豊富にあります。以下のすべてはここでホストされ、チェックされ、Updater CE をクリックするだけでインストールされます。[Y1 ダウンロードを参照](firmware_ja.html?model=Y1)[Updater CE を入手](guide_ja.html#platform)[テーマギャラリー](https://themes.innioasis.app/?lang=ja)

## Innioasis Y1 で利用可能なオペレーティング システム

Y1 は、オーディオファイル コーデック サポートを備えたビルド、最新のランチャー、工場出荷時の復元など、いくつかのソフトウェア システムを実行します。あなたの聴き方に合ったものをお選びください:

### [Rockbox](rockbox-benefits_ja.html)

オープンソースオーディオ再生のゴールドスタンダード。パラメトリック EQ、ギャップレス FLAC/MP3 再生、テーマ、フォント パックは Updater CE に直接インストール可能。[Y1 Rockbox ガイド →](guides/rockbox-y1.html)

### [Better-Y](better-y-benefits_ja.html)

Bluetooth 安定性パッチ、ボリューム カーブ調整、テーマ ギャラリーの 100% 互換性を備えたオリジナルのファームウェアの強化された派生版。[Better-Y ガイド →](guides/better-y-y1.html)

### [Solar](solar-benefits_ja.html)

Flutter で構築された現代的なオープンソース音楽プレーヤーで、スムーズな 60fps アニメーション、アルバム アート グリッド、モダンなタイポグラフィーを提供します。[Solar Y1 ガイド →](guides/solar-y1.html)

### [Rondo](rondo-benefits_ja.html)

ローカル トラックとストリーミング用のオープンソース Y1 ランチャー。迅速で応答性の高いナビゲーションを備えています。[Rondo Y1 ガイド →](guides/rondo-y1.html)

### [Koensayr](koensayr-benefits.html)

独自のアイコン、より優れたバッテリー調整、ストックテーマのサポートを備えたカスタムファームウェアビルド。[Koensayr ガイド →](guides/koensayr-y1.html)

### [オリジナル ソフトウェア (ストック復元)](original-software-benefits_ja.html)

Type A (v2.0.0+) および Type B (v1.x) Y1 プレーヤーのクリーンな工場出荷時のファームウェア イメージ。安全にブリックを解除するか、デバイスを工場出荷時の状態に復元します。[Y1 の復元ガイド →](guides/restore-original-y1.html)

## Y1 ファームウェアをインストールまたはアップデートする方法

マルチプラットフォーム ソフトウェア スイートを使用すると、Innioasis Y1 のアップグレードまたはブリック解除が簡単になります。
  - Innioasis Updater CE を開きます: macOS、Windows、または Linux でアップデーターを起動します。
  - モデル Y1 を選択: 選択してください Y1 [デバイス モデル] ドロップダウンで
  - オペレーティング システムを選択してください: Rockbox、Better-Y、Solar、またはオリジナル ソフトウェアを選択します。
  - 「インストール」をクリックします。 Updater CE は、開発者のリリースからファームウェア パッケージを直接ダウンロードします。プロンプトが表示されたら、電源がオフになっている Y1 を USB 経由で接続して、点滅を開始します。
[すべての Y1 リリースを参照](firmware_ja.html?model=Y1)[ステップバイステップのインストール ガイド](guide_ja.html)
