## Koensayr Y1 install steps
  - আপনার কম্পিউটারে Innioasis Updater CE খুলুন (যদি আপনার অ্যাপটির প্রয়োজন হয়, [Updater CE নিন](guide_bn.html#platform)) সেট ডিভাইস মডেল থেকে Y1.
  - বেছে নিন Koensayr মধ্যে সফটওয়্যার.
  - Choose the listed Y1 release.
  - ক্লিক করুন ইনস্টল / পুনরুদ্ধার.
  - পাওয়ার বন্ধ করুন এবং শুধুমাত্র Updater CE বললেই Y1 সংযোগ করুন।
