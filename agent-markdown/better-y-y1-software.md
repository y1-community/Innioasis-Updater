# Install Better-Y on the Y1.

Better-Y provides an enhanced stock experience for the Innioasis Y1 with tag splitting, album track numbers, Now Playing shortcuts, and smoother RAM caching while maintaining 100% theme compatibility.[Open the full Better-Y guide](guides/better-y-y1.html)[Get this in Updater CE](guide.html?model=Y1&software=better-y-y1)[Why Better-Y?](better-y-benefits.html)

## Better-Y Y1 install steps
  - Open Innioasis Updater CE on your computer (if you need the app, [Get Updater CE](guide.html#platform)). Set Device Model to Y1.
  - Choose Better-Y in Software.
  - Choose the release listed for Y1.
  - Click Install / Restore.
  - Power off and connect the Y1 only when Updater CE asks.

## FAQsWhat is improved over the stock firmware?

Better-Y adds track numbers, splits multi-artist tags, uses real titles, and adds playback shortcuts, plus fixes for caching and Bluetooth. Same themes as before.Can I restore the stock Y1 software?

Yes. Select Y1 and Original Software in Updater CE. The [Y1 stock-software guide](original-software-y1.html) covers the return path.Can I use my existing themes?

Yes! Better-Y is built on official stock 3.1.2 and maintains 100% compatibility with all custom themes from the Themes Gallery.What if installation fails?

Note whether Updater failed before or after detecting the Y1, then check the cable, platform setup, model, and connection timing in [troubleshooting](troubleshooting.html).
