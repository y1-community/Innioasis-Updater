## Koensayr Y1 install steps
  - Buka Innioasis Updater CE di komputer Anda (jika Anda memerlukan aplikasinya, [Dapatkan Updater CE](guide_id.html#platform)). Tetapkan Model perangkat untuk Y1.
  - Pilih Koensayr di Perangkat lunak.
  - Choose the listed Y1 release.
  - Klik Pasang / Pulihkan.
  - Matikan dan sambungkan Y1 hanya ketika Updater CE diminta.

## Pertanyaan umumCan I restore the original Y1 software?

Yes. Select Y1 and Original Software in Updater CE. See the [Y1 stock-software page](original-software-y1_id.html) for the complete restore route.What should I check when it fails?

Check the model, release, cable, platform setup, and whether the player was connected before the prompt. Then use [pemecahan masalah](troubleshooting_id.html).Is there a Koensayr Y2 package?

The current build is for Y1. Don't use it on a Y2 unless the project publishes a separate release for it.
