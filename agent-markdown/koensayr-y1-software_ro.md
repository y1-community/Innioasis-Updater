Alegeți ghidul pentru computerul pe care îl utilizați. Fiecare versiune are configurarea platformei, Updater CE pași și calea de întoarcere la stoc.[Ghidul Windows](install/koensayr-y1-windows.html)[ghid macOS](install/koensayr-y1-mac.html)[Ghid Linux](install/koensayr-y1-linux.html)

## Koensayr Y1 install steps
  - Deschideți Innioasis Updater CE pe computer (dacă aveți nevoie de aplicație, [Obține Updater CE](guide_ro.html#platform)). Setați Model dispozitiv la Y1.
  - Alege Koensayr in Software.
  - Choose the listed Y1 release.
  - Faceți clic Instalează / Restaurează.
  - Opriți și conectați Y1 numai când Updater CE vă cere.

## Întrebări frecventeCan I restore the original Y1 software?

Yes. Select Y1 and Original Software in Updater CE. See the [Y1 stock-software page](original-software-y1_ro.html) for the complete restore route.What should I check when it fails?

Check the model, release, cable, platform setup, and whether the player was connected before the prompt. Then use [depanare](troubleshooting_ro.html).Is there a Koensayr Y2 package?

The current build is for Y1. Don't use it on a Y2 unless the project publishes a separate release for it.
