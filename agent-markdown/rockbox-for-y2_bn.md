# Rockbox for Y2 (Rockbox-Y2)

Rockbox-Y2 (also called “Rockbox for Y2”) is the dedicated community Rockbox firmware port for the Innioasis Y2. It uses its own ROM package (`rom_y2.zip`) and is installed directly through Innioasis Updater CE.[ইনস্টল করুন Rockbox-Y2](rockbox-y2/install.html)[Download the ROM](rockbox-y2/download.html)[Written tutorial](guides/rockbox-y2.html)[Rockbox-Y2 হাব](rockbox-y2/)

## Built specifically for the Innioasis Y2

In Innioasis Updater CE, this firmware is listed as Rockbox when Y2 is selected. Its releases are published by the [spycemagic/y2-rockbox](firmware_bn.html?model=Y2&software=rockbox-y2) project with the package name `rom_y2.zip`.

Never install a Y1 firmware package on a Y2. Selecting Y2 in Updater CE automatically filters the release list to Y2-compatible builds only.

## What Rockbox-Y2 offers
  - Tag-based music library — browse albums, artists, and genres from your audio file tags, or browse folders directly.
  - Playback controls — gapless playback, crossfade, ReplayGain, and equalizer settings.
  - Custom themes — install themes compatible with your Rockbox-Y2 build ([Y2 theme guide](rockbox-y2-themes_bn.html)).
  - 100% offline — plays local files from your MicroSD card with no accounts or subscriptions.
  - Easy factory restore — return to Y2 Original Software at any time in Updater CE.

## Choosing a Rockbox-Y2 release
  - Always select Y2 মধ্যে ডিভাইস মডেল প্রথম
  - Choose the latest release unless you are testing a specific version.
  - পড়ুন [Rockbox-Y2 রিলিজ নোট](release-notes/rockbox-y2/index.html) to see what changed in each build.

## Direct downloads from the community developers

Innioasis Updater CE always downloads firmware packages directly from the community firmware developers ([spycemagic/y2-rockbox](firmware_bn.html?model=Y2&software=rockbox-y2)), and those developers are solely responsible for listing their software releases in Updater CE.

You can let Updater CE download and flash `rom_y2.zip` automatically, or download the package from our [Rockbox-Y2 downloads page](rockbox-y2/download.html) এবং [Rockbox ROM download page](rockbox-rom-download_bn.html).[Rockbox-Y2 downloads](rockbox-y2/download.html)[একটি স্থানীয় জিপ থেকে ইনস্টল করুন](rockbox-y2/portable-zip.html)

## How to install Rockbox-Y2
  - Open Innioasis Updater CE and set ডিভাইস মডেল থেকে Y2.
  - নির্বাচন করুন Rockbox মধ্যে সফটওয়্যার.
  - Pick a Y2 release from the list.
  - ক্লিক করুন ইনস্টল / পুনরুদ্ধার so Updater CE downloads the package directly from the developer.
  - Power the Y2 completely off and connect it with a USB data cable when Updater CE asks.
  - Wait for the completion message, then unplug and turn on your Y2.

For the full step-by-step walkthrough, read the [Rockbox-Y2 tutorial](guides/rockbox-y2.html).

## Restoring the original Y2 software

To go back to factory firmware, select Y2 এবং মূল সফটওয়্যার in Updater CE, choose a stable release, and click ইনস্টল / পুনরুদ্ধার. See the [restore guide](rockbox-y2/restore-stock.html) এবং [Y2 Original Software page](original-software-y2_bn.html).

## Frequently asked questionsWhere does Updater CE download Rockbox-Y2 from?

Updater CE always downloads firmware packages directly from the community firmware developers' own releases (`spycemagic/y2-rockbox`). The developers are solely responsible for listing their software releases in Updater CE.Why is the package named rom_y2.zip?

The developer names the Y2 firmware archive `rom_y2.zip` so it cannot be confused with the Y1's `rom.zip`.Do Y1 themes work on the Y2?

Not always. Check the release notes for your Y2 build and see the [Rockbox-Y2 theme guide](rockbox-y2-themes_bn.html).
