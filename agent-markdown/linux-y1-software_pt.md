# Instale o Linux no Y1.

Linux para Y1 é um kernel Linux da comunidade experimental e uma porta rootfs para o hardware Innioasis Y1. ## Instale Linux para Y1 (Dev) em seu Y1 com seu computador

Escolha o guia para o computador que você está usando. Cada versão possui a configuração da plataforma, Updater CE etapas e o caminho de volta ao estoque.[Guia do Windows](install/linux-y1-windows.html)[guia macOS](install/linux-y1-mac.html)[Guia Linux](install/linux-y1-linux.html)

[Todos Innioasis Y1 guias](install/y1.html) · [Todos os guias Linux para Y1 (Dev)](install/linux-dev.html)

## Etapas de instalação do Linux Y1
  - Abra Innioasis Updater CE no seu computador (se precisar do aplicativo, [Obtenha o atualizador CE](guide_pt.html#platform)). Definir Modelo do dispositivo para Y1.
  - Escolher Linux para Y1 (Desenvolvedor) em Programas.
  - Escolha o lançamento listado para Y1.
  - Clique Instalar / Restaurar.
  - Desligue e conecte o Y1 somente quando Updater CE solicitar.

## Perguntas frequentesPosso restaurar o software padrão Y1?

Sim. Selecione Y1 e Software Original em Updater CE. O [Y1 guia de software de estoque](original-software-y1_pt.html) cobre o caminho de retorno.Esta é uma interface de usuário cotidiana?
