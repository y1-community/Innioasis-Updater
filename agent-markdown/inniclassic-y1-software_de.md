# Installieren Sie Inniclassic auf Y1.

Inniclassic ist ein Community-Softwareprojekt für Y1, und das gleiche Projekt veröffentlicht auch einen Y2-Build, sodass er auf beiden Playern verfügbar ist. ## Inniclassic Y1 Installationsschritte
  - Öffnen Sie Innioasis Updater CE auf Ihrem Computer (wenn Sie die App benötigen, [Updater CE holen](guide_de.html#platform)). Satz Gerätemodell an Y1.
  - Wählen Sie Inniclassic In Software.
  - Wählen Sie die für Y1 aufgeführte Version aus.
  - Klicken Sie Installieren / Wiederherstellen.
  - Schalten Sie das Y1 nur aus und schließen Sie es an, wenn Updater CE dazu fragt.

## FAQKann ich die Standard-Y1-Software wiederherstellen?

Ja. Wählen Sie Y1 und Originalsoftware in Updater CE. Die [Y1-Aktiensoftware-Leitfaden](original-software-y1_de.html) deckt den Rückweg ab.Was passiert, wenn die Installation fehlschlägt?

Beachten Sie, ob der Updater vor oder nach der Erkennung von Y1 fehlgeschlagen ist, und überprüfen Sie dann das Kabel, die Plattformeinrichtung, das Modell und das Verbindungs-Timing [Fehlerbehebung](troubleshooting_de.html).Kann ich Inniclassic auf Y2 verwenden?

Ja. Inniclassic ist auf beiden Modellen verfügbar – dasselbe gepflegte Projekt veröffentlicht ein Y2-Paket aus denselben Releases. Wählen Sie Y2 in Updater CE und installieren Sie den Build Y2; Flashen Sie niemals ein Y1-Paket auf ein Y2. Der [Y2-Installationsseite](inniclassic-y2-software_de.html) deckt es ab.
