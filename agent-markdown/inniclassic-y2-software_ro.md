# Instalați Inniclassic pe Y2.

Inniclassic este disponibil pentru Innioasis Y2, iar același proiect construiește și pachetele Y1. Această pagină vă oferă o prezentare generală a Y2 și link-uri către tutorialul complet.[Deschideți ghidul complet Inniclassic.](guides/inniclassic-y2.html)[Obțineți asta în Updater CE](guide_ro.html?model=Y2&software=inniclassic-y2)[De ce Inniclassic?](inniclassic-benefits_ro.html)

Ghid de instalare pentru computerul dvs

## Instalați Inniclassic pe Y2 cu computerul dvs

Alegeți ghidul pentru computerul pe care îl utilizați. Fiecare versiune are configurarea platformei, Updater CE pași și calea de întoarcere la stoc.[Ghidul Windows](install/inniclassic-y2-windows.html)[ghid macOS](install/inniclassic-y2-mac.html)[Ghid Linux](install/inniclassic-y2-linux.html)

[Toate ghidurile Innioasis Y2](install/y2.html) · [Toate ghidurile Inniclassic.](install/inniclassic.html)

## Inniclassic Y2 pași de instalare
  - Deschideți Innioasis Updater CE pe computer (dacă aveți nevoie de aplicație, [Obține Updater CE](guide_ro.html#platform)). Setați Model dispozitiv la Y2.
  - Alege Inniclassic în Software.
  - Alegeți versiunea listată pentru Y2.
  - Faceți clic Instalează / Restaurează.
  - Opriți și conectați Y2 numai când Updater CE vă cere.

## Întrebări frecventePot restaura software-ul stoc Y2?

Da. Selectați Y2 și Software-ul original în Updater CE. The [Y2 ghid de stoc-software](original-software-y2_ro.html) acoperă calea de întoarcere.Pot folosi Inniclassic pe Y1?

Da. Același proiect publică și Y1 pachete — rom.zip pentru Type A și rom_type_b.zip pentru Type B. Selectați Y1 în Updater CE și instalați versiunea Y1; cel [Pagina de instalare Y1](inniclassic-y1-software_ro.html) o acoperă.Ce se întâmplă dacă instalarea eșuează?

Rețineți dacă Updater a eșuat înainte sau după detectarea Y2, apoi verificați cablul, configurarea platformei, modelul și sincronizarea conexiunii în [depanare](troubleshooting_ro.html).

## Utilizați traseul ghidat

Prima dată când folosești Updater? Consultați configurarea ghidată către [Obține Updater CE](guide_ro.html#platform) pe Windows, macOS sau Linux înainte de a vă conecta playerul.
