# Rockbox ROM téléchargement pour les Y1 et Y2

Téléchargez Rockbox packages de firmware ROM pour les Innioasis Y1 (Rockbox-Y1) et Y2 (Rockbox-Y2) directement auprès des développeurs de la communauté, ou installez-les en un clic avec Innioasis Updater CE.

## Choisissez d'abord votre modèle de lecteur

Rockbox-Y1 et Rockbox-Y2 sont des versions de micrologiciel distinctes créées pour différents matériels. Vérifiez si votre lecteur est un Innioasis Y1 ou un Y2 avant de télécharger ou de flasher.

## Comment Updater CE télécharge le micrologiciel

Innioasis Updater CE télécharge toujours les packages de micrologiciels directement à partir des propres versions des développeurs de micrologiciels de la communauté, et les développeurs eux-mêmes sont seuls responsables de la liste de leurs versions logicielles dans Updater CE. Chaque package ROM contient le fichier scatter MediaTek et les images de partition pour ce modèle.
  - Rockbox-Y1 package de version développeur : `rom.zip` (et `rom_type_b.zip` pour Type B Y1 unités).
  - Rockbox-Y2 package de version développeur : `rom_y2.zip`.

## Installer automatiquement avec Updater CE

Pour la configuration la plus simple, ouvrez Innioasis Updater CE, sélectionnez votre modèle de lecteur et Rockbox, puis laissez l'application télécharger et flasher directement la version. Suivez le [Rockbox-Y1 guide d'installation](rockbox-y1/install.html) ou le [Rockbox-Y2 guide d'installation](rockbox-y2/install.html).
