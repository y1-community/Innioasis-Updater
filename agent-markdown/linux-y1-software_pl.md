## Linux Y1 install steps
  - Otwórz Innioasis Updater CE na swoim komputerze (jeśli potrzebujesz aplikacji, [Pobierz Updater CE](guide_pl.html#platform)). Zestaw Model urządzenia do Y1.
  - Wybierz Linux dla Y1 (wersja deweloperska) w Oprogramowanie.
  - Wybierz wersję wymienioną dla Y1.
  - Kliknij Zainstaluj / Przywróć.
  - Wyłącz i podłącz Y1 tylko wtedy, gdy Updater CE zapyta.
