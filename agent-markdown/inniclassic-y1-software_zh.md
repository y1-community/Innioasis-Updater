## Inniclassic Y1 安装步骤
  - 在您的计算机上打开 Innioasis Updater CE（如果您需要该应用程序， [获取 Updater CE](guide_zh-CN.html#platform)）。套装 设备型号 至 Y1.
  - 选择 Inniclassic 在 软件.
  - 选择为 Y1 列出的版本。
  - 点击 安装 / 恢复.
  - 仅当 Updater CE 询问时关闭电源并连接 Y1。

## 常见问题我可以恢复原厂Y1软件吗？

是的。在Updater CE中选择Y1和原始软件。的 [Y1库存软件指南](original-software-y1_zh-CN.html) 覆盖返回路径。如果安装失败怎么办？

请注意更新程序在检测到 Y1 之前或之后是否失败，然后检查线缆、平台设置、型号和连接时序 [故障排除](troubleshooting_zh-CN.html).我可以在 Y2 上使用 Inniclassic 吗？

是的。 Inniclassic 在两种模型上均可用 — 同一维护项目从相同版本发布 Y2 包。在 Updater CE 中选择 Y2 并安装 Y2 版本；切勿将 Y1 包刷新到 Y2。这 [Y2安装页面](inniclassic-y2-software_zh-CN.html) 覆盖它。
