# Мікропрограмне забезпечення для завантажень мікропрограм Innioasis Y1 - Innioasis.

Завантаження пристрою · Модель Y1

# Прошивка для Innioasis Y1

Y1 має найширший вибір спеціальних систем. Усе, що наведено нижче, розміщується тут, перевіряється та встановлюється в один клік за допомогою Updater CE.[Перегляньте Y1 завантаження](firmware_uk.html?model=Y1)[Отримати Updater CE](guide_uk.html#platform)[Галерея тем](https://themes.innioasis.app/?lang=uk)

## Доступні операційні системи для Innioasis Y1

Y1 працює з кількома програмними системами, включаючи збірки з підтримкою аудіофільських кодеків, сучасні програми запуску та відновлення заводських параметрів. Виберіть те, що вам більше подобається:

### [Rockbox](rockbox-benefits_uk.html)

Золотий стандарт у відтворенні аудіо з відкритим кодом. Параметричний еквалайзер, безперервне відтворення FLAC/MP3, теми та пакети шрифтів, які можна встановити безпосередньо в Updater CE.[Y1 Rockbox Посібник →](guides/rockbox-y1.html)

### [Better-Y](better-y-benefits_uk.html)

Покращена версія оригінальної мікропрограми з виправленнями стабільності Bluetooth, регулюванням кривої гучності та 100% сумісністю з галереєю тем.[Better-Y Посібник →](guides/better-y-y1.html)

### [Solar](solar-benefits_uk.html)

Сучасний музичний програвач із відкритим вихідним кодом, створений за допомогою Flutter, пропонує плавну анімацію зі швидкістю 60 кадрів/с, сітки обкладинок альбомів і сучасну типографіку.[Solar Y1 Посібник →](guides/solar-y1.html)

### [Rondo](rondo-benefits_uk.html)

Засіб із відкритим вихідним кодом Y1 для локальних треків і потокового передавання зі швидкою та чутливою навігацією.[Rondo Y1 Посібник →](guides/rondo-y1.html)

### [Koensayr](koensayr-benefits.html)

Спеціальна збірка прошивки з власною іконографією, кращим калібруванням батареї та підтримкою стандартних тем.[Koensayr Посібник →](guides/koensayr-y1.html)

### [Оригінальне програмне забезпечення (відновлення запасів)](original-software-benefits_uk.html)

Очистити заводські образи прошивки для плеєрів Type A (v2.0.0+) і Type B (v1.x) Y1. Безпечно розблокуйте або відновіть свій пристрій до заводського стану.[Відновити Y1 Керівництво →](guides/restore-original-y1.html)

## Як встановити або оновити мікропрограму Y1.

Оновити або розблокувати Innioasis Y1 легко за допомогою нашого багатоплатформного пакету програмного забезпечення:
  - Відкрити Innioasis Updater CE: Запустіть програму оновлення в macOS, Windows або Linux.
  - Виберіть модель Y1: Виберіть Y1 у спадному списку Модель пристрою.
  - Виберіть свою операційну систему: Виберіть Rockbox, Better-Y, Solar або оригінальне програмне забезпечення.
  - Натисніть Встановити: Updater CE завантажує пакет прошивки безпосередньо з випуску розробника. Коли буде запропоновано, підключіть вимкнений Y1 через USB, щоб почати блимати.
