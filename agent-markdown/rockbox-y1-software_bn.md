## Rockbox Y1 install steps
  - আপনার কম্পিউটারে Innioasis Updater CE খুলুন (যদি আপনার অ্যাপটির প্রয়োজন হয়, [Updater CE নিন](guide_bn.html#platform)) সেট ডিভাইস মডেল থেকে Y1.
  - বেছে নিন Rockbox মধ্যে সফটওয়্যার.
  - Pick the release and variant that match your intended screen or theme path.
  - ক্লিক করুন ইনস্টল / পুনরুদ্ধার and wait for the app to prepare it.
  - Power off and connect the Y1 only at the live prompt.

Use the [written Rockbox Y1 guide](guides/rockbox-y1.html) for the screenshots, video, Type A or Type B note, and connection checklist.

## সাধারণ প্রশ্নCan I go back to the original Y1 software?

Yes. Choose Y1 and Original Software in Updater CE, then run Install / Restore. The [Y1 stock-software page](original-software-y1_bn.html) explains that route.Which Rockbox release should I choose?

Choose a release shown for Y1 and read its release note. If you need older theme compatibility, check the resolution and variant notes rather than selecting a Y2 build.Can I install this on a Y2?

No. Use the separate [Rockbox Y2 page](rockbox-y2-software_bn.html) and select Y2 in Updater CE.
