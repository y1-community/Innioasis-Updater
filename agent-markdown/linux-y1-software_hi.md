# Install Linux on the Y1.

Linux for Y1 is an experimental community Linux kernel and rootfs port for the Innioasis Y1 hardware. This page links to the full installation guide and releases.[Open the full Linux for Y1 (Dev) guide](guides/linux-y1.html)[इसे Updater CE में प्राप्त करें](guide_hi.html?model=Y1&software=linux-y1)[परियोजना स्रोत](https://github.com/y1-community/y1-linux-rom)

अपने कंप्यूटर के लिए गाइड इंस्टॉल करें

## Install Linux for Y1 (Dev) on your Y1 with your computer

आप जिस कंप्यूटर का उपयोग कर रहे हैं उसके लिए गाइड चुनें. प्रत्येक संस्करण में प्लेटफ़ॉर्म सेटअप, Updater CE चरण और स्टॉक में वापस आने का तरीका होता है।[विंडोज़ गाइड](install/linux-y1-windows.html)[macOS गाइड](install/linux-y1-mac.html)[लिनक्स गाइड](install/linux-y1-linux.html)

[सभी Innioasis Y1 गाइड](install/y1.html) · [All Linux for Y1 (Dev) guides](install/linux-dev.html)

## Linux Y1 install steps
  - Open Innioasis Updater CE on your computer (if you need the app, [Updater CE प्राप्त करें](guide_hi.html#platform)). सेट डिवाइस मॉडल को Y1.
  - चुनें Y1 के लिए लिनक्स (डेव) में सॉफ़्टवेयर.
  - Y1 के लिए सूचीबद्ध रिलीज़ चुनें।
  - क्लिक करें इंस्टॉल / पुनर्स्थापित.
  - बिजली बंद करें और Y1 को तभी कनेक्ट करें जब Updater CE पूछे।

## अक्सर पूछे जाने वाले प्रश्नक्या मैं स्टॉक Y1 सॉफ़्टवेयर को पुनर्स्थापित कर सकता हूँ?

हाँ। Updater CE में Y1 और मूल सॉफ़्टवेयर का चयन करें। द [Y1 स्टॉक-सॉफ्टवेयर गाइड](original-software-y1_hi.html) वापसी पथ को कवर करता है।Is this an everyday user interface?

This is an experimental port for developers and Linux tinkerers. Terminal and console instructions are in the project docs.

## निर्देशित मार्ग का प्रयोग करें

क्या आप पहली बार अपडेटर का उपयोग कर रहे हैं? इसके लिए निर्देशित सेटअप देखें [Updater CE प्राप्त करें](guide_hi.html#platform) अपने प्लेयर को कनेक्ट करने से पहले Windows, macOS, या Linux पर।
