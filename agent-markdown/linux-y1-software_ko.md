# Innioasis Y1용 Linux(개발자) 펌웨어 | 설치 튜토리얼 - Innioasis 펌웨어 다운로드

리눅스(개발자) · Innioasis Y1

# Y1에 Linux를 설치합니다.

Y1용 Linux는 Innioasis Y1 하드웨어용 실험적인 커뮤니티 Linux 커널 및 rootfs 포트입니다. 이 페이지는 전체 설치 가이드 및 릴리스에 대한 링크입니다.[Y1(개발자)용 전체 Linux 가이드 열기](guides/linux-y1.html)[이것을 Updater CE에서 얻으세요](guide_ko.html?model=Y1&software=linux-y1)[프로젝트 소스](https://github.com/y1-community/y1-linux-rom)

컴퓨터에 대한 설치 가이드

## 컴퓨터를 사용하여 Y1에 Y1(Dev)용 Linux를 설치합니다.

사용 중인 컴퓨터에 대한 가이드를 선택하세요. 모든 버전에는 플랫폼 설정, Updater CE 단계 및 재고로 돌아가는 방법이 있습니다.[윈도우 가이드](install/linux-y1-windows.html)[macOS 가이드](install/linux-y1-mac.html)[리눅스 가이드](install/linux-y1-linux.html)

[모든 Innioasis Y1 가이드](install/y1.html) · [Y1(Dev)용 모든 Linux 가이드](install/linux-dev.html)

## Linux Y1 설치 단계
  - 컴퓨터에서 Innioasis Updater CE를 엽니다(앱이 필요한 경우, [Updater CE 받기](guide_ko.html#platform)). 세트 기기 모델 에 Y1.
  - 선택 Y1용 Linux(개발자) 안으로 소프트웨어.
  - Y1에 대해 나열된 릴리스를 선택합니다.
  - 클릭 설치 / 복원.
  - 전원을 끄고 Updater CE이 묻는 경우에만 Y1을 연결하세요.

## 자주 묻는 질문재고 Y1 소프트웨어를 복원할 수 있나요?

예. Updater CE에서 Y1과 원본 소프트웨어를 선택합니다. 는 [Y1 스톡 소프트웨어 가이드](original-software-y1_ko.html) 복귀 경로를 덮습니다.이것이 일상적인 사용자 인터페이스입니까?

이것은 개발자와 Linux 개발자를 위한 실험적인 포트입니다. 터미널 및 콘솔 지침은 프로젝트 문서에 있습니다.

## 안내 경로를 이용하세요

업데이터를 처음 사용하시나요? 안내된 설정을 참조하세요. [Updater CE 받기](guide_ko.html#platform) 플레이어를 연결하기 전에 Windows, macOS 또는 Linux에서.
