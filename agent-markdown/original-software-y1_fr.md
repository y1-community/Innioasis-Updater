## Installez-le ou restaurez-le avec Updater

L'outil de mise à jour utilise le même flux guidé, que le Y1 exécute actuellement son logiciel d'origine ou un projet communautaire.
  - Ouvrez Innioasis Updater CE sur votre ordinateur (si vous avez besoin de l'application, [Obtenir Updater CE](guide_fr.html#platform)). Ensemble Modèle d'appareil à Y1.
  - Choisissez Logiciel d'origine dans Logiciel (ou utilisez [Disponible dans Updater CE](guide_fr.html?model=Y1&software=original-y1) pour passer aux étapes guidées).
  - Cliquez Installer / Restaurer et laissez l'application préparer le package.
  - Éteignez et connectez le Y1 uniquement lorsque l'invite en direct vous le demande.

Lors du téléchargement manuel, le package d'installation complète habituel est nommé `rom.zip`. La sélection de modèle dans Updater est le moyen le plus sûr de choisir des fichiers.

## FAQPuis-je restaurer à partir de Rockbox ou d'un autre logiciel personnalisé ?

Oui, utilisez le modèle Y1 et le chemin du logiciel d'origine Y1. Ne supprimez pas d'abord les fichiers système et ne remplacez pas un package Y2.Que faire si mon Y1 n'est pas détecté ?

Vérifiez le câble de données, la configuration de l'ordinateur et la synchronisation de la connexion. Le lecteur doit être éteint et connecté uniquement à l'invite du programme de mise à jour.Quel package dois-je utiliser pour mon Y1 ?

Gardez le modèle imprimé sur votre lecteur sélectionné dans Updater. Les packages Y1 et Y2 sont distincts : arrêtez-vous si la liste des versions ne correspond pas à votre modèle.
