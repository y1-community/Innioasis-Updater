## Choose the Y2 route
  - Open Innioasis Updater CE on your computer (if you don't have it yet, [Get Updater CE](../guide.html#platform)). Select Y2 in Device Model.
  - Choose Solar in Software (or launch with [Get this in Updater CE](../guide.html?model=Y2&software=solar-y2)).
  - Read the release note, confirm the Y2 entry, and click Install / Restore.
  - Power off and connect the player only when Updater asks.
  - Restore with Y2 Original Software if you need the stock interface again.

## Keep the project note in view

Solar is under active development. Features and model support can change, so check the project’s release notes. Updater shows what’s available for your model right now. Do not substitute a Y1 package if the Y2 entry is missing.Updater connection instructionsConnect only at the live prompt.

## Go back to Original Software

Solar does not change the route back to the stock interface. Once Updater is set up for your computer, open it on Windows, macOS, or Linux and select Y2 plus Original Software instead of Solar.
  - Choose a stable Y2 Original Software release.
  - Click Install / Restore and wait for the live connection prompt.
  - Power off the Y2 only when asked.
  - Connect the USB data cable at the prompt and leave it still until success.

Do not manually remove Solar files first, and do not use a Y1 package. If the failure happened before the USB prompt, check the computer setup, cable, and model selection first.[Y2 restore guide](restore-original-y2.html)[Troubleshooting](../troubleshooting.html)
