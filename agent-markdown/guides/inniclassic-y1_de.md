# Installieren Sie Inniclassic auf einem Y1.

Inniclassic wird als Y1-Projekt aufgeführt. Wählen Sie Y1 aus, bevor Sie es auswählen, damit die Release-Liste modellabhängig bleibt.[Updater CE holen](../guide_de.html#platform)[In Updater CE erhalten](../guide_de.html?model=Y1&software=inniclassic-y1)[Warum Inniclassic?](../inniclassic-benefits_de.html)

Installationsanleitung für Ihren Computer

## Installieren Sie Inniclassic auf Ihrem Y1 mit Ihrem Computer

Wählen Sie die Anleitung für den Computer aus, den Sie verwenden. Jede Version verfügt über das Plattform-Setup, Updater CE Schritte und den Weg zurück zum Lagerbestand.[Windows-Anleitung](/install/inniclassic-y1-windows.html)[macOS-Anleitung](/install/inniclassic-y1-mac.html)[Linux-Anleitung](/install/inniclassic-y1-linux.html)

[Alle Innioasis Y1-Anleitungen](/install/y1.html) · [Alle Inniclassic Anleitungen](/install/inniclassic.html)

## Installieren Sie es
  - Öffnen Sie Innioasis Updater CE auf Ihrem Computer (falls Sie es noch nicht haben, [Updater CE holen](../guide_de.html#platform)). Auswählen Y1 In Gerätemodell.
  - Wählen Sie Inniclassic In Software (oder starten Sie mit [In Updater CE erhalten](../guide_de.html?model=Y1&software=inniclassic-y1)).
  - Wählen Sie eine Veröffentlichung aus und klicken Sie Installieren / Wiederherstellen.
  - Schalten Sie das Y1 erst aus und schließen Sie es an, wenn Sie vom Updater dazu aufgefordert werden.
  - Verwenden Sie Y1 Original-Software für den Wiederherstellungspfad.

## Halten Sie die Verbindung aufrechtAnweisungen zum Verbinden mit UpdaterDie genaue Eingabeaufforderung kann je nach Plattform variieren.

Wenn die Installation fehlschlägt, notieren Sie, ob der Fehler aufgetreten ist, bevor oder nachdem Updater den Player erkannt hat. Dieses Detail beschleunigt die Fehlerbehebung erheblich.
