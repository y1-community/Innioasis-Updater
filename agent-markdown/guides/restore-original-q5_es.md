# Restaurar el software original en Timmkoo Q5

Un regreso limpio al software con el que se envió el reproductor. Úselo después de una actualización fallida, antes de vender el reproductor o siempre que un sistema personalizado no sea para usted.[Obtener Updater CE](../guide_es.html#platform)[Q5 descargas](../firmware_es.html?model=Q5)[Q5 manual](../manuals/q5.html)

## Restaure el software original en su Q5 con su computadora

Elija la guía para la computadora que está utilizando. Cada versión tiene la configuración de la plataforma, Updater CE pasos y el camino de regreso al stock.[guía de windows](/install/original-q5-windows.html)[guía de macos](/install/original-q5-mac.html)[guía de linux](/install/original-q5-linux.html)

[Todas las guías Timmkoo Q5](/install/q5.html) · [Todas las guías de software originales](/install/original-software.html)

## lo que necesitas
  - Una computadora con Windows, macOS o Linux. Updater CE se ejecuta en los tres.
  - El cable de datos USB que viene con el reproductor. Los cables de sólo carga no funcionarán.
  - El funcionario `rom_q5.zip` paquete, que Updater descarga por usted, o una copia del [Q5 archivo](../firmware_es.html?model=Q5) si prefieres flashear a mano.
  - Carga en el reproductor. Una restauración que pierde potencia es la única forma común de empeorar una situación mala.

Esto reemplaza el sistema y borra el almacenamiento interno. Primero copie música, grabaciones y fotografías a una computadora.

## Ruta A: Updater CE (recomendada)
  - Instalar [Innioasis Actualizador CE](../guide_es.html#platform) y ábrelo.
  - conjunto Modelo del dispositivo a Q5. El modelo debe coincidir exactamente con el jugador.
  - elegir Software original en la lista de Software.
  - Elija un comunicado. La versión estable más nueva es la predeterminada segura.
  - prensa Instalar / Restaurar y espere mientras el paquete se descarga y extrae.
  - Apague el reproductor por completo y luego conecte el cable USB solo cuando el Actualizador lo solicite.
  - No toque el reproductor ni el cable hasta que aparezca el mensaje de éxito. Desconecta e inicia el reproductor.
Nunca elijas un modelo diferente para "hacer que funcione". Un Q5 necesita un paquete Q5. Mezclar modelos es la forma en que los jugadores terminan necesitando una recuperación manual.

## Ruta B: SP Flash Tool (manual)

Úselo cuando una computadora no pueda ejecutar Updater CE, o cuando ya tenga el paquete y prefiera la herramienta clásica.
  - Descargar `rom_q5.zip` desde el [Q5 archivo](../firmware_es.html?model=Q5) y descomprímelo.
  - Mantenga el archivo de dispersión junto a las imágenes. No cambie el nombre ni mueva las imágenes.
  - Abra SP Flash Tool, elija Descargar sóloy cargue el archivo de dispersión.
  - Apague el reproductor, presione Descargary luego conecte el cable.
  - Espere a que aparezca la marca verde de éxito antes de desconectarse.

el [SP Flash Tool guía](../sp-flash-tool_es.html) Cubre los controladores y las indicaciones de Windows con más detalle. En Linux y macOS, Updater CE es la ruta más fácil porque trae su propio manejo de USB.

## Después de la restauración
  - Desconecta el reproductor y deja que se inicie solo.
  - Elige tu idioma y configura el reloj.
  - Vuelva a conectarse a Wi-Fi o Bluetooth si los usa.
  - Copia tu música nuevamente. el [guía de transferencia](../manuals/transfer-music.html) tiene los nombres de las carpetas.

Si el reproductor se inicia pero la pantalla, la rueda o los botones aún funcionan mal, la restauración funcionó; Esa es una cuestión de hardware o configuración, no de software. el [guía de solución de problemas](../troubleshooting_es.html) es la siguiente parada.

## Si no funciona

### El actualizador nunca ve al jugador

Cambie el cable, luego el puerto USB. Evite los centros. En Windows, instale el controlador MediaTek desde el [página del conductor](../drivers_es.html).

### El flash se detiene temprano

Vuelva a conectarse, cargue el reproductor y comience de nuevo. No cambie al paquete de un modelo diferente.

### El jugador se queda negro.

Cargue durante una hora, luego mantenga la energía durante diez segundos. Si todavía está muerto, lea el [guía de recuperación](../guides/recovery_es.html) antes de volver a intentarlo.

## Preguntas que hace la gente

### ¿Esto borrará mi música?

Sí, se borra el almacenamiento interno. Los archivos en una tarjeta microSD generalmente sobreviven, pero cópielos primero en un lugar seguro.

### ¿Puedo volver a Rockbox después?

Sí. Restaurar el software original no es una puerta unidireccional; La página de software personalizado para su modelo puede instalarlo nuevamente.

### ¿Necesito la configuración Type A / Type B?

Sólo el Y1 tiene esa opción, y sólo para el software original. Todos los demás modelos utilizan un solo paquete.
