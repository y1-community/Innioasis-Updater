# Instale Y2Player no Y2.

Y2Player é um projeto Y2. A rota segura começa com a seleção do modelo, não com o nome do projeto.[Obtenha o atualizador CE](../guide_pt.html#platform)[Obtenha isso em Updater CE](../guide_pt.html?model=Y2&software=y2player-y2)[Por que Y2Player?](../y2player-benefits_pt.html)

Guia de instalação para o seu computador

## Instale Y2Player em seu Y2 com seu computador

Escolha o guia para o computador que você está usando. Cada versão possui a configuração da plataforma, Updater CE etapas e o caminho de volta ao estoque.[Guia do Windows](/install/y2player-y2-windows.html)[guia macOS](/install/y2player-y2-mac.html)[Guia Linux](/install/y2player-y2-linux.html)

[Todos Innioasis Y2 guias](/install/y2.html) · [Todos Y2Player guias](/install/y2player.html)

## No atualizador
  - Abra Innioasis Updater CE no seu computador (se ainda não o tiver, [Obtenha o atualizador CE](../guide_pt.html#platform)). Selecione Y2 em Modelo do dispositivo.
  - Escolher Y2Player em Programas (ou lançar com [Obtenha isso em Updater CE](../guide_pt.html?model=Y2&software=y2player-y2)).
  - Escolha a versão Y2 listada.
  - Clique Instalar / Restaurar, desligue quando solicitado e conecte USB no prompt.
  - Restaurar com Y2 Software Original se necessário.

## Não substitua um pacote Y1Verifique duas vezes: Y2 pacotes de instalação completa podem usar `rom_y2.zip`. Um pacote Y1 simples não é um substituto seguro.Instruções de conexão do atualizador para um Y2 desligadoConecte-se apenas no prompt ao vivo.
