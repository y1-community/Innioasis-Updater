# Як інсталювати JJ Launcher на Innioasis Y1 - Innioasis завантаження мікропрограми

JJ Launcher · Innioasis Y1

# Встановіть JJ Launcher на свій Y1.

Це маршрут Y1 для проекту JJ Launcher. Спочатку виберіть модель, щоб Updater не запропонував неправильний пакет.[Отримати Updater CE](../guide_uk.html#platform)[Отримайте це в Updater CE](../guide_uk.html?model=Y1&software=jj-launcher-y1)[Чому JJ Launcher?](../jj-launcher-benefits_uk.html)

Також доступні: [JJ Launcher на Y2](jj-launcher-y2_uk.html)

Посібник із встановлення для вашого комп’ютера

## Встановіть JJ Launcher на свій Y1 разом із комп’ютером

Виберіть посібник для комп’ютера, яким ви користуєтеся. Кожна версія має налаштування платформи, Updater CE кроків і шлях повернення до запасу.[Керівництво по Windows](/install/jj-launcher-y1-windows.html)[посібник з macOS](/install/jj-launcher-y1-mac.html)[Керівництво по Linux](/install/jj-launcher-y1-linux.html)

[Усі Innioasis Y1 посібники](/install/y1.html) · [Усі JJ Launcher посібники](/install/jj-launcher.html)

## Виберіть маршрут Y1.
  - Відкрийте Innioasis Updater CE на своєму комп’ютері (якщо у вас його ще немає, [Отримати Updater CE](../guide_uk.html#platform)). Виберіть Y1 в Модель пристрою.
  - Виберіть JJ Launcher в Програмне забезпечення (або запустити за допомогою [Отримайте це в Updater CE](../guide_uk.html?model=Y1&software=jj-launcher-y1)).
  - Прочитайте примітку до випуску, виберіть версію Y1 і натисніть Встановити / Відновити.
  - Вимкніть і підключіть плеєр лише тоді, коли програма оновлення запитає.
  - Відновити за допомогою Y1 Заводське ПЗ якщо вам знову потрібен стандартний інтерфейс.

## Подивіться відео

Відео від doitall. Він показує встановлення JJ Launcher на Innioasis Y1 та усунення несправностей встановлення; описані нижче кроки охоплюють Y1 і Y2.

## Невідповідність моделі - це перше, що потрібно перевірити

JJ Launcher also has a Y2 entry. If the package name looks wrong, return to Device Model. Do not force a Y2 package onto a Y1.Інструкції з підключення програми оновленняПідключайтеся лише за живою підказкою.

## Поверніться до оригінального програмного забезпечення

JJ Launcher не змінює маршрут повернення до стандартного інтерфейсу. Коли Updater налаштовано на вашому комп’ютері, відкрийте його в Windows, macOS або Linux і виберіть Y1 плюс Заводське ПЗ замість JJ Launcher.
  - Виберіть стабільну Y1 оригінальну версію програмного забезпечення.
  - Натисніть Встановити / Відновити і дочекайтеся сповіщення про живе підключення.
  - Вимикайте живлення Y1 лише тоді, коли буде запропоновано.
  - Під’єднайте USB-кабель даних після підказки та залиште його непорушним до успіху.

Не видаляйте спочатку вручну файли JJ Launcher і не використовуйте пакет Y2. Якщо помилка сталася до підказки USB, спочатку перевірте налаштування комп’ютера, кабель і вибір моделі.[Посібник з відновлення Y1](restore-original-y1_uk.html)[Усунення несправностей](../troubleshooting_uk.html)
