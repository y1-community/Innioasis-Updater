# Innioasis G5 で元のソフトウェアを復元します

応答しない G5 を回復する必要がある場合、システムを工場出荷時の状態に更新する必要がある場合、またはクリーンな公式ファームウェア アップデートをインストールする必要がある場合は、このガイド付きチュートリアルを使用してください。[Updater CE を入手](../guide_jp.html#platform)[G5 ダウンロードを表示](../firmware_jp.html?model=G5)

お使いのコンピューターのインストールガイド

## コンピュータを使用して G5 上の元のソフトウェアを復元します

使用しているコンピュータのガイドを選択してください。 すべてのバージョンには、プラットフォームのセットアップ、Updater CE の手順、および在庫に戻る方法が含まれています。[Windowsガイド](/install/original-g5-windows.html)[macOS ガイド](/install/original-g5-mac.html)[Linuxガイド](/install/original-g5-linux.html)

[すべての Innioasis G5 ガイド](/install/g5.html) · [すべてのオリジナル ソフトウェア ガイド](/install/original-software.html)

## ステップ 1: コンピューターを準備する

Innioasis Updater CE は、複雑な点滅ハーネスを必要とせずに、Windows、macOS、Linux 上でネイティブに実行されます。
  - 打ち上げ Innioasis アップデーター CE デスクトップまたはラップトップ上で。
  - セット デバイスモデル 支援先: G5.
  - 選択 純正ソフトウェア ソフトウェアのドロップダウンで。 Updater CE は公式を自動的にダウンロードします `rom_g5.zip` パッケージを直接リリースします。
  - クリック インストール / 復元 準備を始めます。

## ステップ 2: プロンプトで G5 を接続します

アプリケーションが次のメッセージを表示するまでは、プレーヤーを接続しないでください。
  - Innioasis G5 の電源が完全にオフになっていることを確認してください。
  - アップデーターに USB 接続プロンプトが表示されたら、USB-C データ ケーブルをコンピューターとプレーヤーに接続します。
  - 点滅中はケーブルや電源ボタンに触れないでください。
  - 成功の確認が表示されたら、USB ケーブルを抜き、G5 の電源を入れます。
