## Install it
  - Open Innioasis Updater CE on your computer (if you don't have it yet, [Get Updater CE](../guide.html#platform)). Select Y2 in Device Model.
  - Choose Inniclassic in Software (or launch with [Get this in Updater CE](../guide.html?model=Y2&software=inniclassic-y2)).
  - Select a release and click Install / Restore.
  - Power off and connect the Y2 only when Updater prompts you.
  - Use Y2 Original Software for the restore path.

## Keep the connection stillUpdater connection instructionsConnect only at the live prompt.

Y2 packages use `rom_y2.zip`. If installation fails, note whether the failure happened before or after Updater detected the player.
