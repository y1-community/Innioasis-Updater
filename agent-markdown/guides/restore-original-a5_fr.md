# Restaurer le logiciel d'origine sur Innioasis et Timmkoo A5

Suivez ce didacticiel pour restaurer le logiciel d'usine officiel sur votre lecteur Innioasis A5 ou Timmkoo A5 avec les packages vérifiés de l'archive du micrologiciel Innioasis.[Obtenir Updater CE](../guide_fr.html#platform)[Afficher A5 téléchargements](../firmware_fr.html?model=A5)

## Étape 1 : Configuration dans Updater CE
  - Lancement Innioasis Programme de mise à jour CE sur votre ordinateur Windows, macOS ou Linux.
  - Ensemble Modèle d'appareil à A5.
  - Sélectionnez Logiciel d'origine. Updater CE télécharge le fichier officiel `rom_a5.zip` publier le package directement.
  - Cliquez Installer / Restaurer et attendez la fin de la préparation.

## Étape 2 : Connectez-vous à l'invite
  - Éteignez complètement l'appareil A5.
  - Attendez l'invite sur l'écran de votre ordinateur avant de connecter le câble de données USB.
  - Laissez le processus de clignotement se terminer sans interruption.
  - Déconnectez et redémarrez votre lecteur A5 fraîchement restauré.
