## Scegli il percorso Y1.
  - Apri Innioasis Updater CE sul tuo computer (se non lo hai ancora, [Ottieni Updater CE](../guide_it.html#platform)). Seleziona Y1 dentro Modello del dispositivo.
  - Scegli JJ Launcher dentro Software (o avvia con [Ottieni questo in Updater CE](../guide_it.html?model=Y1&software=jj-launcher-y1)).
  - Leggere la nota di rilascio, selezionare la versione Y1 e fare clic Installa / Ripristina.
  - Spegnere e collegare il lettore solo quando richiesto dall'Updater.
  - Ripristina con Y1 Software originale se hai bisogno di nuovo dell'interfaccia stock.

## La mancata corrispondenza del modello è la prima cosa da verificare

JJ Launcher ha anche una voce Y2. Se il nome del pacchetto sembra sbagliato, torna a Modello dispositivo. Non forzare un pacchetto Y2 su un Y1.Istruzioni per la connessione dell'aggiornamentoConnettiti solo al prompt live.

## Torna al software originale

JJ Launcher non modifica il percorso di ritorno all'interfaccia stock. Una volta configurato Updater per il tuo computer, aprilo su Windows, macOS o Linux e seleziona Y1 inoltre Software originale invece di JJ Launcher.
  - Scegli una versione stabile del software originale Y1 .
  - Fare clic Installa / Ripristina e attendi la richiesta di connessione live.
  - Spegnere il Y1 solo quando richiesto.
  - Collegare il cavo dati USB quando richiesto e lasciarlo fermo fino al successo.

Non rimuovere prima manualmente i file JJ Launcher e non utilizzare un pacchetto Y2. Se l'errore si è verificato prima della richiesta USB, controllare prima la configurazione del computer, il cavo e la selezione del modello.[Guida al ripristino Y1](restore-original-y1_it.html)[Risoluzione dei problemi](../troubleshooting_it.html)
