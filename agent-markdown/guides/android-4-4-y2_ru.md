# Установите Android 4.4 (Dev) на Y2.

Android 4.4 — это разработка сообщества ROM для тестирования и взлома оборудования Innioasis Y2. Выберите Y2 перед тем, как выбрать его в Updater CE.[Скачать Updater CE](../guide_ru.html#platform)[Получите это в Updater CE](../guide_ru.html?model=Y2&software=android-4-4-y2)[Источник проекта](https://github.com/y1-community/y2-ata-rom)

Руководство по установке для вашего компьютера

## Установите разработку Android ROM на свой Y2 с помощью компьютера.

Выберите руководство для компьютера, который вы используете. В каждой версии есть настройка платформы, Updater CE шагов и возврат к стоку.[Руководство по Windows](/install/android-4-4-y2-windows.html)[руководство по macOS](/install/android-4-4-y2-mac.html)[Руководство по Linux](/install/android-4-4-y2-linux.html)

[Все Innioasis Y2 руководства](/install/y2.html) · [Все руководства по разработке для Android ROM](/install/android-dev.html)

## Установите его
  - Откройте Innioasis Updater CE на своем компьютере (если у вас его еще нет, [Скачать Updater CE](../guide_ru.html#platform)). Выбирать Y2 в Модель устройства.
  - Выбирать Android 4.4 (для разработчиков) в Программное обеспечение (или запустить с помощью [Получите это в Updater CE](../guide_ru.html?model=Y2&software=android-4-4-y2)).
  - Выберите выпуск и нажмите Установить / Восстановить.
  - Выключите питание и подсоедините Y2 только тогда, когда программа обновлений предложит вам это сделать.
  - Используйте Y2 Заводское ПО для пути восстановления.
