# Innioasis Y2 - Innioasis 펌웨어 다운로드에서 원본 소프트웨어 복원

복원 · Innioasis Y2

# Y2 재고 경로를 사용하여 Y2을 복원합니다.

Y2 복원은 Y1 복원이 아닙니다. 첫 화면부터 모델 선택과 패키지를 일치하게 유지하세요.[Updater CE 받기](../guide_ko.html#platform)[이것을 Updater CE에서 얻으세요](../guide_ko.html?model=Y2&software=original-y2)[Y2 소프트웨어 찾아보기](../firmware_ko.html#y2)

컴퓨터에 대한 설치 가이드

## 컴퓨터를 사용하여 Y2의 원본 소프트웨어를 복원하세요.

사용 중인 컴퓨터에 대한 가이드를 선택하세요. 모든 버전에는 플랫폼 설정, Updater CE 단계 및 재고로 돌아가는 방법이 있습니다.[윈도우 가이드](/install/original-y2-windows.html)[macOS 가이드](/install/original-y2-mac.html)[리눅스 가이드](/install/original-y2-linux.html)

[모든 Innioasis Y2 가이드](/install/y2.html) · [모든 원본 소프트웨어 가이드](/install/original-software.html)

## Rockbox 또는 다른 사용자 정의 소프트웨어에서

관련 Windows, macOS 또는 Linux 설정이 준비되면 Y2 스톡 인터페이스로 돌아가면 커뮤니티 프로젝트를 설치할 때와 동일한 업데이터 흐름을 사용합니다. Y1 파일을 플레이어에 수동으로 혼합하거나 시스템 폴더를 먼저 삭제하지 마십시오.
  - 컴퓨터에서 Innioasis 업데이터 CE를 엽니다(아직 설치하지 않은 경우 [Updater CE 받기](../guide_ko.html#platform) ~을 위한 [윈도우](../drivers_ko.html#windows), [macOS](../guide_ko.html#macos), 또는 [리눅스](../drivers_ko.html#linux)).
  - 세트 기기 모델 에 Y2.
  - 선택 원본 소프트웨어.
  - 안정적인 Y2 릴리스를 선택하세요. 수동 전체 설치 패키지는 다음을 사용할 수 있습니다. `rom_y2.zip`.
  - 클릭 설치 / 복원 추출 단계를 기다립니다.
대체하지 마십시오: Y1 `rom.zip` Y2 패키지가 아닙니다. 릴리스 목록이 잘못된 것 같으면 중지하고 Y2을(를) 다시 선택하십시오.

## 연결 프롬프트를 따르세요

Windows, macOS 및 Linux는 컴퓨터 설정 참고 사항이 다르지만 플레이어 측 순서는 동일하게 유지됩니다. 요청 시 전원을 끈 다음 라이브 프롬프트에서 데이터 케이블을 연결합니다.
  - 업데이터가 요청할 때 Y2의 전원을 완전히 끄십시오.
  - 앱에서 준비되었다고 표시되는 경우에만 USB을 연결하세요.
  - 성공 메시지가 나타날 때까지 케이블을 그대로 두십시오.
  - 안전하게 연결을 끊고 플레이어를 시작하세요.
업데이터 연결 지침공유 연결 참조입니다. 라이브 앱 프롬프트는 신뢰할 수 있습니다.

## 아직도 붙어있나요?

수동 도구를 사용하기 전에 모델, 패키지, 케이블 및 연결 타이밍을 확인하십시오. 그만큼 [문제 해결 가이드](../troubleshooting_ko.html) USB 이전의 실패와 장치 감지 후의 실패를 비교하여 설명합니다.패키지를 별도로 보관하십시오. Y1 `rom.zip` Y2 복원이 아닙니다. 릴리스 목록이 잘못된 것 같으면 중지하고 Y2을 다시 선택하십시오.
