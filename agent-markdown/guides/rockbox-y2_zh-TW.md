# 如何在 Innioasis Y2 - Innioasis 上安裝 Rockbox 韌體下載

Rockbox · Innioasis Y2

# 安裝 Y2 版本，而不是 Y1 版本。

用戶旅程很熟悉，但型號和套餐不同。首先選擇 Y2，以便更新程式準備正確的檔案和安裝路徑。[取得 Updater CE](../guide_zh-TW.html#platform)[在 Updater CE 中取得此內容](../guide_zh-TW.html?model=Y2&software=rockbox-y2)[為什麼是Rockbox？](../rockbox-benefits_zh-TW.html)

適用於您的電腦的安裝指南

選擇適合您正在使用的計算機的指南。 每個版本都有平台設定、Updater CE步驟和返回庫存的方式。[Windows 指南](/install/rockbox-y2-windows.html)[macOS 指南](/install/rockbox-y2-mac.html)[Linux指南](/install/rockbox-y2-linux.html)

## 觀看 Rockbox 路線

影片由弗勞吉斯拍攝。它適用於 Y1 和 Y2 型號 - 在 Innioasis Updater CE 中，選擇 Y2 作為你的模型。以下的書面步驟涵蓋了 Y2 安裝順序。

影片由 [克里斯蒂安廣場](https://www.youtube.com/@CristianPlaza) （西班牙語）。它演示了在 Y1 上的安裝；選擇 Y2 在本指南的 Updater CE 中。

## 在單擊安裝之前

準備好一條已充電的 Innioasis Y2、一條 USB 數據線以及一台安裝了 Innioasis Updater CE 的計算機（如果您尚未安裝， [取得 Updater CE](../guide_zh-TW.html#platform) 適用於 Windows、macOS 或 Linux）。不要僅僅因為名稱相似而使用 Y1 版本。型號檢查： Y2 完整安裝包可使用 `rom_y2.zip`。檔案名稱是有用的手動下載線索，但更新程式應該為您處理軟體包選擇。

## 在更新程式中選擇Y2
  - 開啟 Updater CE（或使用下列命令啟動 [在 Updater CE 中取得此內容](../guide_zh-TW.html?model=Y2&software=rockbox-y2)）並設定 裝置型號 到 Y2.
  - 選擇 Rockbox 在 軟體.
  - 選擇 Y2 列出的版本。若未列出 Y2 版本，請勿取代 Y1 版本。
  - 點選 安裝 / 還原 並讓Updater CE直接從社群開發者的release下載套件。

## 關閉電源，然後連接
  - 等待即時連線提示。
  - 將 Y2 完全關閉。如果正常關機失敗，請使用更新程式顯示的確切重設或恢復指令。
  - 當詢問時連接 USB 電纜。讓它保持靜止，直到出現完成訊息。
  - 安全斷開並啟動 Y2。
已關閉裝置的更新程式連線說明連接螢幕僅供參考。您的 Y2 提示可能包含不同的模型措詞。

## 返回原始軟體

Rockbox 不會將您鎖定在自訂軟體中。為您的電腦設定更新程式後，請在 Windows、macOS 或 Linux 上使用它從 Rockbox 或其他列出的項目返回：選擇 Y2， 選擇 原廠軟體，然後運行 安裝 / 還原.
  - 等待更新程式準備 Y2 庫存包。
  - 當應用程式詢問時，關閉 Y2 電源。
  - 僅在出現即時提示時連接 USB 數據線。
  - 讓玩家保持靜止，直到出現成功訊息。

將 Y1 和 Y2 包分開。先不要手動刪除Rockbox檔案；恢復會取代系統軟體。[Y2恢復指南](restore-original-y2_zh-TW.html)[疑難排解](../troubleshooting_zh-TW.html)
