# Innioasis Y2 - Innioasis ファームウェアのダウンロードに Reborn (Y2Linux / Y2Reborn) をインストールする方法

Innioasis Y2 · チュートリアルのインストール

# Innioasis Y2 に Reborn (Y2Linux) をインストールします。

フラッシュするには次の手順に従ってください Reborn (Y2Linux / Y2Reborn) Innioasis Updater CE を使用して Innioasis Y2 に接続し、インストール後の Wi-Fi および Bluetooth セットアップを完了します。[Updater CE を入手](../guide_ja.html#download-updater)[なぜ Reborn (Y2Linux) なのでしょうか?](../reborn-y2linux-benefits_ja.html)[Y2Reborn リリース](../firmware_ja.html?model=Y2&software=reborn-y2linux-y2)

お使いのコンピューターのインストールガイド

## コンピュータを使用して Y2 に Reborn (Y2Linux) をインストールします

使用しているコンピュータのガイドを選択してください。 すべてのバージョンには、プラットフォームのセットアップ、Updater CE の手順、および在庫に戻る方法が含まれています。[Windowsガイド](/install/reborn-y2linux-y2-windows.html)[macOS ガイド](/install/reborn-y2linux-y2-mac.html)[Linuxガイド](/install/reborn-y2linux-y2-linux.html)

[すべての Innioasis Y2 ガイド](/install/y2.html) · [すべての Reborn (Y2Linux) ガイド](/install/reborn.html)

## 段階的なインストール
  - Updater CE をインストールします: ダウンロード [Innioasis アップデーター CE](../guide_ja.html) Windows、macOS、または Linux の場合は、それを開きます。
  - Y2を選択します: 選択してください Y2 デバイスモデルとして。
  - Rebornを選択します: 選択してください Reborn (Y2Linux) そして最新リリース。
  - インストール： クリック インストール / 復元、Y2 の電源を切り、プロンプトが表示されたら USB を接続します。
  - 待って： Updater CE が確認するまでプレーヤーを静止させてから切断します。
  - Wi-Fi、Bluetooth、FM ラジオをセットアップする

コピー `system.img` プレイヤーに一度。残りは Reborn が行います。[セットアップを完了する →](../y2reborn_wifibt_ja.html)

## 元のソフトウェアに戻す

Y2 を選択することで、いつでも工場出荷時のソフトウェアに戻すことができます。 Y2 そして 純正ソフトウェア Updater CE で。を参照してください。 [Y2 復元チュートリアル](restore-original-y2_ja.html).
