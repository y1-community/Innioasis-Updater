# Instale Inniclassic en un Y2.

Inniclassic tiene un puerto dedicado Y2 mantenido por Jonasz Potoniec. Seleccione Y2 antes de elegirlo para que la lista de versiones tenga en cuenta el modelo.[Obtener Updater CE](../guide_es.html#platform)[Obtener en Updater CE](../guide_es.html?model=Y2&software=inniclassic-y2)[¿Por qué Inniclassic?](../inniclassic-benefits_es.html)

Guía de instalación para su computadora

## Instala Inniclassic en tu Y2 con tu computadora

Elija la guía para la computadora que está utilizando. Cada versión tiene la configuración de la plataforma, Updater CE pasos y el camino de regreso al stock.[guía de windows](/install/inniclassic-y2-windows.html)[guía de macos](/install/inniclassic-y2-mac.html)[guía de linux](/install/inniclassic-y2-linux.html)

[Todas las Innioasis Y2 guías](/install/y2.html) · [Todas las Inniclassic guías](/install/inniclassic.html)

## instalarlo
  - Abra Innioasis Updater CE en su computadora (si aún no lo tiene, [Obtener Updater CE](../guide_es.html#platform)). Seleccionar Y2 en Modelo del dispositivo.
  - elegir Inniclassic en Software (o iniciar con [Obtener en Updater CE](../guide_es.html?model=Y2&software=inniclassic-y2)).
  - Seleccione una versión y haga clic Instalar / Restaurar.
  - Apague y conecte el Y2 solo cuando el Actualizador se lo indique.
  - Utilice Y2 Software original para la ruta de restauración.

## Mantén la conexión quietaInstrucciones de conexión con UpdaterConecta solo cuando aparezca el aviso.

Y2 uso de paquetes `rom_y2.zip`. Si la instalación falla, tenga en cuenta si la falla ocurrió antes o después de que Updater detectara el reproductor.
