# Как установить Reborn (Y2Linux / Y2Reborn) на Innioasis Y2 - Innioasis загрузки прошивки

Innioasis Y2 · Учебное пособие по установке

# Установите Reborn (Y2Linux) на свой Innioasis Y2.

Выполните следующие действия, чтобы прошить Reborn (Y2Linux / Y2Reborn) на Innioasis Y2 с помощью Innioasis Updater CE, затем завершите послеустановочную настройку Wi-Fi и Bluetooth.[Скачать Updater CE](../guide_ru.html#download-updater)[Почему Reborn (Y2Linux)?](../reborn-y2linux-benefits_ru.html)[Y2Reborn Релизы](../firmware_ru.html?model=Y2&software=reborn-y2linux-y2)

Руководство по установке для вашего компьютера

## Установите Reborn (Y2Linux) на свой Y2 с помощью компьютера.

Выберите руководство для компьютера, который вы используете. В каждой версии есть настройка платформы, Updater CE шагов и возврат к стоку.[Руководство по Windows](/install/reborn-y2linux-y2-windows.html)[руководство по macOS](/install/reborn-y2linux-y2-mac.html)[Руководство по Linux](/install/reborn-y2linux-y2-linux.html)

[Все Innioasis Y2 руководства](/install/y2.html) · [Все руководства Reborn (Y2Linux)](/install/reborn.html)

## Пошаговая установка
  - Установите программу обновления CE: Скачать [Innioasis Программа обновления CE](../guide_ru.html) для Windows, macOS или Linux, затем откройте его.
  - Выберите Y2: Выбирать Y2 как модель устройства.
  - Выберите Reborn: Выбирать Reborn (Y2Linux) и последний выпуск.
  - Установить: Нажмите Установить / Восстановить, выключите Y2 и подсоедините USB при появлении соответствующего запроса.
  - Ждать: Держите плеер неподвижно до тех пор, пока программа обновлений CE не подтвердит, а затем отключитесь.
  - Настройте Wi-Fi, Bluetooth и FM-радио

Копировать `system.img` игроку один раз. Reborn делает все остальное.[Завершить настройку →](../y2reborn_wifibt_ru.html)

## Возврат к исходному программному обеспечению

Вы можете вернуть Y2 заводское программное обеспечение в любое время, выбрав Y2 и Заводское ПО в программе обновления CE. См. [Y2 руководство по восстановлению](restore-original-y2_ru.html).
