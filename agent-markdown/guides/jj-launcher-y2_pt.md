## Instale JJ Launcher em seu Y2 com seu computador

Escolha o guia para o computador que você está usando. Cada versão possui a configuração da plataforma, Updater CE etapas e o caminho de volta ao estoque.[Guia do Windows](/install/jj-launcher-y2-windows.html)[guia macOS](/install/jj-launcher-y2-mac.html)[Guia Linux](/install/jj-launcher-y2-linux.html)

## Escolha a rota Y2
  - Abra Innioasis Updater CE no seu computador (se ainda não o tiver, [Obtenha o atualizador CE](../guide_pt.html#platform)). Selecione Y2 em Modelo do dispositivo.
  - Escolher JJ Launcher em Programas (ou lançar com [Obtenha isso em Updater CE](../guide_pt.html?model=Y2&software=jj-launcher-y2)).
  - Leia a nota de lançamento, confirme a entrada Y2 e clique Instalar / Restaurar.
  - Desligue e conecte o player somente quando o Updater solicitar.
  - Restaurar com Y2 Software Original se você precisar da interface de estoque novamente.

## A incompatibilidade de modelo é a primeira coisa a verificar

JJ Launcher também possui uma entrada Y1. Se o nome do pacote parecer errado, retorne ao Modelo do Dispositivo. Não force um pacote Y1 em um Y2.Instruções de conexão do atualizadorConecte-se apenas no prompt ao vivo.

## Volte para o software original

JJ Launcher não altera a rota de volta para a interface padrão. Assim que o Updater estiver configurado para o seu computador, abra-o no Windows, macOS ou Linux e selecione Y2 mais Software Original em vez de JJ Launcher.
  - Escolha uma versão de software original estável Y2.
  - Clique Instalar / Restaurar e aguarde o prompt de conexão ao vivo.
  - Desligue o Y2 somente quando solicitado.
  - Conecte o cabo de dados USB no prompt e deixe-o imóvel até obter sucesso.

Não remova manualmente os arquivos JJ Launcher primeiro e não use um pacote Y1. Se a falha ocorreu antes do prompt USB, verifique primeiro a configuração do computador, o cabo e a seleção do modelo.[Y2 guia de restauração](restore-original-y2_pt.html)[Solução de problemas](../troubleshooting_pt.html)
