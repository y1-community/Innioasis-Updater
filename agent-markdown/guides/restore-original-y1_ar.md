## قم باستعادة البرامج الأصلية الموجودة على جهازك Y1 باستخدام جهاز الكمبيوتر الخاص بك

اختر دليل الكمبيوتر الذي تستخدمه. يحتوي كل إصدار على إعداد النظام الأساسي وخطوات Updater CE وطريقة العودة إلى المخزون.[دليل ويندوز](/install/original-y1-windows.html)[دليل ماك](/install/original-y1-mac.html)[دليل لينكس](/install/original-y1-linux.html)

[جميع أدلة Innioasis Y1](/install/y1.html) · [جميع أدلة البرامج الأصلية](/install/original-software.html)

## من Rockbox أو برنامج مخصص آخر

بمجرد أن يصبح إعداد Windows أو macOS أو Linux ذي الصلة جاهزًا، يستخدم Updater نفس التثبيت الموجه لاستعادة المخزون كما يفعل لتثبيت برنامج مخصص. لا تحتاج إلى حذف Rockbox أو ملفات برنامج مخصص آخر يدويًا أولاً.
  - افتح Innioasis Updater CE على جهاز الكمبيوتر الخاص بك (إذا لم تكن قد قمت بتثبيته بعد، [احصل على Updater CE](../guide_ar.html#platform) ل [ويندوز](../drivers_ar.html#windows), [ماك](../guide_ar.html#macos)أو [لينكس](../drivers_ar.html#linux)).
  - تعيين طراز الجهاز ل Y1.
  - اختر البرنامج الأصلي في البرنامج (أو استخدم [احصل على هذا في Updater CE](../guide_ar.html?model=Y1&software=original-y1)).
  - اختر أحدث إصدار ثابت Y1. الحزمة اليدوية المعتادة هي `rom.zip`. Type A يغطي Y1 المشغلات التي تم شحنها مع الإصدار 2.0.0 من البرنامج الأصلي أو الأحدث؛ Type B يغطي اللاعبين الذين تم شحنهم مع إصدار سابق من [البرنامج الأصلي](../firmware_ar.html?software=original-y1) وقد يستخدم اسم حزمة أكثر تحديدًا.
  - انقر تثبيت / استعادة وانتظر حتى يتم استخراج الحزمة.
يُظهر المُحدِّث خيار Y1 البرنامج الأصلييُظهر المُحدِّث خيار Y1 البرنامج الأصلي.

## قم بتوصيل Y1 في الموجه

يقوم نظام التشغيل بتغيير الإعداد حول Updater، وليس رحلة الاستعادة نفسها. على كل منصة، انتظر المطالبة المباشرة قبل الاتصال.
  - قم بإيقاف تشغيل المشغل بالكامل عندما يطلب منك التحديث ذلك.
  - قم بتوصيل كابل البيانات USB فقط عند المطالبة.
  - لا تلمس المشغل أثناء تشغيل التثبيت.
  - اقطع الاتصال بعد رسالة النجاح وابدأ تشغيل Y1.

## إذا كان لا يزال لا يبدأ

كرر عملية الاستعادة مرة واحدة مع تحديد النموذج والنوع والإصدار. إذا فشل برنامج التحديث قبل المطالبة USB، فافحص إعداد الكمبيوتر وبرنامج التشغيل أو الأذونات وكابل البيانات والملفات المستخرجة. إذا فشل بعد اكتشاف Y1، فاستخدم [دليل استكشاف الأخطاء وإصلاحها](../troubleshooting_ar.html) قبل الانتقال إلى الاسترداد اليدوي SP Flash Tool أو MTKClient.لا تقم بالتبديل إلى ملفات Y2. تحتاج عملية الاستعادة Y1 إلى إصدار البرنامج الأصلي Y1، حتى إذا كان المشغل يقوم حاليًا بتشغيل برنامج مخصص مختلف.
