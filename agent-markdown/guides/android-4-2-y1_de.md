# Installieren Sie Android 4.2 (Dev) auf einem Y1.

Android 4.2 ist eine Community-Entwicklung ROM zum Testen und Hacken auf der Innioasis Y1-Hardware. Wählen Sie Y1 aus, bevor Sie es in Updater CE auswählen.[Updater CE holen](../guide_de.html#platform)[In Updater CE erhalten](../guide_de.html?model=Y1&software=android-4-2-y1)[Projektquelle](https://github.com/y1-community/y1-ata-rom)

Installationsanleitung für Ihren Computer

## Installieren Sie die Android-Entwicklung ROM auf Ihrem Y1 mit Ihrem Computer

Wählen Sie die Anleitung für den Computer aus, den Sie verwenden. Jede Version verfügt über das Plattform-Setup, Updater CE Schritte und den Weg zurück zum Lagerbestand.[Windows-Anleitung](/install/android-4-2-y1-windows.html)[macOS-Anleitung](/install/android-4-2-y1-mac.html)[Linux-Anleitung](/install/android-4-2-y1-linux.html)

[Alle Innioasis Y1-Anleitungen](/install/y1.html) · [Alle Android-Entwicklungs-ROM-Anleitungen](/install/android-dev.html)

## Installieren Sie es
  - Öffnen Sie Innioasis Updater CE auf Ihrem Computer (falls Sie es noch nicht haben, [Updater CE holen](../guide_de.html#platform)). Auswählen Y1 In Gerätemodell.
  - Wählen Sie Android 4.2 (Entwickler) In Software (oder starten Sie mit [In Updater CE erhalten](../guide_de.html?model=Y1&software=android-4-2-y1)).
  - Wählen Sie eine Veröffentlichung aus und klicken Sie Installieren / Wiederherstellen.
  - Schalten Sie das Y1 erst aus und schließen Sie es an, wenn Sie vom Updater dazu aufgefordert werden.
  - Verwenden Sie Y1 Original-Software für den Wiederherstellungspfad.
