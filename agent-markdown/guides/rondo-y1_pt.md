## Instalação passo a passo
  - Abra Updater CE: Lançar [Innioasis Atualizador CE](../guide_pt.html) em seu computador Windows, macOS ou Linux.
  - Escolha o modelo do dispositivo Y1: Selecione Y1 no menu suspenso Modelo do dispositivo (escolha Type B se o seu Y1 for enviado com software original anterior a 2.0.0; caso contrário, mantenha Type A).
  - Escolha Rondo no menu suspenso Software: Selecione Rondo na lista Software e escolha a versão mais recente. Updater CE usa a base Wi-Fi do Android 4.2 ROM e Rondo libera feed automaticamente.
  - Atualize o player: Clique Instalar / Restaurar, desligue seu Y1 completamente e conecte-o por meio de um cabo de dados USB quando Updater CE solicitar.
  - Desconecte e inicialize: Aguarde a mensagem verde de conclusão antes de desconectar seu Y1.
  - Conclua a configuração pós-instalação

Siga as etapas em [este guia](../post_install_pt.html?software=rondo-y1&model=Y1) para concluir a configuração em seu Y1.[Ver guia](../post_install_pt.html?software=rondo-y1&model=Y1)
