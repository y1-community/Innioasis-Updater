# Innioasis Y1 - Innioasis 펌웨어 다운로드에 Koensayr을(를) 설치하는 방법

Koensayr · Innioasis Y1

# Y1에 Koensayr을(를) 설치합니다.

Koensayr은(는) Y1 프로젝트로 나열됩니다. 업데이터가 패키지를 관리하게 한 다음 다른 전체 설치와 마찬가지로 신중하게 전원을 끄고 USB 타이밍을 따르십시오.[Updater CE 받기](../guide_ko.html#platform)[이것을 Updater CE에서 얻으세요](../guide_ko.html?model=Y1&software=koensayr-y1)[왜 Koensayr인가요?](../koensayr-benefits_ko.html)

컴퓨터에 대한 설치 가이드

## 컴퓨터를 사용하여 Y1에 Koensayr을(를) 설치합니다.

사용 중인 컴퓨터에 대한 가이드를 선택하세요. 모든 버전에는 플랫폼 설정, Updater CE 단계 및 재고로 돌아가는 방법이 있습니다.[윈도우 가이드](/install/koensayr-y1-windows.html)[macOS 가이드](/install/koensayr-y1-mac.html)[리눅스 가이드](/install/koensayr-y1-linux.html)

[모든 Innioasis Y1 가이드](/install/y1.html) · [모든 Koensayr 가이드](/install/koensayr.html)

## 설치 단계
  - 컴퓨터에서 Innioasis Updater CE를 엽니다. (아직 없다면, [Updater CE 받기](../guide_ko.html#platform)). 선택 Y1 안으로 기기 모델.
  - 선택 Koensayr 안으로 소프트웨어 (또는 다음으로 시작 [이것을 Updater CE에서 얻으세요](../guide_ko.html?model=Y1&software=koensayr-y1)).
  - 나열된 릴리스를 선택하고 클릭하십시오. 설치 / 복원.
  - 앱이 요청할 때만 전원을 끄고 Y1을 연결하세요.
  - Y1 사용 원본 소프트웨어 재고 경로를 복원합니다.

## 뭔가 실패했을 때

먼저 모델과 유형 선택을 확인하세요. 그런 다음 프롬프트가 표시되기 전에 케이블과 플레이어가 연결되었는지 확인하십시오. 앱이 USB을 기다리기 전에 중지된 경우 다음을 엽니다. [문제 해결](../troubleshooting_ko.html).업데이터 연결 지침안정적인 연결은 설치의 일부입니다.
