# Restore Original Software on Innioasis & Timmkoo A5

Follow this tutorial to restore official factory software on your Innioasis A5 or Timmkoo A5 player with verified packages from the Innioasis Firmware Archive.[Get Updater CE](../guide.html#platform)[View A5 Downloads](../firmware.html?model=A5)

## Step 1: Setup in Updater CE
  - Launch Innioasis Updater CE on your Windows, macOS, or Linux computer.
  - Set Device Model to A5.
  - Select Original Software. Updater CE downloads the official `rom_a5.zip` release package directly.
  - Click Install / Restore and wait for preparation to complete.

## Step 2: Connect at the Prompt
  - Power the A5 device off completely.
  - Wait for the prompt on your computer screen before connecting the USB data cable.
  - Allow the flashing process to finish without interruption.
  - Disconnect and reboot your freshly restored A5 player.
