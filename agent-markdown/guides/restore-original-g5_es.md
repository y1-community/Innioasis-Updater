# Restaurar el software original en Innioasis G5

Utilice este tutorial guiado cuando necesite recuperar un G5 que no responde, actualizar el sistema al estado de fábrica o instalar actualizaciones de firmware oficiales limpias.[Obtener Updater CE](../guide_es.html#platform)[Ver G5 Descargas](../firmware_es.html?model=G5)

Guía de instalación para su computadora

## Restaure el software original en su G5 con su computadora

Elija la guía para la computadora que está utilizando. Cada versión tiene la configuración de la plataforma, Updater CE pasos y el camino de regreso al stock.[guía de windows](/install/original-g5-windows.html)[guía de macos](/install/original-g5-mac.html)[guía de linux](/install/original-g5-linux.html)

[Todas las guías Innioasis G5](/install/g5.html) · [Todas las guías de software originales](/install/original-software.html)

## Paso 1: prepare su computadora

Innioasis Updater CE se ejecuta de forma nativa en Windows, macOS y Linux sin requerir arneses de actualización complejos:
  - Lanzamiento Innioasis Actualizador CE en su computadora de escritorio o portátil.
  - conjunto Modelo del dispositivo a G5.
  - Seleccionar Software original en el menú desplegable de software. Updater CE descarga automáticamente el archivo oficial `rom_g5.zip` lanzar el paquete directamente.
  - Haga clic Instalar / Restaurar para comenzar la preparación.

## Paso 2: conecte el G5 cuando se le solicite

Nunca conecte su reproductor antes de que la aplicación le solicite:
  - Asegúrese de que su Innioasis G5 esté completamente apagado.
  - Cuando Updater muestre el mensaje de conexión USB, conecte su cable de datos USB-C a la computadora y al reproductor.
  - No toque el cable ni los botones de encendido mientras se realiza el flasheo.
  - Una vez que aparezca la confirmación de éxito, desconecte el cable USB y encienda su G5.
