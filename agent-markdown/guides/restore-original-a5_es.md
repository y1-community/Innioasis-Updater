# Restaurar el software original en Innioasis y Timmkoo A5

Siga este tutorial para restaurar el software oficial de fábrica en su reproductor Innioasis A5 o Timmkoo A5 con paquetes verificados del Innioasis Archivo de firmware.[Obtener Updater CE](../guide_es.html#platform)[Ver A5 Descargas](../firmware_es.html?model=A5)

## Paso 1: Configuración en Updater CE
  - Lanzamiento Innioasis Actualizador CE en su computadora con Windows, macOS o Linux.
  - conjunto Modelo del dispositivo a A5.
  - Seleccionar Software original. Updater CE descarga el oficial `rom_a5.zip` lanzar el paquete directamente.
  - Haga clic Instalar / Restaurar y espere a que se complete la preparación.

## Paso 2: Conéctese cuando se le solicite
  - Apague el dispositivo A5 por completo.
  - Espere el mensaje en la pantalla de su computadora antes de conectar el cable de datos USB.
  - Permita que el proceso de flasheo finalice sin interrupción.
  - Desconecta y reinicia tu reproductor A5 recién restaurado.
