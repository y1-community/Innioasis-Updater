# Innioasis G5 공장 초기화: 안전한 단계, 삭제되는 항목

공장 초기화 · Innioasis G5

# Innioasis G5 공장 초기화 방법

좋은 파일을 유지하고 문제를 제거하는 명확한 재설정입니다. 이 페이지에서는 설정 경로, 플레이어 정지 경로 및 재설정이 잘못된 수정 사례를 다룹니다.[G5 수동](../manuals/g5.html)[소프트웨어를 다시 설치하세요.](../guides/restore-original-g5_ko.html)[G5 다운로드](../firmware_ko.html?model=G5)

## 시작하기 전에

공장 초기화를 수행하면 플레이어의 내부 저장소가 지워집니다. microSD 카드가 아닌 플레이어에 저장된 설정, 계정, 재생 목록 및 모든 파일을 제거합니다. 먼저 음악과 녹음을 컴퓨터에 복사하세요. 느린 메뉴만 수정하려면 다음을 사용하세요. 캐시 지우기 대신; 파일은 그대로 둡니다.리셋 구멍은 공장 초기화가 아닙니다. 작은 모델의 경우 재설정 핀을 누르면 플레이어가 정지된 경우에만 강제 종료됩니다. 데이터가 삭제되지 않으며 공장 설정을 복원하지 않습니다.

## 정상 노선
  - 보관하고 싶은 것은 무엇이든 컴퓨터에 복사하세요. 재설정하면 내부 저장소가 지워집니다.
  - 플레이어를 절반 이상 충전하십시오.
  - 열기 설정 플레이어에서.
  - 선택 공장 초기화 그리고 확인합니다.
  - 다시 시작하는 동안 기다리세요. 플러그를 뽑거나 버튼을 누르지 마십시오.

다시 표시되면 언어를 선택하고 Wi-Fi 또는 Bluetooth를 사용하는 경우 다시 연결하세요. microSD 카드는 일반적으로 그대로 두지만 사용하기 전에 확인하십시오.

## 플레이어가 정지된 경우
  - 약 10초간 전원을 유지하세요. 대부분의 플레이어는 강제로 종료됩니다.
  - 그래도 아무 효과가 없으면 작은 버튼을 누르세요. 재설정 핀이나 클립으로 구멍을 뚫습니다.
  - 한 시간 동안 충전한 후 전원을 켜고 설정 경로를 다시 시도해 보세요.

핀은 달리고 있는 플레이어에게만 돌아갈 수 있습니다. 소프트웨어를 재설정하지는 않습니다. 설정 경로가 수행합니다.

## 플레이어가 전혀 시작되지 않는 경우

홈 화면에 도달하지 않은 플레이어에서는 재설정을 실행할 수 없습니다. 그건 설정 문제가 아니라 소프트웨어 문제입니다. 사용 [Innioasis 업데이터 CE](../guide_ko.html) G5의 원본 소프트웨어를 복원하려면 다음을 따르십시오. [G5 복원 가이드](../guides/restore-original-g5_ko.html) 수동 SP Flash Tool 경로의 경우. 플레이어가 전혀 반응하지 않는 경우 다음 내용을 읽어보세요. [회복 가이드](../guides/recovery_ko.html) 먼저.

## 공장 초기화 또는 재설치?

### 공장 초기화

설치된 소프트웨어를 유지하고 데이터를 삭제합니다. 플레이어가 작동하지만 지저분하거나 느리거나 설정이 좋지 않은 경우에 사용하세요.

### 소프트웨어 재설치

시스템 자체를 교체합니다. 플레이어가 부팅되지 않을 때, 업데이트에 실패했을 때 또는 사용자 정의 시스템을 종료하고 원래 소프트웨어로 돌아가고 싶을 때 사용하십시오.

## 사람들이 묻는 질문

### 재설정하면 microSD 카드가 삭제되나요?

일반적으로 그렇지 않습니다. 공장 초기화는 내부 저장소를 대상으로 합니다. 확실하게 하려면 재설정하기 전에 카드를 제거하십시오.

### 사용자 정의 펌웨어를 제거합니까?

아니요. 공장 초기화는 현재 시스템 내부의 데이터를 삭제합니다. Rockbox 또는 다른 사용자 정의 시스템을 제거하려면 대신 원본 소프트웨어를 다시 설치하십시오.

### 얼마나 걸리나요?

몇 분. 10시가 지나도 다시 시작되지 않으면 충전하고 전원 버튼을 눌러보세요. 그래도 응답하지 않으면 복구 가이드를 사용하세요.
