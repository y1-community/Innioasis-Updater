# Instale Koensayr en un Y1.

Koensayr aparece como un proyecto Y1. Deje que Updater administre el paquete, luego siga el mismo apagado cuidadoso y el mismo tiempo USB que las otras instalaciones completas.[Obtener Updater CE](../guide_es.html#platform)[Obtener en Updater CE](../guide_es.html?model=Y1&software=koensayr-y1)[¿Por qué Koensayr?](../koensayr-benefits_es.html)

Guía de instalación para su computadora

## Instala Koensayr en tu Y1 con tu computadora

Elija la guía para la computadora que está utilizando. Cada versión tiene la configuración de la plataforma, Updater CE pasos y el camino de regreso al stock.[guía de windows](/install/koensayr-y1-windows.html)[guía de macos](/install/koensayr-y1-mac.html)[guía de linux](/install/koensayr-y1-linux.html)

[Todas las Innioasis Y1 guías](/install/y1.html) · [Todas las Koensayr guías](/install/koensayr.html)

## Pasos de instalación
  - Abra Innioasis Updater CE en su computadora (si aún no lo tiene, [Obtener Updater CE](../guide_es.html#platform)). Seleccionar Y1 en Modelo del dispositivo.
  - elegir Koensayr en Software (o iniciar con [Obtener en Updater CE](../guide_es.html?model=Y1&software=koensayr-y1)).
  - Seleccione la versión listada y haga clic Instalar / Restaurar.
  - Apague y conecte el Y1 solo cuando la aplicación lo solicite.
  - Usar Y1 Software original para restaurar la ruta de stock.

## Cuando algo falla

Primero verifique la selección de modelo y tipo. Luego verifique el cable y si el reproductor estaba conectado antes del mensaje. Si la aplicación se detuvo antes de esperar a USB, ábrala [solución de problemas](../troubleshooting_es.html).Instrucciones de conexión con UpdaterUna conexión estable es parte de la instalación.
