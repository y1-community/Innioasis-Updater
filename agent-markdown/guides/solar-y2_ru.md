Solar · Innioasis Y2

# Установите Solar на свой Y2.

Solar — это отдельный проект сообщества, и в списке указана сборка Y2. Функции могут измениться, поэтому позвольте программе обновлений показать текущую версию вашей модели.[Скачать Updater CE](../guide_ru.html#platform)[Получите это в Updater CE](../guide_ru.html?model=Y2&software=solar-y2)[Почему Solar?](../solar-benefits_ru.html)

Также доступны: [Solar на Y1](solar-y1_ru.html)

Руководство по установке для вашего компьютера

## Установите Solar на свой Y2 с помощью компьютера.

Выберите руководство для компьютера, который вы используете. В каждой версии есть настройка платформы, Updater CE шагов и возврат к стоку.[Руководство по Windows](/install/solar-y2-windows.html)[руководство по macOS](/install/solar-y2-mac.html)[Руководство по Linux](/install/solar-y2-linux.html)

[Все Innioasis Y2 руководства](/install/y2.html) · [Все Solar руководства](/install/solar.html)

## Выберите маршрут Y2
  - Откройте Innioasis Updater CE на своем компьютере (если у вас его еще нет, [Скачать Updater CE](../guide_ru.html#platform)). Выбирать Y2 в Модель устройства.
  - Выбирать Solar в Программное обеспечение (или запустить с помощью [Получите это в Updater CE](../guide_ru.html?model=Y2&software=solar-y2)).
  - Прочтите примечание к выпуску, подтвердите запись Y2 и нажмите Установить / Восстановить.
  - Выключайте и подключайте плеер только по запросу Updater.
  - Восстановить с помощью Y2 Заводское ПО если вам снова понадобится стандартный интерфейс.

## Держите примечание к проекту на виду

Solar находится в активной разработке. Функции и поддержка моделей могут измениться, поэтому ознакомьтесь с примечаниями к выпуску проекта. Программа обновлений показывает, что доступно для вашей модели прямо сейчас. Не заменяйте пакет Y1, если запись Y2 отсутствует.Инструкция по подключению обновленийПодключайтесь только по интерактивной подсказке.

## Вернуться к исходному программному обеспечению

Solar не меняет маршрут обратно на стандартный интерфейс. Как только программа обновлений будет настроена для вашего компьютера, откройте ее в Windows, macOS или Linux и выберите Y2 плюс Заводское ПО вместо Solar.
  - Выберите стабильную Y2 версию оригинального программного обеспечения.
  - Нажмите Установить / Восстановить и дождитесь приглашения на подключение к реальному времени.
  - Выключайте Y2 только по запросу.
  - Подключите USB-кабель для передачи данных по запросу и оставьте его до успешного завершения.

Не удаляйте сначала файлы Solar вручную и не используйте пакет Y1. Если сбой произошел до появления приглашения USB, сначала проверьте настройку компьютера, кабель и выбор модели.[Y2 руководство по восстановлению](restore-original-y2_ru.html)[Устранение неполадок](../troubleshooting_ru.html)
