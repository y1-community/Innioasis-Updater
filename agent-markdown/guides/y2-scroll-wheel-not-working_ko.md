# Innioasis Y2 업데이트 후 스크롤 휠이 작동하지 않습니다.

휠이 회전하지만 플레이어가 이를 무시하거나 플래시 직후 클릭 휠이 멈췄습니다. 다음은 Y2의 하드웨어 오류에서 펌웨어 오류를 확인하는 방법입니다.[Updater CE 받기](../guide_ko.html#platform)[Y2 소프트웨어 다운로드](../firmware_ko.html?model=Y2&software=original-y2)[복구 가이드](recovery_ko.html)

## 휠이나 펌웨어에 결함이 있는지 확인하십시오.

Y2에서 휠은 물리적 입력이지만 펌웨어는 각 회전과 클릭의 기능을 결정합니다. 소프트웨어에서 포인트를 업데이트하거나 플래시하자마자 멈추는 휠입니다. 모든 소프트웨어(재고, Rockbox 또는 복구 화면)를 무시하는 휠은 해당 부품을 가리킵니다.
  - 한 소프트웨어에서는 작동하고 다른 소프트웨어에서는 작동하지 않습니다. 펌웨어 결함.
  - 복구를 포함한 모든 화면에서 작동하지 않음: 휠, 리본 또는 보드.
  - 한 방향만 누락됨: 일반적으로 링 아래에 잔해가 있거나 마모됩니다.
  - 바퀴가 회전하지만 아무 것도 강조 표시되지 않습니다. 플레이어가 정지되었을 수 있습니다. 먼저 강제로 다시 시작하세요.

## 펌웨어 재설치 전 빠른 확인
  - 전원 버튼을 약 15초 동안 눌러 플레이어를 강제로 끈 다음 정상적으로 시작하세요.
  - 홈 화면, 설정, 음악 플레이어에서 휠을 테스트해 보세요.
  - 물리적인 버튼을 누르세요. 전원과 후진이 반응하는데 바퀴가 반응하지 않으면 바퀴 자체에 결함이 있는 것입니다.
  - 알려진 데이터 케이블을 사용하여 플레이어를 30분 동안 충전하십시오.
  - Y2 또는 다른 사용자 정의 빌드에 대해 Rockbox을 설치한 경우 원본 소프트웨어로 돌아가서 다시 테스트하십시오.

## 플레이어와 일치하는 Y2 펌웨어를 다시 설치하십시오.

휠은 펌웨어에 의해 구동되므로 업데이트 관련 오류는 플레이어에 올바른 Y2 원본 소프트웨어를 다시 설치하여 해결됩니다. Y2에 Y1 패키지를 사용하지 말고 "충분히 가까운" 릴리스를 선택하지 마십시오. Y2 패키지는 Y2 하드웨어용으로 제작되었습니다.
  - 열기 [업데이터 CE](../guide_ko.html#platform) 당신의 컴퓨터에서.
  - 세트 기기 모델 에 Y2.
  - 선택 원본 소프트웨어 안으로 소프트웨어 안정적인 Y2 릴리스를 선택합니다. 수동 패키지는 다음과 같습니다. `rom_y2.zip`.
  - 클릭 설치 / 복원 패키지를 추출해 보겠습니다.
  - Y2의 전원을 완전히 끄고, 업데이터가 요청할 때만 USB 데이터 케이블을 연결하고, 성공 메시지가 나타날 때까지 그대로 두십시오.
모델과 릴리스를 일치시킵니다. 릴리스 목록이 Y1 소프트웨어와 유사하면 중지하고 Y2을(를) 다시 선택하십시오. 전체 단계는 [Y2 복원 가이드](restore-original-y2_ko.html).

## 휠 링에 이물질이나 손상이 있는지 확인하십시오.

바퀴가 뻣뻣하거나, 달라붙거나, 한 방향으로만 고장나는 경우, 포켓 보푸라기와 모래가 링과 케이스 사이에 있을 수 있습니다. 플레이어의 전원을 끄고 마른 극세사 천으로 링 주위를 닦아냅니다. 틈에 세제나 알코올을 떨어뜨리지 말고, 링을 들어올리지 마십시오.

링이 느슨하거나 금이 갔거나 더 이상 딸깍 소리가 나지 않으면 플레이어에 대한 서비스가 필요합니다. 펌웨어는 손상된 휠, 분리된 리본 또는 액체 손상을 복구할 수 없습니다.

## 플레이어도 시작되지 않는 경우

업데이트가 실패하면 Y2을(를) 부팅할 수 없게 될 수 있습니다. 이는 입력이 응답하지 않기 때문에 휠 오류처럼 보입니다. 다음을 통해 작업하세요. [Y2 가이드가 켜지지 않습니다](y2-wont-turn-on_ko.html) 충전, 강제 재시작 및 수동 복구가 가능합니다.

## Innioasis Y2 스크롤 휠 FAQ

### 업데이트 후 Innioasis Y2 스크롤 휠이 작동을 멈춘 이유는 무엇입니까?

업데이트로 인해 휠 드라이버가 나머지 펌웨어와 맞지 않을 수 있습니다. 특히 플래시가 중단되거나 Y1 패키지가 사용된 경우 더욱 그렇습니다. 해당 모델에 대한 Y2 원본 소프트웨어 릴리스를 다시 설치하고 기본 홈 화면에서 휠을 테스트하십시오.

### Y2 클릭 휠이 파손되었거나 펌웨어에 결함이 있는지 어떻게 알 수 있나요?

둘 이상의 소프트웨어에서 휠을 테스트하십시오. 기본 소프트웨어에서는 작동하지만 Rockbox에서는 작동하지 않는 경우 펌웨어 매핑 문제입니다. 복구 메뉴를 포함하여 어떤 화면에서도 아무 작업도 수행되지 않으면 휠, 리본 또는 보드를 의심해 보세요.

### 원본 소프트웨어를 복원하면 Y2 스크롤 휠이 수정됩니까?

업데이트 또는 일치하지 않는 패키지로 인해 발생하는 오류를 수정하며 가장 먼저 시도하는 것입니다. 물리적으로 손상된 휠, 느슨한 리본 또는 액체 손상은 수리할 수 없습니다.

### Y2 휠 문제를 해결하기 위해 Y1 펌웨어 패키지를 사용할 수 있습니까?

아니요. Y1 및 Y2 패키지는 서로 바꿔 사용할 수 없으며 잘못된 모델을 플래싱하면 제어가 더 나빠질 수 있습니다. 설치/복원을 실행하기 전에 모델과 릴리스를 일치시키십시오.
