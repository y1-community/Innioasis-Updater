# Installa Solar sul tuo Y2.

Solar è un progetto comunitario separato ed è elencata una build Y2. Le funzionalità possono cambiare, quindi lascia che Updater mostri la versione corrente per il tuo modello.[Ottieni Updater CE](../guide_it.html#platform)[Ottieni questo in Updater CE](../guide_it.html?model=Y2&software=solar-y2)[Perché Solar?](../solar-benefits_it.html)

Disponibile anche: [Solar su Y1](solar-y1_it.html)

Guida all'installazione per il tuo computer

## Installa Solar sul tuo Y2 con il tuo computer

Scegli la guida per il computer che stai utilizzando. Ogni versione ha la configurazione della piattaforma, Updater CE passaggi e il modo per tornare allo stock.[Guida Windows](/install/solar-y2-windows.html)[guida macOS](/install/solar-y2-mac.html)[Guida Linux](/install/solar-y2-linux.html)

[Tutte le Innioasis Y2 guide](/install/y2.html) · [Tutte le Solar guide](/install/solar.html)

## Scegli il percorso Y2.
  - Apri Innioasis Updater CE sul tuo computer (se non lo hai ancora, [Ottieni Updater CE](../guide_it.html#platform)). Seleziona Y2 dentro Modello del dispositivo.
  - Scegli Solar dentro Software (o avvia con [Ottieni questo in Updater CE](../guide_it.html?model=Y2&software=solar-y2)).
  - Leggere la nota di rilascio, confermare la voce Y2 e fare clic Installa / Ripristina.
  - Spegnere e collegare il lettore solo quando richiesto dall'Updater.
  - Ripristina con Y2 Software originale se hai bisogno di nuovo dell'interfaccia stock.

## Tieni in vista la nota del progetto

Solar è in fase di sviluppo attivo. Le funzionalità e il supporto del modello possono cambiare, quindi controlla le note di rilascio del progetto. Updater mostra cosa è disponibile per il tuo modello in questo momento. Non sostituire un pacchetto Y1 se manca la voce Y2.Istruzioni per la connessione dell'aggiornamentoConnettiti solo al prompt live.

## Torna al software originale

Solar non modifica il percorso di ritorno all'interfaccia stock. Una volta configurato Updater per il tuo computer, aprilo su Windows, macOS o Linux e seleziona Y2 inoltre Software originale invece di Solar.
  - Scegli una versione stabile del software originale Y2 .
  - Fare clic Installa / Ripristina e attendi la richiesta di connessione live.
  - Spegnere il Y2 solo quando richiesto.
  - Collegare il cavo dati USB quando richiesto e lasciarlo fermo fino al successo.

Non rimuovere prima manualmente i file Solar e non utilizzare un pacchetto Y1. Se l'errore si è verificato prima della richiesta USB, controllare prima la configurazione del computer, il cavo e la selezione del modello.[Guida al ripristino Y2](restore-original-y2_it.html)[Risoluzione dei problemi](../troubleshooting_it.html)
