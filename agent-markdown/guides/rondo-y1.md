## Step-by-step installation
  - Open Updater CE: Launch [Innioasis Updater CE](../guide.html) on your Windows, macOS, or Linux computer.
  - Choose Device Model Y1: Select Y1 in the Device Model dropdown (choose Type B if your Y1 shipped with Original Software earlier than 2.0.0; otherwise keep Type A).
  - Choose Rondo from the Software dropdown: Select Rondo in the Software list and pick the latest release. Updater CE uses the Android 4.2 Wi-Fi base ROM and Rondo release feed automatically.
  - Install onto the player: Click Install / Restore, power your Y1 completely off, and connect it via a USB data cable when Updater CE prompts you.
  - Disconnect and boot: Wait for the green completion message before unplugging your Y1.
  - Complete setup after install
