# Innioasis G5에서 원본 소프트웨어 복원

응답하지 않는 G5을(를) 복구하거나, 시스템을 공장 상태로 새로 고치거나, 깨끗한 공식 펌웨어 업데이트를 설치해야 하는 경우 이 안내 튜토리얼을 사용하십시오.[Updater CE 받기](../guide_ko.html#platform)[G5 다운로드 보기](../firmware_ko.html?model=G5)

컴퓨터에 대한 설치 가이드

## 컴퓨터를 사용하여 G5의 원본 소프트웨어를 복원하세요.

사용 중인 컴퓨터에 대한 가이드를 선택하세요. 모든 버전에는 플랫폼 설정, Updater CE 단계 및 재고로 돌아가는 방법이 있습니다.[윈도우 가이드](/install/original-g5-windows.html)[macOS 가이드](/install/original-g5-mac.html)[리눅스 가이드](/install/original-g5-linux.html)

[모든 Innioasis G5 가이드](/install/g5.html) · [모든 원본 소프트웨어 가이드](/install/original-software.html)

## 1단계: 컴퓨터 준비

Innioasis 업데이터 CE는 복잡한 플래싱 하네스 없이도 Windows, macOS 및 Linux에서 기본적으로 실행됩니다.
  - 발사 Innioasis 업데이터 CE 데스크탑이나 노트북에서.
  - 세트 기기 모델 에 G5.
  - 선택 원본 소프트웨어 소프트웨어 드롭다운에서 업데이터 CE는 자동으로 공식 다운로드를 다운로드합니다. `rom_g5.zip` 패키지를 직접 출시하세요.
  - 클릭 설치 / 복원 준비를 시작합니다.

## 2단계: 프롬프트에서 G5을 연결합니다.

응용 프로그램에서 다음 메시지를 표시하기 전에는 플레이어를 연결하지 마십시오.
  - Innioasis G5의 전원이 완전히 꺼져 있는지 확인하세요.
  - 업데이터가 USB 연결 프롬프트를 표시하면 USB-C 데이터 케이블을 컴퓨터와 플레이어에 연결하십시오.
  - 깜박이는 동안 케이블이나 전원 버튼을 만지지 마십시오.
  - 성공 확인 메시지가 나타나면 USB 케이블을 분리하고 G5의 전원을 켜세요.
