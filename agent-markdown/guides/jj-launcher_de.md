# So installieren Sie JJ Launcher auf Ihren Innioasis Y1 oder Y2 – Innioasis Firmware-Downloads

JJ Launcher · Y1 und Y2

# Installieren Sie JJ Launcher, nachdem Sie das Modell ausgewählt haben.

Der Projektname wird geteilt, aber das verfügbare Paket hängt immer noch davon ab, ob Ihr Player ein Y1 oder ein Y2 ist. Wählen Sie unten Ihr Modell aus und die Anleitung passt zum Paket.[Updater CE holen](../guide_de.html#platform)[JJ Launcher auf Y1](jj-launcher-y1_de.html)[JJ Launcher auf Y2](jj-launcher-y2_de.html)

## Welchen Leitfaden soll ich verwenden?

Sowohl Y1- als auch Y2-Spieler installieren JJ Launcher über Innioasis Updater CE (wenn Sie die App benötigen, [Updater CE holen](../guide_de.html#platform) für Ihren PC oder starten Sie mit [In Updater CE erhalten](../guide_de.html?model=Y1&software=jj-launcher-y1)). Wählen Sie unten Ihr Modell:

### Innioasis Y1

Folgen Sie der modellspezifischen Route Y1 und lassen Sie das Paket Y1 ausgewählt.[Y1 Installationsschritte](jj-launcher-y1_de.html)

### Innioasis Y2

Folgen Sie der modellspezifischen Route Y2 und lassen Sie das Paket Y2 ausgewählt.[Y2 Installationsschritte](jj-launcher-y2_de.html)
