# Install Solar on your Y1.

Install guide for your computer

## Install Solar on your Y1 with your computer

Pick the guide for the computer you are using. Every version has the platform setup, Updater CE steps and the way back to stock.[Windows guide](/install/solar-y1-windows.html)[macOS guide](/install/solar-y1-mac.html)[Linux guide](/install/solar-y1-linux.html)

[All Innioasis Y1 guides](/install/y1.html) · [All Solar guides](/install/solar.html)

## Choose the Y1 route
  - Open Innioasis Updater CE on your computer (if you don't have it yet, [Get Updater CE](../guide.html#platform)). Select Y1 in Device Model.
  - Choose Solar in Software (or launch with [Get this in Updater CE](../guide.html?model=Y1&software=solar-y1)).
  - Read the release note, select a version, and click Install / Restore.
  - Power off and connect the player only when Updater asks.
  - Restore with Y1 Original Software if you need the stock interface again.

## Keep the project note in view

Solar is under active development. Features and model support can change, so check the project’s release notes. Updater shows what’s available for your model right now.Updater connection instructionsConnect only at the live prompt.

## Go back to Original Software

Solar does not change the route back to the stock interface. Once Updater is set up for your computer, open it on Windows, macOS, or Linux and select Y1 plus Original Software instead of Solar.
  - Choose a stable Y1 Original Software release.
  - Click Install / Restore and wait for the live connection prompt.
  - Power off the Y1 only when asked.
  - Connect the USB data cable at the prompt and leave it still until success.

Do not manually remove Solar files first, and do not use a Y2 package. If the failure happened before the USB prompt, check the computer setup, cable, and model selection first.[Y1 restore guide](restore-original-y1.html)[Troubleshooting](../troubleshooting.html)
