# Installieren Sie Inniclassic auf einem Y2.

Inniclassic verfügt über einen eigenen Y2-Port, der von Jonasz Potoniec verwaltet wird. Wählen Sie Y2 aus, bevor Sie es auswählen, damit die Release-Liste modellabhängig bleibt.[Updater CE holen](../guide_de.html#platform)[In Updater CE erhalten](../guide_de.html?model=Y2&software=inniclassic-y2)[Warum Inniclassic?](../inniclassic-benefits_de.html)

Installationsanleitung für Ihren Computer

## Installieren Sie Inniclassic auf Ihrem Y2 mit Ihrem Computer

Wählen Sie die Anleitung für den Computer aus, den Sie verwenden. Jede Version verfügt über das Plattform-Setup, Updater CE Schritte und den Weg zurück zum Lagerbestand.[Windows-Anleitung](/install/inniclassic-y2-windows.html)[macOS-Anleitung](/install/inniclassic-y2-mac.html)[Linux-Anleitung](/install/inniclassic-y2-linux.html)

[Alle Innioasis Y2-Anleitungen](/install/y2.html) · [Alle Inniclassic Anleitungen](/install/inniclassic.html)

## Installieren Sie es
  - Öffnen Sie Innioasis Updater CE auf Ihrem Computer (falls Sie es noch nicht haben, [Updater CE holen](../guide_de.html#platform)). Auswählen Y2 In Gerätemodell.
  - Wählen Sie Inniclassic In Software (oder starten Sie mit [In Updater CE erhalten](../guide_de.html?model=Y2&software=inniclassic-y2)).
  - Wählen Sie eine Veröffentlichung aus und klicken Sie Installieren / Wiederherstellen.
  - Schalten Sie das Gerät aus und schließen Sie Y2 nur dann an, wenn Sie vom Updater dazu aufgefordert werden.
  - Verwenden Sie Y2 Original-Software für den Wiederherstellungspfad.

## Halten Sie die Verbindung aufrechtAnweisungen zum Verbinden mit UpdaterErst verbinden, wenn die Aufforderung erscheint.

Y2 Pakete verwenden `rom_y2.zip`. Wenn die Installation fehlschlägt, notieren Sie, ob der Fehler aufgetreten ist, bevor oder nachdem Updater den Player erkannt hat.
