# Innioasis Y2 - Innioasis ファームウェアのダウンロードに Android 4.4 (Dev) をインストールする方法

Android 4.4 (開発) · Innioasis Y2

# Android 4.4 (Dev) を Y2 にインストールします。

Android 4.4 は、Innioasis Y2 ハードウェアのテストとハッキングを目的としたコミュニティ開発 ROM です。 Updater CEで選択する前にY2を選択してください。[Updater CE を入手](../guide_ja.html#platform)[Updater CE で入手](../guide_ja.html?model=Y2&software=android-4-4-y2)[プロジェクトソース](https://github.com/y1-community/y2-ata-rom)

お使いのコンピューターのインストールガイド

## コンピュータを使用して Android 開発 ROM を Y2 にインストールします

使用しているコンピュータのガイドを選択してください。 すべてのバージョンには、プラットフォームのセットアップ、Updater CE の手順、および在庫に戻る方法が含まれています。[Windowsガイド](/install/android-4-4-y2-windows.html)[macOS ガイド](/install/android-4-4-y2-mac.html)[Linuxガイド](/install/android-4-4-y2-linux.html)

[すべての Innioasis Y2 ガイド](/install/y2.html) · [すべての Android 開発 ROM ガイド](/install/android-dev.html)

## インストールしてください
  - コンピュータで Innioasis Updater CE を開きます (まだお持ちでない場合は、 [Updater CE を入手](../guide_ja.html#platform)）。選択 Y2 で デバイスモデル.
  - 選択してください Android 4.4 (開発版) で ソフトウェア (または次のように起動します) [Updater CE で入手](../guide_ja.html?model=Y2&software=android-4-4-y2)).
  - リリースを選択してクリックします インストール / 復元.
  - アップデーターが要求した場合にのみ、電源を切り、Y2 を接続してください。
  - Y2 を使用します 純正ソフトウェア 復元パスの場合。

## 開発者ビルドノート開発者ビルド: 実験用の開発画像です。現在のハードウェア サポートと既知の問題については、リリース ノートをお読みください。Updater への接続手順案内が表示されてから接続してください。
