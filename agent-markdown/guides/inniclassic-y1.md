## Install it
  - Open Innioasis Updater CE on your computer (if you don't have it yet, [Get Updater CE](../guide.html#platform)). Select Y1 in Device Model.
  - Choose Inniclassic in Software (or launch with [Get this in Updater CE](../guide.html?model=Y1&software=inniclassic-y1)).
  - Select a release and click Install / Restore.
  - Power off and connect the Y1 only when Updater prompts you.
  - Use Y1 Original Software for the restore path.

## Keep the connection stillUpdater connection instructionsThe exact prompt can vary by platform.

If the install fails, note whether the failure happened before or after Updater detected the player. That detail makes troubleshooting much faster.
