# Y1에 Better-Y을(를) 설치합니다.

Better-Y은 Leska1337이 만든 Innioasis Y1에 대한 향상된 스톡 환경입니다. 모델과 일치하는 패키지를 설치하려면 선택하기 전에 Y1를 선택하세요.[Updater CE 받기](../guide_ko.html#platform)[이것을 Updater CE에서 얻으세요](../guide_ko.html?model=Y1&software=better-y-y1)[왜 Better-Y인가요?](../better-y-benefits_ko.html)

컴퓨터에 대한 설치 가이드

## 컴퓨터를 사용하여 Y1에 Better-Y을(를) 설치합니다.

사용 중인 컴퓨터에 대한 가이드를 선택하세요. 모든 버전에는 플랫폼 설정, Updater CE 단계 및 재고로 돌아가는 방법이 있습니다.[윈도우 가이드](/install/better-y-y1-windows.html)[macOS 가이드](/install/better-y-y1-mac.html)[리눅스 가이드](/install/better-y-y1-linux.html)

[모든 Innioasis Y1 가이드](/install/y1.html) · [모든 Better-Y 가이드](/install/better-y.html)

## 설치하세요
  - 컴퓨터에서 Innioasis Updater CE를 엽니다. (아직 없다면, [Updater CE 받기](../guide_ko.html#platform)). 선택 Y1 안으로 기기 모델.
  - 선택 Better-Y 안으로 소프트웨어 (또는 다음으로 시작 [이것을 Updater CE에서 얻으세요](../guide_ko.html?model=Y1&software=better-y-y1)).
  - 릴리스를 선택하고 클릭하세요. 설치 / 복원.
  - 전원을 끄고 업데이터가 메시지를 표시할 때만 Y1을 연결하세요.
  - Y1 사용 원본 소프트웨어 복원 경로에 대해

## 계속 연결을 유지하세요업데이터 연결 지침라이브 프롬프트에서만 연결하십시오.

깜박임이 완료되는 동안 플레이어를 가만히 두십시오. 업데이터가 성공을 확인하면 플레이어의 플러그를 뽑고 전원을 켜십시오.

## Better-Y 단축키 및 팁
  - 지금 재생 중으로 이동 — 화면이나 메뉴에서 재생/일시 정지 버튼을 두 번 누르면 즉시 재생으로 돌아갑니다.
  - 긴급 재부팅 — 플레이어가 응답하지 않는 경우 위쪽 버튼과 아래쪽 버튼을 함께 눌러 하드웨어를 완전히 재부팅하세요.
  - 알파벳 스크롤 — 긴 트랙 목록에서 알파벳순 빠른 인덱스 바를 활성화하려면 가장자리를 따라 클릭 휠을 돌리십시오.
  - 대화형 지금 재생 중 아이콘 — 좋아요, 임의 재생, 반복(1/전체), 가사, A-B 루프, 대기열, 북마크, 속도 및 절전 타이머에 대한 화면 아이콘을 누릅니다.
  - 태그 분할 — 트랙이 각 아티스트 아래에 개별적으로 표시되도록 하려면 여러 아티스트를 쉼표(,) 또는 세미콜론(;)으로 구분합니다. 다중 장르 태그는 쉼표, 세미콜론 또는 슬래시로 구분됩니다.
