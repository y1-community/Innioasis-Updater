## Choose the Y1 route
  - Open Innioasis Updater CE on your computer (if you don't have it yet, [Get Updater CE](../guide.html#platform)). Select Y1 in Device Model.
  - Choose JJ Launcher in Software (or launch with [Get this in Updater CE](../guide.html?model=Y1&software=jj-launcher-y1)).
  - Read the release note, select the Y1 version, and click Install / Restore.
  - Power off and connect the player only when Updater asks.
  - Restore with Y1 Original Software if you need the stock interface again.

## Model mismatch is the first thing to check

JJ Launcher also has a Y2 entry. If the package name looks wrong, return to Device Model. Do not force a Y2 package onto a Y1.Updater connection instructionsConnect only at the live prompt.

## Go back to Original Software

JJ Launcher does not change the route back to the stock interface. Once Updater is set up for your computer, open it on Windows, macOS, or Linux and select Y1 plus Original Software instead of JJ Launcher.
  - Choose a stable Y1 Original Software release.
  - Click Install / Restore and wait for the live connection prompt.
  - Power off the Y1 only when asked.
  - Connect the USB data cable at the prompt and leave it still until success.

Do not manually remove JJ Launcher files first, and do not use a Y2 package. If the failure happened before the USB prompt, check the computer setup, cable, and model selection first.[Y1 restore guide](restore-original-y1.html)[Troubleshooting](../troubleshooting.html)
