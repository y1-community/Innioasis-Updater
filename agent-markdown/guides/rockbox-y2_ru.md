## Следите за маршрутом Rockbox

Видео от Frawgeeys. Он работает как для моделей Y1, так и для Y2 — в Innioasis Updater CE выберите Y2 как ваша модель. Описанные ниже шаги описывают последовательность установки Y2.

Видео автор [Кристиан Плаза](https://www.youtube.com/@CristianPlaza) (Испанский). Он демонстрирует установку на Y1; выбирать Y2 в Updater CE для этого руководства.

## Прежде чем нажать кнопку «Установить»

Имейте в наличии заряженный Innioasis Y2, кабель для передачи данных USB и компьютер с установленным Innioasis Updater CE (если вы еще не установили его, [Скачать Updater CE](../guide_ru.html#platform) для Windows, macOS или Linux). Не используйте выпуск Y1 только потому, что его имя похоже.Проверка модели: Y2 пакеты полной установки могут использовать `rom_y2.zip`. Имя файла является полезным подсказкой для загрузки вручную, но программа обновлений должна сделать выбор пакета за вас.

## Выберите Y2 в программе обновлений.
  - Откройте Updater CE (или запустите с помощью [Получите это в Updater CE](../guide_ru.html?model=Y2&software=rockbox-y2)) и установите Модель устройства в адрес Y2.
  - Выбирать Rockbox в Программное обеспечение.
  - Выберите выпуск, указанный для Y2. Если в списке нет версии Y2, не заменяйте версию Y1.
  - Нажмите Установить / Восстановить и позвольте Updater CE загрузить пакет непосредственно из версии разработчика сообщества.

## Выключите питание, затем подключите
  - Подождите, пока появится приглашение на подключение к реальному времени.
  - Полностью выключите Y2. Используйте точную инструкцию сброса или восстановления, показанную программой обновления, если нормальное завершение работы не удалось.
  - Когда вас спросят, подключите кабель USB. Оставьте его до появления сообщения о завершении.
  - Безопасно отключитесь и запустите Y2.
Инструкция по подключению программы обновления для выключенного устройстваЭкран подключения является справочным. Подсказка Y2 может содержать другую формулировку модели.

## Вернуться к исходному программному обеспечению

Rockbox не привязывает вас к пользовательскому программному обеспечению. После настройки Updater для вашего компьютера используйте его в Windows, macOS или Linux, чтобы вернуться из Rockbox или другого проекта в списке: выберите Y2, выбирать Заводское ПОи запустить Установить / Восстановить.
  - Подождите, пока программа обновлений подготовит стандартный пакет Y2.
  - Выключите Y2, когда приложение спросит.
  - Подключайте кабель передачи данных USB только при появлении подсказки в режиме реального времени.
  - Оставьте плеер неподвижным до появления сообщения об успехе.

Пакеты Y1 и Y2 храните отдельно. Не удаляйте сначала вручную Rockbox файлов; восстановление заменяет системное программное обеспечение.[Y2 руководство по восстановлению](restore-original-y2_ru.html)[Устранение неполадок](../troubleshooting_ru.html)
