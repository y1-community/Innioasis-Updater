## Schritt-für-Schritt-Installation
  - Installieren Sie Updater CE: Herunterladen [Innioasis Updater CE](../guide_de.html) für Windows, macOS oder Linux, dann öffnen Sie es.
  - Wählen Sie Y2: Wählen Sie Y2 als Gerätemodell.
  - Wählen Sie Reborn: Wählen Sie Reborn (Y2Linux) und die neueste Version.
  - Installieren: Klicken Sie Installieren / Wiederherstellen, schalten Sie Y2 aus und schließen Sie USB an, wenn Sie dazu aufgefordert werden.
  - Warten: Halten Sie den Player still, bis Updater CE bestätigt, und trennen Sie dann die Verbindung.
  - Richten Sie WLAN, Bluetooth und UKW-Radio ein

Kopieren `system.img` einmal an den Spieler. Reborn erledigt den Rest.[Einrichtung abschließen →](../y2reborn_wifibt_de.html)

## Rückkehr zur Originalsoftware

Sie können Ihre Y2 jederzeit auf die Werkssoftware zurücksetzen, indem Sie wählen Y2 und Original-Software in Updater CE. Siehe die [Y2 Tutorial zur Wiederherstellung](restore-original-y2_de.html).
