# 如何在 Innioasis Y2 - Innioasis 上安裝 Reborn (Y2Linux / Y2Reborn) 韌體下載

Innioasis Y2 · 安裝教學課程

# 在您的 Innioasis Y2 上安裝 Reborn (Y2Linux)。

請依照以下步驟進行刷機 Reborn (Y2Linux / Y2Reborn) 使用 Innioasis 更新程式 CE 到 Innioasis Y2，然後完成安裝後 Wi-Fi 和藍牙設定。[取得 Updater CE](../guide_zh-TW.html#download-updater)[為什麼是Reborn（Y2Linux）？](../reborn-y2linux-benefits_zh-TW.html)[Y2Reborn 發布](../firmware_zh-TW.html?model=Y2&software=reborn-y2linux-y2)

適用於您的電腦的安裝指南

## 使用計算機在 Y2 上安裝 Reborn (Y2Linux)

選擇適合您正在使用的計算機的指南。 每個版本都有平台設定、Updater CE步驟和返回庫存的方式。[Windows 指南](/install/reborn-y2linux-y2-windows.html)[macOS 指南](/install/reborn-y2linux-y2-mac.html)[Linux指南](/install/reborn-y2linux-y2-linux.html)

[所有 Innioasis Y2 指南](/install/y2.html) · [所有 Reborn (Y2Linux) 指南](/install/reborn.html)

## 逐步安裝
  - 安裝更新程式 CE： 下載 [Innioasis 更新程式 CE](../guide_zh-TW.html) 對於 Windows、macOS 或 Linux，然後開啟它。
  - 選擇Y2： 選擇 Y2 作為設備型號。
  - 選擇Reborn： 選擇 Reborn (Y2Linux) 和最新版本。
  - 安裝： 點選 安裝 / 還原，關閉 Y2 電源，並在出現提示時連接 USB。
  - 等待： 保持播放器靜止，直到更新程式 CE 確認，然後斷開連接。
  - 設定 Wi-Fi、藍牙和 FM 收音機

複製 `system.img` 給玩家一次。 Reborn 完成剩下的工作。[完成設定 →](../y2reborn_wifibt_zh-TW.html)

## 返回原始軟體

您可以隨時選擇將 Y2 返回工廠軟體 Y2 和 原廠軟體 在更新程式 CE 中。請參閱 [Y2恢復教程](restore-original-y2_zh-TW.html).
