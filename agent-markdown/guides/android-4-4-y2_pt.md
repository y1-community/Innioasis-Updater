# Instale o Android 4.4 (Dev) em um Y2.

O Android 4.4 é um desenvolvimento da comunidade ROM para testes e hacking no hardware Innioasis Y2. Selecione Y2 antes de escolhê-lo em Updater CE.[Obtenha o atualizador CE](../guide_pt.html#platform)[Obtenha isso em Updater CE](../guide_pt.html?model=Y2&software=android-4-4-y2)[Fonte do projeto](https://github.com/y1-community/y2-ata-rom)

Guia de instalação para o seu computador

## Instale o desenvolvimento Android ROM em seu Y2 com seu computador

Escolha o guia para o computador que você está usando. Cada versão possui a configuração da plataforma, Updater CE etapas e o caminho de volta ao estoque.[Guia do Windows](/install/android-4-4-y2-windows.html)[guia macOS](/install/android-4-4-y2-mac.html)[Guia Linux](/install/android-4-4-y2-linux.html)

[Todos Innioasis Y2 guias](/install/y2.html) · [Todos os guias de desenvolvimento Android ROM](/install/android-dev.html)

## Instale-o
  - Abra Innioasis Updater CE no seu computador (se ainda não o tiver, [Obtenha o atualizador CE](../guide_pt.html#platform)). Selecione Y2 em Modelo do dispositivo.
  - Escolher Android 4.4 (desenvolvimento) em Programas (ou lançar com [Obtenha isso em Updater CE](../guide_pt.html?model=Y2&software=android-4-4-y2)).
  - Selecione uma versão e clique em Instalar / Restaurar.
  - Desligue e conecte o Y2 somente quando o Updater solicitar.
  - Usar Y2 Software Original para o caminho de restauração.
