# Innioasis & Timmkoo A5 の元のソフトウェアを復元します

このチュートリアルに従って、Innioasis ファームウェア アーカイブからの検証済みパッケージを使用して、Innioasis A5 または Timmkoo A5 プレーヤー上の公式の出荷時ソフトウェアを復元します。[Updater CE を入手](../guide_jp.html#platform)[A5 ダウンロードを表示](../firmware_jp.html?model=A5)

## ステップ 1: Updater CE でのセットアップ
  - 打ち上げ Innioasis アップデーター CE Windows、macOS、または Linux コンピューター上で。
  - セット デバイスモデル 支援先: A5.
  - 選択 純正ソフトウェア。 Updater CE は公式をダウンロードします `rom_a5.zip` パッケージを直接リリースします。
  - クリック インストール / 復元 そして準備が完了するまで待ちます。

## ステップ 2: プロンプトに応じて接続する
  - A5 デバイスの電源を完全にオフにします。
  - USB データ ケーブルを接続する前に、コンピュータ画面にプロンプ​​トが表示されるのを待ってください。
  - 点滅プロセスが中断せずに完了するまで待ちます。
  - 新しく復元した A5 プレーヤーを切断して再起動します。
