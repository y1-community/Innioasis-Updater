# 在 Innioasis A5 - Innioasis 韌體下載上恢復原始軟體

恢復指南·模型A5

# 恢復 Innioasis 和 Timmkoo A5 上的原始軟體

依照本教學使用 Innioasis 韌體檔案中經過驗證的軟體包在 Innioasis A5 或 Timmkoo A5 播放器上恢復官方出廠軟體。[取得 Updater CE](../guide_zh-TW.html#platform)[查看 A5 下載](../firmware_zh-TW.html?model=A5)

## 第 1 步：在 Updater CE 中設置
  - 發射 Innioasis 更新程式 CE 在您的 Windows、macOS 或 Linux 電腦上。
  - 套裝 裝置型號 到 A5.
  - 選擇 原廠軟體。 Updater CE下載官方 `rom_a5.zip` 直接發布包。
  - 點選 安裝 / 還原 並等待準備完成。

## 第 2 步：根據提示進行連接
  - 完全關閉 A5 設備的電源。
  - 等待電腦螢幕上的提示，然後連接 USB 數據線。
  - 讓閃爍過程不間斷地完成。
  - 斷開連線並重新啟動剛剛恢復的 A5 播放器。
