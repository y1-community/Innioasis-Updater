# Як інсталювати Inniclassic на Innioasis Y1 - Innioasis завантаження мікропрограми

Inniclassic · Innioasis Y1

# Встановіть Inniclassic на Y1.

Inniclassic вказано як проект Y1. Виберіть Y1, перш ніж вибрати його, щоб список випусків залишався з урахуванням моделі.[Отримати Updater CE](../guide_uk.html#platform)[Отримайте це в Updater CE](../guide_uk.html?model=Y1&software=inniclassic-y1)[Чому Inniclassic?](../inniclassic-benefits_uk.html)

Посібник із встановлення для вашого комп’ютера

## Встановіть Inniclassic на свій Y1 разом із комп’ютером

Виберіть посібник для комп’ютера, яким ви користуєтеся. Кожна версія має налаштування платформи, Updater CE кроків і шлях повернення до запасу.[Керівництво по Windows](/install/inniclassic-y1-windows.html)[посібник з macOS](/install/inniclassic-y1-mac.html)[Керівництво по Linux](/install/inniclassic-y1-linux.html)

[Усі Innioasis Y1 посібники](/install/y1.html) · [Усі Inniclassic посібники](/install/inniclassic.html)

## Встановіть його
  - Відкрийте Innioasis Updater CE на своєму комп’ютері (якщо у вас його ще немає, [Отримати Updater CE](../guide_uk.html#platform)). Виберіть Y1 в Модель пристрою.
  - Виберіть Inniclassic в Програмне забезпечення (або запустити за допомогою [Отримайте це в Updater CE](../guide_uk.html?model=Y1&software=inniclassic-y1)).
  - Виберіть випуск і натисніть Встановити / Відновити.
  - Вимкніть живлення та підключіть Y1 лише тоді, коли програма оновлення підкаже.
  - Використовуйте Y1 Заводське ПЗ для шляху відновлення.

## Зберігайте зв'язокІнструкції з підключення програми оновленняТочне підказка може відрізнятися залежно від платформи.

Якщо інсталяція не вдається, зверніть увагу, чи сталася помилка до чи після того, як програма оновлення виявила програвач. Ця деталь значно пришвидшує усунення несправностей.
