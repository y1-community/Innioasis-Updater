# Відновити оригінальне програмне забезпечення на Innioasis G5

Використовуйте цей підручник, коли вам потрібно відновити G5, який не відповідає, оновити систему до заводського стану або встановити чисті офіційні оновлення мікропрограми.[Отримати Updater CE](../guide_uk.html#platform)[Переглянути G5 завантажень](../firmware_uk.html?model=G5)

Посібник із встановлення для вашого комп’ютера

## Відновіть оригінальне програмне забезпечення на G5 за допомогою комп’ютера

Виберіть посібник для комп’ютера, яким ви користуєтеся. Кожна версія має налаштування платформи, Updater CE кроків і шлях повернення до запасу.[Керівництво по Windows](/install/original-g5-windows.html)[посібник з macOS](/install/original-g5-mac.html)[Керівництво по Linux](/install/original-g5-linux.html)

[Усі Innioasis G5 посібники](/install/g5.html) · [Усі посібники з оригінального програмного забезпечення](/install/original-software.html)

## Крок 1. Підготуйте комп’ютер

Innioasis Updater CE працює на Windows, macOS і Linux, не вимагаючи складних програм для перепрошивки:
  - Запуск Innioasis Оновлення CE на робочому столі чи ноутбуці.
  - встановити Модель пристрою для G5.
  - Виберіть Заводське ПЗ у спадному списку програмного забезпечення. Updater CE автоматично завантажує офіц `rom_g5.zip` випуск пакета безпосередньо.
  - Натисніть Встановити / Відновити щоб почати підготовку.

## Крок 2: Під’єднайте G5 у підказці

Ніколи не підключайте плеєр до того, як програма запропонує:
  - Переконайтеся, що Innioasis G5 повністю вимкнено.
  - Коли програма оновлення відобразить запит на підключення USB, підключіть кабель передачі даних USB-C до комп’ютера та плеєра.
  - Не торкайтеся кабелю або кнопок живлення під час перепрограмування.
  - Коли з’явиться підтвердження успіху, від’єднайте кабель USB і увімкніть G5.
