# Installa Inniclassic su Y2.

Inniclassic ha un port dedicato Y2 gestito da Jonasz Potoniec. Seleziona Y2 prima di sceglierlo in modo che l'elenco delle versioni sia sempre compatibile con il modello.[Ottieni Updater CE](../guide_it.html#platform)[Ottieni questo in Updater CE](../guide_it.html?model=Y2&software=inniclassic-y2)[Perché Inniclassic?](../inniclassic-benefits_it.html)

Guida all'installazione per il tuo computer

## Installa Inniclassic sul tuo Y2 con il tuo computer

Scegli la guida per il computer che stai utilizzando. Ogni versione ha la configurazione della piattaforma, Updater CE passaggi e il modo per tornare allo stock.[Guida Windows](/install/inniclassic-y2-windows.html)[guida macOS](/install/inniclassic-y2-mac.html)[Guida Linux](/install/inniclassic-y2-linux.html)

[Tutte le Innioasis Y2 guide](/install/y2.html) · [Tutte le Inniclassic guide](/install/inniclassic.html)

## Installalo
  - Apri Innioasis Updater CE sul tuo computer (se non lo hai ancora, [Ottieni Updater CE](../guide_it.html#platform)). Seleziona Y2 dentro Modello del dispositivo.
  - Scegli Inniclassic dentro Software (o avvia con [Ottieni questo in Updater CE](../guide_it.html?model=Y2&software=inniclassic-y2)).
  - Selezionare una versione e fare clic Installa / Ripristina.
  - Spegnere e collegare Y2 solo quando l'Updater lo richiede.
  - Utilizza Y2 Software originale per il percorso di ripristino.

## Mantieni ferma la connessioneIstruzioni per la connessione dell'aggiornamentoConnettiti solo al prompt live.

Y2 pacchetti utilizzano `rom_y2.zip`. Se l'installazione non riesce, annotare se l'errore si è verificato prima o dopo che l'Updater ha rilevato il lettore.
