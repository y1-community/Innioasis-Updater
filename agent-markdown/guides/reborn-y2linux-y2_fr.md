# Installez Reborn (Y2Linux) sur votre Innioasis Y2.

Suivez ces étapes pour flasher Reborn (Y2Linux / Y2Reborn) sur un Innioasis Y2 à l'aide de Innioasis Updater CE, puis terminez la configuration Wi-Fi et Bluetooth après l'installation.[Obtenir Updater CE](../guide_fr.html#download-updater)[Pourquoi Reborn (Y2Linux) ?](../reborn-y2linux-benefits_fr.html)[Y2Reborn Sorties](../firmware_fr.html?model=Y2&software=reborn-y2linux-y2)

Guide d'installation pour votre ordinateur

## Installez Reborn (Y2Linux) sur votre Y2 avec votre ordinateur

Choisissez le guide correspondant à l'ordinateur que vous utilisez. Chaque version comprend la configuration de la plate-forme, Updater CE étapes et le chemin de retour au stock.[Guide Windows](/install/reborn-y2linux-y2-windows.html)[Guide macOS](/install/reborn-y2linux-y2-mac.html)[Guide Linux](/install/reborn-y2linux-y2-linux.html)

[Tous les guides Innioasis Y2](/install/y2.html) · [Tous les guides Reborn (Y2Linux)](/install/reborn.html)

## Installation étape par étape
  - Installez Updater CE : Télécharger [Innioasis Programme de mise à jour CE](../guide_fr.html) pour Windows, macOS ou Linux, puis ouvrez-le.
  - Sélectionnez Y2 : Choisissez Y2 comme modèle d'appareil.
  - Sélectionnez Reborn : Choisissez Reborn (Y2Linux) et la dernière version.
  - Installer: Cliquez Installer / Restaurer, éteignez le Y2 et connectez USB lorsque vous y êtes invité.
  - Attendez: Gardez le lecteur immobile jusqu'à ce que Updater CE confirme, puis déconnectez-vous.
  - Configurer le Wi-Fi, le Bluetooth et la radio FM

Copier `system.img` au joueur une fois. Reborn fait le reste.[Terminer la configuration →](../y2reborn_wifibt_fr.html)

## Revenir au logiciel d'origine

Vous pouvez renvoyer votre Y2 au logiciel d'usine à tout moment en choisissant Y2 et Logiciel d'origine dans Updater CE. Voir le [Y2 tutoriel de restauration](restore-original-y2_fr.html).
