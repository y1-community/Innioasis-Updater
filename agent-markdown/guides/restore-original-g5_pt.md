# Restaure o software original em Innioasis G5

Use este tutorial guiado quando precisar recuperar um G5 que não responde, atualizar o sistema para o estado de fábrica ou instalar atualizações de firmware oficiais limpas.[Obtenha o atualizador CE](../guide_pt.html#platform)[Ver G5 downloads](../firmware_pt.html?model=G5)

Guia de instalação para o seu computador

## Restaure o software original em seu G5 com seu computador

Escolha o guia para o computador que você está usando. Cada versão possui a configuração da plataforma, Updater CE etapas e o caminho de volta ao estoque.[Guia do Windows](/install/original-g5-windows.html)[guia macOS](/install/original-g5-mac.html)[Guia Linux](/install/original-g5-linux.html)

[Todos Innioasis G5 guias](/install/g5.html) · [Todos os guias de software original](/install/original-software.html)

## Etapa 1: prepare seu computador

Innioasis Updater CE é executado nativamente em Windows, macOS e Linux sem exigir chicotes complexos de flash:
  - Lançar Innioasis Atualizador CE em seu desktop ou laptop.
  - Definir Modelo do dispositivo para G5.
  - Selecione Software Original no menu suspenso do software. Updater CE baixa automaticamente o arquivo oficial `rom_g5.zip` liberar pacote diretamente.
  - Clique Instalar / Restaurar para começar a preparação.

## Etapa 2: conecte G5 no prompt

Nunca conecte seu player antes que o aplicativo solicite:
  - Certifique-se de que seu Innioasis G5 esteja totalmente desligado.
  - Quando o Updater exibir o prompt de conexão USB, conecte seu cabo de dados USB-C ao computador e ao player.
  - Não toque no cabo ou nos botões liga/desliga enquanto o flash estiver em andamento.
  - Assim que a confirmação de sucesso aparecer, desconecte o cabo USB e ligue seu G5.
