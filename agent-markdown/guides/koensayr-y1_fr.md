# Installez Koensayr sur un Y1.

Koensayr est répertorié comme un projet Y1. Laissez Updater gérer le package, puis suivez la même mise hors tension et le même timing USB minutieux que pour les autres installations complètes.[Obtenir Updater CE](../guide_fr.html#platform)[Disponible dans Updater CE](../guide_fr.html?model=Y1&software=koensayr-y1)[Pourquoi Koensayr ?](../koensayr-benefits_fr.html)

Guide d'installation pour votre ordinateur

## Installez Koensayr sur votre Y1 avec votre ordinateur

Choisissez le guide correspondant à l'ordinateur que vous utilisez. Chaque version comprend la configuration de la plate-forme, Updater CE étapes et le chemin de retour au stock.[Guide Windows](/install/koensayr-y1-windows.html)[Guide macOS](/install/koensayr-y1-mac.html)[Guide Linux](/install/koensayr-y1-linux.html)

[Tous les guides Innioasis Y1](/install/y1.html) · [Tous les guides Koensayr](/install/koensayr.html)

## Étapes d'installation
  - Ouvrez Innioasis Updater CE sur votre ordinateur (si vous ne l'avez pas encore, [Obtenir Updater CE](../guide_fr.html#platform)). Sélectionnez Y1 dans Modèle d'appareil.
  - Choisissez Koensayr dans Logiciel (ou lancer avec [Disponible dans Updater CE](../guide_fr.html?model=Y1&software=koensayr-y1)).
  - Sélectionnez la version répertoriée et cliquez sur Installer / Restaurer.
  - Éteignez et connectez le Y1 uniquement lorsque l'application le demande.
  - Utiliser Y1 Logiciel d'origine pour restaurer le chemin du stock.

## Quand quelque chose échoue

Vérifiez d'abord la sélection du modèle et du type. Vérifiez ensuite le câble et si le lecteur était connecté avant l'invite. Si l'application s'est arrêtée avant d'avoir attendu USB, ouvrez [dépannage](../troubleshooting_fr.html).Instructions de connexion à UpdaterUne connexion stable fait partie de l’installation.
