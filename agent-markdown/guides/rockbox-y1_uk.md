## Те, що вам потрібно

Innioasis Y1, заряджена батарея, USB кабель даних і комп’ютер із встановленим Innioasis Updater CE (якщо ви ще не встановили його, [Отримати Updater CE](../guide_uk.html#platform) для Windows, macOS або Linux). Type A підходить для Y1 гравців, які постачаються з оригінальним програмним забезпеченням версії 2.0.0 або новішої; Type B підходить гравцям, які постачалися з попередньою версією [Заводське ПЗ](../firmware_uk.html?software=original-y1). Почніть з Type A, якщо ви вже не знаєте, що вашому гравцеві потрібна збірка Type B.

## Дивіться маршрут Rockbox.

Відео від Frawgeeys. Це працює як для моделей Y1, так і для Y2 — у Innioasis Updater CE виберіть Y1 як свою модель. Написані нижче кроки охоплюють послідовність встановлення Y1.

Відео автора [Крістіан Плаза](https://www.youtube.com/@CristianPlaza) (іспанською), починаючи з етапу встановлення Rockbox. Наведені нижче кроки охоплюють послідовність Y1.

## У програмі оновлення
  - Відкрийте Updater CE (або запустіть за допомогою [Отримайте це в Updater CE](../guide_uk.html?model=Y1&software=rockbox-y1)) і встановіть Модель пристрою для Y1.
  - Виберіть Rockbox в Програмне забезпечення. Точна мітка проекту може відображатися як Rockbox-Y1 у даних випуску.
  - Виберіть стабільний випуск. Збірки 240p мають найширшу сумісність старих тем; Збірки 360p призначені для шляху теми Y1. Перевірте примітки до випуску, якщо відмінність має значення.
  - Натисніть Встановити / Відновити. Зачекайте, поки Updater CE завантажить пакет безпосередньо з випуску розробника спільноти та підготує його.

## Підключіть Y1
  - Зачекайте, доки програма оновлення запитає плеєр.
  - Повністю вимкніть Y1. Якщо він не вимикається, скористайтеся інструкцією з відновлення, яку показує Updater.
  - Підключайте кабель даних USB лише тоді, коли програма каже. Відкладіть плеєр і не заважайте з'єднанню.
  - Відключіться лише після того, як програма оновлення підтвердить успішне виконання, а потім запустіть Y1.
Інструкції з підключення програми оновленняФормулювання підключення може відрізнятися залежно від платформи. Дотримуйтесь підказок у прямому ефірі.

## Повернутися до оригінального програмного забезпечення

Rockbox не блокує вас у спеціальному програмному забезпеченні. Після налаштування програми оновлення для вашого комп’ютера використовуйте її в Windows, macOS або Linux: виберіть Y1, вибрати Заводське ПЗ, і бігти Встановити / Відновити.
  - Зачекайте, доки програма оновлення завершить підготовку стандартного пакета.
  - Вимкніть Y1, коли програма запитає.
  - Підключайте кабель передачі даних USB лише за підказкою в реальному часі.
  - Залиште плеєр нерухомим до повідомлення про успішне виконання.

Не використовуйте пакет Y2 і не видаляйте файли Rockbox вручну перед відновленням. Для Type B поведінки колеса перевірте відповідний варіант випуску перед зміною типу пристрою.[Посібник з відновлення Y1](restore-original-y1_uk.html)[Усунення несправностей](../troubleshooting_uk.html)
