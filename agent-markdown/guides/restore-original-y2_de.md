## Von Rockbox oder einer anderen benutzerdefinierten Software

Sobald das entsprechende Windows-, macOS- oder Linux-Setup bereit ist, erfolgt die Rückkehr zur Standardschnittstelle Y2 mit demselben Updater-Ablauf wie bei der Installation eines Community-Projekts. Mischen Sie Y1 Dateien nicht manuell in den Player und löschen Sie nicht zuerst Systemordner.
  - Öffnen Sie Innioasis Updater CE auf Ihrem Computer (falls Sie es noch nicht installiert haben, [Updater CE holen](../guide_de.html#platform) für [Windows](../drivers_de.html#windows), [macOS](../guide_de.html#macos), oder [Linux](../drivers_de.html#linux)).
  - Satz Gerätemodell an Y2.
  - Wählen Sie Original-Software.
  - Wählen Sie eine stabile Y2-Version. Es können manuelle Vollinstallationspakete verwendet werden `rom_y2.zip`.
  - Klicken Sie Installieren / Wiederherstellen und warten Sie auf den Extraktionsschritt.
Nicht ersetzen: ein Y1 `rom.zip` ist kein Y2-Paket. Wenn die Release-Liste falsch aussieht, stoppen Sie und wählen Sie Y2 erneut aus.

## Folgen Sie der Verbindungsaufforderung

Windows, macOS und Linux haben unterschiedliche Hinweise zur Computereinrichtung, aber die Abfolge auf Spielerseite bleibt dieselbe: Schalten Sie den Computer aus, wenn Sie dazu aufgefordert werden, und schließen Sie dann das Datenkabel an der Live-Eingabeaufforderung an.
  - Schalten Sie Y2 vollständig aus, wenn der Updater Sie dazu auffordert.
  - Verbinden Sie USB nur, wenn die App anzeigt, dass sie bereit ist.
  - Lassen Sie das Kabel bis zur Erfolgsmeldung in Ruhe.
  - Trennen Sie die Verbindung sicher und starten Sie den Player.
Anweisungen zum Verbinden mit UpdaterDie gemeinsame Verbindungsreferenz. Die Live-App-Eingabeaufforderung ist maßgeblich.

## Stecken Sie immer noch fest?

Überprüfen Sie das Modell, die Verpackung, das Kabel und den Anschlusszeitpunkt, bevor Sie ein Handwerkzeug ausprobieren. Der [Anleitung zur Fehlerbehebung](../troubleshooting_de.html) erklärt, was ein Fehler vor USB im Vergleich zu einem Fehler nach der Geräteerkennung bedeutet.Halten Sie die Pakete getrennt: ein Y1 `rom.zip` ist keine Y2-Wiederherstellung. Wenn die Release-Liste falsch aussieht, halten Sie an und wählen Sie erneut Y2.
