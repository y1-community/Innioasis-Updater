# Installieren Sie Linux auf einem Y1.

Linux für Y1 ist ein experimenteller Community-Linux-Kernel und RootFS-Port für Innioasis Y1. Wählen Sie Y1 aus, bevor Sie es in Updater CE auswählen.[Updater CE holen](../guide_de.html#platform)[In Updater CE erhalten](../guide_de.html?model=Y1&software=linux-y1)[Projektquelle](https://github.com/y1-community/y1-linux-rom)

Installationsanleitung für Ihren Computer

## Installieren Sie Linux für Y1 (Dev) auf Ihrem Y1 mit Ihrem Computer

Wählen Sie die Anleitung für den Computer aus, den Sie verwenden. Jede Version verfügt über das Plattform-Setup, Updater CE Schritte und den Weg zurück zum Lagerbestand.[Windows-Anleitung](/install/linux-y1-windows.html)[macOS-Anleitung](/install/linux-y1-mac.html)[Linux-Anleitung](/install/linux-y1-linux.html)

[Alle Innioasis Y1-Anleitungen](/install/y1.html) · [Alle Linux für Y1 (Dev)-Anleitungen](/install/linux-dev.html)

## Installieren Sie es
  - Öffnen Sie Innioasis Updater CE auf Ihrem Computer (falls Sie es noch nicht haben, [Updater CE holen](../guide_de.html#platform)). Auswählen Y1 In Gerätemodell.
  - Wählen Sie Linux für Y1 (Dev) In Software (oder starten Sie mit [In Updater CE erhalten](../guide_de.html?model=Y1&software=linux-y1)).
  - Wählen Sie eine Veröffentlichung aus und klicken Sie Installieren / Wiederherstellen.
  - Schalten Sie das Y1 erst aus und schließen Sie es an, wenn Sie vom Updater dazu aufgefordert werden.
  - Verwenden Sie Y1 Original-Software für den Wiederherstellungspfad.

## Experimenteller HafenExperimenteller Aufbau: Dies ist ein Barebone-Linux-Port, der für Entwickler und Enthusiasten gedacht ist. UART- und Konsolendetails finden Sie in den Projektdokumenten.Anweisungen zum Verbinden mit UpdaterErst verbinden, wenn die Aufforderung erscheint.
