# 如何在 Innioasis Y2 - Innioasis 上安装 Y2Player 固件下载

Y2Player · Innioasis Y2

# 在 Y2 上安装 Y2Player。

Y2Player 是一个 Y2 项目。安全路线从型号选择开始，而不是从项目名称开始。[获取 Updater CE](../guide_zh-CN.html#platform)[在 Updater CE 中获取](../guide_zh-CN.html?model=Y2&software=y2player-y2)[为什么是Y2Player？](../y2player-benefits_zh-CN.html)

适用于您的计算机的安装指南

## 使用计算机在 Y2 上安装 Y2Player

选择适合您正在使用的计算机的指南。 每个版本都有平台设置、Updater CE步骤和返回库存的方式。[Windows 指南](/install/y2player-y2-windows.html)[macOS 指南](/install/y2player-y2-mac.html)[Linux指南](/install/y2player-y2-linux.html)

[所有 Innioasis Y2 指南](/install/y2.html) · [所有 Y2Player 指南](/install/y2player.html)

## 在更新程序中
  - 在您的计算机上打开 Innioasis Updater CE（如果您还没有， [获取 Updater CE](../guide_zh-CN.html#platform)）。选择 Y2 在 设备型号.
  - 选择 Y2Player 在 软件 （或启动 [在 Updater CE 中获取](../guide_zh-CN.html?model=Y2&software=y2player-y2)).
  - 选择列出的 Y2 版本。
  - 点击 安装 / 恢复，根据提示关闭电源，然后根据提示连接 USB。
  - 用 Y2 恢复 原厂软件 如果需要的话。

## 不要替换 Y1 包检查两次： Y2 完整安装包可以使用 `rom_y2.zip`。普通的 Y1 包并不是安全的替代品。关闭电源的更新程序连接说明 Y2仅在提示时连接。
