# Instale Solar em seu Y1.

Solar é um projeto de software comunitário separado. A disponibilidade e os recursos podem mudar, então deixe o Updater mostrar a versão atual do seu modelo.[Obtenha o atualizador CE](../guide_pt.html#platform)[Obtenha isso em Updater CE](../guide_pt.html?model=Y1&software=solar-y1)[Por que Solar?](../solar-benefits_pt.html)

Também disponível: [Solar em Y2](solar-y2_pt.html)

Guia de instalação para o seu computador

## Instale Solar em seu Y1 com seu computador

Escolha o guia para o computador que você está usando. Cada versão possui a configuração da plataforma, Updater CE etapas e o caminho de volta ao estoque.[Guia do Windows](/install/solar-y1-windows.html)[guia macOS](/install/solar-y1-mac.html)[Guia Linux](/install/solar-y1-linux.html)

[Todos Innioasis Y1 guias](/install/y1.html) · [Todos Solar guias](/install/solar.html)

## Escolha a rota Y1
  - Abra Innioasis Updater CE no seu computador (se ainda não o tiver, [Obtenha o atualizador CE](../guide_pt.html#platform)). Selecione Y1 em Modelo do dispositivo.
  - Escolher Solar em Programas (ou lançar com [Obtenha isso em Updater CE](../guide_pt.html?model=Y1&software=solar-y1)).
  - Leia a nota de lançamento, selecione uma versão e clique em Instalar / Restaurar.
  - Desligue e conecte o player somente quando o Updater solicitar.
  - Restaurar com Y1 Software Original se você precisar da interface de estoque novamente.

## Mantenha a nota do projeto à vista

Solar está em desenvolvimento ativo. Os recursos e o suporte do modelo podem mudar, portanto verifique as notas de lançamento do projeto. O atualizador mostra o que está disponível para o seu modelo no momento.Instruções de conexão do atualizadorConecte-se apenas no prompt ao vivo.

## Volte para o software original

Solar não altera a rota de volta para a interface padrão. Assim que o Updater estiver configurado para o seu computador, abra-o no Windows, macOS ou Linux e selecione Y1 mais Software Original em vez de Solar.
  - Escolha uma versão de software original estável Y1.
  - Clique Instalar / Restaurar e aguarde o prompt de conexão ao vivo.
  - Desligue o Y1 somente quando solicitado.
  - Conecte o cabo de dados USB no prompt e deixe-o imóvel até obter sucesso.

Não remova manualmente os arquivos Solar primeiro e não use um pacote Y2. Se a falha ocorreu antes do prompt USB, verifique primeiro a configuração do computador, o cabo e a seleção do modelo.[Y1 guia de restauração](restore-original-y1_pt.html)[Solução de problemas](../troubleshooting_pt.html)
