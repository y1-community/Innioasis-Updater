# Installeer Android 4.4 (ontwikkelaar) op een Y2.

Android 4.4 is een communityontwikkeling ROM voor het testen en hacken van de Innioasis Y2 hardware. Selecteer Y2 voordat u dit kiest in Updater CE.[Updater CE downloaden](../guide_nl.html#platform)[Ontvang dit in Updater CE](../guide_nl.html?model=Y2&software=android-4-4-y2)[Projectbron](https://github.com/y1-community/y2-ata-rom)

Installatiehandleiding voor uw computer

## Installeer Android-ontwikkeling ROM op uw Y2 met uw computer

Kies de handleiding voor de computer die u gebruikt. Elke versie heeft de platformconfiguratie, Updater CE stappen en de weg terug naar de voorraad.[Windows-gids](/install/android-4-4-y2-windows.html)[macOS-gids](/install/android-4-4-y2-mac.html)[Linux-gids](/install/android-4-4-y2-linux.html)

[Alle Innioasis Y2-gidsen](/install/y2.html) · [Alle ROM-handleidingen voor Android-ontwikkeling](/install/android-dev.html)

## Installeer het
  - Open Innioasis Updater CE op uw computer (als u dit nog niet heeft, [Updater CE downloaden](../guide_nl.html#platform)). Selecteer Y2 binnen Apparaatmodel.
  - Kies Android 4.4 (ontwikkelaar) binnen Software (of start met [Ontvang dit in Updater CE](../guide_nl.html?model=Y2&software=android-4-4-y2)).
  - Selecteer een release en klik Installeren / Herstellen.
  - Schakel de Y2 alleen uit en sluit deze alleen aan als Updater u daarom vraagt.
  - Gebruik Y2 Originele software voor het herstelpad.
