# Installieren Sie JJ Launcher auf Ihrem Y2.

Es gibt einen JJ Launcher-Build für Y2. Wählen Sie zuerst Ihr Modell aus, damit Updater das Paket Y1 nicht anbietet.[Updater CE holen](../guide_de.html#platform)[In Updater CE erhalten](../guide_de.html?model=Y2&software=jj-launcher-y2)[Warum JJ Launcher?](../jj-launcher-benefits_de.html)

Installationsanleitung für Ihren Computer

## Installieren Sie JJ Launcher auf Ihrem Y2 mit Ihrem Computer

Wählen Sie die Anleitung für den Computer aus, den Sie verwenden. Jede Version verfügt über das Plattform-Setup, Updater CE Schritte und den Weg zurück zum Lagerbestand.[Windows-Anleitung](/install/jj-launcher-y2-windows.html)[macOS-Anleitung](/install/jj-launcher-y2-mac.html)[Linux-Anleitung](/install/jj-launcher-y2-linux.html)

[Alle Innioasis Y2-Anleitungen](/install/y2.html) · [Alle JJ Launcher Anleitungen](/install/jj-launcher.html)

## Wählen Sie die Route Y2.
  - Öffnen Sie Innioasis Updater CE auf Ihrem Computer (falls Sie es noch nicht haben, [Updater CE holen](../guide_de.html#platform)). Auswählen Y2 In Gerätemodell.
  - Wählen Sie JJ Launcher In Software (oder starten Sie mit [In Updater CE erhalten](../guide_de.html?model=Y2&software=jj-launcher-y2)).
  - Lesen Sie die Versionshinweise, bestätigen Sie den Eintrag Y2 und klicken Sie auf Installieren / Wiederherstellen.
  - Schalten Sie den Player nur aus und schließen Sie ihn an, wenn der Updater Sie dazu auffordert.
  - Mit Y2 wiederherstellen Original-Software wenn Sie die Standardschnittstelle erneut benötigen.

## Die Nichtübereinstimmung der Modelle ist das erste, was überprüft werden muss

JJ Launcher hat auch einen Y1-Eintrag. Wenn der Paketname falsch aussieht, kehren Sie zum Gerätemodell zurück. Erzwingen Sie kein Y1-Paket auf einem Y2.Anweisungen zum Verbinden mit UpdaterErst verbinden, wenn die Aufforderung erscheint.

## Gehen Sie zurück zur Originalsoftware

JJ Launcher ändert die Route zurück zur Standardschnittstelle nicht. Sobald Updater für Ihren Computer eingerichtet ist, öffnen Sie es unter Windows, macOS oder Linux und wählen Sie Y2 Plus Original-Software statt JJ Launcher.
  - Wählen Sie eine stabile Y2 Originalsoftwareversion.
  - Klicken Sie Installieren / Wiederherstellen und warten Sie auf die Live-Verbindungsaufforderung.
  - Schalten Sie Y2 nur aus, wenn Sie dazu aufgefordert werden.
  - Schließen Sie bei der Aufforderung das USB-Datenkabel an und lassen Sie es bis zum Erfolg ruhen.

Entfernen Sie nicht zuerst JJ Launcher-Dateien manuell und verwenden Sie kein Y1-Paket. Wenn der Fehler vor der Eingabeaufforderung USB aufgetreten ist, überprüfen Sie zunächst die Computerkonfiguration, das Kabel und die Modellauswahl.[Y2-Wiederherstellungsanleitung](restore-original-y2_de.html)[Fehlerbehebung](../troubleshooting_de.html)
