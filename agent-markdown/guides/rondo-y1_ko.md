# Innioasis Y1에 Rondo을(를) 설치합니다.

Innioasis 업데이터 CE의 다음 단계에 따라 설치하세요. Rondo Innioasis Y1에서 설치 후 설정 가이드를 완료하세요.[Updater CE 받기](../guide_ko.html#download-updater)[왜 Rondo인가요?](../rondo-benefits_ko.html)[Rondo 릴리스](../firmware_ko.html?model=Y1&software=rondo-y1)

## 컴퓨터를 사용하여 Y1에 Rondo을(를) 설치합니다.

사용 중인 컴퓨터에 대한 가이드를 선택하세요. 모든 버전에는 플랫폼 설정, Updater CE 단계 및 재고로 돌아가는 방법이 있습니다.[윈도우 가이드](/install/rondo-y1-windows.html)[macOS 가이드](/install/rondo-y1-mac.html)[리눅스 가이드](/install/rondo-y1-linux.html)

[모든 Innioasis Y1 가이드](/install/y1.html) · [모든 Rondo 가이드](/install/rondo.html)

## 단계별 설치
  - 오픈 업데이터 CE: 발사 [Innioasis 업데이터 CE](../guide_ko.html) Windows, macOS 또는 Linux 컴퓨터에서.
  - 장치 모델 선택 Y1: 선택 Y1 장치 모델 드롭다운에서(Y1이 2.0.0 이전의 원본 소프트웨어와 함께 제공된 경우 Type B을 선택하고, 그렇지 않으면 Type A를 유지).
  - 소프트웨어 드롭다운에서 Rondo을 선택합니다. 선택 Rondo 소프트웨어 목록에서 최신 릴리스를 선택합니다. 업데이터 CE는 Android 4.2 Wi-Fi 기반 ROM 및 Rondo 릴리스 피드를 자동으로 사용합니다.
  - 플레이어 플래시: 클릭 설치 / 복원, Y1의 전원을 완전히 끄고 Updater CE가 메시지를 표시하면 USB 데이터 케이블을 통해 연결하십시오.
  - 연결을 끊고 부팅합니다. Y1의 플러그를 뽑기 전에 녹색 완료 메시지가 나타날 때까지 기다리십시오.
  - 설치 후 설정 완료
