# Innioasis Y2 - Innioasis에 Reborn (Y2Linux / Y2Reborn)를 설치하는 방법 펌웨어 다운로드

Innioasis Y2 · 튜토리얼 설치

# Innioasis Y2에 Reborn (Y2Linux)을(를) 설치합니다.

플래시하려면 다음 단계를 따르세요. Reborn (Y2Linux / Y2Reborn) Innioasis 업데이터 CE를 사용하여 Innioasis Y2에 설치한 다음 설치 후 Wi-Fi 및 Bluetooth 설정을 완료합니다.[Updater CE 받기](../guide_ko.html#download-updater)[왜 Reborn (Y2Linux)인가요?](../reborn-y2linux-benefits_ko.html)[Y2Reborn 릴리스](../firmware_ko.html?model=Y2&software=reborn-y2linux-y2)

컴퓨터에 대한 설치 가이드

## 컴퓨터를 사용하여 Y2에 Reborn (Y2Linux)을(를) 설치합니다.

사용 중인 컴퓨터에 대한 가이드를 선택하세요. 모든 버전에는 플랫폼 설정, Updater CE 단계 및 재고로 돌아가는 방법이 있습니다.[윈도우 가이드](/install/reborn-y2linux-y2-windows.html)[macOS 가이드](/install/reborn-y2linux-y2-mac.html)[리눅스 가이드](/install/reborn-y2linux-y2-linux.html)

[모든 Innioasis Y2 가이드](/install/y2.html) · [모든 Reborn (Y2Linux) 가이드](/install/reborn.html)

## 단계별 설치
  - 업데이터 CE 설치: 다운로드 [Innioasis 업데이터 CE](../guide_ko.html) Windows, macOS 또는 Linux의 경우 이를 엽니다.
  - Y2을 선택합니다. 선택 Y2 장치 모델로.
  - Reborn을 선택합니다. 선택 Reborn (Y2Linux) 그리고 최신 릴리스.
  - 설치하다: 클릭 설치 / 복원, Y2 전원을 끄고 메시지가 표시되면 USB을 연결합니다.
  - 기다리다: Updater CE가 확인할 때까지 플레이어를 그대로 유지한 다음 연결을 끊습니다.
  - Wi-Fi, Bluetooth, FM 라디오 설정

복사 `system.img` 플레이어에게 한 번. Reborn이 나머지 작업을 수행합니다.[설정 완료 →](../y2reborn_wifibt_ko.html)

## 원래 소프트웨어로 돌아가기

다음을 선택하여 언제든지 Y2을 공장 소프트웨어로 되돌릴 수 있습니다. Y2 그리고 원본 소프트웨어 업데이터 CE에서. 참조 [Y2 복원 튜토리얼](restore-original-y2_ko.html).
