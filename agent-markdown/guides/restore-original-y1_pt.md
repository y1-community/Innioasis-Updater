## De Rockbox ou outro software personalizado

Assim que a configuração relevante do Windows, macOS ou Linux estiver pronta, o Updater usará a mesma instalação guiada para uma restauração de estoque e para uma instalação de software personalizado. Você não precisa excluir manualmente Rockbox ou os arquivos de outro software personalizado primeiro.
  - Abra Innioasis Updater CE no seu computador (se ainda não o tiver instalado, [Obtenha o atualizador CE](../guide_pt.html#platform) para [Windows](../drivers_pt.html#windows), [macOS](../guide_pt.html#macos), ou [Linux](../drivers_pt.html#linux)).
  - Definir Modelo do dispositivo para Y1.
  - Escolher Software Original em Programas (ou usar [Obtenha isso em Updater CE](../guide_pt.html?model=Y1&software=original-y1)).
  - Escolha a versão estável mais recente Y1. O pacote manual usual é `rom.zip`. Type A abrange Y1 reprodutores fornecidos com software original versão 2.0.0 ou posterior; Type B abrange jogadores fornecidos com uma versão anterior do [Software Original](../firmware_pt.html?software=original-y1) e pode usar um nome de pacote mais específico.
  - Clique Instalar / Restaurar e aguarde a extração do pacote.

## Conecte o Y1 no prompt

O sistema operacional altera a configuração do Updater, não a jornada de restauração em si. Em todas as plataformas, aguarde o prompt ao vivo antes de conectar.
  - Desligue totalmente o player quando o Updater solicitar.
  - Conecte o cabo de dados USB somente quando solicitado.
  - Não toque no player enquanto a instalação é executada.
  - Desconecte após a mensagem de sucesso e inicie o Y1.

## Se ainda não começar

Repita a restauração uma vez com o modelo, tipo e versão marcados. Se o atualizador falhar antes do prompt USB, inspecione a configuração do computador, driver ou permissões, cabo de dados e arquivos extraídos. Se falhar após detectar o Y1, use o [guia de solução de problemas](../troubleshooting_pt.html) antes de passar para a recuperação manual SP Flash Tool ou MTKClient.Não mude para arquivos Y2. Uma restauração Y1 precisa de uma versão de software original Y1, mesmo que o player esteja executando um software personalizado diferente.
