# كيفية تثبيت Rondo على Innioasis Y1 - Innioasis تنزيلات البرامج الثابتة

Innioasis Y1 · تثبيت البرنامج التعليمي

# قم بتثبيت Rondo على Innioasis Y1.

اتبع هذه الخطوات في Innioasis Updater CE للتثبيت Rondo على Innioasis Y1، ثم أكمل دليل الإعداد بعد التثبيت.[احصل على Updater CE](../guide_ar.html#download-updater)[لماذا Rondo؟](../rondo-benefits_ar.html)[Rondo الإصدارات](../firmware_ar.html?model=Y1&software=rondo-y1)

دليل التثبيت لجهاز الكمبيوتر الخاص بك

## قم بتثبيت Rondo على جهاز Y1 بجهاز الكمبيوتر الخاص بك

اختر دليل الكمبيوتر الذي تستخدمه. يحتوي كل إصدار على إعداد النظام الأساسي وخطوات Updater CE وطريقة العودة إلى المخزون.[دليل ويندوز](/install/rondo-y1-windows.html)[دليل ماك](/install/rondo-y1-mac.html)[دليل لينكس](/install/rondo-y1-linux.html)

[جميع أدلة Innioasis Y1](/install/y1.html) · [جميع الأدلة Rondo](/install/rondo.html)

## التثبيت خطوة بخطوة
  - افتح برنامج التحديث CE: إطلاق [Innioasis برنامج التحديث CE](../guide_ar.html) على جهاز الكمبيوتر الذي يعمل بنظام التشغيل Windows أو macOS أو Linux.
  - اختر طراز الجهاز Y1: اختر Y1 في القائمة المنسدلة طراز الجهاز (اختر Type B إذا تم شحن Y1 مع البرنامج الأصلي الأقدم من 2.0.0؛ وإلا احتفظ بـ Type A).
  - اختر Rondo من القائمة المنسدلة للبرنامج: اختر Rondo في قائمة البرامج واختر الإصدار الأحدث. يستخدم Updater CE قاعدة Android 4.2 Wi-Fi ROM وخلاصة الإصدار Rondo تلقائيًا.
  - فلاش المشغل: انقر تثبيت / استعادة، قم بإيقاف تشغيل Y1 الخاص بك تمامًا، وقم بتوصيله عبر كابل بيانات USB عندما يطالبك Updater CE.
  - قطع الاتصال والتمهيد: انتظر رسالة الإكمال الخضراء قبل فصل Y1.
  - استكمال الإعداد بعد التثبيت
