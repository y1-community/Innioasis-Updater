# Restaure o software original em Innioasis e Timmkoo A5

Siga este tutorial para restaurar o software oficial de fábrica em seu player Innioasis A5 ou Timmkoo A5 com pacotes verificados do arquivo de firmware Innioasis.[Obtenha o atualizador CE](../guide_pt.html#platform)[Ver A5 downloads](../firmware_pt.html?model=A5)

## Etapa 1: configuração em Updater CE
  - Lançar Innioasis Atualizador CE em seu computador Windows, macOS ou Linux.
  - Definir Modelo do dispositivo para A5.
  - Selecione Software Original. Updater CE baixa o oficial `rom_a5.zip` liberar pacote diretamente.
  - Clique Instalar / Restaurar e aguarde a conclusão da preparação.

## Etapa 2: Conecte-se no prompt
  - Desligue o dispositivo A5 completamente.
  - Aguarde o aviso na tela do computador antes de conectar o cabo de dados USB.
  - Permita que o processo de flashing termine sem interrupção.
  - Desconecte e reinicie seu player A5 recém-restaurado.
