# Installieren Sie den Build Y2, nicht den Build Y1.

Die User Journey ist bekannt, aber das Modell und das Paket sind unterschiedlich. ## Sehen Sie sich die Rockbox-Route an

Video von Frawgeeys. Es funktioniert sowohl für die Modelle Y1 als auch für Y2 – wählen Sie in Innioasis Updater CE aus Y2 als Ihr Vorbild. Die folgenden schriftlichen Schritte decken die Y2-Installationssequenz ab.

Video von [Cristian Plaza](https://www.youtube.com/@CristianPlaza) (Spanisch). Es demonstriert die Installation auf einem Y1; wählen Y2 in Updater CE für diesen Leitfaden.

## Bevor Sie auf „Installieren“ klicken

Halten Sie ein aufgeladenes Innioasis Y2, ein USB-Datenkabel und einen Computer bereit, auf dem Innioasis Updater CE installiert ist (falls Sie es noch nicht installiert haben, [Updater CE holen](../guide_de.html#platform) für Windows, macOS oder Linux). Verwenden Sie keine Y1-Version, nur weil ihr Name ähnlich aussieht.Modellcheck: Y2 Vollinstallationspakete dürfen verwenden `rom_y2.zip`. Der Dateiname ist ein nützlicher Hinweis für den manuellen Download, aber Updater sollte die Paketauswahl für Sie übernehmen.

## Wählen Sie im Updater Y2.
  - Öffnen Sie Updater CE (oder starten Sie mit [In Updater CE erhalten](../guide_de.html?model=Y2&software=rockbox-y2)) und einstellen Gerätemodell an Y2.
  - Wählen Sie Rockbox In Software.
  - Wählen Sie eine für Y2 aufgeführte Version aus. Wenn keine Y2-Version aufgeführt ist, ersetzen Sie sie nicht durch eine Y1-Version.
  - Klicken Sie Installieren / Wiederherstellen und lassen Sie Updater CE das Paket direkt von der Community-Entwicklerversion herunterladen.

## Ausschalten, dann anschließen
  - Warten Sie auf die Aufforderung zur Live-Verbindung.
  - Schalten Sie den Y2 vollständig aus. Verwenden Sie die genauen Reset- oder Wiederherstellungsanweisungen, die Updater anzeigt, wenn das normale Herunterfahren fehlschlägt.
  - Schließen Sie das Kabel USB an, wenn Sie dazu aufgefordert werden. Lassen Sie es ruhig stehen, bis die Abschlussmeldung erscheint.
  - Sicher trennen und Y2 starten.
Anweisungen zum Updater-Anschluss für ein ausgeschaltetes GerätDer Verbindungsbildschirm dient als Referenz. Ihre Y2-Eingabeaufforderung kann einen anderen Modelltext enthalten.

## Zurück zur Originalsoftware

Rockbox bindet Sie nicht an die benutzerdefinierte Software. Sobald Updater für Ihren Computer eingerichtet ist, können Sie es unter Windows, macOS oder Linux verwenden, um von Rockbox oder einem anderen aufgelisteten Projekt zurückzukehren: Wählen Sie aus Y2, wählen Original-Software, und renne Installieren / Wiederherstellen.
  - Warten Sie, bis der Updater das Bestandspaket Y2 vorbereitet hat.
  - Schalten Sie Y2 aus, wenn die App Sie dazu auffordert.
  - Schließen Sie das Datenkabel USB nur bei der Live-Eingabeaufforderung an.
  - Lassen Sie den Player ruhig stehen, bis die Erfolgsmeldung erscheint.

Halten Sie die Pakete Y1 und Y2 getrennt. Löschen Sie Rockbox Dateien nicht zuerst manuell; Die Wiederherstellung ersetzt die Systemsoftware.[Y2-Wiederherstellungsanleitung](restore-original-y2_de.html)[Fehlerbehebung](../troubleshooting_de.html)
