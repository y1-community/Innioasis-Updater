## インストールしてください
  - コンピュータで Innioasis Updater CE を開きます (まだお持ちでない場合は、 [Updater CE を入手](../guide_jp.html#platform)）。選択 Y1 で デバイスモデル.
  - 選択してください Y1 向け Linux (開発) で ソフトウェア (または次のように起動します) [Updater CE で入手](../guide_jp.html?model=Y1&software=linux-y1)).
  - リリースを選択してクリックします インストール / 復元.
  - アップデーターが要求した場合にのみ、電源をオフにして Y1 を接続します。
  - Y1を使用 純正ソフトウェア 復元パスの場合。

## 実験港実験的ビルド: これは、開発者と愛好家を対象としたベアボーン Linux ポートです。 UART とコンソールの詳細はプロジェクトのドキュメントに記載されています。Updater への接続手順案内が表示されてから接続してください。
