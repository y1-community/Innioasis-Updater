# 在您的 Innioasis Y2 上安装 Reborn (Y2Linux)。

按照以下步骤进行刷机 Reborn (Y2Linux / Y2Reborn) 使用 Innioasis 更新程序 CE 到 Innioasis Y2，然后完成安装后 Wi-Fi 和蓝牙设置。[获取 Updater CE](../guide_zh-CN.html#download-updater)[为什么是Reborn（Y2Linux）？](../reborn-y2linux-benefits_zh-CN.html)[Y2Reborn 发布](../firmware_zh-CN.html?model=Y2&software=reborn-y2linux-y2)

适用于您的计算机的安装指南

## 使用计算机在 Y2 上安装 Reborn (Y2Linux)

选择适合您正在使用的计算机的指南。 每个版本都有平台设置、Updater CE步骤和返回库存的方式。[Windows 指南](/install/reborn-y2linux-y2-windows.html)[macOS 指南](/install/reborn-y2linux-y2-mac.html)[Linux指南](/install/reborn-y2linux-y2-linux.html)

[所有 Innioasis Y2 指南](/install/y2.html) · [所有 Reborn (Y2Linux) 指南](/install/reborn.html)

## 分步安装
  - 安装更新程序 CE： 下载 [Innioasis 更新程序 CE](../guide_zh-CN.html) 对于 Windows、macOS 或 Linux，然后打开它。
  - 选择Y2： 选择 Y2 作为设备型号。
  - 选择Reborn： 选择 Reborn (Y2Linux) 和最新版本。
  - 安装： 点击 安装 / 恢复，关闭 Y2 电源，并在出现提示时连接 USB。
  - 等待： 保持播放器静止，直到更新程序 CE 确认，然后断开连接。
  - 设置 Wi-Fi、蓝牙和 FM 收音机

复制 `system.img` 给玩家一次。 Reborn 完成剩下的工作。[完成设置 →](../y2reborn_wifibt_zh-CN.html)

## 返回原始软件

您可以随时选择将 Y2 返回到工厂软件 Y2 和 原厂软件 在更新程序 CE 中。请参阅 [Y2恢复教程](restore-original-y2_zh-CN.html).
