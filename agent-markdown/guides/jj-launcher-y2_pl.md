# Zainstaluj JJ Launcher na swoim Y2.

Istnieje kompilacja JJ Launcher dla Y2. Najpierw wybierz swój model, aby Updater nie oferował pakietu Y1.[Pobierz Updater CE](../guide_pl.html#platform)[Zdobądź to w Updater CE](../guide_pl.html?model=Y2&software=jj-launcher-y2)[Dlaczego JJ Launcher?](../jj-launcher-benefits_pl.html)

## Zainstaluj JJ Launcher na swoim Y2 za pomocą komputera

Wybierz przewodnik dla komputera, którego używasz. Każda wersja ma konfigurację platformy, Updater CE kroki i drogę powrotną do stanu magazynowego.[Przewodnik po Windowsie](/install/jj-launcher-y2-windows.html)[przewodnik po macOS-ie](/install/jj-launcher-y2-mac.html)[Przewodnik po Linuksie](/install/jj-launcher-y2-linux.html)

[Wszystkie Innioasis Y2 przewodniki](/install/y2.html) · [Wszystkie JJ Launcher przewodniki](/install/jj-launcher.html)

## Wybierz trasę Y2.
  - Otwórz Innioasis Updater CE na swoim komputerze (jeśli jeszcze go nie masz, [Pobierz Updater CE](../guide_pl.html#platform)). Wybierz Y2 w Model urządzenia.
  - Wybierz JJ Launcher w Oprogramowanie (lub uruchom za pomocą [Zdobądź to w Updater CE](../guide_pl.html?model=Y2&software=jj-launcher-y2)).
  - Przeczytaj informację o wydaniu, potwierdź wpis Y2 i kliknij Zainstaluj / Przywróć.
  - Wyłącz i podłącz odtwarzacz tylko wtedy, gdy aktualizator o to poprosi.
  - Przywróć za pomocą Y2 Oprogramowanie oryginalne jeśli potrzebujesz ponownie interfejsu podstawowego.

## Pierwszą rzeczą do sprawdzenia jest niedopasowanie modelu

JJ Launcher also has a Y1 entry. If the package name looks wrong, return to Device Model. Do not force a Y1 package onto a Y2.Instrukcje podłączenia aktualizatoraPołącz się tylko po monicie na żywo.

## Wróć do oryginalnego oprogramowania

JJ Launcher nie zmienia trasy z powrotem do standardowego interfejsu. Po skonfigurowaniu narzędzia Updater na komputerze otwórz go w systemie Windows, macOS lub Linux i wybierz Y2 plus Oprogramowanie oryginalne zamiast JJ Launcher.
  - Wybierz stabilną Y2 oryginalną wersję oprogramowania.
  - Kliknij Zainstaluj / Przywróć i poczekaj na monit o połączenie na żywo.
  - Wyłącz Y2 tylko wtedy, gdy zostaniesz o to poproszony.
  - Po wyświetleniu monitu podłącz kabel danych USB i pozostaw go nieruchomo, aż do powodzenia.

Nie usuwaj najpierw ręcznie plików JJ Launcher i nie używaj pakietu Y1. Jeśli awaria wystąpiła przed pojawieniem się monitu USB, sprawdź najpierw konfigurację komputera, kabel i wybór modelu.[Przewodnik przywracania Y2](restore-original-y2_pl.html)[Rozwiązywanie problemów](../troubleshooting_pl.html)
