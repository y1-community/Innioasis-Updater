# 在 Y1 上安装 Linux。

Linux for Y1 是一个实验性社区 Linux 内核和 Innioasis Y1 的 rootfs 端口。在 Updater CE 中选择之前选择 Y1。[获取 Updater CE](../guide_zh-CN.html#platform)[在 Updater CE 中获取](../guide_zh-CN.html?model=Y1&software=linux-y1)[项目来源](https://github.com/y1-community/y1-linux-rom)

适用于您的计算机的安装指南

## 使用计算机在 Y1 上安装 Y1 (Dev) Linux

选择适合您正在使用的计算机的指南。 每个版本都有平台设置、Updater CE步骤和返回库存的方式。[Windows 指南](/install/linux-y1-windows.html)[macOS 指南](/install/linux-y1-mac.html)[Linux指南](/install/linux-y1-linux.html)

[所有 Innioasis Y1 指南](/install/y1.html) · [所有 Linux for Y1（开发）指南](/install/linux-dev.html)

## 安装它
  - 在您的计算机上打开 Innioasis Updater CE（如果您还没有， [获取 Updater CE](../guide_zh-CN.html#platform)）。选择 Y1 在 设备型号.
  - 选择 Linux Y1（开发） 在 软件 （或启动 [在 Updater CE 中获取](../guide_zh-CN.html?model=Y1&software=linux-y1)).
  - 选择一个版本并单击 安装 / 恢复.
  - 仅当更新程序提示时关闭并连接 Y1。
  - 使用Y1 原厂软件 为恢复路径。
