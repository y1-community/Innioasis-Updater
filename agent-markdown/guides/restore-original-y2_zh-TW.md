# 恢復 Innioasis Y2 - Innioasis 韌體下載上的原始軟體

恢復·Innioasis Y2

# 使用 Y2 庫存路徑恢復 Y2。

Y2 恢復不是 Y1 恢復。從第一個畫面開始就保持型號選擇和封裝匹配。[取得 Updater CE](../guide_zh-TW.html#platform)[在 Updater CE 中取得此內容](../guide_zh-TW.html?model=Y2&software=original-y2)[瀏覽Y2軟體](../firmware_zh-TW.html#y2)

適用於您的電腦的安裝指南

## 使用電腦復原 Y2 上的原始軟體

選擇適合您正在使用的計算機的指南。 每個版本都有平台設定、Updater CE步驟和返回庫存的方式。[Windows 指南](/install/original-y2-windows.html)[macOS 指南](/install/original-y2-mac.html)[Linux指南](/install/original-y2-linux.html)

[所有 Innioasis Y2 指南](/install/y2.html) · [所有原始軟體指南](/install/original-software.html)

## 來自 Rockbox 或其他自訂軟體

一旦相關的 Windows、macOS 或 Linux 設定準備就緒，返回 Y2 庫存介面將使用與安裝社群專案相同的更新程式流程。請勿手動將 Y1 檔案混合到播放器中或先刪除系統資料夾。
  - 在您的電腦上開啟 Innioasis Updater CE（如果您尚未安裝， [取得 Updater CE](../guide_zh-TW.html#platform) 為了 [窗戶](../drivers_zh-TW.html#windows), [macOS](../guide_zh-TW.html#macos), 或 [Linux](../drivers_zh-TW.html#linux)).
  - 套裝 裝置型號 到 Y2.
  - 選擇 原廠軟體.
  - 選擇穩定的 Y2 版本。可使用手動完整安裝包 `rom_y2.zip`.
  - 點選 安裝 / 還原 並等待提取步驟。
不要替代： 一個Y1 `rom.zip` 不是 Y2 包。如果發布清單看起來有誤，請停止並重新選擇 Y2。

## 依照連接提示操作

Windows、macOS 和 Linux 有不同的電腦設定說明，但播放器端順序保持不變：在詢問時關閉電源，然後根據即時提示連接資料線。
  - 當更新程式要求時，將 Y2 完全關閉。
  - 僅當應用程式表示已準備就緒時才連接 USB。
  - 保持電纜不​​變，直到出現成功訊息。
  - 安全斷開連線並啟動播放器。
更新器連線說明共享連線參考。即時應用提示具有權威性。

## 還卡住了嗎？

在嘗試手動工具之前，請檢查型號、封裝、電纜和連接時序。這 [故障排除指南](../troubleshooting_zh-TW.html) 解釋了 USB 先前的故障與設備檢測之後的故障相比意味著什麼。將包包分開： 一個Y1 `rom.zip` 不是 Y2 恢復。如果發布清單看起來有誤，請停止並再次選擇 Y2。
