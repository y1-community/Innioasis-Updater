# How to install JJ Launcher on your Innioasis Y1 or Y2 - Innioasis Firmware Downloads

JJ Launcher · Y1 and Y2

# Install JJ Launcher after choosing the model.

The project name is shared, but the available package still depends on whether your player is a Y1 or Y2. Pick your model below and the guide will match the package.[Get Updater CE](../guide.html#platform)[JJ Launcher on Y1](jj-launcher-y1.html)[JJ Launcher on Y2](jj-launcher-y2.html)

## Which guide should I use?

Both Y1 and Y2 players install JJ Launcher via Innioasis Updater CE (if you need the app, [Get Updater CE](../guide.html#platform) for your PC, or launch with [Get this in Updater CE](../guide.html?model=Y1&software=jj-launcher-y1)). Choose your model below:

### Innioasis Y1

Follow the model-specific Y1 route and keep the Y1 package selected.[Y1 install steps](jj-launcher-y1.html)

### Innioasis Y2

Follow the model-specific Y2 route and keep the Y2 package selected.[Y2 install steps](jj-launcher-y2.html)
