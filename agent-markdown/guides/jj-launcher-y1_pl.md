## Zainstaluj JJ Launcher na swoim Y1 za pomocą komputera

Wybierz przewodnik dla komputera, którego używasz. Każda wersja ma konfigurację platformy, Updater CE kroki i drogę powrotną do stanu magazynowego.[Przewodnik po Windowsie](/install/jj-launcher-y1-windows.html)[przewodnik po macOS-ie](/install/jj-launcher-y1-mac.html)[Przewodnik po Linuksie](/install/jj-launcher-y1-linux.html)

## Wybierz trasę Y1.
  - Otwórz Innioasis Updater CE na swoim komputerze (jeśli jeszcze go nie masz, [Pobierz Updater CE](../guide_pl.html#platform)). Wybierz Y1 w Model urządzenia.
  - Wybierz JJ Launcher w Oprogramowanie (lub uruchom za pomocą [Zdobądź to w Updater CE](../guide_pl.html?model=Y1&software=jj-launcher-y1)).
  - Przeczytaj informację o wydaniu, wybierz wersję Y1 i kliknij Zainstaluj / Przywróć.
  - Wyłącz i podłącz odtwarzacz tylko wtedy, gdy aktualizator o to poprosi.
  - Przywróć za pomocą Y1 Oprogramowanie oryginalne jeśli potrzebujesz ponownie interfejsu podstawowego.

JJ Launcher also has a Y2 entry. If the package name looks wrong, return to Device Model. Do not force a Y2 package onto a Y1.Instrukcje podłączenia aktualizatoraPołącz się tylko po monicie na żywo.

## Wróć do oryginalnego oprogramowania

JJ Launcher nie zmienia trasy z powrotem do standardowego interfejsu. Po skonfigurowaniu narzędzia Updater na komputerze otwórz go w systemie Windows, macOS lub Linux i wybierz Y1 plus Oprogramowanie oryginalne zamiast JJ Launcher.
  - Wybierz stabilną Y1 oryginalną wersję oprogramowania.
  - Kliknij Zainstaluj / Przywróć i poczekaj na monit o połączenie na żywo.
  - Wyłącz Y1 tylko wtedy, gdy zostaniesz o to poproszony.
  - Po wyświetleniu monitu podłącz kabel danych USB i pozostaw go nieruchomo, aż do powodzenia.

Nie usuwaj najpierw ręcznie plików JJ Launcher i nie używaj pakietu Y2.
