Android 4.4 (développement) · Innioasis Y2

# Installez Android 4.4 (Dev) sur un Y2.

Android 4.4 est un développement communautaire ROM pour tester et pirater le matériel Innioasis Y2. Sélectionnez Y2 avant de le choisir dans Updater CE.[Obtenir Updater CE](../guide_fr.html#platform)[Disponible dans Updater CE](../guide_fr.html?model=Y2&software=android-4-4-y2)[Origine du projet](https://github.com/y1-community/y2-ata-rom)

Guide d'installation pour votre ordinateur

## Installez le développement Android ROM sur votre Y2 avec votre ordinateur

Choisissez le guide correspondant à l'ordinateur que vous utilisez. Chaque version comprend la configuration de la plate-forme, Updater CE étapes et le chemin de retour au stock.[Guide Windows](/install/android-4-4-y2-windows.html)[Guide macOS](/install/android-4-4-y2-mac.html)[Guide Linux](/install/android-4-4-y2-linux.html)

[Tous les guides Innioasis Y2](/install/y2.html) · [Tous les guides ROM de développement Android](/install/android-dev.html)

## Installez-le
  - Ouvrez Innioasis Updater CE sur votre ordinateur (si vous ne l'avez pas encore, [Obtenir Updater CE](../guide_fr.html#platform)). Sélectionnez Y2 dans Modèle d'appareil.
  - Choisissez Android 4.4 (développement) dans Logiciel (ou lancer avec [Disponible dans Updater CE](../guide_fr.html?model=Y2&software=android-4-4-y2)).
  - Sélectionnez une version et cliquez sur Installer / Restaurer.
  - Éteignez et connectez le Y2 uniquement lorsque le programme de mise à jour vous le demande.
  - Utiliser Y2 Logiciel d'origine pour le chemin de restauration.
