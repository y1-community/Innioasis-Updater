# Instale o Linux em um Y1.

Linux para Y1 é um kernel Linux da comunidade experimental e uma porta rootfs para Innioasis Y1. Selecione Y1 antes de escolhê-lo em Updater CE.[Obtenha o atualizador CE](../guide_pt.html#platform)[Obtenha isso em Updater CE](../guide_pt.html?model=Y1&software=linux-y1)[Fonte do projeto](https://github.com/y1-community/y1-linux-rom)

Guia de instalação para o seu computador

## Instale Linux para Y1 (Dev) em seu Y1 com seu computador

Escolha o guia para o computador que você está usando. Cada versão possui a configuração da plataforma, Updater CE etapas e o caminho de volta ao estoque.[Guia do Windows](/install/linux-y1-windows.html)[guia macOS](/install/linux-y1-mac.html)[Guia Linux](/install/linux-y1-linux.html)

[Todos Innioasis Y1 guias](/install/y1.html) · [Todos os guias Linux para Y1 (Dev)](/install/linux-dev.html)

## Instale-o
  - Abra Innioasis Updater CE no seu computador (se ainda não o tiver, [Obtenha o atualizador CE](../guide_pt.html#platform)). Selecione Y1 em Modelo do dispositivo.
  - Escolher Linux para Y1 (Desenvolvedor) em Programas (ou lançar com [Obtenha isso em Updater CE](../guide_pt.html?model=Y1&software=linux-y1)).
  - Selecione uma versão e clique em Instalar / Restaurar.
  - Desligue e conecte o Y1 somente quando o Updater solicitar.
  - Usar Y1 Software Original para o caminho de restauração.
