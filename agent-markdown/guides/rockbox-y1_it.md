## Di cosa hai bisogno

Un Innioasis Y1, una batteria carica, un USB cavo dati e un computer con Innioasis Updater CE installato (se non lo hai ancora installato, [Ottieni Updater CE](../guide_it.html#platform) per Windows, macOS o Linux). Type A è adatto a Y1 giocatori forniti con la versione del software originale 2.0.0 o successiva; Type B è adatto ai giocatori forniti con una versione precedente di [Software originale](../firmware_it.html?software=original-y1). Inizia con Type A a meno che tu non sappia già che il tuo giocatore ha bisogno di una build Type B.

## Nell'Aggiornamento
  - Apri Updater CE (o avvia con [Ottieni questo in Updater CE](../guide_it.html?model=Y1&software=rockbox-y1)) e impostare Modello del dispositivo a Y1.
  - Scegli Rockbox dentro Software. L'etichetta esatta del progetto potrebbe essere visualizzata come Rockbox-Y1 nei dati di rilascio.
  - Scegli una versione stabile. Le build 240p hanno la più ampia compatibilità con i temi precedenti; Le build a 360p sono destinate al percorso tematico Y1. Controlla le note di rilascio quando la distinzione è importante.
  - Fare clic Installa / Ripristina. Attendi che Updater CE scarichi il pacchetto direttamente dalla release della community di sviluppatori e lo prepari.

## Collega il Y1
  - Attendi finché Updater non richiede il lettore.
  - Spegnere completamente Y1. Se non si spegne, utilizzare le istruzioni di ripristino mostrate da Updater.
  - Collega il cavo dati USB solo quando richiesto dall'app. Metti giù il lettore e non disturbare la connessione.
  - Disconnettersi solo dopo che l'Updater ha confermato il successo, quindi avviare Y1.
Istruzioni per la connessione dell'aggiornamentoLa dicitura della connessione può variare in base alla piattaforma. Segui la richiesta dal vivo.

## Ritorna al software originale

Rockbox non ti vincola al software personalizzato. Una volta configurato Updater per il tuo computer, utilizzalo su Windows, macOS o Linux: seleziona Y1, scegliere Software originalee corri Installa / Ripristina.
  - Attendi che Updater finisca di preparare il pacchetto stock.
  - Spegni il Y1 quando richiesto dall'app.
  - Collegare il cavo dati USB solo al prompt live.
  - Lasciare fermo il lettore fino al messaggio di successo.

Non utilizzare il pacchetto Y2 e non eliminare manualmente i file Rockbox prima del ripristino. Per il comportamento della ruota Type B, verificare la variante di rilascio corrispondente prima di cambiare tipo di dispositivo.[Guida al ripristino Y1](restore-original-y1_it.html)[Risoluzione dei problemi](../troubleshooting_it.html)
