# 如何在 Innioasis Y2 - Innioasis 上安装 JJ Launcher 固件下载

JJ Launcher · Innioasis Y2

# 在您的 Y2 上安装 JJ Launcher。

Y2 有一个 JJ Launcher 版本。首先选择您的型号，以便更新程序不提供 Y1 软件包。[获取 Updater CE](../guide_zh-CN.html#platform)[在 Updater CE 中获取](../guide_zh-CN.html?model=Y2&software=jj-launcher-y2)[为什么是JJ Launcher？](../jj-launcher-benefits_zh-CN.html)

还提供： [Y1 上的 JJ Launcher](jj-launcher-y1_zh-CN.html)

适用于您的计算机的安装指南

## 使用计算机在 Y2 上安装 JJ Launcher

选择适合您正在使用的计算机的指南。 每个版本都有平台设置、Updater CE步骤和返回库存的方式。[Windows 指南](/install/jj-launcher-y2-windows.html)[macOS 指南](/install/jj-launcher-y2-mac.html)[Linux指南](/install/jj-launcher-y2-linux.html)

[所有 Innioasis Y2 指南](/install/y2.html) · [所有 JJ Launcher 指南](/install/jj-launcher.html)

## 选择Y2路线
  - 在您的计算机上打开 Innioasis Updater CE（如果您还没有， [获取 Updater CE](../guide_zh-CN.html#platform)）。选择 Y2 在 设备型号.
  - 选择 JJ Launcher 在 软件 （或启动 [在 Updater CE 中获取](../guide_zh-CN.html?model=Y2&software=jj-launcher-y2)).
  - 阅读发行说明，确认 Y2 条目，然后单击 安装 / 恢复.
  - 仅当更新程序要求时关闭并连接播放器。
  - 用 Y2 恢复 原厂软件 如果您再次需要库存接口。

## 观看视频

视频由 doitall 提供。它是在 Innioasis Y1 上拍摄的，但 JJ Launcher 步骤和故障排除可延续到下面的 Y2 路线。

## 模型不匹配是首先要检查的事情

JJ Launcher 也有一个 Y1 条目。如果包名称看起来错误，请返回设备模型。不要将 Y1 包强行放到 Y2 上。Updater 连接说明仅在提示时连接。

## 返回原始软件

JJ Launcher 不会更改返回库存接口的路由。为您的计算机设置更新程序后，请在 Windows、macOS 或 Linux 上打开它，然后选择 Y2 加号 原厂软件 而不是 JJ Launcher。
  - 选择稳定的 Y2 原始软件版本。
  - 点击 安装 / 恢复 并等待实时连接提示。
  - 仅在询问时关闭 Y2 电源。
  - 根据提示连接USB数据线并保持不动直至成功。

不要先手动删除 JJ Launcher 文件，并且不要使用 Y1 包。如果故障发生在USB提示之前，请首先检查计算机设置、电缆和型号选择。[Y2恢复指南](restore-original-y2_zh-CN.html)[故障排除](../troubleshooting_zh-CN.html)
