# Як інсталювати Rockbox на Innioasis Y2 - Innioasis завантаження мікропрограми

Rockbox · Innioasis Y2

# Встановіть збірку Y2, а не збірку Y1.

Шлях користувача знайомий, але модель і пакет відрізняються. Спочатку виберіть Y2, щоб програма оновлення підготувала правильні файли та шлях встановлення.[Отримати Updater CE](../guide_uk.html#platform)[Отримайте це в Updater CE](../guide_uk.html?model=Y2&software=rockbox-y2)[Чому Rockbox?](../rockbox-benefits_uk.html)

Посібник із встановлення для вашого комп’ютера

## Встановіть Rockbox на свій Y2 разом із комп’ютером

Виберіть посібник для комп’ютера, яким ви користуєтеся. Кожна версія має налаштування платформи, Updater CE кроків і шлях повернення до запасу.[Керівництво по Windows](/install/rockbox-y2-windows.html)[посібник з macOS](/install/rockbox-y2-mac.html)[Керівництво по Linux](/install/rockbox-y2-linux.html)

[Усі Innioasis Y2 посібники](/install/y2.html) · [Усі Rockbox посібники](/install/rockbox.html)

## Дивіться маршрут Rockbox.

Відео від Frawgeeys. Це працює як для моделей Y1, так і для Y2 — у Innioasis Updater CE виберіть Y2 як свою модель. Написані нижче кроки охоплюють послідовність встановлення Y2.

Відео автора [Крістіан Плаза](https://www.youtube.com/@CristianPlaza) (іспанська). Він демонструє встановлення на Y1; вибрати Y2 в Updater CE для цього посібника.

## Перш ніж натиснути «Установити».

Майте заряджений Innioasis Y2, USB кабель даних і комп’ютер із інстальованим Innioasis Updater CE (якщо ви його ще не встановили, [Отримати Updater CE](../guide_uk.html#platform) для Windows, macOS або Linux). Не використовуйте випуск Y1 лише тому, що його назва виглядає схожою.Перевірка моделі: Y2 пакетів повної інсталяції можуть використовуватися `rom_y2.zip`. Назва файлу є корисною підказкою для завантаження вручну, але Updater має обробити вибір пакета за вас.

## Виберіть Y2 в Updater
  - Відкрийте Updater CE (або запустіть за допомогою [Отримайте це в Updater CE](../guide_uk.html?model=Y2&software=rockbox-y2)) і встановіть Модель пристрою для Y2.
  - Виберіть Rockbox в Програмне забезпечення.
  - Виберіть випуск зі списку для Y2. Якщо в списку немає Y2 випуску, не замінюйте Y1 випуск.
  - Натисніть Встановити / Відновити and let Updater CE download the package directly from the community developer's release.

## Вимкніть, потім підключіть
  - Дочекайтеся підказки підключення.
  - Повністю вимкніть Y2. Використовуйте точні інструкції щодо скидання або відновлення, які показує Updater, якщо звичайне завершення роботи не вдається.
  - Коли буде запропоновано, під’єднайте кабель USB. Залиште його нерухомим до повідомлення про завершення.
  - Безпечно від’єднайте та запустіть Y2.
Інструкції з підключення програми оновлення для вимкненого пристроюЕкран підключення є довідковим. Ваш запит Y2 може містити інше формулювання моделі.

## Повернутися до оригінального програмного забезпечення

Rockbox не блокує вас у спеціальному програмному забезпеченні. Налаштувавши Updater для вашого комп’ютера, використовуйте його в Windows, macOS або Linux, щоб повернутися з Rockbox або іншого проекту зі списку: виберіть Y2, вибрати Заводське ПЗ, і бігти Встановити / Відновити.
  - Зачекайте, доки програма оновлення підготує стандартний пакет Y2.
  - Вимкніть Y2, коли програма запитає.
  - Підключайте кабель передачі даних USB лише за підказкою в реальному часі.
  - Залиште плеєр нерухомим до повідомлення про успішне виконання.

Зберігайте пакети Y1 і Y2 окремо. Не видаляйте спочатку Rockbox файли вручну; відновлення замінює системне програмне забезпечення.[Посібник з відновлення Y2](restore-original-y2_uk.html)[Усунення несправностей](../troubleshooting_uk.html)
