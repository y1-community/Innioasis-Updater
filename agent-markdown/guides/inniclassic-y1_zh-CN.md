# 如何在 Innioasis Y1 - Innioasis 上安装 Inniclassic 固件下载

Inniclassic · Innioasis Y1

# 在 Y1 上安装 Inniclassic。

Inniclassic 被列为 Y1 项目。在选择之前先选择 Y1，以便版本列表保持模型感知。[获取 Updater CE](../guide_zh-CN.html#platform)[在 Updater CE 中获取](../guide_zh-CN.html?model=Y1&software=inniclassic-y1)[为什么是Inniclassic？](../inniclassic-benefits_zh-CN.html)

适用于您的计算机的安装指南

## 使用计算机在 Y1 上安装 Inniclassic

选择适合您正在使用的计算机的指南。 每个版本都有平台设置、Updater CE步骤和返回库存的方式。[Windows 指南](/install/inniclassic-y1-windows.html)[macOS 指南](/install/inniclassic-y1-mac.html)[Linux指南](/install/inniclassic-y1-linux.html)

[所有 Innioasis Y1 指南](/install/y1.html) · [所有 Inniclassic 指南](/install/inniclassic.html)

## 安装它
  - 在您的计算机上打开 Innioasis Updater CE（如果您还没有， [获取 Updater CE](../guide_zh-CN.html#platform)）。选择 Y1 在 设备型号.
  - 选择 Inniclassic 在 软件 （或启动 [在 Updater CE 中获取](../guide_zh-CN.html?model=Y1&software=inniclassic-y1)).
  - 选择一个版本并单击 安装 / 恢复.
  - 仅当更新程序提示时关闭并连接 Y1。
  - 使用Y1 原厂软件 为恢复路径。

## 保持连接不变Updater 连接说明确切的提示可能因平台而异。

如果安装失败，请注意失败是发生在更新程序检测到播放器之前还是之后。这些细节使故障排除变得更快。
