# Установите Koensayr на Y1.

Koensayr указан как проект Y1. Позвольте программе обновлений управлять пакетом, а затем выполните такое же тщательное выключение и USB выбор времени, как и при других полных установках.[Скачать Updater CE](../guide_ru.html#platform)[Получите это в Updater CE](../guide_ru.html?model=Y1&software=koensayr-y1)[Почему Koensayr?](../koensayr-benefits_ru.html)

Руководство по установке для вашего компьютера

## Установите Koensayr на свой Y1 с помощью компьютера.

Выберите руководство для компьютера, который вы используете. В каждой версии есть настройка платформы, Updater CE шагов и возврат к стоку.[Руководство по Windows](/install/koensayr-y1-windows.html)[руководство по macOS](/install/koensayr-y1-mac.html)[Руководство по Linux](/install/koensayr-y1-linux.html)

[Все Innioasis Y1 руководства](/install/y1.html) · [Все Koensayr руководства](/install/koensayr.html)

## Шаги установки
  - Откройте Innioasis Updater CE на своем компьютере (если у вас его еще нет, [Скачать Updater CE](../guide_ru.html#platform)). Выбирать Y1 в Модель устройства.
  - Выбирать Koensayr в Программное обеспечение (или запустить с помощью [Получите это в Updater CE](../guide_ru.html?model=Y1&software=koensayr-y1)).
  - Выберите указанный выпуск и нажмите Установить / Восстановить.
  - Выключите питание и подключайте Y1 только тогда, когда приложение запросит это.
  - Используйте Y1 Заводское ПО чтобы восстановить стандартный путь.

## Когда что-то не получается

Сначала проверьте модель и выбор типа. Затем проверьте кабель и был ли подключен плеер до появления подсказки. Если приложение остановилось до того, как дождалось USB, откройте [Поиск неисправностей](../troubleshooting_ru.html).Инструкция по подключению обновленийСтабильное соединение является частью установки.
