## Schritt-für-Schritt-Installation
  - Öffnen Sie Updater CE: Starten [Innioasis Updater CE](../guide_de.html) auf Ihrem Windows-, macOS- oder Linux-Computer.
  - Wählen Sie das Gerätemodell Y1: Auswählen Y1 im Dropdown-Menü „Gerätemodell“ (wählen Sie Type B, wenn Ihr Y1 mit der Originalsoftware vor 2.0.0 geliefert wurde; andernfalls behalten Sie Type A bei).
  - Wählen Sie Rondo aus der Dropdown-Liste „Software“: Auswählen Rondo in der Softwareliste und wählen Sie die neueste Version aus. Updater CE verwendet automatisch den Android 4.2 Wi-Fi Base ROM und Rondo Release-Feed.
  - Flashen Sie den Player: Klicken Sie Installieren / Wiederherstellen, schalten Sie Ihr Y1 vollständig aus und verbinden Sie es über ein USB-Datenkabel, wenn Updater CE Sie dazu auffordert.
  - Trennen und booten: Warten Sie auf die grüne Abschlussmeldung, bevor Sie Ihr Y1 ausstecken.
  - Komplette Einrichtung nach der Installation

Befolgen Sie die Schritte in [diesen Leitfaden](../post_install_de.html?software=rondo-y1&model=Y1) um die Einrichtung auf Ihrem Y1 abzuschließen.[Anleitung anzeigen](../post_install_de.html?software=rondo-y1&model=Y1)
