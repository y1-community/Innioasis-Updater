# Installieren Sie Solar auf Ihrem Y2.

Solar ist ein separates Community-Projekt und es ist ein Y2-Build aufgeführt. Funktionen können sich ändern. Lassen Sie Updater daher die aktuelle Version für Ihr Modell anzeigen.[Updater CE holen](../guide_de.html#platform)[In Updater CE erhalten](../guide_de.html?model=Y2&software=solar-y2)[Warum Solar?](../solar-benefits_de.html)

Auch erhältlich: [Solar am Y1](solar-y1_de.html)

Installationsanleitung für Ihren Computer

## Installieren Sie Solar auf Ihrem Y2 mit Ihrem Computer

Wählen Sie die Anleitung für den Computer aus, den Sie verwenden. Jede Version verfügt über das Plattform-Setup, Updater CE Schritte und den Weg zurück zum Lagerbestand.[Windows-Anleitung](/install/solar-y2-windows.html)[macOS-Anleitung](/install/solar-y2-mac.html)[Linux-Anleitung](/install/solar-y2-linux.html)

[Alle Innioasis Y2-Anleitungen](/install/y2.html) · [Alle Solar Anleitungen](/install/solar.html)

## Wählen Sie die Route Y2.
  - Öffnen Sie Innioasis Updater CE auf Ihrem Computer (falls Sie es noch nicht haben, [Updater CE holen](../guide_de.html#platform)). Auswählen Y2 In Gerätemodell.
  - Wählen Sie Solar In Software (oder starten Sie mit [In Updater CE erhalten](../guide_de.html?model=Y2&software=solar-y2)).
  - Lesen Sie die Versionshinweise, bestätigen Sie den Eintrag Y2 und klicken Sie auf Installieren / Wiederherstellen.
  - Schalten Sie den Player nur aus und schließen Sie ihn an, wenn der Updater Sie dazu auffordert.
  - Mit Y2 wiederherstellen Original-Software wenn Sie die Standardschnittstelle erneut benötigen.

## Behalten Sie die Projektnotiz im Blick

Solar befindet sich in der aktiven Entwicklung. Funktionen und Modellunterstützung können sich ändern. Sehen Sie sich daher die Versionshinweise des Projekts an. Der Updater zeigt, was derzeit für Ihr Modell verfügbar ist. Ersetzen Sie kein Y1-Paket, wenn der Eintrag Y2 fehlt.Anweisungen zum Verbinden mit UpdaterErst verbinden, wenn die Aufforderung erscheint.

## Gehen Sie zurück zur Originalsoftware

Solar ändert die Route zurück zur Standardschnittstelle nicht. Sobald Updater für Ihren Computer eingerichtet ist, öffnen Sie es unter Windows, macOS oder Linux und wählen Sie Y2 Plus Original-Software statt Solar.
  - Wählen Sie eine stabile Y2 Originalsoftwareversion.
  - Klicken Sie Installieren / Wiederherstellen und warten Sie auf die Live-Verbindungsaufforderung.
  - Schalten Sie Y2 nur aus, wenn Sie dazu aufgefordert werden.
  - Schließen Sie bei der Aufforderung das USB-Datenkabel an und lassen Sie es bis zum Erfolg ruhen.

Entfernen Sie nicht zuerst Solar-Dateien manuell und verwenden Sie kein Y1-Paket. Wenn der Fehler vor der Eingabeaufforderung USB aufgetreten ist, überprüfen Sie zunächst die Computerkonfiguration, das Kabel und die Modellauswahl.[Y2-Wiederherstellungsanleitung](restore-original-y2_de.html)[Fehlerbehebung](../troubleshooting_de.html)
