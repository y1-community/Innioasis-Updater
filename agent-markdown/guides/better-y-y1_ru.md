# Как установить Better-Y на загрузку прошивки Innioasis Y1 - Innioasis

Better-Y · Innioasis Y1

# Установите Better-Y на Y1.

Better-Y — это улучшенная версия стокового изображения для Innioasis Y1, созданная Leska1337. Выберите Y1 перед тем, как выбрать его для установки пакетов, соответствующих модели.[Скачать Updater CE](../guide_ru.html#platform)[Получите это в Updater CE](../guide_ru.html?model=Y1&software=better-y-y1)[Почему Better-Y?](../better-y-benefits_ru.html)

Руководство по установке для вашего компьютера

## Установите Better-Y на свой Y1 с помощью компьютера.

Выберите руководство для компьютера, который вы используете. В каждой версии есть настройка платформы, Updater CE шагов и возврат к стоку.[Руководство по Windows](/install/better-y-y1-windows.html)[руководство по macOS](/install/better-y-y1-mac.html)[Руководство по Linux](/install/better-y-y1-linux.html)

[Все Innioasis Y1 руководства](/install/y1.html) · [Все Better-Y руководства](/install/better-y.html)

## Установите его
  - Откройте Innioasis Updater CE на своем компьютере (если у вас его еще нет, [Скачать Updater CE](../guide_ru.html#platform)). Выбирать Y1 в Модель устройства.
  - Выбирать Better-Y в Программное обеспечение (или запустить с помощью [Получите это в Updater CE](../guide_ru.html?model=Y1&software=better-y-y1)).
  - Выберите выпуск и нажмите Установить / Восстановить.
  - Выключите и подключите Y1 только тогда, когда программа обновлений предложит вам это сделать.
  - Используйте Y1 Заводское ПО для пути восстановления.

## Держите соединение по-прежнемуИнструкция по подключению обновленийПодключайтесь только по интерактивной подсказке.

Оставьте плеер неподвижным, пока мигание завершится. Когда программа обновлений подтвердит успех, отключите плеер и включите его.

## Better-Y ярлыки и советы
  - Перейти к «Сейчас играет» — Дважды нажмите кнопку «Воспроизведение/Пауза» на любом экране или меню, чтобы мгновенно вернуться к воспроизведению.
  - Аварийная перезагрузка — Если плеер перестанет отвечать на запросы, удерживайте верхнюю и нижнюю кнопки вместе, чтобы вызвать чистую перезагрузку оборудования.
  - Алфавитный свиток — Вращайте колесико управления по краю, чтобы активировать алфавитную полосу быстрого индексирования в длинных списках треков.
  - Интерактивные значки «Сейчас исполняется» — Коснитесь экранных значков «Нравится», «В случайном порядке», «Повторить (один/все), «Текст», «Петля A–B», «Очередь», «Закладка», «Скорость» и «Таймер сна».
  - Разделение тегов — Разделяйте нескольких исполнителей запятыми (,) или точками с запятой (;), чтобы треки отображались под каждым исполнителем индивидуально. Многожанровые теги разделяются запятыми, точками с запятой или косой чертой.
