# Как установить Inniclassic на загрузку прошивки Innioasis Y2 - Innioasis

Inniclassic · Innioasis Y2

# Установите Inniclassic на Y2.

Inniclassic имеет выделенный порт Y2 , поддерживаемый Йонашем Потонцем. Прежде чем выбирать, выберите Y2 для того, чтобы список выпусков сохранял информацию о модели.[Скачать Updater CE](../guide_ru.html#platform)[Получите это в Updater CE](../guide_ru.html?model=Y2&software=inniclassic-y2)[Почему Inniclassic?](../inniclassic-benefits_ru.html)

Руководство по установке для вашего компьютера

## Установите Inniclassic на свой Y2 с помощью компьютера.

Выберите руководство для компьютера, который вы используете. В каждой версии есть настройка платформы, Updater CE шагов и возврат к стоку.[Руководство по Windows](/install/inniclassic-y2-windows.html)[руководство по macOS](/install/inniclassic-y2-mac.html)[Руководство по Linux](/install/inniclassic-y2-linux.html)

[Все Innioasis Y2 руководства](/install/y2.html) · [Все Inniclassic руководства](/install/inniclassic.html)

## Установите его
  - Откройте Innioasis Updater CE на своем компьютере (если у вас его еще нет, [Скачать Updater CE](../guide_ru.html#platform)). Выбирать Y2 в Модель устройства.
  - Выбирать Inniclassic в Программное обеспечение (или запустить с помощью [Получите это в Updater CE](../guide_ru.html?model=Y2&software=inniclassic-y2)).
  - Выберите выпуск и нажмите Установить / Восстановить.
  - Выключите питание и подсоедините Y2 только тогда, когда программа обновлений предложит вам это сделать.
  - Используйте Y2 Заводское ПО для пути восстановления.

## Держите соединение по-прежнемуИнструкция по подключению обновленийПодключайтесь только по интерактивной подсказке.

Y2 пакеты используют `rom_y2.zip`. Если установка не удалась, обратите внимание, произошел ли сбой до или после того, как программа обновлений обнаружила плеер.
