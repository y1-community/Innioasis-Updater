# Innioasis Y2 - Innioasis ファームウェアのダウンロードに Inniclassic をインストールする方法

Inniclassic · Innioasis Y2

# Inniclassic を Y2 にインストールします。

Inniclassic には、Jonasz Potoniec によって管理される専用の Y2 ポートがあります。リリース リストがモデルを認識できるように、選択する前に Y2 を選択してください。[Updater CE を入手](../guide_jp.html#platform)[Updater CE で入手](../guide_jp.html?model=Y2&software=inniclassic-y2)[なぜInniclassic?](../inniclassic-benefits_jp.html)

お使いのコンピューターのインストールガイド

## コンピュータを使用して Y2 に Inniclassic をインストールします

使用しているコンピュータのガイドを選択してください。 すべてのバージョンには、プラットフォームのセットアップ、Updater CE の手順、および在庫に戻る方法が含まれています。[Windowsガイド](/install/inniclassic-y2-windows.html)[macOS ガイド](/install/inniclassic-y2-mac.html)[Linuxガイド](/install/inniclassic-y2-linux.html)

[すべての Innioasis Y2 ガイド](/install/y2.html) · [すべての Inniclassic ガイド](/install/inniclassic.html)

## インストールしてください
  - コンピュータで Innioasis Updater CE を開きます (まだお持ちでない場合は、 [Updater CE を入手](../guide_jp.html#platform)）。選択 Y2 で デバイスモデル.
  - 選択してください Inniclassic で ソフトウェア (または次のように起動します) [Updater CE で入手](../guide_jp.html?model=Y2&software=inniclassic-y2)).
  - リリースを選択してクリックします インストール / 復元.
  - アップデーターが要求した場合にのみ、電源を切り、Y2 を接続してください。
  - Y2 を使用します 純正ソフトウェア 復元パスの場合。

## 接続を維持したままにしてくださいUpdater への接続手順案内が表示されてから接続してください。

Y2 パッケージは使用します `rom_y2.zip`。インストールが失敗した場合は、アップデータがプレーヤーを検出する前か後に失敗が発生したかをメモします。
