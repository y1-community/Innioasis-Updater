## Install steps
  - Open Innioasis Updater CE on your computer (if you don't have it yet, [Get Updater CE](../guide.html#platform)). Select Y1 in Device Model.
  - Choose Koensayr in Software (or launch with [Get this in Updater CE](../guide.html?model=Y1&software=koensayr-y1)).
  - Select the listed release and click Install / Restore.
  - Power off and connect the Y1 only when the app asks.
  - Use Y1 Original Software to restore the stock path.

## When something fails

Check the model and Type selection first. Then check the cable and whether the player was connected before the prompt. If the app stopped before it waited for USB, open [troubleshooting](../troubleshooting.html).Updater connection instructionsA stable connection is part of the install.
