# Innioasis Y1 - Innioasis ファームウェアのダウンロードに Android 4.2 (Dev) をインストールする方法

Android 4.2 (開発) · Innioasis Y1

# Android 4.2 (Dev) を Y1 にインストールします。

Android 4.2 は、Innioasis Y1 ハードウェアのテストとハッキングを目的としたコミュニティ開発 ROM です。 Updater CEで選択する前にY1を選択してください。[Updater CE を入手](../guide_jp.html#platform)[Updater CE で入手](../guide_jp.html?model=Y1&software=android-4-2-y1)[プロジェクトソース](https://github.com/y1-community/y1-ata-rom)

お使いのコンピューターのインストールガイド

## コンピュータを使用して Android 開発 ROM を Y1 にインストールします

使用しているコンピュータのガイドを選択してください。 すべてのバージョンには、プラットフォームのセットアップ、Updater CE の手順、および在庫に戻る方法が含まれています。[Windowsガイド](/install/android-4-2-y1-windows.html)[macOS ガイド](/install/android-4-2-y1-mac.html)[Linuxガイド](/install/android-4-2-y1-linux.html)

[すべての Innioasis Y1 ガイド](/install/y1.html) · [すべての Android 開発 ROM ガイド](/install/android-dev.html)

## インストールしてください
  - コンピュータで Innioasis Updater CE を開きます (まだお持ちでない場合は、 [Updater CE を入手](../guide_jp.html#platform)）。選択 Y1 で デバイスモデル.
  - 選択してください Android 4.2 (開発版) で ソフトウェア (または次のように起動します) [Updater CE で入手](../guide_jp.html?model=Y1&software=android-4-2-y1)).
  - リリースを選択してクリックします インストール / 復元.
  - アップデーターが要求した場合にのみ、電源をオフにして Y1 を接続します。
  - Y1を使用 純正ソフトウェア 復元パスの場合。

## 開発者ビルドノート開発者ビルド: 実験用の開発画像です。現在のハードウェア サポートと既知の問題については、リリース ノートをお読みください。Updater への接続手順案内が表示されてから接続してください。
