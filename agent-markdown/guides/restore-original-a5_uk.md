# Відновлення оригінального програмного забезпечення на Innioasis A5 - Innioasis завантаження мікропрограми

# Відновити оригінальне програмне забезпечення на Innioasis і Timmkoo A5

Виконайте цей підручник, щоб відновити офіційне заводське програмне забезпечення на вашому Innioasis A5 або Timmkoo A5 плеєрі з перевіреними пакетами з Innioasis Firmware Archive.[Отримати Updater CE](../guide_uk.html#platform)[Переглянути A5 завантажень](../firmware_uk.html?model=A5)

## Крок 1: Налаштування в Updater CE
  - Запуск Innioasis Оновлення CE на вашому комп’ютері з Windows, macOS або Linux.
  - встановити Модель пристрою для A5.
  - Виберіть Заводське ПЗ. Updater CE завантажує офіційний `rom_a5.zip` випуск пакета безпосередньо.
  - Натисніть Встановити / Відновити і дочекайтеся завершення підготовки.

## Крок 2. Підключіться за підказкою
  - Повністю вимкніть пристрій A5.
  - Зачекайте підказки на екрані комп’ютера, перш ніж підключати USB кабель даних.
  - Дозвольте процесу прошивки завершитися без перерви.
  - Відключіть і перезавантажте щойно відновлений плеєр A5.
