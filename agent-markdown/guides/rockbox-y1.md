## What you need

An Innioasis Y1, a charged battery, a USB data cable, and a computer with Innioasis Updater CE installed (if you haven't installed it yet, [Get Updater CE](../guide.html#platform) for Windows, macOS, or Linux). Type A suits Y1 players that shipped with Original Software version 2.0.0 or later; Type B suits players that shipped with an earlier version of the [Original Software](../firmware.html?software=original-y1). Start with Type A unless you already know your player needs a Type B build.

## In Updater
  - Open Updater CE (or launch with [Get this in Updater CE](../guide.html?model=Y1&software=rockbox-y1)) and set Device Model to Y1.
  - Choose Rockbox in Software. The exact project label may appear as Rockbox-Y1 in release data.
  - Choose a stable release. 240p builds have the broadest older theme compatibility; 360p builds are intended for the Y1 theme path. Check the release notes when the distinction matters.
  - Click Install / Restore. Wait while Updater CE downloads the package directly from the community developer's release and prepares it.

## Connect the Y1
  - Wait until Updater asks for the player.
  - Power the Y1 fully off. If it will not shut down, use the recovery instruction shown by Updater.
  - Connect the USB data cable only when the app says to. Put the player down and do not disturb the connection.
  - Disconnect only after Updater confirms success, then start the Y1.
Updater connection instructionsThe connection wording can vary by platform. Follow the live prompt.

## Return to Original Software

Rockbox does not lock you into the custom software. Once Updater is set up for your computer, use it on Windows, macOS, or Linux: select Y1, choose Original Software, and run Install / Restore.
  - Wait for Updater to finish preparing the stock package.
  - Power off the Y1 when the app asks.
  - Connect the USB data cable only at the live prompt.
  - Leave the player still until the success message.

Do not use the Y2 package, and do not manually delete Rockbox files before the restore. For Type B wheel behaviour, check the matching release variant before changing device type.[Y1 restore guide](restore-original-y1.html)[Troubleshooting](../troubleshooting.html)
