# Installa Android 4.2 (Dev) su un Y1.

Android 4.2 è uno sviluppo della community ROM per testare e hackerare l'hardware Innioasis Y1. Selezionare Y1 prima di sceglierlo in Updater CE.[Ottieni Updater CE](../guide_it.html#platform)[Ottieni questo in Updater CE](../guide_it.html?model=Y1&software=android-4-2-y1)[Fonte del progetto](https://github.com/y1-community/y1-ata-rom)

## Installalo
  - Apri Innioasis Updater CE sul tuo computer (se non lo hai ancora, [Ottieni Updater CE](../guide_it.html#platform)). Seleziona Y1 dentro Modello del dispositivo.
  - Scegli Android 4.2 (sviluppo) dentro Software (o avvia con [Ottieni questo in Updater CE](../guide_it.html?model=Y1&software=android-4-2-y1)).
  - Selezionare una versione e fare clic Installa / Ripristina.
  - Spegni e collega Y1 solo quando l'Updater lo richiede.
  - Usa Y1 Software originale per il percorso di ripristino.
