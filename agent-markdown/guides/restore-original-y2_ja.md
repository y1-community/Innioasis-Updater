# Innioasis Y2 - Innioasis ファームウェア ダウンロードで元のソフトウェアを復元します

復元 · Innioasis Y2

# Y2 ストック パスを使用して Y2 を復元します。

Y2 リストアは Y1 リストアではありません。最初の画面でモデルの選択とパッケージを一致させてください。[Updater CE を入手](../guide_ja.html#platform)[Updater CE で入手](../guide_ja.html?model=Y2&software=original-y2)[Y2 ソフトウェアを参照する](../firmware_ja.html#y2)

お使いのコンピューターのインストールガイド

## コンピュータを使用して Y2 上の元のソフトウェアを復元します

使用しているコンピュータのガイドを選択してください。 すべてのバージョンには、プラットフォームのセットアップ、Updater CE の手順、および在庫に戻る方法が含まれています。[Windowsガイド](/install/original-y2-windows.html)[macOS ガイド](/install/original-y2-mac.html)[Linuxガイド](/install/original-y2-linux.html)

[すべての Innioasis Y2 ガイド](/install/y2.html) · [すべてのオリジナル ソフトウェア ガイド](/install/original-software.html)

## Rockbox または別のカスタム ソフトウェアから

関連する Windows、macOS、または Linux セットアップの準備が完了したら、Y2 ストック インターフェイスに戻ると、コミュニティ プロジェクトをインストールする場合と同じアップデーター フローが使用されます。 Y1 ファイルをプレーヤーに手動で混ぜたり、最初にシステム フォルダーを削除したりしないでください。
  - コンピューター上で Innioasis Updater CE を開きます (まだインストールしていない場合は、 [Updater CE を入手](../guide_ja.html#platform) のために [窓](../drivers_ja.html#windows), [macOS](../guide_ja.html#macos)、または [Linux](../drivers_ja.html#linux)).
  - セット デバイスモデル 支援先: Y2.
  - 選択してください 純正ソフトウェア.
  - 安定した Y2 リリースを選択します。手動フルインストール パッケージでは次のものが使用される場合があります `rom_y2.zip`.
  - クリック インストール / 復元 そして抽出ステップを待ちます。
以下のものを代用しないでください。 Y1 `rom.zip` は Y2 パッケージではありません。リリース リストが間違っていると思われる場合は、停止して Y2 を再度選択してください。

## 接続プロンプトに従ってください

Windows、macOS、Linux ではコンピューターのセットアップに関する注意事項が異なりますが、プレーヤー側のシーケンスは同じです。要求されたら電源を切り、ライブ プロンプトでデータ ケーブルを接続します。
  - アップデーターから要求されたら、Y2 の電源を完全にオフにします。
  - USB は、アプリが準備ができたと通知した場合にのみ接続してください。
  - 成功メッセージが表示されるまで、ケーブルはそのままにしておきます。
  - 安全に接続を解除し、プレーヤーを起動します。
Updater への接続手順共有接続参照。ライブアプリのプロンプトには権威があります。

## まだ行き詰まっていますか?

手動ツールを試す前に、モデル、パッケージ、ケーブル、接続タイミングを確認してください。の [トラブルシューティングガイド](../troubleshooting_ja.html) USB 前の障害が何を意味するかを、デバイス検出後の障害と比較して説明します。パッケージを別々にしておきます。 Y1 `rom.zip` Y2 復元ではありません。リリース リストが間違っている場合は、停止して Y2 を再度選択してください。
