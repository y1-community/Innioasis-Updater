# Installa Inniclassic su Y1.

Inniclassic è elencato come progetto Y1. Seleziona Y1 prima di sceglierlo in modo che l'elenco delle versioni sia sempre compatibile con il modello.[Ottieni Updater CE](../guide_it.html#platform)[Ottieni questo in Updater CE](../guide_it.html?model=Y1&software=inniclassic-y1)[Perché Inniclassic?](../inniclassic-benefits_it.html)

Guida all'installazione per il tuo computer

## Installa Inniclassic sul tuo Y1 con il tuo computer

Scegli la guida per il computer che stai utilizzando. Ogni versione ha la configurazione della piattaforma, Updater CE passaggi e il modo per tornare allo stock.[Guida Windows](/install/inniclassic-y1-windows.html)[guida macOS](/install/inniclassic-y1-mac.html)[Guida Linux](/install/inniclassic-y1-linux.html)

[Tutte le Innioasis Y1 guide](/install/y1.html) · [Tutte le Inniclassic guide](/install/inniclassic.html)

## Installalo
  - Apri Innioasis Updater CE sul tuo computer (se non lo hai ancora, [Ottieni Updater CE](../guide_it.html#platform)). Seleziona Y1 dentro Modello del dispositivo.
  - Scegli Inniclassic dentro Software (o avvia con [Ottieni questo in Updater CE](../guide_it.html?model=Y1&software=inniclassic-y1)).
  - Selezionare una versione e fare clic Installa / Ripristina.
  - Spegni e collega Y1 solo quando l'Updater lo richiede.
  - Usa Y1 Software originale per il percorso di ripristino.

## Mantieni ferma la connessioneIstruzioni per la connessione dell'aggiornamentoLa richiesta esatta può variare in base alla piattaforma.

Se l'installazione non riesce, annota se l'errore si è verificato prima o dopo che l'Updater ha rilevato il lettore. Questo dettaglio rende la risoluzione dei problemi molto più rapida.
