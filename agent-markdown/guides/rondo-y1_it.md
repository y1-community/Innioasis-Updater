Scegli la guida per il computer che stai utilizzando. Ogni versione ha la configurazione della piattaforma, Updater CE passaggi e il modo per tornare allo stock.[Guida Windows](/install/rondo-y1-windows.html)[guida macOS](/install/rondo-y1-mac.html)[Guida Linux](/install/rondo-y1-linux.html)

## Installazione passo dopo passo
  - Apri Updater CE: Lancio [Innioasis Programma di aggiornamento CE](../guide_it.html) sul tuo computer Windows, macOS o Linux.
  - Scegli il modello del dispositivo Y1: Seleziona Y1 nel menu a discesa Modello dispositivo (scegli Type B se il tuo Y1 è stato fornito con il software originale prima della 2.0.0; altrimenti mantieni Type A).
  - Scegli Rondo dal menu a discesa Software: Seleziona Rondo nell'elenco Software e seleziona la versione più recente. Updater CE utilizza automaticamente la base Wi-Fi di Android 4.2 ROM e il feed di rilascio Rondo.
  - Flashare il lettore: Fare clic Installa / Ripristina, spegni completamente il tuo Y1 e collegalo tramite un cavo dati USB quando Updater CE lo richiede.
  - Disconnetti e avvia: Attendi il messaggio verde di completamento prima di scollegare il tuo Y1.
  - Completa la configurazione post-installazione

Segui i passaggi indicati in [questa guida](../post_install_it.html?software=rondo-y1&model=Y1) per completare la configurazione sul tuo Y1.[Visualizza la guida](../post_install_it.html?software=rondo-y1&model=Y1)
