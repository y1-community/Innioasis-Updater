# Installeer Android 4.2 (ontwikkelaar) op een Y1.

Android 4.2 is een community-ontwikkeling ROM voor het testen en hacken van de Innioasis Y1 hardware. Selecteer Y1 voordat u dit kiest in Updater CE.[Updater CE downloaden](../guide_nl.html#platform)[Ontvang dit in Updater CE](../guide_nl.html?model=Y1&software=android-4-2-y1)[Projectbron](https://github.com/y1-community/y1-ata-rom)

Installatiehandleiding voor uw computer

## Installeer Android-ontwikkeling ROM op uw Y1 met uw computer

Kies de handleiding voor de computer die u gebruikt. Elke versie heeft de platformconfiguratie, Updater CE stappen en de weg terug naar de voorraad.[Windows-gids](/install/android-4-2-y1-windows.html)[macOS-gids](/install/android-4-2-y1-mac.html)[Linux-gids](/install/android-4-2-y1-linux.html)

[Alle Innioasis Y1-gidsen](/install/y1.html) · [Alle ROM-handleidingen voor Android-ontwikkeling](/install/android-dev.html)

## Installeer het
  - Open Innioasis Updater CE op uw computer (als u dit nog niet heeft, [Updater CE downloaden](../guide_nl.html#platform)). Selecteer Y1 binnen Apparaatmodel.
  - Kies Android 4.2 (ontwikkelaar) binnen Software (of start met [Ontvang dit in Updater CE](../guide_nl.html?model=Y1&software=android-4-2-y1)).
  - Selecteer een release en klik Installeren / Herstellen.
  - Schakel de Y1 alleen uit en sluit deze alleen aan als Updater u daarom vraagt.
  - Gebruik Y1 Originele software voor het herstelpad.
