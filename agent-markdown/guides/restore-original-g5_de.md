# Originalsoftware wiederherstellen auf Innioasis G5

Verwenden Sie dieses geführte Tutorial, wenn Sie ein nicht reagierendes G5 wiederherstellen, das System auf den Werkszustand aktualisieren oder saubere offizielle Firmware-Updates installieren müssen.[Updater CE holen](../guide_de.html#platform)[G5 Downloads anzeigen](../firmware_de.html?model=G5)

Installationsanleitung für Ihren Computer

## Stellen Sie die Originalsoftware auf Ihrem G5 mit Ihrem Computer wieder her

Wählen Sie die Anleitung für den Computer aus, den Sie verwenden. Jede Version verfügt über das Plattform-Setup, Updater CE Schritte und den Weg zurück zum Lagerbestand.[Windows-Anleitung](/install/original-g5-windows.html)[macOS-Anleitung](/install/original-g5-mac.html)[Linux-Anleitung](/install/original-g5-linux.html)

[Alle Innioasis G5 Anleitungen](/install/g5.html) · [Alle Original-Softwarehandbücher](/install/original-software.html)

## Schritt 1: Bereiten Sie Ihren Computer vor

Innioasis Updater CE läuft nativ unter Windows, macOS und Linux, ohne dass komplexe Flash-Kabelbäume erforderlich sind:
  - Starten Innioasis Updater CE auf Ihrem Desktop oder Laptop.
  - Satz Gerätemodell an G5.
  - Auswählen Original-Software im Software-Dropdown. Updater CE lädt automatisch den offiziellen herunter `rom_g5.zip` Paket direkt freigeben.
  - Klicken Sie Installieren / Wiederherstellen um mit der Vorbereitung zu beginnen.

## Schritt 2: Verbinden Sie G5 mit der Eingabeaufforderung

Schließen Sie Ihren Player niemals an, bevor die Anwendung Sie dazu auffordert:
  - Stellen Sie sicher, dass Ihr Innioasis G5 vollständig ausgeschaltet ist.
  - Wenn Updater die Verbindungsaufforderung USB anzeigt, schließen Sie Ihr USB-C-Datenkabel an den Computer und den Player an.
  - Berühren Sie während des Flashens nicht das Kabel oder die Ein-/Aus-Taste.
  - Sobald die Erfolgsbestätigung angezeigt wird, ziehen Sie das USB-Kabel ab und schalten Sie Ihr G5 ein.
