# 恢复 Innioasis Y2 - Innioasis 固件下载上的原始软件

恢复·Innioasis Y2

# 使用 Y2 库存路径恢复 Y2。

Y2 恢复不是 Y1 恢复。从第一个屏幕开始就保持型号选择和封装匹配。[获取 Updater CE](../guide_zh-CN.html#platform)[在 Updater CE 中获取](../guide_zh-CN.html?model=Y2&software=original-y2)[浏览Y2软件](../firmware_zh-CN.html#y2)

适用于您的计算机的安装指南

## 使用计算机恢复 Y2 上的原始软件

选择适合您正在使用的计算机的指南。 每个版本都有平台设置、Updater CE步骤和返回库存的方式。[Windows 指南](/install/original-y2-windows.html)[macOS 指南](/install/original-y2-mac.html)[Linux指南](/install/original-y2-linux.html)

[所有 Innioasis Y2 指南](/install/y2.html) · [所有原始软件指南](/install/original-software.html)

## 来自 Rockbox 或其他自定义软件

一旦相关的 Windows、macOS 或 Linux 设置准备就绪，返回到 Y2 库存界面将使用与安装社区项目相同的更新程序流程。请勿手动将 Y1 文件混合到播放器中或先删除系统文件夹。
  - 在您的计算机上打开 Innioasis Updater CE（如果您尚未安装， [获取 Updater CE](../guide_zh-CN.html#platform) 为了 [窗户](../drivers_zh-CN.html#windows), [macOS](../guide_zh-CN.html#macos), 或 [Linux](../drivers_zh-CN.html#linux)).
  - 套装 设备型号 至 Y2.
  - 选择 原厂软件.
  - 选择稳定的 Y2 版本。可以使用手动完整安装包 `rom_y2.zip`.
  - 点击 安装 / 恢复 并等待提取步骤。
不要替代： 一个Y1 `rom.zip` 不是 Y2 包。如果发布列表看起来有误，请停止并重新选择 Y2。

## 按照连接提示操作

Windows、macOS 和 Linux 具有不同的计算机设置说明，但播放器端顺序保持不变：在询问时关闭电源，然后根据实时提示连接数据线。
  - 当更新程序要求时，将 Y2 完全关闭。
  - 仅当应用程序表示已准备就绪时才连接 USB。
  - 保持电缆不变，直到出现成功消息。
  - 安全断开连接并启动播放器。
Updater 连接说明共享连接参考。实时应用提示具有权威性。

## 还卡住了吗？

在尝试手动工具之前，请检查型号、封装、电缆和连接时序。这 [故障排除指南](../troubleshooting_zh-CN.html) 解释了 USB 之前的故障与设备检测之后的故障相比意味着什么。将包分开： 一个Y1 `rom.zip` 不是 Y2 恢复。如果发布列表看起来有误，请停止并再次选择 Y2。
