## In Updater
  - Open Innioasis Updater CE on your computer (if you don't have it yet, [Get Updater CE](../guide.html#platform)). Select Y2 in Device Model.
  - Choose Y2Player in Software (or launch with [Get this in Updater CE](../guide.html?model=Y2&software=y2player-y2)).
  - Choose the listed Y2 release.
  - Click Install / Restore, power off when asked, and connect USB at the prompt.
  - Restore with Y2 Original Software if needed.

## Do not substitute a Y1 packageCheck twice: Y2 full-install packages may use `rom_y2.zip`. A plain Y1 package is not a safe substitute.Updater connection instructions for a powered-off Y2Connect only at the live prompt.
