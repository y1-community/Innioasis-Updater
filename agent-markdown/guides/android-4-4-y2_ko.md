# Innioasis Y2 - Innioasis 펌웨어 다운로드에 Android 4.4(Dev)를 설치하는 방법

안드로이드 4.4(개발자) · Innioasis Y2

# Y2에 Android 4.4(Dev)를 설치합니다.

Android 4.4는 Innioasis Y2 하드웨어에서 테스트하고 해킹하기 위한 커뮤니티 개발 ROM입니다. Updater CE에서 선택하기 전에 Y2를 선택하세요.[Updater CE 받기](../guide_ko.html#platform)[이것을 Updater CE에서 얻으세요](../guide_ko.html?model=Y2&software=android-4-4-y2)[프로젝트 소스](https://github.com/y1-community/y2-ata-rom)

컴퓨터에 대한 설치 가이드

## 컴퓨터를 사용하여 Y2에 Android 개발 ROM을(를) 설치하세요.

사용 중인 컴퓨터에 대한 가이드를 선택하세요. 모든 버전에는 플랫폼 설정, Updater CE 단계 및 재고로 돌아가는 방법이 있습니다.[윈도우 가이드](/install/android-4-4-y2-windows.html)[macOS 가이드](/install/android-4-4-y2-mac.html)[리눅스 가이드](/install/android-4-4-y2-linux.html)

[모든 Innioasis Y2 가이드](/install/y2.html) · [모든 Android 개발 ROM 가이드](/install/android-dev.html)

## 설치하세요
  - 컴퓨터에서 Innioasis Updater CE를 엽니다. (아직 없다면, [Updater CE 받기](../guide_ko.html#platform)). 선택 Y2 안으로 기기 모델.
  - 선택 안드로이드 4.4(개발자) 안으로 소프트웨어 (또는 다음으로 시작 [이것을 Updater CE에서 얻으세요](../guide_ko.html?model=Y2&software=android-4-4-y2)).
  - 릴리스를 선택하고 클릭하세요. 설치 / 복원.
  - Updater에서 메시지가 표시될 때만 전원을 끄고 Y2을 연결하십시오.
  - Y2 사용 원본 소프트웨어 복원 경로에 대해

## 개발자 빌드 노트개발자 빌드: 실험용으로 제작된 개발 이미지입니다. 현재 하드웨어 지원 및 알려진 문제에 대한 릴리스 노트를 읽어보세요.업데이터 연결 지침라이브 프롬프트에서만 연결하십시오.
