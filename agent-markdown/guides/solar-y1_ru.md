Solar · Innioasis Y1

# Установите Solar на свой Y1.

Solar — это отдельный программный проект сообщества. Доступность и функции могут измениться, поэтому позвольте программе обновлений показать текущую версию для вашей модели.[Скачать Updater CE](../guide_ru.html#platform)[Получите это в Updater CE](../guide_ru.html?model=Y1&software=solar-y1)[Почему Solar?](../solar-benefits_ru.html)

Также доступны: [Solar на Y2](solar-y2_ru.html)

Руководство по установке для вашего компьютера

## Установите Solar на свой Y1 с помощью компьютера.

Выберите руководство для компьютера, который вы используете. В каждой версии есть настройка платформы, Updater CE шагов и возврат к стоку.[Руководство по Windows](/install/solar-y1-windows.html)[руководство по macOS](/install/solar-y1-mac.html)[Руководство по Linux](/install/solar-y1-linux.html)

[Все Innioasis Y1 руководства](/install/y1.html) · [Все Solar руководства](/install/solar.html)

## Выберите маршрут Y1
  - Откройте Innioasis Updater CE на своем компьютере (если у вас его еще нет, [Скачать Updater CE](../guide_ru.html#platform)). Выбирать Y1 в Модель устройства.
  - Выбирать Solar в Программное обеспечение (или запустить с помощью [Получите это в Updater CE](../guide_ru.html?model=Y1&software=solar-y1)).
  - Прочтите примечания к выпуску, выберите версию и нажмите Установить / Восстановить.
  - Выключайте и подключайте плеер только по запросу Updater.
  - Восстановить с помощью Y1 Заводское ПО если вам снова понадобится стандартный интерфейс.

## Держите примечание к проекту на виду

Solar находится в активной разработке. Функции и поддержка моделей могут измениться, поэтому ознакомьтесь с примечаниями к выпуску проекта. Программа обновлений показывает, что доступно для вашей модели прямо сейчас.Инструкция по подключению обновленийПодключайтесь только по интерактивной подсказке.

## Вернуться к исходному программному обеспечению

Solar не меняет маршрут обратно на стандартный интерфейс. Как только программа обновлений будет настроена для вашего компьютера, откройте ее в Windows, macOS или Linux и выберите Y1 плюс Заводское ПО вместо Solar.
  - Выберите стабильную Y1 версию оригинального программного обеспечения.
  - Нажмите Установить / Восстановить и дождитесь приглашения на подключение к реальному времени.
  - Выключайте Y1 только по запросу.
  - Подключите USB-кабель для передачи данных по запросу и оставьте его до успешного завершения.

Не удаляйте сначала файлы Solar вручную и не используйте пакет Y2. Если сбой произошел до появления приглашения USB, сначала проверьте настройку компьютера, кабель и выбор модели.[Y1 руководство по восстановлению](restore-original-y1_ru.html)[Устранение неполадок](../troubleshooting_ru.html)
