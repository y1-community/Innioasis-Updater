# Установите Linux на Y1.

Linux для Y1 — это экспериментальное ядро ​​Linux сообщества и порт rootfs для Innioasis Y1. Выберите Y1 перед тем, как выбрать его в Updater CE.[Скачать Updater CE](../guide_ru.html#platform)[Получите это в Updater CE](../guide_ru.html?model=Y1&software=linux-y1)[Источник проекта](https://github.com/y1-community/y1-linux-rom)

## Установите Linux для Y1 (Dev) на свой Y1 с помощью компьютера.

Выберите руководство для компьютера, который вы используете. В каждой версии есть настройка платформы, Updater CE шагов и возврат к стоку.[Руководство по Windows](/install/linux-y1-windows.html)[руководство по macOS](/install/linux-y1-mac.html)[Руководство по Linux](/install/linux-y1-linux.html)

[Все Innioasis Y1 руководства](/install/y1.html) · [Все руководства по Linux для Y1 (Dev)](/install/linux-dev.html)

## Установите его
  - Откройте Innioasis Updater CE на своем компьютере (если у вас его еще нет, [Скачать Updater CE](../guide_ru.html#platform)). Выбирать Y1 в Модель устройства.
  - Выбирать Linux для Y1 (Дев) в Программное обеспечение (или запустить с помощью [Получите это в Updater CE](../guide_ru.html?model=Y1&software=linux-y1)).
  - Выберите выпуск и нажмите Установить / Восстановить.
  - Выключите и подключите Y1 только тогда, когда программа обновлений предложит вам это сделать.
  - Используйте Y1 Заводское ПО для пути восстановления.
