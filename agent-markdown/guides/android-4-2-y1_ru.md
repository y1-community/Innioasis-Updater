# Установите Android 4.2 (Dev) на Y1.

Android 4.2 — это разработка сообщества ROM для тестирования и взлома оборудования Innioasis Y1. Выберите Y1 перед тем, как выбрать его в Updater CE.[Скачать Updater CE](../guide_ru.html#platform)[Получите это в Updater CE](../guide_ru.html?model=Y1&software=android-4-2-y1)[Источник проекта](https://github.com/y1-community/y1-ata-rom)

Руководство по установке для вашего компьютера

## Установите разработку Android ROM на свой Y1 с помощью компьютера.

Выберите руководство для компьютера, который вы используете. В каждой версии есть настройка платформы, Updater CE шагов и возврат к стоку.[Руководство по Windows](/install/android-4-2-y1-windows.html)[руководство по macOS](/install/android-4-2-y1-mac.html)[Руководство по Linux](/install/android-4-2-y1-linux.html)

[Все Innioasis Y1 руководства](/install/y1.html) · [Все руководства по разработке для Android ROM](/install/android-dev.html)

## Установите его
  - Откройте Innioasis Updater CE на своем компьютере (если у вас его еще нет, [Скачать Updater CE](../guide_ru.html#platform)). Выбирать Y1 в Модель устройства.
  - Выбирать Android 4.2 (для разработчиков) в Программное обеспечение (или запустить с помощью [Получите это в Updater CE](../guide_ru.html?model=Y1&software=android-4-2-y1)).
  - Выберите выпуск и нажмите Установить / Восстановить.
  - Выключите и подключите Y1 только тогда, когда программа обновлений предложит вам это сделать.
  - Используйте Y1 Заводское ПО для пути восстановления.
