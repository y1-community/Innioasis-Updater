# 恢复 Innioasis 和 Timmkoo A5 上的原始软件

按照本教程使用 Innioasis 固件存档中经过验证的软件包在 Innioasis A5 或 Timmkoo A5 播放器上恢复官方出厂软件。[获取 Updater CE](../guide_zh-CN.html#platform)[查看 A5 下载](../firmware_zh-CN.html?model=A5)

## 第 1 步：在 Updater CE 中设置
  - 发射 Innioasis 更新程序 CE 在您的 Windows、macOS 或 Linux 计算机上。
  - 套装 设备型号 至 A5.
  - 选择 原厂软件。 Updater CE下载官方 `rom_a5.zip` 直接发布包。
  - 点击 安装 / 恢复 并等待准备完成。

## 第 2 步：根据提示进行连接
  - 完全关闭 A5 设备的电源。
  - 等待计算机屏幕上的提示，然后连接 USB 数据线。
  - 让闪烁过程不间断地完成。
  - 断开连接并重新启动刚刚恢复的 A5 播放器。
