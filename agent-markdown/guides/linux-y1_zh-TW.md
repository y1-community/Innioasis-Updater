Linux（開發）·Innioasis Y1

# 在 Y1 上安裝 Linux。

Linux for Y1 是一個實驗性社群 Linux 核心和 Innioasis Y1 的 rootfs 埠。在 Updater CE 中選擇之前選擇 Y1。[取得 Updater CE](../guide_zh-TW.html#platform)[在 Updater CE 中取得此內容](../guide_zh-TW.html?model=Y1&software=linux-y1)[專案來源](https://github.com/y1-community/y1-linux-rom)

適用於您的電腦的安裝指南

## 使用電腦在 Y1 上安裝 Y1 (Dev) Linux

選擇適合您正在使用的計算機的指南。 每個版本都有平台設定、Updater CE步驟和返回庫存的方式。[Windows 指南](/install/linux-y1-windows.html)[macOS 指南](/install/linux-y1-mac.html)[Linux指南](/install/linux-y1-linux.html)

[所有 Innioasis Y1 指南](/install/y1.html) · [所有 Linux for Y1（開發）指南](/install/linux-dev.html)

## 安裝它
  - 在您的電腦上開啟 Innioasis Updater CE（如果您還沒有， [取得 Updater CE](../guide_zh-TW.html#platform)）。選擇 Y1 在 裝置型號.
  - 選擇 Linux Y1（開發） 在 軟體 （或啟動 [在 Updater CE 中取得此內容](../guide_zh-TW.html?model=Y1&software=linux-y1)).
  - 選擇一個版本並點擊 安裝 / 還原.
  - 僅當更新程式提示時關閉並連接 Y1。
  - 使用Y1 原廠軟體 為恢復路徑。

## 實驗港實驗建構： 這是一個開發人員和愛好者的準系統 Linux 移植。 UART 和控制台詳細資訊位於專案文件中。更新器連線說明僅在即時提示時連接。
