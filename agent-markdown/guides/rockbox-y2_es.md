# Cómo instalar Rockbox en tu Innioasis Y2 - Innioasis Descargas de firmware

Rockbox · Innioasis Y2

# Instale la compilación Y2, no la compilación Y1.

El recorrido del usuario es familiar, pero el modelo y el paquete son diferentes. Seleccione Y2 primero para que el Actualizador prepare los archivos correctos y la ruta de instalación.[Obtener Updater CE](../guide_es.html#platform)[Obtener en Updater CE](../guide_es.html?model=Y2&software=rockbox-y2)[¿Por qué Rockbox?](../rockbox-benefits_es.html)

Elija la guía para la computadora que está utilizando. ## Mira la ruta Rockbox

Vídeo de Frawgeeys. Funciona para los modelos Y1 y Y2; en Innioasis Updater CE, seleccione Y2 como tu modelo. Los pasos escritos a continuación cubren la secuencia de instalación de Y2.

Vídeo de [cristian plaza](https://www.youtube.com/@CristianPlaza) (Español). Demuestra la instalación en un Y1; elegir Y2 en Updater CE para esta guía.

## Antes de hacer clic en instalar

Tener un Innioasis Y2 cargado, un cable de datos USB y una computadora con Innioasis Updater CE instalado (si aún no lo has instalado, [Obtener Updater CE](../guide_es.html#platform) para Windows, macOS o Linux). No utilice una versión Y1 solo porque su nombre parece similar.Verificación de modelo: Y2 los paquetes de instalación completa pueden usar `rom_y2.zip`. El nombre del archivo es una pista útil para la descarga manual, pero Updater debería encargarse de la selección del paquete por usted.

## Elija Y2 en el Actualizador
  - Abra Updater CE (o ejecútelo con [Obtener en Updater CE](../guide_es.html?model=Y2&software=rockbox-y2)) y establecer Modelo del dispositivo a Y2.
  - elegir Rockbox en Software.
  - Elija una versión listada para Y2. Si no aparece ninguna versión Y2, no la sustituya por una versión Y1.
  - Haga clic Instalar / Restaurar y permita que Updater CE descargue el paquete directamente desde la versión del desarrollador de la comunidad.

## Apague y luego conecte
  - Espere el mensaje de conexión en vivo.
  - Apague el Y2 por completo. Utilice las instrucciones exactas de restablecimiento o recuperación que muestra el Actualizador si falla el apagado normal.
  - Conecte el cable USB cuando se le solicite. Déjelo quieto hasta que aparezca el mensaje de finalización.
  - Desconéctese de forma segura e inicie el Y2.
Instrucciones de conexión del actualizador para un dispositivo apagadoLa pantalla de conexión es una referencia. Su mensaje Y2 puede incluir una redacción de modelo diferente.

## Volver al software original

Rockbox no lo bloquea en el software personalizado. Una vez que Updater esté configurado para su computadora, utilícelo en Windows, macOS o Linux para regresar desde Rockbox u otro proyecto listado: seleccione Y2, elegir Software originaly corre Instalar / Restaurar.
  - Espere a que Updater prepare el paquete de acciones Y2.
  - Apague el Y2 cuando la aplicación lo solicite.
  - Conecte el cable de datos USB solo cuando se le indique en vivo.
  - Deje al jugador quieto hasta que aparezca el mensaje de éxito.

Mantenga los paquetes Y1 y Y2 separados. No elimine manualmente los archivos Rockbox primero; la restauración reemplaza el software del sistema.[guía de restauración Y2](restore-original-y2_es.html)[Solución de problemas](../troubleshooting_es.html)
