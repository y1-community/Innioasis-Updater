# Innioasis Y2 - Innioasis 펌웨어 다운로드에 Rockbox을(를) 설치하는 방법

Rockbox · Innioasis Y2

# Y1 빌드가 아닌 Y2 빌드를 설치하세요.

사용자 여정은 익숙하지만 모델과 패키지가 다릅니다. 먼저 Y2을 선택하면 Updater가 올바른 파일과 설치 경로를 준비합니다.[Updater CE 받기](../guide_ko.html#platform)[이것을 Updater CE에서 얻으세요](../guide_ko.html?model=Y2&software=rockbox-y2)[왜 Rockbox인가요?](../rockbox-benefits_ko.html)

컴퓨터에 대한 설치 가이드

## 컴퓨터를 사용하여 Y2에 Rockbox을(를) 설치합니다.

사용 중인 컴퓨터에 대한 가이드를 선택하세요. 모든 버전에는 플랫폼 설정, Updater CE 단계 및 재고로 돌아가는 방법이 있습니다.[윈도우 가이드](/install/rockbox-y2-windows.html)[macOS 가이드](/install/rockbox-y2-mac.html)[리눅스 가이드](/install/rockbox-y2-linux.html)

[모든 Innioasis Y2 가이드](/install/y2.html) · [모든 Rockbox 가이드](/install/rockbox.html)

## Rockbox 경로를 지켜보세요

Frawgees의 비디오. Y1 및 Y2 모델 모두에서 작동합니다. Innioasis Updater CE에서 Y2 당신의 모델로. 아래에 작성된 단계는 Y2 설치 순서를 다룹니다.

비디오 작성자: [크리스티안 플라자](https://www.youtube.com/@CristianPlaza) (스페인 사람). Y1에 설치하는 방법을 보여줍니다. 선택하다 Y2 이 가이드의 Updater CE에 있습니다.

## 설치를 클릭하기 전에

충전된 Innioasis Y2, USB 데이터 케이블, Innioasis Updater CE가 설치된 컴퓨터가 있어야 합니다(아직 설치하지 않은 경우, [Updater CE 받기](../guide_ko.html#platform) Windows, macOS, Linux의 경우). 단지 이름이 비슷하다고 해서 Y1 릴리스를 사용하지 마십시오.모델 확인: Y2 전체 설치 패키지는 다음을 사용할 수 있습니다. `rom_y2.zip`. 파일 이름은 유용한 수동 다운로드 단서이지만 Updater가 패키지 선택을 자동으로 처리해야 합니다.

## 업데이터에서 Y2을 선택하세요.
  - Updater CE 열기(또는 다음으로 시작) [이것을 Updater CE에서 얻으세요](../guide_ko.html?model=Y2&software=rockbox-y2)) 및 설정 기기 모델 에 Y2.
  - 선택 Rockbox 안으로 소프트웨어.
  - Y2에 나열된 릴리스를 선택하십시오. Y2 릴리스가 나열되지 않은 경우 Y1 릴리스로 대체하지 마십시오.
  - 클릭 설치 / 복원 Updater CE가 커뮤니티 개발자 릴리스에서 직접 패키지를 다운로드하도록 합니다.

## 전원을 끈 후 연결하세요
  - 실시간 연결 프롬프트를 기다립니다.
  - Y2의 전원을 완전히 끕니다. 정상적인 종료가 실패할 경우 업데이터가 표시하는 정확한 재설정 또는 복구 지침을 사용하십시오.
  - 요청 시 USB 케이블을 연결하세요. 완료 메시지가 나올 때까지 그대로 두세요.
  - 안전하게 연결을 끊고 Y2을 시작하십시오.
전원이 꺼진 장치에 대한 업데이터 연결 지침연결화면은 참고사항입니다. Y2 프롬프트에는 다른 모델 문구가 포함될 수 있습니다.

## 원래 소프트웨어로 돌아가기

Rockbox은 사용자 정의 소프트웨어에 사용자를 고정시키지 않습니다. Updater가 컴퓨터에 설정되면 Windows, macOS 또는 Linux에서 이를 사용하여 Rockbox 또는 나열된 다른 프로젝트에서 돌아갈 수 있습니다. Y2, 선택하다 원본 소프트웨어, 그리고 실행 설치 / 복원.
  - 업데이터가 Y2 스톡 패키지를 준비할 때까지 기다립니다.
  - 앱에서 요청하면 Y2의 전원을 끕니다.
  - USB 데이터 케이블은 라이브 프롬프트에서만 연결하십시오.
  - 성공 메시지가 나타날 때까지 플레이어를 가만히 두십시오.

Y1 및 Y2 패키지를 별도로 유지하십시오. 먼저 Rockbox 파일을 수동으로 삭제하지 마십시오. 복원은 시스템 소프트웨어를 대체합니다.[Y2 복원 가이드](restore-original-y2_ko.html)[문제 해결](../troubleshooting_ko.html)
