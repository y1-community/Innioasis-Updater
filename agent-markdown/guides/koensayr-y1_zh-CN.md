# 在 Y1 上安装 Koensayr。

Koensayr 被列为 Y1 项目。让更新程序管理软件包，然后按照与其他完整安装相同的谨慎关闭电源和 USB 计时。[获取 Updater CE](../guide_zh-CN.html#platform)[在 Updater CE 中获取](../guide_zh-CN.html?model=Y1&software=koensayr-y1)[为什么是Koensayr？](../koensayr-benefits_zh-CN.html)

适用于您的计算机的安装指南

## 使用计算机在 Y1 上安装 Koensayr

选择适合您正在使用的计算机的指南。 每个版本都有平台设置、Updater CE步骤和返回库存的方式。[Windows 指南](/install/koensayr-y1-windows.html)[macOS 指南](/install/koensayr-y1-mac.html)[Linux指南](/install/koensayr-y1-linux.html)

[所有 Innioasis Y1 指南](/install/y1.html) · [所有 Koensayr 指南](/install/koensayr.html)

## 安装步骤
  - 在您的计算机上打开 Innioasis Updater CE（如果您还没有， [获取 Updater CE](../guide_zh-CN.html#platform)）。选择 Y1 在 设备型号.
  - 选择 Koensayr 在 软件 （或启动 [在 Updater CE 中获取](../guide_zh-CN.html?model=Y1&software=koensayr-y1)).
  - 选择列出的版本并单击 安装 / 恢复.
  - 仅当应用程序要求时关闭电源并连接 Y1。
  - 使用Y1 原厂软件 恢复库存路径。

## 当某事失败时

首先检查型号和类型选择。然后在出现提示之前检查线缆以及播放器是否已连接。如果应用程序在等待 USB 之前停止，请打开 [故障排除](../troubleshooting_zh-CN.html).Updater 连接说明稳定的连接是安装的一部分。
