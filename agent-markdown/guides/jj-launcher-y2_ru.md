# Как установить JJ Launcher на загрузку прошивки Innioasis Y2 - Innioasis

JJ Launcher · Innioasis Y2

# Установите JJ Launcher на свой Y2.

Существует сборка JJ Launcher для Y2. Сначала выберите свою модель, чтобы Программа обновлений не предлагала пакет Y1.[Скачать Updater CE](../guide_ru.html#platform)[Получите это в Updater CE](../guide_ru.html?model=Y2&software=jj-launcher-y2)[Почему JJ Launcher?](../jj-launcher-benefits_ru.html)

Также доступны: [JJ Launcher на Y1](jj-launcher-y1_ru.html)

Руководство по установке для вашего компьютера

## Установите JJ Launcher на свой Y2 с помощью компьютера.

Выберите руководство для компьютера, который вы используете. В каждой версии есть настройка платформы, Updater CE шагов и возврат к стоку.[Руководство по Windows](/install/jj-launcher-y2-windows.html)[руководство по macOS](/install/jj-launcher-y2-mac.html)[Руководство по Linux](/install/jj-launcher-y2-linux.html)

[Все Innioasis Y2 руководства](/install/y2.html) · [Все JJ Launcher руководства](/install/jj-launcher.html)

## Выберите маршрут Y2
  - Откройте Innioasis Updater CE на своем компьютере (если у вас его еще нет, [Скачать Updater CE](../guide_ru.html#platform)). Выбирать Y2 в Модель устройства.
  - Выбирать JJ Launcher в Программное обеспечение (или запустить с помощью [Получите это в Updater CE](../guide_ru.html?model=Y2&software=jj-launcher-y2)).
  - Прочтите примечание к выпуску, подтвердите запись Y2 и нажмите Установить / Восстановить.
  - Выключайте и подключайте плеер только по запросу Updater.
  - Восстановить с помощью Y2 Заводское ПО если вам снова понадобится стандартный интерфейс.

## Посмотреть видео

Видео от doitall. Он снят на Innioasis Y1, но шаги JJ Launcher и устранение неполадок переносятся на маршрут Y2 ниже.

## Несоответствие модели — первое, что нужно проверить

JJ Launcher также имеет запись Y1. Если имя пакета выглядит неправильно, вернитесь к модели устройства. Не навязывайте пакет Y1 пакету Y2.Инструкция по подключению обновленийПодключайтесь только по интерактивной подсказке.

## Вернуться к исходному программному обеспечению

JJ Launcher не меняет маршрут обратно на стандартный интерфейс. Как только программа обновлений будет настроена для вашего компьютера, откройте ее в Windows, macOS или Linux и выберите Y2 плюс Заводское ПО вместо JJ Launcher.
  - Выберите стабильную Y2 версию оригинального программного обеспечения.
  - Нажмите Установить / Восстановить и дождитесь приглашения на подключение к реальному времени.
  - Выключайте Y2 только по запросу.
  - Подключите USB-кабель для передачи данных по запросу и оставьте его до успешного завершения.

Не удаляйте сначала файлы JJ Launcher вручную и не используйте пакет Y1. Если сбой произошел до появления приглашения USB, сначала проверьте настройку компьютера, кабель и выбор модели.[Y2 руководство по восстановлению](restore-original-y2_ru.html)[Устранение неполадок](../troubleshooting_ru.html)
