# Innioasis Y1 - Innioasis 펌웨어 다운로드에 Linux를 설치하는 방법

리눅스(개발자) · Innioasis Y1

# Y1에 Linux를 설치합니다.

Y1용 Linux는 Innioasis Y1용 실험적인 커뮤니티 Linux 커널 및 rootfs 포트입니다. Updater CE에서 선택하기 전에 Y1를 선택하세요.[Updater CE 받기](../guide_ko.html#platform)[이것을 Updater CE에서 얻으세요](../guide_ko.html?model=Y1&software=linux-y1)[프로젝트 소스](https://github.com/y1-community/y1-linux-rom)

컴퓨터에 대한 설치 가이드

## 컴퓨터를 사용하여 Y1에 Y1(Dev)용 Linux를 설치합니다.

사용 중인 컴퓨터에 대한 가이드를 선택하세요. 모든 버전에는 플랫폼 설정, Updater CE 단계 및 재고로 돌아가는 방법이 있습니다.[윈도우 가이드](/install/linux-y1-windows.html)[macOS 가이드](/install/linux-y1-mac.html)[리눅스 가이드](/install/linux-y1-linux.html)

[모든 Innioasis Y1 가이드](/install/y1.html) · [Y1(Dev)용 모든 Linux 가이드](/install/linux-dev.html)

## 설치하세요
  - 컴퓨터에서 Innioasis Updater CE를 엽니다. (아직 없다면, [Updater CE 받기](../guide_ko.html#platform)). 선택 Y1 안으로 기기 모델.
  - 선택 Y1용 Linux(개발자) 안으로 소프트웨어 (또는 다음으로 시작 [이것을 Updater CE에서 얻으세요](../guide_ko.html?model=Y1&software=linux-y1)).
  - 릴리스를 선택하고 클릭하세요. 설치 / 복원.
  - 전원을 끄고 업데이터가 메시지를 표시할 때만 Y1을 연결하세요.
  - Y1 사용 원본 소프트웨어 복원 경로에 대해

## 실험항실험적 빌드: 이는 개발자와 매니아를 위한 베어본 Linux 포트입니다. UART 및 콘솔 세부 정보는 프로젝트 문서에 있습니다.업데이터 연결 지침라이브 프롬프트에서만 연결하십시오.
