# Instale Linux en un Y1.

Linux para Y1 es un kernel de Linux comunitario experimental y un puerto rootfs para Innioasis Y1. Seleccione Y1 antes de elegirlo en Updater CE.[Obtener Updater CE](../guide_es.html#platform)[Obtener en Updater CE](../guide_es.html?model=Y1&software=linux-y1)[Fuente del proyecto](https://github.com/y1-community/y1-linux-rom)

Guía de instalación para su computadora

## Instale Linux para Y1 (Dev) en su Y1 con su computadora

Elija la guía para la computadora que está utilizando. Cada versión tiene la configuración de la plataforma, Updater CE pasos y el camino de regreso al stock.[guía de windows](/install/linux-y1-windows.html)[guía de macos](/install/linux-y1-mac.html)[guía de linux](/install/linux-y1-linux.html)

[Todas las Innioasis Y1 guías](/install/y1.html) · [Todas las guías de Linux para Y1 (Dev)](/install/linux-dev.html)

## instalarlo
  - Abra Innioasis Updater CE en su computadora (si aún no lo tiene, [Obtener Updater CE](../guide_es.html#platform)). Seleccionar Y1 en Modelo del dispositivo.
  - elegir Linux para Y1 (desarrollador) en Software (o iniciar con [Obtener en Updater CE](../guide_es.html?model=Y1&software=linux-y1)).
  - Seleccione una versión y haga clic Instalar / Restaurar.
  - Apague y conecte el Y1 solo cuando el Actualizador se lo indique.
  - Usar Y1 Software original para la ruta de restauración.
