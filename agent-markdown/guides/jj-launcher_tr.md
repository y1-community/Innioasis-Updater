# Innioasis Y1 veya Y2 cihazınıza JJ Launcher nasıl yüklenir - Innioasis Firmware İndirmeleri

JJ Launcher · Y1 ve Y2

# Modeli seçtikten sonra JJ Launcher yükleyin.

Proje adı paylaşılır, ancak mevcut paket yine de oynatıcınızın Y1 veya Y2 olmasına bağlıdır. Aşağıdan modelinizi seçin, kılavuz paketle eşleşecektir.[Updater CE edin](../guide_tr.html#platform)[JJ Launcher üzerinde Y1](jj-launcher-y1_tr.html)[JJ Launcher üzerinde Y2](jj-launcher-y2_tr.html)

## Hangi kılavuzu kullanmalıyım?

Hem Y1 hem de Y2 oynatıcılar JJ Launcher'yi Innioasis Updater CE aracılığıyla yükler (uygulamaya ihtiyacınız varsa, [Updater CE edin](../guide_tr.html#platform) PC'niz için veya ile başlatın [Bunu Güncelleyici CE'den edinin](../guide_tr.html?model=Y1&software=jj-launcher-y1)). Aşağıdan modelinizi seçin:

### Innioasis Y1

Modele özel Y1 rotasını takip edin ve Y1 paketini seçili tutun.[Y1 yükleme adımları](jj-launcher-y1_tr.html)

### Innioasis Y2

Modele özel Y2 rotasını takip edin ve Y2 paketini seçili tutun.[Y2 yükleme adımları](jj-launcher-y2_tr.html)
