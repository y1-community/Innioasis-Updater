## Depuis Rockbox ou un autre logiciel personnalisé

Une fois que la configuration Windows, macOS ou Linux appropriée est prête, Updater utilise la même installation guidée pour une restauration de stock que pour une installation logicielle personnalisée. Vous n'avez pas besoin de supprimer manuellement Rockbox ou les fichiers d'un autre logiciel personnalisé au préalable.
  - Ouvrez Innioasis Updater CE sur votre ordinateur (si vous ne l'avez pas encore installé, [Obtenir Updater CE](../guide_fr.html#platform) pour [Fenêtres](../drivers_fr.html#windows), [macOS](../guide_fr.html#macos), ou [Linux](../drivers_fr.html#linux)).
  - Ensemble Modèle d'appareil à Y1.
  - Choisissez Logiciel d'origine dans Logiciel (ou utilisez [Disponible dans Updater CE](../guide_fr.html?model=Y1&software=original-y1)).
  - Choisissez la dernière version stable Y1. Le package manuel habituel est `rom.zip`. Type A couvre les lecteurs Y1 livrés avec le logiciel d'origine version 2.0.0 ou ultérieure ; Type B couvre les joueurs livrés avec une version antérieure du [Logiciel d'origine](../firmware_fr.html?software=original-y1) et peut utiliser un nom de package plus spécifique.
  - Cliquez Installer / Restaurer et attendez que le package soit extrait.

## Connectez le Y1 à l'invite

Le système d'exploitation modifie la configuration autour du programme de mise à jour, et non le parcours de restauration lui-même. Sur chaque plateforme, attendez l'invite en direct avant de vous connecter.
  - Éteignez complètement le lecteur lorsque le programme de mise à jour le demande.
  - Connectez le câble de données USB uniquement à l'invite.
  - Ne touchez pas le lecteur pendant l'installation.
  - Déconnectez-vous après le message de réussite et démarrez le Y1.

## S'il ne démarre toujours pas

Répétez la restauration une fois avec le modèle, le type et la version vérifiés. Si le programme de mise à jour échoue avant l'invite USB, inspectez la configuration de l'ordinateur, le pilote ou les autorisations, le câble de données et les fichiers extraits. S'il échoue après avoir détecté le Y1, utilisez le [guide de dépannage](../troubleshooting_fr.html) avant de passer à la récupération manuelle SP Flash Tool ou MTKClient.Ne passez pas aux fichiers Y2. Une restauration Y1 nécessite une version Y1 du logiciel d'origine, même si le lecteur exécute actuellement un autre logiciel personnalisé.
