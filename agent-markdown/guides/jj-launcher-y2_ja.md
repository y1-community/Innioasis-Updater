# Innioasis Y2 - Innioasis ファームウェアのダウンロードに JJ Launcher をインストールする方法

JJ Launcher · Innioasis Y2

# Y2 に JJ Launcher をインストールします。

Y2 の JJ Launcher ビルドがあります。アップデーターが Y1 パッケージを提供しないように、最初にモデルを選択してください。[Updater CE を入手](../guide_ja.html#platform)[Updater CE で入手](../guide_ja.html?model=Y2&software=jj-launcher-y2)[なぜJJ Launcher?](../jj-launcher-benefits_ja.html)

以下もご利用いただけます: [Y1 の JJ Launcher](jj-launcher-y1_ja.html)

お使いのコンピューターのインストールガイド

## コンピュータを使用して Y2 に JJ Launcher をインストールします

使用しているコンピュータのガイドを選択してください。 すべてのバージョンには、プラットフォームのセットアップ、Updater CE の手順、および在庫に戻る方法が含まれています。[Windowsガイド](/install/jj-launcher-y2-windows.html)[macOS ガイド](/install/jj-launcher-y2-mac.html)[Linuxガイド](/install/jj-launcher-y2-linux.html)

[すべての Innioasis Y2 ガイド](/install/y2.html) · [すべての JJ Launcher ガイド](/install/jj-launcher.html)

## Y2 ルートを選択してください
  - コンピュータで Innioasis Updater CE を開きます (まだお持ちでない場合は、 [Updater CE を入手](../guide_ja.html#platform)）。選択 Y2 で デバイスモデル.
  - 選択してください JJ Launcher で ソフトウェア (または次のように起動します) [Updater CE で入手](../guide_ja.html?model=Y2&software=jj-launcher-y2)).
  - リリース ノートを読み、Y2 のエントリを確認し、クリックします。 インストール / 復元.
  - アップデーターが要求した場合にのみ、プレーヤーの電源を切り、接続してください。
  - Y2で復元 純正ソフトウェア ストックインターフェイスが再度必要な場合。

## ビデオを見る

doitall によるビデオ。 Innioasis Y1 で撮影されていますが、JJ Launcher の手順とトラブルシューティングは以下の Y2 ルートに引き継がれます。

## 最初に確認するのはモデルの不一致です

JJ Launcher には Y1 エントリもあります。パッケージ名が間違っていると思われる場合は、「デバイス モデル」に戻ります。 Y1 パッケージを Y2 に無理に押し付けないでください。Updater への接続手順案内が表示されてから接続してください。

## 元のソフトウェアに戻る

JJ Launcher は、ストック インターフェイスに戻るルートを変更しません。コンピューターにアップデーターをセットアップしたら、Windows、macOS、または Linux 上でアップデーターを開いて、 Y2 プラス 純正ソフトウェア JJ Launcher の代わりに。
  - 安定した Y2 オリジナル ソフトウェア リリースを選択してください。
  - クリック インストール / 復元 そして、ライブ接続プロンプトが表示されるまで待ちます。
  - Y2 の電源をオフにするのは、要求された場合のみにしてください。
  - プロンプトで USB データ ケーブルを接続し、成功するまでそのままにしておきます。

最初に JJ Launcher ファイルを手動で削除したり、Y1 パッケージを使用したりしないでください。 USB プロンプトが表示される前に障害が発生した場合は、まずコンピューターのセットアップ、ケーブル、モデルの選択を確認してください。[Y2 復元ガイド](restore-original-y2_ja.html)[トラブルシューティング](../troubleshooting_ja.html)
