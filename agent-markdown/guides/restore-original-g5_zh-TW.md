# 恢復 Innioasis G5 上的原始軟體

當您需要恢復無回應的 G5、將系統刷新至出廠狀態或安裝乾淨的官方韌體更新時，請使用本指導教學。[取得 Updater CE](../guide_zh-TW.html#platform)[查看 G5 下載](../firmware_zh-TW.html?model=G5)

適用於您的電腦的安裝指南

## 使用電腦復原 G5 上的原始軟體

選擇適合您正在使用的計算機的指南。 每個版本都有平台設定、Updater CE步驟和返回庫存的方式。[Windows 指南](/install/original-g5-windows.html)[macOS 指南](/install/original-g5-mac.html)[Linux指南](/install/original-g5-linux.html)

[所有 Innioasis G5 指南](/install/g5.html) · [所有原始軟體指南](/install/original-software.html)

## 第 1 步：準備您的計算機

Innioasis 更新程式 CE 在 Windows、macOS 和 Linux 上本機運行，無需複雜的刷新工具：
  - 發射 Innioasis 更新程式 CE 在您的桌上型電腦或筆記型電腦上。
  - 套裝 裝置型號 到 G5.
  - 選擇 原廠軟體 在軟體下拉選單中。 Updater CE自動下載官方 `rom_g5.zip` 直接發布包。
  - 點選 安裝 / 還原 開始準備。

## 第 2 步：根據提示連接 G5

在應用程式提示您之前，切勿連接您的播放器：
  - 確保您的 Innioasis G5 已完全斷電。
  - 當更新程式顯示 USB 連線提示時，將 USB-C 線插入電腦和播放器。
  - 閃爍期間請勿觸摸電纜或電源按鈕。
  - 出現成功確認訊息後，請拔下 USB 電纜並開啟 G5 電源。
