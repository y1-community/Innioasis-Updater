# Innioasis Y2 - Innioasis ファームウェアのダウンロードに Rockbox をインストールする方法

Rockbox · Innioasis Y2

# Y1 ビルドではなく、Y2 ビルドをインストールします。

ユーザージャーニーはおなじみですが、モデルとパッケージが異なります。最初に Y2 を選択すると、アップデーターが正しいファイルとインストール パスを準備します。[Updater CE を入手](../guide_ja.html#platform)[Updater CE で入手](../guide_ja.html?model=Y2&software=rockbox-y2)[なぜRockbox?](../rockbox-benefits_ja.html)

## コンピュータを使用して Y2 に Rockbox をインストールします

使用しているコンピュータのガイドを選択してください。 すべてのバージョンには、プラットフォームのセットアップ、Updater CE の手順、および在庫に戻る方法が含まれています。[Windowsガイド](/install/rockbox-y2-windows.html)[macOS ガイド](/install/rockbox-y2-mac.html)[Linuxガイド](/install/rockbox-y2-linux.html)

## Rockbox ルートを見る

Frawgeeys によるビデオ。 Y1 と Y2 の両方のモデルで機能します。Innioasis Updater CE で、 Y2 あなたのモデルとして。以下に記載されている手順は、Y2 のインストール シーケンスをカバーしています。

ビデオ: [クリスティアンプラザ](https://www.youtube.com/@CristianPlaza) (スペイン語)。 Y1 へのインストールを示します。選ぶ Y2 このガイドの Updater CE にあります。

## 「インストール」をクリックする前に

充電済みの Innioasis Y2、データ ケーブル USB、および Innioasis Updater CE がインストールされたコンピューターを用意します (まだインストールしていない場合は、 [Updater CE を入手](../guide_ja.html#platform) Windows、macOS、または Linux の場合）。名前が似ているという理由だけで Y1 リリースを使用しないでください。モデルチェック: Y2 のフルインストール パッケージでは次のものが使用される場合があります `rom_y2.zip`。ファイル名は手動ダウンロードの手がかりとして役立ちますが、パッケージの選択はアップデーターが処理する必要があります。

## アップデーターで Y2 を選択します
  - Updater CE を開きます (または次のコマンドで起動します) [Updater CE で入手](../guide_ja.html?model=Y2&software=rockbox-y2)) を設定してください デバイスモデル 支援先: Y2.
  - 選択してください Rockbox で ソフトウェア.
  - Y2 にリストされているリリースを選択します。 Y2 リリースがリストされていない場合は、Y1 リリースを置き換えないでください。
  - クリック インストール / 復元 Updater CE がコミュニティ開発者のリリースからパッケージを直接ダウンロードできるようにします。

## 電源を切ってから接続してください
  - ライブ接続プロンプトが表示されるまで待ちます。
  - Y2 の電源を完全にオフにします。通常のシャットダウンが失敗した場合は、アップデータによって表示される正確なリセットまたは回復手順を使用してください。
  - 要求されたら、USB ケーブルを接続します。完了メッセージが表示されるまでそのままにしておきます。
  - 安全に接続を解除し、Y2 を開始してください。
電源がオフのデバイスのアップデータ接続手順接続画面は参考です。 Y2 プロンプトには、異なるモデルの文言が含まれる場合があります。

## 元のソフトウェアに戻る

Rockbox はカスタム ソフトウェアに閉じ込められることはありません。コンピューター用にアップデーターをセットアップしたら、Windows、macOS、または Linux でそれを使用して、Rockbox またはリストされている別のプロジェクトに戻ります。 Y2、 選ぶ 純正ソフトウェア、実行します インストール / 復元.
  - アップデーターが Y2 ストック パッケージを準備するまで待ちます。
  - アプリが尋ねたら、Y2 の電源を切ります。
  - USB データ ケーブルはライブ プロンプトでのみ接続してください。
  - 成功メッセージが表示されるまでプレーヤーを動かさないでください。

Y1 パッケージと Y2 パッケージは別々に保管してください。最初に Rockbox ファイルを手動で削除しないでください。復元によりシステム ソフトウェアが置き換えられます。[Y2 復元ガイド](restore-original-y2_ja.html)[トラブルシューティング](../troubleshooting_ja.html)
