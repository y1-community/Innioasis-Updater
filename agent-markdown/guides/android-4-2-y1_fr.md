Android 4.2 (développement) · Innioasis Y1

# Installez Android 4.2 (Dev) sur un Y1.

Android 4.2 est un développement communautaire ROM pour tester et pirater le matériel Innioasis Y1. Sélectionnez Y1 avant de le choisir dans Updater CE.[Obtenir Updater CE](../guide_fr.html#platform)[Disponible dans Updater CE](../guide_fr.html?model=Y1&software=android-4-2-y1)[Origine du projet](https://github.com/y1-community/y1-ata-rom)

Guide d'installation pour votre ordinateur

## Installez le développement Android ROM sur votre Y1 avec votre ordinateur

Choisissez le guide correspondant à l'ordinateur que vous utilisez. Chaque version comprend la configuration de la plate-forme, Updater CE étapes et le chemin de retour au stock.[Guide Windows](/install/android-4-2-y1-windows.html)[Guide macOS](/install/android-4-2-y1-mac.html)[Guide Linux](/install/android-4-2-y1-linux.html)

[Tous les guides Innioasis Y1](/install/y1.html) · [Tous les guides ROM de développement Android](/install/android-dev.html)

## Installez-le
  - Ouvrez Innioasis Updater CE sur votre ordinateur (si vous ne l'avez pas encore, [Obtenir Updater CE](../guide_fr.html#platform)). Sélectionnez Y1 dans Modèle d'appareil.
  - Choisissez Android 4.2 (développement) dans Logiciel (ou lancer avec [Disponible dans Updater CE](../guide_fr.html?model=Y1&software=android-4-2-y1)).
  - Sélectionnez une version et cliquez sur Installer / Restaurer.
  - Éteignez et connectez le Y1 uniquement lorsque le programme de mise à jour vous y invite.
  - Utiliser Y1 Logiciel d'origine pour le chemin de restauration.
