# Instale o Android 4.2 (Dev) em um Y1.

O Android 4.2 é um desenvolvimento da comunidade ROM para testes e hacking no hardware Innioasis Y1. Selecione Y1 antes de escolhê-lo em Updater CE.[Obtenha o atualizador CE](../guide_pt.html#platform)[Obtenha isso em Updater CE](../guide_pt.html?model=Y1&software=android-4-2-y1)[Fonte do projeto](https://github.com/y1-community/y1-ata-rom)

Guia de instalação para o seu computador

## Instale o desenvolvimento Android ROM em seu Y1 com seu computador

Escolha o guia para o computador que você está usando. Cada versão possui a configuração da plataforma, Updater CE etapas e o caminho de volta ao estoque.[Guia do Windows](/install/android-4-2-y1-windows.html)[guia macOS](/install/android-4-2-y1-mac.html)[Guia Linux](/install/android-4-2-y1-linux.html)

[Todos Innioasis Y1 guias](/install/y1.html) · [Todos os guias de desenvolvimento Android ROM](/install/android-dev.html)

## Instale-o
  - Abra Innioasis Updater CE no seu computador (se ainda não o tiver, [Obtenha o atualizador CE](../guide_pt.html#platform)). Selecione Y1 em Modelo do dispositivo.
  - Escolher Android 4.2 (desenvolvimento) em Programas (ou lançar com [Obtenha isso em Updater CE](../guide_pt.html?model=Y1&software=android-4-2-y1)).
  - Selecione uma versão e clique em Instalar / Restaurar.
  - Desligue e conecte o Y1 somente quando o Updater solicitar.
  - Usar Y1 Software Original para o caminho de restauração.
