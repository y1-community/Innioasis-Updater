# Installa Linux su Y1.

Linux per Y1 è un kernel Linux della comunità sperimentale e un port rootfs per Innioasis Y1. Selezionare Y1 prima di sceglierlo in Updater CE.[Ottieni Updater CE](../guide_it.html#platform)[Ottieni questo in Updater CE](../guide_it.html?model=Y1&software=linux-y1)[Fonte del progetto](https://github.com/y1-community/y1-linux-rom)

Scegli la guida per il computer che stai utilizzando. Ogni versione ha la configurazione della piattaforma, Updater CE passaggi e il modo per tornare allo stock.[Guida Windows](/install/linux-y1-windows.html)[guida macOS](/install/linux-y1-mac.html)[Guida Linux](/install/linux-y1-linux.html)

## Installalo
  - Apri Innioasis Updater CE sul tuo computer (se non lo hai ancora, [Ottieni Updater CE](../guide_it.html#platform)). Seleziona Y1 dentro Modello del dispositivo.
  - Scegli Linux per Y1 (sviluppo) dentro Software (o avvia con [Ottieni questo in Updater CE](../guide_it.html?model=Y1&software=linux-y1)).
  - Selezionare una versione e fare clic Installa / Ripristina.
  - Spegni e collega Y1 solo quando l'Updater lo richiede.
  - Usa Y1 Software originale per il percorso di ripristino.
