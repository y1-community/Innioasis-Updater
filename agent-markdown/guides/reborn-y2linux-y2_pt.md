# Instale Reborn (Y2Linux) em seu Innioasis Y2.

Siga estas etapas para piscar Reborn (Y2Linux / Y2Reborn) em um Innioasis Y2 usando Innioasis Updater CE e conclua a configuração pós-instalação de Wi-Fi e Bluetooth.[Obtenha o atualizador CE](../guide_pt.html#download-updater)[Por que Reborn (Y2Linux)?](../reborn-y2linux-benefits_pt.html)[Y2Reborn Lançamentos](../firmware_pt.html?model=Y2&software=reborn-y2linux-y2)

Guia de instalação para o seu computador

## Instale Reborn (Y2Linux) em seu Y2 com seu computador

Escolha o guia para o computador que você está usando. Cada versão possui a configuração da plataforma, Updater CE etapas e o caminho de volta ao estoque.[Guia do Windows](/install/reborn-y2linux-y2-windows.html)[guia macOS](/install/reborn-y2linux-y2-mac.html)[Guia Linux](/install/reborn-y2linux-y2-linux.html)

[Todos Innioasis Y2 guias](/install/y2.html) · [Todos os guias Reborn (Y2Linux)](/install/reborn.html)

## Instalação passo a passo
  - Instalar Updater CE: Download [Innioasis Atualizador CE](../guide_pt.html) para Windows, macOS ou Linux e abra-o.
  - Selecione Y2: Escolher Y2 como o modelo do dispositivo.
  - Selecione Reborn: Escolher Reborn (Y2Linux) e o último lançamento.
  - Instalar: Clique Instalar / Restaurar, desligue o Y2 e conecte USB quando solicitado.
  - Espere: Mantenha o player imóvel até que Updater CE confirme e depois desconecte.
  - Configurar Wi-Fi, Bluetooth e rádio FM

Copiar `system.img` para o jogador uma vez. Reborn faz o resto.[Concluir a configuração →](../y2reborn_wifibt_pt.html)

## Retornando ao software original

Você pode retornar seu Y2 ao software de fábrica a qualquer momento escolhendo Y2 e Software Original em Updater CE. Veja o [Y2 tutorial de restauração](restore-original-y2_pt.html).
