# 在 Y1 上安装 Android 4.2（开发版）。

Android 4.2 是一个社区开发 ROM，用于在 Innioasis Y1 硬件上进行测试和黑客攻击。在 Updater CE 中选择之前选择 Y1。[获取 Updater CE](../guide_zh-CN.html#platform)[在 Updater CE 中获取](../guide_zh-CN.html?model=Y1&software=android-4-2-y1)[项目来源](https://github.com/y1-community/y1-ata-rom)

适用于您的计算机的安装指南

## 使用计算机在 Y1 上安装 Android 开发 ROM

选择适合您正在使用的计算机的指南。 每个版本都有平台设置、Updater CE步骤和返回库存的方式。[Windows 指南](/install/android-4-2-y1-windows.html)[macOS 指南](/install/android-4-2-y1-mac.html)[Linux指南](/install/android-4-2-y1-linux.html)

[所有 Innioasis Y1 指南](/install/y1.html) · [所有 Android 开发 ROM 指南](/install/android-dev.html)

## 安装它
  - 在您的计算机上打开 Innioasis Updater CE（如果您还没有， [获取 Updater CE](../guide_zh-CN.html#platform)）。选择 Y1 在 设备型号.
  - 选择 Android 4.2（开发） 在 软件 （或启动 [在 Updater CE 中获取](../guide_zh-CN.html?model=Y1&software=android-4-2-y1)).
  - 选择一个版本并单击 安装 / 恢复.
  - 仅当更新程序提示时关闭并连接 Y1。
  - 使用Y1 原厂软件 为恢复路径。
