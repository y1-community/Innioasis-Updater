# Восстановите исходное программное обеспечение на Innioasis и Timmkoo A5

Следуйте этому руководству, чтобы восстановить официальное заводское программное обеспечение на вашем проигрывателе Innioasis A5 или Timmkoo A5 с помощью проверенных пакетов из Innioasis архива прошивки.[Скачать Updater CE](../guide_ru.html#platform)[Посмотреть A5 загрузок](../firmware_ru.html?model=A5)

## Шаг 1. Настройка в Updater CE
  - Запуск Innioasis Программа обновления CE на вашем компьютере с Windows, macOS или Linux.
  - Набор Модель устройства в адрес A5.
  - Выбирать Заводское ПО. Updater CE скачивает официальную `rom_a5.zip` выпустить пакет напрямую.
  - Нажмите Установить / Восстановить и дождитесь завершения подготовки.

## Шаг 2. Подключитесь по запросу
  - Полностью выключите устройство A5.
  - Прежде чем подключать кабель для передачи данных USB, дождитесь сообщения на экране компьютера.
  - Позвольте процессу перепрошивки завершиться без перерыва.
  - Отключите и перезагрузите только что восстановленный A5 плеер.
