# Як інсталювати Better-Y на Innioasis Y1 - Innioasis завантаження мікропрограми

Better-Y · Innioasis Y1

# Встановіть Better-Y на Y1.

Better-Y — це розширений стандартний досвід для Innioasis Y1, створений Leska1337. Виберіть Y1, перш ніж вибрати його для встановлення пакетів, що відповідають моделі.[Отримати Updater CE](../guide_uk.html#platform)[Отримайте це в Updater CE](../guide_uk.html?model=Y1&software=better-y-y1)[Чому Better-Y?](../better-y-benefits_uk.html)

Посібник із встановлення для вашого комп’ютера

## Встановіть Better-Y на свій Y1 разом із комп’ютером

Виберіть посібник для комп’ютера, яким ви користуєтеся. Кожна версія має налаштування платформи, Updater CE кроків і шлях повернення до запасу.[Керівництво по Windows](/install/better-y-y1-windows.html)[посібник з macOS](/install/better-y-y1-mac.html)[Керівництво по Linux](/install/better-y-y1-linux.html)

[Усі Innioasis Y1 посібники](/install/y1.html) · [Усі Better-Y посібники](/install/better-y.html)

## Встановіть його
  - Відкрийте Innioasis Updater CE на своєму комп’ютері (якщо у вас його ще немає, [Отримати Updater CE](../guide_uk.html#platform)). Виберіть Y1 в Модель пристрою.
  - Виберіть Better-Y в Програмне забезпечення (або запустити за допомогою [Отримайте це в Updater CE](../guide_uk.html?model=Y1&software=better-y-y1)).
  - Виберіть випуск і натисніть Встановити / Відновити.
  - Вимкніть живлення та підключіть Y1 лише тоді, коли програма оновлення підкаже.
  - Використовуйте Y1 Заводське ПЗ для шляху відновлення.

## Зберігайте зв'язокІнструкції з підключення програми оновленняПідключайтеся лише за живою підказкою.

Залиште плеєр нерухомим, поки миготіння завершиться. Коли програма оновлення підтвердить успішне виконання, від’єднайте плеєр і ввімкніть його.

## Better-Y ярликів і порад
  - Перейти до «Зараз грає». — Double-press the Play/Pause button from any screen or menu to instantly return to playback.
  - Екстрене перезавантаження — Якщо програвач коли-небудь перестав реагувати, утримуйте верхню та нижню кнопки разом, щоб запустити чисте перезавантаження апаратного забезпечення.
  - Алфавітний сувій — Обертайте коліщатко вздовж краю, щоб активувати панель швидкого індексу в алфавітному порядку на довгих списках треків.
  - Інтерактивні піктограми «Зараз грає». — Торкніться піктограм на екрані для «Подобається», «Перемішати», «Повторити (один/усі), тексти пісень, цикл A-B, черга, закладка, швидкість і таймер вимкнення».
  - Поділ тегів — Розділіть кількох виконавців комами (,) або крапками з комою (;), щоб треки відображалися під кожним виконавцем окремо. Багатожанрові теги, розділені комами, крапками з комами або скісними рисками.
