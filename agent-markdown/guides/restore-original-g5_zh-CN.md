# 恢复 Innioasis G5 上的原始软件

当您需要恢复无响应的 G5、将系统刷新至出厂状态或安装干净的官方固件更新时，请使用本指导教程。[获取 Updater CE](../guide_zh-CN.html#platform)[查看 G5 下载](../firmware_zh-CN.html?model=G5)

## 使用计算机恢复 G5 上的原始软件

选择适合您正在使用的计算机的指南。 每个版本都有平台设置、Updater CE步骤和返回库存的方式。[Windows 指南](/install/original-g5-windows.html)[macOS 指南](/install/original-g5-mac.html)[Linux指南](/install/original-g5-linux.html)

[所有 Innioasis G5 指南](/install/g5.html) · [所有原始软件指南](/install/original-software.html)

## 第 1 步：准备您的计算机

Innioasis 更新程序 CE 在 Windows、macOS 和 Linux 上本机运行，无需复杂的刷新工具：
  - 发射 Innioasis 更新程序 CE 在您的台式机或笔记本电脑上。
  - 套装 设备型号 至 G5.
  - 选择 原厂软件 在软件下拉菜单中。 Updater CE自动下载官方 `rom_g5.zip` 直接发布包。
  - 点击 安装 / 恢复 开始准备。

## 第 2 步：根据提示连接 G5

在应用程序提示您之前，切勿连接您的播放器：
  - 确保您的 Innioasis G5 已完全断电。
  - 当更新程序显示 USB 连接提示时，将 USB-C 数据线插入电脑和播放器。
  - 闪烁期间请勿触摸电缆或电源按钮。
  - 出现成功确认信息后，拔下 USB 电缆并打开 G5 电源。
