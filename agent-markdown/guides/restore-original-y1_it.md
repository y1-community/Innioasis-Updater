## Da Rockbox o da un altro software personalizzato

Una volta pronta la configurazione Windows, macOS o Linux pertinente, Updater utilizza la stessa installazione guidata per un ripristino stock come per l'installazione di un software personalizzato. Non è necessario eliminare prima manualmente Rockbox o i file di un altro software personalizzato.
  - Apri Innioasis Updater CE sul tuo computer (se non lo hai ancora installato, [Ottieni Updater CE](../guide_it.html#platform) per [Finestre](../drivers_it.html#windows), [macOS](../guide_it.html#macos), o [Linux](../drivers_it.html#linux)).
  - Impostato Modello del dispositivo a Y1.
  - Scegli Software originale dentro Software (o utilizzare [Ottieni questo in Updater CE](../guide_it.html?model=Y1&software=original-y1)).
  - Scegli l'ultima versione stabile Y1. Il solito pacchetto manuale è `rom.zip`. Type A copre Y1 lettori forniti con la versione del software originale 2.0.0 o successiva; Type B copre i lettori forniti con una versione precedente di [Software originale](../firmware_it.html?software=original-y1) e può utilizzare un nome di pacchetto più specifico.
  - Fare clic Installa / Ripristina e attendi l'estrazione del pacchetto.

## Collegare Y1 quando richiesto

Il sistema operativo modifica la configurazione dell'Updater, non il percorso di ripristino stesso. Su ogni piattaforma, attendi il messaggio live prima di connetterti.
  - Spegnere completamente il lettore quando richiesto dall'Updater.
  - Collegare il cavo dati USB solo quando richiesto.
  - Non toccare il lettore durante l'esecuzione dell'installazione.
  - Disconnettersi dopo il messaggio di successo e avviare Y1.

## Se ancora non si avvia

Ripetere il ripristino una volta con il modello, il tipo e la versione selezionati. Se il programma di aggiornamento fallisce prima del prompt USB, controllare la configurazione del computer, il driver o le autorizzazioni, il cavo dati e i file estratti. Se fallisce dopo aver rilevato Y1, utilizzare il file [guida alla risoluzione dei problemi](../troubleshooting_it.html) prima di passare al ripristino manuale SP Flash Tool o MTKClient.Non passare ai file Y2. Un ripristino Y1 richiede una versione del software originale Y1, anche se il lettore sta attualmente utilizzando un software personalizzato diverso.
