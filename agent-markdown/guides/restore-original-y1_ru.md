## Из Rockbox или другого специального программного обеспечения.

Как только соответствующая установка Windows, macOS или Linux будет готова, программа обновлений использует ту же управляемую установку для стандартного восстановления, что и для выборочной установки программного обеспечения. Вам не нужно сначала вручную удалять файлы Rockbox или другого пользовательского программного обеспечения.
  - Откройте Innioasis Updater CE на своем компьютере (если он еще не установлен, [Скачать Updater CE](../guide_ru.html#platform) для [Окна](../drivers_ru.html#windows), [macOS](../guide_ru.html#macos), или [Линукс](../drivers_ru.html#linux)).
  - Набор Модель устройства в адрес Y1.
  - Выбирать Заводское ПО в Программное обеспечение (или используйте [Получите это в Updater CE](../guide_ru.html?model=Y1&software=original-y1)).
  - Выберите последнюю стабильную версию Y1. Обычный ручной пакет `rom.zip`. Type A относится к Y1 плеерам, поставляемым с оригинальным программным обеспечением версии 2.0.0 или новее; Type B относится к игрокам, которые поставлялись с более ранней версией [Заводское ПО](../firmware_ru.html?software=original-y1) и может использовать более конкретное имя пакета.
  - Нажмите Установить / Восстановить и дождитесь извлечения пакета.

## Подключите Y1 в командной строке

Операционная система меняет настройки Updater, а не сам процесс восстановления. На каждой платформе перед подключением дождитесь живого приглашения.
  - Полностью выключите плеер, когда об этом попросит программа обновлений.
  - Подключайте кабель для передачи данных USB только по запросу.
  - Не прикасайтесь к плееру во время установки.
  - Отключитесь после сообщения об успехе и запустите Y1.

## Если все равно не запускается

Повторите восстановление один раз, отметив модель, тип и выпуск. Если программа обновления завершается с ошибкой до появления приглашения USB, проверьте настройки компьютера, драйвер или разрешения, кабель для передачи данных и извлеченные файлы. Если после обнаружения Y1 произошел сбой, используйте команду [руководство по устранению неполадок](../troubleshooting_ru.html) перед переходом к ручному восстановлению SP Flash Tool или MTKClient.Не переключайтесь на файлы Y2. Для восстановления Y1 требуется Y1 версия оригинального программного обеспечения, даже если в настоящее время на плеере используется другое пользовательское программное обеспечение.
