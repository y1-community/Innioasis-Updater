# Як установити Android 4.4 (Dev) на Innioasis Y2 - Innioasis Завантаження мікропрограми

Android 4.4 (Dev) · Innioasis Y2

# Установіть Android 4.4 (Dev) на Y2.

Android 4.4 — це розробка спільноти ROM для тестування та злому апаратного забезпечення Innioasis Y2. Виберіть Y2, перш ніж вибрати його в Updater CE.[Отримати Updater CE](../guide_uk.html#platform)[Отримайте це в Updater CE](../guide_uk.html?model=Y2&software=android-4-4-y2)[Джерело проекту](https://github.com/y1-community/y2-ata-rom)

Посібник із встановлення для вашого комп’ютера

## Установіть Android development ROM на Y2 разом із комп’ютером

Виберіть посібник для комп’ютера, яким ви користуєтеся. Кожна версія має налаштування платформи, Updater CE кроків і шлях повернення до запасу.[Керівництво по Windows](/install/android-4-4-y2-windows.html)[посібник з macOS](/install/android-4-4-y2-mac.html)[Керівництво по Linux](/install/android-4-4-y2-linux.html)

[Усі Innioasis Y2 посібники](/install/y2.html) · [Усі посібники з розробки Android ROM.](/install/android-dev.html)

## Встановіть його
  - Відкрийте Innioasis Updater CE на своєму комп’ютері (якщо у вас його ще немає, [Отримати Updater CE](../guide_uk.html#platform)). Виберіть Y2 в Модель пристрою.
  - Виберіть Android 4.4 (для розробників) в Програмне забезпечення (або запустити за допомогою [Отримайте це в Updater CE](../guide_uk.html?model=Y2&software=android-4-4-y2)).
  - Виберіть випуск і натисніть Встановити / Відновити.
  - Вимкніть живлення та підключіть Y2 лише тоді, коли програма оновлення підкаже.
  - Використовуйте Y2 Заводське ПЗ для шляху відновлення.

## Примітка розробника щодо збіркиЗбірка розробника: Це зображення розробки, призначене для експериментів. Прочитайте примітки до випуску щодо поточної підтримки апаратного забезпечення та відомих проблем.Інструкції з підключення програми оновленняПідключайтеся лише за живою підказкою.
