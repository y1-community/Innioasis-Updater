# 如何在 Innioasis Y1 - Innioasis 上安裝 Rondo 韌體下載

Innioasis Y1 · 安裝教學課程

# 在您的 Innioasis Y1 上安裝 Rondo。

請依照 Innioasis 更新程式 CE 中的下列步驟進行安裝 Rondo 在您的 Innioasis Y1 上，然後完成安裝後設定指南。[取得 Updater CE](../guide_zh-TW.html#download-updater)[為什麼是Rondo？](../rondo-benefits_zh-TW.html)[Rondo 發布](../firmware_zh-TW.html?model=Y1&software=rondo-y1)

適用於您的電腦的安裝指南

## 使用計算機在 Y1 上安裝 Rondo

選擇適合您正在使用的計算機的指南。 每個版本都有平台設定、Updater CE步驟和返回庫存的方式。[Windows 指南](/install/rondo-y1-windows.html)[macOS 指南](/install/rondo-y1-mac.html)[Linux指南](/install/rondo-y1-linux.html)

[所有 Innioasis Y1 指南](/install/y1.html) · [所有 Rondo 指南](/install/rondo.html)

## 逐步安裝
  - 開啟更新程式CE： 發射 [Innioasis 更新程式 CE](../guide_zh-TW.html) 在您的 Windows、macOS 或 Linux 電腦上。
  - 選擇設備型號 Y1： 選擇 Y1 在裝置型號下拉清單中（如果您的 Y1 附帶 2.0.0 之前的原始軟體，請選擇 Type B；否則保留 Type A）。
  - 從軟體下拉清單中選擇 Rondo： 選擇 Rondo 在软件列表中并选择最新版本。更新程式 CE 使用 Android 4.2 Wi-Fi 基礎 ROM 和 Rondo 自動發布來源。
  - 閃光播放器： 點選 安裝 / 還原，完全關閉 Y1 電源，並在 Updater CE 提示時透過 USB 數據線連接。
  - 斷開連線並啟動： 在拔下 Y1 之前，請等待綠色完成訊息。
  - 完成安裝後設定

請依照以下步驟操作 [本指南](../post_install_zh-TW.html?software=rondo-y1&model=Y1) 完成 Y1 上的設定。[查看指南](../post_install_zh-TW.html?software=rondo-y1&model=Y1)
