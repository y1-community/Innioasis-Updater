# Innioasis Y1 또는 Y2 - Innioasis에 JJ Launcher을(를) 설치하는 방법 펌웨어 다운로드

JJ Launcher · Y1 및 Y2

# 모델을 선택하신 후 JJ Launcher을(를) 설치하세요.

프로젝트 이름은 공유되지만 사용 가능한 패키지는 여전히 플레이어가 Y1인지 Y2인지에 따라 다릅니다. 아래에서 모델을 선택하면 가이드가 패키지와 일치합니다.[Updater CE 받기](../guide_ko.html#platform)[Y1의 JJ Launcher](jj-launcher-y1_ko.html)[Y2의 JJ Launcher](jj-launcher-y2_ko.html)

## 어떤 가이드를 사용해야 합니까?

Y1 및 Y2 플레이어 모두 Innioasis 업데이터 CE를 통해 JJ Launcher를 설치합니다(앱이 필요한 경우, [Updater CE 받기](../guide_ko.html#platform) PC용 또는 다음으로 실행 [이것을 Updater CE에서 얻으세요](../guide_ko.html?model=Y1&software=jj-launcher-y1)). 아래에서 모델을 선택하세요.

### Innioasis Y1

모델별 Y1 경로를 따르고 Y1 패키지를 선택된 상태로 유지합니다.[Y1 설치 단계](jj-launcher-y1_ko.html)

### Innioasis Y2

모델별 Y2 경로를 따르고 Y2 패키지를 선택된 상태로 유지합니다.[Y2 설치 단계](jj-launcher-y2_ko.html)
