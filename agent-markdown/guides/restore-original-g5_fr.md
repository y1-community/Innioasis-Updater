# Restaurer le logiciel d'origine sur Innioasis G5

Utilisez ce didacticiel lorsque vous devez récupérer un G5 qui ne répond pas, actualiser le système à l'état d'usine ou installer des mises à jour officielles du micrologiciel.[Obtenir Updater CE](../guide_fr.html#platform)[Afficher G5 téléchargements](../firmware_fr.html?model=G5)

Guide d'installation pour votre ordinateur

## Restaurez le logiciel d'origine sur votre G5 avec votre ordinateur

Choisissez le guide correspondant à l'ordinateur que vous utilisez. Chaque version comprend la configuration de la plate-forme, Updater CE étapes et le chemin de retour au stock.[Guide Windows](/install/original-g5-windows.html)[Guide macOS](/install/original-g5-mac.html)[Guide Linux](/install/original-g5-linux.html)

[Tous les guides Innioasis G5](/install/g5.html) · [Tous les guides de logiciels originaux](/install/original-software.html)

## Étape 1 : Préparez votre ordinateur

Innioasis Updater CE fonctionne nativement sur Windows, macOS et Linux sans nécessiter de harnais de flashage complexes :
  - Lancement Innioasis Programme de mise à jour CE sur votre ordinateur de bureau ou portable.
  - Ensemble Modèle d'appareil à G5.
  - Sélectionnez Logiciel d'origine dans la liste déroulante des logiciels. Updater CE télécharge automatiquement le fichier officiel `rom_g5.zip` publier le package directement.
  - Cliquez Installer / Restaurer pour commencer la préparation.

## Étape 2 : connectez le G5 à l'invite

Ne connectez jamais votre lecteur avant que l'application ne vous demande :
  - Assurez-vous que votre Innioasis G5 est complètement éteint.
  - Lorsque le programme de mise à jour affiche l'invite de connexion USB, branchez votre câble de données USB-C à l'ordinateur et au lecteur.
  - Ne touchez pas le câble ou les boutons d'alimentation pendant le clignotement.
  - Une fois la confirmation de réussite affichée, débranchez le câble USB et allumez votre G5.
