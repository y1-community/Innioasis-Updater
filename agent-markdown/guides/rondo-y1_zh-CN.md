选择适合您正在使用的计算机的指南。 每个版本都有平台设置、Updater CE步骤和返回库存的方式。[Windows 指南](/install/rondo-y1-windows.html)[macOS 指南](/install/rondo-y1-mac.html)[Linux指南](/install/rondo-y1-linux.html)

## 分步安装
  - 打开更新程序CE： 发射 [Innioasis 更新程序 CE](../guide_zh-CN.html) 在您的 Windows、macOS 或 Linux 计算机上。
  - 选择设备型号 Y1： 选择 Y1 在设备型号下拉列表中（如果您的 Y1 附带 2.0.0 之前的原始软件，请选择 Type B；否则保留 Type A）。
  - 从软件下拉列表中选择 Rondo： 选择 Rondo 在软件列表中并选择最新版本。更新程序 CE 使用 Android 4.2 Wi-Fi 基础 ROM 和 Rondo 自动发布源。
  - 闪光播放器： 点击 安装 / 恢复，完全关闭 Y1 电源，并在 Updater CE 提示时通过 USB 数据线连接。
  - 断开连接并启动： 在拔下 Y1 之前，请等待绿色完成消息。
  - 完成安装后设置

请按照以下步骤操作 [本指南](../post_install_zh-CN.html?software=rondo-y1&model=Y1) 完成 Y1 上的设置。[查看指南](../post_install_zh-CN.html?software=rondo-y1&model=Y1)
