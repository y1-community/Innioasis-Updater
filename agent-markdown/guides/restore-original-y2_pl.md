## Z Rockbox lub innego niestandardowego oprogramowania

Gdy odpowiednia konfiguracja systemu Windows, macOS lub Linux będzie już gotowa, powrót do standardowego interfejsu Y2 wykorzystuje ten sam przepływ narzędzia Updater, co podczas instalacji projektu społecznościowego. Nie mieszaj ręcznie plików Y1 w odtwarzaczu ani nie usuwaj najpierw folderów systemowych.
  - Otwórz Innioasis Updater CE na swoim komputerze (jeśli jeszcze go nie masz zainstalowanego, [Pobierz Updater CE](../guide_pl.html#platform) Do [Okna](../drivers_pl.html#windows), [macOS](../guide_pl.html#macos)lub [Linuksa](../drivers_pl.html#linux)).
  - Zestaw Model urządzenia do Y2.
  - Wybierz Oprogramowanie oryginalne.
  - Wybierz stabilną wersję Y2. Można użyć ręcznych pakietów pełnej instalacji `rom_y2.zip`.
  - Kliknij Zainstaluj / Przywróć i poczekaj na etap ekstrakcji.
Nie zastępuj: Y1 `rom.zip` nie jest pakietem Y2. Jeśli lista wydań wygląda nieprawidłowo, zatrzymaj się i ponownie wybierz Y2.

## Postępuj zgodnie z monitem o połączenie

W systemach Windows, macOS i Linux obowiązują różne uwagi dotyczące konfiguracji komputera, ale sekwencja po stronie odtwarzacza pozostaje taka sama: wyłącz zasilanie, gdy zostaniesz o to poproszony, a następnie podłącz kabel danych po wyświetleniu monitu.
  - Całkowicie wyłącz Y2, gdy program aktualizujący poprosi o to.
  - Połącz USB tylko wtedy, gdy aplikacja poinformuje, że jest gotowa.
  - Zostaw kabel w spokoju do czasu pojawienia się komunikatu o powodzeniu.
  - Odłącz bezpiecznie i uruchom odtwarzacz.
Instrukcje podłączenia aktualizatoraOdniesienie do połączenia udostępnionego. Monit aplikacji na żywo jest miarodajny.

## Nadal utknąłeś?

Przed wypróbowaniem narzędzia ręcznego sprawdź model, opakowanie, kabel i czas połączenia. The [przewodnik rozwiązywania problemów](../troubleshooting_pl.html) wyjaśnia, co oznacza awaria przed USB w porównaniu z awarią po wykryciu urządzenia.Trzymaj pakiety oddzielnie: Y1 `rom.zip` nie jest przywracaniem Y2. Jeśli lista wydań wygląda nieprawidłowo, zatrzymaj się i ponownie wybierz Y2.
