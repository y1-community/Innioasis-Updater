# 如何在 Innioasis Y1 - Innioasis 上安裝 Better-Y 韌體下載

Better-Y · Innioasis Y1

# 在 Y1 上安裝 Better-Y。

Better-Y 是 Leska1337 創建的 Innioasis Y1 的增強庫存體驗。選擇Y1，然後選擇它來安裝型號匹配的軟體包。[取得 Updater CE](../guide_zh-TW.html#platform)[在 Updater CE 中取得此內容](../guide_zh-TW.html?model=Y1&software=better-y-y1)[為什麼是Better-Y？](../better-y-benefits_zh-TW.html)

適用於您的電腦的安裝指南

## 使用計算機在 Y1 上安裝 Better-Y

選擇適合您正在使用的計算機的指南。 每個版本都有平台設定、Updater CE步驟和返回庫存的方式。[Windows 指南](/install/better-y-y1-windows.html)[macOS 指南](/install/better-y-y1-mac.html)[Linux指南](/install/better-y-y1-linux.html)

[所有 Innioasis Y1 指南](/install/y1.html) · [所有 Better-Y 指南](/install/better-y.html)

## 安裝它
  - 在您的電腦上開啟 Innioasis Updater CE（如果您還沒有， [取得 Updater CE](../guide_zh-TW.html#platform)）。選擇 Y1 在 裝置型號.
  - 選擇 Better-Y 在 軟體 （或啟動 [在 Updater CE 中取得此內容](../guide_zh-TW.html?model=Y1&software=better-y-y1)).
  - 選擇一個版本並點擊 安裝 / 還原.
  - 僅當更新程式提示時關閉並連接 Y1。
  - 使用Y1 原廠軟體 為恢復路徑。

## 保持連線不變更新器連線說明僅在即時提示時連接。

閃爍完成時讓播放器保持靜止。當更新程式確認成功後，請拔下播放器的插頭並開啟電源。

## Better-Y 快速鍵與提示
  - 跳至正在播放 — 在任何螢幕或選單中按兩下播放/暫停按鈕即可立即返回播放。
  - 緊急重啟 — 如果播放器變得無響應，請同時按住頂部和底部按鈕以觸發乾淨的硬體重新啟動。
  - 按字母順序滾動 — 沿邊緣旋轉點按輪可啟動長曲目清單上的字母快速索引欄。
  - 互動式正在播放圖標 — 點選畫面上的「讚」、「隨機播放」、「重複（一個/全部）」、「歌詞」、「A-B 循環」、「隊列」、「書籤」、「速度」和「睡眠定時器」圖示。
  - 標籤分割 — 以逗號 (,) 或分號 (;) 分隔多位藝術家，以使曲目單獨顯示在每位藝術家下方。多類型標籤以逗號、分號或斜線分隔。
