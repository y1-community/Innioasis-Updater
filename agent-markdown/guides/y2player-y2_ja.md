# Innioasis Y2 - Innioasis ファームウェアのダウンロードに Y2Player をインストールする方法

Y2Player · Innioasis Y2

# Y2 に Y2Player をインストールします。

Y2Player は Y2 プロジェクトです。安全な方法は、プロジェクト名ではなくモデルの選択から始まります。[Updater CE を入手](../guide_ja.html#platform)[Updater CE で入手](../guide_ja.html?model=Y2&software=y2player-y2)[なぜY2Player?](../y2player-benefits_ja.html)

お使いのコンピューターのインストールガイド

## コンピュータを使用して Y2 に Y2Player をインストールします

使用しているコンピュータのガイドを選択してください。 すべてのバージョンには、プラットフォームのセットアップ、Updater CE の手順、および在庫に戻る方法が含まれています。[Windowsガイド](/install/y2player-y2-windows.html)[macOS ガイド](/install/y2player-y2-mac.html)[Linuxガイド](/install/y2player-y2-linux.html)

[すべての Innioasis Y2 ガイド](/install/y2.html) · [すべての Y2Player ガイド](/install/y2player.html)

## アップデーター内
  - コンピュータで Innioasis Updater CE を開きます (まだお持ちでない場合は、 [Updater CE を入手](../guide_ja.html#platform)）。選択 Y2 で デバイスモデル.
  - 選択してください Y2Player で ソフトウェア (または次のように起動します) [Updater CE で入手](../guide_ja.html?model=Y2&software=y2player-y2)).
  - リストされている Y2 リリースを選択します。
  - クリック インストール / 復元、要求されたら電源を切り、プロンプトで USB を接続します。
  - Y2で復元 純正ソフトウェア 必要に応じて。

## Y1 パッケージを置き換えないでください2 回確認してください: Y2 のフルインストール パッケージでは次のものが使用される場合があります `rom_y2.zip`。プレーン Y1 パッケージは安全な代替品ではありません。電源がオフになっている Y2 のアップデータ接続手順案内が表示されてから接続してください。
