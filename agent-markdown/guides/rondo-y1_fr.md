## Installation étape par étape
  - Ouvrir Updater CE : Lancement [Innioasis Programme de mise à jour CE](../guide_fr.html) sur votre ordinateur Windows, macOS ou Linux.
  - Choisissez le modèle de périphérique Y1 : Sélectionnez Y1 dans la liste déroulante Modèle de périphérique (choisissez Type B si votre Y1 a été livré avec le logiciel d'origine antérieur à 2.0.0 ; sinon conservez Type A).
  - Choisissez Rondo dans la liste déroulante Logiciel : Sélectionnez Rondo dans la liste Logiciels et choisissez la dernière version. Updater CE utilise automatiquement la base Wi-Fi Android 4.2 ROM et Rondo.
  - Flasher le lecteur : Cliquez Installer / Restaurer, éteignez complètement votre Y1 et connectez-le via un câble de données USB lorsque Updater CE vous y invite.
  - Déconnectez-vous et démarrez : Attendez le message de fin vert avant de débrancher votre Y1.
  - Terminer la configuration post-installation

Suivez les étapes dans [ce guide](../post_install_fr.html?software=rondo-y1&model=Y1) pour terminer la configuration sur votre Y1.[Voir le guide](../post_install_fr.html?software=rondo-y1&model=Y1)
