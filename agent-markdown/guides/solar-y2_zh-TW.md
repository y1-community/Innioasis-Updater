# 如何在 Innioasis Y2 - Innioasis 上安裝 Solar 韌體下載

Solar · Innioasis Y2

# 在您的 Y2 上安裝 Solar。

Solar 是一個單獨的社區項目，並且列出了 Y2 版本。功能可能會發生變化，因此讓 Updater 顯示您的模型的目前版本。[取得 Updater CE](../guide_zh-TW.html#platform)[在 Updater CE 中取得此內容](../guide_zh-TW.html?model=Y2&software=solar-y2)[為什麼是Solar？](../solar-benefits_zh-TW.html)

還提供： [Y1 上的 Solar](solar-y1_zh-TW.html)

適用於您的電腦的安裝指南

## 使用計算機在 Y2 上安裝 Solar

選擇適合您正在使用的計算機的指南。 每個版本都有平台設定、Updater CE步驟和返回庫存的方式。[Windows 指南](/install/solar-y2-windows.html)[macOS 指南](/install/solar-y2-mac.html)[Linux指南](/install/solar-y2-linux.html)

[所有 Innioasis Y2 指南](/install/y2.html) · [所有 Solar 指南](/install/solar.html)

## 選擇Y2路線
  - 在您的電腦上開啟 Innioasis Updater CE（如果您還沒有， [取得 Updater CE](../guide_zh-TW.html#platform)）。選擇 Y2 在 裝置型號.
  - 選擇 Solar 在 軟體 （或啟動 [在 Updater CE 中取得此內容](../guide_zh-TW.html?model=Y2&software=solar-y2)).
  - 閱讀發行說明，確認 Y2 條目，然後按一下 安裝 / 還原.
  - 僅當更新程式要求時關閉並連接播放器。
  - 用 Y2 恢復 原廠軟體 如果您再次需要庫存接口。

## 保留項目註釋

Solar 正在積極開發中。功能和模型支援可能會發生變化，因此請檢查項目的發行說明。更新程式顯示目前適用於您的模型的內容。如果 Y2 條目遺失，請勿取代 Y1 包。更新器連線說明僅在即時提示時連接。

## 返回原始軟體

Solar 不會變更返回庫存介面的路由。為您的電腦設定更新程式後，請在 Windows、macOS 或 Linux 上開啟它，然後選擇 Y2 加號 原廠軟體 而不是 Solar。
  - 選擇穩定的 Y2 原始軟體版本。
  - 點選 安裝 / 還原 並等待即時連線提示。
  - 僅在詢問時關閉 Y2 電源。
  - 根據提示連接USB數據線並保持不動直至成功。

不要先手動刪除 Solar 文件，並且不要使用 Y1 套件。如果故障發生在USB提示之前，請先檢查電腦設定、電纜和型號選擇。[Y2恢復指南](restore-original-y2_zh-TW.html)[疑難排解](../troubleshooting_zh-TW.html)
