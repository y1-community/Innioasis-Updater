# Instale Inniclassic em um Y1.

Inniclassic está listado como um projeto Y1. Selecione Y1 antes de escolhê-lo para que a lista de versões permaneça ciente do modelo.[Obtenha o atualizador CE](../guide_pt.html#platform)[Obtenha isso em Updater CE](../guide_pt.html?model=Y1&software=inniclassic-y1)[Por que Inniclassic?](../inniclassic-benefits_pt.html)

Guia de instalação para o seu computador

## Instale Inniclassic em seu Y1 com seu computador

Escolha o guia para o computador que você está usando. Cada versão possui a configuração da plataforma, Updater CE etapas e o caminho de volta ao estoque.[Guia do Windows](/install/inniclassic-y1-windows.html)[guia macOS](/install/inniclassic-y1-mac.html)[Guia Linux](/install/inniclassic-y1-linux.html)

[Todos Innioasis Y1 guias](/install/y1.html) · [Todos Inniclassic guias](/install/inniclassic.html)

## Instale-o
  - Abra Innioasis Updater CE no seu computador (se ainda não o tiver, [Obtenha o atualizador CE](../guide_pt.html#platform)). Selecione Y1 em Modelo do dispositivo.
  - Escolher Inniclassic em Programas (ou lançar com [Obtenha isso em Updater CE](../guide_pt.html?model=Y1&software=inniclassic-y1)).
  - Selecione uma versão e clique em Instalar / Restaurar.
  - Desligue e conecte o Y1 somente quando o Updater solicitar.
  - Usar Y1 Software Original para o caminho de restauração.

## Mantenha a conexão paradaInstruções de conexão do atualizadorA solicitação exata pode variar de acordo com a plataforma.

Se a instalação falhar, observe se a falha ocorreu antes ou depois do Updater detectar o player. Esse detalhe torna a solução de problemas muito mais rápida.
