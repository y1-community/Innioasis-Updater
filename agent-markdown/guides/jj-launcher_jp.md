# Innioasis Y1 または Y2 - Innioasis ファームウェアのダウンロードに JJ Launcher をインストールする方法

JJ Launcher · Y1 および Y2

# 機種を選択後、JJ Launcherをインストールしてください。

プロジェクト名は共有されていますが、利用可能なパッケージはプレーヤーが Y1 か Y2 かによって異なります。以下からお使いのモデルを選択してください。ガイドはパッケージと一致します。[Updater CE を入手](../guide_jp.html#platform)[Y1 の JJ Launcher](jj-launcher-y1_jp.html)[Y2 の JJ Launcher](jj-launcher-y2_jp.html)

## どのガイドを使用すればよいですか?

Y1 プレーヤーと Y2 プレーヤーはどちらも Innioasis Updater CE 経由で JJ Launcher をインストールします (アプリが必要な場合は、 [Updater CE を入手](../guide_jp.html#platform) PC の場合、または次のコマンドで起動します [Updater CE で入手](../guide_jp.html?model=Y1&software=jj-launcher-y1)）。以下からモデルを選択してください:

### Innioasis Y1

モデル固有の Y1 ルートに従い、Y1 パッケージを選択したままにしておきます。[Y1 のインストール手順](jj-launcher-y1_jp.html)

### Innioasis Y2

モデル固有の Y2 ルートに従い、Y2 パッケージを選択したままにしておきます。[Y2 のインストール手順](jj-launcher-y2_jp.html)
