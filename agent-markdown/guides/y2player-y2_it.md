# Installare Y2Player su Y2.

Y2Player è un progetto Y2. Il percorso sicuro inizia con la selezione del modello, non con il nome del progetto.[Ottieni Updater CE](../guide_it.html#platform)[Ottieni questo in Updater CE](../guide_it.html?model=Y2&software=y2player-y2)[Perché Y2Player?](../y2player-benefits_it.html)

Guida all'installazione per il tuo computer

## Installa Y2Player sul tuo Y2 con il tuo computer

Scegli la guida per il computer che stai utilizzando. Ogni versione ha la configurazione della piattaforma, Updater CE passaggi e il modo per tornare allo stock.[Guida Windows](/install/y2player-y2-windows.html)[guida macOS](/install/y2player-y2-mac.html)[Guida Linux](/install/y2player-y2-linux.html)

[Tutte le Innioasis Y2 guide](/install/y2.html) · [Tutte le Y2Player guide](/install/y2player.html)

## Nell'Aggiornamento
  - Apri Innioasis Updater CE sul tuo computer (se non lo hai ancora, [Ottieni Updater CE](../guide_it.html#platform)). Seleziona Y2 dentro Modello del dispositivo.
  - Scegli Y2Player dentro Software (o avvia con [Ottieni questo in Updater CE](../guide_it.html?model=Y2&software=y2player-y2)).
  - Scegli la versione Y2 elencata.
  - Fare clic Installa / Ripristina, spegnere quando richiesto e connettere USB quando richiesto.
  - Ripristina con Y2 Software originale se necessario.

## Non sostituire un pacchetto Y1.Controlla due volte: Y2 i pacchetti di installazione completa possono utilizzare `rom_y2.zip`. Un semplice pacchetto Y1 non è un sostituto sicuro.Istruzioni per la connessione dell'aggiornamento per un Y2 spentoConnettiti solo al prompt live.
