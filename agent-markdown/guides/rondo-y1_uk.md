# Як інсталювати Rondo на Innioasis Y1 - Innioasis Завантаження прошивки

Innioasis Y1 · Підручник із встановлення

# Встановіть Rondo на свій Innioasis Y1.

Щоб установити, виконайте ці дії в Innioasis Updater CE Rondo на вашому Innioasis Y1, а потім завершіть інструкцію з налаштування після встановлення.[Отримати Updater CE](../guide_uk.html#download-updater)[Чому Rondo?](../rondo-benefits_uk.html)[Rondo Релізи](../firmware_uk.html?model=Y1&software=rondo-y1)

Посібник із встановлення для вашого комп’ютера

## Встановіть Rondo на свій Y1 разом із комп’ютером

Виберіть посібник для комп’ютера, яким ви користуєтеся. Кожна версія має налаштування платформи, Updater CE кроків і шлях повернення до запасу.[Керівництво по Windows](/install/rondo-y1-windows.html)[посібник з macOS](/install/rondo-y1-mac.html)[Керівництво по Linux](/install/rondo-y1-linux.html)

[Усі Innioasis Y1 посібники](/install/y1.html) · [Усі Rondo посібники](/install/rondo.html)

## Покрокова установка
  - Відкрийте програму оновлення CE: Запуск [Innioasis Оновлення CE](../guide_uk.html) на вашому комп’ютері з Windows, macOS або Linux.
  - Виберіть модель пристрою Y1: Виберіть Y1 у спадному меню «Модель пристрою» (виберіть Type B, якщо ваш Y1 постачався з оригінальним програмним забезпеченням до версії 2.0.0; інакше збережіть Type A).
  - Виберіть Rondo зі спадного списку Програмне забезпечення: Виберіть Rondo у списку Програмне забезпечення та виберіть останню версію. Updater CE автоматично використовує канал випуску Android 4.2 Wi-Fi base ROM і Rondo.
  - Прошити плеєр: Натисніть Встановити / Відновити, повністю вимкніть Y1 і підключіть його через USB кабель передачі даних, коли Updater CE підкаже.
  - Від'єднайте та завантажте: Зачекайте на зелене повідомлення про завершення, перш ніж відключати Y1.
  - Завершіть налаштування після встановлення

Виконайте кроки в [цей посібник](../post_install_uk.html?software=rondo-y1&model=Y1) щоб завершити налаштування на Y1.[Переглянути посібник](../post_install_uk.html?software=rondo-y1&model=Y1)
