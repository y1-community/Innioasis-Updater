# Innioasis Y1 - Innioasis ファームウェアのダウンロードに JJ Launcher をインストールする方法

JJ Launcher · Innioasis Y1

# Y1 に JJ Launcher をインストールします。

これは JJ Launcher プロジェクトの Y1 ルートです。アップデーターが間違ったパッケージを提供しないように、最初にモデルを選択してください。[Updater CE を入手](../guide_jp.html#platform)[Updater CE で入手](../guide_jp.html?model=Y1&software=jj-launcher-y1)[なぜJJ Launcher?](../jj-launcher-benefits_jp.html)

以下もご利用いただけます: [Y2 の JJ Launcher](jj-launcher-y2_jp.html)

## コンピュータを使用して Y1 に JJ Launcher をインストールします

使用しているコンピュータのガイドを選択してください。 すべてのバージョンには、プラットフォームのセットアップ、Updater CE の手順、および在庫に戻る方法が含まれています。[Windowsガイド](/install/jj-launcher-y1-windows.html)[macOS ガイド](/install/jj-launcher-y1-mac.html)[Linuxガイド](/install/jj-launcher-y1-linux.html)

[すべての Innioasis Y1 ガイド](/install/y1.html) · [すべての JJ Launcher ガイド](/install/jj-launcher.html)

## Y1 ルートを選択してください
  - コンピュータで Innioasis Updater CE を開きます (まだお持ちでない場合は、 [Updater CE を入手](../guide_jp.html#platform)）。選択 Y1 で デバイスモデル.
  - 選択してください JJ Launcher で ソフトウェア (または次のように起動します) [Updater CE で入手](../guide_jp.html?model=Y1&software=jj-launcher-y1)).
  - リリース ノートを読み、Y1 バージョンを選択して、 インストール / 復元.
  - アップデーターが要求した場合にのみ、プレーヤーの電源を切り、接続してください。
  - Y1 で復元します 純正ソフトウェア ストックインターフェイスが再度必要な場合。

## 最初に確認するのはモデルの不一致です

JJ Launcher には Y2 エントリもあります。パッケージ名が間違っていると思われる場合は、「デバイス モデル」に戻ります。 Y2 パッケージを Y1 に無理に押し付けないでください。Updater への接続手順案内が表示されてから接続してください。

## 元のソフトウェアに戻る

JJ Launcher は、ストック インターフェイスに戻るルートを変更しません。コンピューターにアップデーターをセットアップしたら、Windows、macOS、または Linux 上でアップデーターを開いて、 Y1 プラス 純正ソフトウェア JJ Launcher の代わりに。
  - 安定した Y1 オリジナル ソフトウェア リリースを選択してください。
  - クリック インストール / 復元 そして、ライブ接続プロンプトが表示されるまで待ちます。
  - Y1 の電源をオフにするのは、要求された場合のみにしてください。
  - プロンプトで USB データ ケーブルを接続し、成功するまでそのままにしておきます。

最初に JJ Launcher ファイルを手動で削除したり、Y2 パッケージを使用したりしないでください。 USB プロンプトが表示される前に障害が発生した場合は、まずコンピューターのセットアップ、ケーブル、モデルの選択を確認してください。[Y1 復元ガイド](restore-original-y1_jp.html)[トラブルシューティング](../troubleshooting_jp.html)
