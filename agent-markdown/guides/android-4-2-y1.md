# Install Android 4.2 (Dev) on a Y1.

Android 4.2 is a community development ROM for testing and hacking on the Innioasis Y1 hardware. ## Install it
  - Open Innioasis Updater CE on your computer (if you don't have it yet, [Get Updater CE](../guide.html#platform)). Select Y1 in Device Model.
  - Choose Android 4.2 (Dev) in Software (or launch with [Get this in Updater CE](../guide.html?model=Y1&software=android-4-2-y1)).
  - Select a release and click Install / Restore.
  - Power off and connect the Y1 only when Updater prompts you.
  - Use Y1 Original Software for the restore path.
