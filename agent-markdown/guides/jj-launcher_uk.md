# Як встановити JJ Launcher на Innioasis Y1 або Y2 - Innioasis Завантаження мікропрограми

JJ Launcher · Y1 і Y2

# Встановіть JJ Launcher після вибору моделі.

Назва проекту є спільною, але доступний пакет усе ще залежить від того, чи є ваш програвач Y1 чи Y2. Виберіть свою модель нижче, і посібник підійде до комплекту.[Отримати Updater CE](../guide_uk.html#platform)[JJ Launcher на Y1](jj-launcher-y1_uk.html)[JJ Launcher на Y2](jj-launcher-y2_uk.html)

## Яким довідником я повинен скористатися?

І гравці Y1, і Y2 встановлюють JJ Launcher через Innioasis Updater CE (якщо вам потрібна програма, [Отримати Updater CE](../guide_uk.html#platform) для вашого ПК або запустіть за допомогою [Отримайте це в Updater CE](../guide_uk.html?model=Y1&software=jj-launcher-y1)). Виберіть свою модель нижче:

### Innioasis Y1

Дотримуйтеся маршруту Y1 для конкретної моделі та залишайте вибраним пакет Y1.[Y1 кроків встановлення](jj-launcher-y1_uk.html)

### Innioasis Y2

Дотримуйтеся маршруту Y2 для конкретної моделі та залишайте вибраним пакет Y2.[Y2 кроків встановлення](jj-launcher-y2_uk.html)
