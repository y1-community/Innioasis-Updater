# Como instalar JJ Launcher em seu Innioasis Y1 ou Y2 - Innioasis Downloads de firmware

JJ Launcher · Y1 e Y2

# Instale JJ Launcher após escolher o modelo.

O nome do projeto é compartilhado, mas o pacote disponível ainda depende se o seu player é Y1 ou Y2. Escolha o seu modelo abaixo e o guia combinará com o pacote.[Obtenha o atualizador CE](../guide_pt.html#platform)[JJ Launcher em Y1](jj-launcher-y1_pt.html)[JJ Launcher em Y2](jj-launcher-y2_pt.html)

## Qual guia devo usar?

Ambos Y1 e Y2 jogadores instalam JJ Launcher via Innioasis Updater CE (se você precisar do aplicativo, [Obtenha o atualizador CE](../guide_pt.html#platform) para o seu PC ou inicie com [Obtenha isso em Updater CE](../guide_pt.html?model=Y1&software=jj-launcher-y1)). Escolha seu modelo abaixo:

### Innioasis Y1

Siga a rota Y1 específica do modelo e mantenha o pacote Y1 selecionado.[Y1 etapas de instalação](jj-launcher-y1_pt.html)

### Innioasis Y2

Siga a rota Y2 específica do modelo e mantenha o pacote Y2 selecionado.[Y2 etapas de instalação](jj-launcher-y2_pt.html)
