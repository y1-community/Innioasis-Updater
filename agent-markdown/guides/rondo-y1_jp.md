# Innioasis Y1 に Rondo をインストールします。

Innioasis Updater CE の次の手順に従ってインストールしてください Rondo Innioasis Y1 で、インストール後のセットアップ ガイドを完了します。[Updater CE を入手](../guide_jp.html#download-updater)[なぜRondo?](../rondo-benefits_jp.html)[Rondo リリース](../firmware_jp.html?model=Y1&software=rondo-y1)

## コンピュータを使用して Y1 に Rondo をインストールします

使用しているコンピュータのガイドを選択してください。 すべてのバージョンには、プラットフォームのセットアップ、Updater CE の手順、および在庫に戻る方法が含まれています。[Windowsガイド](/install/rondo-y1-windows.html)[macOS ガイド](/install/rondo-y1-mac.html)[Linuxガイド](/install/rondo-y1-linux.html)

[すべての Innioasis Y1 ガイド](/install/y1.html) · [すべての Rondo ガイド](/install/rondo.html)

## 段階的なインストール
  - Updater CE を開きます: 打ち上げ [Innioasis アップデーター CE](../guide_jp.html) Windows、macOS、または Linux コンピューター上で。
  - デバイス モデル Y1 を選択してください: 選択 Y1 [デバイス モデル] ドロップダウンで (Y1 が 2.0.0 より前のオリジナル ソフトウェアに同梱されている場合は Type B を選択します。それ以外の場合は Type A のままにします)。
  - [ソフトウェア] ドロップダウンから Rondo を選択します。 選択 Rondo ソフトウェア リストで最新のリリースを選択します。 Updater CE は、Android 4.2 Wi-Fi ベース ROM および Rondo リリース フィードを自動的に使用します。
  - プレーヤーをフラッシュします。 クリック インストール / 復元Updater CE のプロンプトが表示されたら、Y1 の電源を完全にオフにし、USB データ ケーブルを介して接続します。
  - 切断して起動します。 Y1 のプラグを抜く前に、緑色の完了メッセージが表示されるまで待ちます。
  - インストール後のセットアップを完了する

の手順に従います [このガイド](../post_install_jp.html?software=rondo-y1&model=Y1) Y1 でのセットアップを完了します。[ガイドを見る](../post_install_jp.html?software=rondo-y1&model=Y1)
