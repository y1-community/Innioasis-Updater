# Installez Inniclassic sur un Y2.

Inniclassic dispose d'un port dédié Y2 géré par Jonasz Potoniec. Sélectionnez Y2 avant de le choisir afin que la liste des versions reste adaptée au modèle.[Obtenir Updater CE](../guide_fr.html#platform)[Disponible dans Updater CE](../guide_fr.html?model=Y2&software=inniclassic-y2)[Pourquoi Inniclassic ?](../inniclassic-benefits_fr.html)

Guide d'installation pour votre ordinateur

## Installez Inniclassic sur votre Y2 avec votre ordinateur

Choisissez le guide correspondant à l'ordinateur que vous utilisez. Chaque version comprend la configuration de la plate-forme, Updater CE étapes et le chemin de retour au stock.[Guide Windows](/install/inniclassic-y2-windows.html)[Guide macOS](/install/inniclassic-y2-mac.html)[Guide Linux](/install/inniclassic-y2-linux.html)

[Tous les guides Innioasis Y2](/install/y2.html) · [Tous les guides Inniclassic](/install/inniclassic.html)

## Installez-le
  - Ouvrez Innioasis Updater CE sur votre ordinateur (si vous ne l'avez pas encore, [Obtenir Updater CE](../guide_fr.html#platform)). Sélectionnez Y2 dans Modèle d'appareil.
  - Choisissez Inniclassic dans Logiciel (ou lancer avec [Disponible dans Updater CE](../guide_fr.html?model=Y2&software=inniclassic-y2)).
  - Sélectionnez une version et cliquez sur Installer / Restaurer.
  - Éteignez et connectez le Y2 uniquement lorsque le programme de mise à jour vous le demande.
  - Utiliser Y2 Logiciel d'origine pour le chemin de restauration.

## Gardez toujours la connexionInstructions de connexion à UpdaterNe connectez qu'au moment de l'invite.

Y2 packages utilisent `rom_y2.zip`. Si l'installation échoue, notez si l'échec s'est produit avant ou après que le programme de mise à jour ait détecté le lecteur.
