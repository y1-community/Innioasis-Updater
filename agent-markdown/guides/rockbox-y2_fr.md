# Installez la version Y2, pas la version Y1.

Le parcours utilisateur est familier, mais le modèle et le package sont différents. ## Regarder l'itinéraire Rockbox

Vidéo de Frawgeeys. Cela fonctionne pour les modèles Y1 et Y2 — dans Innioasis Updater CE, sélectionnez Y2 comme votre modèle. Les étapes écrites ci-dessous couvrent la séquence d'installation Y2.

Vidéo par [Place Cristian](https://www.youtube.com/@CristianPlaza) (Espagnol). Il démontre l'installation sur un Y1 ; choisir Y2 dans Updater CE pour ce guide.

## Avant de cliquer sur installer

Ayez un Innioasis Y2 chargé, un câble de données USB et un ordinateur avec Innioasis Updater CE installé (si vous ne l'avez pas encore installé, [Obtenir Updater CE](../guide_fr.html#platform) pour Windows, macOS ou Linux). N'utilisez pas une version Y1 simplement parce que son nom semble similaire.Vérification du modèle : Y2 les packages d'installation complète peuvent utiliser `rom_y2.zip`. Le nom du fichier est un indice utile pour le téléchargement manuel, mais le programme de mise à jour doit gérer la sélection du package pour vous.

## Choisissez Y2 dans le programme de mise à jour
  - Ouvrez Updater CE (ou lancez avec [Disponible dans Updater CE](../guide_fr.html?model=Y2&software=rockbox-y2)) et définissez Modèle d'appareil à Y2.
  - Choisissez Rockbox dans Logiciel.
  - Choisissez une version répertoriée pour Y2. Si aucune version Y2 n'est répertoriée, ne la remplacez pas par une version Y1.
  - Cliquez Installer / Restaurer et laissez Updater CE télécharger le package directement à partir de la version du développeur de la communauté.

## Éteignez, puis connectez
  - Attendez l'invite de connexion en direct.
  - Éteignez complètement le Y2. Utilisez les instructions exactes de réinitialisation ou de récupération affichées par le programme de mise à jour si l'arrêt normal échoue.
  - Connectez le câble USB lorsque vous y êtes invité. Laissez-le immobile jusqu'au message de fin.
  - Déconnectez-vous en toute sécurité et démarrez le Y2.
Instructions de connexion du programme de mise à jour pour un appareil éteintL'écran de connexion est une référence. Votre invite Y2 peut inclure une formulation de modèle différente.

## Revenir au logiciel d'origine

Rockbox ne vous verrouille pas dans le logiciel personnalisé. Une fois le programme de mise à jour configuré pour votre ordinateur, utilisez-le sous Windows, macOS ou Linux pour revenir de Rockbox ou d'un autre projet répertorié : sélectionnez Y2, choisir Logiciel d'origine, et cours Installer / Restaurer.
  - Attendez que le programme de mise à jour prépare le package de stock Y2.
  - Éteignez le Y2 lorsque l'application vous le demande.
  - Connectez le câble de données USB uniquement à l'invite en direct.
  - Laissez le joueur immobile jusqu'au message de réussite.

Gardez les packages Y1 et Y2 séparés. Ne supprimez pas manuellement les fichiers Rockbox en premier ; la restauration remplace le logiciel système.[Guide de restauration Y2](restore-original-y2_fr.html)[Dépannage](../troubleshooting_fr.html)
