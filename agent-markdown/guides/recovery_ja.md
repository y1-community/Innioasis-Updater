# Innioasis Y1 および Y2 リカバリ ガイド

電源が入らない、ホイールが機能しない、またはインストールが途中で停止しました。症状から始めて、すぐに手動フラッシュに移行するのではなく、順番に手順に従ってください。[Updater CE を入手](../guide_ja.html#platform)[ファームウェアのダウンロード](../firmware_ja.html)[トラブルシューティング](../troubleshooting_ja.html)

Innioasis Updater から始める

## ガイド付きインストールではこれらのほとんどが修正されます

アップデーターはこれを 1 パスで実行します。ソフトウェアを選択し、画面上の手順に従ってください。これで完了です。また、修正または新しいリリースがいつリリースされるかについても通知されます。

## まずは症状から

これらのガイドでは、アップデートまたはフラッシュ後に最も頻繁に遭遇する 2 つの障害について説明します。表示されている内容と一致するものを選択し、順番に作業してください。

### スクロールホイールが機能しない

ホイールは回転しますが、プレイヤーがそれを無視するか、アップデート直後に停止します。

[Y1 スクロールホイールガイド](y1-scroll-wheel-not-working_ja.html) · [Y2 スクロールホイールガイド](y2-scroll-wheel-not-working_ja.html)

### プレーヤーの電源が入らない

黒い画面、充電ランプが点灯しない、またはロゴが表示されたり消えたりします。

[Y1 パワーガイド](y1-wont-turn-on_ja.html) · [Y2 パワーガイド](y2-wont-turn-on_ja.html)

### インストールが途中で停止しました

USB プロンプトの前後でアップデーターが失敗したか、リリース リストが間違っているようです。

[トラブルシューティングガイド](../troubleshooting_ja.html)

### ファイルが必要です

各モデルのオリジナルソフトウェアとカスタムパッケージ。

[ファームウェアのダウンロード](../firmware_ja.html)

## Y1 パッケージと Y2 パッケージは互換性がありませんモデルをクロスフラッシュしないでください。 Y1 `rom.zip` Y2 パッケージではなく、Y2 パッケージでもありません `rom_y2.zip` Y1 では実行されません。間違ったモデルをフラッシュすることは、プレーヤーが無効なコントロールやブート ループに陥る最も一般的な理由の 1 つです。

プレーヤーに印刷されているモデルを確認し、Updater CE で一致させてからリリースを選択してください。

## 最初に一致する元のソフトウェアを復元します

手動ツールを使用する前に、正しいモデルのストック ファームウェアをプレーヤーに戻してください。これにより、アップデート関連のホイールとブートのほとんどのエラーが修正されます。

Y1: Y1 を選択し、オリジナル ソフトウェアを選択し、安定した Y1 リリースを選択して、インストール/復元を実行します。 [完全な Y1 復元ガイド](restore-original-y1_ja.html).

Y2: Y2 を選択し、オリジナル ソフトウェアを選択し、安定した Y2 リリースを選択して、インストール/復元を実行します。 [完全な Y2 復元ガイド](restore-original-y2_ja.html).

プレーヤーの電源をオフにし、アップデーターが要求した場合にのみ USB データ ケーブルを接続します。成功メッセージが表示されるまで接続したままにしておきます。

## Updater CE に同梱されている手動リカバリ

アップデーターがジョブを完了できない場合、同じインストールには手動ツールが含まれます。 [SP Flash Tool](../sp-flash-tool_ja.html) は Windows および Linux x86 マシンにバンドルされており、MTKClient ルートは macOS をカバーします。どちらも、モデルに一致するファームウェア パッケージが必要です。 [ファームウェアのダウンロード](../firmware_ja.html) ページ。

お使いのプラットフォームのガイドを使用して、プレーヤーを充電し続けてください。どのツールもプレーヤーをまったく検出しない場合は、ファームウェアではなくハードウェアに問題がある可能性があります。

## 助けを求めるときに含めるべきもの
  - モデル — Y1 または Y2 — プレーヤーに印刷されています。
  - 画面の機能: 何もない、ロゴ、ブート ループ、またはホーム画面。
  - コンピューターがプレーヤーを MediaTek デバイスとして検出するかどうか。
  - 正確なアップデータ メッセージと選択したパッケージ。
  - 手動ツールを含む、すでに試したこと。

プライベート トークンや無関係なシステム ファイルを投稿しないでください。の [コミュニティ Discord](https://discord.gg/zHrT2zrcek) そして [r/innioasis](https://reddit.com/r/innioasis) ノートを比較するのに最も速い場所です。

## Innioasis リカバリに関するよくある質問

### 電源が入らない Innioasis プレーヤーを修正するにはどうすればよいですか?

既知のデータ ケーブルを使用して 30 分間充電し、15 秒間電源を保持して強制的に再起動し、コンピュータがそれを検出するかどうかを確認します。存在する場合は、モデルが一致した元のソフトウェアを復元します。そうでない場合は、Updater CE に含まれている手動回復ツールを使用してください。

### Y1 または Y2 スクロール ホイールが機能しないのはなぜですか?

アップデート後にホイールが停止した場合は、通常、ファームウェアの不一致が原因です。モデルに一致する元のソフトウェアを再インストールし、再度テストします。すべてのファームウェアでホイールが故障している場合は、ハードウェア障害として扱います。

### リカバリ用のファームウェアはどこからダウンロードすればよいですか?

innioasis.app/firmware.html のファームウェア ダウンロード ページには、各モデルのオリジナル パッケージとカスタム パッケージがホストされています。プレーヤーに一致する Y1 または Y2 パッケージを常に選択してください。

### Updater CE にはどのような回復ツールが含まれていますか?

Updater CE には、Windows および Linux の SP Flash Tool と、通常のインストールが完了できない場合の手動回復用の macOS を含む MTKClient ルートが含まれています。
