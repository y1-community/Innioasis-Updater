# Innioasis Y2 - Innioasis 펌웨어 다운로드에 Inniclassic을(를) 설치하는 방법

Inniclassic · Innioasis Y2

# Y2에 Inniclassic을(를) 설치합니다.

Inniclassic에는 Jonasz Potoniec이 관리하는 전용 Y2 포트가 있습니다. 릴리스 목록이 모델을 인식하도록 선택하기 전에 Y2를 선택하십시오.[Updater CE 받기](../guide_ko.html#platform)[이것을 Updater CE에서 얻으세요](../guide_ko.html?model=Y2&software=inniclassic-y2)[왜 Inniclassic인가요?](../inniclassic-benefits_ko.html)

컴퓨터에 대한 설치 가이드

## 컴퓨터를 사용하여 Y2에 Inniclassic을(를) 설치합니다.

사용 중인 컴퓨터에 대한 가이드를 선택하세요. 모든 버전에는 플랫폼 설정, Updater CE 단계 및 재고로 돌아가는 방법이 있습니다.[윈도우 가이드](/install/inniclassic-y2-windows.html)[macOS 가이드](/install/inniclassic-y2-mac.html)[리눅스 가이드](/install/inniclassic-y2-linux.html)

[모든 Innioasis Y2 가이드](/install/y2.html) · [모든 Inniclassic 가이드](/install/inniclassic.html)

## 설치하세요
  - 컴퓨터에서 Innioasis Updater CE를 엽니다. (아직 없다면, [Updater CE 받기](../guide_ko.html#platform)). 선택 Y2 안으로 기기 모델.
  - 선택 Inniclassic 안으로 소프트웨어 (또는 다음으로 시작 [이것을 Updater CE에서 얻으세요](../guide_ko.html?model=Y2&software=inniclassic-y2)).
  - 릴리스를 선택하고 클릭하세요. 설치 / 복원.
  - Updater에서 메시지가 표시될 때만 전원을 끄고 Y2을 연결하십시오.
  - Y2 사용 원본 소프트웨어 복원 경로에 대해

## 계속 연결을 유지하세요업데이터 연결 지침라이브 프롬프트에서만 연결하십시오.

Y2 패키지 사용 `rom_y2.zip`. 설치에 실패하면 업데이터가 플레이어를 감지하기 전이나 후에 실패가 발생했는지 확인하십시오.
