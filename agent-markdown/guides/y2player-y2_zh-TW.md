# 如何在 Innioasis Y2 - Innioasis 上安裝 Y2Player 韌體下載

Y2Player · Innioasis Y2

# 在 Y2 上安裝 Y2Player。

Y2Player 是一個 Y2 項目。安全路線從型號選擇開始，而不是從專案名稱開始。[取得 Updater CE](../guide_zh-TW.html#platform)[在 Updater CE 中取得此內容](../guide_zh-TW.html?model=Y2&software=y2player-y2)[為什麼是Y2Player？](../y2player-benefits_zh-TW.html)

適用於您的電腦的安裝指南

## 使用計算機在 Y2 上安裝 Y2Player

選擇適合您正在使用的計算機的指南。 每個版本都有平台設定、Updater CE步驟和返回庫存的方式。[Windows 指南](/install/y2player-y2-windows.html)[macOS 指南](/install/y2player-y2-mac.html)[Linux指南](/install/y2player-y2-linux.html)

[所有 Innioasis Y2 指南](/install/y2.html) · [所有 Y2Player 指南](/install/y2player.html)

## 在更新程式中
  - 在您的電腦上開啟 Innioasis Updater CE（如果您還沒有， [取得 Updater CE](../guide_zh-TW.html#platform)）。選擇 Y2 在 裝置型號.
  - 選擇 Y2Player 在 軟體 （或啟動 [在 Updater CE 中取得此內容](../guide_zh-TW.html?model=Y2&software=y2player-y2)).
  - 選擇列出的 Y2 版本。
  - 點選 安裝 / 還原，根據提示關閉電源，然後根據提示連接 USB。
  - 用 Y2 恢復 原廠軟體 如果需要的話。

## 不要替換 Y1 包檢查兩次： Y2 完整安裝包可使用 `rom_y2.zip`。普通的 Y1 包並不是安全的替代品。關閉電源的更新程序連接說明 Y2僅在即時提示時連接。
