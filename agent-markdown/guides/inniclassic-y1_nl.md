# Installeer Inniclassic op een Y1.

Inniclassic wordt vermeld als een Y1-project. Selecteer Y1 voordat u deze kiest, zodat de releaselijst modelbewust blijft.[Updater CE downloaden](../guide_nl.html#platform)[Ontvang dit in Updater CE](../guide_nl.html?model=Y1&software=inniclassic-y1)[Waarom Inniclassic?](../inniclassic-benefits_nl.html)

Installatiehandleiding voor uw computer

## Installeer Inniclassic op uw Y1 met uw computer

Kies de handleiding voor de computer die u gebruikt. Elke versie heeft de platformconfiguratie, Updater CE stappen en de weg terug naar de voorraad.[Windows-gids](/install/inniclassic-y1-windows.html)[macOS-gids](/install/inniclassic-y1-mac.html)[Linux-gids](/install/inniclassic-y1-linux.html)

[Alle Innioasis Y1-gidsen](/install/y1.html) · [Alle Inniclassic gidsen](/install/inniclassic.html)

## Installeer het
  - Open Innioasis Updater CE op uw computer (als u dit nog niet heeft, [Updater CE downloaden](../guide_nl.html#platform)). Selecteer Y1 binnen Apparaatmodel.
  - Kies Inniclassic binnen Software (of start met [Ontvang dit in Updater CE](../guide_nl.html?model=Y1&software=inniclassic-y1)).
  - Selecteer een release en klik Installeren / Herstellen.
  - Schakel de Y1 alleen uit en sluit deze alleen aan als Updater u daarom vraagt.
  - Gebruik Y1 Originele software voor het herstelpad.

## Houd de verbinding stilUpdater-verbindingsinstructiesDe exacte prompt kan per platform verschillen.

Als de installatie mislukt, noteer dan of de fout plaatsvond voordat of nadat Updater de speler had gedetecteerd. Dat detail maakt het oplossen van problemen veel sneller.
