# Ripristina il software originale su Innioasis G5

Utilizza questo tutorial guidato quando è necessario ripristinare un G5 che non risponde, aggiornare il sistema allo stato di fabbrica o installare aggiornamenti firmware ufficiali puliti.[Ottieni Updater CE](../guide_it.html#platform)[Visualizza G5 download](../firmware_it.html?model=G5)

## Ripristina il software originale sul tuo G5 con il tuo computer

Scegli la guida per il computer che stai utilizzando. Ogni versione ha la configurazione della piattaforma, Updater CE passaggi e il modo per tornare allo stock.[Guida Windows](/install/original-g5-windows.html)[guida macOS](/install/original-g5-mac.html)[Guida Linux](/install/original-g5-linux.html)

[Tutte le guide Innioasis G5.](/install/g5.html) · [Tutte le guide al software originale](/install/original-software.html)

## Passaggio 1: prepara il computer

Innioasis Updater CE funziona in modo nativo su Windows, macOS e Linux senza richiedere complessi cablaggi di flashing:
  - Lancio Innioasis Programma di aggiornamento CE sul tuo desktop o laptop.
  - Impostato Modello del dispositivo a G5.
  - Seleziona Software originale nel menu a discesa del software. Updater CE scarica automaticamente il file ufficiale `rom_g5.zip` rilasciare direttamente il pacchetto.
  - Fare clic Installa / Ripristina per iniziare la preparazione.

## Passaggio 2: collegare G5 al prompt

Non connettere mai il lettore prima che l'applicazione ti chieda:
  - Assicurati che il tuo Innioasis G5 sia completamente spento.
  - Quando Updater visualizza la richiesta di connessione USB, collega il cavo dati USB-C al computer e al lettore.
  - Non toccare il cavo o i pulsanti di accensione mentre è in corso il flashing.
  - Una volta visualizzata la conferma dell'esito positivo, scollega il cavo USB e accendi il tuo G5.
