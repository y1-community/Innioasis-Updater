# كيفية تثبيت Reborn (Y2Linux / Y2Reborn) على Innioasis Y2 - Innioasis تنزيلات البرامج الثابتة

Innioasis Y2 · تثبيت البرنامج التعليمي

# قم بتثبيت Reborn (Y2Linux) على Innioasis Y2.

اتبع هذه الخطوات للفلاش Reborn (Y2Linux / Y2Reborn) على Innioasis Y2 باستخدام Innioasis Updater CE، ثم قم بإنهاء إعداد Wi-Fi وBluetooth بعد التثبيت.[احصل على Updater CE](../guide_ar.html#download-updater)[لماذا Reborn (Y2Linux)؟](../reborn-y2linux-benefits_ar.html)[Y2Reborn الإصدارات](../firmware_ar.html?model=Y2&software=reborn-y2linux-y2)

دليل التثبيت لجهاز الكمبيوتر الخاص بك

## قم بتثبيت Reborn (Y2Linux) على جهاز Y2 بجهاز الكمبيوتر الخاص بك

اختر دليل الكمبيوتر الذي تستخدمه. يحتوي كل إصدار على إعداد النظام الأساسي وخطوات Updater CE وطريقة العودة إلى المخزون.[دليل ويندوز](/install/reborn-y2linux-y2-windows.html)[دليل ماك](/install/reborn-y2linux-y2-mac.html)[دليل لينكس](/install/reborn-y2linux-y2-linux.html)

[جميع أدلة Innioasis Y2](/install/y2.html) · [جميع الأدلة Reborn (Y2Linux).](/install/reborn.html)

## التثبيت خطوة بخطوة
  - تثبيت التحديث CE: تنزيل [Innioasis برنامج التحديث CE](../guide_ar.html) لنظام التشغيل Windows أو macOS أو Linux، ثم افتحه.
  - حدد Y2: اختر Y2 كنموذج الجهاز.
  - حدد Reborn: اختر Reborn (Y2Linux) وأحدث إصدار.
  - ثَبَّتَ: انقر تثبيت / استعادة، قم بإيقاف تشغيل Y2، وقم بتوصيل USB عند المطالبة بذلك.
  - انتظر: أبق المشغل ثابتًا حتى يؤكد Updater CE، ثم افصله.
  - قم بإعداد Wi-Fi وBluetooth وراديو FM

نسخ `system.img` للاعب مرة واحدة. Reborn يقوم بالباقي.[إنهاء الإعداد →](../y2reborn_wifibt_ar.html)

## العودة إلى البرامج الأصلية

You can return your Y2 to factory software anytime by choosing Y2 و البرنامج الأصلي في المحدث CE. انظر [Y2 استعادة البرنامج التعليمي](restore-original-y2_ar.html).
