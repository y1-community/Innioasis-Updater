# Innioasis Y2 - Innioasis 펌웨어 다운로드에 Y2Player을(를) 설치하는 방법

Y2Player · Innioasis Y2

# Y2에 Y2Player을(를) 설치합니다.

Y2Player은(는) Y2 프로젝트입니다. 안전한 경로는 프로젝트 이름이 아닌 모델 선택에서 시작됩니다.[Updater CE 받기](../guide_ko.html#platform)[이것을 Updater CE에서 얻으세요](../guide_ko.html?model=Y2&software=y2player-y2)[왜 Y2Player인가요?](../y2player-benefits_ko.html)

컴퓨터에 대한 설치 가이드

## 컴퓨터를 사용하여 Y2에 Y2Player을(를) 설치합니다.

사용 중인 컴퓨터에 대한 가이드를 선택하세요. 모든 버전에는 플랫폼 설정, Updater CE 단계 및 재고로 돌아가는 방법이 있습니다.[윈도우 가이드](/install/y2player-y2-windows.html)[macOS 가이드](/install/y2player-y2-mac.html)[리눅스 가이드](/install/y2player-y2-linux.html)

[모든 Innioasis Y2 가이드](/install/y2.html) · [모든 Y2Player 가이드](/install/y2player.html)

## 업데이터에서
  - 컴퓨터에서 Innioasis Updater CE를 엽니다. (아직 없다면, [Updater CE 받기](../guide_ko.html#platform)). 선택 Y2 안으로 기기 모델.
  - 선택 Y2Player 안으로 소프트웨어 (또는 다음으로 시작 [이것을 Updater CE에서 얻으세요](../guide_ko.html?model=Y2&software=y2player-y2)).
  - 나열된 Y2 릴리스를 선택합니다.
  - 클릭 설치 / 복원, 요청 시 전원을 끄고 프롬프트에서 USB을 연결합니다.
  - Y2로 복원 원본 소프트웨어 필요한 경우.

## Y1 패키지를 대체하지 마십시오두 번 확인하세요: Y2 전체 설치 패키지는 다음을 사용할 수 있습니다. `rom_y2.zip`. 일반 Y1 패키지는 안전한 대체물이 아닙니다.전원이 꺼진 Y2에 대한 업데이터 연결 지침라이브 프롬프트에서만 연결하십시오.
