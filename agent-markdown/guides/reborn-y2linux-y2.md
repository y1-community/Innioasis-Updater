## Step-by-step installation
  - Install Updater CE: Download [Innioasis Updater CE](../guide.html) for Windows, macOS or Linux, then open it.
  - Select Y2: Choose Y2 as the device model.
  - Select Reborn: Choose Reborn (Y2Linux) and the latest release.
  - Install: Click Install / Restore, power the Y2 off, and connect USB when prompted.
  - Wait: Keep the player still until Updater CE confirms, then disconnect.
  - Set up Wi-Fi, Bluetooth & FM radio

Copy `system.img` to the player once. Reborn does the rest.[Finish setup →](../y2reborn_wifibt.html)

## Returning to Original Software

You can return your Y2 to factory software anytime by choosing Y2 and Original Software in Updater CE. See the [Y2 restore tutorial](restore-original-y2.html).
