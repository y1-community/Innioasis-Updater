# Installieren Sie Y2Player auf Y2.

Y2Player ist ein Y2 Projekt. Der sichere Weg beginnt bei der Modellauswahl, nicht beim Projektnamen.[Updater CE holen](../guide_de.html#platform)[In Updater CE erhalten](../guide_de.html?model=Y2&software=y2player-y2)[Warum Y2Player?](../y2player-benefits_de.html)

Installationsanleitung für Ihren Computer

## Installieren Sie Y2Player auf Ihrem Y2 mit Ihrem Computer

Wählen Sie die Anleitung für den Computer aus, den Sie verwenden. Jede Version verfügt über das Plattform-Setup, Updater CE Schritte und den Weg zurück zum Lagerbestand.[Windows-Anleitung](/install/y2player-y2-windows.html)[macOS-Anleitung](/install/y2player-y2-mac.html)[Linux-Anleitung](/install/y2player-y2-linux.html)

[Alle Innioasis Y2-Anleitungen](/install/y2.html) · [Alle Y2Player Anleitungen](/install/y2player.html)

## Im Updater
  - Öffnen Sie Innioasis Updater CE auf Ihrem Computer (falls Sie es noch nicht haben, [Updater CE holen](../guide_de.html#platform)). Auswählen Y2 In Gerätemodell.
  - Wählen Sie Y2Player In Software (oder starten Sie mit [In Updater CE erhalten](../guide_de.html?model=Y2&software=y2player-y2)).
  - Wählen Sie die aufgeführte Version Y2 aus.
  - Klicken Sie Installieren / Wiederherstellen, schalten Sie das Gerät aus, wenn Sie dazu aufgefordert werden, und schließen Sie USB an, wenn Sie dazu aufgefordert werden.
  - Mit Y2 wiederherstellen Original-Software wenn nötig.

## Ersetzen Sie kein Y1-PaketÜberprüfen Sie zweimal: Y2 Vollinstallationspakete dürfen verwenden `rom_y2.zip`. Ein einfaches Y1-Paket ist kein sicherer Ersatz.Anweisungen zum Updater-Anschluss für einen ausgeschalteten Y2Erst verbinden, wenn die Aufforderung erscheint.
