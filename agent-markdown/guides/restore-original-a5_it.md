# Ripristina il software originale su Innioasis e Timmkoo A5

Segui questo tutorial per ripristinare il software di fabbrica ufficiale sul tuo lettore Innioasis A5 o Timmkoo A5 con pacchetti verificati dall'archivio firmware Innioasis.[Ottieni Updater CE](../guide_it.html#platform)[Visualizza A5 download](../firmware_it.html?model=A5)

## Passaggio 1: installazione in Updater CE
  - Lancio Innioasis Programma di aggiornamento CE sul tuo computer Windows, macOS o Linux.
  - Impostato Modello del dispositivo a A5.
  - Seleziona Software originale. Updater CE scarica il file ufficiale `rom_a5.zip` rilasciare direttamente il pacchetto.
  - Fare clic Installa / Ripristina e attendere il completamento della preparazione.

## Passaggio 2: connettersi quando richiesto
  - Spegnere completamente il dispositivo A5.
  - Attendere la richiesta sullo schermo del computer prima di collegare il cavo dati USB.
  - Consentire al processo di flashing di terminare senza interruzioni.
  - Disconnetti e riavvia il lettore A5 appena ripristinato.
