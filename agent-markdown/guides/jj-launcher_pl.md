# Jak zainstalować JJ Launcher na swoim Innioasis Y1 lub Y2 - Innioasis Pobieranie oprogramowania sprzętowego

JJ Launcher · Y1 i Y2

# Zainstaluj JJ Launcher po wybraniu modelu.

Nazwa projektu jest wspólna, ale dostępny pakiet nadal zależy od tego, czy Twój odtwarzacz to Y1, czy Y2. Wybierz swój model poniżej, a przewodnik dopasuje się do pakietu.[Pobierz Updater CE](../guide_pl.html#platform)[JJ Launcher na Y1](jj-launcher-y1_pl.html)[JJ Launcher na Y2](jj-launcher-y2_pl.html)

## Z jakiego przewodnika powinienem skorzystać?

Zarówno odtwarzacze Y1, jak i Y2 instalują JJ Launcher poprzez Innioasis Updater CE (jeśli potrzebujesz aplikacji, [Pobierz Updater CE](../guide_pl.html#platform) na swój komputer lub uruchom za pomocą [Zdobądź to w Updater CE](../guide_pl.html?model=Y1&software=jj-launcher-y1)). Wybierz swój model poniżej:

### Innioasis Y1

Postępuj zgodnie z trasą Y1 specyficzną dla modelu i pozostaw wybrany pakiet Y1.[Y1 kroki instalacji](jj-launcher-y1_pl.html)

### Innioasis Y2

Postępuj zgodnie z trasą Y2 specyficzną dla modelu i pozostaw wybrany pakiet Y2.[Y2 kroki instalacji](jj-launcher-y2_pl.html)
