# Installieren Sie Android 4.4 (Dev) auf einem Y2.

Android 4.4 ist eine Community-Entwicklung ROM zum Testen und Hacken auf der Innioasis Y2-Hardware. Wählen Sie Y2 aus, bevor Sie es in Updater CE auswählen.[Updater CE holen](../guide_de.html#platform)[In Updater CE erhalten](../guide_de.html?model=Y2&software=android-4-4-y2)[Projektquelle](https://github.com/y1-community/y2-ata-rom)

Installationsanleitung für Ihren Computer

## Installieren Sie die Android-Entwicklung ROM auf Ihrem Y2 mit Ihrem Computer

Wählen Sie die Anleitung für den Computer aus, den Sie verwenden. Jede Version verfügt über das Plattform-Setup, Updater CE Schritte und den Weg zurück zum Lagerbestand.[Windows-Anleitung](/install/android-4-4-y2-windows.html)[macOS-Anleitung](/install/android-4-4-y2-mac.html)[Linux-Anleitung](/install/android-4-4-y2-linux.html)

[Alle Innioasis Y2-Anleitungen](/install/y2.html) · [Alle Android-Entwicklungs-ROM-Anleitungen](/install/android-dev.html)

## Installieren Sie es
  - Öffnen Sie Innioasis Updater CE auf Ihrem Computer (falls Sie es noch nicht haben, [Updater CE holen](../guide_de.html#platform)). Auswählen Y2 In Gerätemodell.
  - Wählen Sie Android 4.4 (Entwickler) In Software (oder starten Sie mit [In Updater CE erhalten](../guide_de.html?model=Y2&software=android-4-4-y2)).
  - Wählen Sie eine Veröffentlichung aus und klicken Sie Installieren / Wiederherstellen.
  - Schalten Sie das Gerät aus und schließen Sie Y2 nur dann an, wenn Sie vom Updater dazu aufgefordert werden.
  - Verwenden Sie Y2 Original-Software für den Wiederherstellungspfad.
