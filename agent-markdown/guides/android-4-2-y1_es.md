# Instale Android 4.2 (Dev) en un Y1.

Android 4.2 es un desarrollo comunitario ROM para probar y piratear el hardware Innioasis Y1. Seleccione Y1 antes de elegirlo en Updater CE.[Obtener Updater CE](../guide_es.html#platform)[Obtener en Updater CE](../guide_es.html?model=Y1&software=android-4-2-y1)[Fuente del proyecto](https://github.com/y1-community/y1-ata-rom)

Guía de instalación para su computadora

## Instala el desarrollo de Android ROM en tu Y1 con tu computadora

Elija la guía para la computadora que está utilizando. Cada versión tiene la configuración de la plataforma, Updater CE pasos y el camino de regreso al stock.[guía de windows](/install/android-4-2-y1-windows.html)[guía de macos](/install/android-4-2-y1-mac.html)[guía de linux](/install/android-4-2-y1-linux.html)

[Todas las Innioasis Y1 guías](/install/y1.html) · [Todas las guías de ROM de desarrollo de Android](/install/android-dev.html)

## instalarlo
  - Abra Innioasis Updater CE en su computadora (si aún no lo tiene, [Obtener Updater CE](../guide_es.html#platform)). Seleccionar Y1 en Modelo del dispositivo.
  - elegir Android 4.2 (desarrollador) en Software (o iniciar con [Obtener en Updater CE](../guide_es.html?model=Y1&software=android-4-2-y1)).
  - Seleccione una versión y haga clic Instalar / Restaurar.
  - Apague y conecte el Y1 solo cuando el Actualizador se lo indique.
  - Usar Y1 Software original para la ruta de restauración.
