## Elige la ruta Y1
  - Abra Innioasis Updater CE en su computadora (si aún no lo tiene, [Obtener Updater CE](../guide_es.html#platform)). Seleccionar Y1 en Modelo del dispositivo.
  - elegir JJ Launcher en Software (o iniciar con [Obtener en Updater CE](../guide_es.html?model=Y1&software=jj-launcher-y1)).
  - Lea la nota de la versión, seleccione la versión Y1 y haga clic en Instalar / Restaurar.
  - Apague y conecte el reproductor solo cuando el Actualizador lo solicite.
  - Restaurar con Y1 Software original Si necesita la interfaz original nuevamente.

## La discrepancia del modelo es lo primero que hay que comprobar

JJ Launcher también tiene una entrada Y2. Si el nombre del paquete parece incorrecto, regrese al Modelo de dispositivo. No fuerces un paquete Y2 sobre un Y1.Instrucciones de conexión con UpdaterConecta solo cuando aparezca el aviso.

## Volver al software original

JJ Launcher no cambia la ruta de regreso a la interfaz original. Una vez que Updater esté configurado para su computadora, ábralo en Windows, macOS o Linux y seleccione Y1 más Software original en lugar de JJ Launcher.
  - Elija una versión estable del software original Y1.
  - Haga clic Instalar / Restaurar y espere el mensaje de conexión en vivo.
  - Apague el Y1 solo cuando se le solicite.
  - Conecte el cable de datos USB cuando se le indique y déjelo quieto hasta que tenga éxito.

No elimine manualmente los archivos JJ Launcher primero y no utilice un paquete Y2. Si la falla ocurrió antes del mensaje USB, verifique primero la configuración de la computadora, el cable y la selección del modelo.[Guía de restauración de Y1](restore-original-y1_es.html)[Solución de problemas](../troubleshooting_es.html)
