## Desde Rockbox u otro software personalizado

Una vez que la configuración relevante de Windows, macOS o Linux esté lista, regresar a la interfaz estándar Y2 utiliza el mismo flujo de actualización que instalar un proyecto comunitario. No mezcle manualmente archivos Y1 en el reproductor ni elimine carpetas del sistema primero.
  - Abra Innioasis Updater CE en su computadora (si aún no lo tiene instalado, [Obtener Updater CE](../guide_es.html#platform) para [ventanas](../drivers_es.html#windows), [macos](../guide_es.html#macos), o [linux](../drivers_es.html#linux)).
  - conjunto Modelo del dispositivo a Y2.
  - elegir Software original.
  - Seleccione una versión estable Y2. Los paquetes de instalación completa manual pueden utilizar `rom_y2.zip`.
  - Haga clic Instalar / Restaurar y espere el paso de extracción.
No sustituir: un Y1 `rom.zip` no es un paquete Y2. Si la lista de versiones parece incorrecta, deténgase y vuelva a seleccionar Y2.

## Siga el mensaje de conexión

Windows, macOS y Linux tienen diferentes notas de configuración de la computadora, pero la secuencia del lado del reproductor sigue siendo la misma: apague cuando se le solicite, luego conecte el cable de datos cuando se le indique en vivo.
  - Apague completamente el Y2 cuando el Actualizador lo solicite.
  - Conecte USB solo cuando la aplicación indique que está lista.
  - Deje el cable en paz hasta que aparezca el mensaje de éxito.
  - Desconéctese de forma segura e inicie el reproductor.
Instrucciones de conexión con UpdaterLa referencia de conexión compartida. El aviso de la aplicación en vivo tiene autoridad.
