# Installez Y2Player sur le Y2.

Guide d'installation pour votre ordinateur

## Installez Y2Player sur votre Y2 avec votre ordinateur

Choisissez le guide correspondant à l'ordinateur que vous utilisez. Chaque version comprend la configuration de la plate-forme, Updater CE étapes et le chemin de retour au stock.[Guide Windows](/install/y2player-y2-windows.html)[Guide macOS](/install/y2player-y2-mac.html)[Guide Linux](/install/y2player-y2-linux.html)

[Tous les guides Innioasis Y2](/install/y2.html) · [Tous les guides Y2Player](/install/y2player.html)

## Dans le programme de mise à jour
  - Ouvrez Innioasis Updater CE sur votre ordinateur (si vous ne l'avez pas encore, [Obtenir Updater CE](../guide_fr.html#platform)). Sélectionnez Y2 dans Modèle d'appareil.
  - Choisissez Y2Player dans Logiciel (ou lancer avec [Disponible dans Updater CE](../guide_fr.html?model=Y2&software=y2player-y2)).
  - Choisissez la version Y2 répertoriée.
  - Cliquez Installer / Restaurer, éteignez-le lorsque vous y êtes invité et connectez USB à l'invite.
  - Restaurer avec Y2 Logiciel d'origine si nécessaire.

## Ne remplacez pas un package Y1Vérifiez deux fois : Y2 les packages d'installation complète peuvent utiliser `rom_y2.zip`. Un simple package Y1 n'est pas un substitut sûr.Instructions de connexion du programme de mise à jour pour un Y2 hors tensionNe connectez qu'au moment de l'invite.
