# Як установити Android 4.2 (Dev) на Innioasis Y1 - Innioasis Завантаження мікропрограми

Android 4.2 (Dev) · Innioasis Y1

# Установіть Android 4.2 (Dev) на Y1.

Android 4.2 — це розробка спільноти ROM для тестування та злому апаратного забезпечення Innioasis Y1. Виберіть Y1, перш ніж вибрати його в Updater CE.[Отримати Updater CE](../guide_uk.html#platform)[Отримайте це в Updater CE](../guide_uk.html?model=Y1&software=android-4-2-y1)[Джерело проекту](https://github.com/y1-community/y1-ata-rom)

Посібник із встановлення для вашого комп’ютера

## Установіть Android development ROM на Y1 разом із комп’ютером

Виберіть посібник для комп’ютера, яким ви користуєтеся. Кожна версія має налаштування платформи, Updater CE кроків і шлях повернення до запасу.[Керівництво по Windows](/install/android-4-2-y1-windows.html)[посібник з macOS](/install/android-4-2-y1-mac.html)[Керівництво по Linux](/install/android-4-2-y1-linux.html)

[Усі Innioasis Y1 посібники](/install/y1.html) · [Усі посібники з розробки Android ROM.](/install/android-dev.html)

## Встановіть його
  - Відкрийте Innioasis Updater CE на своєму комп’ютері (якщо у вас його ще немає, [Отримати Updater CE](../guide_uk.html#platform)). Виберіть Y1 в Модель пристрою.
  - Виберіть Android 4.2 (Dev) в Програмне забезпечення (або запустити за допомогою [Отримайте це в Updater CE](../guide_uk.html?model=Y1&software=android-4-2-y1)).
  - Виберіть випуск і натисніть Встановити / Відновити.
  - Вимкніть живлення та підключіть Y1 лише тоді, коли програма оновлення підкаже.
  - Використовуйте Y1 Заводське ПЗ для шляху відновлення.

## Примітка розробника щодо збіркиЗбірка розробника: Це зображення розробки, призначене для експериментів. Прочитайте примітки до випуску щодо поточної підтримки апаратного забезпечення та відомих проблем.Інструкції з підключення програми оновленняПідключайтеся лише за живою підказкою.
