Это маршрут Y1 для проекта JJ Launcher. Сначала выберите модель, чтобы программа обновлений не предложила неправильный пакет.[Скачать Updater CE](../guide_ru.html#platform)[Получите это в Updater CE](../guide_ru.html?model=Y1&software=jj-launcher-y1)[Почему JJ Launcher?](../jj-launcher-benefits_ru.html)

Руководство по установке для вашего компьютера

## Установите JJ Launcher на свой Y1 с помощью компьютера.

Выберите руководство для компьютера, который вы используете. В каждой версии есть настройка платформы, Updater CE шагов и возврат к стоку.[Руководство по Windows](/install/jj-launcher-y1-windows.html)[руководство по macOS](/install/jj-launcher-y1-mac.html)[Руководство по Linux](/install/jj-launcher-y1-linux.html)

[Все Innioasis Y1 руководства](/install/y1.html) · [Все JJ Launcher руководства](/install/jj-launcher.html)

## Выберите маршрут Y1
  - Откройте Innioasis Updater CE на своем компьютере (если у вас его еще нет, [Скачать Updater CE](../guide_ru.html#platform)). Выбирать Y1 в Модель устройства.
  - Выбирать JJ Launcher в Программное обеспечение (или запустить с помощью [Получите это в Updater CE](../guide_ru.html?model=Y1&software=jj-launcher-y1)).
  - Прочтите примечания к выпуску, выберите версию Y1 и нажмите Установить / Восстановить.
  - Выключайте и подключайте плеер только по запросу Updater.
  - Восстановить с помощью Y1 Заводское ПО если вам снова понадобится стандартный интерфейс.

## Несоответствие модели — первое, что нужно проверить

JJ Launcher также имеет запись Y2. Если имя пакета выглядит неправильно, вернитесь к модели устройства. Не навязывайте пакет Y2 пакету Y1.Инструкция по подключению обновленийПодключайтесь только по интерактивной подсказке.

## Вернуться к исходному программному обеспечению

JJ Launcher не меняет маршрут обратно на стандартный интерфейс. Как только программа обновлений будет настроена для вашего компьютера, откройте ее в Windows, macOS или Linux и выберите Y1 плюс Заводское ПО вместо JJ Launcher.
  - Выберите стабильную Y1 версию оригинального программного обеспечения.
  - Нажмите Установить / Восстановить и дождитесь приглашения на подключение к реальному времени.
  - Выключайте Y1 только по запросу.
  - Подключите USB-кабель для передачи данных по запросу и оставьте его до успешного завершения.

Не удаляйте сначала файлы JJ Launcher вручную и не используйте пакет Y2. Если сбой произошел до появления приглашения USB, сначала проверьте настройку компьютера, кабель и выбор модели.[Y1 руководство по восстановлению](restore-original-y1_ru.html)[Устранение неполадок](../troubleshooting_ru.html)
