# Instale Solar em seu Y2.

Solar é um projeto comunitário separado e há uma compilação Y2 listada. Os recursos podem mudar, então deixe o Updater mostrar a versão atual do seu modelo.[Obtenha o atualizador CE](../guide_pt.html#platform)[Obtenha isso em Updater CE](../guide_pt.html?model=Y2&software=solar-y2)[Por que Solar?](../solar-benefits_pt.html)

Também disponível: [Solar em Y1](solar-y1_pt.html)

Guia de instalação para o seu computador

## Instale Solar em seu Y2 com seu computador

Escolha o guia para o computador que você está usando. Cada versão possui a configuração da plataforma, Updater CE etapas e o caminho de volta ao estoque.[Guia do Windows](/install/solar-y2-windows.html)[guia macOS](/install/solar-y2-mac.html)[Guia Linux](/install/solar-y2-linux.html)

[Todos Innioasis Y2 guias](/install/y2.html) · [Todos Solar guias](/install/solar.html)

## Escolha a rota Y2
  - Abra Innioasis Updater CE no seu computador (se ainda não o tiver, [Obtenha o atualizador CE](../guide_pt.html#platform)). Selecione Y2 em Modelo do dispositivo.
  - Escolher Solar em Programas (ou lançar com [Obtenha isso em Updater CE](../guide_pt.html?model=Y2&software=solar-y2)).
  - Leia a nota de lançamento, confirme a entrada Y2 e clique Instalar / Restaurar.
  - Desligue e conecte o player somente quando o Updater solicitar.
  - Restaurar com Y2 Software Original se você precisar da interface de estoque novamente.

## Mantenha a nota do projeto à vista

Solar está em desenvolvimento ativo. Os recursos e o suporte do modelo podem mudar, portanto verifique as notas de lançamento do projeto. O atualizador mostra o que está disponível para o seu modelo no momento. Não substitua um pacote Y1 se a entrada Y2 estiver faltando.Instruções de conexão do atualizadorConecte-se apenas no prompt ao vivo.

## Volte para o software original

Solar não altera a rota de volta para a interface padrão. Assim que o Updater estiver configurado para o seu computador, abra-o no Windows, macOS ou Linux e selecione Y2 mais Software Original em vez de Solar.
  - Escolha uma versão de software original estável Y2.
  - Clique Instalar / Restaurar e aguarde o prompt de conexão ao vivo.
  - Desligue o Y2 somente quando solicitado.
  - Conecte o cabo de dados USB no prompt e deixe-o imóvel até obter sucesso.

Não remova manualmente os arquivos Solar primeiro e não use um pacote Y1. Se a falha ocorreu antes do prompt USB, verifique primeiro a configuração do computador, o cabo e a seleção do modelo.[Y2 guia de restauração](restore-original-y2_pt.html)[Solução de problemas](../troubleshooting_pt.html)
