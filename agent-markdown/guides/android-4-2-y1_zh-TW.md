Android 4.2（開發）·Innioasis Y1

# 在 Y1 上安裝 Android 4.2（開發版）。

Android 4.2 是一個社群開發 ROM，用於在 Innioasis Y1 硬體上進行測試和駭客攻擊。在 Updater CE 中選擇之前選擇 Y1。[取得 Updater CE](../guide_zh-TW.html#platform)[在 Updater CE 中取得此內容](../guide_zh-TW.html?model=Y1&software=android-4-2-y1)[專案來源](https://github.com/y1-community/y1-ata-rom)

適用於您的電腦的安裝指南

## 使用計算機在 Y1 上安裝 Android 開發 ROM

選擇適合您正在使用的計算機的指南。 每個版本都有平台設定、Updater CE步驟和返回庫存的方式。[Windows 指南](/install/android-4-2-y1-windows.html)[macOS 指南](/install/android-4-2-y1-mac.html)[Linux指南](/install/android-4-2-y1-linux.html)

[所有 Innioasis Y1 指南](/install/y1.html) · [所有 Android 開發 ROM 指南](/install/android-dev.html)

## 安裝它
  - 在您的電腦上開啟 Innioasis Updater CE（如果您還沒有， [取得 Updater CE](../guide_zh-TW.html#platform)）。選擇 Y1 在 裝置型號.
  - 選擇 Android 4.2（開發） 在 軟體 （或啟動 [在 Updater CE 中取得此內容](../guide_zh-TW.html?model=Y1&software=android-4-2-y1)).
  - 選擇一個版本並點擊 安裝 / 還原.
  - 僅當更新程式提示時關閉並連接 Y1。
  - 使用Y1 原廠軟體 為恢復路徑。
