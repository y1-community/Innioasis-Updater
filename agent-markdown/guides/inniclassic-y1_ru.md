# Как установить Inniclassic на загрузку прошивки Innioasis Y1 - Innioasis

Inniclassic · Innioasis Y1

# Установите Inniclassic на Y1.

Inniclassic указан как проект Y1. Прежде чем выбирать, выберите Y1 для того, чтобы список выпусков сохранял информацию о модели.[Скачать Updater CE](../guide_ru.html#platform)[Получите это в Updater CE](../guide_ru.html?model=Y1&software=inniclassic-y1)[Почему Inniclassic?](../inniclassic-benefits_ru.html)

Руководство по установке для вашего компьютера

## Установите Inniclassic на свой Y1 с помощью компьютера.

Выберите руководство для компьютера, который вы используете. В каждой версии есть настройка платформы, Updater CE шагов и возврат к стоку.[Руководство по Windows](/install/inniclassic-y1-windows.html)[руководство по macOS](/install/inniclassic-y1-mac.html)[Руководство по Linux](/install/inniclassic-y1-linux.html)

[Все Innioasis Y1 руководства](/install/y1.html) · [Все Inniclassic руководства](/install/inniclassic.html)

## Установите его
  - Откройте Innioasis Updater CE на своем компьютере (если у вас его еще нет, [Скачать Updater CE](../guide_ru.html#platform)). Выбирать Y1 в Модель устройства.
  - Выбирать Inniclassic в Программное обеспечение (или запустить с помощью [Получите это в Updater CE](../guide_ru.html?model=Y1&software=inniclassic-y1)).
  - Выберите выпуск и нажмите Установить / Восстановить.
  - Выключите и подключите Y1 только тогда, когда программа обновлений предложит вам это сделать.
  - Используйте Y1 Заводское ПО для пути восстановления.

## Держите соединение по-прежнемуИнструкция по подключению обновленийТочная подсказка может варьироваться в зависимости от платформы.

Если установка не удалась, обратите внимание, произошел ли сбой до или после того, как программа обновлений обнаружила проигрыватель. Эта деталь значительно ускоряет устранение неполадок.
