# Installeer Linux op een Y1.

Linux voor Y1 is een experimentele Linux-kernel en rootfs-poort voor de Innioasis Y1. Selecteer Y1 voordat u dit kiest in Updater CE.[Updater CE downloaden](../guide_nl.html#platform)[Ontvang dit in Updater CE](../guide_nl.html?model=Y1&software=linux-y1)[Projectbron](https://github.com/y1-community/y1-linux-rom)

## Installeer Linux voor Y1 (Dev) op uw Y1 met uw computer

Kies de handleiding voor de computer die u gebruikt. Elke versie heeft de platformconfiguratie, Updater CE stappen en de weg terug naar de voorraad.[Windows-gids](/install/linux-y1-windows.html)[macOS-gids](/install/linux-y1-mac.html)[Linux-gids](/install/linux-y1-linux.html)

[Alle Innioasis Y1-gidsen](/install/y1.html) · [Alle Linux voor Y1 (ontwikkelaars) handleidingen](/install/linux-dev.html)

## Installeer het
  - Open Innioasis Updater CE op uw computer (als u dit nog niet heeft, [Updater CE downloaden](../guide_nl.html#platform)). Selecteer Y1 binnen Apparaatmodel.
  - Kies Linux voor Y1 (ontwikkelaar) binnen Software (of start met [Ontvang dit in Updater CE](../guide_nl.html?model=Y1&software=linux-y1)).
  - Selecteer een release en klik Installeren / Herstellen.
  - Schakel de Y1 alleen uit en sluit deze alleen aan als Updater u daarom vraagt.
  - Gebruik Y1 Originele software voor het herstelpad.
