# Installez Inniclassic sur un Y1.

Inniclassic est répertorié comme un projet Y1. Sélectionnez Y1 avant de le choisir afin que la liste des versions reste adaptée au modèle.[Obtenir Updater CE](../guide_fr.html#platform)[Disponible dans Updater CE](../guide_fr.html?model=Y1&software=inniclassic-y1)[Pourquoi Inniclassic ?](../inniclassic-benefits_fr.html)

Guide d'installation pour votre ordinateur

## Installez Inniclassic sur votre Y1 avec votre ordinateur

Choisissez le guide correspondant à l'ordinateur que vous utilisez. Chaque version comprend la configuration de la plate-forme, Updater CE étapes et le chemin de retour au stock.[Guide Windows](/install/inniclassic-y1-windows.html)[Guide macOS](/install/inniclassic-y1-mac.html)[Guide Linux](/install/inniclassic-y1-linux.html)

[Tous les guides Innioasis Y1](/install/y1.html) · [Tous les guides Inniclassic](/install/inniclassic.html)

## Installez-le
  - Ouvrez Innioasis Updater CE sur votre ordinateur (si vous ne l'avez pas encore, [Obtenir Updater CE](../guide_fr.html#platform)). Sélectionnez Y1 dans Modèle d'appareil.
  - Choisissez Inniclassic dans Logiciel (ou lancer avec [Disponible dans Updater CE](../guide_fr.html?model=Y1&software=inniclassic-y1)).
  - Sélectionnez une version et cliquez sur Installer / Restaurer.
  - Éteignez et connectez le Y1 uniquement lorsque le programme de mise à jour vous y invite.
  - Utiliser Y1 Logiciel d'origine pour le chemin de restauration.

## Gardez toujours la connexionInstructions de connexion à UpdaterL'invite exacte peut varier selon la plate-forme.

Si l'installation échoue, notez si l'échec s'est produit avant ou après que le programme de mise à jour ait détecté le lecteur. Ce détail rend le dépannage beaucoup plus rapide.
