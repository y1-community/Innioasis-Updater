Koensayr wird als Y1-Projekt aufgeführt. ## Installieren Sie Koensayr auf Ihrem Y1 mit Ihrem Computer

Wählen Sie die Anleitung für den Computer aus, den Sie verwenden. Jede Version verfügt über das Plattform-Setup, Updater CE Schritte und den Weg zurück zum Lagerbestand.[Windows-Anleitung](/install/koensayr-y1-windows.html)[macOS-Anleitung](/install/koensayr-y1-mac.html)[Linux-Anleitung](/install/koensayr-y1-linux.html)

[Alle Innioasis Y1-Anleitungen](/install/y1.html) · [Alle Koensayr Anleitungen](/install/koensayr.html)

## Schritte installieren
  - Öffnen Sie Innioasis Updater CE auf Ihrem Computer (falls Sie es noch nicht haben, [Updater CE holen](../guide_de.html#platform)). Auswählen Y1 In Gerätemodell.
  - Wählen Sie Koensayr In Software (oder starten Sie mit [In Updater CE erhalten](../guide_de.html?model=Y1&software=koensayr-y1)).
  - Wählen Sie die aufgelistete Version aus und klicken Sie auf Installieren / Wiederherstellen.
  - Schalten Sie das Y1 nur aus und schließen Sie es an, wenn die App Sie dazu auffordert.
  - Verwenden Sie Y1 Original-Software um den Aktienpfad wiederherzustellen.

## Wenn etwas scheitert

Überprüfen Sie zunächst die Modell- und Typauswahl. Überprüfen Sie dann das Kabel und ob der Player vor der Aufforderung angeschlossen war. Wenn die App gestoppt wurde, bevor sie auf USB gewartet hat, öffnen Sie sie [Fehlerbehebung](../troubleshooting_de.html).Anweisungen zum Verbinden mit UpdaterEine stabile Verbindung ist Teil der Installation.
