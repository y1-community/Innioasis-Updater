# Originalsoftware auf Innioasis & Timmkoo A5 wiederherstellen

Befolgen Sie dieses Tutorial, um die offizielle Werkssoftware auf Ihrem Innioasis A5- oder Timmkoo A5-Player mit verifizierten Paketen aus dem Innioasis-Firmware-Archiv wiederherzustellen.[Updater CE holen](../guide_de.html#platform)[A5 Downloads anzeigen](../firmware_de.html?model=A5)

## Schritt 1: Einrichtung in Updater CE
  - Starten Innioasis Updater CE auf Ihrem Windows-, macOS- oder Linux-Computer.
  - Satz Gerätemodell an A5.
  - Auswählen Original-Software. Updater CE lädt den offiziellen herunter `rom_a5.zip` Paket direkt freigeben.
  - Klicken Sie Installieren / Wiederherstellen und warten Sie, bis die Vorbereitung abgeschlossen ist.

## Schritt 2: Stellen Sie an der Eingabeaufforderung eine Verbindung her
  - Schalten Sie das A5-Gerät vollständig aus.
  - Warten Sie auf die Eingabeaufforderung auf Ihrem Computerbildschirm, bevor Sie das Datenkabel USB anschließen.
  - Lassen Sie den Flash-Vorgang ohne Unterbrechung abschließen.
  - Trennen Sie Ihren frisch wiederhergestellten A5-Player und starten Sie ihn neu.
