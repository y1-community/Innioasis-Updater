# Comment installer JJ Launcher sur votre Innioasis Y1 ou Y2 - Innioasis Téléchargements de micrologiciels

JJ Launcher · Y1 et Y2

# Installez JJ Launcher après avoir choisi le modèle.

Le nom du projet est partagé, mais le package disponible dépend toujours du fait que votre lecteur soit un Y1 ou un Y2. Choisissez votre modèle ci-dessous et le guide correspondra au package.[Obtenir Updater CE](../guide_fr.html#platform)[JJ Launcher le Y1](jj-launcher-y1_fr.html)[JJ Launcher sur Y2](jj-launcher-y2_fr.html)

## Quel guide dois-je utiliser ?

Les lecteurs Y1 et Y2 installent JJ Launcher via Innioasis Updater CE (si vous avez besoin de l'application, [Obtenir Updater CE](../guide_fr.html#platform) pour votre PC, ou lancez-le avec [Disponible dans Updater CE](../guide_fr.html?model=Y1&software=jj-launcher-y1)). Choisissez votre modèle ci-dessous :

### Innioasis Y1

Suivez l'itinéraire Y1 spécifique au modèle et conservez le package Y1 sélectionné.[Y1 étapes d'installation](jj-launcher-y1_fr.html)

### Innioasis Y2

Suivez l'itinéraire Y2 spécifique au modèle et conservez le package Y2 sélectionné.[Y2 étapes d'installation](jj-launcher-y2_fr.html)
