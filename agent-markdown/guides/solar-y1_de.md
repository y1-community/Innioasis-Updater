# Installieren Sie Solar auf Ihrem Y1.

Solar ist ein separates Community-Softwareprojekt. Verfügbarkeit und Funktionen können sich ändern. Lassen Sie Updater daher die aktuelle Version für Ihr Modell anzeigen.[Updater CE holen](../guide_de.html#platform)[In Updater CE erhalten](../guide_de.html?model=Y1&software=solar-y1)[Warum Solar?](../solar-benefits_de.html)

Auch erhältlich: [Solar am Y2](solar-y2_de.html)

Installationsanleitung für Ihren Computer

## Installieren Sie Solar auf Ihrem Y1 mit Ihrem Computer

Wählen Sie die Anleitung für den Computer aus, den Sie verwenden. Jede Version verfügt über das Plattform-Setup, Updater CE Schritte und den Weg zurück zum Lagerbestand.[Windows-Anleitung](/install/solar-y1-windows.html)[macOS-Anleitung](/install/solar-y1-mac.html)[Linux-Anleitung](/install/solar-y1-linux.html)

[Alle Innioasis Y1-Anleitungen](/install/y1.html) · [Alle Solar Anleitungen](/install/solar.html)

## Wählen Sie die Route Y1.
  - Öffnen Sie Innioasis Updater CE auf Ihrem Computer (falls Sie es noch nicht haben, [Updater CE holen](../guide_de.html#platform)). Auswählen Y1 In Gerätemodell.
  - Wählen Sie Solar In Software (oder starten Sie mit [In Updater CE erhalten](../guide_de.html?model=Y1&software=solar-y1)).
  - Lesen Sie die Versionshinweise, wählen Sie eine Version aus und klicken Sie Installieren / Wiederherstellen.
  - Schalten Sie den Player nur aus und schließen Sie ihn an, wenn der Updater Sie dazu auffordert.
  - Wiederherstellen mit Y1 Original-Software wenn Sie die Standardschnittstelle erneut benötigen.

## Behalten Sie die Projektnotiz im Blick

Solar befindet sich in der aktiven Entwicklung. Funktionen und Modellunterstützung können sich ändern. Sehen Sie sich daher die Versionshinweise des Projekts an. Der Updater zeigt, was derzeit für Ihr Modell verfügbar ist.Anweisungen zum Verbinden mit UpdaterErst verbinden, wenn die Aufforderung erscheint.

## Gehen Sie zurück zur Originalsoftware

Solar ändert die Route zurück zur Standardschnittstelle nicht. Sobald Updater für Ihren Computer eingerichtet ist, öffnen Sie es unter Windows, macOS oder Linux und wählen Sie Y1 Plus Original-Software statt Solar.
  - Wählen Sie eine stabile Y1 Originalsoftwareversion.
  - Klicken Sie Installieren / Wiederherstellen und warten Sie auf die Live-Verbindungsaufforderung.
  - Schalten Sie Y1 nur aus, wenn Sie dazu aufgefordert werden.
  - Schließen Sie bei der Aufforderung das USB-Datenkabel an und lassen Sie es bis zum Erfolg ruhen.

Entfernen Sie nicht zuerst Solar-Dateien manuell und verwenden Sie kein Y2-Paket. Wenn der Fehler vor der Eingabeaufforderung USB aufgetreten ist, überprüfen Sie zunächst die Computerkonfiguration, das Kabel und die Modellauswahl.[Y1-Wiederherstellungsanleitung](restore-original-y1_de.html)[Fehlerbehebung](../troubleshooting_de.html)
