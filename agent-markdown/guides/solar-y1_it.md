# Installa Solar sul tuo Y1.

Solar è un progetto software comunitario separato. La disponibilità e le funzionalità possono cambiare, quindi lascia che Updater mostri la versione corrente per il tuo modello.[Ottieni Updater CE](../guide_it.html#platform)[Ottieni questo in Updater CE](../guide_it.html?model=Y1&software=solar-y1)[Perché Solar?](../solar-benefits_it.html)

Disponibile anche: [Solar su Y2](solar-y2_it.html)

Guida all'installazione per il tuo computer

## Installa Solar sul tuo Y1 con il tuo computer

Scegli la guida per il computer che stai utilizzando. Ogni versione ha la configurazione della piattaforma, Updater CE passaggi e il modo per tornare allo stock.[Guida Windows](/install/solar-y1-windows.html)[guida macOS](/install/solar-y1-mac.html)[Guida Linux](/install/solar-y1-linux.html)

[Tutte le Innioasis Y1 guide](/install/y1.html) · [Tutte le Solar guide](/install/solar.html)

## Scegli il percorso Y1.
  - Apri Innioasis Updater CE sul tuo computer (se non lo hai ancora, [Ottieni Updater CE](../guide_it.html#platform)). Seleziona Y1 dentro Modello del dispositivo.
  - Scegli Solar dentro Software (o avvia con [Ottieni questo in Updater CE](../guide_it.html?model=Y1&software=solar-y1)).
  - Leggere la nota di rilascio, selezionare una versione e fare clic Installa / Ripristina.
  - Spegnere e collegare il lettore solo quando richiesto dall'Updater.
  - Ripristina con Y1 Software originale se hai bisogno di nuovo dell'interfaccia stock.

## Tieni in vista la nota del progetto

Solar è in fase di sviluppo attivo. Le funzionalità e il supporto del modello possono cambiare, quindi controlla le note di rilascio del progetto. Updater mostra cosa è disponibile per il tuo modello in questo momento.Istruzioni per la connessione dell'aggiornamentoConnettiti solo al prompt live.

## Torna al software originale

Solar non modifica il percorso di ritorno all'interfaccia stock. Una volta configurato Updater per il tuo computer, aprilo su Windows, macOS o Linux e seleziona Y1 inoltre Software originale invece di Solar.
  - Scegli una versione stabile del software originale Y1 .
  - Fare clic Installa / Ripristina e attendi la richiesta di connessione live.
  - Spegnere il Y1 solo quando richiesto.
  - Collegare il cavo dati USB quando richiesto e lasciarlo fermo fino al successo.

Non rimuovere prima manualmente i file Solar e non utilizzare un pacchetto Y2. Se l'errore si è verificato prima della richiesta USB, controllare prima la configurazione del computer, il cavo e la selezione del modello.[Guida al ripristino Y1](restore-original-y1_it.html)[Risoluzione dei problemi](../troubleshooting_it.html)
