## O que você precisa

Um Innioasis Y1, uma bateria carregada, um USB cabo de dados e um computador com Innioasis Updater CE instalado (se você ainda não o instalou, [Obtenha o atualizador CE](../guide_pt.html#platform) para Windows, macOS ou Linux). Type A é adequado para Y1 jogadores que acompanham o software original versão 2.0.0 ou posterior; Type B é adequado para jogadores que acompanham uma versão anterior do [Software Original](../firmware_pt.html?software=original-y1). Comece com Type A, a menos que você já saiba que seu player precisa de uma construção Type B.

## No atualizador
  - Abra Updater CE (ou inicie com [Obtenha isso em Updater CE](../guide_pt.html?model=Y1&software=rockbox-y1)) e definir Modelo do dispositivo para Y1.
  - Escolher Rockbox em Programas. O rótulo exato do projeto pode aparecer como Rockbox-Y1 nos dados de lançamento.
  - Escolha uma versão estável. As compilações de 240p têm a mais ampla compatibilidade de temas mais antigos; As compilações em 360p destinam-se ao caminho do tema Y1. Verifique as notas de lançamento quando a distinção for importante.
  - Clique Instalar / Restaurar. Aguarde enquanto Updater CE baixa o pacote diretamente do lançamento do desenvolvedor da comunidade e o prepara.

## Conecte o Y1
  - Espere até que o Updater solicite o player.
  - Desligue o Y1 totalmente. Se não desligar, use as instruções de recuperação mostradas pelo Updater.
  - Conecte o cabo de dados USB somente quando o aplicativo solicitar. Abaixe o player e não perturbe a conexão.
  - Desconecte somente depois que o Updater confirmar o sucesso e inicie o Y1.
Instruções de conexão do atualizadorO texto da conexão pode variar de acordo com a plataforma. Siga o prompt ao vivo.

## Retornar ao software original

Rockbox não bloqueia você no software personalizado. Depois que o Updater estiver configurado para o seu computador, use-o no Windows, macOS ou Linux: selecione Y1, escolher Software Originale corra Instalar / Restaurar.
  - Aguarde até que o Updater termine de preparar o pacote de estoque.
  - Desligue o Y1 quando o aplicativo solicitar.
  - Conecte o cabo de dados USB somente no prompt ao vivo.
  - Deixe o player imóvel até a mensagem de sucesso.

Não use o pacote Y2 e não exclua manualmente os arquivos Rockbox antes da restauração. Para o comportamento da roda Type B, verifique a variante de versão correspondente antes de alterar o tipo de dispositivo.[Y1 guia de restauração](restore-original-y1_pt.html)[Solução de problemas](../troubleshooting_pt.html)
