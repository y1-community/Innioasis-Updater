# 恢復 Innioasis Y1 - Innioasis 韌體下載上的原始軟體

恢復·Innioasis Y1

# 返回原始軟體的清晰路線。

當您想要離開自訂軟體、恢復無法啟動的播放器或只是返回原始介面時，請使用此功能。[取得 Updater CE](../guide_zh-TW.html#platform)[在 Updater CE 中取得此內容](../guide_zh-TW.html?model=Y1&software=original-y1)[瀏覽Y1軟體](../firmware_zh-TW.html#y1)

適用於您的電腦的安裝指南

## 使用電腦復原 Y1 上的原始軟體

選擇適合您正在使用的計算機的指南。 每個版本都有平台設定、Updater CE步驟和返回庫存的方式。[Windows 指南](/install/original-y1-windows.html)[macOS 指南](/install/original-y1-mac.html)[Linux指南](/install/original-y1-linux.html)

[所有 Innioasis Y1 指南](/install/y1.html) · [所有原始軟體指南](/install/original-software.html)

## 來自 Rockbox 或其他自訂軟體

一旦相關的 Windows、macOS 或 Linux 設定準備就緒，更新程式就會使用與自訂軟體安裝相同的指導安裝進行庫存恢復。您無需先手動移除Rockbox或其他自訂軟體的檔案。
  - 在您的電腦上開啟 Innioasis Updater CE（如果您尚未安裝， [取得 Updater CE](../guide_zh-TW.html#platform) 為了 [窗戶](../drivers_zh-TW.html#windows), [macOS](../guide_zh-TW.html#macos), 或 [Linux](../drivers_zh-TW.html#linux)).
  - 套裝 裝置型號 到 Y1.
  - 選擇 原廠軟體 在 軟體 （或使用 [在 Updater CE 中取得此內容](../guide_zh-TW.html?model=Y1&software=original-y1)).
  - 選擇最新的穩定 Y1 版本。通常的手動包是 `rom.zip`。 Type A 涵蓋隨原始軟體版本 2.0.0 或更高版本一起提供的 Y1 個播放器； Type B 涵蓋了附帶早期版本的播放器 [原廠軟體](../firmware_zh-TW.html?software=original-y1) 並且可以使用更具體的套件名稱。
  - 點選 安裝 / 還原 並等待包解壓縮。
更新程式顯示 Y1 原始軟體選擇更新程式顯示 Y1 原始軟體選擇。

## 根據提示連接 Y1

作業系統更改更新程式周圍的設置，而不是恢復過程本身。在每個平台上，在連接之前等待即時提示。
  - 當更新程式要求時，請完全關閉播放器電源。
  - 僅在出現提示時連接 USB 資料線。
  - 安裝運作時請勿觸摸播放器。
  - 收到成功訊息後斷開連線並啟動 Y1。

## 如果仍然沒有啟動

在檢查型號、類型和版本的情況下重複恢復一次。如果更新程式在出現 USB 提示之前失敗，請檢查電腦設定、驅動程式或權限、資料線和擷取的檔案。如果偵測到Y1後失敗，則使用 [故障排除指南](../troubleshooting_zh-TW.html) 在進行手動 SP Flash Tool 或 MTKClient 恢復之前。不要切換到 Y2 檔案。 Y1 復原需要 Y1 原始軟體版本，即使播放器目前正在執行不同的自訂軟體。
