# 如何在 Innioasis Y2 - Innioasis 上安裝 Inniclassic 韌體下載

Inniclassic · Innioasis Y2

# 在 Y2 上安裝 Inniclassic。

Inniclassic 有一个由 Jonasz Potoniec 维护的专用 Y2 端口。在選擇之前先選擇 Y2，以便版本清單保持模型感知。[取得 Updater CE](../guide_zh-TW.html#platform)[在 Updater CE 中取得此內容](../guide_zh-TW.html?model=Y2&software=inniclassic-y2)[為什麼是Inniclassic？](../inniclassic-benefits_zh-TW.html)

適用於您的電腦的安裝指南

## 使用計算機在 Y2 上安裝 Inniclassic

選擇適合您正在使用的計算機的指南。 每個版本都有平台設定、Updater CE步驟和返回庫存的方式。[Windows 指南](/install/inniclassic-y2-windows.html)[macOS 指南](/install/inniclassic-y2-mac.html)[Linux指南](/install/inniclassic-y2-linux.html)

[所有 Innioasis Y2 指南](/install/y2.html) · [所有 Inniclassic 指南](/install/inniclassic.html)

## 安裝它
  - 在您的電腦上開啟 Innioasis Updater CE（如果您還沒有， [取得 Updater CE](../guide_zh-TW.html#platform)）。選擇 Y2 在 裝置型號.
  - 選擇 Inniclassic 在 軟體 （或啟動 [在 Updater CE 中取得此內容](../guide_zh-TW.html?model=Y2&software=inniclassic-y2)).
  - 選擇一個版本並點擊 安裝 / 還原.
  - 僅當更新程式提示您時，請關閉電源並連接 Y2。
  - 使用Y2 原廠軟體 為恢復路徑。

## 保持連線不變更新器連線說明僅在即時提示時連接。

Y2 包使用 `rom_y2.zip`。如果安裝失敗，請注意失敗是發生在 Updater 偵測到播放器之前還是之後。
