# Originele software herstellen op Innioasis en Timmkoo A5

Volg deze tutorial om de officiële fabriekssoftware te herstellen op uw Innioasis A5 of Timmkoo A5 speler met geverifieerde pakketten uit het Innioasis Firmware-archief.[Updater CE downloaden](../guide_nl.html#platform)[Bekijk A5 downloads](../firmware_nl.html?model=A5)

## Stap 1: Installatie in Updater CE
  - Lancering Innioasis Updater CE op uw Windows-, macOS- of Linux-computer.
  - Instellen Apparaatmodel aan A5.
  - Selecteer Originele software. Updater CE downloadt de officiële `rom_a5.zip` pakket direct vrijgeven.
  - Klik Installeren / Herstellen en wacht tot de voorbereiding is voltooid.

## Stap 2: Maak verbinding via de prompt
  - Schakel het A5-apparaat volledig uit.
  - Wacht op de melding op uw computerscherm voordat u de USB-datakabel aansluit.
  - Laat het knipperproces zonder onderbreking eindigen.
  - Ontkoppel uw zojuist herstelde A5-speler en start deze opnieuw op.
