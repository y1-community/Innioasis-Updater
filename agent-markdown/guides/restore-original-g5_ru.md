# Восстановить исходное программное обеспечение на Innioasis G5

Используйте это руководство, если вам нужно восстановить не отвечающую G5, обновить систему до заводского состояния или установить чистые официальные обновления прошивки.[Скачать Updater CE](../guide_ru.html#platform)[Посмотреть G5 загрузок](../firmware_ru.html?model=G5)

## Восстановите оригинальное программное обеспечение на вашем G5 с помощью компьютера.

Выберите руководство для компьютера, который вы используете. В каждой версии есть настройка платформы, Updater CE шагов и возврат к стоку.[Руководство по Windows](/install/original-g5-windows.html)[руководство по macOS](/install/original-g5-mac.html)[Руководство по Linux](/install/original-g5-linux.html)

[Все руководства Innioasis G5](/install/g5.html) · [Все руководства по оригинальному программному обеспечению](/install/original-software.html)

## Шаг 1. Подготовьте свой компьютер

Innioasis Updater CE изначально работает на Windows, macOS и Linux, не требуя сложных средств перепрошивки:
  - Запуск Innioasis Программа обновления CE на вашем настольном компьютере или ноутбуке.
  - Набор Модель устройства в адрес G5.
  - Выбирать Заводское ПО в раскрывающемся списке программного обеспечения. Программа обновлений CE автоматически загружает официальную `rom_g5.zip` выпустить пакет напрямую.
  - Нажмите Установить / Восстановить начать подготовку.

## Шаг 2. Подключите G5 в командной строке

Никогда не подключайте плеер до того, как приложение предложит вам:
  - Убедитесь, что ваш Innioasis G5 полностью выключен.
  - Когда программа обновлений отобразит запрос на подключение USB, подключите кабель для передачи данных USB-C к компьютеру и плееру.
  - Не прикасайтесь к кабелю или кнопкам питания во время прошивки.
  - Как только появится подтверждение успеха, отсоедините кабель USB и включите питание G5.
