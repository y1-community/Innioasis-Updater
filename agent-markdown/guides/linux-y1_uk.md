# Встановіть Linux на Y1.

Linux для Y1 — це експериментальне ядро ​​Linux спільноти та порт rootfs для Innioasis Y1. Виберіть Y1, перш ніж вибрати його в Updater CE.[Отримати Updater CE](../guide_uk.html#platform)[Отримайте це в Updater CE](../guide_uk.html?model=Y1&software=linux-y1)[Джерело проекту](https://github.com/y1-community/y1-linux-rom)

Посібник із встановлення для вашого комп’ютера

## Встановіть Linux для Y1 (Dev) на Y1 разом із комп’ютером

Виберіть посібник для комп’ютера, яким ви користуєтеся. Кожна версія має налаштування платформи, Updater CE кроків і шлях повернення до запасу.[Керівництво по Windows](/install/linux-y1-windows.html)[посібник з macOS](/install/linux-y1-mac.html)[Керівництво по Linux](/install/linux-y1-linux.html)

[Усі Innioasis Y1 посібники](/install/y1.html) · [Усі посібники з Linux для Y1 (Dev).](/install/linux-dev.html)

## Встановіть його
  - Відкрийте Innioasis Updater CE на своєму комп’ютері (якщо у вас його ще немає, [Отримати Updater CE](../guide_uk.html#platform)). Виберіть Y1 в Модель пристрою.
  - Виберіть Linux для Y1 (Dev) в Програмне забезпечення (або запустити за допомогою [Отримайте це в Updater CE](../guide_uk.html?model=Y1&software=linux-y1)).
  - Виберіть випуск і натисніть Встановити / Відновити.
  - Вимкніть живлення та підключіть Y1 лише тоді, коли програма оновлення підкаже.
  - Використовуйте Y1 Заводське ПЗ для шляху відновлення.
