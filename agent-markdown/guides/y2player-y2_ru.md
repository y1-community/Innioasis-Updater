# Установите Y2Player на Y2.

Y2Player — это проект Y2. Безопасный путь начинается с выбора модели, а не с названия проекта.[Скачать Updater CE](../guide_ru.html#platform)[Получите это в Updater CE](../guide_ru.html?model=Y2&software=y2player-y2)[Почему Y2Player?](../y2player-benefits_ru.html)

Руководство по установке для вашего компьютера

## Установите Y2Player на свой Y2 с помощью компьютера.

Выберите руководство для компьютера, который вы используете. В каждой версии есть настройка платформы, Updater CE шагов и возврат к стоку.[Руководство по Windows](/install/y2player-y2-windows.html)[руководство по macOS](/install/y2player-y2-mac.html)[Руководство по Linux](/install/y2player-y2-linux.html)

[Все Innioasis Y2 руководства](/install/y2.html) · [Все Y2Player руководства](/install/y2player.html)

## В программе обновлений
  - Откройте Innioasis Updater CE на своем компьютере (если у вас его еще нет, [Скачать Updater CE](../guide_ru.html#platform)). Выбирать Y2 в Модель устройства.
  - Выбирать Y2Player в Программное обеспечение (или запустить с помощью [Получите это в Updater CE](../guide_ru.html?model=Y2&software=y2player-y2)).
  - Выберите указанный выпуск Y2.
  - Нажмите Установить / Восстановить, выключите питание при появлении запроса и подключите USB по запросу.
  - Восстановить с помощью Y2 Заводское ПО если необходимо.

## Не заменяйте пакет Y1Проверьте дважды: Y2 пакеты полной установки могут использовать `rom_y2.zip`. Простой пакет Y1 не является безопасной заменой.Инструкция по подключению апдейтера при выключенном Y2Подключайтесь только по интерактивной подсказке.
