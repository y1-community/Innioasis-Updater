# 如何在 Innioasis Y1 或 Y2 上安裝 JJ Launcher - Innioasis 韌體下載

JJ Launcher · Y1 和 Y2

# 選擇型號後安裝JJ Launcher。

項目名稱是共享的，但可用的套件仍然取決於您的播放器是Y1還是Y2。在下面選擇您的型號，指南將與包裝相匹配。[取得 Updater CE](../guide_zh-TW.html#platform)[Y1 上的 JJ Launcher](jj-launcher-y1_zh-TW.html)[Y2 上的 JJ Launcher](jj-launcher-y2_zh-TW.html)

## 我應該使用哪一個指南？

Y1 和 Y2 玩家都透過 Innioasis 更新程式 CE 安裝 JJ Launcher（如果您需要該應用程序， [取得 Updater CE](../guide_zh-TW.html#platform) 對於您的 PC，或啟動 [在 Updater CE 中取得此內容](../guide_zh-TW.html?model=Y1&software=jj-launcher-y1)）。在下面選擇您的型號：

### Innioasis Y1

遵循模型特定的 Y1 路線並保持選取 Y1 套件。[Y1安裝步驟](jj-launcher-y1_zh-TW.html)

### Innioasis Y2

遵循模型特定的 Y2 路線並保持選取 Y2 套件。[Y2安裝步驟](jj-launcher-y2_zh-TW.html)
