# Instala Reborn (Y2Linux) en tu Innioasis Y2.

Sigue estos pasos para flashear Reborn (Y2Linux / Y2Reborn) en un Innioasis Y2 usando Innioasis Updater CE, luego finalice la configuración de Wi-Fi y Bluetooth posterior a la instalación.[Obtener Updater CE](../guide_es.html#download-updater)[¿Por qué Reborn (Y2Linux)?](../reborn-y2linux-benefits_es.html)[Y2Reborn Lanzamientos](../firmware_es.html?model=Y2&software=reborn-y2linux-y2)

Guía de instalación para su computadora

## Instala Reborn (Y2Linux) en tu Y2 con tu computadora

Elija la guía para la computadora que está utilizando. Cada versión tiene la configuración de la plataforma, Updater CE pasos y el camino de regreso al stock.[guía de windows](/install/reborn-y2linux-y2-windows.html)[guía de macos](/install/reborn-y2linux-y2-mac.html)[guía de linux](/install/reborn-y2linux-y2-linux.html)

[Todas las Innioasis Y2 guías](/install/y2.html) · [Todas las guías Reborn (Y2Linux)](/install/reborn.html)

## Instalación paso a paso
  - Instale el actualizador CE: Descargar [Innioasis Actualizador CE](../guide_es.html) para Windows, macOS o Linux, luego ábralo.
  - Seleccione Y2: elegir Y2 como modelo del dispositivo.
  - Seleccione Reborn: elegir Reborn (Y2Linux) y la última versión.
  - Instalar: Haga clic Instalar / Restaurar, apague el Y2 y conecte USB cuando se le solicite.
  - Esperar: Mantenga el reproductor quieto hasta que Updater CE lo confirme, luego desconéctelo.
  - Configurar Wi-Fi, Bluetooth y radio FM

Copiar `system.img` al jugador una vez. Reborn hace el resto.[Finalizar configuración →](../y2reborn_wifibt_es.html)

## Regresar al software original

Puede devolver su Y2 al software de fábrica en cualquier momento eligiendo Y2 y Software original en el Actualizador CE. Ver el [Y2 restaurar tutorial](restore-original-y2_es.html).
