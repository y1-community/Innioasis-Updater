# 如何在 Innioasis Y1 或 Y2 上安装 JJ Launcher - Innioasis 固件下载

JJ Launcher · Y1 和 Y2

# 选择型号后安装JJ Launcher。

项目名称是共享的，但可用的包仍然取决于您的播放器是Y1还是Y2。在下面选择您的型号，指南将与包装相匹配。[获取 Updater CE](../guide_zh-CN.html#platform)[Y1 上的 JJ Launcher](jj-launcher-y1_zh-CN.html)[Y2 上的 JJ Launcher](jj-launcher-y2_zh-CN.html)

## 我应该使用哪个指南？

Y1 和 Y2 玩家都通过 Innioasis 更新程序 CE 安装 JJ Launcher（如果您需要该应用程序， [获取 Updater CE](../guide_zh-CN.html#platform) 对于您的 PC，或启动 [在 Updater CE 中获取](../guide_zh-CN.html?model=Y1&software=jj-launcher-y1)）。在下面选择您的型号：

### Innioasis Y1

遵循模型特定的 Y1 路线并保持选中 Y1 包。[Y1安装步骤](jj-launcher-y1_zh-CN.html)

### Innioasis Y2

遵循模型特定的 Y2 路线并保持选中 Y2 包。[Y2安装步骤](jj-launcher-y2_zh-CN.html)
