## Installieren Sie JJ Launcher auf Ihrem Y1 mit Ihrem Computer

Wählen Sie die Anleitung für den Computer aus, den Sie verwenden. Jede Version verfügt über das Plattform-Setup, Updater CE Schritte und den Weg zurück zum Lagerbestand.[Windows-Anleitung](/install/jj-launcher-y1-windows.html)[macOS-Anleitung](/install/jj-launcher-y1-mac.html)[Linux-Anleitung](/install/jj-launcher-y1-linux.html)

[Alle Innioasis Y1-Anleitungen](/install/y1.html) · [Alle JJ Launcher Anleitungen](/install/jj-launcher.html)

## Wählen Sie die Route Y1.
  - Öffnen Sie Innioasis Updater CE auf Ihrem Computer (falls Sie es noch nicht haben, [Updater CE holen](../guide_de.html#platform)). Auswählen Y1 In Gerätemodell.
  - Wählen Sie JJ Launcher In Software (oder starten Sie mit [In Updater CE erhalten](../guide_de.html?model=Y1&software=jj-launcher-y1)).
  - Lesen Sie die Versionshinweise, wählen Sie die Version Y1 aus und klicken Sie Installieren / Wiederherstellen.
  - Schalten Sie den Player nur aus und schließen Sie ihn an, wenn der Updater Sie dazu auffordert.
  - Wiederherstellen mit Y1 Original-Software wenn Sie die Standardschnittstelle erneut benötigen.

## Die Nichtübereinstimmung der Modelle ist das erste, was überprüft werden muss

JJ Launcher hat auch einen Y2-Eintrag. Wenn der Paketname falsch aussieht, kehren Sie zum Gerätemodell zurück. Erzwingen Sie kein Y2-Paket auf einem Y1.Anweisungen zum Verbinden mit UpdaterErst verbinden, wenn die Aufforderung erscheint.

## Gehen Sie zurück zur Originalsoftware

JJ Launcher ändert die Route zurück zur Standardschnittstelle nicht. Sobald Updater für Ihren Computer eingerichtet ist, öffnen Sie es unter Windows, macOS oder Linux und wählen Sie Y1 Plus Original-Software statt JJ Launcher.
  - Wählen Sie eine stabile Y1 Originalsoftwareversion.
  - Klicken Sie Installieren / Wiederherstellen und warten Sie auf die Live-Verbindungsaufforderung.
  - Schalten Sie Y1 nur aus, wenn Sie dazu aufgefordert werden.
  - Schließen Sie bei der Aufforderung das USB-Datenkabel an und lassen Sie es bis zum Erfolg ruhen.

Entfernen Sie nicht zuerst JJ Launcher-Dateien manuell und verwenden Sie kein Y2-Paket. Wenn der Fehler vor der Eingabeaufforderung USB aufgetreten ist, überprüfen Sie zunächst die Computerkonfiguration, das Kabel und die Modellauswahl.[Y1-Wiederherstellungsanleitung](restore-original-y1_de.html)[Fehlerbehebung](../troubleshooting_de.html)
