Выберите руководство для компьютера, который вы используете. В каждой версии есть настройка платформы, Updater CE шагов и возврат к стоку.[Руководство по Windows](/install/rondo-y1-windows.html)[руководство по macOS](/install/rondo-y1-mac.html)[Руководство по Linux](/install/rondo-y1-linux.html)

## Пошаговая установка
  - Откройте программу обновлений CE: Запуск [Innioasis Программа обновления CE](../guide_ru.html) на вашем компьютере с Windows, macOS или Linux.
  - Выберите модель устройства Y1: Выбирать Y1 в раскрывающемся списке «Модель устройства» (выберите Type B, если ваше Y1 поставляется с исходным программным обеспечением более ранней версии, чем 2.0.0; в противном случае сохраните Type A).
  - Выберите Rondo в раскрывающемся списке «Программное обеспечение»: Выбирать Rondo в списке Программное обеспечение и выберите последнюю версию. Программа обновлений CE автоматически использует базовый канал Wi-Fi Android 4.2 ROM и Rondo.
  - Прошить плеер: Нажмите Установить / Восстановить, полностью отключите питание Y1 и подключите его через кабель для передачи данных USB, когда вам будет предложено Updater CE.
  - Отключите и загрузитесь: Дождитесь зеленого сообщения о завершении, прежде чем отключать Y1.
  - Полная настройка после установки
