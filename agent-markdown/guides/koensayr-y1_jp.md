# Innioasis Y1 - Innioasis ファームウェアのダウンロードに Koensayr をインストールする方法

Koensayr · Innioasis Y1

# Koensayr を Y1 にインストールします。

Koensayr は Y1 プロジェクトとしてリストされています。 Updater にパッケージを管理させてから、他の完全インストールと同じように慎重に電源を切り、USB のタイミングに従います。[Updater CE を入手](../guide_jp.html#platform)[Updater CE で入手](../guide_jp.html?model=Y1&software=koensayr-y1)[なぜKoensayr?](../koensayr-benefits_jp.html)

お使いのコンピューターのインストールガイド

## コンピュータを使用して Y1 に Koensayr をインストールします

使用しているコンピュータのガイドを選択してください。 すべてのバージョンには、プラットフォームのセットアップ、Updater CE の手順、および在庫に戻る方法が含まれています。[Windowsガイド](/install/koensayr-y1-windows.html)[macOS ガイド](/install/koensayr-y1-mac.html)[Linuxガイド](/install/koensayr-y1-linux.html)

[すべての Innioasis Y1 ガイド](/install/y1.html) · [すべての Koensayr ガイド](/install/koensayr.html)

## インストール手順
  - コンピュータで Innioasis Updater CE を開きます (まだお持ちでない場合は、 [Updater CE を入手](../guide_jp.html#platform)）。選択 Y1 で デバイスモデル.
  - 選択してください Koensayr で ソフトウェア (または次のように起動します) [Updater CE で入手](../guide_jp.html?model=Y1&software=koensayr-y1)).
  - リストされたリリースを選択して、 インストール / 復元.
  - 電源を切り、アプリが要求した場合にのみ Y1 を接続します。
  - Y1を使用 純正ソフトウェア ストックパスを復元します。

## 何かが失敗したとき

まずモデルとタイプの選択を確認してください。次に、プロンプトが表示される前にケーブルとプレーヤーが接続されているかどうかを確認します。 USB を待つ前にアプリが停止した場合は、 [トラブルシューティング](../troubleshooting_jp.html).Updater への接続手順安定した接続はインストールの一部です。
