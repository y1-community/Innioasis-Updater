# Як інсталювати Inniclassic на Innioasis Y2 - Innioasis завантаження мікропрограми

Inniclassic · Innioasis Y2

# Встановіть Inniclassic на Y2.

Inniclassic має спеціальний порт Y2, який підтримує Йонаш Потонець. Виберіть Y2, перш ніж вибрати його, щоб список випусків залишався з урахуванням моделі.[Отримати Updater CE](../guide_uk.html#platform)[Отримайте це в Updater CE](../guide_uk.html?model=Y2&software=inniclassic-y2)[Чому Inniclassic?](../inniclassic-benefits_uk.html)

Посібник із встановлення для вашого комп’ютера

## Встановіть Inniclassic на свій Y2 разом із комп’ютером

Виберіть посібник для комп’ютера, яким ви користуєтеся. Кожна версія має налаштування платформи, Updater CE кроків і шлях повернення до запасу.[Керівництво по Windows](/install/inniclassic-y2-windows.html)[посібник з macOS](/install/inniclassic-y2-mac.html)[Керівництво по Linux](/install/inniclassic-y2-linux.html)

[Усі Innioasis Y2 посібники](/install/y2.html) · [Усі Inniclassic посібники](/install/inniclassic.html)

## Встановіть його
  - Відкрийте Innioasis Updater CE на своєму комп’ютері (якщо у вас його ще немає, [Отримати Updater CE](../guide_uk.html#platform)). Виберіть Y2 в Модель пристрою.
  - Виберіть Inniclassic в Програмне забезпечення (або запустити за допомогою [Отримайте це в Updater CE](../guide_uk.html?model=Y2&software=inniclassic-y2)).
  - Виберіть випуск і натисніть Встановити / Відновити.
  - Вимкніть живлення та підключіть Y2 лише тоді, коли програма оновлення підкаже.
  - Використовуйте Y2 Заводське ПЗ для шляху відновлення.

## Зберігайте зв'язокІнструкції з підключення програми оновленняПідключайтеся лише за живою підказкою.

Y2 пакети використовують `rom_y2.zip`. Якщо інсталяція не вдається, зверніть увагу, чи сталася помилка до чи після того, як програма оновлення виявила програвач.
