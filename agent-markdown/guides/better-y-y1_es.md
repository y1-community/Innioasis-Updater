# Instale Better-Y en un Y1.

Better-Y es una experiencia de stock mejorada para Innioasis Y1 creada por Leska1337. Seleccione Y1 antes de elegirlo para instalar paquetes que coincidan con el modelo.[Obtener Updater CE](../guide_es.html#platform)[Obtener en Updater CE](../guide_es.html?model=Y1&software=better-y-y1)[¿Por qué Better-Y?](../better-y-benefits_es.html)

Guía de instalación para su computadora

## Instala Better-Y en tu Y1 con tu computadora

Elija la guía para la computadora que está utilizando. Cada versión tiene la configuración de la plataforma, Updater CE pasos y el camino de regreso al stock.[guía de windows](/install/better-y-y1-windows.html)[guía de macos](/install/better-y-y1-mac.html)[guía de linux](/install/better-y-y1-linux.html)

[Todas las Innioasis Y1 guías](/install/y1.html) · [Todas las Better-Y guías](/install/better-y.html)

## instalarlo
  - Abra Innioasis Updater CE en su computadora (si aún no lo tiene, [Obtener Updater CE](../guide_es.html#platform)). Seleccionar Y1 en Modelo del dispositivo.
  - elegir Better-Y en Software (o iniciar con [Obtener en Updater CE](../guide_es.html?model=Y1&software=better-y-y1)).
  - Seleccione una versión y haga clic Instalar / Restaurar.
  - Apague y conecte el Y1 solo cuando el Actualizador se lo indique.
  - Usar Y1 Software original para la ruta de restauración.

## Mantén la conexión quietaInstrucciones de conexión con UpdaterConecta solo cuando aparezca el aviso.

Deje el reproductor quieto mientras se completa el parpadeo. Cuando Updater confirme el éxito, desconecte el reproductor y enciéndalo.

## Better-Y atajos y consejos
  - Saltar a Reproduciendo ahora — Presione dos veces el botón Reproducir/Pausa desde cualquier pantalla o menú para volver instantáneamente a la reproducción.
  - Reinicio de emergencia — Si el reproductor alguna vez deja de responder, mantenga presionados los botones superior e inferior juntos para iniciar un reinicio limpio del hardware.
  - Desplazamiento alfabético — Gire la rueda de clic a lo largo del borde para activar la barra de índice rápido alfabético en listas de pistas largas.
  - Íconos interactivos en reproducción — Toque los íconos en pantalla para Me gusta, Mezclar, Repetir (uno/todos), Letra, Bucle A-B, Cola, Marcador, Velocidad y Temporizador de apagado.
  - División de etiquetas — Separe varios artistas con comas (,) o punto y coma (;) para que las pistas aparezcan debajo de cada artista individualmente. Las etiquetas de varios géneros se dividen con comas, punto y coma o barras diagonales.
