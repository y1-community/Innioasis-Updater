# 如何在 Innioasis Y1 - Innioasis 上安裝 Koensayr 韌體下載

Koensayr · Innioasis Y1

# 在 Y1 上安裝 Koensayr。

Koensayr 被列為 Y1 項目。讓更新程式管理軟體包，然後按照與其他完整安裝相同的謹慎關閉電源和 USB 計時。[取得 Updater CE](../guide_zh-TW.html#platform)[在 Updater CE 中取得此內容](../guide_zh-TW.html?model=Y1&software=koensayr-y1)[為什麼是Koensayr？](../koensayr-benefits_zh-TW.html)

適用於您的電腦的安裝指南

## 使用計算機在 Y1 上安裝 Koensayr

選擇適合您正在使用的計算機的指南。 每個版本都有平台設定、Updater CE步驟和返回庫存的方式。[Windows 指南](/install/koensayr-y1-windows.html)[macOS 指南](/install/koensayr-y1-mac.html)[Linux指南](/install/koensayr-y1-linux.html)

[所有 Innioasis Y1 指南](/install/y1.html) · [所有 Koensayr 指南](/install/koensayr.html)

## 安裝步驟
  - 在您的電腦上開啟 Innioasis Updater CE（如果您還沒有， [取得 Updater CE](../guide_zh-TW.html#platform)）。選擇 Y1 在 裝置型號.
  - 選擇 Koensayr 在 軟體 （或啟動 [在 Updater CE 中取得此內容](../guide_zh-TW.html?model=Y1&software=koensayr-y1)).
  - 選擇列出的版本並點擊 安裝 / 還原.
  - 僅當應用程式要求時關閉電源並連接 Y1。
  - 使用Y1 原廠軟體 恢復庫存路徑。

## 當某事失敗時

首先檢查型號和類型選擇。然後在出現提示之前檢查線纜以及播放器是否已連接。如果應用程式在等待 USB 之前停止，請開啟 [故障排除](../troubleshooting_zh-TW.html).更新器連線說明穩定的連接是安裝的一部分。
