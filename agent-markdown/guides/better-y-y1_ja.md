# Innioasis Y1 - Innioasis ファームウェアのダウンロードに Better-Y をインストールする方法

Better-Y · Innioasis Y1

# Better-Y を Y1 にインストールします。

Better-Y は、Leska1337 によって作成された Innioasis Y1 の強化されたストック エクスペリエンスです。モデルに一致するパッケージをインストールするには、Y1 を選択してから選択してください。[Updater CE を入手](../guide_ja.html#platform)[Updater CE で入手](../guide_ja.html?model=Y1&software=better-y-y1)[なぜBetter-Y?](../better-y-benefits_ja.html)

お使いのコンピューターのインストールガイド

## コンピュータを使用して Y1 に Better-Y をインストールします

使用しているコンピュータのガイドを選択してください。 すべてのバージョンには、プラットフォームのセットアップ、Updater CE の手順、および在庫に戻る方法が含まれています。[Windowsガイド](/install/better-y-y1-windows.html)[macOS ガイド](/install/better-y-y1-mac.html)[Linuxガイド](/install/better-y-y1-linux.html)

[すべての Innioasis Y1 ガイド](/install/y1.html) · [すべての Better-Y ガイド](/install/better-y.html)

## インストールしてください
  - コンピュータで Innioasis Updater CE を開きます (まだお持ちでない場合は、 [Updater CE を入手](../guide_ja.html#platform)）。選択 Y1 で デバイスモデル.
  - 選択してください Better-Y で ソフトウェア (または次のように起動します) [Updater CE で入手](../guide_ja.html?model=Y1&software=better-y-y1)).
  - リリースを選択してクリックします インストール / 復元.
  - アップデーターが要求した場合にのみ、電源をオフにして Y1 を接続します。
  - Y1を使用 純正ソフトウェア 復元パスの場合。

## 接続を維持したままにしてくださいUpdater への接続手順案内が表示されてから接続してください。

点滅が完了するまでプレーヤーを動かさないでください。 Updater が成功を確認したら、プレーヤーのプラグを抜き、電源を入れます。

## Better-Y のショートカットとヒント
  - 現在再生中のページにジャンプ — 画面またはメニューから再生/一時停止ボタンを 2 回押すと、すぐに再生に戻ります。
  - 緊急再起動 — プレーヤーが応答しなくなった場合は、上部と下部のボタンを押したままにして、ハードウェアのクリーンな再起動をトリガーします。
  - アルファベットスクロール — クリック ホイールを端に沿って回転すると、長いトラック リストのアルファベット順の高速インデックス バーがアクティブになります。
  - インタラクティブな再生中のアイコン — 画面上の「いいね」、シャッフル、リピート (1 つ/すべて)、歌詞、A-B ループ、キュー、ブックマーク、スピード、およびスリープ タイマーのアイコンをタップします。
  - タグの分割 — 複数のアーティストをカンマ (,) またはセミコロン (;) で区切ると、トラックが各アーティストの下に個別に表示されます。複数のジャンルのタグは、カンマ、セミコロン、またはスラッシュで区切られます。
