# Восстановить исходное программное обеспечение на Innioasis G3

Полный возврат к программному обеспечению, с которым поставляется плеер. Используйте его после неудачного обновления, перед продажей плеера или всякий раз, когда кастомная система вам не подходит.[Скачать Updater CE](../guide_ru.html#platform)[G3 скачиваний](../firmware_ru.html?model=G3)[G3 инструкция](../manuals/g3.html)

Руководство по установке для вашего компьютера

## Восстановите оригинальное программное обеспечение на вашем G3 с помощью компьютера.

Выберите руководство для компьютера, который вы используете. В каждой версии есть настройка платформы, Updater CE шагов и возврат к стоку.[Руководство по Windows](/install/original-g3-windows.html)[руководство по macOS](/install/original-g3-mac.html)[Руководство по Linux](/install/original-g3-linux.html)

[Все руководства Innioasis G3](/install/g3.html) · [Все руководства по оригинальному программному обеспечению](/install/original-software.html)

## Что вам нужно
  - Компьютер под управлением Windows, macOS или Linux. Updater CE работает на всех трёх.
  - USB-кабель для передачи данных, входящий в комплект поставки плеера. Кабели только для зарядки не подойдут.
  - Официальный `rom_g3.zip` пакет, который Updater скачает для вас, или копию из [G3 архив](../firmware_ru.html?model=G3) если вы предпочитаете прошивать вручную.
  - Зарядите плеер. Восстановление, при котором теряется мощность, — единственный распространенный способ усугубить плохую ситуацию.

Это заменяет систему и стирает внутреннюю память. Сначала скопируйте музыку, записи и фотографии на компьютер.

## Маршрут A: Updater CE (рекомендуется)
  - Установить [Innioasis Программа обновления CE](../guide_ru.html#platform) и откройте его.
  - Набор Модель устройства в адрес G3. Модель должна точно соответствовать плееру.
  - Выбирать Заводское ПО в списке Программное обеспечение.
  - Выберите релиз. Новейшая стабильная сборка является безопасной по умолчанию.
  - Нажимать Установить / Восстановить и подождите, пока пакет загрузится и распакуется.
  - Полностью выключите плеер, затем подключайте USB-кабель только по запросу программы обновлений.
  - Не прикасайтесь к плееру или кабелю до появления сообщения об успехе. Отключите и запустите плеер.
Никогда не выбирайте другую модель, чтобы «заставить ее работать». Для G3 требуется пакет G3. Из-за смешивания моделей игрокам в конечном итоге требуется восстановление вручную.

## Маршрут B: SP Flash Tool (вручную)

Используйте это, когда компьютер не может запустить Updater CE или если у вас уже есть пакет и вы предпочитаете классический инструмент.
  - Скачать `rom_g3.zip` из [G3 архив](../firmware_ru.html?model=G3) и разархивируйте его.
  - Сохраните scatter-файл рядом с изображениями. Не переименовывайте и не перемещайте изображения.
  - Откройте SP Flash Tool, выберите Только скачатьи загрузите скаттер-файл.
  - Выключите плеер, нажмите Скачать, затем подключите кабель.
  - Прежде чем отключиться, дождитесь зеленой отметки успеха.

The [SP Flash Tool руководство](../sp-flash-tool_ru.html) более подробно описаны драйверы и подсказки Windows. В Linux и macOS Updater CE — более простой путь, поскольку он обеспечивает собственную обработку USB.

## После восстановления
  - Отключите плеер и дайте ему запуститься самостоятельно.
  - Выберите язык и установите часы.
  - Повторно подключитесь к Wi-Fi или Bluetooth, если вы ими пользуетесь.
  - Скопируйте свою музыку обратно. [руководство по трансферу](../manuals/transfer-music.html) имеет имена папок.

Если плеер запускается, но экран, колесо или кнопки по-прежнему работают неправильно, восстановление сработало; это вопрос аппаратного обеспечения или настройки, а не программного обеспечения. [руководство по устранению неполадок](../troubleshooting_ru.html) Следующая остановка.

## Если это не работает

### Программа обновления никогда не видит плеер

Меняем кабель, затем порт USB. Избегайте хабов. В Windows установите драйвер MediaTek из папки [страница драйвера](../drivers_ru.html).

### Вспышка останавливается раньше времени

Переподключитесь, зарядите плеер и начните заново. Не переходите на пакет другой модели.

### Игрок остается черным

Заряжайте в течение часа, затем удерживайте питание в течение десяти секунд. Если он все еще мертв, прочтите [руководство по восстановлению](../guides/recovery_ru.html) прежде чем попытаться еще раз.

## Вопросы, которые задают люди

### Удалит ли это мою музыку?

Да, внутренняя память удалена. Файлы на карте microSD обычно сохраняются, но сначала скопируйте их в безопасное место.

### Могу ли я потом вернуться в Rockbox?

Да. Восстановление оригинального программного обеспечения — это не дверь с односторонним движением; на странице специального программного обеспечения для вашей модели можно установить его снова.

### Нужна ли мне настройка Type A / Type B?

Только Y1 имеет такой выбор и только для оригинального программного обеспечения. Все остальные модели используют один пакет.
