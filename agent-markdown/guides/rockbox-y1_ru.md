## Что вам нужно

Innioasis Y1, заряженный аккумулятор, USB кабель для передачи данных и компьютер с установленным Innioasis Updater CE (если вы еще не установили его, [Скачать Updater CE](../guide_ru.html#platform) для Windows, macOS или Linux). Type A подходит для Y1 игроков, поставлявших оригинальное программное обеспечение версии 2.0.0 или более поздней; Type B подходит игрокам, которые поставлялись с более ранней версией [Заводское ПО](../firmware_ru.html?software=original-y1). Начните с Type A, если вы еще не знаете, что вашему плееру нужна сборка Type B.

## В программе обновлений
  - Откройте Updater CE (или запустите с помощью [Получите это в Updater CE](../guide_ru.html?model=Y1&software=rockbox-y1)) и установите Модель устройства в адрес Y1.
  - Выбирать Rockbox в Программное обеспечение. Точная метка проекта может отображаться как Rockbox-Y1 в данных выпуска.
  - Выберите стабильную версию. Сборки 240p имеют самую широкую совместимость со старыми темами; Сборки 360p предназначены для пути темы Y1. Если различие имеет значение, проверьте примечания к выпуску.
  - Нажмите Установить / Восстановить. Подождите, пока Updater CE загрузит пакет непосредственно из версии разработчика сообщества и подготовит его.

## Подключите Y1
  - Подождите, пока программа обновлений не запросит плеер.
  - Полностью выключите Y1. Если он не выключится, используйте инструкцию по восстановлению, показанную программой обновлений.
  - Подключайте кабель для передачи данных USB только тогда, когда приложение предложит это. Отложите плеер и не нарушайте соединение.
  - Отключитесь только после того, как программа обновлений подтвердит успех, затем запустите Y1.
Инструкция по подключению обновленийФормулировка подключения может различаться в зависимости от платформы. Следуйте подсказкам в реальном времени.

## Вернуться к исходному программному обеспечению

Rockbox не привязывает вас к пользовательскому программному обеспечению. После настройки Updater на вашем компьютере используйте его в Windows, macOS или Linux: выберите Y1, выбирать Заводское ПОи запустить Установить / Восстановить.
  - Подождите, пока программа обновления завершит подготовку стандартного пакета.
  - Выключите Y1, когда приложение спросит.
  - Подключайте кабель передачи данных USB только при появлении подсказки в режиме реального времени.
  - Оставьте плеер неподвижным до появления сообщения об успехе.

Не используйте пакет Y2 и не удаляйте вручную файлы Rockbox перед восстановлением. Для поведения колеса Type B проверьте соответствующий вариант выпуска перед изменением типа устройства.[Y1 руководство по восстановлению](restore-original-y1_ru.html)[Устранение неполадок](../troubleshooting_ru.html)
