# Instala JJ Launcher en tu Y2.

Hay una compilación JJ Launcher para Y2. Elija su modelo primero para que Updater no ofrezca el paquete Y1.[Obtener Updater CE](../guide_es.html#platform)[Obtener en Updater CE](../guide_es.html?model=Y2&software=jj-launcher-y2)[¿Por qué JJ Launcher?](../jj-launcher-benefits_es.html)

También disponible: [JJ Launcher en Y1](jj-launcher-y1_es.html)

Guía de instalación para su computadora

## Instala JJ Launcher en tu Y2 con tu computadora

Elija la guía para la computadora que está utilizando. Cada versión tiene la configuración de la plataforma, Updater CE pasos y el camino de regreso al stock.[guía de windows](/install/jj-launcher-y2-windows.html)[guía de macos](/install/jj-launcher-y2-mac.html)[guía de linux](/install/jj-launcher-y2-linux.html)

[Todas las Innioasis Y2 guías](/install/y2.html) · [Todas las JJ Launcher guías](/install/jj-launcher.html)

## Elige la ruta Y2
  - Abra Innioasis Updater CE en su computadora (si aún no lo tiene, [Obtener Updater CE](../guide_es.html#platform)). Seleccionar Y2 en Modelo del dispositivo.
  - elegir JJ Launcher en Software (o iniciar con [Obtener en Updater CE](../guide_es.html?model=Y2&software=jj-launcher-y2)).
  - Lea la nota de la versión, confirme la entrada Y2 y haga clic en Instalar / Restaurar.
  - Apague y conecte el reproductor solo cuando el Actualizador lo solicite.
  - Restaurar con Y2 Software original Si necesita la interfaz original nuevamente.

## La discrepancia del modelo es lo primero que hay que comprobar

JJ Launcher también tiene una entrada Y1. Si el nombre del paquete parece incorrecto, regrese al Modelo de dispositivo. No fuerces un paquete Y1 sobre un Y2.Instrucciones de conexión con UpdaterConecta solo cuando aparezca el aviso.

## Volver al software original

JJ Launcher no cambia la ruta de regreso a la interfaz original. Una vez que Updater esté configurado para su computadora, ábralo en Windows, macOS o Linux y seleccione Y2 más Software original en lugar de JJ Launcher.
  - Elija una versión estable del software original Y2.
  - Haga clic Instalar / Restaurar y espere el mensaje de conexión en vivo.
  - Apague el Y2 solo cuando se le solicite.
  - Conecte el cable de datos USB cuando se le indique y déjelo quieto hasta que tenga éxito.

No elimine manualmente los archivos JJ Launcher primero y no utilice un paquete Y1. Si la falla ocurrió antes del mensaje USB, verifique primero la configuración de la computadora, el cable y la selección del modelo.[guía de restauración Y2](restore-original-y2_es.html)[Solución de problemas](../troubleshooting_es.html)
