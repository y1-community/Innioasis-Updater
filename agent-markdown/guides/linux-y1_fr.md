# Installez Linux sur un Y1.

Linux pour Y1 est un noyau Linux communautaire expérimental et un port rootfs pour Innioasis Y1. Sélectionnez Y1 avant de le choisir dans Updater CE.[Obtenir Updater CE](../guide_fr.html#platform)[Disponible dans Updater CE](../guide_fr.html?model=Y1&software=linux-y1)[Origine du projet](https://github.com/y1-community/y1-linux-rom)

Guide d'installation pour votre ordinateur

## Installez Linux pour Y1 (Dev) sur votre Y1 avec votre ordinateur

Choisissez le guide correspondant à l'ordinateur que vous utilisez. Chaque version comprend la configuration de la plate-forme, Updater CE étapes et le chemin de retour au stock.[Guide Windows](/install/linux-y1-windows.html)[Guide macOS](/install/linux-y1-mac.html)[Guide Linux](/install/linux-y1-linux.html)

[Tous les guides Innioasis Y1](/install/y1.html) · [Tous les guides Linux pour Y1 (Dev)](/install/linux-dev.html)

## Installez-le
  - Ouvrez Innioasis Updater CE sur votre ordinateur (si vous ne l'avez pas encore, [Obtenir Updater CE](../guide_fr.html#platform)). Sélectionnez Y1 dans Modèle d'appareil.
  - Choisissez Linux pour Y1 (développement) dans Logiciel (ou lancer avec [Disponible dans Updater CE](../guide_fr.html?model=Y1&software=linux-y1)).
  - Sélectionnez une version et cliquez sur Installer / Restaurer.
  - Éteignez et connectez le Y1 uniquement lorsque le programme de mise à jour vous y invite.
  - Utiliser Y1 Logiciel d'origine pour le chemin de restauration.

## Port expérimentalConstruction expérimentale : Il s'agit d'un port Linux barebones destiné aux développeurs et aux passionnés. Les détails de l'UART et de la console se trouvent dans la documentation du projet.Instructions de connexion à UpdaterNe connectez qu'au moment de l'invite.
