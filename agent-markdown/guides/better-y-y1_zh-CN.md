# 如何在 Innioasis Y1 - Innioasis 上安装 Better-Y 固件下载

Better-Y · Innioasis Y1

# 在 Y1 上安装 Better-Y。

Better-Y 是 Leska1337 创建的 Innioasis Y1 的增强库存体验。选择Y1，然后选择它来安装型号匹配的软件包。[获取 Updater CE](../guide_zh-CN.html#platform)[在 Updater CE 中获取](../guide_zh-CN.html?model=Y1&software=better-y-y1)[为什么是Better-Y？](../better-y-benefits_zh-CN.html)

适用于您的计算机的安装指南

## 使用计算机在 Y1 上安装 Better-Y

选择适合您正在使用的计算机的指南。 每个版本都有平台设置、Updater CE步骤和返回库存的方式。[Windows 指南](/install/better-y-y1-windows.html)[macOS 指南](/install/better-y-y1-mac.html)[Linux指南](/install/better-y-y1-linux.html)

[所有 Innioasis Y1 指南](/install/y1.html) · [所有 Better-Y 指南](/install/better-y.html)

## 安装它
  - 在您的计算机上打开 Innioasis Updater CE（如果您还没有， [获取 Updater CE](../guide_zh-CN.html#platform)）。选择 Y1 在 设备型号.
  - 选择 Better-Y 在 软件 （或启动 [在 Updater CE 中获取](../guide_zh-CN.html?model=Y1&software=better-y-y1)).
  - 选择一个版本并单击 安装 / 恢复.
  - 仅当更新程序提示时关闭并连接 Y1。
  - 使用Y1 原厂软件 为恢复路径。

## 保持连接不变Updater 连接说明仅在提示时连接。

闪烁完成时让播放器保持静止。当更新程序确认成功后，拔下播放器的插头并打开电源。

## Better-Y 快捷键和提示
  - 跳至正在播放 — 在任何屏幕或菜单中双击播放/暂停按钮即可立即返回播放。
  - 紧急重启 — 如果播放器变得无响应，请同时按住顶部和底部按钮以触发干净的硬件重新启动。
  - 按字母顺序滚动 — 沿边缘旋转点按轮可激活长曲目列表上的字母快速索引栏。
  - 交互式正在播放图标 — 点击屏幕上的“点赞”、“随机播放”、“重复（一个/全部）”、“歌词”、“A-B 循环”、“队列”、“书签”、“速度”和“睡眠定时器”图标。
  - 标签分割 — 用逗号 (,) 或分号 (;) 分隔多个艺术家，以使曲目单独显示在每个艺术家下方。多类型标签用逗号、分号或斜杠分隔。
