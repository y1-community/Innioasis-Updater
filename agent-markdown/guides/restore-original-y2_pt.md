## De Rockbox ou outro software personalizado

Assim que a configuração relevante do Windows, macOS ou Linux estiver pronta, retornar à interface padrão Y2 usa o mesmo fluxo do Updater da instalação de um projeto da comunidade. Não misture manualmente os arquivos Y1 no player nem exclua as pastas do sistema primeiro.
  - Abra Innioasis Updater CE no seu computador (se ainda não o tiver instalado, [Obtenha o atualizador CE](../guide_pt.html#platform) para [Windows](../drivers_pt.html#windows), [macOS](../guide_pt.html#macos), ou [Linux](../drivers_pt.html#linux)).
  - Definir Modelo do dispositivo para Y2.
  - Escolher Software Original.
  - Selecione uma versão estável Y2. Pacotes de instalação completa manual podem usar `rom_y2.zip`.
  - Clique Instalar / Restaurar e aguarde a etapa de extração.
Não substitua: um Y1 `rom.zip` não é um pacote Y2. Se a lista de lançamentos parecer errada, pare e selecione novamente Y2.

## Siga o prompt de conexão

Windows, macOS e Linux têm notas de configuração de computador diferentes, mas a sequência do lado do player permanece a mesma: desligue quando solicitado e conecte o cabo de dados no prompt ao vivo.
  - Desligue o Y2 totalmente quando o Updater solicitar.
  - Conecte USB somente quando o aplicativo disser que está pronto.
  - Deixe o cabo sozinho até a mensagem de sucesso.
  - Desconecte-se com segurança e inicie o player.
Instruções de conexão do atualizadorA referência de conexão compartilhada. O prompt do aplicativo ao vivo é oficial.
