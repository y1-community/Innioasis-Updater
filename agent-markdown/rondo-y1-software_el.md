# Rondo για Innioasis Y1

Ένα μινιμαλιστικό υλικολογισμικό αναπαραγωγής μουσικής με τροχό κλικ σχεδιασμένο ειδικά για το χωρητικό υλικό Innioasis Y1, εστιασμένο αποκλειστικά στην αναπαραγωγή με απόκριση και στην καθαρή πλοήγηση.[Οδηγός βήμα προς βήμα Y1](guides/rondo-y1.html)[Γιατί Rondo;](rondo-benefits_el.html)[Λήψη εκδόσεων](firmware_el.html?model=Y1&software=rondo-y1)

Οδηγός εγκατάστασης για τον υπολογιστή σας

## Εγκαταστήστε το Rondo στο Y1 με τον υπολογιστή σας

Επιλέξτε τον οδηγό για τον υπολογιστή που χρησιμοποιείτε. Κάθε έκδοση έχει τη ρύθμιση της πλατφόρμας, τα βήματα του Updater CE και τον τρόπο επιστροφής στο απόθεμα.[Οδηγός Windows](install/rondo-y1-windows.html)[οδηγός macOS](install/rondo-y1-mac.html)[Οδηγός Linux](install/rondo-y1-linux.html)

[Όλοι οι Innioasis Y1 οδηγοί](install/y1.html) · [Όλοι οι Rondo οδηγοί](install/rondo.html)

## Βήματα εγκατάστασης
  - Εκκίνηση Innioasis Ενημερωτής CE στον υπολογιστή σας Windows, Mac ή Linux.
  - Επιλέξτε Y1 από το αναπτυσσόμενο μενού Μοντέλο συσκευής.
  - Επιλέξτε Rondo από το αναπτυσσόμενο μενού Λογισμικό.
  - Κάντε κλικ Εγκατάσταση / Επαναφορά και περιμένετε να γίνει λήψη του εργαλείου και προετοιμασία των αρχείων.
  - Όταν σας ζητηθεί από το Updater CE, απενεργοποιήστε το Y1 και συνδέστε το καλώδιο USB.
  - Ολοκληρώστε τη ρύθμιση μετά την εγκατάσταση

Ακολουθήστε τα βήματα στο [αυτόν τον οδηγό](post_install_el.html?software=rondo-y1&model=Y1) για να ολοκληρώσετε τη ρύθμιση στο Y1 σας.[Προβολή Οδηγού](post_install_el.html?software=rondo-y1&model=Y1)
