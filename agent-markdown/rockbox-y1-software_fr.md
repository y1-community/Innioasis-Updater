## Rockbox Y1 étapes d'installation
  - Ouvrez Innioasis Updater CE sur votre ordinateur (si vous avez besoin de l'application, [Obtenir Updater CE](guide_fr.html#platform)). Ensemble Modèle d'appareil à Y1.
  - Choisissez Rockbox dans Logiciel.
  - Choisissez la version et la variante qui correspondent à votre écran ou chemin de thème prévu.
  - Cliquez Installer / Restaurer et attendez que l'application le prépare.
  - Éteignez et connectez le Y1 uniquement à l'invite en direct.

Utilisez le [guide écrit Rockbox Y1](guides/rockbox-y1.html) pour les captures d'écran, la vidéo, la note Type A ou Type B et la liste de contrôle de connexion.

## FAQPuis-je revenir au logiciel Y1 d'origine ?

Oui. Choisissez Y1 et Logiciel d'origine dans Updater CE, puis exécutez Installer/Restaurer. Le [Y1 page de stock de logiciels](original-software-y1_fr.html) explique cet itinéraire.Quelle version de Rockbox dois-je choisir ?

Choisissez une version affichée pour Y1 et lisez sa note de version. Si vous avez besoin d'une compatibilité de thème plus ancien, vérifiez la résolution et les notes de variantes plutôt que de sélectionner une version Y2.Puis-je l'installer sur un Y2 ?

Non. Utilisez le [Rockbox Y2 page](rockbox-y2-software_fr.html) et sélectionnez Y2 dans Updater CE.
