### 📥 MediaTek Informations sur l'installation du pilote

Lors de l'installation du pilote MediaTek, vous pouvez voir une boîte de dialogue vous demandant de supprimer le « pilote d'origine ». Voici ce qu'il faut faire :Important: Si le programme d'installation demande « Supprimer le pilote d'origine ? », cliquez sur Oui. Ceci est normal et permet de garantir que le pilote fonctionne correctement avec votre périphérique Y1. 

Cette étape est nécessaire car :
  - Il supprime tous les pilotes en conflit qui pourraient interférer
  - Il garantit que le pilote MediaTek a un contrôle total sur la communication USB
  - Il évite les conflits de pilotes qui pourraient provoquer des problèmes de connexion

Après l'installation, redémarrez votre ordinateur lorsque vous y êtes invité pour terminer la configuration.×

Installons maintenant l'application sur votre Mac :
