## Y2Player install steps
  - Open Innioasis Updater CE on your computer (if you need the app, [Get Updater CE](guide.html#platform)). Set Device Model to Y2.
  - Choose Y2Player in Software.
  - Choose a release listed for Y2.
  - Click Install / Restore.
  - Power off and connect the Y2 at the live prompt.

Some Y2 full-install packages use `rom_y2.zip`. Let Updater choose the package when possible.

## FAQsCan I go back to the original software?

Yes. Select Y2 and Original Software in Updater CE, then follow the [Y2 restore guide](original-software-y2.html).Can I use this on a Y1?

No. This page is for the Y2Player Y2 entry. Keep Y1 and Y2 packages separate.What if the Y2 is not detected?

Check platform setup, cable, power-off state, model selection, and timing. Use [troubleshooting](troubleshooting.html) before trying manual recovery.
