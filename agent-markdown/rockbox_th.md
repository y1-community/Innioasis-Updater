# วิธีติดตั้ง Rockbox บน Innioasis Y1 หรือ Y2 - Innioasis Updater

Rockbox ข้อมูลอ้างอิง

# รับ Rockbox บน Y1 หรือ Y2

Rockbox เปลี่ยนซอฟต์แวร์เครื่องเล่นและเปิดอินเทอร์เฟซเครื่องเล่นเพลงที่ลึกขึ้น การควบคุมการเล่น การเรียงลำดับ และตัวเลือกธีม มีคำแนะนำในการติดตั้ง แต่ Y1 และ Y2 เป็นการเดินทางที่แยกจากกัน[Rockbox บน Y1](guides/rockbox-y1.html)[Rockbox บน Y2](guides/rockbox-y2.html)[ทำไมต้อง Rockbox?](rockbox-benefits_th.html)

## สิ่งที่การติดตั้งเปลี่ยนแปลงไป

Rockbox คือซอฟต์แวร์แบบกำหนดเอง จะไม่ลบความสามารถของคุณในการกลับสู่อินเทอร์เฟซหุ้นเมื่อมีแพ็คเกจซอฟต์แวร์ต้นฉบับที่ตรงกัน สามารถปรับปรุงการค้นหาและปรับแต่งเพลงได้ แต่ฟีเจอร์ ความละเอียด อายุการใช้งานแบตเตอรี่ และความเข้ากันได้ของธีมนั้นขึ้นอยู่กับรุ่นอย่าผสมรุ่น เลือก Y1 สำหรับเครื่องเล่น Y1 และ Y2 สำหรับเครื่องเล่น Y2 ชื่อรีลีสที่ดูคล้ายกันนั้นไม่เพียงพอเป็นหลักฐานว่าแพ็คเกจเข้ากันได้

## ดูวิดีโอ

วิดีโอโดย Frawgeeys แสดงเส้นทาง Innioasis Updater; ใช้ขั้นตอนที่เขียนไว้เฉพาะรุ่นด้านล่างสำหรับ Y1 หรือ Y2 ของคุณ

วิดีโอโดย [คริสเตียน พลาซ่า](https://www.youtube.com/@CristianPlaza) (ภาษาสเปน) แสดง Rockbox บน Y1 ใช้ขั้นตอนเฉพาะรุ่นด้านล่างสำหรับเครื่องเล่นของคุณ

## เส้นทาง Updater ที่ใช้ร่วมกัน
  - ติดตั้ง Updater และไม่เชื่อมต่ออะไรเลยจนกว่าจะถาม
  - เลือกรุ่นที่พิมพ์อยู่บนเครื่องเล่นค่ะ รุ่นอุปกรณ์.
  - เลือก Rockbox ใน ซอฟต์แวร์.
  - เลือกรุ่นที่เสถียร เว้นแต่คุณจะจงใจทดสอบบิลด์ทุกคืน
  - คลิก ติดตั้ง / คืนค่าจากนั้นปฏิบัติตามข้อความแจ้งการปิดเครื่องและการเชื่อมต่อ USB
  - ตัดการเชื่อมต่อหลังจากข้อความแสดงความสำเร็จเท่านั้น

## 240p, 360p และธีม

คอลเลกชันธีมเก่า Rockbox อาจสร้างด้วยความละเอียด 240p Y1 การสร้างชุมชนยังใช้ป้ายกำกับความเข้ากันได้ 360p อ่านบันทึกประจำรุ่นและแหล่งที่มาของธีมก่อนเลือกบิลด์ ธีมที่สร้างขึ้นสำหรับความละเอียดหนึ่งหรือตระกูลซอฟต์แวร์หนึ่งอาจไม่ทำงานในอีกตระกูลหนึ่ง[เรียกดูธีมชุมชน](https://themes.innioasis.app/?lang=th)[เครื่องมือธีม](https://themes.innioasis.app/?lang=th)

## การกลับสู่ซอฟต์แวร์ดั้งเดิม

เลือกรุ่นเดิมอีกครั้ง เลือก ซอฟต์แวร์ดั้งเดิมเลือกรุ่นที่เสถียรแล้วใช้งาน ติดตั้ง / คืนค่า. หากความล้มเหลวเกิดขึ้นก่อนข้อความ USB ให้ตรวจสอบคอมพิวเตอร์และแตกไฟล์ หากตรวจพบเครื่องเล่นแต่แฟลชล้มเหลว ให้เริ่มด้วย [การแก้ไขปัญหา](troubleshooting_th.html).[Y1 คืนค่า](guides/restore-original-y1.html)[Y2 คืนค่า](guides/restore-original-y2.html)

## คำถามที่พบบ่อยฉันติดตั้ง Rockbox ใหม่แล้ว และไม่ได้แก้ไขอะไรเลย

การติดตั้ง Rockbox ใหม่จะเขียนบิลด์เดียวกันบนไฟล์เดียวกัน ดังนั้นจึงไม่สามารถรีเซ็ตสิ่งที่ Rockbox เก็บไว้ใน MicroSD ได้ หากปัญหาคือการตั้งค่า ธีม เพลย์ลิสต์ หรือฐานข้อมูลที่ใช้งานไม่ได้บนการ์ด การติดตั้งใหม่จะไม่สามารถล้างข้อมูลได้ การรีเซ็ตที่เชื่อถือได้กำลังลบ `.rockbox` โฟลเดอร์จาก MicroSD — Rockbox สร้างใหม่ในการบูตครั้งถัดไป
  - ปิดเครื่องเล่นจนสุดแล้วถอดการ์ด MicroSD ออก หรือเชื่อมต่อเครื่องเล่นเป็นไดรฟ์ USB
  - แสดงไฟล์ที่ซ่อนอยู่ในคอมพิวเตอร์ของคุณเพื่อให้มองเห็นโฟลเดอร์ได้ วิธีแสดงไฟล์ที่ซ่อนอยู่แสดง dotfiles บนคอมพิวเตอร์ของคุณWindows: ใน File Explorer ให้เปิดไฟล์ ดู แท็บและทำเครื่องหมาย รายการที่ซ่อนอยู่.macOS: ใน Finder กด Cmd+Shift+. เพื่อสลับไฟล์ที่ซ่อนลินุกซ์ · ไฟล์ GNOME: กด Ctrl+Hหรือเปิดเมนูแล้วเลือก แสดงไฟล์ที่ซ่อน.ลินุกซ์ · KDE ดอลฟิน: กด Ctrl+Hหรือใช้ ดู → แสดงไฟล์ที่ซ่อน.
  - ลบ `.rockbox` โฟลเดอร์จากรูทการ์ด
  - ใส่การ์ดกลับเข้าไปและเริ่มเครื่องเล่น Rockbox สร้างโฟลเดอร์ใหม่ด้วยค่าเริ่มต้น
  - ใช้ธีมและการตั้งค่าของคุณอีกครั้ง หากปัญหาเกิดขึ้นหลังจากธีมใดธีมหนึ่งเท่านั้น แสดงว่าธีมนั้นคือสาเหตุ

กำลังลบ `.rockbox` ไม่ถอนการติดตั้ง Rockbox และไม่แตะต้องเพลงของคุณ — โฟลเดอร์จะเก็บการตั้งค่า ธีม และแคชไว้ และจะสร้างขึ้นใหม่โดยอัตโนมัติ หากคุณต้องการเก็บธีมของคุณไว้ ให้คัดลอกโฟลเดอร์ออกไป `.rockbox` ก่อนที่จะลบหรือเปลี่ยนชื่อโฟลเดอร์เป็น `.rockbox-old` ก่อนเหตุใดฉันจึงไม่เห็นโฟลเดอร์ .rockbox บน MicroSD ของฉัน

โฟลเดอร์ที่ชื่อขึ้นต้นด้วยจุดจะถูกซ่อนไว้ตามค่าเริ่มต้นในคอมพิวเตอร์ส่วนใหญ่ คุณไม่จำเป็นต้องเห็นมันเพื่อติดตั้ง Rockbox — Updater จัดการไฟล์ต่างๆ หากคุณกำลังแก้ไขปัญหาและต้องการลบ ให้เปิดไฟล์ที่ซ่อนก่อน วิธีแสดงไฟล์ที่ซ่อนอยู่แสดง dotfiles บนคอมพิวเตอร์ของคุณWindows: ใน File Explorer ให้เปิดไฟล์ ดู แท็บและทำเครื่องหมาย รายการที่ซ่อนอยู่.macOS: ใน Finder กด Cmd+Shift+. เพื่อสลับไฟล์ที่ซ่อนลินุกซ์ · ไฟล์ GNOME: กด Ctrl+Hหรือเปิดเมนูแล้วเลือก แสดงไฟล์ที่ซ่อน.ลินุกซ์ · KDE ดอลฟิน: กด Ctrl+Hหรือใช้ ดู → แสดงไฟล์ที่ซ่อน.การลบ .rockbox จะรีเซ็ตธีมและการตั้งค่าของฉันหรือไม่

ใช่ - `.rockbox` เก็บการตั้งค่า ธีม เพลย์ลิสต์ และฐานข้อมูลแคชของ Rockbox การลบจะทำให้ Rockbox กลับสู่สถานะเริ่มต้นใหม่ทั้งหมด สำรองข้อมูลทั้งโฟลเดอร์ (หรือเปลี่ยนชื่อเป็น `.rockbox-old`) หากคุณต้องการสิ่งใดๆ กลับคืน ให้เริ่มโปรแกรมเล่นและ Rockbox จะสร้างโฟลเดอร์ใหม่
