Pilih panduan untuk komputer yang anda gunakan. Setiap versi mempunyai persediaan platform, Updater CE langkah dan jalan kembali ke stok.[Panduan Windows](install/koensayr-y1-windows.html)[panduan macOS](install/koensayr-y1-mac.html)[Panduan Linux](install/koensayr-y1-linux.html)

## Koensayr Y1 install steps
  - Buka Innioasis Updater CE pada komputer anda (jika anda memerlukan apl itu, [Dapatkan Updater CE](guide_ms.html#platform)). Tetapkan Model Peranti kepada Y1.
  - pilih Koensayr dalam Perisian.
  - Choose the listed Y1 release.
  - klik Pasang / Pulihkan.
  - Matikan dan sambungkan Y1 hanya apabila Updater CE bertanya.

## Soalan LazimCan I restore the original Y1 software?

Yes. Select Y1 and Original Software in Updater CE. See the [Y1 stock-software page](original-software-y1_ms.html) for the complete restore route.What should I check when it fails?

Check the model, release, cable, platform setup, and whether the player was connected before the prompt. Then use [penyelesaian masalah](troubleshooting_ms.html).Is there a Koensayr Y2 package?

The current build is for Y1. Don't use it on a Y2 unless the project publishes a separate release for it.
