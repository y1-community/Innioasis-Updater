# เฟิร์มแวร์ Linux (Dev) สำหรับ Innioasis Y1 | ติดตั้งบทช่วยสอน - Innioasis ดาวน์โหลดเฟิร์มแวร์

ลินุกซ์ (ผู้พัฒนา) · Innioasis Y1

# ติดตั้ง Linux บน Y1

Linux สำหรับ Y1 คือเคอร์เนล Linux ชุมชนทดลองและพอร์ต rootfs สำหรับฮาร์ดแวร์ Innioasis Y1 หน้านี้เชื่อมโยงไปยังคู่มือการติดตั้งฉบับเต็มและการเผยแพร่[เปิดคู่มือ Linux สำหรับ Y1 (Dev) ฉบับเต็ม](guides/linux-y1.html)[รับสิ่งนี้ใน Updater CE](guide_th.html?model=Y1&software=linux-y1)[แหล่งที่มาของโครงการ](https://github.com/y1-community/y1-linux-rom)

คู่มือการติดตั้งสำหรับคอมพิวเตอร์ของคุณ

## ติดตั้ง Linux สำหรับ Y1 (Dev) บน Y1 ด้วยคอมพิวเตอร์ของคุณ

เลือกคำแนะนำสำหรับคอมพิวเตอร์ที่คุณใช้ ทุกรุ่นมีการตั้งค่าแพลตฟอร์ม ขั้นตอน Updater CE และวิธีคืนสินค้าในสต็อก[คู่มือวินโดวส์](install/linux-y1-windows.html)[คู่มือ macOS](install/linux-y1-mac.html)[คู่มือลินุกซ์](install/linux-y1-linux.html)

[คำแนะนำ Innioasis Y1 ทั้งหมด](install/y1.html) · [คู่มือ Linux ทั้งหมดสำหรับ Y1 (Dev)](install/linux-dev.html)

## ขั้นตอนการติดตั้ง Linux Y1
  - เปิด Innioasis Updater CE บนคอมพิวเตอร์ของคุณ (หากคุณต้องการแอป [รับ Updater CE](guide_th.html#platform)). ชุด รุ่นอุปกรณ์ ถึง Y1.
  - เลือก Linux สำหรับ Y1 (Dev) ใน ซอฟต์แวร์.
  - เลือกรุ่นที่ระบุไว้สำหรับ Y1
  - คลิก ติดตั้ง / คืนค่า.
  - ปิดเครื่องและเชื่อมต่อ Y1 เมื่อ Updater CE ถามเท่านั้น

## คำถามที่พบบ่อยฉันสามารถกู้คืนซอฟต์แวร์สต็อก Y1 ได้หรือไม่

ใช่. เลือก Y1 และซอฟต์แวร์ต้นฉบับใน Updater CE ที่ [คู่มือซอฟต์แวร์หุ้น Y1](original-software-y1_th.html) ครอบคลุมเส้นทางขากลับนี่เป็นส่วนต่อประสานผู้ใช้ในชีวิตประจำวันหรือไม่?

นี่คือพอร์ตทดลองสำหรับนักพัฒนาและนักปรับแต่ง Linux คำแนะนำเกี่ยวกับเทอร์มินัลและคอนโซลอยู่ในเอกสารโครงการ

## ใช้เส้นทางที่แนะนำ

ครั้งแรกที่ใช้ Updater? ดูการตั้งค่าที่แนะนำไปที่ [รับ Updater CE](guide_th.html#platform) บน Windows, macOS หรือ Linux ก่อนที่จะเชื่อมต่อเครื่องเล่นของคุณ
