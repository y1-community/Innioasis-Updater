# Flash Tool для гравців Innioasis і Timmkoo.

SP Flash Tool входить до Innioasis Оновлення ввімкнено [Windows](drivers_uk.html#windows) і [Linux](drivers_uk.html#linux). Ви його вже маєте. У цьому посібнику показано безпечний спосіб використання на Innioasis Y1 або Y2, а також шлях оновлення для гравців Timmkoo.[Поверніться до посібника з оновлення](guide_uk.html)[Завантаження прошивки](firmware_uk.html)[Усунення несправностей](troubleshooting_uk.html)

Почати з Innioasis Updater

## Оновлення виконує всю роботу за один прохід

Оновлення виконує більшість установок за один прохід. Виберіть програмне забезпечення, дотримуйтеся вказівок і готово. Він також повідомляє вам, коли виходить виправлення або новий випуск. SP Flash Tool знаходиться в наборі інструментів Updater для рідкісних випадків, коли Updater не може завершити роботу. Наведені нижче дії є винятком.

## Для чого цей інструмент

Оновлення прошиває плеєр для вас. SP Flash Tool — той самий двигун, без огорожі. Використовуйте його, коли Updater не запускається, коли програвач не підключається або якщо ви знаєте, як обійти scatter-файл.Спочатку спробуйте Updater. Для більшості інсталяцій і відновлення, інструкції [Маршрут оновлення](guide_uk.html) є безпечнішим вибором. Використовуйте SP Flash Tool, коли знаєте, навіщо він вам потрібен, і тримайте напоготові заряджений акумулятор і USB кабель даних.

## Інструмент Flash для гравців Innioasis.

Innioasis Updater — це флеш-інструмент для гравців Innioasis. Він встановлює офіційне програмне забезпечення, оновлює та відновлює пакети за допомогою процесу, що відповідає моделі, і зберігає вашу музику та налаштування.

### Innioasis Y1 флеш-інструмент

Виберіть випуск Y1 у Updater, а потім підключіть вимкнений плеєр, коли програма запитає. Ті самі пакети Y1 працюють із SP Flash Tool, коли вам потрібен ручний маршрут.

### Innioasis Y2 флеш-інструмент

Виберіть випуск зі списку для Y2. Пакунки Y2 не взаємозамінні з пакетами Y1, тому перед початком перевірте модель.

## Інструмент Flash для гравців Timmkoo.

Гравці Timmkoo використовують той самий процес встановлення програми оновлення. Він безпосередньо зчитує пакети ZIP і RAR Timmkoo, тому вам не потрібен окремий флеш-інструмент або файл розкиду.

### Timmkoo Q5 флеш інструмент

Виберіть модель Q5 у Updater, виберіть пакет Timmkoo, потім запустіть Install / Restore і підключіть програвач за підказкою.

### Timmkoo Q3 і Q3E флеш інструмент

Запис Q3 однаково охоплює Q3 і Q3E. Програма оновлення вибирає відповідні файли з пакета, який публікує проект.

### Timmkoo A5 флеш інструмент

Виберіть модель A5 перед вибором пакета, а потім виконайте ту саму підказку встановлення.

## Куди розміщує Updater

SP Flash Tool постачається разом із папкою встановлення Updater, а не як окреме завантаження. Відкрийте його звідти, коли вам це потрібно.

### Windows

Відкрийте папку встановлення Updater і запустіть `flash_tool.exe`. Папка зазвичай знаходиться під `%LOCALAPPDATA%\Innioasis Updater`. Папка Toolkit із ярликом SP Flash Tool включена до деяких налаштувань.

### Linux

Запустити в комплекті `flash_tool` двійковий файл у папці програми Updater на x86 / x86_64. Інсталятор проекту готує USB дозволи з правилами udev, тому програвач має з’явитися після підключення.

### macOS

SP Flash Tool не включено в macOS. Натомість програма оновлення використовує маршрут MTKClient. Використовуйте [керована установка](guide_uk.html) на Mac і збережіть SP Flash Tool для комп’ютера з Windows або Linux.

Інструмент постачається з агентом завантаження MediaTek і конфігурацією для конкретної моделі, тому вам не потрібно збирати файли DA або файли розкиду з інших місць.

## Підготуйте прошивку
  - Візьміть потрібний випуск [Завантаження прошивки](firmware_uk.html). Виберіть `rom.zip` для Y1 або `rom_y2.zip` для Y2.
  - Розпакуйте ZIP у власну папку. Windows може використовувати Extract All. У Linux використовуйте менеджер архівів або `unzip` в терміналі.
  - Переконайтеся, що scatter-файл знаходиться в розпакованій папці. Зазвичай його називають іменним `MT6572_Android_scatter.txt` для Y1 пакетів і `MT6582_Android_scatter_def.txt` для пакетів Y2, хоча реліз може назвати його за своїм проектом.
Тримайте моделі окремо. Розкид Y1 описує пристрій MT6572, а розкид Y2 описує пристрій MT6582. Миготіння з неправильним ось як гравці отримують цеглу. Якщо розкид всередині ZIP-архіву не відповідає вашій моделі, зупиніться та використовуйте натомість пакет, указаний для вашої моделі.

## Завантажте скаттер і флеш
  - Відкрийте SP Flash Tool із папки встановлення Updater.
  - На вкладці «Завантаження» натисніть Виберіть поруч із пунктом «Файл розкидного завантаження» та виберіть файл розкиду з витягнутої папки. Список розділів заповниться.
  - Залиште режим спалаху увімкненим Тільки завантажити якщо ви навмисне не виконуєте повне відновлення, яке необхідно Оновлення прошивки.
  - Натисніть Завантажити. Інструмент буде чекати гравця.
  - Повністю вимкніть плеєр, а потім під’єднайте кабель передачі даних USB. Покладіть плеєр і не рухайте його.
  - Дочекайтеся зеленої галочки. Тільки після цього від'єднайте кабель і запустіть плеєр.

Дотримуйтеся тих самих USB правил щодо кабелю та часу, що й у маршруті з інструкціями: кабель даних, без концентратора та під’єднуйтеся лише тоді, коли інструмент готовий.

## Якщо не блимає
  - Переконайтеся, що Scatter і ZIP відповідають моделі, надрукованій на плеєрі.
  - Перед підключенням переконайтеся, що плеєр повністю вимкнено.
  - У Windows перевірте драйвер MediaTek, інстальований разом із програмою оновлення; у Linux підтвердіть правила udev у програмі встановлення проекту.
  - Повторно підключайте кабель лише тоді, коли інструмент очікує. Для перегонів портів може знадобитися повне відключення та оновлення Завантажити натисніть.

Для будь-чого, крім цього, відкрийте [усунення несправностей](troubleshooting_uk.html). І пам’ятайте: програма оновлення все ще є звичайним маршрутом, і [Y1](guides/restore-original-y1.html) і [Y2](guides/restore-original-y2.html) посібники з відновлення також використовують його.
