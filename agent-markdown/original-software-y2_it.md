## Installalo o ripristinalo con Updater

Configura prima il computer, quindi lascia che Updater prepari il pacchetto corrispondente al modello.
  - Apri Innioasis Updater CE sul tuo computer (se ti serve l'app, [Ottieni Updater CE](guide_it.html#platform)). Impostato Modello del dispositivo a Y2.
  - Scegli Software originale e una versione Y2.
  - Fare clic Installa / Ripristina.
  - Spegnere e collegare Y2 solo quando richiesto dal prompt live.

È possibile utilizzare i pacchetti di installazione completa manuale `rom_y2.zip`. Non trattare un Y1 `rom.zip` come sostituto.

## Domande frequentiPosso restituire da Rockbox o da un altro software personalizzato?

Utilizza lo stesso flusso di ripristino Y2: scegli Y2, seleziona Software originale e segui la richiesta di connessione. Non mescolare file di modello.Perché il pacchetto Y2 ha un aspetto diverso?

Le versioni Y2 possono utilizzare un nome di pacchetto e una voce di versione diversi. Seleziona Y2 in Updater invece di indovinare da un nome file ZIP manuale.Cosa succede se il giocatore non viene rilevato?

Controlla il cavo dati, i permessi o i driver del computer e la tempistica. Collegare il Y2 spento solo dopo che Updater ha dichiarato che è pronto.
