# Сравните прошивки и варианты программного обеспечения

От официального заводского оригинального программного обеспечения до творений сообщества, таких как Rockbox, Solar, Better-Y и Reborn (Y2Linux) — откройте для себя лучшее программное обеспечение для своих аудио-привычек.[Просмотрите загрузки программного обеспечения](firmware_ru.html)[Помогите выбрать](firmware-faq_ru.html)[Скачать Updater CE](guide_ru.html#platform)

## Обзор программного обеспеченияЗаводская прошивка

### Заводское ПО

Полная поддержка аудио Bluetooth, FM-радио, аудиокниг и пользовательских скинов из галереи тем. [Узнать больше →](original-software-benefits_ru.html)Аудиофильский стандарт

### Rockbox

Параметрический эквалайзер, воспроизведение без пауз, перекрестная подача и обширная настройка тем. [Узнать больше →](rockbox-benefits_ru.html)Улучшенная фабрика

### Better-Y

Улучшения сообщества в дополнение к оригинальному программному обеспечению с настраиваемой загрузкой, исправленными приложениями и поддержкой тем. [Узнать больше →](better-y-benefits_ru.html)Современный пользовательский интерфейс

### Solar

Чистый современный интерфейс с богатыми художественными работами и пользовательской анимацией. [Узнать больше →](solar-benefits_ru.html)Родной Linux

### Reborn (Y2Linux)

Операционная система на базе Debian, разработанная для колеса управления Y2 и исправляющая сбои Bluetooth. [Узнать больше →](reborn-y2linux-benefits_ru.html)Скорость и фокус

### Rondo

Легкая специальная прошивка аудио с колесом управления для Y1. [Узнать больше →](rondo-benefits_ru.html)
