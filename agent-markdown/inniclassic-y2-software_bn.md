আপনি যে কম্পিউটারটি ব্যবহার করছেন তার জন্য গাইডটি বেছে নিন। প্রতিটি সংস্করণে প্ল্যাটফর্ম সেটআপ, Updater CE পদক্ষেপ এবং স্টকে ফিরে যাওয়ার উপায় রয়েছে।[উইন্ডোজ গাইড](install/inniclassic-y2-windows.html)[macOS গাইড](install/inniclassic-y2-mac.html)[লিনাক্স গাইড](install/inniclassic-y2-linux.html)

## Inniclassic Y2 install steps
  - আপনার কম্পিউটারে Innioasis Updater CE খুলুন (যদি আপনার অ্যাপটির প্রয়োজন হয়, [Updater CE নিন](guide_bn.html#platform)) সেট ডিভাইস মডেল থেকে Y2.
  - বেছে নিন Inniclassic মধ্যে সফটওয়্যার.
  - Choose the release listed for Y2.
  - ক্লিক করুন ইনস্টল / পুনরুদ্ধার.
  - পাওয়ার বন্ধ করুন এবং শুধুমাত্র Updater CE বললেই Y2 কানেক্ট করুন।

## সাধারণ প্রশ্নCan I restore the stock Y2 software?

Yes. Select Y2 and Original Software in Updater CE. The [Y2 stock-software guide](original-software-y2_bn.html) ফেরার পথ কভার করে।Can I use Inniclassic on Y1?

Yes. The same project publishes Y1 packages as well — rom.zip for Type A and rom_type_b.zip for Type B. Select Y1 in Updater CE and install the Y1 build; the [Y1 ইন্সটল পেজ](inniclassic-y1-software_bn.html) covers it.ইনস্টলেশন ব্যর্থ হলে কি হবে?

Note whether Updater failed before or after detecting the Y2, then check the cable, platform setup, model, and connection timing in [সমস্যা সমাধান](troubleshooting_bn.html).
