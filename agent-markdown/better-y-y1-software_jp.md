# Y1 に Better-Y をインストールします。

Better-Y は、テーマの 100% の互換性を維持しながら、タグ分割、アルバム トラック番号、再生中のショートカット、よりスムーズな RAM キャッシュを備えた強化されたストック エクスペリエンスを Innioasis Y1 に提供します。[Better-Y ガイド全体を開く](guides/better-y-y1.html)[Updater CE で入手](guide_ja.html?model=Y1&software=better-y-y1)[なぜBetter-Y?](better-y-benefits_ja.html)

## Better-Y Y1 のインストール手順
  - コンピューターで Innioasis Updater CE を開きます (アプリが必要な場合は、 [Updater CE を入手](guide_ja.html#platform)）。セット デバイスモデル 支援先: Y1.
  - 選択してください Better-Y で ソフトウェア.
  - Y1 にリストされているリリースを選択します。
  - クリック インストール / 復元.
  - Updater CE が要求した場合にのみ、電源をオフにして Y1 を接続してください。

## よくある質問純正ファームウェアと比べて何が改善されましたか?

Better-Y はトラック番号を追加し、マルチアーティストタグを分割し、実際のタイトルを使用し、再生ショートカットを追加し、さらにキャッシュと Bluetooth を修正します。前回と同じテーマ。在庫の Y1 ソフトウェアを復元できますか?

はい。 Updater CEでY1とオリジナルソフトウェアを選択します。の [Y1 ストック ソフトウェア ガイド](original-software-y1_ja.html) 復路をカバーします。既存のテーマを使用できますか?

はい！ Better-Y は公式ストック 3.1.2 に基づいて構築されており、テーマ ギャラリーのすべてのカスタム テーマと 100% の互換性を維持しています。インストールに失敗した場合はどうなりますか?

Y1 を検出する前または後にアップデーターが失敗したかに注意し、ケーブル、プラットフォームのセットアップ、モデル、および接続のタイミングを確認してください。 [トラブルシューティング](troubleshooting_ja.html).
