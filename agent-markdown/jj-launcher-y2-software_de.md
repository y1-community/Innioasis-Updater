## Modellkorrekte Prüfungen
  - Öffnen Sie Innioasis Updater CE auf Ihrem Computer (wenn Sie die App benötigen, [Updater CE holen](guide_de.html#platform)). Satz Gerätemodell an Y2.
  - Bestätigen JJ Launcher erscheint für Y2 in den aktuellen Versionsdaten.
  - Lesen Sie die Versionshinweise zum Projekt und wählen Sie die aufgeführte Version Y2 aus.
  - Klicken Sie Installieren / Wiederherstellen.
  - Schalten Sie das Gerät aus und schließen Sie das Y2 nur an, wenn Sie dazu aufgefordert werden.
Nicht ersetzen: Ein Y1-Paket ist kein Y2-Paket. Stoppen Sie, wenn Modell und Release nicht übereinstimmen.

## FAQIst der Support von Y2 garantiert?

Erzwingen Sie kein Y1-Paket. Überprüfen Sie die Projektfreigaben und die [Anleitung zur Fehlerbehebung](troubleshooting_de.html).
