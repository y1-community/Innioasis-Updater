# ทำไมต้อง JJ Launcher สำหรับ Innioasis ของคุณ

JJ Launcher คืออันที่เร็ว โดยจะสแกนไลบรารีขนาดใหญ่อย่างรวดเร็ว ข้ามแทร็กด้วยปุ่มฮาร์ดแวร์ได้จากทุกที่ และให้คุณเปลี่ยนรูปลักษณ์โดยไม่ต้องเขียนโค้ด[รับ JJ Launcher ใน Updater](guide_th.html?model=Y1&software=jj-launcher-y1)[หน้าติดตั้ง Y1](jj-launcher-y1-software_th.html)[หน้าติดตั้ง Y2](jj-launcher-y2-software_th.html)

## ความพร้อมของรุ่น

Innioasis รุ่นใดที่ใช้งานได้[Y1 · ว่าง](jj-launcher-y1-software_th.html)[Y2 · มีจำหน่าย](jj-launcher-y2-software_th.html)

บิลด์ Y1 และ Y2 แยกจากกัน ดังนั้นคว้าอันที่สร้างมาเพื่อเครื่องเล่นของคุณในการดาวน์โหลดซอฟต์แวร์ — อย่าสลับอันหนึ่งกับอันอื่น

## ทำไมคนถึงเลือกมัน

รวดเร็ว ทันใจ ของคุณ
  - การสแกนห้องสมุดอย่างรวดเร็ว — เครื่องสแกนสื่อแบบกำหนดเองจัดหมวดหมู่ไลบรารีขนาดใหญ่โดยไม่ต้องรอเครื่องสแกนระบบ Android
  - ข้ามแทร็กจากหน้าจอใดก็ได้ — การแมปคีย์ฮาร์ดแวร์ส่วนกลางหมายความว่าก่อนหน้าและถัดไปจะทำงานเสมอ แม้ว่าคุณจะไม่ได้อยู่ในแอปเพลงก็ตาม
  - EQ ที่ตั้งไว้ล่วงหน้าและสุ่ม - โหมดสุ่มและเล่นซ้ำเต็มรูปแบบพร้อมการตั้งค่าอีควอไลเซอร์ในตัว
  - ธีมที่ไม่มีโค้ด — วางธีมสีที่กำหนดเองโดยการคัดลอกไฟล์ หรือออกแบบของคุณเองด้วยโปรแกรมแก้ไขธีมบนเว็บและส่งออก .zip
  - การอัพโหลดไฟล์โดยไม่ต้องใช้สายเคเบิล — โฮสต์เว็บเซิร์ฟเวอร์ Wi-Fi ในพื้นที่และอัปโหลดเพลงจากเบราว์เซอร์พีซีของคุณ — สายเคเบิลยังคงอยู่ในลิ้นชัก
  - การจับคู่บลูทูธในแอป — สแกนและจับคู่อุปกรณ์บลูทูธจากการตั้งค่าตัวเรียกใช้งานโดยไม่ต้องออกจากแอป

## ชุมชน

สิ่งที่ชุมชนพูด

JJ Launcher มีไว้สำหรับผู้ที่ต้องการให้ผู้เล่นรู้สึกเร็วด้วยนิ้วหัวแม่มือข้างหนึ่งบนพวงมาลัย มีโครงการอื่นๆ อีกหลายโครงการที่ถูกสร้างขึ้นบนโครงการนี้ ซึ่งบอกเล่ามากมายเกี่ยวกับแกนหลัก

ผู้สร้างชุมชน doitall มีวิดีโอการติดตั้งและการแก้ปัญหาสั้นๆ สำหรับ JJ Launcher บน Y1 และตัวแก้ไขธีมช่วยให้เจ้าของสามารถแลกเปลี่ยนและปรับแต่งรูปลักษณ์ได้โดยไม่ต้องรอรุ่นใหม่
  - [doitall · JJ Launcher ติดตั้งและแก้ไขปัญหา](https://www.youtube.com/shorts/wW7Vg_fb-JU)

## สิ่งที่โครงการนำเสนอ
  - เครื่องสแกนสื่อแบบฝังแบบกำหนดเองพร้อมการจัดหมวดหมู่ไลบรารีขนาดใหญ่อย่างรวดเร็ว
  - สุ่ม โหมดเล่นซ้ำ และค่าที่ตั้งไว้ล่วงหน้า EQ ในตัว
  - การแมปคีย์ฮาร์ดแวร์ส่วนกลาง — การข้ามแทร็กจากหน้าจอใดก็ได้
  - การซิงค์หน้าจอหลักแบบเรียลไทม์ของปกอัลบั้มและข้อมูลแทร็ก
  - ธีมแบบกำหนดเองที่ไม่มีที่สิ้นสุดโดยการคัดลอกโฟลเดอร์ Y1 ตัวแก้ไขธีมสำหรับการออกแบบของคุณเอง
  - พื้นหลังเบลอ HD แบบไดนามิกที่สร้างจากปกอัลบั้มที่กำลังเล่น
  - การสแกนและจับคู่บลูทูธในแอป
  - แป้นพิมพ์เสมือนที่ปรับให้เหมาะสมสำหรับวงล้อสำหรับรหัสผ่าน Wi-Fi
  - การอัพโหลดไฟล์ PC แบบไร้สายผ่านเว็บเซิร์ฟเวอร์ Wi-Fi ในพื้นที่

## เรื่องน่ารู้ก่อน
  - โปรเจ็กต์อยู่ในขั้นอัลฟ่า — อาจมีข้อบกพร่องที่ไม่คาดคิดและปัญหาด้านความเสถียรเกิดขึ้นได้
  - ได้รับการทดสอบบนซอฟต์แวร์ระบบ 2.1.9; ตรวจสอบเวอร์ชันซอฟต์แวร์ของคุณเองก่อนทำการติดตั้ง
  - การเชื่อมต่อบลูทูธบางอย่างอาจต้องได้รับอนุญาตจาก ADB เพียงครั้งเดียวเพื่อการตั้งค่าที่ปลอดภัย
  - ธีมที่สร้างขึ้นสำหรับโปรแกรมแก้ไขเว็บต้องมี Launcher 0.8 หรือสูงกว่า
