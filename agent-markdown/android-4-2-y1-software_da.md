# Install Android 4.2 (Dev) on the Y1.

Android 4.2 is a community development ROM for testing and hacking on Innioasis Y1 hardware. This page links to the full tutorial and release list.[Open the full Android 4.2 (Dev) guide](guides/android-4-2-y1.html)[Få dette i Updater CE](guide_da.html?model=Y1&software=android-4-2-y1)[Projektkilde](https://github.com/y1-community/y1-ata-rom)

## Install Android development ROM on your Y1 with your computer

Vælg vejledningen til den computer, du bruger. Hver version har platformsopsætningen, Updater CE trin og vejen tilbage til lageret.[Windows guide](install/android-4-2-y1-windows.html)[macOS guide](install/android-4-2-y1-mac.html)[Linux guide](install/android-4-2-y1-linux.html)

## Android 4.2 Y1 install steps
  - Åbn Innioasis Updater CE på din computer (hvis du har brug for appen, [Hent Updater CE](guide_da.html#platform)). Sæt Enhedsmodel til Y1.
  - Vælg Android 4.2 (Dev) ind Software.
  - Vælg den udgivelse, der er angivet for Y1.
  - Klik Installer / Gendan.
  - Sluk og tilslut kun Y1, når Updater CE spørger.
