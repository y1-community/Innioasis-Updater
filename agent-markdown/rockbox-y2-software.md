## Rockbox Y2 install steps
  - Open Innioasis Updater CE on your computer (if you need the app, [Get Updater CE](guide.html#platform)). Set Device Model to Y2.
  - Choose Rockbox in Software.
  - Choose a release explicitly listed for Y2.
  - Click Install / Restore and wait for package preparation.
  - Power off and connect the Y2 only when Updater CE asks.

Do not force a Y1 package because the project name looks the same. If no Y2 release appears, stop and check the model and current release data.
