# Reborn (Y2Linux) para Innioasis Y2

Una distribución Debian Linux rápida y especialmente diseñada con una interfaz de usuario nativa con rueda de clic para Innioasis Y2, que presenta estabilidad de auriculares Bluetooth y desarrollo comunitario activo.[Guía paso a paso Y2](guides/reborn-y2linux-y2.html)[¿Por qué Y2Reborn?](reborn-y2linux-benefits_es.html)[Descargar lanzamientos](firmware_es.html?model=Y2&software=reborn-y2linux-y2)

Guía de instalación para su computadora

## Instala Reborn (Y2Linux) en tu Y2 con tu computadora

Elija la guía para la computadora que está utilizando. Cada versión tiene la configuración de la plataforma, Updater CE pasos y el camino de regreso al stock.[guía de windows](install/reborn-y2linux-y2-windows.html)[guía de macos](install/reborn-y2linux-y2-mac.html)[guía de linux](install/reborn-y2linux-y2-linux.html)

[Todas las Innioasis guías Y2](install/y2.html) · [Todas las guías Reborn (Y2Linux)](install/reborn.html)

## Pasos de instalación
  - Abra el Actualizador CE. Disponible para Windows, macOS y Linux.
  - Seleccione Y2 como modelo del dispositivo.
  - Seleccione Reborn (Y2Linux) como el software.
  - Haga clic en Instalar/Restaurar. Espere mientras Updater CE prepara los archivos.
  - Conecte USB cuando se le solicite. Apague el Y2 primero.
  - Configurar Wi-Fi, Bluetooth y radio FM

Copiar `system.img` al jugador una vez. Reborn hace el resto.[Finalizar configuración →](y2reborn_wifibt_es.html)
