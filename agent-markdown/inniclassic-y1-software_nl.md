# Installeer Inniclassic op de Y1.

Inniclassic is een communitysoftwareproject voor de Y1, en hetzelfde project publiceert ook een Y2-build, dus deze is beschikbaar op beide spelers. Deze pagina geeft u het Y1 zoekvriendelijke antwoord en links naar de gedetailleerde verbindingsstappen.[Open de volledige Inniclassic-gids](guides/inniclassic-y1.html)[Ontvang dit in Updater CE](guide_nl.html?model=Y1&software=inniclassic-y1)[Waarom Inniclassic?](inniclassic-benefits_nl.html)

Kies de handleiding voor de computer die u gebruikt. Elke versie heeft de platformconfiguratie, Updater CE stappen en de weg terug naar de voorraad.[Windows-gids](install/inniclassic-y1-windows.html)[macOS-gids](install/inniclassic-y1-mac.html)[Linux-gids](install/inniclassic-y1-linux.html)

## Inniclassic Y1 installatiestappen
  - Open Innioasis Updater CE op uw computer (als u de app nodig heeft, [Updater CE downloaden](guide_nl.html#platform)). Instellen Apparaatmodel aan Y1.
  - Kies Inniclassic binnen Software.
  - Kies de release vermeld voor J1.
  - Klik Installeren / Herstellen.
  - Schakel de Y1 alleen uit en sluit deze alleen aan als Updater CE daarom vraagt.

## Veelgestelde vragenKan ik de standaard Y1-software herstellen?

Ja. Selecteer Y1 en originele software in Updater CE. De [Y1 voorraadsoftwaregids](original-software-y1_nl.html) bedekt het retourtraject.Wat als de installatie mislukt?

Noteer of Updater is mislukt voor of na het detecteren van de Y1 en controleer vervolgens de kabel, platformconfiguratie, model en verbindingstijdstip in [probleemoplossing](troubleshooting_nl.html).Kan ik Inniclassic gebruiken op Y2?

Ja. Inniclassic is beschikbaar op beide modellen; hetzelfde onderhouden project publiceert een Y2-pakket uit dezelfde releases. Selecteer Y2 in Updater CE en installeer de Y2 build; flash nooit een Y1-pakket naar een Y2. De [Y2-installatiepagina](inniclassic-y2-software_nl.html) bedekt het.
