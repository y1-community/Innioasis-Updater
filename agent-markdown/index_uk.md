## Що таке Innioasis Updater CE?

Innioasis Оновлення CE is an open-source tool that simplifies updating and restoring your player across Windows, macOS, and Linux.

Flashing through Updater CE preserves your music library, video collection, and Bluetooth pairings while guiding each step on screen.[Отримати Updater CE](guide_uk.html#platform)[Compare flashing tools](updater-comparison_uk.html)[Огляд програмного забезпечення](firmware_uk.html)

## Getting started with Rockbox

### Встановити Rockbox на Y1

Select Y1, choose Rockbox stable, and connect only when prompted.[Y1 instructions](guides/rockbox-y1.html)[Чому Rockbox?](rockbox-benefits_uk.html)

### Встановити Rockbox на Y2

Select Y2 in the tool. The Y2 route uses hardware-specific binaries.[Y2 instructions](guides/rockbox-y2.html)[Чому Rockbox?](rockbox-benefits_uk.html)

### Restore factory software

Returning to factory software uses the same flow: select your model and choose Original Software.[Y1 factory restore](guides/restore-original-y1.html)[Y2 factory restore](guides/restore-original-y2.html)

Compatible with Windows, macOS, and Linux.
