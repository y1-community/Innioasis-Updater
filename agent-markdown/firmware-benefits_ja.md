# ファームウェアとソフトウェアのオプションを比較する

公式の工場オリジナル ソフトウェアから Rockbox、Solar、Better-Y、Reborn (Y2Linux) などのコミュニティ作品まで、あなたのオーディオ習慣に最適なソフトウェアを見つけてください。[ソフトウェアのダウンロードを参照する](firmware_ja.html)[選び方を見る](firmware-faq_ja.html)[Updater CE を入手](guide_ja.html#platform)

## ソフトウェアの概要工場出荷時のファームウェア

### 純正ソフトウェア

Bluetooth オーディオ、FM ラジオ、オーディオブック、テーマ ギャラリーのカスタム スキンを完全にサポートします。 [さらに詳しく→](original-software-benefits_ja.html)オーディオマニアの標準

### Rockbox

パラメトリックEQ、ギャップレス再生、クロスフィード、および広範なテーマのカスタマイズ。 [さらに詳しく→](rockbox-benefits_ja.html)強化されたファクトリー

### Better-Y

カスタム ブート、パッチ適用済みのアプリ、テーマのサポートを備えたオリジナル ソフトウェアに加えてコミュニティが強化されています。 [さらに詳しく→](better-y-benefits_ja.html)モダンなUI

### Solar

豊富なアーティストのアートワークとカスタム アニメーションを備えたクリーンでモダンなインターフェイス。 [さらに詳しく→](solar-benefits_ja.html)ネイティブ Linux

### Reborn (Y2Linux)

Y2 クリックホイール用に設計された Debian ベースのオペレーティング システムで、Bluetooth ドロップアウトが修正されています。 [さらに詳しく→](reborn-y2linux-benefits_ja.html)スピードと集中力

### Rondo

Y1 用の軽量専用クリックホイール オーディオ ファームウェア。 [さらに詳しく→](rondo-benefits_ja.html)
