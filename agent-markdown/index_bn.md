## What is Innioasis Updater CE?

Innioasis আপডেটার CE is the easy way to update your player. It is free to use. It is the tool creators recommend first.

It keeps your music, videos, and Bluetooth pairings. It tells you when updates are ready. It shows each step on screen. It runs on Windows, macOS, and Linux.[Updater CE নিন](guide_bn.html#platform)[আমি কোন টুল ব্যবহার করা উচিত?](updater-comparison_bn.html)[Browse software](firmware_bn.html)

## Getting started with Rockbox on your Innioasis

### Install Rockbox on Y1

Choose Y1, select Rockbox, pick a stable release, then connect only when Updater asks.[Read Y1 steps](guides/rockbox-y1.html)[কেন Rockbox?](rockbox-benefits_bn.html)

### Install Rockbox on Y2

Choose Y2 first. The Y2 route uses a different package and must not be treated as a Y1 install.[Read Y2 steps](guides/rockbox-y2.html)[কেন Rockbox?](rockbox-benefits_bn.html)

### Restore Original Software

Coming back from Rockbox or another custom software uses the same Updater flow: select your model, choose Original Software, and run Install / Restore.[Y1 stock restore](guides/restore-original-y1.html)[Y2 stock restore](guides/restore-original-y2.html)

Works on Windows, macOS, or Linux after that computer’s Updater setup is ready.
