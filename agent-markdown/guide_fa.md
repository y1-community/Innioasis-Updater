# شروع به کار با Innioasis Updater CE

با همه پخش کننده های صوتی Innioasis و Timmkoo کار می کند. Innioasis Updater CE را روی رایانه خود نصب کنید، مدل و نرم افزار مورد نظر خود را انتخاب کنید، سپس دستورات را دنبال کنید.

## 

[دریافت Updater CE](guide_fa.html#download-updater)[آموزش کامل کتبی](guide_fa.html)

## Innioasis Updater CE دریافت کنید

Innioasis به‌روزرسان CE برنامه‌ای است که به‌روزرسانی‌های رسمی و نرم‌افزار انجمن را روی پخش‌کننده شما نصب می‌کند. موسیقی و تنظیمات شما را نگه می دارد و روی ویندوز، macOS و لینوکس اجرا می شود.

### Windows

نصب کننده را دانلود کنید، آن را اجرا کنید، سپس کامپیوتر خود را پس از اتمام راه اندازی مجدد کنید.[درایورها را دریافت کنید](https://github.com/y1-community/supplemental-apks/releases/latest/download/DriverInstall.exe)[دانلود Updater CE](https://github.com/y1-community/Innioasis-Updater/releases/latest/download/installer.exe)

اگر ویندوز شما را از اجرای برنامه باز می دارد یا آن را راه اندازی نمی کند، لطفاً تنظیمات را باز کنید، روی حریم خصوصی و امنیت → امنیت ویندوز → کنترل برنامه و مرورگر کلیک کنید و Smart App Control را خاموش کنید. Smart App Control در حال حاضر بر برنامه‌های محبوبی مانند سرویس Epic Overlay (که توسط Fortnite استفاده می‌شود) تأثیر می‌گذارد - Updater CE ایمن است و برای استفاده تأیید شده است. [ویندوز برنامه را راه اندازی نمی کند؟ کمک کنید](#smart-app-control)

پس از نصب کامپیوتر خود را ریستارت کنید. کمک راننده در [یادداشت های راه اندازی ویندوز](drivers_fa.html#windows).

### macOS[دانلود Updater CE](https://github.com/y1-community/Innioasis-Updater/releases/latest/download/Innioasis.Updater.for.Mac.dmg)

اگر مک شما برای اولین بار مانع از اجرای برنامه شد، لطفاً تنظیمات سیستم را باز کنید، روی Privacy & Security کلیک کنید، به پایین بروید و به Security بروید و کلیک کنید. [به هر حال باز کن](https://support.apple.com/en-gb/102445#openanyway). همچنین می توانید روی برنامه در Finder کلیک کنید (یا راست کلیک کنید) و Open را انتخاب کنید.

روی مک‌های سیلیکونی اینتل و اپل با macOS Monterey و نسخه‌های جدیدتر کار می‌کند.

### Linux

AppImage را برای سیستم های Intel و AMD دانلود کنید، آن را قابل اجرا کنید و اجرا کنید.[دانلود AppImage برای Intel/AMD](https://github.com/y1-community/innioasis-updater/releases/latest/download/UpdaterCE.AppImage)

[یادداشت های راه اندازی لینوکس](drivers_fa.html#linux)پلتفرم دیگه؟

شما به پخش کننده خود، یک کابل داده USB که داده را حمل می کند (یک کابل فقط شارژ نمی تواند نصب شود) و چند دقیقه نیاز دارید. کابل را متصل نگه دارید تا زمانی که Updater CE بگوید این کار تمام شده است.

## مدل و نرم افزار خود را انتخاب کنید
  - مدل دستگاه: مدل چاپ شده روی پخش کننده را انتخاب کنید، Y1 یا Y2. نرم افزار ساخته شده برای یک مدل را نمی توان روی مدل دیگر نصب کرد.
  - نرم افزار و انتشار: هنگامی که برای مدل شما فهرست شده است، Rockbox، Solar، JJ Launcher، Inniclassic، Y2Player یا Koensayr را انتخاب کنید، سپس یک نسخه را انتخاب کنید. پایدار انتخاب مطمئن است.
  - نصب کنید: کلیک کنید نصب / بازگردانی، پخش کننده را کاملا خاموش کنید و کابل USB را فقط زمانی وصل کنید که Updater CE درخواست کند.
  - پایان: پخش کننده و کابل را تنها بگذارید تا پیام موفقیت آمیز باشد، سپس آن را جدا کرده و پخش کنید.

Y1 بازیکنانی که با نرم‌افزار اصلی قبل از نسخه 2.0.0 ارسال شده‌اند، نیاز دارند دستگاه Type B. همه افراد پیش فرض Type A را حفظ می کنند.دستورالعمل های اتصال به روز رسانی برای اتصال پخش کننده خاموشدرخواست زنده Updater CE را برای مدل خود دنبال کنید.

## بازگشت به نرم افزار اصلی

نرم افزار سفارشی برگشت پذیر است. در Updater CE، مدل خود را انتخاب کنید، انتخاب کنید نرم‌افزار اصلی، یک نسخه پایدار انتخاب کنید، سپس اجرا کنید نصب / بازگردانی به همین ترتیب چیزی برای حذف با دست وجود ندارد.[راهنمای بازیابی Y1](guides/restore-original-y1.html)[راهنمای بازیابی Y2](guides/restore-original-y2.html)

اگر فلاش قبل از فرمان USB متوقف شد، ابتدا کابل، تنظیمات پلت فرم و مدل را بررسی کنید. ببینید [عیب یابی](troubleshooting_fa.html) برای رفع، [راهنمای بازیابی Y1 و Y2](guides/recovery.html) برای خطاهای قدرت و چرخ، و [SP Flash Tool](sp-flash-tool_fa.html) برای بهبودی پیشرفته

این راهنما استفاده می کند Innioasis به روز رسانی 2.5.1، به روز رسانی CE نیز نامیده می شود. آهنگ‌ها، ویدیوها و جفت‌های بلوتوث شما را ایمن نگه می‌دارد. به شما می گوید چه زمانی به روز رسانی ها آماده هستند. Innioasis Universal Flash Tool پخش کننده شما را پاک می کند و به مراحل دستی نیاز دارد. [مقایسه ابزار →](updater-comparison_fa.html)

## ویندوز برنامه را راه اندازی نمی کند؟ راه حل کنترل برنامه هوشمند

Windows Defender SmartScreen یا Smart App Control می‌تواند برنامه‌های تازه دانلود شده انجمن را قبل از انتشار شهرت امضا مسدود کند. Smart App Control در حال حاضر روی برنامه‌های محبوبی مانند Epic Overlay Service (که توسط Fortnite استفاده می‌شود) تأثیر می‌گذارد - Updater CE ایمن و تأیید شده برای استفاده است. خاموش کردن Smart App Control به Updater CE اجازه می دهد تا به طور عادی باز و اجرا شود.
  - باز کنید تنظیمات در رایانه ویندوزی خود (فشار دهید Win + I).
  - کلیک کنید حریم خصوصی و امنیت در نوار کناری سمت چپ، سپس کلیک کنید Windows Security.
  - کلیک کنید کنترل برنامه و مرورگر.
  - زیر کنترل برنامه هوشمند، کلیک کنید تنظیمات کنترل برنامه هوشمند.
  - ضامن را روی خاموش اجازه می دهد تا به روز رسانی CE راه اندازی شود.

از طریق Edge دانلود شده است؟ اگر Edge خود دانلود را مسدود کرد، روی دکمه گزینه های بیشتر کلیک کنید (…) → نگه دارید → نمایش بیشتر → به هر حال نگه دار.

فعال کردن مجدد Smart App Control بعدا: هنگامی که می خواهید Smart App Control را دوباره فعال کنید، می توانید آن را از طریق رجیستری ویندوز در زیر فعال کنید `HKEY_LOCAL_MACHINE\SYSTEM\CurrentControlSet\Control\CI\Policy` با تنظیم `VerifiedAndReputablePolicyState` به `1` (روشن) یا `2` (حالت ارزیابی) و راه اندازی مجدد.

Windows Defender SmartScreen یا Smart App Control می‌تواند برنامه‌های تازه دانلود شده انجمن را قبل از انتشار شهرت امضا مسدود کند.
