# Y2에 Y2Player을(를) 설치합니다.

Y2Player은 Y2을 위해 만들어졌습니다. 실수로 Y1 패키지를 사용하지 않도록 모델을 먼저 선택하세요.[전체 Y2Player 가이드 열기](guides/y2player-y2.html)[이것을 Updater CE에서 얻으세요](guide_ko.html?model=Y2&software=y2player-y2)[왜 Y2Player인가요?](y2player-benefits_ko.html)

## 컴퓨터를 사용하여 Y2에 Y2Player을(를) 설치합니다.

사용 중인 컴퓨터에 대한 가이드를 선택하세요. 모든 버전에는 플랫폼 설정, Updater CE 단계 및 재고로 돌아가는 방법이 있습니다.[윈도우 가이드](install/y2player-y2-windows.html)[macOS 가이드](install/y2player-y2-mac.html)[리눅스 가이드](install/y2player-y2-linux.html)

[모든 Innioasis Y2 가이드](install/y2.html) · [모든 Y2Player 가이드](install/y2player.html)

## Y2Player 설치 단계
  - 컴퓨터에서 Innioasis Updater CE를 엽니다(앱이 필요한 경우, [Updater CE 받기](guide_ko.html#platform)). 세트 기기 모델 에 Y2.
  - 선택 Y2Player 안으로 소프트웨어.
  - Y2에 나열된 릴리스를 선택하십시오.
  - 클릭 설치 / 복원.
  - 전원을 끄고 라이브 프롬프트에서 Y2을 연결합니다.

일부 Y2 전체 설치 패키지는 다음을 사용합니다. `rom_y2.zip`. 가능한 경우 업데이터가 패키지를 선택하도록 합니다.
