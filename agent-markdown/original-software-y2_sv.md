## Installera eller återställ det med Updater

Ställ in datorn först och låt sedan Updater förbereda det modellmatchade paketet.
  - Öppna Innioasis Updater CE på din dator (om du behöver appen, [Hämta Updater CE](guide_sv.html#platform)). Ställ in Enhetsmodell till Y2.
  - Välj Originalprogramvara och en Y2 release.
  - Klicka Installera / Återställ.
  - Stäng av och anslut Y2 endast när liveprompten frågar.

Manuella fullinstallationspaket kan använda `rom_y2.zip`. Behandla inte en Y1 `rom.zip` som ersättare.

## Vanliga frågorKan jag återvända från Rockbox eller annan anpassad programvara?

Använd samma Y2 återställningsflöde: välj Y2, välj Originalprogramvara och följ anslutningsprompten. Blanda inte modellfiler.Varför ser Y2-paketet annorlunda ut?

Y2 releaser kan använda ett annat paketnamn och releasepost. Välj Y2 i Updater istället för att gissa från ett manuellt ZIP-filnamn.Vad händer om spelaren inte upptäcks?

Kontrollera datakabeln, datorbehörigheter eller drivrutiner och tidpunkten. Anslut den avstängda Y2 först efter att Updater säger att den är klar.
