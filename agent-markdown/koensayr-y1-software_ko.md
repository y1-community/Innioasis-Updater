# Innioasis Y1에 대한 Koensayr 펌웨어 | 설치 튜토리얼 - Innioasis 펌웨어 다운로드

Koensayr · Innioasis Y1

# Y1에 Koensayr을(를) 설치합니다.

Koensayr은(는) Y1 커뮤니티 소프트웨어 옵션으로 나열됩니다. 파일 이름으로 패키지를 찾는 대신 모델 인식 업데이터 흐름을 사용하세요.[전체 Koensayr 가이드 열기](guides/koensayr-y1.html)[이것을 Updater CE에서 얻으세요](guide_ko.html?model=Y1&software=koensayr-y1)[왜 Koensayr인가요?](koensayr-benefits_ko.html)

컴퓨터에 대한 설치 가이드

## 컴퓨터를 사용하여 Y1에 Koensayr을(를) 설치합니다.

사용 중인 컴퓨터에 대한 가이드를 선택하세요. 모든 버전에는 플랫폼 설정, Updater CE 단계 및 재고로 돌아가는 방법이 있습니다.[윈도우 가이드](install/koensayr-y1-windows.html)[macOS 가이드](install/koensayr-y1-mac.html)[리눅스 가이드](install/koensayr-y1-linux.html)

[모든 Innioasis Y1 가이드](install/y1.html) · [모든 Koensayr 가이드](install/koensayr.html)

## Koensayr Y1 설치 단계
  - 컴퓨터에서 Innioasis Updater CE를 엽니다(앱이 필요한 경우, [Updater CE 받기](guide_ko.html#platform)). 세트 기기 모델 에 Y1.
  - 선택 Koensayr 안으로 소프트웨어.
  - 나열된 Y1 릴리스를 선택합니다.
  - 클릭 설치 / 복원.
  - 전원을 끄고 Updater CE이 묻는 경우에만 Y1을 연결하세요.

## 자주 묻는 질문원래 Y1 소프트웨어를 복원할 수 있습니까?

예. Updater CE에서 Y1 및 원본 소프트웨어를 선택합니다. 참조 [Y1 재고 소프트웨어 페이지](original-software-y1_ko.html) 완전한 복원 경로를 위해.실패할 경우 무엇을 확인해야 합니까?

프롬프트가 표시되기 전에 모델, 릴리스, 케이블, 플랫폼 설정 및 플레이어 연결 여부를 확인하십시오. 그런 다음 사용 [문제 해결](troubleshooting_ko.html).Koensayr Y2 패키지가 있나요?

현재 빌드는 Y1용입니다. 프로젝트에서 별도의 릴리스를 게시하지 않는 한 Y2에 사용하지 마세요.

## 컴퓨터 설정부터 시작하세요

업데이터는 플랫폼 설정이 준비된 후 Windows, macOS 및 Linux에서 작동합니다. 읽기 [일반 가이드](guide_ko.html#platform) 먼저.
