## JJ Launcher Y1 Installationsschritte
  - Öffnen Sie Innioasis Updater CE auf Ihrem Computer (wenn Sie die App benötigen, [Updater CE holen](guide_de.html#platform)). Satz Gerätemodell an Y1.
  - Wählen Sie JJ Launcher In Software.
  - Wählen Sie die für Y1 angezeigte Version.
  - Klicken Sie Installieren / Wiederherstellen.
  - Schalten Sie das Y1 nur aus und schließen Sie es an, wenn Updater CE dazu fragt.

## FAQKann ich den Eintrag Y2 auf einem Y1 installieren?

Nein. Achten Sie darauf, dass Modell und Verpackung aufeinander abgestimmt sind. Wenn der Eintrag Y1 fehlt, erzwingen Sie keine Y2-Datei.Kann ich zur ursprünglichen Software zurückkehren?

Ja. Wählen Sie Y1 und Originalsoftware in Updater CE. Siehe die [Y1 Wiederherstellungsseite](original-software-y1_de.html).Wo sind alle JJ Launcher Veröffentlichungen?

Aktuelle Builds sind da [Software-Downloads](firmware_de.html#y1). Versionshinweise finden Sie auf dem Projekt [Versionshinweise](release_notes_de.html?software=jj-launcher-y1).
