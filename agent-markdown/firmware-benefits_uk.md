# Переваги мікропрограми та порівняння програмного забезпечення - Innioasis Завантаження мікропрограм

Каталог програмного забезпечення · Innioasis і Timmkoo

# Порівняйте мікропрограми та параметри програмного забезпечення

Від офіційного заводського оригінального програмного забезпечення до творінь спільноти, таких як Rockbox, Solar, Better-Y і Reborn (Y2Linux), відкрийте для себе найкраще програмне забезпечення для ваших звичок аудіо.[Перегляньте завантажені програми](firmware_uk.html)[Допоможіть вибрати](firmware-faq_uk.html)[Отримати Updater CE](guide_uk.html#platform)

## Огляд програмного забезпеченняЗаводська прошивка

### Заводське ПЗ

Повна підтримка Bluetooth-аудіо, FM-радіо, аудіокниг і власних оболонок із галереї тем. [Дізнайтеся більше →](original-software-benefits_uk.html)Аудіофільський стандарт

### Rockbox

Параметричний еквалайзер, безперервне відтворення, перехресна подача та широке налаштування теми. [Дізнайтеся більше →](rockbox-benefits_uk.html)Покращена фабрика

### Better-Y

Покращення спільноти на основі оригінального програмного забезпечення з користувацькими завантаженнями, виправленими програмами та підтримкою тем. [Дізнайтеся більше →](better-y-benefits_uk.html)Сучасний інтерфейс користувача

### Solar

Чистий сучасний інтерфейс із багатою ілюстрацією художника та спеціальною анімацією. [Дізнайтеся більше →](solar-benefits_uk.html)Рідний Linux

### Reborn (Y2Linux)

Операційна система на основі Debian, розроблена для Y2 коліщатка, що виправляє відключення Bluetooth. [Дізнайтеся більше →](reborn-y2linux-benefits_uk.html)Швидкість і фокус

### Rondo

Легка спеціальна прошивка аудіо коліщатка для Y1. [Дізнайтеся більше →](rondo-benefits_uk.html)
