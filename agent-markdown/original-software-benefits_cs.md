# Původní software pro hráče Innioasis a Timmkoo

Původní software je systém, se kterým je váš přehrávač dodán. Stabilní, s tématy z [Galerie motivů](https://themes.innioasis.app/?lang=cs), FM rádio, Bluetooth, audioknihy a bezpečné obnovení v Updater CE.[Procházet software ke stažení](firmware_cs.html)[Získat Updater CE](guide_cs.html#platform)[Procházet galerii motivů](https://themes.innioasis.app/?lang=cs)

## Proč používat nebo obnovovat původní software?

### Plná podpora galerie motivů

Původní software na Y1 a Y2 pracuje přímo s vlastními vzhledy z [Galerie motivů](https://themes.innioasis.app/?lang=cs). Změňte ikony, tapety na pozadí, ovladače přehrávače a písma bez úpravy základních systémových oddílů.

### Všechno funguje hned po vybalení

Plná podpora Bluetooth sluchátek a audiozařízení do auta, fyzická navigace klikacím kolečkem, hardwarové ladění FM rádia, záložky audioknih, e-knihy a přehrávání videa s nulovou manuální konfigurací.

### Bezpečné zotavení & Unbrick Baseline

Pokud se někdy budete chtít vrátit z experimentu s vlastním firmwarem nebo obnovit přehrávač, který nelze spustit, Updater CE obnoví původní software v jediném řízeném kroku.

## Podporované modely a balíčkyInnioasis

### Innioasis Y1 & Y2

MP3 přehrávače Clickwheel s displejem 240p a 360p. Original Software poskytuje tovární zvukové profily a podporu témat.[Y1 Průvodce obnovením](guides/restore-original-y1.html)[Y2 Průvodce obnovením](guides/restore-original-y2.html)Innioasis

### Innioasis G1, G3 & G5

Dotykové přehrávače se systémem Android. Tovární paměti ROM obnovují původní spouštěč, ladění zvuku a systémové aplikace.[Najděte ROM G-Series](firmware_cs.html)Innioasis & Timmkoo

### Innioasis R1, PR1 & Timmkoo Q3, Q5

Hi-Fi audio přehrávače a digitální rekordéry. Oficiální tovární balíčky obnovují původní oddíly firmwaru a kalibraci.[Procházet všechny modely](firmware_cs.html)
