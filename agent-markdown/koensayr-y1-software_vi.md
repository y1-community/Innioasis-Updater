## Koensayr Y1 install steps
  - Mở Innioasis Updater CE trên máy tính của bạn (nếu bạn cần ứng dụng này, [Tải Updater CE](guide_vi.html#platform)). Đặt Mẫu thiết bị để Y1.
  - chọn Koensayr trong Phần mềm.
  - Choose the listed Y1 release.
  - nhấp chuột Cài đặt / Khôi phục.
  - Tắt nguồn và chỉ kết nối Y1 khi Updater CE yêu cầu.

## Câu hỏi thường gặpCan I restore the original Y1 software?

Yes. Select Y1 and Original Software in Updater CE. See the [Y1 stock-software page](original-software-y1_vi.html) for the complete restore route.What should I check when it fails?

Check the model, release, cable, platform setup, and whether the player was connected before the prompt. Then use [khắc phục sự cố](troubleshooting_vi.html).Is there a Koensayr Y2 package?

The current build is for Y1. Don't use it on a Y2 unless the project publishes a separate release for it.
