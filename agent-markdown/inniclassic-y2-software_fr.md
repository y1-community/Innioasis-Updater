# Installez Inniclassic sur le Y2.

Inniclassic est disponible pour le Innioasis Y2, et le même projet construit également les packages Y1. Cette page vous donne un aperçu de Y2 et des liens vers le didacticiel complet.[Ouvrir le guide Inniclassic complet](guides/inniclassic-y2.html)[Disponible dans Updater CE](guide_fr.html?model=Y2&software=inniclassic-y2)[Pourquoi Inniclassic ?](inniclassic-benefits_fr.html)

## Installez Inniclassic sur votre Y2 avec votre ordinateur

Choisissez le guide correspondant à l'ordinateur que vous utilisez. Chaque version comprend la configuration de la plate-forme, Updater CE étapes et le chemin de retour au stock.[Guide Windows](install/inniclassic-y2-windows.html)[Guide macOS](install/inniclassic-y2-mac.html)[Guide Linux](install/inniclassic-y2-linux.html)

[Tous les Innioasis guides Y2](install/y2.html) · [Tous les guides Inniclassic](install/inniclassic.html)

## Inniclassic Y2 étapes d'installation
  - Ouvrez Innioasis Updater CE sur votre ordinateur (si vous avez besoin de l'application, [Obtenir Updater CE](guide_fr.html#platform)). Ensemble Modèle d'appareil à Y2.
  - Choisissez Inniclassic dans Logiciel.
  - Choisissez la version répertoriée pour Y2.
  - Cliquez Installer / Restaurer.
  - Éteignez et connectez le Y2 uniquement lorsque Updater CE le demande.

## FAQPuis-je restaurer le logiciel d'origine Y2 ?

Oui. Sélectionnez Y2 et Logiciel original dans Updater CE. Le [Y2 guide des logiciels en stock](original-software-y2_fr.html) couvre le chemin de retour.Puis-je utiliser Inniclassic sur Y1 ?

Oui. Le même projet publie également des packages Y1 – rom.zip pour Type A et rom_type_b.zip pour Type B. Sélectionnez Y1 dans Updater CE et installez la version Y1 ; le [Page d'installation Y1](inniclassic-y1-software_fr.html) le recouvre.Que se passe-t-il si l'installation échoue ?

Notez si le programme de mise à jour a échoué avant ou après la détection du Y2, puis vérifiez le câble, la configuration de la plate-forme, le modèle et le timing de connexion dans [dépannage](troubleshooting_fr.html).
