Vyberte průvodce pro počítač, který používáte. Každá verze má nastavení platformy, Updater CE kroky a cestu zpět na sklad.[Průvodce Windows](install/koensayr-y1-windows.html)[průvodce macOS](install/koensayr-y1-mac.html)[Linux průvodce](install/koensayr-y1-linux.html)

## Koensayr Y1 install steps
  - Otevřete Innioasis Updater CE na svém počítači (pokud potřebujete aplikaci, [Získat Updater CE](guide_cs.html#platform)). Soubor Model zařízení do Y1.
  - Vyberte si Koensayr v Software.
  - Choose the listed Y1 release.
  - Klikněte Nainstalovat / Obnovit.
  - Vypněte a připojte Y1 pouze tehdy, když se zeptá Updater CE.

## Časté dotazyCan I restore the original Y1 software?

Yes. Select Y1 and Original Software in Updater CE. See the [Y1 stock-software page](original-software-y1_cs.html) for the complete restore route.What should I check when it fails?

Check the model, release, cable, platform setup, and whether the player was connected before the prompt. Then use [odstraňování problémů](troubleshooting_cs.html).Is there a Koensayr Y2 package?

The current build is for Y1. Don't use it on a Y2 unless the project publishes a separate release for it.
