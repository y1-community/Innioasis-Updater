## Rockbox Y1 pasos de instalación
  - Abra Innioasis Updater CE en su computadora (si necesita la aplicación, [Obtener Updater CE](guide_es.html#platform)). conjunto Modelo del dispositivo a Y1.
  - elegir Rockbox en Software.
  - Elija la versión y la variante que coincidan con la pantalla o la ruta del tema deseada.
  - Haga clic Instalar / Restaurar y espera a que la aplicación lo prepare.
  - Apague y conecte el Y1 solo cuando se le indique en vivo.

Utilice el [guía escrita Rockbox Y1](guides/rockbox-y1.html) para las capturas de pantalla, el video, la nota Type A o Type B y la lista de verificación de conexión.

## Preguntas frecuentes¿Puedo volver al software Y1 original?

Sí. Elija Y1 y el software original en Updater CE, luego ejecute Instalar/Restaurar. El [Y1 página de software de stock](original-software-y1_es.html) explica esa ruta.¿Qué versión Rockbox debo elegir?

Elija una versión que se muestra para Y1 y lea su nota de versión. Si necesita compatibilidad con temas anteriores, consulte las notas de resolución y variantes en lugar de seleccionar una compilación Y2.¿Puedo instalar esto en un Y2?

No. Utilice el separado [Rockbox Y2 página](rockbox-y2-software_es.html) y seleccione Y2 en Updater CE.
