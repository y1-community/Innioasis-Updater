# Y2 に Inniclassic をインストールします。

Inniclassic は Innioasis Y2 で使用でき、同じプロジェクトで Y1 パッケージもビルドされます。このページには、Y2 の概要と完全なチュートリアルへのリンクが記載されています。[Inniclassic ガイド全体を開く](guides/inniclassic-y2.html)[Updater CE で入手](guide_ja.html?model=Y2&software=inniclassic-y2)[なぜInniclassic?](inniclassic-benefits_ja.html)

## コンピュータを使用して Y2 に Inniclassic をインストールします

使用しているコンピュータのガイドを選択してください。 すべてのバージョンには、プラットフォームのセットアップ、Updater CE の手順、および在庫に戻る方法が含まれています。[Windowsガイド](install/inniclassic-y2-windows.html)[macOS ガイド](install/inniclassic-y2-mac.html)[Linuxガイド](install/inniclassic-y2-linux.html)

## Inniclassic Y2 のインストール手順
  - コンピューターで Innioasis Updater CE を開きます (アプリが必要な場合は、 [Updater CE を入手](guide_ja.html#platform)）。セット デバイスモデル 支援先: Y2.
  - 選択してください Inniclassic で ソフトウェア.
  - Y2 にリストされているリリースを選択します。
  - クリック インストール / 復元.
  - Updater CE が要求した場合にのみ、電源をオフにして Y2 を接続してください。

## よくある質問在庫 Y2 ソフトウェアを復元できますか?

はい。 Y2を選択し、Updater CEでオリジナルソフトウェアを選択します。の [Y2 ストック ソフトウェア ガイド](original-software-y2_ja.html) 復路をカバーします。Y1 で Inniclassic を使用できますか?

はい。同じプロジェクトが Y1 パッケージも公開しています — rom.zip Type A の場合と rom_type_b.zip Type Bの場合。 Updater CE で Y1 を選択し、Y1 ビルドをインストールします。の [Y1 インストールページ](inniclassic-y1-software_ja.html) それをカバーします。インストールに失敗した場合はどうなりますか?

Y2 を検出する前または後にアップデーターが失敗したかに注意し、ケーブル、プラットフォームのセットアップ、モデル、および接続のタイミングを確認してください。 [トラブルシューティング](troubleshooting_ja.html).
