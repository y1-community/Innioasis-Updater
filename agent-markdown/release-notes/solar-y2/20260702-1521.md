Solar is not yet stable for everyday use - we recommend using this only if you're willing to face bugs and report issues at github.com/thesolarproject/solar/issues

Solar is a custom firmware and launcher for the [Innioasis Y1](https://innioasis.com/pages/y1) — a full interface replacement with podcast downloads, a global quick menu, Reach (Deezer + Soulseek), Y1 theme support and a Stem Player clone.

### Features
  - 🎵 Reach — search, play and download music from Deezer and Soulseek
  - YouTube — Play / Download videos and music from YouTube
  - 🎙️ Podcasts — search and download episodes to your Y1 over the internet
  - ⚡ Quick menu — global context menu for playback, queue, Wi‑Fi, Bluetooth, and more
  - 🎨 Y1 themes — install and apply themes from the original Y1/Y2 firmware

## Assets
  - `app-release.apk` — signed Solar launcher
  - `rom.zip` — Y1 type A firmware (2.0.0+, MT6572)
  - `rom_type_b.zip` — Y1 type B firmware (before 2.0.0, MT6572)
