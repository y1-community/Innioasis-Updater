## Install
  - Download `rom_r1.zip` (every numbered volume if the release has more than one, then `cat rom_r1.zip.* > rom_r1.zip`).
  - Unzip it. Keep the scatter file next to the images.
  - Open SP Flash Tool, choose Download Only, load the scatter file from the archive and flash.
  - Or use Innioasis Updater CE: [https://innioasis.app/guide.html](https://innioasis.app/guide.html)

This wipes the player. Back up music and recordings first.
