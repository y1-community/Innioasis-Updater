## 🚀 What's New in v0.9

### ✨ New Features & Improvements
  - Added User Equalizer (EQ), Bass Boost, and Spatial Audio Engine
    - Customize your sound with the new custom EQ settings, enhanced bass boost, and an immersive spatial audio engine.

  - Full Playlist File Support
    - You can now easily create, delete, and manage your playlist files directly within the app.

  - File Information Display
    - Added the ability to view detailed file and track information directly on the player screen.

  - Bug Fixes
    - Fixed various minor bugs and improved overall system stability.
