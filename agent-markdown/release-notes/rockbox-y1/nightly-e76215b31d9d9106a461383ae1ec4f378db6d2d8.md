# Please read!

This release is especially experimental and will probably cause issues. Follow the guide at the end if you want to try it.

This is a full rebase on the current upstream Rockbox repository as a preparation for eventually submitting this port to the Rockbox project.

For now this means the removal of very specific and rarely used features like the Apps menu. It also means simpler merges of new upstream features. 360p only, there won't be any future 240p releases.

Since a lot had to change under the hood you will need to do the following:
  - Delete `.rockbox` on your SD card.
  - Full flash of the new ROM.
  - Install any of the patched themes from here: [https://github.com/rockbox-y1/themes/archive/refs/heads/patch.zip](https://innioasis.app/rockbox-y1-themes.html)
  - If you want to use any custom themes that worked for older Rockbox-Y1 versions, you will need to change paths in the theme files from `/.rockbox` to `/sdcard/.rockbox`

Other changes:
  - fixes WPS hotkey for plugins
