# InniClassic 20261001

A classic-style Y1 Software.20261001Y12026-10-01[JonaszPotoniec/inniclassic-y2](https://innioasis.app/firmware.html?model=Y1&software=inniclassic-y1)[Get it in Updater CE](../../guide.html?model=Y1&software=inniclassic-y1)[Firmware Downloads](../../firmware.html?model=Y1&software=inniclassic-y1)
  - Volume now uses a 30-step virtual scale with an iPod-style overlay across all screens instead of the stock Android popup. It works across music, video playback, FM radio, and Music Quiz, and includes six extra-quiet digital sub-steps at the bottom of the scale (down to -28 dBFS) for sensitive earphones.
  - A full QWERTY on-screen keyboard is now available in Settings alongside the original grid layout. It includes a symbol layer, column memory when moving vertically across the spacebar, lighter 10ms key vibration, and full punctuation (`; : , / \ ( ) [ ] { } < > ' ~ \``and`|`) for Wi-Fi passwords and search queries.
  - Cover Flow and album lists use a 9-slot buffered layout and a 256x256 disk and RAM thumbnail cache (`.y1_thumbs_cache`), eliminating card pop-in and lag when spinning the wheel fast or reversing direction.
  - Holding the Center button for 0.8 seconds now locks all buttons and turns the screen off (Hold mode, from upstream 1.4.4). Hold Center again to unlock.
  - On Now Playing, wheel seeking previews the target time in 5-second steps until you press Center to jump, and pausing in the Classic theme keeps album art bright while remembering your active bottom bar mode. Starting a video also pauses active music so the Play/Pause button controls the video.
  - Custom themes no longer reset to the default theme after unplugging from USB Mass Storage because the selected theme is now saved by name instead of folder scan order. Newly created `.scrobbler.log` files also declare `#TZ/UTC` so scrobble importers read their timestamps as UTC.
