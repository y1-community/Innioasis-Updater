# InniClassic 20260929

A classic-style Y1 Software.20260929Y12026-09-29[JonaszPotoniec/inniclassic-y2](https://innioasis.app/firmware.html?model=Y1&software=inniclassic-y1)[Get it in Updater CE](../../guide.html?model=Y1&software=inniclassic-y1)[Firmware Downloads](../../firmware.html?model=Y1&software=inniclassic-y1)
  - Muted wheel clicks, system touch sounds, and vibration when the screen is off and "Screen Off Control" is disabled in Settings. Accidental touches in your pocket no longer make noise, buzz, or reset the backlight timer to wake the screen, and feedback turns back on as soon as you wake the display.
