# InniClassic 20260928 (Build 6)

A classic-style Y1 Software.20260928-build.6Y12026-09-28[JonaszPotoniec/inniclassic-y2](https://innioasis.app/firmware.html?model=Y1&software=inniclassic-y1)[Get it in Updater CE](../../guide.html?model=Y1&software=inniclassic-y1)[Firmware Downloads](../../firmware.html?model=Y1&software=inniclassic-y1)
  - Removed Android's Safe Media Volume cap in both the app and the ROM so headphone volume can reach 100% without stopping at the system warning limit. You can also tap or drag the on-screen volume bar to change the volume directly.
  - Added a full Polish translation and improved how bundled language files load on startup.
