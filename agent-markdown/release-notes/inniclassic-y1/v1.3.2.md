Small follow-up polish release.

### Fixed
  - Videos screen looked out of place compared to every other menu (Settings, Bluetooth, Wi-Fi) — it was missing the uppercase title header those screens have. Added, matching the existing look exactly.

### Install
  - `rom.zip` — flash via the [Innioasis Updater](https://innioasis.app/guide.html), no ADB required. Must keep the filename exactly `rom.zip`.
  - `InniClassic-1.3.2.apk` — install over an existing JJ Launcher / InniClassic install via `adb install InniClassic-1.3.2.apk`.

Full changelog: [CHANGELOG.md](https://innioasis.app/post_install.html?url=https%3A%2F%2Fgithub.com%2FFabianZettl%2Finniclassic%2Fblob%2Fmaster%2FCHANGELOG.md)
