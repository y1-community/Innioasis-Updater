# InniClassic 20260927

Inniclassic build for the Innioasis Y2.20260927Y22026-09-27[JonaszPotoniec/inniclassic-y2](https://innioasis.app/firmware.html?model=Y2&software=inniclassic-y2)[Get it in Updater CE](../../guide.html?model=Y2&software=inniclassic-y2)[Firmware Downloads](../../firmware.html?model=Y2&software=inniclassic-y2)

First release with support for the Innioasis Y2 alongside the Innioasis Y1 (Type A and Type B).
  - Music, audiobooks, and videos are now indexed across both internal storage (`/storage/sdcard0`) and the removable microSD card (`/storage/sdcard1`).
  - A background SD card monitor watches for unexpected microSD disconnects, such as after unplugging from USB, and remounts the card automatically before refreshing your library. This also fixes a crash loop during media indexing and stops the monitor from touching internal storage.
  - The Y2 capacitive click wheel (`mtk-tpd-kpd`) is mapped to standard left and right scroll navigation across all menus and lists.
  - FM radio now works on the Y2. Opening the radio sets tuner device permissions, stops background stock radio apps that would otherwise lock `/dev/fm`, and keeps Airplane Mode from blocking the tuner.
  - Automated builds produce flashable ROM packages for the Y2, Y1 Type A, and Y1 Type B, along with a standalone APK.
