This fork is kept as the OTA endpoint for devices running the InniClassic builds, and as an archive of the last release published under that name.

Mirror of [20261105 on ClassyPlayer/Classy](https://innioasis.app/release_notes.html?author=ClassyPlayer&project=Classy&version=20261105&software=classy-formerly-inniclassic-for-y2-y2). Only the launcher APK and the OTA metadata are copied here; the flashable ROMs (~2.1 GB) stay on the Classy repository.

### InniClassic Release

Automated build with full support for Innioasis Y1 (Type A & Type B) and Innioasis Y2.

#### 📦 Release Assets``````

| File | Target Device | Notes |
| --- | --- | --- |
| InniClassic-20261105.apk | All Devices (Y1 / Y2) | Standalone launcher APK (sideload or install) |
| update.json | All Devices | OTA update metadata for in-app updater |
| SHA256SUMS.txt | All Files | SHA-256 integrity checksums |

The flashable ROMs are not mirrored here — download them from [ClassyPlayer/Classy 20261105](https://innioasis.app/release_notes.html?author=ClassyPlayer&project=Classy&version=20261105&software=classy-formerly-inniclassic-for-y2-y2):``````````

| File | Target Device | Notes |
| --- | --- | --- |
| rom_y2.zip | Innioasis Y2 (MT6582) | Complete flashable ROM with dual-storage, watchdog & clickwheel keylayout |
| rom_y1_type_a.zip (rom.zip) | Innioasis Y1 (Type A) | Flashable ROM for Y1 players with original firmware 2.0.0 or higher |
| rom_y1_type_b.zip (rom_type_b.zip) | Innioasis Y1 (Type B) | Flashable ROM for Y1 players with original firmware below 2.0.0 |

#### ⚡ Flashing Instructions (SP Flash Tool)
  - Extract the corresponding zip file for your device.
  - Launch `flash_tool.exe` (or Linux `flash_tool`).
  - Load the scatter file (`MT6582_Android_scatter.txt` for Y2, `MT6572_Android_scatter.txt` for Y1).
  - Select Firmware Upgrade or Download Only.
  - Power off the device completely, click Download, and connect the USB cable.
