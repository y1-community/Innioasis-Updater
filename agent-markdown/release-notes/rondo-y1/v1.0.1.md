A small update to Rondo for the Innioasis Y1, Type A. If your Y1 already runs Rondo, it installs over the one you have in about a minute, and everything stays: settings, Wi-Fi, server connection, playlists and music.

## What's new
  - Click sound stays off. Turning off Settings › Click sound (or the switch in the dashboard) now lasts through a restart. Before, the Y1's own sound profile turned the click back on every time it started.
  - Every release now comes with its firmware. The `rom.zip` that Innioasis Updater CE installs is built automatically for each release, so a new install always gets the newest Rondo.
  - Rondo knows which updates it can install. The firmware now carries a version of its own. If a future release changes the firmware itself, not only Rondo, Settings › Software update, the dashboard and the update page say so and point you to Innioasis Updater CE, instead of offering an install that couldn't work.
  - One place for news of a release. The Y1 (through your server), the dashboard and the update page all learn about a new Rondo from the update page, once its firmware is ready, so they always agree with each other and with Innioasis Updater CE.
  - New README and guides, with screenshots.

The full list is in [CHANGELOG.md](https://innioasis.app/post_install.html?url=https%3A%2F%2Fgithub.com%2Fjarvissax%2Frondo%2Fblob%2Fmain%2FCHANGELOG.md).

## Updating from 1.0.0

Pick whichever is handiest; none of them reinstalls the firmware:
  - On the Y1: Settings › Software update, then Install now (needs your Rondo server).
  - In the dashboard: Settings › Dashboard on the Y1, open it on your phone, press Install.
  - Over USB: open [the update page](https://jarvissax.github.io/rondo/) in Chrome or Edge and plug the Y1 in.

If you run a Rondo server, update it too ([how](https://innioasis.app/post_install.html?url=https%3A%2F%2Fgithub.com%2Fjarvissax%2Frondo%2Fblob%2Fmain%2Fdocs%2Fserver.md%23keeping-it-running&anchor=keeping-it-running)); it's 1.0.1 as well.

## Installing for the first time

Choose Rondo in [Innioasis Updater CE](https://innioasis.app) (Y1, then Type A), or download `rom.zip` below and use the Updater's Settings › Install from a file…. Installing replaces everything on the Y1 itself; the microSD card isn't touched. The [install guide](https://innioasis.app/guides/rondo-y1.html) has the details.

Only for the Y1 Type A (players that shipped with software 2.0.0 or later), not the Type B or the Y2.

## Files
  - `rom.zip`: the firmware, for Innioasis Updater CE (Y1 Type A). Built from `rondo-1.0.1.apk` by this repository's release workflow, a few minutes after publishing.
  - `rondo-1.0.1.apk`: the update, for a Y1 that already runs the Rondo firmware.
