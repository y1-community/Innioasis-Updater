# Rockbox Y2 V2.5

V2.5 updates the Y2 dual-boot firmware to the official Innioasis Stock 3.2FM baseline while retaining Rockbox and Stock boot routes.

## What changed from V2
  - Stock mode is updated to version `3.2` from the 3.2FM firmware release.
  - Clean installs default to MacClassic-Dark with a black Rockbox title screen.
  - Boot presentation and route handoff were requalified to prevent persistent

upper-screen artifacts.
  - The Community Updater asset is now a complete 3.2FM-based full-ROM package,

compatible with the public updater's clean-install route.

## Qualified V2.5 behavior

The five V2.5 firmware images have passed the full hands-on matrix on macOS and Windows:
  - Clean, responsive Rockbox root in about 28 seconds on normal cold boots.
  - Clean dark Rockbox title with no persistent upper artifacts.
  - Automatic screen timeout, centre wake, and power-button sleep/wake.
  - USB-storage mount, safe eject, clean return, and foreground retention.
  - Boot Settings switching between Rockbox and Stock.
  - Responsive Stock root reporting version `3.2` from Stock 3.2FM.
  - No microSD card required for installation or normal boot testing.

The exact public full-ROM archive passed clean Stock 3.2FM installation and the complete functional matrix on both macOS and Windows.

## Important installation behavior

V2.5 performs a clean full installation and erases internal user data. Back up first. On macOS, public Updater CE hands the install to the Innioasis Y2 Install Tool. On Windows, Updater CE uses its full Y2 installation route. Follow every connection prompt and wait for an explicit completion message.
