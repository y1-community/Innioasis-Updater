  - Added native USB Mass Storage support for the microSD card when plugging the player into a computer. A prompt asks whether to "Connect as Storage" or "Charge Only" (which can be toggled under Settings -> Ask on USB Connect). While connected, the player shows an iPod-style "Connected - Eject before disconnecting" screen where pressing Center safely ejects the drive and automatically rescans your library for newly added music.
  - Translated the new keyboard settings, "Add to Favorites", equalizer headers, screen recorder prompts, and error toasts across all 7 supported languages, and replaced leftover Korean internal keys in the screen recorder menus with English text.
