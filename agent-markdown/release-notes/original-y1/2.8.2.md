# System Software Update 2.8.2

This Original Software release predates 3.0.7. It is not compatible with Y1 units sold with Innioasis OS 3.0.7; flashing it on those units will prevent booting until a newer version is reinstalled.

Video Fix: Resolved an issue that prevented videos from being paused reliably.

Video Stability: Improved handling of video playback to prevent the application from crashing (fixing IllegalStateException on startup).

Video Management: Enhanced logic for checking video folders to ensure that non-folder files are skipped.

Multilingual Support:

User Interface (UI):

Implemented a scrolling marquee effect for file names that are too long to fit on the screen.

Fixed several bugs related to the Theme interface.

File Management:

Improved folder deletion logic to ensure all checks for video files are completed.

Changed file name sorting to be case-insensitive (treating "A" and "a" the same).

Music & Video Sync:

Fixed a bug where the music database was not synchronized when video folders were deleted.

Crucial Fix: Ensured that music playback is completely stopped when a video starts playing.

Database: Database version updated from 3 to 4.

Key Lock: Modified the Key Lock implementation to ensure it persists correctly after a restart.

Video Thumbnails: Reduced the number of concurrent processes for generating video thumbnails to prevent conflicts and improve stability.

Video Thumbnails: Optimized thumbnail generation logic, now saving thumbnails as files for better performance.

Video Error Handling: Adjusted video error detection (error code -38 is no longer treated as a playback failure).

Search/Multi-select: Fixed an issue where the multi-select status and search results were not cleared after adding items to a playlist.

Localization: Corrected German and French translations.

Playback List: Fixed issues where default playback list names were not set according to the device's primary language after a factory reset.

Theming/Customization: Fixed bugs related to theme deletion and ensuring the default wallpaper is restored correctly.

Theme Installation: Default themes are now copied in the background to prevent copying from stopping if the screen turns off.
