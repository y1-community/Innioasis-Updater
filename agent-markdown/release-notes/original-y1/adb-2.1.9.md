# System Software Update 2.1.9

The stock Software path for restoring an Innioasis Y1.ADB-2.1.9Y12025-07-18[y1-community/y1-stock-rom](https://innioasis.app/firmware.html?model=Y1&software=original-y1)[Get it in Updater CE](../../guide.html?model=Y1&software=original-y1)[Firmware Downloads](../../firmware.html?model=Y1&software=original-y1)Original Software Compatibility Warning

This Original Software release predates 3.0.7. It is not compatible with Y1 units sold with Innioasis OS 3.0.7; flashing it on those units will prevent booting until a newer version is reinstalled.
