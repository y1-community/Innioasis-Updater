# Rockbox เฟิร์มแวร์สำหรับ Innioasis Y2 | ติดตั้งบทช่วยสอน - Innioasis ดาวน์โหลดเฟิร์มแวร์

Rockbox · Innioasis Y2

# ติดตั้งซอฟต์แวร์ Y2 Rockbox ไม่ใช่บิลด์ Y1

การเดินทางของ Updater นั้นคุ้นเคย แต่ Y2 จำเป็นต้องมีการเลือกรุ่นและการเปิดตัวของตัวเอง หน้านี้ตอบคำถามทั่วไป "Rockbox ใน Y2" ก่อนที่คุณจะเริ่ม[เปิดคำแนะนำ Rockbox ฉบับเต็ม](guides/rockbox-y2.html)[รับสิ่งนี้ใน Updater CE](guide_th.html?model=Y2&software=rockbox-y2)[ทำไมต้อง Rockbox?](rockbox-benefits_th.html)

คู่มือการติดตั้งสำหรับคอมพิวเตอร์ของคุณ

## ติดตั้ง Rockbox บน Y2 ด้วยคอมพิวเตอร์ของคุณ

เลือกคำแนะนำสำหรับคอมพิวเตอร์ที่คุณใช้ ทุกรุ่นมีการตั้งค่าแพลตฟอร์ม ขั้นตอน Updater CE และวิธีคืนสินค้าในสต็อก[คู่มือวินโดวส์](install/rockbox-y2-windows.html)[คู่มือ macOS](install/rockbox-y2-mac.html)[คู่มือลินุกซ์](install/rockbox-y2-linux.html)

[คำแนะนำ Innioasis Y2 ทั้งหมด](install/y2.html) · [คำแนะนำ Rockbox ทั้งหมด](install/rockbox_th.html)

## Rockbox Y2 ขั้นตอนการติดตั้ง
  - เปิด Innioasis Updater CE บนคอมพิวเตอร์ของคุณ (หากคุณต้องการแอป [รับ Updater CE](guide_th.html#platform)). ชุด รุ่นอุปกรณ์ ถึง Y2.
  - เลือก Rockbox ใน ซอฟต์แวร์.
  - เลือกรุ่นที่ระบุไว้อย่างชัดเจนสำหรับ Y2
  - คลิก ติดตั้ง / คืนค่า และรอการเตรียมบรรจุภัณฑ์
  - ปิดเครื่องและเชื่อมต่อ Y2 เมื่อ Updater CE ถามเท่านั้น

อย่าบังคับใช้แพ็กเกจ Y1 เนื่องจากชื่อโปรเจ็กต์มีลักษณะเหมือนกัน หากไม่มีรุ่น Y2 ปรากฏขึ้น ให้หยุดและตรวจสอบรุ่นและข้อมูลรุ่นปัจจุบัน

## คำถามที่พบบ่อยฉันสามารถกู้คืนซอฟต์แวร์ Y2 ดั้งเดิมในภายหลังได้หรือไม่

ใช่. เลือก Y2 และซอฟต์แวร์ต้นฉบับใน Updater CE ดู [Y2 หน้าสต็อกซอฟต์แวร์](original-software-y2_th.html) สำหรับลำดับการคืนค่าเหตุใดแพ็คเกจจึงถูกเรียกว่า rom_y2.zip

นั่นเป็นเบาะแสการดาวน์โหลดด้วยตนเองซึ่งใช้โดย Y2 รุ่นที่ติดตั้งแบบเต็มบางรุ่น ตัวเลือกที่ปลอดภัยกว่ายังคงเลือก Y2 ใน Updater CE และใช้รุ่นที่นำเสนอฉันสามารถใช้บทช่วยสอน Y1 Rockbox ได้หรือไม่

ใช้มันเพื่อความคิดกว้างๆ เท่านั้น สำหรับการเลือกแพ็คเกจและรุ่นให้ทำตามนี้ครับ [Y2-คำแนะนำเฉพาะ](guides/rockbox-y2.html).
