# Installez Android 4.2 (Dev) sur le Y1.

Android 4.2 est un développement communautaire ROM pour tester et pirater le matériel Innioasis Y1. Cette page renvoie au didacticiel complet et à la liste des versions.[Ouvrez le guide complet Android 4.2 (Dev)](guides/android-4-2-y1.html)[Disponible dans Updater CE](guide_fr.html?model=Y1&software=android-4-2-y1)[Origine du projet](https://github.com/y1-community/y1-ata-rom)

## Étapes d'installation d'Android 4.2 Y1
  - Ouvrez Innioasis Updater CE sur votre ordinateur (si vous avez besoin de l'application, [Obtenir Updater CE](guide_fr.html#platform)). Ensemble Modèle d'appareil à Y1.
  - Choisissez Android 4.2 (développement) dans Logiciel.
  - Choisissez la version répertoriée pour Y1.
  - Cliquez Installer / Restaurer.
  - Éteignez et connectez le Y1 uniquement lorsque Updater CE le demande.

## FAQPuis-je restaurer le logiciel d'origine Y1 ?

Oui. Sélectionnez Y1 et le logiciel original dans Updater CE. Le [Guide des logiciels boursiers Y1](original-software-y1_fr.html) couvre le chemin de retour.Est-ce un conducteur quotidien ROM ?

Il s'agit d'un développeur expérimental ROM destiné aux tests et au développement. Les mises à jour des fonctionnalités sont sur la page du projet.
