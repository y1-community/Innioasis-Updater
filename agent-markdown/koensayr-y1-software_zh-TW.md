## Koensayr Y1 安裝步驟
  - 在您的電腦上開啟 Innioasis Updater CE（如果您需要該應用程序， [取得 Updater CE](guide_zh-TW.html#platform)）。套裝 裝置型號 到 Y1.
  - 選擇 Koensayr 在 軟體.
  - 選擇列出的 Y1 版本。
  - 點選 安裝 / 還原.
  - 僅當 Updater CE 詢問時關閉電源並連接 Y1。

## 常見問題我可以恢復原來的Y1軟體嗎？

是的。在 Updater CE 中選擇 Y1 和原始軟體。請參閱 [Y1 庫存軟體頁面](original-software-y1_zh-TW.html) 完整的恢復路線。失敗時該檢查什麼？

在出現提示之前檢查型號、版本、電纜、平台設定以及播放器是否已連接。然後使用 [故障排除](troubleshooting_zh-TW.html).有KoensayrY2包嗎？

目前版本適用於 Y1。不要在 Y2 上使用它，除非專案為其發佈單獨的版本。
