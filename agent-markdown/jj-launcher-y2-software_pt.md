## Verificações corretas do modelo
  - Abra Innioasis Updater CE no seu computador (se precisar do aplicativo, [Obtenha o atualizador CE](guide_pt.html#platform)). Definir Modelo do dispositivo para Y2.
  - Confirmar JJ Launcher aparece para Y2 nos dados da versão atual.
  - Leia a nota de lançamento do projeto e selecione a versão Y2 listada.
  - Clique Instalar / Restaurar.
  - Desligue e conecte o Y2 somente quando solicitado.
Não substitua: um pacote Y1 não é um pacote Y2. Pare se o modelo e a versão não concordarem.

## Perguntas frequentesO suporte Y2 é garantido?
