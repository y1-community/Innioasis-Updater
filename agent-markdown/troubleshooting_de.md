# Innioasis Updater Fehlerbehebung | Innioasis und Timmkoo Installationsprobleme - Innioasis Updater

Fehlerbehebung

# Suchen Sie den Punkt, an dem die Installation gestoppt wurde.

Wo hat es aufgehört? Das sagt Ihnen, was Sie reparieren müssen.[Kehren Sie zur normalen Anleitung zurück](guide_de.html)[Firmware prüfen](firmware_de.html)

## Es stoppte vor der Eingabeaufforderung USB.

Dies ist ein Computerproblem, kein Kabelproblem. Überprüfen Sie Ihr Modell. Entpacken Sie die Datei erneut. Dann versuchen Sie es Installieren / Wiederherstellen. Wenn die Release-Liste leer ist, öffnen Sie die [Firmware-Verzeichnis](firmware_de.html).

## Es kann keine Verbindung zum Player hergestellt werden
  - Schalten Sie die richtige Y1 oder Y2 vollständig aus.
  - Ziehen Sie das Kabel ab, schließen Sie andere Flash- oder Android-Tools und starten Sie die Installation erneut.
  - Stellen Sie die Verbindung nur her, wenn der Updater meldet, dass er bereit ist.
  - Verwenden Sie ein kurzes USB-Datenkabel direkt im Computer, möglichst keinen Hub.
  - Unter Windows installieren Sie den MediaTek-Treiber neu und starten Sie neu. Überprüfen Sie unter Linux die Berechtigungen USB/seriell.
Verbindungsaufforderung des UpdatersDie Live-Updater-Eingabeaufforderung ist für das aktuelle Modell und die aktuelle Plattform maßgeblich.

## Der Player wurde erkannt, aber der Flash ist fehlgeschlagen

Halten Sie hier an. Probieren Sie kein anderes Modell aus. Schließen Sie andere Tools, überprüfen Sie, ob Sie die richtige Y1 oder Y2 ausgewählt haben, und verwenden Sie die passende Originalsoftware, wenn der Player nicht startet. [SP Flash Tool](sp-flash-tool_de.html) und MTKClient sind bei Bedarf enthalten, und die Dateien befinden sich auf der [Firmware-Seite](firmware_de.html).

## Hinweise zum Windows-Treiber

Einige Windows-Installationen blockieren den MediaTek-Treiber aufgrund der Core-Isolation. Befolgen Sie die aktuellen Windows-Sicherheitsrichtlinien, bevor Sie die Speicherintegrität ändern, und schalten Sie sie wieder ein, wenn Sie fertig sind, sofern Ihr System dies zulässt.[Öffnen Sie den Treiberführer](drivers_de.html)[Anleitung zur sauberen Installation](Troubleshooting/clean_install.html)

## Das Rad funktioniert nicht oder der Player startet nicht

Eingangs- und Stromfehler erfordern andere Schritte als ein fehlgeschlagener Flash. Diese Leitfäden decken die häufigsten Fälle Y1 und Y2 ab.[Y1 Scrollrad](guides/y1-scroll-wheel-not-working.html)[Y2 Scrollrad](guides/y2-scroll-wheel-not-working.html)[Y1 lässt sich nicht einschalten](guides/y1-wont-turn-on.html)[Y2 lässt sich nicht einschalten](guides/y2-wont-turn-on.html)[Wiederherstellungsanleitung](guides/recovery.html)
