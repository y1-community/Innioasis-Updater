## קבל Innioasis Updater CE

הנה היכן להתחיל אם עדיין לא קיבלת את Updater CE.השג אותו ב-Updater CEעם התקנה מודרכת

### Windows

הורד את תוכנית ההתקנה, פתח אותו ופעל לפי הנחיות ההתקנה.[הורד והתקן דרייבר](https://github.com/y1-community/supplemental-apks/releases/latest/download/DriverInstall.exe)[הורד אפליקציה ומנהלי התקנים](https://github.com/y1-community/Innioasis-Updater/releases/latest/download/installer.exe)[חסום על ידי Edge?](#)

אם Windows מונע ממך להפעיל את האפליקציה או לא מפעיל אותה, פתח את 'הגדרות', לחץ על פרטיות ואבטחה ← אבטחת Windows ← בקרת אפליקציות ודפדפן, וכבה את בקרת האפליקציה החכמה. [Windows לא יפעיל את האפליקציה? עזרה](#smart-app-control)

תצטרך לאתחל את המחשב לאחר ההתקנה כדי שזה יעבוד.

### macOS

הורד את האפליקציה והעבר אותה לאפליקציות. אם macOS חוסם את זה, פתח את הגדרות מערכת ולאחר מכן פרטיות ואבטחה ולחץ על פתח בכל מקרה. [איך זה עובד](https://support.apple.com/en-gb/102445#openanyway)[הורד את Updater CE](https://github.com/y1-community/Innioasis-Updater/releases/latest/download/Innioasis.Updater.for.Mac.dmg)

### Linux

הורד את AppImage עבור מערכות אינטל ו-AMD, הפוך אותה לניתנת להפעלה והפעל אותה.[הורד את AppImage עבור Intel/AMD](https://github.com/y1-community/innioasis-updater/releases/latest/download/UpdaterCE.AppImage)[הערות התקנה של לינוקס](drivers_he.html#linux)פלטפורמה אחרת?

צריך את הערות הגדרת המחשב הארוכות יותר? פתח את [Windows](drivers_he.html#windows) או [Linux](drivers_he.html#linux) מדריך התקנה.

## באיזה כלי כדאי להשתמש?

Innioasis Updater לספירה היא הדרך הבטוחה ביותר לעדכן את הנגן שלך. זה שומר את המוזיקה, הסרטונים וההתאמות שלך עם Bluetooth. זה אומר לך מתי העדכונים מוכנים. זה פועל על Windows, macOS ו- Linux. ה-Innioasis Universal Flash Tool מנגב את הנגן שלך ועובד על פחות מחשבים.[פתח את ההשוואה המלאה](updater-comparison_he.html)

### Windows לא יפעיל את האפליקציה? כיצד לכבות את בקרת האפליקציה החכמה

Windows Defender SmartScreen או Smart App Control יכולים לחסום יישומי קהילה שהורדו לאחרונה לפני שהמוניטין החתימה יתפשט. בקרת אפליקציות חכמה משפיעה כעת על יישומים פופולריים כמו שירות ה-Epic Overlay (בשימוש על ידי Fortnite) - Updater CE בטוח ומאומת לשימוש. כיבוי Smart App Control מאפשר ל-Update CE להיפתח ולהפעיל כרגיל.
  - פתוח הגדרות במחשב Windows שלך (לחץ על Win + I).
  - לחץ פרטיות ואבטחה בסרגל הצד השמאלי ולאחר מכן לחץ Windows Security.
  - לחץ שליטה באפליקציה ובדפדפן.
  - מתחת בקרת אפליקציה חכמה, לחץ הגדרות בקרת אפליקציה חכמה.
  - הגדר את המתג למצב כבוי כדי לאפשר את הפעלת Updater CE.

חסום על ידי Edge? אם Microsoft Edge חוסם את ההורדה עצמה, לחץ על כפתור אפשרויות נוספות (…) → שמור → הצג עוד → שמור בכל מקרה.

הפעלה מחדש של בקרת אפליקציות חכמה מאוחר יותר: כאשר אתה רוצה להפעיל מחדש את בקרת האפליקציות החכמה, אתה יכול להפעיל אותה מחדש דרך הרישום של Windows תחת `HKEY_LOCAL_MACHINE\SYSTEM\CurrentControlSet\Control\CI\Policy` לפי הגדרה `VerifiedAndReputablePolicyState` ל `1` (מופעל) או `2` (מצב הערכה) והפעלה מחדש.עזרה קרובה
