# Rondo لـ Innioasis Y1

برنامج ثابت لمشغل موسيقى بعجلة النقر تم تصميمه خصيصًا للأجهزة ذات السعة Innioasis Y1، مع التركيز بشكل كامل على التشغيل سريع الاستجابة والتنقل النظيف.[دليل خطوة بخطوة Y1](guides/rondo-y1.html)[لماذا Rondo؟](rondo-benefits_ar.html)[تحميل الإصدارات](firmware_ar.html?model=Y1&software=rondo-y1)

## قم بتثبيت Rondo على جهاز Y1 بجهاز الكمبيوتر الخاص بك

اختر دليل الكمبيوتر الذي تستخدمه. يحتوي كل إصدار على إعداد النظام الأساسي وخطوات Updater CE وطريقة العودة إلى المخزون.[دليل ويندوز](install/rondo-y1-windows.html)[دليل ماك](install/rondo-y1-mac.html)[دليل لينكس](install/rondo-y1-linux.html)

[جميع أدلة Innioasis Y1](install/y1.html) · [جميع الأدلة Rondo](install/rondo.html)

## خطوات التثبيت
  - إطلاق Innioasis Updater م على جهاز الكمبيوتر الذي يعمل بنظام التشغيل Windows أو Mac أو Linux.
  - اختر Y1 من القائمة المنسدلة لطراز الجهاز.
  - اختر Rondo من القائمة المنسدلة للبرامج.
  - انقر تثبيت / استعادة وانتظر حتى تقوم الأداة بتنزيل الملفات وإعدادها.
  - عندما يطلب منك Updater CE، قم بإيقاف تشغيل Y1 الخاص بك وقم بتوصيل الكابل USB.
  - استكمال الإعداد بعد التثبيت

اتبع الخطوات الواردة في [هذا الدليل](post_install_ar.html?software=rondo-y1&model=Y1) لإكمال الإعداد على Y1.[عرض الدليل](post_install_ar.html?software=rondo-y1&model=Y1)
