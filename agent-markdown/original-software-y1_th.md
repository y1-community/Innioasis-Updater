# เฟิร์มแวร์หุ้นดั้งเดิมสำหรับ Innioasis Y1 | ติดตั้งและกู้คืน - Innioasis ดาวน์โหลดเฟิร์มแวร์

ซอฟต์แวร์ต้นฉบับ · Y1 ซอฟต์แวร์สต็อก

# กู้คืนซอฟต์แวร์ต้นฉบับบน Innioasis Y1 ของคุณ

กำลังมองหาซอฟต์แวร์สต็อก Y1 การคืนค่าจากโรงงาน หรือการย้อนกลับจาก Rockbox หรือซอฟต์แวร์อื่นที่กำหนดเองอยู่ใช่ไหม นี่คือเส้นทาง Updater ที่ถูกต้องตามรุ่น[เปิดคู่มือซอฟต์แวร์ต้นฉบับฉบับเต็ม](guides/restore-original-y1.html)[รับสิ่งนี้ใน Updater CE](guide_th.html?model=Y1&software=original-y1)[เรียกดู Y1 รุ่น](firmware_th.html#y1)

คู่มือการติดตั้งสำหรับคอมพิวเตอร์ของคุณ

## กู้คืนซอฟต์แวร์ต้นฉบับบน Y1 ของคุณด้วยคอมพิวเตอร์ของคุณ

เลือกคำแนะนำสำหรับคอมพิวเตอร์ที่คุณใช้ ทุกรุ่นมีการตั้งค่าแพลตฟอร์ม ขั้นตอน Updater CE และวิธีคืนสินค้าในสต็อก[คู่มือวินโดวส์](install/original-y1-windows.html)[คู่มือ macOS](install/original-y1-mac.html)[คู่มือลินุกซ์](install/original-y1-linux.html)

[คำแนะนำ Innioasis Y1 ทั้งหมด](install/y1.html) · [คู่มือซอฟต์แวร์ต้นฉบับทั้งหมด](install/original-software.html)

## ติดตั้งหรือกู้คืนด้วย Updater

Updater ใช้ขั้นตอนแนะนำเดียวกันไม่ว่า Y1 กำลังใช้งานซอฟต์แวร์ต้นฉบับหรือโครงการชุมชนอยู่ก็ตาม
  - เปิด Innioasis Updater CE บนคอมพิวเตอร์ของคุณ (หากคุณต้องการแอป [รับ Updater CE](guide_th.html#platform)). ชุด รุ่นอุปกรณ์ ถึง Y1.
  - เลือก ซอฟต์แวร์ดั้งเดิม ใน ซอฟต์แวร์ (หรือใช้ [รับสิ่งนี้ใน Updater CE](guide_th.html?model=Y1&software=original-y1) เพื่อข้ามไปยังขั้นตอนที่แนะนำ)
  - คลิก ติดตั้ง / คืนค่า และให้แอปเตรียมแพ็คเกจให้
  - ปิดเครื่องและเชื่อมต่อ Y1 เฉพาะเมื่อมีการถามสดเท่านั้น

เมื่อดาวน์โหลดด้วยตนเอง จะมีชื่อแพ็คเกจการติดตั้งแบบเต็มตามปกติ `rom.zip`. การเลือกรุ่นใน Updater เป็นวิธีที่ปลอดภัยกว่าในการเลือกไฟล์

## คำถามที่พบบ่อยฉันสามารถกู้คืนจาก Rockbox หรือซอฟต์แวร์อื่นที่กำหนดเองได้หรือไม่

ใช่ ใช้โมเดล Y1 และเส้นทางซอฟต์แวร์ต้นฉบับ Y1 อย่าลบไฟล์ระบบก่อนและอย่าแทนที่แพ็คเกจ Y2จะเกิดอะไรขึ้นหากตรวจไม่พบ Y1 ของฉัน

ตรวจสอบสายเคเบิลข้อมูล การตั้งค่าคอมพิวเตอร์ และระยะเวลาในการเชื่อมต่อ เครื่องเล่นควรปิดและเชื่อมต่อเฉพาะเมื่อพร้อมท์ Updater เท่านั้นฉันควรใช้แพ็คเกจใดกับ Y1 ของฉัน

คงรุ่นพิมพ์ไว้บนเครื่องเล่นของคุณที่เลือกไว้ใน Updater แพ็คเกจ Y1 และ Y2 แยกจากกัน — หยุดหากรายการวางจำหน่ายไม่ตรงกับรุ่นของคุณ
