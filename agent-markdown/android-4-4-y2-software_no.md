# Install Android 4.4 (Dev) on the Y2.

Android 4.4 is a community development ROM for testing and hacking on Innioasis Y2 hardware. ## Android 4.4 Y2 install steps
  - Åpne Innioasis Updater CE på datamaskinen din (hvis du trenger appen, [Få Updater CE](guide_no.html#platform)). Sett Enhetsmodell til Y2.
  - Velg Android 4.4 (Dev) inn Programvare.
  - Choose the release listed for Y2.
  - Klikk Installer / Gjenopprett.
  - Slå av og koble til Y2 kun når Updater CE spør.
