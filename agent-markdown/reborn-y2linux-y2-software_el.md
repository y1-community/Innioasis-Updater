# Reborn (Y2Linux) για Innioasis Y2

Μια γρήγορη, ειδικά κατασκευασμένη διανομή Debian Linux με μια εγγενή διεπαφή χρήστη με τροχό κλικ για το Innioasis Y2, με σταθερότητα ακουστικών Bluetooth και ενεργή ανάπτυξη κοινότητας.[Οδηγός βήμα προς βήμα Y2](guides/reborn-y2linux-y2.html)[Γιατί Y2Reborn;](reborn-y2linux-benefits_el.html)[Λήψη εκδόσεων](firmware_el.html?model=Y2&software=reborn-y2linux-y2)

Οδηγός εγκατάστασης για τον υπολογιστή σας

## Εγκαταστήστε το Reborn (Y2Linux) στο Y2 σας με τον υπολογιστή σας

Επιλέξτε τον οδηγό για τον υπολογιστή που χρησιμοποιείτε. Κάθε έκδοση έχει τη ρύθμιση της πλατφόρμας, τα βήματα του Updater CE και τον τρόπο επιστροφής στο απόθεμα.[Οδηγός Windows](install/reborn-y2linux-y2-windows.html)[οδηγός macOS](install/reborn-y2linux-y2-mac.html)[Οδηγός Linux](install/reborn-y2linux-y2-linux.html)

[Όλοι οι Innioasis Y2 οδηγοί](install/y2.html) · [Όλοι οι Reborn (Y2Linux) οδηγοί](install/reborn.html)

## Βήματα εγκατάστασης
  - Ανοίξτε το Updater CE. Διαθέσιμο για Windows, macOS και Linux.
  - Επιλέξτε Y2 ως μοντέλο συσκευής.
  - Επιλέξτε Reborn (Y2Linux) όπως το λογισμικό.
  - Κάντε κλικ στην Εγκατάσταση / Επαναφορά. Περιμένετε όσο το Updater CE προετοιμάζει τα αρχεία.
  - Συνδέστε το USB όταν σας ζητηθεί. Απενεργοποιήστε πρώτα το Y2.
  - Ρύθμιση Wi-Fi, Bluetooth και ραδιόφωνο FM

Αντιγραφή `system.img` στον παίκτη μια φορά. Ο Reborn κάνει τα υπόλοιπα.[Ολοκληρώστε τη ρύθμιση →](y2reborn_wifibt_el.html)
