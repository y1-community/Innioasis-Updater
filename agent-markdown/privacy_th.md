# ความเป็นส่วนตัว - Innioasis Updater และ Firmware Archive

# ความเป็นส่วนตัว

อัปเดตล่าสุดเมื่อวันที่ 8 พฤศจิกายน 2026

innioasis.app โฮสต์การดาวน์โหลด Updater CE, ไฟล์เก็บถาวรเฟิร์มแวร์ และคำแนะนำที่มาพร้อมกับสิ่งเหล่านั้น ดำเนินการโดย Ryan Specter พร้อมด้วยชุมชน Innioasis Luci Ltd ให้บริการโฮสติ้ง ไม่มีบัญชีและไม่มีการลงชื่อเข้าใช้

## สิ่งที่ยังคงอยู่บนอุปกรณ์ของคุณ

ไซต์จะบันทึกการตั้งค่าบางอย่างไว้ในเบราว์เซอร์ของคุณ: ภาษา ธีมสี ขนาดตัวอักษร ตัวเลือกความเป็นส่วนตัว ไม่ว่าคุณจะซ่อนคำอุทธรณ์การบริจาค และคำแปลที่ดึงข้อมูลไว้แล้ว สิ่งเหล่านี้จะคงอยู่ในอุปกรณ์ของคุณ การล้างข้อมูลไซต์จะเป็นการลบออก

## สิ่งที่เราวัด

เราใช้ Google Tag Manager กับ Google Analytics เพื่อนับจำนวนการดูหน้าเว็บและเพื่อดูว่าหน้าใดล้มเหลวหรือโหลดช้า Cloudflare ให้บริการโฮสติ้ง การรักษาความปลอดภัย และการป้องกันการโจมตี จำนวนการดาวน์โหลดจะถูกเก็บไว้รวมกัน เราไม่ขอชื่อ อีเมล หรือที่อยู่ทางไปรษณีย์ของคุณ และเราจะไม่ขายข้อมูล

## คุกกี้และที่จัดเก็บในเครื่อง

ไซต์ใช้พื้นที่เก็บข้อมูลเบราว์เซอร์สำหรับการตั้งค่าข้างต้น Google Analytics และ Cloudflare อาจตั้งค่าคุกกี้ของตนเอง คุณสามารถบล็อกหรือล้างคุกกี้ในเบราว์เซอร์ของคุณได้ตลอดเวลา หน้าดาวน์โหลดจะยังคงใช้งานได้

## ทางเลือกของคุณ

คุณสามารถปิดการวิเคราะห์ได้โดยไม่สูญเสียการเข้าถึงการดาวน์โหลดใดๆ การตั้งค่านี้จะถูกจดจำบนอุปกรณ์นี้และแชร์กับแกลเลอรีธีมผ่านคุกกี้บน innioasis.app

การวิเคราะห์อยู่ในขณะนี้ บน สำหรับเบราว์เซอร์นี้

## การบริจาค

ปุ่มบริจาคเชื่อมโยงกับ Ko-fi, Buy Me a Coffee, PayPal, Revolut, Patreon และ Boosty บริการเหล่านั้นจัดการการชำระเงินและข้อมูลของตนเอง ไซต์นี้ไม่เคยเห็นรายละเอียดบัตรของคุณ

## ลิงค์ไปยังเว็บไซต์อื่น

คำแนะนำลิงก์ไปยังผู้ผลิต GitHub และไซต์ชุมชน และส่วนท้ายลิงก์ไปยัง Discord และ Reddit เว็บไซต์เหล่านั้นมีนโยบายความเป็นส่วนตัวของตนเอง เราไม่ได้ควบคุมสิ่งที่พวกเขารวบรวม

## สิทธิของคุณ

หากคุณอาศัยอยู่ใน EEA สหราชอาณาจักร หรือสวิตเซอร์แลนด์ คุณสามารถสอบถามว่าข้อมูลส่วนบุคคลใดที่เกี่ยวข้องกับคุณ ขอสำเนา ขอให้เราลบข้อมูลนั้น หรือคัดค้านการประมวลผล ผู้อยู่อาศัยในแคลิฟอร์เนียสามารถขอทราบหรือลบข้อมูลส่วนบุคคลและสามารถเลือกไม่ขายได้ เราไม่ได้ขายมัน

เนื่องจากไซต์ไม่มีบัญชี เราจึงอาจไม่สามารถเชื่อมต่อคำขอกับผู้เยี่ยมชมได้หากไม่มีบันทึกความยินยอมจัดเก็บไว้ในเบราว์เซอร์ของผู้เยี่ยมชมรายนั้น คุณสามารถติดต่อเราผ่านทาง [หน้าปัญหาพื้นที่เก็บข้อมูล](https://github.com/y1-community/Innioasis-Updater/issues) หรือ [r/innioasis](https://reddit.com/r/innioasis).

## เด็กๆ

ไซต์นี้ไม่ได้มุ่งเป้าไปที่เด็กอายุต่ำกว่า 13 ปี และเราไม่ได้รวบรวมข้อมูลส่วนบุคคลจากพวกเขาโดยเจตนา

## การเปลี่ยนแปลง

หากนโยบายนี้เปลี่ยนแปลง วันที่ด้านบนจะเปลี่ยนตามไปด้วย การเปลี่ยนแปลงเนื้อหาจะถูกบันทึกไว้ในหน้าแรก

ข้อความภาษาอังกฤษในหน้านี้เป็นฉบับที่เชื่อถือได้ มีสำเนาที่แปลไว้เพื่อให้สามารถอ่านนโยบายได้ในภาษาของคุณ หากคำแปลและข้อความภาษาอังกฤษไม่ตรงกัน ให้ใช้ข้อความภาษาอังกฤษ
