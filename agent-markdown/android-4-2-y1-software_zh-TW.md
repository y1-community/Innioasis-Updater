Android 4.2 是一個社群開發 ROM，用於在 Innioasis Y1 硬體上進行測試和駭客攻擊。此頁面連結到完整的教學和版本清單。[開啟完整的 Android 4.2（開發）指南](guides/android-4-2-y1.html)[在 Updater CE 中取得此內容](guide_zh-TW.html?model=Y1&software=android-4-2-y1)[專案來源](https://github.com/y1-community/y1-ata-rom)

## Android 4.2 Y1安裝步驟
  - 在您的電腦上開啟 Innioasis Updater CE（如果您需要該應用程序， [取得 Updater CE](guide_zh-TW.html#platform)）。套裝 裝置型號 到 Y1.
  - 選擇 Android 4.2（開發） 在 軟體.
  - 選擇為 Y1 列出的版本。
  - 點選 安裝 / 還原.
  - 僅當 Updater CE 詢問時關閉電源並連接 Y1。
