# Installez Inniclassic sur le Y1.

Inniclassic est un projet logiciel communautaire pour le Y1, et le même projet publie également un build Y2, il est donc disponible sur les deux lecteurs. Cette page vous donne la réponse conviviale Y1 et des liens vers les étapes de connexion détaillées.[Ouvrir le guide Inniclassic complet](guides/inniclassic-y1.html)[Disponible dans Updater CE](guide_fr.html?model=Y1&software=inniclassic-y1)[Pourquoi Inniclassic ?](inniclassic-benefits_fr.html)

Guide d'installation pour votre ordinateur

## Installez Inniclassic sur votre Y1 avec votre ordinateur

Choisissez le guide correspondant à l'ordinateur que vous utilisez. Chaque version comprend la configuration de la plate-forme, Updater CE étapes et le chemin de retour au stock.[Guide Windows](install/inniclassic-y1-windows.html)[Guide macOS](install/inniclassic-y1-mac.html)[Guide Linux](install/inniclassic-y1-linux.html)

[Tous les Innioasis guides Y1](install/y1.html) · [Tous les guides Inniclassic](install/inniclassic.html)

## Inniclassic Y1 étapes d'installation
  - Ouvrez Innioasis Updater CE sur votre ordinateur (si vous avez besoin de l'application, [Obtenir Updater CE](guide_fr.html#platform)). Ensemble Modèle d'appareil à Y1.
  - Choisissez Inniclassic dans Logiciel.
  - Choisissez la version répertoriée pour Y1.
  - Cliquez Installer / Restaurer.
  - Éteignez et connectez le Y1 uniquement lorsque Updater CE le demande.

## FAQPuis-je restaurer le logiciel d'origine Y1 ?

Oui. Sélectionnez Y1 et le logiciel original dans Updater CE. Le [Guide des logiciels boursiers Y1](original-software-y1_fr.html) couvre le chemin de retour.Que se passe-t-il si l'installation échoue ?

Notez si le programme de mise à jour a échoué avant ou après la détection du Y1, puis vérifiez le câble, la configuration de la plate-forme, le modèle et le timing de connexion dans [dépannage](troubleshooting_fr.html).Puis-je utiliser Inniclassic sur Y2 ?

Oui. Inniclassic est disponible sur les deux modèles — le même projet maintenu publie un package Y2 à partir des mêmes versions. Sélectionnez Y2 dans Updater CE et installez la version Y2 ; never flash a Y1 package to a Y2. Le [Page d'installation Y2](inniclassic-y2-software_fr.html) le recouvre.
