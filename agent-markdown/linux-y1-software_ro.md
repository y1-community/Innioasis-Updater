# Install Linux on the Y1.

Linux for Y1 is an experimental community Linux kernel and rootfs port for the Innioasis Y1 hardware. This page links to the full installation guide and releases.[Open the full Linux for Y1 (Dev) guide](guides/linux-y1.html)[Obțineți asta în Updater CE](guide_ro.html?model=Y1&software=linux-y1)[Sursa proiectului](https://github.com/y1-community/y1-linux-rom)

## Install Linux for Y1 (Dev) on your Y1 with your computer

Alegeți ghidul pentru computerul pe care îl utilizați. Fiecare versiune are configurarea platformei, Updater CE pași și calea de întoarcere la stoc.[Ghidul Windows](install/linux-y1-windows.html)[ghid macOS](install/linux-y1-mac.html)[Ghid Linux](install/linux-y1-linux.html)

[Toate ghidurile Innioasis Y1](install/y1.html) · [All Linux for Y1 (Dev) guides](install/linux-dev.html)

## Linux Y1 install steps
  - Deschideți Innioasis Updater CE pe computer (dacă aveți nevoie de aplicație, [Obține Updater CE](guide_ro.html#platform)). Setați Model dispozitiv la Y1.
  - Alege Linux pentru Y1 (Dev) in Software.
  - Alegeți versiunea listată pentru Y1.
  - Faceți clic Instalează / Restaurează.
  - Opriți și conectați Y1 numai când Updater CE vă cere.
