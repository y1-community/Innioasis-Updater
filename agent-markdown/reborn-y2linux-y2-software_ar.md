# Reborn (Y2Linux) لـ Innioasis Y2

توزيعة Debian Linux سريعة ومصممة خصيصًا لهذا الغرض مع واجهة مستخدم أصلية لعجلة النقر لـ Innioasis Y2، تتميز بثبات سماعات الرأس Bluetooth وتطوير المجتمع النشط.[دليل خطوة بخطوة Y2](guides/reborn-y2linux-y2.html)[لماذا Y2Reborn؟](reborn-y2linux-benefits_ar.html)[تحميل الإصدارات](firmware_ar.html?model=Y2&software=reborn-y2linux-y2)

## قم بتثبيت Reborn (Y2Linux) على جهاز Y2 بجهاز الكمبيوتر الخاص بك

اختر دليل الكمبيوتر الذي تستخدمه. يحتوي كل إصدار على إعداد النظام الأساسي وخطوات Updater CE وطريقة العودة إلى المخزون.[دليل ويندوز](install/reborn-y2linux-y2-windows.html)[دليل ماك](install/reborn-y2linux-y2-mac.html)[دليل لينكس](install/reborn-y2linux-y2-linux.html)

[جميع أدلة Innioasis Y2](install/y2.html) · [جميع الأدلة Reborn (Y2Linux).](install/reborn.html)

## خطوات التثبيت
  - افتح برنامج التحديث CE. متاح لأنظمة التشغيل Windows وmacOS وLinux.
  - حدد Y2 كنموذج الجهاز.
  - حدد Reborn (Y2Linux) كالبرنامج.
  - انقر فوق تثبيت / استعادة. انتظر حتى يقوم Updater CE بتحضير الملفات.
  - قم بتوصيل USB عند سؤالك. قم بإيقاف تشغيل Y2 أولاً.
  - قم بإعداد Wi-Fi وBluetooth وراديو FM

نسخ `system.img` للاعب مرة واحدة. Reborn يقوم بالباقي.[إنهاء الإعداد →](y2reborn_wifibt_ar.html)
