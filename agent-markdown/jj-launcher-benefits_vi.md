## Tại sao mọi người chọn nó

Fast, thumb-driven, yours.
  - Rapid library scanning — A custom media scanner categorises large libraries without waiting on the Android system scanner.
  - Skip tracks from any screen — Global hardware key mapping means previous and next always work, even when you are not in the music app.
  - EQ presets and shuffle — Full shuffle and repeat modes plus the built-in device equalizer presets.
  - Themes without code — Drop in custom colour themes by copying files, or design your own with the web-based theme editor and export a .zip.
  - No-cable file uploads — Host a local Wi-Fi web server and upload music from your PC browser — the cable stays in the drawer.
  - In-app Bluetooth pairing — Scan and pair Bluetooth devices from launcher settings without leaving the app.

## Dự án cung cấp những gì
  - Custom embedded media scanner with rapid categorisation of large libraries
  - Shuffle, repeat modes, and built-in EQ presets
  - Global hardware key mapping — track skipping from any screen
  - Real-time main screen sync of album art and track info
  - Infinite custom themes by copying folders; Y1 Theme Editor for designing your own
  - Dynamic HD blur background generated from the playing album art
  - In-app Bluetooth scanning and pairing
  - Wheel-optimised virtual keyboard for Wi-Fi passwords
  - Wireless PC file upload over a local Wi-Fi web server

## Những điều cần biết đầu tiên
  - The project is at alpha stage — unexpected bugs and stability issues are possible
  - It was tested on System Software 2.1.9; check your own software version before installing
  - Some Bluetooth connections may need a one-time ADB permission grant for secure settings
  - Themes made for the web editor need Launcher 0.8 or higher
