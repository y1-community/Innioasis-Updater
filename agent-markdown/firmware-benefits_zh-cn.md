# 比较固件和软件选项

从官方工厂原创软件到社区创作，如 Rockbox、Solar、Better-Y 和 Reborn (Y2Linux)，发现最适合您音频习惯的软件。[浏览软件下载](firmware_zh-CN.html)[帮我选择](firmware-faq_zh-CN.html)[获取 Updater CE](guide_zh-CN.html#platform)

## 软件概述工厂固件

### 原厂软件

完全支持蓝牙音频、调频收音机、有声读物和主题库中的自定义皮肤。 [了解更多→](original-software-benefits_zh-CN.html)发烧友标准

### Rockbox

参数均衡器、无缝播放、交叉馈送和广泛的主题定制。 [了解更多→](rockbox-benefits_zh-CN.html)强化工厂

### Better-Y

在原始软件之上进行社区增强，包括自定义启动、修补应用程序和主题支持。 [了解更多→](better-y-benefits_zh-CN.html)现代用户界面

### Solar

干净的现代界面，具有丰富的艺术作品和自定义动画。 [了解更多→](solar-benefits_zh-CN.html)原生Linux

### Reborn (Y2Linux)

基于 Debian 的操作系统，专为 Y2 点击轮设计，修复了蓝牙丢失问题。 [了解更多→](reborn-y2linux-benefits_zh-CN.html)速度和焦点

### Rondo

Y1 的轻量级专用滚轮音频固件。 [了解更多→](rondo-benefits_zh-CN.html)
