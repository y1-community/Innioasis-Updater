# 為什麼要在 Innioasis Y1 上安裝 Rondo？

Rondo 是一款開源、專用的點擊輪音樂播放器固件，專為 Innioasis Y1 硬體設計。它提供乾淨的庫瀏覽、乾淨的排版和快速的音訊解碼。[在 Y1 上安裝 Rondo](guides/rondo-y1.html)[瀏覽版本](firmware_zh-TW.html?model=Y1&software=rondo-y1)

## Rondo 的亮點

### 快速滾輪響應

精心調整的加速曲線與 Y1 實體電容式觸控輪相匹配，可平滑滾動大型音樂庫。

### 專注的音訊播放器

沒有臃腫軟體、後台分析或不必要的守護程序：100% 的硬體資源專用於清晰的音訊輸出。

### 隨時可逆

使用 Innioasis Updater CE 輕鬆安裝，並在您選擇時返回原始軟體或 Rockbox。
