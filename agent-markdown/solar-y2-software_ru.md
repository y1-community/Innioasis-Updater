Solar · Innioasis Y2

# Перед установкой проверьте маршрут Solar Y2.

Для Y2 указана сборка Solar, но поддержка может измениться. Перед прошивкой проверьте последние примечания к выпуску на странице проекта.[Открыть полное руководство Solar](guides/solar-y2.html)[Получите это в Updater CE](guide_ru.html?model=Y2&software=solar-y2)[Почему Solar?](solar-benefits_ru.html)

Руководство по установке для вашего компьютера

## Установите Solar на свой Y2 с помощью компьютера.

Выберите руководство для компьютера, который вы используете. В каждой версии есть настройка платформы, Updater CE шагов и возврат к стоку.[Руководство по Windows](install/solar-y2-windows.html)[руководство по macOS](install/solar-y2-mac.html)[Руководство по Linux](install/solar-y2-linux.html)

[Все Innioasis Y2 руководства](install/y2.html) · [Все Solar руководства](install/solar.html)

## Проверка правильности модели Y2
  - Откройте Innioasis Updater CE на своем компьютере (если вам нужно приложение, [Скачать Updater CE](guide_ru.html#platform)). Набор Модель устройства в адрес Y2.
  - Подтвердите это Solar указан для Y2 в текущих данных выпуска.
  - Прочтите примечания к выпуску проекта и проверьте его поддержку Y2.
  - Выберите указанный выпуск и нажмите Установить / Восстановить.
  - Выключите питание и подсоедините Y2 только при запросе Updater CE.
Не заменяйте пакет Y1. Доступность проекта для Y1 не делает его пакет Y1 безопасным для Y2.

## Вопросы и ответыГарантируется ли поддержка Solar Y2?

В списке указана сборка Solar Y2, но поддержка и содержимое могут измениться. Перед установкой проверьте последний список и примечания к выпуску.Как мне вернуться на сток?

Выберите Y2 и оригинальное программное обеспечение в Updater CE, затем следуйте инструкциям. [Y2 руководство по восстановлению](original-software-y2_ru.html).Что делать, если Solar не отображается для Y2?

Не форсируйте пакет Y1. Проверьте исходный код проекта и [руководство по устранению неполадок](troubleshooting_ru.html), затем дождитесь совместимой версии.
