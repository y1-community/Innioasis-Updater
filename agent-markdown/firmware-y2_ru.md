# Прошивка для Innioasis Y2

Y2 имеет лучшее аудиооборудование, Bluetooth и файловый менеджер. Выберите собственную систему, сборку Linux или официальное программное обеспечение для восстановления.[Просмотр Y2 загрузок](firmware_ru.html?model=Y2)[Скачать Updater CE](guide_ru.html#platform)[Y2 Руководство по темам](https://themes.innioasis.app/y2-themes.html?lang=ru)

## Доступные операционные системы для Innioasis Y2

Выберите, что вы хотите запустить на своем Y2:

### [Reborn (Y2Linux)](reborn-y2linux-benefits_ru.html)

Собственная встроенная ОС Linux, сочетающая в себе Buildroot, LVGL, PipeWire и MPD. Обеспечивает время загрузки 3 секунды, настоящие исправления повторного подключения наушников Bluetooth и воспроизведение без пауз.[Y2Reborn Руководство →](guides/reborn-y2linux-y2.html)

### [Rockbox для Y2](rockbox-benefits_ru.html)

Лучшая прошивка для аудиофилов, портированная на Innioasis Y2. Параметрическое выравнивание, пользовательские шрифты, перекрестная подача и обширная поддержка библиотеки плагинов.[Y2 Rockbox Руководство →](guides/rockbox-y2.html)

### [Solar для Y2](solar-benefits_ru.html)

Современный, гибкий интерфейс музыкального проигрывателя на основе Flutter для Y2. Имеет богатые визуализаторы, большое представление обложек альбомов и навигацию с помощью жестов.[Solar Y2 Руководство →](guides/solar-y2.html)

### [Y2Player](y2player-benefits_ru.html)

Легкий аудиоплеер сообщества, созданный для оборудования Y2 с простым просмотром папок и быстрым сканированием индекса.[Y2Player Руководство →](guides/y2player-y2.html)

### [Оригинальное программное обеспечение (восстановление заводских настроек)](original-software-benefits_ru.html)

Официальный стандартный образ прошивки (rom_y2.zip) для восстановления Innioasis Y2 до исходного заводского состояния с поддержкой скинов Галереи тем.[Восстановить Y2 Руководство →](guides/restore-original-y2.html)

## Установка прошивки на ваш Innioasis Y2

Updater CE подхватывает нужные файлы и проверяет драйвер перед прошивкой:
  - Запустите Innioasis Updater CE: Доступно изначально в macOS, Linux и Windows.
  - Модель набора: Выбирать Y2 в меню Модель устройства.
  - Выберите операционную систему: Выберите Reborn, Rockbox, Solar или оригинальное программное обеспечение.
  - Безопасная вспышка: Следуйте инструкциям на экране, чтобы подключить свое устройство через USB для чистой и проверенной прошивки.
