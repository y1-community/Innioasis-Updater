# Навіщо встановлювати Rondo на Innioasis Y1?

Rondo це прошивка музичного плеєра з відкритим вихідним кодом, розроблена спеціально для апаратного забезпечення Innioasis Y1. Він пропонує чистий перегляд бібліотеки, чисту типографіку та швидке декодування аудіо.[Встановити Rondo на Y1](guides/rondo-y1.html)[Огляд релізів](firmware_uk.html?model=Y1&software=rondo-y1)

## Основні моменти Rondo

### Швидка відповідь на коліщатко

Ретельно налаштована крива прискорення, узгоджена з фізичним ємнісним сенсорним колесом Y1 для плавного прокручування великих музичних бібліотек.

### Зосереджений аудіопрогравач

Жодного програмного забезпечення, фонової аналітики чи непотрібних демонов: 100% апаратних ресурсів призначено для виведення чіткого звуку.

### Реверсивний у будь-який час

Легко встановіть за допомогою Innioasis Updater CE і поверніться до оригінального програмного забезпечення або Rockbox будь-коли.
