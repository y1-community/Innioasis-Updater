# Мікропрограмне забезпечення для завантажень мікропрограм Innioasis Y2 - Innioasis.

Завантаження пристрою · Модель Y2

# Прошивка для Innioasis Y2

Y2 має краще звукове обладнання, Bluetooth і файловий менеджер. Виберіть спеціальну систему, збірку Linux або офіційне програмне забезпечення для відновлення.[Перегляньте Y2 завантаження](firmware_uk.html?model=Y2)[Отримати Updater CE](guide_uk.html#platform)[Y2 Посібник з тем](https://themes.innioasis.app/y2-themes.html?lang=uk)

## Доступні операційні системи для Innioasis Y2

Виберіть, що ви хочете запустити на своєму Y2:

### [Reborn (Y2Linux)](reborn-y2linux-benefits_uk.html)

Рідна вбудована ОС Linux, що поєднує Buildroot, LVGL, PipeWire та MPD. Пропонує час завантаження 3 секунди, справжні виправлення повторного підключення навушників Bluetooth і відтворення без перерв.[Y2Reborn Посібник →](guides/reborn-y2linux-y2.html)

### [Rockbox для Y2](rockbox-benefits_uk.html)

Найкраще аудіофільське мікропрограмне забезпечення, перенесене на Innioasis Y2. Параметричне вирівнювання, користувацькі шрифти, перехресна передача та широка підтримка бібліотеки плагінів.[Y2 Rockbox Посібник →](guides/rockbox-y2.html)

### [Solar для Y2](solar-benefits_uk.html)

Сучасний інтерфейс музичного плеєра на основі Flutter для Y2. Містить розширені візуалізатори, велику презентацію обкладинок альбомів і навігацію жестами.[Solar Y2 Посібник →](guides/solar-y2.html)

### [Y2Player](y2player-benefits_uk.html)

Легкий аудіопрогравач спільноти, створений для обладнання Y2 із простим переглядом папок і швидким скануванням індексу.[Y2Player Посібник →](guides/y2player-y2.html)

### [Оригінальне програмне забезпечення (відновлення заводських параметрів)](original-software-benefits_uk.html)

Офіційний стандартний образ мікропрограми (rom_y2.zip) для відновлення Innioasis Y2 до початкового заводського стану разом із підтримкою скінів Галереї тем.[Відновити Y2 Керівництво →](guides/restore-original-y2.html)

## Встановлення мікропрограми на Innioasis Y2

Updater CE захоплює потрібні файли та перевіряє драйвер перед перепрошиванням:
  - Запустіть Innioasis Updater CE: Нативно доступний для macOS, Linux і Windows.
  - Набір моделі: Виберіть Y2 у меню «Модель пристрою».
  - Виберіть операційну систему: Виберіть Reborn, Rockbox, Solar або оригінальне програмне забезпечення.
  - Безпечний спалах: Дотримуйтеся вказівок на екрані, щоб підключити свій пристрій через USB для чистого, перевіреного спалаху.
