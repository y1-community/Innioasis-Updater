# JJ Launcher สำหรับ Innioasis Y2 | คู่มือความเข้ากันได้และการติดตั้ง - Innioasis ดาวน์โหลดเฟิร์มแวร์

JJ Launcher · Innioasis Y2

# ตรวจสอบ JJ Launcher สำหรับ Y2 ก่อนทำการติดตั้ง

มี JJ Launcher บิลด์สำหรับ Y2 แม้ว่าสิ่งที่รวมอยู่สามารถเปลี่ยนแปลงได้ระหว่างการเปิดตัว ตรวจสอบรายชื่อปัจจุบันก่อนที่จะเริ่มต้น[เปิดคำแนะนำ JJ Launcher ฉบับเต็ม](guides/jj-launcher-y2.html)[รับสิ่งนี้ใน Updater CE](guide_th.html?model=Y2&software=jj-launcher-y2)[ทำไมต้อง JJ Launcher?](jj-launcher-benefits_th.html)

คู่มือการติดตั้งสำหรับคอมพิวเตอร์ของคุณ

## ติดตั้ง JJ Launcher บน Y2 ด้วยคอมพิวเตอร์ของคุณ

เลือกคำแนะนำสำหรับคอมพิวเตอร์ที่คุณใช้ ทุกรุ่นมีการตั้งค่าแพลตฟอร์ม ขั้นตอน Updater CE และวิธีคืนสินค้าในสต็อก[คู่มือวินโดวส์](install/jj-launcher-y2-windows.html)[คู่มือ macOS](install/jj-launcher-y2-mac.html)[คู่มือลินุกซ์](install/jj-launcher-y2-linux.html)

[คำแนะนำ Innioasis Y2 ทั้งหมด](install/y2.html) · [คำแนะนำ JJ Launcher ทั้งหมด](install/jj-launcher.html)

## การตรวจสอบที่ถูกต้องตามแบบ
  - เปิด Innioasis Updater CE บนคอมพิวเตอร์ของคุณ (หากคุณต้องการแอป [รับ Updater CE](guide_th.html#platform)). ชุด รุ่นอุปกรณ์ ถึง Y2.
  - ยืนยัน JJ Launcher ปรากฏสำหรับ Y2 ในข้อมูลการเผยแพร่ปัจจุบัน
  - อ่านบันทึกประจำรุ่นของโครงการและเลือกรุ่น Y2 ที่อยู่ในรายการ
  - คลิก ติดตั้ง / คืนค่า.
  - ปิดเครื่องและเชื่อมต่อ Y2 เมื่อได้รับแจ้งเท่านั้น
อย่าทดแทน: แพ็คเกจ Y1 ไม่ใช่แพ็คเกจ Y2 หยุดหากรุ่นและรุ่นไม่ตรงกัน

## คำถามที่พบบ่อยรับประกันการสนับสนุน Y2 หรือไม่

มีบิลด์ Y2 อยู่ในรายการ แต่สิ่งที่รองรับสามารถเปลี่ยนแปลงได้ ตรวจสอบรายการล่าสุดและหมายเหตุของโครงการก่อนทำการติดตั้งฉันจะคืนค่า Y2 ได้อย่างไร

เลือก Y2 และซอฟต์แวร์ต้นฉบับใน Updater CE จากนั้นปฏิบัติตาม [Y2 ขั้นตอนการกู้คืน](original-software-y2_th.html).จะเกิดอะไรขึ้นถ้า JJ Launcher ไม่อยู่ในรายการ?

อย่าบังคับแพ็คเกจ Y1 ตรวจสอบการเผยแพร่โครงการและ [คู่มือการแก้ไขปัญหา](troubleshooting_th.html).
