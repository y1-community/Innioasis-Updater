## Y2Player Installationsschritte
  - Öffnen Sie Innioasis Updater CE auf Ihrem Computer (wenn Sie die App benötigen, [Updater CE holen](guide_de.html#platform)). Satz Gerätemodell an Y2.
  - Wählen Sie Y2Player In Software.
  - Wählen Sie eine für Y2 aufgeführte Version aus.
  - Klicken Sie Installieren / Wiederherstellen.
  - Schalten Sie das Gerät aus und schließen Sie Y2 an der Live-Eingabeaufforderung an.

Einige Y2 Vollinstallationspakete verwenden `rom_y2.zip`. Lassen Sie den Updater nach Möglichkeit das Paket auswählen.

## FAQKann ich zur ursprünglichen Software zurückkehren?

Ja. Wählen Sie Y2 und Originalsoftware in Updater CE und folgen Sie dann den Anweisungen [Y2-Wiederherstellungsanleitung](original-software-y2_de.html).Kann ich dies auf einem Y1 verwenden?

Nein. Diese Seite ist für den Eintrag Y2Player Y2. Halten Sie die Pakete Y1 und Y2 getrennt.Was passiert, wenn Y2 nicht erkannt wird?

Überprüfen Sie Plattform-Setup, Kabel, Ausschaltzustand, Modellauswahl und Timing. Verwenden [Fehlerbehebung](troubleshooting_de.html) bevor Sie die manuelle Wiederherstellung versuchen.
