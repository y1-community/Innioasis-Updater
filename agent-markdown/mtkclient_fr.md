# MTKClient et diagnostics de déblocage

MTKClient est le moteur de flashage open source MediaTek sous-jacent utilisé par Innioasis Updater CE. Si un lecteur ne répond plus ou échoue au clignotement standard, utilisez ces diagnostics de récupération.[Dépannage général](troubleshooting_fr.html)[Notes de configuration du pilote](drivers_fr.html)

Commencez par Innioasis Updater

## Essayez l'itinéraire guidé avant celui de basse altitude

Le programme de mise à jour le fait en un seul passage. Choisissez le logiciel, suivez les étapes à l'écran et vous avez terminé. Il vous indique également quand un correctif ou une nouvelle version arrive.

## Comprendre le mode BootROM (BROM)

Lorsqu'il est complètement éteint, le processeur MediaTek MT6572 / MT6580 écoute sur le bus USB un paquet de prise de contact avant de charger le chargeur de démarrage principal. Si un flash corrompu se produit, le mode BROM permet une réécriture de récupération complète.
