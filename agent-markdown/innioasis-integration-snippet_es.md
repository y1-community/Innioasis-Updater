# 🚀 Innioasis Actualizador - Guía de instalación integrable

Este es un widget de guía de instalación completo e integrable que se puede integrar fácilmente en cualquier sitio web. Cuenta con una interesante CTA emergente en la esquina inferior derecha que abre una guía de instalación completa para usuarios de Windows, macOS y Linux.

### 🎨 Hermoso diseño

Diseño moderno y responsivo que funciona en todos los dispositivos compatibles con el modo oscuro

### 📱 Multiplataforma

Guías de instalación completas para Windows, macOS y Linux con instrucciones paso a paso

### 🔧 Fácil integración

Simplemente copie y pegue el fragmento: no se requieren dependencias ni configuraciones complejas

### 💾 Almacenamiento inteligente

Recuerda si los usuarios han cerrado el banner para no ser intrusivo

## 📋 Instrucciones de integración

Para agregar la guía de instalación del actualizador Innioasis a su sitio web, simplemente copie y pegue este fragmento de código en su HTML: <!-- Innioasis Widget de guía de instalación del actualizador --> <script> (function() { // Crear e inyectar el widget const script = document.createElement('script'); script.src = 'https://your-domain.com/innioasis-embed.html'; script.async = true; // Alternativa: cargar desde un archivo local // script.src = './innioasis-embed.html'; document.head.appendChild(script); // Crear contenedor iframe const iframe = document.createElement('iframe'); iframe.src = 'https://your-domain.com/innioasis-embed.html'; iframe.style.cssText = ` posición: fijo; 20px; ancho: 400px; borde: ninguno; none; `; // Hacer iframe interactivo iframe.onload = function() { iframe.style.pointerEvents = 'auto'; </script> 📋 Copiar código de integración

## 🎯 Alternativa: método de inserción directa

Para una integración aún más sencilla, puede incrustar directamente el widget mediante un iframe: <!-- Incrustación directa de iframe --> <iframe src="https://your-domain.com/innioasis-embed.html" width="400" height="200" frameborder="0" style="posición: fijo; abajo: 20px; derecha: 20px; índice z: 999999; radio de borde: 12px; sombra de cuadro: 0 8px 32px rgba(0,0,0,0.3);" permitirtransparency="true"> </iframe> 📋 Copiar código Iframe

## 🌐 Requisitos de alojamiento

Para utilizar este widget en su sitio web, debe:
  - Sube el `innioasis-embed.html` archivo a su servidor web
  - Actualice las URL en el fragmento de integración para que apunten a su servidor
  - Asegúrese de que su servidor admita HTTPS (requerido para los navegadores modernos)
  - Pruebe el widget en su sitio web para asegurarse de que funciona correctamente

## 🆘 Soporte

Si necesita ayuda para integrar este widget o tiene preguntas, por favor:
  - Verifique la consola del navegador para ver si hay mensajes de error.
  - Asegúrese de que todos los archivos se carguen correctamente en su servidor
  - Verifique que las URL en el código de integración sean correctas
  - Pruebe en diferentes navegadores y dispositivos
