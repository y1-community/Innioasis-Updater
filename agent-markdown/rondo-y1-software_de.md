## Installieren Sie Rondo auf Ihrem Y1 mit Ihrem Computer

Wählen Sie die Anleitung für den Computer aus, den Sie verwenden. Jede Version verfügt über das Plattform-Setup, Updater CE Schritte und den Weg zurück zum Lagerbestand.[Windows-Anleitung](install/rondo-y1-windows.html)[macOS-Anleitung](install/rondo-y1-mac.html)[Linux-Anleitung](install/rondo-y1-linux.html)

[Alle Innioasis Y1-Anleitungen](install/y1.html) · [Alle Rondo Anleitungen](install/rondo.html)

## Installationsschritte
  - Starten Innioasis Updater CE auf Ihrem Windows-, Mac- oder Linux-Computer.
  - Auswählen Y1 aus der Dropdown-Liste „Gerätemodell“.
  - Auswählen Rondo aus der Dropdown-Liste „Software“.
  - Klicken Sie Installieren / Wiederherstellen und warten Sie, bis das Tool die Dateien heruntergeladen und vorbereitet hat.
  - Wenn Sie von Updater CE dazu aufgefordert werden, schalten Sie Ihr Y1 aus und schließen Sie das USB-Kabel an.
  - Komplette Einrichtung nach der Installation

Befolgen Sie die Schritte in [diesen Leitfaden](post_install_de.html?software=rondo-y1&model=Y1) um die Einrichtung auf Ihrem Y1 abzuschließen.[Anleitung anzeigen](post_install_de.html?software=rondo-y1&model=Y1)
