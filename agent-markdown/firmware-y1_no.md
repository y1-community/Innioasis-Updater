# Fastvare for Innioasis Y1

Y1 har det bredeste utvalget av tilpassede systemer. Alt nedenfor er vert her, sjekket og installeres med ett klikk med Updater CE.[Bla gjennom Y1 Nedlastinger](firmware_no.html?model=Y1)[Få Updater CE](guide_no.html#platform)[Temagalleri](https://themes.innioasis.app/?lang=no)

## Tilgjengelige operativsystemer for Innioasis Y1

Y1 kjører flere programvaresystemer, inkludert bygg med audiofil kodekstøtte, moderne oppstartere og en fabrikkgjenoppretting. Velg den som passer til hvordan du lytter:

### [Rockbox](rockbox-benefits_no.html)

Gullstandarden innen åpen kildekode-lydavspilling. Parametrisk EQ, gapless FLAC/MP3-avspilling, temaer og fontpakker kan installeres direkte i Updater CE.[Y1 Rockbox Veiledning →](guides/rockbox-y1.html)

### [Better-Y](better-y-benefits_no.html)

Et forbedret derivat av den originale fastvaren med Bluetooth-stabilitetsoppdateringer, volumkurvejusteringer og 100 % temagallerikompatibilitet.[Better-Y Veiledning →](guides/better-y-y1.html)

### [Solar](solar-benefits_no.html)

En moderne åpen kildekode-musikkspiller bygget med Flutter, og tilbyr jevne 60fps-animasjoner, albumgrafikk og moderne typografi.[Solar Y1 Veiledning →](guides/solar-y1.html)

### [Rondo](rondo-benefits_no.html)

En åpen kildekode Y1-starter for lokale spor og strømming, med rask, responsiv navigasjon.[Rondo Y1 Veiledning →](guides/rondo-y1.html)

### [Koensayr](koensayr-benefits.html)

En tilpasset fastvarebygging med sin egen ikonografi, bedre batterikalibrering og støtte for lagertema.[Koensayr Veiledning →](guides/koensayr-y1.html)

### [Original programvare (lagergjenoppretting)](original-software-benefits_no.html)

Rengjør fabrikkfastvarebilder for Type A (v2.0.0+) og Type B (v1.x) Y1 spillere. Fjern murstein på en trygg måte eller gjenopprett enheten til fabrikktilstand.[Gjenopprett Y1 veiledning →](guides/restore-original-y1.html)

## Hvordan installere eller oppdatere Y1 fastvare

Det er enkelt å oppgradere eller fjerne mursteinen på Innioasis Y1 med vår multiplattformprogramvarepakke:
  - Åpne Innioasis Updater CE: Start oppdateringsprogrammet på macOS, Windows eller Linux.
  - Velg modell Y1: Velg Y1 i rullegardinmenyen Enhetsmodell.
  - Velg ditt operativsystem: Velg Rockbox, Better-Y, Solar eller original programvare.
  - Klikk Installer: Updater CE laster ned fastvarepakken direkte fra utviklerens utgivelse. Når du blir bedt om det, kobler du til den avslåtte Y1 via USB for å begynne å blinke.
