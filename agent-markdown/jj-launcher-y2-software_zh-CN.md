## 模型正确性检查
  - 在您的计算机上打开 Innioasis Updater CE（如果您需要该应用程序， [获取 Updater CE](guide_zh-CN.html#platform)）。套装 设备型号 至 Y2.
  - 确认 JJ Launcher 当前版本数据中显示 Y2。
  - 阅读项目发行说明并选择列出的 Y2 版本。
  - 点击 安装 / 恢复.
  - 仅在出现提示时关闭电源并连接 Y2。
不要替代： Y1 包不是 Y2 包。如果模型和版本不一致，请停止。
