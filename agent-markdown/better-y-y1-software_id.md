# Instal Better-Y pada Y1.

Better-Y memberikan pengalaman stok yang ditingkatkan untuk Innioasis Y1 dengan pemisahan tag, nomor trek album, pintasan Now Playing, dan cache RAM yang lebih lancar sambil mempertahankan kompatibilitas tema 100%.[Buka panduan lengkap Better-Y](guides/better-y-y1.html)[Dapatkan ini di Updater CE](guide_id.html?model=Y1&software=better-y-y1)[Mengapa Better-Y?](better-y-benefits_id.html)

Panduan instalasi untuk komputer Anda

## Instal Better-Y pada Y1 Anda dengan komputer Anda

Pilih panduan untuk komputer yang Anda gunakan. Setiap versi memiliki pengaturan platform, Updater CE langkah-langkahnya, dan cara kembali ke stok.[Panduan Windows](install/better-y-y1-windows.html)[panduan macOS](install/better-y-y1-mac.html)[Panduan Linux](install/better-y-y1-linux.html)

[Semua Innioasis panduan Y1](install/y1.html) · [Semua panduan Better-Y](install/better-y.html)

## Better-Y Y1 langkah-langkah pemasangan
  - Buka Innioasis Updater CE di komputer Anda (jika Anda memerlukan aplikasinya, [Dapatkan Updater CE](guide_id.html#platform)). Tetapkan Model perangkat untuk Y1.
  - Pilih Better-Y di Perangkat lunak.
  - Pilih rilis yang terdaftar untuk Y1.
  - Klik Pasang / Pulihkan.
  - Matikan dan sambungkan Y1 hanya ketika Updater CE diminta.

## Pertanyaan umumApa yang ditingkatkan dibandingkan firmware bawaan?

Better-Y menambahkan nomor trek, membagi tag multi-artis, menggunakan judul asli, dan menambahkan pintasan pemutaran, ditambah perbaikan untuk cache dan Bluetooth. Tema yang sama seperti sebelumnya.Bisakah saya memulihkan perangkat lunak stok Y1?

Ya. Pilih Y1 dan Perangkat Lunak Asli di Updater CE. Itu [Panduan perangkat lunak stok Y1](original-software-y1_id.html) meliputi jalur pulang.Bisakah saya menggunakan tema yang sudah ada?

Ya! Better-Y dibuat pada stok resmi 3.1.2 dan mempertahankan kompatibilitas 100% dengan semua tema khusus dari Galeri Tema.Bagaimana jika instalasi gagal?

Catat apakah Updater gagal sebelum atau setelah mendeteksi Y1, lalu periksa kabel, pengaturan platform, model, dan waktu koneksi di [pemecahan masalah](troubleshooting_id.html).
