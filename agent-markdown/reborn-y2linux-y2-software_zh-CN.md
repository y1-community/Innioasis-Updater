## 安装步骤
  - 打开更新程序 CE。 适用于 Windows、macOS 和 Linux。
  - 选择Y2 作为设备型号。
  - 选择Reborn（Y2Linux） 作为软件。
  - 单击安装/恢复。 等待 Updater CE 准备文件。
  - 当询问时连接 USB。 首先关闭 Y2 的电源。
  - 设置 Wi-Fi、蓝牙和 FM 收音机

复制 `system.img` 给玩家一次。 Reborn 完成剩下的工作。[完成设置 →](y2reborn_wifibt_zh-CN.html)
