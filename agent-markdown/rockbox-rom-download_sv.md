# Rockbox ROM nedladdning för Y1 och Y2

Ladda ner Rockbox ROM-firmwarepaket för Innioasis Y1 (Rockbox-Y1) och Y2 (Rockbox-Y2) direkt från communityutvecklarna, eller installera med ett klick med Innioasis Updater CE.

## Välj din spelarmodell först

Rockbox-Y1 och Rockbox-Y2 är separata firmwarebyggen skapade för olika hårdvara. Kontrollera om din spelare är en Innioasis Y1 eller Y2 innan du laddar ner eller blinkar.

## Hur Updater CE laddar ner firmware

Innioasis Updater CE laddar alltid ner firmware-paket direkt från community-firmware-utvecklarnas egna releaser, och utvecklarna själva är ensamma ansvariga för att lista sina programvaruversioner i Updater CE. Varje ROM-paket innehåller MediaTek scatter-filen och partitionsbilder för den modellen.
  - Rockbox-Y1 utvecklarversionspaket: `rom.zip` (och `rom_type_b.zip` för Type B Y1 enheter).
  - Rockbox-Y2 utvecklarversionspaket: `rom_y2.zip`.

## Installera automatiskt med Updater CE

För den enklaste installationen, öppna Innioasis Updater CE, välj din spelarmodell och Rockbox och låt appen ladda ner och flasha releasen direkt. Följ [Rockbox-Y1 installationsguide](rockbox-y1/install.html) eller den [Rockbox-Y2 installationsguide](rockbox-y2/install.html).
