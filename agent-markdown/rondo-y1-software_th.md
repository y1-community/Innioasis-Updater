# Rondo สำหรับ Innioasis Y1

เฟิร์มแวร์เครื่องเล่นเพลงแบบคลิกวีลที่เรียบง่ายซึ่งออกแบบมาโดยเฉพาะสำหรับฮาร์ดแวร์แบบคาปาซิทีฟ Innioasis Y1 โดยเน้นที่การเล่นแบบตอบสนองและการนำทางที่สะอาดตา[คำแนะนำทีละขั้นตอน Y1](guides/rondo-y1.html)[ทำไมต้อง Rondo?](rondo-benefits_th.html)[ดาวน์โหลดเผยแพร่](firmware_th.html?model=Y1&software=rondo-y1)

คู่มือการติดตั้งสำหรับคอมพิวเตอร์ของคุณ

## ติดตั้ง Rondo บน Y1 ด้วยคอมพิวเตอร์ของคุณ

เลือกคำแนะนำสำหรับคอมพิวเตอร์ที่คุณใช้ ทุกรุ่นมีการตั้งค่าแพลตฟอร์ม ขั้นตอน Updater CE และวิธีคืนสินค้าในสต็อก[คู่มือวินโดวส์](install/rondo-y1-windows.html)[คู่มือ macOS](install/rondo-y1-mac.html)[คู่มือลินุกซ์](install/rondo-y1-linux.html)

[คำแนะนำ Innioasis Y1 ทั้งหมด](install/y1.html) · [คำแนะนำ Rondo ทั้งหมด](install/rondo.html)

## ขั้นตอนการติดตั้ง
  - เปิดตัว Innioasis Updater ส.ค บนคอมพิวเตอร์ Windows, Mac หรือ Linux
  - เลือก Y1 จากเมนูแบบเลื่อนลงรุ่นอุปกรณ์
  - เลือก Rondo จากดรอปดาวน์ซอฟต์แวร์
  - คลิก ติดตั้ง / คืนค่า และรอให้เครื่องมือดาวน์โหลดและเตรียมไฟล์
  - เมื่อได้รับแจ้งจาก Updater CE ให้ปิด Y1 ของคุณและเชื่อมต่อสายเคเบิล USB
  - ตั้งค่าหลังการติดตั้งให้เสร็จสมบูรณ์

ทำตามขั้นตอนใน [คู่มือนี้](post_install_th.html?software=rondo-y1&model=Y1) เพื่อตั้งค่า Y1 ของคุณให้เสร็จสิ้น[ดูคำแนะนำ](post_install_th.html?software=rondo-y1&model=Y1)
