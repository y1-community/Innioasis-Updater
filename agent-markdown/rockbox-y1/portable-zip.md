# Rockbox-Y1 local ZIP

If you downloaded a Rockbox-Y1 ROM ZIP package ahead of time, you can install it from your computer or let Updater CE handle the entire download and flash for you.[Get it in Updater CE](../guide.html?model=Y1&software=rockbox-y1)[Full written tutorial](../guides/rockbox-y1.html)

## Download the ROM package
  - `rom.zip` — the standard Rockbox-Y1 firmware package published by the developer.
  - On our [Firmware Downloads](../firmware.html?model=Y1&software=rockbox-y1) page, the download button can also bundle platform flashing scripts for Windows, macOS, or Linux when you want a standalone web download.
[Rockbox-Y1 downloads](download.html)[Get it in Updater CE](../guide.html?model=Y1&amp;software=rockbox-y1)[Release notes (stable-v0.6)](../release_notes.html?author=rockbox-y1&project=rockbox&version=stable-v0.6&software=rockbox-y1)

## How to install from a downloaded ZIP
  - Download the ROM ZIP and extract it to a folder on your computer (avoid folder paths with special characters).
  - Open Innioasis Updater CE and set Device Model to Y1.
  - Select the local package option and choose your downloaded ZIP or extracted folder.
  - Click Install / Restore.
  - Power off your Y1 completely and connect it over USB when Updater CE prompts you.

## What is inside the ROM package

Each ROM package contains a MediaTek scatter file and the partition images for your Y1. Keep all files in the extracted folder together so the scatter file can locate every image.

## Frequently asked questionsDoes Updater CE use the website's standalone portable ZIP mirror?

No. Updater CE always downloads firmware packages directly from the community firmware developers themselves, who are solely responsible for listing their releases in Updater CE.Do I need to install Python or MediaTek tools separately?

No. Updater CE includes everything needed to flash the ROM.Can I flash the ZIP from the player's MicroSD card?

No. Flashing is always performed from a computer over USB while the player is powered off.
