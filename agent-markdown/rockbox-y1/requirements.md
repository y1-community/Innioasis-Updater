# What you need before installing Rockbox-Y1

Check these five items before installing Rockbox-Y1 on your Innioasis Y1: the model printed on the player, a USB data cable, battery charge, computer drivers, and connection timing.[Get it in Updater CE](../guide.html?model=Y1&software=rockbox-y1)[Full written tutorial](../guides/rockbox-y1.html)

## What you need
  - An Innioasis Y1 — verify the model name on the player.
  - A USB data cable (charge-only cables cannot transfer firmware).
  - A charged battery (at least 50%% recommended).
  - Windows: MediaTek USB drivers. Linux: udev permissions for `0e8d:*`. macOS: no extra driver needed.
  - About 1 GB of free disk space on your computer.

Need help with drivers? See the [USB drivers guide](../drivers.html) or [troubleshooting](troubleshooting.html).

## Choosing the right Rockbox-Y1 build

Y1 community builds are labelled by screen resolution. 360p is current: Rockbox-Y1 0.5 and later is 360p only. 240p builds ended at 0.4 and use the Rockbox iPod classic themes.
  - Y1: Choose Type A if your player shipped with software 2.0.0+, or Type B for earlier units.
  - Choose a stable release for everyday use, or a nightly build to test the latest changes.
