# Rockbox-Y1 dual boot

Many Rockbox-Y1 builds allow you to switch between Rockbox and the factory Original Software without reflashing your player.[Get it in Updater CE](../guide.html?model=Y1&software=rockbox-y1)[Full written tutorial](../guides/rockbox-y1.html)

## How to switch between Rockbox and Original Software
  - From Rockbox: check the System menu for an option to restart into the original player software.
  - From Original Software: on supported builds, hold Menu/Back + Play/Pause while powering on (check your release notes for build-specific shortcuts).
  - If you want to remove Rockbox completely and run only factory software, follow the [restore guide](restore-stock.html).

## When to restore instead of dual booting

If you are giving the player to someone else or want a clean factory setup, flash Original Software in Updater CE.

## Frequently asked questionsIs switching between dual-boot systems safe?

Yes. Switching only reboots the player into the other system; it does not reflash the storage.Where can I check if my version supports dual boot?

Check the [Rockbox-Y1 release notes](../release-notes/rockbox-y1/index.html) for the build you installed.
