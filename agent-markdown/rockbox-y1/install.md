# Install Rockbox-Y1 on the Innioasis Y1 (Updater CE guide)

Install Rockbox-Y1 on your Innioasis Y1 in six steps with Innioasis Updater CE. Select your model first, choose Rockbox, pick a release, and connect your powered-off player when prompted.[Get it in Updater CE](../guide.html?model=Y1&software=rockbox-y1)[Full written tutorial](../guides/rockbox-y1.html)

## Step-by-step installation
  - Open Innioasis Updater CE and set Device Model to Y1.
  - Select Rockbox in the Software dropdown.
  - Pick a stable release (or check Show nightly builds to test a preview).
  - Click Install / Restore so Updater CE downloads the package directly from the developer's release.
  - Power the Y1 completely off, then connect it with a USB data cable when Updater CE prompts you.
  - Wait for the completion message before unplugging and turning on your player.

## Why selecting Y1 first matters

Updater CE shows only the firmware listed for the device model you select. Setting Device Model to Y1 ensures you get the Rockbox-Y1 build published by rockbox-y1/rockbox instead of a Y2 package.

If you already downloaded a ROM ZIP to your computer, see [installing from a local ZIP package](portable-zip.html).

## How Updater CE installs the firmware

Updater CE downloads the firmware package directly from the community developer's release (the developer is solely responsible for listing their releases in Updater CE), unpacks it, and flashes your player over USB while the player is powered off.

Once the download finishes, flashing takes only a couple of minutes. Keep the USB cable connected until Updater CE shows the success message.Do I need to root or unlock the Y1 first?
