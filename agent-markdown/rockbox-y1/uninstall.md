# Remove Rockbox-Y1 or reset it to defaults

Whether you want to remove Rockbox-Y1 completely and return to factory software, or simply reset Rockbox-Y1 back to default settings, both take only a few minutes.[Get it in Updater CE](../guide.html?model=Y1&software=rockbox-y1)[Full written tutorial](../guides/rockbox-y1.html)

## Option 1: Return to factory Original Software

To replace Rockbox-Y1 with the factory firmware, open Innioasis Updater CE, select Y1, choose Original Software, and click Install / Restore. See the [restore guide](restore-stock.html).

## Option 2: Reset Rockbox-Y1 settings to default

To keep Rockbox-Y1 installed but reset all settings, themes, and database caches, delete or rename the hidden `.rockbox` folder on your MicroSD card and reboot the player. See the [MicroSD card guide](sd-card.html).

## Frequently asked questionsDoes deleting .rockbox uninstall the firmware?

No. It only resets your settings and themes; the player recreates a clean .rockbox folder on the next boot.Can I reinstall Rockbox-Y1 after restoring Original Software?

Yes, at any time through Innioasis Updater CE.
