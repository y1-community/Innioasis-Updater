## Установите свой выбор с помощью Updater CE
  - Откройте руководство и установите Innioasis Updater CE на свой компьютер, если у вас его еще нет.
  - В Updater CE выберите модель, напечатанную на вашем плеере, из Модель устройства.
  - От Программное обеспечение, выберите программное обеспечение, которое вы хотите запустить на этой модели.
  - Выберите выпуск, нажмите Установить / Восстановить, затем выключите и подключите плеер только по запросу Updater CE.

Нужен установщик? [Откройте руководство и разверните раздел загрузки Updater CE.](guide_ru.html#download-updater).

## Безопасный путь назад

### Проверьте модель

Y1 and Y2 software is not interchangeable. Re-select the model in Updater CE and start again.

### Подождите подсказки

Полностью выключите плеер и подключайте его только тогда, когда Updater CE сообщит, что он готов.

### Восстановить оригинальное программное обеспечение

Выберите оригинальное программное обеспечение для той же модели. Если требуется восстановление вручную, откройте [руководство по устранению неполадок](troubleshooting_ru.html) первый.

## Supported Devices and Official Stock Firmware

The Innioasis Firmware Archive hosts verified stock firmware, original factory restore images, and custom operating systems for portable players:

### Innioasis Y1 & Y2

Official software and custom systems including Rockbox, Better-Y, and Solar.

### Innioasis G1, G3 & G5

Официальное ПО и файлы восстановления для тачскрин плееров.

### Innioasis R1 & PR1

Оригинальное программное обеспечение и файлы восстановления для аудиоплееров.

### Timmkoo Q5 & Q3

Packages provided for Timmkoo players via Updater CE.

New releases appear here as soon as they are verified.

## Какой инструмент мне следует использовать?

Innioasis Средство обновления CE is the recommended tool for daily updates and community OS installs across Windows, macOS, and Linux. Flashing through Updater CE preserves your library and pairings.

The legacy Universal Flash Tool remains available for emergency unbricking when a device cannot boot into fastboot.[Compare flashing tools](updater-comparison_ru.html)
