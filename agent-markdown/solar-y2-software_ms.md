## Model-correct Y2 checks
  - Buka Innioasis Updater CE pada komputer anda (jika anda memerlukan apl itu, [Dapatkan Updater CE](guide_ms.html#platform)). Tetapkan Model Peranti kepada Y2.
  - Confirm that Solar is listed for Y2 in the current release data.
  - Read the project release note and check its Y2 support.
  - Choose the listed release and click Pasang / Pulihkan.
  - Matikan dan sambungkan Y2 hanya apabila Updater CE bertanya.
Do not substitute a Y1 package. A project being available for Y1 does not make its Y1 package safe for Y2.
