## Inniclassic Y1 install steps
  - Open Innioasis Updater CE on your computer (if you need the app, [Get Updater CE](guide.html#platform)). Set Device Model to Y1.
  - Choose Inniclassic in Software.
  - Choose the release listed for Y1.
  - Click Install / Restore.
  - Power off and connect the Y1 only when Updater CE asks.

## FAQsCan I restore the stock Y1 software?

Yes. Select Y1 and Original Software in Updater CE. The [Y1 stock-software guide](original-software-y1.html) covers the return path.What if installation fails?

Note whether Updater failed before or after detecting the Y1, then check the cable, platform setup, model, and connection timing in [troubleshooting](troubleshooting.html).Can I use Inniclassic on Y2?

Yes. Inniclassic is available on both models — the same maintained project publishes a Y2 package from the same releases. Select Y2 in Updater CE and install the Y2 build; never flash a Y1 package to a Y2. The [Y2 install page](inniclassic-y2-software.html) covers it.
