# Asenna Inniclassic laitteeseen Y2.

Inniclassic on saatavilla Innioasis Y2:lle, ja sama projekti rakentaa myös Y1-paketit. Tämä sivu antaa sinulle Y2 yleiskatsauksen ja linkit koko opetusohjelmaan.[Avaa koko Inniclassic-opas](guides/inniclassic-y2.html)[Hanki tämä Updater CE](guide_fi.html?model=Y2&software=inniclassic-y2)[Miksi Inniclassic?](inniclassic-benefits_fi.html)

Asennusopas tietokoneellesi

## Asenna Inniclassic Y2-laitteeseen tietokoneesi kanssa

Valitse käyttämäsi tietokoneen opas. Jokaisessa versiossa on alustan asetukset, Updater CE vaiheet ja tie takaisin varastoon.[Windowsin opas](install/inniclassic-y2-windows.html)[macOS-opas](install/inniclassic-y2-mac.html)[Linux opas](install/inniclassic-y2-linux.html)

[Kaikki Innioasis Y2-oppaat](install/y2.html) · [Kaikki Inniclassic oppaat](install/inniclassic.html)

## Inniclassic Y2 asennusvaiheet
  - Avaa Innioasis Updater CE tietokoneellasi (jos tarvitset sovelluksen, [Hanki Updater CE](guide_fi.html#platform)). Aseta Laitteen malli to Y2.
  - Valitse Inniclassic sisään Ohjelmisto.
  - Valitse Y2:lle listattu julkaisu.
  - Napsauta Asenna / Palauta.
  - Katkaise virta ja liitä Y2 vain, kun Updater CE kysyy.

## UKKVoinko palauttaa varastossa olevan Y2-ohjelmiston?

Kyllä. Valitse Y2 ja Original Software Updater CE:ssä. The [Y2 osakeohjelmistoopas](original-software-y2_fi.html) kattaa paluutien.Voinko käyttää Inniclassic:ta Y1:ssä?

Kyllä. Sama projekti julkaisee myös Y1 paketteja - rom.zip Type A ja rom_type_b.zip Type B. Valitse Y1 Updater CE:ssä ja asenna Y1-koonnos; the [Y1 asennussivu](inniclassic-y1-software_fi.html) peittää sen.Entä jos asennus epäonnistuu?

Huomaa, epäonnistuiko Updater ennen Y2:n havaitsemista vai sen jälkeen, ja tarkista sitten kaapeli, alustan asetukset, malli ja yhteyden ajoitus [vianetsintä](troubleshooting_fi.html).

## Käytä ohjattua reittiä

Käytät ensimmäistä kertaa Updateria? Katso opastettu asennus [Hanki Updater CE](guide_fi.html#platform) Windowsissa, macOS:ssä tai Linuxissa ennen soittimen liittämistä.
