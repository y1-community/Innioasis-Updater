# เฟิร์มแวร์สำหรับ Innioasis Y1

Y1 มีตัวเลือกระบบแบบกำหนดเองให้เลือกมากที่สุด ทุกอย่างด้านล่างโฮสต์อยู่ที่นี่ ตรวจสอบ และติดตั้งได้ในคลิกเดียวด้วย Updater CE[เรียกดู Y1 ดาวน์โหลด](firmware_th.html?model=Y1)[รับ Updater CE](guide_th.html#platform)[แกลลอรี่ธีม](https://themes.innioasis.app/?lang=th)

## ระบบปฏิบัติการที่ใช้ได้สำหรับ Innioasis Y1

Y1 ใช้งานระบบซอฟต์แวร์หลายระบบ รวมถึงบิลด์ที่รองรับตัวแปลงสัญญาณออดิโอไฟล์ ตัวเรียกใช้งานสมัยใหม่ และการคืนค่าจากโรงงาน เลือกอันที่เหมาะกับวิธีการฟังของคุณ:

### [Rockbox](rockbox-benefits_th.html)

มาตรฐานทองคำในการเล่นเสียงโอเพ่นซอร์ส Parametric EQ, การเล่น FLAC/MP3 ที่ไม่มีช่องว่าง, ธีม และชุดแบบอักษรที่สามารถติดตั้งได้โดยตรงใน Updater CE[Y1 Rockbox แนะนำ →](guides/rockbox-y1.html)

### [Better-Y](better-y-benefits_th.html)

อนุพันธ์ที่ได้รับการปรับปรุงของเฟิร์มแวร์ดั้งเดิมพร้อมแพตช์ความเสถียรของ Bluetooth การปรับเส้นโค้งระดับเสียง และความเข้ากันได้ของ Themes Gallery 100%[Better-Y คำแนะนำ →](guides/better-y-y1.html)

### [Solar](solar-benefits_th.html)

เครื่องเล่นเพลงโอเพ่นซอร์สร่วมสมัยที่สร้างด้วย Flutter นำเสนอแอนิเมชั่น 60fps ที่ราบรื่น ตารางปกอัลบั้ม และตัวพิมพ์สมัยใหม่[Solar Y1 แนะนำ →](guides/solar-y1.html)

### [Rondo](rondo-benefits_th.html)

ตัวเรียกใช้โอเพ่นซอร์ส Y1 สำหรับแทร็กและการสตรีมในเครื่องพร้อมการนำทางที่รวดเร็วและตอบสนอง[Rondo Y1 แนะนำ →](guides/rondo-y1.html)

### [Koensayr](koensayr-benefits.html)

โครงสร้างเฟิร์มแวร์แบบกำหนดเองพร้อมสัญลักษณ์ของตัวเอง การปรับเทียบแบตเตอรี่ที่ดีขึ้น และการรองรับธีมสต็อก[Koensayr คำแนะนำ →](guides/koensayr-y1.html)

### [ซอฟต์แวร์ต้นฉบับ (การเรียกคืนสต็อก)](original-software-benefits_th.html)

ทำความสะอาดอิมเมจเฟิร์มแวร์จากโรงงานสำหรับผู้เล่น Type A (v2.0.0+) และ Type B (v1.x) Y1 ปลดบล็อกหรือกู้คืนอุปกรณ์ของคุณให้กลับสู่สถานะโรงงานอย่างปลอดภัย[คืนค่าคำแนะนำ Y1 →](guides/restore-original-y1.html)

## วิธีการติดตั้งหรืออัพเดตเฟิร์มแวร์ Y1

การอัพเกรดหรือยกเลิกการปิดกั้น Innioasis Y1 ของคุณทำได้ง่าย ๆ ด้วยชุดซอฟต์แวร์หลายแพลตฟอร์มของเรา:
  - เปิด Innioasis Updater CE: เปิดตัวอัปเดตบน macOS, Windows หรือ Linux
  - เลือกรุ่น Y1: เลือก Y1 ในเมนูแบบเลื่อนลงรุ่นอุปกรณ์
  - เลือกระบบปฏิบัติการของคุณ: เลือก Rockbox, Better-Y, Solar หรือซอฟต์แวร์ต้นฉบับ
  - คลิกติดตั้ง: Updater CE ดาวน์โหลดแพ็คเกจเฟิร์มแวร์โดยตรงจากรุ่นของผู้พัฒนา เมื่อได้รับแจ้ง ให้เชื่อมต่อ Y1 ขณะปิดเครื่องผ่าน USB เพื่อเริ่มการกะพริบ
[เรียกดูข่าว Y1 ทั้งหมด](firmware_th.html?model=Y1)[คู่มือการติดตั้งทีละขั้นตอน](guide_th.html)
