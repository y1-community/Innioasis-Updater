# שחזר את התוכנה המקורית ב-Innioasis Y2 שלך.

דף זה מיועד לתוכנת מלאי Y2, שחזור מפעל והחזרה מפרויקט קהילתי. שמור את הדגם והחבילה Y2 ביחד.[פתח את מדריך התוכנה המקורית המלא](guides/restore-original-y2.html)[קבל את זה ב-Updater CE](guide_he.html?model=Y2&software=original-y2)[עיין במהדורות Y2](firmware_he.html#y2)

מדריך התקנת המחשב שלך

## שחזר תוכנה מקורית ב-Y2 באמצעות המחשב שלך

בחר את המדריך עבור המחשב שבו אתה משתמש. לכל גרסה יש את הגדרת הפלטפורמה, Updater CE שלבים והדרך חזרה למלאי.[מדריך Windows](install/original-y2-windows.html)[מדריך macOS](install/original-y2-mac.html)[מדריך לינוקס](install/original-y2-linux.html)

[כל Innioasis מדריכי Y2](install/y2.html) · [כל מדריכי התוכנה המקורית](install/original-software.html)

## התקן או שחזר אותו באמצעות Updater

הגדר את המחשב תחילה, ולאחר מכן תן ל-Update להכין את החבילה התואמת לדגם.
  - פתח את Innioasis Updater CE במחשב שלך (אם אתה צריך את האפליקציה, [הורדת Updater CE](guide_he.html#platform)). סט דגם המכשיר ל Y2.
  - בחר תוכנה מקורית ושחרור Y2.
  - לחץ התקנה / שחזור.
  - כבה וחבר את Y2 רק כאשר ההנחיה החיה מבקשת.

חבילות התקנה מלאה ידני עשויות להשתמש `rom_y2.zip`. אל תטפל ב-Y1 `rom.zip` כתחליף.

## שאלות נפוצותהאם אוכל להחזיר מ-Rockbox או מתוכנה מותאמת אישית אחרת?

השתמש באותה זרימת שחזור של Y2: בחר Y2, בחר תוכנה מקורית, ובצע את הוראת החיבור. אין לערבב קבצי דגמים.מדוע החבילה Y2 נראית אחרת?

Y2 מהדורות יכולות להשתמש בשם חבילה ובערך גרסה שונה. בחר Y2 בעדכון במקום לנחש מתוך שם קובץ ZIP ידני.מה אם הנגן לא מזוהה?

בדוק את כבל הנתונים, הרשאות המחשב או מנהלי ההתקנים והתזמון. חבר את ה-Y2 הכבוי רק לאחר שהעדכון אומר שהוא מוכן.
