## Verificações Y2 corretas do modelo
  - Abra Innioasis Updater CE no seu computador (se precisar do aplicativo, [Obtenha o atualizador CE](guide_pt-PT.html#platform)). Definir Modelo do dispositivo para Y2.
  - Confirme isso Solar está listado para Y2 nos dados da versão atual.
  - Leia a nota de lançamento do projeto e verifique seu suporte Y2.
  - Escolha a versão listada e clique em Instalar / Restaurar.
  - Desligue e conecte o Y2 somente quando Updater CE solicitar.
Não substitua um pacote Y1. Um projeto disponível para Y1 não torna seu pacote Y1 seguro para Y2.

## Perguntas frequentesÉ garantido que Solar Y2 seja compatível?

Uma compilação Solar Y2 está listada, mas o suporte e o conteúdo podem mudar. Verifique a listagem mais recente e as notas de versão antes de instalar.Como faço para voltar ao stock?

Escolha Y2 e Software Original em Updater CE e siga as [Y2 guia de restauração](original-software-y2_pt-PT.html).E se Solar não for mostrado para Y2?

Não force um pacote Y1. Verifique a origem do projeto e o [guia de solução de problemas](troubleshooting_pt-PT.html)e aguarde uma versão compatível.
