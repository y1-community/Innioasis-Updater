# Instale Inniclassic no Y1.

Inniclassic é um projeto de software comunitário para Y1, e o mesmo projeto também publica uma compilação Y2, portanto está disponível em ambos os jogadores. Esta página fornece a Y1 resposta amigável para pesquisa e links para as etapas detalhadas de conexão.[Abra o guia Inniclassic completo](guides/inniclassic-y1.html)[Obter no Updater CE](guide_pt-BR.html?model=Y1&software=inniclassic-y1)[Por que Inniclassic?](inniclassic-benefits_pt-BR.html)

## Inniclassic Y1 etapas de instalação
  - Abra o Innioasis Updater CE no seu computador (se precisar do aplicativo, [Obter o Updater CE](guide_pt-BR.html#platform)). Definir Modelo do aparelho para Y1.
  - Escolher Inniclassic em Software.
  - Escolha o lançamento listado para Y1.
  - Clique Instalar / Restaurar.
  - Desligue e conecte o Y1 somente quando o Updater CE solicitar.

## Perguntas frequentesPosso restaurar o software padrão Y1?

Sim. Selecione Y1 e Software Original em Updater CE. O [Y1 guia de software de estoque](original-software-y1_pt-BR.html) cobre o caminho de retorno.E se a instalação falhar?

Observe se o Updater falhou antes ou depois de detectar o Y1, então verifique o cabo, configuração da plataforma, modelo e tempo de conexão em [solução de problemas](troubleshooting_pt-BR.html).Posso usar Inniclassic em Y2?

Sim. Inniclassic está disponível em ambos os modelos — o mesmo projeto mantido publica um pacote Y2 das mesmas versões. Selecione Y2 em Updater CE e instale a compilação Y2; nunca atualize um pacote Y1 para um Y2. O [Página de instalação do Y2](inniclassic-y2-software_pt-BR.html) cobre isso.
