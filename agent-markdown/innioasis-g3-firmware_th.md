# Innioasis G3 & G1 ดาวน์โหลดเฟิร์มแวร์

การอัปเดตเฟิร์มแวร์อย่างเป็นทางการจากโรงงานและการกระจายการกู้คืนสำหรับเครื่องเล่นเพลงพกพา Innioasis G3 และ G1 ดาวน์โหลดได้รับการยืนยันแล้ว `rom_g3.zip` และ `rom_g1.zip` แพ็คเกจโดยตรงจากส่วนการดาวน์โหลดซอฟต์แวร์ของ Innioasis Firmware Archive[เรียกดู G3 ดาวน์โหลด](firmware_th.html?model=G3)[เรียกดู G1 ดาวน์โหลด](firmware_th.html?model=G1)[รับ Updater CE](guide_th.html#platform)

## เฟิร์มแวร์ที่เชื่อถือได้สำหรับผู้เล่น G-Series

ที่ Innioasis G3 และ Innioasis G1 เป็นเครื่องเล่นเสียงขนาดกะทัดรัดพกพาสะดวก สร้างขึ้นเพื่ออายุการใช้งานแบตเตอรี่ที่ยาวนานและการฟังแบบออฟไลน์ หากเครื่องเล่นของคุณไม่ตอบสนอง ค้างขณะบูต หรือต้องการซอฟต์แวร์ระบบใหม่ ไฟล์เก็บถาวรของเราจะจัดเตรียมอิมเมจการคืนค่าจากโรงงานที่ได้รับการทดสอบแล้ว

คุณสมบัติของแค็ตตาล็อกเฟิร์มแวร์ G-series ของเรา:
  - ซอฟต์แวร์สต็อกดั้งเดิม: คืนค่าเครื่องเล่นเสียงจากโรงงาน ฟังก์ชั่นวิทยุ FM และไดรเวอร์ Bluetooth
  - การติดตั้งข้ามแพลตฟอร์ม: ติดตั้งโดยตรงโดยใช้ [Innioasis ตัวอัพเดต CE](guide_th.html) บน macOS, Linux หรือ Windows
  - ใช้ได้เสมอ: โฮสต์โดยชุมชน โดยไม่มีลิงก์แชร์ไฟล์ที่หมดอายุ

## กระพริบเครื่องเล่นของคุณด้วย Updater CE

หากต้องการคืนค่าเครื่องเล่น G3 หรือ G1 ของคุณ:
  - เปิด Innioasis ตัวอัพเดต CE บนเดสก์ท็อปหรือแล็ปท็อปของคุณ
  - เลือก G3 หรือ G1 จากเมนูรุ่นอุปกรณ์
  - เลือก ซอฟต์แวร์ดั้งเดิม และ Updater จะดึงไฟล์ที่ถูกต้อง: `rom_g3.zip` หรือ `rom_g1.zip`.
  - ปฏิบัติตามข้อความแจ้งการเชื่อมต่อเพื่อแนบเครื่องเล่นของคุณบน USB และทำการแฟลชให้เสร็จสิ้น
