# Install Linux on the Y1.

Linux for Y1 is an experimental community Linux kernel and rootfs port for the Innioasis Y1 hardware. This page links to the full installation guide and releases.[Open the full Linux for Y1 (Dev) guide](guides/linux-y1.html)[Få dette i Updater CE](guide_da.html?model=Y1&software=linux-y1)[Projektkilde](https://github.com/y1-community/y1-linux-rom)

Installationsvejledning til din computer

## Install Linux for Y1 (Dev) on your Y1 with your computer

Vælg vejledningen til den computer, du bruger. Hver version har platformsopsætningen, Updater CE trin og vejen tilbage til lageret.[Windows guide](install/linux-y1-windows.html)[macOS guide](install/linux-y1-mac.html)[Linux guide](install/linux-y1-linux.html)

[Alle Innioasis Y1 guider](install/y1.html) · [All Linux for Y1 (Dev) guides](install/linux-dev.html)

## Linux Y1 install steps
  - Åbn Innioasis Updater CE på din computer (hvis du har brug for appen, [Hent Updater CE](guide_da.html#platform)). Sæt Enhedsmodel til Y1.
  - Vælg Linux til Y1 (Dev) ind Software.
  - Vælg den udgivelse, der er angivet for Y1.
  - Klik Installer / Gendan.
  - Sluk og tilslut kun Y1, når Updater CE spørger.
