# Hvorfor installere Rondo på din Innioasis Y1?

Rondo er en open source, specialbygget clickwheel-musikafspiller-firmware designet specifikt til Innioasis Y1-hardwaren. Det tilbyder ren bibliotekssøgning, ren typografi og hurtig lydafkodning.[Installer Rondo på Y1](guides/rondo-y1.html)[Gennemse udgivelser](firmware_da.html?model=Y1&software=rondo-y1)

## Højdepunkter fra Rondo

### Hurtig klikhjulsrespons

Omhyggeligt afstemt accelerationskurve matchet med det Y1 fysiske kapacitive berøringshjul for jævn rulning gennem store musikbiblioteker.

### Fokuseret lydafspiller

Ingen bloatware, baggrundsanalyse eller unødvendige dæmoner: 100 % af hardwareressourcerne er dedikeret til sprød lydoutput.

### Vendbar når som helst

Installer nemt ved hjælp af Innioasis Updater CE og vend tilbage til original software eller Rockbox, når du vil.
