# เฟิร์มแวร์สำหรับ Innioasis Y2

Y2 มีฮาร์ดแวร์เสียง บลูทูธ และตัวจัดการไฟล์ที่ดีกว่า เลือกระบบที่กำหนดเอง บิลด์ Linux หรือซอฟต์แวร์อย่างเป็นทางการที่จะกู้คืน[เรียกดู Y2 ดาวน์โหลด](firmware_th.html?model=Y2)[รับ Updater CE](guide_th.html#platform)[Y2 คำแนะนำธีม](https://themes.innioasis.app/y2-themes.html?lang=th)

## ระบบปฏิบัติการที่ใช้ได้สำหรับ Innioasis Y2

เลือกสิ่งที่คุณต้องการเรียกใช้บน Y2:

### [Reborn (Y2Linux)](reborn-y2linux-benefits_th.html)

Linux OS แบบฝังในตัวที่รวม Buildroot, LVGL, PipeWire และ MPD ให้เวลาบูตเครื่อง 3 วินาที แก้ไขปัญหาการเชื่อมต่อหูฟัง Bluetooth อย่างแท้จริง และการเล่นที่ไม่มีช่องว่าง[Y2Reborn คำแนะนำ →](guides/reborn-y2linux-y2.html)

### [Rockbox สำหรับ Y2](rockbox-benefits_th.html)

สุดยอดเฟิร์มแวร์ออดิโอไฟล์ที่ย้ายไปยัง Innioasis Y2 การปรับสมดุลพารามิเตอร์ แบบอักษรที่กำหนดเอง การป้อนข้าม และการสนับสนุนไลบรารีปลั๊กอินที่ครอบคลุม[Y2 Rockbox แนะนำ →](guides/rockbox-y2.html)

### [Solar สำหรับ Y2](solar-benefits_th.html)

อินเทอร์เฟซเครื่องเล่นเพลงที่ใช้ Flutter ที่ทันสมัยและลื่นไหลสำหรับ Y2 นำเสนอวิชวลไลเซอร์ที่หลากหลาย การนำเสนอปกอัลบั้มขนาดใหญ่ และการนำทางด้วยท่าทาง[Solar Y2 แนะนำ →](guides/solar-y2.html)

### [Y2Player](y2player-benefits_th.html)

เครื่องเล่นเสียงชุมชนน้ำหนักเบาที่สร้างขึ้นสำหรับฮาร์ดแวร์ Y2 พร้อมการเรียกดูโฟลเดอร์ที่ง่ายดายและการสแกนดัชนีที่รวดเร็ว[Y2Player คำแนะนำ →](guides/y2player-y2.html)

### [ซอฟต์แวร์ดั้งเดิม (การคืนค่าจากโรงงาน)](original-software-benefits_th.html)

อิมเมจเฟิร์มแวร์หุ้นอย่างเป็นทางการ (rom_y2.zip) สำหรับการกู้คืน Innioasis Y2 กลับไปสู่สภาพดั้งเดิมจากโรงงาน พร้อมการรองรับสกิน Themes Gallery[คืนค่าคำแนะนำ Y2 →](guides/restore-original-y2.html)

## การติดตั้งเฟิร์มแวร์บน Innioasis Y2 ของคุณ

Updater CE คว้าไฟล์ที่ถูกต้องและตรวจสอบไดรเวอร์ก่อนกระพริบ:
  - เปิดตัว Innioasis Updater CE: พร้อมใช้งานบน macOS, Linux และ Windows
  - กำหนดรุ่น: เลือก Y2 ในเมนูรุ่นอุปกรณ์
  - เลือกระบบปฏิบัติการ: เลือก Reborn, Rockbox, Solar หรือซอฟต์แวร์ต้นฉบับ
  - แฟลชอย่างปลอดภัย: ปฏิบัติตามคำแนะนำบนหน้าจอเพื่อเชื่อมต่ออุปกรณ์ของคุณผ่าน USB เพื่อให้ได้แฟลชที่สะอาดและได้รับการยืนยัน
[สำรวจแคตตาล็อกเฟิร์มแวร์ Y2](firmware_th.html?model=Y2)[ภาพรวมการติดตั้ง](guide_th.html)
