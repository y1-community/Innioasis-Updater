# Install Android 4.2 (Dev) on the Y1.

Android 4.2 is a community development ROM for testing and hacking on Innioasis Y1 hardware. This page links to the full tutorial and release list.[Open the full Android 4.2 (Dev) guide](guides/android-4-2-y1.html)[इसे Updater CE में प्राप्त करें](guide_hi.html?model=Y1&software=android-4-2-y1)[परियोजना स्रोत](https://github.com/y1-community/y1-ata-rom)

## Install Android development ROM on your Y1 with your computer

आप जिस कंप्यूटर का उपयोग कर रहे हैं उसके लिए गाइड चुनें. प्रत्येक संस्करण में प्लेटफ़ॉर्म सेटअप, Updater CE चरण और स्टॉक में वापस आने का तरीका होता है।[विंडोज़ गाइड](install/android-4-2-y1-windows.html)[macOS गाइड](install/android-4-2-y1-mac.html)[लिनक्स गाइड](install/android-4-2-y1-linux.html)

## Android 4.2 Y1 install steps
  - Open Innioasis Updater CE on your computer (if you need the app, [Updater CE प्राप्त करें](guide_hi.html#platform)). सेट डिवाइस मॉडल को Y1.
  - चुनें एंड्रॉइड 4.2 (डेव) में सॉफ़्टवेयर.
  - Y1 के लिए सूचीबद्ध रिलीज़ चुनें।
  - क्लिक करें इंस्टॉल / पुनर्स्थापित.
  - बिजली बंद करें और Y1 को तभी कनेक्ट करें जब Updater CE पूछे।

## अक्सर पूछे जाने वाले प्रश्नक्या मैं स्टॉक Y1 सॉफ़्टवेयर को पुनर्स्थापित कर सकता हूँ?

हाँ। Updater CE में Y1 और मूल सॉफ़्टवेयर का चयन करें। द [Y1 स्टॉक-सॉफ्टवेयर गाइड](original-software-y1_hi.html) वापसी पथ को कवर करता है।Is this a daily driver ROM?

This is an experimental developer ROM intended for testing and development. Feature updates are on the project's page.

## निर्देशित मार्ग का प्रयोग करें

क्या आप पहली बार अपडेटर का उपयोग कर रहे हैं? इसके लिए निर्देशित सेटअप देखें [Updater CE प्राप्त करें](guide_hi.html#platform) अपने प्लेयर को कनेक्ट करने से पहले Windows, macOS, या Linux पर।
