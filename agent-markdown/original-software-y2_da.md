## Installer eller gendan det med Updater

Konfigurer først computeren, og lad derefter Updater forberede den model-matchede pakke.
  - Åbn Innioasis Updater CE på din computer (hvis du har brug for appen, [Få Updater CE](guide_da.html#platform)). Sæt Enhedsmodel til Y2.
  - Vælg Original software og en Y2 udgivelse.
  - Klik Installer / Gendan.
  - Sluk og tilslut kun Y2, når live-prompten spørger.

Manuel fuldinstallationspakker kan bruge `rom_y2.zip`. Behandl ikke en Y1 `rom.zip` som erstatning.
