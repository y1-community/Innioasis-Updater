# Innioasis Y2 の Solar ファームウェア |互換性とインストール ガイド - Innioasis ファームウェアのダウンロード

Solar · Innioasis Y2

# インストールする前にSolarY2のルートを確認してください。

Y2 には Solar ビルドがリストされていますが、サポートは変更される可能性があります。フラッシュする前に、プロジェクト ページで最新のリリース ノートを確認してください。[Solar ガイド全体を開く](guides/solar-y2.html)[Updater CE で入手](guide_ja.html?model=Y2&software=solar-y2)[なぜSolar?](solar-benefits_ja.html)

お使いのコンピューターのインストールガイド

## コンピュータを使用して Y2 に Solar をインストールします

使用しているコンピュータのガイドを選択してください。 すべてのバージョンには、プラットフォームのセットアップ、Updater CE の手順、および在庫に戻る方法が含まれています。[Windowsガイド](install/solar-y2-windows.html)[macOS ガイド](install/solar-y2-mac.html)[Linuxガイド](install/solar-y2-linux.html)

[すべての Innioasis Y2 ガイド](install/y2.html) · [すべての Solar ガイド](install/solar.html)

## モデルが正しい Y2 チェック
  - コンピューターで Innioasis Updater CE を開きます (アプリが必要な場合は、 [Updater CE を入手](guide_ja.html#platform)）。セット デバイスモデル 支援先: Y2.
  - それを確認してください Solar 現在のリリース データでは Y2 にリストされています。
  - プロジェクトのリリース ノートを読み、その Y2 サポートを確認してください。
  - リストされているリリースを選択して、 インストール / 復元.
  - Updater CE が要求した場合にのみ、電源をオフにして Y2 を接続してください。
Y1 パッケージを置き換えないでください。 Y1 で利用可能なプロジェクトは、その Y1 パッケージを Y2 に対して安全にしません。

## よくある質問Solar Y2 はサポートされることが保証されていますか?

Solar Y2 ビルドがリストされていますが、サポートと内容は変更される可能性があります。インストールする前に、最新のリストとリリース ノートを確認してください。在庫に戻すにはどうすればよいですか?

Y2 を選択し、Updater CE でオリジナル ソフトウェアを選択し、次の手順に従います。 [Y2 復元ガイド](original-software-y2_ja.html).Y2 に Solar が表示されない場合はどうなりますか?

Y1 パッケージを強制しないでください。プロジェクトのソースと [トラブルシューティングガイド](troubleshooting_ja.html)、その後、互換性のあるリリースを待ちます。

## まずコンピューターをセットアップします

プラットフォームのセットアップが完了した後のプレーヤー側のフローは同じです。から始めてください [Windows、macOS、または Linux 用のアップデータ ガイド](guide_ja.html#platform).
