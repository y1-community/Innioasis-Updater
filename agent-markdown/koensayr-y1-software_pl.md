## Koensayr Y1 install steps
  - Otwórz Innioasis Updater CE na swoim komputerze (jeśli potrzebujesz aplikacji, [Pobierz Updater CE](guide_pl.html#platform)). Zestaw Model urządzenia do Y1.
  - Wybierz Koensayr w Oprogramowanie.
  - Choose the listed Y1 release.
  - Kliknij Zainstaluj / Przywróć.
  - Wyłącz i podłącz Y1 tylko wtedy, gdy Updater CE zapyta.

## Najczęstsze pytaniaCan I restore the original Y1 software?

Yes. Select Y1 and Original Software in Updater CE. See the [Y1 stock-software page](original-software-y1_pl.html) for the complete restore route.What should I check when it fails?

Check the model, release, cable, platform setup, and whether the player was connected before the prompt. Then use [rozwiązywanie problemów](troubleshooting_pl.html).Is there a Koensayr Y2 package?

The current build is for Y1. Don't use it on a Y2 unless the project publishes a separate release for it.
