## Model-correct checks
  - Buka Innioasis Updater CE pada komputer anda (jika anda memerlukan apl itu, [Dapatkan Updater CE](guide_ms.html#platform)). Tetapkan Model Peranti kepada Y2.
  - Confirm JJ Launcher appears for Y2 in the current release data.
  - Read the project release note and select the listed Y2 release.
  - klik Pasang / Pulihkan.
  - Power off and connect the Y2 only when prompted.
Do not substitute: a Y1 package is not a Y2 package. Stop if the model and release do not agree.
