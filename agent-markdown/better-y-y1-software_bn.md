# Install Better-Y on the Y1.

Better-Y provides an enhanced stock experience for the Innioasis Y1 with tag splitting, album track numbers, Now Playing shortcuts, and smoother RAM caching while maintaining 100% theme compatibility.[Open the full Better-Y guide](guides/better-y-y1.html)[এটি Updater CE এ পান](guide_bn.html?model=Y1&software=better-y-y1)[কেন Better-Y?](better-y-benefits_bn.html)

## Install Better-Y on your Y1 with your computer

আপনি যে কম্পিউটারটি ব্যবহার করছেন তার জন্য গাইডটি বেছে নিন। প্রতিটি সংস্করণে প্ল্যাটফর্ম সেটআপ, Updater CE পদক্ষেপ এবং স্টকে ফিরে যাওয়ার উপায় রয়েছে।[উইন্ডোজ গাইড](install/better-y-y1-windows.html)[macOS গাইড](install/better-y-y1-mac.html)[লিনাক্স গাইড](install/better-y-y1-linux.html)

## Better-Y Y1 install steps
  - আপনার কম্পিউটারে Innioasis Updater CE খুলুন (যদি আপনার অ্যাপটির প্রয়োজন হয়, [Updater CE নিন](guide_bn.html#platform)) সেট ডিভাইস মডেল থেকে Y1.
  - বেছে নিন Better-Y মধ্যে সফটওয়্যার.
  - Y1-এর জন্য তালিকাভুক্ত রিলিজ বেছে নিন।
  - ক্লিক করুন ইনস্টল / পুনরুদ্ধার.
  - পাওয়ার বন্ধ করুন এবং শুধুমাত্র Updater CE বললেই Y1 সংযোগ করুন।

## সাধারণ প্রশ্নWhat is improved over the stock firmware?

Better-Y adds track numbers, splits multi-artist tags, uses real titles, and adds playback shortcuts, plus fixes for caching and Bluetooth. Same themes as before.আমি কি স্টক Y1 সফ্টওয়্যার পুনরুদ্ধার করতে পারি?

হ্যাঁ। Updater CE-এ Y1 এবং অরিজিনাল সফটওয়্যার নির্বাচন করুন। দ [Y1 স্টক-সফ্টওয়্যার গাইড](original-software-y1_bn.html) ফেরার পথ কভার করে।Can I use my existing themes?

Yes! Better-Y is built on official stock 3.1.2 and maintains 100% compatibility with all custom themes from the Themes Gallery.ইনস্টলেশন ব্যর্থ হলে কি হবে?

Note whether Updater failed before or after detecting the Y1, then check the cable, platform setup, model, and connection timing in [সমস্যা সমাধান](troubleshooting_bn.html).
