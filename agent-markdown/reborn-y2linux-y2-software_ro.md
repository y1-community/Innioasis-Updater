# Reborn (Y2Linux) pentru Innioasis Y2

O distribuție Debian Linux rapidă, special concepută, cu o interfață de utilizator nativă cu rotiță de clic pentru Innioasis Y2, oferind stabilitate pentru căști Bluetooth și dezvoltare activă a comunității.[Ghid Y2 pas cu pas](guides/reborn-y2linux-y2.html)[De ce Y2Reborn?](reborn-y2linux-benefits_ro.html)[Descărcați versiunile](firmware_ro.html?model=Y2&software=reborn-y2linux-y2)

Ghid de instalare pentru computerul dvs

## Instalați Reborn (Y2Linux) pe Y2 cu computerul dvs

Alegeți ghidul pentru computerul pe care îl utilizați. Fiecare versiune are configurarea platformei, Updater CE pași și calea de întoarcere la stoc.[Ghidul Windows](install/reborn-y2linux-y2-windows.html)[ghid macOS](install/reborn-y2linux-y2-mac.html)[Ghid Linux](install/reborn-y2linux-y2-linux.html)

[Toate ghidurile Innioasis Y2](install/y2.html) · [Toate ghidurile Reborn (Y2Linux).](install/reborn.html)

## Etape de instalare
  - Deschideți Updater CE. Disponibil pentru Windows, macOS și Linux.
  - Selectați Y2 ca model de dispozitiv.
  - Selectați Reborn (Y2Linux) ca software.
  - Faceți clic pe Instalare/Restaurare. Așteptați până când Updater CE pregătește fișierele.
  - Conectați USB când vi se solicită. Opriți mai întâi Y2.
  - Configurați Wi-Fi, Bluetooth și radio FM

Copiere `system.img` jucătorului o dată. Reborn face restul.[Terminați configurarea →](y2reborn_wifibt_ro.html)
