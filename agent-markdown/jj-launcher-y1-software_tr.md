## JJ Launcher Y1 install steps
  - Bilgisayarınızda Innioasis Updater CE'yi açın (uygulamaya ihtiyacınız varsa, [Updater CE edin](guide_tr.html#platform)). Ayarlamak Cihaz modeli ile Y1.
  - Seçmek JJ Launcher içinde Yazılım.
  - Choose the release shown for Y1.
  - Tıklamak Yükle / Geri yükle.
  - Y1'i yalnızca Updater CE sorduğunda kapatın ve bağlayın.

## SSSCan I install the Y2 entry on a Y1?

No. Keep the model and package matched. If the Y1 entry is missing, do not force a Y2 file.Can I go back to the original software?
