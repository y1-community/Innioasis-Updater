## What is Innioasis Updater CE?

Innioasis Updater CE is an open-source tool that simplifies updating and restoring your player across Windows, macOS, and Linux.

Flashing through Updater CE preserves your music library, video collection, and Bluetooth pairings while guiding each step on screen.[Get Updater CE](guide.html#platform)[Compare flashing tools](updater-comparison.html)[Browse software](firmware.html)

## Using Innioasis Updater01

### Check your model

Verify the model printed on the back of your device. Y1 and Y2 packages differ.02

### Select firmware

Choose the build you want from the catalog for your hardware revision.03

### Install or restore

Updater prepares the archive and prompts you when to connect your player.

## Getting started with Rockbox

### Install Rockbox on Y1

Select Y1, choose Rockbox stable, and connect only when prompted.[Y1 instructions](guides/rockbox-y1.html)[Why Rockbox?](rockbox-benefits.html)

### Install Rockbox on Y2

Select Y2 in the tool. The Y2 route uses hardware-specific binaries.[Y2 instructions](guides/rockbox-y2.html)[Why Rockbox?](rockbox-benefits.html)

### Restore factory software

Returning to factory software uses the same flow: select your model and choose Original Software.[Y1 factory restore](guides/restore-original-y1.html)[Y2 factory restore](guides/restore-original-y2.html)

Compatible with Windows, macOS, and Linux.
