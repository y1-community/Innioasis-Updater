## JJ Launcher Y1 install steps
  - Open Innioasis Updater CE on your computer (if you need the app, [Updater CE प्राप्त करें](guide_hi.html#platform)). सेट डिवाइस मॉडल को Y1.
  - चुनें JJ Launcher में सॉफ़्टवेयर.
  - Choose the release shown for Y1.
  - क्लिक करें इंस्टॉल / पुनर्स्थापित.
  - बिजली बंद करें और Y1 को तभी कनेक्ट करें जब Updater CE पूछे।

## अक्सर पूछे जाने वाले प्रश्नCan I install the Y2 entry on a Y1?

No. Keep the model and package matched. If the Y1 entry is missing, do not force a Y2 file.Can I go back to the original software?

Yes. Choose Y1 and Original Software in Updater CE. See the [Y1 restore page](original-software-y1_hi.html).Where are all the JJ Launcher releases?
