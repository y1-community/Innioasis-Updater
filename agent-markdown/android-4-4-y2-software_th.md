# เฟิร์มแวร์ Android 4.4 (Dev) สำหรับ Innioasis Y2 | ติดตั้งบทช่วยสอน - Innioasis ดาวน์โหลดเฟิร์มแวร์

แอนดรอยด์ 4.4 (พัฒนา) · Innioasis Y2

# ติดตั้ง Android 4.4 (Dev) บน Y2

Android 4.4 เป็นการพัฒนาชุมชน ROM สำหรับการทดสอบและการแฮ็กฮาร์ดแวร์ Innioasis Y2 หน้านี้เชื่อมโยงไปยังบทช่วยสอนและรายการเผยแพร่ฉบับเต็ม[เปิดคู่มือ Android 4.4 (Dev) ฉบับเต็ม](guides/android-4-4-y2.html)[รับสิ่งนี้ใน Updater CE](guide_th.html?model=Y2&software=android-4-4-y2)[แหล่งที่มาของโครงการ](https://github.com/y1-community/y2-ata-rom)

คู่มือการติดตั้งสำหรับคอมพิวเตอร์ของคุณ

## ติดตั้งการพัฒนา Android ROM บน Y2 ด้วยคอมพิวเตอร์ของคุณ

เลือกคำแนะนำสำหรับคอมพิวเตอร์ที่คุณใช้ ทุกรุ่นมีการตั้งค่าแพลตฟอร์ม ขั้นตอน Updater CE และวิธีคืนสินค้าในสต็อก[คู่มือวินโดวส์](install/android-4-4-y2-windows.html)[คู่มือ macOS](install/android-4-4-y2-mac.html)[คู่มือลินุกซ์](install/android-4-4-y2-linux.html)

[คำแนะนำ Innioasis Y2 ทั้งหมด](install/y2.html) · [คู่มือ ROM การพัฒนา Android ทั้งหมด](install/android-dev.html)

## ขั้นตอนการติดตั้ง Android 4.4 Y2
  - เปิด Innioasis Updater CE บนคอมพิวเตอร์ของคุณ (หากคุณต้องการแอป [รับ Updater CE](guide_th.html#platform)). ชุด รุ่นอุปกรณ์ ถึง Y2.
  - เลือก ระบบปฏิบัติการ Android 4.4 (พัฒนา) ใน ซอฟต์แวร์.
  - เลือกรุ่นที่แสดงรายการสำหรับ Y2
  - คลิก ติดตั้ง / คืนค่า.
  - ปิดเครื่องและเชื่อมต่อ Y2 เมื่อ Updater CE ถามเท่านั้น

## คำถามที่พบบ่อยฉันสามารถกู้คืนซอฟต์แวร์สต็อก Y2 ได้หรือไม่

ใช่. เลือก Y2 และซอฟต์แวร์ต้นฉบับใน Updater CE ที่ [Y2 คู่มือซอฟต์แวร์หุ้น](original-software-y2_th.html) ครอบคลุมเส้นทางขากลับนี่เป็นไดรเวอร์รายวัน ROM หรือไม่

นี่คือนักพัฒนาทดลอง ROM ที่มีไว้สำหรับการทดสอบและพัฒนา การอัปเดตการเปิดตัวอยู่ในหน้าของโครงการ

## ใช้เส้นทางที่แนะนำ

ครั้งแรกที่ใช้ Updater? ดูการตั้งค่าที่แนะนำไปที่ [รับ Updater CE](guide_th.html#platform) บน Windows, macOS หรือ Linux ก่อนที่จะเชื่อมต่อเครื่องเล่นของคุณ
