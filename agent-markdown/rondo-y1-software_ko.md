## 컴퓨터를 사용하여 Y1에 Rondo을(를) 설치합니다.

사용 중인 컴퓨터에 대한 가이드를 선택하세요. 모든 버전에는 플랫폼 설정, Updater CE 단계 및 재고로 돌아가는 방법이 있습니다.[윈도우 가이드](install/rondo-y1-windows.html)[macOS 가이드](install/rondo-y1-mac.html)[리눅스 가이드](install/rondo-y1-linux.html)

[모든 Innioasis Y1 가이드](install/y1.html) · [모든 Rondo 가이드](install/rondo.html)

## 설치 단계
  - 발사 Innioasis 업데이터 CE Windows, Mac 또는 Linux 컴퓨터에서.
  - 선택 Y1 장치 모델 드롭다운에서
  - 선택 Rondo 소프트웨어 드롭다운에서
  - 클릭 설치 / 복원 도구가 파일을 다운로드하고 준비할 때까지 기다립니다.
  - Updater CE에서 메시지가 표시되면 Y1의 전원을 끄고 USB 케이블을 연결합니다.
  - 설치 후 설정 완료

다음 단계를 따르세요. [이 가이드](post_install_ko.html?software=rondo-y1&model=Y1) Y1에서 설정을 완료하려면[가이드 보기](post_install_ko.html?software=rondo-y1&model=Y1)
