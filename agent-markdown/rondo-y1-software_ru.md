# Rondo для Innioasis Y1

Минималистичная прошивка музыкального проигрывателя с колесиком управления, разработанная специально для емкостного оборудования Innioasis Y1 и полностью ориентированная на быстрое воспроизведение и понятную навигацию.[Пошаговое руководство Y1](guides/rondo-y1.html)[Почему Rondo?](rondo-benefits_ru.html)[Скачать релизы](firmware_ru.html?model=Y1&software=rondo-y1)

Руководство по установке для вашего компьютера

## Установите Rondo на свой Y1 с помощью компьютера.

Выберите руководство для компьютера, который вы используете. В каждой версии есть настройка платформы, Updater CE шагов и возврат к стоку.[Руководство по Windows](install/rondo-y1-windows.html)[руководство по macOS](install/rondo-y1-mac.html)[Руководство по Linux](install/rondo-y1-linux.html)

[Все Innioasis Y1 руководства](install/y1.html) · [Все Rondo руководства](install/rondo.html)

## Этапы установки
  - Запуск Innioasis Средство обновления CE на вашем компьютере с Windows, Mac или Linux.
  - Выбирать Y1 из раскрывающегося списка Модель устройства.
  - Выбирать Rondo из раскрывающегося списка «Программное обеспечение».
  - Нажмите Установить / Восстановить и подождите, пока инструмент загрузит и подготовит файлы.
  - При появлении запроса Updater CE выключите Y1 и подключите кабель USB.
  - Полная настройка после установки
