## 使用 Updater CE 安裝您的選擇
  - 如果您的電腦尚未安裝，請開啟指南並安裝 Innioasis Updater CE。
  - 在 Updater CE 中，從下列位置選擇印在播放機上的型號 裝置型號.
  - 從 軟體，選擇您想要在該型號上運行的軟體。
  - 選擇一個版本，點擊 安裝 / 還原，然後僅在更新程式 CE 詢問時關閉並連接播放器。

需要安裝程式嗎？ [開啟指南並展開 Updater CE 下載部分](guide_zh-TW.html#download-updater).

## 安全回來的路

### 檢查型號

Y1 and Y2 software is not interchangeable. Re-select the model in Updater CE and start again.

### 等待提示

只有當更新程式 CE 表示已準備就緒時，才完全關閉播放器並連接它。

### 恢復原始軟體

同一型號請選擇原廠軟體。如果需要手動恢復，請打開 [故障排除指南](troubleshooting_zh-TW.html) 首先。
