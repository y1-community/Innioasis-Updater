# Innioasis Y1에 Rondo을(를) 설치하는 이유는 무엇입니까?

Rondo Innioasis Y1 하드웨어용으로 특별히 설계된 오픈 소스 전용 클릭휠 음악 플레이어 펌웨어입니다. 깔끔한 라이브러리 탐색, 깔끔한 타이포그래피, 빠른 오디오 디코딩을 제공합니다.[Y1에 Rondo을(를) 설치합니다.](guides/rondo-y1.html)[릴리스 찾아보기](firmware_ko.html?model=Y1&software=rondo-y1)

## Rondo의 하이라이트

### 빠른 클릭휠 응답

대규모 음악 라이브러리를 통한 부드러운 스크롤을 위해 Y1 물리적 용량성 터치휠과 일치하도록 세심하게 조정된 가속 곡선.

### 집중 오디오 플레이어

블로트웨어, 백그라운드 분석 또는 불필요한 데몬이 없습니다. 하드웨어 리소스의 100%가 선명한 오디오 출력에 사용됩니다.

### 언제든지 되돌릴 수 있음

Innioasis 업데이터 CE를 사용하여 쉽게 설치하고 원할 때마다 원본 소프트웨어 또는 Rockbox로 돌아갈 수 있습니다.
