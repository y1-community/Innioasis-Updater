## JJ Launcher Y1 のインストール手順
  - コンピューターで Innioasis Updater CE を開きます (アプリが必要な場合は、 [Updater CE を入手](guide_ja.html#platform)）。セット デバイスモデル 支援先: Y1.
  - 選択してください JJ Launcher で ソフトウェア.
  - Y1 に表示されているリリースを選択します。
  - クリック インストール / 復元.
  - Updater CE が要求した場合にのみ、電源をオフにして Y1 を接続してください。

## よくある質問Y2 エントリを Y1 にインストールできますか?

いいえ。モデルとパッケージを一致させてください。 Y1 エントリがない場合は、Y2 ファイルを強制的に作成しないでください。元のソフトウェアに戻すことはできますか?

はい。 Y1 を選択し、Updater CE でオリジナル ソフトウェアを選択します。を参照してください。 [Y1 ページの復元](original-software-y1_ja.html).すべての JJ Launcher リリースはどこにありますか?
