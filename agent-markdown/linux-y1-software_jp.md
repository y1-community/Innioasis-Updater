# Y1 に Linux をインストールします。

Linux for Y1 は、実験的なコミュニティ Linux カーネルと Innioasis Y1 ハードウェアの rootfs ポートです。このページは、完全なインストール ガイドとリリースにリンクしています。[Y1 の完全な Linux (開発) ガイドを開く](guides/linux-y1.html)[Updater CE で入手](guide_ja.html?model=Y1&software=linux-y1)[プロジェクトソース](https://github.com/y1-community/y1-linux-rom)

お使いのコンピューターのインストールガイド

## コンピューターを使用して Y1 に Y1 (Dev) 用の Linux をインストールします

使用しているコンピュータのガイドを選択してください。 すべてのバージョンには、プラットフォームのセットアップ、Updater CE の手順、および在庫に戻る方法が含まれています。[Windowsガイド](install/linux-y1-windows.html)[macOS ガイド](install/linux-y1-mac.html)[Linuxガイド](install/linux-y1-linux.html)

[すべての Innioasis Y1 ガイド](install/y1.html) · [Y1 用のすべての Linux (開発) ガイド](install/linux-dev.html)

## Linux Y1 のインストール手順
  - コンピューターで Innioasis Updater CE を開きます (アプリが必要な場合は、 [Updater CE を入手](guide_ja.html#platform)）。セット デバイスモデル 支援先: Y1.
  - 選択してください Y1 向け Linux (開発) で ソフトウェア.
  - Y1 にリストされているリリースを選択します。
  - クリック インストール / 復元.
  - Updater CE が要求した場合にのみ、電源をオフにして Y1 を接続してください。

## よくある質問在庫の Y1 ソフトウェアを復元できますか?

はい。 Updater CEでY1とオリジナルソフトウェアを選択します。の [Y1 ストック ソフトウェア ガイド](original-software-y1_ja.html) 復路をカバーします。これは日常的なユーザー インターフェイスですか?

これは、開発者と Linux いじくり回し者のための実験的なポートです。ターミナルとコンソールの手順はプロジェクトのドキュメントに記載されています。

## ガイド付きルートを利用する

アップデーターを初めて使用しますか?ガイド付きセットアップを参照してください。 [Updater CE を入手](guide_ja.html#platform) Windows、macOS、または Linux では、プレーヤーを接続する前に。
