# Android 4.4 (Dev) を Y2 にインストールします。

Android 4.4 は、Innioasis Y2 ハードウェアのテストとハッキングを目的としたコミュニティ開発 ROM です。このページは、完全なチュートリアルとリリース リストにリンクしています。[完全な Android 4.4 (Dev) ガイドを開く](guides/android-4-4-y2.html)[Updater CE で入手](guide_ja.html?model=Y2&software=android-4-4-y2)[プロジェクトソース](https://github.com/y1-community/y2-ata-rom)

## コンピュータを使用して Android 開発 ROM を Y2 にインストールします

使用しているコンピュータのガイドを選択してください。 すべてのバージョンには、プラットフォームのセットアップ、Updater CE の手順、および在庫に戻る方法が含まれています。[Windowsガイド](install/android-4-4-y2-windows.html)[macOS ガイド](install/android-4-4-y2-mac.html)[Linuxガイド](install/android-4-4-y2-linux.html)

[すべての Innioasis Y2 ガイド](install/y2.html) · [すべての Android 開発 ROM ガイド](install/android-dev.html)

## Android 4.4 Y2 のインストール手順
  - コンピューターで Innioasis Updater CE を開きます (アプリが必要な場合は、 [Updater CE を入手](guide_ja.html#platform)）。セット デバイスモデル 支援先: Y2.
  - 選択してください Android 4.4 (開発版) で ソフトウェア.
  - Y2 にリストされているリリースを選択します。
  - クリック インストール / 復元.
  - Updater CE が要求した場合にのみ、電源をオフにして Y2 を接続してください。

## よくある質問在庫 Y2 ソフトウェアを復元できますか?

はい。 Y2を選択し、Updater CEでオリジナルソフトウェアを選択します。の [Y2 ストック ソフトウェア ガイド](original-software-y2_ja.html) 復路をカバーします。これは日雇い運転手 ROM ですか?

これは、テストと開発を目的とした実験的な開発者 ROM です。リリースの更新情報はプロジェクトのページにあります。
