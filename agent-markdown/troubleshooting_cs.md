# Innioasis Odstraňování problémů s aktualizací | Problémy s instalací Innioasis a Timmkoo - Innioasis Updater

Řešení problémů

# Najděte místo, kde se instalace zastavila.

kde se to zastavilo? To vám říká, co opravit.[Vraťte se k normálnímu průvodci](guide_cs.html)[Zkontrolujte firmware](firmware_cs.html)

## Zastavil se před výzvou USB

Toto je problém s počítačem, ne s kabelem. Zkontrolujte svůj model. Znovu rozbalte soubor. Pak zkuste Nainstalovat / Obnovit. Pokud je seznam verzí prázdný, otevřete [adresář firmwaru](firmware_cs.html).

## Nelze se připojit k přehrávači
  - Úplně vypněte správné Y1 nebo Y2.
  - Odpojte kabel, zavřete ostatní nástroje flash nebo Android a spusťte instalaci znovu.
  - Připojte se pouze tehdy, když Updater říká, že je připraven.
  - Použijte krátký datový kabel USB přímo v počítači, pokud možno ne rozbočovač.
  - V systému Windows přeinstalujte ovladač MediaTek a restartujte počítač. V systému Linux zkontrolujte oprávnění USB/serial.
Výzva k připojení aktualizaceVýzva živého Updater je směrodatná pro aktuální model a platformu.

## Rozpoznal přehrávač, ale blesk selhal

Zastavte se zde. Nezkoušejte jiný model. Zavřete ostatní nástroje, zkontrolujte, zda jste vybrali správné Y1 nebo Y2, a pokud se přehrávač nespustí, použijte odpovídající originální software. [SP Flash Tool](sp-flash-tool_cs.html) a MTKClient jsou zahrnuty, pokud je potřebujete, a soubory jsou na [stránka firmwaru](firmware_cs.html).

## Poznámky k ovladačům Windows

Některé instalace Windows blokují ovladač MediaTek kvůli izolaci jádra. Před změnou integrity paměti postupujte podle aktuálních pokynů k zabezpečení systému Windows a po dokončení ji znovu zapněte, pokud to váš systém umožňuje.[Otevřete průvodce ovladačem](drivers_cs.html)[Průvodce čistou instalací](Troubleshooting/clean_install.html)

## Kolo nefunguje nebo se přehrávač nespustí

Poruchy vstupu a napájení vyžadují jiné kroky než selhání blesku. Tyto pokyny pokrývají běžné případy Y1 a Y2.[Y1 rolovací kolečko](guides/y1-scroll-wheel-not-working.html)[Y2 rolovací kolečko](guides/y2-scroll-wheel-not-working.html)[Y1 se nezapne](guides/y1-wont-turn-on.html)[Y2 se nezapne](guides/y2-wont-turn-on.html)[Průvodce obnovou](guides/recovery.html)
