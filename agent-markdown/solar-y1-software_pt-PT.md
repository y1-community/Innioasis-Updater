## Solar Y1 etapas de instalação
  - Abra Innioasis Updater CE no seu computador (se precisar do aplicativo, [Obtenha o atualizador CE](guide_pt-PT.html#platform)). Definir Modelo do dispositivo para Y1.
  - Escolher Solar em Programas.
  - Leia a nota de lançamento do projeto e escolha uma versão Y1.
  - Clique Instalar / Restaurar.
  - Desligue e conecte o Y1 somente quando o prompt aparecer.

Solar recursos e disponibilidade podem mudar. Os recursos podem mudar entre os lançamentos, portanto verifique a página de lançamento do projeto e a listagem atual do seu modelo.

## Perguntas frequentesPosso retornar de Solar para o software original?

Use Y1 software original em Updater CE. Você não precisa remover manualmente Solar primeiro. Siga o [Y1 etapas de restauração](original-software-y1_pt-PT.html).Posso instalar a entrada Solar Y2 neste player?

Não. Mantenha o player Y1 na entrada Y1 e verifique o modelo antes de instalar.Onde devo verificar os recursos Solar atuais?

Leia o [notas de lançamento](release_notes_pt-PT.html?software=solar-y1) antes de escolher um lançamento.
