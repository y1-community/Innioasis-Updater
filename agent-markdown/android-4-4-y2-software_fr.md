# Installez Android 4.4 (Dev) sur le Y2.

Android 4.4 est un développement communautaire ROM pour tester et pirater le matériel Innioasis Y2. Cette page renvoie au didacticiel complet et à la liste des versions.[Ouvrez le guide complet Android 4.4 (Dev)](guides/android-4-4-y2.html)[Disponible dans Updater CE](guide_fr.html?model=Y2&software=android-4-4-y2)[Origine du projet](https://github.com/y1-community/y2-ata-rom)

## Étapes d'installation d'Android 4.4 Y2
  - Ouvrez Innioasis Updater CE sur votre ordinateur (si vous avez besoin de l'application, [Obtenir Updater CE](guide_fr.html#platform)). Ensemble Modèle d'appareil à Y2.
  - Choisissez Android 4.4 (développement) dans Logiciel.
  - Choisissez la version répertoriée pour Y2.
  - Cliquez Installer / Restaurer.
  - Éteignez et connectez le Y2 uniquement lorsque Updater CE le demande.

## FAQPuis-je restaurer le logiciel d'origine Y2 ?

Oui. Sélectionnez Y2 et Logiciel original dans Updater CE. Le [Y2 guide des logiciels en stock](original-software-y2_fr.html) couvre le chemin de retour.Est-ce un conducteur quotidien ROM ?

Il s'agit d'un développeur expérimental ROM destiné aux tests et au développement. Les mises à jour des versions sont sur la page du projet.
