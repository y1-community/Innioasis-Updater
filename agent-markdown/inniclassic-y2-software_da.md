# Installer Inniclassic på Y2.

Inniclassic er tilgængelig for Innioasis Y2, og det samme projekt bygger også Y1-pakkerne. Denne side giver dig Y2 oversigten og links til hele selvstudiet.[Åbn den fulde Inniclassic guide](guides/inniclassic-y2.html)[Få dette i Updater CE](guide_da.html?model=Y2&software=inniclassic-y2)[Hvorfor Inniclassic?](inniclassic-benefits_da.html)

## Installer Inniclassic på din Y2 med din computer

Vælg vejledningen til den computer, du bruger. Hver version har platformsopsætningen, Updater CE trin og vejen tilbage til lageret.[Windows guide](install/inniclassic-y2-windows.html)[macOS guide](install/inniclassic-y2-mac.html)[Linux guide](install/inniclassic-y2-linux.html)

[Alle Innioasis Y2 guider](install/y2.html) · [Alle Inniclassic guider](install/inniclassic.html)

## Inniclassic Y2 installationstrin
  - Åbn Innioasis Updater CE på din computer (hvis du har brug for appen, [Få Updater CE](guide_da.html#platform)). Sæt Enhedsmodel til Y2.
  - Vælg Inniclassic ind Software.
  - Vælg den udgivelse, der er angivet for Y2.
  - Klik Installer / Gendan.
  - Sluk og tilslut kun Y2, når Updater CE spørger.

## Ofte stillede spørgsmålKan jeg gendanne aktiesoftwaren Y2?

Ja. Vælg Y2 og original software i Updater CE. Den [Y2 vejledning til aktiesoftware](original-software-y2_da.html) dækker returvejen.Kan jeg bruge Inniclassic på Y1?

Ja. Det samme projekt udgiver også Y1 pakker - rom.zip for Type A og rom_type_b.zip for Type B. Vælg Y1 i Updater CE og installer Y1 build; de [Y1 installationsside](inniclassic-y1-software_da.html) dækker det.Hvad hvis installationen mislykkes?

Bemærk, om opdateringen fejlede før eller efter registrering af Y2, og tjek derefter kablet, platformsopsætningen, modellen og forbindelsestidspunktet i [fejlfinding](troubleshooting_da.html).
