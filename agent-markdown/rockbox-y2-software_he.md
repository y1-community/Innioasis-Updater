# התקן את התוכנה Y2 Rockbox, לא את ה-Y1 build.

המסע של Updater מוכר, אבל Y2 זקוק לבחירת דגמים משלו ולשחרור שלו. דף זה עונה על השאלות הנפוצות "Rockbox על Y2" לפני שתתחיל.[פתח את המדריך המלא Rockbox](guides/rockbox-y2.html)[קבל את זה ב-Updater CE](guide_he.html?model=Y2&software=rockbox-y2)[למה Rockbox?](rockbox-benefits_he.html)

## התקן את Rockbox ב-Y2 שלך עם המחשב שלך

בחר את המדריך עבור המחשב שבו אתה משתמש. לכל גרסה יש את הגדרת הפלטפורמה, Updater CE שלבים והדרך חזרה למלאי.[מדריך Windows](install/rockbox-y2-windows.html)[מדריך macOS](install/rockbox-y2-mac.html)[מדריך לינוקס](install/rockbox-y2-linux.html)

[כל Innioasis מדריכי Y2](install/y2.html) · [כל המדריכים Rockbox](install/rockbox_he.html)

## Rockbox Y2 שלבי התקנה
  - פתח את Innioasis Updater CE במחשב שלך (אם אתה צריך את האפליקציה, [הורדת Updater CE](guide_he.html#platform)). סט דגם המכשיר ל Y2.
  - בחר Rockbox ב תוכנה.
  - בחר מהדורה הרשומה במפורש עבור Y2.
  - לחץ התקנה / שחזור ומחכים להכנת החבילה.
  - כבה וחבר את ה-Y2 רק כאשר Updater CE מבקש.

אל תכריח חבילה Y1 מכיוון ששם הפרויקט נראה זהה. אם לא מופיעה שחרור Y2, עצור ובדוק את הדגם ונתוני השחרור הנוכחיים.

## שאלות נפוצותהאם אוכל לשחזר את התוכנה המקורית Y2 מאוחר יותר?

כן. בחר Y2 ותוכנה מקורית בעדכון CE. ראה את [Y2 דף תוכנה במניות](original-software-y2_he.html) עבור רצף השחזור.מדוע החבילה עשויה להיקרא rom_y2.zip?

זהו רמז להורדה ידנית המשמש כמה מהדורות Y2 בהתקנה מלאה. הבחירה הבטוחה יותר היא עדיין בחירה ב-Y2 בעדכון CE ושימוש במהדורה שהוא מציג.האם אני יכול להשתמש במדריך Y1 Rockbox?

השתמש בו רק עבור הרעיון הרחב. לבחירת החבילה והדגם, עקוב אחר זה [Y2 מדריך ספציפי](guides/rockbox-y2.html).
