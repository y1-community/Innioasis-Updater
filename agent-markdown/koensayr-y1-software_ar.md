## Koensayr Y1 install steps
  - افتح Innioasis Updater CE على جهاز الكمبيوتر الخاص بك (إذا كنت بحاجة إلى التطبيق، [احصل على Updater CE](guide_ar.html#platform)). تعيين طراز الجهاز ل Y1.
  - اختر Koensayr في البرنامج.
  - Choose the listed Y1 release.
  - انقر تثبيت / استعادة.
  - قم بإيقاف تشغيل Y1 وتوصيله فقط عندما يطلب منك Updater CE.

## الأسئلة الشائعةCan I restore the original Y1 software?

Yes. Select Y1 and Original Software in Updater CE. See the [Y1 stock-software page](original-software-y1_ar.html) for the complete restore route.What should I check when it fails?

Check the model, release, cable, platform setup, and whether the player was connected before the prompt. Then use [استكشاف الأخطاء وإصلاحها](troubleshooting_ar.html).Is there a Koensayr Y2 package?

The current build is for Y1. Don't use it on a Y2 unless the project publishes a separate release for it.
