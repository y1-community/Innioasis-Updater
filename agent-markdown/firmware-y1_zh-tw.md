# Innioasis Y1 的韌體

Y1 擁有最廣泛的客製化系統選擇。下面的所有內容都在這裡託管、檢查並透過 Updater CE 一鍵安裝。[瀏覽 Y1 下載](firmware_zh-TW.html?model=Y1)[取得 Updater CE](guide_zh-TW.html#platform)[主題畫廊](https://themes.innioasis.app/?lang=zh-TW)

## Innioasis Y1 的可用作業系統

Y1 運行多個軟體系統，包括具有發燒級編解碼器支援的建置、現代啟動器和工廠恢復。選擇適合您聆聽方式的：

### [Rockbox](rockbox-benefits_zh-TW.html)

開源音訊播放的黃金標準。參數均衡器、無縫 FLAC/MP3 播放、主題和字型包可直接安裝在 Updater CE 中。[Y1 Rockbox 指引 →](guides/rockbox-y1.html)

### [Better-Y](better-y-benefits_zh-TW.html)

原始韌體的增強衍生版本，具有藍牙穩定性補丁、音量曲線調整和 100% 主題庫相容性。[Better-Y 指南 →](guides/better-y-y1.html)

### [Solar](solar-benefits_zh-TW.html)

使用 Flutter 建立的當代開源音樂播放器，提供流暢的 60fps 動畫、專輯封面網格和現代版。[Solar Y1 指引 →](guides/solar-y1.html)

### [Rondo](rondo-benefits_zh-TW.html)

用於本地曲目和串流媒體的開源 Y1 啟動器，具有快速、響應式導航。[Rondo Y1 指南 →](guides/rondo-y1.html)

### [Koensayr](koensayr-benefits.html)

自訂韌體建立具有自己的圖示、更好的電池校準和庫存主題支援。[Koensayr 指南 →](guides/koensayr-y1.html)

### [原始軟體（庫存恢復）](original-software-benefits_zh-TW.html)

清理 Type A (v2.0.0+) 和 Type B (v1.x) Y1 播放器的出廠韌體映像。安全地解鎖設備或將設備恢復至出廠狀態。[恢復 Y1 指南 →](guides/restore-original-y1.html)

## 如何安裝或更新 Y1 韌體

使用我們的多平台軟體套件，升級或取消變磚您的 Innioasis Y1 非常簡單：
  - 開啟 Innioasis 更新程式 CE： 在 macOS、Windows 或 Linux 上啟動更新程式。
  - 選擇型號 Y1： 選擇 Y1 在設備型號下拉清單中。
  - 選擇您的作業系統： 選擇Rockbox、Better-Y、Solar或原始軟體。
  - 點選安裝： 更新程式CE直接從開發人員的版本下載韌體套件。出現提示時，透過 USB 連接已關閉電源的 Y1 以開始閃爍。
