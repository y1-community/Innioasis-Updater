### 📥 MediaTek 驱动程序安装信息

安装 MediaTek 驱动程序时，您可能会看到一个对话框，询问是否删除“原始驱动程序”。该怎么做：重要的： 如果安装程序询问“删除原始驱动程序？”，请单击 是的。这是正常现象，有助于确保驱动程序在您的 Y1 设备上正常工作。 

这一步是必要的，因为：
  - 它删除了任何可能干扰的冲突驱动程序
  - 它确保 MediaTek 驱动程序完全控制 USB 通信
  - 它可以防止可能导致连接问题的驱动程序冲突

安装完成后，根据提示重新启动计算机即可完成设置。×

#### 第 1 步：获取合适的驱动程序

您的计算机需要知道如何与您的 Y1 对话。我们将安装两个驱动程序来实现这一点：📥 MediaTek 司机

这有助于您的计算机识别您的 Y1 设备下载 MediaTek 驱动程序帮助[已经这样做了](#)下一步：下载应用程序 →

#### 第 2 步：下载 Innioasis 更新程序

现在让我们获取将处理固件更新的实际应用程序：📱 Innioasis Windows 更新程序

这是引导您更新 Y1 的主应用程序下载 Windows 安装程序← 返回驱动程序下一步：安装 →

#### 第 3 步：安装所有内容

快到了！接下来要做的事情如下：
  - 安装您下载的 MediaTek 驱动程序
  - 安装 Innioasis 更新程序
  - 重新启动计算机 （这很重要！）
  - 从开始菜单启动 Innioasis 更新程序
← 返回下载完成设置1自制2下载3安装

#### 第1步：安装自制软件

Homebrew 就像一个包管理器，可以帮助安装 Mac 所需的所有组件。将其视为一个有用的助手，确保一切正常工作。📥 获取自制软件

单击下面的按钮访问 Homebrew 网站并遵循其简单的安装指南：访问自制网站下一步：下载应用程序 →

#### 第 2 步：下载 Innioasis 更新程序

现在让我们来获取实际的应用程序。单击下面的按钮，它将开始下载到您的下载文件夹：📱 Innioasis Mac 更新程序

这会将 .dmg 文件（磁盘映像）下载到您的下载文件夹中下载 Mac 版← 返回自制程序下一步：安装 →

#### 第 3 步：安装应用程序

现在让我们在 Mac 上安装该应用程序：
  - 双击下载的 .dmg 文件（它看起来像磁盘映像）
  - 将 Innioasis 更新程序应用程序拖至您的应用程序文件夹
  - 从您的应用程序文件夹中打开它
🔒 安全设置

您可能需要告诉您的 Mac 可以运行此应用程序。确切的步骤取决于您的 macOS 版本：打开安全指南← 返回下载完成设置
