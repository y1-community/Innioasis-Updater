Firmware pemutar musik clickwheel minimalis yang dirancang khusus untuk perangkat keras kapasitif Innioasis Y1, berfokus sepenuhnya pada pemutaran responsif dan navigasi yang bersih.[Panduan langkah demi langkah Y1](guides/rondo-y1.html)[Mengapa Rondo?](rondo-benefits_id.html)[Unduh Rilis](firmware_id.html?model=Y1&software=rondo-y1)

## Instal Rondo pada Y1 Anda dengan komputer Anda

Pilih panduan untuk komputer yang Anda gunakan. Setiap versi memiliki pengaturan platform, Updater CE langkah-langkahnya, dan cara kembali ke stok.[Panduan Windows](install/rondo-y1-windows.html)[panduan macOS](install/rondo-y1-mac.html)[Panduan Linux](install/rondo-y1-linux.html)

[Semua Innioasis panduan Y1](install/y1.html) · [Semua panduan Rondo](install/rondo.html)

## Langkah-Langkah Instalasi
  - Peluncuran Innioasis Updater Masehi di komputer Windows, Mac, atau Linux Anda.
  - Pilih Y1 dari tarik-turun Model Perangkat.
  - Pilih Rondo dari tarik-turun Perangkat Lunak.
  - Klik Pasang / Pulihkan dan tunggu alat mengunduh dan menyiapkan file.
  - Saat diminta oleh Updater CE, matikan Y1 Anda dan sambungkan kabel USB.
  - Selesaikan pengaturan pasca pemasangan

Ikuti langkah-langkah di [panduan ini](post_install_id.html?software=rondo-y1&model=Y1) untuk menyelesaikan pengaturan pada Y1 Anda.[Lihat Panduan](post_install_id.html?software=rondo-y1&model=Y1)
