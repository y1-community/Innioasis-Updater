# Nastavte Wi-Fi, Bluetooth a FM rádio.

Zkopírujte jeden soubor do přehrávače. Reborn se postará o zbytek.[Stáhnout system.img (860 MB)](https://github.com/y1-community/y1-stock-rom/releases/download/3.2.0-fm/system.img)[Průvodce instalací](guides/reborn-y2linux-y2.html)[Proč Y2Reborn?](reborn-y2linux-benefits_cs.html)

## Proč tento soubor?

Wi-Fi, Bluetooth a FM rádio potřebují pět MediaTek modulů firmwaru, které Reborn nelze dodat. Jsou uvnitř oficiální Y2 `system.img`. Reborn je jednou extrahuje, zkontroluje a smaže soubor.

## Nastavení
  - Stáhněte si system.img

Stáhněte si v3.2.0 FM `system.img` do vašeho počítače.[ Stáhněte si system.img ](https://github.com/y1-community/y1-stock-rom/releases/download/3.2.0-fm/system.img)
  - Spusťte Reborn jednou

Zapněte přehrávač. Počkejte Nastavení úložiště dokončit, pak jej jednou restartujte.
  - Připojte se k počítači

Použijte datový kabel USB. Přehrávač se zobrazí jako Interní úložiště.Na Macu?

Instalovat [OpenMTP](https://openmtp.ganeshrvel.com/) pro procházení přehrávače. Windows a Linux jej připojí automaticky.
  - Zkopírujte system.img do Firmware

Vytvořte složku s názvem `Firmware` v kořenovém adresáři Interního úložiště. Kopírovat `system.img` do toho.
  - Počkejte na dokončení nastavení

Reborn automaticky nainstaluje firmware rádia a smaže `system.img`. To trvá asi 10–20 sekund. Počkejte Wi-Fi a Bluetooth jsou připraveny.
  - Připojte Wi-Fi, Bluetooth a FM rádio
    - Wi-Fi: Nastavení → Systém → Síť → Wi-Fi. Vyberte si svou 2,4 GHz síť.
    - Bluetooth: Přepněte sluchátka do režimu párování. Nastavení → Bluetooth → vyberte je.
    - FM rádio: Zapojte kabelová sluchátka jako anténu a poté otevřete FM rádio.

  - Aktualizace přes Wi-Fi

Budoucí aktualizace Reborn se instalují z Nastavení → Systém → Aktualizace softwaru. Firmware vašeho rádia zůstane zachován.
