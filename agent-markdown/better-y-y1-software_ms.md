# Install Better-Y on the Y1.

Better-Y provides an enhanced stock experience for the Innioasis Y1 with tag splitting, album track numbers, Now Playing shortcuts, and smoother RAM caching while maintaining 100% theme compatibility.[Open the full Better-Y guide](guides/better-y-y1.html)[Dapatkan ini dalam Updater CE](guide_ms.html?model=Y1&software=better-y-y1)[Mengapa Better-Y?](better-y-benefits_ms.html)

## Better-Y Y1 install steps
  - Buka Innioasis Updater CE pada komputer anda (jika anda memerlukan apl itu, [Dapatkan Updater CE](guide_ms.html#platform)). Tetapkan Model Peranti kepada Y1.
  - pilih Better-Y dalam Perisian.
  - Pilih keluaran yang disenaraikan untuk Y1.
  - klik Pasang / Pulihkan.
  - Matikan dan sambungkan Y1 hanya apabila Updater CE bertanya.

## Soalan LazimWhat is improved over the stock firmware?

Better-Y adds track numbers, splits multi-artist tags, uses real titles, and adds playback shortcuts, plus fixes for caching and Bluetooth. Same themes as before.Bolehkah saya memulihkan perisian stok Y1?

ya. Pilih Y1 dan Perisian Asal dalam Updater CE. The [Panduan perisian stok Y1](original-software-y1_ms.html) meliputi laluan pulang.Can I use my existing themes?

Yes! Better-Y is built on official stock 3.1.2 and maintains 100% compatibility with all custom themes from the Themes Gallery.Bagaimana jika pemasangan gagal?

Note whether Updater failed before or after detecting the Y1, then check the cable, platform setup, model, and connection timing in [penyelesaian masalah](troubleshooting_ms.html).
