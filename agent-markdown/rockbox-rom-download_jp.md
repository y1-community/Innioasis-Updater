# Y1 および Y2 の Rockbox ROM ダウンロード

Innioasis Y1 (Rockbox-Y1) および Y2 (Rockbox-Y2) 用の Rockbox ROM ファームウェア パッケージをコミュニティ開発者から直接ダウンロードするか、Innioasis Updater CE を使用してワンクリックでインストールします。

## まずプレーヤーのモデルを選択してください

Rockbox-Y1 と Rockbox-Y2 は、異なるハードウェア用に作成された個別のファームウェア ビルドです。ダウンロードまたはフラッシュする前に、お使いのプレーヤーが Innioasis Y1 または Y2 であるかどうかを確認してください。

| パッケージ | ファイル | リンク |
| --- | --- | --- |
| Rockbox-Y1 開発者 ROM パッケージ | rom.zip | ダウンロード |
| Rockbox-Y1 Type B 開発者 ROM パッケージ | rom_type_b.zip | ダウンロード |

発行者 [rockbox-y1/rockbox](firmware_ja.html?model=Y1&software=rockbox-y1) リリース中の開発者 [stable-v0.6](release_notes_ja.html?author=rockbox-y1&project=rockbox&version=stable-v0.6&software=rockbox-y1) ([プロジェクトの README](firmware_info_ja.html?repo=rockbox-y1%2Frockbox&software=rockbox-y1)）。 Innioasis Updater CE は常にコミュニティ ファームウェア開発者自身から直接ファームウェア パッケージをダウンロードし、それらの開発者は自分のリリースを Updater CE にリストする責任を単独で負います。[Rockbox-Y1 をインストールします](rockbox-y1/install.html)[Rockbox-Y1 ダウンロード数](rockbox-y1/download.html)[Y1 の Rockbox](rockbox-for-y1_ja.html)

## Updater CE がファームウェアをダウンロードする方法

Innioasis Updater CE は常にコミュニティ ファームウェア開発者自身のリリースからファームウェア パッケージを直接ダウンロードし、開発者自身がソフトウェア リリースを Updater CE にリストすることについて単独で責任を負います。各 ROM パッケージには、そのモデルの MediaTek スキャッタ ファイルとパーティション イメージが含まれています。
  - Rockbox-Y1 開発者リリース パッケージ: `rom.zip` （そして `rom_type_b.zip` Type B Y1 ユニットの場合)。
  - Rockbox-Y2 開発者リリース パッケージ: `rom_y2.zip`.

## Updater CE を使用して自動的にインストールします

最も簡単なセットアップを行うには、Innioasis Updater CE を開いてプレーヤーのモデルと Rockbox を選択し、アプリにリリースを直接ダウンロードしてフラッシュさせます。フォローしてください [Rockbox-Y1 インストール ガイド](rockbox-y1/install.html) または [Rockbox-Y2 インストール ガイド](rockbox-y2/install.html).
