## Install your choice with Updater CE
  - Open the guide and install Innioasis Updater CE for your computer if you do not have it yet.
  - In Updater CE, select the model printed on your player from Model Peranti.
  - From Perisian, select the software you want to run on that model.
  - Select a release, click Pasang / Pulihkan, then power off and connect the player only when Updater CE asks.

Need the installer? [Open the guide and expand the Updater CE download section](guide_ms.html#download-updater).

## The safe way back

### Check the model

Y1 and Y2 Software is not interchangeable. Re-select the model in Updater CE and start again.

### Wait for the prompt

Power the player fully off and connect it only when Updater CE says it is ready.

### Restore Original Software

Choose Original Software for the same model. If manual recovery is needed, open the [panduan penyelesaian masalah](troubleshooting_ms.html) pertama.

## Alat mana yang patut saya gunakan?

Innioasis Pengemaskini CE is the safest way to update your player. It keeps your music, videos, and settings. It tells you when updates are ready. It runs on Windows, macOS, and Linux.

The Innioasis Universal Flash Tool still exists for recovery. They wipe your player and need manual steps. You do not need them for a normal install. The Universal Flash Tool is also limited on newer Macs and not available on Linux.

Creators recommend Updater CE too: [Catsteal3r](https://www.tiktok.com/@catsteal3r/video/7572687586867612942) dan [Dammit Jeff](https://www.youtube.com/watch?v=3d2cATPt8Nk&t=477).[Alat mana yang patut saya gunakan?](updater-comparison_ms.html)
