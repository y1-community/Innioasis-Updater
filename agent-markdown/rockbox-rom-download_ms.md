# Rockbox ROM download for the Y1 and Y2

Muat turun Rockbox pakej perisian tegar ROM untuk Innioasis Y1 (Rockbox-Y1) dan Y2 (Rockbox-Y2) terus daripada pembangun komuniti, atau pasang dalam satu klik dengan Innioasis Updater CE.

## Choose your player model first

Rockbox-Y1 and Rockbox-Y2 are separate firmware builds created for different hardware. Check whether your player is an Innioasis Y1 or Y2 before downloading or flashing.

## How Updater CE downloads firmware

Innioasis Updater CE always downloads firmware packages directly from the community firmware developers' own releases, and the developers themselves are solely responsible for listing their software releases in Updater CE. Each ROM package contains the MediaTek scatter file and partition images for that model.
  - Rockbox-Y1 developer release package: `rom.zip` (and `rom_type_b.zip` for Type B Y1 units).
  - Rockbox-Y2 developer release package: `rom_y2.zip`.

## Install automatically with Updater CE

For the easiest setup, open Innioasis Updater CE, select your player model and Rockbox, and let the app download and flash the release directly. Follow the [Rockbox-Y1 install guide](rockbox-y1/install.html) or the [Rockbox-Y2 install guide](rockbox-y2/install.html).
