# התקן את Better-Y ב-Y1.

Better-Y מספק חוויית מלאי משופרת עבור Innioasis Y1 עם פיצול תגים, מספרי רצועות אלבומים, קיצורי דרך שמנגנים כעת ושמירה חלקה יותר במטמון של RAM תוך שמירה על 100% תאימות ערכת נושא.[פתח את המדריך המלא Better-Y](guides/better-y-y1.html)[קבל את זה ב-Updater CE](guide_he.html?model=Y1&software=better-y-y1)[למה Better-Y?](better-y-benefits_he.html)

מדריך התקנת המחשב שלך

## התקן את Better-Y ב-Y1 שלך עם המחשב שלך

בחר את המדריך עבור המחשב שבו אתה משתמש. לכל גרסה יש את הגדרת הפלטפורמה, Updater CE שלבים והדרך חזרה למלאי.[מדריך Windows](install/better-y-y1-windows.html)[מדריך macOS](install/better-y-y1-mac.html)[מדריך לינוקס](install/better-y-y1-linux.html)

[כל Innioasis מדריכי Y1](install/y1.html) · [כל המדריכים Better-Y](install/better-y.html)

## Better-Y Y1 שלבי התקנה
  - פתח את Innioasis Updater CE במחשב שלך (אם אתה צריך את האפליקציה, [הורדת Updater CE](guide_he.html#platform)). סט דגם המכשיר ל Y1.
  - בחר Better-Y ב תוכנה.
  - בחר את המהדורה הרשומה עבור Y1.
  - לחץ התקנה / שחזור.
  - כבה וחבר את ה-Y1 רק כאשר Updater CE מבקש.

## שאלות נפוצותמה השתפר לעומת קושחת המניות?

Better-Y מוסיף מספרי רצועות, מפצל תגיות מרובות אמנים, משתמש בכותרות אמיתיות ומוסיף קיצורי דרך להפעלה, בתוספת תיקונים לאחסון במטמון ו-Bluetooth. אותם נושאים כמו קודם.האם אוכל לשחזר את תוכנת המניות Y1?

כֵּן. בחר Y1 ותוכנה מקורית ב-Updater CE. ה [Y1 מדריך תוכנה למניות](original-software-y1_he.html) מכסה את נתיב החזרה.האם אני יכול להשתמש בערכות הנושא הקיימות שלי?

כֵּן! Better-Y בנוי על סטוק רשמי 3.1.2 ושומר על תאימות של 100% לכל הנושאים המותאמים אישית מגלריית הנושאים.מה אם ההתקנה נכשלת?

שים לב אם העדכון נכשל לפני או אחרי זיהוי ה-Y1, ולאחר מכן בדוק את הכבל, הגדרת הפלטפורמה, הדגם ותזמון החיבור ב- [פתרון בעיות](troubleshooting_he.html).

## השתמשו במסלול המודרך

פעם ראשונה שאתה משתמש ב-Updater? עיין בהגדרה המודרכת ל [הורדת Updater CE](guide_he.html#platform) ב-Windows, macOS או Linux לפני חיבור הנגן.
