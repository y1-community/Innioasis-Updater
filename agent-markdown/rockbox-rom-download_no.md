# Rockbox ROM nedlasting for Y1 og Y2

Last ned Rockbox ROM-fastvarepakker for Innioasis Y1 (Rockbox-Y1) og Y2 (Rockbox-Y2) direkte fra fellesskapsutviklerne, eller installer med ett klikk med Innioasis Updater CE.

## Velg din spillermodell først

Rockbox-Y1 og Rockbox-Y2 er separate fastvarebygg laget for forskjellig maskinvare. Sjekk om spilleren din er en Innioasis Y1 eller Y2 før du laster ned eller blinker.

## Hvordan Updater CE laster ned fastvare

Innioasis Updater CE laster alltid ned fastvarepakker direkte fra fellesskapsfastvareutviklernes egne utgivelser, og utviklerne selv er eneansvarlige for å liste programvareutgivelsene deres i Updater CE. Hver ROM-pakke inneholder MediaTek scatter-filen og partisjonsbilder for den modellen.
  - Rockbox-Y1 utviklerutgivelsespakke: `rom.zip` (og `rom_type_b.zip` for Type B Y1 enheter).
  - Rockbox-Y2 utviklerutgivelsespakke: `rom_y2.zip`.

## Installer automatisk med Updater CE

For det enkleste oppsettet, åpne Innioasis Updater CE, velg din spillermodell og Rockbox, og la appen laste ned og flashe utgivelsen direkte. Følg [Rockbox-Y1 installasjonsveiledning](rockbox-y1/install.html) eller den [Rockbox-Y2 installasjonsveiledning](rockbox-y2/install.html).
