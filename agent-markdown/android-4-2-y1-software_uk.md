## Android 4.2 Y1 install steps
  - Відкрийте Innioasis Updater CE на своєму комп’ютері (якщо вам потрібна програма, [Отримати Updater CE](guide_uk.html#platform)). встановити Модель пристрою для Y1.
  - Виберіть Android 4.2 (Dev) в Програмне забезпечення.
  - Виберіть випуск із списку для Y1.
  - Натисніть Встановити / Відновити.
  - Вимкніть живлення та підключіть Y1 лише тоді, коли Updater CE запитає.
