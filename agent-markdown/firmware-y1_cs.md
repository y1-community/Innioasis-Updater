# Firmware pro Innioasis Y1

Y1 má nejširší výběr vlastních systémů. Vše níže je zde hostováno, kontrolováno a instalováno jedním kliknutím pomocí Updater CE.[Procházet Y1 stažené soubory](firmware_cs.html?model=Y1)[Získat Updater CE](guide_cs.html#platform)[Galerie motivů](https://themes.innioasis.app/?lang=cs)

## Dostupné operační systémy pro Innioasis Y1

Na Y1 běží několik softwarových systémů, včetně sestavení s podporou kodeků pro audiofily, moderní spouštěče a obnovení továrního nastavení. Vyberte si ten, který se hodí k tomu, jak posloucháte:

### [Rockbox](rockbox-benefits_cs.html)

Zlatý standard v přehrávání zvuku s otevřeným zdrojovým kódem. Parametrický EQ, přehrávání FLAC/MP3 bez mezer, motivy a balíčky písem instalovatelné přímo v Updater CE.[Y1 Rockbox Průvodce →](guides/rockbox-y1.html)

### [Better-Y](better-y-benefits_cs.html)

Vylepšený derivát původního firmwaru se záplatami stability Bluetooth, úpravami křivky hlasitosti a 100% kompatibilitou Galerie motivů.[Better-Y Průvodce →](guides/better-y-y1.html)

### [Solar](solar-benefits_cs.html)

Současný hudební přehrávač s otevřeným zdrojovým kódem vytvořený pomocí nástroje Flutter, který nabízí plynulé animace 60 snímků za sekundu, mřížky obrázků alb a moderní typografii.[Solar Y1 Průvodce →](guides/solar-y1.html)

### [Rondo](rondo-benefits_cs.html)

Open-source Y1 launcher pro místní stopy a streamování s rychlou a citlivou navigací.[Rondo Y1 Průvodce →](guides/rondo-y1.html)

### [Koensayr](koensayr-benefits.html)

Vlastní sestavení firmwaru s vlastní ikonografií, lepší kalibrací baterie a podporou akciových témat.[Koensayr Průvodce →](guides/koensayr-y1.html)

### [Původní software (obnovení zásob)](original-software-benefits_cs.html)

Vyčistěte tovární obrazy firmwaru pro přehrávače Type A (v2.0.0+) a Type B (v1.x) Y1. Bezpečně odeberte nebo obnovte zařízení do továrního stavu.[Obnovit Y1 Průvodce →](guides/restore-original-y1.html)

## Jak nainstalovat nebo aktualizovat Y1 firmware

Upgrade nebo zrušení blokování vašeho Innioasis Y1 je jednoduché s naší multiplatformní softwarovou sadou:
  - Otevřít Innioasis Updater CE: Spusťte aktualizátor v systému macOS, Windows nebo Linux.
  - Vyberte model Y1: Vyberte si Y1 v rozevíracím seznamu Model zařízení.
  - Vyberte si svůj operační systém: Vyberte Rockbox, Better-Y, Solar nebo Originální software.
  - Klikněte na Instalovat: Updater CE stáhne balíček firmwaru přímo z vydání vývojáře. Až budete vyzváni, připojte svůj vypnutý Y1 přes USB, aby začal blikat.
