# Innioasis Solución de problemas del actualizador | Problemas de instalación de Innioasis y Timmkoo - Innioasis Actualizador

Solución de problemas

# Encuentre el punto donde se detuvo la instalación.

¿Dónde se detuvo? Eso te dice qué arreglar.[Volver a la guía normal](guide_es-419.html)[comprobar el firmware](firmware_es-419.html)

## Se detuvo antes del mensaje USB

Este es un problema de computadora, no de cables. Consulta tu modelo. Desempaquete el archivo nuevamente. Entonces intenta Instalar / Restaurar. Si la lista de versiones está vacía, abra la [directorio de firmware](firmware_es-419.html).

## No se puede conectar al reproductor.
  - Apague completamente el Y1 o Y2 correcto.
  - Desenchufe el cable, cierre otras herramientas flash o de Android y comience la instalación nuevamente.
  - Conéctese solo cuando el Actualizador indique que está listo.
  - Utilice un cable de datos corto USB directamente en la computadora, no un concentrador si es posible.
  - En Windows, reinstale el controlador MediaTek y reinicie. En Linux, verifique USB/permisos de serie.
Aviso de conexión del actualizadorEl mensaje del actualizador en vivo tiene autoridad para el modelo y la plataforma actuales.

## Detectó el reproductor pero el flash falló.

Deténgase aquí. No pruebes con un modelo diferente. Cierre otras herramientas, verifique que haya elegido el Y1 o Y2 correcto y use el software original correspondiente si el reproductor no se inicia. [SP Flash Tool](sp-flash-tool_es-419.html) y MTKClient están incluidos si los necesita, y los archivos están en el [página de firmware](firmware_es-419.html).

## Notas del controlador de Windows

Algunas instalaciones de Windows bloquean el controlador MediaTek debido al aislamiento del núcleo. Siga las instrucciones de seguridad actuales de Windows antes de cambiar la integridad de la memoria y vuelva a activarla cuando haya terminado si su sistema lo permite.[Abrir guía del conductor](drivers_es-419.html)[Guía de instalación limpia](Troubleshooting/clean_install.html)

## La rueda no funciona o el reproductor no arranca

Las fallas de entrada y energía necesitan pasos diferentes a los de un flash fallido. Estas guías cubren los casos comunes Y1 y Y2.[Y1 rueda de desplazamiento](guides/y1-scroll-wheel-not-working.html)[Y2 rueda de desplazamiento](guides/y2-scroll-wheel-not-working.html)[Y1 no enciende](guides/y1-wont-turn-on.html)[Y2 no enciende](guides/y2-wont-turn-on.html)[Guía de recuperación](guides/recovery.html)
