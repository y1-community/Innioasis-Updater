## Rockbox Y1 Installationsschritte
  - Öffnen Sie Innioasis Updater CE auf Ihrem Computer (wenn Sie die App benötigen, [Updater CE holen](guide_de.html#platform)). Satz Gerätemodell an Y1.
  - Wählen Sie Rockbox In Software.
  - Wählen Sie die Version und Variante aus, die Ihrem beabsichtigten Bildschirm oder Themenpfad entspricht.
  - Klicken Sie Installieren / Wiederherstellen und warten Sie, bis die App es vorbereitet.
  - Schalten Sie das Gerät aus und schließen Sie Y1 erst an der Live-Eingabeaufforderung an.

Benutzen Sie die [geschriebene Rockbox Y1 Anleitung](guides/rockbox-y1.html) für die Screenshots, das Video, die Notiz Type A oder Type B und die Verbindungscheckliste.

## FAQKann ich zur ursprünglichen Y1-Software zurückkehren?

Ja. Wählen Sie Y1 und Originalsoftware in Updater CE und führen Sie dann „Installieren/Wiederherstellen“ aus. Der [Y1 Aktien-Software-Seite](original-software-y1_de.html) erklärt diesen Weg.Welche Rockbox-Version soll ich wählen?

Wählen Sie eine für Y1 angezeigte Version aus und lesen Sie deren Versionshinweis. Wenn Sie ältere Theme-Kompatibilität benötigen, überprüfen Sie die Auflösungs- und Variantenhinweise, anstatt einen Y2-Build auszuwählen.Kann ich das auf einem Y2 installieren?

Nein. Verwenden Sie die separate [Rockbox Y2 Seite](rockbox-y2-software_de.html) und wählen Sie Y2 in Updater CE.
