## JJ Launcher Y1 étapes d'installation
  - Ouvrez Innioasis Updater CE sur votre ordinateur (si vous avez besoin de l'application, [Obtenir Updater CE](guide_fr.html#platform)). Ensemble Modèle d'appareil à Y1.
  - Choisissez JJ Launcher dans Logiciel.
  - Choisissez la version affichée pour Y1.
  - Cliquez Installer / Restaurer.
  - Éteignez et connectez le Y1 uniquement lorsque Updater CE le demande.

## FAQPuis-je installer l'entrée Y2 sur un Y1 ?

Non. Gardez le modèle et l’emballage correspondant. Si l'entrée Y1 est manquante, ne forcez pas un fichier Y2.Puis-je revenir au logiciel d'origine ?

Oui. Choisissez Y1 et Logiciel original dans Updater CE. Voir le [Y1 page de restauration](original-software-y1_fr.html).Où sont toutes les versions JJ Launcher ?
