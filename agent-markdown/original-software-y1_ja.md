## アップデーターを使用してインストールまたは復元する

アップデーターは、Y1 が現在オリジナルのソフトウェアを実行しているかコミュニティ プロジェクトを実行しているかに関係なく、同じガイド付きフローを使用します。
  - コンピューターで Innioasis Updater CE を開きます (アプリが必要な場合は、 [Updater CE を入手](guide_ja.html#platform)）。セット デバイスモデル 支援先: Y1.
  - 選択してください 純正ソフトウェア で ソフトウェア (または使用 [Updater CE で入手](guide_ja.html?model=Y1&software=original-y1) ガイド付きの手順にジャンプします)。
  - クリック インストール / 復元 そしてアプリにパッケージを準備させます。
  - ライブプロンプトが要求した場合にのみ、電源を切り、Y1 を接続してください。

手動でダウンロードする場合、通常のフルインストール パッケージには次の名前が付けられます。 `rom.zip`。 Updater でのモデルの選択は、ファイルを選択するより安全な方法です。

## よくある質問Rockbox または別のカスタム ソフトウェアから復元できますか?

はい、Y1 モデルと Y1 オリジナル ソフトウェア パスを使用します。最初にシステム ファイルを削除したり、Y2 パッケージを置き換えたりしないでください。Y1 が検出されない場合はどうすればよいですか?

データケーブル、コンピュータの設定、接続のタイミングを確認してください。プレーヤーの電源をオフにし、アップデーター プロンプトが表示された場合にのみ接続する必要があります。Y1 にはどのパッケージを使用すればよいですか?

アップデーターで選択したプレーヤーに印刷されたモデルを保持します。 Y1 パッケージと Y2 パッケージは別個です。リリース リストがお使いのモデルと一致しない場合は停止してください。
