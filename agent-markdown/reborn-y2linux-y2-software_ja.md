# Innioasis Y2 の Reborn (Y2Linux)

Innioasis Y2 用のネイティブ クリックホイール ユーザー インターフェイスを備えた、専用の高速 Debian Linux ディストリビューション。Bluetooth ヘッドフォンの安定性と活発なコミュニティ開発が特徴です。[ステップバイステップの Y2 ガイド](guides/reborn-y2linux-y2.html)[なぜY2Reborn?](reborn-y2linux-benefits_ja.html)[リリースをダウンロード](firmware_ja.html?model=Y2&software=reborn-y2linux-y2)

## コンピュータを使用して Y2 に Reborn (Y2Linux) をインストールします

使用しているコンピュータのガイドを選択してください。 すべてのバージョンには、プラットフォームのセットアップ、Updater CE の手順、および在庫に戻る方法が含まれています。[Windowsガイド](install/reborn-y2linux-y2-windows.html)[macOS ガイド](install/reborn-y2linux-y2-mac.html)[Linuxガイド](install/reborn-y2linux-y2-linux.html)

[すべての Innioasis Y2 ガイド](install/y2.html) · [すべての Reborn (Y2Linux) ガイド](install/reborn.html)

## インストール手順
  - Updater CE を開きます。 Windows、macOS、Linux で利用できます。
  - Y2を選択してください デバイスモデルとして。
  - Reborn (Y2Linux) を選択します ソフトウェアとして。
  - 「インストール/復元」をクリックします。 Updater CE がファイルを準備するまで待ちます。
  - 尋ねられたら USB を接続します。 まず Y2 の電源をオフにします。
  - Wi-Fi、Bluetooth、FM ラジオをセットアップする

コピー `system.img` プレイヤーに一度。残りは Reborn が行います。[セットアップを完了する →](y2reborn_wifibt_ja.html)
