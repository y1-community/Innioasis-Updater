## Install or restore it with Updater

Updater uses the same guided flow whether the Y1 is currently running its original software or a community project.
  - Buka Innioasis Updater CE pada komputer anda (jika anda memerlukan apl itu, [Dapatkan Updater CE](guide_ms.html#platform)). Tetapkan Model Peranti kepada Y1.
  - pilih Perisian Asal dalam Perisian (or use [Dapatkan ini dalam Updater CE](guide_ms.html?model=Y1&software=original-y1) to jump to the guided steps).
  - klik Pasang / Pulihkan and let the app prepare the package.
  - Power off and connect the Y1 only when the live prompt asks.

When downloading manually, the usual full-install package is named `rom.zip`. The model selection in Updater is the safer way to choose files.

## Soalan LazimCan I restore from Rockbox or another custom software?

Yes, use the Y1 model and Y1 Original Software path. Do not delete system files first and do not substitute a Y2 package.What if my Y1 is not detected?

Check the data cable, computer setup, and connection timing. The player should be powered off and connected only at the Updater prompt.Which package should I use for my Y1?

Keep the model printed on your player selected in Updater. Y1 and Y2 packages are separate — stop if the release list does not match your model.
