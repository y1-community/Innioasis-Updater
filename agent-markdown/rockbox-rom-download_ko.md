# Y1 및 Y2에 대한 Rockbox ROM 다운로드

Innioasis Y1(Rockbox-Y1) 및 Y2(Rockbox-Y2)용 Rockbox ROM 펌웨어 패키지를 커뮤니티 개발자로부터 직접 다운로드하거나 Innioasis Updater CE를 사용하여 한 번의 클릭으로 설치하세요.

## 먼저 플레이어 모델을 선택하세요

Rockbox-Y1 및 Rockbox-Y2은 서로 다른 하드웨어용으로 생성된 별도의 펌웨어 빌드입니다. 다운로드하거나 플래시하기 전에 플레이어가 Innioasis Y1 또는 Y2인지 확인하세요.

## Updater CE가 펌웨어를 다운로드하는 방법

Innioasis Updater CE는 항상 커뮤니티 펌웨어 개발자의 자체 릴리스에서 직접 펌웨어 패키지를 다운로드하며, 개발자 자신은 Updater CE에 소프트웨어 릴리스를 나열할 전적인 책임을 집니다. 각 ROM 패키지에는 해당 모델에 대한 MediaTek 스캐터 파일과 파티션 이미지가 포함되어 있습니다.
  - Rockbox-Y1 개발자 릴리스 패키지: `rom.zip` (그리고 `rom_type_b.zip` Type B Y1 단위의 경우).
  - Rockbox-Y2 개발자 릴리스 패키지: `rom_y2.zip`.

## Updater CE를 사용하여 자동으로 설치

가장 쉬운 설정을 위해 Innioasis 업데이터 CE를 열고 플레이어 모델과 Rockbox을 선택한 다음 앱이 직접 릴리스를 다운로드하고 플래시하도록 합니다. 따라가다 [Rockbox-Y1 설치 가이드](rockbox-y1/install.html) 또는 [Rockbox-Y2 설치 가이드](rockbox-y2/install.html).
