## Rockbox Y2 installationssteg
  - Öppna Innioasis Updater CE på din dator (om du behöver appen, [Hämta Updater CE](guide_sv.html#platform)). Ställ in Enhetsmodell till Y2.
  - Välj Rockbox i Programvara.
  - Välj en version som uttryckligen anges för Y2.
  - Klicka Installera / Återställ och vänta på paketberedning.
  - Stäng av och anslut Y2 endast när Updater CE frågar.

Tvinga inte fram ett Y1-paket eftersom projektnamnet ser likadant ut. Om ingen Y2 release visas, stoppa och kontrollera modellen och aktuella releasedata.

## Vanliga frågorKan jag återställa den ursprungliga Y2 programvaran senare?

Ja. Välj Y2 och originalprogramvara i Updater CE. Se den [Y2 sida med lagerprogramvara](original-software-y2_sv.html) för återställningssekvensen.Varför kan paketet heta rom_y2.zip?

Det är en ledtråd för manuell nedladdning som används av vissa Y2 fullständiga versioner. Det säkrare valet är fortfarande att välja Y2 i Updater CE och använda den version som den presenterar.Kan jag använda handledningen Y1 Rockbox?

Använd den bara för den breda idén. För val av paket och modell, följ detta [Y2-specifik guide](guides/rockbox-y2.html).
