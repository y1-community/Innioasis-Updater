## Instale sua escolha com Updater CE
  - Abra o guia e instale Innioasis Updater CE em seu computador, caso ainda não o tenha feito.
  - Em Updater CE, selecione o modelo impresso no seu player em Modelo do dispositivo.
  - De Programas, selecione o software que deseja executar nesse modelo.
  - Selecione uma versão, clique em Instalar / Restaurar, desligue e conecte o player somente quando Updater CE solicitar.

Precisa do instalador? [Abra o guia e expanda a seção de download Updater CE](guide_pt-PT.html#download-updater).

## O caminho seguro de volta

### Verifique o modelo

Y1 and Y2 software is not interchangeable. Re-select the model in Updater CE and start again.

### Aguarde o aviso

Desligue o player totalmente e conecte-o somente quando Updater CE disser que está pronto.

### Restaurar software original

Escolha Software Original para o mesmo modelo. Se a recuperação manual for necessária, abra o [guia de solução de problemas](troubleshooting_pt-PT.html) primeiro.

## Supported Devices and Official Stock Firmware

The Innioasis Firmware Archive hosts verified stock firmware, original factory restore images, and custom operating systems for portable players:

### Innioasis Y1 & Y2

Official software and custom systems including Rockbox, Better-Y, and Solar.

### Innioasis G1, G3 & G5

Software oficial e arquivos de recuperação para reprodutores touchscreen.

### Innioasis R1 & PR1

Software original e arquivos de recuperação para reprodutores de áudio.

### Timmkoo Q5 & Q3

Packages provided for Timmkoo players via Updater CE.

New releases appear here as soon as they are verified.

## Que ferramenta devo usar?

Innioasis Atualizador CE is the recommended tool for daily updates and community OS installs across Windows, macOS, and Linux. Flashing through Updater CE preserves your library and pairings.

The legacy Universal Flash Tool remains available for emergency unbricking when a device cannot boot into fastboot.[Compare flashing tools](updater-comparison_pt-PT.html)
