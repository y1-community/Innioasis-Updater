## 安裝步驟
  - 開啟更新程式 CE。 適用於 Windows、macOS 和 Linux。
  - 選擇Y2 作為設備型號。
  - 選擇Reborn（Y2Linux） 作為軟體。
  - 點選安裝/恢復。 等待 Updater CE 準備文件。
  - 當詢問時連接 USB。 首先關閉 Y2 的電源。
  - 設定 Wi-Fi、藍牙和 FM 收音機

複製 `system.img` 給玩家一次。 Reborn 完成剩下的工作。[完成設定 →](y2reborn_wifibt_zh-TW.html)
