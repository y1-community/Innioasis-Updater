# Rockbox для Y1 (Rockbox-Y1)

«Rockbox», «Rockbox-Y1» и «Rockbox для Y1» относятся к одной и той же прошивке сообщества Rockbox для Innioasis Y1. Вот что он добавляет в ваш плеер, какую сборку выбрать и как установить ее с помощью Innioasis Updater CE.[Установить Rockbox-Y1](rockbox-y1/install.html)[Загрузите ROM](rockbox-y1/download.html)[Письменное руководство](guides/rockbox-y1.html)[Rockbox-Y1 концентратор](rockbox-y1/)

## Одна прошивка, несколько названий

В Innioasis Updater CE эта прошивка отображается как Rockbox при выборе модели устройства Y1. Руководства, видеоролики и примечания к выпуску также называют его Rockbox-Y1 или Rockbox для Y1 поэтому ясно, что сборка предназначена для Y1, а не для Y2.

Перед установкой всегда проверяйте модель, указанную на вашем плеере: пакеты прошивки Y1 и Y2 не являются взаимозаменяемыми.

## Что Rockbox-Y1 добавляет к вашему Y1

Rockbox-Y1 — это общественный порт прошивки музыкального плеера Rockbox с открытым исходным кодом для Innioasis Y1:
  - Музыкальная библиотека на основе тегов — просмотр по исполнителю, альбому, жанру и году с помощью аудиотегов или просмотр папок напрямую.
  - Расширенное воспроизведение звука — воспроизведение без пауз, кроссфейд, ReplayGain и полноценный эквалайзер.
  - Пользовательские темы — выбирайте одну из сотен тем сообщества с разрешением 240p и 360p, включая классические макеты в стиле iPod.
  - FM-радио — встроенная поддержка FM-радио.
  - Дополнительные опции — загрузка подкастов через Wi-Fi и Last.fm/ListenBrainz/Maloja скробблинг на поддерживаемых сборках.
  - Двойная загрузка — вернуться к заводскому оригинальному программному обеспечению без перепрошивки на поддерживаемых сборках.

## Какую сборку Y1 мне выбрать?
  - 240p против 360p — сборки 240p работают с классическими темами 320×240 Rockbox; В сборках 360p используются более четкие темы 480×360 Y1. Сопоставьте разрешение сборки с темами, которые вы хотите использовать ([Руководство по 240p и 360p](rockbox-y1/resolution.html)).
  - Type A против Type B — Type A предназначено для Y1 плееров, поставляемых с заводским программным обеспечением версии 2.0.0 или новее; Type B — для более ранних единиц Y1. Выберите Type A, если вы не уверены, что ваш Y1 равен Type B.
  - Стабильный против ночного — Выберите стабильную сборку для повседневного прослушивания или ночную сборку, чтобы протестировать новейшие изменения.

## Прямые загрузки от разработчиков сообщества.

Innioasis Программа обновлений CE всегда загружает пакеты прошивок непосредственно от разработчиков прошивок сообщества ([rockbox-y1/rockbox](firmware_ru.html?model=Y1&software=rockbox-y1)), и сами разработчики несут полную ответственность за размещение выпусков своего программного обеспечения в Updater CE.

Вы можете разрешить Updater CE загружать и устанавливать прошивку автоматически или загрузить пакеты ROM с нашего сайта. [Rockbox-Y1 страница загрузок](rockbox-y1/download.html) и [Rockbox ROM страница загрузки](rockbox-rom-download_ru.html).[Rockbox-Y1 скачиваний](rockbox-y1/download.html)[Установить из локального ZIP-архива](rockbox-y1/portable-zip.html)

## Как установить Rockbox-Y1
  - Откройте Innioasis Updater CE и установите Модель устройства в адрес Y1.
  - Выбирать Rockbox в Программное обеспечение.
  - Выберите стабильную версию (или включите ночные сборки, чтобы протестировать предварительную версию).
  - Нажмите Установить / Восстановить поэтому Updater CE загружает пакет непосредственно от разработчика.
  - Полностью выключите Y1 и подключите его с помощью кабеля для передачи данных USB, когда вам будет предложено Updater CE.
  - Дождитесь сообщения о завершении, затем отключите и включите плеер.

Скриншоты и подробные советы по настройке см. [полное Rockbox-Y1 руководство](guides/rockbox-y1.html).

## Восстановление исходного программного обеспечения Y1

Вернуться к заводскому ПО можно в любой момент: выберите Y1 и Заводское ПО в Updater CE выберите стабильную версию и нажмите Установить / Восстановить. Ваша музыка на карте MicroSD сохранится. См. [руководство по восстановлению](rockbox-y1/restore-stock.html) и [Y1 Страница оригинального программного обеспечения](original-software-y1_ru.html).

## Часто задаваемые вопросыЯвляется ли Rockbox для Y1 тем же, что и Rockbox-Y1?

Да. Rockbox, Rockbox-Y1, Rockbox для Y1 и `rockbox-y1` все они относятся к одному и тому же порту сообщества Rockbox для Innioasis Y1.Откуда Updater CE загружает Rockbox-Y1?

Программа обновлений CE всегда загружает пакеты встроенного ПО непосредственно из собственных выпусков разработчиков встроенного ПО сообщества (`rockbox-y1/rockbox`). Разработчики несут единоличную ответственность за размещение выпусков своего программного обеспечения в Updater CE.Могу ли я установить Rockbox-Y1 на Y2?

Нет. У Y2 есть отдельная сборка прошивки. Использовать [Rockbox для Y2](rockbox-for-y2_ru.html) вместо.Удалит ли установка Rockbox-Y1 мою музыку?

Нет. Музыка хранится на карте MicroSD и не затрагивается при перепрошивке внутренней прошивки плеера.
