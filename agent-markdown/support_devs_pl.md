# Kontynuuj to, co dobre.

Aktualizator CE jest bezpłatny. Tworzą go ludzie, którzy chcą, aby Innioasis i Timmkoo gracze pozostali użyteczni. Twoje wsparcie opłaca archiwum, serwery i czas.
