# Install Android 4.4 (Dev) on the Y2.

Android 4.4 is a community development ROM for testing and hacking on Innioasis Y2 hardware. This page links to the full tutorial and release list.[Open the full Android 4.4 (Dev) guide](guides/android-4-4-y2.html)[Ontvang dit in Updater CE](guide_nl.html?model=Y2&software=android-4-4-y2)[Projectbron](https://github.com/y1-community/y2-ata-rom)

## Android 4.4 Y2 install steps
  - Open Innioasis Updater CE op uw computer (als u de app nodig heeft, [Updater CE downloaden](guide_nl.html#platform)). Instellen Apparaatmodel aan Y2.
  - Kies Android 4.4 (ontwikkelaar) binnen Software.
  - Choose the release listed for Y2.
  - Klik Installeren / Herstellen.
  - Schakel de Y2 alleen uit en sluit hem aan als Updater CE daarom vraagt.
