## 什么是 Innioasis 更新程序 CE？

Innioasis Updater 行政长官 is an open-source tool that simplifies updating and restoring your player across Windows, macOS, and Linux.

Flashing through Updater CE preserves your music library, video collection, and Bluetooth pairings while guiding each step on screen.[Compare flashing tools](updater-comparison_zh-CN.html)[浏览软件](firmware_zh-CN.html)

## Getting started with Rockbox

### 在 Y1 上安装 Rockbox

Select Y1, choose Rockbox stable, and connect only when prompted.[Y1 instructions](guides/rockbox-y1.html)[为什么是Rockbox？](rockbox-benefits_zh-CN.html)

### 在 Y2 上安装 Rockbox

Select Y2 in the tool. The Y2 route uses hardware-specific binaries.[Y2 instructions](guides/rockbox-y2.html)[为什么是Rockbox？](rockbox-benefits_zh-CN.html)

### Restore factory software

Returning to factory software uses the same flow: select your model and choose Original Software.[Y1 factory restore](guides/restore-original-y1.html)[Y2 factory restore](guides/restore-original-y2.html)

Compatible with Windows, macOS, and Linux.
