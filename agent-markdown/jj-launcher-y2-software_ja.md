  - コンピューターで Innioasis Updater CE を開きます (アプリが必要な場合は、 [Updater CE を入手](guide_ja.html#platform)）。セット デバイスモデル 支援先: Y2.
  - 確認する JJ Launcher 現在のリリース データの Y2 には が表示されます。
  - プロジェクトのリリース ノートを読み、リストされている Y2 リリースを選択します。
  - クリック インストール / 復元.

Y2 ビルドがリストされていますが、サポートされる内容は変更される可能性があります。インストールする前に、最新のリストとプロジェクトのメモを確認してください。Y2 を復元するにはどうすればよいですか?

Y2を選択し、Updater CEでオリジナルソフトウェアを選択し、次の手順に従います。 [Y2 の復元ステップ](original-software-y2_ja.html).JJ Launcher がリストされていない場合はどうなりますか?
