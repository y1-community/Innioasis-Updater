## Telepítési lépések
  - Indítsa el Innioasis Frissítő CE Windows, Mac vagy Linux számítógépén.
  - Válassza ki Y1 az Eszközmodell legördülő menüből.
  - Válassza ki Rondo a Szoftver legördülő menüből.
  - Kattintson Telepítés / visszaállítás és várja meg, amíg az eszköz letölti és előkészíti a fájlokat.
  - Amikor az Updater CE kéri, kapcsolja ki a Y1 készüléket, és csatlakoztassa az USB kábelt.
  - Telepítés utáni beállítás befejezése
