# Instale Inniclassic en Y1.

Inniclassic es un proyecto de software comunitario para Y1, y el mismo proyecto también publica una compilación Y2, por lo que está disponible en ambos reproductores. Esta página le brinda la respuesta fácil de buscar Y1 y enlaces a los pasos de conexión detallados.[Abra la guía completa Inniclassic](guides/inniclassic-y1.html)[Obtener en Updater CE](guide_es.html?model=Y1&software=inniclassic-y1)[¿Por qué Inniclassic?](inniclassic-benefits_es.html)

Guía de instalación para su computadora

## Instala Inniclassic en tu Y1 con tu computadora

Elija la guía para la computadora que está utilizando. Cada versión tiene la configuración de la plataforma, Updater CE pasos y el camino de regreso al stock.[guía de windows](install/inniclassic-y1-windows.html)[guía de macos](install/inniclassic-y1-mac.html)[guía de linux](install/inniclassic-y1-linux.html)

## Inniclassic Y1 pasos de instalación
  - Abra Innioasis Updater CE en su computadora (si necesita la aplicación, [Obtener Updater CE](guide_es.html#platform)). conjunto Modelo del dispositivo a Y1.
  - elegir Inniclassic en Software.
  - Elija la versión listada para Y1.
  - Haga clic Instalar / Restaurar.
  - Apague y conecte el Y1 solo cuando Updater CE lo solicite.

## Preguntas frecuentes¿Puedo restaurar el software Y1 original?

Sí. Seleccione Y1 y Software original en Updater CE. el [Guía de software de stock Y1](original-software-y1_es.html) cubre el camino de regreso.¿Qué pasa si la instalación falla?

Tenga en cuenta si el Actualizador falló antes o después de detectar Y1, luego verifique el cable, la configuración de la plataforma, el modelo y el tiempo de conexión en [solución de problemas](troubleshooting_es.html).¿Puedo usar Inniclassic en Y2?

Sí. Inniclassic está disponible en ambos modelos: el mismo proyecto mantenido publica un paquete Y2 de las mismas versiones. Seleccione Y2 en Updater CE e instale la compilación Y2; nunca actualice un paquete Y1 a un Y2. El [Página de instalación de Y2](inniclassic-y2-software_es.html) lo cubre.
