## Kurulum Adımları
  - Öğle yemeği Innioasis Güncelleyici CE Windows, Mac veya Linux bilgisayarınızda.
  - Seçme Y1 Cihaz Modeli açılır menüsünden.
  - Seçme Rondo Yazılım açılır menüsünden.
  - Tıklamak Yükle / Geri yükle ve aracın dosyaları indirip hazırlamasını bekleyin.
  - Güncelleyici CE tarafından istendiğinde, Y1 cihazınızı kapatın ve USB kablosunu bağlayın.
  - Kurulum sonrası kurulumu tamamlayın
