# Sammenlign firmware og softwareindstillinger

Opdag den bedste software til dine lydvaner, fra officiel original software fra fabrikken til fællesskabsskabelser som Rockbox, Solar, Better-Y og Reborn (Y2Linux).[Gennemse softwaredownloads](firmware_da.html)[Hjælp mig med at vælge](firmware-faq_da.html)[Få Updater CE](guide_da.html#platform)

## Software oversigtFabriksfirmware

### Original software

Fuld understøttelse af Bluetooth-lyd, FM-radio, lydbøger og brugerdefinerede skins fra temagalleriet. [Lær mere →](original-software-benefits_da.html)Audiofil standard

### Rockbox

Parametrisk EQ, mellemrumsfri afspilning, krydsfeed og omfattende tematilpasning. [Lær mere →](rockbox-benefits_da.html)Udvidet fabrik

### Better-Y

Fællesskabsforbedringer oven på original software med brugerdefinerede støvler, patchede apps og temaunderstøttelse. [Lær mere →](better-y-benefits_da.html)Moderne brugergrænseflade

### Solar

Ren moderne grænseflade med rig kunstnerkunst og brugerdefinerede animationer. [Lær mere →](solar-benefits_da.html)Native Linux

### Reborn (Y2Linux)

Debian-baseret styresystem designet til Y2 klikhjulet, der fikser Bluetooth-frafald. [Lær mere →](reborn-y2linux-benefits_da.html)Hastighed & fokus

### Rondo

Letvægts dedikeret klikhjulslydfirmware til Y1. [Lær mere →](rondo-benefits_da.html)
