# Y1 に Inniclassic をインストールします。

Inniclassic は Y1 のコミュニティ ソフトウェア プロジェクトであり、同じプロジェクトは Y2 ビルドも公開しているため、両方のプレーヤーで利用できます。このページには、Y1 の検索しやすい答えと、詳細な接続手順へのリンクが表示されます。[Inniclassic ガイド全体を開く](guides/inniclassic-y1.html)[Updater CE で入手](guide_ja.html?model=Y1&software=inniclassic-y1)[なぜInniclassic?](inniclassic-benefits_ja.html)

お使いのコンピューターのインストールガイド

## コンピュータを使用して Y1 に Inniclassic をインストールします

使用しているコンピュータのガイドを選択してください。 すべてのバージョンには、プラットフォームのセットアップ、Updater CE の手順、および在庫に戻る方法が含まれています。[Windowsガイド](install/inniclassic-y1-windows.html)[macOS ガイド](install/inniclassic-y1-mac.html)[Linuxガイド](install/inniclassic-y1-linux.html)

[すべての Innioasis Y1 ガイド](install/y1.html) · [すべての Inniclassic ガイド](install/inniclassic.html)

## Inniclassic Y1 のインストール手順
  - コンピューターで Innioasis Updater CE を開きます (アプリが必要な場合は、 [Updater CE を入手](guide_ja.html#platform)）。セット デバイスモデル 支援先: Y1.
  - 選択してください Inniclassic で ソフトウェア.
  - Y1 にリストされているリリースを選択します。
  - クリック インストール / 復元.
  - Updater CE が要求した場合にのみ、電源をオフにして Y1 を接続してください。

## よくある質問在庫の Y1 ソフトウェアを復元できますか?

はい。 Updater CEでY1とオリジナルソフトウェアを選択します。の [Y1 ストック ソフトウェア ガイド](original-software-y1_ja.html) 復路をカバーします。インストールに失敗した場合はどうなりますか?

Y1 を検出する前または後にアップデーターが失敗したかに注意し、ケーブル、プラットフォームのセットアップ、モデル、および接続のタイミングを確認してください。 [トラブルシューティング](troubleshooting_ja.html).Y2 で Inniclassic を使用できますか?

はい。 Inniclassic は両方のモデルで使用できます。同じ管理プロジェクトが同じリリースから Y2 パッケージを公開します。 Updater CE で Y2 を選択し、Y2 ビルドをインストールします。 Y1 パッケージを Y2 にフラッシュしないでください。の [Y2 インストールページ](inniclassic-y2-software_ja.html) それをカバーします。
