# Перед установкой проверьте JJ Launcher на Y2.

Существует сборка JJ Launcher для Y2, хотя то, что включено, может меняться в зависимости от выпуска. ## Проверка правильности модели
  - Откройте Innioasis Updater CE на своем компьютере (если вам нужно приложение, [Скачать Updater CE](guide_ru.html#platform)). Набор Модель устройства в адрес Y2.
  - Подтверждать JJ Launcher появляется для Y2 в текущих данных выпуска.
  - Прочтите примечания к выпуску проекта и выберите указанный выпуск Y2.
  - Нажмите Установить / Восстановить.
  - Выключите питание и подсоедините Y2 только при появлении соответствующего запроса.
Не заменяйте: пакет Y1 не является пакетом Y2. Остановитесь, если модель и версия не совпадают.
