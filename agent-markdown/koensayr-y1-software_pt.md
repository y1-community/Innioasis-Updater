## Instale Koensayr em seu Y1 com seu computador

Escolha o guia para o computador que você está usando. Cada versão possui a configuração da plataforma, Updater CE etapas e o caminho de volta ao estoque.[Guia do Windows](install/koensayr-y1-windows.html)[guia macOS](install/koensayr-y1-mac.html)[Guia Linux](install/koensayr-y1-linux.html)

[Todos Innioasis Y1 guias](install/y1.html) · [Todos Koensayr guias](install/koensayr.html)

## Koensayr Y1 etapas de instalação
  - Abra Innioasis Updater CE no seu computador (se precisar do aplicativo, [Obtenha o atualizador CE](guide_pt.html#platform)). Definir Modelo do dispositivo para Y1.
  - Escolher Koensayr em Programas.
  - Escolha a versão Y1 listada.
  - Clique Instalar / Restaurar.
  - Desligue e conecte o Y1 somente quando Updater CE solicitar.

## Perguntas frequentesPosso restaurar o software original Y1?

Sim. Selecione Y1 e Software Original em Updater CE. Veja o [Y1 página de software de estoque](original-software-y1_pt.html) para a rota de restauração completa.O que devo verificar quando falhar?

Verifique o modelo, a versão, o cabo, a configuração da plataforma e se o player estava conectado antes do aviso. Então use [solução de problemas](troubleshooting_pt.html).Existe um pacote Koensayr Y2?

A compilação atual é para Y1. Não use-o em Y2, a menos que o projeto publique uma versão separada para ele.

## Comece com a configuração do computador

O atualizador funciona em Windows, macOS e Linux depois que a configuração da plataforma estiver pronta. Leia o [guia geral](guide_pt.html#platform) primeiro.
