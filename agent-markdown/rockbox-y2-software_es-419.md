## Rockbox Y2 pasos de instalación
  - Abra Innioasis Updater CE en su computadora (si necesita la aplicación, [Obtener Updater CE](guide_es-419.html#platform)). conjunto Modelo del dispositivo a Y2.
  - elegir Rockbox en Software.
  - Elija una versión listada explícitamente para Y2.
  - Haga clic Instalar / Restaurar y espere la preparación del paquete.
  - Apague y conecte el Y2 solo cuando Updater CE lo solicite.

No fuerce un paquete Y1 porque el nombre del proyecto tiene el mismo aspecto. Si no aparece ninguna versión Y2, deténgase y verifique el modelo y los datos de la versión actual.
