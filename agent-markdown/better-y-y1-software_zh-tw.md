# 在 Y1 上安裝 Better-Y。

Better-Y 為 Innioasis Y1 提供增強的庫存體驗，包括標籤分割、專輯曲目編號、「正在播放」快捷方式和更流暢的 RAM 緩存，同時保持 100% 的主題相容性。[開啟完整的 Better-Y 指南](guides/better-y-y1.html)[在 Updater CE 中取得此內容](guide_zh-TW.html?model=Y1&software=better-y-y1)[為什麼是Better-Y？](better-y-benefits_zh-TW.html)

## Better-Y Y1 安裝步驟
  - 在您的電腦上開啟 Innioasis Updater CE（如果您需要該應用程序， [取得 Updater CE](guide_zh-TW.html#platform)）。套裝 裝置型號 到 Y1.
  - 選擇 Better-Y 在 軟體.
  - 選擇為 Y1 列出的版本。
  - 點選 安裝 / 還原.
  - 僅當 Updater CE 詢問時關閉電源並連接 Y1。

## 常見問題與原廠韌體相比有何改進？

Better-Y 新增曲目編號、分割多藝術家標籤、使用真實標題、新增播放捷徑以及快取和藍牙修復。和以前一樣的主題。我可以恢復原廠Y1軟體嗎？

是的。在Updater CE中選擇Y1和原始軟體。的 [Y1庫存軟體指南](original-software-y1_zh-TW.html) 覆蓋返迴路徑。我可以使用現有的主題嗎？

是的！ Better-Y 基於官方庫存 3.1.2 構建，並與主題庫中的所有自訂主題保持 100% 兼容性。如果安裝失敗怎麼辦？

請注意更新程式在偵測到 Y1 之前或之後是否失敗，然後檢查線纜、平台設定、型號和連接時序 [故障排除](troubleshooting_zh-TW.html).
