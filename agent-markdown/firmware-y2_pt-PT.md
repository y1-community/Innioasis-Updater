# Firmware para Innioasis Y2

O Y2 possui melhor hardware de áudio, Bluetooth e um gerenciador de arquivos. Escolha um sistema personalizado, uma versão Linux ou o software oficial para restaurar.[Navegar por Y2 downloads](firmware_pt-PT.html?model=Y2)[Obtenha o atualizador CE](guide_pt-PT.html#platform)[Y2 Guia de temas](https://themes.innioasis.app/y2-themes.html?lang=pt-PT)

## Sistemas operacionais disponíveis para Innioasis Y2

Escolha o que você deseja executar em seu Y2:

### [Reborn (Y2Linux)](reborn-y2linux-benefits_pt-PT.html)

SO Linux incorporado nativo combinando Buildroot, LVGL, PipeWire e MPD. Oferece tempos de inicialização de 3 segundos, correções reais de reconexão de fones de ouvido Bluetooth e reprodução contínua.[Y2Reborn Guia →](guides/reborn-y2linux-y2.html)

### [Rockbox para Y2](rockbox-benefits_pt-PT.html)

O firmware audiófilo definitivo portado para o Innioasis Y2. Equalização paramétrica, fontes personalizadas, crossfeed e amplo suporte à biblioteca de plugins.[Y2 Rockbox Guia →](guides/rockbox-y2.html)

### [Solar para Y2](solar-benefits_pt-PT.html)

Interface de reprodutor de música moderna e fluida baseada em Flutter para Y2. Apresenta visualizadores avançados, grande apresentação de capas de álbuns e navegação por gestos.[Solar Y2 Guia →](guides/solar-y2.html)

### [Y2Player](y2player-benefits_pt-PT.html)

Reprodutor de áudio comunitário leve feito para hardware Y2 com navegação simples em pastas e verificação rápida de índices.[Y2Player Guia →](guides/y2player-y2.html)

### [Software original (restauração de fábrica)](original-software-benefits_pt-PT.html)

Imagem oficial de firmware de estoque (rom_y2.zip) para restaurar um Innioasis Y2 à condição original de fábrica, completa com suporte para skin da Galeria de Temas.[Restaurar Y2 Guia →](guides/restore-original-y2.html)

## Instalando firmware em seu Innioasis Y2

Updater CE pega os arquivos corretos e verifica o driver antes de atualizar:
  - Lançamento Innioasis Updater CE: Disponível nativamente em macOS, Linux e Windows.
  - Definir modelo: Selecione Y2 no menu Modelo do dispositivo.
  - Escolha o sistema operacional: Escolha Reborn, Rockbox, Solar ou Software Original.
  - Flash com segurança: Siga as instruções na tela para conectar seu dispositivo em USB para obter um flash limpo e verificado.
