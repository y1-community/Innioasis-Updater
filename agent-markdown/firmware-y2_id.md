# Firmware untuk Innioasis Y2

Y2 memiliki perangkat keras audio, Bluetooth, dan pengelola file yang lebih baik. Pilih sistem khusus, versi Linux, atau perangkat lunak resmi yang akan dipulihkan.[Telusuri Y2 Unduhan](firmware_id.html?model=Y2)[Dapatkan Updater CE](guide_id.html#platform)[Y2 Panduan Tema](https://themes.innioasis.app/y2-themes.html?lang=id)

## Sistem Operasi yang Tersedia untuk Innioasis Y2

Pilih apa yang ingin Anda jalankan di Y2:

### [Reborn (Y2Linux)](reborn-y2linux-benefits_id.html)

OS Linux tertanam asli yang menggabungkan Buildroot, LVGL, PipeWire, dan MPD. Menawarkan waktu booting 3 detik, perbaikan koneksi ulang headphone Bluetooth yang sebenarnya, dan pemutaran tanpa celah.[Y2Reborn Panduan →](guides/reborn-y2linux-y2.html)

### [Rockbox untuk Y2](rockbox-benefits_id.html)

Firmware audiophile terbaik di-porting ke Innioasis Y2. Pemerataan parametrik, font khusus, crossfeed, dan dukungan perpustakaan plugin yang luas.[Y2 Rockbox Panduan →](guides/rockbox-y2.html)

### [Solar untuk Y2](solar-benefits_id.html)

Antarmuka pemutar musik berbasis Flutter yang modern dan lancar untuk Y2. Menampilkan visualisator yang kaya, presentasi seni album besar, dan navigasi gerakan.[Solar Y2 Panduan →](guides/solar-y2.html)

### [Y2Player](y2player-benefits_id.html)

Pemutar audio komunitas ringan yang dibuat untuk perangkat keras Y2 dengan penjelajahan folder sederhana dan pemindaian indeks cepat.[Y2Player Panduan →](guides/y2player-y2.html)

### [Perangkat Lunak Asli (Pemulihan Pabrik)](original-software-benefits_id.html)

Gambar firmware stok resmi (rom_y2.zip) untuk memulihkan Innioasis Y2 ke kondisi asli pabrik, lengkap dengan dukungan skin Galeri Tema.[Kembalikan Y2 Panduan →](guides/restore-original-y2.html)

## Menginstal Firmware pada Innioasis Y2 Anda

Updater CE mengambil file yang tepat dan memeriksa driver sebelum melakukan flashing:
  - Luncurkan Innioasis Pembaruan CE: Tersedia secara asli di macOS, Linux, dan Windows.
  - Tetapkan Model: Pilih Y2 di menu Model Perangkat.
  - Pilih Sistem Operasi: Pilih Reborn, Rockbox, Solar, atau Perangkat Lunak Asli.
  - Berkedip dengan Aman: Ikuti petunjuk di layar untuk menghubungkan perangkat Anda melalui USB untuk mendapatkan flash yang bersih dan terverifikasi.
