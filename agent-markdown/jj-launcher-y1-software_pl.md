## JJ Launcher Y1 install steps
  - Otwórz Innioasis Updater CE na swoim komputerze (jeśli potrzebujesz aplikacji, [Pobierz Updater CE](guide_pl.html#platform)). Zestaw Model urządzenia do Y1.
  - Wybierz JJ Launcher w Oprogramowanie.
  - Choose the release shown for Y1.
  - Kliknij Zainstaluj / Przywróć.
  - Wyłącz i podłącz Y1 tylko wtedy, gdy Updater CE zapyta.

## Najczęstsze pytaniaCan I install the Y2 entry on a Y1?

No. Keep the model and package matched. If the Y1 entry is missing, do not force a Y2 file.Can I go back to the original software?

Yes. Choose Y1 and Original Software in Updater CE. See the [Y1 restore page](original-software-y1_pl.html).Where are all the JJ Launcher releases?
