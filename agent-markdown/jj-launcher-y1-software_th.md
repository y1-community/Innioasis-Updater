JJ Launcher · Innioasis Y1

# ติดตั้ง JJ Launcher บน Innioasis Y1 ของคุณ

หน้านี้ครอบคลุมรายการ Y1 เลือกรุ่นก่อนตัวเรียกใช้งาน เพื่อให้ Updater เสนอแพ็คเกจที่ไม่ถูกต้อง[เปิดคำแนะนำ JJ Launcher ฉบับเต็ม](guides/jj-launcher-y1.html)[รับสิ่งนี้ใน Updater CE](guide_th.html?model=Y1&software=jj-launcher-y1)[ทำไมต้อง JJ Launcher?](jj-launcher-benefits_th.html)

คู่มือการติดตั้งสำหรับคอมพิวเตอร์ของคุณ

## ติดตั้ง JJ Launcher บน Y1 ด้วยคอมพิวเตอร์ของคุณ

เลือกคำแนะนำสำหรับคอมพิวเตอร์ที่คุณใช้ ทุกรุ่นมีการตั้งค่าแพลตฟอร์ม ขั้นตอน Updater CE และวิธีคืนสินค้าในสต็อก[คู่มือวินโดวส์](install/jj-launcher-y1-windows.html)[คู่มือ macOS](install/jj-launcher-y1-mac.html)[คู่มือลินุกซ์](install/jj-launcher-y1-linux.html)

[คำแนะนำ Innioasis Y1 ทั้งหมด](install/y1.html) · [คำแนะนำ JJ Launcher ทั้งหมด](install/jj-launcher.html)

## JJ Launcher Y1 ขั้นตอนการติดตั้ง
  - เปิด Innioasis Updater CE บนคอมพิวเตอร์ของคุณ (หากคุณต้องการแอป [รับ Updater CE](guide_th.html#platform)). ชุด รุ่นอุปกรณ์ ถึง Y1.
  - เลือก JJ Launcher ใน ซอฟต์แวร์.
  - เลือกรุ่นที่แสดงสำหรับ Y1
  - คลิก ติดตั้ง / คืนค่า.
  - ปิดเครื่องและเชื่อมต่อ Y1 เมื่อ Updater CE ถามเท่านั้น

## คำถามที่พบบ่อยฉันสามารถติดตั้งรายการ Y2 บน Y1 ได้หรือไม่

ไม่ได้ รักษารุ่นและแพ็คเกจให้ตรงกัน หากรายการ Y1 หายไป อย่าบังคับให้มีไฟล์ Y2ฉันสามารถกลับไปใช้ซอฟต์แวร์ดั้งเดิมได้หรือไม่

ใช่. เลือก Y1 และซอฟต์แวร์ต้นฉบับใน Updater CE ดู [Y1 กู้คืนหน้า](original-software-y1_th.html).JJ Launcher รุ่นทั้งหมดอยู่ที่ไหน

บิลด์ปัจจุบันเข้าแล้ว [ดาวน์โหลดซอฟต์แวร์](firmware_th.html#y1). บันทึกประจำรุ่นอยู่ในโครงการ [บันทึกประจำรุ่น](release_notes_th.html?software=jj-launcher-y1).

## การตั้งค่าคอมพิวเตอร์

สามารถใช้ Updater บน Windows, macOS และ Linux ได้เมื่อการตั้งค่าที่เกี่ยวข้องพร้อมแล้ว เริ่มกันที่ [คู่มือแพลตฟอร์ม](guide_th.html#platform).
