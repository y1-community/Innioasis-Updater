# Why Rockbox for your Innioasis

Rockbox turns your player into a proper music library. Gapless playback, an equalizer, and a deep theme library. ## Why people pick it

The library becomes the point.
  - Stop scrolling by filename — Rockbox reads the tags on your music and sorts by album, artist, and genre the way a real library should. Big collections stop feeling like a folder dump.
  - Gapless, crossfade, EQ — Songs flow into each other without the gap, and a full equalizer lets you tune the sound without leaving the player.
  - A theme for every taste — From clean minimal looks to iPod-style interfaces, the theme library is enormous — and the Y1 community builds use 360p compatibility labels to help you pick.
  - Dual boot with stock — Reboot back to the original software any time from the Rockbox menu. It is an experiment with a door left open.
  - Podcasts and scrobbling — This fork adds podcast downloads over the built-in Wi-Fi and Last.fm / ListenBrainz / Maloja scrobbling, so your listening history stays yours.
  - Offline by design — Rockbox runs on local files. No account, no subscription, no streaming dependency — the reason many community members say it helped them quit the subscription treadmill.

## What the project offers
  - Tag-based database: albums and artists sorted by tags, not file names
  - Gapless playback, crossfade, and a built-in equalizer
  - Deep theme library including iPod-style interfaces; Y1 builds carry 360p compatibility labels
  - iPod 6G-style controls with a restart shortcut (hold Next + Previous for 10 seconds)
  - FM radio app inside Rockbox
  - Podcast download plugin using the built-in Wi-Fi chip
  - Scrobbling to Last.fm, ListenBrainz, or Maloja
  - Dual boot: reboot to stock from Main Menu → System, and back by holding Menu/Back + Play/Pause
  - Separate Y1 and Y2 builds — the Y2 package is its own ROM and must not be swapped in

## Things to know first
  - This is an experimental build — the project itself warns it is not associated with Innioasis and that flashing carries a brick risk if rushed
  - Always choose the release listed for your exact model (Y1 or Y2)
  - Older theme collections may be made for 240p; check the resolution and release notes before choosing a build
  - You can restore Original Software afterwards with the matching Y1 or Y2 stock package
