# Install Linux on the Y1.

Linux for Y1 is an experimental community Linux kernel and rootfs port for the Innioasis Y1 hardware. This page links to the full installation guide and releases.[Open the full Linux for Y1 (Dev) guide](guides/linux-y1.html)[এটি Updater CE এ পান](guide_bn.html?model=Y1&software=linux-y1)[প্রকল্পের উৎস](https://github.com/y1-community/y1-linux-rom)

## Install Linux for Y1 (Dev) on your Y1 with your computer

আপনি যে কম্পিউটারটি ব্যবহার করছেন তার জন্য গাইডটি বেছে নিন। প্রতিটি সংস্করণে প্ল্যাটফর্ম সেটআপ, Updater CE পদক্ষেপ এবং স্টকে ফিরে যাওয়ার উপায় রয়েছে।[উইন্ডোজ গাইড](install/linux-y1-windows.html)[macOS গাইড](install/linux-y1-mac.html)[লিনাক্স গাইড](install/linux-y1-linux.html)

[সমস্ত Innioasis Y1 গাইড](install/y1.html) · [All Linux for Y1 (Dev) guides](install/linux-dev.html)

## Linux Y1 install steps
  - আপনার কম্পিউটারে Innioasis Updater CE খুলুন (যদি আপনার অ্যাপটির প্রয়োজন হয়, [Updater CE নিন](guide_bn.html#platform)) সেট ডিভাইস মডেল থেকে Y1.
  - বেছে নিন Y1 (Dev) এর জন্য Linux মধ্যে সফটওয়্যার.
  - Y1-এর জন্য তালিকাভুক্ত রিলিজ বেছে নিন।
  - ক্লিক করুন ইনস্টল / পুনরুদ্ধার.
  - পাওয়ার বন্ধ করুন এবং শুধুমাত্র Updater CE বললেই Y1 সংযোগ করুন।

## সাধারণ প্রশ্নআমি কি স্টক Y1 সফ্টওয়্যার পুনরুদ্ধার করতে পারি?

হ্যাঁ। Updater CE-এ Y1 এবং অরিজিনাল সফটওয়্যার নির্বাচন করুন। দ [Y1 স্টক-সফ্টওয়্যার গাইড](original-software-y1_bn.html) ফেরার পথ কভার করে।Is this an everyday user interface?

This is an experimental port for developers and Linux tinkerers. Terminal and console instructions are in the project docs.
