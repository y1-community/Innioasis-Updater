## Innioasis Updater CE چیست؟

Innioasis به‌روزرسان CE is an open-source tool that simplifies updating and restoring your player across Windows, macOS, and Linux.

Flashing through Updater CE preserves your music library, video collection, and Bluetooth pairings while guiding each step on screen.[دریافت Updater CE](guide_fa.html#platform)[Compare flashing tools](updater-comparison_fa.html)[نرم افزار را مرور کنید](firmware_fa.html)

Every package is verified before publication. New builds appear as soon as they are tested.

## Getting started with Rockbox

### نصب Rockbox در Y1

Select Y1, choose Rockbox stable, and connect only when prompted.[Y1 instructions](guides/rockbox-y1.html)[چرا Rockbox؟](rockbox-benefits_fa.html)

### نصب Rockbox در Y2

Select Y2 in the tool. The Y2 route uses hardware-specific binaries.[Y2 instructions](guides/rockbox-y2.html)[چرا Rockbox؟](rockbox-benefits_fa.html)

### Restore factory software

Returning to factory software uses the same flow: select your model and choose Original Software.[Y1 factory restore](guides/restore-original-y1.html)[Y2 factory restore](guides/restore-original-y2.html)

Compatible with Windows, macOS, and Linux.
