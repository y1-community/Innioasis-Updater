# Install Android 4.4 (Dev) on the Y2.

Android 4.4 is a community development ROM for testing and hacking on Innioasis Y2 hardware. This page links to the full tutorial and release list.[Open the full Android 4.4 (Dev) guide](guides/android-4-4-y2.html)[Få dette i Updater CE](guide_da.html?model=Y2&software=android-4-4-y2)[Projektkilde](https://github.com/y1-community/y2-ata-rom)

## Install Android development ROM on your Y2 with your computer

Vælg vejledningen til den computer, du bruger. Hver version har platformsopsætningen, Updater CE trin og vejen tilbage til lageret.[Windows guide](install/android-4-4-y2-windows.html)[macOS guide](install/android-4-4-y2-mac.html)[Linux guide](install/android-4-4-y2-linux.html)

[Alle Innioasis Y2 guider](install/y2.html) · [Alle Android-udviklings-ROM-vejledninger](install/android-dev.html)

## Android 4.4 Y2 install steps
  - Åbn Innioasis Updater CE på din computer (hvis du har brug for appen, [Hent Updater CE](guide_da.html#platform)). Sæt Enhedsmodel til Y2.
  - Vælg Android 4.4 (Dev) ind Software.
  - Choose the release listed for Y2.
  - Klik Installer / Gendan.
  - Sluk og tilslut kun Y2, når Updater CE spørger.
