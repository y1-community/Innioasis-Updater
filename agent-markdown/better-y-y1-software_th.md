# Better-Y เฟิร์มแวร์สำหรับ Innioasis Y1 | ติดตั้งบทช่วยสอน - Innioasis ดาวน์โหลดเฟิร์มแวร์

Better-Y · Innioasis Y1

# ติดตั้ง Better-Y บน Y1

Better-Y มอบประสบการณ์สต็อกที่ได้รับการปรับปรุงสำหรับ Innioasis Y1 ด้วยการแยกแท็ก หมายเลขแทร็กอัลบั้ม ทางลัดกำลังเล่น และการแคช RAM ที่ราบรื่นยิ่งขึ้น ในขณะที่ยังคงความเข้ากันได้ของธีม 100%[เปิดคำแนะนำ Better-Y ฉบับเต็ม](guides/better-y-y1.html)[รับสิ่งนี้ใน Updater CE](guide_th.html?model=Y1&software=better-y-y1)[ทำไมต้อง Better-Y?](better-y-benefits_th.html)

คู่มือการติดตั้งสำหรับคอมพิวเตอร์ของคุณ

## ติดตั้ง Better-Y บน Y1 ด้วยคอมพิวเตอร์ของคุณ

เลือกคำแนะนำสำหรับคอมพิวเตอร์ที่คุณใช้ ทุกรุ่นมีการตั้งค่าแพลตฟอร์ม ขั้นตอน Updater CE และวิธีคืนสินค้าในสต็อก[คู่มือวินโดวส์](install/better-y-y1-windows.html)[คู่มือ macOS](install/better-y-y1-mac.html)[คู่มือลินุกซ์](install/better-y-y1-linux.html)

[คำแนะนำ Innioasis Y1 ทั้งหมด](install/y1.html) · [คำแนะนำ Better-Y ทั้งหมด](install/better-y.html)

## Better-Y Y1 ขั้นตอนการติดตั้ง
  - เปิด Innioasis Updater CE บนคอมพิวเตอร์ของคุณ (หากคุณต้องการแอป [รับ Updater CE](guide_th.html#platform)). ชุด รุ่นอุปกรณ์ ถึง Y1.
  - เลือก Better-Y ใน ซอฟต์แวร์.
  - เลือกรุ่นที่ระบุไว้สำหรับ Y1
  - คลิก ติดตั้ง / คืนค่า.
  - ปิดเครื่องและเชื่อมต่อ Y1 เมื่อ Updater CE ถามเท่านั้น

## คำถามที่พบบ่อยมีการปรับปรุงอะไรมากกว่าเฟิร์มแวร์หุ้น?

Better-Y เพิ่มหมายเลขแทร็ก แยกแท็กหลายศิลปิน ใช้ชื่อจริง และเพิ่มทางลัดในการเล่น รวมถึงแก้ไขแคชและบลูทูธ ธีมเดียวกันกับเมื่อก่อนฉันสามารถกู้คืนซอฟต์แวร์สต็อก Y1 ได้หรือไม่

ใช่. เลือก Y1 และซอฟต์แวร์ต้นฉบับใน Updater CE ที่ [คู่มือซอฟต์แวร์หุ้น Y1](original-software-y1_th.html) ครอบคลุมเส้นทางขากลับฉันสามารถใช้ธีมที่มีอยู่ได้หรือไม่?

ใช่! Better-Y สร้างขึ้นจากสต็อกอย่างเป็นทางการ 3.1.2 และรักษาความเข้ากันได้ 100% กับธีมที่กำหนดเองทั้งหมดจากแกลเลอรีธีมจะทำอย่างไรถ้าการติดตั้งล้มเหลว?

โปรดทราบว่าตัวอัปเดตล้มเหลวก่อนหรือหลังการตรวจจับ Y1 จากนั้นตรวจสอบสายเคเบิล การตั้งค่าแพลตฟอร์ม รุ่น และระยะเวลาการเชื่อมต่อใน [การแก้ไขปัญหา](troubleshooting_th.html).
