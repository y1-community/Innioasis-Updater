## Innioasis Y1 的可用操作系统

Y1 运行多个软件系统，包括具有发烧级编解码器支持的构建、现代启动器和工厂恢复。选择适合您聆听方式的一个：

### [Rockbox](rockbox-benefits_zh-CN.html)

开源音频播放的黄金标准。参数均衡器、无缝 FLAC/MP3 播放、主题和字体包可直接安装在 Updater CE 中。[Y1 Rockbox 指南 →](guides/rockbox-y1.html)

### [Better-Y](better-y-benefits_zh-CN.html)

原始固件的增强衍生版本，具有蓝牙稳定性补丁、音量曲线调整和 100% 主题库兼容性。[Better-Y 指南 →](guides/better-y-y1.html)

### [Solar](solar-benefits_zh-CN.html)

使用 Flutter 构建的当代开源音乐播放器，提供流畅的 60fps 动画、专辑封面网格和现代版式。[Solar Y1 指南 →](guides/solar-y1.html)

### [Rondo](rondo-benefits_zh-CN.html)

用于本地曲目和流媒体的开源 Y1 启动器，具有快速、响应式导航。[Rondo Y1 指南 →](guides/rondo-y1.html)

### [Koensayr](koensayr-benefits.html)

自定义固件构建具有自己的图标、更好的电池校准和库存主题支持。[Koensayr 指南 →](guides/koensayr-y1.html)

### [原始软件（库存恢复）](original-software-benefits_zh-CN.html)

清理 Type A (v2.0.0+) 和 Type B (v1.x) Y1 播放器的出厂固件映像。安全地解锁设备或将设备恢复至出厂状态。[恢复 Y1 指南 →](guides/restore-original-y1.html)

## 如何安装或更新 Y1 固件

使用我们的多平台软件套件，升级或取消变砖您的 Innioasis Y1 非常简单：
  - 打开 Innioasis 更新程序 CE： 在 macOS、Windows 或 Linux 上启动更新程序。
  - 选择型号 Y1： 选择 Y1 在设备型号下拉列表中。
  - 选择您的操作系统： 选择Rockbox、Better-Y、Solar或原始软件。
  - 点击安装： 更新程序CE直接从开发人员的版本下载固件包。出现提示时，通过 USB 连接已关闭电源的 Y1 以开始闪烁。
