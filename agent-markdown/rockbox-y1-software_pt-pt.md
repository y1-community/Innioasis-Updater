## Rockbox Y1 etapas de instalação
  - Abra Innioasis Updater CE no seu computador (se precisar do aplicativo, [Obtenha o atualizador CE](guide_pt-PT.html#platform)). Definir Modelo do dispositivo para Y1.
  - Escolher Rockbox em Programas.
  - Escolha o lançamento e a variante que correspondem à tela ou ao caminho do tema pretendido.
  - Clique Instalar / Restaurar e espere o aplicativo prepará-lo.
  - Desligue e conecte o Y1 somente no prompt ao vivo.

Use o [guia escrito Rockbox Y1](guides/rockbox-y1.html) para capturas de tela, vídeo, nota Type A ou Type B e lista de verificação de conexão.

## Perguntas frequentesPosso voltar ao software original Y1?

Sim. Escolha Y1 e Software Original em Updater CE e execute Instalar/Restaurar. O [Y1 página de software de estoque](original-software-y1_pt-PT.html) explica esse caminho.Qual Rockbox versão devo escolher?

Escolha um lançamento mostrado para Y1 e leia sua nota de lançamento. Se você precisar de compatibilidade de temas mais antigos, verifique as notas de resolução e variantes em vez de selecionar uma compilação Y2.Posso instalar isso em um Y2?

Não. Use o separado [Rockbox Y2 página](rockbox-y2-software_pt-PT.html) e selecione Y2 em Updater CE.
