# Compare Firmwares & Software Options

From official factory Original Software to community creations like Rockbox, Solar, Better-Y, and Reborn (Y2Linux), discover the best software for your audio habits.[Browse Software Downloads](firmware.html)[Help me choose](firmware-faq.html)[Get Updater CE](guide.html#platform)

## Software OverviewFactory Firmware

### Original Software

Full support for Bluetooth audio, FM radio, audiobooks, and custom skins from the Themes Gallery. [Learn more →](original-software-benefits.html)Audiophile Standard

### Rockbox

Parametric EQ, gapless playback, crossfeed, and extensive theme customization. [Learn more →](rockbox-benefits.html)Enhanced Factory

### Better-Y

Community enhancements on top of Original Software with custom boots, patched apps, and theme support. [Learn more →](better-y-benefits.html)Modern UI

### Solar

Clean modern interface with rich artist artwork and custom animations. [Learn more →](solar-benefits.html)Native Linux

### Reborn (Y2Linux)

Debian-based operating system designed for the Y2 clickwheel, fixing Bluetooth dropouts. [Learn more →](reborn-y2linux-benefits.html)Speed & Focus

### Rondo

Lightweight dedicated clickwheel audio firmware for the Y1. [Learn more →](rondo-benefits.html)
