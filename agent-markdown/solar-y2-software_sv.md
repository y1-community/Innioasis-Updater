# Kontrollera rutten Solar Y2 innan du installerar.

Det finns en Solar build listad för Y2, men supporten kan ändras. Kontrollera de senaste utgåvorna på projektsidan innan den blinkar.[Öppna hela Solar guiden](guides/solar-y2.html)[Hämta detta i Updater CE](guide_sv.html?model=Y2&software=solar-y2)[Varför Solar?](solar-benefits_sv.html)

## Modellkorrekta Y2 kontroller
  - Öppna Innioasis Updater CE på din dator (om du behöver appen, [Hämta Updater CE](guide_sv.html#platform)). Ställ in Enhetsmodell till Y2.
  - Bekräfta det Solar är listad för Y2 i aktuella utgivningsdata.
  - Läs projektets releasenot och kontrollera dess Y2-stöd.
  - Välj den listade versionen och klicka Installera / Återställ.
  - Stäng av och anslut Y2 endast när Updater CE frågar.
Byt inte ut ett Y1-paket. Ett projekt som är tillgängligt för Y1 gör inte dess Y1-paket säkert för Y2.
