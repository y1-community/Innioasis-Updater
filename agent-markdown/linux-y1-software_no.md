# Install Linux on the Y1.

Linux for Y1 is an experimental community Linux kernel and rootfs port for the Innioasis Y1 hardware. This page links to the full installation guide and releases.[Open the full Linux for Y1 (Dev) guide](guides/linux-y1.html)[Få dette i Updater CE](guide_no.html?model=Y1&software=linux-y1)[Prosjektkilde](https://github.com/y1-community/y1-linux-rom)

## Install Linux for Y1 (Dev) on your Y1 with your computer

Velg veiledningen for datamaskinen du bruker. Hver versjon har plattformoppsettet, Updater CE trinn og veien tilbake til lageret.[Windows guide](install/linux-y1-windows.html)[macOS-veiledning](install/linux-y1-mac.html)[Linux guide](install/linux-y1-linux.html)

## Linux Y1 install steps
  - Åpne Innioasis Updater CE på datamaskinen din (hvis du trenger appen, [Få Updater CE](guide_no.html#platform)). Sett Enhetsmodell til Y1.
  - Velg Linux for Y1 (Dev) inn Programvare.
  - Velg utgivelsen som er oppført for Y1.
  - Klikk Installer / Gjenopprett.
  - Slå av og koble til Y1 bare når Updater CE spør.
