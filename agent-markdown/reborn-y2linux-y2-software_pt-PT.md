# Reborn (Y2Linux) para Innioasis Y2

Uma distribuição Debian Linux rápida e desenvolvida especificamente com uma interface de usuário clickwheel nativa para Innioasis Y2, apresentando estabilidade de fone de ouvido Bluetooth e desenvolvimento ativo da comunidade.[Guia passo a passo Y2](guides/reborn-y2linux-y2.html)[Por que Y2Reborn?](reborn-y2linux-benefits_pt-PT.html)[Baixar lançamentos](firmware_pt-PT.html?model=Y2&software=reborn-y2linux-y2)

## Instale Reborn (Y2Linux) em seu Y2 com seu computador

Escolha o guia para o computador que você está usando. Cada versão possui a configuração da plataforma, Updater CE etapas e o caminho de volta ao estoque.[Guia do Windows](install/reborn-y2linux-y2-windows.html)[guia macOS](install/reborn-y2linux-y2-mac.html)[Guia Linux](install/reborn-y2linux-y2-linux.html)

[Todos Innioasis Y2 guias](install/y2.html) · [Todos os guias Reborn (Y2Linux)](install/reborn.html)

## Etapas de instalação
  - Abra Updater CE. Disponível para Windows, macOS e Linux.
  - Selecione Y2 como o modelo do dispositivo.
  - Selecione Reborn (Y2Linux) como o software.
  - Clique em Instalar/Restaurar. Aguarde enquanto Updater CE prepara os arquivos.
  - Conecte USB quando solicitado. Desligue o Y2 primeiro.
  - Configurar Wi-Fi, Bluetooth e rádio FM

Copiar `system.img` para o jogador uma vez. Reborn faz o resto.[Concluir a configuração →](y2reborn_wifibt_pt-PT.html)
