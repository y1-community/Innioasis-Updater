# Rockbox-Y2 temi

Come installare i temi su Rockbox-Y2, verificare la compatibilità del tema con la build installata e reimpostare un tema se non viene visualizzato correttamente.[Rockbox-Y2 note sulla versione](release-notes/rockbox-y2/index.html)[Sfoglia i temi della community](https://themes.innioasis.app/)[Installa Rockbox-Y2](rockbox-y2/install.html)

## Verifica la compatibilità del tema per la tua build

Rockbox-Y2 è sviluppato separatamente dal port Y1, quindi la compatibilità del tema segue la versione build Y2 installata. Controlla il [Rockbox-Y2 note sulla versione](release-notes/rockbox-y2/index.html) per la tua versione prima di installare un pacchetto di temi.

Vedere [Rockbox-Y1 contro Rockbox-Y2](rockbox-y1-vs-y2_it.html) per un confronto completo tra i due porti.

## Come installare i temi su Y2

I temi sono memorizzati sulla tua scheda MicroSD all'interno della sezione nascosta `.rockbox` cartella.
  - Avvia Rockbox-Y2 almeno una volta in modo da creare il file `.rockbox` cartella sulla tua carta MicroSD.
  - Estrai o copia i file del tema in `.rockbox/` (COSÌ `themes`, `wps`, `fonts`, e `backdrops` fondersi in `.rockbox/`).
  - Sul lettore, apri Impostazioni → Impostazioni tema → Sfoglia file tema e seleziona il tuo tema.

Per visualizzare le cartelle nascoste sul computer: premere Cmd+Shift+. su macOS, abilita Visualizza → Oggetti nascosti su Windows oppure premere Ctrl+H su Linux.

## Come resettare un tema rotto

Se un tema rende difficile la lettura dello schermo, rinomina o elimina il file `.rockbox` cartella sulla scheda MicroSD e riavviare il lettore. Rockbox-Y2 creerà un file fresh `.rockbox` cartella con il tema predefinito mantenendo intatta la tua musica.[La cartella .rockbox](rockbox-y2/sd-card.html)[Aggiornamento Rockbox-Y2](rockbox-y2/update.html)[Rockbox-Y2 crea note](rockbox-y2/resolution.html)
