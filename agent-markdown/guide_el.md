# Ξεκινώντας με το Innioasis Updater CE

Λειτουργεί με όλες τις συσκευές αναπαραγωγής ήχου Innioasis και Timmkoo. Εγκαταστήστε το Innioasis Updater CE στον υπολογιστή σας, επιλέξτε το μοντέλο σας και το λογισμικό που θέλετε και, στη συνέχεια, ακολουθήστε τις οδηγίες.

## 

[Αποκτήστε το Updater CE](guide_el.html#download-updater)[Πλήρες γραπτό σεμινάριο](guide_el.html)

## Αποκτήστε το Innioasis Updater CE

Innioasis Ενημερωτής CE είναι η εφαρμογή που εγκαθιστά επίσημες ενημερώσεις και λογισμικό κοινότητας στη συσκευή σας. Διατηρεί τη μουσική και τις ρυθμίσεις σας και εκτελείται σε Windows, macOS και Linux.

### Windows

Κατεβάστε το πρόγραμμα εγκατάστασης, εκτελέστε το και επανεκκινήστε τον υπολογιστή σας όταν τελειώσει.[Λάβετε προγράμματα οδήγησης](https://github.com/y1-community/supplemental-apks/releases/latest/download/DriverInstall.exe)[Κατεβάστε το Updater CE](https://github.com/y1-community/Innioasis-Updater/releases/latest/download/installer.exe)

Εάν τα Windows σας εμποδίσουν να εκτελέσετε την εφαρμογή ή δεν την εκκινήσουν, ανοίξτε τις Ρυθμίσεις, κάντε κλικ στην επιλογή Απόρρητο και ασφάλεια → Ασφάλεια των Windows → Έλεγχος εφαρμογών και προγράμματος περιήγησης και απενεργοποιήστε τον Έλεγχο Smart App. Ο Έξυπνος Έλεγχος εφαρμογών επηρεάζει επί του παρόντος δημοφιλείς εφαρμογές όπως η υπηρεσία Epic Overlay Service (που χρησιμοποιείται από το Fortnite) — Το Updater CE είναι ασφαλές και επαληθευμένο για χρήση. [Τα Windows δεν θα εκκινήσουν την εφαρμογή; Βοήθεια](#smart-app-control)

Κάντε επανεκκίνηση του υπολογιστή σας μετά την εγκατάσταση. Η βοήθεια του οδηγού βρίσκεται στο [Σημειώσεις εγκατάστασης των Windows](drivers_el.html#windows).

### macOS[Κατεβάστε το Updater CE](https://github.com/y1-community/Innioasis-Updater/releases/latest/download/Innioasis.Updater.for.Mac.dmg)

Εάν το Mac σας εμποδίσει να εκτελέσετε την εφαρμογή για πρώτη φορά, ανοίξτε τις Ρυθμίσεις συστήματος, κάντε κλικ στην επιλογή Απόρρητο και ασφάλεια, κάντε κύλιση προς τα κάτω στην επιλογή Ασφάλεια και κάντε κλικ [Ανοίξτε πάντως](https://support.apple.com/en-gb/102445#openanyway). Μπορείτε επίσης να κάνετε Control-κλικ (ή δεξί κλικ) στην εφαρμογή στο Finder και να επιλέξετε Άνοιγμα.

Λειτουργεί σε υπολογιστές Intel και Apple Silicon Mac με macOS Monterey και νεότερες εκδόσεις.

### Linux

Κατεβάστε το AppImage για συστήματα Intel και AMD, κάντε το εκτελέσιμο και εκτελέστε το.[Κατεβάστε το AppImage για Intel/AMD](https://github.com/y1-community/innioasis-updater/releases/latest/download/UpdaterCE.AppImage)

[Σημειώσεις εγκατάστασης Linux](drivers_el.html#linux)Άλλη πλατφόρμα;

Χρειάζεστε τη συσκευή αναπαραγωγής σας, ένα καλώδιο δεδομένων USB που μεταφέρει δεδομένα (δεν μπορεί να εγκατασταθεί ένα καλώδιο μόνο με φόρτιση) και μερικά λεπτά. Διατηρήστε το καλώδιο συνδεδεμένο έως ότου το Updater CE πει ότι έχει ολοκληρωθεί.

## Επιλέξτε το μοντέλο και το λογισμικό σας
  - Μοντέλο συσκευής: επιλέξτε το μοντέλο που είναι τυπωμένο στη συσκευή αναπαραγωγής, Y1 ή Y2. Το λογισμικό που έχει κατασκευαστεί για ένα μοντέλο δεν μπορεί να εγκατασταθεί στο άλλο.
  - Λογισμικό και έκδοση: επιλέξτε Πρωτότυπο λογισμικό, Rockbox, Solar, JJ Launcher, Inniclassic, Y2Player ή Koensayr όταν αναφέρεται για το μοντέλο σας και, στη συνέχεια, επιλέξτε μια έκδοση. Το σταθερό είναι η ασφαλής επιλογή.
  - Εγκατάσταση: κλικ Εγκατάσταση / Επαναφορά, απενεργοποιήστε πλήρως τη συσκευή αναπαραγωγής και συνδέστε το καλώδιο USB μόνο όταν σας ζητήσει το Updater CE.
  - Τερματισμός: αφήστε τη συσκευή αναπαραγωγής και το καλώδιο μόνο μέχρι το μήνυμα επιτυχίας και, στη συνέχεια, αποσυνδέστε και ξεκινήστε τη συσκευή αναπαραγωγής.

Y1 παίκτες που απεστάλησαν με το πρωτότυπο λογισμικό πριν από την ανάγκη έκδοσης 2.0.0 Συσκευή Type B. Όλοι οι άλλοι διατηρούν την προεπιλογή Type A.Οδηγίες σύνδεσης προγράμματος ενημέρωσης για τη σύνδεση μιας συσκευής αναπαραγωγής που είναι απενεργοποιημένηΑκολουθήστε τη ζωντανή προτροπή του Updater CE για το μοντέλο σας.

## Επιστρέφοντας στο Αρχικό Λογισμικό

Το προσαρμοσμένο λογισμικό είναι αναστρέψιμο. Στο Updater CE, επιλέξτε το μοντέλο σας, επιλέξτε Πρωτότυπο λογισμικό, επιλέξτε μια σταθερή απελευθέρωση και μετά τρέξτε Εγκατάσταση / Επαναφορά με τον ίδιο τρόπο. Δεν υπάρχει τίποτα να διαγράψετε με το χέρι.[Y1 οδηγός επαναφοράς](guides/restore-original-y1.html)[Y2 οδηγός επαναφοράς](guides/restore-original-y2.html)

Εάν ένα φλας σταματήσει πριν από την προτροπή USB, ελέγξτε πρώτα το καλώδιο, τη ρύθμιση της πλατφόρμας και το μοντέλο. Βλ [αντιμετώπιση προβλημάτων](troubleshooting_el.html) για διορθώσεις, το [Y1 και Y2 οδηγός ανάκτησης](guides/recovery.html) για σφάλματα ισχύος και τροχών και [SP Flash Tool](sp-flash-tool_el.html) για προχωρημένη αποκατάσταση.

## Τα Windows δεν θα εκκινήσουν την εφαρμογή; Λύση Έξυπνης εφαρμογής Έλεγχος

Το Windows Defender SmartScreen ή το Smart App Control μπορεί να αποκλείσει τις εφαρμογές κοινότητας που λήφθηκαν πρόσφατα πριν από τη διάδοση της φήμης της υπογραφής. Ο Έξυπνος Έλεγχος εφαρμογών επηρεάζει επί του παρόντος δημοφιλείς εφαρμογές όπως η υπηρεσία Epic Overlay (που χρησιμοποιείται από το Fortnite) — Το Updater CE είναι ασφαλές και επαληθευμένο για χρήση. Η απενεργοποίηση του Smart App Control επιτρέπει στο Updater CE να ανοίγει και να λειτουργεί κανονικά.
  - Ανοίξτε Ρυθμίσεις στον υπολογιστή σας με Windows (πατήστε Win + I).
  - Κάντε κλικ Απόρρητο και ασφάλεια στην αριστερή πλαϊνή γραμμή και, στη συνέχεια, κάντε κλικ Windows Security.
  - Κάντε κλικ Έλεγχος εφαρμογών και προγράμματος περιήγησης.
  - Κάτω Έξυπνος έλεγχος εφαρμογών, κάντε κλικ Ρυθμίσεις Smart App Control.
  - Ρυθμίστε την εναλλαγή σε Απενεργοποίηση για να επιτρέψετε την εκκίνηση του Updater CE.

Έγινε λήψη μέσω Edge; Εάν ο Edge μπλοκάρει τη λήψη, κάντε κλικ στο κουμπί Περισσότερες επιλογές (…) → Κρατήστε → Εμφάνιση περισσότερων → Διατήρησε πάντως.

Εκ νέου ενεργοποίηση Smart App Control αργότερα: Όταν θέλετε να ενεργοποιήσετε ξανά τον Έλεγχο Smart App, μπορείτε να τον ενεργοποιήσετε ξανά μέσω του Μητρώου των Windows κάτω `HKEY_LOCAL_MACHINE\SYSTEM\CurrentControlSet\Control\CI\Policy` με ρύθμιση `VerifiedAndReputablePolicyState` να `1` (Ενεργό) ή `2` (Λειτουργία αξιολόγησης) και επανεκκίνηση.
