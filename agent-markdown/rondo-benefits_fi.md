# Miksi asentaa Rondo laitteeseesi Innioasis Y1?

Rondo on avoimen lähdekoodin tarkoitukseen rakennettu napsautuspyörän musiikkisoittimen laiteohjelmisto, joka on suunniteltu erityisesti Innioasis Y1-laitteistolle. Se tarjoaa puhtaan kirjaston selailun, puhtaan typografian ja nopean äänen dekoodauksen.[Asenna Rondo Y1](guides/rondo-y1.html)[Selaa julkaisuja](firmware_fi.html?model=Y1&software=rondo-y1)

## Kohokohdat Rondo

### Nopea klikkauspyörän vaste

Huolellisesti viritetty kiihtyvyyskäyrä, joka on sovitettu Y1 fyysiseen kapasitiiviseen kosketuspyörään, mahdollistaa sujuvan selaamisen suurten musiikkikirjastojen läpi.

### Keskitetty äänisoitin

Ei bloatwarea, taustaanalytiikkaa tai tarpeettomia demoneja: 100 % laitteistoresursseista on omistettu terävälle äänentoistolle.

### Käännettävä milloin tahansa

Asenna helposti käyttämällä Innioasis Updater CE:tä ja palaa alkuperäiseen ohjelmistoon tai Rockbox:iin milloin tahansa.
