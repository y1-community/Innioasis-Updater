# Instale Inniclassic en Y2.

Inniclassic está disponible para Innioasis Y2, y el mismo proyecto también construye los paquetes Y1. Esta página le brinda la descripción general de Y2 y enlaces al tutorial completo.[Abra la guía completa Inniclassic](guides/inniclassic-y2.html)[Obtener en Updater CE](guide_es-419.html?model=Y2&software=inniclassic-y2)[¿Por qué Inniclassic?](inniclassic-benefits_es-419.html)

Guía de instalación para su computadora

## Instala Inniclassic en tu Y2 con tu computadora

Elija la guía para la computadora que está utilizando. Cada versión tiene la configuración de la plataforma, Updater CE pasos y el camino de regreso al stock.[guía de windows](install/inniclassic-y2-windows.html)[guía de macos](install/inniclassic-y2-mac.html)[guía de linux](install/inniclassic-y2-linux.html)

[Todas las Innioasis Y2 guías](install/y2.html) · [Todas las Inniclassic guías](install/inniclassic.html)

## Inniclassic Y2 pasos de instalación
  - Abra Innioasis Updater CE en su computadora (si necesita la aplicación, [Obtener Updater CE](guide_es-419.html#platform)). conjunto Modelo del dispositivo a Y2.
  - elegir Inniclassic en Software.
  - Elija la versión listada para Y2.
  - Haga clic Instalar / Restaurar.
  - Apague y conecte el Y2 solo cuando Updater CE lo solicite.

## Preguntas frecuentes¿Puedo restaurar el software original Y2?

Sí. Seleccione Y2 y Software original en Updater CE. El [Y2 guía de software de stock](original-software-y2_es-419.html) cubre el camino de regreso.¿Puedo usar Inniclassic en Y1?

Sí. El mismo proyecto también publica Y1 paquetes: rom.zip para Type A y rom_type_b.zip para Type B. Seleccione Y1 en Updater CE e instale la compilación Y1; el [Página de instalación de Y1](inniclassic-y1-software_es-419.html) lo cubre.¿Qué pasa si la instalación falla?

Tenga en cuenta si el Actualizador falló antes o después de detectar Y2, luego verifique el cable, la configuración de la plataforma, el modelo y el tiempo de conexión en [solución de problemas](troubleshooting_es-419.html).
