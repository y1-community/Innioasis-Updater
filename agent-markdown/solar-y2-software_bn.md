## Model-correct Y2 checks
  - আপনার কম্পিউটারে Innioasis Updater CE খুলুন (যদি আপনার অ্যাপটির প্রয়োজন হয়, [Updater CE নিন](guide_bn.html#platform)) সেট ডিভাইস মডেল থেকে Y2.
  - Confirm that Solar is listed for Y2 in the current release data.
  - Read the project release note and check its Y2 support.
  - Choose the listed release and click ইনস্টল / পুনরুদ্ধার.
  - পাওয়ার বন্ধ করুন এবং শুধুমাত্র Updater CE বললেই Y2 কানেক্ট করুন।
Do not substitute a Y1 package. A project being available for Y1 does not make its Y1 package safe for Y2.
