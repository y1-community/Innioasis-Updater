Koensayr указан как опция программного обеспечения сообщества Y1. Используйте поток средства обновления с учетом модели вместо поиска пакета по имени файла.[Открыть полное руководство Koensayr](guides/koensayr-y1.html)[Получите это в Updater CE](guide_ru.html?model=Y1&software=koensayr-y1)[Почему Koensayr?](koensayr-benefits_ru.html)

## Koensayr Y1 шаги установки
  - Откройте Innioasis Updater CE на своем компьютере (если вам нужно приложение, [Скачать Updater CE](guide_ru.html#platform)). Набор Модель устройства в адрес Y1.
  - Выбирать Koensayr в Программное обеспечение.
  - Выберите указанный выпуск Y1.
  - Нажмите Установить / Восстановить.
  - Выключите питание и подсоедините Y1 только тогда, когда появится запрос Updater CE.

## Вопросы и ответыМогу ли я восстановить исходное программное обеспечение Y1?

Да. Выберите Y1 и оригинальное программное обеспечение в Updater CE. См. [Y1 страница стандартного программного обеспечения](original-software-y1_ru.html) для полного маршрута восстановления.Что мне следует проверить в случае сбоя?

Проверьте модель, версию, кабель, настройку платформы и был ли плеер подключен до появления запроса. Затем используйте [Поиск неисправностей](troubleshooting_ru.html).Есть ли пакет Koensayr Y2?

Текущая сборка предназначена для Y1. Не используйте его в Y2, если только проект не опубликует для него отдельный выпуск.
