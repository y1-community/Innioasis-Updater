# Reborn (Y2Linux) pro Innioasis Y2

Rychlá, účelově vytvořená distribuce Debian Linux s nativním uživatelským rozhraním clickwheel pro Innioasis Y2, vyznačující se stabilitou Bluetooth sluchátek a aktivním rozvojem komunity.[Průvodce krok za krokem Y2](guides/reborn-y2linux-y2.html)[Proč Y2Reborn?](reborn-y2linux-benefits_cs.html)[Vydání ke stažení](firmware_cs.html?model=Y2&software=reborn-y2linux-y2)

Průvodce instalací pro váš počítač

## Nainstalujte Reborn (Y2Linux) do svého Y2 pomocí počítače

Vyberte průvodce pro počítač, který používáte. Každá verze má nastavení platformy, Updater CE kroky a cestu zpět na sklad.[Průvodce Windows](install/reborn-y2linux-y2-windows.html)[průvodce macOS](install/reborn-y2linux-y2-mac.html)[Linux průvodce](install/reborn-y2linux-y2-linux.html)

[Všechna Innioasis vodítka Y2](install/y2.html) · [Všechny Reborn (Y2Linux) vodítka](install/reborn.html)

## Kroky instalace
  - Otevřete Updater CE. K dispozici pro Windows, MacOS a Linux.
  - Vyberte Y2 jako model zařízení.
  - Vyberte Reborn (Y2Linux) jako software.
  - Klikněte na Instalovat / Obnovit. Počkejte, než Updater CE připraví soubory.
  - Až budete požádáni, připojte USB. Nejprve vypněte Y2.
  - Nastavte Wi-Fi, Bluetooth a FM rádio

Kopírovat `system.img` do přehrávače jednou. Reborn udělá zbytek.[Dokončete nastavení →](y2reborn_wifibt_cs.html)
