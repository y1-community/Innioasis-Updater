# Οδηγίες μετά την εγκατάσταση

Τα βήματα που σας ζητά να ολοκληρώσετε το έργο μετά την εγκατάσταση του υλικολογισμικού.

[Λήψεις υλικολογισμικού →](firmware_el.html)[Οδηγός εγκατάστασης](guide_el.html)

## Οδηγίες μετά την εγκατάσταση από το υλικολογισμικό

Αυτοί είναι οι σύνδεσμοι του Updater CE των οδηγών μετά την εγκατάσταση για κάθε υλικολογισμικό. Επιλέξτε το υλικολογισμικό σας για να ανοίξετε τα βήματα εγκατάστασης.
