## JJ Launcher Y1 install steps
  - Otevřete Innioasis Updater CE na svém počítači (pokud potřebujete aplikaci, [Získat Updater CE](guide_cs.html#platform)). Soubor Model zařízení do Y1.
  - Vyberte si JJ Launcher v Software.
  - Choose the release shown for Y1.
  - Klikněte Nainstalovat / Obnovit.
  - Vypněte a připojte Y1 pouze tehdy, když se zeptá Updater CE.

## Časté dotazyCan I install the Y2 entry on a Y1?

No. Keep the model and package matched. If the Y1 entry is missing, do not force a Y2 file.Can I go back to the original software?

Yes. Choose Y1 and Original Software in Updater CE. See the [Y1 restore page](original-software-y1_cs.html).Where are all the JJ Launcher releases?
