# Install Linux on the Y1.

Linux for Y1 is an experimental community Linux kernel and rootfs port for the Innioasis Y1 hardware. ## Linux Y1 install steps
  - Buka Innioasis Updater CE pada komputer anda (jika anda memerlukan apl itu, [Dapatkan Updater CE](guide_ms.html#platform)). Tetapkan Model Peranti kepada Y1.
  - pilih Linux untuk Y1 (Dev) dalam Perisian.
  - Pilih keluaran yang disenaraikan untuk Y1.
  - klik Pasang / Pulihkan.
  - Matikan dan sambungkan Y1 hanya apabila Updater CE bertanya.
