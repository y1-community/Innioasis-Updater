# Innioasis Y1에 Better-Y을 사용하는 이유 | Better-Y 혜택 - Innioasis 펌웨어 다운로드

맞춤형 소프트웨어 · Better-Y

# Innioasis Y1이(가) Better-Y인 이유

Better-Y은 더 나은 스톡 플레이어입니다. 공식 3.1.2 소프트웨어에서 Leska1337에 의해 구축되었습니다. 태그, 트랙 번호, 캐싱 및 재생 제어 기능을 수정하고 친숙한 모양, 휠 및 테마를 유지합니다.[업데이터에서 Better-Y 가져오기](firmware_ko.html?model=Y1&software=better-y-y1)[Y1 설치 페이지](better-y-y1-software_ko.html)[전체 Y1 튜토리얼](guides/better-y-y1.html)[프로젝트 소스](https://github.com/Leska1337/better-Y)

## 모델 가용성

어떤 Innioasis 모델이 이를 실행합니까?[Y1 (Type A) · 사용 가능](better-y-y1-software_ko.html)Y2 · 사용할 수 없음

Better-Y은 Innioasis Y1 (Type A 하드웨어)에 대해 만들어졌습니다. Y1 및 Y2 빌드는 별개이므로 서로 교체하지 마십시오.

## 사람들이 그것을 선택하는 이유

주식에 관해 당신이 좋아하는 모든 것, 단점은 하나도 없습니다.
  - 자신이 속한 트랙 번호 — 앨범 보기에는 마침내 트랙 번호가 표시되므로 임의 정렬이 아닌 원하는 트랙 목록 순서로 앨범이 재생되고 표시됩니다.
  - 지능형 태그 분할 — 여러 아티스트의 노래(쉼표 또는 세미콜론으로 구분)가 각 개별 아티스트 아래에 표시됩니다. 다중 장르 태그(쉼표, 세미콜론 또는 슬래시로 구분)는 일치하는 모든 장르 아래에 표시됩니다.
  - 파일 이름에 대한 ID3 메타데이터 — 원시 파일 이름을 표시하는 대신 노래 제목, 앨범 및 아티스트를 ID3 태그에서 올바르게 읽습니다.
  - 이제 대화형 컨트롤을 재생 중입니다. — 즐겨찾기(하트), 임의 재생 토글, 반복 모드(한 번/모두/꺼짐), 가사, A-B 반복 루프, 재생 대기열, 북마크 위치, 속도 제어 및 절전 타이머에 대한 직접 화면 아이콘.
  - 부드럽고 깜박임 없는 RAM 캐싱 — 완전히 재작업된 이미지 캐싱 엔진은 대규모 음악 라이브러리를 스크롤할 때 UI 깜박임, 깜박임 및 지연을 제거합니다.
  - 공식 3.1.2 재단 — 최신 3.1.2 기반으로 구축되어 공식 Apple AirPods 연결 수정 사항을 유지하는 동시에 모든 맞춤형 스톡 테마와 100% 호환성을 유지합니다.

## 커뮤니티 및 릴리스

커뮤니티에서 말하는 내용

Better-Y은 개발자 Leska1337이 r/innioasis 하위 레딧에서 논의된 정확한 일일 사용성 문제를 해결하기 위해 만들어졌습니다. Better-Y은 시스템을 다른 OS로 교체하는 대신 사용자가 이미 알고 좋아하는 기본 플레이어 경험을 완벽하게 구현합니다.

사람들은 친숙한 느낌을 좋아합니다. 테마 갤러리의 기존 테마가 계속 작동하고 재생 목록과 Bluetooth가 주식처럼 작동하며 탐색이 눈에 띄게 빨라졌습니다.
  - [r/innioasis · Better-Y v1.0.0 릴리스 토론](https://www.reddit.com/r/innioasis/comments/1w6wt7i/bettery_v100_release_stock_launcher_but_better/)
  - [Leska1337/better-Y 소스](https://github.com/Leska1337/better-Y)

## 프로젝트가 제공하는 것
  - 앨범 트랙 목록에 직접 표시되는 트랙 번호
  - 쉼표(,) 및 세미콜론(;)으로 다중 아티스트 태그 분할
  - 쉼표(,), 세미콜론(;) 및 슬래시(/)로 다중 장르 태그 분할
  - 편집물, 찬사 및 기능에 대한 전체 앨범 아티스트 태그 지원
  - 외부 표지 아트 지원(자동 감지 `cover.jpg`, `cover.png`, `folder.jpg`)
  - 다중 디스크 릴리스에 대한 디스크 번호 표시(CD 1, CD 2, 비닐 면)
  - 대화형 지금 재생 아이콘(즐겨찾기, 임의 재생, 반복, 가사, A-B 루프, 대기열, 북마크, 속도, 절전 타이머)
  - 자동 자르기/채우기 및 기울기 수정/전환 기능을 갖춘 더 큰 앨범 아트웍 프리젠테이션
  - 긴 트랙 제목과 아티스트 이름에 대한 부드러운 윤곽 텍스트 자동 스크롤
  - 가사 줄 오버플로 및 텍스트 잘림 버그 수정
  - 대규모 라이브러리에서 신속한 휠 탐색을 위한 알파벳순 빠른 스크롤 인덱스 막대
  - 선택 커서는 현재 재생 중인 트랙을 자동으로 기억하고 따라갑니다.
  - 아티스트 보기는 모든 노래를 단순 목록에 버리는 대신 앨범을 먼저 표시합니다.
  - 폴더 보기에 "모든 노래 표시" 및 "셔플" 버튼 추가
  - 기본 탐색 바로가기는 다음으로 바로 이동합니다. `/Music/` 그리고 `/Videos/`
  - 재생/일시 중지 하드웨어 버튼을 두 번 누르면 모든 화면에서 지금 재생 중으로 바로 이동합니다.
  - 출시 연도별로 앨범을 정렬합니다. 추가된 날짜별로 재생목록 정렬
  - 목록 깜박임을 제거하는 고속 RAM 이미지 캐싱 엔진
  - 즉각적인 "라이브러리 업데이트" 옵션을 갖춘 신속한 라이브러리 스캐너
  - 폴더의 마지막 노래가 삭제되면 빈 상위 디렉토리 자동 정리
  - 보다 쉬운 검색을 위한 Caps Lock 및 케이스 스위치가 포함된 3레이아웃 온스크린 키보드
  - 가사 및 읽기 표시 중 깨우기 설정 표시
  - 하드웨어 긴급 재부팅 단축키(상단 버튼과 하단 버튼을 동시에 누르기)

## 먼저 알아야 할 사항
  - Innioasis Y1 (Type A 하드웨어)용으로 특별히 제작됨 — Y2로 플래시하지 마십시오.
  - 모든 사용자 정의 테마 및 스톡 설정과의 완벽한 호환성을 유지합니다.
  - 업데이터 CE를 통해 Y1 원본 소프트웨어를 플래싱하여 언제든지 완전히 되돌릴 수 있습니다.
  - 플래시하기 전에 릴리스 노트를 확인하고 모델을 확인하세요.

## 시작하기

Updater CE에서 Y1을 선택하고 Better-Y을 선택한 다음 안정 릴리스를 선택하고 메시지가 나타나면 전원이 꺼진 플레이어를 연결하십시오. 단계별 가이드에서는 전체 프로세스를 다룹니다.[Better-Y 릴리스 찾아보기](firmware_ko.html?model=Y1&software=better-y-y1)[Y1 설치 개요](better-y-y1-software_ko.html)[전체 Y1 튜토리얼](guides/better-y-y1.html)
