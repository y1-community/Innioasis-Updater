# 比較韌體和軟體選項

從官方工廠原創軟體到社群創作，如 Rockbox、Solar、Better-Y 和 Reborn (Y2Linux)，發現最適合您音訊習慣的軟體。[瀏覽軟體下載](firmware_zh-TW.html)[幫我選擇](firmware-faq_zh-TW.html)[取得 Updater CE](guide_zh-TW.html#platform)

## 軟體概述工廠韌體

### 原廠軟體

完全支援藍牙音訊、調頻收音機、有聲書和主題庫中的自訂皮膚。 [了解更多→](original-software-benefits_zh-TW.html)發燒友標準

### Rockbox

參數均衡器、無縫播放、交叉饋送和廣泛的主題自訂。 [了解更多→](rockbox-benefits_zh-TW.html)強化工廠

### Better-Y

在原始軟體之上進行社群增強，包括自訂啟動、修補應用程式和主題支援。 [了解更多→](better-y-benefits_zh-TW.html)現代使用者介面

### Solar

乾淨的現代介面，具有豐富的藝術作品和自訂動畫。 [了解更多→](solar-benefits_zh-TW.html)原生Linux

### Reborn (Y2Linux)

基於 Debian 的作業系統，專為 Y2 點擊輪設計，修復了藍牙遺失問題。 [了解更多→](reborn-y2linux-benefits_zh-TW.html)速度和焦點

### Rondo

Y1 的輕量級專用滾輪音訊韌體。 [了解更多→](rondo-benefits_zh-TW.html)
