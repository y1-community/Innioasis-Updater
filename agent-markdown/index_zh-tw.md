## 什麼是 Innioasis 更新程式 CE？

Innioasis Updater 行政長官 is an open-source tool that simplifies updating and restoring your player across Windows, macOS, and Linux.

Flashing through Updater CE preserves your music library, video collection, and Bluetooth pairings while guiding each step on screen.[取得 Updater CE](guide_zh-TW.html#platform)[Compare flashing tools](updater-comparison_zh-TW.html)[瀏覽軟體](firmware_zh-TW.html)

## Getting started with Rockbox

### 在 Y1 上安裝 Rockbox

Select Y1, choose Rockbox stable, and connect only when prompted.[Y1 instructions](guides/rockbox-y1.html)[為什麼是Rockbox？](rockbox-benefits_zh-TW.html)

### 在 Y2 上安裝 Rockbox

Select Y2 in the tool. The Y2 route uses hardware-specific binaries.[Y2 instructions](guides/rockbox-y2.html)[為什麼是Rockbox？](rockbox-benefits_zh-TW.html)

### Restore factory software

Returning to factory software uses the same flow: select your model and choose Original Software.[Y1 factory restore](guides/restore-original-y1.html)[Y2 factory restore](guides/restore-original-y2.html)

Compatible with Windows, macOS, and Linux.
