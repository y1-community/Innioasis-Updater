## Instale su elección con Updater CE
  - Abra la guía e instale Innioasis Updater CE para su computadora si aún no lo tiene.
  - En Updater CE, seleccione el modelo impreso en su reproductor de Modelo del dispositivo.
  - De Software, seleccione el software que desea ejecutar en ese modelo.
  - Seleccione una versión, haga clic Instalar / Restaurar, luego apague y conecte el reproductor solo cuando Updater CE lo solicite.

¿Necesitas el instalador? [Abra la guía y expanda la sección de descarga de Updater CE](guide_es.html#download-updater).

## El camino seguro de vuelta

### Consulta el modelo

Y1 and Y2 software is not interchangeable. Re-select the model in Updater CE and start again.

### Espere el mensaje

Apague el reproductor por completo y conéctelo sólo cuando Updater CE indique que está listo.

### Restaurar software original

Elija software original para el mismo modelo. Si es necesaria la recuperación manual, abra el [guía de solución de problemas](troubleshooting_es.html) primero.

## Supported Devices and Official Stock Firmware

The Innioasis Firmware Archive hosts verified stock firmware, original factory restore images, and custom operating systems for portable players:

### Innioasis Y1 & Y2

Official software and custom systems including Rockbox, Better-Y, and Solar.

### Innioasis G1, G3 & G5

Software oficial y archivos de recuperación para reproductores con pantalla táctil.

### Innioasis R1 & PR1

Software original y archivos de recuperación para reproductores de audio.

### Timmkoo Q5 & Q3

Packages provided for Timmkoo players via Updater CE.

New releases appear here as soon as they are verified.

## ¿Qué herramienta debo utilizar?

Innioasis Actualizador CE is the recommended tool for daily updates and community OS installs across Windows, macOS, and Linux. Flashing through Updater CE preserves your library and pairings.

The legacy Universal Flash Tool remains available for emergency unbricking when a device cannot boot into fastboot.[Compare flashing tools](updater-comparison_es.html)
