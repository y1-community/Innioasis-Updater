# Better-Y прошивка для Innioasis Y1 | Руководство по установке — Innioasis Загрузка прошивки

Better-Y · Innioasis Y1

# Установите Better-Y на Y1.

Better-Y предоставляет расширенные возможности стандартного контента для Innioasis Y1 с разделением тегов, номерами дорожек альбома, ярлыками «Сейчас исполняется» и более плавным кэшированием в оперативной памяти, сохраняя при этом 100% совместимость с темами.[Открыть полное руководство Better-Y](guides/better-y-y1.html)[Получите это в Updater CE](guide_ru.html?model=Y1&software=better-y-y1)[Почему Better-Y?](better-y-benefits_ru.html)

Руководство по установке для вашего компьютера

## Установите Better-Y на свой Y1 с помощью компьютера.

Выберите руководство для компьютера, который вы используете. В каждой версии есть настройка платформы, Updater CE шагов и возврат к стоку.[Руководство по Windows](install/better-y-y1-windows.html)[руководство по macOS](install/better-y-y1-mac.html)[Руководство по Linux](install/better-y-y1-linux.html)

[Все Innioasis Y1 руководства](install/y1.html) · [Все Better-Y руководства](install/better-y.html)

## Better-Y Y1 шаги установки
  - Откройте Innioasis Updater CE на своем компьютере (если вам нужно приложение, [Скачать Updater CE](guide_ru.html#platform)). Набор Модель устройства в адрес Y1.
  - Выбирать Better-Y в Программное обеспечение.
  - Выберите выпуск, указанный для Y1.
  - Нажмите Установить / Восстановить.
  - Выключите питание и подсоедините Y1 только тогда, когда появится запрос Updater CE.

## Вопросы и ответыЧто улучшено по сравнению со стоковой прошивкой?

Better-Y добавляет номера треков, разделяет теги нескольких исполнителей, использует настоящие названия и добавляет ярлыки воспроизведения, а также исправления для кэширования и Bluetooth. Те же темы, что и раньше.Могу ли я восстановить стандартное программное обеспечение Y1?

Да. Выберите Y1 и оригинальное программное обеспечение в Updater CE. [Y1 руководство по стандартному программному обеспечению](original-software-y1_ru.html) перекрывает обратный путь.Могу ли я использовать существующие темы?

Да! Better-Y построен на официальной версии 3.1.2 и поддерживает 100% совместимость со всеми пользовательскими темами из галереи тем.Что делать, если установка не удалась?

Обратите внимание, произошел сбой программы обновления до или после обнаружения Y1, затем проверьте кабель, настройку платформы, модель и время подключения в [Поиск неисправностей](troubleshooting_ru.html).

## Используйте маршрут с гидом

Впервые пользуетесь программой обновлений? См. пошаговую настройку, чтобы [Скачать Updater CE](guide_ru.html#platform) в Windows, macOS или Linux перед подключением плеера.
