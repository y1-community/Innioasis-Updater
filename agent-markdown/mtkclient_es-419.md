# MTKClient y diagnóstico de desbloqueo

MTKClient es el motor de actualización subyacente de código abierto MediaTek utilizado por Innioasis Updater CE. Si un reproductor deja de responder o falla el flasheo estándar, utilice estos diagnósticos de recuperación.[Solución de problemas generales](troubleshooting_es-419.html)[Notas de configuración del controlador](drivers_es-419.html)

Empezar con Innioasis Updater

## Prueba la ruta guiada antes que la de bajo nivel.

El actualizador lo hace de una sola vez. Elija el software, siga los pasos que aparecen en pantalla y listo. También le indica cuándo llega una solución o una nueva versión.

## Comprender el modo BootROM (BROM)

Cuando está completamente apagado, el procesador MediaTek MT6572/MT6580 escucha en el bus USB un paquete de protocolo de enlace antes de cargar el gestor de arranque principal. Si se produce un flash dañado, el modo BROM permite una reescritura de recuperación completa.
