# Install Android 4.4 (Dev) on the Y2.

Android 4.4 is a community development ROM for testing and hacking on Innioasis Y2 hardware. This page links to the full tutorial and release list.[Open the full Android 4.4 (Dev) guide](guides/android-4-4-y2.html)[Obțineți asta în Updater CE](guide_ro.html?model=Y2&software=android-4-4-y2)[Sursa proiectului](https://github.com/y1-community/y2-ata-rom)

## Install Android development ROM on your Y2 with your computer

Alegeți ghidul pentru computerul pe care îl utilizați. Fiecare versiune are configurarea platformei, Updater CE pași și calea de întoarcere la stoc.[Ghidul Windows](install/android-4-4-y2-windows.html)[ghid macOS](install/android-4-4-y2-mac.html)[Ghid Linux](install/android-4-4-y2-linux.html)

[Toate ghidurile Innioasis Y2](install/y2.html) · [Toate ghidurile de dezvoltare Android ROM](install/android-dev.html)

## Android 4.4 Y2 install steps
  - Deschideți Innioasis Updater CE pe computer (dacă aveți nevoie de aplicație, [Obține Updater CE](guide_ro.html#platform)). Setați Model dispozitiv la Y2.
  - Alege Android 4.4 (dezvoltare) in Software.
  - Choose the release listed for Y2.
  - Faceți clic Instalează / Restaurează.
  - Opriți și conectați Y2 numai când Updater CE vă cere.
