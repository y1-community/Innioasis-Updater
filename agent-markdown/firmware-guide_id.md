## Dapatkan Innioasis Updater CE

Inilah tempat untuk memulai jika Anda belum mendapatkan Updater CE.Dapatkan di Updater CEdengan instalasi terpandu

### Windows

Unduh penginstal, buka, dan ikuti petunjuk pengaturan.[Unduh & Instal Driver](https://github.com/y1-community/supplemental-apks/releases/latest/download/DriverInstall.exe)[Unduh Aplikasi dan Driver](https://github.com/y1-community/Innioasis-Updater/releases/latest/download/installer.exe)[Diblokir oleh Edge?](#)

Jika Windows menghentikan Anda menjalankan aplikasi atau tidak dapat meluncurkannya, buka Pengaturan, klik Privasi & keamanan → Keamanan Windows → Kontrol aplikasi & browser, dan matikan Kontrol Aplikasi Cerdas. [Windows tidak meluncurkan aplikasi? Bantuan](#smart-app-control)

Anda harus me-reboot PC Anda setelah menginstal agar dapat berfungsi.

### macOS

Unduh aplikasi dan pindahkan ke Aplikasi. Jika macOS memblokirnya, buka Pengaturan Sistem, lalu Privasi & Keamanan, dan klik Tetap Buka. [Cara kerjanya](https://support.apple.com/en-gb/102445#openanyway)[Unduh Updater CE](https://github.com/y1-community/Innioasis-Updater/releases/latest/download/Innioasis.Updater.for.Mac.dmg)

### Linux

Unduh AppImage untuk sistem Intel dan AMD, buat agar dapat dieksekusi, dan jalankan.[Unduh AppImage untuk Intel/AMD](https://github.com/y1-community/innioasis-updater/releases/latest/download/UpdaterCE.AppImage)[Catatan pengaturan Linux](drivers_id.html#linux)Platform lain?

Butuh catatan pengaturan komputer yang lebih panjang? Buka [Windows](drivers_id.html#windows) atau [Linux](drivers_id.html#linux) panduan pengaturan.

## Alat mana yang harus saya gunakan?

Innioasis Updater Masehi adalah cara paling aman untuk memperbarui pemutar Anda. Itu menyimpan musik, video, dan pasangan Bluetooth Anda. Ini memberi tahu Anda kapan pembaruan sudah siap. Ini berjalan di Windows, macOS dan Linux. Innioasis Universal Flash Tool menghapus pemutar Anda dan berfungsi pada lebih sedikit komputer.[Buka perbandingan lengkapnya](updater-comparison_id.html)

### Windows tidak meluncurkan aplikasi? Cara mematikan Kontrol Aplikasi Cerdas

Windows Defender SmartScreen atau Smart App Control dapat memblokir aplikasi komunitas yang baru diunduh sebelum reputasi tanda tangan menyebar. Kontrol Aplikasi Cerdas saat ini memengaruhi aplikasi populer seperti Epic Overlay Service (digunakan oleh Fortnite) — Updater CE aman dan terverifikasi untuk digunakan. Mematikan Kontrol Aplikasi Cerdas memungkinkan Updater CE terbuka dan berjalan normal.
  - Buka Pengaturan di PC Windows Anda (tekan Win + I).
  - Klik Privasi & keamanan di sidebar kiri, lalu klik Windows Security.
  - Klik Kontrol aplikasi & browser.
  - Di bawah Kontrol Aplikasi Cerdas, klik Pengaturan Kontrol Aplikasi Cerdas.
  - Setel tombol ke Mati untuk mengizinkan Updater CE diluncurkan.

Diblokir oleh Edge? Jika Microsoft Edge memblokir pengunduhan itu sendiri, klik tombol Opsi lainnya (…) → Simpan → Tampilkan lebih banyak → Tetap pertahankan.

Mengaktifkan kembali Kontrol Aplikasi Cerdas nanti: Saat Anda ingin mengaktifkan kembali Smart App Control, Anda dapat mengaktifkannya kembali melalui Windows Registry di bawah `HKEY_LOCAL_MACHINE\SYSTEM\CurrentControlSet\Control\CI\Policy` dengan mengatur `VerifiedAndReputablePolicyState` untuk `1` (Aktif) atau `2` (Mode Evaluasi) dan memulai ulang.Tutup bantuan
