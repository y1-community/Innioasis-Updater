## Inniclassic Y2 кроки встановлення
  - Відкрийте Innioasis Updater CE на своєму комп’ютері (якщо вам потрібна програма, [Отримати Updater CE](guide_uk.html#platform)). встановити Модель пристрою для Y2.
  - Виберіть Inniclassic в Програмне забезпечення.
  - Виберіть випуск із списку для Y2.
  - Натисніть Встановити / Відновити.
  - Вимкніть живлення та підключіть Y2 лише тоді, коли Updater CE запитає.
