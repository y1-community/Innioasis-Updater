# Machen Sie weiter so mit den guten Sachen.

Updater CE ist kostenlos. Es wurde von Leuten entwickelt, die möchten, dass Innioasis und Timmkoo Spieler nützlich bleiben. Ihr Support bezahlt das Archiv, die Server und die Zeit.

## Dies ist ein von Menschen getragenes Projekt.

Jeder Beitrag hilft jemandem, eine funktionierende Firmware zu finden, ein neues Projekt auszuprobieren oder einen alten Player etwas länger am Leben zu halten.
