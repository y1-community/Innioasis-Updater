# Innioasis に Rockbox を選択する理由

Rockbox は、プレーヤーを適切な音楽ライブラリに変えます。ギャップレス再生、イコライザー、豊富なテーマ ライブラリ。必要に応じて元のソフトウェアに戻って起動できます。[Updater CE の Rockbox を取得します](guide_ja.html?model=Y1&software=rockbox-y1)[Y1 インストールページ](rockbox-y1-software_ja.html)[Y2 インストールページ](rockbox-y2-software_ja.html)

## モデルの入手可能性

どの Innioasis モデルで実行されますか?[Y1 · 利用可能](rockbox-y1-software_ja.html)[Y2 · 利用可能](rockbox-y2-software_ja.html)

Y1 ビルドと Y2 ビルドは別個であるため、ソフトウェア ダウンロードでプレーヤー用に作成されたビルドを入手してください。一方をもう一方と交換しないでください。

## 人々がそれを選ぶ理由

図書館がポイントになります。
  - ファイル名によるスクロールを停止する — Rockbox は、実際のライブラリと同じように、音楽のタグを読み取り、アルバム、アーティスト、ジャンルごとに並べ替えます。大きなコレクションがフォルダーのダンプのように感じられなくなります。
  - ギャップレス、クロスフェード、EQ — 曲は隙間なく互いに流れ込み、フルイコライザーによりプレーヤーから離れずにサウンドをチューニングできます。
  - あらゆる好みに合わせたテーマ — クリーンでミニマルな外観から iPod スタイルのインターフェイスに至るまで、テーマ ライブラリは膨大です。Y1 コミュニティ ビルドでは、選択に役立つ 360p 互換性ラベルが使用されています。
  - ストック付きデュアルブート — Rockbox メニューからいつでも元のソフトウェアに再起動できます。ドアを開けっ放しにしての実験です。
  - ポッドキャストとスクロブル — このフォークにより、内蔵 Wi-Fi 経由でのポッドキャストのダウンロードと Last.fm / ListenBrainz / Maloja のスクロブルが追加されるため、視聴履歴は自分のものになります。
  - 設計によりオフライン — Rockbox はローカル ファイル上で実行されます。アカウントもサブスクリプションもストリーミングへの依存もありません。これが、多くのコミュニティ メンバーがサブスクリプションのトレッドミルをやめるのに役立ったと言っている理由です。

## コミュニティ

コミュニティの意見

Innioasis Updater は Rockbox コミュニティのために存在します。これは、Y1 と Y2 の所有者の第一波がプレーヤーを純正のオルゴールから適切な音楽データベースに変えるためにたどったルートであり、このサイトのチュートリアル ビデオのほとんどで取り上げられているソフトウェアでもあります。

Dammit Jeff (そのビデオは文字通りストリーミング サービスを実際にやめる方法についてのものです)、Frawgeeys、TUXX Reviews、veromarstars などのクリエイターが、Rockbox のインストール、テーマ、および YouTube と TikTok の日常的な使用方法をカバーしています。コメントと返信の一貫したテーマ: タグベースのライブラリと詳細なテーマ オプションにより、プレーヤーが自分のものであるかのように感じられます。

## プロジェクトが提供するもの
  - タグベースのデータベース: アルバムとアーティストはファイル名ではなくタグで並べ替えられます。
  - ギャップレス再生、クロスフェード、内蔵イコライザー
  - iPod スタイルのインターフェイスを含む詳細なテーマ ライブラリ。 Y1 ビルドには 360p 互換性ラベルが付いています
  - 再起動ショートカットを備えた iPod 6G スタイルのコントロール (「次へ」+「前へ」を 10 秒間押し続ける)
  - Rockbox 内の FM ラジオ アプリ
  - 内蔵Wi-Fiチップを使用したポッドキャストダウンロードプラグイン
  - Last.fm、ListenBrainz、または Maloja へのスクロブリング
  - デュアルブート: メインメニュー → システムから再起動し、メニュー/戻る + 再生/一時停止を押して元の状態に戻ります。
  - 個別の Y1 ビルドと Y2 ビルド — Y2 パッケージは独自の ROM であり、入れ替えてはなりません

## 最初に知っておくべきこと
  - これは実験的なビルドです。プロジェクト自体は、Innioasis とは関連付けられておらず、急ぐとブリックのリスクが伴うことを警告しています。
  - 必ず、実際のモデルにリストされているリリースを選択してください (Y1 または Y2)
  - 古いテーマのコレクションは 240p で作成できます。ビルドを選択する前に解像度とリリースノートを確認してください
  - 一致する Y1 または Y2 ストック パッケージを使用して、後で元のソフトウェアを復元できます。
