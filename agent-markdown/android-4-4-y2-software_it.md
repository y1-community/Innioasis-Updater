## Passaggi di installazione di Android 4.4 Y2.
  - Apri Innioasis Updater CE sul tuo computer (se ti serve l'app, [Ottieni Updater CE](guide_it.html#platform)). Impostato Modello del dispositivo a Y2.
  - Scegli Android 4.4 (sviluppo) dentro Software.
  - Scegli la versione elencata per Y2.
  - Fare clic Installa / Ripristina.
  - Spegni e collega Y2 solo quando Updater CE lo richiede.
