# Reborn (Y2Linux) для Innioasis Y2

Швидкий, спеціально створений дистрибутив Debian Linux із власним користувальницьким інтерфейсом коліщатка для Innioasis Y2, що забезпечує стабільність навушників Bluetooth та активний розвиток спільноти.[Покрокова Y2 інструкція](guides/reborn-y2linux-y2.html)[Чому Y2Reborn?](reborn-y2linux-benefits_uk.html)[Завантажити випуски](firmware_uk.html?model=Y2&software=reborn-y2linux-y2)

## Встановіть Reborn (Y2Linux) на ваш Y2 разом із комп’ютером

Виберіть посібник для комп’ютера, яким ви користуєтеся. Кожна версія має налаштування платформи, Updater CE кроків і шлях повернення до запасу.[Керівництво по Windows](install/reborn-y2linux-y2-windows.html)[посібник з macOS](install/reborn-y2linux-y2-mac.html)[Керівництво по Linux](install/reborn-y2linux-y2-linux.html)

[Усі Innioasis посібники Y2](install/y2.html) · [Усі Reborn (Y2Linux) посібники](install/reborn.html)

## Етапи встановлення
  - Відкрийте Updater CE. Доступно для Windows, macOS і Linux.
  - Виберіть Y2 як модель пристрою.
  - Виберіть Reborn (Y2Linux) як програмне забезпечення.
  - Натисніть Встановити / Відновити. Зачекайте, поки Updater CE підготує файли.
  - Підключіть USB, коли буде запропоновано. Спочатку вимкніть Y2.
  - Налаштуйте Wi-Fi, Bluetooth і FM-радіо

Копія `system.img` гравцеві один раз. Reborn робить все інше.[Завершити налаштування →](y2reborn_wifibt_uk.html)
