# Rondo для Innioasis Y1

Мінімалістична прошивка музичного плеєра з коліщатком, розроблена спеціально для Innioasis Y1 ємнісного обладнання, повністю зосереджена на швидкому відтворенні та чіткій навігації.[Покрокова Y1 інструкція](guides/rondo-y1.html)[Чому Rondo?](rondo-benefits_uk.html)[Завантажити випуски](firmware_uk.html?model=Y1&software=rondo-y1)

Посібник із встановлення для вашого комп’ютера

## Встановіть Rondo на свій Y1 разом із комп’ютером

Виберіть посібник для комп’ютера, яким ви користуєтеся. Кожна версія має налаштування платформи, Updater CE кроків і шлях повернення до запасу.[Керівництво по Windows](install/rondo-y1-windows.html)[посібник з macOS](install/rondo-y1-mac.html)[Керівництво по Linux](install/rondo-y1-linux.html)

[Усі Innioasis посібники Y1](install/y1.html) · [Усі Rondo посібники](install/rondo.html)

## Етапи встановлення
  - Запуск Innioasis Оновлення CE на комп’ютері Windows, Mac або Linux.
  - Виберіть Y1 зі спадного списку Модель пристрою.
  - Виберіть Rondo зі спадного меню Програмне забезпечення.
  - Натисніть Встановити / Відновити і зачекайте, поки інструмент завантажить і підготує файли.
  - Коли з’явиться запит Updater CE, вимкніть Y1 і під’єднайте кабель USB.
  - Завершіть налаштування після встановлення

Виконайте кроки в [цей посібник](post_install_uk.html?software=rondo-y1&model=Y1) щоб завершити налаштування на Y1.[Переглянути посібник](post_install_uk.html?software=rondo-y1&model=Y1)
