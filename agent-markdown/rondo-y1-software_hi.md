# Rondo के लिए Innioasis Y1

एक न्यूनतम क्लिकव्हील म्यूजिक प्लेयर फर्मवेयर विशेष रूप से Innioasis Y1 कैपेसिटिव हार्डवेयर के लिए डिज़ाइन किया गया है, जो पूरी तरह से रिस्पॉन्सिव प्लेबैक और स्वच्छ नेविगेशन पर केंद्रित है।[चरण-दर-चरण Y1 मार्गदर्शिका](guides/rondo-y1.html)[क्यों Rondo?](rondo-benefits_hi.html)[विज्ञप्ति डाउनलोड करें](firmware_hi.html?model=Y1&software=rondo-y1)

अपने कंप्यूटर के लिए गाइड इंस्टॉल करें

## अपने कंप्यूटर पर Y1 पर Rondo इंस्टॉल करें

आप जिस कंप्यूटर का उपयोग कर रहे हैं उसके लिए गाइड चुनें. प्रत्येक संस्करण में प्लेटफ़ॉर्म सेटअप, Updater CE चरण और स्टॉक में वापस आने का तरीका होता है।[विंडोज़ गाइड](install/rondo-y1-windows.html)[macOS गाइड](install/rondo-y1-mac.html)[लिनक्स गाइड](install/rondo-y1-linux.html)

[सभी Innioasis Y1 गाइड](install/y1.html) · [सभी Rondo मार्गदर्शक](install/rondo.html)

## स्थापना चरण
  - प्रक्षेपण Innioasis Updater सीई आपके विंडोज़, मैक, या लिनक्स कंप्यूटर पर।
  - चयन करें Y1 डिवाइस मॉडल ड्रॉपडाउन से।
  - चयन करें Rondo सॉफ़्टवेयर ड्रॉपडाउन से.
  - क्लिक करें इंस्टॉल / पुनर्स्थापित और टूल के डाउनलोड होने और फ़ाइलें तैयार होने तक प्रतीक्षा करें।
  - अपडेटर सीई द्वारा संकेत दिए जाने पर, अपने Y1 को बंद करें और USB केबल को कनेक्ट करें।
  - इंस्टॉल के बाद का सेटअप पूरा करें

इसमें दिए गए चरणों का पालन करें [यह मार्गदर्शिका](post_install_hi.html?software=rondo-y1&model=Y1) अपने Y1 पर सेटअप पूरा करने के लिए।[गाइड देखें](post_install_hi.html?software=rondo-y1&model=Y1)
