## JJ Launcher Y1 install steps
  - Åbn Innioasis Updater CE på din computer (hvis du har brug for appen, [Hent Updater CE](guide_da.html#platform)). Sæt Enhedsmodel til Y1.
  - Vælg JJ Launcher ind Software.
  - Choose the release shown for Y1.
  - Klik Installer / Gendan.
  - Sluk og tilslut kun Y1, når Updater CE spørger.
