# Android 4.2 (Dev) を Y1 にインストールします。

Android 4.2 は、Innioasis Y1 ハードウェアのテストとハッキングを目的としたコミュニティ開発 ROM です。このページは、完全なチュートリアルとリリース リストにリンクしています。[完全な Android 4.2 (Dev) ガイドを開く](guides/android-4-2-y1.html)[Updater CE で入手](guide_ja.html?model=Y1&software=android-4-2-y1)[プロジェクトソース](https://github.com/y1-community/y1-ata-rom)

## コンピュータを使用して Android 開発 ROM を Y1 にインストールします

使用しているコンピュータのガイドを選択してください。 すべてのバージョンには、プラットフォームのセットアップ、Updater CE の手順、および在庫に戻る方法が含まれています。[Windowsガイド](install/android-4-2-y1-windows.html)[macOS ガイド](install/android-4-2-y1-mac.html)[Linuxガイド](install/android-4-2-y1-linux.html)

[すべての Innioasis Y1 ガイド](install/y1.html) · [すべての Android 開発 ROM ガイド](install/android-dev.html)

## Android 4.2 Y1 のインストール手順
  - コンピューターで Innioasis Updater CE を開きます (アプリが必要な場合は、 [Updater CE を入手](guide_ja.html#platform)）。セット デバイスモデル 支援先: Y1.
  - 選択してください Android 4.2 (開発版) で ソフトウェア.
  - Y1 にリストされているリリースを選択します。
  - クリック インストール / 復元.
  - Updater CE が要求した場合にのみ、電源をオフにして Y1 を接続してください。

## よくある質問在庫の Y1 ソフトウェアを復元できますか?

はい。 Updater CEでY1とオリジナルソフトウェアを選択します。の [Y1 ストック ソフトウェア ガイド](original-software-y1_ja.html) 復路をカバーします。これは日雇い運転手 ROM ですか?

これは、テストと開発を目的とした実験的な開発者 ROM です。機能の更新情報はプロジェクトのページにあります。
