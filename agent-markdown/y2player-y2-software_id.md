# Instal Y2Player pada Y2.

Y2Player dibuat untuk Y2. Pilih model Anda terlebih dahulu sehingga Anda tidak menggunakan paket Y1 secara tidak sengaja.[Buka panduan lengkap Y2Player](guides/y2player-y2.html)[Dapatkan ini di Updater CE](guide_id.html?model=Y2&software=y2player-y2)[Mengapa Y2Player?](y2player-benefits_id.html)

Panduan instalasi untuk komputer Anda

## Instal Y2Player pada Y2 Anda dengan komputer Anda

Pilih panduan untuk komputer yang Anda gunakan. Setiap versi memiliki pengaturan platform, Updater CE langkah-langkahnya, dan cara kembali ke stok.[Panduan Windows](install/y2player-y2-windows.html)[panduan macOS](install/y2player-y2-mac.html)[Panduan Linux](install/y2player-y2-linux.html)

[Semua Innioasis panduan Y2](install/y2.html) · [Semua panduan Y2Player](install/y2player.html)

## Y2Player langkah-langkah pemasangan
  - Buka Innioasis Updater CE di komputer Anda (jika Anda memerlukan aplikasinya, [Dapatkan Updater CE](guide_id.html#platform)). Tetapkan Model perangkat untuk Y2.
  - Pilih Y2Player di Perangkat lunak.
  - Pilih rilis yang terdaftar untuk Y2.
  - Klik Pasang / Pulihkan.
  - Matikan dan sambungkan Y2 pada perintah langsung.

Beberapa Y2 paket instalasi penuh menggunakan `rom_y2.zip`. Biarkan Updater memilih paket bila memungkinkan.
