# Прошивка для Innioasis Y1

Y1 имеет самый широкий выбор пользовательских систем. Все, что указано ниже, размещено здесь, проверено и устанавливается в один клик с помощью Updater CE.[Просмотр Y1 загрузок](firmware_ru.html?model=Y1)[Скачать Updater CE](guide_ru.html#platform)[Галерея тем](https://themes.innioasis.app/?lang=ru)

## Доступные операционные системы для Innioasis Y1

На Y1 установлено несколько программных систем, включая сборки с поддержкой аудиофильских кодеков, современными программами запуска и восстановлением заводских настроек. Выберите тот, который соответствует вашему способу прослушивания:

### [Rockbox](rockbox-benefits_ru.html)

Золотой стандарт воспроизведения аудио с открытым исходным кодом. Параметрический эквалайзер, воспроизведение FLAC/MP3 без пауз, темы и пакеты шрифтов, которые можно установить непосредственно в Updater CE.[Y1 Rockbox Руководство →](guides/rockbox-y1.html)

### [Better-Y](better-y-benefits_ru.html)

Усовершенствованная версия оригинальной прошивки с исправлениями стабильности Bluetooth, настройкой кривой громкости и 100% совместимостью с галереей тем.[Better-Y Руководство →](guides/better-y-y1.html)

### [Solar](solar-benefits_ru.html)

Современный музыкальный проигрыватель с открытым исходным кодом, созданный на основе Flutter, предлагающий плавную анимацию со скоростью 60 кадров в секунду, сетку обложек альбомов и современную типографику.[Solar Y1 Руководство →](guides/solar-y1.html)

### [Rondo](rondo-benefits_ru.html)

Программа запуска Y1 с открытым исходным кодом для локальных треков и потоковой передачи с быстрой и отзывчивой навигацией.[Rondo Y1 Руководство →](guides/rondo-y1.html)

### [Koensayr](koensayr-benefits.html)

Специальная сборка прошивки с собственной иконкой, улучшенной калибровкой батареи и поддержкой стандартных тем.[Koensayr Руководство →](guides/koensayr-y1.html)

### [Оригинальное программное обеспечение (стоковое восстановление)](original-software-benefits_ru.html)

Очистите образы заводской прошивки для плееров Type A (v2.0.0+) и Type B (v1.x) Y1. Безопасно разблокируйте или восстановите заводское состояние вашего устройства.[Восстановить Y1 Руководство →](guides/restore-original-y1.html)

## Как установить или обновить Y1 прошивку

Обновить или разблокировать ваш Innioasis Y1 очень просто с помощью нашего многоплатформенного пакета программного обеспечения:
  - Откройте Innioasis Средство обновления CE: Запустите программу обновления на macOS, Windows или Linux.
  - Выберите модель Y1: Выбирать Y1 в раскрывающемся списке Модель устройства.
  - Выберите свою операционную систему: Выберите Rockbox, Better-Y, Solar или оригинальное программное обеспечение.
  - Нажмите «Установить»: Updater CE загружает пакет прошивки непосредственно из релиза разработчика. При появлении запроса подключите выключенный Y1 через USB, чтобы начать мигание.
