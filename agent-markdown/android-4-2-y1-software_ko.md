# Innioasis Y1용 Android 4.2(Dev) 펌웨어 | 설치 튜토리얼 - Innioasis 펌웨어 다운로드

안드로이드 4.2(개발자) · Innioasis Y1

# Y1에 Android 4.2(Dev)를 설치합니다.

Android 4.2는 Innioasis Y1 하드웨어를 테스트하고 해킹하기 위한 커뮤니티 개발 ROM입니다. 이 페이지는 전체 튜토리얼 및 릴리스 목록으로 연결됩니다.[전체 Android 4.2(개발자) 가이드 열기](guides/android-4-2-y1.html)[이것을 Updater CE에서 얻으세요](guide_ko.html?model=Y1&software=android-4-2-y1)[프로젝트 소스](https://github.com/y1-community/y1-ata-rom)

컴퓨터에 대한 설치 가이드

## 컴퓨터를 사용하여 Y1에 Android 개발 ROM을(를) 설치하세요.

사용 중인 컴퓨터에 대한 가이드를 선택하세요. 모든 버전에는 플랫폼 설정, Updater CE 단계 및 재고로 돌아가는 방법이 있습니다.[윈도우 가이드](install/android-4-2-y1-windows.html)[macOS 가이드](install/android-4-2-y1-mac.html)[리눅스 가이드](install/android-4-2-y1-linux.html)

[모든 Innioasis Y1 가이드](install/y1.html) · [모든 Android 개발 ROM 가이드](install/android-dev.html)

## Android 4.2 Y1 설치 단계
  - 컴퓨터에서 Innioasis Updater CE를 엽니다(앱이 필요한 경우, [Updater CE 받기](guide_ko.html#platform)). 세트 기기 모델 에 Y1.
  - 선택 안드로이드 4.2(개발자) 안으로 소프트웨어.
  - Y1에 대해 나열된 릴리스를 선택합니다.
  - 클릭 설치 / 복원.
  - 전원을 끄고 Updater CE이 묻는 경우에만 Y1을 연결하세요.

## 자주 묻는 질문재고 Y1 소프트웨어를 복원할 수 있나요?

예. Updater CE에서 Y1과 원본 소프트웨어를 선택합니다. 는 [Y1 스톡 소프트웨어 가이드](original-software-y1_ko.html) 복귀 경로를 덮습니다.이 사람은 일일 운전자ROM입니까?

테스트 및 개발을 목적으로 하는 실험적 개발자ROM입니다. 기능 업데이트는 프로젝트 페이지에 있습니다.

## 안내 경로를 이용하세요

업데이터를 처음 사용하시나요? 안내된 설정을 참조하세요. [Updater CE 받기](guide_ko.html#platform) 플레이어를 연결하기 전에 Windows, macOS 또는 Linux에서.
