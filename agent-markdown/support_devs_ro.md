# Continuă lucrurile bune.

Updater CE este gratuit. Este construit de oameni care doresc ca jucătorii Innioasis și Timmkoo să rămână utili. Asistența dvs. plătește pentru arhivă, servere și timp.

## Acesta este un proiect alimentat de oameni.

Fiecare contribuție ajută pe cineva să găsească un firmware funcțional, să încerce un proiect nou sau să mențină un vechi player în viață puțin mai mult.
