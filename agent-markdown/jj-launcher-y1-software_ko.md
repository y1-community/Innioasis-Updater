# Innioasis Y1에 JJ Launcher을(를) 설치합니다.

## 컴퓨터를 사용하여 Y1에 JJ Launcher을(를) 설치합니다.

사용 중인 컴퓨터에 대한 가이드를 선택하세요. 모든 버전에는 플랫폼 설정, Updater CE 단계 및 재고로 돌아가는 방법이 있습니다.[윈도우 가이드](install/jj-launcher-y1-windows.html)[macOS 가이드](install/jj-launcher-y1-mac.html)[리눅스 가이드](install/jj-launcher-y1-linux.html)

[모든 Innioasis Y1 가이드](install/y1.html) · [모든 JJ Launcher 가이드](install/jj-launcher.html)

## JJ Launcher Y1 설치 단계
  - 컴퓨터에서 Innioasis Updater CE를 엽니다(앱이 필요한 경우, [Updater CE 받기](guide_ko.html#platform)). 세트 기기 모델 에 Y1.
  - 선택 JJ Launcher 안으로 소프트웨어.
  - Y1에 표시된 릴리스를 선택합니다.
  - 클릭 설치 / 복원.
  - 전원을 끄고 Updater CE이 묻는 경우에만 Y1을 연결하세요.

## 자주 묻는 질문Y1에 Y2 항목을 설치할 수 있습니까?

아니요. 모델과 패키지를 일치하게 유지하세요. Y1 항목이 누락된 경우 Y2 파일을 강제로 생성하지 마십시오.원래 소프트웨어로 돌아갈 수 있나요?

예. Updater CE에서 Y1 및 원본 소프트웨어를 선택합니다. 참조 [Y1 복원 페이지](original-software-y1_ko.html).JJ Launcher 릴리스는 모두 어디에 있나요?

현재 빌드는 [소프트웨어 다운로드](firmware_ko.html#y1). 릴리스 노트는 프로젝트의 [릴리스 노트](release_notes_ko.html?software=jj-launcher-y1).

## 컴퓨터 설정

관련 설정이 준비되면 Windows, macOS 및 Linux에서 업데이터를 사용할 수 있습니다. 다음으로 시작하세요. [플랫폼 가이드](guide_ko.html#platform).
