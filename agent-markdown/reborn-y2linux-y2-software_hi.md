# Reborn (Y2Linux) के लिए Innioasis Y2

Innioasis Y2 के लिए देशी क्लिकव्हील उपयोगकर्ता इंटरफ़ेस के साथ एक तेज़, उद्देश्य-निर्मित डेबियन लिनक्स वितरण, जिसमें ब्लूटूथ हेडफ़ोन स्थिरता और सक्रिय सामुदायिक विकास शामिल है।[चरण-दर-चरण Y2 मार्गदर्शिका](guides/reborn-y2linux-y2.html)[क्यों Y2Reborn?](reborn-y2linux-benefits_hi.html)[विज्ञप्ति डाउनलोड करें](firmware_hi.html?model=Y2&software=reborn-y2linux-y2)

अपने कंप्यूटर के लिए गाइड इंस्टॉल करें

## अपने कंप्यूटर के साथ अपने Y2 पर Reborn (Y2Linux) इंस्टॉल करें

आप जिस कंप्यूटर का उपयोग कर रहे हैं उसके लिए गाइड चुनें. प्रत्येक संस्करण में प्लेटफ़ॉर्म सेटअप, Updater CE चरण और स्टॉक में वापस आने का तरीका होता है।[विंडोज़ गाइड](install/reborn-y2linux-y2-windows.html)[macOS गाइड](install/reborn-y2linux-y2-mac.html)[लिनक्स गाइड](install/reborn-y2linux-y2-linux.html)

[सभी Innioasis Y2 गाइड](install/y2.html) · [सभी Reborn (Y2Linux) मार्गदर्शक](install/reborn.html)

## स्थापना चरण
  - अपडेटर सीई खोलें। विंडोज़, मैकओएस और लिनक्स के लिए उपलब्ध है।
  - Y2 चुनें डिवाइस मॉडल के रूप में.
  - Reborn (Y2Linux) चुनें सॉफ्टवेयर के रूप में.
  - इंस्टॉल/रिस्टोर पर क्लिक करें। अपडेटर सीई द्वारा फ़ाइलें तैयार करने तक प्रतीक्षा करें।
  - पूछे जाने पर USB कनेक्ट करें। पहले Y2 को बंद करें।
  - वाई-फाई, ब्लूटूथ और एफएम रेडियो सेट करें

प्रतिलिपि `system.img` खिलाड़ी को एक बार. Reborn बाकी काम करता है।[सेटअप समाप्त करें →](y2reborn_wifibt_hi.html)
