# Inniclassic เฟิร์มแวร์สำหรับ Innioasis Y1 | ติดตั้งบทช่วยสอน - Innioasis ดาวน์โหลดเฟิร์มแวร์

Inniclassic · Innioasis Y1

# ติดตั้ง Inniclassic บน Y1

Inniclassic เป็นโปรเจ็กต์ซอฟต์แวร์ชุมชนสำหรับ Y1 และโปรเจ็กต์เดียวกันนี้ยังเผยแพร่บิลด์ Y2 ดังนั้นจึงพร้อมใช้งานสำหรับผู้เล่นทั้งสองคน หน้านี้ให้คำตอบที่ง่ายต่อการค้นหา Y1 และลิงก์ไปยังขั้นตอนการเชื่อมต่อโดยละเอียด[เปิดคำแนะนำ Inniclassic ฉบับเต็ม](guides/inniclassic-y1.html)[รับสิ่งนี้ใน Updater CE](guide_th.html?model=Y1&software=inniclassic-y1)[ทำไมต้อง Inniclassic?](inniclassic-benefits_th.html)

คู่มือการติดตั้งสำหรับคอมพิวเตอร์ของคุณ

## ติดตั้ง Inniclassic บน Y1 ด้วยคอมพิวเตอร์ของคุณ

เลือกคำแนะนำสำหรับคอมพิวเตอร์ที่คุณใช้ ทุกรุ่นมีการตั้งค่าแพลตฟอร์ม ขั้นตอน Updater CE และวิธีคืนสินค้าในสต็อก[คู่มือวินโดวส์](install/inniclassic-y1-windows.html)[คู่มือ macOS](install/inniclassic-y1-mac.html)[คู่มือลินุกซ์](install/inniclassic-y1-linux.html)

[คำแนะนำ Innioasis Y1 ทั้งหมด](install/y1.html) · [คำแนะนำ Inniclassic ทั้งหมด](install/inniclassic.html)

## Inniclassic Y1 ขั้นตอนการติดตั้ง
  - เปิด Innioasis Updater CE บนคอมพิวเตอร์ของคุณ (หากคุณต้องการแอป [รับ Updater CE](guide_th.html#platform)). ชุด รุ่นอุปกรณ์ ถึง Y1.
  - เลือก Inniclassic ใน ซอฟต์แวร์.
  - เลือกรุ่นที่ระบุไว้สำหรับ Y1
  - คลิก ติดตั้ง / คืนค่า.
  - ปิดเครื่องและเชื่อมต่อ Y1 เมื่อ Updater CE ถามเท่านั้น

## คำถามที่พบบ่อยฉันสามารถกู้คืนซอฟต์แวร์สต็อก Y1 ได้หรือไม่

ใช่. เลือก Y1 และซอฟต์แวร์ต้นฉบับใน Updater CE ที่ [คู่มือซอฟต์แวร์หุ้น Y1](original-software-y1_th.html) ครอบคลุมเส้นทางขากลับจะทำอย่างไรถ้าการติดตั้งล้มเหลว?

โปรดทราบว่าตัวอัปเดตล้มเหลวก่อนหรือหลังการตรวจจับ Y1 จากนั้นตรวจสอบสายเคเบิล การตั้งค่าแพลตฟอร์ม รุ่น และระยะเวลาการเชื่อมต่อใน [การแก้ไขปัญหา](troubleshooting_th.html).ฉันสามารถใช้ Inniclassic กับ Y2 ได้หรือไม่

ใช่. Inniclassic มีอยู่ในทั้งสองรุ่น - โปรเจ็กต์ที่ได้รับการดูแลเดียวกันจะเผยแพร่แพ็คเกจ Y2 จากรุ่นเดียวกัน เลือก Y2 ใน Updater CE และติดตั้งบิลด์ Y2 ไม่เคยแฟลชแพ็คเกจ Y1 ไปที่ Y2 ที่ [หน้าติดตั้ง Y2](inniclassic-y2-software_th.html) ครอบคลุมมัน

## ใช้เส้นทางที่แนะนำ

ครั้งแรกที่ใช้ Updater? ดูการตั้งค่าที่แนะนำไปที่ [รับ Updater CE](guide_th.html#platform) บน Windows, macOS หรือ Linux ก่อนที่จะเชื่อมต่อเครื่องเล่นของคุณ
