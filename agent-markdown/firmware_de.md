## Installieren Sie Ihre Wahl mit Updater CE
  - Öffnen Sie die Anleitung und installieren Sie Innioasis Updater CE für Ihren Computer, falls Sie es noch nicht haben.
  - Wählen Sie unter Updater CE das auf Ihrem Player aufgedruckte Modell aus Gerätemodell.
  - Aus Software, wählen Sie die Software aus, die Sie auf diesem Modell ausführen möchten.
  - Wählen Sie eine Veröffentlichung aus und klicken Sie auf Installieren / Wiederherstellen, dann schalten Sie den Player aus und schließen Sie ihn erst an, wenn Updater CE dazu fragt.

Benötigen Sie das Installationsprogramm? [Öffnen Sie den Leitfaden und erweitern Sie den Download-Bereich Updater CE.](guide_de.html#download-updater).

## Der sichere Rückweg

### Überprüfen Sie das Modell

Y1 and Y2 software is not interchangeable. Re-select the model in Updater CE and start again.

### Warten Sie auf die Aufforderung

Schalten Sie den Player vollständig aus und schließen Sie ihn erst an, wenn Updater CE anzeigt, dass er bereit ist.

### Originalsoftware wiederherstellen

Wählen Sie Originalsoftware für dasselbe Modell. Wenn eine manuelle Wiederherstellung erforderlich ist, öffnen Sie die [Anleitung zur Fehlerbehebung](troubleshooting_de.html) zuerst.

## Supported Devices and Official Stock Firmware

The Innioasis Firmware Archive hosts verified stock firmware, original factory restore images, and custom operating systems for portable players:

### Innioasis Y1 & Y2

Official software and custom systems including Rockbox, Better-Y, and Solar.

### Innioasis G1, G3 & G5

Offizielle Software und Wiederherstellungsdateien für Touchscreen-Player.

### Innioasis R1 & PR1

Originalsoftware und Wiederherstellungsdateien für Audioplayer.

### Timmkoo Q5 & Q3

Packages provided for Timmkoo players via Updater CE.

New releases appear here as soon as they are verified.

## Welches Werkzeug soll ich verwenden?

Innioasis Updater CE is the recommended tool for daily updates and community OS installs across Windows, macOS, and Linux. Flashing through Updater CE preserves your library and pairings.

The legacy Universal Flash Tool remains available for emergency unbricking when a device cannot boot into fastboot.[Compare flashing tools](updater-comparison_de.html)
