# Pierwsze kroki z Innioasis Updater CE

Współpracuje ze wszystkimi odtwarzaczami audio Innioasis i Timmkoo. Zainstaluj Innioasis Updater CE na swoim komputerze, wybierz model i oprogramowanie, które chcesz, a następnie postępuj zgodnie z instrukcjami.

## Zdobądź Innioasis Updater CE

Innioasis Aktualizator CE to aplikacja, która instaluje w odtwarzaczu oficjalne aktualizacje i oprogramowanie społecznościowe. Przechowuje Twoją muzykę i ustawienia oraz działa w systemach Windows, macOS i Linux.

### Windows

Pobierz instalator, uruchom go, a po zakończeniu uruchom ponownie komputer.[Pobierz sterowniki](https://github.com/y1-community/supplemental-apks/releases/latest/download/DriverInstall.exe)[Pobierz Updater CE](https://github.com/y1-community/Innioasis-Updater/releases/latest/download/installer.exe)

Jeśli system Windows uniemożliwia uruchomienie aplikacji lub jej nie uruchamia, otwórz Ustawienia, kliknij Prywatność i bezpieczeństwo → Zabezpieczenia systemu Windows → Kontrola aplikacji i przeglądarki, a następnie wyłącz Inteligentną kontrolę aplikacji. Inteligentna kontrola aplikacji ma obecnie wpływ na popularne aplikacje, takie jak usługa Epic Overlay Service (używana przez Fortnite) — narzędzie Updater CE jest bezpieczne i sprawdzone w użyciu. [System Windows nie uruchamia aplikacji? Pomoc](#smart-app-control)

Uruchom ponownie komputer po instalacji. Pomoc kierowcy jest w [Uwagi dotyczące konfiguracji systemu Windows](drivers_pl.html#windows).

### macOS[Pobierz Updater CE](https://github.com/y1-community/Innioasis-Updater/releases/latest/download/Innioasis.Updater.for.Mac.dmg)

Jeśli Twój Mac blokuje uruchomienie aplikacji po raz pierwszy, otwórz Ustawienia systemowe, kliknij Prywatność i ochrona, przewiń w dół do sekcji Ochrona i kliknij [Otwórz mimo to](https://support.apple.com/en-gb/102445#openanyway). Możesz także kliknąć aplikację w Finderze z wciśniętym klawiszem Control (lub prawym przyciskiem myszy) i wybrać Otwórz.

Działa na komputerach Mac z procesorami Intel i Apple Silicon z systemem macOS Monterey i nowszym.

### Linux

Pobierz AppImage dla systemów Intel i AMD, nadaj mu charakter wykonywalny i uruchom go.[Pobierz AppImage dla Intel/AMD](https://github.com/y1-community/innioasis-updater/releases/latest/download/UpdaterCE.AppImage)

[Uwagi dotyczące konfiguracji Linuksa](drivers_pl.html#linux)Inna platforma?

Potrzebujesz odtwarzacza, kabla do transmisji danych USB (nie można zainstalować kabla przeznaczonego tylko do ładowania) i kilku minut. Pozostaw kabel podłączony do czasu, aż narzędzie Updater CE poinformuje, że zostało to wykonane.

## Wybierz swój model i oprogramowanie
  - Model urządzenia: wybierz model wydrukowany na odtwarzaczu, Y1 lub Y2. Oprogramowania przeznaczonego dla jednego modelu nie można zainstalować na drugim.
  - Oprogramowanie i wydanie: wybierz Oprogramowanie oryginalne, Rockbox, Solar, JJ Launcher, Inniclassic, Y2Player lub Koensayr, jeśli jest ono wymienione dla Twojego modelu, a następnie wybierz wersję. Stabilność to bezpieczny wybór.
  - Zainstalować: trzask Zainstaluj / Przywróć, całkowicie wyłącz odtwarzacz i podłącz kabel USB tylko wtedy, gdy Updater CE o to poprosi.
  - Skończyć: pozostaw odtwarzacz i kabel w spokoju do czasu pojawienia się komunikatu o powodzeniu, a następnie odłącz i uruchom odtwarzacz.

Y1 gracze, którzy otrzymali oryginalne oprogramowanie przed wersją 2.0.0 Urządzenie Type B. Wszyscy pozostali zachowują ustawienie domyślne Type A.Instrukcje podłączenia aktualizatora do podłączenia wyłączonego odtwarzaczaPostępuj zgodnie z monitami narzędzia Updater CE na żywo dla Twojego modelu.

## Wracając do oryginalnego oprogramowania

Oprogramowanie niestandardowe jest odwracalne. W Updater CE wybierz swój model, wybierz Oprogramowanie oryginalne, wybierz wersję stabilną i uruchom Zainstaluj / Przywróć w ten sam sposób. Nie ma nic do usunięcia ręcznie.[Przewodnik przywracania Y1](guides/restore-original-y1.html)[Przewodnik przywracania Y2](guides/restore-original-y2.html)

Jeśli miganie zatrzyma się przed komunikatem USB, sprawdź najpierw kabel, konfigurację platformy i model. Widzieć [rozwiązywanie problemów](troubleshooting_pl.html) do poprawek, [Y1 i Y2 przewodnik odzyskiwania](guides/recovery.html) za usterki zasilania i kół oraz [SP Flash Tool](sp-flash-tool_pl.html) do zaawansowanej regeneracji.

## System Windows nie uruchamia aplikacji? Rozwiązanie inteligentnej kontroli aplikacji

Funkcja Windows Defender SmartScreen lub Smart App Control może blokować nowo pobrane aplikacje społecznościowe, zanim reputacja sygnatur zacznie się rozprzestrzeniać. Inteligentna kontrola aplikacji ma obecnie wpływ na popularne aplikacje, takie jak usługa Epic Overlay Service (używana przez Fortnite) — użycie narzędzia Updater CE jest bezpieczne i zweryfikowane. Wyłączenie inteligentnej kontroli aplikacji umożliwia normalne otwieranie i działanie narzędzia Updater CE.
  - Otwórz Ustawienia na komputerze z systemem Windows (naciśnij Win + I).
  - Kliknij Prywatność i bezpieczeństwo na lewym pasku bocznym, a następnie kliknij Windows Security.
  - Kliknij Kontrola aplikacji i przeglądarki.
  - Pod Inteligentna kontrola aplikacji, kliknij Ustawienia inteligentnej kontroli aplikacji.
  - Ustaw przełącznik na Wyłączony aby umożliwić uruchomienie Updatera CE.

Pobrałeś przez Edge'a? Jeśli Edge blokuje samo pobieranie, kliknij przycisk Więcej opcji (…) → Trzymać → Pokaż więcej → Mimo to zachowaj.

Ponowne włączenie inteligentnej kontroli aplikacji później: Jeśli chcesz ponownie włączyć funkcję Smart App Control, możesz ją ponownie włączyć za pośrednictwem rejestru systemu Windows w obszarze `HKEY_LOCAL_MACHINE\SYSTEM\CurrentControlSet\Control\CI\Policy` poprzez ustawienie `VerifiedAndReputablePolicyState` do `1` (Wł.) lub `2` (Tryb ewaluacyjny) i ponowne uruchomienie.
