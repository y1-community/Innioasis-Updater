# Install Linux on the Y1.

Linux for Y1 is an experimental community Linux kernel and rootfs port for the Innioasis Y1 hardware. This page links to the full installation guide and releases.[Open the full Linux for Y1 (Dev) guide](guides/linux-y1.html)[Získejte to v Updater CE](guide_cs.html?model=Y1&software=linux-y1)[Zdroj projektu](https://github.com/y1-community/y1-linux-rom)

Průvodce instalací pro váš počítač

## Install Linux for Y1 (Dev) on your Y1 with your computer

Vyberte průvodce pro počítač, který používáte. Každá verze má nastavení platformy, Updater CE kroky a cestu zpět na sklad.[Průvodce Windows](install/linux-y1-windows.html)[průvodce macOS](install/linux-y1-mac.html)[Linux průvodce](install/linux-y1-linux.html)

[All Innioasis Y1 guides](install/y1.html) · [All Linux for Y1 (Dev) guides](install/linux-dev.html)

## Linux Y1 install steps
  - Otevřete Innioasis Updater CE na svém počítači (pokud potřebujete aplikaci, [Získat Updater CE](guide_cs.html#platform)). Soubor Model zařízení do Y1.
  - Vyberte si Linux pro Y1 (vývoj) v Software.
  - Vyberte vydání uvedené pro Y1.
  - Klikněte Nainstalovat / Obnovit.
  - Vypněte a připojte Y1 pouze tehdy, když se zeptá Updater CE.

## Časté dotazyMohu obnovit software Y1?

Ano. Vyberte Y1 a originální software v Updater CE. The [Y1 průvodce skladovým softwarem](original-software-y1_cs.html) pokrývá zpáteční cestu.Is this an everyday user interface?

This is an experimental port for developers and Linux tinkerers. Terminal and console instructions are in the project docs.
