## Koensayr Y1 étapes d'installation
  - Ouvrez Innioasis Updater CE sur votre ordinateur (si vous avez besoin de l'application, [Obtenir Updater CE](guide_fr.html#platform)). Ensemble Modèle d'appareil à Y1.
  - Choisissez Koensayr dans Logiciel.
  - Choisissez la version Y1 répertoriée.
  - Cliquez Installer / Restaurer.
  - Éteignez et connectez le Y1 uniquement lorsque Updater CE le demande.

## FAQPuis-je restaurer le logiciel Y1 d'origine ?

Oui. Sélectionnez Y1 et Logiciel original dans Updater CE. Voir le [Y1 page de stock de logiciels](original-software-y1_fr.html) pour l'itinéraire de restauration complet.Que dois-je vérifier en cas d'échec ?

Vérifiez le modèle, la version, le câble, la configuration de la plate-forme et si le lecteur était connecté avant l'invite. Utilisez ensuite [dépannage](troubleshooting_fr.html).Existe-t-il un package Koensayr Y2 ?

La version actuelle est pour Y1. Ne l'utilisez pas sur un Y2 à moins que le projet ne publie une version distincte pour celui-ci.
