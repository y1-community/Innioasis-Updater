Inniclassic Y1 install steps

  1. פתח את Innioasis Updater CE במחשב שלך (אם אתה צריך את האפליקציה, הורדת Updater CE). סט דגם המכשיר ל Y1.
  2. בחר Inniclassic ב תוכנה.
  3. בחר את המהדורה הרשומה עבור Y1.
  4. לחץ התקנה / שחזור.
  5. כבה וחבר את ה-Y1 רק כאשר Updater CE מבקש.

שאלות נפוצות

האם אוכל לשחזר את תוכנת המניות Y1?

כֵּן. בחר Y1 ותוכנה מקורית ב-Updater CE. ה Y1 מדריך תוכנה למניות מכסה את נתיב החזרה.

מה אם ההתקנה נכשלת?

Note whether Updater failed before or after detecting the Y1, then check the cable, platform setup, model, and connection timing in פתרון בעיות.

Can I use Inniclassic on Y2?

Yes. Inniclassic is available on both models — the same maintained project publishes a Y2 package from the same releases. Select Y2 in Updater CE and install the Y2 build; never flash a Y1 package to a Y2. The דף ההתקנה של Y2 covers it.
