Solar Y1 Installationsschritte

  1. Öffnen Sie Innioasis Updater CE auf Ihrem Computer (wenn Sie die App benötigen, Updater CE holen). Satz Gerätemodell an Y1.
  2. Wählen Sie Solar In Software.
  3. Lesen Sie die Versionshinweise zum Projekt und wählen Sie eine Y1-Version aus.
  4. Klicken Sie Installieren / Wiederherstellen.
  5. Schalten Sie das Y1 erst aus und schließen Sie es an, wenn die Aufforderung erscheint.

Solar Funktionen und Verfügbarkeit können sich ändern. Die Funktionen können sich zwischen den Veröffentlichungen ändern. Überprüfen Sie daher die Veröffentlichungsseite des Projekts und die aktuelle Auflistung Ihres Modells.

FAQ

Kann ich von Solar zur Originalsoftware zurückkehren?

Verwenden Sie Y1 Originalsoftware in Updater CE. Sie müssen Solar nicht zuerst manuell entfernen. Folgen Sie dem Y1 Wiederherstellungsschritte.

Kann ich den Eintrag Solar Y2 auf diesem Player installieren?

Nein. Lassen Sie den Y1-Player auf dem Y1-Eintrag und überprüfen Sie das Modell vor der Installation.

Wo kann ich die aktuellen Solar-Funktionen überprüfen?

Lesen Sie die Versionshinweise bevor Sie sich für eine Veröffentlichung entscheiden.

Benötigen Sie eine umfassendere Updater-Erklärung?

Siehe die Windows-, macOS- und Linux-Updater-Anleitung vor dem Start, insbesondere wenn die Y1 nicht erkannt wird.
