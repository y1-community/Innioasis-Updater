Koensayr Y1 install steps

  1. Set Device Model to Y1.
  2. Choose Koensayr in Software.
  3. Choose the listed Y1 release.
  4. Click Install / Restore.
  5. Power off and connect the Y1 only when Updater asks.

Koensayr questions

Can I restore the original Y1 software?

Yes. Select Y1 and Original Software in Updater. See the Y1 stock-firmware page for the complete restore route.

What should I check when it fails?

Check the model, release, cable, platform setup, and whether the player was connected before the prompt. Then use troubleshooting.

Is there a Koensayr Y2 package?

The current catalogue entry is Y1. Do not use it for Y2 unless the project publishes a separate compatible release.

Start with the computer setup

Updater works across Windows, macOS, and Linux after the platform setup is ready. Read the general guide first.
