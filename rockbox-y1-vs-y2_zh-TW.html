Rockbox-Y1 與 Rockbox-Y2

Rockbox-Y1 和 Rockbox-Y2 是為不同播放器所建立的單獨韌體版本。始終將建造與播放器上列印的型號相匹配。

為什麼先選擇模型很重要

儘管兩個版本都運行 Rockbox，但 Innioasis Y1 和 Y2 具有不同的硬體和分區佈局。切勿在 Y2 上閃爍 Y1 ROM 或在 Y1 上閃爍 Y2 ROM。

Innioasis 更新程式 CE 透過在您選擇後立即過濾可用軟體來防止不匹配 Y1 或 Y2 在 裝置型號。 Updater CE 始終直接從社群韌體開發人員的版本下載選定的軟體包（開發人員全權負責在 Updater CE 中列出其版本）。

您需要哪一個指南？

  • Innioasis Y1 — 前往 Rockbox-Y1 輪轂。選擇 Type A（對於附帶 2.0.0+ 版本的玩家）或 Type B（對於較舊的設備），然後選擇 240p 或 360p 版本。
  • Innioasis Y2 — 前往 Rockbox-Y2 輪轂。在 Updater CE 中選擇 Y2 並選擇最新的 Y2 版本。

兩個連接埠共享什麼

兩者都帶來了 Rockbox 基於標籤的音樂資料庫、無縫播放、均衡器、自訂主題以及 100% 離線聆聽播放器。讀 為什麼Rockbox 看看 Rockbox 在工廠軟體上添加了什麼。
