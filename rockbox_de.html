Erhalten Sie Rockbox auf Ihrem Y1 oder Y2

Rockbox ändert die Player-Software und öffnet eine umfassendere Musik-Player-Benutzeroberfläche, Wiedergabesteuerung, Sortierung und Themenoptionen. Die Installation ist geführt, aber Y1 und Y2 sind separate Reisen.

Was sich durch die Installation ändert

Rockbox ist kundenspezifische Software. Ihre Möglichkeit, zur Standardschnittstelle zurückzukehren, wenn das entsprechende Originalsoftwarepaket verfügbar ist, wird dadurch nicht beeinträchtigt. Es kann das Durchsuchen und Anpassen von Musik verbessern, aber Funktionen, Auflösung, Akkulaufzeit und Themenkompatibilität hängen vom Build ab.

Mischen Sie keine Modelle. Wählen Sie Y1 für einen Y1-Spieler und Y2 für einen Y2-Spieler. Ein ähnlich aussehender Release-Name ist kein ausreichender Beweis dafür, dass ein Paket kompatibel ist.

Die freigegebene Updater-Route

  1. Installieren Sie Updater und verbinden Sie nichts, bis Sie dazu aufgefordert werden.
  2. Wählen Sie das auf dem Player aufgedruckte Modell aus Gerätemodell.
  3. Wählen Sie Rockbox In Software.
  4. Wählen Sie eine stabile Version, es sei denn, Sie testen absichtlich einen nächtlichen Build.
  5. Klicken Sie Installieren / Wiederherstellen, und folgen Sie dann der Aufforderung zum Ausschalten und USB-Verbindung.
  6. Trennen Sie die Verbindung erst nach der Erfolgsmeldung.

240p, 360p und Themen

Ältere Rockbox Themensammlungen können für 240p erstellt werden. Y1 Community-Builds verwenden auch 360p-Kompatibilitätsbezeichnungen. Lesen Sie die Versionshinweise und die Theme-Quelle, bevor Sie einen Build auswählen. Ein für eine Auflösung oder Softwarefamilie erstelltes Theme funktioniert möglicherweise nicht für eine andere.

FAQ

Ich habe Rockbox neu installiert und es hat nichts behoben.

Durch die Neuinstallation von Rockbox wird derselbe Build über dieselben Dateien geschrieben, sodass die Dinge, die Rockbox auf dem MicroSD behält, nicht zurückgesetzt werden können. Wenn das Problem eine fehlerhafte Einstellung, ein Thema, eine Wiedergabeliste oder eine Datenbank auf der Karte ist, lässt sich das Problem durch eine Neuinstallation nicht beheben. Der zuverlässige Reset löscht die .rockbox Ordner aus MicroSD – Rockbox erstellt beim nächsten Start einen neuen Ordner.

  1. Schalten Sie den Player vollständig aus und entfernen Sie die MicroSD-Karte oder schließen Sie den Player als USB-Laufwerk an.
  2. Zeigen Sie versteckte Dateien auf Ihrem Computer an, damit der Ordner sichtbar ist. Punktedateien auf Ihrem Computer anzeigenWindows: Öffnen Sie im Datei-Explorer die Sicht Tab und Häkchen Versteckte Gegenstände.macOS: im Finder drücken Cmd+Shift+. um versteckte Dateien umzuschalten.Linux · GNOME-Dateien: drücken Ctrl+H, oder öffnen Sie das Menü und wählen Sie Versteckte Dateien anzeigen.Linux · KDE Dolphin: drücken Ctrl+H, oder verwenden Ansicht → Versteckte Dateien anzeigen.
  3. Löschen Sie die .rockbox Ordner aus dem Stammverzeichnis der Karte.
  4. Legen Sie die Karte erneut ein und starten Sie den Player. Rockbox erstellt den Ordner mit den Standardeinstellungen neu.
  5. Wenden Sie Ihr Design und Ihre Einstellungen erneut an. Tritt das Problem erst nach einem bestimmten Thema wieder auf, ist dieses Thema die Ursache.

Löschen .rockbox deinstalliert Rockbox nicht und berührt Ihre Musik nicht – der Ordner enthält Einstellungen, Themen und Caches und wird automatisch neu erstellt. Wenn Sie Ihre Themes behalten möchten, kopieren Sie den Ordner aus .rockbox bevor Sie ihn löschen, oder benennen Sie den Ordner in um .rockbox-old zuerst.

Warum kann ich den .rockbox-Ordner auf meinem MicroSD nicht sehen?

Ordner, deren Name mit einem Punkt beginnt, werden auf den meisten Computern standardmäßig ausgeblendet. Sie müssen es nicht sehen, um Rockbox zu installieren – Updater verwaltet die Dateien. Wenn Sie eine Fehlerbehebung durchführen und diese löschen möchten, aktivieren Sie zunächst die versteckten Dateien. Punktedateien auf Ihrem Computer anzeigenWindows: Öffnen Sie im Datei-Explorer die Sicht Tab und Häkchen Versteckte Gegenstände.macOS: im Finder drücken Cmd+Shift+. um versteckte Dateien umzuschalten.Linux · GNOME-Dateien: drücken Ctrl+H, oder öffnen Sie das Menü und wählen Sie Versteckte Dateien anzeigen.Linux · KDE Dolphin: drücken Ctrl+H, oder verwenden Ansicht → Versteckte Dateien anzeigen.

Werden durch das Löschen von .rockbox mein Theme und meine Einstellungen zurückgesetzt?

Ja - .rockbox enthält die Einstellungen, das Thema, die Wiedergabelisten und die zwischengespeicherte Datenbank von Rockbox. Durch das Löschen wird Rockbox in einen sauberen Standardzustand zurückversetzt. Sichern Sie den gesamten Ordner (oder benennen Sie ihn um in .rockbox-old) Wenn Sie etwas davon zurückhaben möchten, starten Sie den Player und Rockbox erstellt einen neuen Ordner.
