Método de instalación

SP Flash Tool dentro de Innioasis Actualizador CE

SP Flash Tool no es una descarga independiente y no hay nada que encontrar en la carpeta de la aplicación. Es un método de instalación en Innioasis Updater CE en PC Windows x64 y Linux x86-64 con procesadores Intel o AMD. Elija su firmware de la forma habitual, luego configúrelo Mostrar configuración avanzada > Método de instalación > SP Flash Tool e instalar.

La ruta normal es lo primero.

Elija su firmware, luego elija el motor

Una instalación en Updater CE es siempre el mismo proceso: seleccione su modelo, elija el firmware y la versión, luego ejecute Instalar/Restaurar. El método de instalación solo decide qué motor MediaTek realiza la actualización. Déjalo encendido Automático a menos que tengas una razón para fijarlo y configurarlo en SP Flash Tool cuando lo hagas.

¿Qué computadoras tienen SP Flash Tool

MediaTek publica SP Flash Tool solo para x86-64, por lo que Updater CE lo ofrece en PC x86-64 y en ningún otro lugar. La aplicación en sí se ejecuta en más lugares que el motor.

Windows x64: disponible

Windows 10 u 11 en un procesador Intel o AMD. el SP Flash Tool método de instalación y el SP Flash Tool El botón está ahí.

Linux x86-64: disponible

Una máquina Intel o AMD Linux de 64 bits que ejecuta Updater CE AppImage. Mismo método de instalación, mismo botón.

macOS: no disponible

SP Flash Tool no existe para macOS de ninguna forma. Updater CE se instala y restaura con MTKClient en su lugar, y no existe ningún método o botón de instalación SP Flash Tool. Mantenga la Mac en la ruta guiada o utilice el notas mac.

Linux ARM64: no disponible

Raspberry Pi, placas ARM y ARM64 Linux son ​​la misma historia que macOS: MediaTek no incluye ninguna versión ARM, por lo que Updater CE usa MTKClient allí.

¿No estás seguro de una máquina? Abra Configuración y encienda Mostrar configuración avanzada: si no hay Método de instalación con una opción SP Flash Tool, esa computadora no puede ejecutarlo. En macOS y ARM64 Linux el reproductor aún se instala normalmente, así que use la ruta guiada con Auto y solo muévase a una PC Windows x64 o Linux x86-64 si necesita específicamente SP Flash Tool.

Instale el firmware elegido con SP Flash Tool

  1. Abra Updater CE y seleccione el modelo impreso en su reproductor: Innioasis Y1, Y2, G1, G3, G5, R1 o PR1, o un modelo Timmkoo.
  2. Elija el software que desee, Software original o un proyecto comunitario, luego elija la versión. Esta es la misma lista, el mismo modelo coincidente y las mismas comprobaciones que cualquier otra instalación.
  3. Abierto Configuración y enciende Mostrar configuración avanzada.
  4. encontrar Método de instalación y elige SP Flash Tool en lugar de Automático.
  5. Regrese a la pantalla de instalación y haga clic Instalar / Restaurar.
  6. Apague el reproductor por completo cuando la aplicación lo solicite, luego conecte el cable de datos USB directamente a la computadora cuando se le indique. Utilice un cable de datos, no un cable de sólo carga, y omita los concentradores.
  7. Espere a que Updater CE informe que la instalación finalizó, luego desconecte el cable e inicie el reproductor.

Ese es todo el viaje. Updater CE todavía proporciona el paquete específico del modelo, el agente de descarga MediaTek, las comprobaciones del controlador y el mensaje de conexión; elegir SP Flash Tool solo cambia el motor de abajo.

Mantenga los modelos separados. Un paquete Y1 y un paquete Y2 nunca son intercambiables y un archivo disperso de un modelo no describe el otro. Si Updater CE no ofrece el firmware para el modelo que seleccionó, deténgase y seleccione el paquete listado para ese modelo.

Para qué sirve el botón SP Flash Tool

En una computadora compatible, Updater CE también tiene una SP Flash Tool botón que abre la herramienta de MediaTek para trabajar con él directamente, por ejemplo con un paquete disperso que usted mismo proporcionó. Las instalaciones, actualizaciones y restauraciones de rutina no lo necesitan: el método de instalación hace el mismo trabajo con la coincidencia de modelos, las comprobaciones de controladores y las indicaciones de conexión manejadas por usted.

Si falta el botón, la computadora es uno de los sistemas no compatibles anteriores o el modelo seleccionado utiliza un flujo diferente. Utilice el método de instalación o la ruta guiada en ese caso en lugar de buscar una herramienta binaria.

Cuando SP Flash Tool es el método de instalación correcto

  • Un reproductor que no arranca. El modo de descarga de SP Flash Tool aún puede llegar a un dispositivo cuyo precargador o imagen de inicio esté dañado, que es donde se realiza un cuidadoso trabajo de recuperación.
  • Un flash que se detiene en una PC compatible. Si Auto o MTKClient se detiene parcialmente en una máquina Windows x64 o Linux x86-64, fijar la instalación en SP Flash Tool le da al otro motor un encendido en el mismo paquete.
  • Un paquete de fábrica en el que confía. Versiones de software originales de archivo de firmware combina bien con él, porque restaurar particiones originales es exactamente para lo que está diseñado SP Flash Tool.

Para una actualización ordinaria o una primera instalación, deje Método de instalación en Automático. Elige el motor que se adapta a tu modelo y plataforma, y ​​la aplicación te mantiene en la ruta compatible sin configuraciones adicionales.

Si la instalación no comienza

  1. Confirme que el modelo que seleccionó en Updater CE coincida con el modelo impreso en el reproductor y que el paquete esté listado para él.
  2. Confirme que el reproductor esté completamente apagado antes de conectarlo y conéctelo solo cuando se lo indique la aplicación.
  3. En Windows, instale el controlador MediaTek y reinicie; en Linux, verifique los permisos USB indicados en configuración de la computadora.
  4. Pruebe con un puerto USB diferente directamente en la computadora, sin un concentrador, e inicie Instalar/Restaurar nuevamente.

Todo lo demás pertenece a solución de problemas. Y en macOS o ARM64 Linux, la respuesta no es un botón diferente: mantén el instalación guiada y use SP Flash Tool solo desde una PC Windows x64 o Linux x86-64.
