SP Flash Tool uvnitř Innioasis Updater CE

SP Flash Tool není samostatným stažením a ve složce aplikace není nic k nalezení. Jedná se o metodu instalace v Innioasis Updater CE na Windows x64 a Linux x86-64 PC s procesory Intel nebo AMD. Vyberte firmware běžným způsobem a poté nastavte Zobrazit rozšířená nastavení > Způsob instalace > SP Flash Tool a nainstalovat.

Na prvním místě je normální cesta

Vyberte firmware a poté motor

Instalace v Updater CE je vždy stejná: vyberte svůj model, vyberte firmware a verzi a poté spusťte Install / Restore. Způsob instalace rozhoduje pouze o tom, který MediaTek engine provede flash. Nechte to zapnuté Auto pokud nemáte důvod ji připnout a nastavit ji na SP Flash Tool když to uděláte.

Které počítače mají SP Flash Tool

MediaTek publikuje SP Flash Tool pouze pro x86-64, takže Updater CE jej nabízí na x86-64 PC a nikde jinde. Samotná aplikace běží na více místech než engine.

Windows x64: k dispozici

Windows 10 nebo 11 na procesoru Intel nebo AMD. The SP Flash Tool způsob instalace a SP Flash Tool tlačítko jsou tam oba.

Linux x86-64: k dispozici

64bitový počítač Intel nebo AMD Linux s aplikací Updater CE AppImage. Stejný způsob instalace, stejné tlačítko.

macOS: není k dispozici

SP Flash Tool neexistuje pro macOS v žádné podobě. Updater CE se místo toho nainstaluje a obnoví pomocí MTKClient a neexistuje žádná instalační metoda nebo tlačítko SP Flash Tool. Udržujte Mac na naváděné trase nebo použijte Mac poznámky.

Linux ARM64: není k dispozici

Raspberry Pi, desky ARM a ARM64 Linux jsou stejný příběh jako macOS: MediaTek nedodává sestavení ARM, takže Updater CE tam používá MTKClient.

Nejste si jisti strojem? Otevřete Nastavení a zapněte Zobrazit Pokročilá nastavení: pokud není Metoda instalace s volbou SP Flash Tool jej tento počítač nemůže spustit. Na macOS a ARM64 Linux se přehrávač stále normálně nainstaluje, takže použijte řízenou trasu s Auto a přejděte na Windows x64 nebo Linux x86-64 PC pouze v případě, že konkrétně potřebujete SP Flash Tool.

Nainstalujte vybraný firmware pomocí SP Flash Tool

  1. Otevřete Updater CE a vyberte model vytištěný na vašem přehrávači: Innioasis Y1, Y2, G1, G3, G5, R1 nebo PR1 nebo model Timmkoo.
  2. Vyberte požadovaný software, Původní software nebo komunitní projekt a poté vyberte vydání. Toto je stejný seznam, stejný model a stejné kontroly jako u jakékoli jiné instalace.
  3. Otevřít Nastavení a zapněte Zobrazit Pokročilá nastavení.
  4. Najít Metoda instalace a vybrat si SP Flash Tool místo Auto.
  5. Vraťte se na instalační obrazovku a klikněte Nainstalovat / Obnovit.
  6. Jakmile se aplikace zeptá, zcela vypněte přehrávač a poté na výzvu připojte datový kabel USB přímo k počítači. Použijte datový kabel, nikoli pouze nabíjecí kabel, a přeskočte rozbočovače.
  7. Počkejte, až Updater CE oznámí dokončení instalace, poté odpojte kabel a spusťte přehrávač.

To je celá cesta. Updater CE stále dodává balíček specifický pro model, agenta stahování MediaTek, kontroly ovladačů a výzvu k připojení; volba SP Flash Tool pouze vymění motor pod ním.

Udržujte modely odděleně. Balíček Y1 a balíček Y2 nejsou nikdy zaměnitelné a soubor scatter z jednoho modelu nepopisuje druhý. Pokud Updater CE nenabízí firmware pro model, který jste vybrali, zastavte se a vyberte si balíček uvedený pro daný model.

K čemu slouží tlačítko SP Flash Tool

Na podporovaném počítači má Updater CE také příponu SP Flash Tool tlačítko, které otevře nástroj MediaTek pro přímou práci s ním, například s rozptylovým balíčkem, který jste dodali sami. Rutinní instalace, aktualizace a obnovy to nepotřebují: metoda instalace funguje stejně jako při hledání shody modelu, kontrol ovladačů a výzev k připojení.

Pokud tlačítko chybí, počítač je jedním z nepodporovaných systémů výše nebo váš vybraný model používá jiný postup. V takovém případě použijte metodu instalace nebo řízenou cestu, než abyste hledali binární soubor nástroje.

Když SP Flash Tool je správný způsob instalace

  • Přehrávač, který nenabootuje. Režim stahování SP Flash Tool se stále může dostat k zařízení, jehož preloader nebo spouštěcí obraz je poškozen, což je místo, kde probíhá pečlivá obnova.
  • Blesk, který se na podporovaném počítači zastaví. Pokud se Auto nebo MTKClient zastaví na stroji Windows x64 nebo Linux x86-64, připnutí instalace k SP Flash Tool umožní druhému enginu zapnout stejný balíček.
  • Tovární balíček, kterému důvěřujete. Původní verze softwaru z archiv firmwaru dobře se s ním spáruje, protože obnova diskových oddílů je přesně to, na co je SP Flash Tool stvořeno.

Pro běžnou aktualizaci nebo první instalaci nechte Metoda instalace na Auto. Vybere motor, který vyhovuje vašemu modelu a platformě, a aplikace vás udrží na podporované cestě bez dalších nastavení.

Pokud se instalace nespustí

  1. Potvrďte, že model, který jste vybrali v Updater CE, se shoduje s modelem vytištěným na přehrávači a že balení je pro něj uvedeno.
  2. Před připojením se ujistěte, že je přehrávač zcela vypnutý, a připojte se pouze na výzvu aplikace.
  3. Na Windows nainstalujte ovladač MediaTek a restartujte; dne Linux zkontrolujte oprávnění USB uvedená v nastavení počítače.
  4. Vyzkoušejte jiný port USB přímo na počítači bez rozbočovače a znovu spusťte instalaci / obnovení.

Cokoli dále patří odstraňování problémů. A na macOS nebo ARM64 Linux není odpovědí jiné tlačítko: ponechte řízená instalace a použijte SP Flash Tool pouze z Windows x64 nebo Linux x86-64 PC.
