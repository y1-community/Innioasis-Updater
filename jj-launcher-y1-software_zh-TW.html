JJ Launcher Y1 安裝步驟

  1. 在您的電腦上開啟 Innioasis Updater CE（如果您需要該應用程序， 取得 Updater CE）。套裝 裝置型號 到 Y1.
  2. 選擇 JJ Launcher 在 軟體.
  3. 選擇 Y1 顯示的版本。
  4. 點選 安裝 / 還原.
  5. 僅當 Updater CE 詢問時關閉電源並連接 Y1。

常見問題

我可以在 Y1 上安裝 Y2 條目嗎？

不需要。保持型號和包裝匹配。如果缺少 Y1 條目，請勿強制建立 Y2 檔案。

我可以回到原來的軟體嗎？

是的。在 Updater CE 中選擇 Y1 和原始軟體。請參閱 Y1 恢復頁面.

所有 JJ Launcher 版本在哪裡？

目前版本位於 軟體下載。發行說明位於專案的 發行說明.

電腦設定

一旦相關設定準備就緒，更新程式就可以在 Windows、macOS 和 Linux 上使用。從 平台指南.
