Работает со всеми аудиоплеерами Innioasis и Timmkoo. Установите Innioasis Updater CE на свой компьютер, выберите свою модель и необходимое программное обеспечение, затем следуйте подсказкам.

    Получить Innioasis Обновление CE

    Innioasis Средство обновления CE это приложение, которое устанавливает на ваш плеер официальные обновления и программное обеспечение сообщества. Он сохраняет вашу музыку и настройки и работает на Windows, macOS и Linux.

    Windows

    Загрузите установщик, запустите его, а затем перезагрузите компьютер, когда он завершится.

    Получить драйверыСкачать программу обновления CE

    Если Windows не позволяет вам запустить приложение или не запускает его, откройте «Настройки», нажмите «Конфиденциальность и безопасность» → «Безопасность Windows» → «Управление приложениями и браузером» и отключите Smart App Control. Smart App Control в настоящее время влияет на популярные приложения, такие как Epic Overlay Service (используется Fortnite) — Updater CE безопасен и проверен для использования.     macOS

    Скачать программу обновления CE

    Если Mac блокирует первый запуск приложения, откройте «Системные настройки», выберите «Конфиденциальность и безопасность», прокрутите вниз до раздела «Безопасность» и нажмите Все равно открыть. Вы также можете нажать на приложение в Finder удерживая клавишу Control (или правой кнопкой мыши) и выбрать «Открыть».

    Работает на компьютерах Mac Intel и Apple Silicon с macOS Monterey и более поздних версиях.

    Замечания по настройке Linux

    Вам понадобится плеер, кабель для передачи данных USB, по которому передаются данные (кабель только для зарядки установить невозможно), и несколько минут. Держите кабель подключенным до тех пор, пока программа Updater CE не сообщит, что все готово.

    Выберите свою модель и программное обеспечение

    1. Модель устройства: выберите модель, напечатанную на плеере, Y1 или Y2. Программное обеспечение, созданное для одной модели, не может быть установлено на другую.
    2. Программное обеспечение и версия: выберите оригинальное программное обеспечение, Rockbox, Solar, JJ Launcher, Inniclassic, Y2Player или Koensayr, если оно указано для вашей модели, затем выберите версию. Стабильный — безопасный выбор.
    3. Установить: щелкнуть Установить / Восстановить, полностью выключите плеер и подключайте кабель USB только по запросу Updater CE.
    4. Заканчивать: оставьте плеер и кабель в покое до появления сообщения об успехе, затем отключите и запустите плеер.

    Y1 игрокам, которые поставлялись с оригинальным программным обеспечением до версии 2.0.0, необходимо Устройство Type B. Все остальные сохраняют значение по умолчанию Type A.

    Возврат к оригинальному программному обеспечению

    Пользовательское программное обеспечение является обратимым. В Updater CE выберите свою модель, выберите Заводское ПО, выберите стабильную версию и запустите Установить / Восстановить таким же образом. Руками удалять нечего.

    Windows не запускает приложение? Обходной путь Smart App Control

    SmartScreen Защитника Windows или Smart App Control могут блокировать недавно загруженные приложения сообщества до распространения репутации подписи. Smart App Control в настоящее время влияет на популярные приложения, такие как Epic Overlay Service (используется Fortnite) — Updater CE безопасен и проверен для использования. Отключение Smart App Control позволяет Updater CE открываться и работать в обычном режиме.

    1. Открыть Настройки на вашем ПК с Windows (нажмите Win + I).
    2. Нажмите Конфиденциальность и безопасность на левой боковой панели, затем нажмите Windows Security.
    3. Нажмите Управление приложениями и браузерами.
    4. Под Интеллектуальное управление приложениями, нажмите Настройки смарт-контроля приложений.
    5. Установите переключатель в положение Выключенный чтобы разрешить запуск Updater CE.

    Скачивали через Edge? Если Edge блокирует саму загрузку, нажмите кнопку «Дополнительные параметры» (…) → Держать → Показать больше → Сохранить в любом случае.

    Повторное включение Smart App Control позже: Если вы хотите снова включить Smart App Control, вы можете снова включить его через реестр Windows в разделе HKEY_LOCAL_MACHINE\SYSTEM\CurrentControlSet\Control\CI\Policy установив VerifiedAndReputablePolicyState в адрес 1 (Вкл.) или 2 (Режим оценки) и перезапуск.
