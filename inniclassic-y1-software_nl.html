Inniclassic Y1 install steps

  1. Open Innioasis Updater CE op uw computer (als u de app nodig heeft, Updater CE downloaden). Instellen Apparaatmodel aan Y1.
  2. Kies Inniclassic binnen Software.
  3. Choose the release listed for Y1.
  4. Klik Installeren / Herstellen.
  5. Schakel de Y1 alleen uit en sluit deze alleen aan als Updater CE daarom vraagt.

Veelgestelde vragen

Kan ik de standaard Y1-software herstellen?

Ja. Selecteer Y1 en originele software in Updater CE. De Y1 voorraadsoftwaregids bedekt het retourtraject.

Wat als de installatie mislukt?

Note whether Updater failed before or after detecting the Y1, then check the cable, platform setup, model, and connection timing in probleemoplossing.

Can I use Inniclassic on Y2?

Yes. Inniclassic is available on both models — the same maintained project publishes a Y2 package from the same releases. Select Y2 in Updater CE and install the Y2 build; never flash a Y1 package to a Y2. The Y2-installatiepagina covers it.
