    Windows tidak meluncurkan aplikasi? Cara mematikan Kontrol Aplikasi Cerdas

    Windows Defender SmartScreen atau Smart App Control dapat memblokir aplikasi komunitas yang baru diunduh sebelum reputasi tanda tangan menyebar. Kontrol Aplikasi Cerdas saat ini memengaruhi aplikasi populer seperti Epic Overlay Service (digunakan oleh Fortnite) — Updater CE aman dan terverifikasi untuk digunakan. Mematikan Kontrol Aplikasi Cerdas memungkinkan Updater CE terbuka dan berjalan normal.

    1. Buka Pengaturan di PC Windows Anda (tekan Win + I).
    2. Klik Privasi & keamanan di sidebar kiri, lalu klik Windows Security.
    3. Klik Kontrol aplikasi & browser.
    4. Di bawah Kontrol Aplikasi Cerdas, klik Pengaturan Kontrol Aplikasi Cerdas.
    5. Setel tombol ke Mati untuk mengizinkan Updater CE diluncurkan.

    Diblokir oleh Edge? Jika Microsoft Edge memblokir pengunduhan itu sendiri, klik tombol Opsi lainnya (…) → Simpan → Tampilkan lebih banyak → Tetap pertahankan.

    Mengaktifkan kembali Kontrol Aplikasi Cerdas nanti: Saat Anda ingin mengaktifkan kembali Smart App Control, Anda dapat mengaktifkannya kembali melalui Windows Registry di bawah HKEY_LOCAL_MACHINE\SYSTEM\CurrentControlSet\Control\CI\Policy dengan mengatur VerifiedAndReputablePolicyState untuk 1 (Aktif) atau 2 (Mode Evaluasi) dan memulai ulang.
