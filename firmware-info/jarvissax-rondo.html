Rondo

**A click-wheel firmware for the Innioasis Y1: the music on your card, YouTube Music, YouTube and FM radio, all from the wheel.**

Install · Use · Server · Dashboard · Help · What's new

The Innioasis Y1 is a small music player with an iPod-style click wheel. Underneath, it runs Android 4.2. Rondo is a firmware for it, built from the community's Android 4.2 base: everything else is taken out, and the Y1 starts straight into menus made for the wheel. Play the music on your microSD card, stream YouTube Music and YouTube, and listen to FM radio, all without a touchscreen. You install it with Innioasis Updater CE, the same way as Rockbox or the Y1's original software, and you can always go back.

What it does

Your music, from the card

Copy music onto the microSD card and Rondo sorts it by song, artist and album, using the files' tags. You get covers, lyrics that scroll along with the song, search as you type, and playlists you can make on the Y1 or in your browser. Videos on the card play too, and plugging the Y1 into a computer turns the card into a USB drive.

Lyrics that follow the song

FLAC, MP3, M4A, AAC, OGG, Opus and WAV. Lyrics come from the file's tags or an .lrc file next to it. Nothing on the card ever needs the internet.

YouTube Music and YouTube

With a small server you run yourself, the Y1 streams YouTube Music and YouTube: home, search, artists, albums, playlists, lyrics, Shorts, and video up to 720p. Sign the server in to your YouTube account for your own library, subscriptions and history, or use it without an account.

Streams play as they arrive: neither the Y1 nor the server ever stores audio or video from YouTube. (In the pictures: Kevin MacLeod's music and Blender Studio's open movie Spring, both openly licensed.)

Made for the wheel

Every screen works with the wheel and five buttons. Each wheel pulse is one step, like Rockbox, with an optional buzz and click on every step and acceleration for long lists. Searches, Wi-Fi passwords and playlist names are typed on a keyboard you move through with the wheel or the buttons. Choose a light or dark look, an accent color and a text size, and which entries the main menu shows, in which order.

Settings

FM radio, Bluetooth and Wi-Fi

The Y1's FM radio, with station names, a scan of the whole band, saved stations and a speaker option; wired headphones are the antenna. Bluetooth headphones and speakers, and Wi-Fi networks, are set up from the wheel as well.

A dashboard in your browser

Open Settings › Dashboard on the Y1, then the address it shows on your phone or computer. From there you can upload music, make playlists, control what's playing, change the theme and every setting, manage Wi-Fi, Bluetooth and the radio, and shut down, restart or update the Y1. It runs on the Y1 itself, over your Wi-Fi, and needs no internet.

Updates that keep everything

A new Rondo installs in about a minute, without reinstalling the firmware: from **Settings › Software update over Wi-Fi, with Install** in the dashboard, or over USB from the update page. Your settings, Wi-Fi, server connection, playlists and music stay as they are. The rare release that changes the firmware itself says so, and installs with Innioasis Updater CE instead.

What you need

  • An Innioasis Y1, Type A: one that shipped with software 2.0.0 or later. Not sure which type

    yours is? See Before you start.

  • A computer (macOS, Windows or Linux) with Innioasis Updater CE, and a USB-C cable that

    carries data, for the install.

  • 2.4 GHz Wi-Fi. The Y1 can't see 5 GHz networks.
  • For YouTube Music and YouTube, a Rondo server: a computer at home that stays on (a 64-bit

    Raspberry Pi or a NAS is fine), or a small VPS. Your music card, the radio and Bluetooth work without it.

Getting started

  1. Install Rondo with Innioasis Updater CE: choose the Y1, Type A, then

    Rondo. It takes about 10 minutes, and your microSD card isn't touched.

  2. First start: join Wi-Fi, copy your music onto the card, and

    look through Settings.

  3. Set up a server if you want YouTube Music and YouTube. About 15 minutes

    with Docker.

  4. Learn the controls, and open the dashboard on

    your phone.

Your own server

The Y1 is too old to talk to YouTube directly: Android 4.2 can't handle today's YouTube pages, video formats or encryption. So a small server does that part. You run it with Docker at home or on a VPS, set it up from its admin page in the browser, connect your Y1 with a six-digit code, and optionally sign it in to your YouTube account. It keeps yt-dlp up to date by itself, its admin page tells you when something needs attention, and a new version of the server installs with one click there. One server serves one Y1. See Setting up a Rondo server.

How it works

 Innioasis Y1                 your Rondo server                YouTube
┌──────────────┐   Wi-Fi    ┌───────────────────┐   internet  ┌─────────┐
│ Rondo        │ ─────────▶ │ browse + stream   │ ──────────▶ │         │
│ music on SD  │ ◀───────── │ (Node, yt-dlp)    │ ◀────────── │         │
│ FM, Bluetooth│   audio,   └───────────────────┘             └─────────┘
└──────────────┘   video

The server browses YouTube for the Y1 with youtubei.js, finds the streams with yt-dlp, and passes audio and video through to the Y1 in a form it can play. The Y1 only ever talks to your server.

The project

FolderWhat's in it
app/Rondo itself, the Android app at the heart of the firmware (Kotlin, classic Views, ExoPlayer 2)
firmware/The script that builds the firmware (rom.zip) from the community's base ROM
server/The Rondo server (Node 22, TypeScript, Fastify)
infra/Docker and Caddy files for running the server
web-updater/The update page (WebUSB), published on GitHub Pages
tools/Mock servers for UI work, the boot screen generator, the version script
docs/Guides, plus notes on the Y1's internals and API references

Every release is built the same way: the signed app goes up, and GitHub Actions builds the firmware from it and publishes the update page. To build it yourself, start with Building Rondo.
