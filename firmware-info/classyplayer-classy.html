Classy

Classy is an iPod classic-style launcher, music player and firmware for the Innioasis Y2. It brings the click wheel menus, Cover Flow, synced lyrics and Now Playing of the iPod classic, and adds what the iPod never had: Play On to a Sonos or smart TV, Bluetooth in the car, Wi-Fi and FM radio.

Website, with screenshots and videos of each feature: classyplayer.github.io/Classy

MusicNow PlayingCover Flow

The album covers in the screenshots are from Creative Commons albums, for example Edge of Summer by Tenth Cloud (CC BY-SA 4.0; photo Anatoliy Laptev, artwork Anna Riet). The credits and the licence of each album are at the end of site/index.html, in Music and covers in the screenshots.

Features

  • The iPod interface: Classic Light and Classic Dark (Auto changes at sunrise and sunset), menus that slide, Cover Flow, a letter jump in long lists, and Now Playing with synced and romanised lyrics.
  • Library: music on the internal storage and the microSD card, by artist, album, genre, composer, folder and playlist. Favorites, Recently Played, Top 25 Most Played and Last.fm scrobbles.
  • More than music: videos, audiobooks with bookmarks, podcasts, Music Quiz and iPod click wheel games.
  • Wireless: Play On (Sonos, DLNA, Google Cast), Bluetooth headphones and car audio, Jellyfin sync, upload from a browser, and updates over Wi-Fi.
  • FM radio with saved stations, also with the screen off. Battery history of the last 24 hours and 10 days.

File formats, folders, covers, lyrics files, playlists and the known limits: Files and limits on the website.

Install

  1. Open the Classy page on innioasis.app and install Innioasis Updater CE.
  2. In Updater CE, choose Y2 and Inniclassic (the old name of Classy). Select a release and click Install / Restore.
  3. Power off the Y2. Connect it only when the updater asks. Keep the cable in until the update is done.

[!WARNING] A full flash erases the internal storage. First copy your files from it to a computer. Music on the microSD card stays.

To install a downloaded firmware file or only the app (APK): Install on the website.

Updates

Settings → General → System Update installs new releases over Wi-Fi. In it, Update Channel chooses Stable or Beta (the releases marked Pre-release). All releases and their notes: Releases.

Build from source

You need JDK 17 and the Android SDK:

./gradlew assembleDebug testDebugUnitTest
  • The Last.fm API keys are not in the repository. Without them, only the upload to Last.fm is off. To add them, make an API account at last.fm/api/account/create and put lastfm.api.key=… and lastfm.api.secret=… in local.properties.
  • A debug build has a different signing key from the releases, so it does not install over a release. To test it on a player, make a firmware with it on Linux (the script uses sudo and loop mounts): scripts/build-rom.sh y2 --launcher-apk app/build/outputs/apk/debug/app-debug.apk rom_y2.zip.
  • Bugs and ideas: issues. Pull requests: one change each, with a Conventional Commits title. Add each new text that the user sees to all files in app/src/main/assets/languages/ (CI runs python3 scripts/check_translations.py --strict).
  • Maintainers publish releases as described in RELEASING.md.
