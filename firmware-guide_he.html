    באיזה כלי כדאי להשתמש?

    Innioasis Updater לספירה היא הדרך הבטוחה ביותר לעדכן את הנגן שלך. זה שומר את המוזיקה, הסרטונים וההתאמות שלך עם Bluetooth. זה אומר לך מתי העדכונים מוכנים. זה פועל על Windows, macOS ו- Linux. ה-Innioasis Universal Flash Tool מנגב את הנגן שלך ועובד על פחות מחשבים.

    פתח את ההשוואה המלאה

    Windows לא יפעיל את האפליקציה? כיצד לכבות את בקרת האפליקציה החכמה

    Windows Defender SmartScreen או Smart App Control יכולים לחסום יישומי קהילה שהורדו לאחרונה לפני שהמוניטין החתימה יתפשט. בקרת אפליקציות חכמה משפיעה כעת על יישומים פופולריים כמו שירות ה-Epic Overlay (בשימוש על ידי Fortnite) - Updater CE בטוח ומאומת לשימוש. כיבוי Smart App Control מאפשר ל-Update CE להיפתח ולהפעיל כרגיל.

    1. פתוח הגדרות במחשב Windows שלך (לחץ על Win + I).
    2. לחץ פרטיות ואבטחה בסרגל הצד השמאלי ולאחר מכן לחץ Windows Security.
    3. לחץ שליטה באפליקציה ובדפדפן.
    4. מתחת בקרת אפליקציה חכמה, לחץ הגדרות בקרת אפליקציה חכמה.
    5. הגדר את המתג למצב כבוי כדי לאפשר את הפעלת Updater CE.

    חסום על ידי Edge? אם Microsoft Edge חוסם את ההורדה עצמה, לחץ על כפתור אפשרויות נוספות (…) → שמור → הצג עוד → שמור בכל מקרה.

    הפעלה מחדש של בקרת אפליקציות חכמה מאוחר יותר: כאשר אתה רוצה להפעיל מחדש את בקרת האפליקציות החכמה, אתה יכול להפעיל אותה מחדש דרך הרישום של Windows תחת HKEY_LOCAL_MACHINE\SYSTEM\CurrentControlSet\Control\CI\Policy לפי הגדרה VerifiedAndReputablePolicyState ל 1 (מופעל) או 2 (מצב הערכה) והפעלה מחדש.
