Tillgängliga operativsystem för Innioasis Y2

Välj vad du vill köra på din Y2:

Reborn (Y2Linux)

Native inbäddade Linux OS som kombinerar Buildroot, LVGL, PipeWire och MPD. Erbjuder 3-sekunders starttider, äkta återkopplingsfixar för Bluetooth-hörlurar och uppspelning utan mellanrum.

Y2Reborn Guide →

Rockbox för Y2

Den ultimata audiofila firmware portad till Innioasis Y2. Parametrisk utjämning, anpassade typsnitt, korsmatning och omfattande stöd för pluginbibliotek.

Y2 Rockbox Guide →

Solar för Y2

Modernt, flytande Flutter-baserat musikspelaregränssnitt för Y2. Innehåller rika visualiserare, stor albumomslagspresentation och gestnavigering.

Solar Y2 Guide →

Y2Player

Lätt gemenskapsljudspelare gjord för Y2 hårdvara med enkel mappsökning och snabb indexskanning.

Y2Player Guide →

Originalprogramvara (fabriksåterställning)

Officiell firmware-bild (rom_y2.zip) för att återställa Innioasis Y2 till det ursprungliga fabriksskicket, komplett med Themes Gallery-skalstöd.

Installera firmware på din Innioasis Y2

Updater CE tar tag i rätt filer och kontrollerar drivrutinen innan den blinkar:

  1. Starta Innioasis Updater CE: Tillgänglig på macOS, Linux och Windows.
  2. Set modell: Välj Y2 i menyn Enhetsmodell.
  3. Välj operativsystem: Välj Reborn, Rockbox, Solar eller originalprogramvara.
  4. Flash säkert: Följ anvisningarna på skärmen för att ansluta din enhet över USB för en ren, verifierad blixt.
