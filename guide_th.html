เริ่มต้นใช้งาน Innioasis Updater CE

ใช้งานได้กับเครื่องเล่นเสียง Innioasis และ Timmkoo ทั้งหมด ติดตั้ง Innioasis Updater CE บนคอมพิวเตอร์ของคุณ เลือกรุ่นและซอฟต์แวร์ที่คุณต้องการ จากนั้นปฏิบัติตามคำแนะนำ

    รับ Updater CEกวดวิชาเขียนเต็มรูปแบบ

    รับ Innioasis Updater CE

    Innioasis ตัวอัพเดต CE เป็นแอปที่ติดตั้งการอัปเดตอย่างเป็นทางการและซอฟต์แวร์ชุมชนบนเครื่องเล่นของคุณ มันเก็บเพลงและการตั้งค่าของคุณไว้ และทำงานบน Windows, macOS และ Linux

    หน้าต่าง

    ดาวน์โหลดตัวติดตั้ง รัน จากนั้นรีสตาร์ทพีซีของคุณเมื่อเสร็จสิ้น

    รับไดรเวอร์ดาวน์โหลดตัวอัพเดต CE

    If Windows stops you from running the app or won't launch it, please open Settings, click Privacy & security → Windows Security → App & browser control, and turn Smart App Control off. Smart App Control currently impacts popular applications like the Epic Overlay Service (used by Fortnite) — Updater CE is safe and verified to use. Windows จะไม่เปิดแอปใช่ไหม ช่วย

    รีสตาร์ทพีซีของคุณหลังการติดตั้ง ระบบช่วยเหลือผู้ขับขี่อยู่ใน บันทึกการตั้งค่า Windows.

    ระบบปฏิบัติการ macOS

    ดาวน์โหลดตัวอัพเดต CE

    If your Mac stops you from running the app for the first time, please open System Settings, click Privacy & Security, scroll down to Security and click เปิดยังไงก็ได้. You can also Control-click (or right-click) the app in Finder and choose Open.

    ใช้งานได้บน Intel และ Apple Silicon Mac ที่มี macOS Monterey และใหม่กว่า

    ลินุกซ์

    ดาวน์โหลด AppImage สำหรับระบบ Intel และ AMD ทำให้สามารถปฏิบัติการได้ และเปิดใช้งาน

    ดาวน์โหลด AppImage สำหรับ Intel/AMD

    บันทึกการตั้งค่า Linux

    คุณต้องมีเครื่องเล่น สายเคเบิลข้อมูล USB ที่รองรับข้อมูล (ไม่สามารถติดตั้งสายเคเบิลแบบชาร์จอย่างเดียวได้) และใช้เวลาสักครู่ เชื่อมต่อสายเคเบิลไว้จนกว่า Updater CE จะแจ้งว่าเสร็จสิ้น

    เลือกรุ่นและซอฟต์แวร์ของคุณ

    1. รุ่นอุปกรณ์: เลือกรุ่นที่พิมพ์บนเครื่องเล่น Y1 หรือ Y2. ซอฟต์แวร์ที่สร้างขึ้นสำหรับรุ่นหนึ่งไม่สามารถติดตั้งบนอีกรุ่นได้
    2. ซอฟต์แวร์และรุ่น: เลือกซอฟต์แวร์ต้นฉบับ, Rockbox, Solar, JJ Launcher, Inniclassic, Y2Player หรือ Koensayr เมื่ออยู่ในรายการสำหรับรุ่นของคุณ จากนั้นเลือกรุ่น ความมั่นคงคือทางเลือกที่ปลอดภัย
    3. ติดตั้ง: คลิก ติดตั้ง / คืนค่าปิดเครื่องเล่นจนสุด และเชื่อมต่อสายเคเบิล USB เมื่อ Updater CE ถามเท่านั้น
    4. เสร็จ: ปล่อยให้เครื่องเล่นและสายเคเบิลอยู่ตามลำพังจนกระทั่งข้อความแสดงความสำเร็จ จากนั้นถอดการเชื่อมต่อและเริ่มการทำงานของเครื่องเล่น

    Y1 ผู้เล่นที่จัดส่งมาพร้อมกับซอฟต์แวร์ต้นฉบับก่อนความต้องการ 2.0.0 อุปกรณ์ Type B. คนอื่นๆ คงค่าเริ่มต้น Type A ไว้

    กลับไปที่ซอฟต์แวร์ดั้งเดิม

    ซอฟต์แวร์ที่กำหนดเองสามารถย้อนกลับได้ ใน Updater CE เลือกรุ่นของคุณ เลือก ซอฟต์แวร์ดั้งเดิมเลือกรุ่นเสถียรแล้วรัน ติดตั้ง / คืนค่า แบบเดียวกัน ไม่มีอะไรจะลบด้วยมือ

    คู่มือการคืนค่า Y1คู่มือการคืนค่า Y2

    หากแฟลชหยุดก่อนข้อความ USB ให้ตรวจสอบสายเคเบิล การตั้งค่าแพลตฟอร์ม และรุ่นก่อน ดู การแก้ไขปัญหา สำหรับการแก้ไข คำแนะนำการกู้คืน Y1 และ Y2 สำหรับความผิดปกติของระบบไฟฟ้าและล้อ และ SP Flash Tool เพื่อการฟื้นฟูขั้นสูง

    Windows won't launch the app? Smart App Control workaround

    Windows Defender SmartScreen หรือ Smart App Control สามารถบล็อกแอปพลิเคชันชุมชนที่ดาวน์โหลดใหม่ก่อนที่จะเผยแพร่ชื่อเสียงของลายเซ็น ขณะนี้การควบคุมแอปอัจฉริยะกำลังส่งผลกระทบต่อแอปพลิเคชันยอดนิยม เช่น Epic Overlay Service (ใช้โดย Fortnite) — Updater CE ปลอดภัยและตรวจสอบแล้วว่าใช้งานได้ การปิดการควบคุมแอปอัจฉริยะทำให้ Updater CE สามารถเปิดและทำงานได้ตามปกติ

    1. เปิด การตั้งค่า on your Windows PC (press Win + I).
    2. คลิก Privacy & security in the left sidebar, then click Windows Security.
    3. คลิก App & browser control.
    4. ภายใต้ Smart App Control, click Smart App Control settings.
    5. Set the toggle to ปิด to allow Updater CE to launch.

    Downloaded via Edge? If Edge blocks the download itself, click the More options button (…) → Keep → Show more → Keep anyway.

    Re-enabling Smart App Control later: When you want to turn Smart App Control back on, you can re-enable it via the Windows Registry under HKEY_LOCAL_MACHINE\SYSTEM\CurrentControlSet\Control\CI\Policy by setting VerifiedAndReputablePolicyState ถึง 1 (On) or 2 (Evaluation Mode) and restarting.
