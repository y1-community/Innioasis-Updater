Rockbox för Y2 (Rockbox-Y2)

Rockbox-Y2 (även kallad “Rockbox för Y2”) är den dedikerade community Rockbox firmware-porten för Innioasis Y2. Den använder sitt eget ROM-paket (rom_y2.zip) och installeras direkt via Innioasis Updater CE.

Byggd speciellt för Innioasis Y2

I Innioasis Updater CE är denna firmware listad som Rockbox när Y2 är valt. Dess utgåvor publiceras av spycemagic/y2-rockbox projekt med paketnamnet rom_y2.zip.

Installera aldrig ett Y1 firmwarepaket på en Y2. Väljer Y2 i Updater filtrerar CE automatiskt versionslistan till endast Y2-kompatibla versioner.

Vad Rockbox-Y2 erbjuder

  • Taggbaserat musikbibliotek — bläddra bland album, artister och genrer från dina ljudfiltaggar, eller bläddra direkt i mappar.
  • Uppspelningskontroller — gapfri uppspelning, crossfade, ReplayGain och equalizerinställningar.
  • Anpassade teman – installera teman som är kompatibla med din Rockbox-Y2 build (Y2 temaguide).
  • 100 % offline — spelar upp lokala filer från ditt MicroSD-kort utan konton eller prenumerationer.
  • Enkel fabriksåterställning — gå tillbaka till Y2 originalprogramvara när som helst i Updater CE.

Att välja en Rockbox-Y2 release

  • Välj alltid Y2 i Enhetsmodell först.
  • Välj den senaste versionen om du inte testar en specifik version.
  • Läs Rockbox-Y2 release notes för att se vad som förändrades i varje byggnad.

Direktnedladdningar från communityutvecklarna

Innioasis Updater CE laddar alltid ner firmware-paket direkt från community-firmware-utvecklarna (spycemagic/y2-rockbox), och dessa utvecklare är ensamma ansvariga för att lista sina programvaruversioner i Updater CE.

Du kan låta Updater CE ladda ner och flasha rom_y2.zip automatiskt, eller ladda ner paketet från vår Rockbox-Y2 nedladdningssida och Rockbox ROM nedladdningssida.

Hur man installerar Rockbox-Y2

  1. Öppna Innioasis Updater CE och ställ in Enhetsmodell till Y2.
  2. Välj Rockbox i Programvara.
  3. Välj en Y2 release från listan.
  4. Klicka Installera / Återställ så Updater CE laddar ner paketet direkt från utvecklaren.
  5. Stäng av Y2 helt och anslut den med en USB datakabel när Updater CE frågar.
  6. Vänta på meddelandet om slutförandet, koppla sedan ur och slå på din Y2.

För den fullständiga steg-för-steg-genomgången, läs Rockbox-Y2 handledning.

Återställer den ursprungliga programvaran Y2

För att gå tillbaka till fabriksfast programvara, välj Y2 och Originalprogramvara i Updater CE, välj en stabil version och klicka Installera / Återställ. Se den återställningsguide och Y2 Sida för originalprogramvara.

Vanliga frågor

Var hämtar Updater CE Rockbox-Y2 från?

Updater CE laddar alltid ner firmware-paket direkt från community-firmware-utvecklarnas egna releaser (spycemagic/y2-rockbox). Utvecklarna är ensamma ansvariga för att lista sina programvaruversioner i Updater CE.

Varför heter paketet rom_y2.zip?

Utvecklaren namnger Y2 firmware-arkivet rom_y2.zip så det kan inte förväxlas med Y1 rom.zip.

Fungerar Y1 teman på Y2?

Inte alltid. Kontrollera versionskommentarerna för din Y2-byggnad och se Rockbox-Y2 temaguide.
