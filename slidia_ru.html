Что такое Слидия?

📋 Система манифеста

Slidia предоставляет комплексную систему XML-манифестов, в которой каталогизированы все доступные пакеты прошивки, темы и инструменты для Y1 устройств. Такой централизованный подход упрощает обнаружение ресурсов и управление ими.

🔗 Интеграция репозитория

Подключается к репозиториям проектов, чтобы вы могли получать последние версии встроенного ПО, обновления и материалы сообщества.

📱 Совместимость устройств

Создано специально для устройств Y1 с полной поддержкой типов и моделей устройств, обеспечивая совместимость со всеми вариантами Y1.

⚡ Оптимизирована производительность

Высокопроизводительное обнаружение пакетов и управление ими с интеллектуальным кэшированием и ограничением скорости для оптимального потока обновлений.

🌍 Кроссплатформенность

Работает на Windows, macOS и Linux.

🛠️ Удобство для разработчиков

Чистые API и хорошо документированная структура позволяют разработчикам легко расширять и интегрировать свои собственные инструменты и приложения.

🚀 Получите Innioasis средство обновления

Загрузите настольное приложение для вашей системы

🪟 Установка Windows

Загрузите установщик Windows и следуйте инструкциям по установке. После установки вам необходимо установить драйверы MTK для правильной связи устройства.

🍎 Установка macOS

Скопируйте и вставьте эту команду в Терминал и нажмите Enter:

/bin/bash -c "$(curl -fsSL https://raw.githubusercontent.com/team-slide/Innioasis-Updater/main/run_mac.sh)"

Это автоматически настроит все, что вам нужно!

После первого запуска вы можете использовать ту же команду еще раз, чтобы запустить приложение для дальнейшего использования.

Примечание: Это временная предварительная версия. Скоро появится приложение-установщик, в котором вам не понадобится окно терминала.

🐧 Установка Linux

Для наилучшего опыта рекомендуется использовать Ubuntu, но другие дистрибутивы также должны работать.

Запустите эту однострочную команду установки в своем терминале:

curl -sL https://github.com/y1-community/Innioasis-Updater/releases/latest/download/run_linux.sh | bash

Для получения подробной информации о зависимостях и устранения неполадок откройте полное руководство.

🖥️ ChromeOS/FydeOS

Вы МОЖЕТЕ запустить Innioasis Updater в режиме Linux, но мы не тестировали эту конфигурацию. Следуйте инструкциям Linux на новой вкладке и попробуйте запустить его в своей среде Linux.

Примечание. Это экспериментальный вариант, который может работать не так, как ожидалось.

🪟 Windows ARM64

Для пользователей Windows ARM64 более продвинутые пользователи могут запустить версию Linux, используя Python, Libusb, инструменты платформы Android, USBIPD-win и WSLg. Рекомендуется Ubuntu.
