📋 手動インストール手順

⚠️重要: テーマをダウンロードしたら、Y1 デバイスに手動でコピーする必要があります。ブラウザはデバイスのファイル システムに直接アクセスできません。

🎯 Y1 テーマの場合:

  1. 上のボタンを使用して、選択した Y1 テーマをダウンロードします
  2. ダウンロードした ZIP ファイルを一時フォルダーに解凍します。
  3. USB 経由で Y1 デバイスを接続し、USB ストレージ モードを有効にします
  4. ファイルマネージャーで Y1 デバイスに移動します
  5. という名前のフォルダーを作成します Themes Y1 デバイスのルート (存在しない場合)
  6. テーマごとに、テーマ フォルダーを次の場所にコピーします。 Themes/ Y1 デバイス上で
  7. 各テーマは独自のサブフォルダーに存在する必要があります。 Themes/ThemeName/
  8. テーマ ファイルは、テーマのサブフォルダー内に直接配置する必要があります (より深くネストされてはなりません)。
Y1 デバイス/ ├── .rockbox/ ├── テーマ/ │ ├── テーマ 1/ │ │ §── テーマ.wps │ │ ├── テーマ.sbs │ │ └── ... │ §── テーマ 2/ │ │ §── テーマ．

🎨 Rockbox 360p テーマの場合:

  1. 上のボタンを使用して、選択した Rockbox テーマをダウンロードします
  2. ダウンロードした ZIP ファイルを一時フォルダーに解凍します。
  3. USB 経由で Y1 デバイスを接続し、USB ストレージ モードを有効にします
  4. ファイルマネージャーで Y1 デバイスに移動します
  5. を見つけてください .rockbox Y1 デバイス上のフォルダー
  6. テーマごとに、テーマの .rockbox フォルダ
  7. テーマからすべてのファイルをコピーします .rockbox フォルダーを Y1 に直接コピーします .rockbox フォルダ
  8. プロンプトが表示されたら、既存のファイルを上書きします (これはテーマのインストールでは正常です)
Y1 Device/ ├── .rockbox/ │ ├── テーマ/ │ §── fonts/ │ ├── wps/ │ ├── (テーマファイルはここにマージされます) │ └── ... └── ...
💡 プロのヒント: 複数のテーマを選択して、一度にすべてダウンロードできます。各テーマは、ダウンロードした ZIP ファイル内の独自のフォルダーに格納されます。

🔄 インストール後:

  1. Y1 デバイスをコンピュータから安全に取り出します
  2. USBケーブルを外します
  3. Y1 デバイスで、次の場所に移動します。 設定→テーマ
  4. 新しくインストールしたテーマをリストから選択します
  5. 新しいテーマをお楽しみください!

  2. Rockbox テーマの場合: 上の Rockbox フォルダーをリセット」ボタンを使用して、360p 以外のテーマをすべて削除します
