Innioasis Y2 - Native Linux & Reborn UI

Why install Reborn (Y2Linux) on your Innioasis Y2?

Built by SchulzCode, Reborn (Y2Linux / Y2Reborn) brings a clean, responsive Debian-based Linux foundation and purpose-built clickwheel interface to the Innioasis Y2. It succeeds the earlier Y2Player project and solves long-standing Y2 Bluetooth headphone and library navigation quirks.

Install Reborn (Y2Linux) on Y2 Browse Y2Reborn Releases Wi-Fi & Bluetooth Setup Guide

What makes Y2Reborn stand out on the Y2

Reliable Bluetooth headphones

Community members on r/innioasis report that Y2Reborn resolves pairing and playback dropouts with modern Bluetooth headphones and earbuds once the Wi-Fi and Bluetooth firmware package is enabled.

Fast clickwheel navigation

Designed from the ground up around the Y2 clickwheel and physical buttons, Y2Reborn provides instant menu response, fast alphabetical scrubbing, and smooth library scrolling.

Real Debian Linux under the hood

Powered by SchulzCode/Y2Linux and SchulzCode/Y2Reborn, giving you a full Linux environment with modern ALSA audio drivers and community updates.

Get started with Y2Reborn

Step 1

Instal dengan Pembaruan CE

Open Innioasis Updater CE, choose Y2, select Reborn (Y2Linux), and click Pasang / Pulihkan.

Step 2

Enable Wi-Fi and Bluetooth

Baca Wi-Fi & Bluetooth setup guide to complete initial pairing for headphones and network sync.

Safe Rollback

Return to Original Software anytime

If you ever wish to return to factory stock, Updater CE can restore your Y2 back to Original Software at any time.
