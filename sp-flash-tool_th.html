วิธีการติดตั้ง

SP Flash Tool ภายใน Innioasis Updater CE

SP Flash Tool ไม่ใช่การดาวน์โหลดแยกต่างหาก และไม่มีอะไรให้ค้นหาในโฟลเดอร์แอป เป็นวิธีการติดตั้งใน Innioasis Updater CE บนพีซี Windows x64 และ Linux x86-64 ที่ใช้โปรเซสเซอร์ Intel หรือ AMD เลือกเฟิร์มแวร์ของคุณตามปกติ จากนั้นตั้งค่า แสดงการตั้งค่าขั้นสูง > วิธีการติดตั้ง > SP Flash Tool และติดตั้ง

รับ Updater CE และติดตั้งดาวน์โหลดเฟิร์มแวร์การแก้ไขปัญหา

เส้นทางปกติมาก่อน

เลือกเฟิร์มแวร์ของคุณ จากนั้นเลือกเครื่องยนต์

การติดตั้งใน Updater CE จะเป็นเส้นทางเดียวกันเสมอ: เลือกรุ่นของคุณ เลือกเฟิร์มแวร์และรีลีส จากนั้นเรียกใช้การติดตั้ง / กู้คืน วิธีการติดตั้งจะตัดสินว่าเครื่องยนต์ MediaTek ใดทำหน้าที่แฟลชเท่านั้น ทิ้งมันไว้ อัตโนมัติ เว้นแต่คุณจะมีเหตุผลที่จะปักหมุดและตั้งค่าเป็น SP Flash Tool เมื่อคุณทำ

คอมพิวเตอร์เครื่องใดมี SP Flash Tool

MediaTek เผยแพร่ SP Flash Tool สำหรับ x86-64 เท่านั้น ดังนั้น Updater CE จึงนำเสนอบนพีซี x86-64 และไม่มีที่อื่นอีก ตัวแอปเองทำงานในที่ต่างๆ มากกว่าที่เครื่องยนต์ทำงาน

Windows x64: พร้อมใช้งาน

Windows 10 หรือ 11 บนโปรเซสเซอร์ Intel หรือ AMD ที่ SP Flash Tool วิธีการติดตั้งและ SP Flash Tool ปุ่มก็มีทั้งคู่

Linux x86-64: พร้อมใช้งาน

เครื่อง Intel หรือ AMD Linux 64 บิตที่ใช้งาน Updater CE AppImage วิธีการติดตั้งเดียวกัน ปุ่มเดียวกัน

macOS: ไม่พร้อมใช้งาน

SP Flash Tool ไม่มีอยู่สำหรับ macOS ในรูปแบบใด ๆ Updater CE จะติดตั้งและกู้คืนด้วย MTKClient แทน และไม่มีวิธีการหรือปุ่มติดตั้ง SP Flash Tool ให้ Mac อยู่ในเส้นทางที่แนะนำ หรือใช้ แมคโน๊ต.

Linux ARM64: ไม่พร้อมใช้งาน

Raspberry Pi, บอร์ด ARM และ ARM64 Linux เป็นเรื่องเดียวกันกับ macOS: MediaTek ไม่มีการสร้าง ARM ดังนั้น Updater CE จึงใช้ MTKClient ที่นั่น

ไม่แน่ใจเกี่ยวกับเครื่อง? เปิดการตั้งค่าแล้วเปิด แสดงการตั้งค่าขั้นสูง: ถ้าไม่มี วิธีการติดตั้ง ด้วยตัวเลือก SP Flash Tool คอมพิวเตอร์เครื่องนั้นไม่สามารถเรียกใช้ได้ บน macOS และ ARM64 Linux เครื่องเล่นยังคงติดตั้งตามปกติ ดังนั้นให้ใช้เส้นทางที่แนะนำด้วยอัตโนมัติและย้ายไปที่พีซี Windows x64 หรือ Linux x86-64 เท่านั้น หากคุณต้องการ SP Flash Tool โดยเฉพาะ

ติดตั้งเฟิร์มแวร์ที่คุณเลือกด้วย SP Flash Tool

  1. เปิด Updater CE และเลือกรุ่นที่พิมพ์อยู่บนเครื่องเล่นของคุณ: Innioasis Y1, Y2, G1, G3, G5, R1 หรือ PR1 หรือรุ่น Timmkoo
  2. เลือกซอฟต์แวร์ที่คุณต้องการ ซอฟต์แวร์ดั้งเดิม หรือโครงการชุมชน จากนั้นเลือกรุ่น นี่คือรายการเดียวกัน รุ่นเดียวกันที่ตรงกัน และการตรวจสอบเดียวกันกับการติดตั้งอื่นๆ
  3. เปิด การตั้งค่า และเปิดเครื่อง แสดงการตั้งค่าขั้นสูง.
  4. ค้นหา วิธีการติดตั้ง และเลือก SP Flash Tool แทนอัตโนมัติ
  5. กลับไปที่หน้าจอการติดตั้งแล้วคลิก ติดตั้ง / คืนค่า.
  6. ปิดเครื่องเล่นโดยสมบูรณ์เมื่อแอพถาม จากนั้นเชื่อมต่อสายเคเบิลข้อมูล USB เข้ากับคอมพิวเตอร์โดยตรงเมื่อได้รับแจ้ง ใช้สายเคเบิลข้อมูล ไม่ใช่สายเคเบิลแบบชาร์จอย่างเดียว และใช้ฮับแบบข้าม
  7. รอให้ Updater CE รายงานว่าการติดตั้งเสร็จสิ้น จากนั้นถอดสายเคเบิลออกและเริ่มเครื่องเล่น

นั่นคือการเดินทางทั้งหมด Updater CE ยังคงจัดหาแพ็คเกจเฉพาะรุ่น เอเจนต์การดาวน์โหลด MediaTek การตรวจสอบไดรเวอร์ และพร้อมท์การเชื่อมต่อ การเลือก SP Flash Tool จะสลับเฉพาะเครื่องยนต์ที่อยู่ด้านล่างเท่านั้น

แยกโมเดลออกจากกัน แพ็คเกจ Y1 และแพ็คเกจ Y2 ไม่สามารถใช้แทนกันได้ และไฟล์กระจายจากรุ่นหนึ่งไม่ได้อธิบายอีกรุ่นหนึ่ง หาก Updater CE ไม่มีเฟิร์มแวร์สำหรับรุ่นที่คุณเลือก ให้หยุดและเลือกแพ็คเกจที่แสดงสำหรับรุ่นนั้นแทน

ปุ่ม SP Flash Tool มีไว้เพื่ออะไร

บนคอมพิวเตอร์ที่รองรับ Updater CE ยังมี SP Flash Tool ปุ่มที่เปิดเครื่องมือของ MediaTek เพื่อใช้งานโดยตรง เช่น กับแพ็คเกจกระจายที่คุณจัดเตรียมเอง ไม่จำเป็นต้องติดตั้ง อัปเดต และกู้คืนข้อมูลตามปกติ: วิธีการติดตั้งจะทำงานเดียวกันกับการจับคู่รุ่น การตรวจสอบไดรเวอร์ และพร้อมท์การเชื่อมต่อที่จัดการสำหรับคุณ

หากไม่มีปุ่มดังกล่าว แสดงว่าคอมพิวเตอร์เป็นหนึ่งในระบบที่ไม่รองรับด้านบน หรือรุ่นที่คุณเลือกใช้ขั้นตอนอื่น ใช้วิธีการติดตั้งหรือเส้นทางที่แนะนำในกรณีนั้น แทนที่จะมองหาไบนารี่ของเครื่องมือ

เมื่อ SP Flash Tool เป็นวิธีการติดตั้งที่ถูกต้อง

  • ผู้เล่นที่ไม่ยอมบู๊ต โหมดดาวน์โหลดของ SP Flash Tool ยังคงสามารถเข้าถึงอุปกรณ์ที่ตัวโหลดล่วงหน้าหรืออิมเมจสำหรับบูตเสียหาย ซึ่งเป็นจุดที่ต้องทำการกู้คืนอย่างระมัดระวัง
  • แฟลชที่ค้างบนพีซีที่รองรับ หากอัตโนมัติหรือ MTKClient หยุดกลางคันบนเครื่อง Windows x64 หรือ Linux x86-64 การปักหมุดการติดตั้งไว้ที่ SP Flash Tool จะทำให้เอ็นจิ้นอื่นเปิดแพ็คเกจเดียวกัน
  • แพ็คเกจโรงงานที่คุณไว้วางใจ ซอฟต์แวร์ต้นฉบับเผยแพร่จาก ไฟล์เก็บถาวรเฟิร์มแวร์ เข้ากันได้ดีกับมัน เพราะการกู้คืนพาร์ติชั่นสต็อกคือสิ่งที่ SP Flash Tool ถูกสร้างขึ้นมา

สำหรับการอัพเดตปกติหรือการติดตั้งครั้งแรกให้ออก วิธีการติดตั้ง อัตโนมัติ โดยจะเลือกเอ็นจิ้นที่เหมาะกับรุ่นและแพลตฟอร์มของคุณ และแอปจะช่วยให้คุณอยู่ในเส้นทางที่รองรับโดยไม่ต้องตั้งค่าเพิ่มเติม

หากการติดตั้งไม่เริ่มต้น

  1. ยืนยันว่ารุ่นที่คุณเลือกใน Updater CE ตรงกับรุ่นที่พิมพ์บนเครื่องเล่น และแพคเกจนั้นอยู่ในรายการ
  2. ยืนยันว่าเครื่องเล่นปิดอยู่อย่างสมบูรณ์ก่อนที่คุณจะเชื่อมต่อ และเชื่อมต่อเมื่อได้รับแจ้งจากแอปเท่านั้น
  3. บน Windows ให้ติดตั้งไดรเวอร์ MediaTek และรีสตาร์ท บน Linux ให้ตรวจสอบสิทธิ์ USB ที่ระบุไว้ การตั้งค่าคอมพิวเตอร์.
  4. ลองใช้พอร์ต USB อื่นบนคอมพิวเตอร์โดยตรงโดยไม่ต้องใช้ฮับ และเริ่มการติดตั้ง / กู้คืนอีกครั้ง

สิ่งใดเพิ่มเติมก็อยู่ในนั้น การแก้ไขปัญหา. และใน macOS หรือ ARM64 Linux คำตอบก็ไม่ใช่ปุ่มอื่น: เก็บ การติดตั้งแบบมีคำแนะนำ และใช้ SP Flash Tool จากพีซี Windows x64 หรือ Linux x86-64 เท่านั้น
