กระพริบด้วยตนเอง

เครื่องมือแฟลชสำหรับผู้เล่น Innioasis และ Timmkoo

SP Flash Tool เข้ามาข้างใน Innioasis Updater Windows และ Linux. คุณมีมันแล้ว คู่มือนี้แสดงวิธีที่ปลอดภัยในการใช้งานบน Innioasis Y1 หรือ Y2 และเส้นทาง Updater สำหรับผู้เล่น Timmkoo

กลับไปที่คู่มือการอัพเดตดาวน์โหลดเฟิร์มแวร์การแก้ไขปัญหา

เริ่มต้นด้วย Innioasis Updater

Updater ทำงานทั้งหมดในครั้งเดียว

Updater ทำการติดตั้งส่วนใหญ่ในครั้งเดียว เลือกซอฟต์แวร์ ทำตามขั้นตอน เท่านี้คุณก็เสร็จแล้ว นอกจากนี้ยังแจ้งให้คุณทราบเมื่อมีการแก้ไขหรือออกรุ่นใหม่ SP Flash Tool อยู่ใน Updater's Toolkit ในกรณีที่พบไม่บ่อยนัก Updater ไม่สามารถดำเนินการให้เสร็จสิ้นได้ ขั้นตอนด้านล่างถือเป็นข้อยกเว้น

เครื่องมือนี้มีไว้เพื่ออะไร

Updater จะกะพริบเครื่องเล่นให้คุณ SP Flash Tool เป็นเครื่องยนต์เดียวกัน ไม่มีราวกั้น ใช้เมื่อ Updater ไม่เริ่มทำงาน เมื่อเครื่องเล่นไม่เชื่อมต่อ หรือเมื่อคุณทราบวิธีแก้ไขไฟล์กระจาย

ลอง Updater ก่อน สำหรับการติดตั้งส่วนใหญ่และการกู้คืนส่วนใหญ่ โปรดดูคำแนะนำ เส้นทางการอัพเดต เป็นทางเลือกที่ปลอดภัยกว่า ใช้ SP Flash Tool เมื่อคุณรู้ว่าเหตุใดจึงจำเป็นต้องใช้ และเตรียมแบตเตอรี่ที่ชาร์จแล้วพร้อมสายเคเบิลข้อมูล USB ให้พร้อม

เครื่องมือแฟลชสำหรับผู้เล่น Innioasis

Innioasis Updater เป็นเครื่องมือแฟลชสำหรับผู้เล่น Innioasis โดยจะติดตั้งซอฟต์แวร์อย่างเป็นทางการ อัปเดตและกู้คืนแพ็คเกจผ่านโฟลว์ที่ตรงกับรุ่น และจะเก็บเพลงและการตั้งค่าของคุณไว้

Innioasis Y1 เครื่องมือแฟลช

เลือก Y1 ใน Updater จากนั้นเชื่อมต่อเครื่องเล่นที่ปิดอยู่เมื่อแอปถาม แพ็คเกจ Y1 เดียวกันใช้งานได้กับ SP Flash Tool เมื่อคุณต้องการเส้นทางแบบแมนนวล

Innioasis Y2 เครื่องมือแฟลช

เลือกรุ่นที่แสดงรายการสำหรับ Y2 แพ็คเกจ Y2 ไม่สามารถเปลี่ยนได้กับแพ็คเกจ Y1 ดังนั้นโปรดตรวจสอบรุ่นก่อนที่จะเริ่ม

เครื่องมือแฟลชสำหรับผู้เล่น Timmkoo

ผู้เล่น Timmkoo ใช้ขั้นตอนการติดตั้ง Updater เดียวกัน โดยจะอ่านแพ็คเกจ ZIP และ RAR ของ Timmkoo โดยตรง ดังนั้นคุณไม่จำเป็นต้องใช้เครื่องมือแฟลชหรือไฟล์กระจายแยกต่างหาก

Timmkoo Q5 เครื่องมือแฟลช

เลือกรุ่น Q5 ใน Updater เลือกแพ็คเกจ Timmkoo จากนั้นเรียกใช้ Install / Restore และเชื่อมต่อเครื่องเล่นเมื่อได้รับแจ้ง

เครื่องมือแฟลช Timmkoo Q3 และ Q3E

รายการ Q3 ครอบคลุมทั้ง Q3 และ Q3E เหมือนกัน Updater จะเลือกไฟล์ที่ตรงกันจากแพ็คเกจที่โปรเจ็กต์เผยแพร่

Timmkoo A5 เครื่องมือแฟลช

เลือกรุ่น A5 ก่อนเลือกแพ็คเกจ จากนั้นปฏิบัติตามพร้อมท์การติดตั้งเดียวกัน

ที่ Updater วางไว้

SP Flash Tool มาพร้อมกับโฟลเดอร์การติดตั้ง Updater ไม่ใช่การดาวน์โหลดแยกต่างหาก เปิดจากที่นั่นเมื่อคุณต้องการ

Windows

เปิดโฟลเดอร์ติดตั้ง Updater และเรียกใช้ flash_tool.exe. โดยปกติโฟลเดอร์จะอยู่ภายใต้ %LOCALAPPDATA%\Innioasis Updater. โฟลเดอร์ Toolkit ที่มีทางลัด SP Flash Tool รวมอยู่ในการตั้งค่าบางอย่าง

Linux

เรียกใช้การรวมกลุ่ม flash_tool ไบนารี่ภายในโฟลเดอร์แอป Updater บน x86 / x86_64 โปรแกรมติดตั้งโปรเจ็กต์เตรียมสิทธิ์ USB ด้วยกฎ udev ดังนั้นโปรแกรมเล่นควรปรากฏขึ้นเมื่อเชื่อมต่อ

macOS

SP Flash Tool ไม่ได้รวมมากับ macOS Updater ใช้เส้นทาง MTKClient ที่นั่นแทน ใช้ การติดตั้งแบบมีคำแนะนำ บน Mac และเก็บ SP Flash Tool ไว้สำหรับเครื่อง Windows หรือ Linux

เครื่องมือนี้มาพร้อมกับเอเจนต์การดาวน์โหลด MediaTek และการกำหนดค่าเฉพาะรุ่น ดังนั้นคุณจึงไม่จำเป็นต้องรวบรวม DA หรือกระจายไฟล์จากที่อื่น

เตรียมเฟิร์มแวร์

  1. คว้ารุ่นที่คุณต้องการ ดาวน์โหลดเฟิร์มแวร์. เลือก rom.zip สำหรับ Y1 หรือ rom_y2.zip สำหรับ Y2
  2. แยก ZIP ลงในโฟลเดอร์ของตัวเอง Windows สามารถใช้แยกทั้งหมดได้ บน Linux ให้ใช้ตัวจัดการไฟล์เก็บถาวรของคุณหรือ unzip ในอาคารผู้โดยสาร
  3. ตรวจสอบว่าไฟล์กระจายอยู่ในโฟลเดอร์ที่แยกออกมา โดยปกติจะมีชื่อว่า MT6572_Android_scatter.txt สำหรับแพ็คเกจ Y1 และ MT6582_Android_scatter_def.txt สำหรับแพ็คเกจ Y2 แม้ว่าการเปิดตัวอาจตั้งชื่อตามโปรเจ็กต์ก็ตาม
แยกโมเดลออกจากกัน สแกตเตอร์ Y1 อธิบายอุปกรณ์ MT6572 และสแกตเตอร์ Y2 อธิบายอุปกรณ์ MT6582 การกระพริบผิดอันจะทำให้ผู้เล่นโดนปิดกั้น หากการกระจายภายใน ZIP ไม่ตรงกับโมเดลของคุณ ให้หยุดและใช้แพ็คเกจที่แสดงสำหรับโมเดลของคุณแทน

โหลดการกระจายและแฟลช

  1. เปิด SP Flash Tool จากโฟลเดอร์การติดตั้ง Updater
  2. ในแท็บดาวน์โหลด คลิก เลือก ถัดจากไฟล์โหลดกระจาย และเลือกไฟล์กระจายจากโฟลเดอร์ที่แยกออกมา รายการพาร์ติชันจะกรอก
  3. เปิดโหมดแฟลชทิ้งไว้ ดาวน์โหลดเท่านั้น เว้นแต่คุณจะจงใจทำการกู้คืนทั้งหมดตามความจำเป็น อัพเกรดเฟิร์มแวร์.
  4. คลิก ดาวน์โหลด. เครื่องมือจะรอผู้เล่น
  5. ปิดเครื่องเล่นจนสุด จากนั้นเชื่อมต่อสายเคเบิลข้อมูล USB วางเครื่องเล่นลงและอย่าขยับ
  6. รอเครื่องหมายถูกสีเขียว จากนั้นให้ถอดสายเคเบิลออกและเริ่มการทำงานของเครื่องเล่น

ใช้สายเคเบิลและกฎเวลา USB เดียวกันกับเส้นทางที่แนะนำ: สายเคเบิลข้อมูล ไม่มีฮับ และเชื่อมต่อเมื่อเครื่องมือพร้อมเท่านั้น

ถ้าไม่กระพริบ

  1. ตรวจสอบว่าการกระจายและ ZIP ตรงกับโมเดลที่พิมพ์บนเครื่องเล่น
  2. ตรวจสอบให้แน่ใจว่าเครื่องเล่นปิดอยู่อย่างสมบูรณ์ก่อนทำการเชื่อมต่อ
  3. บน Windows ให้ยืนยันไดรเวอร์ MediaTek ที่ติดตั้งด้วยการตั้งค่า Updater บน Linux ให้ยืนยันกฎ udev จากตัวติดตั้งโปรเจ็กต์
  4. เชื่อมต่อสายเคเบิลใหม่เฉพาะเมื่อเครื่องมือกำลังรออยู่เท่านั้น การแข่งขันในท่าเรืออาจต้องถอดปลั๊กออกอย่างสมบูรณ์และสดใหม่ ดาวน์โหลด คลิก.

หากเกินกว่านั้นให้เปิด การแก้ไขปัญหา. และจำไว้ว่า: Updater ยังคงเป็นเส้นทางปกติและ Y1 และ Y2 คู่มือการคืนค่าก็ใช้เช่นกัน
