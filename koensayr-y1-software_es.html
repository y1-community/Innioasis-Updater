Koensayr Y1 pasos de instalación

  1. Abra Innioasis Updater CE en su computadora (si necesita la aplicación, Obtener Updater CE). conjunto Modelo del dispositivo a Y1.
  2. elegir Koensayr en Software.
  3. Elija la versión Y1 listada.
  4. Haga clic Instalar / Restaurar.
  5. Apague y conecte el Y1 solo cuando Updater CE lo solicite.

Preguntas frecuentes

¿Puedo restaurar el software Y1 original?

Sí. Seleccione Y1 y Software original en Updater CE. Ver el Y1 página de software de stock para la ruta de restauración completa.

¿Qué debo comprobar cuando falla?

Verifique el modelo, la versión, el cable, la configuración de la plataforma y si el reproductor estaba conectado antes del mensaje. Entonces usa solución de problemas.

¿Existe un paquete Koensayr Y2?

La compilación actual es para Y1. No lo use en un Y2 a menos que el proyecto publique una versión separada para él.
