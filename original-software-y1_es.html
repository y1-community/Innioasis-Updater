Instálalo o restáuralo con Updater

El actualizador utiliza el mismo flujo guiado ya sea que Y1 esté ejecutando actualmente su software original o un proyecto comunitario.

  1. Abra Innioasis Updater CE en su computadora (si necesita la aplicación, Obtener Updater CE). conjunto Modelo del dispositivo a Y1.
  2. elegir Software original en Software (o usar Obtener en Updater CE para saltar a los pasos guiados).
  3. Haga clic Instalar / Restaurar y deja que la aplicación prepare el paquete.
  4. Apague y conecte el Y1 solo cuando se lo solicite el mensaje en vivo.

Al descargar manualmente, el paquete de instalación completa habitual se denomina rom.zip. La selección de modelo en Updater es la forma más segura de elegir archivos.

Preguntas frecuentes

¿Puedo restaurar desde Rockbox u otro software personalizado?

Sí, utilice el modelo Y1 y la ruta del software original Y1. No elimine los archivos del sistema primero y no los sustituya por un paquete Y2.

¿Qué pasa si no se detecta mi Y1?

Verifique el cable de datos, la configuración de la computadora y el tiempo de conexión. El reproductor debe apagarse y conectarse solo cuando se le indique el Actualizador.

¿Qué paquete debo usar para mi Y1?

Mantenga el modelo impreso en su reproductor seleccionado en Updater. Los paquetes Y1 y Y2 están separados; deténgase si la lista de versiones no coincide con su modelo.
