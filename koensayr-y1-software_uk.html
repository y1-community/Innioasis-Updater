Koensayr Y1 install steps

  1. Відкрийте Innioasis Updater CE на своєму комп’ютері (якщо вам потрібна програма, Отримати Updater CE). встановити Модель пристрою для Y1.
  2. Виберіть Koensayr в Програмне забезпечення.
  3. Choose the listed Y1 release.
  4. Натисніть Встановити / Відновити.
  5. Вимкніть живлення та підключіть Y1 лише тоді, коли Updater CE запитає.

Запитання та відповіді

Can I restore the original Y1 software?

Yes. Select Y1 and Original Software in Updater CE. See the Y1 stock-software page for the complete restore route.

What should I check when it fails?

Check the model, release, cable, platform setup, and whether the player was connected before the prompt. Then use усунення несправностей.

Is there a Koensayr Y2 package?

The current build is for Y1. Don't use it on a Y2 unless the project publishes a separate release for it.
