🎨 Y1 и 360p Rockbox Загрузчик тем

Загрузите и установите темы для вашего устройства Y1 прямо в браузере.

📱 Настройка устройства

Y1 Устройство: Включите Y1, подключитесь через USB и включите USB режим хранения.

Компьютер: Ваш Y1 должен отображаться как съемный диск (обычно с именем «Y1» или аналогичным).

Расположение темы: Найдите папку с именем .rockbox на вашем Y1 устройстве

📋 Инструкции по ручной установке

⚠️ Важно: После загрузки тем вам необходимо вручную скопировать их на свое устройство Y1. Браузер не может напрямую получить доступ к файловой системе вашего устройства.

🎯 Для Y1 тем:

  1. Загрузите выбранные темы Y1 с помощью кнопки выше
  2. Извлеките загруженный ZIP-файл во временную папку.
  3. Подключите устройство Y1 через USB и включите USB режим хранения.
  4. Перейдите к устройству Y1 в файловом менеджере.
  5. Создайте папку с именем Themes в корне вашего устройства Y1 (если оно не существует)
  6. Для каждой темы скопируйте папку темы в Themes/ на вашем Y1 устройстве
  7. Каждая тема должна находиться в отдельной подпапке: Themes/ThemeName/
  8. Файлы темы должны быть помещены непосредственно в подпапку темы (не вложены глубже).
Y1 Устройство/ ├── .rockbox/ ├── Темы/ │ ├── Theme1/ │ │ ├── theme.wps │ │ ├── theme.sbs │ │ └── ... │ ├── Theme2/ │ │ ├── theme.wps │ │ └── ... │ └── ... └── ...

🎨 Для Rockbox тем 360p:

  1. Загрузите выбранные темы Rockbox с помощью кнопки выше
  2. Извлеките загруженный ZIP-файл во временную папку.
  3. Подключите устройство Y1 через USB и включите USB режим хранения.
  4. Перейдите к устройству Y1 в файловом менеджере.
  5. Найдите .rockbox папка на вашем Y1 устройстве
  6. Для каждой темы откройте тему .rockbox папка
  7. Скопируйте все файлы из темы .rockbox папку прямо в папку Y1 .rockbox папка
  8. Перезаписать существующие файлы при появлении запроса (это нормально для установки темы).
Y1 Устройство/ ├── .rockbox/ │ ├── themes/ │ ├── шрифты/ │ ├── wps/ │ ├── (файлы тем объединены здесь) │ └── ... └── ...
💡Совет профессионала: Вы можете выбрать несколько тем и загрузить их все одновременно. Каждая тема будет находиться в отдельной папке в загруженном ZIP-файле.

🔄После установки:

  1. Безопасно извлеките устройство Y1 из компьютера.
  2. Отсоедините кабель USB
  3. На вашем устройстве Y1 перейдите в Настройки → Темы
  4. Выберите недавно установленную тему из списка.
  5. Наслаждайтесь новой темой!

🗑️ Удаление тем:

  1. Для Y1 тем: удалите папку темы из Themes/ на вашем Y1 устройстве
  2. Для Rockbox тем: используйте кнопку «Сбросить папку Rockbox» выше, чтобы удалить все темы, отличные от 360p.
