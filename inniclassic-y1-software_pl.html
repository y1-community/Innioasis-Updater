Inniclassic Y1 install steps

  1. Otwórz Innioasis Updater CE na swoim komputerze (jeśli potrzebujesz aplikacji, Pobierz Updater CE). Zestaw Model urządzenia do Y1.
  2. Wybierz Inniclassic w Oprogramowanie.
  3. Wybierz wersję wymienioną dla Y1.
  4. Kliknij Zainstaluj / Przywróć.
  5. Wyłącz i podłącz Y1 tylko wtedy, gdy Updater CE zapyta.

Najczęstsze pytania

Czy mogę przywrócić standardowe oprogramowanie Y1?

Tak. Wybierz Y1 i oryginalne oprogramowanie w Updater CE. The Przewodnik po oprogramowaniu podstawowym Y1 obejmuje drogę powrotną.

Co się stanie, jeśli instalacja się nie powiedzie?

Note whether Updater failed before or after detecting the Y1, then check the cable, platform setup, model, and connection timing in rozwiązywanie problemów.

Can I use Inniclassic on Y2?

Yes. Inniclassic is available on both models — the same maintained project publishes a Y2 package from the same releases. Select Y2 in Updater CE and install the Y2 build; never flash a Y1 package to a Y2. The Strona instalacji Y2 covers it.
