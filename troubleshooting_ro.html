S-a oprit înainte de promptul USB.

Aceasta este o problemă de computer, nu o problemă de cablu. Verificați-vă modelul. Despachetați fișierul din nou. Atunci încearcă Instalează / Restaurează. Dacă lista de lansări este goală, deschideți directorul de firmware.

Nu se poate conecta la player

  1. Opriți complet Y1 sau Y2.
  2. Deconectați cablul, închideți alte instrumente flash sau Android și începeți din nou instalarea.
  3. Conectați-vă numai când Updater spune că este gata.
  4. Utilizați un cablu de date scurt USB direct în computer, nu un hub dacă este posibil.
  5. Pe Windows, reinstalați driverul MediaTek și reporniți. Pe Linux, verificați permisiunile USB/serial.

A detectat playerul, dar blițul a eșuat

Oprește-te aici. Nu încercați un alt model. Închideți alte instrumente, verificați că ați ales Y1 sau Y2 corect și utilizați software-ul original corespunzător dacă playerul nu pornește. SP Flash Tool și MTKClient sunt incluse dacă aveți nevoie de ele, iar fișierele sunt pe pagina de firmware.

Note despre driverul Windows

Unele instalări Windows blochează driverul MediaTek din cauza izolării Core. Urmați instrucțiunile actuale de securitate Windows înainte de a schimba integritatea memoriei și reporniți-o când ați terminat, dacă sistemul dvs. permite acest lucru.
