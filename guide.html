Getting started with Innioasis Updater CE

One app for every Y1 and Y2 firmware project. Install it on your computer, choose your model and software, then follow the prompts.

    Get Updater CEFull written tutorial

    Get Innioasis Updater CE

    Windows

    Download the installer, run it, then restart your PC when it finishes.

    Get DriversDownload Updater CE

    Restart your PC after installing. Driver help is in the Windows setup notes.

    macOS

    Download the app, move it to Applications, then open it. If macOS says the app can't be opened because it is from an unidentified developer, open System Settings, click Privacy & Security, scroll down and click Open Anyway, then click Open when the warning reappears. How Open Anyway works

    Works on Intel and Apple Silicon Macs with macOS Ventura and later.

    Linux

    Download the AppImage for Intel and AMD systems, make it executable, and run it.

    Linux setup notes

    You need your player, a USB data cable that carries data (a charge-only cable cannot install), and a few minutes. Keep the cable connected until Updater CE says it is done.

    Pick your model and software

    1. Device Model: choose the model printed on the player, Y1 or Y2. Packages are not interchangeable between models.
    2. Software and release: choose Original Software, Rockbox, Solar, JJ Launcher, Inniclassic, Y2Player, or Koensayr when it is listed for your model, then pick a release. Stable is the safe choice.
    3. Install: click Install / Restore, power the player fully off, and connect the USB cable only when Updater CE asks.
    4. Finish: leave the player and cable alone until the success message, then disconnect and start the player.

    Y1 players that shipped with Original Software before 2.0.0 need Device Type B. Everyone else keeps the default Type A.

    Going back to Original Software

    Custom software is reversible. In Updater CE, choose your model, select Original Software, pick a stable release, then run Install / Restore the same way. There is nothing to delete by hand.

    Y1 restore guideY2 restore guide

    If a flash stops before the USB prompt, check the cable, platform setup, and model first. See troubleshooting for fixes and SP Flash Tool for advanced recovery.

    Which Updater should you use?

    This guide covers Innioasis Updater CE, the community, donation-supported app that lists current firmware for you. The manufacturer's Innioasis Updater only flashes official packages you already have. Compare the two.
