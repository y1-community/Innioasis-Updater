Why Better-Y for your Innioasis Y1

Better-Y is the stock player, made better. Built by Leska1337 on the official 3.1.2 software. It fixes tags, track numbers, caching and playback controls, and keeps the familiar look, wheel and themes.

Better-Y is made for the Innioasis Y1 (Type A hardware). Y1 and Y2 builds are separate, so don't swap one for the other.

Mengapa orang memilihnya

Everything you liked about stock, none of the quirks.

  • Track numbers where they belong — Album views finally display track numbers so your albums play and display in their intended tracklist order rather than arbitrary sorting.
  • Intelligent tag splitting — Multi-artist songs (split by commas or semicolons) appear under each individual artist. Multi-genre tags (split by commas, semicolons, or forward slashes) appear under every matching genre.
  • ID3 metadata over filenames — Song titles, albums, and artists are properly read from ID3 tags instead of displaying raw filenames.
  • Now Playing interactive controls — Direct on-screen icons for Favorite (Heart), Shuffle toggle, Repeat mode (One/All/Off), Lyrics, A-B Repeat loop, Playback Queue, Bookmark position, Speed control, and Sleep timer.
  • Smooth, flicker-free RAM caching — A completely reworked image caching engine eliminates UI flashing, flickering, and lag when scrolling through large music libraries.
  • Official 3.1.2 foundation — Built on the latest 3.1.2 base, retaining official Apple AirPods connectivity fixes while preserving 100% compatibility with all custom stock themes.

Community & Release

Apa yang masyarakat katakan

Better-Y was created by developer Leska1337 to address the exact daily usability issues discussed on the r/innioasis subreddit. Rather than replacing the system with a different OS, Better-Y perfects the native player experience that users already know and love.

People like how familiar it feels: existing themes from the Themes Gallery keep working, playlists and Bluetooth behave like stock, and navigation is noticeably faster.

Apa yang ditawarkan oleh projek itu

  • Track numbers displayed directly in album track listings
  • Multi-artist tag splitting on commas (,) and semicolons (;)
  • Multi-genre tag splitting on commas (,), semicolons (;), and slashes (/)
  • Full Album Artist tag support for compilations, tributes, and features
  • External cover art support (auto-detects cover.jpg, cover.png, folder.jpg)
  • Disc number display for multi-disc releases (CD 1, CD 2, Vinyl Sides)
  • Interactive Now Playing icons (Favorite, Shuffle, Repeat, Lyrics, A-B Loop, Queue, Bookmark, Speed, Sleep timer)
  • Larger album artwork presentation with automatic crop/fill and tilt fix/toggle
  • Smooth marquee text auto-scrolling for long track titles and artist names
  • Fixed lyrics line overflow and text truncation bugs
  • Alphabetical fast-scrolling index bar for rapid wheel navigation in large libraries
  • Selection cursor automatically remembers and follows the currently playing track
  • Artist view displays albums first instead of dumping all songs into a flat list
  • Folder view adds "Show all songs" and "Shuffle" buttons
  • Default browsing shortcuts jump directly to /Music/ dan /Videos/
  • Double-press Play/Pause hardware button shortcut jumps directly to Now Playing from any screen
  • Sort albums by release year; sort playlists by date added
  • High-speed RAM image caching engine eliminating list flickering
  • Rapid library scanner with instant "Update library" option
  • Automatic cleanup of empty parent directories when the last song in a folder is deleted
  • 3-layout on-screen keyboard with Caps Lock and Case Switch for easier searching
  • Display keep-awake setting during lyrics and reading display
  • Hardware emergency reboot shortcut (hold top and bottom buttons simultaneously)
