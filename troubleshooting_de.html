Wo hat es aufgehört? Das sagt Ihnen, was Sie reparieren müssen.

Kehren Sie zur normalen Anleitung zurückFirmware prüfen

Es stoppte vor der Eingabeaufforderung USB.

Dies ist ein Computerproblem, kein Kabelproblem. Überprüfen Sie Ihr Modell. Entpacken Sie die Datei erneut. Dann versuchen Sie es Installieren / Wiederherstellen. Wenn die Release-Liste leer ist, öffnen Sie die Firmware-Verzeichnis.

Es kann keine Verbindung zum Player hergestellt werden

  1. Schalten Sie die richtige Y1 oder Y2 vollständig aus.
  2. Ziehen Sie das Kabel ab, schließen Sie andere Flash- oder Android-Tools und starten Sie die Installation erneut.
  3. Stellen Sie die Verbindung nur her, wenn der Updater meldet, dass er bereit ist.
  4. Verwenden Sie ein kurzes USB-Datenkabel direkt im Computer, möglichst keinen Hub.
  5. Unter Windows installieren Sie den MediaTek-Treiber neu und starten Sie neu. Überprüfen Sie unter Linux die Berechtigungen USB/seriell.

Der Player wurde erkannt, aber der Flash ist fehlgeschlagen

Halten Sie hier an. Probieren Sie kein anderes Modell aus. Schließen Sie andere Tools, überprüfen Sie, ob Sie die richtige Y1 oder Y2 ausgewählt haben, und verwenden Sie die passende Originalsoftware, wenn der Player nicht startet. SP Flash Tool und MTKClient sind bei Bedarf enthalten, und die Dateien befinden sich auf der Firmware-Seite.

Hinweise zum Windows-Treiber

Einige Windows-Installationen blockieren den MediaTek-Treiber aufgrund der Core-Isolation. Befolgen Sie die aktuellen Windows-Sicherheitsrichtlinien, bevor Sie die Speicherintegrität ändern, und schalten Sie sie wieder ein, wenn Sie fertig sind, sofern Ihr System dies zulässt.
