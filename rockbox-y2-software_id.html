Rockbox Y2 langkah-langkah pemasangan

  1. Buka Innioasis Updater CE di komputer Anda (jika Anda memerlukan aplikasinya, Dapatkan Updater CE). Tetapkan Model perangkat untuk Y2.
  2. Pilih Rockbox di Perangkat lunak.
  3. Pilih rilis yang secara eksplisit tercantum untuk Y2.
  4. Klik Pasang / Pulihkan dan tunggu persiapan paket.
  5. Matikan dan sambungkan Y2 hanya ketika Updater CE diminta.

Jangan memaksakan paket Y1 karena nama proyek terlihat sama. Jika tidak ada rilis Y2 yang muncul, hentikan dan periksa model dan data rilis saat ini.

Pertanyaan umum

Dapatkah saya memulihkan perangkat lunak Y2 asli nanti?

Ya. Pilih Y2 dan Perangkat Lunak Asli di Updater CE. Lihat Y2 halaman perangkat lunak stok untuk urutan pemulihan.

Mengapa paket tersebut diberi nama rom_y2.zip?

Itu adalah petunjuk pengunduhan manual yang digunakan oleh beberapa Y2 rilis instalasi penuh. Pilihan yang lebih aman adalah tetap memilih Y2 di Updater CE dan menggunakan rilis yang disajikan.

Bisakah saya menggunakan tutorial Y1 Rockbox?

Gunakan hanya untuk gagasan luas. Untuk pemilihan paket dan model ikuti ini Y2-panduan khusus.
