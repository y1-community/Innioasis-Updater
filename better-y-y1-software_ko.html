Better-Y · Innioasis Y1

Y1에 Better-Y을(를) 설치합니다.

Better-Y은(는) 100% 테마 호환성을 유지하면서 태그 분할, 앨범 트랙 번호, Now Playing 바로가기 및 보다 원활한 RAM 캐싱을 통해 Innioasis Y1에 대한 향상된 스톡 환경을 제공합니다.

전체 Better-Y 가이드 열기이것을 Updater CE에서 얻으세요왜 Better-Y인가요?

컴퓨터에 대한 설치 가이드

컴퓨터를 사용하여 Y1에 Better-Y을(를) 설치합니다.

사용 중인 컴퓨터에 대한 가이드를 선택하세요. 모든 버전에는 플랫폼 설정, Updater CE 단계 및 재고로 돌아가는 방법이 있습니다.

Better-Y Y1 설치 단계

  1. 컴퓨터에서 Innioasis Updater CE를 엽니다(앱이 필요한 경우, Updater CE 받기). 세트 기기 모델 에 Y1.
  2. 선택 Better-Y 안으로 소프트웨어.
  3. Y1에 대해 나열된 릴리스를 선택합니다.
  4. 클릭 설치 / 복원.
  5. 전원을 끄고 Updater CE이 묻는 경우에만 Y1을 연결하세요.

자주 묻는 질문

순정 펌웨어에 비해 개선된 점은 무엇입니까?

Better-Y은 트랙 번호를 추가하고, 다중 아티스트 태그를 분할하고, 실제 제목을 사용하고, 재생 바로 가기를 추가하고, 캐싱 및 Bluetooth에 대한 수정 사항을 추가합니다. 이전과 동일한 테마입니다.

재고 Y1 소프트웨어를 복원할 수 있나요?

예. Updater CE에서 Y1과 원본 소프트웨어를 선택합니다. 는 Y1 스톡 소프트웨어 가이드 복귀 경로를 덮습니다.

기존 테마를 사용할 수 있나요?

예! Better-Y은 공식 스톡 3.1.2를 기반으로 구축되었으며 테마 갤러리의 모든 사용자 정의 테마와 100% 호환성을 유지합니다.

설치에 실패하면 어떻게 되나요?

Y1을(를) 감지하기 전이나 후에 업데이터가 실패했는지 확인한 다음, 다음에서 케이블, 플랫폼 설정, 모델 및 연결 타이밍을 확인하세요. 문제 해결.

안내 경로를 이용하세요

업데이터를 처음 사용하시나요? 안내된 설정을 참조하세요. Updater CE 받기 플레이어를 연결하기 전에 Windows, macOS 또는 Linux에서.
