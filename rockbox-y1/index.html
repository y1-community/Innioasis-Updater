Rockbox-Y1 · Innioasis Y1

Rockbox-Y1

Rockbox-Y1 is the community Rockbox firmware for the Innioasis Y1. It adds a tag-based music library, gapless playback, a full equalizer, and custom themes. Use this hub to install Rockbox-Y1 with Updater CE, download ROM packages, browse themes, or restore the factory software.

Rockbox, Rockbox-Y1 and “Rockbox for Y1” are the same firmware

Innioasis Updater CE lists this firmware as Rockbox under device model Y1. Guides, videos, and search results also call it Rockbox-Y1 or Rockbox for Y1. All of these names refer to the exact same Y1 port. Always select Y1 first so you do not install a Y2 build by mistake.

Direct downloads from the community developers

Innioasis Updater CE always downloads firmware packages directly from the community firmware developers (rockbox-y1/rockbox), who are solely responsible for publishing and listing their software releases in Updater CE. You can let Updater CE download and install the release for you, or download the ROM package from our firmware directory.

Before you install

  • Select Y1 in Device Model before choosing Rockbox.
  • Choose a stable release for daily use, or enable nightly builds if you want to test a preview.
  • Use a USB data cable and a charged player; power the player off and connect it only when Updater CE asks.
  • You can return to factory firmware at any time by installing Original Software for the Y1.

Y1 community builds are labelled by screen resolution: 240p builds work with classic iPod-style Rockbox themes, while 360p builds use higher-resolution Y1 themes.

Frequently asked questions

Is Rockbox-Y1 safe to install?

Yes. It uses the same MediaTek flashing process as the factory firmware, and you can restore Original Software at any time. Always use a reliable USB data cable and keep the player charged.

Where does Updater CE download Rockbox-Y1 from?

Updater CE downloads firmware packages directly from the community firmware developers' own releases (rockbox-y1/rockbox). The developers themselves are solely responsible for listing their releases in Updater CE.

Can I install Rockbox-Y1 on an Innioasis Y2?

No. The Y1 and Y2 use different hardware and separate firmware builds. Select Y2 in Updater CE and use the Rockbox-Y2 guide instead.

How do I return to the original factory software?

In Updater CE, select Y1, choose Original Software, pick a stable release, and click Install / Restore. See the restore guide.
