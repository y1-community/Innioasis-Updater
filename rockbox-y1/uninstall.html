Rockbox-Y1 · Innioasis Y1

Remove Rockbox-Y1 or reset it to defaults

Whether you want to remove Rockbox-Y1 completely and return to factory software, or simply reset Rockbox-Y1 back to default settings, both take only a few minutes.

Get it in Updater CEFull written tutorial

Option 1: Return to factory Original Software

To replace Rockbox-Y1 with the factory firmware, open Innioasis Updater CE, select Y1, choose Original Software, and click Install / Restore. See the restore guide.

Option 2: Reset Rockbox-Y1 settings to default

To keep Rockbox-Y1 installed but reset all settings, themes, and database caches, delete or rename the hidden .rockbox folder on your MicroSD card and reboot the player. See the MicroSD card guide.

Frequently asked questions

Does deleting .rockbox uninstall the firmware?

No. It only resets your settings and themes; the player recreates a clean .rockbox folder on the next boot.

Can I reinstall Rockbox-Y1 after restoring Original Software?

Yes, at any time through Innioasis Updater CE.
