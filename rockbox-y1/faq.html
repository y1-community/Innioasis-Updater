Rockbox-Y1 FAQ

Clear answers to the most common questions about installing, updating, and using Rockbox-Y1 on the Innioasis Y1.

At a glance

Rockbox, Rockbox-Y1, and “Rockbox for Y1” are the same community firmware for the Innioasis Y1. Innioasis Updater CE always downloads packages directly from the community firmware developers (rockbox-y1/rockbox), who are solely responsible for listing their releases in Updater CE.

Frequently asked questions

Are Rockbox, Rockbox-Y1, and Rockbox for Y1 the same thing?

Yes. Updater CE lists it as Rockbox when Y1 is selected, while guides and release notes call it Rockbox-Y1 so it is clear which player model it is for.

Where does Updater CE download Rockbox-Y1 from?

Updater CE always downloads firmware packages directly from the community firmware developers' own releases (rockbox-y1/rockbox), never from a mirror archive. The developers are solely responsible for listing their software releases in Updater CE.

How do I install Rockbox-Y1?

Follow the 6-step install guide in Innioasis Updater CE.

Can I install Rockbox-Y1 on an Innioasis Y2?

No. Use Rockbox-Y2 for the Y2.

Will installing Rockbox-Y1 erase my music?

No. Your music lives on the MicroSD card and is not touched by flashing the firmware.

How do I go back to factory software?

Install Original Software for Y1 in Updater CE (restore guide).
