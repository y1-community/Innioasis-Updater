Rockbox-Y1 · Innioasis Y1

Update Rockbox-Y1

Updating Rockbox-Y1 on your Innioasis Y1 uses the exact same steps in Updater CE as a first-time install, and keeps the music, themes, and settings stored on your MicroSD card.

Get it in Updater CEFull written tutorial

How to update to a newer release

  1. Open Innioasis Updater CE and select Y1 in Device Model.
  2. Choose Rockbox and select the newer stable or nightly release.
  3. Click Install / Restore and connect your powered-off player when prompted.
  4. Turn on the player once the update finishes.

Updater CE downloads the new release directly from the community developer's repository.

Stable vs. nightly builds

Stable releases are recommended for everyday listening. Nightly builds let you test the newest changes and bug fixes. You can read what changed in every version on the Rockbox-Y1 release notes page.

Frequently asked questions

Do I need to uninstall the old version before updating?

No. Flashing the new release overwrites the previous firmware while leaving your MicroSD card untouched.

Can I downgrade to an earlier release?

Yes. Select any earlier release listed for your model in Updater CE and install it the same way.
