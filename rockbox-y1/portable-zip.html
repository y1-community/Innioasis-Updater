How to install from a downloaded ZIP

  1. Download the ROM ZIP and extract it to a folder on your computer (avoid folder paths with special characters).
  2. Open Innioasis Updater CE and set Device Model to Y1.
  3. Select the local package option and choose your downloaded ZIP or extracted folder.
  4. Click Install / Restore.
  5. Power off your Y1 completely and connect it over USB when Updater CE prompts you.

What is inside the ROM package

Each ROM package contains a MediaTek scatter file and the partition images for your Y1. Keep all files in the extracted folder together so the scatter file can locate every image.

Frequently asked questions

Does Updater CE use the website's standalone portable ZIP mirror?

No. Updater CE always downloads firmware packages directly from the community firmware developers themselves, who are solely responsible for listing their releases in Updater CE.

Do I need to install Python or MediaTek tools separately?

No. Updater CE includes everything needed to flash the ROM.

Can I flash the ZIP from the player's MicroSD card?

No. Flashing is always performed from a computer over USB while the player is powered off.
