Published by the rockbox-y1/rockbox developers in release stable-v0.6 (project README). Innioasis Updater CE always downloads firmware packages directly from the community firmware developers themselves, and those developers are solely responsible for listing their releases in Updater CE.

Which package should I choose?

  • Install with Updater CE (recommended) — Updater CE downloads the package directly from the developer's release and flashes your Y1 automatically.
  • Developer ROM package (rom.zip) — the firmware ZIP published by the developer for offline archiving or manual installation.
  • Type B ROM package (rom_type_b.zip) — for Y1 players that shipped with pre-2.0.0 factory firmware.

Current recommended release tag: stable-v0.6.

Install with one click in Updater CE

You do not need to download ZIP files manually for a normal install. Open Updater CE, select Y1 and Rockbox, and it will download the release directly from the developer.

Frequently asked questions

Where do Rockbox-Y1 downloads come from?

Updater CE always downloads packages directly from the community firmware developer's releases (rockbox-y1/rockbox). The developer is solely responsible for listing their releases in Updater CE.

Can I copy the ROM ZIP onto the MicroSD card to install it?

No. Firmware ROM packages are flashed from a computer over USB using Updater CE. See installing from a downloaded ZIP.
