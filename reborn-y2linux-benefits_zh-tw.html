Innioasis Y2 - 本機 Linux 和 Reborn UI

為什麼要在 Innioasis Y2 上安裝 Reborn (Y2Linux)？

由 SchulzCode 構建， Reborn (Y2Linux / Y2Reborn) 為 Innioasis Y2 帶來了乾淨、響應靈敏的基於 Debian 的 Linux 基礎和專門構建的點擊輪介面。它繼承了早期的 Y2Player 項目，並解決了長期存在的 Y2 藍牙耳機和圖書館導航問題。

在 Y2 上安裝 Reborn (Y2Linux) 瀏覽 Y2Reborn 版本 Wi-Fi 與藍牙設定指南

是什麼讓 Y2Reborn 在 Y2 中脫穎而出

可靠的藍牙耳機

社區成員在 r/innioasis 報告稱，一旦啟用 Wi-Fi 和藍牙韌體包，Y2Reborn 就可以解決現代藍牙耳機和耳塞的配對和播放遺失問題。

快速點擊輪導航

Y2Reborn 圍繞 Y2 撥輪和實體按鈕從頭開始設計，提供即時選單響應、快速字母順序擦洗和流暢的庫滾動。

真正的 Debian Linux 底層

由 SchulzCode/Y2Linux 和 SchulzCode/Y2Reborn 提供支持，為您提供具有現代 ALSA 音訊驅動程式和社群更新的完整 Linux 環境。

開始使用 Y2Reborn

步驟1

使用更新程式 CE 安裝

開啟InnioasisUpdater CE，選擇 Y2， 選擇 Reborn (Y2Linux)，然後按一下 安裝 / 還原.

步驟2

啟用 Wi-Fi 和藍牙

閱讀 Wi-Fi 與藍牙設定指南 完成耳機的初始配對和網路同步。

安全復原

隨時返回原始軟體

如果您希望恢復原廠庫存，Updater CE 可以隨時將您的 Y2 恢復為原始軟體。
