Etapas de instalação do Android 4.2 Y1

  1. Abra o Innioasis Updater CE no seu computador (se precisar do aplicativo, Obter o Updater CE). Definir Modelo do aparelho para Y1.
  2. Escolher Android 4.2 (desenvolvimento) em Programas.
  3. Escolha o lançamento listado para Y1.
  4. Clique Instalar / Restaurar.
  5. Desligue e conecte o Y1 somente quando o Updater CE solicitar.

Perguntas frequentes

Posso restaurar o software padrão Y1?

Sim. Selecione Y1 e Software Original em Updater CE. O Y1 guia de software de estoque cobre o caminho de retorno.

Este é um motorista diário ROM?

Este é um desenvolvedor experimental ROM destinado a testes e desenvolvimento. As atualizações de recursos estão na página do projeto.

Use a rota guiada

Primeira vez usando o Updater? Veja a configuração guiada para Obter o Updater CE no Windows, macOS ou Linux antes de conectar seu player.
