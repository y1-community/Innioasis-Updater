Etapas de instalação

  1. Abra Updater CE. Disponível para Windows, macOS e Linux.
  2. Selecione Y2 como o modelo do dispositivo.
  3. Selecione Reborn (Y2Linux) como o software.
  4. Clique em Instalar/Restaurar. Aguarde enquanto Updater CE prepara os arquivos.
  5. Conecte USB quando solicitado. Desligue o Y2 primeiro.
  6. Configurar Wi-Fi, Bluetooth e rádio FM

    Copiar system.img para o jogador uma vez. Reborn faz o resto.
