Загрузите пакеты прошивок Rockbox ROM для Innioasis Y1 (Rockbox-Y1) и Y2 (Rockbox-Y2) напрямую от разработчиков сообщества или установите в один клик с помощью Innioasis Updater CE.

Как Updater CE загружает прошивку

Innioasis Updater CE всегда загружает пакеты встроенного ПО непосредственно из собственных выпусков разработчиков встроенного ПО сообщества, и сами разработчики несут полную ответственность за размещение своих выпусков программного обеспечения в Updater CE. Каждый пакет ROM содержит скаттер-файл MediaTek и образы разделов для этой модели.

  • Rockbox-Y1 пакет выпуска для разработчиков: rom.zip (и rom_type_b.zip для единиц Type B Y1).
  • Rockbox-Y2 пакет выпуска для разработчиков: rom_y2.zip.

Автоматическая установка с помощью Updater CE

Для самой простой настройки откройте Innioasis Updater CE, выберите модель вашего плеера и Rockbox и позвольте приложению загрузить и установить версию напрямую. Следуйте Rockbox-Y1 руководство по установке или Rockbox-Y2 руководство по установке.
