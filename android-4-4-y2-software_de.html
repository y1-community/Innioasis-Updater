Installationsschritte für Android 4.4 Y2.

  1. Öffnen Sie Innioasis Updater CE auf Ihrem Computer (wenn Sie die App benötigen, Updater CE holen). Satz Gerätemodell an Y2.
  2. Wählen Sie Android 4.4 (Entwickler) In Software.
  3. Wählen Sie die für Y2 aufgeführte Version aus.
  4. Klicken Sie Installieren / Wiederherstellen.
  5. Schalten Sie das Y2 nur aus und schließen Sie es an, wenn Updater CE dazu fragt.

FAQ

Kann ich die Standardsoftware Y2 wiederherstellen?

Ja. Wählen Sie Y2 und Originalsoftware in Updater CE. Der Y2 Stock-Software-Leitfaden deckt den Rückweg ab.

Ist das ein Daily Driver ROM?

Dies ist ein experimenteller Entwickler ROM, der für Tests und Entwicklung gedacht ist. Release-Updates finden Sie auf der Projektseite.
