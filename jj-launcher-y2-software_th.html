JJ Launcher · Innioasis Y2

ตรวจสอบ JJ Launcher สำหรับ Y2 ก่อนทำการติดตั้ง

มี JJ Launcher บิลด์สำหรับ Y2 แม้ว่าสิ่งที่รวมอยู่สามารถเปลี่ยนแปลงได้ระหว่างการเปิดตัว ตรวจสอบรายชื่อปัจจุบันก่อนที่จะเริ่มต้น

เปิดคำแนะนำ JJ Launcher ฉบับเต็มรับสิ่งนี้ใน Updater CEทำไมต้อง JJ Launcher?

คู่มือการติดตั้งสำหรับคอมพิวเตอร์ของคุณ

ติดตั้ง JJ Launcher บน Y2 ด้วยคอมพิวเตอร์ของคุณ

เลือกคำแนะนำสำหรับคอมพิวเตอร์ที่คุณใช้ ทุกรุ่นมีการตั้งค่าแพลตฟอร์ม ขั้นตอน Updater CE และวิธีคืนสินค้าในสต็อก

คู่มือวินโดวส์คู่มือ macOSคู่มือลินุกซ์

คำแนะนำ Innioasis Y2 ทั้งหมด · คำแนะนำ JJ Launcher ทั้งหมด

การตรวจสอบที่ถูกต้องตามแบบ

  1. เปิด Innioasis Updater CE บนคอมพิวเตอร์ของคุณ (หากคุณต้องการแอป รับ Updater CE). ชุด รุ่นอุปกรณ์ ถึง Y2.
  2. ยืนยัน JJ Launcher ปรากฏสำหรับ Y2 ในข้อมูลการเผยแพร่ปัจจุบัน
  3. อ่านบันทึกประจำรุ่นของโครงการและเลือกรุ่น Y2 ที่อยู่ในรายการ
  4. คลิก ติดตั้ง / คืนค่า.
  5. ปิดเครื่องและเชื่อมต่อ Y2 เมื่อได้รับแจ้งเท่านั้น
อย่าทดแทน: แพ็คเกจ Y1 ไม่ใช่แพ็คเกจ Y2 หยุดหากรุ่นและรุ่นไม่ตรงกัน

คำถามที่พบบ่อย

รับประกันการสนับสนุน Y2 หรือไม่

มีบิลด์ Y2 อยู่ในรายการ แต่สิ่งที่รองรับสามารถเปลี่ยนแปลงได้ ตรวจสอบรายการล่าสุดและหมายเหตุของโครงการก่อนทำการติดตั้ง

ฉันจะคืนค่า Y2 ได้อย่างไร

เลือก Y2 และซอฟต์แวร์ต้นฉบับใน Updater CE จากนั้นปฏิบัติตาม Y2 ขั้นตอนการกู้คืน.

จะเกิดอะไรขึ้นถ้า JJ Launcher ไม่อยู่ในรายการ?

อย่าบังคับแพ็คเกจ Y1 ตรวจสอบการเผยแพร่โครงการและ คู่มือการแก้ไขปัญหา.

เริ่มต้นด้วย Updater CE

ใช้ คู่มือการตั้งค่า Windows, macOS หรือ Linux ก่อนที่จะเชื่อมต่อเครื่องเล่น
