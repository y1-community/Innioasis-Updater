🌐 Requisitos de alojamiento

Para utilizar este widget en su sitio web, debe:

  1. Sube el innioasis-embed.html archivo a su servidor web
  2. Actualice las URL en el fragmento de integración para que apunten a su servidor
  3. Asegúrese de que su servidor admita HTTPS (requerido para los navegadores modernos)
  4. Pruebe el widget en su sitio web para asegurarse de que funciona correctamente

🆘 Soporte

Si necesita ayuda para integrar este widget o tiene preguntas, por favor:
