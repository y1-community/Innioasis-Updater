Inniclassic Y2 install steps

  1. Buka Innioasis Updater CE pada komputer anda (jika anda memerlukan apl itu, Dapatkan Updater CE). Tetapkan Model Peranti kepada Y2.
  2. pilih Inniclassic dalam Perisian.
  3. Choose the release listed for Y2.
  4. klik Pasang / Pulihkan.
  5. Matikan dan sambungkan Y2 hanya apabila Updater CE bertanya.

Soalan Lazim

Can I restore the stock Y2 software?

Yes. Select Y2 and Original Software in Updater CE. The Y2 stock-software guide meliputi laluan pulang.

Can I use Inniclassic on Y1?

Yes. The same project publishes Y1 packages as well — rom.zip for Type A and rom_type_b.zip for Type B. Select Y1 in Updater CE and install the Y1 build; the Halaman pemasangan Y1 covers it.

Bagaimana jika pemasangan gagal?

Note whether Updater failed before or after detecting the Y2, then check the cable, platform setup, model, and connection timing in penyelesaian masalah.
