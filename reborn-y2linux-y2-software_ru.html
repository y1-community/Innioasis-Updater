Установите Reborn (Y2Linux) на свой Y2 с помощью компьютера.

Выберите руководство для компьютера, который вы используете. В каждой версии есть настройка платформы, Updater CE шагов и возврат к стоку.

Этапы установки

  1. Откройте программу обновлений CE. Доступно для Windows, macOS и Linux.
  2. Выберите Y2 как модель устройства.
  3. Выберите Reborn (Y2Linux) как программное обеспечение.
  4. Нажмите Установить/Восстановить. Подождите, пока Updater CE подготовит файлы.
  5. Подключите USB по запросу. Сначала выключите Y2.
  6. Настройте Wi-Fi, Bluetooth и FM-радио

    Копировать system.img игроку один раз. Reborn делает все остальное.
