Verificações corretas do modelo

  1. Abra o Innioasis Updater CE no seu computador (se precisar do aplicativo, Obter o Updater CE). Definir Modelo do aparelho para Y2.
  2. Confirmar JJ Launcher aparece para Y2 nos dados da versão atual.
  3. Leia a nota de lançamento do projeto e selecione a versão Y2 listada.
  4. Clique Instalar / Restaurar.
  5. Desligue e conecte o Y2 somente quando solicitado.
Não substitua: um pacote Y1 não é um pacote Y2. Pare se o modelo e a versão não concordarem.

Perguntas frequentes

O suporte Y2 é garantido?

Há uma compilação Y2 listada, mas o que é compatível pode mudar. Verifique a listagem mais recente e as notas do projeto antes de instalar.

Como faço para restaurar o Y2?

Selecione Y2 e Software Original em Updater CE e siga as instruções Y2 etapas de restauração.

E se JJ Launcher não estiver listado?

Não force um pacote Y1. Confira os lançamentos do projeto e o guia de solução de problemas.
