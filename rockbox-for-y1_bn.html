Rockbox-Y1 · Innioasis Y1

Rockbox for Y1 (Rockbox-Y1)

“Rockbox”, “Rockbox-Y1”, and “Rockbox for Y1” all refer to the same community Rockbox firmware for the Innioasis Y1. Here is what it adds to your player, which build to choose, and how to install it with Innioasis Updater CE.

One firmware, several names

In Innioasis Updater CE, this firmware appears as Rockbox when you select device model Y1. Guides, videos, and release notes also call it Rockbox-Y1 বা Rockbox Y1 এর জন্য so it is clear that the build is for the Y1 and not the Y2.

Always check the model printed on your player before installing: Y1 and Y2 firmware packages are not interchangeable.

What Rockbox-Y1 adds to your Y1

Rockbox-Y1 is a community port of the open-source Rockbox music player firmware for the Innioasis Y1:

  • Tag-based music library — browse by artist, album, genre, and year using audio tags, or browse folders directly.
  • Advanced audio playback — gapless playback, crossfade, ReplayGain, and a full equalizer.
  • Custom themes — choose from hundreds of 240p and 360p community themes, including classic iPod-style layouts.
  • FM radio — built-in FM radio support.
  • Optional extras — podcast downloads over Wi-Fi and Last.fm / ListenBrainz / Maloja scrobbling on supported builds.
  • Dual boot — switch back to the factory Original Software without reflashing on supported builds.

Which Y1 build should I choose?

  • 240p vs. 360p — 240p builds work with classic 320×240 Rockbox themes; 360p builds use sharper 480×360 Y1 themes. Match the build resolution to the themes you want to use (240p vs. 360p guide).
  • Type A vs. Type B — Type A is for Y1 players that shipped with factory software 2.0.0 or newer; Type B is for earlier Y1 units. Choose Type A unless you know your Y1 is Type B.
  • Stable vs. Nightly — Choose a stable build for everyday listening, or a nightly build to test the newest changes.

Direct downloads from the community developers

Innioasis Updater CE always downloads firmware packages directly from the community firmware developers (rockbox-y1/rockbox), and the developers themselves are solely responsible for listing their software releases in Updater CE.

You can let Updater CE download and install the firmware automatically, or download the ROM packages from our Rockbox-Y1 downloads page এবং Rockbox ROM download page.

How to install Rockbox-Y1

  1. Open Innioasis Updater CE and set ডিভাইস মডেল থেকে Y1.
  2. নির্বাচন করুন Rockbox মধ্যে সফটওয়্যার.
  3. Pick a stable release (or enable nightly builds to test a preview).
  4. ক্লিক করুন ইনস্টল / পুনরুদ্ধার so Updater CE downloads the package directly from the developer.
  5. Power the Y1 completely off and connect it with a USB data cable when Updater CE prompts you.
  6. Wait for the completion message, then disconnect and turn on your player.

For screenshots and detailed setup tips, read the full Rockbox-Y1 tutorial.

Restoring the original Y1 software

You can return to factory software at any time: select Y1 এবং মূল সফটওয়্যার in Updater CE, pick a stable release, and click ইনস্টল / পুনরুদ্ধার. Your music on the MicroSD card is preserved. See the restore guide এবং Y1 Original Software page.

Frequently asked questions

Is Rockbox for Y1 the same as Rockbox-Y1?

Yes. Rockbox, Rockbox-Y1, Rockbox for Y1, and rockbox-y1 all refer to the same community Rockbox port for the Innioasis Y1.

Where does Updater CE download Rockbox-Y1 from?

Updater CE always downloads firmware packages directly from the community firmware developers' own releases (rockbox-y1/rockbox). The developers are solely responsible for listing their software releases in Updater CE.

Can I install Rockbox-Y1 on a Y2?

No. The Y2 has its own separate firmware build. Use Rockbox Y2 এর জন্য instead.

Will installing Rockbox-Y1 erase my music?

No. Music is stored on the MicroSD card and is not affected when flashing the player's internal firmware.
