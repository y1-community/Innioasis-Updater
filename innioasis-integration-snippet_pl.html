📋 Instrukcja integracji

Aby dodać poradnik instalacji Innioasis Updater do swojej strony, wystarczy skopiować i wkleić ten fragment kodu do HTML:

<!-- Innioasis Updater Install Guide Widget --> <script> (function() { // Create and inject the widget const script = document.createElement('script'); script.src = 'https://your-domain.com/innioasis-embed.html'; script.async = true; // Alternative: Load from local file // script.src = './innioasis-embed.html'; document.head.appendChild(script); // Create iframe container const iframe = document.createElement('iframe'); iframe.src = 'https://your-domain.com/innioasis-embed.html'; iframe.style.cssText = ` position: fixed; bottom: 20px; right: 20px; width: 400px; height: 200px; border: none; z-index: 999999; pointer-events: none; `; // Make iframe interactive iframe.onload = function() { iframe.style.pointerEvents = 'auto'; }; document.body.appendChild(iframe); })(); </script>

🎯 Alternatywa: osadzanie bezpośrednie

Jeszcze prościej: widżet możesz osadzić bezpośrednio za pomocą iframe:

<!-- Direct iframe embed --> <iframe src="https://your-domain.com/innioasis-embed.html" width="400" height="200" frameborder="0" style="position: fixed; bottom: 20px; right: 20px; z-index: 999999; border-radius: 12px; box-shadow: 0 8px 32px rgba(0,0,0,0.3);" allowtransparency="true"> </iframe>

🌐 Wymagania hostingu

Aby użyć tego widżetu na swojej stronie, musisz:

  1. Wgraj plik innioasis-embed.html plik na swój serwer WWW
  2. Zmień adresy URL we fragmencie kodu osadzania tak, by wskazywały na Twój serwer
  3. Upewnij się, że Twój serwer obsługuje HTTPS (wymagane przez nowoczesne przeglądarki)
  4. Przetestuj widżet na swojej stronie, żeby upewnić się, że działa poprawnie

🆘 Pomoc

Jeśli potrzebujesz pomocy w integracji tego widżetu lub masz pytania:

  • Sprawdź w konsoli przeglądarki, czy nie ma komunikatów o błędach
  • Upewnij się, że wszystkie pliki zostały poprawnie wgrane na Twój serwer
  • Sprawdź, czy adresy URL w kodzie osadzania są poprawne
