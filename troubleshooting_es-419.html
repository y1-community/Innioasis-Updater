Se detuvo antes del mensaje USB

Este es un problema de computadora, no de cables. Consulta tu modelo. Desempaquete el archivo nuevamente. Entonces intenta Instalar / Restaurar. Si la lista de versiones está vacía, abra la directorio de firmware.

No se puede conectar al reproductor.

  1. Apague completamente el Y1 o Y2 correcto.
  2. Desenchufe el cable, cierre otras herramientas flash o de Android y comience la instalación nuevamente.
  3. Conéctese solo cuando el Actualizador indique que está listo.
  4. Utilice un cable de datos corto USB directamente en la computadora, no un concentrador si es posible.
  5. En Windows, reinstale el controlador MediaTek y reinicie. En Linux, verifique USB/permisos de serie.

Detectó el reproductor pero el flash falló.

Deténgase aquí. No pruebes con un modelo diferente. Cierre otras herramientas, verifique que haya elegido el Y1 o Y2 correcto y use el software original correspondiente si el reproductor no se inicia. SP Flash Tool y MTKClient están incluidos si los necesita, y los archivos están en el página de firmware.

Notas del controlador de Windows

Algunas instalaciones de Windows bloquean el controlador MediaTek debido al aislamiento del núcleo. Siga las instrucciones de seguridad actuales de Windows antes de cambiar la integridad de la memoria y vuelva a activarla cuando haya terminado si su sistema lo permite.
