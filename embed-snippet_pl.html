🚀 Innioasis Updater - widżet do osadzenia

Skopiuj ten kod i wklej go na swojej stronie, aby osadzić widżet Innioasis Updater:

<!-- Innioasis Updater Embed Widget --> <iframe src="https://inniaosis.app/innioasis-simple-embed.html" width="300" height="120" frameborder="0" style="position: fixed; bottom: 20px; right: 20px; z-index: 999999; border-radius: 12px; box-shadow: 0 8px 32px rgba(0,0,0,0.3);" allowtransparency="true"> </iframe>

📝 Jak z tego korzystać:

  1. Skopiuj powyższy kod
  2. Wklej to do kodu HTML swojej strony
  3. Widżet pojawi się w prawym dolnym rogu
  4. Kliknij, aby przejść do poradników instalacji dla swojego systemu
