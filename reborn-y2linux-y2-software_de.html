Installationsschritte

  1. Öffnen Sie Updater CE. Verfügbar für Windows, macOS und Linux.
  2. Wählen Sie Y2 als Gerätemodell.
  3. Wählen Sie Reborn (Y2Linux) als die Software.
  4. Klicken Sie auf Installieren/Wiederherstellen. Warten Sie, während Updater CE die Dateien vorbereitet.
  5. Verbinden Sie USB, wenn Sie dazu aufgefordert werden. Schalten Sie zuerst den Y2 aus.
  6. Richten Sie WLAN, Bluetooth und UKW-Radio ein

    Kopieren system.img einmal an den Spieler. Reborn erledigt den Rest.
