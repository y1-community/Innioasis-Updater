Innioasis Y2 firmware

The Y2 is the compact player with buttons and a touchscreen. Updater CE installs the firmware that matches the model printed on the player.

Y2 update

The archive lists the Original Software, Solar, Rockbox and the other systems published for the Y2. An update is a newer build of the system you already run. Rockbox on the Y2 replaces that system and brings its own themes.

Open the Y2 archive

Y2 themes

Themes for the Original Software and Solar are the same files as the Y1 themes. Browse them in the Y2 themes gallery. Rockbox themes stay with the Rockbox install.

If the Y2 will not start

Use the recovery guide. The unbrick page collects the same path for people searching for an unbrick.
