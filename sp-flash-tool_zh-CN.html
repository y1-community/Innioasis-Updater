安装方法

SP Flash Tool 内 Innioasis 更新程序 CE

SP Flash Tool 不是单独的下载，并且在应用程序文件夹中找不到任何内容。它是配备 Intel 或 AMD 处理器的 Windows x64 和 Linux x86-64 PC 上 Innioasis Updater CE 中的安装方法。 Choose your firmware the normal way, then set 显示高级设置 > 安装方法 > SP Flash Tool 并安装。

正常路线优先

选择您的固件，然后选择引擎

Updater CE 中的安装始终是相同的过程：选择型号，选择固件和版本，然后运行安装/恢复。 install 方法仅决定哪个 MediaTek 引擎执行刷新。保持开启状态 汽车 除非你有理由固定它，并将其设置为 SP Flash Tool 当你这样做的时候。

哪些计算机有 SP Flash Tool

MediaTek 仅针对 x86-64 发布 SP Flash Tool，因此 Updater CE 在 x86-64 PC 上提供它，而不是在其他地方。应用程序本身比引擎运行在更多的地方。

Windows x64：可用

在 Intel 或 AMD 处理器上为 Windows 10 或 11。的 SP Flash Tool 安装方法及 SP Flash Tool button are both there.

Linux x86-64：可用

运行 Updater CE AppImage 的 64 位 Intel 或 AMD Linux 计算机。相同的安装方法，相同的按钮。

macOS：不可用

SP Flash Tool 对于任何形式的 macOS 都不存在。更新程序 CE 改为使用 MTKClient 安装和恢复，并且没有 SP Flash Tool 安装方法或按钮。让 Mac 保持在引导路线上，或者使用 Mac笔记.

Linux ARM64：不可用

Raspberry Pi、ARM 板和 ARM64 Linux 与 macOS 相同：MediaTek 不提供 ARM 版本，因此 Updater CE 在那里使用 MTKClient。

不确定机器？打开设置并开启 显示高级设置: 如果没有的话 安装方法 使用 SP Flash Tool 选项，该计算机无法运行它。在 macOS 和 ARM64 Linux 上，播放器仍然可以正常安装，因此请使用自动引导路线，并且如果您特别需要 SP Flash Tool，则仅移动到 Windows x64 或 Linux x86-64 PC。

使用 SP Flash Tool 安装您选择的固件

  1. 打开 Updater CE 并选择播放器上打印的型号：Innioasis Y1、Y2、G1、G3、G5、R1 或 PR1，或 Timmkoo 型号。
  2. 选择您想要的软件， 原厂软件 或社区项目，然后选择版本。这是与任何其他安装相同的列表、相同的型号匹配和相同的检查。
  3. 打开 设置 并打开 显示高级设置.
  4. 查找 安装方法 并选择 SP Flash Tool 而不是自动。
  5. 返回安装屏幕并单击 安装 / 恢复.
  6. 当应用程序询问时，将播放器完全关闭，然后根据提示将 USB 数据线直接连接到计算机。使用数据线，而不是仅充电线，并跳过集线器。
  7. 等待 Updater CE 报告安装完成，然后断开电缆并启动播放器。

这就是整个旅程。更新程序 CE 仍提供特定于型号的软件包、MediaTek 下载代理、驱动程序检查和连接提示；选择 SP Flash Tool 仅交换下面的引擎。

将模型分开。 Y1 包和 Y2 包永远不可互换，并且一个模型的分散文件不会描述另一个模型。如果 Updater CE 不提供您选择的型号的固件，请停止并选择为该型号列出的软件包。

SP Flash Tool 按钮的用途

在支持的计算机上，Updater CE 还具有 SP Flash Tool 按钮，打开 MediaTek 的工具以直接使用它，例如使用您自己提供的分散包。常规安装、更新和恢复不需要它：安装方法与为您处理的型号匹配、驱动程序检查和连接提示执行相同的工作。

如果该按钮丢失，则计算机是上述不受支持的系统之一，或者您选择的型号使用不同的流程。在这种情况下，请使用安装方法或引导路径，而不是寻找工具二进制文件。

当 SP Flash Tool 是正确的安装方法时

  • 无法启动的播放器。 SP Flash Tool 的下载模式仍然可以到达预加载器或启动映像已损坏的设备，这是需要仔细恢复工作的地方。
  • 在支持的 PC 上停止的闪存。 如果 Auto 或 MTKClient 在 Windows x64 或 Linux x86-64 计算机上中途停止，则将安装固定到 SP Flash Tool 可以让另一个引擎启动同一软件包。
  • 您值得信赖的工厂包装。 原始软件发布自 固件存档 与它配合得很好，因为恢复库存分区正是 SP Flash Tool 的构建目的。

对于普通更新或首次安装，请保留 安装方法 on Auto.它会选择适合您的模型和平台的引擎，并且应用程序可以让您保持支持的路径，无需额外的设置。

如果安装没有开始

  1. 确认您在 Updater CE 中选择的型号与播放器上打印的型号相匹配，并且列出了相应的软件包。
  2. 连接前请确认播放器已完全断电，并且仅在应用程序提示时进行连接。
  3. 在Windows上，安装MediaTek驱动程序并重新启动；在 Linux 上，检查 USB 中注明的权限 电脑设置.
  4. 直接在计算机上尝试不同的 USB 端口（不使用集线器），然后再次启动安装/恢复。

任何进一步的内容都属于 故障排除。在 macOS 或 ARM64 Linux 上，答案不是不同的按钮：保留 引导安装 并仅在 Windows x64 或 Linux x86-64 PC 上使用 SP Flash Tool。
