為什麼 JJ Launcher 適合您的 Innioasis

JJ Launcher 是最快的。它可以快速掃描大型庫，從任何地方使用硬體按鈕跳過曲目，並讓您無需編寫程式碼即可更改外觀。

為什麼人們選擇它

快速，拇指驅動，您的。

  • 快速圖書館掃描 — 自訂媒體掃描器可對大型程式庫進行分類，無需等待 Android 系統掃描器。
  • 跳過任何螢幕上的曲目 — 全域硬體按鍵映射意味著上一個和下一個始終有效，即使您不在音樂應用程式中也是如此。
  • EQ 預設與隨機播放 — 完全隨機播放和重複模式以及內建裝置等化器預設。
  • 沒有代碼的主題 — 透過複製檔案放入自訂顏色主題，或使用基於 Web 的主題編輯器設計自己的顏色主題並匯出 .zip。
  • 無線檔案上傳 — 託管本機 Wi-Fi 網路伺服器並從 PC 瀏覽器上傳音樂 — 電纜位於抽屜中。
  • 應用程式內藍牙配對 — 無需離開應用程序，即可從啟動器設定掃描並配對藍牙裝置。

社群

社區怎麼說

JJ Launcher 適合那些希望玩家感覺快速、用一根拇指控制方向盤的人。其他幾個項目都是建立在它之上的，這說明了許多關於核心的內容。

社區創建者 doitall 在 Y1 上有一個關於 JJ Launcher 的簡短安裝和故障排除視頻，主題編輯器允許所有者交易和調整外觀，而無需等待新版本。

  • doitall · JJ Launcher 安裝與故障排除

該項目提供什麼

  • 客製化嵌入式媒體掃描儀，可對大型庫進行快速分類
  • 隨機播放、重複模式和內建 EQ 預設
  • 全域硬體鍵映射 — 從任何畫面跳過曲目
  • 主螢幕即時同步專輯封面與曲目訊息
  • 透過複製資料夾無限自訂主題； Y1 用於設計您自己的主題編輯器
  • 從播放專輯封面產生的動態高清模糊背景
  • 應用內藍牙掃描和配對
  • 用於 Wi-Fi 密碼的滾輪優化虛擬鍵盤
  • 透過本機 Wi-Fi 網路伺服器無線 PC 檔案上傳

首先要知道的事情

  • 該專案處於 alpha 階段 - 可能會出現意外錯誤和穩定性問題
  • 在系統軟體2.1.9上進行測試；安裝前檢查您自己的軟體版本
  • 某些藍牙連線可能需要一次性 ADB 權限授予才能進行安全性設定
  • 為網頁編輯器製作的主題需要 Launcher 0.8 或更高版本

開始使用

在更新程式中選擇您的型號，選擇 JJ Launcher，然後安裝穩定版本。這些指南涵蓋配對、上傳和設定主題。
