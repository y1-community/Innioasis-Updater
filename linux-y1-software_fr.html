Étapes d'installation de Linux Y1

  1. Ouvrez Innioasis Updater CE sur votre ordinateur (si vous avez besoin de l'application, Obtenir Updater CE). Ensemble Modèle d'appareil à Y1.
  2. Choisissez Linux pour Y1 (développement) dans Logiciel.
  3. Choisissez la version répertoriée pour Y1.
  4. Cliquez Installer / Restaurer.
  5. Éteignez et connectez le Y1 uniquement lorsque Updater CE le demande.

FAQ

Puis-je restaurer le logiciel d'origine Y1 ?

Oui. Sélectionnez Y1 et le logiciel original dans Updater CE. Le Guide des logiciels boursiers Y1 couvre le chemin de retour.

Est-ce une interface utilisateur quotidienne ?

Il s'agit d'un port expérimental pour les développeurs et les bricoleurs Linux. Les instructions du terminal et de la console se trouvent dans la documentation du projet.

Utilisez l'itinéraire guidé

Vous utilisez Updater pour la première fois ? Consultez la configuration guidée pour Obtenir Updater CE sous Windows, macOS ou Linux avant de connecter votre lecteur.
