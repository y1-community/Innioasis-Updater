Etapas de instalação do Linux Y1

  1. Abra Innioasis Updater CE no seu computador (se precisar do aplicativo, Obtenha o atualizador CE). Definir Modelo do dispositivo para Y1.
  2. Escolher Linux para Y1 (Desenvolvedor) em Programas.
  3. Escolha o lançamento listado para Y1.
  4. Clique Instalar / Restaurar.
  5. Desligue e conecte o Y1 somente quando Updater CE solicitar.

Perguntas frequentes

Posso restaurar o software padrão Y1?

Sim. Selecione Y1 e Software Original em Updater CE. O Y1 guia de software de estoque cobre o caminho de retorno.

Esta é uma interface de usuário cotidiana?

Esta é uma porta experimental para desenvolvedores e criadores de Linux. As instruções do terminal e do console estão nos documentos do projeto.

Use a rota guiada

Primeira vez usando o Updater? Veja a configuração guiada para Obtenha o atualizador CE no Windows, macOS ou Linux antes de conectar seu player.
