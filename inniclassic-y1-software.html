Inniclassic Y1 install steps

  1. Open Innioasis Updater CE on your computer (if you need the app, Get Updater CE). Set Device Model to Y1.
  2. Choose Inniclassic in Software.
  3. Choose the release listed for Y1.
  4. Click Install / Restore.
  5. Power off and connect the Y1 only when Updater CE asks.

FAQs

Can I restore the stock Y1 software?

Yes. Select Y1 and Original Software in Updater CE. The Y1 stock-software guide covers the return path.

What if installation fails?

Note whether Updater failed before or after detecting the Y1, then check the cable, platform setup, model, and connection timing in troubleshooting.

Can I use Inniclassic on Y2?

Yes. Inniclassic is available on both models — the same maintained project publishes a Y2 package from the same releases. Select Y2 in Updater CE and install the Y2 build; never flash a Y1 package to a Y2. The Y2 install page covers it.
