The text session.

This page is for people working on Updater CE. It is not a promoted way to install the app. The AppImage, the tarball and the zip still open the window when they are started with no flag. The window's flashing path is unchanged.

How to open it

--tui opens Select Software in the terminal: Brand, Model, Type, Software, the release list, notes, Install, Install from a file, Settings, Support, Language and Credits. A mouse click and the keyboard both complete that journey. --cli is the non-interactive command path. Windows, macOS and Linux use the same entry. Windows has no curses in the standard library, so it uses numbered prompts; a terminal that reports mouse clicks still selects a row.

python3 launcher.py --tui
python3 launcher.py --cli list --model Y1

Streamed Linux installer

run_linux_lite.sh, also served at https://innioasis.app/run_linux_lite.sh, is the Linux text session for a headless machine or a 32-bit Intel or ARM board. It does not install the Qt window. On those machines, and whenever there is no display, the session says so and uses MTKclient (mtk wl <folder>) instead of the Qt SP Flash Tool window. SP Flash Tool remains the Linux x86_64 tool.

When tools are downloaded

A component that is already inside the AppImage, the tarball, the portable zip, or the user tool cache is not downloaded again. On a measured link above 60 Mbps the session prefetches the tools that session will need before the menu. At 60 Mbps or below, or if the probe fails, each file is fetched at the step that needs it, with progress. adb is fetched for a Rockbox step. On Linux x86_64 with a display, SP Flash Tool is fetched before the first install that needs it, then run with the same console arguments the window uses.
