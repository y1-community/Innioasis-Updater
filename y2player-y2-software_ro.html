Y2Player install steps

  1. Deschideți Innioasis Updater CE pe computer (dacă aveți nevoie de aplicație, Obține Updater CE). Setați Model dispozitiv la Y2.
  2. Alege Y2Player in Software.
  3. Choose a release listed for Y2.
  4. Faceți clic Instalează / Restaurează.
  5. Power off and connect the Y2 at the live prompt.

Some Y2 full-install packages use rom_y2.zip. Let Updater choose the package when possible.

Întrebări frecvente

Can I go back to the original software?

Yes. Select Y2 and Original Software in Updater CE, then follow the Ghid de restaurare Y2.

Can I use this on a Y1?

No. This page is for the Y2Player Y2 entry. Keep Y1 and Y2 packages separate.

What if the Y2 is not detected?

Check platform setup, cable, power-off state, model selection, and timing. Use depanare before trying manual recovery.
