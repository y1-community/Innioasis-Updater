Install Y2Reborn on the Y2.

Y2Reborn is the native Linux custom firmware for the Innioasis Y2. Built by Schulzcode with a high-performance Rust player, it features 60 FPS GPU graphics, Wi-Fi Internet Radio, Last.fm scrobbling, and OTA updates.

Y2Reborn install steps

  1. Open Innioasis Updater CE on your computer (if you need the app, Get Updater CE). Set Device Model to Y2.
  2. Choose Y2Reborn in Software (or use Get this in Updater CE to jump to the guided steps).
  3. Choose a release listed for Y2 (installs rom_y2.zip).
  4. Click Install / Restore.
  5. Power off and connect the Y2 at the live prompt.

Y2 full-install packages use rom_y2.zip. Let Updater CE manage the extraction and flashing process.

FAQs

What is Y2Reborn?

Y2Reborn is a custom operating system that replaces Android with native Linux (Y2Linux Buildroot) and runs a native Rust player binary (reborn) by Schulzcode. It features direct GPU hardware acceleration at 60 FPS, ALSA bit-perfect wired audio, LDAC/AAC Bluetooth, 47 AutoEQ presets, Wi-Fi Internet Radio, Last.fm scrobbling, and OTA system updates.

Can I restore the factory software later?

Yes. Select Y2 and Original Software in Updater CE to flash the stock Android ROM back to your device at any time. The Y2 restore guide covers the complete process.

Can I use this on a Y1?

No. Y2Reborn is built specifically for the Innioasis Y2 hardware. Y1 and Y2 packages are completely incompatible.

How do Over-The-Air (OTA) updates work?

Once installed and connected to Wi-Fi, you can update Y2Reborn directly from the device by navigating to Settings -> About & Updates -> Update Now without needing a computer.

What if the Y2 is not detected during installation?

Ensure the player is completely powered off before connecting the USB cable, use a high-quality data cable, and check the platform setup in troubleshooting.
