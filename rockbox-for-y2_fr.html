Rockbox-Y2 · Innioasis Y2

Rockbox pour Y2 (Rockbox-Y2)

Rockbox-Y2 (également appelé « Rockbox pour Y2 ») est le port du micrologiciel communautaire dédié Rockbox pour le Innioasis Y2. Il utilise son propre package ROM (rom_y2.zip) et est installé directement via Innioasis Updater CE.

Installer Rockbox-Y2 Téléchargez le ROM Tutoriel écrit Rockbox-Concentrateur Y2

Conçu spécifiquement pour le Innioasis Y2

Dans Innioasis Updater CE, ce firmware est répertorié comme Rockbox quand Y2 est sélectionné. Ses sorties sont publiées par le spycemagic/y2-rockbox projet avec le nom du package rom_y2.zip.

N'installez jamais un package de micrologiciel Y1 sur un Y2. Sélection Y2 in Updater CE filtre automatiquement la liste des versions sur les versions compatibles avec Y2 uniquement.

Ce que propose Rockbox-Y2

  • Bibliothèque musicale basée sur des tags - parcourez les albums, les artistes et les genres à partir des balises de vos fichiers audio ou parcourez directement les dossiers.
  • Commandes de lecture - Paramètres de lecture sans interruption, de fondu enchaîné, de ReplayGain et d'égaliseur.
  • Thèmes personnalisés — installez des thèmes compatibles avec votre build Rockbox-Y2 (Y2 guide thématique).
  • 100% hors ligne — lit les fichiers locaux de votre carte MicroSD sans compte ni abonnement.
  • Restauration d'usine facile — revenir à Y2 Logiciel d'origine à tout moment dans Updater CE.

Choisir une version Rockbox-Y2

  • Sélectionnez toujours Y2 dans Modèle d'appareil d'abord.
  • Choisissez la dernière version, sauf si vous testez une version spécifique.
  • Lire le Rockbox-Notes de version Y2 pour voir ce qui a changé dans chaque build.

Téléchargements directs des développeurs de la communauté

Innioasis Updater CE télécharge toujours les packages de micrologiciels directement auprès des développeurs de micrologiciels de la communauté (spycemagic/y2-rockbox), et ces développeurs sont seuls responsables de la liste de leurs versions logicielles dans Updater CE.

Vous pouvez laisser Updater CE télécharger et flasher rom_y2.zip automatiquement, ou téléchargez le package depuis notre Rockbox-Y2 page de téléchargement et Rockbox ROM page de téléchargement.

Comment installer Rockbox-Y2

  1. Ouvrez Innioasis Updater CE et définissez Modèle d'appareil à Y2.
  2. Sélectionnez Rockbox dans Logiciel.
  3. Choisissez une version Y2 dans la liste.
  4. Cliquez Installer / Restaurer donc Updater CE télécharge le package directement depuis le développeur.
  5. Éteignez complètement le Y2 et connectez-le avec un câble de données USB lorsque Updater CE le demande.
  6. Attendez le message de fin, puis débranchez et allumez votre Y2.

Pour la procédure complète étape par étape, lisez le Rockbox-Y2 tutoriel.

Restauration du logiciel Y2 d'origine

Pour revenir au firmware d'usine, sélectionnez Y2 et Logiciel d'origine dans Updater CE, choisissez une version stable et cliquez sur Installer / Restaurer. Voir le guide de restauration et Y2 Page du logiciel d'origine.

Questions fréquemment posées

D'où Updater CE télécharge-t-il Rockbox-Y2 ?

Updater CE télécharge toujours les packages de micrologiciels directement à partir des propres versions des développeurs de micrologiciels de la communauté (spycemagic/y2-rockbox). Les développeurs sont seuls responsables de répertorier leurs versions logicielles dans Updater CE.

Pourquoi le package est-il nommé rom_y2.zip ?

Le développeur nomme l'archive du firmware Y2 rom_y2.zip donc il ne peut pas être confondu avec les Y1 rom.zip.

Les thèmes Y1 fonctionnent-ils sur le Y2 ?

Pas toujours. Consultez les notes de version de votre build Y2 et consultez les Rockbox-Y2 guide thématique.
