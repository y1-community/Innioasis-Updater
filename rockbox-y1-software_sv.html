Rockbox Y1 installationssteg

  1. Öppna Innioasis Updater CE på din dator (om du behöver appen, Hämta Updater CE). Ställ in Enhetsmodell till Y1.
  2. Välj Rockbox i Programvara.
  3. Välj den version och variant som matchar din avsedda skärm eller temasökväg.
  4. Klicka Installera / Återställ och vänta på att appen förbereder den.
  5. Stäng av och anslut Y1 endast vid direktuppmaningen.

Använd skriven Rockbox Y1 guide för skärmdumpar, video, Type A eller Type B anteckning och anslutningschecklista.

Vanliga frågor

Kan jag gå tillbaka till den ursprungliga Y1-mjukvaran?

Ja. Välj Y1 och originalprogramvara i Updater CE och kör sedan Install/Restore. Den Y1 sida med lagerprogramvara förklarar den vägen.

Vilken Rockbox version ska jag välja?

Välj en version som visas för Y1 och läs dess releasenot. Om du behöver äldre temakompatibilitet, kontrollera upplösningen och variantanteckningarna istället för att välja en Y2-build.

Kan jag installera detta på en Y2?

Nej. Använd den separata Rockbox Y2 sida och välj Y2 i Updater CE.
