Rockbox завантажень ПЗУ

Rockbox ROM завантажити для Y1 і Y2

Завантажте Rockbox пакети вбудованого ПЗУ для Innioasis Y1 (Rockbox-Y1) і Y2 (Rockbox-Y2) безпосередньо від розробників спільноти або встановіть одним клацанням миші за допомогою Innioasis Updater CE.

Спочатку виберіть модель плеєра

Rockbox-Y1 і Rockbox-Y2 — це окремі версії прошивки, створені для різного обладнання. Перевірте, чи є ваш плеєр Innioasis Y1 або Y2 перед завантаженням або прошивкою.

Як Updater CE завантажує прошивку

Innioasis Updater CE завжди завантажує пакети мікропрограм безпосередньо з власних випусків мікропрограм спільноти розробників, і самі розробники несуть виключну відповідальність за перелік своїх випусків програмного забезпечення в Updater CE. Кожен пакет ROM містить файл розкиду MediaTek і зображення розділів для цієї моделі.

  • Rockbox-Y1 пакет випуску для розробників: rom.zip (і rom_type_b.zip для Type B Y1 одиниць).
  • Rockbox-Y2 пакет випуску для розробників: rom_y2.zip.

Встановити автоматично за допомогою Updater CE

Для найпростішого налаштування відкрийте Innioasis Updater CE, виберіть модель плеєра та Rockbox, а потім дозвольте додатку завантажити та оновити випуск безпосередньо. Дотримуйтесь Rockbox-Y1 посібник із встановлення або Rockbox-Y2 посібник із встановлення.
