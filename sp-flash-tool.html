Install method

SP Flash Tool inside Innioasis Updater CE

SP Flash Tool is not a separate download and there is nothing to find in the app folder. It is an install method in Innioasis Updater CE on Windows x64 and Linux x86-64 PCs with Intel or AMD processors. Choose your firmware the normal way, then set Show Advanced Settings > Install method > SP Flash Tool and install.

The normal route comes first

Pick your firmware, then pick the engine

An install in Updater CE is always the same journey: select your model, choose the firmware and release, then run Install / Restore. The install method only decides which MediaTek engine performs the flash. Leave it on Auto unless you have a reason to pin it, and set it to SP Flash Tool when you do.

Which computers have SP Flash Tool

MediaTek publishes SP Flash Tool for x86-64 only, so Updater CE offers it on x86-64 PCs and nowhere else. The app itself runs in more places than the engine does.

Windows x64: available

Windows 10 or 11 on an Intel or AMD processor. The SP Flash Tool install method and the SP Flash Tool button are both there.

Linux x86-64: available

A 64-bit Intel or AMD Linux machine running the Updater CE AppImage. Same install method, same button.

macOS: not available

SP Flash Tool does not exist for macOS in any form. Updater CE installs and restores with MTKClient instead, and there is no SP Flash Tool install method or button. Keep the Mac on the guided route, or use the Mac notes.

Linux ARM64: not available

Raspberry Pi, ARM boards and ARM64 Linux are the same story as macOS: MediaTek ships no ARM build, so Updater CE uses MTKClient there.

Not sure about a machine? Open Settings and turn on Show Advanced Settings: if there is no Install method with an SP Flash Tool option, that computer cannot run it. On macOS and ARM64 Linux the player still installs normally, so use the guided route with Auto and only move to a Windows x64 or Linux x86-64 PC if you specifically need SP Flash Tool.

Install your chosen firmware with SP Flash Tool

  1. Open Updater CE and select the model printed on your player: Innioasis Y1, Y2, G1, G3, G5, R1 or PR1, or a Timmkoo model.
  2. Choose the software you want, Original Software or a community project, then choose the release. This is the same list, the same model match and the same checks as any other install.
  3. Open Settings and turn on Show Advanced Settings.
  4. Find Install method and choose SP Flash Tool instead of Auto.
  5. Return to the install screen and click Install / Restore.
  6. Power the player fully off when the app asks, then connect the USB data cable directly to the computer at the prompt. Use a data cable, not a charge-only cable, and skip hubs.
  7. Wait for Updater CE to report that the install finished, then disconnect the cable and start the player.

That is the whole journey. Updater CE still supplies the model-specific package, the MediaTek download agent, the driver checks and the connect prompt; choosing SP Flash Tool only swaps the engine underneath.

Keep the models separate. A Y1 package and a Y2 package are never interchangeable, and a scatter file from one model does not describe the other. If Updater CE does not offer the firmware for the model you selected, stop and pick the package listed for that model instead.

What the SP Flash Tool button is for

On a supported computer, Updater CE also has an SP Flash Tool button that opens MediaTek's tool for working with it directly, for example with a scatter package you supplied yourself. Routine installs, updates and restores do not need it: the install method does the same work with the model matching, driver checks and connect prompts handled for you.

If the button is missing, the computer is one of the unsupported systems above, or your selected model uses a different flow. Use the install method or the guided route in that case rather than looking for a tool binary.

When SP Flash Tool is the right install method

  • A player that will not boot. SP Flash Tool's download mode can still reach a device whose preloader or boot image is damaged, which is where careful recovery work happens.
  • A flash that stalls on a supported PC. If Auto or MTKClient stops partway on a Windows x64 or Linux x86-64 machine, pinning the install to SP Flash Tool gives the other engine a turn on the same package.
  • A factory package you trust. Original Software releases from the firmware archive pair well with it, because restoring stock partitions is exactly what SP Flash Tool is built for.

For an ordinary update or a first install, leave Install method on Auto. It picks the engine that suits your model and platform, and the app keeps you on the supported path without extra settings.

If the install does not start

  1. Confirm the model you selected in Updater CE matches the model printed on the player, and that the package is listed for it.
  2. Confirm the player is fully powered off before you connect it, and connect only at the app's prompt.
  3. On Windows, install the MediaTek driver and restart; on Linux, check the USB permissions noted in computer setup.
  4. Try a different USB port straight on the computer, without a hub, and start Install / Restore again.

Anything further belongs in troubleshooting. And on macOS or ARM64 Linux, the answer is not a different button: keep the guided install and use SP Flash Tool only from a Windows x64 or Linux x86-64 PC.
