Installation Steps

  1. Open Updater CE. Available for Windows, macOS and Linux.
  2. Select Y2 as the device model.
  3. Select Reborn (Y2Linux) as the software.
  4. Click Install / Restore. Wait while Updater CE prepares the files.
  5. Connect USB when asked. Power the Y2 off first.
  6. Set up Wi-Fi, Bluetooth & FM radio
