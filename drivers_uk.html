Налаштування комп'ютера

Підготуйте комп’ютер перед гравцем.

Більшість проблем із підключенням виникають через драйвер, дозволи, кабель або час. Для Windows потрібно встановити драйвер MediaTek. Linux потрібні відповідні USB дозволи. Знайдіть свою платформу нижче.

Отримати Updater CEУсунення несправностей

Windows

  1. Завантажте програму встановлення драйвера MediaTek нижче.
  2. Запустіть інсталятор і дозвольте Windows інсталювати драйвер.
  3. Перезавантажте комп'ютер.
  4. Відкрийте Updater CE і дочекайтеся підказки підключення, перш ніж підключати вимкнений плеєр.

Деякі системи Windows блокують драйвер через ізоляцію ядра (цілісність пам’яті). Якщо Updater CE все ще не бачить програвач після перезапуску, вимкніть цілісність пам’яті в Безпеці Windows, перезапустіть і перевстановіть драйвер. Увімкніть налаштування знову, коли закінчите, якщо ваша система це дозволяє.

Windows не запускає програму? Якщо Безпека Windows або функція розумного керування програмами блокує відкриття Updater CE, відкрийте Налаштування (прес Win + I) → Конфіденційність і безпека → Windows Security → Керування додатком і браузером → Налаштування Smart App Control і встановіть його Вимкнено. Функція розумного керування програмами наразі впливає на популярні програми, такі як Epic Overlay Service (використовується Fortnite) — Updater CE безпечний і перевірений. Щоб увімкнути знову пізніше, установіть VerifiedAndReputablePolicyState для 1 (Увімкнено) або 2 (Режим оцінювання) під HKEY_LOCAL_MACHINE\SYSTEM\CurrentControlSet\Control\CI\Policy у Редакторі реєстру.

Дозволи Linux USB.

Linux потрібен ваш обліковий запис користувача, щоб мати доступ до мікросхеми MediaTek USB у програвачі. Програма оновлення CE зазвичай вирішує це під час встановлення, і той самий дозвіл стосується SP Flash Tool, тому сприймайте це як крок виправлення, а не як звичайний етап.

  1. Запустіть Updater CE як звичайний користувач, а не як root. Інсталятор запитує доступ адміністратора лише тоді, коли він потрібен.
  2. Перевірте плеєр взагалі видно. Вимкніть плеєр, підключіть кабель і запустіть команду lsusb у терміналі. Підключений програвач відображається як пристрій MediaTek з ідентифікатором постачальника 0e8d.
lsusb
  1. Якщо він з’являється в lsusb, але Innioasis Updater CE або SP Flash Tool повідомляє, що дозвіл заборонено або не може відкрити порт, ваш користувач не має доступу до пристрою USB. Те саме правило udev охоплює обидва інструменти, тому додайте той, який дозволяє групі користувачів читати його.
SUBSYSTEM=="usb", ATTR{idVendor}=="0e8d", MODE="0666", GROUP="plugdev"

Збережіть цей рядок у новому файлі під назвою /etc/udev/rules.d/51-innioasis.rules, а потім запустіть:

sudo udevadm control --reload && sudo udevadm trigger
  1. Повністю від'єднайте плеєр, підключіть його знову та повторіть спробу інсталяції.
  2. Якщо SP Flash Tool повідомляє про послідовний дозвіл або гонку портів, повністю від’єднайте та повторно підключіться, лише коли буде запропоновано.
Не імпровізуйте флеш-зміщення.Якщо ви переходите на інструмент відновлення вручну, використовуйте файли та конфігурацію для конкретної моделі, які постачаються разом із проектом.

Кабель і ГРМ

  1. Використовуйте відомий кабель передачі даних USB.
  2. Уникайте концентраторів під час усунення несправностей.
  3. Повністю вимкніть правильну модель.
  4. Підключайтеся лише за підказкою.
