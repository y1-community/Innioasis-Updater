Install Rockbox-Y1 360p themes by hand on Linux

Copy the 360p Rockbox-Y1 themes onto an Innioasis Y1 from Linux: download the theme pack, unzip it, merge its .rockbox folder into the player's, then pick a theme. Works on Rockbox-Y1 0.5 or later.

Before you start

  • Rockbox-Y1 0.5 or later on any Y1. These are 360p themes; 0.5 and later is 360p only.
  • A USB data cable. Charge-only cables don't show the player as a drive.
  • About 400 MB free on your computer for the theme pack and its unzipped copy.

Install, step by step

  1. Download the theme pack below. It holds every theme as one merged .rockbox folder. The individual themes download has each theme in its own folder, each with its own .rockbox inside.
  2. Right-click the zip and choose Extract Here, or run unzip in a terminal.
  3. Start Rockbox on the Y1 once before you begin. Rockbox makes its .rockbox folder on the first start.
  4. Plug the Y1 into your computer with a USB data cable. When the player asks, choose USB Storage Mode. It mounts like any USB drive, usually under /media/<you>/ or /run/media/<you>/.
  5. Show hidden items and open the Y1's .rockbox folder (how to show it on Linux).
  6. Open the theme's own .rockbox folder. Keep hidden files showing.
  7. Select everything inside it and copy it into the Y1's .rockbox folder.
  8. GNOME Files asks to Merge folders that already exist: choose it, then Replace for files. In Dolphin the folder button is Write Into, then Overwrite for files.
  9. Prefer a terminal? cp -r ~/Downloads/THEME/.rockbox/. /media/$USER/Y1/.rockbox/ merges and overwrites in one go. Use your own paths.
  10. Click the eject icon next to the Y1 in your file manager, wait for it to finish, then unplug.
  11. On the Y1, open Settings → Theme Settings → Browse Theme Files and pick a theme.

On a Y2

The same 360p files can be copied by hand onto a Y2 running Rockbox-Y2: merge them into the .rockbox folder Rockbox-Y2 made on the player. Rockbox-Y2 is a separate port, so read the release notes for your version first. Updater CE's automatic theme install is for Rockbox-Y1.

Frequently asked questions

A theme I used before 0.5 no longer works.

Rockbox-Y1 0.5 moved its files. The release notes say to change paths inside old theme files from /.rockbox to /sdcard/.rockbox. The themes in this pack are already updated.

Can I use 240p themes?

Not on Rockbox-Y1 0.5 or later, which is 360p only. 240p themes need a 240p build: 240p builds can't be used on a Y1 bought new after May 2026, or on any Y1 that shipped with Original Software 3.0.7 or later. Flashing one there stops the player from starting.

Will this delete my settings?

No, as long as you merge. Replacing the whole .rockbox folder would.
