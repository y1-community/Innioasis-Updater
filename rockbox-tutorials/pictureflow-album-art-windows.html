Add album art for Rockbox PictureFlow with Mp3tag on Windows

Make PictureFlow on your Innioasis Y1 show every album cover: add the art with Mp3tag on Windows, copy the music across, then let Rockbox build its database and PictureFlow cache.

Using another computer? macOS · Windows · Linux

Get the art right first

  • Use a square JPEG. Rockbox doesn't show progressive JPEGs; if a cover stays blank, re-save it as a standard JPEG.
  • Big images aren't sharper on a 480×360 screen; they just make the cache slower to build. 500×500 is plenty.
  • One cover per album: PictureFlow groups by the album tag, so tracks with matching album and artist tags stay together.

Add the covers with Mp3tag

  1. Install Mp3tag for Windows from mp3tag.de.
  2. Choose File → Change Directory and open one album's folder.
  3. Select every track of that album (Ctrl+A).
  4. In the Tag Panel on the left, right-click the cover box and choose Add cover, then pick the image. Dragging the image onto the box works too.
  5. Save with Ctrl+S. The cover is now inside every selected file.

Put them on the Y1

  1. Start Rockbox on the Y1 once before you begin. Rockbox makes its .rockbox folder on the first start.
  2. Plug the Y1 into your computer with a USB data cable. When the player asks, choose USB Storage Mode. It shows up in File Explorer under This PC as a new drive.
  3. Copy your albums to the player in File Explorer.
  4. Right-click the Y1's drive in File Explorer, choose Eject, then unplug.
  5. On the Y1, open Settings → General Settings → Database and choose Initialize Now.
  6. Open Plugins → Demos → PictureFlow. The first start builds its cover cache, which takes a while with a big library.

Frequently asked questions

New albums don't show up in PictureFlow.

Update the database again, then rebuild PictureFlow's cache from its own settings menu.

Some covers are blank.

Check the image is a standard (baseline) JPEG and that every track of the album carries the same album tag.
