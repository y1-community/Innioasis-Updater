Find the hidden .rockbox folder on your Y1 from Windows

Rockbox keeps themes, fonts and settings in a hidden .rockbox folder. Here's how to connect your Innioasis Y1 in USB Storage Mode and show that folder in File Explorer on Windows.

Using another computer? macOS · Windows · Linux

Show .rockbox, step by step

  1. Start Rockbox on the Y1 once before you begin. Rockbox makes its .rockbox folder on the first start.
  2. Plug the Y1 into your computer with a USB data cable. When the player asks, choose USB Storage Mode. It shows up in File Explorer under This PC as a new drive.
  3. Open the Y1's drive in File Explorer. Windows usually shows .rockbox straight away: a leading dot doesn't hide a folder on Windows.
  4. Can't see it? On Windows 11 choose View → Show → Hidden items. On Windows 10 open the View tab and tick Hidden items.
  5. Open .rockbox.

What's inside

  • themes: the small .cfg file that names each theme.
  • wps, backdrops, icons, fonts: the parts a theme is made of.
  • Your settings, playlists and the music database also live here, so copy into it rather than replacing it.

When you're done

Right-click the Y1's drive in File Explorer, choose Eject, then unplug.

Frequently asked questions

I can't see .rockbox at all, even with hidden items on.

Start Rockbox on the Y1 once, then connect again. The folder only exists after Rockbox has started.

Can I delete .rockbox?

Yes, if you want a clean start. Rockbox makes a new one with default settings on the next start, and the Rockbox-Y1 0.5 release notes suggest it as a fix for odd path problems. Your themes and settings go with it.
