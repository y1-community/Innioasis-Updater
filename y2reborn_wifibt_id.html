Unduh system.img (860 MB) Panduan Instalasi Mengapa Y2Reborn?

Mengapa file ini?

Wi-Fi, Bluetooth, dan radio FM memerlukan lima modul firmware MediaTek yang Reborn tidak dapat dikirimkan. Mereka berada di dalam Y2 resmi system.img. Reborn mengekstraknya satu kali, memeriksanya, dan menghapus file.

Pengaturan

  1. Unduh sistem.img

    Unduh FM v3.2.0 system.img ke komputer Anda.

    Unduh sistem.img
  2. Boot Reborn sekali

    Nyalakan pemutar. Tunggu Menyiapkan penyimpanan untuk menyelesaikan, lalu mulai ulang sekali.

  3. Hubungkan ke komputer Anda

    Gunakan kabel data USB. Pemain muncul sebagai Penyimpanan Internal.

    Di Mac?

    Instal BukaMTP untuk menelusuri pemutar. Windows dan Linux memasangnya secara otomatis.

  4. Salin system.img ke Firmware

    Buat folder bernama Firmware di akar Penyimpanan Internal. Salin system.img ke dalamnya.

  5. Tunggu hingga pengaturan selesai

    Reborn menginstal firmware radio secara otomatis dan menghapusnya system.img. Ini membutuhkan waktu sekitar 10–20 detik. Tunggu Wi-Fi dan Bluetooth sudah siap.

  6. Hubungkan Wi-Fi, Bluetooth, dan radio FM
    • Wi-Fi: Pengaturan → Sistem → Jaringan → Wi-Fi. Pilih jaringan 2,4 GHz Anda.
    • Bluetooth: Letakkan headphone Anda dalam mode berpasangan. Pengaturan → Bluetooth → pilih.
    • Radio FM: Colokkan headphone berkabel sebagai antena, lalu buka Radio FM.
  7. Perbarui melalui Wi-Fi

    Pembaruan Reborn di masa mendatang diinstal dari Pengaturan → Sistem → Pembaruan Perangkat Lunak. Firmware radio Anda tetap terpasang.
