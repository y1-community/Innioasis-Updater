설치 방법

Innioasis 업데이터 CE 내부 SP Flash Tool

SP Flash Tool은 별도의 다운로드가 아니며 앱 폴더에서 찾을 수 있는 내용이 없습니다. Intel 또는 AMD 프로세서가 탑재된 Windows x64 및 Linux x86-64 PC에 Innioasis Updater CE를 설치하는 방법입니다. 일반적인 방법으로 펌웨어를 선택한 다음 설정하십시오. 고급 설정 표시 > 설치 방법 > SP Flash Tool 그리고 설치하세요.

일반 경로가 먼저 옵니다.

펌웨어를 선택한 다음 엔진을 선택하세요.

Updater CE의 설치 과정은 항상 동일합니다. 모델을 선택하고 펌웨어와 릴리스를 선택한 다음 설치/복원을 실행하세요. 설치 방법은 플래시를 수행하는 MediaTek 엔진만 결정합니다. 그대로 두세요 자동 고정할 이유가 없다면 다음과 같이 설정하세요. SP Flash Tool 당신이 할 때.

SP Flash Tool이(가) 있는 컴퓨터

MediaTek은 x86-64용으로만 SP Flash Tool을 게시하므로 Updater CE는 x86-64 PC에서만 제공하며 다른 곳에서는 제공하지 않습니다. 앱 자체는 엔진보다 더 많은 곳에서 실행됩니다.

Windows x64: 사용 가능

Windows 10 또는 Intel 또는 AMD 프로세서의 경우 11입니다. 는 SP Flash Tool 설치 방법과 SP Flash Tool 버튼이 둘 다 있어요.

Linux x86-64: 사용 가능

Updater CE AppImage를 실행하는 64비트 Intel 또는 AMD Linux 시스템. 동일한 설치 방법, 동일한 버튼.

macOS: 사용할 수 없음

SP Flash Tool은(는) 어떤 형태로든 macOS에 대해 존재하지 않습니다. Updater CE는 대신 MTKClient로 설치 및 복원하며, SP Flash Tool 설치 방법이나 버튼은 없습니다. Mac을 안내 경로에 유지하거나 맥 노트.

Linux ARM64: 사용할 수 없음

Raspberry Pi, ARM 보드 및 ARM64 Linux은 macOS과 동일합니다. MediaTek는 ARM 빌드를 제공하지 않으므로 Updater CE는 거기에서 MTKClient을 사용합니다.

기계에 대해 잘 모르시나요? 설정을 열고 켜세요. 고급 설정 표시: 없는 경우 설치 방법 SP Flash Tool 옵션을 사용하면 해당 컴퓨터에서 실행할 수 없습니다. macOS 및 ARM64 Linux에서 플레이어는 여전히 정상적으로 설치되므로 자동으로 안내 경로를 사용하고 SP Flash Tool가 특별히 필요한 경우에만 Windows x64 또는 Linux x86-64 PC로 이동하세요.

SP Flash Tool을(를) 사용하여 선택한 펌웨어를 설치하세요.

  1. Updater CE를 열고 플레이어에 인쇄된 모델을 선택하십시오: Innioasis Y1, Y2, G1, G3, G5, R1 또는 PR1 또는 Timmkoo 모델.
  2. 원하는 소프트웨어를 선택하고, 원본 소프트웨어 또는 커뮤니티 프로젝트를 선택한 다음 릴리스를 선택하세요. 이는 다른 설치와 동일한 목록, 동일한 모델 일치 및 동일한 점검입니다.
  3. 열기 설정 그리고 켜 고급 설정 표시.
  4. 찾기 설치 방법 그리고 선택 SP Flash Tool 자동 대신.
  5. 설치 화면으로 돌아가서 다음을 클릭하세요. 설치 / 복원.
  6. 앱에서 요청할 때 플레이어의 전원을 완전히 끈 다음, 메시지가 나타나면 USB 데이터 케이블을 컴퓨터에 직접 연결하세요. 충전 전용 케이블이 아닌 데이터 케이블을 사용하고 허브를 건너뛰십시오.
  7. Updater CE가 설치가 완료되었음을 보고할 때까지 기다린 다음 케이블을 분리하고 플레이어를 시작하십시오.

그것이 전체 여행입니다. 업데이터 CE는 여전히 모델별 패키지, MediaTek 다운로드 에이전트, 드라이버 확인 및 연결 프롬프트를 제공합니다. SP Flash Tool을 선택하면 아래에 있는 엔진만 교체됩니다.

모델을 별도로 유지하십시오. Y1 패키지와 Y2 패키지는 서로 바꿔 사용할 수 없으며 한 모델의 스캐터 파일은 다른 모델을 설명하지 않습니다. Updater CE가 선택한 모델에 대한 펌웨어를 제공하지 않는 경우 중지하고 대신 해당 모델에 대해 나열된 패키지를 선택하십시오.

SP Flash Tool 버튼의 용도

지원되는 컴퓨터에서는 Updater CE에도 다음이 있습니다. SP Flash Tool 예를 들어 직접 제공한 스캐터 패키지를 사용하여 직접 작업하기 위한 MediaTek 도구를 여는 버튼입니다. 일상적인 설치, 업데이트 및 복원에는 필요하지 않습니다. 설치 방법은 모델 일치, 드라이버 확인 및 연결 프롬프트 처리와 동일한 작업을 수행합니다.

버튼이 없으면 컴퓨터가 위에서 지원되지 않는 시스템 중 하나이거나 선택한 모델이 다른 흐름을 사용하는 것입니다. 이 경우 도구 바이너리를 찾는 대신 설치 방법이나 안내 경로를 사용하세요.

SP Flash Tool이 올바른 설치 방법인 경우

  • 부팅되지 않는 플레이어. SP Flash Tool의 다운로드 모드는 프리로더나 부팅 이미지가 손상된 장치에 계속 도달할 수 있으며, 여기서는 신중한 복구 작업이 수행됩니다.
  • 지원되는 PC에서 멈추는 플래시. Auto 또는 MTKClient이 Windows x64 또는 Linux x86-64 시스템에서 중간에 중지되는 경우 설치를 SP Flash Tool에 고정하면 다른 엔진이 동일한 패키지를 켤 수 있습니다.
  • 당신이 신뢰하는 공장 패키지. 원본 소프트웨어 릴리스 펌웨어 아카이브 스톡 파티션을 복원하는 것이 정확히 SP Flash Tool의 목적이기 때문에 그것과 잘 어울립니다.

일반적인 업데이트나 첫 설치의 경우에는 그대로 두세요. 설치 방법 자동에. 귀하의 모델과 플랫폼에 적합한 엔진을 선택하고 앱은 추가 설정 없이 지원되는 경로를 계속 유지합니다.

설치가 시작되지 않는 경우

  1. Updater CE에서 선택한 모델이 플레이어에 인쇄된 모델과 일치하는지, 해당 모델에 대한 패키지가 나열되어 있는지 확인하세요.
  2. 연결하기 전에 플레이어의 전원이 완전히 꺼졌는지 확인하고, 앱 프롬프트에서만 연결하세요.
  3. Windows에서 MediaTek 드라이버를 설치하고 다시 시작합니다. Linux에서 다음에 언급된 USB 권한을 확인하세요. 컴퓨터 설정.
  4. 허브 없이 컴퓨터의 다른 USB 포트를 직접 사용해 보고 설치/복원을 다시 시작하세요.

그 이상은 다음에 속합니다. 문제 해결. 그리고 macOS 또는 ARM64 Linux에서 대답은 다른 버튼이 아닙니다. 안내 설치 Windows x64 또는 Linux x86-64 PC에서만 SP Flash Tool을 사용하세요.
