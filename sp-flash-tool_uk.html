SP Flash Tool в Innioasis Updater CE

SP Flash Tool не є окремим завантаженням, і в папці програми нічого не можна знайти. Це метод встановлення в Innioasis Updater CE на Windows x64 і Linux x86-64 ПК із процесорами Intel або AMD. Виберіть прошивку звичайним способом, а потім налаштуйте Показати додаткові параметри > Метод встановлення > SP Flash Tool і встановити.

Виберіть прошивку, а потім виберіть двигун

Встановлення в Updater CE — це завжди однаковий шлях: виберіть свою модель, виберіть мікропрограму та випуск, а потім запустіть Install/Restore. Метод інсталяції лише вирішує, який механізм MediaTek виконує спалах. Залиште це Авто якщо у вас немає причини закріпити його та встановити значення SP Flash Tool коли ви це зробите.

Які комп’ютери мають SP Flash Tool

MediaTek публікує SP Flash Tool лише для x86-64, тому Updater CE пропонує його на ПК x86-64 і ніде більше. Сам додаток працює в більшій кількості місць, ніж двигун.

Windows x64: доступно

Windows 10 або 11 на процесорі Intel або AMD. The SP Flash Tool спосіб встановлення та SP Flash Tool обидві кнопки є.

Linux x86-64: доступно

64-розрядна машина Intel або AMD Linux, на якій працює Updater CE AppImage. Той самий спосіб встановлення, та сама кнопка.

macOS: недоступний

SP Flash Tool не існує для macOS в жодній формі. Оновлення CE встановлює та відновлює за допомогою MTKClient замість цього, і немає SP Flash Tool методу чи кнопки встановлення. Тримайте Mac на прокладеному маршруті або використовуйте Нотатки Mac.

Linux ARM64: недоступний

Raspberry Pi, плати ARM і ARM64 Linux — це та сама історія, що й macOS: MediaTek не постачає збірки ARM, тому Updater CE використовує там MTKClient.

Не впевнені щодо машини? Відкрийте налаштування та ввімкніть Показати додаткові параметри: якщо немає Спосіб встановлення з параметром SP Flash Tool цей комп’ютер не може його запустити. На macOS і ARM64 Linux програвач усе ще встановлюється нормально, тому використовуйте маршрут із підказками з автоматичним режимом і переходьте на ПК Windows x64 або Linux x86-64, лише якщо вам особливо потрібен SP Flash Tool.

Встановіть вибране мікропрограмне забезпечення за допомогою SP Flash Tool

  1. Відкрийте Updater CE і виберіть модель, надруковану на вашому плеєрі: Innioasis Y1, Y2, G1, G3, G5, R1 або PR1, або модель Timmkoo.
  2. Виберіть потрібне програмне забезпечення, Заводське ПЗ або проект спільноти, а потім виберіть випуск. Це той самий список, така ж відповідність моделі та ті самі перевірки, що й будь-яка інша інсталяція.
  3. відкритий Налаштування і включити Показати додаткові параметри.
  4. знайти Спосіб встановлення і вибирайте SP Flash Tool замість Авто.
  5. Поверніться до екрана встановлення та натисніть Встановити / Відновити.
  6. Повністю вимкніть плеєр, коли програма запитає, а потім під’єднайте кабель передачі даних USB безпосередньо до комп’ютера за запитом. Використовуйте кабель для передачі даних, а не кабель для зарядки, і пропускайте концентратори.
  7. Зачекайте, поки Updater CE повідомить, що встановлення завершено, потім від’єднайте кабель і запустіть програвач.

Ось і вся подорож. Updater CE все ще надає пакет для конкретної моделі, агент завантаження MediaTek, перевірку драйверів і підказку підключення; вибір SP Flash Tool змінює лише двигун під ним.

Тримайте моделі окремо. Пакунки Y1 і Y2 ніколи не є взаємозамінними, а файл розкиду з однієї моделі не описує іншу. Якщо Updater CE не пропонує мікропрограму для вибраної вами моделі, зупиніться та виберіть натомість пакет, указаний для цієї моделі.

Для чого призначена кнопка SP Flash Tool.

На підтримуваному комп’ютері Updater CE також має SP Flash Tool кнопка, яка відкриває інструмент MediaTek для безпосередньої роботи з ним, наприклад, із пакетом розкиду, який ви надали самі. Він не потрібен для звичайних інсталяцій, оновлень і відновлення: метод інсталяції виконує ту саму роботу, а також перевіряє відповідність моделі, перевіряє драйвер і підказує підключення.

Якщо кнопки немає, це означає, що комп’ютер є однією з непідтримуваних систем, або вибрана вами модель використовує інший потік. У цьому випадку скористайтеся методом інсталяції або маршрутом з інструкціями, а не шукайте двійковий файл інструмента.

Коли SP Flash Tool є правильним методом встановлення

  • Плеєр, який не завантажується. Режим завантаження SP Flash Tool усе ще може досягати пристрою, попередній завантажувач або завантажувальний образ якого пошкоджено, і саме тут виконується ретельна робота з відновлення.
  • Спалах, який зупиняється на підтримуваному ПК. Якщо Auto або MTKClient зупиняються частково на комп’ютері Windows x64 або Linux x86-64, закріплення інсталяції на SP Flash Tool дає змогу іншому механізму включити той самий пакет.
  • Заводська упаковка, якій ви довіряєте. Випуски оригінального програмного забезпечення від архів прошивки добре поєднується з ним, тому що відновлення стандартних розділів — це саме те, для чого створено SP Flash Tool.

Для звичайного оновлення або першого встановлення вийдіть Спосіб встановлення на Авто. Він вибирає движок, який підходить вашій моделі та платформі, і програма тримає вас на підтримуваному шляху без додаткових налаштувань.

Якщо інсталяція не починається

  1. Переконайтеся, що модель, яку ви вибрали в Updater CE, відповідає моделі, надрукованій на програвачі, і що пакет для неї вказано.
  2. Переконайтеся, що плеєр повністю вимкнено, перш ніж підключати його, і підключайтеся лише за підказкою програми.
  3. На Windows встановіть драйвер MediaTek і перезапустіть; на Linux перевірте дозволи USB, зазначені в налаштування комп'ютера.
  4. Спробуйте інший порт USB безпосередньо на комп’ютері, без концентратора, і знову запустіть установку/відновлення.

Все, що далі, належить усунення несправностей. І на macOS або ARM64 Linux, відповідь не інша кнопка: зберегти керована установка і використовуйте SP Flash Tool лише з ПК Windows x64 або Linux x86-64.
