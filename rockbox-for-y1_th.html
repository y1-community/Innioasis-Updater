Rockbox-Y1 · Innioasis Y1

Rockbox สำหรับ Y1 (Rockbox-Y1)

"Rockbox", "Rockbox-Y1" และ "Rockbox สำหรับ Y1" ทั้งหมดอ้างอิงถึงเฟิร์มแวร์ชุมชนเดียวกัน Rockbox สำหรับ Innioasis Y1 นี่คือสิ่งที่จะเพิ่มให้กับเครื่องเล่นของคุณ บิวด์ใดให้เลือก และวิธีการติดตั้งด้วย Innioasis Updater CE

ติดตั้ง Rockbox-Y1 ดาวน์โหลด ROM กวดวิชาเขียน Rockbox-ฮับ Y1

หนึ่งเฟิร์มแวร์ หลายชื่อ

ใน Innioasis Updater CE เฟิร์มแวร์นี้จะปรากฏเป็น Rockbox เมื่อคุณเลือกรุ่นอุปกรณ์ Y1. คำแนะนำ วิดีโอ และบันทึกประจำรุ่นก็เรียกสิ่งนี้เช่นกัน Rockbox-Y1 หรือ Rockbox สำหรับ Y1 ดังนั้นจึงชัดเจนว่างานสร้างมีไว้สำหรับ Y1 ไม่ใช่ Y2

ตรวจสอบรุ่นที่พิมพ์บนเครื่องเล่นของคุณทุกครั้งก่อนทำการติดตั้ง: แพ็คเกจเฟิร์มแวร์ Y1 และ Y2 ไม่สามารถเปลี่ยนกันได้

สิ่งที่ Rockbox-Y1 เพิ่มใน Y1 ของคุณ

Rockbox-Y1 เป็นพอร์ตชุมชนของเฟิร์มแวร์เครื่องเล่นเพลงโอเพ่นซอร์ส Rockbox สำหรับ Innioasis Y1:

  • คลังเพลงตามแท็ก — เรียกดูตามศิลปิน อัลบั้ม แนวเพลง และปีโดยใช้แท็กเสียง หรือเรียกดูโฟลเดอร์โดยตรง
  • การเล่นเสียงขั้นสูง — การเล่นแบบไม่มีช่องว่าง, ครอสเฟด, ReplayGain และอีควอไลเซอร์เต็มรูปแบบ
  • ธีมที่กำหนดเอง — เลือกจากธีมชุมชน 240p และ 360p หลายร้อยแบบ รวมถึงเค้าโครงสไตล์ iPod แบบคลาสสิก
  • วิทยุเอฟเอ็ม - รองรับวิทยุ FM ในตัว
  • อุปกรณ์เสริมเพิ่มเติม - ดาวน์โหลดพอดแคสต์ผ่าน Wi-Fi และ Last.fm / ListenBrainz / Maloja scrobbling บนบิลด์ที่รองรับ
  • บูตคู่ — เปลี่ยนกลับไปใช้ซอฟต์แวร์ดั้งเดิมจากโรงงานโดยไม่ต้องรีแฟลชบนบิลด์ที่รองรับ

ฉันควรเลือก Y1 บิวด์ใด

  • 240p กับ 360p — งานสร้าง 240p กับธีมคลาสสิก 320×240 Rockbox บิลด์ 360p ใช้ธีม 480×360 Y1 ที่คมชัดยิ่งขึ้น จับคู่ความละเอียดของบิลด์กับธีมที่คุณต้องการใช้ (คู่มือ 240p กับ 360p).
  • Type A กับ Type B — Type A สำหรับผู้เล่น Y1 ที่มาพร้อมกับซอฟต์แวร์จากโรงงาน 2.0.0 หรือใหม่กว่า Type B ใช้สำหรับหน่วยก่อนหน้า Y1 เลือก Type A เว้นแต่คุณจะรู้ว่า Y1 ของคุณคือ Type B
  • เสถียรกับทุกคืน — เลือกเวอร์ชันที่เสถียรสำหรับการฟังทุกวัน หรือเวอร์ชันกลางคืนเพื่อทดสอบการเปลี่ยนแปลงใหม่ล่าสุด

ดาวน์โหลดโดยตรงจากนักพัฒนาชุมชน

Innioasis Updater CE ดาวน์โหลดแพ็คเกจเฟิร์มแวร์โดยตรงจากผู้พัฒนาเฟิร์มแวร์ชุมชนเสมอ (rockbox-y1/rockbox) และนักพัฒนาเองก็มีหน้าที่รับผิดชอบแต่เพียงผู้เดียวในการแสดงรายการซอฟต์แวร์ของตนใน Updater CE

คุณสามารถให้ Updater CE ดาวน์โหลดและติดตั้งเฟิร์มแวร์โดยอัตโนมัติ หรือดาวน์โหลดแพ็คเกจ ROM จากของเรา Rockbox-Y1 หน้าดาวน์โหลด และ Rockbox ROM หน้าดาวน์โหลด.

Rockbox-Y1 ดาวน์โหลด ติดตั้งจาก ZIP ในเครื่อง

วิธีการติดตั้ง Rockbox-Y1

  1. เปิด Innioasis Updater CE และตั้งค่า รุ่นอุปกรณ์ ถึง Y1.
  2. เลือก Rockbox ใน ซอฟต์แวร์.
  3. เลือกรุ่นที่เสถียร (หรือเปิดใช้งานบิลด์ทุกคืนเพื่อทดสอบการแสดงตัวอย่าง)
  4. คลิก ติดตั้ง / คืนค่า ดังนั้น Updater CE จึงดาวน์โหลดแพ็คเกจโดยตรงจากผู้พัฒนา
  5. ปิด Y1 โดยสมบูรณ์แล้วเชื่อมต่อด้วยสายเคเบิลข้อมูล USB เมื่อ Updater CE แจ้งให้คุณทราบ
  6. รอข้อความแจ้งเสร็จสิ้น จากนั้นตัดการเชื่อมต่อและเปิดเครื่องเล่นของคุณ

สำหรับภาพหน้าจอและเคล็ดลับการตั้งค่าโดยละเอียด โปรดอ่าน บทช่วยสอน Rockbox-Y1 แบบเต็ม.

การกู้คืนซอฟต์แวร์ Y1 ดั้งเดิม

คุณสามารถกลับสู่ซอฟต์แวร์จากโรงงานได้ตลอดเวลา: เลือก Y1 และ ซอฟต์แวร์ดั้งเดิม ใน Updater CE เลือกรุ่นที่เสถียร แล้วคลิก ติดตั้ง / คืนค่า. เพลงของคุณบนการ์ด MicroSD จะถูกเก็บรักษาไว้ ดู คู่มือการคืนค่า และ Y1 หน้าซอฟต์แวร์ต้นฉบับ.

คำถามที่พบบ่อย

Rockbox สำหรับ Y1 เหมือนกับ Rockbox-Y1 หรือไม่

ใช่. Rockbox, Rockbox-Y1, Rockbox สำหรับ Y1 และ rockbox-y1 ทั้งหมดอ้างถึงพอร์ตชุมชนเดียวกัน Rockbox สำหรับ Innioasis Y1

Updater CE ดาวน์โหลด Rockbox-Y1 จากที่ไหน

Updater CE ดาวน์โหลดแพ็คเกจเฟิร์มแวร์โดยตรงจากรีลีสของผู้พัฒนาเฟิร์มแวร์ชุมชนเสมอ (rockbox-y1/rockbox). นักพัฒนามีหน้าที่รับผิดชอบแต่เพียงผู้เดียวในการแสดงรายการซอฟต์แวร์ของตนใน Updater CE

ฉันสามารถติดตั้ง Rockbox-Y1 บน Y2 ได้หรือไม่

ไม่ Y2 มีเฟิร์มแวร์บิวด์แยกต่างหากของตัวเอง ใช้ Rockbox สำหรับ Y2 แทน.

การติดตั้ง Rockbox-Y1 จะลบเพลงของฉันหรือไม่

ไม่ เพลงจะถูกจัดเก็บไว้ในการ์ด MicroSD และไม่ได้รับผลกระทบใดๆ เมื่อทำการแฟลชเฟิร์มแวร์ภายในของเครื่องเล่น
