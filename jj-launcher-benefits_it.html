Perché la gente lo sceglie

Veloce, guidato dal pollice, il tuo.

  • Scansione rapida della libreria — Uno scanner multimediale personalizzato classifica librerie di grandi dimensioni senza attendere lo scanner del sistema Android.
  • Salta le tracce da qualsiasi schermata — La mappatura globale dei tasti hardware significa che precedente e successivo funzionano sempre, anche quando non sei nell'app musicale.
  • Preset EQ e riproduzione casuale — Modalità di riproduzione casuale e ripetizione completa oltre alle preimpostazioni dell'equalizzatore del dispositivo integrato.
  • Temi senza codice — Inserisci temi di colore personalizzati copiando i file oppure progettane uno tuo con l'editor di temi basato sul Web ed esporta un file .zip.
  • Caricamenti di file senza cavo — Ospita un server Web Wi-Fi locale e carica musica dal browser del tuo PC: il cavo rimane nel cassetto.
  • Associazione Bluetooth in-app — Scansiona e associa i dispositivi Bluetooth dalle impostazioni di avvio senza uscire dall'app.

Comunità

Cosa dice la comunità

JJ Launcher è per le persone che vogliono che il giocatore si senta veloce, con un pollice sul volante. Molti altri progetti sono basati su di esso, il che la dice lunga sul nucleo.

Il creatore della community doitall mette a disposizione un breve video di installazione e risoluzione dei problemi per JJ Launcher su Y1, mentre l'editor dei temi consente ai proprietari di scambiare e modificare l'aspetto senza attendere una nuova versione.

Cosa offre il progetto

  • Scanner multimediale incorporato personalizzato con categorizzazione rapida di librerie di grandi dimensioni
  • Modalità casuale, ripetizione e preimpostazioni EQ integrate
  • Mappatura globale dei tasti hardware: traccia i salti da qualsiasi schermata
  • Sincronizzazione della schermata principale in tempo reale delle copertine degli album e delle informazioni sui brani
  • Infiniti temi personalizzati copiando cartelle; Y1 Editor di temi per progettare il tuo
  • Sfondo sfocato HD dinamico generato dalla copertina dell'album in riproduzione
  • Scansione e accoppiamento Bluetooth in-app
  • Tastiera virtuale ottimizzata per il volante per password Wi-Fi
  • Caricamento file da PC wireless su un server Web Wi-Fi locale

Cose da sapere prima

  • Il progetto è in fase alfa: sono possibili bug imprevisti e problemi di stabilità
  • È stato testato sul software di sistema 2.1.9; controlla la versione del tuo software prima dell'installazione
  • Alcune connessioni Bluetooth potrebbero richiedere una concessione di autorizzazione ADB una tantum per le impostazioni sicure
  • I temi realizzati per l'editor web richiedono Launcher 0.8 o versione successiva
