Metoda de instalare

SP Flash Tool în Innioasis Updater CE

SP Flash Tool nu este o descărcare separată și nu există nimic de găsit în folderul aplicației. Este o metodă de instalare în Innioasis Updater CE pe computerele Windows x64 și Linux x86-64 cu procesoare Intel sau AMD. Alegeți firmware-ul în mod normal, apoi setați Afișați Setări avansate > Metodă de instalare > SP Flash Tool și instalați.

O instalare în Updater CE este întotdeauna aceeași călătorie: selectați modelul dvs., alegeți firmware-ul și lansați, apoi rulați Instalare/Restaurare. Metoda de instalare decide doar ce motor MediaTek efectuează flash-ul. Lasă-l pe Auto dacă nu aveți un motiv să-l fixați și să îl setați SP Flash Tool când faci.

Ce computere au SP Flash Tool

MediaTek publică SP Flash Tool numai pentru x86-64, așa că Updater CE îl oferă pe computerele x86-64 și nicăieri altundeva. Aplicația în sine rulează în mai multe locuri decât motorul.

Windows x64: disponibil

Windows 10 sau 11 pe un procesor Intel sau AMD. The SP Flash Tool metoda de instalare și SP Flash Tool butonul sunt ambele acolo.

Linux x86-64: disponibil

O mașină Intel sau AMD Linux pe 64 de biți care rulează Updater CE AppImage. Aceeași metodă de instalare, același buton.

macOS: nu este disponibil

SP Flash Tool nu există pentru macOS sub nicio formă. Updater CE instalează și restaurează cu MTKClient în schimb și nu există nicio metodă sau buton de instalare SP Flash Tool. Păstrați Mac-ul pe traseul ghidat sau utilizați Note Mac.

Linux ARM64: nu este disponibil

Raspberry Pi, plăcile ARM și ARM64 Linux sunt aceeași poveste ca macOS: MediaTek nu furnizează nicio versiune ARM, așa că Updater CE folosește MTKClient acolo.

Nu sunteți sigur despre o mașină? Deschide Setări și pornește Afișați Setări avansate: dacă nu există Metoda de instalare cu o opțiune SP Flash Tool, acel computer nu o poate rula. Pe macOS și ARM64 Linux playerul se instalează în continuare normal, așa că utilizați traseul ghidat cu Auto și treceți la un PC Windows x64 sau Linux x86-64 numai dacă aveți nevoie în mod specific de SP Flash Tool.

Instalați firmware-ul ales cu SP Flash Tool

  1. Deschideți Updater CE și selectați modelul imprimat pe player: Innioasis Y1, Y2, G1, G3, G5, R1 sau PR1 sau un model Timmkoo.
  2. Alegeți software-ul dorit, Software original sau un proiect comunitar, apoi alegeți lansarea. Aceasta este aceeași listă, aceeași potrivire de model și aceleași verificări ca orice altă instalare.
  3. Deschide Setări și pornește Afișați Setări avansate.
  4. Găsiți Metoda de instalare și alegeți SP Flash Tool în loc de Auto.
  5. Reveniți la ecranul de instalare și faceți clic Instalează / Restaurează.
  6. Opriți complet playerul când aplicația solicită, apoi conectați cablul de date USB direct la computer la solicitare. Utilizați un cablu de date, nu un cablu de încărcare și omiteți hub-urile.
  7. Așteptați ca Updater CE să raporteze că instalarea s-a încheiat, apoi deconectați cablul și porniți playerul.

Asta este toată călătoria. Updater CE încă furnizează pachetul specific modelului, agentul de descărcare MediaTek, verificările driverului și promptul de conectare; alegând SP Flash Tool schimbă doar motorul de dedesubt.

Păstrați modelele separate. Un pachet Y1 și un pachet Y2 nu sunt niciodată interschimbabile, iar un fișier scatter dintr-un model nu îl descrie pe celălalt. Dacă Updater CE nu oferă firmware-ul pentru modelul pe care l-ați selectat, opriți și alegeți pachetul listat pentru modelul respectiv.

Pentru ce este butonul SP Flash Tool.

Pe un computer acceptat, Updater CE are și un SP Flash Tool butonul care deschide instrumentul lui MediaTek pentru a lucra direct cu acesta, de exemplu cu un pachet scatter pe care l-ați furnizat dvs. Instalările de rutină, actualizările și restaurările nu au nevoie de el: metoda de instalare face aceeași activitate cu potrivirea modelului, verificările driverului și solicitările de conectare gestionate pentru dvs.

Dacă butonul lipsește, computerul este unul dintre sistemele neacceptate de mai sus sau modelul selectat utilizează un flux diferit. Utilizați metoda de instalare sau traseul ghidat în acest caz, în loc să căutați un instrument binar.

Când SP Flash Tool este metoda de instalare corectă

  • Un jucător care nu va porni. Modul de descărcare al lui SP Flash Tool poate ajunge în continuare la un dispozitiv al cărui preîncărcare sau imagine de pornire este deteriorată, care este locul unde se efectuează o recuperare atentă.
  • Un bliț care se blochează pe un computer compatibil. Dacă Auto sau MTKClient se oprește parțial pe o mașină Windows x64 sau Linux x86-64, fixarea instalării la SP Flash Tool dă celuilalt motor să activeze același pachet.
  • Un pachet din fabrică în care ai încredere. Versiuni de software originale de la arhiva firmware se potrivește bine cu el, deoarece restaurarea partițiilor stoc este exact pentru care este construit SP Flash Tool.

Pentru o actualizare obișnuită sau o primă instalare, plecați Metoda de instalare pe Auto. Alege motorul care se potrivește modelului și platformei dvs., iar aplicația vă menține pe calea acceptată fără setări suplimentare.

Dacă instalarea nu începe

  1. Confirmați că modelul pe care l-ați selectat în Updater CE se potrivește cu modelul imprimat pe player și că pachetul este listat pentru acesta.
  2. Confirmați că playerul este complet oprit înainte de a-l conecta și conectați-vă numai la solicitarea aplicației.
  3. Pe Windows, instalați driverul MediaTek și reporniți; pe Linux, verificați permisiunile USB notate în configurarea computerului.
  4. Încercați un alt port USB direct pe computer, fără hub și porniți din nou Instalarea/Restaurare.

Orice mai aparține depanare. Și pe macOS sau ARM64 Linux, răspunsul nu este un alt buton: păstrați instalare ghidată și utilizați SP Flash Tool numai de pe un PC Windows x64 sau Linux x86-64.
