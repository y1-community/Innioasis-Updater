Install Rondo on Linux

A lightweight custom audio system for the Y1 with iPod-style click-wheel menus. These Linux guides cover every model the project supports. People also search for Rondo Y1, Rondo firmware, Rondo music player; this is the same Rondo install.

Prepare Linux for the install

  1. Download UpdaterCE.AppImage, make it executable with chmod +x UpdaterCE.AppImage, and run it. The current AppImage targets Intel/AMD x86_64 systems.
  2. If the AppImage does not start on Ubuntu 22.04 or newer, install libfuse2 with your package manager. On Ubuntu 24.04 the package is libfuse2t64. Do not run the app as root.
  3. If Updater CE cannot open the player, add the MediaTek USB permission rule: save SUBSYSTEM=="usb", ATTR{idVendor}=="0e8d", MODE="0666", GROUP="plugdev" as /etc/udev/rules.d/51-innioasis.rules, then run sudo udevadm control --reload && sudo udevadm trigger. Add your user to plugdev if needed.

The official AppImage is for Intel/AMD Linux. No Linux ARM build is listed. Full Linux setup notes.

How the install works

  1. Install Updater CE on Linux using the steps above.
  2. Select the model printed on the player, then choose Rondo.
  3. Choose a stable release listed for that model.
  4. Click Install / Restore, power the player off and connect it at the prompt.
  5. Wait for success. The first start takes a couple of minutes. For YouTube Music and YouTube, set up a Rondo server; the card, radio and Bluetooth work without one.

Questions people ask

Which Rondo package should I download on Linux?

Use Innioasis Updater CE and select the model first. The app downloads the package from the project's official release. If you download manually, use the ZIP that names the model and, on a Y1, the correct Type A or Type B asset.

Does Rondo work on every model?

This project is listed for Innioasis Y1. Open the model card for the exact guide.

Is Rondo Y1 the same as Rondo?

Yes. Rondo Y1, Rondo firmware, Rondo music player are names people use for the same project.

Do I need a driver?

No proprietary driver, but the udev rule for vendor ID 0e8d and your user in plugdev are required.

Can I undo it?

Restore Original Software for Y1 if you want the stock player back.
