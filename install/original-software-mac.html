Original Software · macOS

Restore Original Software (stock firmware) on macOS

The factory system image from Innioasis or Timmkoo, used to undo a custom install or recover a player that will not boot. These macOS guides cover every model the project supports. People also search for stock firmware, factory firmware, stock ROM, original firmware; this is the same Original Software install.

Prepare macOS for the install

  1. Download the macOS disk image (Innioasis.Updater.for.Mac.dmg), open it, and drag Innioasis Updater CE into Applications.
  2. The first launch is blocked by Gatekeeper until you approve it. Right-click the app and choose Open, or open System Settings → Privacy & Security and click Open Anyway. Do not disable Gatekeeper for the whole Mac.
  3. No separate USB driver is needed. Connect the player directly to the Mac, not through an unpowered hub; some USB-C adapters drop the connection during a flash.

Intel and Apple Silicon Macs are supported. The current guide targets macOS Monterey (12.0) or later. Full macOS setup notes.

How the install works

  1. Install Updater CE on macOS using the steps above.
  2. Select the model printed on the player, then choose Original Software.
  3. Choose a stable release listed for that model.
  4. Click Install / Restore, power the player off and connect it at the prompt.
  5. Wait for success. The first start can take a few minutes. Set the language, Wi-Fi and Bluetooth again if the restore cleared them.

Questions people ask

Which Original Software package should I download on macOS?

Use Innioasis Updater CE and select the model first. The app downloads the package from the project's official release. If you download manually, use the ZIP that names the model and, on a Y1, the correct Type A or Type B asset.

Does Original Software work on every model?

This project is listed for Innioasis Y1, Innioasis Y2, Innioasis / Timmkoo G1, Innioasis / Timmkoo G3, Innioasis / Timmkoo G5, Innioasis R1, Innioasis PR1, Innioasis SR1, Innioasis / Timmkoo Q3, Innioasis / Timmkoo Q5. Open the model card for the exact guide.

Is stock firmware the same as Original Software?

Yes. stock firmware, factory firmware, stock ROM are names people use for the same project.

Do I need a driver?

No separate driver is needed. Approve the app in Privacy & Security on first launch.

Can I undo it?

This is the restore path itself: choose Original Software for the model and run Install / Restore.
