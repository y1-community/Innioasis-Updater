Install Inniclassic (iPod Classic interface) on Windows

An iPod Classic-style interface for the Innioasis Y1 and Y2. These Windows guides cover every model the project supports. People also search for InniClassic, Inni Classic, iPod Classic firmware, Classic Y1; this is the same Inniclassic install.

Prepare Windows for the install

  1. Download the Innioasis Updater CE installer (installer.exe) from the official GitHub release and run it. If SmartScreen says “Windows protected your PC”, choose More info then Run anyway only for the file you just downloaded from github.com/y1-community/Innioasis-Updater.
  2. Install the MediaTek USB driver with DriverInstall.exe, then restart the PC. The driver is what lets Windows see a powered-off player when Updater CE asks for it.
  3. Use a USB port on the PC itself and a cable that carries data. A charge-only cable or an unpowered hub is the usual reason the player never appears.

Windows 10 and 11 x64 are the normal targets. ARM64 Windows is experimental. Full Windows setup notes.

How the install works

  1. Install Updater CE on Windows using the steps above.
  2. Select the model printed on the player, then choose Inniclassic.
  3. Choose a stable release listed for that model.
  4. Click Install / Restore, power the player off and connect it at the prompt.
  5. Wait for success. The first boot may take longer while the library indexes. Let the scan finish before you judge performance.

Questions people ask

Which Inniclassic package should I download on Windows?

Use Innioasis Updater CE and select the model first. The app downloads the package from the project's official release. If you download manually, use the ZIP that names the model and, on a Y1, the correct Type A or Type B asset.

Does Inniclassic work on every model?

This project is listed for Innioasis Y1, Innioasis Y2. Open the model card for the exact guide.

Is InniClassic the same as Inniclassic?

Yes. InniClassic, Inni Classic, iPod Classic firmware are names people use for the same project.

Do I need a driver?

Yes. Install the MediaTek driver with DriverInstall.exe and restart before connecting the player.

Can I undo it?

Restore Original Software for the same model if you want the stock interface back.
