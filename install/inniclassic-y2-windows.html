Install Inniclassic (iPod Classic interface) on Innioasis Y2 with a Windows PC

An iPod Classic-style interface for the Innioasis Y1 and Y2. This Windows tutorial is for the Innioasis Y2 only. People also search for InniClassic, Inni Classic, iPod Classic firmware, Classic Y1; this is the same Inniclassic install.

Before you start

  • Player: Innioasis Y2. Check the model printed on the player; Inniclassic packages for another model will not work.
  • Computer: Windows. Windows 10 and 11 x64 are the normal targets. ARM64 Windows is experimental.
  • Cable: a USB cable that carries data, not a charge-only cable.
  • Power: charge the player to at least half before you begin.
  • Backup: The Y1 and Y2 builds come from separate release lines. Never cross-flash them, and pick the Type B asset if you have an early Y1.

Prepare Windows for the install

  1. Download the Innioasis Updater CE installer (installer.exe) from the official GitHub release and run it. If SmartScreen says “Windows protected your PC”, choose More info then Run anyway only for the file you just downloaded from github.com/y1-community/Innioasis-Updater.
  2. Install the MediaTek USB driver with DriverInstall.exe, then restart the PC. The driver is what lets Windows see a powered-off player when Updater CE asks for it.
  3. Use a USB port on the PC itself and a cable that carries data. A charge-only cable or an unpowered hub is the usual reason the player never appears.

Windows 10 and 11 x64 are the normal targets. ARM64 Windows is experimental. Full Windows setup notes.

Install Inniclassic on Innioasis Y2 with a Windows PC

  1. Get Updater CE ready: Install Innioasis Updater CE on a Windows PC and open it. The Windows setup is covered above; the main guide has the download links.
  2. Select Innioasis Y2: In Device Model, choose Innioasis Y2. Do not substitute another model, even when the software name is the same.
  3. Choose Inniclassic: In Software, choose Inniclassic. The Y1 and Y2 builds come from separate release lines. Never cross-flash them, and pick the Type B asset if you have an early Y1.
  4. Choose a release: Choose the newest stable release shown for this model. Nightly and pre-release builds are for testing; tick the nightly-builds option only if you need one. Read the release note for the Innioasis Y2 before you continue.
  5. Install / Restore: Click Install / Restore. When Updater CE asks, power the player fully off and plug it into the Windows PC. Device Manager should briefly show a MediaTek PreLoader USB VCOM or MTK USB Port entry while the player is connected.
  6. Finish and check: Leave the player and cable alone until Updater CE shows success. The first boot may take longer while the library indexes. Let the scan finish before you judge performance.
  7. Keep the way back: Restore Original Software for the same model if you want the stock interface back. The stock package is always available from the software archive.

If the install does not work

  1. Updater CE cannot see the player: reinstall DriverInstall.exe, restart Windows, and try another USB port. If Core isolation / Memory integrity is enabled, Windows Security can block the MediaTek driver. Turn it off, reinstall the driver, then turn it back on when you are finished.
  2. The install waits for the device: unplug the cable, power the player off again, click Install / Restore, and reconnect only at the fresh prompt.
  3. SmartScreen or antivirus blocks the app: check that the file came from the official y1-community/Innioasis-Updater release, then allow it. Do not run an installer from an untrusted mirror.
  4. Wrong package or model: return to Device Model and confirm the printed model. On a Y1, confirm Type A or Type B before choosing the asset again.
  5. The player stopped responding: do not keep reconnecting. Read the recovery guide and the troubleshooting guide before trying a manual flash.

For a manual recovery on Innioasis Y2, use the files and scatter file that match the model. SP Flash Tool notes.

Going back to Original Software

Restore Original Software for the same model if you want the stock interface back. The stock restore uses the same Updater CE flow: choose Innioasis Y2, choose Original Software, pick a stable release and run Install / Restore.

Questions people ask

Can I install Inniclassic on Innioasis Y2 on Windows?

Yes. This page is the Windows guide for Inniclassic on the Innioasis Y2. Install Updater CE, select the model, choose the project and follow the install prompt.

Do I need a driver on Windows?

Yes. Install DriverInstall.exe and restart Windows before connecting the powered-off player.

Will this erase my music?

The Y1 and Y2 builds come from separate release lines. Never cross-flash them, and pick the Type B asset if you have an early Y1. Files on the microSD card are normally left alone, but remove the card first if you want to be certain.

Is InniClassic the same as Inniclassic?

Yes. InniClassic is one of the names people use for Inniclassic. This guide covers the same project on the Innioasis Y2.

Does Inniclassic work on other models?

This project is listed for Innioasis Y1. Use the model-specific guide for each player. Never install a package built for another model.

How do I undo the install?

Restore Original Software for the same model if you want the stock interface back. Open the software archive or the model restore guide for the exact steps.

What if the player is not detected?

Start with the Windows checklist above, then read the troubleshooting guide. A data cable, a direct USB port and connecting only at the prompt fix most connection problems.
