Questions people ask

What is Solar?

A network-first custom system with podcasts, YouTube, streaming and a global quick menu. Solar turns the player into a connected music device while keeping the local library. It is listed for both Y1 and Y2, with separate builds and feature sets.

Is Solar Y1 the same as Solar?

Yes. Solar Y1, Solar Y2, Solar firmware, Solar music player all refer to the same project.

Which models are supported?

Innioasis Y1, Innioasis Y2. Use the model-specific guide before installing.

How do I go back to stock?

Restore Original Software for the same model if you want the stock player back.
