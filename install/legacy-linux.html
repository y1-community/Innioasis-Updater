Install firmware on a 32-bit Linux PC

This guide installs with a software install zip: one download that carries the firmware, the installer and a readme, built for a 32-bit Intel or AMD Linux PC. Use it for firmware, a community software release, an update or a stock package.

Before you start

  • Model: the name printed on the player. A Y1 package will not work on a Y2, and Timmkoo models are not interchangeable with Innioasis ones either.
  • Computer: a 32-bit Intel or AMD Linux install. A 64-bit Linux machine can use Updater CE from the main guide instead.
  • Cable: a USB cable that carries data. A charge-only cable is the usual reason the player is never detected.
  • Power: charge the player to at least half before you begin.
  • Backup: copy music and other files you cannot replace off the player. An install replaces the system partition.

Which file do I download?

Open the firmware list, find the model, then the software you want: Original Software, Rockbox, Solar, JJ Launcher, Inniclassic, Y2Player, Koensayr or another community system. For each release the archive lists the packages it has.

A package for this computer ends in -linux-legacy.zip. It is named after the release, for example rom-linux-legacy.zip or rom_y2-linux-legacy.zip, and it contains the firmware, the installer that writes it, a readme with the details of that release and a donate.txt. If you only see Linux, Windows or macOS packages, that release has not been built for 32-bit Linux yet; try the newest release of the same software.

Same firmware, different wrapper. The software install zip holds exactly the same scatter file and partition images as the Updater CE version. The only difference is which app opens them.

Step 1: unpack the zip

  1. Unpack the download into its own folder, for example ~/innioasis. Keep the folder together: the installer reads the rom files beside itself.
  2. Open a terminal in that folder.
  3. Mark the installer executable. The readme inside the zip names the file; chmod +x ./* covers the whole folder.
cd ~/innioasis
chmod +x ./*
./flash_tool

No driver installer is needed on Linux. The player needs the MediaTek udev rule for vendor ID 0e8d, which the Linux setup notes cover. If the shell answers Permission denied, the executable bit is missing; run chmod +x again.

Step 2: write the firmware

  1. Start the installer from the folder, as shown above.
  2. Choose Scatter-loading and pick the _Android_scatter.txt file. The partition list should fill with the rom files beside it.
  3. Leave the mode on Download Only. Tick Preloader only when the player will not start at all and you are restoring it.
  4. Press Download. Then power the player fully off and plug in the USB cable.
  5. Wait for the green success box. Do not unplug the player and do not close the installer while the progress bar is moving.

The player will not switch on? Straighten a paperclip and press the small reset hole on the player for a second, then connect it while it is still off. That resets the power state and leaves your files alone.

Never cross-install a model.A Y1 package on a Y2, or the other way round, can leave the player with dead controls or a boot loop. Check the printed model before you start.

If the install does not start

  1. Permission denied: the installer is not executable yet. Run chmod +x on it in the folder it lives in.
  2. Nothing happens after Download: unplug the cable, hold the player's power button for ten seconds, press the reset hole with a paperclip, then press Download again and reconnect only once the installer is waiting.
  3. The player is never detected: add the udev rule for vendor ID 0e8d, reload udev, and try another USB port on the computer itself rather than a hub.
  4. It finishes but will not boot: give the first boot a few minutes, then restore Original Software for the same model from the firmware list.

If no app detects the player at all, treat it as a cable, udev or hardware problem before trying another firmware.

Firmware, software, update or package?

The words are used interchangeably across this site, and the steps above are the same for each:

  • Firmware or rom: the complete system image for a model.
  • Software or system: a community build such as Rockbox, Solar or JJ Launcher, delivered as the same kind of package.
  • Update: a newer release of either. Install it exactly like a fresh package.
  • Package or zip: the download. A software install zip is the one built for this PC.

Supporting the projects

Every software install zip includes donate.txt, which lists the ways to support the people who keep these players usable. Nothing in the package is limited by whether you donate.

Questions people ask

Can I install Innioasis firmware on a 32-bit Linux PC?

Yes. Updater CE is published for 64-bit Linux and ARM64 only, but every release has a software install zip ending in -linux-legacy.zip that carries the same firmware and an installer that runs on 32-bit Intel and AMD systems.

Which package should I use on a 32-bit Linux PC?

Updater CE needs 64-bit Windows 10 1809 or newer, macOS, or 64-bit Linux. On a 32-bit Linux install the site offers the software install zip instead, because there is no build the app could run as.

Do I need a driver package on Linux?

No separate installer is needed. Linux needs the MediaTek udev rule for vendor ID 0e8d so your user may open the player; the setup notes cover it, and the readme in the zip repeats the terminal steps.

Is the -linux-legacy.zip the same firmware?

Yes. It is the same rom for the same release, packaged with a stand-alone installer instead of the Updater CE app. The scatter file and partition images are identical.

Will installing erase my music?

An install writes the system partition, so copy any files you cannot replace off the player first. Files on a microSD card are normally left alone, but remove the card if you want to be certain.
