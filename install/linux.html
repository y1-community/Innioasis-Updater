Install Innioasis and Timmkoo software on Linux

Set up Innioasis Updater CE on a Linux computer, then use the model-specific guide for the software you want. The official AppImage is for Intel/AMD Linux. No Linux ARM build is listed.

Get Updater CE for LinuxLinux install guidesLinux USB permission notes

Prepare Linux for the install

  1. Download UpdaterCE.AppImage, make it executable with chmod +x UpdaterCE.AppImage, and run it. The current AppImage targets Intel/AMD x86_64 systems.
  2. If the AppImage does not start on Ubuntu 22.04 or newer, install libfuse2 with your package manager. On Ubuntu 24.04 the package is libfuse2t64. Do not run the app as root.
  3. If Updater CE cannot open the player, add the MediaTek USB permission rule: save SUBSYSTEM=="usb", ATTR{idVendor}=="0e8d", MODE="0666", GROUP="plugdev" as /etc/udev/rules.d/51-innioasis.rules, then run sudo udevadm control --reload && sudo udevadm trigger. Add your user to plugdev if needed.

The official AppImage is for Intel/AMD Linux. No Linux ARM build is listed. Full Linux setup notes.

Questions people ask

Do I need to install a driver on Linux?

No proprietary driver, but add the udev rule for vendor ID 0e8d and make the AppImage executable.

Does Updater CE keep my music?

A normal Updater CE install keeps the music on the microSD card. A full stock restore can wipe internal storage, so back up first.

Where are the model-specific guides?

Use the software table above, or open the model card for your player. Every install page names the model and platform in its title.

Can I use a different computer?

Yes. Each guide has links to the Windows, macOS and Linux versions at the top of the page.
