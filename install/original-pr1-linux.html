Restore Original Software (stock firmware) on Innioasis PR1 on Linux

The factory system image from Innioasis or Timmkoo, used to undo a custom install or recover a player that will not boot. This Linux tutorial is for the Innioasis PR1 only. People also search for stock firmware, factory firmware, stock ROM, original firmware; this is the same Original Software install.

Before you start

  • Player: Innioasis PR1. Check the model printed on the player; Original Software packages for another model will not work.
  • Computer: Linux. The official AppImage is for Intel/AMD Linux. No Linux ARM build is listed.
  • Cable: a USB cable that carries data, not a charge-only cable.
  • Power: charge the player to at least half before you begin.
  • Backup: Back up music and recordings first. A stock restore replaces the system and can wipe internal storage; the microSD card is normally left alone.

Prepare Linux for the install

  1. Download UpdaterCE.AppImage, make it executable with chmod +x UpdaterCE.AppImage, and run it. The current AppImage targets Intel/AMD x86_64 systems.
  2. If the AppImage does not start on Ubuntu 22.04 or newer, install libfuse2 with your package manager. On Ubuntu 24.04 the package is libfuse2t64. Do not run the app as root.
  3. If Updater CE cannot open the player, add the MediaTek USB permission rule: save SUBSYSTEM=="usb", ATTR{idVendor}=="0e8d", MODE="0666", GROUP="plugdev" as /etc/udev/rules.d/51-innioasis.rules, then run sudo udevadm control --reload && sudo udevadm trigger. Add your user to plugdev if needed.

The official AppImage is for Intel/AMD Linux. No Linux ARM build is listed. Full Linux setup notes.

Restore Original Software on Innioasis PR1 on Linux

  1. Get Updater CE ready: Install Innioasis Updater CE on a Linux computer and open it. The Linux setup is covered above; the main guide has the download links.
  2. Select Innioasis PR1: In Device Model, choose Innioasis PR1. Do not substitute another model, even when the software name is the same.
  3. Choose Original Software: In Software, choose Original Software. Back up music and recordings first. A stock restore replaces the system and can wipe internal storage; the microSD card is normally left alone.
  4. Choose a release: Choose the newest stable release shown for this model. Nightly and pre-release builds are for testing; tick the nightly-builds option only if you need one. Read the release note for the Innioasis PR1 before you continue.
  5. Install / Restore: Click Install / Restore. Power the player fully off, then connect it only when Updater CE asks. Run lsusb in another terminal to see the MediaTek vendor ID 0e8d appear briefly.
  6. Finish and check: Leave the player and cable alone until Updater CE shows success. The first start can take a few minutes. Set the language, Wi-Fi and Bluetooth again if the restore cleared them.
  7. Keep the way back: This is the restore path itself: choose Original Software for the model and run Install / Restore. The stock package is always available from the software archive.

If the install does not work

  1. Permission denied or cannot open the USB port: the udev rule is missing or your user is not in plugdev. Add both, unplug the player, and reconnect.
  2. The AppImage will not launch: check chmod +x, install libfuse2 or libfuse2t64, and confirm you are on x86_64. A blank window under Wayland usually means trying an X11 session.
  3. The player is not detected: use a data cable and a direct port, avoid hubs, and connect only at the prompt. Check lsusb while the player is plugged in.
  4. Wrong package or model: return to Device Model and confirm the printed model. On a Y1, confirm Type A or Type B before choosing the asset again.
  5. The player stopped responding: do not keep reconnecting. Read the recovery guide and the troubleshooting guide before trying a manual flash.

For a manual recovery on Innioasis PR1, use the files and scatter file that match the model. SP Flash Tool notes.

Questions people ask

Can I restore Original Software on Innioasis PR1 on Linux?

Yes. This page is the Linux guide for Original Software on the Innioasis PR1. Install Updater CE, select the model, choose the project and follow the install prompt.

Do I need a driver on Linux?

No proprietary driver is needed, but your user needs the udev permission rule for vendor ID 0e8d before Updater CE can open the player.

Will this erase my music?

Back up music and recordings first. A stock restore replaces the system and can wipe internal storage; the microSD card is normally left alone. Files on the microSD card are normally left alone, but remove the card first if you want to be certain.

Is stock firmware the same as Original Software?

Yes. stock firmware is one of the names people use for Original Software. This guide covers the same project on the Innioasis PR1.

Does Original Software work on other models?

This project is listed for Innioasis / Timmkoo G1, Innioasis / Timmkoo G3, Innioasis / Timmkoo G5, Innioasis / Timmkoo Q3, Innioasis / Timmkoo Q5, Innioasis R1, Innioasis SR1, Innioasis Y1, Innioasis Y2. Use the model-specific guide for each player. Never install a package built for another model.

How do I undo the install?

This is the restore path itself: choose Original Software for the model and run Install / Restore. Open the software archive or the model restore guide for the exact steps.

What if the player is not detected?

Start with the Linux checklist above, then read the troubleshooting guide. A data cable, a direct USB port and connecting only at the prompt fix most connection problems.
