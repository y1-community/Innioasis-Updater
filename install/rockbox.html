Why people install Rockbox

Rockbox is the long-running community firmware for both Y1 and Y2. It adds a real music database, gapless playback, a graphic equalizer, themes and a large plugin set.

Source: rockbox-y1/rockbox and spycemagic/y2-rockbox

Questions people ask

What is Rockbox?

Music-first custom firmware with a tag database, gapless playback, EQ, themes and plugins. Rockbox is the long-running community firmware for both Y1 and Y2. It adds a real music database, gapless playback, a graphic equalizer, themes and a large plugin set.

Is Rockbox-Y1 the same as Rockbox?

Yes. Rockbox-Y1, Rockbox-Y2, Rockbox for Y1, Rockbox for Y2, Rockbox firmware all refer to the same project.

Which models are supported?

Innioasis Y1, Innioasis Y2. Use the model-specific guide before installing.

How do I go back to stock?

Restore Original Software for the same model if you want the stock player back.
