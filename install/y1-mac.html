Prepare macOS for the install

  1. Download the macOS disk image (Innioasis.Updater.for.Mac.dmg), open it, and drag Innioasis Updater CE into Applications.
  2. The first launch is blocked by Gatekeeper until you approve it. Right-click the app and choose Open, or open System Settings → Privacy & Security and click Open Anyway. Do not disable Gatekeeper for the whole Mac.
  3. No separate USB driver is needed. Connect the player directly to the Mac, not through an unpowered hub; some USB-C adapters drop the connection during a flash.

Intel and Apple Silicon Macs are supported. The current guide targets macOS Monterey (12.0) or later. Full macOS setup notes.

Questions people ask

Can I install custom software on the Innioasis Y1 with macOS?

Yes, when the project lists the Innioasis Y1. Every project card above opens the macOS guide for that software and model.

Do I need a driver on macOS?

No separate driver. Approve the app in Privacy & Security on first launch.

Will I lose my music?

Back up first. A full system install can wipe internal storage; the microSD card is normally left alone.

How do I restore the factory software?

Choose the model and Original Software in Updater CE, pick a stable release, then run Install / Restore.
