What is Y2Player?

A music-first home screen for the Innioasis Y2. Y2Player is built around local playback: a simple home screen, quick access to the library and fewer distractions than the stock Android interface.

Yes. Y2 Player, Y2Player firmware, Y2 Player firmware all refer to the same project.
