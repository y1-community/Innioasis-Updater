Questions people ask

What is JJ Launcher?

A fast, wheel-friendly home screen replacement for the Y1 and Y2. JJ Launcher keeps the player's music-first flow but makes the home screen quicker to move around with the wheel, with hardware-key shortcuts and wireless uploads.

Is JJLauncher the same as JJ Launcher?

Yes. JJLauncher, JJ launcher, y1_launcher, JJ Launcher Y1, JJ Launcher Y2 all refer to the same project.

Which models are supported?

Innioasis Y1, Innioasis Y2. Use the model-specific guide before installing.

How do I go back to stock?

Restore Original Software for the same model if you want the stock home screen back.
