Questions people ask

What is Reborn (Y2Linux)?

A Debian-based Linux system with the native Reborn music player for the Innioasis Y2. Reborn replaces the stock Android system with Linux and a music-first interface. It is the project people search for as y2reborn, Y2Linux or Reborn on Y2.

Is Y2Linux the same as Reborn (Y2Linux)?

Yes. Y2Linux, Y2 Reborn, y2reborn, Reborn Y2, Y2 Linux, Reborn OS all refer to the same project.

Which models are supported?

Innioasis Y2. Use the model-specific guide before installing.

How do I go back to stock?

Restore Original Software for Y2 if you want the stock player back.
