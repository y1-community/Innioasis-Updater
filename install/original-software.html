Why people install Original Software

A stock restore replaces the system with the build the player shipped with. It is the safe way back from Rockbox, Solar, JJ Launcher, Reborn or any other custom system, and it is the first recovery step when an update leaves the player stuck.

Questions people ask

What is Original Software?

The factory system image from Innioasis or Timmkoo, used to undo a custom install or recover a player that will not boot. A stock restore replaces the system with the build the player shipped with. It is the safe way back from Rockbox, Solar, JJ Launcher, Reborn or any other custom system, and it is the first recovery step when an update leaves the player stuck.

Is stock firmware the same as Original Software?

Yes. stock firmware, factory firmware, stock ROM, original firmware, restore firmware all refer to the same project.

Which models are supported?

Innioasis Y1, Innioasis Y2, Innioasis / Timmkoo G1, Innioasis / Timmkoo G3, Innioasis / Timmkoo G5, Innioasis R1, Innioasis PR1, Innioasis SR1, Innioasis / Timmkoo Q3, Innioasis / Timmkoo Q5. Use the model-specific guide before installing.

How do I go back to stock?

This is the restore path itself: choose Original Software for the model and run Install / Restore.
