Install software on Innioasis PR1 on Linux

The Innioasis PR1 is the newer recorder with a colour touchscreen, side buttons and long recording sessions. Its factory software is archived as rom_pr1.zip. The PR1 shares the MT6765 platform family with the G5, but the packages are not interchangeable. These are the Linux routes for the Innioasis PR1.

Prepare Linux for the install

  1. Download UpdaterCE.AppImage, make it executable with chmod +x UpdaterCE.AppImage, and run it. The current AppImage targets Intel/AMD x86_64 systems.
  2. If the AppImage does not start on Ubuntu 22.04 or newer, install libfuse2 with your package manager. On Ubuntu 24.04 the package is libfuse2t64. Do not run the app as root.
  3. If Updater CE cannot open the player, add the MediaTek USB permission rule: save SUBSYSTEM=="usb", ATTR{idVendor}=="0e8d", MODE="0666", GROUP="plugdev" as /etc/udev/rules.d/51-innioasis.rules, then run sudo udevadm control --reload && sudo udevadm trigger. Add your user to plugdev if needed.

The official AppImage is for Intel/AMD Linux. No Linux ARM build is listed. Full Linux setup notes.

Questions people ask

Can I install custom software on the Innioasis PR1 with Linux?

Yes, when the project lists the Innioasis PR1. Every project card above opens the Linux guide for that software and model.

Do I need a driver on Linux?

Add the udev rule for vendor ID 0e8d and make the AppImage executable.

Will I lose my music?

Back up first. A full system install can wipe internal storage; the microSD card is normally left alone.

How do I restore the factory software?

Choose the model and Original Software in Updater CE, pick a stable release, then run Install / Restore.
