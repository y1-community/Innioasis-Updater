Install Better-Y on macOS

A polished stock-based Y1 system with metadata fixes, caching and Now Playing controls. These macOS guides cover every model the project supports. People also search for Better Y, BetterY, Better-Y Y1; this is the same Better-Y install.

Prepare macOS for the install

  1. Download the macOS disk image (Innioasis.Updater.for.Mac.dmg), open it, and drag Innioasis Updater CE into Applications.
  2. The first launch is blocked by Gatekeeper until you approve it. Right-click the app and choose Open, or open System Settings → Privacy & Security and click Open Anyway. Do not disable Gatekeeper for the whole Mac.
  3. No separate USB driver is needed. Connect the player directly to the Mac, not through an unpowered hub; some USB-C adapters drop the connection during a flash.

Intel and Apple Silicon Macs are supported. The current guide targets macOS Monterey (12.0) or later. Full macOS setup notes.

How the install works

  1. Install Updater CE on macOS using the steps above.
  2. Select the model printed on the player, then choose Better-Y.
  3. Choose a stable release listed for that model.
  4. Click Install / Restore, power the player off and connect it at the prompt.
  5. Wait for success. No extra setup is needed for the core features. Check the release notes for the stock version it builds on.

Questions people ask

Which Better-Y package should I download on macOS?

Use Innioasis Updater CE and select the model first. The app downloads the package from the project's official release. If you download manually, use the ZIP that names the model and, on a Y1, the correct Type A or Type B asset.

Does Better-Y work on every model?

This project is listed for Innioasis Y1. Open the model card for the exact guide.

Is Better Y the same as Better-Y?

Yes. Better Y, BetterY, Better-Y Y1 are names people use for the same project.

Do I need a driver?

No separate driver is needed. Approve the app in Privacy & Security on first launch.

Can I undo it?

Restore Original Software for Y1 if you want the stock software back.
