Install firmware on Windows XP, Vista, 7, 8 or 8.1

This guide installs with a software install zip: one download that carries the firmware, the MediaTek driver and the installer, and runs from Windows XP onwards on 32-bit and 64-bit PCs. Use it for firmware, a community software release, an update or a stock package.

Before you start

  • Model: the name printed on the player. A Y1 package will not work on a Y2, and Timmkoo models are not interchangeable with Innioasis ones either.
  • Computer: Windows XP, Vista, 7, 8 or 8.1, 32-bit or 64-bit. Windows 10 and 11 can use Updater CE from the main guide instead.
  • Cable: a USB cable that carries data. A charge-only cable is the usual reason the player is never detected.
  • Power: charge the player to at least half before you begin.
  • Backup: copy music and other files you cannot replace off the player. An install replaces the system partition.

Which file do I download?

Open the firmware list, find the model, then the software you want: Original Software, Rockbox, Solar, JJ Launcher, Inniclassic, Y2Player, Koensayr or another community system. For each release the archive lists the packages it has.

A package for this computer ends in -windows-legacy.zip. It is named after the release, for example rom-windows-legacy.zip or rom_y2-windows-legacy.zip, and it contains the firmware, the installer that writes it, the MediaTek driver, a readme with the details of that release and a donate.txt. If you only see Windows, macOS or Linux packages, that release has not been built for older Windows yet; try the newest release of the same software.

Same firmware, different wrapper. The software install zip holds exactly the same scatter file and partition images as the Updater CE version. The only difference is which app opens them.

Step 1: install the MediaTek USB driver

  1. Unpack the zip somewhere short and simple, such as C:\Innioasis. Avoid folders with long names or spaces.
  2. Run the driver installer from the zip. It is named 1. Install Drivers and Reboot PC. Windows XP and Vista will warn about an unsigned driver; allow it, because the player is invisible without it.
  3. Restart the PC. The driver only takes effect after a reboot.

If Windows still does not see the player later, reinstall the driver and try another USB port on the PC itself rather than a hub. Full Windows driver notes.

Step 2: unpack the firmware

  1. Right-click the downloaded zip and choose Extract All, or use 7-Zip or WinRAR. Do not run anything from inside the zip window.
  2. You should now have a folder with a driver folder, a folder numbered 2 for the app, README.txt and donate.txt. The numbers follow the order you use them.
  3. Find the scatter file: a small text file ending in _Android_scatter.txt. It sits in the folder numbered 2, beside the rom images.

Step 3: write the firmware

  1. Open the app in the folder numbered 2 (its name begins with 2. Open and run).
  2. Choose Scatter-loading and pick the _Android_scatter.txt file. The partition list should fill with the rom files beside it.
  3. Leave the mode on Download Only. Tick Preloader only when the player will not start at all and you are restoring it.
  4. Press Download. Then power the player fully off and plug in the USB cable.
  5. Wait for the green success box. Do not unplug the player and do not close the app while the progress bar is moving.

The player will not switch on? Straighten a paperclip and press the small reset hole on the player for a second, then connect it while it is still off. That resets the power state and leaves your files alone.

Never cross-install a model.A Y1 package on a Y2, or the other way round, can leave the player with dead controls or a boot loop. Check the printed model before you start.

If the install does not start

  1. Nothing happens after Download: unplug the cable, hold the player's power button for ten seconds, press the reset hole with a paperclip, then press Download again and reconnect only once the app is waiting.
  2. The player is never detected: reinstall the MediaTek driver from the first folder, restart the PC and try a different USB port. Some older PCs only work on a rear port.
  3. An error appears part-way through: close the app, power the player off completely, and start again from the scatter file. Do not try a different model's package.
  4. It finishes but will not boot: give the first boot a few minutes, then restore Original Software for the same model from the firmware list.

If no app detects the player at all, treat it as a cable, driver or hardware problem before trying another firmware.

Firmware, software, update or package?

The words are used interchangeably across this site, and the steps above are the same for each:

  • Firmware or rom: the complete system image for a model.
  • Software or system: a community build such as Rockbox, Solar or JJ Launcher, delivered as the same kind of package.
  • Update: a newer release of either. Install it exactly like a fresh package.
  • Package or zip: the download. A software install zip is the one built for this PC.

Supporting the projects

Every software install zip includes donate.txt, which lists the ways to support the people who keep these players usable. Nothing in the package is limited by whether you donate.

Questions people ask

Can I install Innioasis firmware on Windows XP or Windows 7?

Yes. Every release has a software install zip ending in -windows-legacy.zip that carries the same firmware and an installer that works from Windows XP onwards, on both 32-bit and 64-bit Windows.

Which package should I use on an older or 32-bit PC?

Use the software install zip. It is built for these PCs and includes the firmware, the driver and the installer, so no separate download is needed.

Is the -windows-legacy.zip the same firmware?

Yes. It is the same rom for the same release, packaged with a stand-alone installer instead of the Updater CE app. The scatter file and partition images are identical.

Do I need the internet on the player?

No. Everything needed is inside the zip: the firmware, the installer, the MediaTek driver and a donate.txt. Nothing is downloaded during the install.

Will installing erase my music?

An install writes the system partition, so copy any files you cannot replace off the player first. Files on a microSD card are normally left alone, but remove the card if you want to be certain.

What if the installer does not detect the player?

Reinstall the MediaTek driver from the first folder, restart the PC, use a USB port on the PC itself rather than a hub, and press Download before connecting the powered-off player. If the player will not switch on, press the reset hole with a paperclip first.
