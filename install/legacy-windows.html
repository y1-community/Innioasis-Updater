Older Windows · Windows XP / Vista / 7 / 8 / 8.1 · 32-bit and 64-bit

Install firmware on Windows XP, Vista, 7, 8 or 8.1

Updater CE needs 64-bit Windows 10 (1809 or newer), so it cannot open on these PCs. The same firmware is published as a package that carries SP Flash Tool beside the rom, and that tool runs from Windows XP onwards. This guide installs firmware, a community software release, an update or a stock package with it.

Before you start

  • Model: the name printed on the player. A Y1 package will not work on a Y2, and Timmkoo models are not interchangeable with Innioasis ones either.
  • Computer: Windows XP, Vista, 7, 8 or 8.1, 32-bit or 64-bit. Windows 10 and 11 can use Updater CE from the main guide instead.
  • Cable: a USB cable that carries data. A charge-only cable is the usual reason the player is never detected.
  • Power: charge the player to at least half before you begin.
  • Backup: copy music and other files you cannot replace off the player. A flash replaces the system partition.

Which file do I download?

Open the firmware list, find the model, then the software you want: Original Software, Rockbox, Solar, JJ Launcher, Inniclassic, Y2Player, Koensayr or another community system. For each release the archive lists the packages it has.

A package for this computer ends in -windows-legacy.zip. It is named after the release, for example rom-windows-legacy.zip or rom_y2-windows-legacy.zip, and it contains the firmware, SP Flash Tool, the MediaTek driver and a donate.txt. If you only see Windows, macOS or Linux packages, that release has not been built for older Windows yet; try the newest release of the same software.

Same firmware, different wrapper. The legacy package holds exactly the same scatter file and partition images as the Updater CE version. The only difference is which tool opens them.

Step 1: install the MediaTek USB driver

  1. Unpack the zip somewhere short and simple, such as C:\Innioasis. Avoid folders with long names or spaces.
  2. Open the Driver folder and run the installer inside it. Windows XP and Vista will warn about an unsigned driver; allow it, because the player is invisible without it.
  3. Restart the PC. The driver only takes effect after a reboot.

If Windows still does not see the player later, reinstall the driver and try another USB port on the PC itself rather than a hub. Full Windows driver notes.

Step 2: unpack the firmware package

  1. Right-click the downloaded zip and choose Extract All, or use 7-Zip or WinRAR. Do not run anything from inside the zip window.
  2. You should now have a folder with the SP_Flash_Tool folder, a Driver folder, README.txt and donate.txt.
  3. Find the scatter file: a small text file ending in _Android_scatter.txt. It sits in the SP_Flash_Tool folder beside the rom images.

Step 3: flash the player

  1. Open flash_tool.exe from the SP_Flash_Tool folder.
  2. Click Scatter-loading and choose the _Android_scatter.txt file. The partition list should fill with the rom files beside it.
  3. Leave the mode on Download Only. Tick Preloader only when the player will not start at all and you are restoring it.
  4. Click Download, then power the player fully off and connect the USB cable.
  5. Wait for the green success box. Do not unplug the player or close SP Flash Tool while the progress bar is moving.
Never cross-install a model.A Y1 package on a Y2, or the other way round, can leave the player with dead controls or a boot loop. Check the printed model before you start.

If the flash does not start

  1. Nothing happens after Download: unplug the cable, hold the player's power button for ten seconds, then click Download again and reconnect only after SP Flash Tool is waiting.
  2. The player is never detected: reinstall the MediaTek driver from the Driver folder, restart the PC and try a different USB port. Some older PCs only work on a rear port.
  3. An error appears part-way through: close SP Flash Tool, power the player off completely, and start again from the scatter file. Do not try a different model's package.
  4. It finishes but will not boot: give the first boot a few minutes, then restore Original Software for the same model from the firmware list.

If no tool detects the player at all, treat it as a cable, driver or hardware problem before trying another firmware.

Firmware, software, update or package?

The words are used interchangeably across this site, and the steps above are the same for each:

  • Firmware or rom: the complete system image for a model.
  • Software or system: a community build such as Rockbox, Solar or JJ Launcher, delivered as the same kind of package.
  • Update: a newer release of either. Install it exactly like a fresh package.
  • Package or zip: the download. A legacy package is the one that includes SP Flash Tool.

Supporting the projects

Every legacy package includes donate.txt, which lists the ways to support the people who keep these players usable. Nothing in the package is limited by whether you donate.

Questions people ask

Can I install Innioasis firmware on Windows XP or Windows 7?

Yes. Updater CE cannot run there, but every release has a package ending in -windows-legacy.zip that carries SP Flash Tool and the same firmware. It works from Windows XP onwards, on both 32-bit and 64-bit Windows.

Why is Updater CE not offered on this computer?

Updater CE is a 64-bit application and needs Windows 10 1809 or newer. On Windows XP, Vista, 7, 8, 8.1 or 32-bit Windows the site offers the SP Flash Tool package instead, because the app cannot open there.

Is the -windows-legacy.zip the same firmware?

Yes. It is the same rom for the same release, packed beside SP Flash Tool instead of the Updater CE app. The scatter file and partition images are identical.

Do I need the internet on the player?

No. Everything needed is inside the zip: the firmware, SP Flash Tool, the MediaTek driver and a donate.txt. Nothing is downloaded during the flash.

Will flashing erase my music?

A flash writes the system partition, so copy any files you cannot replace off the player first. Files on a microSD card are normally left alone, but remove the card if you want to be certain.

What if SP Flash Tool does not detect the player?

Reinstall the MediaTek driver from the Driver folder, restart the PC, use a USB port on the PC itself rather than a hub, and press Download before connecting the powered-off player.
