Linux Y1 install steps

  1. Bilgisayarınızda Innioasis Updater CE'yi açın (uygulamaya ihtiyacınız varsa, Updater CE edin). Ayarlamak Cihaz modeli ile Y1.
  2. Seçmek Linux for Y1 (Dev) içinde Yazılım.
  3. Y1 için listelenen sürümü seçin.
  4. Tıklamak Yükle / Geri yükle.
  5. Y1'i yalnızca Updater CE sorduğunda kapatın ve bağlayın.
