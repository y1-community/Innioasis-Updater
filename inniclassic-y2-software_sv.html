Inniclassic Y2 install steps

  1. Öppna Innioasis Updater CE på din dator (om du behöver appen, Hämta Updater CE). Ställ in Enhetsmodell till Y2.
  2. Välj Inniclassic i Programvara.
  3. Choose the release listed for Y2.
  4. Klicka Installera / Återställ.
  5. Stäng av och anslut Y2 endast när Updater CE frågar.

Vanliga frågor

Can I restore the stock Y2 software?

Yes. Select Y2 and Original Software in Updater CE. The Y2 stock-software guide täcker returvägen.

Can I use Inniclassic on Y1?

Yes. The same project publishes Y1 packages as well — rom.zip for Type A and rom_type_b.zip for Type B. Select Y1 in Updater CE and install the Y1 build; the Y1 installationssida covers it.

Vad händer om installationen misslyckas?

Note whether Updater failed before or after detecting the Y2, then check the cable, platform setup, model, and connection timing in felsökning.
