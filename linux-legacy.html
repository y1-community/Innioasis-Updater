Install software, firmware or updates on a 32-bit Linux PC

On a 32-bit Intel or AMD Linux PC we install with a 32-bit Linux software install zip instead of Updater CE. Every package in the archive has one, it runs here, and it contains everything needed for the install: the firmware, the installer and a readme. On older Windows instead, read the Windows page.

Which package do I download?

Open the firmware list, find your model, then find the software you want: Original Software, Rockbox, Solar, JJ Launcher, Inniclassic, Y2Player, Koensayr or a community system. Each release shows its packages as buttons. On a 32-bit Linux PC the archive offers the 32-bit Linux package; the same row offers the normal Linux, Windows and macOS builds for other computers.

The package name tells you what it is. A software install zip is named after the release, with -linux-legacy before .zip. Inside you get the firmware files (the rom and its scatter file), the installer that writes the firmware, a readme with the details of that release and a donate.txt. Nothing in it needs an internet connection.

Firmware is model-specific. Software written for the Y1 cannot be installed on a Y2, and the reverse is also true. Check the model printed on the player before you download.

Step 1: unpack the zip

  1. Unpack the software install zip into its own folder, for example ~/innioasis. Keep the folder together: the installer reads the rom files next to itself.
  2. Open a terminal in that folder.
  3. Make the installer runnable. The readme inside the zip names the exact file; the usual command is chmod +x ./*.

Linux needs no separate USB driver package for this. If the player is never detected, see the Linux setup notes for the MediaTek udev rule.

Step 2: write the firmware

  1. Start the installer from the folder: ./flash_tool, or the name the readme gives.
  2. Choose Scatter-loading, pick the _Android_scatter.txt file from the firmware folder, and check that the partition list fills with the rom files beside it.
  3. Leave the default Download Only mode. Keep Preloader ticked only if you are restoring a player that will not start at all.
  4. Press Download. Then power the player fully off and plug in the USB cable. The installer writes the firmware the moment the player appears.
  5. Wait for the green success box. Do not unplug the player, and do not close the installer, while the progress bar is moving.

If the player will not switch on at all, straighten a paperclip and press the small reset hole on the player for a second before you connect it. That resets the power state without touching your files, and it is the usual fix when nothing appears after you press Download.

Some distributions block a program that was unpacked from a download until it is marked executable. If the shell answers Permission denied, run the chmod +x command again in the folder that holds the installer.

Software, firmware, update or package: what is the difference?

The words are used interchangeably on this site, and the steps above are the same for each:

  • Firmware or rom: the complete system image for a model. Installing it replaces everything on the player's system partition.
  • Software or system: a community build such as Rockbox, Solar or JJ Launcher, delivered as the same kind of rom package.
  • Update: a newer release of either of the above. Install it exactly like a fresh package.
  • Package, zip or software install zip: the download itself. The software install zip is the one built for this PC.

Updater CE does the same job with fewer steps, and it keeps your music and Bluetooth pairings. It is only available on 64-bit Windows 10 (1809 or newer), macOS and 64-bit Linux. A software install zip install writes the system partition, so copy your music off the player first if you have files you cannot replace.

After the install

Disconnect the player, switch it on, and let it finish its first boot. If it starts but shows the wrong language, install the package again with the language you want. If it does not start, connect it while switched off and write the firmware again, this time with Preloader ticked.
