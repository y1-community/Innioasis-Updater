🚀 Innioasis Updater - Guia de instalação incorporável

Este é um widget de guia de instalação completo e incorporável que pode ser facilmente integrado a qualquer site. Ele apresenta um CTA pop-up no canto inferior direito que abre um guia de instalação abrangente para usuários de Windows, macOS e Linux.

🎨 Belo design

Design moderno e responsivo que funciona em todos os dispositivos com suporte ao modo escuro

📱 Plataforma cruzada

Guias de instalação completos para Windows, macOS e Linux com instruções passo a passo

🔧 Fácil Integração

Basta copiar e colar o snippet - sem necessidade de dependências ou configurações complexas

💾 Armazenamento Inteligente

Lembra se os usuários fecharam o banner para evitar ser intrusivo

📋 Instruções de integração

Para adicionar o guia de instalação Innioasis Updater ao seu site, basta copiar e colar este trecho de código em seu HTML:

<!-- Innioasis Updater Guia de instalação do widget --> <script> (function() { // Crie e injete o widget const script = document.createElement('script'); script.src = 'https://your-domain.com/innioasis-embed.html'; script.async = true; // Alternativa: Carregar do arquivo local // script.src = './innioasis-embed.html'; document.head.appendChild(script); // Criar contêiner iframe const iframe = document.createElement ('iframe'); iframe.src = 'https://your-domain.com/innioasis-embed.html'; `; // Torna o iframe interativo iframe.onload = function() { iframe.style.pointerEvents = 'auto' }; </script>

🎯 Alternativa: método de incorporação direta

Para uma integração ainda mais simples, você pode incorporar o widget diretamente usando um iframe:

<!-- Incorporação direta de iframe --> <iframe src="https://seu-domínio.com/innioasis-embed.html" largura="400" altura="200" frameborder="0" style="posição: fixa; inferior: 20px; direita: 20px; índice z: 999999; raio da borda: 12px; sombra da caixa: 0 8px 32px rgb(0,0,0,0,3);" permitirtransparência="true"> </iframe>

🌐 Requisitos de hospedagem

Para usar este widget em seu site, você precisa:

  1. Carregar o innioasis-embed.html arquivo para o seu servidor web
  2. Atualize os URLs no snippet de integração para apontar para seu servidor
  3. Certifique-se de que seu servidor suporte HTTPS (obrigatório para navegadores modernos)
  4. Teste o widget em seu site para garantir que funciona corretamente

🆘 Suporte

Se precisar de ajuda para integrar este widget ou tiver dúvidas, por favor:

  • Verifique se há mensagens de erro no console do navegador
  • Certifique-se de que todos os arquivos sejam carregados corretamente em seu servidor
  • Verifique se os URLs no código de integração estão corretos
  • Teste em diferentes navegadores e dispositivos
