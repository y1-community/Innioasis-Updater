Como instalar ou atualizar Y1 firmware

Atualizar ou desbloquear seu Innioasis Y1 é simples com nosso pacote de software multiplataforma:

  1. Abra Innioasis Updater CE: Inicie o atualizador no macOS, Windows ou Linux.
  2. Selecione o modelo Y1: Escolher Y1 no menu suspenso Modelo do dispositivo.
  3. Escolha seu sistema operacional: Selecione Rockbox, Better-Y, Solar ou Software Original.
  4. Clique em Instalar: Updater CE baixa o pacote de firmware diretamente da versão do desenvolvedor. Quando solicitado, conecte seu Y1 desligado via USB para começar a piscar.
