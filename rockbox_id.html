Rockbox referensi

Mendapatkan Rockbox di Y1 atau Y2 Anda

Rockbox mengubah perangkat lunak pemutar dan membuka antarmuka pemutar musik yang lebih dalam, kontrol pemutaran, pengurutan, dan opsi tema. Penginstalan dipandu, tetapi Y1 dan Y2 merupakan perjalanan yang terpisah.

Rockbox pada Y1Rockbox pada Y2Mengapa Rockbox?

Apa yang diubah oleh instalasi

Rockbox adalah perangkat lunak khusus. Ini tidak menghilangkan kemampuan Anda untuk kembali ke antarmuka stok ketika paket Perangkat Lunak Asli yang cocok tersedia. Ini dapat meningkatkan penelusuran dan penyesuaian musik, tetapi fitur, resolusi, masa pakai baterai, dan kompatibilitas tema bergantung pada versinya.

Jangan mencampur model. Pilih Y1 untuk pemain Y1 dan Y2 untuk pemain Y2. Nama rilis yang tampak serupa tidak cukup untuk membuktikan bahwa suatu paket kompatibel.

Rute Updater bersama

  1. Instal Updater dan jangan sambungkan apa pun sampai diminta.
  2. Pilih model yang tercetak pada pemutar di Model perangkat.
  3. Pilih Rockbox di Perangkat lunak.
  4. Pilih rilis stabil kecuali Anda sengaja menguji versi malam.
  5. Klik Pasang / Pulihkan, lalu ikuti perintah mematikan dan koneksi USB.
  6. Putuskan sambungan hanya setelah pesan sukses.

240p, 360p, dan tema

Koleksi tema Rockbox yang lebih lama dapat dibuat untuk 240p. Y1 build komunitas juga menggunakan label kompatibilitas 360p. Baca catatan rilis dan sumber tema sebelum memilih build. Tema yang dibuat untuk satu resolusi atau rangkaian perangkat lunak mungkin tidak berfungsi pada resolusi lain.

Kembali ke Perangkat Lunak Asli

Pilih model yang sama lagi, pilih Perangkat lunak asli, pilih rilis stabil, dan gunakan Pasang / Pulihkan. Jika kegagalan terjadi sebelum prompt USB, periksa komputer dan ekstrak file. Jika pemutar terdeteksi tetapi flash gagal, mulailah dengan pemecahan masalah.

Pertanyaan umum

Saya menginstal ulang Rockbox dan tidak memperbaiki apa pun.

Menginstal ulang Rockbox akan menulis build yang sama pada file yang sama, sehingga tidak dapat mengatur ulang hal-hal yang Rockbox simpan di MicroSD. Jika masalahnya adalah pengaturan, tema, daftar putar, atau basis data yang rusak pada kartu, menginstal ulang tidak akan menghapusnya. Reset yang andal adalah menghapus .rockbox folder dari MicroSD — Rockbox membuat yang baru pada boot berikutnya.

  1. Matikan pemutar sepenuhnya dan keluarkan kartu MicroSD, atau sambungkan pemutar sebagai drive USB.
  2. Tampilkan file tersembunyi di komputer Anda sehingga foldernya terlihat. Tampilkan dotfiles di komputer AndaWindows: di File Explorer buka Lihat tab dan centang Barang tersembunyi.macOS: di Penemu tekan Cmd+Shift+. untuk mengaktifkan file tersembunyi.Linux · Berkas GNOME: tekan Ctrl+H, atau buka menu dan pilih Tampilkan File Tersembunyi.Linux · KDE Lumba-lumba: tekan Ctrl+H, atau gunakan Lihat → Tampilkan File Tersembunyi.
  3. Hapus itu .rockbox folder dari root kartu.
  4. Masukkan kembali kartu dan mulai pemutar. Rockbox membuat ulang folder dengan default.
  5. Terapkan kembali tema dan pengaturan Anda. Jika masalah hanya muncul kembali setelah tema tertentu, maka tema itulah penyebabnya.

Menghapus .rockbox tidak menghapus instalan Rockbox dan tidak menyentuh musik Anda — folder tersebut menyimpan pengaturan, tema, dan cache, dan dibuat ulang secara otomatis. Jika Anda ingin menyimpan tema Anda, salin folder tersebut .rockbox sebelum menghapusnya, atau ganti nama folder menjadi .rockbox-old pertama.

Mengapa saya tidak dapat melihat folder .rockbox di MicroSD saya?

Folder yang namanya dimulai dengan titik disembunyikan secara default di sebagian besar komputer. Anda tidak perlu melihatnya untuk menginstal Rockbox — Updater menangani file. Jika Anda sedang memecahkan masalah dan ingin menghapusnya, aktifkan file tersembunyi terlebih dahulu. Tampilkan dotfiles di komputer AndaWindows: di File Explorer buka Lihat tab dan centang Barang tersembunyi.macOS: di Penemu tekan Cmd+Shift+. untuk mengaktifkan file tersembunyi.Linux · Berkas GNOME: tekan Ctrl+H, atau buka menu dan pilih Tampilkan File Tersembunyi.Linux · KDE Lumba-lumba: tekan Ctrl+H, atau gunakan Lihat → Tampilkan File Tersembunyi.

Apakah menghapus .rockbox akan mengatur ulang tema dan pengaturan saya?

Ya — .rockbox menyimpan pengaturan Rockbox, tema, daftar putar, dan basis data cache. Menghapusnya akan mengembalikan Rockbox ke keadaan default yang bersih. Cadangkan seluruh folder (atau ganti namanya menjadi .rockbox-old) jika Anda menginginkannya kembali, jalankan pemutar dan Rockbox buat folder baru.
