Kom godt i gang med Innioasis Updater CE

Fungerer med alle Innioasis og Timmkoo lydafspillere. Installer Innioasis Updater CE på din computer, vælg din model og den ønskede software, og følg derefter vejledningen.

    Få Innioasis Updater CE

    Innioasis Opdaterer CE er appen, der installerer officielle opdateringer og community-software på din afspiller. Den beholder din musik og dine indstillinger, og den kører på Windows, macOS og Linux.

    Windows

    Download installationsprogrammet, kør det, og genstart derefter din pc, når det er færdigt.

    Hent drivereDownload Updater CE

    Hvis Windows forhindrer dig i at køre appen eller ikke starter den, skal du åbne Indstillinger, klikke på Privatliv og sikkerhed → Windows Sikkerhed → App- og browserkontrol og slå Smart App Control fra. Smart App Control påvirker i øjeblikket populære applikationer som Epic Overlay Service (brugt af Fortnite) - Updater CE er sikker og verificeret at bruge. Vil Windows ikke starte appen? Hjælp

    Genstart din pc efter installation. Driver hjælp er i Windows opsætningsnoter.

    macOS

    Download Updater CE

    Hvis din Mac forhindrer dig i at køre appen for første gang, skal du åbne Systemindstillinger, klikke på Privatliv og sikkerhed, rulle ned til Sikkerhed og klikke på Åben alligevel. Du kan også Ctrl-klikke (eller højreklikke) på appen i Finder og vælge Åbn.

    Fungerer på Intel og Apple Silicon Macs med macOS Monterey og nyere.

    Linux

    Download AppImage til Intel- og AMD-systemer, gør det eksekverbart, og kør det.

    Download AppImage til Intel/AMD

    Noter til Linux-opsætning

    Du skal bruge din afspiller, et USB datakabel, der bærer data (et kabel, der kun kan oplades), og et par minutter. Hold kablet tilsluttet, indtil Updater CE siger, at det er gjort.

    Vælg din model og software

    1. Enhedsmodel: vælg den model, der er trykt på afspilleren, Y1 eller Y2. Software lavet til den ene model kan ikke installeres på den anden.
    2. Software og udgivelse: vælg Original Software, Rockbox, Solar, JJ Launcher, Inniclassic, Y2Player, eller Koensayr, når det er angivet for din model, og vælg derefter en udgivelse. Stabil er det sikre valg.
    3. Installer: klik Installer / Gendan, sluk for afspilleren helt, og tilslut kun USB-kablet, når Updater CE spørger.
    4. Afslut: lad afspilleren og kablet være i fred indtil succesmeddelelsen, afbryd derefter og start afspilleren.

    Y1 spillere, der blev leveret med original software før 2.0.0 har brug for Enhed Type B. Alle andre beholder standard Type A.

    Går tilbage til original software

    Brugerdefineret software er reversibel. I Updater CE, vælg din model, vælg Original software, vælg en stabil udgivelse, og kør derefter Installer / Gendan på samme måde. Der er ikke noget at slette i hånden.

    Vil Windows ikke starte appen? Smart App Control-løsning

    Windows Defender SmartScreen eller Smart App Control kan blokere nyligt downloadede fællesskabsapplikationer, før signaturomdømmet breder sig. Smart App Control påvirker i øjeblikket populære applikationer som Epic Overlay Service (brugt af Fortnite) - Updater CE er sikker og verificeret at bruge. Hvis du slår Smart App Control fra, kan Updater CE åbne og køre normalt.

    1. Åbn Indstillinger på din Windows-pc (tryk på Win + I).
    2. Klik Privatliv og sikkerhed i venstre sidebjælke, og klik derefter Windows Security.
    3. Klik App og browser kontrol.
    4. Under Smart app kontrol, klik Indstillinger for Smart App Control.
    5. Indstil kontakten til Slukket for at tillade Updater CE at starte.

    Downloadet via Edge? Hvis Edge blokerer selve overførslen, skal du klikke på knappen Flere muligheder (…) → Behold → Vis mere → Behold alligevel.

    Genaktiver Smart App Control senere: Når du vil slå Smart App Control til igen, kan du genaktivere den via Windows-registreringsdatabasen under HKEY_LOCAL_MACHINE\SYSTEM\CurrentControlSet\Control\CI\Policy ved indstilling VerifiedAndReputablePolicyState til 1 (Til) eller 2 (Evalueringstilstand) og genstart.
