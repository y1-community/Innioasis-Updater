模型正確性檢查

  1. 在您的電腦上開啟 Innioasis Updater CE（如果您需要該應用程序， 取得 Updater CE）。套裝 裝置型號 到 Y2.
  2. 確認 JJ Launcher 在目前版本資料中顯示 Y2。
  3. 閱讀項目發行說明並選擇列出的 Y2 版本。
  4. 點選 安裝 / 還原.
  5. 僅在出現提示時關閉電源並連接 Y2。
不要替代： Y1 包不是 Y2 包。如果模型和版本不一致，請停止。

常見問題

Y2 支援有保證嗎？

列出了 Y2 版本，但支援的內容可能會發生變化。安裝前檢查最新清單和項目說明。

如何恢復Y2？

在 Updater CE 中選擇 Y2 和原始軟體，然後依照 Y2恢復步驟.

如果 JJ Launcher 未列出怎麼辦？

不要強制使用 Y1 包。檢查項目版本和 故障排除指南.

從更新程式 CE 開始

使用 Windows、macOS 或 Linux 設定指南 連接播放器之前。
