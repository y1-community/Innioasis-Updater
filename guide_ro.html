Noțiuni introductive cu Innioasis Updater CE

Funcționează cu toate playerele audio Innioasis și Timmkoo. Instalați Innioasis Updater CE pe computer, alegeți modelul și software-ul dorit, apoi urmați instrucțiunile.

    Obțineți Innioasis Updater CE

    Innioasis Updater CE este aplicația care instalează actualizări oficiale și software comunitar pe playerul tău. Îți păstrează muzica și setările și rulează pe Windows, macOS și Linux.

    Windows

    Descărcați programul de instalare, rulați-l, apoi reporniți computerul când se termină.

    Obțineți șoferiDescărcați Updater CE

    Dacă Windows vă împiedică să rulați aplicația sau nu o lansează, deschideți Setări, faceți clic pe Confidențialitate și securitate → Securitate Windows → Control aplicație și browser și dezactivați Controlul aplicației inteligente. Smart App Control afectează în prezent aplicațiile populare, cum ar fi Epic Overlay Service (utilizat de Fortnite) - Updater CE este sigur și verificat pentru utilizare. Windows nu va lansa aplicația? Ajutor

    Reporniți computerul după instalare. Ajutorul șoferului este în Note de instalare Windows.

    macOS

    Descărcați Updater CE

    Dacă Mac-ul dvs. vă oprește să rulați aplicația pentru prima dată, deschideți Setări sistem, faceți clic pe Confidențialitate și securitate, derulați în jos la Securitate și faceți clic pe Deschide oricum. Puteți, de asemenea, să faceți Control-clic (sau să faceți clic dreapta) pe aplicație în Finder și să alegeți Deschidere.

    Funcționează pe Intel și Apple Silicon Mac cu macOS Monterey și mai târziu.

    Linux

    Descărcați AppImage pentru sistemele Intel și AMD, faceți-l executabil și rulați-l.

    Descărcați AppImage pentru Intel/AMD

    Note de configurare Linux

    Aveți nevoie de playerul dvs., de un cablu de date USB care transportă date (un cablu de încărcare nu poate fi instalat) și de câteva minute. Țineți cablul conectat până când Updater CE spune că s-a terminat.

    Alegeți modelul și software-ul dvs

    1. Model de dispozitiv: alege modelul imprimat pe player, Y1 sau Y2. Software-ul creat pentru un model nu poate fi instalat pe celălalt.
    2. Software și lansare: alegeți Software original, Rockbox, Solar, JJ Launcher, Inniclassic, Y2Player sau Koensayr când este listat pentru modelul dvs., apoi alegeți o versiune. Stabil este alegerea sigură.
    3. Instalați: faceți clic Instalează / Restaurează, opriți complet playerul și conectați cablul USB numai când Updater CE vă solicită.
    4. Terminare: lăsați playerul și cablul în pace până la mesajul de succes, apoi deconectați și porniți playerul.

    Y1 jucători care au fost livrate cu software-ul original înainte de 2.0.0 au nevoie Dispozitiv Type B. Toți ceilalți păstrează valoarea implicită Type A.

    Revenind la software-ul original

    Software-ul personalizat este reversibil. În Updater CE, alegeți modelul dvs., selectați Software original, alegeți o versiune stabilă, apoi rulați Instalează / Restaurează la fel. Nu există nimic de șters manual.

    Windows nu va lansa aplicația? Soluție pentru controlul aplicațiilor inteligente

    Windows Defender SmartScreen sau Smart App Control pot bloca aplicațiile comunitare recent descărcate înainte ca reputația semnăturii să se propage. Smart App Control afectează în prezent aplicațiile populare, cum ar fi Epic Overlay Service (utilizat de Fortnite) - Updater CE este sigur și verificat pentru utilizare. Dezactivarea Smart App Control permite ca Updater CE să se deschidă și să ruleze normal.

    1. Deschide Setări pe computerul dvs. cu Windows (apăsați Win + I).
    2. Faceți clic Confidențialitate și securitate în bara laterală din stânga, apoi faceți clic Windows Security.
    3. Faceți clic Controlul aplicației și browserului.
    4. Sub Control inteligent al aplicației, faceți clic Setări Smart App Control.
    5. Setați comutatorul la Oprit pentru a permite lansarea Updater CE.

    Descărcat prin Edge? Dacă Edge blochează descărcarea în sine, faceți clic pe butonul Mai multe opțiuni (…) → Păstrează → Arată mai multe → Păstrați oricum.

    Reactivarea Smart App Control mai târziu: Când doriți să reactivați Smart App Control, îl puteți reactiva prin Registrul Windows de sub HKEY_LOCAL_MACHINE\SYSTEM\CurrentControlSet\Control\CI\Policy prin setare VerifiedAndReputablePolicyState la 1 (Activat) sau 2 (Mod de evaluare) și repornire.
