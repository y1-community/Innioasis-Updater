🚀 Innioasis Updater - Incorporar widget

Copie e cole este código em seu site para incorporar o widget Innioasis Updater:

<!-- Innioasis Updater Widget incorporado --> <iframe src="https://inniaosis.app/innioasis-simple-embed.html" width="300" height="120" frameborder="0" style="position: fixa; inferior: 20px; direita: 20px; índice z: 999999; raio da borda: 12px; sombra da caixa: 0 8px 32px RGB(0,0,0,0,3);" permitirtransparência="true"> </iframe>

📝 Como usar:

  1. Copie o código acima
  2. Cole-o no HTML do seu site
  3. O widget aparecerá no canto inferior direito
  4. Os usuários podem clicar para obter guias de instalação para sua plataforma
