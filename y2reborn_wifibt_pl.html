Dlaczego ten plik?

Wi-Fi, Bluetooth i radio FM wymagają pięciu modułów firmware MediaTek, których Reborn nie może dołączyć. Znajdują się w oficjalnym pliku Y2 system.img. Reborn rozpakowuje je raz, sprawdza i usuwa plik.

Konfiguracja

  1. Pobierz system.img

    Pobierz plik FM v3.2.0 system.img na komputer.

    Pobierz system.img
  2. Uruchom Reborn raz

    Włącz odtwarzacz. Poczekaj na Konfiguracja pamięci aby zakończyć, a potem raz go zrestartuj.

  3. Podłącz do komputera

    Użyj kabla USB do transmisji danych. Odtwarzacz pojawi się jako Pamięć wewnętrzna.

    Masz Maca?

    Zainstaluj OpenMTP aby przeglądać zawartość odtwarzacza. Windows i Linux montują go automatycznie.

  4. Skopiuj system.img do firmware

    Utwórz folder o nazwie Firmware w katalogu głównym pamięci wewnętrznej. Skopiuj system.img do niego.

  5. Poczekaj na zakończenie konfiguracji

    Reborn instaluje firmware radia automatycznie i usuwa system.img. Zajmuje to około 10–20 sekund. Poczekaj na Wi-Fi i Bluetooth są gotowe.

  6. Połącz Wi-Fi, Bluetooth i radio FM
    • Wi-Fi: Settings → System → Network → Wi-Fi. Wybierz sieć 2,4 GHz.
    • Bluetooth: Włącz w słuchawkach tryb parowania. Ustawienia → Bluetooth → wybierz je.
    • Radio FM: Podłącz słuchawki przewodowe jako antenę, a potem otwórz Radio FM.
  7. Aktualizacja przez Wi-Fi

    Kolejne aktualizacje Reborn zainstalujesz z Settings → System → Software Update. Firmware radia pozostaje bez zmian.
