Modellkorrekte Prüfungen

  1. Öffnen Sie Innioasis Updater CE auf Ihrem Computer (wenn Sie die App benötigen, Updater CE holen). Satz Gerätemodell an Y2.
  2. Bestätigen JJ Launcher erscheint für Y2 in den aktuellen Versionsdaten.
  3. Lesen Sie die Versionshinweise zum Projekt und wählen Sie die aufgeführte Version Y2 aus.
  4. Klicken Sie Installieren / Wiederherstellen.
  5. Schalten Sie das Gerät aus und schließen Sie das Y2 nur an, wenn Sie dazu aufgefordert werden.
Nicht ersetzen: Ein Y1-Paket ist kein Y2-Paket. Stoppen Sie, wenn Modell und Release nicht übereinstimmen.

FAQ

Ist der Support von Y2 garantiert?

Es ist ein Y2 Build aufgeführt, aber was unterstützt wird, kann sich ändern. Überprüfen Sie vor der Installation die aktuelle Auflistung und die Projektnotizen.

Wie stelle ich die Y2 wieder her?

Wählen Sie Y2 und Originalsoftware in Updater CE und folgen Sie dann den Anweisungen Y2 Wiederherstellungsschritte.

Was passiert, wenn JJ Launcher nicht aufgeführt ist?

Erzwingen Sie kein Y1-Paket. Überprüfen Sie die Projektfreigaben und die Anleitung zur Fehlerbehebung.
