Solar Y1 etapas de instalação

  1. Abra o Innioasis Updater CE no seu computador (se precisar do aplicativo, Obter o Updater CE). Definir Modelo do aparelho para Y1.
  2. Escolher Solar em Software.
  3. Leia a nota de lançamento do projeto e escolha uma versão Y1.
  4. Clique Instalar / Restaurar.
  5. Desligue e conecte o Y1 somente quando o prompt aparecer.

Solar recursos e disponibilidade podem mudar. Os recursos podem mudar entre os lançamentos, portanto verifique a página de lançamento do projeto e a listagem atual do seu modelo.

Perguntas frequentes

Posso retornar de Solar para o software original?

Use Y1 software original em Updater CE. Você não precisa remover manualmente Solar primeiro. Siga o Y1 etapas de restauração.

Posso instalar a entrada Solar Y2 neste player?

Não. Mantenha o player Y1 na entrada Y1 e verifique o modelo antes de instalar.

Onde devo verificar os recursos Solar atuais?

Leia o notas de lançamento antes de escolher um lançamento.

Precisa de uma explicação mais ampla do atualizador?

Veja o Guia do atualizador do Windows, macOS e Linux antes de iniciar, especialmente se Y1 não for detectado.
