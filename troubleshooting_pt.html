Solução de problemas

Encontre o ponto onde a instalação foi interrompida.

Onde isso parou? Isso lhe diz o que consertar.

Voltar ao guia normalVerifique o firmware

Parou antes do prompt USB

Este é um problema de computador, não de cabo. Verifique seu modelo. Descompacte o arquivo novamente. Então tente Instalar / Restaurar. Se a lista de lançamentos estiver vazia, abra o diretório de firmware.

Não é possível conectar ao player

  1. Desligue totalmente o Y1 ou Y2 correto.
  2. Desconecte o cabo, feche outras ferramentas flash ou Android e reinicie a instalação.
  3. Conecte-se somente quando o Updater disser que está pronto.
  4. Use um cabo de dados curto USB diretamente no computador, não um hub, se possível.
  5. On Windows, reinstall the MediaTek driver and restart. No Linux, verifique as permissões USB/serial.

Ele detectou o player, mas o flash falhou

Pare aqui. Não tente um modelo diferente. Feche as outras ferramentas, verifique se você escolheu Y1 ou Y2 correto e use o software original correspondente se o player não iniciar. SP Flash Tool e MTKClient estão incluídos se você precisar deles, e os arquivos estão no página de firmware.

Notas sobre drivers do Windows

Algumas instalações do Windows bloqueiam o driver MediaTek devido ao isolamento do Core. Siga as orientações de segurança atuais do Windows antes de alterar a integridade da memória e ligue-a novamente quando terminar, se o seu sistema permitir.
