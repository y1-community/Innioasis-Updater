Rockbox Y2 pasos de instalación

  1. Abra Innioasis Updater CE en su computadora (si necesita la aplicación, Obtener Updater CE). conjunto Modelo del dispositivo a Y2.
  2. elegir Rockbox en Software.
  3. Elija una versión listada explícitamente para Y2.
  4. Haga clic Instalar / Restaurar y espere la preparación del paquete.
  5. Apague y conecte el Y2 solo cuando Updater CE lo solicite.

No fuerce un paquete Y1 porque el nombre del proyecto tiene el mismo aspecto. Si no aparece ninguna versión Y2, deténgase y verifique el modelo y los datos de la versión actual.

Preguntas frecuentes

¿Puedo restaurar el software Y2 original más adelante?

Sí. Elija Y2 y Software original en Updater CE. Ver el Y2 página de software de stock para la secuencia de restauración.

¿Por qué el paquete podría llamarse rom_y2.zip?

Esa es una pista de descarga manual utilizada por algunas versiones de instalación completa Y2. La opción más segura sigue siendo seleccionar Y2 en Updater CE y utilizar la versión que presenta.

¿Puedo usar el tutorial Y1 Rockbox?

Úselo sólo para la idea amplia. Para la selección de paquete y modelo, siga esto Y2-guía específica.
