Methode installieren

SP Flash Tool innerhalb von Innioasis Updater CE

SP Flash Tool ist kein separater Download und im App-Ordner ist nichts zu finden. Es handelt sich um eine Installationsmethode in Innioasis Updater CE auf Windows x64- und Linux x86-64-PCs mit Intel- oder AMD-Prozessoren. Wählen Sie Ihre Firmware wie gewohnt aus und stellen Sie sie dann ein Erweiterte Einstellungen anzeigen > Installationsmethode > SP Flash Tool und installieren.

Zuerst kommt der Normalweg

Wählen Sie Ihre Firmware und dann die Engine aus

Eine Installation in Updater CE verläuft immer auf dem gleichen Weg: Wählen Sie Ihr Modell, die Firmware und die Version aus und führen Sie dann „Installieren/Wiederherstellen“ aus. Die Installationsmethode entscheidet nur, welche MediaTek-Engine den Flash durchführt. Lass es an Automatisch es sei denn, Sie haben einen Grund, es anzupinnen und festzulegen SP Flash Tool wenn du es tust.

Welche Computer haben SP Flash Tool

MediaTek veröffentlicht SP Flash Tool nur für x86-64, daher bietet Updater CE es auf x86-64-PCs und nirgendwo sonst an. Die App selbst läuft an mehr Orten als die Engine.

Windows x64: verfügbar

Windows 10 oder 11 auf einem Intel- oder AMD-Prozessor. Die SP Flash Tool Installationsmethode und die SP Flash Tool Schaltfläche sind beide vorhanden.

Linux x86-64: verfügbar

Ein 64-Bit-Intel- oder AMD-Computer Linux, auf dem das Updater CE AppImage ausgeführt wird. Gleiche Installationsmethode, gleiche Schaltfläche.

macOS: nicht verfügbar

SP Flash Tool existiert für macOS in keiner Form. Updater CE wird stattdessen mit MTKClient installiert und wiederhergestellt, und es gibt keine SP Flash Tool-Installationsmethode oder -Schaltfläche. Lassen Sie den Mac auf der geführten Route oder verwenden Sie die Mac-Notizen.

Linux ARM64: nicht verfügbar

Raspberry Pi, ARM-Boards und ARM64 Linux sind die gleiche Geschichte wie macOS: MediaTek liefert keinen ARM-Build aus, daher verwendet Updater CE dort MTKClient.

Sie sind sich bei einer Maschine nicht sicher? Öffnen Sie die Einstellungen und aktivieren Sie sie Erweiterte Einstellungen anzeigen: wenn es nein gibt Methode installieren mit einer SP Flash Tool-Option kann dieser Computer es nicht ausführen. Auf macOS und ARM64 Linux wird der Player weiterhin normal installiert. Verwenden Sie daher die geführte Route mit Auto und wechseln Sie nur dann zu einem Windows x64- oder Linux x86-64-PC, wenn Sie SP Flash Tool ausdrücklich benötigen.

Installieren Sie die von Ihnen gewählte Firmware mit SP Flash Tool

  1. Öffnen Sie Updater CE und wählen Sie das auf Ihrem Player aufgedruckte Modell aus: Innioasis Y1, Y2, G1, G3, G5, R1 oder PR1 oder ein Timmkoo-Modell.
  2. Wählen Sie die gewünschte Software aus, Original-Software oder ein Community-Projekt, und wählen Sie dann die Veröffentlichung aus. Dies ist dieselbe Liste, dieselbe Modellübereinstimmung und dieselben Prüfungen wie bei jeder anderen Installation.
  3. Offen Einstellungen und einschalten Erweiterte Einstellungen anzeigen.
  4. Finden Methode installieren und wählen SP Flash Tool statt Auto.
  5. Kehren Sie zum Installationsbildschirm zurück und klicken Sie auf Installieren / Wiederherstellen.
  6. Schalten Sie den Player vollständig aus, wenn die App Sie dazu auffordert, und schließen Sie dann bei Aufforderung das Datenkabel USB direkt an den Computer an. Verwenden Sie ein Datenkabel, kein reines Ladekabel, und verzichten Sie auf Hubs.
  7. Warten Sie, bis Updater CE meldet, dass die Installation abgeschlossen ist, ziehen Sie dann das Kabel ab und starten Sie den Player.

Das ist die ganze Reise. Updater CE stellt weiterhin das modellspezifische Paket, den MediaTek Download-Agent, die Treiberprüfungen und die Verbindungsaufforderung bereit; Wenn Sie SP Flash Tool wählen, wird nur die Engine darunter ausgetauscht.

Halten Sie die Modelle getrennt. Ein Y1-Paket und ein Y2-Paket sind niemals austauschbar, und eine Streudatei eines Modells beschreibt das andere nicht. Wenn Updater CE die Firmware für das von Ihnen ausgewählte Modell nicht anbietet, stoppen Sie und wählen Sie stattdessen das für dieses Modell aufgeführte Paket aus.

Wozu die Schaltfläche SP Flash Tool dient

Auf einem unterstützten Computer verfügt Updater CE auch über eine SP Flash Tool Klicken Sie auf die Schaltfläche, die das Tool von MediaTek öffnet, mit dem Sie direkt damit arbeiten können, beispielsweise mit einem Scatter-Paket, das Sie selbst bereitgestellt haben. Für routinemäßige Installationen, Aktualisierungen und Wiederherstellungen ist dies nicht erforderlich: Die Installationsmethode erledigt die gleiche Arbeit, wobei Modellabgleich, Treiberprüfungen und Verbindungsaufforderungen für Sie erledigt werden.

Wenn die Schaltfläche fehlt, handelt es sich bei dem Computer um eines der oben nicht unterstützten Systeme oder Ihr ausgewähltes Modell verwendet einen anderen Fluss. Verwenden Sie in diesem Fall die Installationsmethode oder die geführte Route, anstatt nach einer Tool-Binärdatei zu suchen.

Wenn SP Flash Tool die richtige Installationsmethode ist

  • Ein Player, der nicht bootet. Der Download-Modus von SP Flash Tool kann weiterhin ein Gerät erreichen, dessen Preloader oder Boot-Image beschädigt ist, weshalb sorgfältige Wiederherstellungsarbeiten durchgeführt werden.
  • Ein Flash, der auf einem unterstützten PC blockiert. Wenn Auto oder MTKClient auf einem Windows x64- oder Linux x86-64-Computer teilweise stoppt, kann die andere Engine durch Anheften der Installation an SP Flash Tool dasselbe Paket ausführen.
  • Ein Werkspaket, dem Sie vertrauen können. Original-Softwareversionen von Firmware-Archiv passt gut dazu, denn die Wiederherstellung von Standardpartitionen ist genau das, wofür SP Flash Tool entwickelt wurde.

Für ein normales Update oder eine Erstinstallation verlassen Sie es Methode installieren auf Auto. Es wählt die Engine aus, die zu Ihrem Modell und Ihrer Plattform passt, und die App hält Sie ohne zusätzliche Einstellungen auf dem unterstützten Pfad.

Wenn die Installation nicht startet

  1. Vergewissern Sie sich, dass das von Ihnen in Updater CE ausgewählte Modell mit dem auf dem Player aufgedruckten Modell übereinstimmt und dass das Paket dafür aufgeführt ist.
  2. Stellen Sie sicher, dass der Player vollständig ausgeschaltet ist, bevor Sie ihn anschließen, und stellen Sie die Verbindung erst her, wenn Sie von der App dazu aufgefordert werden.
  3. Installieren Sie auf Windows den Treiber MediaTek und starten Sie ihn neu. Überprüfen Sie auf Linux die in aufgeführten USB-Berechtigungen Computer-Setup.
  4. Probieren Sie einen anderen USB-Port direkt am Computer ohne Hub aus und starten Sie die Installation/Wiederherstellung erneut.

Alles weitere gehört rein Fehlerbehebung. Und auf macOS oder ARM64 Linux ist die Antwort keine andere Taste: Behalten Sie die Geführte Installation und verwenden Sie SP Flash Tool nur von einem Windows x64- oder Linux x86-64-PC.
