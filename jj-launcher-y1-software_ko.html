JJ Launcher Y1 설치 단계

  1. 컴퓨터에서 Innioasis Updater CE를 엽니다(앱이 필요한 경우, Updater CE 받기). 세트 기기 모델 에 Y1.
  2. 선택 JJ Launcher 안으로 소프트웨어.
  3. Y1에 표시된 릴리스를 선택합니다.
  4. 클릭 설치 / 복원.
  5. 전원을 끄고 Updater CE이 묻는 경우에만 Y1을 연결하세요.

자주 묻는 질문

Y1에 Y2 항목을 설치할 수 있습니까?

아니요. 모델과 패키지를 일치하게 유지하세요. Y1 항목이 누락된 경우 Y2 파일을 강제로 생성하지 마십시오.

원래 소프트웨어로 돌아갈 수 있나요?

예. Updater CE에서 Y1 및 원본 소프트웨어를 선택합니다. 참조 Y1 복원 페이지.

JJ Launcher 릴리스는 모두 어디에 있나요?

현재 빌드는 소프트웨어 다운로드. 릴리스 노트는 프로젝트의 릴리스 노트.
