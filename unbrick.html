Unbrick a Y1 or Y2

An unbrick is a restore. You put the Original Software for that exact model back on the player.

Before the restore

Charge the player for half an hour with a cable you know can carry data. Hold the power button for about 15 seconds. If a computer then sees the player, Updater CE can install the stock package.

Which package

The model printed on the player decides the file. A Y1 package will not restore a Y2, and a Timmkoo package will not restore either of them.

Recovery guide Y1 firmware Y2 firmware

When the computer does not see it

Updater CE is the recommended route for that case and includes the recovery tools: the driver checks on Windows, and its SP Flash Tool install method on Windows x64 and Linux x86-64. If Updater CE cannot run on this computer, start from the software install zip built for it instead.
