Y2Player Installationsschritte

  1. Öffnen Sie Innioasis Updater CE auf Ihrem Computer (wenn Sie die App benötigen, Updater CE holen). Satz Gerätemodell an Y2.
  2. Wählen Sie Y2Player In Software.
  3. Wählen Sie eine für Y2 aufgeführte Version aus.
  4. Klicken Sie Installieren / Wiederherstellen.
  5. Schalten Sie das Gerät aus und schließen Sie Y2 an der Live-Eingabeaufforderung an.

Einige Y2 Vollinstallationspakete verwenden rom_y2.zip. Lassen Sie den Updater nach Möglichkeit das Paket auswählen.

FAQ

Kann ich zur ursprünglichen Software zurückkehren?

Ja. Wählen Sie Y2 und Originalsoftware in Updater CE und folgen Sie dann den Anweisungen Y2-Wiederherstellungsanleitung.

Kann ich dies auf einem Y1 verwenden?

Nein. Diese Seite ist für den Eintrag Y2Player Y2. Halten Sie die Pakete Y1 und Y2 getrennt.

Was passiert, wenn Y2 nicht erkannt wird?

Überprüfen Sie Plattform-Setup, Kabel, Ausschaltzustand, Modellauswahl und Timing. Verwenden Fehlerbehebung bevor Sie die manuelle Wiederherstellung versuchen.
