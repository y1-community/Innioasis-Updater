Installera eller återställ det med Updater

Updater använder samma guidade flöde oavsett om Y1 för närvarande kör sin ursprungliga programvara eller ett community-projekt.

  1. Öppna Innioasis Updater CE på din dator (om du behöver appen, Hämta Updater CE). Ställ in Enhetsmodell till Y1.
  2. Välj Originalprogramvara i Programvara (eller använd Hämta detta i Updater CE för att hoppa till de guidade stegen).
  3. Klicka Installera / Återställ och låt appen förbereda paketet.
  4. Stäng av och anslut Y1 endast när liveprompten frågar.

Vid manuell nedladdning namnges det vanliga fullinstallationspaketet rom.zip. Modellvalet i Updater är det säkrare sättet att välja filer.

Vanliga frågor

Kan jag återställa från Rockbox eller annan anpassad programvara?

Ja, använd modellen Y1 och sökvägen för originalprogramvaran Y1. Ta inte bort systemfiler först och ersätt inte ett Y2-paket.

Vad händer om min Y1 inte upptäcks?

Kontrollera datakabeln, datorinställningen och anslutningstiden. Spelaren ska vara avstängd och ansluten endast vid Updater-prompten.

Vilket paket ska jag använda för min Y1?

Behåll modellen tryckt på din spelare vald i Updater. Y1- och Y2-paketen är separata – sluta om releaselistan inte matchar din modell.
