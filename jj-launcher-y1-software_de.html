JJ Launcher Y1 Installationsschritte

  1. Öffnen Sie Innioasis Updater CE auf Ihrem Computer (wenn Sie die App benötigen, Updater CE holen). Satz Gerätemodell an Y1.
  2. Wählen Sie JJ Launcher In Software.
  3. Wählen Sie die für Y1 angezeigte Version.
  4. Klicken Sie Installieren / Wiederherstellen.
  5. Schalten Sie das Y1 nur aus und schließen Sie es an, wenn Updater CE dazu fragt.

FAQ

Kann ich den Eintrag Y2 auf einem Y1 installieren?

Nein. Achten Sie darauf, dass Modell und Verpackung aufeinander abgestimmt sind. Wenn der Eintrag Y1 fehlt, erzwingen Sie keine Y2-Datei.

Kann ich zur ursprünglichen Software zurückkehren?

Ja. Wählen Sie Y1 und Originalsoftware in Updater CE. Siehe die Y1 Wiederherstellungsseite.

Wo sind alle JJ Launcher Veröffentlichungen?

Aktuelle Builds sind da Software-Downloads. Versionshinweise finden Sie auf dem Projekt Versionshinweise.

Computer-Setup

Updater kann unter Windows, macOS und Linux verwendet werden, sobald das entsprechende Setup bereit ist. Beginnen Sie mit dem Plattformführer.
