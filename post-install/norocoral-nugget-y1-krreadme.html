Nugget for Innioasis Y1

Nugget for Y1은 Innioasis Y1 디지털 오디오 플레이어를 위한 오픈 소스 커스텀 펌웨어입니다. 안드로이드를 최소 구성 다운스트림 리눅스 커널(3.4.67)로 완전히 대체하며, 개발자가 네이티브 환경에서 직접 애플리케이션을 구현할 수 있도록 개발자 라이브러리를 제공합니다.

기술 문서

서브시스템 사양, 아키텍처 문서 및 리버스 엔지니어링 분석 내용은 docs/kr/에 있습니다:

  • iPod 5.5G USB 모드 및 iTunes 연동: ipod_vpd.ko EVPD 스푸핑, iTunesDB TagCache 로드, .ithmb 앨범아트 디코딩, Play Counts/OTGPlaylistInfo 기록 및 USB 가젯 구성.
  • 기술 분석 결과: 하드웨어 인터페이스, /dev/eac 오디오 드라이버, PMIC 레지스터, 전력 튜닝, 부팅 측정 결과 및 입력 이벤트 동작.
  • 시스템 아키텍처: 아키텍처 블록 다이어그램, 부팅 시퀀스, 스토리지 레이아웃 및 HAL 매핑.
  • 오디오 서브시스템: MediaTek EAC 드라이버, 팝 노이즈 완화, 클록 전환 및 게인 스테이징.
  • 전원 관리: 절전/wakelock 처리, CPU 주파수 거버너, 코어 핫플러그 및 Always-On Display (AOD).

설치 방법

권장: Innioasis Updater CE

https://innioasis.app/firmware_ko.html?brand=Innioasis&model=Y1&software=nugget-rock8ox-240p-360p-y1&type=A

수동 설치 방법

  1. boot_rockbox.img 및 rockbox_sdcard.zip을 준비합니다.
  2. 다음 도구를 사용하여 boot_rockbox.img를 boot 파티션에 플래시합니다:
    • SP Flash Tool: MT6572 scatter 로드, BOOTIMG 체크, boot_rockbox.img 선택 후 Download 클릭, 볼륨 다운 버튼을 누른 채로 Y1 연결.
    • Fastboot / python-mtk:

      `bash python mtk.py w boot boot_rockbox.img `

  3. MicroSD 카드를 FAT32 또는 exFAT 형식으로 포맷합니다.
  4. .rockbox 디렉터리가 최상위 루트에 위치하도록 rockbox_sdcard.zip 압축을 카드 루트에 직접 풉니다.
  5. MicroSD 카드를 Y1에 삽입하고 전원을 켭니다.

소스 코드 빌드

사전 필수 패키지 (Ubuntu / Debian / WSL)

sudo apt update
sudo apt install -y build-essential gcc-arm-linux-gnueabihf python3 python3-pip zip curl

필수 외부 파일

  1. 순정 boot.img (커널 및 안드로이드 듀얼 부팅 램디스크 추출용):

    Y1 Type A 순정 ROM(rom.zip)을 다운로드하여 boot.img를 추출한 뒤 stock_rom/boot.img 경로에 배치합니다(또는 STOCK_BOOT=/path/to/boot.img 지정).

  2. Rockbox 소스 (Rockbox 포함 빌드 시):

    이 저장소와 나란히 https://github.com/norocoral/rockbox를 클론(../rockbox)하거나 ROCKBOX_SRC=/path/to/rockbox를 지정합니다. Rockbox 없이 ROM/SDK만 빌드하려면 ./build.sh --no-rockbox를 실행합니다.

빌드 명령

./build.sh

빌드 스크립트 실행 동작:

  1. !stock_rom/boot.img에서 순정 커널을 추출합니다(없는 경우).
  2. ARM 하드 플로트 GCC를 사용하여 커스텀 PID 1 C /init 및 unmute_eac 유틸리티를 컴파일합니다.
  3. 스플래시 화면 PNG 이미지를 32비트 원시 프레임버퍼 파일로 변환합니다.
  4. Innioasis Y1용 호스티드 록박스를 컴파일합니다(build_y1/).
  5. .rockbox SD 카드 리소스를 rockbox_sdcard.zip으로 패키징합니다.
  6. 최소 구성의 initramfs 램디스크를 빌드하고 MediaTek 헤더가 포함된 플래시용 boot_rockbox.img를 생성합니다.

참고: 오픈 소스 라이선스 규정을 준수하기 위해 MediaTek 독점 바이너리(bt_blobs/, stock_unpacked/, logo.bin)는 Git 추적에서 제외되어 있습니다.

듀얼 부팅 서브시스템 및 부트로더 메뉴

내부 eMMC의 안드로이드 파티션(SYSTEM, DATA, CACHE)을 변경하지 않고 유지하므로 안드로이드와 듀얼 부팅이 가능합니다:

  • 부트로더 메뉴:
    • Rockbox 실행 전 부팅 초기 단계에서 실행됩니다.
    • 지원 항목:
    • Pick 1: Rockbox — MicroSD 카드에서 Rockbox를 부팅합니다.
    • Pick 2: MeUI — .meui/meui가 존재할 때 MeUI를 실행합니다.
    • Pick 3: User Software — .custom/launch가 존재할 때 사용자 바이너리를 실행합니다.
    • Pick 4: Android — BCB 플래그를 초기화하고 순정 램디스크를 압축 해제한 뒤 SYSTEM/DATA/CACHE를 마운트하여 안드로이드 init을 PID 1로 실행합니다.
    • Pick 5: Shut down — 기기 전원을 끕니다.
    • Pick 6: USB Mass Storage — 부트로더에서 USB 대용량 저장소 모드를 활성화합니다. 아무 버튼이나 누르면 종료되고 메뉴로 복귀합니다.
    • Pick 7: Linux terminal (USB) — /dev/ttyGS0 및 /dev/ttyGS1에서 USB 시리얼 루트 셸을 시작합니다.
    • Pick 8: Debug Info — MicroSD 카드 루트에 간략한 진단 로그(debuginfoYYYYMMDD_HHMMSS.txt)를 생성합니다.
    • 조작법: 클릭 휠 또는 좌/우 버튼으로 항목을 선택하고 센터 버튼 또는 재생 버튼으로 확정합니다.
    • 하드웨어 강제 진입: 부팅 중 MENU 버튼을 누르고 있으면 설정과 무관하게 부트로더 메뉴가 표시됩니다.
    • 설정 옵션: 설정 -> Nugget -> 부트로더 메뉴 (예 / 아니오).
  • Rockbox에서 안드로이드로 재부팅:
    • 설정 -> Nugget -> 안드로이드로 재부팅을 선택하면 버퍼를 플러시하고 순정 안드로이드로 전환합니다.
