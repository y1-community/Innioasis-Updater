Since Beta 4.1: keyboard, search and a UI pass (Reborn only)

Owner request (2026-10-15): station search with the one-row letter wheel is "a miserable experience"; a full-screen keyboard for every text entry, driven by the buttons, not the wheel, keeping a way back. Owner decisions: Back = row up, hold Back = leave; QWERTY. Then: "do a ui pass that everything is correct and looks good".

PartDetail
Keyboardreborn_ui::keyboard: four QWERTY rows; pages abc/ABC (Shift once, twice = lock), 123, #+= (all printable ASCII), àé (searches); show/hide key for passwords; Done reads Join or Search; rows wrap. Used for the Wi-Fi password, radio station search (reopens with the last search) and library search.
ButtonsActionRouter::set_keyboard: Back/Play-Pause/Previous/Next = up/down/left/right on press, held Previous/Next repeat every 180 ms, hold Back = cancel, the wheel is inert; Select types, hold Select = Done. No track skipping while it is open; volume, Power and headphone buttons unchanged.
Library searchHome → Search: artists, albums and songs whose words begin with every typed word, folded like A to Z order; live count while typing; results list (Edit Search, artists, albums, songs).
UI passAll 95 preview states checked in Reborn's look and skins: one capitalization rule (Title Case titles/rows/buttons/menus, sentence case descriptions and values; 83 labels), one name for "Scan for Music", notices in the status bar instead of over the focused row or cover, opaque turn-off hold, "Wi-Fi Password" keyboard title.
AssetsIcons Shift, ShiftOn, Backspace, Eye, EyeOff added; font atlases unchanged (regeneration reproduced them).

Host evidence: 437 Reborn tests (keyboard layout/movement/pages/limits; router keyboard mode including held buttons and a keyboard closed while a button is held; search matching; Wi-Fi, radio and library flows), strict Clippy, fmt; preview renders.

Device checks owed (after the owner's over-the-air install)

Type a Wi-Fi password and join; radio search; library search; held Previous/Next repeat speed; hold Back cancels; playback keeps running while typing; screens look as in the previews. Still owed from Beta 4.1: station stop/pause, Wi-Fi after screen-off, update check after deep sleep.

Known gaps

FM radio (next beta); HLS stations; sleep ≈9.4 mA vs stock ≈1.3 mA; Bluetooth range hardware-limited; no headphone-jack detection; full install from stock run on one player only.
