Reborn skins

A skin gives Reborn a different look: its own colours, fonts, pictures and screen layouts, for example the shipped Classic skin with light menus and blue highlights. A skin only draws. What the buttons do, the menus, playback, settings and the built-in parts (Cover Flow, the equalizer, text entry, the update screens) stay Reborn's. Reborn's own look is not a skin and is always available as Reborn in the picker.

Installing and choosing

  1. Copy the skin's folder (the one holding skin.json) into a folder

    named Skins on Internal Storage or on the SD card, for example Internal Storage/Skins/Neon/skin.json. Any letter case works for Skins; a Themes folder (its name before Beta 7.5) is read too.

  2. On the player: Settings → Skin. The list is read again every

    time it opens. Select a skin; it applies at once and is remembered.

The folder name is the skin's id. A skin in a Skins folder with the same folder name as a shipped skin (in /usr/share/reborn/skins) is hidden by the shipped one. A skin that cannot be used appears greyed out with the reason; choosing a broken skin keeps the current look and shows why in a message. If a chosen skin is missing at start (for example the SD card was removed), Reborn uses its own look for that session and keeps the choice.

The package

Neon/
  skin.json        the description (at most 256 KB)
  images/…         PNG, JPEG or WebP pictures, each at most 480 × 360
  fonts/…          TrueType/OpenType fonts (at most 8 MB each)
  LICENSE…         licences of fonts and pictures you ship

Paths in skin.json are relative to the folder, use /, and must stay inside it (no .., no absolute paths, no links that point outside).

skin.json

{
  "format": 1,
  "name": "Neon",
  "author": "You",
  "version": "1.0",
  "description": "One line for the picker.",
  "palette": { "bg": "#101018", "text": "#F0F0FF", "accent": "cover" },
  "colors":  { "pink": "#FF3EA5" },
  "fonts":   { "menu": { "file": "fonts/MyFont-Bold.ttf", "size": 18 } },
  "images":  { "bar": "images/bar.png" },
  "parts":   { "titlebar": [ … elements … ] },
  "screens": { "list": [ … elements … ], "now_playing": [ … ] }
}

Only format (always 1) and name are required. Unknown fields are errors, so a typo is reported instead of silently ignored.

Palette

The palette has fixed names. Your layouts use them, and every screen you do not describe is drawn by Reborn in these colours:

text on bg must reach a contrast of 3:1 or the skin is refused; below 4.5:1, and for muted/dim below 3:1, Reborn loads it with a warning.

Colours

Anywhere a colour is asked for you can write #RRGGBB, #RRGGBBAA, a palette token, a name from colors, or accent. Add /NN for an opacity in percent: "accent/40", "text/60".

Fonts

fonts names a font file and a pixel size (8 to 72). Each entry is drawn once when the skin loads, for Latin text (Latin‑1, Latin Extended‑A and common punctuation). Large display sizes may not fit the texture with all of Latin; add "charset": "ascii" to carry only plain ASCII (other letters then come from Reborn's font). Characters the font lacks fall back to Reborn's own font. Text elements may also use Reborn's fonts by name: R11, R13, R15, R17 (regular), L23, L44 (light), S10, S13, S15, S17, S20, S25, S28, S36 (semibold). Ship only fonts whose licence allows it (for example the SIL Open Font License).

Pictures

images names picture files (PNG, JPEG or WebP, at most 480 × 360 each, at most 64). They are drawn at any size; give slice: [left, top, right, bottom] to nine-slice them so corners and edges keep their size while the middle stretches. All pictures and font glyphs share one 1024 × 1024 texture; a skin that does not fit is refused.

Pairing, installing an update, the Power hold and the start/shut-down screens are always Reborn's, in the skin's palette.

Elements

Every element has "type" and may have "if" (see Conditions). Positions x, y default to 0. Inside a list row and inside group/part they are relative to the row or group.

Text is cut with “…” to w. One line is centred vertically in h; several lines are centred as a block in h, or start at y when h is 0.

A list draws rows rows of row_height from the list it shows: rows is the screen's own list (songs, settings…), facts the label/value pairs of a page, sheet the choices of a sheet or dialog. row is drawn for each row, focused (default: row) for the selected one. The list keeps the selection visible and scrolls by your row count.

Conditions

"if" takes names joined with & (and), | (or, lower precedence) and ! (not), e.g. "playing & !shuffle | paused".

Anywhere: playing, paused, has_track, has_art, shuffle (Songs or Albums), shuffle_albums (Shuffle Albums only), repeat, repeat_one, charging, battery_low, bluetooth, bluetooth_connected, wifi, wifi_connected, back (not Home), empty, error (toast), danger (dialog), eq, gapless, crossfade, normalise, sleep (a sleep timer runs), has_status, has_clock (the time is known; give the title less room), live (a station plays: remaining and duration read LIVE, the progress bar is full; hide the queue position), favorite (the song playing is in Favorites), has_body, has_title, has_action, has_facts, interactive.

Inside list rows: focused, disabled, toggle, on, check, checked, chevron, has_detail, row_art, numbered (a song on the album page with a track number: show {track_number} there instead of its cover, as Reborn's own album page does), current (the playing song), first, last, odd.

Limits and checks

skin.json 256 KB; 64 pictures of at most 480 × 360; 8 fonts of at most 8 MB; 4000 elements; one 1024 × 1024 texture for pictures and glyphs. Loading names the first problem with its place, e.g. screens.list[2] (text): unknown value "{lyrics}".

Trying a skin on a computer

From a Y2Reborn checkout (needs FFmpeg development files):

cargo run --bin reborn-preview -- out/preview --skin path/to/Neon
python3 tools/preview/render_previews.py out/preview

out/preview/png/ then holds every screen in your skin and a contact sheet. On the player, rebornctl theme lists the installed skins with their problems and rebornctl theme Neon (or theme reborn) switches.

Reborn ships 16 skins in skins/ (installed to /usr/share/reborn/skins): Classic (pictures from tools/assets/build_classic_skin.py) and, generated by tools/assets/build_skins.py, Nano Glass, Walkman, Terminal, Winamp, Paper, Big Type, Cassette, Neon Night, Zune, Bunny Bow (pixel art and the Pixelify Sans pixel font) and Mini Silver, Pink, Blue, Green and Gold. Each is a complete example to copy and change. charset and case: lower (used by Zune) need Reborn after candidate 33.
