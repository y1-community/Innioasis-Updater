B3, B4, P2Library (Reborn d11563b)A supported file FFmpeg cannot open no longer makes a scan incomplete: it is counted (unreadable, Settings → Library N can't be read), keeps its row and no longer stops pruning of deleted songs; the scanner remembers it for the process. Before, one such file left library.error set after every scan.
B3, R7Update health (Linux e361b8b, Reborn d11563b)rebornctl status carries healthy + health_reasons (drawing, database working, no stuck worker); health_ack uses it. Before, one unreadable song rolled every OTA back 180 s after install.
B7Session (Reborn d11563b)A session Reborn refuses (e.g. after a rollback from a newer release) is kept as session.json.rejected-<time>; every setting this version understands is recovered.
B5, R5, P1SD admission (Linux 3bc6abb)media reconcile runs as its own process (150 s limit, then 10 min back-off) instead of with a 7 s deadline inside the service loop; command() kills every descendant on timeout. Before, a card whose check outlasted 7 s never mounted and checkers piled up.
B6USB receive DMA (Linux ca119ff, overlays 0055/0065)A multi-packet start that gives up first stops the engine (y2_hsdma_stop) and looks: nothing moved → PIO as before; whole packets → counted, CPU continues; part of one → flushed, request fails with -EIO (host repeats).
B8Recovery (Linux ebc164e)A stuck installer powers off after ten minutes without a charger (request kept).
R6Internal Storage (Linux f261044)Mounted with noinit_itable, made with nodiscard: no refused background zeroing at every start.
A7Licensing (Linux 9c45e5c, 662ff11)New asset Y2Linux-sources-toolchain-f7cda4c7d213.tar: glibc 2.44 snapshot and GCC 15.3.0 sources of the Bootlin toolchain, byte-identical to Buildroot's pinned archives, with the toolchain's summary.csv.
B1/A3, A4, A5, A12, A13Docs and packages (Linux a90ba0c)The first-install and computer-update packages ship docs/INSTALL.md as install.md (was a historical runbook); only firmware v3.2.0 works, said loudly; current tag in BUILDING; old feature audit retired; catalog complete.

Upload over SSH ran at 8.4 MB/s (scp) and 9.5 MB/s (ssh pipe) with the player idle: the SSH cipher on the one online core is the limit there; the Beta 7.11 figure of 10–14 MB/s for USB Ethernet was a different measurement. MTP uploads (29.6 MB/s in 7.11) use the same receive path, whose normal operation is unchanged.

Known gaps

Not run with this release: MTP copies (the player was in developer USB mode), the cable pulled mid-copy, sleep and wake, Windows Explorer, a large or slow SD card for B5, the stuck-installer power-off (B8, covered by the fixture test only). Still open from the readiness audit: standby drain (A1, #42), an install and a build by someone else (A2), the owed device checks (A8, A9, A11), headphone detection (A10), and the owner decisions A14/R3, A16, A18.
