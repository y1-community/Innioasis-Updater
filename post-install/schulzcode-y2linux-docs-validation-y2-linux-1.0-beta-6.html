Since Beta 5.1 (Reborn)

PartDetail
PlaylistsOwner: a playlist feature like Y2Player's, its own section, add/remove on the device, optimized, fixing Y2Player's issues. The .m3u/.m3u8 file is the playlist (no database copy): found anywhere on Internal Storage and the SD card (not Radio/hidden/system folders), read in UTF-8, UTF-8/16 with BOM or Windows-1252 and written back in kind, comments/tags/missing entries kept, atomic writes, each edit checked against a fresh read. Entries by place (duplicates, one removed at a time). Paths from computers (Windows, macOS, Linux, file://) matched in memory by their ending. Section with mosaics, Favorites with a heart, Move with the wheel, picker, rename/duplicate/delete, Save Queue as Playlist. 20 000 entries: 19 ms first open on the host, 0.3 µs per frame.
Pause in placeOwner: "pausing and playing again … will always buffer". Beta 5.1 log: pause closed the BlueALSA PCM, play reopened file, seek and PCM (≈1.3–1.4 s). Now the pipeline holds (device paused via snd_pcm_pause, else drop/prepare; decoder waits with its heartbeat), resume instant; released after 3 min, before sleep, by any stop/start. Wired and Bluetooth. Stations still stop (live).
SeekingOwner: "scrolling right and left also gives an error" (hold Previous/Next: a restart per 90-ms step → "audio reconfiguration is still pending"). Steps now move the position while the sound holds; one restart 350 ms after the last step.

Host evidence: 460 Reborn tests (playlist files, encodings, path styles, edits vs computer edits, worker, UI flows; a held pause writes nothing and never reopens the device), strict Clippy, fmt; previews 80–87. Image check: the new pause and playlist code is in the built Reborn.

Device checks owed (after the owner's over-the-air install)

Pause/play continues at once (Bluetooth and wired; the alsa paused log line says whether the device paused itself); holding Previous/Next scrubs without errors; Playlists: a computer's playlist opens and matches, New Playlist, Add to Playlist, Move, Remove, Favorites heart, rename/delete; files stay readable on the computer afterwards.

Known gaps

FM radio (next beta); HLS stations; sleep ≈9.4 mA vs stock ≈1.3 mA; Bluetooth range hardware-limited; no headphone-jack detection; a seek still restarts playback (≈1 s on Bluetooth).
