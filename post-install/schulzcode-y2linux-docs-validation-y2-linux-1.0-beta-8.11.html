The report

A user wrote "My internal storage is still 700 mb after multiple restarts" with error report y2linux-report-20261019-153610 (Beta 8.10):

EvidenceValue
/run/y2/internal-media.jsonUnavailable, filesystem_identity_not_y2media: p8 is still the stock FAT
/run/y2/internal-media-setup.jsonPending, reason battery_low
What they saw as storageY2DATA only: 789 MB, 729 MB free (the MTP drive "Firmware")
Every logged startOn battery, no charger: 3.54–3.59 V at 0.3 s; the charger came later (68 s, 105 s)
Power-on OCV / shownBAT0 voltage_ocv 3.621 V (24.8 % on the stock curve) / 21 %

Two faults:

  1. Reborn dropped the reason. Every Pending said Restart to finish setting up, so the user restarted on

    battery again and again, and each start refused the setup for the same reason.

  2. The battery gate read the wrong voltage. internal_media.automatic_blocked compared voltage_now during the

    boot load with 3.7 V. 3.7 V at rest is ≈39 % on the stock curve; with the boot sag (≈60–120 mV, ledger F30) a player needed roughly 45 % or more. The plan (STORAGE-SETUP) had said "battery ≥ 25 % or charging".

What changed since Beta 8.10

PartChange
Setup battery gateOn battery the setup now needs 25 % read from BAT0 voltage_ocv (PMIC power-on OCV, latched before the boot load; the same value the shown percentage starts from, stock oam_init) through the stock battery profile; voltage_now only when no OCV was latched; no profile → battery_unknown. Charging or USB input online still skips the check. Linux fee6b36.
Storage screenInternalSetup::Pending carries SetupWait: battery_low/battery_unknown say Connect a charger and restart; an update's health boot keeps Restart to finish setting up. Preview 32-storage-setup-battery. Reborn f649609.
User guideStorage: the setup waits below 25 % without a charger and what the screen says.

The reporter's own player would still wait on battery (24.8 % at power-on); it now tells them to connect a charger.

Device results

None: this build was not installed on a player before publishing. Host evidence: tests for the reporter's values (OCV 3.621 V → battery_low), an OCV above 25 % with voltage_now under load at 3.56 V → setup runs, missing OCV/voltage/profile → battery_unknown; Reborn parses the reasons and draws the new line (preview checked by eye).

Known gaps

  • Owed on a player: the setup on battery above 25 % on a stock-FAT player, and the new storage line.
  • A system.img copied after the radio firmware is already installed is never removed (radiofw.scan returns at

    installed() first); a second user asked whether the leftover copy may be deleted (it may).

  • Unchanged from 8.10: #47 confirmation, WAF rule and billing alert, sleep drain (#42), GC9503V confirmation (#45).
