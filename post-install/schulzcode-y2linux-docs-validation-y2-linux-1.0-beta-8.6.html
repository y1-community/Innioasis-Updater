What changed

A review of everything in audio playback after Beta 8.5 (owner: "do it all").

PartChange
Kernel level writeThe headphone level's PDN_HP check and the OUT_FS/HV_EN write run under the card's DAPM mutex: a stream powering up at that moment can no longer get the level written with the amplifier on (DS1155F2). y2_hp/hpload_measure refuses an open stream (EBUSY) and holds DAPM while it measures. Linux 0c8e7f5, tests/test_hp_level.py models the lock.
No loudness jumpsA fade-in carries over when the stream restarts during it (Next, a seek, another rate); volume up during a fade keeps fading; sound settings that play ≥ 1 dB louder (a profile turned off, a boosting preset, Normalize changed) fade in over 2 s.
Held pauseEvery sound-settings change gives a held pause's stream back, so Play uses the new settings; choosing the Headphone Level already in use no longer restarts the song.
BatteryAn equalizer or profile no longer asks for the heavy playback class (747.5 MHz floor, 1 ms wake-up limit); only crossfade does. The FFmpeg filter graph runs on one thread (bit-identical output).
ProfilesThe clip-safe preamp covers source rates 44.1–384 kHz (six shipped profiles 0.1–0.4 dB lower, e.g. AirPods Pro −6.0 → −6.1, Sony WF-1000XM4 −7.7 → −8.1; HD 650 unchanged). The license file no longer appears as a profile.
TestsFFI layouts pinned on both sides, sanitize idempotence, hi-res preamp, a full 10-filter profile with ReplayGain +6 dB on a new near-full-scale fixture at S24/S16 (limiter holds; without it the output clips), the real shipped-folder scan.

Known gaps

  • Battery current with a profile not measured (USB stayed connected); deep idle is blocked during any playback either

    way (audio keeps INFRA up), so the gain is the lower CPU floor and fewer wake-ups.

  • A 10-filter profile still costs ≈46 MHz of the decode thread on the device.
  • Not run on the player: volume up during a fade (host test), a DAC Filter change by ear, sleep with a level set.
  • Files below 44.1 kHz rely on the limiter (FFmpeg skips filters above Nyquist).
  • Unchanged from 8.5: no output measurement yet, maximum output ≈0.18 Vrms, the sleep drain (#42), GC9503V (#45).
