Since Beta 7.1 (Reborn)

Owner (2026-10-16): more animation to make the UI feel polished and responsive, at 60 fps; the Now Playing progress as a "cool" wave, not a perfect sine. Reborn 634f83a.

PartDetail
Motion systemcrates/reborn-ui/src/motion.rs: per-key eased values (exponential, ≈125–190 ms), retargetable at any moment, frame-rate independent, settled values stop all redrawing. Anything moving keeps Cover Flow's 60-fps path (12-ms frame gap, Interactive CPU lease). Off in previews and tests (Ui::ui_motion); reborn-preview --motion captures frames mid-animation.
Lists and focusShared components mark moving quads (canvas::Moving): the focus row and Home's marker glide; Artists, Songs, Genres, search, Up Next, Folders, Playlists and the radio lists scroll smoothly (one row more on each side, hidden at rest; the status bar stays above); a long wheel jump glides only its last row.
Screens, menus, messagesNew screens slide in from the right, Back slides out (200 ms, ease-out); sheets rise over a fading scrim; dialogs and toasts fade in; switches slide their knob and blend their colour.
Now PlayingThe position moves on between reports; the progress is a travelling wave (two sines, breathing height, tapered ends, opaque 2.6-px strokes with a faint 5-px edge) that lies flat when paused; a new song fades in; the play button dips on a change. Continuous 60 fps while playing and visible.

Host evidence: 487 Reborn tests (new: motion springs, wave while playing / flat when paused, focus glide, slide with one focus target, long jumps), strict Clippy, fmt; mid-animation captures compared by eye. Device frame rate not yet measured.
