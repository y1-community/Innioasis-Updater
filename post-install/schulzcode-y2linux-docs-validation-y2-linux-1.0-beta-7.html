Since Beta 6.3

Reborn: UI v4, one strict system

Owner (2026-10-16): since playlists, search and radio the UI "looks kind full"; the default look is liked but "still a little rough"; make it consistent everywhere, for listeners rather than developers, and remove what users would not need. Review of all 92 interactive screens (host renders, one device capture), the plan, the owner's four decisions and every phase are recorded in Reborn's Product UI v4.

PartChange
ColourOne fixed accent for every control and state; the cover's colour only on Now Playing and the Home cover card. Skins keep their own accent.
ComponentsOne focus row (neutral glass) in every list, page and menu; one button; one empty/info state (icon, title, sentence); one LIVE badge. Wi-Fi/Bluetooth lists in a grouped card, switches in the accent.
HomeNow Playing, Music, Playlists, Radio, Search, Settings (was ten items with counts). Music lists Artists, Albums, Songs, Genres and Folders with counts; Settings → Display → Home Menu pins any of them back on Home.
Less on screenNo hint lines (the hold-Select menus already name every action); no "NOW PLAYING" label, gapless icon or radio codec tags; stations read "Country · Genre" without ranks; Bluetooth Connected/Paired, Wi-Fi Saved/Secured/Open; folders show songs, not free space; theme picker shows each look's colours; Storage has bars and Scan; About shows "1.0 Beta 7" and the library size.

Host evidence: 479 Reborn tests, strict Clippy, fmt; before/after previews of all 114 states and of all 16 skins compared by eye (skins change only where they show Reborn's own keyboard, rows or texts).

Platform: two fixes from the Beta 6.3 overnight test (archive 156)

PartDetail
OvernightBeta 6.3, 14 h asleep (01:13–15:21), 27 maintenance wakes, all SPM/INFRA/PMIC/wheel/PHY counters clean, INFRA lost 0; drain ≈7.8 mA (8.3 build 26, 9.4 Beta 1).
CPU thermal zoneThe 1100b000 monitor was programmed only at probe; INFRA power-down in sleep wipes it (monitor/period/filter/poll read 0), y2_soc_temp returned -ENODATA and the thermal core disabled cpu-thermal (passive 110 °C, critical 120 °C) until the next boot. Seen in archives 124, 125, 155 and 156. kernel/platform/thermal.c now programs the monitor again on resume when it is off.
Refused Power sleepA routine BAT0 notification during sleep preparation invalidated the wakeup count (wake_event_in_progress; the screen went off for 4 s and came back; Beta 1's 06:38 self-wake had the same cause). product_sleep takes a fresh count up to two times; Power/RTC interrupts and the cable are checked again on each pass. 3 new host tests.

Known gaps

FM radio (next beta, Beta 8); no 12/24-hour switch; in-place decoder seek (≈1 s on Bluetooth); sleep ≈7.8–9.4 mA vs stock ≈1.3 mA; Bluetooth range hardware-limited; no headphone-jack detection.
