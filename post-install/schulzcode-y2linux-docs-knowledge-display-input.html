Y2E-130 memory evidence

The retained stock iomem identifies framebuffer [0xbfb00000,0xc0000000) (5 MiB). FM display-size functions were remapped at 0xc05128d4/0xc051296c; the unknown-panel fallback is actually 20 MiB despite its misleading log. LK also forms a scratch pointer framebuffer minus 4 MiB. Buffer lifetime and inherited DMA are not fully established. See initial RAM policy; all high display/scratch storage is excluded initially. These findings do not identify the panel or prove DMA shutdown.
