Using Innioasis Updater

01

Choose Y1 or Y2

Use the model printed on the player. Y2 packages and install tools are different from Y1 packages.

02

Choose your software

Pick Original Software, Rockbox, Solar, JJ Launcher, Inniclassic, Y2Player, or Koensayr when it is listed for your model.

03

Install / Restore

Updater prepares the files, then tells you when to power off and connect the USB cable.

Coming back from Rockbox or another custom software uses the same Updater flow: select your model, choose Original Software, and run Install / Restore.
