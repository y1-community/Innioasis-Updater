Pasos de instalación de Android 4.4 Y2

  1. Abra Innioasis Updater CE en su computadora (si necesita la aplicación, Obtener Updater CE). conjunto Modelo del dispositivo a Y2.
  2. elegir Android 4.4 (desarrollador) en Software.
  3. Elija la versión listada para Y2.
  4. Haga clic Instalar / Restaurar.
  5. Apague y conecte el Y2 solo cuando Updater CE lo solicite.

Preguntas frecuentes

¿Puedo restaurar el software original Y2?

Sí. Seleccione Y2 y Software original en Updater CE. El Y2 guía de software de stock cubre el camino de regreso.

¿Es este un controlador diario ROM?

Este es un desarrollador experimental ROM destinado a pruebas y desarrollo. Las actualizaciones de lanzamiento están en la página del proyecto.

Utiliza la ruta guiada
