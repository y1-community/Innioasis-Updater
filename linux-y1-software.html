Linux (Dev) · Innioasis Y1

Install Linux on the Y1.

Linux for Y1 is an experimental community Linux kernel and rootfs port for the Innioasis Y1 hardware. This page links to the full installation guide and releases.

Open the full Linux for Y1 (Dev) guideGet this in Updater CEProject source

Linux Y1 install steps

  1. Open Innioasis Updater CE on your computer (if you need the app, Get Updater CE). Set Device Model to Y1.
  2. Choose Linux for Y1 (Dev) in Software (or use Get this in Updater CE to jump to the guided steps).
  3. Choose the release listed for Y1.
  4. Click Install / Restore.
  5. Power off and connect the Y1 only when Updater CE asks.

FAQs

Can I restore the stock Y1 software?

Yes. Select Y1 and Original Software in Updater CE. The Y1 stock-software guide covers the return path.

Is this an everyday user interface?

This is an experimental port for developers and Linux tinkerers. Review the GitHub repository for terminal and console instructions.
