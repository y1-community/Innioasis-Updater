Rockbox Y1 βήματα εγκατάστασης

  1. Ανοίξτε το Innioasis Updater CE στον υπολογιστή σας (αν χρειάζεστε την εφαρμογή, Αποκτήστε το Updater CE). Σετ Μοντέλο συσκευής να Y1.
  2. Επιλέξτε Rockbox σε Λογισμικό.
  3. Επιλέξτε την κυκλοφορία και την παραλλαγή που ταιριάζουν με την οθόνη ή τη διαδρομή θέματος που θέλετε.
  4. Κάντε κλικ Εγκατάσταση / Επαναφορά και περιμένετε να το προετοιμάσει η εφαρμογή.
  5. Απενεργοποιήστε και συνδέστε το Y1 μόνο στη ζωντανή προτροπή.

Χρησιμοποιήστε το γραπτός Rockbox Y1 οδηγός για τα στιγμιότυπα οθόνης, το βίντεο, τη σημείωση Type A ή Type B και τη λίστα ελέγχου σύνδεσης.

Συχνές ερωτήσεις

Μπορώ να επιστρέψω στο αρχικό Y1 λογισμικό;

Ναί. Επιλέξτε Y1 και Original Software στο Updater CE και, στη συνέχεια, εκτελέστε Εγκατάσταση / Επαναφορά. Το Y1 σελίδα αποθεμάτων λογισμικού εξηγεί αυτή τη διαδρομή.

Ποια έκδοση Rockbox να επιλέξω;

Επιλέξτε μια έκδοση που εμφανίζεται για Y1 και διαβάστε τη σημείωση κυκλοφορίας της. Εάν χρειάζεστε συμβατότητα παλαιότερου θέματος, ελέγξτε τις σημειώσεις ανάλυσης και παραλλαγής αντί να επιλέξετε μια έκδοση Y2.

Μπορώ να το εγκαταστήσω σε Y2;

Όχι. Χρησιμοποιήστε το ξεχωριστό Rockbox Y2 σελίδα και επιλέξτε Y2 στο Updater CE.
