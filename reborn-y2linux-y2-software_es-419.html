Pasos de instalación

  1. Abra el Actualizador CE. Disponible para Windows, macOS y Linux.
  2. Seleccione Y2 como modelo del dispositivo.
  3. Seleccione Reborn (Y2Linux) como el software.
  4. Haga clic en Instalar/Restaurar. Espere mientras Updater CE prepara los archivos.
  5. Conecte USB cuando se le solicite. Apague el Y2 primero.
  6. Configurar Wi-Fi, Bluetooth y radio FM
