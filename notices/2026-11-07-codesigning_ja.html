Windows 10/11 アプリの起動の問題と Smart App Control の回避策

Windows 10/11 または Smart App Control によってアプリの起動が停止された場合は、こちらの回避策に従ってください。

2026-10-25 · 2026-12-31 まで · モデル: Y1、Y2

誤検知レポートは次の目的で Microsoft に提出されました。 installer.exe そして InnioasisUpdater.exe 対処しましたが、Windows Endpoint Protection または Smart App Control が依然としてコンピューター上のアプリケーションをブロックしている場合は、次の回避策を使用してください。

一時的な回避策: スマート アプリ コントロールをオフにする

  1. ウィンドウを開く 設定 （プレス Win + I).
  2. に行く プライバシーとセキュリティ > Windows セキュリティ > アプリとブラウザの制御.
  3. 下 スマートアプリコントロール、 クリック スマートアプリコントロールの設定.
  4. スマート アプリ コントロールを次のように設定します オフ。これにより、アプリがすぐに開いて実行できるようになります。

Windows または Edge によって Updater CE をダウンロードできない場合は、その他のオプション (…） それから 保つ > もっと見る > とにかく保管してください.

スマート アプリ コントロールを再度有効にする

コンピューター上で誤検知の定義の更新が完了したら、Windows レジストリを使用して Smart App Control を再度有効にすることができます。

  1. プレス Windowsキー+R、 タイプ regeditをクリックし、Enter キーを押して、管理者としてレジストリ エディタを開きます。
  2. 次の場所に移動します: HKEY_LOCAL_MACHINE\SYSTEM\CurrentControlSet\Control\CI\Policy （または Policies).
  3. 位置を特定する VerifiedAndReputablePolicyState 右側のペインで。
  4. ダブルクリック VerifiedAndReputablePolicyState そして、その値データを次のように変更します。
  • 1 = オン (強制)
  • 2 = 評価モード
  1. [OK] をクリックし、レジストリ エディタを閉じて、コンピュータを再起動します。

Microsoft への installer.exe レポートを参照してください。 Microsoft への InnioasisUpdater.exe レポートを参照してください。
