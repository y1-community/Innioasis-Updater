Windows 10/11-appstartsproblem och lösning för smart appkontroll

Om Windows 10/11 eller Smart App Control hindrar dig från att starta appen, följ lösningen här.

From 2026-10-25 · until 2026-12-31 · Platform: Windows · Models: Y1,Y2

False-positive reports were submitted to Microsoft for installer.exe och InnioasisUpdater.exe och åtgärdat, men om Windows Endpoint Protection eller Smart App Control fortfarande blockerar programmet på din dator, använd den här lösningen:

Tillfällig lösning: Stäng av Smart App Control

  1. Öppna Windows Inställningar (tryck Win + I).
  2. Gå till Sekretess & säkerhet > Windows Security > App- och webbläsarkontroll.
  3. Under Smart appkontroll, klicka Smart App Control-inställningar.
  4. Ställ in Smart App Control till Av. Detta gör att appen omedelbart kan öppnas och köras.

Om Windows eller Edge hindrar dig från att ladda ner Updater CE, klicka på fler alternativ (…) sedan Behåll > Visa mer > Behåll ändå.

Återaktiverar Smart App Control

När falskt positiva definitioner har uppdaterats på din dator kan du återaktivera Smart App Control via Windows-registret:

  1. Tryck Windows-tangent + R, typ regedit, och tryck på Retur för att öppna Registereditorn som administratör.
  2. Navigera till: HKEY_LOCAL_MACHINE\SYSTEM\CurrentControlSet\Control\CI\Policy (eller Policies).
  3. Lokalisera VerifiedAndReputablePolicyState i den högra rutan.
  4. Dubbelklicka VerifiedAndReputablePolicyState och ändra dess värdedata till:
  • 1 = På (tillämpad)
  • 2 = Utvärderingsläge
  1. Klicka på OK, stäng Registereditorn och starta om datorn.
