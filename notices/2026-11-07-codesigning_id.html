Masalah peluncuran aplikasi Windows 10/11 & solusi Kontrol Aplikasi Cerdas

Jika Windows 10/11 atau Smart App Control menghentikan Anda meluncurkan aplikasi, ikuti solusinya di sini.

From 2026-10-25 · until 2026-12-31 · Platform: Windows · Models: Y1,Y2

Laporan positif palsu telah diserahkan ke Microsoft untuk installer.exe dan InnioasisUpdater.exe dan mengambil tindakan, namun jika Windows Endpoint Protection atau Smart App Control masih memblokir aplikasi di komputer Anda, gunakan solusi ini:

Solusi Sementara: Matikan Kontrol Aplikasi Cerdas

  1. Buka jendela Pengaturan (tekan Win + I).
  2. Pergi ke Privasi & keamanan > Windows Security > Kontrol aplikasi & browser.
  3. Di bawah Kontrol Aplikasi Cerdas, klik Pengaturan Kontrol Aplikasi Cerdas.
  4. Setel Kontrol Aplikasi Cerdas ke Mati. Ini segera memungkinkan aplikasi untuk dibuka dan dijalankan.

Jika Windows atau Edge mencegah Anda mengunduh Updater CE, klik opsi lainnya (…) Kemudian Simpan > Tampilkan lebih banyak > Tetap pertahankan.

Mengaktifkan kembali Kontrol Aplikasi Cerdas

Ketika definisi positif palsu selesai diperbarui di komputer Anda, Anda dapat mengaktifkan kembali Smart App Control melalui Windows Registry:

  1. Tekan Tombol Windows + R, jenis regedit, dan tekan Enter untuk membuka Editor Registri sebagai administrator.
  2. Arahkan ke: HKEY_LOCAL_MACHINE\SYSTEM\CurrentControlSet\Control\CI\Policy (atau Policies).
  3. Menemukan VerifiedAndReputablePolicyState di panel sebelah kanan.
  4. Klik dua kali VerifiedAndReputablePolicyState dan ubah data Nilainya menjadi:
  • 1 = Aktif (Diberlakukan)
  • 2 = Mode Evaluasi
  1. Klik OK, tutup Editor Registri, dan mulai ulang komputer Anda.
