Windows 10/11-appstartproblemer og smart appkontroll-løsning

Hvis Windows 10/11 eller Smart App Control hindrer deg i å starte appen, følg løsningen her.

From 2026-10-25 · until 2026-12-31 · Platform: Windows · Models: Y1,Y2

Falsk-positive rapporter ble sendt til Microsoft for installer.exe og InnioasisUpdater.exe og handlet, men hvis Windows Endpoint Protection eller Smart App Control fortsatt blokkerer applikasjonen på datamaskinen din, bruk denne løsningen:

Midlertidig løsning: Slå av Smart App Control

  1. Åpne Windows Innstillinger (trykk Win + I).
  2. Gå til Personvern og sikkerhet > Windows Security > App- og nettleserkontroll.
  3. Under Smart appkontroll, klikk Smart App Control-innstillinger.
  4. Sett Smart App Control til Av. Dette lar appen åpne og kjøre umiddelbart.

Hvis Windows eller Edge hindrer deg i å laste ned Updater CE, klikk på flere alternativer (…) deretter Behold > Vis mer > Behold uansett.

Aktiverer Smart App Control på nytt

Når falske positive definisjoner er ferdig med å oppdatere på datamaskinen din, kan du aktivere Smart App Control på nytt via Windows-registeret:

  1. Trykk på Windows-tast + R, type regedit, og trykk Enter for å åpne Registerredigering som administrator.
  2. Naviger til: HKEY_LOCAL_MACHINE\SYSTEM\CurrentControlSet\Control\CI\Policy (eller Policies).
  3. Finn VerifiedAndReputablePolicyState i høyre rute.
  4. Dobbeltklikk VerifiedAndReputablePolicyState og endre verdidataene til:
  • 1 = På (håndhevet)
  • 2 = Evalueringsmodus
  1. Klikk OK, lukk Registerredigering og start datamaskinen på nytt.
