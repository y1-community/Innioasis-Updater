From 2026-11-11 · until 2026-12-31

Original Software 3.2.0 is the latest Original Software release for the Y2. Install it before you install Reborn (Y2Linux).

In Updater CE

  1. Choose Y2, then Original Software, pick the 3.2.0 release and select Install. Follow the guided steps through to the end.
  2. Choose Reborn (Y2Linux) and select Refresh to see whether any new Reborn versions have become available.
  3. Select Install and Updater CE guides you through the rest of the install.

Updates after the install

Once Reborn starts on the player, enable Wi-Fi there. From then on Reborn updates itself over the internet on the Y2 itself, so no computer or Updater CE run is needed for later versions.
