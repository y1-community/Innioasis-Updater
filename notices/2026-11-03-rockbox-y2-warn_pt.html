Usuários tendo problemas com Rockbox para Y2.

Rockbox Temas 360p não funcionam e música não é lida em MicroSD.

De 03/11/2026 · até 31/12/2026 · Modelos: Y2 · Software: y2-rockbox · Versão *

Rockbox para Y2 tem dois problemas em aberto relatados pela comunidade:

  • Temas 360p não se aplicam. O player continua mostrando a arte em 360p.
  • A música em um cartão MicroSD não está listada após uma instalação Rockbox.

Se você depende de uma biblioteca MicroSD, permaneça no software original até que eles sejam corrigidos.

A restauração do firmware original leva uma execução de Updater CE. A música no seu cartão MicroSD é deixada sozinha, mas a música salva no armazenamento interno do Y2 é apagada: em Y2, a opção Manter dados em Updater CE 2.5.1 apenas transporta dados entre firmwares que são compatíveis entre si, e mudar para o software original não é um desses casos.

As etapas estão no Y2 guia de restauração de estoque.
