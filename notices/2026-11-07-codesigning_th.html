ปัญหาการเปิดแอป Windows 10/11 และวิธีแก้ปัญหาการควบคุมแอปอัจฉริยะ

หาก Windows 10/11 หรือ Smart App Control ทำให้คุณไม่สามารถเปิดแอปได้ ให้ปฏิบัติตามวิธีแก้ปัญหาชั่วคราวที่นี่

From 2026-10-25 · until 2026-12-31 · Platform: Windows · Models: Y1,Y2

รายงานผลบวกลวงถูกส่งไปยัง Microsoft เพื่อ installer.exe และ InnioasisUpdater.exe และดำเนินการแล้ว แต่หาก Windows Endpoint Protection หรือ Smart App Control ยังคงบล็อกแอปพลิเคชันบนคอมพิวเตอร์ของคุณ ให้ใช้วิธีแก้ปัญหาชั่วคราวนี้:

วิธีแก้ปัญหาชั่วคราว: ปิดการควบคุมแอปอัจฉริยะ

  1. เปิดหน้าต่าง การตั้งค่า (กด Win + I).
  2. ไปที่ ความเป็นส่วนตัวและความปลอดภัย > Windows Security > การควบคุมแอปและเบราว์เซอร์.
  3. ภายใต้ การควบคุมแอปอัจฉริยะคลิก การตั้งค่าการควบคุมแอปอัจฉริยะ.
  4. ตั้งค่าการควบคุมแอปอัจฉริยะเป็น ปิด. ซึ่งจะทำให้แอปสามารถเปิดและรันได้ทันที

หาก Windows หรือ Edge ป้องกันไม่ให้คุณดาวน์โหลด Updater CE ให้คลิกตัวเลือกเพิ่มเติม (…) แล้ว เก็บ > แสดงเพิ่มเติม > ยังไงก็เก็บไว้.

เปิดใช้งานการควบคุมแอปอัจฉริยะอีกครั้ง

เมื่อคำจำกัดความบวกลวงเสร็จสิ้นการอัปเดตบนคอมพิวเตอร์ของคุณ คุณสามารถเปิดใช้งานการควบคุมแอปอัจฉริยะได้อีกครั้งผ่านรีจิสทรีของ Windows:

  1. กด ปุ่ม Windows + R, พิมพ์ regeditแล้วกด Enter เพื่อเปิด Registry Editor ในฐานะผู้ดูแลระบบ
  2. นำทางไปยัง: HKEY_LOCAL_MACHINE\SYSTEM\CurrentControlSet\Control\CI\Policy (หรือ Policies).
  3. ค้นหา VerifiedAndReputablePolicyState ในบานหน้าต่างด้านขวา
  4. ดับเบิลคลิก VerifiedAndReputablePolicyState และเปลี่ยนข้อมูลค่าเป็น:
  • 1 = เปิด (บังคับใช้)
  • 2 = โหมดการประเมินผล
  1. คลิกตกลง ปิดตัวแก้ไขรีจิสทรี แล้วรีสตาร์ทคอมพิวเตอร์

ดูรายงาน installer.exe ไปยัง Microsoft ดูรายงาน InnioasisUpdater.exe ไปยัง Microsoft
