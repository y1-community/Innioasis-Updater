Utilisateurs rencontrant des problèmes avec Rockbox pour Y2.

Rockbox Les thèmes 360p ne fonctionnent pas et la musique ne est pas lue depuis MicroSD.

Du 03/11/2026 · jusqu'au 31/12/2026 · Modèles : Y2 · Logiciel : y2-rockbox · Version *

Rockbox pour Y2 présente deux problèmes ouverts signalés par la communauté :

  • Les thèmes 360p ne s'appliquent pas. Le lecteur continue d’afficher l’illustration 360p d’origine.
  • La musique sur une carte MicroSD n'est pas répertoriée après une installation de Rockbox.

Si vous comptez sur une bibliothèque MicroSD, restez sur le logiciel d'origine jusqu'à ce que ceux-ci soient corrigés.

La restauration du micrologiciel d'origine nécessite une exécution de Updater CE. La musique sur votre carte MicroSD est laissée seule, mais la musique enregistrée dans la mémoire interne du Y2 est effacée : sur Y2, l'option Conserver les données dans Updater CE 2.5.1 ne transporte les données qu'entre les firmwares qui sont compatibles entre eux, et le passage au logiciel d'origine n'est pas l'un de ces cas.

Les étapes sont dans le Y2 guide de restauration des stocks.
