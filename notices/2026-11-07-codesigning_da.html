Problemer med lancering af Windows 10/11 og Smart App Control-løsning

Hvis Windows 10/11 eller Smart App Control forhindrer dig i at starte appen, skal du følge løsningen her.

From 2026-10-25 · until 2026-12-31 · Platform: Windows · Models: Y1,Y2

Falsk-positive rapporter blev indsendt til Microsoft for installer.exe og InnioasisUpdater.exe og handlet, men hvis Windows Endpoint Protection eller Smart App Control stadig blokerer programmet på din computer, skal du bruge denne løsning:

Midlertidig løsning: Slå Smart App Control fra

  1. Åbn Windows Indstillinger (tryk Win + I).
  2. Gå til Privatliv og sikkerhed > Windows Security > App og browser kontrol.
  3. Under Smart app kontrol, klik Indstillinger for Smart App Control.
  4. Indstil Smart App Control til Slukket. Dette gør det straks muligt for appen at åbne og køre.

Hvis Windows eller Edge forhindrer dig i at downloade Updater CE, skal du klikke på flere muligheder (…) derefter Behold > Vis mere > Behold alligevel.

Genaktiverer Smart App Control

Når falsk-positive definitioner er færdige med at opdatere på din computer, kan du genaktivere Smart App Control via Windows-registreringsdatabasen:

  1. Tryk på Windows-tast + R, type regedit, og tryk på Enter for at åbne Registreringseditor som administrator.
  2. Naviger til: HKEY_LOCAL_MACHINE\SYSTEM\CurrentControlSet\Control\CI\Policy (eller Policies).
  3. Find VerifiedAndReputablePolicyState i højre rude.
  4. Dobbeltklik VerifiedAndReputablePolicyState og ændre dens værdidata til:
  • 1 = Til (håndhævet)
  • 2 = Evalueringstilstand
  1. Klik på OK, luk Registreringseditor, og genstart din computer.
