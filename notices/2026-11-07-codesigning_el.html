Ζητήματα εκκίνησης εφαρμογών Windows 10/11 και λύση Έλεγχου Smart App

Εάν τα Windows 10/11 ή ο Έλεγχος Smart App σας εμποδίσουν να εκκινήσετε την εφαρμογή, ακολουθήστε την επίλυση εδώ.

From 2026-10-25 · until 2026-12-31 · Platform: Windows · Models: Y1,Y2

Υποβλήθηκαν ψευδώς θετικές αναφορές στη Microsoft για installer.exe και InnioasisUpdater.exe και ενεργήσατε, αλλά εάν η Προστασία τελικού σημείου των Windows ή ο Έλεγχος έξυπνων εφαρμογών εξακολουθούν να αποκλείουν την εφαρμογή στον υπολογιστή σας, χρησιμοποιήστε αυτήν τη λύση:

Προσωρινή λύση: Απενεργοποιήστε τον Έλεγχο Smart App

  1. Ανοίξτε τα Windows Ρυθμίσεις (πατήστε Win + I).
  2. Μεταβείτε στο Απόρρητο και ασφάλεια > Windows Security > Έλεγχος εφαρμογών και προγράμματος περιήγησης.
  3. Κάτω Έξυπνος έλεγχος εφαρμογών, κάντε κλικ Ρυθμίσεις Smart App Control.
  4. Ρυθμίστε το Smart App Control σε Απενεργοποίηση. Αυτό επιτρέπει αμέσως στην εφαρμογή να ανοίξει και να εκτελεστεί.

Εάν τα Windows ή ο Edge σας εμποδίζουν να κάνετε λήψη του Updater CE, κάντε κλικ σε περισσότερες επιλογές (…) τότε Κρατήστε > Εμφάνιση περισσότερων > Διατήρησε πάντως.

Επανενεργοποίηση Έλεγχου Έξυπνης Εφαρμογής

Όταν ολοκληρωθεί η ενημέρωση των ψευδώς θετικών ορισμών στον υπολογιστή σας, μπορείτε να ενεργοποιήσετε ξανά τον Έλεγχο Smart App μέσω του Μητρώου των Windows:

  1. Τύπος Windows Key + R, τύπος regeditκαι πατήστε Enter για να ανοίξετε τον Επεξεργαστή Μητρώου ως διαχειριστής.
  2. Πλοηγηθείτε σε: HKEY_LOCAL_MACHINE\SYSTEM\CurrentControlSet\Control\CI\Policy (ή Policies).
  3. Εγκατάσταση VerifiedAndReputablePolicyState στο δεξιό τζάμι.
  4. Κάντε διπλό κλικ VerifiedAndReputablePolicyState και αλλάξτε τα δεδομένα αξίας του σε:
  • 1 = Ενεργό (Επιβάλλεται)
  • 2 = Λειτουργία αξιολόγησης
  1. Κάντε κλικ στο OK, κλείστε τον Επεξεργαστή Μητρώου και επανεκκινήστε τον υπολογιστή σας.
