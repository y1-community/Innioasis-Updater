Datamaskinoppsett

Gjør datamaskinen klar før spilleren.

De fleste tilkoblingsproblemer kommer fra driveren, tillatelser, kabel eller timing. Windows trenger MediaTek-driveren installert. Linux trenger de riktige USB tillatelsene. Finn din plattform nedenfor.

Få Updater CEFeilsøking

Windows

  1. Last ned MediaTek driverinstallasjonsprogrammet nedenfor.
  2. Kjør installasjonsprogrammet og la Windows installere driveren.
  3. Start datamaskinen på nytt.
  4. Åpne Updater CE og vent på tilkoblingsmeldingen før du kobler til den avslåtte spilleren.

Noen Windows-systemer blokkerer driveren gjennom kjerneisolering (minneintegritet). Hvis Updater CE fortsatt ikke kan se spilleren etter en omstart, slå av minneintegritet i Windows Security, start på nytt og installer driveren på nytt. Slå på innstillingen igjen når du er ferdig hvis systemet tillater det.

Vil ikke Windows starte appen? Hvis Windows Security eller Smart App Control stopper Updater CE fra å åpne, åpne Innstillinger (trykk Win + I) → Personvern og sikkerhet → Windows Security → App- og nettleserkontroll → Smart App Control-innstillinger og sett den til Av. Smart App Control påvirker for tiden populære applikasjoner som Epic Overlay Service (brukt av Fortnite) - Updater CE er trygg og verifisert å bruke. For å reaktivere senere, still inn VerifiedAndReputablePolicyState til 1 (På) eller 2 (Evalueringsmodus) under HKEY_LOCAL_MACHINE\SYSTEM\CurrentControlSet\Control\CI\Policy i Registerredigering.

Linux USB tillatelser

Linux trenger brukerkontoen din for å få lov til å snakke med MediaTek USB-brikken inne i spilleren. Updater CE ordner vanligvis dette under installasjonen, og den samme tillatelsen dekker SP Flash Tool, så behandle dette som et fix-it-trinn i stedet for et normalt stadium.

  1. Kjør Updater CE som din vanlige bruker, ikke som root. Installasjonsprogrammet ber om administratortilgang bare når det trenger det.
  2. Sjekk at spilleren er sett i det hele tatt. Slå av spilleren, koble til kabelen og kjør lsusb-kommandoen i en terminal. En tilkoblet spiller vises som en MediaTek enhet med leverandør-ID 0e8d.
lsusb
  1. Hvis det vises i lsusb, men Innioasis Updater CE eller SP Flash Tool sier at tillatelse nektes eller ikke kan åpne porten, mangler brukeren tilgang til USB-enheten. Den samme udev-regelen dekker begge verktøyene, så legg til en som lar brukergruppen lese den.
SUBSYSTEM=="usb", ATTR{idVendor}=="0e8d", MODE="0666", GROUP="plugdev"

Lagre den linjen i en ny fil som heter /etc/udev/rules.d/51-innioasis.rules, og kjør deretter:

sudo udevadm control --reload && sudo udevadm trigger
  1. Koble spilleren helt fra, koble den til igjen og prøv å installere på nytt.
  2. Hvis SP Flash Tool rapporterer en serietillatelse eller portrace, koble fra helt og koble til igjen når du blir bedt om det.
Ikke improviser flash-offsets.Hvis du flytter til et manuelt gjenopprettingsverktøy, bruk filene og modellspesifikke konfigurasjonen som ble levert med prosjektet.

Kabel og timing

  1. Bruk en kjent USB datakabel.
  2. Unngå nav under feilsøking.
  3. Slå den riktige modellen helt av.
  4. Koble kun til når du blir bedt om det.
