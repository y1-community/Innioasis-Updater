Rockbox-Y2 · Innioasis Y2

Rockbox untuk Y2 (Rockbox-Y2)

Rockbox-Y2 (juga disebut “Rockbox untuk Y2”) adalah port firmware komunitas Rockbox khusus untuk Innioasis Y2. Ia menggunakan paket ROM miliknya sendiri (rom_y2.zip) dan diinstal langsung melalui Innioasis Updater CE.

Instal Rockbox-Y2 Unduh ROM Tutorial tertulis Rockbox-pusat Y2

Dibuat khusus untuk Innioasis Y2

Di Innioasis Updater CE, firmware ini terdaftar sebagai Rockbox kapan Y2 dipilih. Rilisannya diterbitkan oleh spycemagic/y2-rockbox proyek dengan nama paket rom_y2.zip.

Jangan pernah menginstal paket firmware Y1 pada Y2. Memilih Y2 di Updater CE secara otomatis memfilter daftar rilis ke versi yang kompatibel dengan Y2 saja.

Apa yang Rockbox-Y2 tawarkan

  • Perpustakaan musik berbasis tag — menelusuri album, artis, dan genre dari tag file audio Anda, atau menelusuri folder secara langsung.
  • Kontrol pemutaran — pengaturan pemutaran tanpa celah, crossfade, ReplayGain, dan equalizer.
  • Tema khusus — instal tema yang kompatibel dengan build Rockbox-Y2 Anda (Y2 panduan tema).
  • 100% offline — memutar file lokal dari kartu MicroSD Anda tanpa akun atau langganan.
  • Pemulihan pabrik yang mudah — kembali ke Y2 Perangkat Lunak Asli kapan saja di Updater CE.

Memilih rilis Rockbox-Y2

  • Selalu pilih Y2 di Model perangkat pertama.
  • Pilih rilis terbaru kecuali Anda sedang menguji versi tertentu.
  • Baca Rockbox-Catatan rilis Y2 untuk melihat apa yang berubah di setiap build.

Unduhan langsung dari komunitas pengembang

Innioasis Updater CE selalu mengunduh paket firmware langsung dari komunitas pengembang firmware (spycemagic/y2-rockbox), dan para pengembang tersebut sepenuhnya bertanggung jawab untuk mencantumkan rilis perangkat lunak mereka di Updater CE.

Anda dapat membiarkan Updater CE mengunduh dan mem-flash rom_y2.zip secara otomatis, atau unduh paket dari kami Rockbox-Y2 halaman unduhan dan Rockbox ROM halaman unduh.

Rockbox-Y2 unduhan Instal dari ZIP lokal

Cara menginstal Rockbox-Y2

  1. Buka Innioasis Updater CE dan atur Model perangkat untuk Y2.
  2. Pilih Rockbox di Perangkat lunak.
  3. Pilih rilis Y2 dari daftar.
  4. Klik Pasang / Pulihkan jadi Updater CE mengunduh paket langsung dari pengembangnya.
  5. Matikan Y2 sepenuhnya dan sambungkan dengan kabel data USB saat Updater CE meminta.
  6. Tunggu hingga pesan selesai, lalu cabut dan hidupkan Y2 Anda.

Untuk panduan langkah demi langkah selengkapnya, baca Rockbox-Y2 tutorial.

Memulihkan perangkat lunak Y2 asli

Untuk kembali ke firmware pabrik, pilih Y2 dan Perangkat lunak asli di Updater CE, pilih rilis stabil, dan klik Pasang / Pulihkan. Lihat panduan pemulihan dan Y2 Halaman Perangkat Lunak Asli.

Pertanyaan yang sering diajukan

Dari mana Updater CE mengunduh Rockbox-Y2?

Updater CE selalu mengunduh paket firmware langsung dari rilis milik pengembang firmware komunitas (spycemagic/y2-rockbox). Pengembang sepenuhnya bertanggung jawab untuk mencantumkan rilis perangkat lunak mereka di Updater CE.

Mengapa paketnya diberi nama rom_y2.zip?

Pengembang memberi nama arsip firmware Y2. rom_y2.zip jadi tidak bisa disamakan dengan Y1's rom.zip.

Apakah tema Y1 berfungsi di Y2?

Tidak selalu. Periksa catatan rilis untuk build Y2 Anda dan lihat Rockbox-Y2 panduan tema.
