USB 프롬프트 전에 중지되었습니다.

케이블 문제가 아니라 컴퓨터 문제입니다. 모델을 확인하세요. 파일의 압축을 다시 풀어보세요. 그럼 시도해 보세요 설치 / 복원. 릴리스 목록이 비어 있으면 펌웨어 디렉토리.

플레이어에 연결할 수 없습니다

  1. 올바른 Y1 또는 Y2의 전원을 완전히 끕니다.
  2. 케이블을 분리하고 다른 플래시 또는 Android 도구를 닫은 후 설치를 다시 시작하세요.
  3. 업데이터가 준비되었다고 말할 때만 연결하십시오.
  4. 가능하면 허브가 아닌 짧은 USB 데이터 케이블을 컴퓨터에 직접 사용하십시오.
  5. Windows에서는 MediaTek 드라이버를 다시 설치하고 다시 시작하세요. Linux에서는 USB/serial 권한을 확인하세요.

플레이어를 감지했지만 플래시가 실패했습니다.

여기서 멈춰라. 다른 모델을 시도하지 마십시오. 다른 도구를 닫고 올바른 Y1 또는 Y2을 선택했는지 확인하고 플레이어가 시작되지 않으면 일치하는 원본 소프트웨어를 사용하십시오. SP Flash Tool 필요한 경우 및 MTKClient이 포함되며 파일은 다음 위치에 있습니다. 펌웨어 페이지.

Windows 드라이버 참고사항

일부 Windows 설치에서는 코어 격리로 인해 MediaTek 드라이버를 차단합니다. 메모리 무결성을 변경하기 전에 현재 Windows 보안 지침을 따르고, 시스템에서 허용하는 경우 완료한 후 다시 켜십시오.
