ซอฟต์แวร์ต้นฉบับ · Y1 ซอฟต์แวร์สต็อก

กู้คืนซอฟต์แวร์ต้นฉบับบน Innioasis Y1 ของคุณ

กำลังมองหาซอฟต์แวร์สต็อก Y1 การคืนค่าจากโรงงาน หรือการย้อนกลับจาก Rockbox หรือซอฟต์แวร์อื่นที่กำหนดเองอยู่ใช่ไหม นี่คือเส้นทาง Updater ที่ถูกต้องตามรุ่น

เปิดคู่มือซอฟต์แวร์ต้นฉบับฉบับเต็มรับสิ่งนี้ใน Updater CEเรียกดู Y1 รุ่น

คู่มือการติดตั้งสำหรับคอมพิวเตอร์ของคุณ

กู้คืนซอฟต์แวร์ต้นฉบับบน Y1 ของคุณด้วยคอมพิวเตอร์ของคุณ

เลือกคำแนะนำสำหรับคอมพิวเตอร์ที่คุณใช้ ทุกรุ่นมีการตั้งค่าแพลตฟอร์ม ขั้นตอน Updater CE และวิธีคืนสินค้าในสต็อก

คู่มือวินโดวส์คู่มือ macOSคู่มือลินุกซ์

คำแนะนำ Innioasis Y1 ทั้งหมด · คู่มือซอฟต์แวร์ต้นฉบับทั้งหมด

ติดตั้งหรือกู้คืนด้วย Updater

Updater ใช้ขั้นตอนแนะนำเดียวกันไม่ว่า Y1 กำลังใช้งานซอฟต์แวร์ต้นฉบับหรือโครงการชุมชนอยู่ก็ตาม

  1. เปิด Innioasis Updater CE บนคอมพิวเตอร์ของคุณ (หากคุณต้องการแอป รับ Updater CE). ชุด รุ่นอุปกรณ์ ถึง Y1.
  2. เลือก ซอฟต์แวร์ดั้งเดิม ใน ซอฟต์แวร์ (หรือใช้ รับสิ่งนี้ใน Updater CE เพื่อข้ามไปยังขั้นตอนที่แนะนำ)
  3. คลิก ติดตั้ง / คืนค่า และให้แอปเตรียมแพ็คเกจให้
  4. ปิดเครื่องและเชื่อมต่อ Y1 เฉพาะเมื่อมีการถามสดเท่านั้น

เมื่อดาวน์โหลดด้วยตนเอง จะมีชื่อแพ็คเกจการติดตั้งแบบเต็มตามปกติ rom.zip. การเลือกรุ่นใน Updater เป็นวิธีที่ปลอดภัยกว่าในการเลือกไฟล์

คำถามที่พบบ่อย

ฉันสามารถกู้คืนจาก Rockbox หรือซอฟต์แวร์อื่นที่กำหนดเองได้หรือไม่

ใช่ ใช้โมเดล Y1 และเส้นทางซอฟต์แวร์ต้นฉบับ Y1 อย่าลบไฟล์ระบบก่อนและอย่าแทนที่แพ็คเกจ Y2

จะเกิดอะไรขึ้นหากตรวจไม่พบ Y1 ของฉัน

ตรวจสอบสายเคเบิลข้อมูล การตั้งค่าคอมพิวเตอร์ และระยะเวลาในการเชื่อมต่อ เครื่องเล่นควรปิดและเชื่อมต่อเฉพาะเมื่อพร้อมท์ Updater เท่านั้น

ฉันควรใช้แพ็คเกจใดกับ Y1 ของฉัน

คงรุ่นพิมพ์ไว้บนเครื่องเล่นของคุณที่เลือกไว้ใน Updater แพ็คเกจ Y1 และ Y2 แยกจากกัน — หยุดหากรายการวางจำหน่ายไม่ตรงกับรุ่นของคุณ

รักษาขั้นตอนต่อไปให้เรียบง่าย

ครั้งแรกที่ใช้ Updater? ดูการตั้งค่าที่แนะนำไปที่ รับ Updater CE, อ่านรายละเอียด Y1 คืนค่าบทช่วยสอนหรือใช้ การแก้ไขปัญหา.
