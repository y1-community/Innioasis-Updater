Étapes d'installation

  1. Ouvrez Updater CE. Disponible pour Windows, macOS et Linux.
  2. Sélectionnez Y2 comme modèle d'appareil.
  3. Sélectionnez Reborn (Y2Linux) comme le logiciel.
  4. Cliquez sur Installer/Restaurer. Attendez pendant que Updater CE prépare les fichiers.
  5. Connectez USB lorsque cela vous est demandé. Éteignez d'abord le Y2.
  6. Configurer le Wi-Fi, le Bluetooth et la radio FM
