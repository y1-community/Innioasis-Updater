JJ Launcher Y1 install steps

  1. Deschideți Innioasis Updater CE pe computer (dacă aveți nevoie de aplicație, Obține Updater CE). Setați Model dispozitiv la Y1.
  2. Alege JJ Launcher in Software.
  3. Choose the release shown for Y1.
  4. Faceți clic Instalează / Restaurează.
  5. Opriți și conectați Y1 numai când Updater CE vă cere.

Întrebări frecvente

Can I install the Y2 entry on a Y1?

No. Keep the model and package matched. If the Y1 entry is missing, do not force a Y2 file.

Can I go back to the original software?

Yes. Choose Y1 and Original Software in Updater CE. See the Y1 restore page.

Where are all the JJ Launcher releases?

Current builds are in Descărcări de software. Release notes are on the project’s release notes.
