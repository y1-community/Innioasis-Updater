Tillgängliga operativsystem för Innioasis Y1

Y1 kör flera mjukvarusystem, inklusive builds med audiofil codec-stöd, moderna startprogram och en fabriksåterställning. Välj den som passar hur du lyssnar:

Rockbox

Guldstandarden för ljuduppspelning med öppen källkod. Parametrisk EQ, gapfri FLAC/MP3-uppspelning, teman och teckensnittspaket kan installeras direkt i Updater CE.

Y1 Rockbox Guide →

Better-Y

En förbättrad derivata av den ursprungliga firmware med Bluetooth-stabilitetskorrigeringar, volymkurvor och 100 % temagallerikompatibilitet.

Better-Y Guide →

Solar

En modern musikspelare med öppen källkod byggd med Flutter, som erbjuder smidiga 60fps-animationer, skivomslagsrutnät och modern typografi.

Solar Y1 Guide →

Rondo

Ett startprogram med öppen källkod Y1 för lokala spår och streaming, med snabb, lyhörd navigering.

Rondo Y1 Guide →

Koensayr

En anpassad firmware-konstruktion med sin egen ikonografi, bättre batterikalibrering och stöd för lagertema.

Koensayr Guide →

Originalprogramvara (Stock Restore)

Rengör fabriksfirmwarebilder för Type A (v2.0.0+) och Type B (v1.x) Y1 spelare. Ta bort klossar på ett säkert sätt eller återställ din enhet till fabriksstatus.

Hur man installerar eller uppdaterar Y1 Firmware

Att uppgradera eller ta bort klossar på din Innioasis Y1 är enkelt med vår programsvit för flera plattformar:

  1. Öppna Innioasis Updater CE: Starta uppdateringsprogrammet på macOS, Windows eller Linux.
  2. Välj modell Y1: Välj Y1 i rullgardinsmenyn Enhetsmodell.
  3. Välj ditt operativsystem: Välj Rockbox, Better-Y, Solar eller originalprogramvara.
  4. Klicka på Installera: Updater CE laddar ner firmwarepaketet direkt från utvecklarens utgåva. När du uppmanas, anslut din avstängda Y1 via USB för att börja blinka.
