Inniclassic Y2 asennusvaiheet

  1. Avaa Innioasis Updater CE tietokoneellasi (jos tarvitset sovelluksen, Hanki Updater CE). Aseta Laitteen malli to Y2.
  2. Valitse Inniclassic sisään Ohjelmisto.
  3. Valitse Y2:lle listattu julkaisu.
  4. Napsauta Asenna / Palauta.
  5. Katkaise virta ja liitä Y2 vain, kun Updater CE kysyy.

UKK

Voinko palauttaa varastossa olevan Y2-ohjelmiston?

Kyllä. Valitse Y2 ja Original Software Updater CE:ssä. The Y2 osakeohjelmistoopas kattaa paluutien.

Voinko käyttää Inniclassic:ta Y1:ssä?

Kyllä. Sama projekti julkaisee myös Y1 paketteja - rom.zip Type A ja rom_type_b.zip Type B. Valitse Y1 Updater CE:ssä ja asenna Y1-koonnos; the Y1 asennussivu peittää sen.

Entä jos asennus epäonnistuu?

Huomaa, epäonnistuiko Updater ennen Y2:n havaitsemista vai sen jälkeen, ja tarkista sitten kaapeli, alustan asetukset, malli ja yhteyden ajoitus vianetsintä.
