Inniclassic Y2 install steps

  1. Avaa Innioasis Updater CE tietokoneellasi (jos tarvitset sovelluksen, Hanki Updater CE). Aseta Laitteen malli to Y2.
  2. Valitse Inniclassic sisään Ohjelmisto.
  3. Choose the release listed for Y2.
  4. Napsauta Asenna / Palauta.
  5. Katkaise virta ja liitä Y2 vain, kun Updater CE kysyy.

UKK

Can I restore the stock Y2 software?

Yes. Select Y2 and Original Software in Updater CE. The Y2 stock-software guide kattaa paluutien.

Can I use Inniclassic on Y1?

Yes. The same project publishes Y1 packages as well — rom.zip for Type A and rom_type_b.zip for Type B. Select Y1 in Updater CE and install the Y1 build; the Y1 asennussivu covers it.
