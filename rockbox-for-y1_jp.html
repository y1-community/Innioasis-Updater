Rockbox-Y1 · Innioasis Y1

Y1 の Rockbox (Rockbox-Y1)

「Rockbox」、「Rockbox-Y1」、および「Y1 の Rockbox」はすべて、Innioasis Y1 の同じコミュニティ Rockbox ファームウェアを参照します。プレーヤーに何を追加するか、どのビルドを選択するか、Innioasis Updater CE を使用してインストールする方法は次のとおりです。

1 つのファームウェアに複数の名前

Innioasis Updater CE では、このファームウェアは次のように表示されます Rockbox デバイスモデルを選択するとき Y1。ガイド、ビデオ、リリース ノートでもこのように呼ばれています。 Rockbox-Y1 または Y1 の Rockbox したがって、ビルドは Y1 用であり、Y2 用ではないことは明らかです。

インストールする前に、プレーヤーに印刷されているモデルを必ず確認してください。 Y1 および Y2 ファームウェア パッケージには互換性がありません。

Rockbox-Y1 が Y1 に追加するもの

Rockbox-Y1 は、Innioasis Y1 用のオープンソース Rockbox 音楽プレーヤー ファームウェアのコミュニティ ポートです。

  • タグベースの音楽ライブラリ — オーディオタグを使用してアーティスト、アルバム、ジャンル、年ごとに参照するか、フォルダーを直接参照します。
  • 高度なオーディオ再生 — ギャップレス再生、クロスフェード、リプレイゲイン、フルイコライザー。
  • カスタムテーマ — クラシックな iPod スタイルのレイアウトを含む、数百もの 240p および 360p コミュニティ テーマから選択します。
  • FMラジオ — 内蔵 FM ラジオのサポート。
  • オプションの追加物 — Wi-Fi 経由でポッドキャストをダウンロードし、サポートされているビルドで Last.fm / ListenBrainz / Maloja をスクロブルします。
  • デュアルブート — サポートされているビルドを再フラッシュせずに、工場出荷時のオリジナル ソフトウェアに切り替えます。

どの Y1 ビルドを選択すればよいですか?

  • 240p 対 360p — 240p ビルドは、クラシックな 320×240 Rockbox テーマで動作します。 360p ビルドでは、より鮮明な 480×360 Y1 テーマが使用されます。ビルド解像度を使用するテーマに合わせます (240p 対 360p ガイド).
  • Type A 対 Type B — Type A は、工場出荷時のソフトウェア 2.0.0 以降が付属している Y1 プレーヤー用です。 Type B は以前の Y1 ユニット用です。 Y1 が Type B であることがわかっていない限り、Type A を選択してください。
  • 安定版と夜間版 — 毎日のリスニング用に安定したビルドを選択するか、最新の変更をテストするために夜間ビルドを選択します。

コミュニティ開発者からの直接ダウンロード

Innioasis Updater CE は常にコミュニティ ファームウェア開発者からファームウェア パッケージを直接ダウンロードします (rockbox-y1/rockbox)、開発者自身がソフトウェア リリースを Updater CE にリストすることに単独で責任を負います。

Updater CE にファームウェアを自動的にダウンロードしてインストールさせることも、弊社から ROM パッケージをダウンロードさせることもできます。 Rockbox-Y1 ダウンロード ページ そして Rockbox ROM ダウンロード ページ.

Rockbox-Y1 のインストール方法

  1. Innioasis Updater CEを開いて設定します デバイスモデル 支援先: Y1.
  2. 選択 Rockbox で ソフトウェア.
  3. 安定したリリースを選択します (または、夜間ビルドを有効にしてプレビューをテストします)。
  4. クリック インストール / 復元 したがって、Updater CE は開発者からパッケージを直接ダウンロードします。
  5. Updater CE のプロンプトが表示されたら、Y1 の電源を完全にオフにし、USB データ ケーブルで接続します。
  6. 完了メッセージが表示されるまで待ってから、プレーヤーを切断して電源を入れます。

よくある質問

Y1 の Rockbox は Rockbox-Y1 と同じですか?

はい。 Y1 の Rockbox、Rockbox-Y1、Rockbox、および rockbox-y1 すべては Innioasis Y1 の同じコミュニティ Rockbox ポートを参照します。

Updater CE は Rockbox-Y1 をどこからダウンロードしますか?

Updater CE は常に、コミュニティ ファームウェア開発者自身のリリースからファームウェア パッケージを直接ダウンロードします (rockbox-y1/rockbox）。開発者は、ソフトウェア リリースを Updater CE にリストすることに単独で責任を負います。

Rockbox-Y1 を Y2 にインストールできますか?

いいえ。Y2 には独自の個別のファームウェア ビルドがあります。使用 Y2 の Rockbox その代わり。

Rockbox-Y1 をインストールすると音楽は消去されますか?

いいえ。音楽は MicroSD カードに保存されており、プレーヤーの内部ファームウェアをフラッシュしても影響を受けません。
