Android 4.4 Y2 install steps

  1. Bilgisayarınızda Innioasis Updater CE'yi açın (uygulamaya ihtiyacınız varsa, Updater CE edin). Ayarlamak Cihaz modeli ile Y2.
  2. Seçmek Android 4.4 (Dev) içinde Yazılım.
  3. Choose the release listed for Y2.
  4. Tıklamak Yükle / Geri yükle.
  5. Y2'yi yalnızca Updater CE sorduğunda kapatın ve bağlayın.

SSS

Can I restore the stock Y2 software?

Yes. Select Y2 and Original Software in Updater CE. The Y2 stock-software guide dönüş yolunu kapsar.

Is this a daily driver ROM?

This is an experimental developer ROM intended for testing and development. Release updates are on the project's page.
