Rockbox Y2 Installationsschritte

  1. Öffnen Sie Innioasis Updater CE auf Ihrem Computer (wenn Sie die App benötigen, Updater CE holen). Satz Gerätemodell an Y2.
  2. Wählen Sie Rockbox In Software.
  3. Wählen Sie eine Version, die explizit für Y2 aufgeführt ist.
  4. Klicken Sie Installieren / Wiederherstellen und warten Sie auf die Paketvorbereitung.
  5. Schalten Sie das Y2 nur aus und schließen Sie es an, wenn Updater CE dazu fragt.

Erzwingen Sie kein Y1-Paket, da der Projektname gleich aussieht. Wenn keine Version Y2 angezeigt wird, halten Sie an und überprüfen Sie das Modell und die aktuellen Versionsdaten.

FAQ

Kann ich die ursprüngliche Y2-Software später wiederherstellen?

Ja. Wählen Sie Y2 und Originalsoftware in Updater CE. Siehe die Y2 Aktien-Software-Seite für die Wiederherstellungssequenz.

Warum könnte das Paket rom_y2.zip heißen?

Dies ist ein manueller Download-Hinweis, der von einigen Y2 Vollinstallationsversionen verwendet wird. Die sicherere Wahl ist immer noch die Auswahl von Y2 in Updater CE und die Verwendung der darin enthaltenen Version.

Kann ich das Tutorial Y1 Rockbox verwenden?

Verwenden Sie es nur für die allgemeine Idee. Befolgen Sie für die Paket- und Modellauswahl diese Y2-spezifische Anleitung.
