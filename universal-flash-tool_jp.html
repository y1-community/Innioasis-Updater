Innioasis Updater から始める

より単純なルートはアップデータ内で実行されます

アップデーターがすべての仕事を行います。ソフトウェアを選択し、画面上の手順に従ってください。これで完了です。また、アップデートがいつ到着したかを通知します。そのツールにはガイダンスがなく、ストレージを消去します。以下はそれが何であるか、そして実際にそれが必要な場合です。

コミュニティ版のコラボレーション

Innioasis アップデーター ライアン スペクターとオーディオ ファンのグループが Innioasis と協力して始めました。それ以来成長してきました。 Innioasis アップデーター CE.

Updater CE はカスタム ソフトウェアを作成する人々とともに構築されているため、作成者は Updater CE を推奨します。音楽、ビデオ、Bluetooth のペアリングを維持します。アップデートの準備が完了すると通知されます。 Windows、macOS、Linux 上の新旧コンピューターで実行できます。

Innioasis Universal Flash Tool / 共有 Flash ツールとは何ですか?

の Innioasis Universal Flash Tool、とも呼ばれます 共有Flashツール (v5.0.2) は、工場出荷時のユーティリティです。サービスセンターで機能します。ほとんどのオーナーにとって、それは必要以上に難しいものです。

  • 内部ストレージをワイプします: 共有/ユニバーサル フラッシュ ツールを使用してフラッシュすると、デバイスの内部ストレージが完全に消去されます。つまり、アップデート後に Bluetooth オーディオ デバイスを再接続し、すべての音楽とビデオを置き換える必要があります。 (microSD カードに保存されているメディアは、どちらのツールの影響も受けません。)
  • 更新通知がありません: プレーヤー用の新しいアップデートや改善がリリースされたときに警告するメカニズムのない、オフライン専用のユーティリティです。
  • ガイダンスなし: アプリの手順については何も説明されていません。プレーヤーを準備するために、外部のビデオを見たり、PDF を読んだりする必要があります。 Updater CE では、代わりに各ステップが表示されます。
  • 限定的な Mac サポート: その Mac ビルドには、macOS 15 以降の Apple Silicon Mac が必要です。 Intel Mac は除外されます。 Updater CE は、macOS 10.15 以降の両方で実行されます。
  • Linux または ARM64 Windows ビルドはありません: Universal Flash Tool には Linux ビルドや ARM 上の Windows サポートはありませんが、Updater CE は Linux 用の公式 AppImage とアクティブな ARM64 Windows サポートを提供します。
  • オフラインのみ: あなたはそれを見つけます .zip または .rar 自分で梱包してください。 Updater CE がダウンロードします。
  • 工場出荷時のソフトウェアのみ: Universal Flash Tool は、Rockbox、Better-Y、Solar、Koensayr、Rondo、Reborn (Y2Linux) などのカスタム システムをインストールできません。

クリエイターとコミュニティが Innioasis Updater CE を推奨する理由

Innioasis アップデーター CE プレーヤーの所有者や愛好家向けに特別に構築されています。それは以下を提供します:

  1. ワイプなしで更新: 内部ストレージを消去せずにプレーヤーを更新します。Bluetooth オーディオのペアリング、サウンド設定、オンボードの音楽とビデオは保持されます (microSD に保存されているメディアはどちらのツールの影響も受けません)。
  2. アクティブなアップデート通知: デバイス用の新しいソフトウェア リリースまたはパッチが公開されると、コンピュータ上で積極的に警告を発します。
  3. カスタム プロジェクト作成者との共同開発: オリジナルのソフトウェアで構築され、Innioasis および Timmkoo プレーヤー (Rockbox、Better-Y、Solar、JJ Launcher、Inniclassic、Y2Player、Koensayr) 用のカスタム ソフトウェア作成者と協力して開発されました。
  4. 古いコンピュータやその他のコンピュータのサポート: macOS (Apple Silicon と Intel Mac の両方)、Linux、Windows 10/11 など、古いマシンと新しいマシンを完全にネイティブでサポートします。
  5. 開発者による直接ダウンロード: コミュニティ ファームウェア開発者のリリースから適切なファームウェア パッケージを直接取得します。別途ダウンロードして探す必要はありません。
  6. 簡単な在庫復元: いつでも元のソフトウェアに戻ることができます。
