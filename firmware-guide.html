    Linux

    Take the file that matches your processor. Intel and AMD PCs use the x86_64 builds; ARM boards and ARM laptops, including Raspberry Pi and Snapdragon machines, use the arm64 builds.

    AppImage for Intel/AMDAppImage for ARM64tar.gz for Intel/AMDtar.gz for ARM64zip for Intel/AMDzip for ARM64

    An AppImage needs chmod +x before it runs. The tar.gz and the zip are folders to unpack, not installers. Every one of these files carries the terminal interface, so --tui opens the same app without a window.

    To skip the downloads and let the launcher choose, copy this into a terminal. It reads your processor, fetches the matching build, and asks whether to install or run once:

    curl -fsSL https://innioasis.app/run_linux.sh | bash

    A note on the two tools

    Which tool should I use?

    Innioasis Updater CE is the safest way to update your player. It keeps your music, videos and Bluetooth pairings. It tells you when updates are ready. It runs on Windows, macOS and Linux. The Innioasis Universal Flash Tool wipes your player and works on fewer computers.

    Windows won't launch the app? How to turn off Smart App Control

    Windows Defender SmartScreen or Smart App Control can block newly downloaded community applications before signature reputations propagate. Smart App Control is currently impacting popular applications like the Epic Overlay Service (used by Fortnite) — Updater CE is safe and verified to use. Turning Smart App Control off allows Updater CE to open and run normally.

    1. Open Settings on your Windows PC (press Win + I).
    2. Click Privacy & security in the left sidebar, then click Windows Security.
    3. Click App & browser control.
    4. Under Smart App Control, click Smart App Control settings.
    5. Set the toggle to Off to allow Updater CE to launch.

    Blocked by Edge? If Microsoft Edge blocks the download itself, click the More options button (…) → Keep → Show more → Keep anyway.

    Re-enabling Smart App Control later: When you want to turn Smart App Control back on, you can re-enable it via the Windows Registry under HKEY_LOCAL_MACHINE\SYSTEM\CurrentControlSet\Control\CI\Policy by setting VerifiedAndReputablePolicyState to 1 (On) or 2 (Evaluation Mode) and restarting.
