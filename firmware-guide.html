    Get Innioasis Updater

    Here's where to start if you haven't already got Updater.

    Get it on Updaterwith guided install

    Windows

    Download the installer, open it, and follow the setup prompts.

    Download & Install DriverDownload Windows installer

    You'll need to reboot your PC after installing to make it work.

    macOS

    Download the app, move it to Applications, then open it. If macOS warns about an unidentified developer, Control-click the app and choose Open. Updater needs Homebrew to install the software packages it uses.

    Download HomebrewmacOS Download

    If macOS needs Homebrew, use the macOS setup notes.

    Linux

    Open a terminal and run the project installer. It downloads and prepares the current Linux release.

    curl -sL https://github.com/y1-community/Innioasis-Updater/releases/latest/download/run_linux.sh | bash
    Linux setup notes

    Need the longer computer setup notes? Open the Windows, macOS, or Linux setup guide.

    Going back to Original Software

    You can return from or another listed custom software with Updater: choose the model printed on your player, select Original Software, and run Install / Restore. The stock restore is a software install, so Updater replaces the system software for you.
