업데이터로 설치 또는 복원

업데이터는 Y1이 현재 원본 소프트웨어를 실행 중이든 커뮤니티 프로젝트를 실행 중이든 동일한 안내 흐름을 사용합니다.

  1. 컴퓨터에서 Innioasis Updater CE를 엽니다(앱이 필요한 경우, Updater CE 받기). 세트 기기 모델 에 Y1.
  2. 선택 원본 소프트웨어 안으로 소프트웨어 (또는 사용 이것을 Updater CE에서 얻으세요 안내된 단계로 이동하려면)
  3. 클릭 설치 / 복원 앱이 패키지를 준비하도록 합니다.
  4. 라이브 프롬프트가 나타날 때만 전원을 끄고 Y1을 연결하십시오.

수동으로 다운로드하는 경우 일반적인 전체 설치 패키지 이름은 다음과 같습니다. rom.zip. Updater에서 모델을 선택하는 것이 파일을 선택하는 더 안전한 방법입니다.
