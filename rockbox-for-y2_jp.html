Rockbox-Y2 · Innioasis Y2

Y2 の Rockbox (Rockbox-Y2)

Rockbox-Y2 (Y2 の Rockbox とも呼ばれます) は、Innioasis Y2 の専用コミュニティ Rockbox ファームウェア ポートです。独自の ROM パッケージを使用します (rom_y2.zip) であり、Innioasis Updater CE を通じて直接インストールされます。

Innioasis Y2 専用に構築

Innioasis Updater CE では、このファームウェアは次のようにリストされます。 Rockbox いつ Y2 が選択されます。そのリリースは、 spycemagic/y2-rockbox パッケージ名のプロジェクト rom_y2.zip.

Y1 ファームウェア パッケージを Y2 にインストールしないでください。選択中 Y2 Updater CE では、リリース リストが Y2 と互換性のあるビルドのみに自動的にフィルターされます。

Rockbox-Y2 が提供するもの

  • タグベースの音楽ライブラリ — オーディオ ファイルのタグからアルバム、アーティスト、ジャンルを参照するか、フォルダーを直接参照します。
  • 再生コントロール — ギャップレス再生、クロスフェード、リプレイゲイン、イコライザー設定。
  • カスタムテーマ — Rockbox-Y2 ビルドと互換性のあるテーマをインストールします (Y2 テーマ ガイド).
  • 100%オフライン — アカウントやサブスクリプションなしで MicroSD カードからローカル ファイルを再生します。
  • 簡単な工場出荷時の復元 — Updater CEでいつでもY2の元のソフトウェアに戻ります。

Rockbox-Y2 リリースの選択

  • 常に選択する Y2 で デバイスモデル まず。
  • 特定のバージョンをテストする場合を除き、最新のリリースを選択してください。
  • 読んでください Rockbox-Y2 リリースノート 各ビルドで何が変更されたかを確認します。

コミュニティ開発者からの直接ダウンロード

Innioasis Updater CE は常にコミュニティ ファームウェア開発者からファームウェア パッケージを直接ダウンロードします (spycemagic/y2-rockbox)、これらの開発者はソフトウェア リリースを Updater CE にリストする責任を単独で負います。

Updater CE をダウンロードしてフラッシュすることができます rom_y2.zip 自動的にパッケージをダウンロードするか、弊社からパッケージをダウンロードします。 Rockbox-Y2 ダウンロード ページ そして Rockbox ROM ダウンロード ページ.

Rockbox-Y2 のインストール方法

  1. Innioasis Updater CEを開いて設定します デバイスモデル 支援先: Y2.
  2. 選択 Rockbox で ソフトウェア.
  3. リストから Y2 リリースを選択します。
  4. クリック インストール / 復元 したがって、Updater CE は開発者からパッケージを直接ダウンロードします。
  5. Updater CE の要求に応じて、Y2 の電源を完全にオフにし、USB データ ケーブルで接続します。
  6. 完了メッセージが表示されるまで待ってから、プラグを抜き、Y2 の電源を入れます。

完全なステップバイステップのチュートリアルについては、「 Rockbox-Y2 チュートリアル.

元の Y2 ソフトウェアの復元

工場出荷時のファームウェアに戻すには、次を選択します。 Y2 そして 純正ソフトウェア Updater CE で安定したリリースを選択し、 インストール / 復元。を参照してください。 復元ガイド そして Y2 オリジナル ソフトウェア ページ.

よくある質問

Updater CE は Rockbox-Y2 をどこからダウンロードしますか?

Updater CE は常に、コミュニティ ファームウェア開発者自身のリリースからファームウェア パッケージを直接ダウンロードします (spycemagic/y2-rockbox）。開発者は、ソフトウェア リリースを Updater CE にリストすることに単独で責任を負います。

パッケージの名前が rom_y2.zip なのはなぜですか?

開発者は Y2 ファームウェア アーカイブに名前を付けます rom_y2.zip したがって、Y1 と混同することはできません rom.zip.

Y1 テーマは Y2 で動作しますか?

いつもではありません。 Y2 ビルドのリリース ノートを確認し、 Rockbox-Y2 テーマ ガイド.
