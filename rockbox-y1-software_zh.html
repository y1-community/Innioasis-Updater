Rockbox Y1 安装步骤

  1. 在您的计算机上打开 Innioasis Updater CE（如果您需要该应用程序， 获取 Updater CE）。套装 设备型号 至 Y1.
  2. 选择 Rockbox 在 软件.
  3. 选择与您的预期屏幕或主题路径相匹配的版本和变体。
  4. 点击 安装 / 恢复 并等待应用程序准备好。
  5. 仅在实时提示时关闭电源并连接 Y1。

使用 书面 Rockbox Y1 指南 获取屏幕截图、视频、Type A 或 Type B 注释以及连接清单。

常见问题

我可以回到原来的 Y1 软件吗？

是的。在 Updater CE 中选择 Y1 和原始软件，然后运行安装/恢复。这 Y1 库存软件页面 解释了那条路线。

我应该选择哪个 Rockbox 版本？

选择 Y1 显示的版本并阅读其发行说明。如果您需要较旧的主题兼容性，请检查分辨率和变体注释，而不是选择 Y2 版本。

我可以将其安装在 Y2 上吗？

否。使用单独的 Rockbox Y2 页 并在 Updater CE 中选择 Y2。
