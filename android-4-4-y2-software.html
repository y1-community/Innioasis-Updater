Install Android 4.4 (Dev) on the Y2.

Android 4.4 is a community development ROM for testing and hacking on Innioasis Y2 hardware. This page links to the full tutorial and release list.

Android 4.4 Y2 install steps

  1. Open Innioasis Updater CE on your computer (if you need the app, Get Updater CE). Set Device Model to Y2.
  2. Choose Android 4.4 (Dev) in Software (or use Get this in Updater CE to jump to the guided steps).
  3. Choose the release listed for Y2.
  4. Click Install / Restore.
  5. Power off and connect the Y2 only when Updater CE asks.

FAQs

Can I restore the stock Y2 software?

Yes. Select Y2 and Original Software in Updater CE. The Y2 stock-software guide covers the return path.

Is this a daily driver ROM?

This is an experimental developer ROM intended for testing and development. Check the project repository for release updates.
