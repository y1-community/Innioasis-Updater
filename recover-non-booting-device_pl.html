Rozwiązywanie problemów i odzyskiwanie urządzenia

Odzyskiwanie urządzenia, które się nie uruchamia po wgraniu przez MTKClient

Jeśli Twój Innioasis Y1, Y2 lub inne urządzenie MediaTek nie włącza się lub pokazuje czarny ekran po wgraniu za pomocą MTKclient na macOS lub Linuksie, nie panikuj. Sprzętowy BootROM (BROM) jest trwały i nie można go zniszczyć.

Dlaczego MTKclient może się zawiesić lub zostawić czarny ekran

MTKClient wykorzystuje programowe exploity (kamakiri / amonet), aby ominąć uwierzytelnianie DA, oraz surową komunikację USB przez libusb. W systemach macOS i Linux ARM64:

  • Opóźnienia w komunikacji USB lub przekroczenia czasu portu w macOS mogą zatrzymać wczytywanie payloadu DA w trakcie transferu.
  • Brakujące lub niekompletne nagłówki partycji sprawiają, że bootloader (preloader / lk) przestaje odpowiadać.
  • Odtwarzacz wygląda na całkowicie martwy — brak diody, ikony ładowania i podświetlenia ekranu.

Nawet w takim stanie układ MediaTek wraca do Tryb BROM (USB VID 0e8d, PID 0003), gotowe do oficjalnego odzyskiwania niskopoziomowego.

Sprawdzona metoda odzyskiwania: silnik SP Flash Tool w Updater CE

Najbezpieczniejszy i najpewniejszy sposób odzyskania zbrickowanego odtwarzacza to użycie Updater CE skonfigurowany z oficjalnym SP Flash Tool backend.

Dokładne kroki w Updater CE:

  1. Otwórz Updater CE.
  2. Kliknij Ustawienia na lewym pasku nawigacji.
  3. Przewiń w dół do sekcji Advanced i włącz Show Advanced Settings.
  4. W Metoda instalacji (lub Silnik wgrywania dla instalatora MediaTek), znajdź Metoda wgrywania listy.
  5. Zmień wybór z Auto (zalecane) lub MTKClient do SP Flash Tool.
  6. Potwierdź komunikat i wróć do głównego procesu instalacji.

Architektura i wymagania systemowe SP Flash Tool

Oficjalne narzędzie MediaTek SP Flash Tool jest kompilowane natywnie jako binarka ELF x86_64 dla Linuksa i Plik wykonywalny PE32+ dla Windows x64.

Ważna uwaga sprzętowa dla użytkowników macOS i Linuksa ARM64:
MediaTek nie udostępnia SP Flash Tool dla macOS (Darwin) ani Linuksa ARM64 (aarch64), dlatego użytkownicy macOS i Linuksa ARM64 (np. Raspberry Pi albo Apple Silicon z Asahi Linux), którzy mają zbrickowany odtwarzacz, muszą podłączyć go do:
  • Jakiś komputer z Windows x64 (Windows 10 / 11, 64-bitowy) lub
  • Jakiś komputer z Linuksem x86_64 (Ubuntu, Debian, Fedora, Arch 64-bit).

Sprzętowe odbrykowanie krok po kroku

  1. Odłącz odtwarzacz: Całkowicie odłącz kabel USB od odtwarzacza i komputera.
  2. Twarde wyłączenie: Przytrzymaj przycisk zasilania (lub zasilanie + ściszanie) przez 15 sekund, aby mieć pewność, że układ jest całkowicie wyłączony i nie utknął w niskoprądowej pętli USB.
  3. Uruchom Updater CE w trybie SP Flash Tool: Wybierz model urządzenia (np. Innioasis Y1 lub Innioasis Y2) i wybierz Oryginalne oprogramowanie aby przywrócić fabryczne partycje.
  4. Rozpocznij instalację / przywracanie: Kliknij Install / Restore w Updater CE. Poczekaj, aż w komunikacie o stanie pojawi się Oczekiwanie na odtwarzacz...
  5. Włóż kabel USB, aby uruchomić BROM: Przy wyłączonym urządzeniu podłącz kabel USB bezpośrednio do szybkiego portu USB na płycie głównej (unikaj hubów USB bez zasilania).
  6. System wykryje port MediaTek VCOM, wyśle Download Agent (DA), przepisze tablice partycji i czysto przywróci wszystkie obrazy firmware.
