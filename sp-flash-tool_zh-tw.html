安裝方法

SP Flash Tool 內 Innioasis 更新程式 CE

SP Flash Tool 不是單獨的下載，並且在應用程式資料夾中找不到任何內容。它是配備 Intel 或 AMD 處理器的 Windows x64 和 Linux x86-64 PC 上 Innioasis Updater CE 中的安裝方法。按照正常方式選擇您的固件，然後設置 顯示進階設定 > 安裝方法 > SP Flash Tool 並安裝。

取得更新程式 CE 並安裝韌體下載疑難排解

正常路線優先

選擇您的固件，然後選擇引擎

Updater CE 中的安裝始終是相同的過程：選擇型號，選擇韌體和版本，然後運行安裝/恢復。 install 方法僅決定哪一個 MediaTek 引擎執行刷新。保持開啟狀態 汽車 除非你有理由固定它，並將其設定為 SP Flash Tool 當你這樣做的時候。

哪些計算機有 SP Flash Tool

MediaTek 僅針對 x86-64 發布 SP Flash Tool，因此 Updater CE 在 x86-64 PC 上提供它，而不是在其他地方。應用程式本身比引擎運行在更多的地方。

Windows x64：可用

在 Intel 或 AMD 處理器上為 Windows 10 或 11。的 SP Flash Tool 安裝方法及 SP Flash Tool 按鈕都在那裡。

Linux x86-64：可用

運行 Updater CE AppImage 的 64 位元 Intel 或 AMD Linux 電腦。相同的安裝方法，相同的按鈕。

macOS：不可用

SP Flash Tool 對於任何形式的 macOS 都不存在。更新程式 CE 改為使用 MTKClient 安裝和恢復，並且沒有 SP Flash Tool 安裝方法或按鈕。讓 Mac 保持在導引路線上，或使用 Mac筆記.

Linux ARM64：不可用

Raspberry Pi、ARM 板和 ARM64 Linux 與 macOS 相同：MediaTek 不提供 ARM 版本，因此 Updater CE 在那裡使用 MTKClient。

不確定機器？打開設定並開啟 顯示進階設定: 如果沒有的話 安裝方法 使用 SP Flash Tool 選項，該計算機無法運行它。在 macOS 和 ARM64 Linux 上，播放器仍然可以正常安裝，因此請使用自動引導路線，並且如果您特別需要 SP Flash Tool，則僅移動到 Windows x64 或 Linux x86-64 PC。

使用 SP Flash Tool 安裝您選擇的韌體

  1. 開啟 Updater CE 並選擇播放器上列印的型號：Innioasis Y1、Y2、G1、G3、G5、R1 或 PR1，或 Timmkoo 型號。
  2. 選擇您想要的軟體， 原廠軟體 或社區項目，然後選擇版本。這是與任何其他安裝相同的清單、相同的型號匹配和相同的檢查。
  3. 打開 設定 並打開 顯示進階設定.
  4. 尋找 安裝方法 並選擇 SP Flash Tool 而不是自動。
  5. 返回安裝畫面並點擊 安裝 / 還原.
  6. 當應用程式詢問時，將播放器完全關閉，然後根據提示將 USB 數據線直接連接到電腦。使用數據線，而不是僅充電線，並跳過集線器。
  7. 等待 Updater CE 報告安裝完成，然後斷開電纜並啟動播放器。

這就是整個旅程。更新程式 CE 仍提供特定於型號的軟體包、MediaTek 下載代理、驅動程式檢查和連接提示；選擇 SP Flash Tool 僅交換下面的引擎。

將模型分開。 Y1 套件和 Y2 套件永遠不可互換，而且一個模型的分散檔案不會描述另一個模型。如果 Updater CE 不提供您選擇的型號的固件，請停止並選擇為該型號列出的軟體包。

SP Flash Tool 按鈕的用途

在支援的計算機上，Updater CE 還具有 SP Flash Tool 按鈕，開啟 MediaTek 的工具以直接使用它，例如使用您自己提供的分散包。常規安裝、更新和恢復不需要它：安裝方法與為您處理的型號匹配、驅動程式檢查和連接提示執行相同的工作。

如果該按鈕遺失，則電腦是上述不支援的系統之一，或者您選擇的型號使用不同的流程。在這種情況下，請使用安裝方法或引導路徑，而不是尋找工具二進位。

當 SP Flash Tool 是正確的安裝方法時

  • 無法啟動的播放器。 SP Flash Tool 的下載模式仍然可以到達預先載入器或啟動映像已損壞的設備，這是需要仔細恢復工作的地方。
  • 在支援的 PC 上停止的快閃記憶體。 如果 Auto 或 MTKClient 在 Windows x64 或 Linux x86-64 電腦上中途停止，則將安裝固定至 SP Flash Tool 可讓另一個引擎啟動相同軟體包。
  • 您值得信賴的工廠包裝。 原始軟體發佈自 韌體存檔 與它配合得很好，因為恢復庫存分區正是 SP Flash Tool 的建造目的。

對於普通更新或首次安裝，請保留 安裝方法 在自動上。它會選擇適合您的模型和平台的引擎，並且應用程式可以讓您保持支援的路徑，無需額外的設定。

如果安裝沒有開始

  1. 確認您在 Updater CE 中選擇的型號與播放器上列印的型號相匹配，並且列出了相應的軟體包。
  2. 連接前請確認播放器已完全斷電，並且僅在應用程式提示時進行連接。
  3. 在Windows上，安裝MediaTek驅動程式並重新啟動；在 Linux 上，檢查 USB 中註明的權限 電腦設定.
  4. 直接在電腦上嘗試不同的 USB 連接埠（不使用集線器），然後再次啟動安裝/恢復。

任何進一步的內容都屬於 故障排除。在 macOS 或 ARM64 Linux 上，答案不是不同的按鈕：保留 引導安裝 並僅在 Windows x64 或 Linux x86-64 PC 上使用 SP Flash Tool。
