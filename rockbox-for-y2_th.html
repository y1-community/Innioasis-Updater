Rockbox-Y2 · Innioasis Y2

Rockbox สำหรับ Y2 (Rockbox-Y2)

Rockbox-Y2 (เรียกอีกอย่างว่า "Rockbox สำหรับ Y2") คือพอร์ตเฟิร์มแวร์ชุมชน Rockbox เฉพาะสำหรับ Innioasis Y2 มันใช้แพ็คเกจ ROM ของตัวเอง (rom_y2.zip) และติดตั้งโดยตรงผ่าน Innioasis Updater CE

ติดตั้ง Rockbox-Y2 ดาวน์โหลด ROM กวดวิชาเขียน Rockbox-Y2 ฮับ

สร้างขึ้นโดยเฉพาะสำหรับ Innioasis Y2

ใน Innioasis Updater CE เฟิร์มแวร์นี้แสดงเป็น Rockbox เมื่อไร Y2 ถูกเลือก การเผยแพร่ได้รับการเผยแพร่โดย spycemagic/y2-rockbox โครงการที่มีชื่อแพ็คเกจ rom_y2.zip.

ห้ามติดตั้งแพ็คเกจเฟิร์มแวร์ Y1 บน Y2 การเลือก Y2 ใน Updater CE จะกรองรายการรีลีสโดยอัตโนมัติเป็น Y2 - บิลด์ที่เข้ากันได้เท่านั้น

สิ่งที่ Rockbox-Y2 นำเสนอ

  • คลังเพลงตามแท็ก — เรียกดูอัลบั้ม ศิลปิน และแนวเพลงจากแท็กไฟล์เสียงของคุณ หรือเรียกดูโฟลเดอร์โดยตรง
  • การควบคุมการเล่น - การเล่นแบบไม่มีช่องว่าง, ครอสเฟด, ReplayGain และการตั้งค่าอีควอไลเซอร์
  • ธีมที่กำหนดเอง — ติดตั้งธีมที่เข้ากันได้กับบิลด์ Rockbox-Y2 ของคุณ (Y2 คำแนะนำธีม).
  • ออฟไลน์ 100% — เล่นไฟล์ในเครื่องจากการ์ด MicroSD ของคุณโดยไม่มีบัญชีหรือการสมัครรับข้อมูล
  • คืนค่าโรงงานได้ง่าย — กลับสู่ Y2 ซอฟต์แวร์ต้นฉบับเมื่อใดก็ได้ใน Updater CE

การเลือกรุ่น Rockbox-Y2

  • เลือกอยู่เสมอ Y2 ใน รุ่นอุปกรณ์ ก่อน
  • เลือกรุ่นล่าสุด เว้นแต่ว่าคุณกำลังทดสอบเวอร์ชันเฉพาะ
  • อ่าน Rockbox-Y2 บันทึกประจำรุ่น เพื่อดูว่ามีอะไรเปลี่ยนแปลงไปบ้างในแต่ละรุ่น

ดาวน์โหลดโดยตรงจากนักพัฒนาชุมชน

Innioasis Updater CE ดาวน์โหลดแพ็คเกจเฟิร์มแวร์โดยตรงจากผู้พัฒนาเฟิร์มแวร์ชุมชนเสมอ (spycemagic/y2-rockbox) และนักพัฒนาเหล่านั้นมีหน้าที่รับผิดชอบแต่เพียงผู้เดียวในการแสดงรายการซอฟต์แวร์ของตนใน Updater CE

คุณสามารถให้ Updater CE ดาวน์โหลดและแฟลชได้ rom_y2.zip อัตโนมัติหรือดาวน์โหลดแพ็คเกจจากเรา Rockbox-Y2 หน้าดาวน์โหลด และ Rockbox ROM หน้าดาวน์โหลด.

Rockbox-Y2 ดาวน์โหลด ติดตั้งจาก ZIP ในเครื่อง

วิธีการติดตั้ง Rockbox-Y2

  1. เปิด Innioasis Updater CE และตั้งค่า รุ่นอุปกรณ์ ถึง Y2.
  2. เลือก Rockbox ใน ซอฟต์แวร์.
  3. เลือกรุ่น Y2 จากรายการ
  4. คลิก ติดตั้ง / คืนค่า ดังนั้น Updater CE จึงดาวน์โหลดแพ็คเกจโดยตรงจากผู้พัฒนา
  5. ปิด Y2 โดยสมบูรณ์แล้วเชื่อมต่อด้วยสายเคเบิลข้อมูล USB เมื่อ Updater CE ถาม
  6. รอข้อความแจ้งเสร็จสิ้น จากนั้นถอดปลั๊กแล้วเปิด Y2

สำหรับคำแนะนำแบบทีละขั้นตอนทั้งหมด โปรดอ่าน Rockbox-Y2 บทช่วยสอน.

การกู้คืนซอฟต์แวร์ Y2 ดั้งเดิม

หากต้องการกลับไปใช้เฟิร์มแวร์จากโรงงาน ให้เลือก Y2 และ ซอฟต์แวร์ดั้งเดิม ใน Updater CE เลือกรุ่นที่เสถียร แล้วคลิก ติดตั้ง / คืนค่า. ดู คู่มือการคืนค่า และ Y2 หน้าซอฟต์แวร์ต้นฉบับ.

คำถามที่พบบ่อย

Updater CE ดาวน์โหลด Rockbox-Y2 จากที่ไหน

Updater CE ดาวน์โหลดแพ็คเกจเฟิร์มแวร์โดยตรงจากรีลีสของผู้พัฒนาเฟิร์มแวร์ชุมชนเสมอ (spycemagic/y2-rockbox). นักพัฒนามีหน้าที่รับผิดชอบแต่เพียงผู้เดียวในการแสดงรายการซอฟต์แวร์ของตนใน Updater CE

เหตุใดแพ็คเกจจึงมีชื่อว่า rom_y2.zip

นักพัฒนาตั้งชื่อไฟล์เก็บถาวรเฟิร์มแวร์ Y2 rom_y2.zip ดังนั้นจึงไม่สามารถสับสนกับของ Y1 ได้ rom.zip.

ธีม Y1 ใช้งานได้บน Y2 หรือไม่

ไม่เสมอไป ตรวจสอบบันทึกประจำรุ่นสำหรับบิลด์ Y2 ของคุณและดู Rockbox-Y2 คำแนะนำธีม.
