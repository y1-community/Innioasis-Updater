Для разработчиков прошивок

Добавьте свою прошивку в Updater CE.

Updater CE — это каталог сообщества и установщик кастомных прошивок. Разработайте свой проект на базе ROM, опубликуйте его как общедоступный репозиторий с правильными ресурсами выпуска, добавьте записи модели в slidia_manifest.xml, протестируйте фильтры модели и откройте запрос на включение. Один репозиторий может обслуживать каждую поддерживаемую модель.

Начать с базы ROM

Базовые ПЗУ предоставляют разработчикам специализированных прошивок чистую основу Android с включенными чипами беспроводной радиосвязи. На Y1 они включают Wi-Fi и GPS наряду с заводскими Bluetooth и FM; на Y2 они включают Wi-Fi, GPS и FM наряду с заводским Bluetooth.

Базовые ROM загрузки для разработки индивидуального встроенного ПО, каждая из которых включает версию Android и функции беспроводной связи.
СкачатьУстройствоAndroidБеспроводные функции
rom.zipY1 · Type AAndroid 4.2.2Добавляет Wi-Fi и GPS к заводским Bluetooth и FM (FM уже работает на Y1 с завода). Для Y1 игроков, поставлявшихся с ОС версии 2.0.0 или новее.
rom_type_b.zipY1 · Type BAndroid 4.2.2Добавляет Wi-Fi и GPS к заводским Bluetooth и FM (FM уже работает на Y1 с завода). Для Y1 игроков, поставлявшихся с ОС более ранней версии, чем 2.0.0.
rom_y2.zipY2Android 4.4.2Добавляет Wi-Fi, GPS и FM к заводскому Bluetooth. Радиочип Y2 полностью включен, поэтому FM здесь тоже доступен.

Эти образы представляют собой стандартную базу Android (AOSP) с включенной беспроводной связью устройства, поэтому специальная прошивка может добавлять сетевые функции вместо замены стека радиосвязи. Они являются практической отправной точкой для описанных ниже этапов публикации.

Используйте эти названия ресурсов выпуска

Имя файла является частью сигнала совместимости. Сохраняйте имена точными и помещайте ZIP-файлы в ресурсы выпуска проекта, а не только в дерево исходного кода репозитория.

rom_type_b.zipY1Type BY1 устройства, поставляемые с ОС более ранней версии, чем 2.0.0.
rom_y2.zipY2Y2Полноустановочный пакет Y2 . Держите его отдельно от Y1 ресурсов.

Как работает соединение

Средство обновления CE считывает манифест как свой каталог. Каждый <package> строка сообщает ему имя проекта, репозиторий, модель и обработчик. Когда пользователь выбирает этот проект, Updater проверяет опубликованные выпуски репозитория и ищет rom*.zip объект.

Манифест

Называет проект и сопоставляет его с моделью. Y1 и Y2 нуждаются в отдельных строках, даже если они используют общий репозиторий.

Опубликованный выпуск

Содержит устанавливаемые ZIP-ресурсы. Один выпуск может содержать пакеты Y1 Type A, Y1 Type B и Y2 вместе.

Установка обновления CE

Использует выбранную модель для выбора соответствующего пакета и пути прошивки для конкретной модели. Пользователю не нужно угадывать имя файла.

Публикация проекта за пять шагов

  1. Форк репозитория Updater CE. Создайте свой собственный форк y1-community/Innioasis-Updater, затем клонируйте свою вилку локально.
  2. Подготовьте общедоступный репозиторий прошивки. Убедитесь, что репозиторий является общедоступным и его версия содержит правильные ZIP-ресурсы. Вы можете положить rom.zip, rom_type_b.zip, и rom_y2.zip в одном выпуске, если они принадлежат одной и той же версии.
  3. Отредактируйте манифест. Открыть slidia_manifest.xml в корне вашей вилки Updater CE. Добавьте по одной строке для каждой модели, поддерживаемой выпуском (Y1 и Y2 — общая пара). repo значение — это репозиторий owner/repository; url — это общедоступная страница проекта.
  4. Протестируйте каталог. Запустите Updater из отредактированной кассы. Выберите Y1 и подтвердите, что в проекте показаны ресурсы Y1. Выберите Y2 и подтвердите, что отображается версия Y2. Проверьте Type A и Type B отдельно, если оба опубликованы.
  5. Откройте запрос на вытягивание. Отправьте изменение манифеста в свою вилку и откройте запрос на включение в вышестоящий репозиторий Updater CE. Укажите ссылку на проект, поддерживаемые модели, тег выпуска, названия активов и протестированные вами устройства.

Почему записи модели имеют значение при перепрошивке

      
Манифест — это не просто меню загрузки. После извлечения Updater CE использует решенную модель для подготовки соответствующего пути установки. Y1 и Y2 имеют разные файлы платформы, предварительные загрузчики, конфигурацию разброса и макеты устройств.

      
    
        
  • Y1: программа обновления подготавливает путь Y1 и использует именованные разделы устройства, когда используется MTKClient.
    • 
        
  • Y2: программа обновления подготавливает путь Y2 и использует конфигурацию Y2 MT6582. Полное восстановление может использовать физические адреса из данных разброса, соответствующих модели.
    • 
        
  • Кроссплатформенная поддержка: Updater CE выполняет встроенную прошивку непосредственно в Windows, Linux и macOS (поддерживает компьютеры Mac Intel и Apple Silicon) без дополнительных инструментов для прошивки.
    • 
      

      
Участники должны предоставлять правильные файлы прошивки, а не смещения прошивки. Не редактируйте адреса разброса, файлы предварительной загрузки, файлы DA или команды разделов, чтобы обойти плохой пакет. Исправьте актив выпуска и протестируйте его на предполагаемой модели.
