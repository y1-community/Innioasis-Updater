Rockbox-Y1 · ธีม & Updater CE

ธีม Rockbox-Y1: ถ่ายโอนด้วย Updater CE เลือกโครงสร้าง จากนั้นเลือกรูปลักษณ์

Updater CE จัดการ Rockbox-Y1 ธีมและแบบอักษรให้กับคุณ — ถ่ายโอนไปยัง Y1 โดยอัตโนมัติทุกครั้งที่ทำได้ และแนะนำคุณตลอดขั้นตอนการถ่ายโอนเมื่อไม่สามารถเกิดขึ้นโดยไม่ได้ตั้งใจ (เช่น หลังจากติดตั้งเฟิร์มแวร์ MTKClient บน macOS หรือ Linux)

รับ Rockbox & Updater CE เรียกดูธีมชุมชน 240p กับ 360p

การถ่ายโอนธีมไปยัง Y1 ด้วย Updater CE

Rockbox เก็บเฟิร์มแวร์ไว้ในแฟลชภายในของ Y1 ในขณะที่ธีม แบบอักษร และการตั้งค่าผู้ใช้จะอยู่ภายในส่วนที่ซ่อนอยู่ .rockbox โฟลเดอร์บนที่เก็บข้อมูลของผู้เล่น (MicroSD การ์ด) เนื่องจากการแฟลช ROM และการคัดลอกไฟล์ไปยังที่เก็บข้อมูลใช้การเชื่อมต่อที่แตกต่างกันสองแบบ ตัวอัพเดต CE ปรับให้เข้ากับระบบปฏิบัติการของคุณโดยอัตโนมัติและวิธีการติดตั้ง:

  • ถ่ายโอนอัตโนมัติเมื่อ Updater CE สามารถเข้าถึงผู้เล่น: เมื่อคุณติดตั้งบิวด์ 360p Rockbox-Y1 (หรือเปิดใช้งานการซิงค์ธีมอัตโนมัติในการตั้งค่า) Updater CE จะดาวน์โหลดและรวมธีม 360p และชุดฟอนต์ที่ได้รับการดูแลจัดการในเบื้องหลัง ทันทีที่ Y1 สามารถเข้าถึงได้ เอดีบี (Android Debug Bridge) หรือติดตั้งเป็น USB ขับ ด้วย .rockbox โฟลเดอร์ Updater CE จะพุชธีมและแบบอักษรตรงไปยังเครื่องเล่นสำหรับคุณโดยไม่จำเป็นต้องแตกไฟล์ zip ด้วยตนเอง
  • การถ่ายโอนทีละขั้นตอนที่แนะนำเมื่อไม่สามารถเกิดขึ้นได้โดยไม่ต้องดูแล (เช่น MTKClient บน macOS และ Linux): เมื่อคุณแฟลช Rockbox โดยใช้ MTKClient วิธีการติดตั้งบน macOS หรือ Linux แฟลชจะเกิดขึ้นในขณะที่ Y1 ถูกปิดในโหมด Preloader/BROM ระดับต่ำ - ก่อนที่ Rockbox จะบูตเป็นครั้งแรกเพื่อสร้าง .rockbox และก่อนที่จะติดตั้งที่เก็บข้อมูลของผู้เล่นบนคอมพิวเตอร์ของคุณ เมื่อใดก็ตามที่ Updater CE ไม่สามารถถ่ายโอนให้เสร็จสิ้นโดยไม่มีใครดูแลในระหว่างที่ใช้แฟลชได้ ระบบจะเปิดขึ้นมาโดยอัตโนมัติ ผู้ช่วยธีมและแบบอักษรหลังการติดตั้ง และนำคุณไปสู่การเสร็จสิ้น:
    1. บูต Rockbox ก่อน: Updater CE แจ้งให้คุณถอดสายเคเบิล USB หากจำเป็น และเปิดเครื่อง Y1 ดังนั้น Rockbox บูตหนึ่งครั้งและเริ่มต้น .rockbox โฟลเดอร์บนการ์ด
    2. เชื่อมต่อใหม่ผ่าน USB: เสียบ Y1 กลับเข้าไปใน Mac หรือ Linux PC ของคุณ หาก ADB พร้อมใช้งาน Updater CE จะตรวจจับเครื่องเล่นที่บูตแล้วและพุชธีมและชุดแบบอักษรโดยอัตโนมัติ
    3. หรือใช้โหมดการจัดเก็บ USB ด้วยตัวเลือกโฟลเดอร์ที่แนะนำ: หาก ADB ไม่ทำงานหรือคุณต้องการถ่ายโอนที่เก็บข้อมูลโดยตรง Updater CE จะแนะนำให้คุณเข้าสู่โหมดที่เก็บข้อมูล USB บน Y1 จากนั้นคลิก เลือกโฟลเดอร์ .rockboxเปิดเผยโฟลเดอร์ที่ซ่อนอยู่ (Cmd+Shift+. ในกล่องโต้ตอบไฟล์ macOS หรือ Ctrl+H บน Linux) และเลือก .rockbox บนไดรฟ์ Y1 — จากนั้น Updater CE จะรวมธีมและแบบอักษรทั้งหมดเข้าที่สำหรับคุณ
  • Add or refresh themes anytime on demand: คุณสามารถเรียกใช้การถ่ายโอนแบบอัตโนมัติหรือแบบมีไกด์เดียวกันได้ตลอดเวลาโดยไม่ต้องรีแฟลชเฟิร์มแวร์ — เปิด Updater CE และเลือก การตั้งค่า → ติดตั้ง Rockbox ธีม 360p (Cmd+T บน macOS Ctrl+T บน Windows และ Linux) หรือลากแต่ละธีม .zip แพ็คลงบนของ Updater CE สมาร์ทดรอป หน้าต่าง.

240p, 360p และเหตุใดจึงมีป้ายกำกับอยู่บนบิลด์

Y1 งานสร้างชุมชนได้รับการเผยแพร่โดยมีป้ายกำกับความละเอียด และคอลเลกชันธีมมีป้ายกำกับเดียวกัน รุ่น 240p มีความเข้ากันได้ในวงกว้างที่สุดกับชุดรูปแบบเก่า การสร้าง 360p ถูกสร้างขึ้นสำหรับเส้นทางธีม Y1 ที่ใหม่กว่า การติดตั้งอันหนึ่งแล้วใช้อันอื่นไม่เป็นอันตราย แค่ดูผิด มีข้อความถูกตัด องค์ประกอบขาดหายไป หรือมีอินเทอร์เฟซที่คุณไม่สามารถอ่านได้

หากคุณยังไม่มีการตั้งค่าธีม ให้ใช้เวอร์ชันเสถียรที่ใหม่กว่าและธีมเริ่มต้น จากนั้นเลือกธีมที่ตรงกับป้ายกำกับ ที่ หน้าความละเอียด ลึกลงไป; หลักการง่ายๆ นั้นง่ายมาก: ป้ายกำกับการสร้างและป้ายกำกับธีมจะต้องสอดคล้องกัน

ธีมอยู่ที่ไหน

ธีมคือไฟล์ในการ์ด MicroSD ซึ่งอยู่ภายใน .rockbox โฟลเดอร์ — โฟลเดอร์เดียวกับที่เก็บการตั้งค่าและแคช เฟิร์มแวร์นั้นอยู่ในแฟลชภายใน ดังนั้นการเพิ่ม การเปลี่ยนแปลง หรือการลบธีมจึงไม่จำเป็นต้องทำการแฟลชใหม่

  • คัดลอกโฟลเดอร์ของธีมลงไป .rockbox/themes บนการ์ด
  • จากนั้นเลือกในการตั้งค่าธีมของผู้เล่นและรีบูตเพื่อดูว่ามีการใช้หรือไม่
  • เก็บสำเนาของธีมที่คุณต้องการไว้ก่อนที่จะอัปเดตบิลด์ ซึ่งเป็นไฟล์ ไม่ใช่การติดตั้ง

เปิดไฟล์ที่ซ่อนก่อนหากคุณไม่เห็นโฟลเดอร์: macOS Cmd+Shift+., Windows View → รายการที่ซ่อนอยู่, Linux Ctrl+H.

การใช้ธีมตามลำดับ

  1. ติดตั้งและบูต Rockbox-Y1 ก่อน ธีมต้องการบิลด์ที่ทำงานอยู่
  2. คัดลอกโฟลเดอร์ธีมไปที่ .rockbox/themes บนการ์ด
  3. เปิดการตั้งค่าธีมและเลือกธีม
  4. รีบูตเพื่อให้อินเทอร์เฟซทั้งหมด — ไม่ใช่แค่เมนู — หยิบมันขึ้นมา
  5. หากดูใช้งานไม่ได้ ให้เลือกธีมอื่น ไฟล์จะยังคงอยู่หากคุณต้องการลองอีกครั้งในภายหลัง

เลิกทำธีมที่ทำให้อินเทอร์เฟซเสียหาย

หากเครื่องเล่นบูทเข้าสู่สิ่งที่ใช้ไม่ได้ คุณไม่จำเป็นต้องติดตั้งเฟิร์มแวร์ใหม่ เปลี่ยนชื่อหรือลบ .rockbox โฟลเดอร์บนการ์ดและเริ่มเครื่องเล่น: บิลด์จะสร้างโฟลเดอร์ขึ้นใหม่ด้วยการตั้งค่าเริ่มต้นและธีมเริ่มต้น เพลงของคุณไม่ถูกแตะต้อง และคุณสามารถคัดลอกธีมที่คุณต้องการกลับมาได้ในภายหลัง

โฟลเดอร์ .rockbox เริ่มแรก กำลังอัปเดตการสร้าง

คำถามที่ผู้คนถาม

เหตุใด Updater CE จึงแนะนำฉันเกี่ยวกับการถ่ายโอนธีมหลังจากติดตั้ง MTKClient บน macOS หรือ Linux

MTKClient กะพริบ Rockbox ROM ไปยังที่จัดเก็บข้อมูลภายในในขณะที่ Y1 ของคุณปิดอยู่ในโหมด Preloader/BROM ระดับต่ำ ก่อนที่ Rockbox จะบู๊ตเพื่อเริ่มต้น .rockbox โฟลเดอร์และก่อนที่จะติดตั้งการ์ด MicroSD บนคอมพิวเตอร์ของคุณ เมื่อใดก็ตามที่ Updater CE สามารถเข้าถึงเครื่องเล่นที่บูทไว้ได้โดยตรง (ผ่าน ADB หรือไดรฟ์ USB ที่ติดตั้งอยู่) มันจะถ่ายโอนธีมโดยอัตโนมัติ เมื่อไม่สามารถทำสิ่งนั้นได้โดยไม่มีใครดูแลในระหว่างที่แฟลช จะเปิดขั้นตอนธีมและแบบอักษรที่แนะนำทันทีหลังจากการกะพริบ เพื่อช่วยคุณเปิด Y1 และทำการถ่ายโอนให้เสร็จสิ้นผ่าน ADB หรือโหมดที่เก็บข้อมูล USB

ธีม Y2 จะใช้งานได้บน Y1 หรือไม่

ไม่ พอร์ตต่างๆ แยกจากกัน และการรองรับธีมบน Y2 จะเป็นไปตามรุ่นเบต้า ดู Rockbox-Y2 ธีม.

ธีมจะมีการอัปเดตต่อไปหรือไม่

โดยปกติแล้วจะใช่ เนื่องจากพวกมันอยู่บนการ์ดและแฟลชเขียน ROM หากบิลด์ใหม่เปลี่ยนเส้นทางของธีม ให้นำธีมที่ตรงกับป้ายกำกับไปใช้ใหม่

เหตุใดจึงใช้ธีมเพียงครึ่งเดียว

โดยปกติแล้วการรีบูตจะช่วยแก้ปัญหาได้ หากไม่เป็นเช่นนั้น ไฟล์ของธีมจะไม่สมบูรณ์ ให้คัดลอกโฟลเดอร์ใหม่แทนที่จะแก้ไขแต่ละไฟล์
