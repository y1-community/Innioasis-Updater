Koensayr Y1 шаги установки

  1. Откройте Innioasis Updater CE на своем компьютере (если вам нужно приложение, Скачать Updater CE). Набор Модель устройства в адрес Y1.
  2. Выбирать Koensayr в Программное обеспечение.
  3. Выберите указанный выпуск Y1.
  4. Нажмите Установить / Восстановить.
  5. Выключите питание и подсоедините Y1 только тогда, когда появится запрос Updater CE.

Вопросы и ответы

Могу ли я восстановить исходное программное обеспечение Y1?

Да. Выберите Y1 и оригинальное программное обеспечение в Updater CE. См. Y1 страница стандартного программного обеспечения для полного маршрута восстановления.

Что мне следует проверить в случае сбоя?

Проверьте модель, версию, кабель, настройку платформы и был ли плеер подключен до появления запроса. Затем используйте Поиск неисправностей.

Есть ли пакет Koensayr Y2?

Текущая сборка предназначена для Y1. Не используйте его в Y2, если только проект не опубликует для него отдельный выпуск.

Начнём с настройки компьютера

Программа обновлений работает в Windows, macOS и Linux после завершения настройки платформы. Прочтите общее руководство первый.
