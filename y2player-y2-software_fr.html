Y2Player étapes d'installation

  1. Ouvrez Innioasis Updater CE sur votre ordinateur (si vous avez besoin de l'application, Obtenir Updater CE). Ensemble Modèle d'appareil à Y2.
  2. Choisissez Y2Player dans Logiciel.
  3. Choisissez une version répertoriée pour Y2.
  4. Cliquez Installer / Restaurer.
  5. Éteignez et connectez le Y2 à l'invite en direct.

Certains Y2 packages d'installation complète utilisent rom_y2.zip. Laissez Updater choisir le package lorsque cela est possible.

FAQ

Puis-je revenir au logiciel d'origine ?

Oui. Sélectionnez Y2 et Logiciel original dans Updater CE, puis suivez les instructions Guide de restauration Y2.

Puis-je l'utiliser sur un Y1 ?

Non. Cette page concerne l'entrée Y2Player Y2. Gardez les packages Y1 et Y2 séparés.

Que faire si le Y2 n'est pas détecté ?

Vérifiez la configuration de la plate-forme, le câble, l'état de mise hors tension, la sélection du modèle et la synchronisation. Utiliser dépannage avant d'essayer la récupération manuelle.

Préparez l'ordinateur

Suivez le Configuration de Windows, macOS et Linux Updater CE d'abord.
