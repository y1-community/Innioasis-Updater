🎨 Y1 und 360p Rockbox Theme-Downloader

Laden Sie Themes für Ihr Y1-Gerät herunter und installieren Sie sie direkt in Ihrem Browser

📱 Geräteeinrichtung

Y1 Gerät: Schalten Sie Ihr Y1 ein, stellen Sie eine Verbindung über USB her und aktivieren Sie den USB-Speichermodus

Computer: Ihr Y1 sollte als Wechseldatenträger erscheinen (normalerweise mit dem Namen „Y1“ oder ähnlich).

Themenort: Suchen Sie nach einem Ordner mit dem Namen .rockbox auf Ihrem Y1-Gerät

Bereit zum Herunterladen von Themen

📋 Anleitung zur manuellen Installation

⚠️ Wichtig: Nachdem Sie Themes heruntergeladen haben, müssen Sie diese manuell auf Ihr Y1-Gerät kopieren. Der Browser kann nicht direkt auf das Dateisystem Ihres Geräts zugreifen.

🎯 Für Y1 Themen:

  1. Laden Sie die ausgewählten Y1 Themes über die Schaltfläche oben herunter
  2. Extrahieren Sie die heruntergeladene ZIP-Datei in einen temporären Ordner
  3. Verbinden Sie Ihr Y1-Gerät über USB und aktivieren Sie den USB-Speichermodus
  4. Navigieren Sie in Ihrem Dateimanager zu Ihrem Y1-Gerät
  5. Erstellen Sie einen Ordner mit dem Namen Themes im Stammverzeichnis Ihres Y1-Geräts (falls nicht vorhanden)
  6. Kopieren Sie für jedes Thema den Themenordner nach Themes/ auf Ihrem Y1-Gerät
  7. Jedes Theme sollte sich in einem eigenen Unterordner befinden: Themes/ThemeName/
  8. Theme-Dateien sollten direkt im Theme-Unterordner abgelegt werden (nicht tiefer verschachtelt)
Y1 Gerät/ ├── .rockbox/ ├── Themes/ │ ├── Theme1/ │ │ ├── theme.wps │ │ ├── theme.sbs │ │ └── ... │ ├── Theme2/ │ │ ├── theme.wps │ │ └── ... │ └── ... └── ...

🎨 Für Rockbox 360p-Themen:

  1. Laden Sie die ausgewählten Rockbox Themes über die Schaltfläche oben herunter
  2. Extrahieren Sie die heruntergeladene ZIP-Datei in einen temporären Ordner
  3. Verbinden Sie Ihr Y1-Gerät über USB und aktivieren Sie den USB-Speichermodus
  4. Navigieren Sie in Ihrem Dateimanager zu Ihrem Y1-Gerät
  5. Finden Sie die .rockbox Ordner auf Ihrem Y1-Gerät
  6. Öffnen Sie für jedes Thema das Thema .rockbox Ordner
  7. Kopieren Sie alle Dateien aus dem Theme .rockbox Ordner direkt in Ihren Y1-Ordner .rockbox Ordner
  8. Überschreiben Sie vorhandene Dateien, wenn Sie dazu aufgefordert werden (dies ist bei der Theme-Installation normal).
Y1 Gerät/ ├── .rockbox/ │ ├── Themen/ │ ├── Schriftarten/ │ ├── wps/ │ ├── (Themendateien hier zusammengeführt) │ └── ... └── ...
💡 Profi-Tipp: Sie können mehrere Themen auswählen und alle auf einmal herunterladen. Jedes Thema befindet sich in der heruntergeladenen ZIP-Datei in einem eigenen Ordner.

🔄 Nach der Installation:

  1. Werfen Sie Ihr Y1-Gerät sicher von Ihrem Computer aus
  2. Trennen Sie das USB-Kabel
  3. Gehen Sie auf Ihrem Y1-Gerät zu Einstellungen → Themen
  4. Wählen Sie Ihr neu installiertes Theme aus der Liste aus
  5. Viel Spaß mit Ihrem neuen Thema!

🗑️ Themen entfernen:

  1. Für Y1 Themes: Löschen Sie den Theme-Ordner aus Themes/ auf Ihrem Y1-Gerät
  2. Für Rockbox-Designs: Verwenden Sie die Schaltfläche „Rockbox-Ordner zurücksetzen“ oben, um alle Nicht-360p-Designs zu entfernen
