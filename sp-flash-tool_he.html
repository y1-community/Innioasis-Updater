שיטת ההתקנה

SP Flash Tool בתוך Innioasis Updater CE

SP Flash Tool אינה הורדה נפרדת ואין שום דבר למצוא בתיקיית האפליקציה. זוהי שיטת התקנה ב-Innioasis Updater CE במחשבי Windows x64 ו-Linux x86-64 עם מעבדי Intel או AMD. בחר את הקושחה שלך בדרך הרגילה ולאחר מכן הגדר הצג הגדרות מתקדמות > שיטת התקנה > SP Flash Tool ולהתקין.

המסלול הרגיל קודם

בחר את הקושחה שלך ואז בחר את המנוע

התקנה ב-Updater CE היא תמיד אותו מסע: בחר את הדגם שלך, בחר את הקושחה והגרסה, ואז הפעל את ההתקנה / שחזור. שיטת ההתקנה רק מחליטה איזה מנוע MediaTek מבצע את ההבזק. תשאיר את זה דולק אוטומטי אלא אם כן יש לך סיבה להצמיד אותו, ולהגדיר אותו SP Flash Tool כאשר אתה עושה זאת.

לאילו מחשבים יש SP Flash Tool

MediaTek מפרסם SP Flash Tool עבור x86-64 בלבד, כך ש-Updater CE מציע את זה במחשבי x86-64 ובשום מקום אחר. האפליקציה עצמה פועלת ביותר מקומות מאשר המנוע.

Windows x64: זמין

Windows 10 או 11 במעבד של אינטל או AMD. ה SP Flash Tool שיטת ההתקנה וה- SP Flash Tool כפתור שניהם שם.

Linux x86-64: זמין

מכונת 64 סיביות של אינטל או AMD Linux המריץ את Updater CE AppImage. אותה שיטת התקנה, אותו כפתור.

macOS: לא זמין

SP Flash Tool אינו קיים עבור macOS בשום צורה. Updater CE מתקין ומשחזר עם MTKClient במקום זאת, ואין שיטת התקנה או כפתור SP Flash Tool. השאר את ה-Mac במסלול המודרך, או השתמש ב- הערות מק.

Linux ARM64: לא זמין

Raspberry Pi, לוחות ARM ו-ARM64 Linux הם אותו סיפור כמו macOS: MediaTek לא מספק ARM build, אז Updater CE משתמש ב-MTKClient שם.

לא בטוח לגבי מכונה? פתח את ההגדרות והפעל הצג הגדרות מתקדמות: אם אין שיטת ההתקנה עם אפשרות SP Flash Tool, המחשב הזה לא יכול להפעיל אותו. ב-macOS ו-ARM64 Linux הנגן עדיין מותקן כרגיל, אז השתמש במסלול המודרך עם Auto ועבור למחשב Windows x64 או Linux x86-64 רק אם אתה צריך SP Flash Tool.

התקן את הקושחה שבחרת עם SP Flash Tool

  1. פתח את Updater CE ובחר את הדגם המודפס על הנגן שלך: Innioasis Y1, Y2, G1, G3, G5, R1 או PR1, או דגם Timmkoo.
  2. בחר את התוכנה שאתה רוצה, תוכנה מקורית או פרויקט קהילתי, ולאחר מכן בחר את הגרסה. זוהי אותה רשימה, אותה התאמה לדגם ואותם בדיקות כמו כל התקנה אחרת.
  3. פתוח הגדרות ולהדליק הצג הגדרות מתקדמות.
  4. מצא שיטת ההתקנה ולבחור SP Flash Tool במקום אוטומטי.
  5. חזור למסך ההתקנה ולחץ התקנה / שחזור.
  6. כבה את הנגן לחלוטין כאשר האפליקציה מבקשת, ולאחר מכן חבר את כבל הנתונים USB ישירות למחשב בהנחיה. השתמש בכבל נתונים, לא בכבל לטעינה בלבד, ודלג על רכזות.
  7. המתן עד שהעדכון CE ידווח שההתקנה הסתיימה, ואז נתק את הכבל והפעל את הנגן.

זה כל המסע. Updater CE עדיין מספק את החבילה הספציפית לדגם, סוכן ההורדה MediaTek, בדיקות מנהל ההתקן והנחיית החיבור; בחירה ב-SP Flash Tool רק מחליפה את המנוע שמתחתיו.

שמור את הדגמים נפרדים. חבילה Y1 וחבילה Y2 לעולם אינן ניתנות להחלפה, וקובץ פיזור מדגם אחד אינו מתאר את השני. אם Updater CE אינו מציע את הקושחה עבור הדגם שבחרת, עצור ובחר במקום זאת את החבילה הרשומה עבור אותו דגם.

לשם מה הלחצן SP Flash Tool

במחשב נתמך, Updater CE כולל גם SP Flash Tool כפתור שפותח את הכלי של MediaTek לעבודה איתו ישירות, למשל עם חבילת פיזור שסיפקת בעצמך. התקנות, עדכונים ושחזורים שגרתיים אינם זקוקים לכך: שיטת ההתקנה עושה את אותה עבודה עם התאמת הדגם, בדיקות מנהלי התקנים והנחיות חיבור המטופלות עבורך.

אם הלחצן חסר, המחשב הוא אחת מהמערכות שאינן נתמכות למעלה, או שהדגם שבחרת משתמש בזרימה אחרת. השתמש בשיטת ההתקנה או במסלול המודרך במקרה זה במקום לחפש כלי בינארי.

כאשר SP Flash Tool היא שיטת ההתקנה הנכונה

  • שחקן שלא יאתחל. מצב ההורדה של SP Flash Tool עדיין יכול להגיע למכשיר שהטעינה המוקדמת או תמונת האתחול שלו פגומה, וזה המקום שבו מתרחשת עבודת שחזור זהירה.
  • פלאש שנתקע במחשב נתמך. אם Auto או MTKClient עוצרים בחלק מהדרך במכשיר Windows x64 או Linux x86-64, הצמדת ההתקנה ל-SP Flash Tool נותנת למנוע השני סיבוב על אותה חבילה.
  • חבילת מפעל שאתה סומך עליה. תוכנה מקורית יוצאת מה- ארכיון קושחה להתאים אותו היטב, כי שחזור מחיצות מלאי הוא בדיוק מה ש-SP Flash Tool בנוי עבורו.

לעדכון רגיל או התקנה ראשונה, עזוב שיטת ההתקנה על אוטומטי. הוא בוחר את המנוע המתאים לדגם ולפלטפורמה שלך, והאפליקציה שומרת אותך על הנתיב הנתמך ללא הגדרות נוספות.

אם ההתקנה לא מתחילה

  1. ודא שהדגם שבחרת ב-Updater CE מתאים לדגם המודפס על הנגן, ושהחבילה רשומה עבורו.
  2. ודא שהנגן כבוי לחלוטין לפני שאתה מחבר אותו, והתחבר רק בהנחיית האפליקציה.
  3. ב-Windows, התקן את מנהל ההתקן MediaTek והפעל מחדש; ב-Linux, בדוק את ההרשאות USB שצוינו ב הגדרת המחשב.
  4. נסה יציאת USB אחרת ישירות במחשב, ללא רכזת, והתחל שוב בהתקנה/שחזור.

כל דבר נוסף שייך פתרון בעיות. וב-macOS או ARM64 Linux, התשובה היא לא כפתור שונה: שמור על התקנה מודרכת והשתמש ב-SP Flash Tool רק ממחשב Windows x64 או Linux x86-64.
