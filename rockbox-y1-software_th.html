ติดตั้ง Rockbox บน Y1 ด้วยคอมพิวเตอร์ของคุณ

เลือกคำแนะนำสำหรับคอมพิวเตอร์ที่คุณใช้ ทุกรุ่นมีการตั้งค่าแพลตฟอร์ม ขั้นตอน Updater CE และวิธีคืนสินค้าในสต็อก

คู่มือวินโดวส์คู่มือ macOSคู่มือลินุกซ์

คำแนะนำ Innioasis Y1 ทั้งหมด · คำแนะนำ Rockbox ทั้งหมด

Rockbox Y1 ขั้นตอนการติดตั้ง

  1. เปิด Innioasis Updater CE บนคอมพิวเตอร์ของคุณ (หากคุณต้องการแอป รับ Updater CE). ชุด รุ่นอุปกรณ์ ถึง Y1.
  2. เลือก Rockbox ใน ซอฟต์แวร์.
  3. เลือกรุ่นและรูปแบบที่ตรงกับหน้าจอหรือเส้นทางธีมที่คุณต้องการ
  4. คลิก ติดตั้ง / คืนค่า และรอให้แอปเตรียมการ
  5. ปิดเครื่องและเชื่อมต่อ Y1 เฉพาะเมื่อมีข้อความแสดงสดเท่านั้น

ใช้ เขียนคำแนะนำ Rockbox Y1 สำหรับภาพหน้าจอ วิดีโอ บันทึก Type A หรือ Type B และรายการตรวจสอบการเชื่อมต่อ
