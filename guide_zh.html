    Innioasis 更新程序 CE 是在您的播放器上安装官方更新和社区软件的应用程序。它会保留您的音乐和设置，并且可以在 Windows、macOS 和 Linux 上运行。

    Linux 设置注意事项

    您需要您的播放器、一根可传输数据的 USB 数据线（无法安装只能充电的数据线）以及几分钟的时间。保持电缆连接，直到更新程序 CE 表示已完成。

    选择您的型号和软件

    1. 设备型号： 选择播放器上印有的型号， Y1 或 Y2。为一种型号制作的软件无法安装在另一种型号上。
    2. 软件及发布： 当为您的型号列出时，选择原始软件、Rockbox、Solar、JJ Launcher、Inniclassic、Y2Player 或 Koensayr，然后选择一个版本。稳定是安全的选择。
    3. 安装： 点击 安装 / 恢复，完全关闭播放器电源，仅在更新程序 CE 要求时连接 USB 电缆。
    4. 结束： 将播放器和电缆放在一边，直到出现成功消息，然后断开连接并启动播放器。

    Y1 2.0.0 之前附带原始软件的玩家需要 设备 Type B。其他人都保留默认值 Type A。

    返回原始软件

    定制软件是可逆的。在 Updater CE 中，选择您的型号，然后选择 原厂软件，选择一个稳定版本，然后运行 安装 / 恢复 同样的方式。没有什么可以手动删除的。

    Windows 无法启动该应用程序？智能应用程序控制解决方法

    Windows Defender SmartScreen 或智能应用程序控制可以在签名信誉传播之前阻止新下载的社区应用程序。智能应用程序控制目前正在影响流行的应用程序，例如 Epic Overlay Service（由 Fortnite 使用）——Updater CE 是安全的并且经过验证可以使用。关闭智能应用程序控制允许 Updater CE 正常打开和运行。

    1. 打开 设置 在您的 Windows PC 上（按 Win + I).
    2. 点击 隐私与安全 ，然后单击左侧边栏中的 Windows安全.
    3. 点击 应用程序和浏览器控制.
    4. 在下面 智能应用程序控制， 点击 智能应用程序控制设置.
    5. 将切换开关设置为 离开 以允许 Updater CE 启动。

    通过 Edge 下载？ 如果 Edge 本身阻止下载，请单击“更多选项”按钮 (…) → 保持 → 显示更多 → 无论如何都要保留.

    稍后重新启用智能应用程序控制： 当您想要重新打开智能应用程序控制时，您可以通过 Windows 注册表重新启用它 HKEY_LOCAL_MACHINE\SYSTEM\CurrentControlSet\Control\CI\Policy 通过设置 VerifiedAndReputablePolicyState 至 1 （开）或 2 （评估模式）并重新启动。

    Windows 无法启动该应用程序？如何关闭智能应用程序控制

    Windows Defender SmartScreen 或智能应用程序控制可以在签名信誉传播之前阻止新下载的社区应用程序。智能应用程序控制目前正在影响流行的应用程序，例如 Epic Overlay Service（由 Fortnite 使用）——Updater CE 是安全的并且经过验证可以使用。关闭智能应用程序控制允许 Updater CE 正常打开和运行。

    1. 打开 设置 在您的 Windows PC 上（按 Win + I).
    2. 点击 隐私与安全 ，然后单击左侧边栏中的 Windows安全.
    3. 点击 应用程序和浏览器控制.
    4. 在下面 智能应用程序控制， 点击 智能应用程序控制设置.
    5. 将切换开关设置为 离开 以允许 Updater CE 启动。

    被边缘阻止？ 如果 Microsoft Edge 本身阻止下载，请单击“更多选项”按钮 (…) → 保持 → 显示更多 → 无论如何都要保留.

    稍后重新启用智能应用程序控制： 当您想要重新打开智能应用程序控制时，您可以通过 Windows 注册表重新启用它 HKEY_LOCAL_MACHINE\SYSTEM\CurrentControlSet\Control\CI\Policy 通过设置 VerifiedAndReputablePolicyState 至 1 （开）或 2 （评估模式）并重新启动。
