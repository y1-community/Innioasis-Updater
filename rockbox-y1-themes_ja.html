Rockbox-Y1 · テーマ & Updater CE

Rockbox-Y1 テーマ: Updater CE で転送し、ビルドを選択してから外観を選択します

Updater CE は Rockbox-Y1 のテーマとフォントを処理します。可能な限り自動的に Y1 に転送し、無人で実行できない場合 (たとえば、macOS または Linux に MTKClient ファームウェアをインストールした直後) には転送を段階的にガイドします。

Rockbox と Updater CE を取得します コミュニティのテーマを参照する 240p 対 360p

Updater CE でテーマを Y1 に転送しています

Rockbox はファームウェアを Y1 の内部フラッシュに保存しますが、テーマ、フォント、ユーザー設定は非表示のフラッシュ内に保存されます。 .rockbox プレーヤーのストレージ上のフォルダー (MicroSD カード)。 ROM のフラッシュとストレージへのファイルのコピーには 2 つの異なる接続が使用されるため、 アップデーター CE オペレーティング システムとインストール方法に自動的に適応します。

  • Updater CE がプレーヤーに到達できる場合に自動転送: 360p Rockbox-Y1 ビルドをインストールすると (または設定でテーマの自動同期を有効にすると)、Updater CE は厳選された 360p テーマとフォント パックをダウンロードしてバックグラウンドで結合します。 Y1 に到達するとすぐに ADB (Android Debug Bridge) またはとしてマウントされます。 USB ドライブ と .rockbox フォルダー、Updater CE は、手動で zip 抽出する必要がなく、テーマとフォントをプレーヤーに直接プッシュします。
  • 無人で実行できない場合のガイド付きステップバイステップ転送 (例: macOS および Linux の MTKClient): を使用してRockboxを点滅させると、 MTKClient macOS または Linux でのインストール方法では、フラッシュは Y1 が低レベルのプリローダー/BROM モードで電源オフになっている間、つまり Rockbox が初めて起動して作成される前に発生します。 .rockbox プレーヤーのストレージがコンピュータにマウントされる前。 Updater CE がフラッシュ中に無人で転送を完了できない場合は常に、自動的に ポストインストールテーマとフォントアシスタント そして、それを完了するまでの手順を説明します。
    1. 最初に Rockbox をブートします: Updater CE では、必要に応じて USB ケーブルを取り外し、Y1 の電源をオンにするよう求められます。これにより、Rockbox が一度起動して、 .rockbox カード上のフォルダー。
    2. USB 経由で再接続します。 Y1 を Mac または Linux PC に再度接続します。 ADB が利用可能な場合、Updater CE は起動されたプレーヤーを検出し、テーマとフォント パックを自動的にプッシュします。
    3. または、ガイド付きフォルダー ピッカーで USB ストレージ モードを使用します。 ADB がアクティブでない場合、または直接ストレージ転送を希望する場合は、Updater CE をクリックすると、Y1 で USB ストレージ モードに入ることができます。 .rockboxフォルダーを選択します、隠しフォルダーを表示します (Cmd+Shift+. macOSのファイルダイアログで、または Ctrl+H Linux の場合)、選択します .rockbox Y1 ドライブ上で、Updater CE がすべてのテーマとフォントを所定の位置にマージします。
  • いつでも必要に応じてテーマを追加または更新します。 ファームウェアを再フラッシュせずに、いつでも同じ自動転送またはガイド付き転送を実行できます。Updater CE を開いて選択します。 設定 → Rockbox 360p テーマをインストール (Cmd+T macOS では、 Ctrl+T Windows および Linux の場合)、または個別のテーマをドラッグします .zip Updater CE にパックします スマートドロップ ウィンドウ。

240p、360p、およびビルドにラベルが付いている理由

Y1 コミュニティ ビルドは解決ラベル付きで公開され、テーマ コレクションにも同じラベルが付けられます。 240p ビルドは、古いテーマ パックと最も幅広い互換性を持っています。 360p ビルドは、新しい Y1 テーマ パス用に作成されています。一方をインストールしてもう一方を適用することは危険ではありません。単にテキストが切り取られたり、要素が欠落していたり​​、インターフェースが読めなかったりするなど、見た目が間違っているだけです。

まだテーマを設定していない場合は、新しい安定したビルドとそのデフォルトのテーマを選択し、そのラベルと一致するテーマを選択します。の 解決ページ さらに深くなる。経験則は単純です。ビルド ラベルとテーマ ラベルは一致する必要があります。

テーマが存在する場所

テーマは、MicroSD カード内のファイルです。 .rockbox フォルダー — 設定とキャッシュを保持するフォルダーと同じフォルダーです。ファームウェア自体は内部フラッシュ上にあるため、テーマの追加、変更、削除の際に再フラッシュする必要はありません。

  • テーマ自体のフォルダーをにコピーします .rockbox/themes カード上で。
  • 次に、プレーヤーのテーマ設定でそれを選択し、再起動して適用されたことを確認します。
  • ビルドを更新する前に、気に入ったテーマのコピーを保存しておいてください。これはファイルであり、インストールではありません。

フォルダーが表示されない場合は、まず隠しファイルを有効にしてください: macOS Cmd+Shift+.、Windows ビュー → 隠し項目、Linux Ctrl+H.

テーマを順番に適用する

  1. まず Rockbox-Y1 をインストールして起動します。テーマには実行中のビルドが必要です。
  2. テーマフォルダーを次の場所にコピーします .rockbox/themes カード上で。
  3. テーマ設定を開き、テーマを選択します。
  4. 再起動すると、メニューだけでなくインターフェース全体がそれを認識します。
  5. 壊れているように見える場合は、別のテーマを選択してください。後で再試行する場合でも、ファイルはまだ存在します。

インターフェースを壊したテーマを元に戻す

プレーヤーが使用できない状態で起動した場合でも、ファームウェアを再インストールする必要はありません。名前を変更または削除する .rockbox カード上のフォルダーを選択してプレーヤーを開始します。ビルドにより、デフォルト設定とデフォルトのテーマでフォルダーが再作成されます。音楽はそのままなので、後で必要なテーマをコピーして戻すことができます。

人々が尋ねる質問

macOS または Linux に MTKClient をインストールした後、Updater CE でテーマの転送手順が説明されるのはなぜですか?

MTKClient は、Rockbox が起動して初期化する前に、Y1 の電源が低レベルのプリローダー/BROM モードでオフになっている間、Rockbox ROM を内部ストレージにフラッシュします。 .rockbox MicroSD カードがコンピュータにマウントされる前に、フォルダーに移動します。 Updater CE が起動したプレーヤーに (ADB またはマウントされた USB ドライブ経由で) 直接アクセスできる場合は常に、テーマが自動的に転送されます。フラッシュ中に無人で実行できない場合は、フラッシュ直後にガイド付きのテーマとフォントのステップが開き、Y1 の電源をオンにして、ADB または USB ストレージ モード経由で転送を完了できるようにします。

Y2 テーマは Y1 で機能しますか?

いいえ。ポートは別々であり、Y2 でのテーマのサポートはベータ ビルドに従います。見る Rockbox-Y2 テーマ.

テーマはアップデート後も存続しますか?

これらはカード上に存在し、フラッシュは ROM を書き込むため、通常はそうです。新しいビルドによってテーマのパスが変更された場合は、そのラベルと一致するテーマを再適用します。

テーマが半分しか適用されていないのはなぜですか?

通常は再起動すると解決します。そうでない場合は、テーマのファイルが不完全です。個々のファイルを編集するのではなく、そのフォルダーを再コピーしてください。
