Getting started with Innioasis Updater CE

Works with all Innioasis and Timmkoo audio players. Install Innioasis Updater CE on your computer, choose your model and the software you want, then follow the prompts.

    Hanki Innioasis Updater CE

    Innioasis Päivittäjä CE is the app that installs official updates and community software on your player. It keeps your music and settings, and it runs on Windows, macOS and Linux.

    Windows

    Download the installer, run it, then restart your PC when it finishes.

    Get DriversLataa Updater CE

    If Windows stops you from running the app or won't launch it, please open Settings, click Privacy & security → Windows Security → App & browser control, and turn Smart App Control off. Smart App Control currently impacts popular applications like the Epic Overlay Service (used by Fortnite) — Updater CE is safe and verified to use. Windows ei käynnistä sovellusta? Auttaa

    Restart your PC after installing. Driver help is in the Windows setup notes.

    macOS

    Lataa Updater CE

    If your Mac stops you from running the app for the first time, please open System Settings, click Privacy & Security, scroll down to Security and click Open Anyway. You can also Control-click (or right-click) the app in Finder and choose Open.

    Works on Intel and Apple Silicon Macs with macOS Ventura and later.

    Linux

    Download the AppImage for Intel and AMD systems, make it executable, and run it.

    Linux setup notes

    You need your player, a USB data cable that carries data (a charge-only cable cannot install), and a few minutes. Keep the cable connected until Updater CE says it is done.

    Pick your model and software

    1. Device Model: choose the model printed on the player, Y1 tai Y2. Software made for one model cannot be installed on the other.
    2. Software and release: choose Original Software, Rockbox, Solar, JJ Launcher, Inniclassic, Y2Player, or Koensayr when it is listed for your model, then pick a release. Stable is the safe choice.
    3. Install: click Asenna / Palauta, power the player fully off, and connect the USB cable only when Updater CE asks.
    4. Finish: leave the player and cable alone until the success message, then disconnect and start the player.

    Y1 players that shipped with Original Software before 2.0.0 need Device Type B. Everyone else keeps the default Type A.

    Going back to Original Software

    Custom software is reversible. In Updater CE, choose your model, select Alkuperäinen ohjelmisto, pick a stable release, then run Asenna / Palauta the same way. There is nothing to delete by hand.

    If a flash stops before the USB prompt, check the cable, platform setup, and model first. See vianetsintä for fixes, the Y1 and Y2 recovery guide for power and wheel faults, and SP Flash Tool for advanced recovery.

    Windows won't launch the app? Smart App Control workaround

    Windows Defender SmartScreen tai Smart App Control voivat estää äskettäin ladatut yhteisösovellukset ennen kuin allekirjoituksen maine leviää. Smart App Control vaikuttaa tällä hetkellä suosittuihin sovelluksiin, kuten Epic Overlay Service (Fortniten käyttämä) – Updater CE on turvallinen ja varmennettu käytettäväksi. Smart App Controlin kytkeminen pois päältä sallii Updater CE:n avautua ja toimia normaalisti.

    1. Avaa Asetukset on your Windows PC (press Win + I).
    2. Napsauta Privacy & security in the left sidebar, then click Windows Security.
    3. Napsauta App & browser control.
    4. Under Smart App Control, click Smart App Control settings.
    5. Set the toggle to Pois to allow Updater CE to launch.

    Downloaded via Edge? If Edge blocks the download itself, click the More options button (…) → Keep → Show more → Keep anyway.

    Re-enabling Smart App Control later: When you want to turn Smart App Control back on, you can re-enable it via the Windows Registry under HKEY_LOCAL_MACHINE\SYSTEM\CurrentControlSet\Control\CI\Policy by setting VerifiedAndReputablePolicyState to 1 (On) or 2 (Evaluation Mode) and restarting.
