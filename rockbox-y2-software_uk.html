Rockbox Y2 кроки встановлення

  1. Відкрийте Innioasis Updater CE на своєму комп’ютері (якщо вам потрібна програма, Отримати Updater CE). встановити Модель пристрою для Y2.
  2. Виберіть Rockbox в Програмне забезпечення.
  3. Виберіть випуск, явно вказаний для Y2.
  4. Натисніть Встановити / Відновити і дочекайтеся підготовки упаковки.
  5. Вимкніть живлення та підключіть Y2 лише тоді, коли Updater CE запитає.

Не примусово створюйте пакет Y1, оскільки назва проекту виглядає так само. Якщо випуск Y2 не відображається, зупиніться та перевірте дані моделі та поточного випуску.

так Виберіть Y2 і оригінальне програмне забезпечення в Updater CE. Див Y2 сторінка стандартного програмного забезпечення для послідовності відновлення.

Чому пакет може називатися rom_y2.zip?

Це підказка для ручного завантаження, яка використовується в деяких Y2 випусках повної інсталяції. Більш безпечним вибором залишається вибір Y2 у Updater CE та використання випуску, який він представляє.

Чи можу я скористатися підручником Y1 Rockbox?

Використовуйте його лише для загальної ідеї. Для вибору упаковки та моделі дотримуйтеся цього Спеціальний посібник для Y2..
