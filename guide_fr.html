Premiers pas avec Innioasis Updater CE

Fonctionne avec tous les lecteurs audio Innioasis et Timmkoo. Installez Innioasis Updater CE sur votre ordinateur, choisissez votre modèle et le logiciel souhaité, puis suivez les instructions.

    Obtenez Innioasis Updater CE

    Innioasis Programme de mise à jour CE est l'application qui installe les mises à jour officielles et les logiciels communautaires sur votre lecteur. Il conserve votre musique et vos paramètres et fonctionne sous Windows, macOS et Linux.

    Windows

    Téléchargez le programme d'installation, exécutez-le, puis redémarrez votre PC une fois l'installation terminée.

    Obtenir des pilotesTélécharger Updater CE

    Si Windows vous empêche d'exécuter l'application ou ne la lance pas, veuillez ouvrir Paramètres, cliquez sur Confidentialité et sécurité → Sécurité Windows → Contrôle des applications et du navigateur, puis désactivez Smart App Control. Smart App Control affecte actuellement les applications populaires telles que Epic Overlay Service (utilisé par Fortnite) – Updater CE est sûr et vérifié à utiliser. Windows ne lance pas l'application ? Aide

    Redémarrez votre PC après l'installation. L'aide au conducteur est dans le Notes de configuration de Windows.

    macOS

    Télécharger Updater CE

    Si votre Mac vous empêche d'exécuter l'application pour la première fois, ouvrez Réglages Système, cliquez sur Confidentialité et sécurité, faites défiler jusqu'à Sécurité et cliquez sur Ouvrir quand même. Vous pouvez également faire un Contrôle-clic (ou un clic droit) sur l'application dans le Finder et choisir Ouvrir.

    Fonctionne sur les Mac Intel et Apple Silicon avec macOS Monterey et versions ultérieures.

    Linux

    Téléchargez l'AppImage pour les systèmes Intel et AMD, rendez-la exécutable et exécutez-la.

    Téléchargez AppImage pour Intel/AMD

    Notes de configuration Linux

    Vous avez besoin de votre lecteur, d'un câble de données USB qui transporte les données (un câble de charge uniquement ne peut pas être installé) et de quelques minutes. Gardez le câble connecté jusqu'à ce que Updater CE dise que c'est terminé.

    Choisissez votre modèle et votre logiciel

    1. Modèle d'appareil : choisissez le modèle imprimé sur le lecteur, Y1 ou Y2. Les logiciels conçus pour un modèle ne peuvent pas être installés sur un autre.
    2. Logiciel et version : choisissez Logiciel d'origine, Rockbox, Solar, JJ Launcher, Inniclassic, Y2Player ou Koensayr lorsqu'il est répertorié pour votre modèle, puis choisissez une version. Stable est le choix sûr.
    3. Installer: cliquez Installer / Restaurer, éteignez complètement le lecteur et connectez le câble USB uniquement lorsque Updater CE le demande.
    4. Finition: laissez le lecteur et le câble tranquilles jusqu'au message de réussite, puis déconnectez et démarrez le lecteur.

    Y1 les lecteurs livrés avec le logiciel d'origine avant la version 2.0.0 doivent Appareil Type B. Tout le monde conserve la valeur par défaut Type A.

    Revenir au logiciel d'origine

    Le logiciel personnalisé est réversible. Dans Updater CE, choisissez votre modèle, sélectionnez Logiciel d'origine, choisissez une version stable, puis exécutez Installer / Restaurer de la même manière. Il n'y a rien à supprimer à la main.

    Guide de restauration Y1Guide de restauration Y2

    Si un flash s'arrête avant l'invite USB, vérifiez d'abord le câble, la configuration de la plate-forme et le modèle. Voir dépannage pour les correctifs, le Y1 et Y2 guide de récupération pour les défauts de puissance et de roue, et SP Flash Tool pour une récupération avancée.

    Windows ne lance pas l'application ? Solution de contournement du contrôle intelligent des applications

    Windows Defender SmartScreen ou Smart App Control peut bloquer les applications communautaires nouvellement téléchargées avant que les réputations de signature ne se propagent. Smart App Control a actuellement un impact sur des applications populaires telles que Epic Overlay Service (utilisé par Fortnite) – Updater CE est sûr et vérifié à utiliser. La désactivation de Smart App Control permet à Updater CE de s’ouvrir et de fonctionner normalement.

    1. Ouvert Paramètres sur votre PC Windows (appuyez sur Win + I).
    2. Cliquez Confidentialité et sécurité dans la barre latérale gauche, puis cliquez sur Windows Security.
    3. Cliquez Contrôle des applications et du navigateur.
    4. Sous Contrôle intelligent des applications, cliquez Paramètres de contrôle des applications intelligentes.
    5. Réglez la bascule sur Désactivé pour permettre à Updater CE de se lancer.

    Téléchargé via Edge ? Si Edge bloque lui-même le téléchargement, cliquez sur le bouton Plus d'options (…) → Garder → Afficher plus → Gardez quand même.

    Réactivation ultérieure de Smart App Control : Lorsque vous souhaitez réactiver Smart App Control, vous pouvez le réactiver via le registre Windows sous HKEY_LOCAL_MACHINE\SYSTEM\CurrentControlSet\Control\CI\Policy en définissant VerifiedAndReputablePolicyState à 1 (Activé) ou 2 (Mode d'évaluation) et redémarrage.
