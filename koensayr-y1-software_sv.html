Koensayr Y1 install steps

  1. Öppna Innioasis Updater CE på din dator (om du behöver appen, Hämta Updater CE). Ställ in Enhetsmodell till Y1.
  2. Välj Koensayr i Programvara.
  3. Choose the listed Y1 release.
  4. Klicka Installera / Återställ.
  5. Stäng av och anslut Y1 endast när Updater CE frågar.

Vanliga frågor

Can I restore the original Y1 software?

Yes. Select Y1 and Original Software in Updater CE. See the Y1 stock-software page for the complete restore route.

What should I check when it fails?

Check the model, release, cable, platform setup, and whether the player was connected before the prompt. Then use felsökning.

Is there a Koensayr Y2 package?

The current build is for Y1. Don't use it on a Y2 unless the project publishes a separate release for it.
