So installieren oder aktualisieren Sie die Y1-Firmware

Mit unserer plattformübergreifenden Software-Suite können Sie Ihr Innioasis Y1 ganz einfach aktualisieren oder das Bricking aufheben:

  1. Öffnen Sie Innioasis Updater CE: Starten Sie den Updater unter macOS, Windows oder Linux.
  2. Wählen Sie Modell Y1: Wählen Sie Y1 in der Dropdown-Liste Gerätemodell.
  3. Wählen Sie Ihr Betriebssystem: Wählen Sie Rockbox, Better-Y, Solar oder Originalsoftware.
  4. Klicken Sie auf „Installieren“: Updater CE lädt das Firmware-Paket direkt aus der Entwicklerversion herunter. Wenn Sie dazu aufgefordert werden, verbinden Sie Ihr ausgeschaltetes Y1 über USB, um mit dem Blinken zu beginnen.
