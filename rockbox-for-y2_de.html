Rockbox-Y2 · Innioasis Y2

Rockbox für Y2 (Rockbox-Y2)

Rockbox-Y2 (auch „Rockbox für Y2 genannt) ist der dedizierte Community-Firmware-Port Rockbox für Innioasis Y2. Es verwendet sein eigenes ROM-Paket (rom_y2.zip) und wird direkt über Innioasis Updater CE installiert.

Installieren Sie Rockbox-Y2 Laden Sie die ROM herunter Schriftliches Tutorial Rockbox-Y2-Hub

Speziell für die Innioasis Y2 entwickelt

In Innioasis Updater CE ist diese Firmware aufgeführt als Rockbox Wann Y2 ausgewählt ist. Seine Veröffentlichungen werden von der veröffentlicht spycemagic/y2-rockbox Projekt mit dem Paketnamen rom_y2.zip.

Installieren Sie niemals ein Y1-Firmware-Paket auf einem Y2. Auswählen Y2 in Updater CE filtert die Release-Liste automatisch nur nach Y2-kompatiblen Builds.

Was Rockbox-Y2 bietet

  • Tag-basierte Musikbibliothek – Durchsuchen Sie Alben, Künstler und Genres anhand Ihrer Audiodatei-Tags oder durchsuchen Sie Ordner direkt.
  • Wiedergabesteuerung – Gapless-Wiedergabe, Crossfade, ReplayGain und Equalizer-Einstellungen.
  • Benutzerdefinierte Themen — Installieren Sie Themes, die mit Ihrem Rockbox-Y2-Build kompatibel sind (Y2 Themenführer).
  • 100 % offline – spielt lokale Dateien von Ihrer MicroSD-Karte ohne Konten oder Abonnements ab.
  • Einfache Wiederherstellung der Werkseinstellungen — jederzeit in Updater CE zur Originalsoftware von Y2 zurückkehren.

Auswählen einer Rockbox-Y2-Version

  • Immer auswählen Y2 In Gerätemodell zuerst.
  • Wählen Sie die neueste Version, es sei denn, Sie testen eine bestimmte Version.
  • Lesen Sie die Rockbox-Y2 Versionshinweise um zu sehen, was sich in jedem Build geändert hat.

Direkte Downloads von den Community-Entwicklern

Innioasis Updater CE lädt Firmware-Pakete immer direkt von den Community-Firmware-Entwicklern herunter (spycemagic/y2-rockbox), und diese Entwickler sind allein dafür verantwortlich, ihre Softwareversionen in Updater CE aufzulisten.

Sie können Updater CE herunterladen und flashen lassen rom_y2.zip automatisch, oder laden Sie das Paket von unserem herunter Rockbox-Y2 Downloadseite und Rockbox ROM Download-Seite.

Rockbox-Y2 Downloads Von einer lokalen ZIP-Datei installieren

So installieren Sie Rockbox-Y2

  1. Öffnen Sie Innioasis Updater CE und stellen Sie ein Gerätemodell an Y2.
  2. Auswählen Rockbox In Software.
  3. Wählen Sie eine Y2-Version aus der Liste aus.
  4. Klicken Sie Installieren / Wiederherstellen also lädt Updater CE das Paket direkt vom Entwickler herunter.
  5. Schalten Sie Y2 vollständig aus und verbinden Sie es mit einem USB-Datenkabel, wenn Updater CE Sie dazu auffordert.
  6. Warten Sie auf die Abschlussmeldung, ziehen Sie dann den Netzstecker und schalten Sie Ihr Y2 ein.

Die vollständige Schritt-für-Schritt-Anleitung finden Sie im Rockbox-Y2 Tutorial.

Wiederherstellen der ursprünglichen Y2-Software

Um zur werkseitigen Firmware zurückzukehren, wählen Sie Y2 und Original-Software Wählen Sie in Updater CE eine stabile Version aus und klicken Sie auf Installieren / Wiederherstellen. Siehe die Anleitung zur Wiederherstellung und Y2 Original-Softwareseite.

Häufig gestellte Fragen

Woher lädt Updater CE Rockbox-Y2 herunter?

Updater CE lädt Firmware-Pakete immer direkt von den eigenen Versionen der Community-Firmware-Entwickler herunter (spycemagic/y2-rockbox). Die Entwickler sind allein dafür verantwortlich, ihre Softwareversionen in Updater CE aufzulisten.

Warum heißt das Paket rom_y2.zip?

Der Entwickler nennt das Firmware-Archiv Y2. rom_y2.zip es kann also nicht mit den Y1 verwechselt werden rom.zip.

Funktionieren Y1-Themen auf Y2?

Nicht immer. Überprüfen Sie die Versionshinweise für Ihren Y2-Build und sehen Sie sich die an Rockbox-Y2 Themenführer.
