安裝步驟

  1. 發射 Innioasis Updater 行政長官 在您的 Windows、Mac 或 Linux 電腦上。
  2. 選擇 Y1 從設備型號下拉清單中。
  3. 選擇 Rondo 從軟體下拉清單中。
  4. 點選 安裝 / 還原 並等待該工具下載並準備文件。
  5. 當 Updater CE 提示時，關閉 Y1 電源並連接 USB 電纜。
  6. 完成安裝後設定
