安装步骤

  1. 发射 Innioasis Updater 行政长官 在您的 Windows、Mac 或 Linux 计算机上。
  2. 选择 Y1 从设备型号下拉列表中。
  3. 选择 Rondo 从软件下拉列表中。
  4. 点击 安装 / 恢复 并等待该工具下载并准备文件。
  5. 当 Updater CE 提示时，关闭 Y1 电源并连接 USB 电缆。
  6. 完成安装后设置
