Installez-le ou restaurez-le avec Updater

Configurez d’abord l’ordinateur, puis laissez Updater préparer le package correspondant au modèle.

  1. Ouvrez Innioasis Updater CE sur votre ordinateur (si vous avez besoin de l'application, Obtenir Updater CE). Ensemble Modèle d'appareil à Y2.
  2. Choisissez Logiciel d'origine et une version Y2.
  3. Cliquez Installer / Restaurer.
  4. Éteignez et connectez le Y2 uniquement lorsque l'invite en direct vous le demande.

Les packages d'installation complète manuelle peuvent utiliser rom_y2.zip. Ne traitez pas un Y1 rom.zip comme substitut.

FAQ

Puis-je revenir depuis Rockbox ou un autre logiciel personnalisé ?

Utilisez le même flux de restauration Y2 : choisissez Y2, sélectionnez Logiciel d'origine et suivez l'invite de connexion. Ne mélangez pas les fichiers de modèle.

Pourquoi le package Y2 est-il différent ?

Les versions Y2 peuvent utiliser un nom de package et une entrée de version différents. Sélectionnez Y2 dans Updater plutôt que de deviner à partir d'un nom de fichier ZIP manuel.

Que faire si le joueur n'est pas détecté ?

Vérifiez le câble de données, les autorisations ou les pilotes de l'ordinateur et la synchronisation. Connectez le Y2 éteint uniquement après que le programme de mise à jour indique qu'il est prêt.

Besoin d'une liste de contrôle de récupération ?

Suivez l'intégralité Y2 tutoriel de restauration, puis ouvrez dépannage si l'application signale un échec.
