Model-correct checks

  1. Set Device Model to Y2.
  2. Confirm JJ Launcher appears for Y2 in the current release data.
  3. Read the project release note and select the listed Y2 release.
  4. Click Install / Restore.
  5. Power off and connect the Y2 only when prompted.
Do not substitute: a Y1 package is not a Y2 package. Stop if the model and release do not agree.

FAQs

Is Y2 support guaranteed?

The current catalogue exposes a Y2 entry, but release support can change. Check the live entry and upstream notes before installing.

How do I restore the Y2?

Select Y2 and Original Software in Updater, then follow the Y2 restore steps.

What if JJ Launcher is not listed?

Do not force a Y1 package. Check the project releases and the troubleshooting guide.
