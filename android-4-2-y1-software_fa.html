Android 4.2 Y1 install steps

  1. Innioasis Updater CE را در رایانه خود باز کنید (اگر به برنامه نیاز دارید، دریافت Updater CE). تنظیم کنید مدل دستگاه به Y1.
  2. انتخاب کنید Android 4.2 (Dev) در نرم‌افزار.
  3. نسخه فهرست شده برای Y1 را انتخاب کنید.
  4. کلیک کنید نصب / بازگردانی.
  5. فقط زمانی که Updater CE درخواست کرد Y1 را خاموش کنید و وصل کنید.

Is this a daily driver ROM?

This is an experimental developer ROM intended for testing and development. Feature updates are on the project's page.
