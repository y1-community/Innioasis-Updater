Solar Y1 langkah-langkah pemasangan

  1. Buka Innioasis Updater CE di komputer Anda (jika Anda memerlukan aplikasinya, Dapatkan Updater CE). Tetapkan Model perangkat untuk Y1.
  2. Pilih Solar di Perangkat lunak.
  3. Baca catatan rilis proyek dan pilih rilis Y1.
  4. Klik Pasang / Pulihkan.
  5. Matikan dan sambungkan Y1 hanya ketika perintah muncul.

Solar fitur dan ketersediaan dapat berubah. Fitur dapat berubah antar rilis, jadi periksa halaman rilis proyek dan daftar model Anda saat ini.

Pertanyaan umum

Bisakah saya kembali dari Solar ke perangkat lunak asli?

Gunakan Y1 Perangkat Lunak Asli di Updater CE. Anda tidak perlu menghapus Solar secara manual terlebih dahulu. Ikuti Y1 langkah pemulihan.

Bisakah saya memasang entri Solar Y2 pada pemutar ini?

Tidak. Pertahankan pemutar Y1 pada entri Y1 dan periksa modelnya sebelum memasang.

Di mana saya harus memeriksa fitur Solar saat ini?

Baca catatan rilis sebelum memilih rilis.

Butuh penjelasan Updater yang lebih luas?

Lihat Panduan Pembaruan Windows, macOS, dan Linux sebelum memulai, terutama jika Y1 tidak terdeteksi.
