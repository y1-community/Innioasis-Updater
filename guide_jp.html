Innioasis Updater CE を使ってみる

すべての Innioasis および Timmkoo オーディオ プレーヤーで動作します。コンピュータに Innioasis Updater CE をインストールし、モデルと必要なソフトウェアを選択して、画面の指示に従います。

    Updater CE を入手完全な書面によるチュートリアル

    Innioasis Updater CEを取得

    Innioasis アップデーター CE は、プレーヤーに公式アップデートとコミュニティ ソフトウェアをインストールするアプリです。音楽と設定を保持し、Windows、macOS、Linux 上で実行できます。

    窓

    インストーラーをダウンロードして実行し、完了したら PC を再起動します。

    ドライバーを入手するアップデータ CE をダウンロード

    Windows によってアプリの実行が停止されたり、起動されない場合は、[設定] を開き、[プライバシーとセキュリティ] → [Windows セキュリティ] → [アプリとブラウザー コントロール] をクリックして、スマート アプリ コントロールをオフにしてください。 Smart App Control は現在、Epic Overlay Service (Fortnite で使用) などの人気のあるアプリケーションに影響を与えています。Updater CE は安全で、使用が検証されています。 Windows ではアプリが起動しませんか?ヘルプ

    インストール後、PC を再起動します。ドライバーのヘルプは、 Windows セットアップに関するメモ.

    macOS

    アップデータ CE をダウンロード

    初めてアプリを実行する際にMacでブロックされた場合は、「システム設定」を開き、「プライバシーとセキュリティ」をクリックして、「セキュリティ」まで下にスクロールし、 とにかく開くをクリックしてください。FinderでアプリをControlキーを押しながらクリック（または右クリック）して「開く」を選択することもできます。

    macOS Ventura 以降を搭載した Intel および Apple Silicon Mac で動作します。

    Linux

    Intel および AMD システム用の AppImage をダウンロードし、実行可能にして実行します。

    Intel/AMD 用の AppImage をダウンロード

    Linux セットアップに関するメモ

    プレーヤー、データを伝送する USB データ ケーブル (充電専用ケーブルでは取り付けられません)、そして数分が必要です。 Updater CE で完了と表示されるまで、ケーブルを接続したままにしてください。

    モデルとソフトウェアを選択してください

    1. デバイスモデル: プレーヤーに印刷されているモデルを選択し、 Y1 または Y2。あるモデル用に作成されたソフトウェアを他のモデルにインストールすることはできません。
    2. ソフトウェアとリリース: モデルにリストされているオリジナル ソフトウェア Rockbox、Solar、JJ Launcher、Inniclassic、Y2Player、または Koensayr を選択し、リリースを選択します。安定したものを選択するのが安全です。
    3. インストール： クリック インストール / 復元、プレーヤーの電源を完全にオフにし、Updater CE が要求した場合にのみ USB ケーブルを接続します。
    4. 仕上げる： 成功メッセージが表示されるまでプレーヤーとケーブルを放置し、接続を解除してプレーヤーを起動します。

    2.0.0 より前のオリジナル ソフトウェアとともに出荷された Y1 プレーヤーには、 デバイス Type B。他の人はデフォルトの Type A をそのまま使用します。

    元のソフトウェアに戻る

    カスタム ソフトウェアは元に戻すことができます。 Updater CE でモデルを選択し、 純正ソフトウェア、安定したリリースを選択して実行します インストール / 復元 同じように。手動で削除するものはありません。

    Y1 復元ガイドY2 復元ガイド

    USB プロンプトが表示される前にフラッシュが停止する場合は、まずケーブル、プラットフォームの設定、モデルを確認してください。見る トラブルシューティング 修正するには、 Y1 および Y2 リカバリ ガイド 動力と車輪の故障、そして SP Flash Tool 高度な回復のために。

    Windows ではアプリが起動しませんか?スマート アプリ コントロールの回避策

    Windows Defender SmartScreen または Smart App Control は、署名の評価が伝播する前に、新しくダウンロードされたコミュニティ アプリケーションをブロックできます。 Smart App Control は現在、Epic Overlay Service (Fortnite で使用) などの人気のあるアプリケーションに影響を与えています。Updater CE は安全で、使用が検証されています。 Smart App Control をオフにすると、Updater CE が正常に開いて実行できるようになります。

    1. 開く 設定 Windows PC 上で ( Win + I).
    2. クリック プライバシーとセキュリティ 左側のサイドバーで をクリックし、 Windows セキュリティ.
    3. クリック アプリとブラウザの制御.
    4. 下 スマートアプリコントロール、 クリック スマートアプリコントロールの設定.
    5. トグルを次のように設定します オフ Updater CE の起動を許可します。

    Edge経由でダウンロードしましたか? Edge がダウンロード自体をブロックする場合は、[その他のオプション] ボタン (…) → 保つ → もっと見る → とにかく保管してください.

    後でスマート アプリ コントロールを再度有効にします。 スマート アプリ コントロールをオンに戻したい場合は、次の Windows レジストリから再度有効にすることができます。 HKEY_LOCAL_MACHINE\SYSTEM\CurrentControlSet\Control\CI\Policy 設定により VerifiedAndReputablePolicyState 支援先: 1 (オン) または 2 （評価モード）して再起動します。
