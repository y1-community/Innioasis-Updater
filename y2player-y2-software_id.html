Y2Player langkah-langkah pemasangan

  1. Buka Innioasis Updater CE di komputer Anda (jika Anda memerlukan aplikasinya, Dapatkan Updater CE). Tetapkan Model perangkat untuk Y2.
  2. Pilih Y2Player di Perangkat lunak.
  3. Pilih rilis yang terdaftar untuk Y2.
  4. Klik Pasang / Pulihkan.
  5. Matikan dan sambungkan Y2 pada perintah langsung.

Beberapa Y2 paket instalasi penuh menggunakan rom_y2.zip. Biarkan Updater memilih paket bila memungkinkan.

Pertanyaan umum

Bisakah saya kembali ke perangkat lunak asli?

Ya. Pilih Y2 dan Perangkat Lunak Asli di Updater CE, lalu ikuti Panduan pemulihan Y2.

Bisakah saya menggunakan ini pada Y1?

Tidak. Halaman ini untuk entri Y2Player Y2. Pisahkan paket Y1 dan Y2.

Bagaimana jika Y2 tidak terdeteksi?

Periksa pengaturan platform, kabel, status mati, pemilihan model, dan waktu. Gunakan pemecahan masalah sebelum mencoba pemulihan manual.
