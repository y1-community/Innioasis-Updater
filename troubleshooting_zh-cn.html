返回正常引导检查固件

它在 USB 提示符之前停止

这是计算机问题，而不是电缆问题。检查您的型号。再次解压文件。然后尝试 安装 / 恢复。如果发布列表为空，则打开 固件目录.

无法连接到播放器

  1. 完全关闭正确的 Y1 或 Y2 的电源。
  2. 拔下电缆，关闭其他闪存或 Android 工具，然后重新开始安装。
  3. 仅当更新程序表示已准备就绪时才连接。
  4. 如果可能，请直接在计算机中使用短的 USB 数据线，而不是集线器。
  5. 在 Windows 上，重新安装 MediaTek 驱动程序并重新启动。在 Linux 上，检查 USB/serial 权限。

检测到播放器但闪光失败

停在这里。不要尝试不同的模型。关闭其他工具，检查您选择了正确的Y1或Y2，如果播放器无法启动，请使用匹配的原始软件。 SP Flash Tool 和 MTKClient 如果您需要的话，它们也包含在内，并且文件位于 固件页面.

Windows 驱动程序注释

由于核心隔离，某些 Windows 安装会阻止 MediaTek 驱动程序。在更改内存完整性之前，请遵循当前的 Windows 安全指南，并在完成后将其重新打开（如果系统允许）。
