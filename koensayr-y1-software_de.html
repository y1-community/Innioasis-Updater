Koensayr Y1 Installationsschritte

  1. Öffnen Sie Innioasis Updater CE auf Ihrem Computer (wenn Sie die App benötigen, Updater CE holen). Satz Gerätemodell an Y1.
  2. Wählen Sie Koensayr In Software.
  3. Wählen Sie die aufgeführte Version Y1 aus.
  4. Klicken Sie Installieren / Wiederherstellen.
  5. Schalten Sie das Y1 nur aus und schließen Sie es an, wenn Updater CE dazu fragt.

FAQ

Kann ich die ursprüngliche Y1-Software wiederherstellen?

Ja. Wählen Sie Y1 und Originalsoftware in Updater CE. Siehe die Y1 Aktien-Software-Seite für die vollständige Wiederherstellungsroute.

Was sollte ich überprüfen, wenn es fehlschlägt?

Überprüfen Sie Modell, Release, Kabel, Plattform-Setup und ob der Player vor der Aufforderung angeschlossen war. Dann verwenden Fehlerbehebung.

Gibt es ein Koensayr Y2-Paket?

Der aktuelle Build ist für Y1. Verwenden Sie es nicht auf einem Y2, es sei denn, das Projekt veröffentlicht eine separate Version dafür.

Beginnen Sie mit der Computereinrichtung

Updater funktioniert unter Windows, macOS und Linux, nachdem die Plattformeinrichtung abgeschlossen ist. Lesen Sie die allgemeiner Leitfaden zuerst.
