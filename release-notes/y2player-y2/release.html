Y2Player v1.0

This is the first public release of Y2Player.

Y2Player is an offline music player and launcher replacement for the Innioasis Y2, designed to provide a fast, reliable, and iPod-like music experience while preserving the device's original hardware controls.

Installation

Please follow the installation instructions in the repository README.

Y2Player is installed by building and flashing a modified system.img. Do not simply install the APK manually, as this will not replace the stock launcher or provide the intended experience.

The README includes:

  • required files
  • build instructions
  • flashing instructions
  • important safety warnings
  • known limitations

Please read the instructions carefully before flashing your device.

Feedback

As this is the first release, bug reports and feedback are greatly appreciated. If you encounter any issues, please open a GitHub issue and include as much information as possible, along with an exported diagnostic log if available.

Thank you for trying Y2Player!

Updating to Y2Player Release

The same steps install this release for the first time or replace the build already on the player. Back up your music before you start.

  1. Check the model and type

    Confirm the player is an Innioasis Y2 before downloading. Y1 players come in two hardware revisions, Type A (software 2.0.0 or later) and Type B (earlier software); the two ROMs are not interchangeable.

  2. Download the package built for your computer

    Use Updater CE for the guided route, or download the portable package for Windows, macOS or Linux from this page. The release's own ZIP is also listed for manual flashing.

  3. Connect the player while it is switched off

    Use a data-capable USB cable and connect the player only when the installer asks. Keep it connected until the flash reports success.

  4. Verify the version after it reboots

    Open the player's Settings or About screen and check that it reports Y2Player Release.

Questions about this update

How do I update Innioasis Y2 to Y2Player Release?

Download the package for your computer from this page, or open Updater CE and choose Y2Player Release for Innioasis Y2. Connect the player while it is switched off, then let the installer finish and let the player reboot.

Is Y2Player Release the latest Y2Player release?

The release list on this page is ordered newest first, so the top entry is the latest published build. Preview and nightly builds are labelled as such.

Can I install Y2Player Release from another computer?

Yes. Download the ZIP here, copy it to the computer that can talk to the player, and follow the install guide there. The package is self-contained.
