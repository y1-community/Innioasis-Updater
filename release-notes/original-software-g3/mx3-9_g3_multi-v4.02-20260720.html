Install

  1. Download rom_g3.zip (every numbered volume if the release has more than one, then cat rom_g3.zip.* > rom_g3.zip).
  2. Unzip it. Keep the scatter file next to the images.
  3. Open SP Flash Tool, choose Download Only, load the scatter file from the archive and flash.
  4. Or use Innioasis Updater CE: https://innioasis.app/guide.html

This wipes the player. Back up music and recordings first.
