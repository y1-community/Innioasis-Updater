🎧 Bluetooth Connection & Pairing

Bluetooth headphone connection testing has been successfully completed, and it works perfectly!

[!CAUTION] ⚠️ Important Security Permission Note If you encounter a security-related error message when trying to connect after pairing, you must grant the secure settings permission via ADB by running the following script:

adb shell pm grant com.themoon.y1 android.permission.WRITE_SECURE_SETTINGS
