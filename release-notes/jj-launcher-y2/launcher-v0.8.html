🚀 What's New in v0.8

🎨 1. New Theme Engine Implemented

  • A brand-new theme engine has been added to the launcher!
  • You can easily design and customize your own themes using the web editor below:

    👉 Go to Theme Editor

🔤 2. Fixed Case-Insensitive Song Sorting Bug

  • Fixed an issue where uppercase and lowercase song titles were not sorting properly in alphabetical order.

    (Special thanks to Whimsical_Sandwich for reporting this issue!)

🖥️ 3. Server Connection Page UI Redesign

  • Overhauled and improved the User Interface (UI) for the server connection page for a cleaner look.

📂 4. Added Folder Playback Feature

  • You can now browse and play your music files directly by folder structure.

❤️ 5. Added Favorites Feature

  • Added a bookmarking function so you can easily save and access your favorite songs.

🔄 6. Added Rockbox Booting Feature

  • Added the ability to boot directly into Rockbox from the launcher.

[!WARNING] ⚠️ Important Notice regarding Rockbox Booting Please note that an additional script is required if you want to safely return to the launcher from Rockbox.
