This is a bare android firmware for modifications to the Innioasis Y2 - it includes flash_tool.exe to install it from Windows systems

This is not suitable for everyday use - the original firmware is available here

Disconnect your Y2 from USB, fully power it off using a paper clip or pin between the headphone jack and charging port

Run flash_tool.exe

Select Format All + Download from the dropdown that reads "Download"

Click Download (green arrow)

Connect your Y2 and wait for install to finish.
