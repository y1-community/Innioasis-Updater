Another round of Reddit-reported bugs, mostly around the Music library screens.

Fixed

  • "Albums" was completely broken — tapping into it either showed a black screen, froze, or silently bounced back to the Music menu. The row renderer was doing a full library scan plus a synchronous MediaMetadataRetriever lookup on the UI thread for every row, every time it scrolled into view — fine for a handful of albums, but an ANR/freeze risk for a real-sized library. Cover art lookup now runs on a background thread (placeholder shown immediately, real art swapped in once ready), and the per-album file lookup is precomputed once instead of rescanning the whole library per row.
  • Videos screen: nothing could be selected or played — rows were added to the list but never given initial focus, so spinning the wheel had no "current" row to move from (you'd hear the click sound but nothing would highlight or respond). Now the first row gets focus like every other list in the app.
  • Some FLAC albums showed no cover art in "Albums" (but did show it correctly on Now Playing/Cover Flow) — the Albums screen's cover lookup skipped embedded art entirely for FLAC files with no fallback, so only albums with a folder cover.jpg/folder.jpg showed anything. It now uses the same dedicated FLAC metadata parser Now Playing already relies on.
  • Confusion around Last.fm scrobbling / "where's my .scrobbler.log?" — the local scrobble log was silently gated behind the "Scrobble to Last.fm" toggle (off by default) even though it's just a private text file that needs no account. It's now written automatically for every played track, no setup required; the Settings toggle (renamed Sync Scrobbles to Last.fm) now only controls whether scrobbles are also sent to a real Last.fm account. Also documented in the README that .scrobbler.log is a dotfile and hidden by default in most file managers.
  • Cover art looking noticeably blurry/soft while panning on the Main Menu and Music menu — cover art was always decoded at half resolution regardless of its actual size, which compounded badly for anyone using smaller (e.g. 300×300) cover images against a pan panel rendered near full screen height. Downsampling now only kicks in for genuinely large source images; small covers are decoded at full resolution. README now recommends 600×600 minimum, 1000×1000+ ideally.

Install

  • rom.zip — flash via the Innioasis Updater, no ADB required. Must keep the filename exactly rom.zip.
  • InniClassic-1.3.1.apk — install over an existing JJ Launcher / InniClassic install via adb install InniClassic-1.3.1.apk.

Updating to Inniclassic 1.3.1

The same steps install this release for the first time or replace the build already on the player. Back up your music before you start.

  1. Check the model and type

    Confirm the player is an Innioasis Y1 before downloading. Y1 players come in two hardware revisions, Type A (software 2.0.0 or later) and Type B (earlier software); the two ROMs are not interchangeable.

  2. Download the package built for your computer

    Use Updater CE for the guided route, or download the portable package for Windows, macOS or Linux from this page. The release's own ZIP is also listed for manual flashing.

  3. Connect the player while it is switched off

    Use a data-capable USB cable and connect the player only when the installer asks. Keep it connected until the flash reports success.

  4. Verify the version after it reboots

    Open the player's Settings or About screen and check that it reports Inniclassic 1.3.1.

Questions about this update

How do I update Innioasis Y1 to Inniclassic 1.3.1?

Download the package for your computer from this page, or open Updater CE and choose Inniclassic 1.3.1 for Innioasis Y1. Connect the player while it is switched off, then let the installer finish and let the player reboot.

Is Inniclassic 1.3.1 the latest Inniclassic release?

The release list on this page is ordered newest first, so the top entry is the latest published build. Preview and nightly builds are labelled as such.

Can I install Inniclassic 1.3.1 from another computer?

Yes. Download the ZIP here, copy it to the computer that can talk to the player, and follow the install guide there. The package is self-contained.
