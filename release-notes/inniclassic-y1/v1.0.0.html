JJ Launcher Classic Version 1.0.0

Inniclassic 1.0.0 update for the Innioasis Y1. Download it below, or let Updater CE install it for you.

A classic-style Y1 Software.

v1.0.0Y12026-07-21FabianZettl/inniclassic
Get it in Updater CEFirmware Downloads

First public release. Based on JJ Launcher 0.11.

Added

  • Bundled "iPod Classic" theme: two-pane Main Menu and Music menu with a full-bleed panning album cover, angled Now Playing cover with reflection, redesigned Artist/Album lists (icon-free, large covers, "All Songs" per artist), a text search screen, and system-wide bold Nimbus Sans typography
  • Last.fm scrobbling: local Rockbox-style .scrobbler.log + live API scrobbling with browser-based login
  • Music Quiz: first version of the classic iPod Music Quiz mini-game, styled after the original's "Fruitiger Aero" look
  • OGG Vorbis playback and library support (including auto-detection of Opus-encoded files mislabeled as .ogg)
  • Main Menu shortcuts for Music Quiz, Podcasts, Audiobooks, Folders, Years, Recently Added, My Favorites

Fixed

  • Duplicate songs in album track lists after interrupted scans
  • Missing album art in Artist -> Albums lists (folder cover.jpg/folder.jpg fallback)
  • OGG files not appearing in the library
  • OOM crash loop scanning large libraries
  • Album art forced to true 1:1 crop

Notes

  • Currently only tested/available for the Innioasis Y1, on System Software 2.1.9
  • Prerequisite: device must already be running JJ Launcher (installed via the Innioasis Updater) - this release replaces the launcher app itself, not the device firmware
  • Install with adb install -r JJLauncherClassic-1.0.0.apk
  • This APK is debug-signed (no production keystore has been set up yet for this fork)

See CHANGELOG.md for the full list.

Updating to Inniclassic 1.0.0

The same steps install this release for the first time or replace the build already on the player. Back up your music before you start.

  1. Check the model and type

    Confirm the player is an Innioasis Y1 before downloading. Y1 players come in two hardware revisions, Type A (software 2.0.0 or later) and Type B (earlier software); the two ROMs are not interchangeable.

  2. Download the package built for your computer

    Use Updater CE for the guided route, or download the portable package for Windows, macOS or Linux from this page. The release's own ZIP is also listed for manual flashing.

  3. Connect the player while it is switched off

    Use a data-capable USB cable and connect the player only when the installer asks. Keep it connected until the flash reports success.

  4. Verify the version after it reboots

    Open the player's Settings or About screen and check that it reports Inniclassic 1.0.0.

Questions about this update

How do I update Innioasis Y1 to Inniclassic 1.0.0?

Download the package for your computer from this page, or open Updater CE and choose Inniclassic 1.0.0 for Innioasis Y1. Connect the player while it is switched off, then let the installer finish and let the player reboot.

Is Inniclassic 1.0.0 the latest Inniclassic release?

The release list on this page is ordered newest first, so the top entry is the latest published build. Preview and nightly builds are labelled as such.

Can I install Inniclassic 1.0.0 from another computer?

Yes. Download the ZIP here, copy it to the computer that can talk to the player, and follow the install guide there. The package is self-contained.
