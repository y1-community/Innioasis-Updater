Y2 Rockbox Beta v0.1.0 for the Innioasis Y2.

This beta uses the physically tested V88 firmware base. The release filename is new, but the firmware ZIP is byte-for-byte identical to the tested V88 package.

Important

Flashing uses InnioasisUpdater 1.1.2 in full format-download mode and erases the complete player. Back up internal storage, microSD content, settings, playlists, and the complete .rockbox folder before flashing. Keep the official Y2 stock-recovery package available.

Read README-FIRST.txt and the illustrated PDF guide before starting. Verify every download against SHA256SUMS.txt.

Physically tested

  • Rockbox and Stock cold-boot routes
  • Boot Settings save, verification, restart, and repeated cold boots
  • 15-minute audio playback and hardware controls
  • Sleep and wake
  • Theme selection and persistence
  • Internal-storage and microSD playback
  • USB storage transfer, safe eject, and automatic Rockbox return
  • Normal power off
  • Official-stock rollback

Beta limitations

  • Bluetooth playback is untested.
  • The both-volume fastboot chord did not open fastboot; do not rely on it.
  • Date/time changes did not persist during testing; the relationship to stock firmware is unresolved.
  • SNAZZ3 deliberately uses visible 30-pixel margins. This is theme layout, not display scaling.
  • The Windows updater executable is unsigned; verify its SHA-256 before running it.

Updating to Rockbox-Y2 v0.1.0

The same steps install this release for the first time or replace the build already on the player. Back up your music before you start.

  1. Check the model and type

    Confirm the player is an Innioasis Y2 before downloading. Y1 players come in two hardware revisions, Type A (software 2.0.0 or later) and Type B (earlier software); the two ROMs are not interchangeable.

  2. Download the package built for your computer

    Use Updater CE for the guided route, or download the portable package for Windows, macOS or Linux from this page. The release's own ZIP is also listed for manual flashing.

  3. Connect the player while it is switched off

    Use a data-capable USB cable and connect the player only when the installer asks. Keep it connected until the flash reports success.

  4. Verify the version after it reboots

    Open the player's Settings or About screen and check that it reports Rockbox-Y2 v0.1.0.

Questions about this update

How do I update Innioasis Y2 to Rockbox-Y2 v0.1.0?

Download the package for your computer from this page, or open Updater CE and choose Rockbox-Y2 v0.1.0 for Innioasis Y2. Connect the player while it is switched off, then let the installer finish and let the player reboot.

Is Rockbox-Y2 v0.1.0 the latest Rockbox-Y2 release?

The release list on this page is ordered newest first, so the top entry is the latest published build. Preview and nightly builds are labelled as such.

Can I install Rockbox-Y2 v0.1.0 from another computer?

Yes. Download the ZIP here, copy it to the computer that can talk to the player, and follow the install guide there. The package is self-contained.

Which file do I download for Windows, macOS or Linux?

Each portable package in the download section is built for one computer. The guide pages linked under "Install on your computer" name the exact file and its size.
