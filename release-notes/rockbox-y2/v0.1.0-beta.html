Y2 Rockbox Beta v0.1.0 for the Innioasis Y2.

This beta uses the physically tested V88 firmware base. The release filename is new, but the firmware ZIP is byte-for-byte identical to the tested V88 package.

Important

Flashing uses InnioasisUpdater 1.1.2 in full format-download mode and erases the complete player. Back up internal storage, microSD content, settings, playlists, and the complete .rockbox folder before flashing. Keep the official Y2 stock-recovery package available.

Read README-FIRST.txt and the illustrated PDF guide before starting. Verify every download against SHA256SUMS.txt.

Physically tested

  • Rockbox and Stock cold-boot routes
  • Boot Settings save, verification, restart, and repeated cold boots
  • 15-minute audio playback and hardware controls
  • Sleep and wake
  • Theme selection and persistence
  • Internal-storage and microSD playback
  • USB storage transfer, safe eject, and automatic Rockbox return
  • Normal power off
  • Official-stock rollback

Beta limitations

  • Bluetooth playback is untested.
  • The both-volume fastboot chord did not open fastboot; do not rely on it.
  • Date/time changes did not persist during testing; the relationship to stock firmware is unresolved.
  • SNAZZ3 deliberately uses visible 30-pixel margins. This is theme layout, not display scaling.
  • The Windows updater executable is unsigned; verify its SHA-256 before running it.
