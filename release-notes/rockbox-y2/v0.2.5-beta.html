Rockbox Y2 V2.5

V2.5 updates the Y2 dual-boot firmware to the official Innioasis Stock 3.2FM baseline while retaining Rockbox and Stock boot routes.

What changed from V2

  • Stock mode is updated to version 3.2 from the 3.2FM firmware release.
  • Clean installs default to MacClassic-Dark with a black Rockbox title screen.
  • Boot presentation and route handoff were requalified to prevent persistent

    upper-screen artifacts.

  • The Community Updater asset is now a complete 3.2FM-based full-ROM package,

    compatible with the public updater's clean-install route.

Qualified V2.5 behavior

The five V2.5 firmware images have passed the full hands-on matrix on macOS and Windows:

  • Clean, responsive Rockbox root in about 28 seconds on normal cold boots.
  • Clean dark Rockbox title with no persistent upper artifacts.
  • Automatic screen timeout, centre wake, and power-button sleep/wake.
  • USB-storage mount, safe eject, clean return, and foreground retention.
  • Boot Settings switching between Rockbox and Stock.
  • Responsive Stock root reporting version 3.2 from Stock 3.2FM.
  • No microSD card required for installation or normal boot testing.

The exact public full-ROM archive passed clean Stock 3.2FM installation and the complete functional matrix on both macOS and Windows.

Important installation behavior

V2.5 performs a clean full installation and erases internal user data. Back up first. On macOS, public Updater CE hands the install to the Innioasis Y2 Install Tool. On Windows, Updater CE uses its full Y2 installation route. Follow every connection prompt and wait for an explicit completion message.

Updating to Rockbox-Y2 v0.2.5-beta

The same steps install this release for the first time or replace the build already on the player. Back up your music before you start.

  1. Check the model and type

    Confirm the player is an Innioasis Y2 before downloading. Y1 players come in two hardware revisions, Type A (software 2.0.0 or later) and Type B (earlier software); the two ROMs are not interchangeable.

  2. Download the package built for your computer

    Use Updater CE for the guided route, or download the portable package for Windows, macOS or Linux from this page. The release's own ZIP is also listed for manual flashing.

  3. Connect the player while it is switched off

    Use a data-capable USB cable and connect the player only when the installer asks. Keep it connected until the flash reports success.

  4. Verify the version after it reboots

    Open the player's Settings or About screen and check that it reports Rockbox-Y2 v0.2.5-beta.

Questions about this update

How do I update Innioasis Y2 to Rockbox-Y2 v0.2.5-beta?

Download the package for your computer from this page, or open Updater CE and choose Rockbox-Y2 v0.2.5-beta for Innioasis Y2. Connect the player while it is switched off, then let the installer finish and let the player reboot.

Is Rockbox-Y2 v0.2.5-beta the latest Rockbox-Y2 release?

The release list on this page is ordered newest first, so the top entry is the latest published build. Preview and nightly builds are labelled as such.

Can I install Rockbox-Y2 v0.2.5-beta from another computer?

Yes. Download the ZIP here, copy it to the computer that can talk to the player, and follow the install guide there. The package is self-contained.

Which file do I download for Windows, macOS or Linux?

Each portable package in the download section is built for one computer. The guide pages linked under "Install on your computer" name the exact file and its size.
