Y2 Rockbox Beta V2

Beta V2 is a state-preserving update for Innioasis Y2 players on the official Stock 3.1.7 lineage. This corrected release has passed separate end-to-end macOS and Windows updater qualifications, complete readback verification, and the full physical functional matrix.

Manual-download release: the files below are public for users who want to download and verify them manually. Direct installation through the public Updater CE catalogue is still pending Updater CE PR #45. Downloading a ZIP manually does not make an old or generic updater safe; use only an updater explicitly carrying the guarded Y2 Class A route.

Highlights since Beta V1

  • Bluetooth access, pairing and A2DP playback from Rockbox and Stock.
  • Hold Previous/Next to seek; optional held-Volume track skipping.
  • Persistent time/date and independently adjustable Rockbox wheel vibration.
  • Stable Rockbox and Stock USB-storage lifecycle.
  • Cleaner boot presentation and reliable saved Rockbox/Stock routing.
  • Centre wake, long-Centre Now Playing context menu, and improved Back/Database navigation.
  • PictureFlow recovery and functional album carousel.

Physical acceptance

Both platform routes began from freshly restored official Stock 3.1.7, wrote only UBOOT, BOOTIMG, RECOVERY, LOGO, and ANDROID, and completed mandatory readback verification. After the required complete unplug and one unplugged pinhole reset, Rockbox reached a clean responsive root in 28 seconds with no upper artifacts. Playback, controls, sleep/wake, USB, Stock, Boot Settings, saved routes, and shutdown passed.

Known limitation and Beta V3

The final power-down animation can look imperfect; shutdown itself works. Beta V3 is expected to cover that presentation polish plus lyrics/theme diagnostics, high-resolution FLAC stability, DAC/wired-audio qualification, PictureFlow polish, and database/playlist presentation controls.

Updating to Rockbox-Y2 v0.2.0-beta

The same steps install this release for the first time or replace the build already on the player. Back up your music before you start.

  1. Check the model and type

    Confirm the player is an Innioasis Y2 before downloading. Y1 players come in two hardware revisions, Type A (software 2.0.0 or later) and Type B (earlier software); the two ROMs are not interchangeable.

  2. Download the package built for your computer

    Use Updater CE for the guided route, or download the portable package for Windows, macOS or Linux from this page. The release's own ZIP is also listed for manual flashing.

  3. Connect the player while it is switched off

    Use a data-capable USB cable and connect the player only when the installer asks. Keep it connected until the flash reports success.

  4. Verify the version after it reboots

    Open the player's Settings or About screen and check that it reports Rockbox-Y2 v0.2.0-beta.

Questions about this update

How do I update Innioasis Y2 to Rockbox-Y2 v0.2.0-beta?

Download the package for your computer from this page, or open Updater CE and choose Rockbox-Y2 v0.2.0-beta for Innioasis Y2. Connect the player while it is switched off, then let the installer finish and let the player reboot.

Is Rockbox-Y2 v0.2.0-beta the latest Rockbox-Y2 release?

The release list on this page is ordered newest first, so the top entry is the latest published build. Preview and nightly builds are labelled as such.

Can I install Rockbox-Y2 v0.2.0-beta from another computer?

Yes. Download the ZIP here, copy it to the computer that can talk to the player, and follow the install guide there. The package is self-contained.

Which file do I download for Windows, macOS or Linux?

Each portable package in the download section is built for one computer. The guide pages linked under "Install on your computer" name the exact file and its size.
