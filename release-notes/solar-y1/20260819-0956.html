Solar is a custom firmware and launcher for the Innioasis Y1 — a full interface replacement with podcast downloads, a global quick menu, Reach (Deezer + Soulseek), Stem Player (stem separation powered by Lalal.ai), Y1 theme support, and Rockbox-Y1 on the same ROM (switch without reboot).

Features

  • 🎛️ Stem Player — Gen1-style vocal/drums/bass/melody mixing on the wheel; separate local tracks with Lalal.ai stem separation (cache local stems; mash up 1–3 songs)
  • 🎵 Reach — search, play and download music from Deezer and Soulseek
  • 🎙️ Podcasts — search and download episodes to your Y1 over the internet
  • ⚡ Quick menu — global context menu for playback, queue, Wi‑Fi, Bluetooth, and more
  • 🎨 Y1 themes — install and apply themes from the original Y1 firmware

Assets

  • app-release.apk — signed Solar launcher
  • rom.zip — Y1 type A ATA firmware (2.0.0+, MT6572, SP Flash Tool included)
  • rom_type_b.zip — Y1 type B ATA firmware (before 2.0.0, MT6572, SP Flash Tool included)
  • rom_y2.zip — Y2 ATA firmware (MT6582, desparsed ext4, permissive root)
  • rom_a5.zip — Timmkoo A5 ATA firmware (MT6572, A5 keylayouts, family pin, SP Flash Tool included, no Rockbox bake)

Updating to Solar 20260819-0956

The same steps install this release for the first time or replace the build already on the player. Back up your music before you start.

  1. Check the model and type

    Confirm the player is an Innioasis Y1 before downloading. Y1 players come in two hardware revisions, Type A (software 2.0.0 or later) and Type B (earlier software); the two ROMs are not interchangeable.

  2. Download the package built for your computer

    Use Updater CE for the guided route, or download the portable package for Windows, macOS or Linux from this page. The release's own ZIP is also listed for manual flashing.

  3. Connect the player while it is switched off

    Use a data-capable USB cable and connect the player only when the installer asks. Keep it connected until the flash reports success.

  4. Verify the version after it reboots

    Open the player's Settings or About screen and check that it reports Solar 20260819-0956.
