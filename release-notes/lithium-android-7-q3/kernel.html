Lithium 5 Kernel Beta v0.06.04.25

This is a beta release of the Lithium 5 Android kernel & ramdisk, with built-in Magisk support.

You can use this kernel with any other Android 5 ROM for Timmkoo devices, and you are welcome to modify the kernel and contribute with any changes.

If you have any issues, feel free to join the discussion, or join the Discord server.

Full Changelog: https://github.com/NoahDomingues/Lithium/commits/Kernel

Updating to Lithium (Android 7) Kernel

The same steps install this release for the first time or replace the build already on the player. Back up your music before you start.

  1. Check the model and type

    Confirm the player is an Timmkoo Q3 before downloading. Y1 players come in two hardware revisions, Type A (software 2.0.0 or later) and Type B (earlier software); the two ROMs are not interchangeable.

  2. Download the package built for your computer

    Use Updater CE for the guided route, or download the portable package for Windows, macOS or Linux from this page. The release's own ZIP is also listed for manual flashing.

  3. Connect the player while it is switched off

    Use a data-capable USB cable and connect the player only when the installer asks. Keep it connected until the flash reports success.

  4. Verify the version after it reboots

    Open the player's Settings or About screen and check that it reports Lithium (Android 7) Kernel.

Questions about this update

How do I update Timmkoo Q3 to Lithium (Android 7) Kernel?

Download the package for your computer from this page, or open Updater CE and choose Lithium (Android 7) Kernel for Timmkoo Q3. Connect the player while it is switched off, then let the installer finish and let the player reboot.

Is Lithium (Android 7) Kernel the latest Lithium (Android 7) release?

The release list on this page is ordered newest first, so the top entry is the latest published build. Preview and nightly builds are labelled as such.

Can I install Lithium (Android 7) Kernel from another computer?

Yes. Download the ZIP here, copy it to the computer that can talk to the player, and follow the install guide there. The package is self-contained.
