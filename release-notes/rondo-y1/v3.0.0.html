Rondo 3.0.0

A lightweight, custom audio operating system for the Innioasis Y1.

For the Innioasis Y1, Type A. A new firmware without the stock firmware's root backdoors.

  • The root backdoors are gone. Innioasis's own firmware, and so every Rondo firmware before this one, ran three programs as root that nothing on the Y1 needs:
    • aggdll, an app pusher's agent: a hidden su and a silent app installer;
    • wifi_init, a downloader it starts, which checks in with a server and runs what it downloads as root. That server doesn't answer today;
    • SPWall (libsp.so), which runs commands as root for other programs.

This firmware leaves all three out, with what they left behind, and puts Android's own am back.

  • A Y1 installed again runs the firmware's own Rondo, not an older update it took over Wi-Fi before.

How to get it

  • Innioasis Updater CE: Y1, Type A, Rondo, 3.0.0. Turn on Keep my settings so your settings, Wi-Fi networks, server connection and paired headphones stay. Your music on the card is never touched.
  • Software update on 2.0 shows 3.0.0 but can't install it, because the firmware itself has to change.

Files: rondo-3.0.0.rondo is the signed update bundle; rom.zip (the firmware) and updater.png are added by the release workflow a few minutes after publishing. Everything else: changelog.
