Rondo 3.0.0

For the Innioasis Y1, Type A. A new firmware without the stock firmware's root backdoors.

  • The root backdoors are gone. Innioasis's own firmware, and so every Rondo firmware before this one, ran three programs as root that nothing on the Y1 needs:
    • aggdll, an app pusher's agent: a hidden su and a silent app installer;
    • wifi_init, a downloader it starts, which checks in with a server and runs what it downloads as root. That server doesn't answer today;
    • SPWall (libsp.so), which runs commands as root for other programs.

This firmware leaves all three out, with what they left behind, and puts Android's own am back.

  • A Y1 installed again runs the firmware's own Rondo, not an older update it took over Wi-Fi before.

How to get it

  • Innioasis Updater CE: Y1, Type A, Rondo, 3.0.0. Turn on Keep my settings so your settings, Wi-Fi networks, server connection and paired headphones stay. Your music on the card is never touched.
  • Software update on 2.0 shows 3.0.0 but can't install it, because the firmware itself has to change.

Files: rondo-3.0.0.rondo is the signed update bundle; rom.zip (the firmware) and updater.png are added by the release workflow a few minutes after publishing. Everything else: changelog.

Updating to Rondo 3.0.0

The same steps install this release for the first time or replace the build already on the player. Back up your music before you start.

  1. Check the model and type

    Confirm the player is an Innioasis Y1 before downloading. Y1 players come in two hardware revisions, Type A (software 2.0.0 or later) and Type B (earlier software); the two ROMs are not interchangeable.

  2. Download the package built for your computer

    Use Updater CE for the guided route, or download the portable package for Windows, macOS or Linux from this page. The release's own ZIP is also listed for manual flashing.

  3. Connect the player while it is switched off

    Use a data-capable USB cable and connect the player only when the installer asks. Keep it connected until the flash reports success.

  4. Verify the version after it reboots

    Open the player's Settings or About screen and check that it reports Rondo 3.0.0.

Questions about this update

How do I update Innioasis Y1 to Rondo 3.0.0?

Download the package for your computer from this page, or open Updater CE and choose Rondo 3.0.0 for Innioasis Y1. Connect the player while it is switched off, then let the installer finish and let the player reboot.

Is Rondo 3.0.0 the latest Rondo release?

The release list on this page is ordered newest first, so the top entry is the latest published build. Preview and nightly builds are labelled as such.

Can I install Rondo 3.0.0 from another computer?

Yes. Download the ZIP here, copy it to the computer that can talk to the player, and follow the install guide there. The package is self-contained.

Which file do I download for Windows, macOS or Linux?

Each portable package in the download section is built for one computer. The guide pages linked under "Install on your computer" name the exact file and its size.
