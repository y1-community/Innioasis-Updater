Rondo server 3.1.1

A lightweight, custom audio operating system for the Innioasis Y1.

server-v3.1.1Y12026-11-12jarvissax/rondo
Get it in Updater CEFirmware Downloads

A small clean-up of the Rondo server.

  • /healthz no longer sends the api number that 3.1.0 added. Nothing reads it: Rondo tells whether a server is new enough from the server's version, against the oldest server it works with. Nothing else changes, so this update is optional.

How to update

  • The admin page's Update.
  • Or by hand: docker compose -f infra/compose.home.yaml pull && docker compose -f infra/compose.home.yaml up -d (or compose.vps.yaml).

Images: ghcr.io/jarvissax/rondo-server:3.1.1 and ghcr.io/jarvissax/rondo-updater:3.1.1 (also latest). Changes: server/CHANGELOG.md.
