For the Innioasis Y1, Type A, on the Rondo 3.0 firmware. An update you can install over Wi-Fi. With your own server, update it once to Rondo server 3.1.0 (its admin page offers it); from then on, Rondo and the server update apart.

  • Downloads are about three times faster. A YouTube download now comes in four parts at once: a 10-minute 720p video took 50 seconds instead of 145, a two-hour episode about 8 minutes.
  • A download survives a dropout. When the Wi-Fi or the internet goes away for a while, the download waits and carries on where it stopped, instead of failing or starting over (Software update's download too).
  • The Y1 stays awake while a download runs, unplugged with the screen off too.
  • YouTube's pictures are back in search, the feeds and on a download's row.
  • A download's row says what it's doing: Downloading video, Downloading sound, Getting subtitles, Saving.
  • Rondo and the server have their own version numbers now. Most releases change only the Y1, so they no longer ask you to update your server. This Rondo works with Rondo server 3.1.0 or newer; with an older one, Settings › YouTube › Connection, the dashboard and the YouTube screens say Server needs an update.

How to get it

  • On Rondo 3.0.x: Settings › System › Software update, the dashboard's Overview, or the update page over USB.
  • On Rondo 2.0 or earlier: Innioasis Updater CE (Y1, Type A, Rondo 3.0.2), with Keep my settings turned on.

Files: rondo-3.0.2.rondo is the signed update bundle; rom.zip (the firmware) and updater.png are added by the release workflow a few minutes after publishing. Everything else: changelog.

Updating to Rondo 3.0.2

The same steps install this release for the first time or replace the build already on the player. Back up your music before you start.

  1. Check the model and type

    Confirm the player is an Innioasis Y1 before downloading. Y1 players come in two hardware revisions, Type A (software 2.0.0 or later) and Type B (earlier software); the two ROMs are not interchangeable.

  2. Download the package built for your computer

    Use Updater CE for the guided route, or download the portable package for Windows, macOS or Linux from this page. The release's own ZIP is also listed for manual flashing.

  3. Connect the player while it is switched off

    Use a data-capable USB cable and connect the player only when the installer asks. Keep it connected until the flash reports success.

  4. Verify the version after it reboots

    Open the player's Settings or About screen and check that it reports Rondo 3.0.2.

Questions about this update

How do I update Innioasis Y1 to Rondo 3.0.2?

Download the package for your computer from this page, or open Updater CE and choose Rondo 3.0.2 for Innioasis Y1. Connect the player while it is switched off, then let the installer finish and let the player reboot.

Is Rondo 3.0.2 the latest Rondo release?

The release list on this page is ordered newest first, so the top entry is the latest published build. Preview and nightly builds are labelled as such.

Can I install Rondo 3.0.2 from another computer?

Yes. Download the ZIP here, copy it to the computer that can talk to the player, and follow the install guide there. The package is self-contained.

Which file do I download for Windows, macOS or Linux?

Each portable package in the download section is built for one computer. The guide pages linked under "Install on your computer" name the exact file and its size.
