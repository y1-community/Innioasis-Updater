Rondo 3.0.2

A lightweight, custom audio operating system for the Innioasis Y1.

v3.0.2Y12026-11-12jarvissax/rondo
Get it in Updater CEFirmware Downloads

Download this release

Rondo 505 MB

For the Innioasis Y1, Type A, on the Rondo 3.0 firmware. An update you can install over Wi-Fi. With your own server, update it once to Rondo server 3.1.0 (its admin page offers it); from then on, Rondo and the server update apart.

  • Downloads are about three times faster. A YouTube download now comes in four parts at once: a 10-minute 720p video took 50 seconds instead of 145, a two-hour episode about 8 minutes.
  • A download survives a dropout. When the Wi-Fi or the internet goes away for a while, the download waits and carries on where it stopped, instead of failing or starting over (Software update's download too).
  • The Y1 stays awake while a download runs, unplugged with the screen off too.
  • YouTube's pictures are back in search, the feeds and on a download's row.
  • A download's row says what it's doing: Downloading video, Downloading sound, Getting subtitles, Saving.
  • Rondo and the server have their own version numbers now. Most releases change only the Y1, so they no longer ask you to update your server. This Rondo works with Rondo server 3.1.0 or newer; with an older one, Settings › YouTube › Connection, the dashboard and the YouTube screens say Server needs an update.

How to get it

  • On Rondo 3.0.x: Settings › System › Software update, the dashboard's Overview, or the update page over USB.
  • On Rondo 2.0 or earlier: Innioasis Updater CE (Y1, Type A, Rondo 3.0.2), with Keep my settings turned on.

Files: rondo-3.0.2.rondo is the signed update bundle; rom.zip (the firmware) and updater.png are added by the release workflow a few minutes after publishing. Everything else: changelog.
