An update for the 4.0 firmware: Settings › System › Software update, the dashboard or the update page. It works with Rondo server 3.1.0 or newer, as 4.0.0 does.

New

  • YouTube Music playlists download as playlists: Download playlist saves its songs and a

    playlist of them in Library › Playlists, in YouTube's order and with the playlist's cover. A song already on the card isn't downloaded twice, and downloading the playlist again brings it up to date. Deleting it asks whether its songs go too. Now Playing's options download the song playing.

  • Downloads pause and resume, one or all, videos too, and go on after a restart or a power cut.

    They wait by themselves while Wi-Fi is off, while the card is the computer's or full, and go on afterwards. The dashboard has the same controls.

  • Emoji on every keyboard, each in its app's look: Rondo's own, YouTube's and YouTube Music's,

    and WhatsApp's. Every emoji the Y1's emoji font draws, in tabs (recent ones, then Unicode's groups), with skin tones, and found by name.

  • WhatsApp's reaction bar: a message's menu starts with 👍 ❤️ 😂 😮 😢 🙏, and + opens every emoji.

Fixed

  • Voice messages that weren't sent: one sent right after another WhatsApp action (marking a chat

    read, a reaction, a text) could send garbage instead of the recording, or close WhatsApp and lose it.

  • Voice messages with a headset: the Y1 can't use a headset's microphone, and a voice message

    recorded with one held only a steady tone. With a headset in, Rondo now records from the Y1's own microphone (inside, beside the jack).

  • FM radio sounded doubled: MediaTek's chip played the radio too, a moment ahead of Rondo's own.

    Only Rondo's plays now.

  • FM radio on the speaker: choosing Speaker kept the sound in the headphones, or played only hiss.

    The radio now plays from the speaker, with a volume of its own for each output. The headphones play too: the Y1's speaker is fed from their amplifier, and they stay in as the antenna (the Output setting says so).

Updating to Rondo 4.0.1

The same steps install this release for the first time or replace the build already on the player. Back up your music before you start.

  1. Check the model and type

    Confirm the player is an Innioasis Y1 before downloading. Y1 players come in two hardware revisions, Type A (software 2.0.0 or later) and Type B (earlier software); the two ROMs are not interchangeable.

  2. Download the package built for your computer

    Use Updater CE for the guided route, or download the portable package for Windows, macOS or Linux from this page. The release's own ZIP is also listed for manual flashing.

  3. Connect the player while it is switched off

    Use a data-capable USB cable and connect the player only when the installer asks. Keep it connected until the flash reports success.

  4. Verify the version after it reboots

    Open the player's Settings or About screen and check that it reports Rondo 4.0.1.

Questions about this update

How do I update Innioasis Y1 to Rondo 4.0.1?

Download the package for your computer from this page, or open Updater CE and choose Rondo 4.0.1 for Innioasis Y1. Connect the player while it is switched off, then let the installer finish and let the player reboot.

Is Rondo 4.0.1 the latest Rondo release?

The release list on this page is ordered newest first, so the top entry is the latest published build. Preview and nightly builds are labelled as such.

Can I install Rondo 4.0.1 from another computer?

Yes. Download the ZIP here, copy it to the computer that can talk to the player, and follow the install guide there. The package is self-contained.

Which file do I download for Windows, macOS or Linux?

Each portable package in the download section is built for one computer. The guide pages linked under "Install on your computer" name the exact file and its size.
