An update for the 4.0 firmware: Settings › System › Software update, the dashboard or the update page. It works with Rondo server 3.1.0 or newer, as 4.1.1 does; it needs no server update.

New

  • Audiobooks (Library › Audiobooks): the books on the card, Continue listening first, each

    with its cover, author and time left. A book is everything in an Audiobooks folder (the stock firmware's, so its books carry over), any .m4b, or files tagged Audiobook; a folder of files is one book, its disc folders included. Books stay out of Songs, Shuffle songs, Artists, Albums, Genres and Organize. - Where you stopped is kept for every book, and a resume starts a few seconds earlier after a pause (more after a long one). - Next and Previous move by chapter (an .m4b's chapters, or each file of a folder); a book without chapters skips 30 seconds forward and 15 back. - Speed from 0.75× to 3×, the voice's pitch kept, remembered per book. - Bookmarks, Mark as finished, and Now Playing with the chapter and the time left in it and in the book. A cover.jpg in a book's folder is its cover; Library's search finds books. - Your music waits: a book plays as its own queue, and the music comes back where it was when the book ends or with Back to your music.

  • Sleep timer, for music too, in Now Playing's options: 15 to 60 minutes, or the end of the

    song or chapter, with a 10-second fade.

  • The dashboard has Audiobooks too (progress, chapters, bookmarks, speed, uploads into

    Audiobooks), and the sleep timer on its Overview.

Changed

  • Settings › Language is now above System.
  • The dashboard's Library on a phone: its buttons wrap instead of running off the screen, and

    the sections show their icons, the chosen one with its name.

Updating to Rondo 4.1.2

The same steps install this release for the first time or replace the build already on the player. Back up your music before you start.

  1. Check the model and type

    Confirm the player is an Innioasis Y1 before downloading. Y1 players come in two hardware revisions, Type A (software 2.0.0 or later) and Type B (earlier software); the two ROMs are not interchangeable.

  2. Download the package built for your computer

    Use Updater CE for the guided route, or download the portable package for Windows, macOS or Linux from this page. The release's own ZIP is also listed for manual flashing.

  3. Connect the player while it is switched off

    Use a data-capable USB cable and connect the player only when the installer asks. Keep it connected until the flash reports success.

  4. Verify the version after it reboots

    Open the player's Settings or About screen and check that it reports Rondo 4.1.2.

Questions about this update

How do I update Innioasis Y1 to Rondo 4.1.2?

Download the package for your computer from this page, or open Updater CE and choose Rondo 4.1.2 for Innioasis Y1. Connect the player while it is switched off, then let the installer finish and let the player reboot.

Is Rondo 4.1.2 the latest Rondo release?

The release list on this page is ordered newest first, so the top entry is the latest published build. Preview and nightly builds are labelled as such.

Can I install Rondo 4.1.2 from another computer?

Yes. Download the ZIP here, copy it to the computer that can talk to the player, and follow the install guide there. The package is self-contained.

Which file do I download for Windows, macOS or Linux?

Each portable package in the download section is built for one computer. The guide pages linked under "Install on your computer" name the exact file and its size.
