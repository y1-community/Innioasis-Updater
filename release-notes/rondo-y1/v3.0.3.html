For the Innioasis Y1, Type A, on the Rondo 3.0 firmware. An update you can install over Wi-Fi. With your own server, update it to Rondo server 3.2.0 (its admin page offers it) so YouTube Music downloads get their year and track number; 3.1.0 works for everything else.

New

  • YouTube Music downloads. Hold center on a song and choose Download, or Download all on an album or playlist. Songs go to Music/YouTube Music/Artist/Album (Year)/01 - Title.m4a: YouTube's own AAC, with the artist, album, year, track number, cover and lyrics (timed where LRCLIB has them) in its tags. YouTube Music › Home › Downloads plays them from the card, also offline.
  • YouTube Music's Home looks like the app's: each section a shelf of covers that slides along as you turn the wheel, then on into the next one.
  • The dashboard fills in what your songs' tags leave out (Library › Fill in): a missing genre, year, album or track number from the iTunes Store and MusicBrainz, reviewed before it's saved into the songs; and lyrics from LRCLIB for every song that has none.
  • Organize looks up a show's or a movie's years on the dashboard (TVmaze, Wikidata), so shows are filed as Silo (2023-) or The Walking Dead (2010-2022).

Changed

  • Shows and movies go inside Videos: Videos/Shows/… and Videos/Movies/…, the way Jellyfin expects them. Organize moves the old top-level Shows and Movies folders' files there.
  • A song's menu has an icon for each action.

Fixed

  • A YouTube video downloads and plays in its original language, not a dub YouTube listed first.
  • Changing Repeat or Shuffle no longer stops the song for a moment.
  • Library › Files slides in like every other screen.
  • The dashboard's Wheel acceleration and Wheel vibration can be changed again, and its notes keep their distance from what's around them.

How to get it

  • On Rondo 3.0.x: Settings › System › Software update, the dashboard's Overview, or the update page over USB.
  • On Rondo 2.0 or earlier: Innioasis Updater CE (Y1, Type A, Rondo 3.0.3), with Keep my settings turned on.

Files: rondo-3.0.3.rondo is the signed update bundle; rom.zip (the firmware) and updater.png are added by the release workflow a few minutes after publishing. Everything else: changelog.

Updating to Rondo 3.0.3

The same steps install this release for the first time or replace the build already on the player. Back up your music before you start.

  1. Check the model and type

    Confirm the player is an Innioasis Y1 before downloading. Y1 players come in two hardware revisions, Type A (software 2.0.0 or later) and Type B (earlier software); the two ROMs are not interchangeable.

  2. Download the package built for your computer

    Use Updater CE for the guided route, or download the portable package for Windows, macOS or Linux from this page. The release's own ZIP is also listed for manual flashing.

  3. Connect the player while it is switched off

    Use a data-capable USB cable and connect the player only when the installer asks. Keep it connected until the flash reports success.

  4. Verify the version after it reboots

    Open the player's Settings or About screen and check that it reports Rondo 3.0.3.

Questions about this update

How do I update Innioasis Y1 to Rondo 3.0.3?

Download the package for your computer from this page, or open Updater CE and choose Rondo 3.0.3 for Innioasis Y1. Connect the player while it is switched off, then let the installer finish and let the player reboot.

Is Rondo 3.0.3 the latest Rondo release?

The release list on this page is ordered newest first, so the top entry is the latest published build. Preview and nightly builds are labelled as such.

Can I install Rondo 3.0.3 from another computer?

Yes. Download the ZIP here, copy it to the computer that can talk to the player, and follow the install guide there. The package is self-contained.

Which file do I download for Windows, macOS or Linux?

Each portable package in the download section is built for one computer. The guide pages linked under "Install on your computer" name the exact file and its size.
