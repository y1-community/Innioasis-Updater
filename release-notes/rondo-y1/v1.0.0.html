Rondo 1.0.0

Rondo 1.0.0 update for the Innioasis Y1. Download it below, or let Updater CE install it for you.

A lightweight, custom audio operating system for the Innioasis Y1.

Rondo is now a firmware for the Innioasis Y1: the Y1 starts straight into Rondo's click-wheel menus, with nothing else on it.

For the Y1, Type A only (players that shipped with software 2.0.0 or later). Not for the Type B or the Y2.

Install

Choose Rondo in Innioasis Updater CE (Y1, Type A). Or download rom.zip below and use the Updater's Settings › Install from a file….

Installing replaces everything on the Y1 itself: the original player, Rockbox, settings. The microSD card isn't touched, so your music stays. When the Updater is done, press the Y1's Power button; the first start takes a couple of minutes. The install guide has the details and the first steps after it.

For YouTube Music and YouTube, set up a Rondo server with Docker, at home or on a VPS.

Updates

Later versions install over this one in a minute, without flashing again, keeping your settings, Wi-Fi, playlists and music: Settings › Software update on the Y1, Install in the dashboard, or the update page over USB.

What's in it

  • iPod-style menus for the click wheel, with optional vibration and a click on every step
  • Your music and videos from the microSD card, with covers, lyrics, search and playlists
  • The card as a USB drive when the Y1 is plugged into a computer
  • YouTube Music and YouTube, streamed live through your own server, including Shorts, with or without a YouTube account
  • FM radio with station names, scanning and saved stations
  • Bluetooth headphones and speakers, and Wi-Fi, set up from the wheel
  • A dashboard in your phone's browser for music, playlists, settings, the theme, Wi-Fi, Bluetooth, the radio and updates
  • Shut down and restart from Settings, or by holding the Power button

Good to know

  • Only the Y1 Type A is supported; the Type B and Y2 haven't been tested.
  • Rockbox, the original player and Android's own Settings aren't part of Rondo. Innioasis Updater CE puts any of them back.
  • YouTube Music and YouTube need your own Rondo server; the card, the radio and Bluetooth don't.

Updating to Rondo 1.0.0

The same steps install this release for the first time or replace the build already on the player. Back up your music before you start.

  1. Check the model and type

    Confirm the player is an Innioasis Y1 before downloading. Y1 players come in two hardware revisions, Type A (software 2.0.0 or later) and Type B (earlier software); the two ROMs are not interchangeable.

  2. Download the package built for your computer

    Use Updater CE for the guided route, or download the portable package for Windows, macOS or Linux from this page. The release's own ZIP is also listed for manual flashing.

  3. Connect the player while it is switched off

    Use a data-capable USB cable and connect the player only when the installer asks. Keep it connected until the flash reports success.

  4. Verify the version after it reboots

    Open the player's Settings or About screen and check that it reports Rondo 1.0.0.

Questions about this update

How do I update Innioasis Y1 to Rondo 1.0.0?

Download the package for your computer from this page, or open Updater CE and choose Rondo 1.0.0 for Innioasis Y1. Connect the player while it is switched off, then let the installer finish and let the player reboot.

Is Rondo 1.0.0 the latest Rondo release?

The release list on this page is ordered newest first, so the top entry is the latest published build. Preview and nightly builds are labelled as such.

Can I install Rondo 1.0.0 from another computer?

Yes. Download the ZIP here, copy it to the computer that can talk to the player, and follow the install guide there. The package is self-contained.

Which file do I download for Windows, macOS or Linux?

Each portable package in the download section is built for one computer. The guide pages linked under "Install on your computer" name the exact file and its size.
