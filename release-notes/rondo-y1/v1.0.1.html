A small update to Rondo for the Innioasis Y1, Type A. If your Y1 already runs Rondo, it installs over the one you have in about a minute, and everything stays: settings, Wi-Fi, server connection, playlists and music.

What's new

  • Click sound stays off. Turning off Settings › Click sound (or the switch in the dashboard) now lasts through a restart. Before, the Y1's own sound profile turned the click back on every time it started.
  • Every release now comes with its firmware. The rom.zip that Innioasis Updater CE installs is built automatically for each release, so a new install always gets the newest Rondo.
  • Rondo knows which updates it can install. The firmware now carries a version of its own. If a future release changes the firmware itself, not only Rondo, Settings › Software update, the dashboard and the update page say so and point you to Innioasis Updater CE, instead of offering an install that couldn't work.
  • One place for news of a release. The Y1 (through your server), the dashboard and the update page all learn about a new Rondo from the update page, once its firmware is ready, so they always agree with each other and with Innioasis Updater CE.
  • New README and guides, with screenshots.

The full list is in CHANGELOG.md.

Updating from 1.0.0

Pick whichever is handiest; none of them reinstalls the firmware:

  • On the Y1: Settings › Software update, then Install now (needs your Rondo server).
  • In the dashboard: Settings › Dashboard on the Y1, open it on your phone, press Install.
  • Over USB: open the update page in Chrome or Edge and plug the Y1 in.

If you run a Rondo server, update it too (how); it's 1.0.1 as well.

Installing for the first time

Choose Rondo in Innioasis Updater CE (Y1, then Type A), or download rom.zip below and use the Updater's Settings › Install from a file…. Installing replaces everything on the Y1 itself; the microSD card isn't touched. The install guide has the details.

Only for the Y1 Type A (players that shipped with software 2.0.0 or later), not the Type B or the Y2.

Files

  • rom.zip: the firmware, for Innioasis Updater CE (Y1 Type A). Built from rondo-1.0.1.apk by this repository's release workflow, a few minutes after publishing.
  • rondo-1.0.1.apk: the update, for a Y1 that already runs the Rondo firmware.

Updating to Rondo 1.0.1

The same steps install this release for the first time or replace the build already on the player. Back up your music before you start.

  1. Check the model and type

    Confirm the player is an Innioasis Y1 before downloading. Y1 players come in two hardware revisions, Type A (software 2.0.0 or later) and Type B (earlier software); the two ROMs are not interchangeable.

  2. Download the package built for your computer

    Use Updater CE for the guided route, or download the portable package for Windows, macOS or Linux from this page. The release's own ZIP is also listed for manual flashing.

  3. Connect the player while it is switched off

    Use a data-capable USB cable and connect the player only when the installer asks. Keep it connected until the flash reports success.

  4. Verify the version after it reboots

    Open the player's Settings or About screen and check that it reports Rondo 1.0.1.

Questions about this update

How do I update Innioasis Y1 to Rondo 1.0.1?

Download the package for your computer from this page, or open Updater CE and choose Rondo 1.0.1 for Innioasis Y1. Connect the player while it is switched off, then let the installer finish and let the player reboot.

Is Rondo 1.0.1 the latest Rondo release?

The release list on this page is ordered newest first, so the top entry is the latest published build. Preview and nightly builds are labelled as such.

Can I install Rondo 1.0.1 from another computer?

Yes. Download the ZIP here, copy it to the computer that can talk to the player, and follow the install guide there. The package is self-contained.

Which file do I download for Windows, macOS or Linux?

Each portable package in the download section is built for one computer. The guide pages linked under "Install on your computer" name the exact file and its size.
