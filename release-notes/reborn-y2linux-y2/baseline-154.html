Y2Linux 1.0 Beta 8.40: charging while switched off. Linux 6.18 and the native Reborn music player for the Innioasis Y2.

Already running Y2Linux

Settings → About & Updates → Check for Updates → Update Now.

What's new

  • Power Off on a charger now charges: switching the player off with a cable plugged in used to turn it fully off, and it did not charge until you unplugged and plugged it in again. Now it does what the stock firmware does: it restarts into the charging screen and charges. Unplug on that screen and it switches off; hold Power to start the player. Without a cable, Power Off works as before.

Everything from Beta 8.39 (Folders by file name, Shuffle Albums, playlist Sort, big libraries) is included. Thanks for the report!

Install (from stock)

You need SP Flash Tool v5.2032, a USB cable, Y2Linux-1.0.0-beta.8.40-first-install.zip below and the Innioasis Y2 firmware package v3.2.0 from Innioasis (only this version works; it is also your way back to stock).

  1. Unpack both.
  2. SP Flash Tool → Download Only → load MT6582_Android_scatter.txt from the Y2Linux zip. Exactly BOOTIMG, RECOVERY, ANDROID and USRDATA are ticked.
  3. Click Download and connect the switched-off Y2; wait for the green tick.
  4. Unplug and press Power: the player sets up its Internal Storage (a few seconds), then Y2Linux and Reborn start, music works.
  5. Connect the Y2 to the computer and copy (don't move) system.img from the Innioasis package into the Firmware folder on Internal Storage. The player takes the Wi-Fi/Bluetooth firmware from it and turns the radios on.

Known issues (beta)

  • Going back to a version older than 8.33 starts with an empty queue (your settings are kept).
  • The Bluetooth volume takeover was tested without real headphones; if your headphones' volume behaves oddly, please send a report.
  • Some car radios don't show the song and artist yet; we are looking into it.
  • In a very long single-file book, jumping to another chapter takes 2–3 seconds.
  • The headphone levels of 8.35 are not measured with a meter yet; very low-sensitivity headphones (some planars, 300–600 Ω) may still want an external amplifier.
  • With very large libraries (100 000+ songs) a list can still take up to about a second the first time right after the player starts, and the first scan of such a card takes several minutes.
  • Haptic feedback is not there yet: the player's vibration motor needs a driver first.
  • The restart fix of Beta 8.4 is not yet confirmed over many restarts. If the screen ever stays dark, hold Power for 10 s and start again.
  • Battery life in sleep is not yet stock-like (about 8 mA vs stock 1.3 mA on the developer's player).
  • The charging fixes (#47, Beta 8.29) are not yet confirmed on an affected player; if yours still doesn't charge, please send a report.
  • Charging after Power Off (8.40) is not yet confirmed on a player. If yours still stays dark and doesn't charge after Power Off on a cable, unplug and plug the cable in again and please send a report.
  • The player cannot detect wired headphones yet; the jack plays whenever no Bluetooth headphones are connected.
  • BBC radio stations stream only in HLS, which the player does not play yet (planned for a later beta).
  • FM radio is in the works for a later beta.

Updating to Reborn (Y2Linux) 1.0

The same steps install this release for the first time or replace the build already on the player. Back up your music before you start.

  1. Check the model and type

    Confirm the player is an Innioasis Y2 before downloading. Y1 players come in two hardware revisions, Type A (software 2.0.0 or later) and Type B (earlier software); the two ROMs are not interchangeable.

  2. Download the package built for your computer

    Use Updater CE for the guided route, or download the portable package for Windows, macOS or Linux from this page. The release's own ZIP is also listed for manual flashing.

  3. Connect the player while it is switched off

    Use a data-capable USB cable and connect the player only when the installer asks. Keep it connected until the flash reports success.

  4. Verify the version after it reboots

    Open the player's Settings or About screen and check that it reports Reborn (Y2Linux) 1.0.

Questions about this update

How do I update Innioasis Y2 to Reborn (Y2Linux) 1.0?

Download the package for your computer from this page, or open Updater CE and choose Reborn (Y2Linux) 1.0 for Innioasis Y2. Connect the player while it is switched off, then let the installer finish and let the player reboot.

Is Reborn (Y2Linux) 1.0 the latest Reborn (Y2Linux) release?

The release list on this page is ordered newest first, so the top entry is the latest published build. Preview and nightly builds are labelled as such.

Can I install Reborn (Y2Linux) 1.0 from another computer?

Yes. Download the ZIP here, copy it to the computer that can talk to the player, and follow the install guide there. The package is self-contained.

Which file do I download for Windows, macOS or Linux?

Each portable package in the download section is built for one computer. The guide pages linked under "Install on your computer" name the exact file and its size.
