Y2Linux 1.0 Beta 7.4: tidier messages, a cooler Now Playing. Linux 6.18 and the native Reborn music player for the Innioasis Y2.

Already running Y2Linux

Settings → About & Updates → Check for Updates → Update Now.

Changed

  • Messages sit in the status bar. A slim pill with an icon for what it is about (a USB symbol for the computer, a note for new songs, Bluetooth, Wi-Fi, a red warning for problems) briefly takes the status bar's place. It no longer covers the clock or any content.
  • Now Playing runs cooler. The playing wave still moves at 60 frames per second, but no longer keeps the processor at a raised speed; its frames are light enough for the lowest speed.

Measured on the player (Beta 7.3): motion runs at 62 frames per second (median) with no missed frames, the wave at 64–65, and nothing is redrawn at rest.

Everything from Beta 7.3 (the computer message and USB symbol), 7.2 (motion, the wave) and earlier is included.

Install (from stock)

You need SP Flash Tool v5.2032, a USB cable, Y2Linux-1.0.0-beta.7.4-first-install.zip below and the Innioasis Y2 firmware package v3.2.0 from Innioasis (also your way back to stock).

  1. Unpack both.
  2. SP Flash Tool → Download Only → load MT6582_Android_scatter.txt from the Y2Linux zip. Exactly BOOTIMG, RECOVERY, ANDROID and USRDATA are ticked.
  3. Click Download and connect the switched-off Y2; wait for the green tick.
  4. Unplug and press Power: Y2Linux and Reborn start, music works.
  5. Connect the Y2 to the computer and copy (don't move) system.img from the Innioasis package onto the Firmware drive. The player takes the Wi-Fi/Bluetooth firmware from it and turns the radios on.

Known issues (beta)

  • Now Playing redraws continuously while music plays and the screen is on (for the wave); with this release at the lowest processor speed.
  • The 12- or 24-hour clock follows the time zone; there is no switch yet.
  • FM radio is planned for the next beta.
  • Battery life in sleep is not yet stock-like (about 8 mA vs stock 1.3 mA). The player cannot detect wired headphones yet.

Updating to Reborn (Y2Linux) 1.0

The same steps install this release for the first time or replace the build already on the player. Back up your music before you start.

  1. Check the model and type

    Confirm the player is an Innioasis Y2 before downloading. Y1 players come in two hardware revisions, Type A (software 2.0.0 or later) and Type B (earlier software); the two ROMs are not interchangeable.

  2. Download the package built for your computer

    Use Updater CE for the guided route, or download the portable package for Windows, macOS or Linux from this page. The release's own ZIP is also listed for manual flashing.

  3. Connect the player while it is switched off

    Use a data-capable USB cable and connect the player only when the installer asks. Keep it connected until the flash reports success.

  4. Verify the version after it reboots

    Open the player's Settings or About screen and check that it reports Reborn (Y2Linux) 1.0.

Questions about this update

How do I update Innioasis Y2 to Reborn (Y2Linux) 1.0?

Download the package for your computer from this page, or open Updater CE and choose Reborn (Y2Linux) 1.0 for Innioasis Y2. Connect the player while it is switched off, then let the installer finish and let the player reboot.

Is Reborn (Y2Linux) 1.0 the latest Reborn (Y2Linux) release?

The release list on this page is ordered newest first, so the top entry is the latest published build. Preview and nightly builds are labelled as such.

Can I install Reborn (Y2Linux) 1.0 from another computer?

Yes. Download the ZIP here, copy it to the computer that can talk to the player, and follow the install guide there. The package is self-contained.

Which file do I download for Windows, macOS or Linux?

Each portable package in the download section is built for one computer. The guide pages linked under "Install on your computer" name the exact file and its size.
