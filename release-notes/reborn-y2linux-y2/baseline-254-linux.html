Before you start

  • A 64-bit Linux distribution (x64 or arm64), or the legacy build on 32-bit Linux
  • A data-capable USB cable (charge-only cables are not enough)
  • About 1 GB of free space for the ZIP and the extracted files

How to install Reborn (Y2Linux) 1.0 on Linux

  1. Download the Linux ZIP

    The button above saves Y2Linux-1.0.0-beta.9.3.27-first-install-linux-arm64.zip, Y2Linux-1.0.0-beta.9.3.27-first-install-linux-legacy.zip, Y2Linux-1.0.0-beta.9.3.27-first-install-linux.zip. Use the arm64 build on ARM hardware and the legacy ZIP on 32-bit Linux.

  2. Unzip it

    Expand the archive in your file manager or with unzip, and keep the folder contents together.

  3. Make the tool executable

    Open a terminal in the folder and run chmod +x on the flash tool. If it asks for udev rules for the player, install them as described in the folder's README.

  4. Connect the player switched off and run the tool

    With the player powered off, connect it with a data-capable USB cable, then start the tool and follow its prompts until the flash reports success.

Linux install questions

Which package do I need for Linux?

Y2Linux-1.0.0-beta.9.3.27-first-install-linux-arm64.zip, Y2Linux-1.0.0-beta.9.3.27-first-install-linux-legacy.zip, Y2Linux-1.0.0-beta.9.3.27-first-install-linux.zip is the Linux build for Reborn (Y2Linux) 1.0. Use the x64 build on an ordinary Intel or AMD desktop, the arm64 build on a Raspberry Pi or other ARM board, and the legacy ZIP on 32-bit Linux.

Do I need Innioasis Updater CE to install Reborn (Y2Linux) 1.0?

No. The portable package includes the flash tool, so the steps on this page install the same release without Updater CE. Updater CE is the easier route when you want it to pick the right file for the player.

Will installing this release erase my music?

A firmware flash can erase the player's internal storage. Copy your music, playlists and recordings to your computer before you start.

How do I check that Reborn (Y2Linux) 1.0 is installed?

After the player reboots, open Settings (or About) on the Innioasis Y2 and check the version it reports. It should match 1.0.
