Before you start

  • macOS 11 or later on Apple silicon or Intel
  • A data-capable USB cable (charge-only cables are not enough)
  • About 1 GB of free space for the ZIP and the extracted files

How to install Reborn (Y2Linux) 1.0 on macOS

  1. Download the macOS ZIP

    The button above saves Y2Linux-1.0.0-beta.9.3.17-first-install-macos.zip. The package is universal, so the same file runs on Apple silicon and Intel Macs.

  2. Unzip it

    Double-click the downloaded ZIP to expand it in Finder. Keep the expanded folder together; the flash tool needs the images beside it.

  3. Allow the tool to open

    If macOS blocks it as an unidentified developer, Control-click the app and choose Open, or allow it in System Settings → Privacy & Security.

  4. Connect the player switched off and run the tool

    Use a data-capable USB cable, connect the player while it is powered off, and start the tool. Keep the player connected until it reports success.

macOS install questions

Which package do I need for a Mac?

Y2Linux-1.0.0-beta.9.3.17-first-install-macos.zip is the macOS build for Reborn (Y2Linux) 1.0. The macOS package is universal: it runs on Apple silicon and Intel Macs.

Do I need Innioasis Updater CE to install Reborn (Y2Linux) 1.0?

No. The portable package includes the flash tool, so the steps on this page install the same release without Updater CE. Updater CE is the easier route when you want it to pick the right file for the player.

Will installing this release erase my music?

A firmware flash can erase the player's internal storage. Copy your music, playlists and recordings to your computer before you start.

How do I check that Reborn (Y2Linux) 1.0 is installed?

After the player reboots, open Settings (or About) on the Innioasis Y2 and check the version it reports. It should match 1.0.
