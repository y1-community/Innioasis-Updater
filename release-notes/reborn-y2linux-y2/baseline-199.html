Y2Linux 1.0 Beta 9.2.8: why a Wi-Fi router turns the player away. Linux 6.18 and the native Reborn music player for the Innioasis Y2.

Already running Y2Linux

Settings → About & Updates → Check for Updates → Update Now.

What changed

  • Wi-Fi refusals are recorded (#83): when a router refuses to let the player join, error reports now note the reason each refusal gave (or that the router never answered), so we can tell a router that turns the Y2 away on purpose from one that does not hear it. Nothing you will see changes.
  • If your player keeps failing to join your Wi-Fi, send an error report right after it happens. Routers that use one name for 2.4 and 5 GHz ("band steering", "Smart Connect") may push devices to 5 GHz, which the Y2 does not have; a separate 2.4 GHz network is worth a try.

Tested on the developer's player: installed over the air from Beta 9.2.7 and confirmed by the player itself; all services and Reborn running, health OK. Before release: the platform's full check, Reborn's workspace tests and the tests of the release images.

What changed and why, in plain words: Beta 9.2.8 report. Everything from Beta 9.2.7 is included (Beta 9.2.7 report).

Install (from stock)

You need SP Flash Tool v5.2032, a USB cable, Y2Linux-1.0.0-beta.9.2.8-first-install.zip below and the Innioasis Y2 firmware package v3.2.0 from Innioasis (only this version works; it is also your way back to stock).

  1. Unpack both.
  2. SP Flash Tool → Download Only → load MT6582_Android_scatter.txt from the Y2Linux zip. Exactly BOOTIMG, RECOVERY, ANDROID and USRDATA are ticked.
  3. Click Download and connect the switched-off Y2; wait for the green tick.
  4. Unplug and press Power: the player sets up its Internal Storage (a few seconds), then Y2Linux and Reborn start, music works.
  5. Connect the Y2 to the computer and copy (don't move) system.img from the Innioasis package into the Firmware folder on Internal Storage. The player takes the Wi-Fi/Bluetooth firmware from it and turns the radios on.

Known issues (beta)

  • Everything listed for Beta 9.0 still applies. If anything behaves differently from 9.2.7, send an error report (Settings → Diagnostics); Settings → Diagnostics → Restore Previous System goes back to the version you had, with your data kept.
  • Battery life in sleep: about 2 mA overnight on the developer's player (estimated from the battery voltage); stock is about 1.3 mA.
  • Some players turned off by themselves during playback; the cause is not found yet. If yours does, start it again and send a report.
  • The speaker uses the same volume as the headphones; its loudest step is the stock speaker's. Start low the first time.
  • How loud the wheel click should be is a first guess; tell us if it is too loud or too soft.
  • BBC radio stations stream only in HLS, which the player does not play yet. FM radio is in the works for a later beta.
