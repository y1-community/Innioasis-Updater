Y2Linux 1.0 Beta 9.3.24: Bluetooth always sends standard SBC, and the battery shows the right level after charging while switched off.

Fixed

  • Battery level after charging while switched off (#113). A player that was charged while off and started later, off the charger, still showed the old lower percentage, which looked like a drained battery. It now shows the level it measures at the start.

Changed

  • SBC XQ is gone; Bluetooth sends standard SBC (Y2Reborn #123). XQ and XQ+ sent much more data than headphones and speakers on a busy or weak link could take, and the music stuttered. The SBC Quality row in the service menu is removed. A player that was set to XQ uses standard SBC after the update, with nothing to do. SBC Auto Rate stays. AAC and LDAC are unchanged.

Behind the scenes

  • Error reports now show Bluetooth's data rate over time, so a stutter can be matched to what the link did (#99, Y2Reborn #87).

Everything from Beta 9.3.23 is included: Now Playing's progress wave in the cover's colour, the screen that stays dark after a sleep that didn't work, steadier Bluetooth on a weak signal and Wi-Fi on channels 12 and 13.

Known issues

  • A network on channel 12 or 13 may need a second scan to appear.
  • Music can stutter for a few seconds while Wi-Fi switches on.
  • Far from the headphones the music still pauses when the signal is lost; it no longer rushes afterwards.
  • A charge-only USB cable only charges. If your computer doesn't see the player, try a cable that transfers data with a phone.
  • Skins with their own fonts (Luna XP, Winamp and others) show boxes instead of Chinese, Japanese and Korean titles.
  • After a sleep, Bluetooth headphones reconnect within a few seconds of waking. Headphones that went back to a phone meanwhile must be picked again in Settings → Bluetooth.
  • WPA3-only Wi-Fi networks can't be joined; a "WPA2/WPA3 mixed" setting on the router works.
  • One audiobook file longer than about 36 hours may not play or not show up; split it into parts of up to 30 hours.
  • Some players turned off by themselves during playback; the cause isn't found yet.
  • Something wrong? Send an error report (Settings → System → Error Reports). Restore Previous System (Settings → System → About, tap Version seven times, then Diagnostics) takes you back to the version you had, with your data kept.

Updating to Reborn (Y2Linux) 1.0

The same steps install this release for the first time or replace the build already on the player. Back up your music before you start.

  1. Check the model and type

    Confirm the player is an Innioasis Y2 before downloading. Y1 players come in two hardware revisions, Type A (software 2.0.0 or later) and Type B (earlier software); the two ROMs are not interchangeable.

  2. Download the package built for your computer

    Use Updater CE for the guided route, or download the portable package for Windows, macOS or Linux from this page. The release's own ZIP is also listed for manual flashing.

  3. Connect the player while it is switched off

    Use a data-capable USB cable and connect the player only when the installer asks. Keep it connected until the flash reports success.

  4. Verify the version after it reboots

    Open the player's Settings or About screen and check that it reports Reborn (Y2Linux) 1.0.

Questions about this update

How do I update Innioasis Y2 to Reborn (Y2Linux) 1.0?

Download the package for your computer from this page, or open Updater CE and choose Reborn (Y2Linux) 1.0 for Innioasis Y2. Connect the player while it is switched off, then let the installer finish and let the player reboot.

Is Reborn (Y2Linux) 1.0 the latest Reborn (Y2Linux) release?

The release list on this page is ordered newest first, so the top entry is the latest published build. Preview and nightly builds are labelled as such.

Can I install Reborn (Y2Linux) 1.0 from another computer?

Yes. Download the ZIP here, copy it to the computer that can talk to the player, and follow the install guide there. The package is self-contained.

Which file do I download for Windows, macOS or Linux?

Each portable package in the download section is built for one computer. The guide pages linked under "Install on your computer" name the exact file and its size.
