Y2Linux Baseline 48 — a new download screen.

Install over Wi-Fi: Settings → About & Updates → Check for Updates → Download Update → Restart and Install (charger or at least half a battery).

  • Downloads show their step, the percentage, a smooth progress bar, MB downloaded, the speed and the time left, then a short check with its own bar.
  • When the download is finished the page turns to Ready to Install and a notice says so, wherever you are.
  • The download is checked once instead of twice (about 12 seconds faster) and runs at low priority, so music and the screen stay smooth.
  • Includes Baseline 47's fix for the dark screen while an update installs.

The new screen appears from the next download on (this download still uses the installed version's screen).

Kernel 6.18.56-y2linux-platform-v1-power-final-48, release 1.0.0-platform-v1-power-final-candidate.48, update sequence 4800. Assets: manifest.json + manifest.sig (Ed25519, key platform-v1-release-20261015) and the three payloads pinned by SHA-256. Developer preview.

Note (2026-10-16): the system image (rootfs.ext4.gz) was removed from this release because it contained proprietary MediaTek radio firmware that may not be redistributed. Use Baseline 49 or later; their images contain no firmware.

Updating to Reborn (Y2Linux) 48

The same steps install this release for the first time or replace the build already on the player. Back up your music before you start.

  1. Check the model and type

    Confirm the player is an Innioasis Y2 before downloading. Y1 players come in two hardware revisions, Type A (software 2.0.0 or later) and Type B (earlier software); the two ROMs are not interchangeable.

  2. Download the package built for your computer

    Use Updater CE for the guided route, or download the portable package for Windows, macOS or Linux from this page. The release's own ZIP is also listed for manual flashing.

  3. Connect the player while it is switched off

    Use a data-capable USB cable and connect the player only when the installer asks. Keep it connected until the flash reports success.

  4. Verify the version after it reboots

    Open the player's Settings or About screen and check that it reports Reborn (Y2Linux) 48.

Questions about this update

How do I update Innioasis Y2 to Reborn (Y2Linux) 48?

Download the package for your computer from this page, or open Updater CE and choose Reborn (Y2Linux) 48 for Innioasis Y2. Connect the player while it is switched off, then let the installer finish and let the player reboot.

Is Reborn (Y2Linux) 48 the latest Reborn (Y2Linux) release?

The release list on this page is ordered newest first, so the top entry is the latest published build. Preview and nightly builds are labelled as such.

Can I install Reborn (Y2Linux) 48 from another computer?

Yes. Download the ZIP here, copy it to the computer that can talk to the player, and follow the install guide there. The package is self-contained.
