Before you start

  • Windows 10 or 11 on an Intel/AMD PC, Windows on ARM, or the legacy build on Windows 7/8 and 32-bit systems
  • A data-capable USB cable (charge-only cables are not enough)
  • About 1 GB of free space for the ZIP and the extracted files

How to install Reborn (Y2Linux) 1.0 on Windows

  1. Download the Windows ZIP

    The button above saves Y2Linux-1.0.0-beta.8.7-first-install-windows-legacy.zip, Y2Linux-1.0.0-beta.8.7-first-install-windows.zip. Choose Windows on ARM if the PC runs a Snapdragon or other ARM processor; the ordinary Windows ZIP is for Intel and AMD PCs.

  2. Extract the archive

    Right-click the downloaded ZIP, choose Extract All, and open the new folder. Keep every file beside the flash tool; it looks for its images in that folder.

  3. Connect the player switched off

    Use a data-capable USB cable. With the player powered off, hold its power button until Windows recognises the device, then release it.

  4. Run the installer and wait

    Start the tool in the extracted folder, follow its prompts, and leave the player alone until it reports success. Windows may show a SmartScreen prompt for a new tool: choose More info, then Run anyway.

Windows install questions

Which package do I need for a Windows PC?

Y2Linux-1.0.0-beta.8.7-first-install-windows-legacy.zip, Y2Linux-1.0.0-beta.8.7-first-install-windows.zip is the Windows build for Reborn (Y2Linux) 1.0. Windows 11 and Windows 10 are supported; the legacy ZIP is for Windows 7/8 and 32-bit Windows, and Windows on ARM runs its own build natively.

Do I need Innioasis Updater CE to install Reborn (Y2Linux) 1.0?

No. The portable package includes the flash tool, so the steps on this page install the same release without Updater CE. Updater CE is the easier route when you want it to pick the right file for the player.

Will installing this release erase my music?

A firmware flash can erase the player's internal storage. Copy your music, playlists and recordings to your computer before you start.

How do I check that Reborn (Y2Linux) 1.0 is installed?

After the player reboots, open Settings (or About) on the Innioasis Y2 and check the version it reports. It should match 1.0.
