Y2Linux 1.0 Beta 9.2.14: Bluetooth stays connected while you change stations. Linux 6.18 and the native Reborn music player for the Innioasis Y2.

Already running Y2Linux

Settings → System → Software Update → Update Now (on Beta 9.2.8 and older: Settings → About & Updates → Check for Updates → Update Now).

What changed

  • Bluetooth no longer drops when you change radio stations quickly (from an error report): every new station or song closed the Bluetooth output and opened it again, twice, and each time the headphones were asked to start streaming anew. Some earbuds answer that slowly; when one answer took longer than six seconds, the connection ended. The player now keeps the Bluetooth output open from one station or song to the next while the headphones stay the same, as it already did for the headphone jack. Pause still releases it at once.
  • New issue forms on GitHub: a new issue now opens a short form for its kind of problem (something wrong, slow, battery, sound and Bluetooth, Wi-Fi and radio, install or update, a feature request, a question), so the details needed to find the cause are there from the start.

Before release: the platform's full check, Reborn's workspace tests (new, each failing without its change: a Bluetooth output plays the next stream in the open sink; it is taken only while the headphones' connection, codec, rate and format are unchanged) and the tests of the release images. On the developer's player: installed by update from 9.2.13, and six quick skips on AirPods Pro each played at once in the open Bluetooth output.

What changed and why, in plain words: Beta 9.2.14 report. Everything from Beta 9.2.13 is included (Beta 9.2.13 report).

Install (from stock)

You need SP Flash Tool v5.2032, a USB cable, Y2Linux-1.0.0-beta.9.2.14-first-install.zip below and the Innioasis Y2 firmware package v3.2.0 from Innioasis (only this version works; it is also your way back to stock).

  1. Unpack both.
  2. SP Flash Tool → Download Only → load MT6582_Android_scatter.txt from the Y2Linux zip. Exactly BOOTIMG, RECOVERY, ANDROID and USRDATA are ticked.
  3. Click Download and connect the switched-off Y2; wait for the green tick.
  4. Unplug and press Power: the player sets up its Internal Storage (a few seconds), then Y2Linux and Reborn start, music works.
  5. Connect the Y2 to the computer and copy (don't move) system.img from the Innioasis package into the Firmware folder on Internal Storage. The player takes the Wi-Fi/Bluetooth firmware from it and turns the radios on.

Known issues (beta)

  • Everything listed for Beta 9.0 still applies. If anything behaves differently from 9.2.13, send an error report (Settings → System → Error Reports); Restore Previous System (Settings → System → About, tap Version seven times, then Diagnostics) goes back to the version you had, with your data kept.
  • Battery life in sleep: about 2 mA overnight on the developer's player (estimated from the battery voltage); stock is about 1.3 mA.
  • Some players turned off by themselves during playback; the cause is not found yet. If yours does, start it again and send a report.
  • The speaker uses the same volume as the headphones; its loudest step is the stock speaker's. Start low the first time.
  • How loud the wheel click should be is a first guess; tell us if it is too loud or too soft.
  • BBC radio stations stream only in HLS, which the player does not play yet. FM radio is in the works for a later beta.
