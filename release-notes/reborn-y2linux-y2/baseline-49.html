Y2Linux Baseline 49 — ready-made images for a first install, and the update for players that already run Y2Linux.

Already running Y2Linux (46 or later)

Settings → About & Updates → Check for Updates → Download Update → Restart and Install. Your Wi-Fi and Bluetooth firmware is kept automatically.

New install (from stock)

You need SP Flash Tool v5.2032, a USB cable, this release's Y2Linux-49-first-install.zip and the Innioasis Y2 firmware package v3.2.0 from Innioasis.

  1. Unpack the Y2Linux zip and the Innioasis package.
  2. SP Flash Tool → Download Only → load MT6582_Android_scatter.txt from the Y2Linux zip. Exactly BOOTIMG, RECOVERY, ANDROID and USRDATA are ticked.
  3. Click Download, connect the switched-off Y2; wait for the green tick.
  4. Unplug, press Power: Y2Linux and Reborn start.
  5. Connect the Y2 to the computer again and copy system.img from the Innioasis package to the Firmware drive. The player takes the Wi-Fi/Bluetooth firmware from it and turns the radios on.

Full guide: INSTALL · why RECOVERY is flashed: Recovery and updates

What's new

  • No proprietary MediaTek firmware in any image. Each player uses its owner's copy (kept across updates). The system images of releases 46–48 were removed because they contained it.
  • One-time flash package with the Y2 recovery image; afterwards everything updates over Wi-Fi.
  • Bluetooth codecs: SBC, AAC (fdk-aac-free, AAC-LC) and LDAC.
  • Headphone load measurement and two CS43131 driver fixes (thanks @samanz, #38); covers that load reliably, A–Z sorting that ignores case, accents and "The", genre titles on the album grid (thanks @samanz, Y2Reborn #6–#8).

Files

  • Y2Linux-49-first-install.zip: images, scatter files and checksums for SP Flash Tool. The data image has no SSH key (developers: tools/production/first_owner.py).
  • manifest.json, manifest.sig, rootfs.ext4.gz, bootimg.img.gz, recovery.img.gz: the signed over-the-air update (Ed25519 key platform-v1-release-20261015, sequence 4900).
  • Y2Linux-49-sources-*: corresponding sources (Buildroot legal-info with package sources, patches and licences; the Linux 6.18.56 archive). Our own code is this repository and Y2Reborn at tag baseline-49.
  • SHA256SUMS for all of the above.

Updating to Reborn (Y2Linux) 49

The same steps install this release for the first time or replace the build already on the player. Back up your music before you start.

  1. Check the model and type

    Confirm the player is an Innioasis Y2 before downloading. Y1 players come in two hardware revisions, Type A (software 2.0.0 or later) and Type B (earlier software); the two ROMs are not interchangeable.

  2. Download the package built for your computer

    Use Updater CE for the guided route, or download the portable package for Windows, macOS or Linux from this page. The release's own ZIP is also listed for manual flashing.

  3. Connect the player while it is switched off

    Use a data-capable USB cable and connect the player only when the installer asks. Keep it connected until the flash reports success.

  4. Verify the version after it reboots

    Open the player's Settings or About screen and check that it reports Reborn (Y2Linux) 49.

Questions about this update

How do I update Innioasis Y2 to Reborn (Y2Linux) 49?

Download the package for your computer from this page, or open Updater CE and choose Reborn (Y2Linux) 49 for Innioasis Y2. Connect the player while it is switched off, then let the installer finish and let the player reboot.

Is Reborn (Y2Linux) 49 the latest Reborn (Y2Linux) release?

The release list on this page is ordered newest first, so the top entry is the latest published build. Preview and nightly builds are labelled as such.

Can I install Reborn (Y2Linux) 49 from another computer?

Yes. Download the ZIP here, copy it to the computer that can talk to the player, and follow the install guide there. The package is self-contained.

Which file do I download for Windows, macOS or Linux?

Each portable package in the download section is built for one computer. The guide pages linked under "Install on your computer" name the exact file and its size.
