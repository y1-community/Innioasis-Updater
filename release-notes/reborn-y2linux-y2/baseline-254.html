Y2Linux 1.0 Beta 9.3.27: Wi-Fi Share. Copy music onto the player without a cable, from a phone (an iPhone too), a tablet or a computer.

What's new

  • Wi-Fi Share. The player becomes a small website on your home network, with a file browser for Internal Storage and the SD Card. No cable and nothing to install, so it also works from an iPhone, which cannot open the player over USB (#115).
  • How to use it. On the player open Settings → Library → Wi-Fi Share. Scan the QR code with your phone's camera, or type the address shown (such as 192.168.1.23) into a browser on the same Wi-Fi, then enter the six-digit code from the player's screen.
  • What the page can do. Upload files or a whole folder (on a computer you can drop them onto the page), download, rename, delete and make folders. A broken upload leaves no half song, and a file that is already there is kept unless you agree to replace it.
  • When you are done press Back or Stop Sharing. The website is only there while that page is open on the player, and the player stays awake for it. If anything changed, the player looks for new music by itself.

Known issues

  • Wi-Fi Share is new and was only tried from a computer's browser so far. Phones, the QR code, whole folders and very large uploads are unconfirmed. Please tell us how it goes, above all from an iPhone.
  • The connection is not encrypted, and anyone on the same network who sees the code on the player can get in. Use it on your home network, not on public Wi-Fi. Every start has a new code; five wrong codes lock it for half a minute.
  • The player's Wi-Fi is 2.4 GHz: a USB cable is faster for a whole library. A broken upload starts again from the beginning. On a FAT32 card a file can't be larger than 4 GB.
  • Everything listed for Beta 9.3.26 still applies.
  • Something wrong? Send an error report (Settings → System → Error Reports). Restore Previous System (Settings → System → About, tap Version seven times, then Diagnostics) takes you back to the version you had, with your data kept.
