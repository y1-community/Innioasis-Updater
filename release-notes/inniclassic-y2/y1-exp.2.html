Y1 experimental 2 (20261112-exp.2-y1)

Classy build for the Innioasis Y2, formerly Inniclassic for Y2.

y1-exp.2Y22026-11-13Preview buildClassyPlayer/Classy
Get it in Updater CEFirmware Downloads

Experimental build for the Innioasis Y1 (Android 4.2), to collect test results for #82. Only y1-exp.1 has a test on one Y1 Type A. Type B has no test. Do not use it on a Y2.

  • classy-y1-exp.2-type-a.zip (Type A) or classy-y1-exp.2-type-b.zip (Type B): keep the file name. Do not rename it to rom.zip. In Innioasis Updater CE, select Y1, click Install from a file… > Browse Files…, select the zip, and click Install / Restore. If you installed a firmware file before, first click Settings > Clear Firmware Cache.
  • After the first boot, /system/app/com.themoon.y1.apk must be 25,237,181 bytes. If it has a different size, the Updater installed an earlier firmware.
  • y1-logs.sh (macOS, Linux) or y1-logs.bat (Windows): collect the logs and the clock data with adb into one zip file per boot.
  • Do not use Settings → System Update on this build. Do not select Classy in the Updater CE list for the Y1: that is the official release, which needs Android 4.4.
  • To go back: flash the stock Y1 firmware with the Updater.
  • Changes since y1-exp.1: #83 (wheel keylayout, Cut-mode scrolling, library load at boot), main of 2026-11-12 (#84, #88, #89, #90, #91), album thumbnails at background priority. Branch exp/y1-sdk17. Instructions: #82.
