Note: This is a re-release because the old version had broken builds.

Adds a few new features that use the wifi chip:

  • Adds a Podcast Downloader Plugin
  • Extends the Last.fm Scrobble Plugin to directly upload to Last.fm, ListenBrainz and compatible endpoints

More information: INTERNET.md

Also:

  • Adds many plugins
  • Battery optimization: only use wake lock when needed for sleep timers, should increase standby battery life significantly
  • Fixes A-B repeat: start/stop can be triggered using center button in WPS
  • Typo fixes
