Changelog

A lot has happened since v0.2 and Rockbox on the Y1. If you are still running v0.2 you might want to consider updating.

Major Changes

  • Dual Boot Stock OS/Rockbox
  • Type A & Type B support - use Type B if you have click wheel issues
  • 240p and 360p versions
  • Idle Poweroff, Timed Shutdown
  • Lyrics (lrc) support

Improvements for Audiobooks

Playback Speed Setting

  • WPS > hold Center button > Pitch
  • You might need to enable Timestretch in the Sound Settings first if you only see options for pitch, not speed

Automatic Bookmarking

  • Enabling "Bookmark on Stop"
  • To stop press play 3-4 times
  • Or: use Timed Shutdown (General Settings > Startup/Shutdown > Start Sleep Timer)

UI/UX

  • Accessibility: WPS voice announcements
  • Button combination to restart Rockbox if it got stuck
  • Enabled charging indicator
  • Enabled plugin to rearrange Main Menu (Plugins > Applications > main_menu_config)
  • Many button mapping improvements, e.g., for PictureFlow
  • Larger memory allocation for larger themes
  • App only starts when SD is ready, no Rockbox restarts necessary after copying files over or on initial boot
  • Battery optimizations (you may still need to recalibrate your battery after installation https://www.ifixit.com/Wiki/Battery_Calibration#Section_How_to_calibrate_your_battery)

And many bug fixes and general UI/UX improvements. A big thanks to all the contributors on Github!
