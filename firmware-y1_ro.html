Cum se instalează sau se actualizează firmware-ul Y1.

Actualizarea sau deblocarea Innioasis Y1-ului dvs. este simplă cu suita noastră de software multiplatformă:

  1. Deschideți Innioasis Updater CE: Lansați actualizatorul pe macOS, Windows sau Linux.
  2. Selectați modelul Y1: Alege Y1 în meniul derulant Model de dispozitiv.
  3. Alegeți sistemul dvs. de operare: Selectați Rockbox, Better-Y, Solar sau Software original.
  4. Faceți clic pe Instalare: Updater CE descarcă pachetul de firmware direct din versiunea dezvoltatorului. Când vi se solicită, conectați Y1 oprit prin USB pentru a începe să clipească.
