Installationsschritte für Linux Y1.

  1. Öffnen Sie Innioasis Updater CE auf Ihrem Computer (wenn Sie die App benötigen, Updater CE holen). Satz Gerätemodell an Y1.
  2. Wählen Sie Linux für Y1 (Dev) In Software.
  3. Wählen Sie die für Y1 aufgeführte Version aus.
  4. Klicken Sie Installieren / Wiederherstellen.
  5. Schalten Sie das Y1 nur aus und schließen Sie es an, wenn Updater CE dazu fragt.

FAQ

Kann ich die Standard-Y1-Software wiederherstellen?

Ja. Wählen Sie Y1 und Originalsoftware in Updater CE. Die Y1-Aktiensoftware-Leitfaden deckt den Rückweg ab.

Handelt es sich um eine alltägliche Benutzeroberfläche?

Dies ist eine experimentelle Portierung für Entwickler und Linux-Tüftler. Anweisungen zu Terminal und Konsole finden Sie in den Projektdokumenten.
