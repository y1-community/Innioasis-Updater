Feature comparison

FeatureOriginal SoftwareRockbox-Y2
Music libraryFolder and basic tag browsingFull tag database (artist, album, genre, year) + folder view
PlaybackStandard playbackGapless playback, crossfade, ReplayGain, parametric EQ
ThemesBuilt-in factory themesHundreds of custom community themes
FM radioBuilt-in FM radioIncluded on builds/models with FM hardware
Restoring factory OSAlready installedOne-click restore via Original Software in Updater CE

Which should you choose?

  • Choose Rockbox-Y2 if you want gapless playback, custom themes, a faster tag database, and fine-grained audio controls.
  • Choose Original Software if you prefer the simple out-of-the-box factory interface.
  • You can switch back and forth at any time using Innioasis Updater CE.

Frequently asked questions

Does Rockbox browse large music libraries faster?

Yes. Once the tag database is built, scrolling and searching large MicroSD cards is very fast.

Can I switch back to Original Software if I prefer how the player shipped?

Yes. Select Y2 and Original Software in Updater CE to restore factory firmware.
