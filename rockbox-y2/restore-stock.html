Rockbox-Y2 · Innioasis Y2

Undo Rockbox-Y2

You can return your Innioasis Y2 to its factory Original Software at any time using Innioasis Updater CE.

Get it in Updater CEFull written tutorial

Restore Original Software on the Y2

  1. Open Innioasis Updater CE and set Device Model to Y2.
  2. Select Original Software in the Software dropdown.
  3. Pick a stable factory release for the Y2.
  4. Click Install / Restore, power off your player, and connect it when prompted.
  5. Wait for the success message, then disconnect and turn on the player.

For a full walkthrough, see the Y2 Original Software restore guide.

Good to know before restoring

  • Your music files on the MicroSD card are not erased when restoring Original Software.
  • You do not need to delete Rockbox files before flashing Original Software.
  • If the flash does not start when you plug in the player, check our troubleshooting guide.

Frequently asked questions

Does restoring Original Software delete my music?

No. Flashing Original Software updates the internal firmware and leaves your MicroSD card files intact.

Can I install Rockbox-Y2 again later?

Yes. You can switch between Original Software and Rockbox whenever you like.
