Which package should I choose?

  • Install with Updater CE (recommended) — Updater CE downloads the package directly from the developer's release and flashes your Y2 automatically.
  • Developer ROM package (rom_y2.zip) — the firmware ZIP published by the developer for offline archiving or manual installation.
  • Earlier beta builds — browse all versions in the firmware directory.

Current recommended release tag: v0.2.5-beta.

Install with one click in Updater CE

You do not need to download ZIP files manually for a normal install. Open Updater CE, select Y2 and Rockbox, and it will download the release directly from the developer.

Frequently asked questions

Where do Rockbox-Y2 downloads come from?

Updater CE always downloads packages directly from the community firmware developer's releases (spycemagic/y2-rockbox). The developer is solely responsible for listing their releases in Updater CE.

Can I copy the ROM ZIP onto the MicroSD card to install it?

No. Firmware ROM packages are flashed from a computer over USB using Updater CE. See installing from a downloaded ZIP.
