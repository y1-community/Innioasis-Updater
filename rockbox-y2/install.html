Install Rockbox-Y2 on the Innioasis Y2 (Updater CE guide)

Install Rockbox-Y2 on your Innioasis Y2 in six steps with Innioasis Updater CE. Select your model first, choose Rockbox, pick a release, and connect your powered-off player when prompted.

Get it in Updater CEFull written tutorial

Step-by-step installation

  1. Open Innioasis Updater CE and set Device Model to Y2.
  2. Select Rockbox in the Software dropdown.
  3. Pick a stable release (or check Show nightly builds to test a preview).
  4. Click Install / Restore so Updater CE downloads the package directly from the developer's release.
  5. Power the Y2 completely off, then connect it with a USB data cable when Updater CE prompts you.
  6. Wait for the completion message before unplugging and turning on your player.

Why selecting Y2 first matters

Updater CE shows only the firmware listed for the device model you select. Setting Device Model to Y2 ensures you get the Rockbox-Y2 build published by spycemagic/y2-rockbox instead of a Y1 package.

If you already downloaded a ROM ZIP to your computer, see installing from a local ZIP package.

How Updater CE installs the firmware

Updater CE downloads the firmware package directly from the community developer's release (the developer is solely responsible for listing their releases in Updater CE), unpacks it, and flashes your player over USB while the player is powered off.

Frequently asked questions

How long does installing Rockbox-Y2 take?

Once the download finishes, flashing takes only a couple of minutes. Keep the USB cable connected until Updater CE shows the success message.

Do I need to root or unlock the Y2 first?

No. Updater CE flashes the player directly while it is powered off.

Which release should I choose?

Choose the latest stable release for everyday use. Nightly builds are preview releases for testing new changes.
