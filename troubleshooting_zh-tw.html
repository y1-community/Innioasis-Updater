疑難排解

找到安裝停止的點。

停在哪裡了？这会告诉您要修复什么。

返回正常引導檢查韌體

它在 USB 提示符號之前停止

這是計算機問題，而不是電纜問題。檢查您的型號。再次解壓縮文件。然後嘗試 安裝 / 還原。如果發布清單為空，則開啟 韌體目錄.

無法連接到播放器

  1. 完全關閉正確的 Y1 或 Y2 的電源。
  2. 拔下電纜，關閉其他快閃記憶體或 Android 工具，然後重新開始安裝。
  3. 僅當更新程式表示已準備就緒時才連線。
  4. 如果可能，請直接在電腦中使用短的 USB 資料線，而不是集線器。
  5. 在 Windows 上，重新安裝 MediaTek 驅動程式並重新啟動。在 Linux 上，檢查 USB/serial 權限。

偵測到播放器但閃光失敗

停在這裡。不要嘗試不同的模型。關閉其他工具，檢查您選擇了正確的Y1或Y2，如果播放器無法啟動，請使用相符的原始軟體。 SP Flash Tool 和 MTKClient 如果您需要的話，它們也包含在內，並且文件位於 韌體頁面.

Windows 驅動程式註釋

由於核心隔離，某些 Windows 安裝會阻止 MediaTek 驅動程式。在更改記憶體完整性之前，請遵循當前的 Windows 安全指南，並在完成後將其重新開啟（如果系統允許）。
