JJ Launcher Y1 のインストール手順

  1. コンピューターで Innioasis Updater CE を開きます (アプリが必要な場合は、 Updater CE を入手）。セット デバイスモデル 支援先: Y1.
  2. 選択してください JJ Launcher で ソフトウェア.
  3. Y1 に表示されているリリースを選択します。
  4. クリック インストール / 復元.
  5. Updater CE が要求した場合にのみ、電源をオフにして Y1 を接続してください。

よくある質問

Y2 エントリを Y1 にインストールできますか?

いいえ。モデルとパッケージを一致させてください。 Y1 エントリがない場合は、Y2 ファイルを強制的に作成しないでください。

元のソフトウェアに戻すことはできますか?

はい。 Y1 を選択し、Updater CE でオリジナル ソフトウェアを選択します。を参照してください。 Y1 ページの復元.
