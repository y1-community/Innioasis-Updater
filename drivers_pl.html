Większość problemów z połączeniem wynika ze sterownika, uprawnień, kabla lub taktowania. System Windows wymaga zainstalowania sterownika MediaTek. Linux potrzebuje odpowiednich USB uprawnień. Znajdź swoją platformę poniżej.

Pobierz Updater CERozwiązywanie problemów

Okna

  1. Pobierz poniższy instalator sterownika MediaTek.
  2. Uruchom instalator i pozwól systemowi Windows zainstalować sterownik.
  3. Uruchom ponownie komputer.
  4. Otwórz Updater CE i poczekaj na monit o połączenie, zanim podłączysz wyłączony odtwarzacz.

Niektóre systemy Windows blokują sterownik poprzez izolację rdzenia (integralność pamięci). Jeśli Updater CE nadal nie widzi odtwarzacza po ponownym uruchomieniu, wyłącz integralność pamięci w Zabezpieczeniach Windows, uruchom ponownie i ponownie zainstaluj sterownik. Po zakończeniu włącz to ustawienie ponownie, jeśli system na to pozwala.

System Windows nie uruchamia aplikacji? Jeśli zabezpieczenia systemu Windows lub funkcja Smart App Control uniemożliwiają otwarcie narzędzia Updater CE, otwórz Ustawienia (naciskać Win + I) → Prywatność i bezpieczeństwo → Bezpieczeństwo systemu Windows → Kontrola aplikacji i przeglądarki → Ustawienia inteligentnej kontroli aplikacji i ustaw to Wyłączony. Inteligentna kontrola aplikacji ma obecnie wpływ na popularne aplikacje, takie jak Epic Overlay Service (używana przez Fortnite) — Updater CE jest bezpieczny i zweryfikowany. Aby włączyć ponownie później, ustaw VerifiedAndReputablePolicyState do 1 (Wł.) lub 2 (Tryb oceny) pod HKEY_LOCAL_MACHINE\SYSTEM\CurrentControlSet\Control\CI\Policy w Edytorze rejestru.

Uprawnienia w systemie Linux USB

Linux potrzebuje Twojego konta użytkownika, aby móc komunikować się z chipem MediaTek USB wewnątrz odtwarzacza. Updater CE zwykle rozwiązuje ten problem podczas instalacji i te same uprawnienia obejmują SP Flash Tool, więc traktuj to jako krok naprawczy, a nie normalny etap.

  1. Uruchom Updater CE jako zwykły użytkownik, a nie jako root. Instalator prosi o dostęp administratora tylko wtedy, gdy tego potrzebuje.
  2. Sprawdź, czy odtwarzacz jest w ogóle widoczny. Wyłącz odtwarzacz, podłącz kabel i uruchom polecenie lsusb w terminalu. Podłączony odtwarzacz pojawia się jako urządzenie MediaTek z identyfikatorem dostawcy 0e8d.
lsusb
  1. Jeśli pojawia się w lsusb, ale Innioasis Updater CE lub SP Flash Tool wyświetla komunikat odmowy uprawnień lub nie może otworzyć portu, oznacza to, że Twój użytkownik nie ma dostępu do urządzenia USB. Ta sama reguła udev dotyczy obu narzędzi, więc dodaj takie, które pozwoli grupie użytkowników je przeczytać.
SUBSYSTEM=="usb", ATTR{idVendor}=="0e8d", MODE="0666", GROUP="plugdev"

Zapisz tę linię w nowym pliku o nazwie /etc/udev/rules.d/51-innioasis.rules, a następnie uruchom:

sudo udevadm control --reload && sudo udevadm trigger
  1. Odłącz całkowicie odtwarzacz, podłącz go ponownie i ponów próbę instalacji.
  2. Jeśli SP Flash Tool zgłosi pozwolenie na port szeregowy lub wyścig portów, odłącz całkowicie i podłącz ponownie tylko po wyświetleniu monitu.
