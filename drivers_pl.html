Konfiguracja komputera

Najpierw przygotuj komputer, dopiero potem odtwarzacz.

Większość problemów z połączeniem wynika ze sterownika, uprawnień, kabla albo momentu podłączenia. Windows wymaga zainstalowanego sterownika MediaTek. Linux wymaga odpowiednich uprawnień USB. Poniżej znajdź swój system.

Pobierz Updater CERozwiązywanie problemów

Windows

  1. Pobierz poniższy instalator sterownika MediaTek.
  2. Uruchom instalator i zezwól Windowsowi na zainstalowanie sterownika.
  3. Uruchom komputer ponownie.
  4. Otwórz Updater CE i poczekaj na prośbę o podłączenie, zanim podłączysz wyłączony odtwarzacz.

Niektóre systemy Windows blokują sterownik przez izolację rdzenia (Integralność pamięci). Jeśli po restarcie Updater CE nadal nie widzi odtwarzacza, wyłącz Integralność pamięci w Zabezpieczeniach Windows, uruchom komputer ponownie i zainstaluj sterownik jeszcze raz. Po zakończeniu włącz to ustawienie z powrotem, jeśli system na to pozwala.

Windows nie uruchamia aplikacji? Jeśli Zabezpieczenia Windows lub Smart App Control uniemożliwiają otwarcie Updater CE, otwórz Ustawienia (naciśnij Win + I) → Prywatność i bezpieczeństwo → Windows Security → Sterowanie aplikacją i przeglądarką → Ustawienia Smart App Control i ustaw na Wyłączone. Smart App Control obecnie utrudnia działanie popularnych aplikacji, np. Epic Overlay Service (używanej przez Fortnite) – Updater CE jest bezpieczny i zweryfikowany. Żeby włączyć go ponownie później, ustaw VerifiedAndReputablePolicyState do 1 (włączone) lub 2 (tryb oceny) w sekcji HKEY_LOCAL_MACHINE\SYSTEM\CurrentControlSet\Control\CI\Policy w Edytorze rejestru.

Uprawnienia USB w systemie Linux

Linux musi pozwolić Twojemu kontu użytkownika na komunikację z układem USB MediaTek w odtwarzaczu. Updater CE zwykle ustawia to podczas instalacji, a to samo uprawnienie obejmuje SP Flash Tool, więc traktuj ten krok jako naprawczy, a nie zwykły etap.

  1. Uruchamiaj Updater CE jako zwykły użytkownik, nie jako root. Instalator poprosi o uprawnienia administratora tylko wtedy, gdy będą potrzebne.
  2. Sprawdź, czy odtwarzacz jest w ogóle widoczny. Wyłącz odtwarzacz, podłącz kabel i uruchom w terminalu polecenie lsusb. Podłączony odtwarzacz pojawia się jako urządzenie MediaTek z identyfikatorem producenta 0e8d.
lsusb
  1. Jeśli odtwarzacz widać w lsusb, ale Innioasis Updater CE lub SP Flash Tool zgłasza brak uprawnień (permission denied) lub nie może otworzyć portu, Twój użytkownik nie ma dostępu do urządzenia USB. Ta sama reguła udev obejmuje oba narzędzia, więc dodaj taką, która pozwala czytać je grupie users.
SUBSYSTEM=="usb", ATTR{idVendor}=="0e8d", MODE="0666", GROUP="plugdev"

Zapisz tę linijkę w nowym pliku o nazwie /etc/udev/rules.d/51-innioasis.rules, a następnie uruchom:

sudo udevadm control --reload && sudo udevadm trigger
  1. Całkowicie odłącz odtwarzacz, podłącz go ponownie i spróbuj zainstalować jeszcze raz.
  2. Jeśli SP Flash Tool zgłasza brak uprawnień do portu szeregowego lub konflikt dostępu do portu, całkowicie odłącz kabel i podłącz ponownie dopiero po wyświetleniu monitu.

Kabel i moment podłączenia

  1. Użyj sprawdzonego kabla USB do transmisji danych.
  2. Podczas rozwiązywania problemów unikaj hubów USB.
  3. Całkowicie wyłącz odpowiedni model.
  4. Podłącz dopiero po wyświetleniu komunikatu.
