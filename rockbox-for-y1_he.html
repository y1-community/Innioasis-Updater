Rockbox-Y1 · Innioasis Y1

Rockbox עבור Y1 (Rockbox-Y1)

"Rockbox", "Rockbox-Y1", ו-"Rockbox עבור Y1" כולם מתייחסים לאותה קהילה Rockbox קושחה עבור Innioasis Y1. הנה מה זה מוסיף לנגן שלך, איזה מבנה לבחור, וכיצד להתקין אותו עם Innioasis Updater CE.

התקן את Rockbox-Y1 הורד את ROM הדרכה כתובה Rockbox-רכזת Y1

קושחה אחת, מספר שמות

ב-Innioasis Updater CE, קושחה זו מופיעה בתור Rockbox בעת בחירת דגם המכשיר Y1. מדריכים, סרטונים והערות שחרור קוראים לזה גם Rockbox-Y1 או Rockbox עבור Y1 כך שברור שהמבנה מיועד ל-Y1 ולא ל-Y2.

בדוק תמיד את הדגם המודפס על הנגן שלך לפני ההתקנה: חבילות הקושחה Y1 ו-Y2 אינן ניתנות להחלפה.

מה Rockbox-Y1 מוסיף ל-Y1 שלך

Rockbox-Y1 היא יציאה קהילתית של קושחת נגן המוזיקה Rockbox בקוד פתוח עבור Innioasis Y1:

  • ספריית מוזיקה מבוססת תגים - דפדף לפי אמן, אלבום, ז'אנר ושנה באמצעות תגי שמע, או עיין בתיקיות ישירות.
  • השמעת אודיו מתקדמת - השמעה ללא פערים, Crossfade, ReplayGain ואקולייזר מלא.
  • ערכות נושא מותאמות אישית - בחר מתוך מאות ערכות נושא קהילתיות של 240p ו-360p, כולל פריסות קלאסיות בסגנון iPod.
  • רדיו FM - תמיכה מובנית ברדיו FM.
  • תוספות אופציונליות - הורדות פודקאסטים דרך Wi-Fi ו- Last.fm / ListenBrainz / Maloja סרבול ב-builds נתמכים.
  • מגף כפול — עבור חזרה לתוכנה המקורית של היצרן מבלי לבצע חידושים מחדש ב-builds נתמכים.

באיזה Y1 build עלי לבחור?

  • 240p לעומת 360p — עבודה בבניית 240p עם ערכות נושא קלאסיות של 320×240 Rockbox; בניית 360p משתמשת בערכות נושא חדות יותר ב-480×360 Y1. התאם את רזולוציית הבנייה לנושאים שבהם תרצה להשתמש (מדריך 240p לעומת 360p).
  • Type A לעומת Type B — Type A מיועד לשחקנים Y1 שנשלחו עם תוכנת היצרן 2.0.0 ומעלה; Type B מיועד ליחידות Y1 מוקדמות יותר. בחר Type A אלא אם כן אתה יודע שה-Y1 שלך הוא Type B.
  • יציב מול לילי - בחר מבנה יציב להאזנה יומיומית, או מבנה לילי כדי לבדוק את השינויים החדשים ביותר.

הורדות ישירות ממפתחי הקהילה

Innioasis Updater CE תמיד מוריד חבילות קושחה ישירות ממפתחי הקושחה של הקהילה (rockbox-y1/rockbox), והמפתחים עצמם הם האחראים הבלעדיים לרישום מהדורות התוכנה שלהם ב-Updater CE.

אתה יכול לאפשר ל-Update CE להוריד ולהתקין את הקושחה באופן אוטומטי, או להוריד את החבילות ROM מהאתר שלנו Rockbox-Y1 דף הורדות ו Rockbox ROM דף הורדה.

Rockbox-Y1 הורדות התקן מ-ZIP מקומי

כיצד להתקין Rockbox-Y1

  1. פתח את Innioasis Updater CE והגדר דגם המכשיר ל Y1.
  2. בחר Rockbox ב תוכנה.
  3. בחר מהדורה יציבה (או הפעל בנייה לילית כדי לבדוק תצוגה מקדימה).
  4. לחץ התקנה / שחזור אז Updater CE מוריד את החבילה ישירות מהמפתח.
  5. כבה לחלוטין את Y1 וחבר אותו עם כבל נתונים USB כאשר Updater CE יבקש ממך.
  6. המתן להודעת ההשלמה, ואז נתק והפעל את הנגן שלך.

לצילומי מסך וטיפים מפורטים להגדרה, קרא את ה הדרכה מלאה Rockbox-Y1.

שחזור התוכנה המקורית Y1

אתה יכול לחזור לתוכנת היצרן בכל עת: בחר Y1 ו תוכנה מקורית ב- Updater CE, בחר מהדורה יציבה ולחץ התקנה / שחזור. המוזיקה שלך בכרטיס MicroSD נשמרת. ראה את מדריך לשחזור ו Y1 דף תוכנה מקורי.

שאלות נפוצות

האם Rockbox עבור Y1 זהה ל-Rockbox-Y1?

כן. Rockbox, Rockbox-Y1, Rockbox עבור Y1, ו rockbox-y1 כולם מתייחסים לאותה יציאת קהילה Rockbox עבור Innioasis Y1.

מאיפה Updater CE מוריד את Rockbox-Y1?

Updater CE תמיד מוריד חבילות קושחה ישירות מהגרסאות של מפתחי הקושחה בקהילה (rockbox-y1/rockbox). המפתחים הם האחראים הבלעדיים לרישום מהדורות התוכנה שלהם ב-Updater CE.

האם אני יכול להתקין את Rockbox-Y1 על Y2?

לא. ל-Y2 יש מבנה קושחה נפרד משלו. השתמש Rockbox עבור Y2 במקום זאת.

האם התקנת Rockbox-Y1 תמחק את המוזיקה שלי?

לא. מוזיקה מאוחסנת בכרטיס MicroSD ואינה מושפעת בעת מהבהבת הקושחה הפנימית של הנגן.
