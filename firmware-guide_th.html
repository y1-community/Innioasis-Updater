    Windows won't launch the app? How to turn off Smart App Control

    Windows Defender SmartScreen หรือ Smart App Control สามารถบล็อกแอปพลิเคชันชุมชนที่ดาวน์โหลดใหม่ก่อนที่จะเผยแพร่ชื่อเสียงของลายเซ็น ขณะนี้การควบคุมแอปอัจฉริยะกำลังส่งผลกระทบต่อแอปพลิเคชันยอดนิยม เช่น Epic Overlay Service (ใช้โดย Fortnite) — Updater CE ปลอดภัยและตรวจสอบแล้วว่าใช้งานได้ การปิดการควบคุมแอปอัจฉริยะทำให้ Updater CE สามารถเปิดและทำงานได้ตามปกติ

    1. เปิด การตั้งค่า on your Windows PC (press Win + I).
    2. คลิก Privacy & security in the left sidebar, then click Windows Security.
    3. คลิก App & browser control.
    4. ภายใต้ Smart App Control, click Smart App Control settings.
    5. Set the toggle to ปิด to allow Updater CE to launch.

    บล็อกโดย Edge? If Microsoft Edge blocks the download itself, click the More options button (…) → Keep → Show more → Keep anyway.

    Re-enabling Smart App Control later: When you want to turn Smart App Control back on, you can re-enable it via the Windows Registry under HKEY_LOCAL_MACHINE\SYSTEM\CurrentControlSet\Control\CI\Policy by setting VerifiedAndReputablePolicyState ถึง 1 (On) or 2 (Evaluation Mode) and restarting.
