    Windows

    ดาวน์โหลดตัวติดตั้ง เปิดและปฏิบัติตามคำแนะนำในการตั้งค่า

    ดาวน์โหลดและติดตั้งไดรเวอร์ดาวน์โหลดแอพและไดรเวอร์บล็อกโดย Edge?

    หาก Windows หยุดคุณไม่ให้เรียกใช้แอปหรือไม่เปิดใช้งาน โปรดเปิดการตั้งค่า คลิกความเป็นส่วนตัวและความปลอดภัย → ความปลอดภัยของ Windows → การควบคุมแอปและเบราว์เซอร์ และปิดการควบคุมแอปอัจฉริยะ Windows จะไม่เปิดแอปใช่ไหม ช่วย

    คุณจะต้องรีบูทพีซีของคุณหลังจากติดตั้งเพื่อให้ทำงานได้

    เปิดการเปรียบเทียบแบบเต็ม

    Windows จะไม่เปิดแอปใช่ไหม วิธีปิดการควบคุมแอปอัจฉริยะ

    Windows Defender SmartScreen หรือ Smart App Control สามารถบล็อกแอปพลิเคชันชุมชนที่ดาวน์โหลดใหม่ก่อนที่จะเผยแพร่ชื่อเสียงของลายเซ็น ขณะนี้การควบคุมแอปอัจฉริยะกำลังส่งผลกระทบต่อแอปพลิเคชันยอดนิยม เช่น Epic Overlay Service (ใช้โดย Fortnite) — Updater CE ปลอดภัยและตรวจสอบแล้วว่าใช้งานได้ การปิดการควบคุมแอปอัจฉริยะทำให้ Updater CE สามารถเปิดและทำงานได้ตามปกติ

    1. เปิด การตั้งค่า บนพีซี Windows ของคุณ (กด Win + I).
    2. คลิก ความเป็นส่วนตัวและความปลอดภัย ในแถบด้านข้างซ้าย จากนั้นคลิก Windows Security.
    3. คลิก การควบคุมแอปและเบราว์เซอร์.
    4. ภายใต้ การควบคุมแอปอัจฉริยะคลิก การตั้งค่าการควบคุมแอปอัจฉริยะ.
    5. ตั้งค่าสลับเป็น ปิด เพื่อให้ Updater CE สามารถเปิดใช้งานได้

    บล็อกโดย Edge? หาก Microsoft Edge บล็อกการดาวน์โหลด ให้คลิกปุ่มตัวเลือกเพิ่มเติม (…) → เก็บ → แสดงเพิ่มเติม → ยังไงก็เก็บไว้.

    เปิดใช้งานการควบคุมแอปอัจฉริยะอีกครั้งในภายหลัง: เมื่อคุณต้องการเปิด Smart App Control อีกครั้ง คุณสามารถเปิดใช้งานได้อีกครั้งผ่านทาง Windows Registry ที่อยู่ด้านล่าง HKEY_LOCAL_MACHINE\SYSTEM\CurrentControlSet\Control\CI\Policy โดยการตั้งค่า VerifiedAndReputablePolicyState ถึง 1 (เปิด) หรือ 2 (โหมดการประเมินผล) และรีสตาร์ท
