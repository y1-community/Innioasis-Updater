הגדרת מחשב

הכינו את המחשב לפני הנגן.

רוב בעיות החיבור נובעות מהנהג, ההרשאות, הכבל או התזמון. Windows צריך להתקין את מנהל ההתקן MediaTek. לינוקס צריכה את ההרשאות הנכונות USB. מצא את הפלטפורמה שלך למטה.

הורדת Updater CEפתרון תקלות

Windows

  1. הורד את מתקין מנהל ההתקן MediaTek למטה.
  2. הפעל את תוכנית ההתקנה ואפשר ל-Windows להתקין את מנהל ההתקן.
  3. הפעל מחדש את המחשב.
  4. פתח את Updater CE והמתן להנחיית החיבור לפני שתחבר את הנגן הכבוי.

חלק ממערכות Windows חוסמות את מנהל ההתקן באמצעות בידוד ליבה (שלמות זיכרון). אם Updater CE עדיין לא יכול לראות את הנגן לאחר הפעלה מחדש, כבה את שלמות הזיכרון באבטחת Windows, הפעל מחדש והתקן מחדש את מנהל ההתקן. הפעל שוב את ההגדרה כשתסיים אם המערכת שלך מאפשרת זאת.

Windows לא יפעיל את האפליקציה? אם Windows Security או Smart App Control עוצרים את פתיחת Updater CE, פתח הגדרות (לחץ Win + I) → פרטיות ואבטחה → Windows Security → שליטה באפליקציה ובדפדפן → הגדרות בקרת אפליקציה חכמה והגדר אותו ל כבוי. בקרת אפליקציות חכמה משפיעה כעת על יישומים פופולריים כמו שירות ה-Epic Overlay (בשימוש על ידי Fortnite) - Updater CE בטוח ומאומת לשימוש. כדי להפעיל מחדש מאוחר יותר, הגדר VerifiedAndReputablePolicyState ל 1 (מופעל) או 2 (מצב הערכה) תחת HKEY_LOCAL_MACHINE\SYSTEM\CurrentControlSet\Control\CI\Policy בעורך הרישום.

הרשאות לינוקס USB

לינוקס צריך שחשבון המשתמש שלך יורשה לדבר עם השבב MediaTek USB בתוך הנגן. Updater CE בדרך כלל מסדר את זה במהלך ההתקנה, ואותה הרשאה מכסה את SP Flash Tool, אז התייחס לזה כשלב תיקון ולא כשלב רגיל.

  1. הפעל את Updater CE כמשתמש הרגיל שלך, לא כשורש. המתקין מבקש גישת מנהל רק כאשר הוא זקוק לה.
  2. בדוק שהשחקן נראה בכלל. כבה את הנגן, חבר את הכבל והפעל את הפקודה lsusb במסוף. נגן מחובר מופיע כהתקן MediaTek עם מזהה הספק 0e8d.
lsusb
  1. אם זה מופיע ב-lsusb אבל Innioasis Updater CE או SP Flash Tool אומרים שההרשאה נדחתה או לא יכול לפתוח את היציאה, למשתמש שלך חסרה גישה למכשיר USB. אותו כלל udev מכסה את שני הכלים, אז הוסף אחד שמאפשר לקבוצת המשתמשים לקרוא אותו.
SUBSYSTEM=="usb", ATTR{idVendor}=="0e8d", MODE="0666", GROUP="plugdev"

שמור את השורה בקובץ חדש בשם /etc/udev/rules.d/51-innioasis.rules, ולאחר מכן הרץ:

sudo udevadm control --reload && sudo udevadm trigger
  1. נתק את הנגן במלואו, חבר אותו בחזרה ונסה להתקין שוב.
  2. אם SP Flash Tool מדווח על הרשאה טורית או מרוץ יציאה, נתק לחלוטין מהחשמל והתחבר מחדש רק כאשר תתבקש.
אין לאלתר קיזוז הבזק.אם אתה עובר לכלי שחזור ידני, השתמש בקבצים ובתצורה הספציפית לדגם שנשלחו עם הפרויקט.
