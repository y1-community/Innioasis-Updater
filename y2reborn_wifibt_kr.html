왜 이 파일인가요?

Wi-Fi, Bluetooth 및 FM 라디오에는 Reborn 배송할 수 없는 5개의 MediaTek 펌웨어 모듈이 필요합니다. 공식 Y2 내부에 있습니다. system.img. Reborn 한번 추출해서 확인한 후 파일을 삭제합니다.

설정

  1. system.img 다운로드

    v3.2.0 FM 다운로드 system.img 당신의 컴퓨터에.

    system.img 다운로드
  2. Reborn을 한 번 부팅

    플레이어를 켜십시오. 기다려 저장소 설정 완료한 다음 한 번 다시 시작하세요.

  3. 컴퓨터에 연결

    USB 데이터 케이블을 사용하세요. 플레이어가 다음과 같이 나타납니다. 내부 저장소.

    Mac에서?

    설치 오픈MTP 플레이어를 탐색합니다. Windows 및 Linux에서는 자동으로 마운트됩니다.

  4. system.img를 펌웨어에 복사

    라는 폴더를 만듭니다. Firmware 내부 저장소의 루트에 있습니다. 복사 system.img 그것에.

  5. 설정이 완료될 때까지 기다리세요

    Reborn 라디오 펌웨어를 자동으로 설치하고 삭제합니다. system.img. 이 작업은 약 10~20초 정도 소요됩니다. 기다려 Wi-Fi와 블루투스가 준비되었습니다..

  6. Wi-Fi, Bluetooth, FM 라디오 연결
    • Wi-Fi: 설정 → 시스템 → 네트워크 → Wi-Fi. 2.4GHz 네트워크를 선택하세요.
    • 블루투스: 헤드폰을 페어링 모드로 전환하세요. 설정 → 블루투스 → 선택하세요.
    • FM 라디오: 유선 헤드폰을 안테나로 연결한 다음 FM 라디오를 엽니다.
  7. Wi-Fi를 통한 업데이트

    향후 Reborn 업데이트는 설정 → 시스템 → 소프트웨어 업데이트에서 설치됩니다. 라디오 펌웨어는 그대로 유지됩니다.
