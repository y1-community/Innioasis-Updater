    Få Innioasis Updater CE

    Innioasis Oppdaterer CE er appen som installerer offisielle oppdateringer og fellesskapsprogramvare på spilleren din. Den beholder musikken og innstillingene dine, og den kjører på Windows, macOS og Linux.

    Windows

    Last ned installasjonsprogrammet, kjør det og start PC-en på nytt når det er ferdig.

    Skaff deg drivereLast ned Updater CE

    Hvis Windows stopper deg fra å kjøre appen eller ikke starter den, åpner du Innstillinger, klikker på Personvern og sikkerhet → Windows Sikkerhet → App- og nettleserkontroll, og slår av Smart App Control. Smart App Control påvirker for tiden populære applikasjoner som Epic Overlay Service (brukt av Fortnite) - Updater CE er trygg og verifisert å bruke. Vil ikke Windows starte appen? Hjelp

    Start PC-en på nytt etter installasjon. Sjåførhjelp er i Windows-oppsettnotater.

    macOS

    Last ned Updater CE

    Hvis Mac-en din stopper deg fra å kjøre appen for første gang, vennligst åpne Systeminnstillinger, klikk på Personvern og sikkerhet, bla ned til Sikkerhet og klikk Åpne uansett. Du kan også Ctrl-klikke (eller høyreklikke) appen i Finder og velge Åpne.

    Fungerer på Intel og Apple Silicon Mac-maskiner med macOS Monterey og nyere.

    Linux

    Last ned AppImage for Intel- og AMD-systemer, gjør det kjørbart og kjør det.

    Notater om Linux-oppsett

    Du trenger spilleren din, en USB datakabel som bærer data (en kabel som kun kan lades kan ikke installeres), og noen få minutter. Hold kabelen tilkoblet til Updater CE sier at det er gjort.

    Velg modell og programvare

    1. Enhetsmodell: velg modellen som er trykt på spilleren, Y1 eller Y2. Programvare laget for én modell kan ikke installeres på den andre.
    2. Programvare og utgivelse: velg Original Software, Rockbox, Solar, JJ Launcher, Inniclassic, Y2Player, eller Koensayr når den er oppført for modellen din, og velg deretter en utgivelse. Stall er det sikre valget.
    3. Installer: klikk Installer / Gjenopprett, slå spilleren helt av og koble til USB-kabelen bare når Updater CE ber om det.
    4. Fullfør: la spilleren og kabelen være i fred frem til suksessmeldingen, koble deretter fra og start spilleren.

    Y1 spillere som ble levert med original programvare før 2.0.0 trenger Enhet Type B. Alle andre beholder standard Type A.

    Går tilbake til original programvare

    Tilpasset programvare er reversibel. I Updater CE, velg din modell, velg Original programvare, velg en stabil utgivelse, og løp Installer / Gjenopprett på samme måte. Det er ingenting å slette for hånd.

    Vil ikke Windows starte appen? Løsning for smart appkontroll

    Windows Defender SmartScreen eller Smart App Control kan blokkere nylig nedlastede fellesskapsapplikasjoner før signaturomdømmet sprer seg. Smart App Control påvirker for tiden populære applikasjoner som Epic Overlay Service (brukt av Fortnite) - Updater CE er trygg og verifisert å bruke. Ved å slå av Smart App Control kan Updater CE åpne og kjøre normalt.

    1. Åpne Innstillinger på din Windows-PC (trykk Win + I).
    2. Klikk Personvern og sikkerhet i venstre sidefelt, og klikk deretter Windows Security.
    3. Klikk App- og nettleserkontroll.
    4. Under Smart appkontroll, klikk Smart App Control-innstillinger.
    5. Sett bryteren til Av for å la Updater CE starte.

    Lastet ned via Edge? Hvis Edge blokkerer selve nedlastingen, klikker du på knappen Flere alternativer (…) → Behold → Vis mer → Behold uansett.

    Aktiverer Smart App Control på nytt senere: Når du vil slå på Smart App Control igjen, kan du aktivere den på nytt via Windows-registeret under HKEY_LOCAL_MACHINE\SYSTEM\CurrentControlSet\Control\CI\Policy ved innstilling VerifiedAndReputablePolicyState til 1 (På) eller 2 (Evalueringsmodus) og omstart.
