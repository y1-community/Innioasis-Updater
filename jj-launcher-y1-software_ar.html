JJ Launcher Y1 install steps

  1. افتح Innioasis Updater CE على جهاز الكمبيوتر الخاص بك (إذا كنت بحاجة إلى التطبيق، احصل على Updater CE). تعيين طراز الجهاز ل Y1.
  2. اختر JJ Launcher في البرنامج.
  3. Choose the release shown for Y1.
  4. انقر تثبيت / استعادة.
  5. قم بإيقاف تشغيل Y1 وتوصيله فقط عندما يطلب منك Updater CE.

الأسئلة الشائعة

Can I install the Y2 entry on a Y1?

No. Keep the model and package matched. If the Y1 entry is missing, do not force a Y2 file.

Can I go back to the original software?

Yes. Choose Y1 and Original Software in Updater CE. See the Y1 restore page.

Where are all the JJ Launcher releases?

Current builds are in تنزيلات البرامج. Release notes are on the project’s release notes.

Computer setup

Updater can be used on Windows, macOS, and Linux once the relevant setup is ready. Start with the platform guide.
